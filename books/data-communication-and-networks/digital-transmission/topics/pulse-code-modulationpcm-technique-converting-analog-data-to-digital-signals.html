What is Pulse Code Modulation(PCM) technique converting analog data to digital signals?

Pulse Code Modulation is a standard technique for converting analog signals to digital form by sampling the analog waveform at regular intervals, quantizing each sample to the nearest discrete level, and encoding those levels into binary digits.
