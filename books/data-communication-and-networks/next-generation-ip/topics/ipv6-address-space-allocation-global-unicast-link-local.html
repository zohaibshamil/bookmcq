Q1. If a network administrator changes the subnet mask from \(255.255.255.0\) (/24) to \(255.255.255.192\) (/26), what is the most direct effect on the number of usable host addresses per subnet?

🔹 A. Increases the number of usable hosts per subnet
🔹 B. Decreases the number of usable hosts per subnet
🔹 C. Leaves the number of usable hosts unchanged
🔹 D. Converts the subnet into a class B network

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Changing from /24 to /26 adds two subnet bits, reducing the host portion from 8 bits to 6 bits. This yields \(2^{6}-2 = 62\) usable hosts per subnet, down from \(2^{8}-2 = 254\). Hence the number of usable host addresses per subnet decreases.

Q2. Given that a backbone ISP allocates a /16 block to a regional ISP, and the regional ISP further subdivides it into /20 subnets, what can be inferred about the maximum number of /20 subnets the regional ISP can create?

🔹 A. 4
🔹 B. 8
🔹 C. 12
🔹 D. 16

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

A /16 mask has 16 network bits. Moving to /20 adds 4 more bits for subnetting, allowing \(2^{4}=16\) distinct /20 subnets. This is the theoretical maximum the regional ISP can create from the original /16 allocation.

Q3. Assume an ISP uses classful addressing and assigns a Class B address (255.255.0.0) to a customer network that only needs 200 hosts. What logical problem arises, and how does it affect the overall address space efficiency?

🔹 A. No problem; classful addressing always fits any size
🔹 B. The ISP wastes address space by allocating far more addresses than needed
🔹 C. The ISP must split the network into multiple Class C blocks
🔹 D. The ISP cannot assign a Class B address to a network requiring fewer than 256 hosts

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A Class B block provides \(2^{16}-2 = 65,534\) usable addresses, far exceeding the 200‑host requirement. This over‑allocation leads to significant address waste, reducing overall efficiency and limiting the pool of available addresses for other customers.

Q4. If BGP selects a path with a lower AS_PATH length but traverses an ISP that uses a /22 address block, what is the likely impact on the end‑to‑end address allocation for the destination network?

🔹 A. The destination network will receive a larger address block
🔹 B. The address block size remains unchanged, but routing efficiency improves
🔹 C. The destination may experience address fragmentation due to smaller ISP block
🔹 D. The destination network must change its subnet mask to /22

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The chosen path passes through an ISP that only advertises a /22 prefix, which is relatively small. While BGP prefers the shorter AS_PATH, the limited address block can cause the destination network to be confined within that /22, leading to fragmentation relative to larger aggregates.

Q5. Consider an ISP that aggregates multiple /24 customer subnets into a single /20 advertisement. If one customer later requires a /23 subnet, what logical change must the ISP make to maintain correct routing without losing address aggregation benefits?

🔹 A. Re‑advertise the /20 as separate /24s
🔹 B. Split the /20 into two /21s and allocate one /23 within a /21
🔹 C. Keep the /20 unchanged; the /23 will be implicitly covered
🔹 D. Increase the advertised prefix to /19

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A /23 cannot be cleanly represented inside the original /20 without breaking the aggregation. By splitting the /20 into two /21s, the ISP can assign one /21 to the customer and carve a /23 within it, preserving as much aggregation as possible while supporting the larger subnet.

Q6. When a provider network reduces its advertised prefix from /18 to /20, what is the immediate effect on the number of host addresses available to downstream customer networks?

🔹 A. Increases available host addresses per customer
🔹 B. Decreases available host addresses per customer
🔹 C. No effect on host addresses, only on routing table size
🔹 D. Forces customers to use NAT

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Moving from /18 to /20 adds two subnet bits, reducing the host portion by two bits. This cuts the number of usable host addresses per downstream subnet from \(2^{14}-2\) to \(2^{12}-2\), directly decreasing the address space each customer can utilize.

Q7. If an organization moves from a /24 subnet to a /26 subnet, what happens to the number of subnets it can create within the original /24 block?

🔹 D. It can create 16 subnets

📖 Explanation:

A /24 to /26 shift adds two additional subnet bits. The original /24 can therefore be divided into \(2^{2}=4\) equal /26 subnets, each containing 62 usable host addresses.

Q9. Which of the following best compares the address utilization efficiency between classful addressing and CIDR (Classless Inter‑Domain Routing)?

🔹 A. Classful provides higher efficiency because it uses fixed sizes
🔹 B. CIDR provides higher efficiency by allowing variable‑length subnets
🔹 C. Both have equal efficiency in modern networks
🔹 D. Classful is more efficient for small networks only

📖 Explanation:

CIDR permits variable‑length subnet masks, enabling networks to allocate address space that closely matches host requirements. Classful schemes assign fixed‑size blocks regardless of need, often resulting in unused addresses and lower overall utilization.

Tier‑1 providers possess vast address pools and can perform extensive aggregation, offering more flexibility. Regional ISPs typically receive delegated blocks from upstream providers and must work within those constraints, limiting their ability to aggregate and affecting allocation efficiency.

Q12. Compare the impact on routing table size when an ISP advertises multiple /24 prefixes versus a single aggregated /20 prefix. Which outcome is more likely?

🔹 A. Advertising multiple /24s reduces routing table size
🔹 B. Advertising a single /20 increases routing table size
🔹 C. Advertising multiple /24s increases routing table size
🔹 D. Both approaches result in identical routing table sizes

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Each /24 prefix appears as a separate entry in neighboring routing tables, increasing the total number of entries. Aggregating those prefixes into a single /20 reduces the number of distinct entries, thereby decreasing the size of routing tables.

Giving an ISP a large, contiguous block eases routing and aggregation but can quickly deplete the global address pool if many ISPs request oversized blocks, limiting the ability to allocate addresses to new networks.

Q14. Which statement correctly differentiates the role of a peering point from that of a backbone in address space allocation?
