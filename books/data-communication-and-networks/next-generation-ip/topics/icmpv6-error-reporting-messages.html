What is ICMPv6 error reporting messages?

ICMPv6 error messages notify senders about problems encountered during packet delivery, including destination unreachable, packet too big, time exceeded, and parameter problem errors, which help diagnose network issues and support path MTU discovery in IPv6.

Q1. If a router does not receive any update for a route within the expiration interval, what immediate action does RIP take regarding that route’s metric?

A.Metric is set to 0
B.Metric is set to 16 ✅
C.Metric is unchanged
D.Route is deleted instantly
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When the expiration timer reaches zero, RIP treats the route as timed‑out and sets its metric to 16, which represents an infinite distance, signaling that the destination is unreachable. The route remains in the table and continues to be advertised with this metric until the garbage‑collection timer later removes it.

Q2. Suppose Router A’s expiration timer for a route expires exactly when Router B’s garbage‑collection timer for the same route reaches zero. What is the most likely effect on neighboring routers’ view of that route?

A.Neighbors will see the route as reachable with metric 1
B.Neighbors will receive a metric of 16 for a brief period ✅
C.The route will be removed without any metric advertisement
D.Neighbors will ignore the update
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When the expiration timer expires, the route is marked unreachable and advertised with metric 16. If the garbage‑collection timer also reaches zero at that moment, the router still sends the metric‑16 advertisement before purging the entry, so neighbors briefly observe the route as unreachable before it disappears from their tables.

Q3. Consider two adjacent routers that have their update timers synchronized such that both send full routing updates at the same instant every 35 seconds. How does this synchronization impact network convergence compared to the randomized timer approach described in RIP?

A.Convergence speeds up because updates are simultaneous
B.Convergence slows due to temporary routing loops
C.No effect on convergence
D.Increases likelihood of count‑to‑infinity problems ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Simultaneous updates create a burst of identical information, which can mask failures and cause routers to rely on stale data longer. This synchronization raises the chance that a failed link is not detected promptly, fostering count‑to‑infinity situations and therefore slowing overall convergence compared with the randomized approach that spreads updates over time.

Q4. Which statement correctly contrasts the purposes of the expiration timer and the garbage‑collection timer in RIP?

A.Expiration timer deletes the route, garbage‑collection timer marks it unreachable
B.Expiration timer marks route unreachable, garbage‑collection timer eventually removes it ✅
C.Both timers perform identical functions
D.Expiration timer only applies to directly connected routes
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The expiration timer is triggered when no update is received within its interval; it changes the route’s metric to 16, indicating unreachability. The garbage‑collection timer then starts, counting down a fixed period (typically 120 seconds) before the route entry is finally removed from the forwarding table.

Q5. If the expiration timer were increased from 180 seconds to 300 seconds while keeping the garbage‑collection timer at 120 seconds, what is the most probable impact on network stability after a link failure?

A.Faster detection of failures
B.Slower detection but longer retention of stale routes ✅
C.No change in detection speed
D.Immediate route removal
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A longer expiration interval means routers will wait longer before declaring a route invalid, so the failure is detected more slowly. However, once the route is marked unreachable, the existing 120‑second garbage‑collection timer still controls removal, causing stale (but unreachable) entries to persist for a greater overall period, which can reduce stability.

Q6. How does the combination of split‑horizon with poison‑reverse and the 180‑second expiration timer work together to mitigate the count‑to‑infinity problem in RIP?

A.Poison‑reverse forces a metric of 16 to be advertised, preventing loops, while the expiration timer removes stale routes ✅
B.Split‑horizon prevents any updates
C.The expiration timer alone solves count‑to‑infinity
D.Neither mechanism affects count‑to‑infinity
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Poison‑reverse ensures that a router advertises a metric of 16 for a route it learned from a neighbor, so that neighbor will not reuse that path, breaking potential loops. The expiration timer then guarantees that if updates cease, the route will be marked unreachable after 180 seconds, preventing indefinite metric increments.

Q7. In RIP, a route whose hop count reaches 16 is interpreted as what?

A.Reachable with high cost
B.Unreachable ✅
C.Preferred path
D.Reserved for future use
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: RIP defines a metric of 16 as infinity, meaning the destination cannot be reached. When a route’s hop count reaches this value, routers treat the route as invalid and propagate the metric 16 to inform neighbors that the path is no longer usable.

Q8. Explain how the randomization of the 35‑second update interval contributes to faster convergence while reducing routing traffic.

A.It spreads updates evenly, lowering bursts ✅
B.It synchronizes all routers
C.It disables updates
D.It increases metric values
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: By adding a random delay to each router’s 35‑second timer, updates are staggered across the network. This prevents many routers from transmitting simultaneously, reducing the chance of packet collisions and excessive bandwidth use, while still delivering timely information that aids quicker convergence.

Q9. Propose a modification to RIP’s timer scheme that would improve robustness against a single router failure without significantly increasing control‑plane traffic. Which of the following changes best meets these criteria?

A.Reduce the update interval to 10 seconds
B.Introduce a secondary “heartbeat” timer of 60 seconds that triggers immediate updates on failure ✅
C.Eliminate the garbage‑collection timer
D.Increase the expiration timer to 600 seconds
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A dedicated heartbeat timer that fires quickly after a failure can prompt neighboring routers to send immediate updates, accelerating detection of the problem. Because it only activates on failure events, overall control‑plane traffic remains low, preserving robustness without the constant overhead of a shorter regular update interval.

Q10. What is the default duration of the expiration timer for a route in RIP?

A.60 seconds
B.120 seconds
C.180 seconds ✅
D.240 seconds
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: RIP specifies that when a route entry is created or refreshed, its expiration timer is set to 180 seconds. If no further updates are received before this period elapses, the route is marked unreachable.

Q11. A router receives a valid update for a route just 5 seconds before its expiration timer would expire. What is the effect on the timer and the route’s status?

A.Timer is reset to 180 seconds and route remains valid ✅
B.Timer continues unchanged and route expires
C.Timer is set to 5 seconds
D.Route is immediately purged
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Receiving a fresh update restarts the expiration timer, resetting it to the full 180 seconds. Consequently, the route stays in the forwarding table with its current metric, and the timer begins counting down from the new value, preventing premature expiration.

Q12. Compare the impact on network bandwidth of using a fixed 35‑second update interval versus a randomized interval between 30 seconds and 40 seconds. Which statement is accurate?

A.Fixed interval generates more traffic
B.Randomized interval reduces the chance of simultaneous bursts ✅
C.Both produce identical bandwidth usage
D.Randomized interval doubles traffic
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Randomizing the interval spreads update transmissions over a wider time window, lowering the probability that many routers send updates at the same moment. This distribution eases bandwidth demand during any single second, even though the average number of updates per unit time remains comparable to the fixed‑interval case.

Q13. How does the garbage‑collection timer ensure that neighboring routers become aware of an invalid route before it is removed from the forwarding table?

A.By advertising the route with metric 16 during the timer’s countdown ✅
B.By sending a special “route‑down” packet
C.By disabling all updates
D.By increasing the hop count gradually
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When a route becomes invalid, RIP continues to advertise it with a metric of 16 while the garbage‑collection timer counts down. This persistent advertisement informs all neighboring routers that the path is no longer usable, giving them time to update their tables before the route entry is finally purged.
