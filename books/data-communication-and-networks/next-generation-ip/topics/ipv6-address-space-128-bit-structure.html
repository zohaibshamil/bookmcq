📝 IPv6 address space 128-bit structure

📖 From Data Communication and Networks • 22. Next Generation IP • 10 questions available

What is IPv6 address space 128-bit structure?

The IPv6 address is made up of 128 bits that provide an extremely large number of unique addresses, which are typically divided into a network prefix portion used for routing and an interface identifier portion used to identify a specific device on that network.

Q1. If an organization exhausts its IPv4 address space and obtains additional addresses from a different block, what is the most likely immediate effect on its routing tables?

A. Decrease number of entries
B. Increase number of entries ✅
C. No change
D. Router will shutdown

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When a network acquires a new, separate address block, the router must create additional routes to reach the new prefixes. This adds entries to the routing table, increasing its size. The change does not reduce existing entries, nor does it halt the router, so the correct effect is an increase in entries.

Q2. Suppose subnet A is defined as 192.168.1.0/24 and subnet B as 192.168.1.128/25. What can be inferred about the relationship between these subnets?

A. B is completely inside A ✅
B. A is inside B
C. They are disjoint
D. They overlap partially

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A /24 network covers addresses from 192.168.1.0 to 192.168.1.255. A /25 network starting at .128 spans .128 to .255, which lies entirely within the /24 range. Therefore subnet B is a subset of subnet A, meaning B is completely inside A. The other statements describe different relationships that do not match the address ranges.

Q3. If an ISP restructures its address space from a flat /16 allocation to a hierarchical scheme where each site receives a /24, how will the number of OSPF Type‑3 LSAs (summary LSAs) likely change?

A. Increase exponentially
B. Remain the same
C. OSPF will stop
D. Decrease ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

OSPF Type‑3 LSAs are generated when an area summarizes multiple networks into a single prefix. By moving from a single /16 to many /24 prefixes, the network can be aggregated at higher levels (e.g., /20 or /16) reducing the need for individual summaries. Consequently, the total number of summary LSAs tends to decrease, easing LSA traffic.

Q4. Which statement best captures the main advantage of class‑less (CIDR) addressing over classful addressing?

A. Simpler subnet masks
B. Fixed network sizes
C. More efficient use of address space ✅
D. No need for routing tables

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

CIDR allows network prefixes of arbitrary length, enabling allocation of address blocks that closely match an organization’s size. This flexibility prevents the waste inherent in classful schemes, where whole classes (e.g., /24, /16) must be assigned even if only a fraction of the addresses are needed. Hence, CIDR improves the efficiency of address space usage.

Q5. When comparing IPv4 address fragmentation with CIDR aggregation, which trade‑off most accurately reflects their impact on routing and address utilization?

A. CIDR reduces waste and can reduce routing table size when aggregated ✅
B. Fragmentation reduces routing table size
C. CIDR increases waste but simplifies routing
D. Fragmentation simplifies routing but wastes addresses

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Fragmentation (splitting a large block into many small, unrelated pieces) often leads to a larger routing table because each fragment must be advertised separately, and it wastes address space by leaving gaps. CIDR aggregation groups contiguous blocks under a common prefix, conserving addresses and allowing routers to advertise a single aggregated route, thereby reducing table size.

Q6. How does hierarchical address allocation affect the growth of routing tables compared to flat allocation?

A. Hierarchical leads to exponential growth
B. Flat leads to linear growth
C. Both produce identical growth
D. Hierarchical allows summarization reducing entries ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

In hierarchical allocation, addresses are assigned in a way that reflects the network’s topology, enabling routers to summarize multiple sub‑nets under a common prefix. This summarization dramatically cuts the number of distinct routes that must be stored. Flat allocation lacks this structure, forcing routers to keep individual entries for each sub‑net, leading to larger tables.

Q7. A network is assigned a /24 prefix. How many usable host IP addresses does this network contain?

A. 256
B. 254 ✅
C. 255
D. 252

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A /24 prefix provides \(2^{8}\) total addresses because the host portion is 8 bits. Two addresses are reserved: the network identifier (all host bits zero) and the broadcast address (all host bits one). Therefore, usable hosts equal \(2^{8} - 2 = 256 - 2 = 254\).

Q8. What is the primary effect of a highly fragmented address space on the convergence time of distance‑vector routing protocols?

A. Slower convergence due to more updates ✅
B. Faster convergence
C. No effect
D. Convergence becomes impossible

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Distance‑vector protocols rely on periodic exchange of entire routing tables. When address space is fragmented into many small prefixes, each router must advertise a larger number of routes. The increased volume of updates amplifies processing and propagation delays, causing the network to take longer to reach a stable state after a change.

Q9. An ISP with multiple edge routers wants to allocate IPv6 address space to minimize global routing table entries. Which strategy best achieves this goal?

A. Assign each customer a unique /48 from a single /32
B. Allocate /64 per customer without aggregation
C. Use a /48 per customer aggregated under a /32 per region ✅
D. Give each router a /56 from a flat pool

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

By assigning each customer a /48 that is part of a region‑wide /32, the ISP can advertise the regional /32 as a single aggregate route. Individual customer routes are hidden behind this summary, reducing the number of prefixes announced to the global Internet. The other options either lack aggregation or use flat pools that increase advertised entries.

Q10. In IP networking, what does the term 'network prefix' refer to?

A. The host portion of an address
B. The portion that identifies the subnet mask
C. The decimal representation of the address
D. The leading bits that define the network portion ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The network prefix consists of the most significant bits of an IP address that designate the network to which the host belongs. These bits are determined by the subnet mask or prefix length (e.g., /24) and allow routers to forward packets based on the network identifier rather than the individual host address.
