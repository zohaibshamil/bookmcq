What is Neighbor Discovery Messages ND?

Neighbor Discovery is an ICMPv6-based mechanism that replaces ARP and IPv4 router discovery by using specific message types to find link-layer addresses of neighbors, verify reachability, discover routers, and perform duplicate address detection on the local network.

Q1. What is the primary purpose of a Neighbor Discovery Message (NDM) in intra‑AS routing?

A. To advertise link‑state or distance‑vector information to directly connected routers. ✅
B. To encapsulate user data for end‑to‑end delivery.
C. To assign IP addresses to hosts.
D. To establish TCP connections.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

NDMs are control packets exchanged between directly connected routers to convey routing information such as link‑state advertisements (OSPF) or distance‑vector updates (RIP). This exchange enables each router to build a consistent view of the network topology, which is essential for correct packet forwarding.

Q2. When AS1 runs OSPF and AS2 runs RIP, how does R5 discover a path to N4?

A. It receives an OSPF link‑state advertisement from R1 and a RIP update from R6, then combines them.
B. It only uses RIP updates because OSPF cannot cross AS boundaries. ✅
C. It relies on a BGP path‑vector advertisement from AS2.
D. It queries a central controller for the route.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

R5 first learns the OSPF topology inside AS1 via LSAs, but to reach N4 (located in AS2) it must rely on the RIP updates propagated by R6. Since RIP is the intra‑AS protocol for AS2, R5 uses the RIP metric advertised by R6 to select the next hop toward N4.

Q3. Compare the convergence time of OSPF versus RIP when R5 learns the route to N4 after a link failure. Which statement is most accurate?

A. OSPF converges faster because it floods updated LSAs immediately. ✅
B. RIP converges faster because it uses a smaller hop‑count metric.
C. Both converge in the same amount of time because they exchange NDMs at identical intervals.
D. Convergence time depends solely on the physical distance, not the protocol.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

OSPF, as a link‑state protocol, triggers an immediate flood of updated LSAs to all routers when a link changes, leading to rapid convergence. RIP, a distance‑vector protocol, relies on periodic updates and may experience slower convergence due to its slower update interval and count‑to‑infinity problems.

Q4. If AS2 replaces RIP with OSPF, how would R5’s discovery process for N4 be altered?

A. R5 would now receive OSPF LSAs from AS2, allowing a single consistent view of the topology. ✅
B. R5 would still need RIP updates because OSPF cannot carry external routes.
C. R5 would no longer need any NDMs because OSPF eliminates the need for neighbor discovery.
D. R5 would use BGP instead of OSPF for intra‑AS routing.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

With OSPF in both AS1 and AS2, R5 receives OSPF link‑state advertisements that describe the full network graph, eliminating the need to interpret RIP metrics. The OSPF hello and LSA exchanges provide a unified topology, enabling R5 to compute the shortest‑path tree directly to N4.

Q5. In Figure 20.24, assuming AS3 and AS4 run RIP, which sequence of NDM exchanges enables R8 to learn a route to N13?

A. R8 receives a RIP update from R7, then R7 receives one from R6, and finally R6 advertises N13. ✅
B. R8 first gets an OSPF LSA from R5, then a RIP update from R9.
C. R8 directly receives a BGP path‑vector from AS5.
D. R8 must poll each neighbor sequentially until N13 is found.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

RIP propagates distance‑vector information hop‑by‑hop. R8 learns N13’s distance when R7 forwards the RIP update it received from R6, which originally learned the route from its neighbor that directly knows N13. This cascading exchange of NDMs builds the route incrementally across the RIP‑based ASes.

Q6. Evaluate the scalability impact of using link‑state NDMs versus distance‑vector NDMs in a large autonomous system. Which assessment is most appropriate?

A. Link‑state NDMs generate higher overhead but scale better because each router stores the full topology. ✅
B. Distance‑vector NDMs generate lower overhead but scale poorly due to routing loops and slow convergence.
C. Both have identical scalability characteristics in large networks.
D. Link‑state NDMs cannot be used in large ASes because they exceed memory limits.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Link‑state protocols flood LSAs throughout the AS, incurring more bandwidth usage, yet each router maintains a complete map, enabling efficient shortest‑path computation even as the network grows. Distance‑vector protocols exchange only metrics, reducing traffic, but the limited view leads to routing loops and slower convergence, limiting scalability.

Q7. Synthesize a scenario where R5 must rely on both OSPF and RIP NDMs to route to N4. What mechanism allows this hybrid operation?

A. R5 runs OSPF internally, imports RIP routes via an external route redistribution process, and then selects the best path. ✅
B. R5 alternates between OSPF and RIP every other packet.
C. R5 ignores RIP routes and only uses OSPF LSAs.
D. R5 uses BGP to translate RIP metrics into OSPF costs.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

In a hybrid environment, R5 maintains an OSPF database for its own AS while also receiving RIP updates from the neighboring AS. Through route redistribution, RIP‑learned routes are injected into the OSPF LSDB with appropriate cost conversion, letting R5 compute a unified shortest‑path tree that includes N4.

Q8. When a router receives conflicting routes to the same destination via OSPF and RIP NDMs, which metric is typically preferred according to common routing policy?

A. The OSPF metric because link‑state protocols have higher administrative distance. ✅
B. The RIP metric because hop count is more reliable.
C. The route with the lower numerical metric regardless of protocol.
D. The route received first in time.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Most implementations assign a lower administrative distance to OSPF (e.g., 110) than to RIP (e.g., 120). Consequently, when both protocols advertise a route to the same prefix, the OSPF entry is preferred, and the router installs that path in its forwarding table.

Q9. Differentiate the role of sequence numbers in OSPF NDMs from hop count in RIP NDMs for loop prevention. Which statement best captures the difference?

A. Sequence numbers uniquely identify each LSA to detect stale information, while hop count merely measures distance and does not prevent loops. ✅
B. Both sequence numbers and hop count serve the same purpose of loop avoidance.
C. Hop count is used to order LSAs, while sequence numbers indicate path length.
D. Only OSPF uses sequence numbers; RIP does not need any loop‑prevention mechanism.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

OSPF attaches a monotonically increasing sequence number to each LSA; routers discard older LSAs, ensuring that only the most recent topology information is used, thereby preventing loops. RIP relies on hop count, which can cause count‑to‑infinity problems; additional mechanisms like split horizon are required to avoid loops.

Q10. Apply the split‑horizon rule to RIP NDMs in AS2. How would the NDMs be altered?

A. Routers would not advertise a route back onto the interface from which it was learned. ✅
B. Routers would double the metric of the advertised route.
C. Routers would convert RIP NDMs into OSPF LSAs.
D. Routers would broadcast the route to all interfaces regardless of origin.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Split horizon prevents a router from sending a routing update containing a route back out through the same interface that received it. This eliminates the possibility of a router repeatedly advertising a route to its neighbor, thereby reducing routing loops in RIP‑based networks.

Q11. If the link between AS1 and AS2 fails, how does R5 detect the change via NDMs and update its routing table?

A. R5 stops receiving OSPF LSAs from the neighbor, triggers a timeout, and recomputes the shortest‑path tree without that link. ✅
B. R5 receives a RIP update with a metric of zero indicating failure.
C. R5 waits for a BGP withdrawal message.
D. R5 cannot detect the failure without manual configuration.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

OSPF routers exchange hello packets; when R5 no longer receives hello or LSAs from the neighbor across the failed link, the adjacency times out. R5 then floods a Link‑State Update indicating the link is down, prompting all routers to recalculate their shortest‑path trees, which removes any routes that depended on the failed link.

Q12. Compare the overhead of periodic NDMs in OSPF with event‑driven NDMs in DVMRP for multicast routing. Which observation is correct?

A. OSPF’s periodic LSAs generate constant overhead, whereas DVMRP’s prune messages are sent only on topology changes, reducing traffic. ✅
B. Both generate the same amount of traffic because they use identical timers.
C. DVMRP’s periodic NDMs are larger than OSPF’s LSAs.
D. OSPF does not use NDMs for multicast, so overhead is zero.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

OSPF periodically floods LSAs regardless of network changes, incurring steady bandwidth consumption. DVMRP, a distance‑vector multicast protocol, primarily sends prune and graft messages when receivers join or leave groups, resulting in lower average overhead but potentially higher spikes during membership changes.

Q13. How do path‑vector NDMs incorporate autonomous‑system numbers to avoid routing loops in inter‑domain scenarios?

A. Each NDM carries the full AS‑path list; a router discards any update that contains its own AS number. ✅
B. AS numbers are ignored in path‑vector NDMs.
C. Path‑vector NDMs use a single AS number to represent the entire path.
D. Loops are prevented by encrypting the AS numbers.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Path‑vector protocols (e.g., BGP) attach the sequence of AS numbers traversed by a route to the NDM. When a router receives an update, it checks the AS‑path; if its own AS identifier appears, the update is rejected, thereby preventing the formation of routing loops across autonomous systems.

Q14. R8 receives two NDMs for N13: one via AS3 with metric \(2\) and another via AS4 with metric \(3\). Which route will R8 install and why?

A. The route via AS3 because it has the lower metric, indicating a shorter path. ✅
B. The route via AS4 because higher metrics are preferred for load balancing.
C. Both routes are installed as equal‑cost multipath.
D. R8 discards both routes until a BGP update arrives.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Routing decisions prioritize the lowest numerical metric when multiple paths exist. Since the NDM received via AS3 reports a metric of \(2\) (shorter distance) compared with the metric \(3\) via AS4, R8 selects the AS3 path as the best route to N13.

Q15. What is the effect of increasing the OSPF hello interval on network stability and convergence?

A. A longer interval reduces control‑plane traffic but delays detection of neighbor loss, slowing convergence. ✅
B. A longer interval speeds up convergence because routers exchange hellos more frequently.
C. It has no impact on stability; only LSAs matter.
D. It causes immediate network partitioning.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The OSPF hello interval determines how often routers send hello packets to confirm adjacency. Raising this interval lowers the number of hello messages, easing bandwidth usage, but it also means a failed neighbor is detected later, which can postpone topology recomputation and thus degrade convergence speed and transient stability.
