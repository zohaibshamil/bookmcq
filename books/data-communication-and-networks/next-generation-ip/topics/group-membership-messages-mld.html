📝 Group Membership Messages MLD (12 MCQs)

Multicast Listener Discovery for IPv6 Groups

Multicast Listener Discovery allows an IPv6 router to learn which multicast addresses are of interest to nodes on a directly attached link. Hosts use MLD messages to report membership and source-filtering preferences. The router supplies this information to multicast routing functions, helping avoid delivery to links where no receiver has requested the multicast traffic. It is required for efficient IPv6 multicast delivery on local networks.

MLDv1 and MLDv2 Membership Information

MLDv1 supports basic group membership reporting and listener completion, while MLDv2 adds source filtering. A host can report interest in traffic from specified sources or exclude selected sources for a multicast group. MLD messages are carried in ICMPv6, and current MLDv2 is specified by RFC 9777, which obsoletes RFC 3810.

Query, Report and Listener State Processing

A multicast-capable router sends General or group-specific Queries to discover listeners. Hosts respond with Listener Reports identifying the multicast groups they want to receive. When membership changes, hosts send appropriate reports or state-change messages. The router maintains link-level listener information and passes it to the multicast routing protocol for forwarding-tree decisions.

Example of Joining an IPv6 Multicast Group

A host joins multicast group FF3E::1234 to receive a local video stream. It sends an MLD report, allowing the local router to record listener interest on that link. The router can then arrange multicast forwarding toward the link, rather than sending the stream to every subnet regardless of membership.

MLD and Multicast Routing Cooperation

MLD is the IPv6 counterpart to IGMP in IPv4, but it uses ICMPv6 and IPv6 multicast addresses. It reports listener state on a local link; it does not itself calculate the complete inter-router distribution tree. Protocols such as PIM use membership information together with routing information to decide where multicast packets should travel.

Misconceptions About MLD Membership

'MLD routes multicast packets between all routers' is incorrect because it reports local listener state. 'MLD is an IPv4 protocol' is false; IPv4 uses IGMP. 'MLDv2 only reports group membership' is incomplete because it also supports source filtering, allowing receivers to specify which senders they accept. Membership signaling and packet forwarding are separate tasks.

Interpreting MLD Group and Source Reports

For examinations, identify MLD as IPv6 multicast listener management carried by ICMPv6. Compare its purpose with IGMP, and distinguish membership reports from multicast forwarding protocols. Know that MLDv2 supports source filtering, recognize the role of router queries, and understand that membership information is link-local input to routing decisions. Trace how listener reports affect forwarding state.

Multicast Listener Discovery Terms

  • MLD - IPv6 protocol for multicast listener discovery.
  • Listener - Node requesting multicast group traffic.
  • Group address - IPv6 multicast destination identifying receivers.
  • Query - Router message asking about listener state.
  • Report - Message identifying multicast listening interest.
  • Source filtering - Selects which senders a listener accepts.

📝 All Group Membership Messages MLD MCQs

Q1. When converting the IPv4 multicast address 38.212.24.9 to an Ethernet multicast MAC address, the rightmost three bytes are D4:18:09. After subtracting 8 from the left‑most hexadecimal digit, which MAC address is obtained?

A.54:18:09 ✅
B.44:18:09
C.64:18:09
D.34:18:09
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The leftmost hex digit of D4 is D (13). Subtracting 8 yields 5, forming 54. The other bytes stay unchanged, so the MAC address becomes 54:18:09, following the standard IPv4‑to‑MAC mapping rule.

Q2. Router R knows that its interfaces have hosts in groups G1, G2, and G3. If a new host joins group G4 on interface 2, what must R do to keep its forwarding table correct?

A.Immediately flood the new group G4 to all routers
B.Wait for the periodic IGMP report from the host
C.Update its local membership list and propagate a membership report for G4 ✅
D.No action is required because multicast groups are static
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Multicast membership is dynamic; when a host joins a new group, the router learns the change via IGMP, updates its local database, and propagates the new group information so other routers know that G4 is present on interface 2.

Q3. In a WAN that does not support physical multicast, a multicast packet is tunneled inside a unicast packet with a TTL of 64. If the packet traverses three WAN segments, each decrementing TTL by 1, what is the most likely effect on the original multicast delivery?

A.The multicast packet will be dropped after the third segment
B.The original TTL of the multicast packet is unchanged
C.The multicast packet will arrive with TTL 61 ✅
D.The packet will be converted back to unicast permanently
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: TTL is decremented once per encapsulating hop. After three hops the wrapper TTL becomes 61. When the packet emerges as multicast, the original multicast TTL remains unchanged, so the multicast packet is delivered with the remaining TTL of 61.

Q4. Which statement best contrasts the information a router gathers in the first step of unicast routing versus multicast routing?

A.Unicast collects host MAC addresses, multicast collects IP prefixes
B.Unicast automatically knows network prefixes, multicast must learn group memberships ✅
C.Both collect the same information but store it differently
D.Unicast requires IGMP, multicast requires ARP
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: In unicast routing a router automatically knows the network prefixes of directly attached networks. In multicast routing it cannot infer group membership from prefixes and must rely on protocols such as IGMP to learn which groups have listeners on each interface.

Q5. Between Protocol Independent Multicast Dense Mode (PIM‑DM) and Sparse Mode (PIM‑SM), which protocol generally generates fewer group‑membership messages in a network with highly dynamic group changes?

A.PIM‑DM
B.PIM‑SM ✅
C.Both generate equal amounts
D.Neither uses membership messages
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: PIM‑SM uses a pull‑based model, requesting join/prune messages only when needed, which reduces the volume of membership traffic in highly dynamic environments. PIM‑DM floods the network and then prunes, producing more messages.

Q6. If a router stops receiving IGMP membership reports on one of its interfaces, what is the most probable impact on its multicast forwarding table?

A.The router will continue forwarding to that interface indefinitely
B.The router will instantly delete all entries for that interface
C.The router will age out the entries after the IGMP timeout ✅
D.The router will convert multicast traffic to unicast on that interface
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: When IGMP reports cease, the router does not immediately purge entries. It waits for the protocol‑defined timeout period, after which stale group entries are removed, preventing unnecessary forwarding.

Q7. How does IGMP snooping on a switch improve multicast efficiency within a LAN?

A.By converting multicast frames to broadcast
B.By learning which ports have listeners for each group and forwarding only to those ports ✅
C.By assigning a unique VLAN to each multicast group
D.By disabling multicast traffic altogether
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: IGMP snooping lets a switch monitor IGMP messages, building a table that maps multicast groups to the ports with listeners. The switch then forwards multicast frames only to those ports, reducing unnecessary traffic.

Q8. In a network where a router must tunnel multicast traffic across a WAN, which sequence correctly describes the steps taken from the source host to the destination host?

A.Source → IGMP → Multicast Router → Encapsulate in Unicast → WAN → Decapsulate → Destination ✅
B.Source → Unicast Router → Direct Multicast → WAN
C.Source → Broadcast → Multicast Router → WAN
D.Source → IGMP → Direct Multicast → WAN
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The source host joins a multicast group via IGMP. The local router receives the multicast packet, encapsulates it in a unicast packet for transport across the WAN, sends it to the remote router, which decapsulates and forwards the original multicast packet to the destination host.

Q9. Which of the following correctly describes the relationship between an IPv4 multicast address and its corresponding Ethernet MAC address?

A.The MAC address is formed by prefix 01:00:5E and the low‑order 23 bits of the IPv4 address ✅
B.The MAC address copies the full 32‑bit IPv4 address
C.The MAC address uses the high‑order 24 bits of the IPv4 address
D.There is no systematic mapping between them
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Ethernet multicast MAC addresses start with the fixed prefix 01:00:5E. The remaining 23 bits are taken from the lower 23 bits of the IPv4 multicast address, providing a deterministic mapping used by switches and routers.

Q10. After adding a new WAN segment that lacks support for physical multicast, what modifications must be made to the existing multicast routing configuration to maintain end‑to‑end group delivery?

A.Replace all multicast groups with unicast equivalents
B.Enable IGMP tunneling on bordering routers and ensure PIM operates across the tunnel ✅
C.Disable multicast routing entirely on the network
D.No changes are needed because multicast works over any WAN
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Because the new WAN cannot carry Ethernet multicast frames, routers at each end must encapsulate multicast traffic in unicast packets (tunneling). The routing protocol (e.g., PIM) must be aware of the tunnel so join/prune messages are exchanged correctly, preserving group delivery across the non‑multicast segment.

Q11. What does IGMP stand for in the context of IP multicast?

A.Internet Group Management Protocol ✅
B.Inter‑Network General Messaging Procedure
C.Integrated Global Multicast Process
D.Internal Group Mapping Protocol
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: IGMP is the Internet Group Management Protocol, used by hosts and adjacent routers to establish and maintain multicast group memberships on a local network segment.

Q12. A network engineer observes that multicast traffic is being flooded to all ports on a switch despite hosts joining only group 224.1.2.3. Which of the following is the most likely cause?

A.IGMP snooping is disabled on the switch ✅
B.The switch firmware is outdated
C.The multicast MAC address is incorrectly mapped
D.The router is sending unicast packets instead of multicast
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When IGMP snooping is disabled, the switch cannot learn which ports have listeners for specific groups and therefore treats multicast frames as broadcast, forwarding them out every port. Enabling snooping allows selective forwarding based on IGMP reports.
