Q1. If a router receives a BGP UPDATE that lists its own AS number in the AS‑PATH, what should the router do with that update?

🔹 A. Drop the update
🔹 B. Accept and forward the update
🔹 C. Modify the AS‑PATH to remove its own AS
🔹 D. Log the update and ignore it

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The router detects a loop because its own AS appears in the AS‑PATH. According to BGP loop‑prevention rules, the safest action is to discard the UPDATE, preventing the router from advertising a path that would create a routing loop.

Q2. An UPDATE arrives with ORIGIN set to value 2 and a high MULTI‑EXIT‑DISC metric. Compared to a route with ORIGIN value 1 and a lower MED, which attribute most directly makes the first route less preferred?

🔹 A. ORIGIN
🔹 B. MULTI‑EXIT‑DISCRIMINATOR
🔹 C. NEXT‑HOP
🔹 D. LOCAL‑PREF

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

BGP first evaluates the ORIGIN attribute; a value of 2 (EGP) is less preferred than a value of 1 (IGP). Because ORIGIN is examined before MED, the higher ORIGIN value causes the route to be less attractive regardless of the MED value.

Q3. When a BGP speaker receives an UPDATE that lacks a LOCAL‑PREF attribute, what default value does it assume for internal routes?

🔹 A. Assume 0
🔹 B. Assume 100
🔹 C. Assume 0 only for eBGP
🔹 D. Assume 100 only for iBGP

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

For iBGP updates, the LOCAL‑PREF attribute is mandatory; if it is missing, the receiving router uses the default value of 100. This default ensures consistent preference handling across the autonomous system while external routes may omit the attribute.

Q4. An AS sets LOCAL‑PREF to 200 and MED to 50 for routes from a neighbor. A downstream AS sees two alternatives: Path X (LOCAL‑PREF 150, MED 30) and Path Y (LOCAL‑PREF 200, MED 70). Which path will be selected and why?

🔹 A. Path X
🔹 B. Path Y
🔹 C. Both equally
🔹 D. None

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

BGP first compares LOCAL‑PREF values; the higher value (200 for Path Y) outweighs the longer AS‑PATH or higher MED. Consequently, Path Y is preferred even though its MED is larger, because LOCAL‑PREF has higher decision‑process priority.

Q5. Compare the transitive nature of the ORIGIN attribute with that of the MULTI‑EXIT‑DISCRIMINATOR attribute. Which statement is accurate?

🔹 A. Both are transitive
🔹 B. Both are non‑transitive
🔹 C. ORIGIN is transitive and MED is not
🔹 D. ORIGIN is non‑transitive and MED is transitive

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The ORIGIN attribute is a well‑known transitive attribute, meaning it is passed unchanged between ASes. In contrast, the MULTI‑EXIT‑DISCRIMINATOR (MED) is an optional non‑transitive attribute; it is not advertised beyond the neighboring AS.

Q6. What is the effect of erroneously setting the OPTIONAL bit on the LOCAL‑PREF attribute flag?

🔹 A. It would become optional and not passed between ASes
🔹 B. It would be ignored by all routers
🔹 C. It would be treated as a well‑known discretionary attribute still propagated
🔹 D. It would cause an attribute‑length error

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

LOCAL‑PREF is defined as a well‑known discretionary attribute. If the OPTIONAL bit is set, the attribute becomes malformed; compliant routers treat it as an unknown optional attribute and discard it, effectively preventing the value from being propagated.

Q7. Which statement correctly describes AS‑PATH handling in iBGP versus eBGP sessions?

🔹 A. AS‑PATH is stripped on iBGP
🔹 B. AS‑PATH is unchanged on iBGP
🔹 C. AS‑PATH is appended on eBGP only
🔹 D. AS‑PATH is never modified

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

During an eBGP exchange, the local AS number is appended to the AS‑PATH before the UPDATE is sent. In iBGP sessions, the AS‑PATH is left unchanged because the update is already within the same autonomous system, so no new AS number is added.

Q8. An administrator configures a router to prepend its own AS three times for routes from a neighbor and also sets LOCAL‑PREF to 250. How does this affect selection in a downstream AS that receives these routes alongside alternatives with shorter AS‑PATH but lower LOCAL‑PREF?

🔹 A. The prepended routes will always be preferred
🔹 B. The lower LOCAL‑PREF will outweigh the longer AS‑PATH
🔹 C. The decision will depend on the relative values of LOCAL‑PREF and AS‑PATH length
🔹 D. The routes will be discarded due to conflict

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

BGP first evaluates LOCAL‑PREF; the higher value (250) outranks a shorter AS‑PATH with a lower LOCAL‑PREF. Therefore, the downstream AS will select the prepended routes despite their longer AS‑PATH because LOCAL‑PREF has higher priority in the decision process.

Q9. Which ORIGIN attribute value is considered most trustworthy when selecting a route?

🔹 A. IGP (value 1)
🔹 B. EGP (value 2)
🔹 C. INCOMPLETE (value 3)
🔹 D. UNKNOWN (value 3)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The ORIGIN attribute ranks IGP (value 1) as the most reliable source, followed by EGP (value 2) and INCOMPLETE (value 3). Consequently, routes advertised with an IGP origin are preferred over those with higher‑value origins.

Q10. How can the MULTI‑EXIT‑DISCRIMINATOR (MED) attribute be used for inbound traffic engineering between two neighboring ASes?

🔹 A. Setting a lower MED on the preferred exit path
🔹 B. Setting a higher MED on the preferred exit path
🔹 C. Ignoring MED altogether
🔹 D. Using MED only for eBGP updates

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

By assigning a lower MED value to the preferred exit point, an AS signals its neighbor that this path should be favored for inbound traffic. The neighbor’s BGP decision process will select the path with the smallest MED when other attributes are equal.

Q11. What best describes how route reflectors treat the LOCAL‑PREF attribute in iBGP?

🔹 A. Route reflectors reset LOCAL‑PREF to the default
🔹 B. Route reflectors propagate LOCAL‑PREF unchanged
🔹 C. Route reflectors ignore LOCAL‑PREF
🔹 D. Route reflectors convert LOCAL‑PREF to MED

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Route reflectors are designed to preserve the LOCAL‑PREF attribute when reflecting routes. They forward the attribute unchanged to client peers, ensuring that the original preference decisions made by the originating router remain effective throughout the iBGP topology.

Q12. An AS receives two routes to the same prefix: Route A (LOCAL‑PREF 100, ORIGIN IGP, AS‑PATH length 2) and Route B (LOCAL‑PREF 200, ORIGIN EGP, AS‑PATH length 1). Which route will BGP select and why?

🔹 A. Route A
🔹 B. Route B
🔹 C. Both are equal
🔹 D. Selection is random

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

BGP first compares LOCAL‑PREF values; the higher value (200 for Route B) wins regardless of ORIGIN or AS‑PATH length. Thus, Route B is selected even though it has a shorter AS‑PATH and a less preferred ORIGIN type.

Q13. Which attribute type number corresponds to the NEXT‑HOP attribute in BGP?

🔹 A. 1
🔹 B. 2
🔹 C. 3
🔹 D. 4

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

In the BGP attribute type field, the NEXT‑HOP attribute is assigned type number 3. This well‑known mandatory attribute conveys the IP address of the next hop router for forwarding traffic toward the destination network.
