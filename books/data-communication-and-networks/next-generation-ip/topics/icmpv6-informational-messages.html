📝 ICMPv6 informational messages (13 MCQs)

Informational Messages for IPv6 Diagnostics and Control

ICMPv6 informational messages communicate status and support operations that are not classified as delivery errors. Their Type values range from 128 through 255 under the basic classification. Echo Request and Echo Reply are widely recognized examples, but Router Discovery, Neighbor Discovery, and Multicast Listener Discovery also use ICMPv6 informational message types to support IPv6 network operation. They are identified by distinct Type values in the protocol.

Echo and Discovery Message Types

Echo Request has Type 128 and Echo Reply has Type 129, providing the basis for ping-style reachability testing. Router Solicitation and Advertisement use Types 133 and 134. Neighbor Solicitation and Advertisement use Types 135 and 136. These messages carry different fields and serve specific link-level discovery or diagnostic tasks. Their Code fields give further message-specific detail.

How Informational Messages Are Exchanged

A host or router generates an informational message when it needs to test reachability, discover a router, resolve a neighbor, or report multicast membership. The message is placed inside an IPv6 packet with Next Header 58. The receiver interprets the Type-specific format and performs the requested control action or returns a corresponding response.

Tracing a Ping Exchange over IPv6

A computer sends an Echo Request with Type 128 to an IPv6 destination and includes an identifier and sequence number in the message data. The destination responds with Type 129 when permitted. The originating computer matches the reply and measures round-trip time, using repeated exchanges to observe loss or changing response delay.

Informational Messages as Part of IPv6 Operation

These messages connect basic diagnostics with automatic configuration and local-link communication. Router advertisements can supply prefixes and default-router details, while neighbor messages support address resolution and reachability checks. Multicast Listener Discovery informs local routers about multicast listeners. Blocking all informational ICMPv6 traffic can therefore impair normal operation, not merely diagnostic tools.

Misconceptions About Informational ICMPv6

'Informational means optional and safe to block' is incorrect because several messages are essential to IPv6. 'Echo Reply proves every application works' is false because it tests only IP-level reachability. 'All informational messages are ping messages' is wrong; router, neighbor, and multicast discovery use their own types and formats. Network behavior depends on the message family.

Identifying Informational Types in IPv6 Questions

Students should recognize Echo Request and Reply as Types 128 and 129, and identify common Router and Neighbor Discovery types. Explain the role of Next Header 58 and distinguish informational messages from error reports. In practical questions, state what a successful ping demonstrates and what it cannot establish about application services.

ICMPv6 Informational Message Terms

  • Informational message - ICMPv6 message not classified as an error.
  • Echo Request - ICMPv6 message requesting a diagnostic response.
  • Echo Reply - Response to an Echo Request message.
  • Router Advertisement - Announces router and prefix information.
  • Neighbor Solicitation - Queries a neighbor's link-layer address.
  • Message Type - Identifies the informational message function.

Q1. Which of the following best describes the split‑horizon strategy in distance‑vector routing?

A.A node advertises a route back to the neighbor from which it learned the route.
B.A node advertises routes only to neighbors that are not the source of that route. ✅
C.A node sends its complete routing table to all neighbors.
D.A node never advertises routes with infinite metric.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Split‑horizon prevents a node from sending information about a destination back to the neighbor that originally supplied that information, thereby reducing the chance of routing loops. This description matches option B, making it the correct choice.

Q2. In a poison‑reverse implementation, when node X discovers that neighbor Y is unreachable for a destination, what metric does X advertise to Y for that destination?

A.0
B.1
C.Infinity ✅
D.Cost of an alternative path
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Poison‑reverse forces the node to advertise an infinite distance (often represented as “Infinity”) for the unreachable destination, indicating that the route is poisoned. This prevents Y from using X as a path to that destination, so option C is correct.

Q3. Node E is added with a link of cost 1 to node D. Without rerunning the distance‑vector algorithm, how can the new forwarding tables be obtained?

A.Yes, by adding 1 to all paths through D
B.No, the algorithm must be rerun
C.Yes, by recomputing shortest paths only for affected nodes
D.Yes, by updating only entries that involve node E ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: The addition only affects routes that now may pass through the new link D‑E. Updating the entries that involve node E (and any routes that become shorter via D‑E) yields correct tables, so option D is the right answer.

Q4. When comparing poison‑reverse to split‑horizon, which strategy more effectively prevents count‑to‑infinity problems?

A.Poison‑reverse ✅
B.Split‑horizon
C.Both equally
D.Neither
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Poison‑reverse explicitly advertises an infinite metric for a failed route, guaranteeing that the neighbor will not consider that path, which stops the count‑to‑infinity phenomenon more reliably than split‑horizon alone. Hence option A is correct.

Q5. Using split‑horizon, node A has a distance of 3 to destination Z via neighbor B. What distance does A advertise to B for Z in the next period?

A.3
B.Infinity ✅
C.2
D.4
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Because split‑horizon forbids A from sending to B any route information that A learned from B, A must advertise an infinite metric for Z to B. This prevents B from using A as a back‑hop, making option B the correct choice.

Q6. When Dijkstra’s algorithm is implemented with an adjacency‑matrix representation, what is its time‑complexity in terms of the number of nodes \(n\)?

A.\(O(n)\)
B.\(O(n\log n)\)
C.\(O(n^{2})\) ✅
D.\(O(2^{n})\)
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Each iteration scans the entire row of the matrix to find the minimum tentative distance, and this scanning occurs for every node, resulting in \(n\) scans of size \(n\). Therefore the overall work is proportional to \(n^{2}\), so option C is correct.

Q7. If the link cost between nodes C and D increases from 2 to 5, how does the shortest‑path tree rooted at node A change?

A.The tree remains unchanged
B.The path through D becomes longer
C.All paths increase by 3
D.The tree is restructured ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A higher cost may make alternative routes more attractive, potentially altering the hierarchy of the tree. The most likely outcome is that the tree must be recomputed to reflect the new optimal paths, which corresponds to option D.

Q8. Applying the path‑vector algorithm, which path is selected as the best route from AS A to AS B when the shortest AS‑list is preferred?

A.A → B ✅
B.A → C → B
C.A → D → B
D.A → E → B
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The direct AS‑level connection A‑B yields the shortest list of autonomous systems (a single hop), satisfying the rule that the path with the fewest ASes is preferred. Hence option A is the correct route.

Q9. How many search operations does Dijkstra’s algorithm perform to determine the shortest path for a single source when the network contains \(n\) nodes?

A.\(n-1\) ✅
B.\(n\)
C.\(n^{2}\)
D.\(n\log n\)
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The algorithm selects the minimum‑distance node in each iteration; after the source is fixed, it needs to perform this selection for the remaining \(n-1\) nodes. Thus the number of searches equals \(n-1\), making option A correct.

Q10. After adding node E with a cost‑1 link to D, which forwarding‑table entries are most likely to change?

A.Only entries for D change
B.All entries increase by 1
C.Only entries for destinations reachable via D change ✅
D.No entries change
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The new link only affects routes that can now reach destinations through D‑E, so entries that previously used D as a next hop may be updated to reflect the shorter path via E. This aligns with option C.

Q12. If split‑horizon is violated, which routing problem is most likely to persist?

A.Count‑to‑infinity ✅
B.Routing loops are eliminated
C.Convergence becomes faster
D.No effect on routing
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: When split‑horizon is not respected, a node may advertise a route back to the neighbor that originally supplied it, allowing the classic count‑to‑infinity problem to reappear. Hence option A correctly identifies the issue.
