What is ICMPv6 informational messages?

ICMPv6 informational messages include echo request and echo reply used for ping diagnostics, as well as other non-error messages that support network management and testing without indicating any failure in packet delivery.

Q1. Which of the following best describes the split‑horizon strategy in distance‑vector routing?

A.A node advertises a route back to the neighbor from which it learned the route.
B.A node advertises routes only to neighbors that are not the source of that route. ✅
C.A node sends its complete routing table to all neighbors.
D.A node never advertises routes with infinite metric.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Split‑horizon prevents a node from sending information about a destination back to the neighbor that originally supplied that information, thereby reducing the chance of routing loops. This description matches option B, making it the correct choice.

Q2. In a poison‑reverse implementation, when node X discovers that neighbor Y is unreachable for a destination, what metric does X advertise to Y for that destination?

A.0
B.1
C.Infinity ✅
D.Cost of an alternative path
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Poison‑reverse forces the node to advertise an infinite distance (often represented as “Infinity”) for the unreachable destination, indicating that the route is poisoned. This prevents Y from using X as a path to that destination, so option C is correct.

Q3. Node E is added with a link of cost 1 to node D. Without rerunning the distance‑vector algorithm, how can the new forwarding tables be obtained?

📖 Explanation: The addition only affects routes that now may pass through the new link D‑E. Updating the entries that involve node E (and any routes that become shorter via D‑E) yields correct tables, so option D is the right answer.

Q4. When comparing poison‑reverse to split‑horizon, which strategy more effectively prevents count‑to‑infinity problems?

A.Poison‑reverse ✅
B.Split‑horizon
C.Both equally
D.Neither
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Poison‑reverse explicitly advertises an infinite metric for a failed route, guaranteeing that the neighbor will not consider that path, which stops the count‑to‑infinity phenomenon more reliably than split‑horizon alone. Hence option A is correct.
