Q1. Why does router R3 forward the multicast datagram only through interface 1 and not interface 2?

🔹 A. Interface 2 is congested, so R3 drops the packet.
🔹 B. There are no group members reachable via interface 2.
🔹 C. Interface 1 has higher bandwidth, so R3 prefers it.
🔹 D. R3 is configured to ignore interface 2 for all traffic.

💡 Difficulty: easy | ✅ Correct: B

Q2. Assume a source sends the same data to three destinations. In multiple unicasting, three separate packets of size \(P\) bytes travel each link. In multicasting, only one packet of size \(P\) bytes travels each link once. Which statement correctly describes the total bandwidth consumption on a link with capacity \(C\)?

🔹 A. Unicasting uses \(3P\) bytes, multicast uses \(P\) bytes, saving 50% bandwidth.
🔹 B. Both use \(3P\) bytes, no saving.
🔹 C. Unicasting uses \(P\) bytes, multicast uses \(3P\) bytes, increasing bandwidth.
🔹 D. Unicasting uses \(3P\) bytes, multicast uses \(P\) bytes, saving 66% bandwidth.

💡 Difficulty: medium | ✅ Correct: D

Q3. If a new host joins the multicast group behind router R2, which of the following changes will occur in the forwarding behavior of router R1?

🔹 A. R1 will start sending the datagram out through interface 2 in addition to its existing interfaces.
🔹 B. R1 will stop sending the datagram through interface 3.
🔹 C. R1 will duplicate the packet and send one copy to R2 and another to R3.
🔹 D. R1’s forwarding behavior remains unchanged because R2 handles the new member locally.

💡 Difficulty: hard | ✅ Correct: D
