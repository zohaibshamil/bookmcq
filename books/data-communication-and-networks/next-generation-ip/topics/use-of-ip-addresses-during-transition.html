What is Use of IP addresses during transition?

During the IPv4-to-IPv6 transition, networks may use IPv4-compatible or IPv4-mapped IPv6 addresses, employ special address ranges for tunnel endpoints, and utilize translation-friendly address formats to ensure backward compatibility while gradually shifting traffic to native IPv6 addressing.

Q1. Why does router R3 forward the multicast datagram only through interface 1 and not interface 2?

A. Interface 2 is congested, so R3 drops the packet.
B. There are no group members reachable via interface 2. ✅
C. Interface 1 has higher bandwidth, so R3 prefers it.
D. R3 is configured to ignore interface 2 for all traffic.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The multicast group has no members downstream of interface 2, so R3 knows that forwarding there would be wasteful. Multicast routing protocols prune branches without receivers, ensuring that only interfaces leading to at least one group member forward the packet, which in this case is only interface 1.

Q2. Assume a source sends the same data to three destinations. In multiple unicasting, three separate packets of size \(P\) bytes travel each link. In multicasting, only one packet of size \(P\) bytes travels each link once. Which statement correctly describes the total bandwidth consumption on a link with capacity \(C\)?

A. Unicasting uses \(3P\) bytes, multicast uses \(P\) bytes, saving 50% bandwidth.
B. Both use \(3P\) bytes, no saving.
C. Unicasting uses \(P\) bytes, multicast uses \(3P\) bytes, increasing bandwidth.
D. Unicasting uses \(3P\) bytes, multicast uses \(P\) bytes, saving 66% bandwidth. ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

With three destinations, unicasting sends three copies, each \(P\) bytes, totaling \(3P\) bytes on the link. Multicasting sends a single copy, only \(P\) bytes. The reduction is \((3P-P)/3P = 2/3\), or about 66%, demonstrating the bandwidth efficiency of multicast over multiple unicasts.

Q3. When a source transmits a single multicast packet to 1,000 receivers, what is the primary advantage regarding transmission delay compared with sending 1,000 separate unicast packets?

A. All receivers get the data simultaneously, eliminating the cumulative creation delay. ✅
B. The packet size automatically reduces proportionally to the number of receivers.
C. Each router adds a fixed delay, making total delay independent of receiver count.
D. Multicast packets are prioritized by routers, guaranteeing faster delivery.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A single multicast packet is generated once by the source, so there is no per‑receiver packet‑creation time. In contrast, sending 1,000 unicast packets introduces a sequential creation and queuing delay that can be significant. Multicast therefore removes the cumulative delay, delivering the data to all members as quickly as the network permits.

Q4. What does a multicast group address represent in IP networking?

A. An address that identifies a single host.
B. The MAC address of a router.
C. An address that identifies all members of a multicast group. ✅
D. The subnet mask for a network.

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

A multicast group address is a special IP address reserved for a set of hosts that have expressed interest in receiving the same data stream. Any packet sent to this address is delivered to every host that has joined the group, allowing efficient one‑to‑many communication.

Q5. If a new host joins the multicast group behind router R2, which of the following changes will occur in the forwarding behavior of router R1?

A. R1 will start sending the datagram out through interface 2 in addition to its existing interfaces.
B. R1 will stop sending the datagram through interface 3.
C. R1 will duplicate the packet and send one copy to R2 and another to R3.
D. R1’s forwarding behavior remains unchanged because R2 handles the new member locally. ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Router R1 already forwards the multicast datagram toward R2 via its interface that connects to R2. Adding a new receiver behind R2 does not require R1 to alter its forwarding decisions; the downstream router (R2) will take responsibility for delivering the packet to the new member.

Q6. Consider a link with capacity \(C = 10\) Mbps connecting routers R1 and R4. If the source sends data to 5 receivers via multiple unicasting, each packet of size \(P = 2\) Mb, what is the minimum time to transmit all packets over this link? Compare this with multicast where only one copy is sent.

A. Unicasting: 1 s; Multicast: 0.2 s. ✅
B. Unicasting: 2 s; Multicast: 0.2 s.
C. Unicasting: 1 s; Multicast: 0.4 s.
D. Unicasting: 2 s; Multicast: 0.4 s.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Five unicast packets require \(5 \times 2\) Mb = 10 Mb of transmission. At 10 Mbps, this takes \(10 \text{Mb} / 10 \text{Mbps} = 1\) s. A single multicast packet of 2 Mb needs only \(2 \text{Mb} / 10 \text{Mbps} = 0.2\) s, showing a substantial time and bandwidth reduction.

Q7. In a multicast routing tree, which router is responsible for duplicating the incoming packet so that it can be sent out on multiple outgoing interfaces?

A. The router that first receives the packet from the source and has more than one downstream interface requiring the data. ✅
B. Every router along the path duplicates the packet regardless of downstream members.
C. Only the last router before the receivers duplicates the packet.
D. No router duplicates; the source sends multiple copies.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The first router that receives the multicast packet and discovers that more than one downstream interface leads to group members must replicate the packet. This duplication enables the packet to be forwarded along each branch of the tree, ensuring delivery to all receivers while minimizing unnecessary copies.

Q8. Given the network of routers R1–R4 shown in Figure 21.2, which modification would most efficiently reduce duplicate transmissions while ensuring all group members still receive the multicast datagram?

A. Configure R3 to forward the packet also through interface 2, creating redundancy.
B. Enable R1 to perform source‑specific multicast, sending separate streams to each member.
C. Implement a shared tree (PIM‑SM) so that R4 forwards the packet only on the interface that leads to members, eliminating the extra copy on its second interface. ✅
D. Replace multicast routers with unicast routers and rely on multiple unicasting.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Using a shared multicast tree (e.g., PIM‑SM) allows routers to construct a single distribution structure rooted at the source. R4 would then forward the packet only on the interface that reaches downstream members, removing the unnecessary duplicate on its other interface while still delivering the data to every group member.
