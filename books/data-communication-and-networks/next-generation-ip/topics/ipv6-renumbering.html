What is IPv6 renumbering?

IPv6 renumbering is the process of changing the network prefix of devices on a subnet, which is simplified compared to IPv4 because routers can advertise new prefixes via Router Advertisements and devices can automatically configure new addresses while maintaining connectivity during the transition period.

Q1. When a router receives a route whose cost is higher than the cost stored in its old forwarding table, but the next‑router field is identical in both entries, what does the RIP algorithm prescribe?

A.Discard the received route and keep the old entry.
B.Replace the old entry with the received route. ✅
C.Mark the route as unreachable but retain the old cost.
D.Send a query to the neighbor for clarification.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The RIP rule states that if the received cost is greater but the next‑router matches, the router must adopt the received entry. This ensures that stale information is overwritten, even though the cost is higher, because the next‑router indicates the same path and the higher cost reflects a change such as a possible failure.

Q2. Router A has an old route to network X with cost \(2\) via neighbor N. Neighbor N now advertises the same network X with cost \(16\) (infinity). According to RIP, what action should Router A take?

A.Keep the old route because its cost is lower.
B.Replace the old route with the advertised infinite cost.
C.Ignore the advertisement since the old cost is better.
D.Send a probe to verify the new cost. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Because the next‑router field is unchanged (still N), the received route is selected despite its higher cost. The infinite metric signals that the path is no longer reachable, and RIP requires the router to update its table to reflect the loss of connectivity, preventing stale routes.

Q3. Consider two routers, R1 and R2. R1’s table contains a route to 10.0.0.0/24 with cost \(3\) via R2. R2 sends an update showing the same destination with cost \(2\) via R3. After processing the update, which entry will R1 store?

A.The entry with cost \(2\) via R3. ✅
B.The original entry with cost \(3\) via R2.
C.Both entries, choosing the lower cost during lookup.
D.Neither entry; R1 will request a new route.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: RIP selects the received route when its cost is lower than the existing one. Here the received cost \(2\) beats the old cost \(3\), so R1 replaces its entry with the new route that points to R3, ensuring the shortest‑path information is retained.

Q4. Which statement correctly contrasts the periodic timer and the invalid timer used in RIP?

A.The periodic timer triggers route invalidation, while the invalid timer schedules regular updates.
B.The periodic timer controls regular advertisement intervals; the invalid timer marks a route as unreachable after no updates.
C.Both timers serve the same purpose but operate on different time scales. ✅
D.The periodic timer is only used during router boot, whereas the invalid timer runs continuously.
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The periodic timer is responsible for sending update messages at set intervals, whereas the invalid timer monitors the age of received routes and marks them unreachable if they exceed a timeout. Their functions are distinct, affecting update frequency versus route validity.

Q5. If the periodic timer range in RIP is increased from 25‑35 seconds to 50‑70 seconds, what is the most likely impact on network convergence after a topology change?

A.Convergence will be faster because updates are less frequent.
B.Convergence will be slower due to longer intervals between updates. ✅
C.Convergence speed remains unchanged; only timer granularity changes.
D.Network loops will be eliminated automatically.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Longer periodic intervals mean routers send updates less often, so information about topology changes propagates more slowly. This delay extends the time required for all routers to learn the new routes, reducing overall convergence speed.

Q6. When the number of routers in an autonomous system doubles, how does the scalability of distance‑vector routing (such as RIP) compare to link‑state routing?

A.Distance‑vector scales linearly, while link‑state scales quadratically.
B.Both scale equally because they use the same amount of bandwidth.
C.Link‑state scales better because each router stores only its own distances.
D.Distance‑vector scales worse due to increased routing table size and slower convergence. ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Distance‑vector protocols exchange entire tables with neighbors, causing the amount of transmitted information to grow with network size. Link‑state protocols instead flood link information once, and each router computes paths locally, making them more scalable as the network expands.

Q7. Router B receives a route to 192.168.1.0/24 with cost \(1\) via neighbor C, while its current table has the same destination with cost \(3\) via neighbor D. According to RIP rules, what should Router B do?

A.Ignore the received route because the cost is lower. ✅
B.Update its table to store the route with cost \(1\) via neighbor C.
C.Add the new route as an alternative path without removing the old one.
D.Flag both routes as invalid until a confirmation is received.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: RIP specifies that a received route with a lower cost replaces the old entry. Since the incoming cost \(1\) is less than the stored cost \(3\), Router B must update its forwarding table to reflect the cheaper path via neighbor C.

Q8. How does sorting the forwarding table by longest‑prefix‑first after multiple RIP updates affect packet forwarding decisions?

A.It causes routers to always select the route with the smallest numeric network address.
B.It ensures that more specific routes are matched before broader ones, reducing ambiguity.
C.It has no effect because RIP uses hop count only. ✅
D.It forces routers to drop packets that match multiple entries.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Sorting by longest prefix first guarantees that when several entries could match a destination, the most specific (longest) prefix is chosen. This ordering eliminates conflicts and ensures deterministic forwarding, especially after frequent updates that may introduce overlapping routes.

Q9. To mitigate the count‑to‑infinity problem in RIP, which modification would be most effective?

A.Increasing the maximum hop count from 16 to 32.
B.Implementing split horizon with poison reverse. ✅
C.Reducing the periodic timer to 1 second.
D.Disabling the invalid timer entirely.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Split horizon with poison reverse prevents a router from advertising a route back to the neighbor from which it learned that route, and it advertises the route with an infinite metric. This strategy directly addresses the count‑to‑infinity issue by blocking the propagation of invalid paths.
