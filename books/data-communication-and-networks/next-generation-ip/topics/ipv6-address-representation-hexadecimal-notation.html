What is IPv6 address representation hexadecimal notation?

IPv6 addresses are written as eight groups of four hexadecimal digits separated by colons, where leading zeros in each group can be omitted and a single consecutive sequence of all-zero groups can be replaced with a double colon to make the address shorter and easier for students to read and write.

Q4. How does a Path Vector protocol prevent routing loops compared with a traditional Distance‑Vector protocol?

A.It includes the full AS path in each update ✅
B.It uses only hop‑count as a metric
C.Both rely on identical loop‑avoidance techniques
D.Only Distance‑Vector protocols prevent loops
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A Path Vector protocol attaches the entire sequence of AS numbers to each advertisement. When a router receives a vector that already contains its own AS number, it knows a loop would form and discards the update. Distance‑Vector protocols lack this explicit path information, making them more prone to looping without additional safeguards.

Q5. Why is RIP generally unsuitable for large‑scale networks despite being based on the distance‑vector algorithm?

A.RIP supports unlimited hop counts
B.RIP converges instantly after changes
C.RIP limits routes to 15 hops and converges slowly ✅
D.RIP uses link‑state flooding instead of vectors
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: RIP caps the maximum metric at 15 hops, which restricts its applicability in expansive topologies where longer paths are common. Moreover, its periodic update interval (typically 30 seconds) leads to slower convergence after failures, causing transient routing inconsistencies that are unacceptable in large, dynamic networks.

Q6. Which statement correctly differentiates the update mechanisms of RIP and OSPF?

A.RIP sends updates only when a link changes, while OSPF sends them every 30 seconds
B.OSPF sends periodic updates, whereas RIP uses event‑driven updates
C.RIP transmits periodic full‑table updates, while OSPF generates event‑driven link‑state advertisements ✅
D.Both protocols employ the same periodic broadcast method
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: RIP routinely broadcasts its entire routing table at fixed intervals (usually every 30 seconds), regardless of topology changes. In contrast, OSPF employs a link‑state approach where routers emit LSAs only when a change occurs, reducing unnecessary traffic and enabling faster, more precise convergence.

Q7. Applying the path‑vector principle, how does BGP avoid routing loops?

A.By advertising only the next‑hop address
B.By including the complete AS path in each update ✅
C.By limiting the hop count to a fixed value
D.By ignoring received path information
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: BGP attaches the full list of AS numbers traversed by a route to every advertisement. When a router receives an update that already lists its own AS, it recognises that forwarding the route would create a loop and therefore discards the advertisement, ensuring loop‑free propagation.

Q11. Transmitting full path vectors to all neighbors has security implications. Which threat is most directly mitigated by the presence of the AS‑path information?

A.IP address spoofing
B.Route hijacking attempts ✅
C.Distributed denial‑of‑service attacks

Q12. Design a scenario where a misconfiguration creates a path‑vector loop despite the algorithm’s loop‑avoidance. Which additional mechanism could reliably detect such a loop?

B.Deploy route‑flap damping

D.Increase the periodic update interval

Applying AS‑path filtering on inbound updates—rejecting any route that lacks the router’s own AS identifier—provides a safety net that catches such configuration errors, ensuring loops are identified and eliminated.
