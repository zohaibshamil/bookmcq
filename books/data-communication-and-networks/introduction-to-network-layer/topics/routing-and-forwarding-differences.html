Q1. Which statement best defines a transparent switch in Ethernet networks?

🔹 A. It requires each host to be manually configured with the switch’s MAC address
🔹 B. It forwards frames without the attached stations needing to know the switch exists
🔹 C. It only operates at the network layer, ignoring MAC addresses
🔹 D. It blocks all broadcast traffic by default

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A transparent switch operates at layer 2, learning source MAC addresses from incoming frames and building its forwarding table automatically. Because it does not require any configuration on attached stations, the stations remain unaware of the switch’s existence. Option B captures this behavior accurately.

Q2. A frame arrives at Switch 496 on port 2 with destination MAC address 71:2B:13:45:61:42, which is not present in the switch’s MAC table. What will the switch do next?

🔹 A. Drop the frame
🔹 B. Forward out all ports except the incoming port
🔹 C. Flood only to port 1
🔹 D. Update the table and forward to port 4

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Since the destination MAC is unknown, the switch cannot determine a specific egress port. According to standard switching behavior, it floods the frame out every port except the one on which it was received, ensuring the destination can receive the frame if reachable.

Q3. How does a transparent switch differ from a source‑routing bridge in terms of MAC address handling?

🔹 A. A transparent switch learns MAC addresses dynamically, while a source‑routing bridge requires pre‑configured routes
🔹 B. A transparent switch uses static MAC tables, whereas a source‑routing bridge learns dynamically
🔹 C. Both devices use identical MAC learning algorithms
🔹 D. A source‑routing bridge operates only at layer 3, ignoring MAC addresses

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Transparent switches build their forwarding tables by observing source MAC addresses in incoming frames, requiring no manual configuration. In contrast, source‑routing bridges rely on pre‑defined routing information and do not learn MAC addresses on the fly, making option A the correct distinction.

Q4. When a router receives a packet whose destination IP belongs to a directly connected network, how does the forwarding process interact with the switch’s MAC learning mechanism?

🔹 A. The router broadcasts ARP, the switch learns the MAC, then forwards the packet
🔹 B. The router forwards based on IP alone, bypassing the switch
🔹 C. The router uses ARP to resolve the next‑hop MAC; the switch then learns that MAC for future frames
🔹 D. The switch drops the packet because it cannot interpret IP addresses

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The router must resolve the destination IP to a MAC address via ARP. Once the MAC is known, the frame is sent to the switch, which learns the MAC‑to‑port mapping. Subsequent frames use this entry, making option C the accurate description.

Q5. If a switch’s forwarding table contains an entry mapping MAC 64:2B:13:45:61:13 to port 3, what will happen to a frame destined for that MAC arriving on port 2?

🔹 A. The frame is discarded as a security violation
🔹 B. The frame is forwarded out port 3
🔹 C. The frame is flooded to all ports except port 2
🔹 D. The frame is sent to the switch’s CPU for processing

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Because the destination MAC is already associated with port 3, the switch will forward the frame directly to that port, bypassing any flooding. This deterministic forwarding is the core function of a learned MAC entry, so option B is correct.

Q6. A network engineer adds a new transparent switch between two existing switches. Which statement best predicts the impact on the overall forwarding tables after traffic stabilizes?

🔹 A. All switches will retain their original tables; the new switch will not learn any MACs
🔹 B. Only the new switch will have a populated table; the existing switches’ tables remain empty
🔹 C. Each switch will learn MAC‑to‑port mappings for its directly attached devices, extending learning time but preserving correct forwarding
🔹 D. The addition will cause permanent routing loops that cannot be resolved by MAC learning

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

When the new switch is introduced, each device will begin learning MAC addresses from the traffic that traverses it. Over time, all switches acquire the necessary entries, and the network converges without lasting loops. Option D correctly describes this learning process.

Q7. In IPv4 networks, what role does ARP play in conjunction with layer‑2 forwarding performed by a transparent switch?

🔹 A. ARP resolves IP addresses to MAC addresses, enabling the switch to forward frames based on learned MACs
🔹 B. ARP directly updates the switch’s forwarding table with IP‑to‑port mappings
🔹 C. ARP replaces the need for MAC learning by providing static MAC entries
🔹 D. ARP is unrelated to MAC forwarding and is only used by routers

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

ARP translates a target IP address into its corresponding MAC address. Once the MAC is known, the transparent switch can learn the MAC‑to‑port association and forward frames accordingly. This cooperative function is captured by option A.

Q8. Given the following MAC table entries for Switch 496: 71:2B:13:45:61:41 → port 1, 64:2B:13:45:61:12 → port 2, and 64:2B:13:45:61:13 → port 3, which port will a frame destined for 64:2B:13:45:61:12 be sent out?

🔹 A. Port 1
🔹 B. Port 2
🔹 C. Port 3
🔹 D. The frame will be flooded to all ports

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The destination MAC matches the entry that maps to port 2, so the switch forwards the frame solely on that port, avoiding unnecessary flooding. This precise unicast forwarding aligns with option B.

Q9. What is the primary difference between static and dynamic forwarding entries in a switch’s MAC table?

🔹 A. Static entries are learned automatically, while dynamic entries are manually configured
🔹 B. Static entries never age out and must be configured by an administrator; dynamic entries are learned automatically and age out when inactive
🔹 C. Static entries include VLAN information, whereas dynamic entries do not
🔹 D. Dynamic entries are stored in hardware, static entries are stored in software

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Static MAC entries are manually entered and remain in the table indefinitely unless removed, providing predictable forwarding. Dynamic entries are learned from traffic and expire after a timeout if not refreshed. This distinction is accurately described in option C.

Q10. How does VLAN tagging affect the operation of a transparent switch that is not VLAN‑aware?

🔹 A. The switch ignores the VLAN tag and forwards based only on MAC, potentially causing inter‑VLAN traffic leakage
🔹 B. The switch drops all frames containing VLAN tags, preventing any VLAN traffic
🔹 C. The switch adds its own VLAN tag to every frame, overriding the original tag
🔹 D. The switch rewrites the MAC address to match the VLAN ID

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A non‑VLAN‑aware transparent switch does not interpret the 802.1Q tag; it treats the frame as a regular Ethernet frame and forwards it based on the MAC address alone. Consequently, frames from different VLANs may be forwarded across the same physical link, which is described in option A.

Q11. Suppose Switch 496 has learned the following entries: 71:2B:13:45:61:41 → port 1, 71:2B:13:45:61:42 → port 2, 64:2B:13:45:61:13 → port 3. A frame arrives on port 4 destined for 71:2B:13:45:61:43, which is unknown. Which ports will the switch forward the frame to?

🔹 A. Only port 1
🔹 B. Only port 2
🔹 C. Ports 1, 2, 3
🔹 D. All ports except port 4

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Because the destination MAC is absent from the table, the switch must flood the frame to every port except the one on which it was received (port 4). This ensures the unknown destination can receive the frame if reachable, making option D correct.

Q12. When multiple transparent switches are interconnected forming a loop‑free topology, how does the Spanning Tree Protocol (STP) complement the MAC learning process to prevent broadcast storms?

🔹 A. STP disables redundant links, guaranteeing a single forwarding path while MAC learning directs unicast traffic
🔹 B. STP replaces MAC learning entirely, using tree calculations to forward all frames
🔹 C. STP forces all switches to use static MAC tables, eliminating dynamic learning
🔹 D. STP tags each frame with a sequence number that MAC learning uses to drop duplicates

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

STP computes a spanning tree and blocks any redundant links, ensuring there is only one active path for broadcast traffic. Meanwhile, MAC learning continues to provide efficient unicast forwarding. This combined operation prevents broadcast storms, as described in option B.
