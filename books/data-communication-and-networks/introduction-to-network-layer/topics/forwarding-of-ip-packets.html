What is Forwarding of IP Packets?

IP packet forwarding is the router's data plane operation of examining the destination address in each incoming packet header and consulting the forwarding table to determine the correct outgoing interface and next-hop address for continued delivery toward the destination.

📝 All Forwarding of IP Packets MCQs

Q1. When an IP packet is forwarded using the traditional destination‑address method, which of the following statements is true?

A.The router ignores the destination IP and forwards based on the source IP.
B.The router looks up the destination IP in its forwarding table to determine the next hop. ✅
C.The packet is always sent directly to the final destination without intermediate hops.
D.The forwarding decision is made solely by the transport‑layer protocol.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The router examines the destination IP address of the incoming datagram, searches its forwarding table for a matching network prefix, and then uses the associated next‑hop information to forward the packet. This process is the core of destination‑address based forwarding, whereas source IP, transport layer, or direct delivery are not used for the routing decision.

Q2. Given the classless entry 180.70.65.192/26 in a forwarding table, which of the following destination IP addresses would match this entry?

A.180.70.65.130
B.180.70.65.180
C.180.70.65.191
D.180.70.65.210 ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A /26 mask keeps the first 26 bits of the address fixed. The network portion 180.70.65.192 spans from .192 to .255. Only addresses whose first 26 bits equal the network prefix fall within this block. Among the choices, 180.70.65.210 shares the same 26‑bit prefix, while the others differ, so it matches the entry.

Q3. A router has three overlapping entries: 10.0.0.0/8 via Interface 1, 10.1.0.0/16 via Interface 2, and 10.1.2.0/24 via Interface 3. For a packet destined to 10.1.2.45, which interface will the router select?

A.Interface 3 ✅
B.Interface 2
C.Interface 1
D.Drop
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The router applies the longest‑prefix‑match algorithm, preferring the most specific network that includes the destination address. The /24 prefix (10.1.2.0/24) is more specific than the /16 and /8 entries, and 10.1.2.45 lies within that /24 block, so the packet is forwarded out Interface 3.

Q4. Which statement correctly distinguishes classful from classless forwarding tables?

A.Classful tables include mask length while classless do not.
B.Classless tables require separate entries for each host.
C.Classful tables have fixed-size entries based on network classes. ✅
D.Classless tables cannot represent variable‑length prefixes.
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Classful forwarding tables rely on fixed class boundaries (A, B, C) and therefore contain entries that implicitly define the mask based on the class of the network address. In contrast, classless tables explicitly store a variable‑length mask with each prefix, allowing arbitrary subnet sizes and more efficient routing.

Q5. If a router’s forwarding table omits the mask for each entry, what is the most likely consequence?

A.All packets will be forwarded to the default gateway.
B.The router may select an incorrect next hop for overlapping networks. ✅
C.The router will only forward packets destined for its own interfaces.
D.The router will treat every entry as a /32 host address.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Without a mask, the router cannot differentiate between overlapping or adjacent networks, because it lacks the information needed to apply the correct prefix length. Consequently, when two entries share the same network prefix but differ in size, the router may choose the wrong next hop, leading to misrouting of packets.

Q6. Why does a router employ the longest‑prefix‑match rule when selecting a forwarding entry?

A.It minimizes processing time.
B.It ensures packets follow the shortest physical path.
C.It selects the most specific route, preventing ambiguous forwarding. ✅
D.It balances load across interfaces.
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The longest‑prefix‑match rule selects the route with the most specific network prefix that still covers the destination address. This specificity ensures that the packet follows the intended subnet rather than a broader, less accurate route, preventing ambiguous forwarding and preserving correct traffic engineering.

Q7. In a NAT device, which fields from the translation table are used to map an incoming packet to the correct internal host?

A.External address and port. ✅
B.Private port only.
C.Transport protocol only.
D.External address only.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: NAT translation tables map external (public) address‑port pairs to internal (private) address‑port pairs. When a packet arrives from the Internet, the router looks up the external IP address and port in the table to retrieve the corresponding private IP and port, thereby directing the packet to the correct internal host.

Q8. A router has interfaces I1 (192.168.1.0/24), I2 (10.0.0.0/8), I3 (172.16.0.0/12). Which entry correctly represents the route for traffic destined to the 10.0.0.0 network?

A.Network 192.168.1.0/24 via I2
B.Network 10.0.0.0/8 via I1
C.Network 10.0.0.0/8 via I2 ✅
D.Network 172.16.0.0/12 via I3
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The forwarding entry must associate the destination network 10.0.0.0/8 with the interface that directly connects to that network. Interface I2 is assigned the 10.0.0.0/8 subnet, so the correct table line records the network prefix 10.0.0.0/8 and specifies I2 as the outgoing interface.

Q9. When IP forwarding uses a label (as in MPLS), how does the router determine the outgoing interface?

A.It extracts the destination IP and performs a standard lookup.
B.The label itself encodes the interface identifier, bypassing IP address lookup. ✅
C.It uses the source IP to select the interface.
D.The router randomly selects an interface.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: In label‑switching architectures like MPLS, the incoming label is swapped for an outgoing label that encodes the next‑hop information, often including the egress interface identifier. The router therefore does not perform a traditional IP prefix lookup; it simply uses the label to determine the appropriate egress interface.

Q10. What is the primary purpose of a forwarding table in a router?

A.To map destination network prefixes to outgoing interfaces and next‑hop addresses. ✅
B.To store MAC addresses of all hosts on the Internet.
C.To keep a log of all packets processed.
D.To assign IP addresses to connected devices.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A forwarding table stores mappings from destination network prefixes to the corresponding outgoing interface and next‑hop IP address. When a router receives a packet, it consults this table to decide where to forward the datagram, enabling efficient packet switching across the network.
