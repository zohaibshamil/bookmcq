What is Routers as packet switches internal architecture?

Modern routers function as high-speed packet switches with input ports performing buffering and lookup, a switching fabric transferring packets between ports at line rate, output ports scheduling and queueing packets, and a routing processor running control plane protocols to build forwarding tables.

Q1. Which virtual layer is introduced to transform the connectionless service of the network layer into a connection‑oriented service for security purposes?

A. IPSec ✅
B. SSL
C. TLS
D. SSH

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

IPSec operates as a virtual layer that encapsulates IP packets, providing authentication and encryption. By doing so, it converts the inherently connectionless IP service into a secure, connection‑oriented one, addressing the original lack of security provisions in the network layer.

Q2. If a router employs a store‑and‑forward mechanism, how does an increase in average packet size affect the end‑to‑end latency compared to a cut‑through mechanism, assuming link bandwidth and propagation delay remain constant?

A. Latency remains unchanged
B. Latency decreases for store‑and‑forward
C. Latency increases more for cut‑through
D. Latency increases more for store‑and‑forward ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Store‑and‑forward must receive the entire packet before forwarding, so larger packets add transmission time at each hop. Cut‑through begins forwarding after the header is received, so its latency grows much less with packet size. Consequently, the latency gap widens as packets become larger.

Q3. Consider a network where routers prioritize real‑time video packets using a strict priority queue. What is the most likely effect on best‑effort data traffic when bursty video traffic suddenly doubles its rate?

A. Best‑effort traffic suffers higher queuing delay and possible loss ✅
B. Best‑effort traffic experiences reduced jitter
C. Best‑effort traffic sees increased throughput
D. Best‑effort traffic is unaffected

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When video traffic doubles, the high‑priority queue fills quickly, forcing best‑effort packets to wait longer or be dropped. Strict priority scheduling gives no bandwidth guarantee to lower‑priority traffic, so its delay rises and loss probability increases during video bursts.

Q4. How does a router differ from a Layer‑2 switch in the way it forwards packets?

A. Router forwards based on MAC addresses
B. Router makes forwarding decisions based on IP header and routing table ✅
C. Router floods frames to all ports
D. Router does not maintain any forwarding table

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Routers operate at the network layer, examining the IP header and consulting a routing table to determine the next hop. In contrast, a Layer‑2 switch works at the data‑link layer, using MAC addresses and a forwarding database, and does not interpret IP information.

Q5. Evaluate the advantage of using routers as packet switches in a network that interconnects both IPv4 and IPv6 segments.

A. Routers can translate addresses without additional devices
B. Routers can maintain separate forwarding tables for each protocol ✅
C. Routers can forward packets without inspecting headers
D. Routers eliminate the need for QoS mechanisms

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Routers are capable of maintaining distinct routing tables for IPv4 and IPv6, allowing seamless forwarding across protocol boundaries. This dual‑stack capability avoids the need for separate translation devices and supports simultaneous operation of both address families.

Q6. Differentiate between virtual‑circuit switching and datagram‑based forwarding in routers regarding path setup and resource reservation.

A. Virtual‑circuit requires per‑packet routing decisions
B. Datagram forwarding reserves bandwidth before packet transmission
C. Datagram forwarding guarantees ordered delivery
D. Virtual‑circuit establishes a pre‑defined path and may reserve resources ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Virtual‑circuit switching creates a fixed path before data transfer, optionally reserving bandwidth along that route. Datagram (or IP) forwarding makes an independent routing decision for each packet, without pre‑allocated resources, leading to potentially variable paths and no guaranteed bandwidth.

Q7. When a router performs longest‑prefix matching, how does it select the next hop for a destination address \(1010\,1100\,0011\) given the following prefix entries: 1010/4 → NH1, 1010 11/6 → NH2, 1010 1100/8 → NH3?

A. NH3 ✅
B. NH2
C. NH1
D. No match

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The destination address matches all three prefixes, but the longest prefix (8 bits) provides the most specific match. Therefore the router selects the entry 1010 1100/8, which points to NH3, implementing the longest‑prefix rule.

Q8. In a scenario where every router applies IPSec ESP encryption to outbound packets, what trade‑off is most likely to arise for high‑throughput backbone traffic?

A. Decreased packet loss
B. Increased latency due to cryptographic processing ✅
C. Unlimited bandwidth
D. Elimination of routing table lookups

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Applying ESP encryption requires each router to encrypt and decrypt packets, adding CPU overhead. This processing introduces additional per‑packet latency, which becomes noticeable on high‑speed links where the cryptographic cost can approach the line rate, potentially limiting throughput.

Q9. Explain how packet switching enables quality‑of‑service (QoS) differentiation for latency‑sensitive applications.

A. By assigning fixed bandwidth to each flow
B. By allowing routers to queue packets based on priority markings ✅
C. By using circuit‑switched paths
D. By ignoring packet headers

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Packet switching lets routers inspect QoS fields such as DSCP or VLAN tags and place packets into priority queues. Latency‑sensitive traffic receives higher priority, reducing its queuing delay, while lower‑priority traffic may experience longer waits, thus achieving differentiated service levels.
