What is IPv4 Addresses?

An IPv4 address is a 32-bit unique identifier assigned to each network interface that enables hierarchical addressing, routing decisions, and end-to-end communication across IP networks using dotted-decimal notation for human readability.

📝 All IPv4 Addresses MCQs

Q1. What is the size, in bits, of an IPv4 address?

A.16
B.32 ✅
C.64
D.128
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: An IPv4 address consists of four octets, each 8 bits, giving a total of \(4 \times 8 = 32\) bits. This fixed length allows routers to process addresses efficiently and is the standard defined in the TCP/IP suite. Therefore, the address space is exactly 32 bits long, providing about 4.3 billion unique identifiers.

Q2. In a network that uses a /24 subnet mask, how many usable host addresses are available?

A.256
B.255
C.254 ✅
D.252
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: A /24 mask leaves 8 bits for host addresses, yielding \(2^{8}=256\) total addresses. The first address is the network identifier and the last is the broadcast address, so subtracting these two leaves 254 usable host addresses. Hence option C is correct.

Q3. Given the IPv4 address 192.168.10.0 with a /26 prefix, what is the broadcast address for that subnet?

A.192.168.10.31
B.192.168.10.127
C.192.168.10.255
D.192.168.10.63 ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: A /26 prefix allocates 26 network bits and 6 host bits, giving \(2^{6}=64\) addresses per subnet. Starting at .0, the highest address in the block is .63, which serves as the broadcast address. Therefore, option D correctly identifies the broadcast address.

Q4. Which of the following statements about classful IPv4 addressing is false?

A.Class A provides approximately 16 million host addresses
B.Class B uses a default mask of /16
C.Class C has 24 network bits
D.Class D is used for unicast traffic ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Class D addresses (224.0.0.0/4) are reserved for multicast traffic, not for standard unicast communication. The other statements correctly describe classful characteristics, making the claim about Class D being used for unicast false.

Q5. Why do private IP address ranges help reduce the demand for public IPv4 addresses?

A.They are routable on the Internet
B.They can be reused in different local networks ✅
C.They increase the total address space
D.They require DHCP
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Private ranges such as 10.0.0.0/8 are not advertised globally, allowing many organizations to use the same addresses internally. This reuse conserves the limited pool of public IPv4 addresses, reducing the overall demand for globally unique addresses.

Q6. In a /28 subnet where the network address is 172.16.0.0, which address is most commonly assigned as the default gateway?

A.172.16.0.1 ✅
B.172.16.0.14
C.172.16.0.15
D.172.16.0.0
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A /28 subnet contains 16 addresses; .0 is the network identifier and .15 the broadcast address. The first usable host, .1, is traditionally chosen as the gateway because it is easy to remember and consistently positioned across subnets.

Q7. How does Classless Inter-Domain Routing (CIDR) improve routing efficiency in the Internet?

A.By increasing the number of routing table entries
B.By allowing aggregation of multiple prefixes into a single entry ✅
C.By using only longer subnet masks
D.By eliminating the need for subnetting
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: CIDR enables route summarization, where several contiguous address blocks are combined into one routing entry. This reduces the size of routing tables, lowers lookup times, and conserves memory, resulting in more efficient Internet routing.

Q8. An organization needs at least 500 hosts on a single subnet. Which subnet mask should be applied to satisfy this requirement?

A./24
B./23 ✅
C./22
D./21
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: To host 500 devices, a subnet must provide at least \(2^{9}=512\) addresses; subtracting two reserved addresses leaves 510 usable hosts. A /23 mask (32‑9=23) yields exactly this capacity, making it the appropriate choice.

Q9. When a class B network (default /16) is subnetted with a /18 mask, how does the number of possible subnets change?

A.Each additional subnet bit doubles the number of subnets ✅
B.The mask does not affect subnet count
C.More subnet bits reduce the number of subnets
D.Only class C networks can be subnetted
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Changing from /16 to /18 adds two bits for subnetting. Each added bit doubles the subnet count, so the original class B network can be divided into \(2^{2}=4\) subnets. This illustrates the exponential increase in subnets when extra subnet bits are used.

Q10. In the IPv4 address 10.0.0.0/8, what is the decimal value of the first octet of the network address?

A.0
B.10 ✅
C.192
D.255
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The address 10.0.0.0 belongs to the private Class A range, where the first octet identifies the network portion. Its value is simply the decimal number 10, while the remaining octets are set to zero for the network identifier.

Q11. What is the most significant impact of IPv4 address exhaustion on the adoption of Network Address Translation (NAT)?

A.NAT becomes unnecessary
B.NAT usage decreases
C.NAT becomes more prevalent in networks ✅
D.IPv6 immediately replaces NAT
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: As the pool of globally unique IPv4 addresses dwindles, organizations increasingly rely on NAT to allow multiple internal devices to share a single public address. This necessity drives widespread NAT deployment, making it a dominant technique for conserving address space.

Q12. Two LANs with subnets 192.168.1.0/24 and 192.168.2.0/24 need to communicate without a router. Which technique enables this communication?

A.Routing
B.Bridging ✅
C.NAT
D.VPN
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Bridging operates at Layer 2, linking separate Ethernet segments into a single broadcast domain. By using a bridge or switch that forwards frames between the two subnets, devices can exchange traffic directly without requiring Layer 3 routing, satisfying the requirement for communication without a router.
