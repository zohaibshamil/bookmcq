📖 From Data Communication and Networks • 18. Introduction to Network Layer • 11 questions available

What is Datagram approach connectionless service?

The datagram approach is a connectionless network service where each packet is treated independently with full destination addressing, requiring no setup phase but potentially resulting in out-of-order delivery and variable paths through the network.

Q1. Which field does the network layer add to a datagram to detect corruption in the header?

A. Checksum ✅
B. Sequence number
C. Time‑to‑Live
D. Total length

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The checksum field is appended to each datagram by the network layer and is computed over the header only. When a router receives the datagram, it recomputes the checksum; a mismatch indicates header corruption, allowing the datagram to be discarded before further processing.

Q2. If a router drops datagrams because of congestion, what is the most likely effect on the sender's upper‑layer protocol?

A. The sender will automatically lower its transmission rate
B. The sender will retransmit duplicate datagrams ✅
C. The sender will ignore the loss
D. The sender will generate an ICMP Destination Unreachable message

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When a datagram is lost, the transport layer (e.g., TCP) assumes the loss indicates an error and triggers its reliability mechanism, which typically involves retransmitting the same segment. The network layer itself does not adjust the sender’s rate, so the upper‑layer protocol reacts by sending duplicates until acknowledgment is received.

Q3. Given that the network layer does not provide flow control, which protocol layer is primarily responsible for preventing the receiver from being overwhelmed?

A. Data link layer
B. Transport layer ✅
C. Application layer
D. Physical layer

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Flow control is a function of the transport layer (e.g., TCP) which uses mechanisms such as sliding windows and acknowledgments to regulate the amount of data sent. Since the network layer forwards datagrams without regard to receiver readiness, the transport layer must ensure that the receiver’s buffers are not overrun.

Q4. Which of the following is a reason cited for the network layer's lack of flow control?

A. Upper‑layer protocols already implement buffers ✅
B. Routers cannot handle flow‑control information
C. Flow control would violate the end‑to‑end principle
D. The checksum field replaces flow control

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The designers argued that the transport and application layers already provide buffering and flow‑control mechanisms, making an additional network‑layer flow‑control redundant and unnecessarily complex. Adding such control would increase router processing overhead without clear benefit.

Q5. How does the absence of congestion control in the Internet’s network layer most directly affect real‑time multimedia applications?

A. It guarantees constant bandwidth
B. It can cause variable latency and packet loss, degrading QoS ✅
C. It eliminates the need for error correction
D. It improves synchronization between sender and receiver

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Multimedia streams are sensitive to delay and jitter. Without network‑layer congestion control, routers may drop packets when queues fill, leading to bursts of loss and fluctuating delays. Upper‑layer protocols cannot fully compensate, so the perceived quality of service deteriorates.

Q6. If the checksum were extended to cover the entire datagram instead of only the header, which change would most likely occur in error‑detection responsibilities?

A. Upper‑layer protocols would no longer need any checksums
B. Network layer would detect more errors, reducing reliance on upper‑layer checksums ✅
C. The probability of undetected errors would increase
D. Header processing time would become negligible

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A full‑datagram checksum would allow the network layer to detect corruption anywhere in the packet, catching many errors before they reach higher layers. Consequently, transport protocols could rely less on their own checksums, although they would still retain error detection for end‑to‑end verification.

Q7. Which mechanism best describes using ICMP to provide flow‑control feedback to a sender?

A. Sender tags each packet with a priority, and routers discard low‑priority packets
B. Receiver sends ICMP Echo requests to probe capacity
C. Receiver sends ICMP Source‑Quench messages containing a sequence number, prompting the sender to pause transmission ✅
D. ICMP redirects are employed to reroute traffic around congested links

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

ICMP Source‑Quench messages were historically used to tell a sender to reduce its sending rate. By embedding a sequence number, the receiver can indicate which flow is congested, and the sender can temporarily suspend transmission for that flow, providing a primitive form of network‑layer flow control.

Q8. Assume a network experiences 30 % packet loss and the transport layer uses stop‑and‑wait ARQ. What factor multiplies the average transmission time compared with a lossless network?

A. \(1 - 0.3 = 0.7\)
B. \( \frac{1}{1-0.3}= \frac{1}{0.7}\approx1.43\) ✅
C. \(1 + 0.3 = 1.3\)
D. \( \frac{1}{0.3}\approx3.33\)

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Stop‑and‑wait ARQ must retransmit each lost packet. With loss probability p = 0.30, the expected number of transmissions per packet is \(1/(1-p)\). Thus the average time grows by a factor of \(1/(1-0.3)=1/0.7\approx1.43\), meaning about a 43 % increase over the ideal case.

Q9. Which statement correctly contrasts ICMP error messages with transport‑layer retransmission when a datagram is lost?

A. ICMP guarantees that the lost datagram will be resent, while transport layer only notifies the sender
B. ICMP merely notifies the sender of loss; transport layer handles retransmission and ordering ✅
C. Both ICMP and transport layer perform identical retransmission functions
D. Transport layer ignores ICMP notifications and always retransmits

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

ICMP provides a best‑effort notification that a packet could not be delivered, but it does not initiate retransmission. The transport layer (e.g., TCP) is responsible for detecting loss (via timeouts or duplicate ACKs) and performing reliable retransmission and sequencing of data.

Q10. Which quality‑of‑service attribute is most directly impacted by the lack of network‑layer congestion control?

A. Bandwidth
B. Latency ✅
C. Reliability
D. Security

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When congestion occurs, packets experience queuing delays and may be dropped, leading to increased latency and jitter. Although bandwidth and reliability are also affected, latency is the attribute most immediately observable to applications, especially those requiring timely delivery such as voice or video.

Q11. If a new protocol introduced flow control at the network layer, what is the most probable effect on overall system efficiency?

A. Increased overhead leading to reduced throughput ✅
B. Simplified design of transport protocols
C. Improved end‑to‑end latency
D. Elimination of the need for buffers in receivers

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Adding flow control to the network layer requires routers to maintain state for each flow and exchange control information, which adds processing overhead and extra header fields. This extra work typically reduces the raw throughput of the network, even though it may simplify some aspects of upper‑layer protocol design.
