📝 All Dynamic Host Configuration Protocol (DHCP) process MCQs

Q1. What does the acronym DHCP stand for?

🔹 A. Dynamic Host Configuration Protocol
🔹 B. Distributed Host Control Procedure
🔹 C. Dynamic Hypertext Communication Process
🔹 D. Direct Host Configuration Protocol

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

DHCP is defined as Dynamic Host Configuration Protocol, a network management protocol used on IP networks for automatically assigning IP addresses and other configuration parameters to devices. The other options are fabricated terms that do not correspond to the standard definition.

Q2. Which UDP port does a DHCP client use to receive replies from a server?

🔹 A. 67
🔹 B. 68
🔹 C. 69
🔹 D. 53

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

DHCP clients listen on UDP port 68 for replies, while servers listen on UDP port 67 for client messages. This separation allows the client and server to communicate without port conflicts. Ports 69 and 53 are used for TFTP and DNS respectively, making them incorrect in this context.

Q3. In DHCP, what is the purpose of the 'lease' time?

🔹 A. Defines how long an IP address is valid for a client
🔹 B. Specifies the interval between DHCP Discover messages
🔹 C. Determines the timeout for DHCP server response
🔹 D. Sets the maximum number of DHCP clients allowed

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The lease time specifies the duration for which the DHCP server grants the client use of the assigned IP address. After the lease expires, the client must renew or obtain a new address. It does not control message intervals, server timeouts, or client limits.

Q4. If a DHCP server assigns an IP address with a lease of 24 hours and the client does not renew it, what will happen after 24 hours?

🔹 A. The client will keep using the address indefinitely
🔹 B. The address becomes available for reassignment
🔹 C. The client will automatically get a new address without request
🔹 D. The network will shut down

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When the lease expires without renewal, the server marks the address as free, allowing it to be offered to other clients. The client must stop using the address and either request a new lease or fall back to a static configuration. The other options describe behaviors that DHCP does not exhibit.

Q5. A network has two DHCP servers with overlapping address pools. What is the most likely outcome for a client that sends a DHCPDISCOVER?

🔹 A. The client will receive two DHCPOFFERs and may accept either
🔹 B. The client will be ignored by both servers
🔹 C. Only the server with higher IP will respond
🔹 D. The client will get a NACK

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

When multiple DHCP servers respond, the client typically receives several DHCPOFFER packets. It will select one offer—often the first received or the one with preferred parameters—and send a DHCPREQUEST to that server. Overlapping pools can cause address conflicts if the client later switches servers, but the initial behavior is to accept one of the offers.

Q6. Suppose a DHCP client receives a DHCPOFFER with a subnet mask of \(255.255.255.0\) and a default gateway of \(10.0.0.1\). If the client’s assigned IP is \(10.0.0.50\), which of the following statements is true?

🔹 A. The client can communicate directly with hosts in the 10.0.1.0/24 network
🔹 B. The client must use the default gateway to reach any IP outside 10.0.0.0/24
🔹 C. The subnet mask prevents communication with the gateway
🔹 D. The client will have no route to the internet

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

With a /24 mask, the client’s local network is 10.0.0.0‑10.0.0.255. Any destination outside this range requires forwarding through the default gateway (10.0.0.1). Therefore the client must use the gateway for external traffic, while communication within the /24 subnet occurs directly.

Q7. A DHCP server is configured to allocate addresses from the range \(192.168.1.100\) to \(192.168.1.150\). If 30 clients have already obtained leases, what is the probability that the next client will receive an address ending in .120?

🔹 A. 30/51
🔹 B. Jan-51
🔹 C. Jan-30
🔹 D. Impossible to determine

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The pool contains 51 possible addresses (100‑150 inclusive). Assuming uniform random allocation, each address has an equal chance, giving a probability of 1/51 for any specific address such as .120. The other fractions do not reflect the correct sample space.

Q8. During a DHCP lease renewal, a client sends a DHCPREQUEST to the server it received its lease from. If the server is down, but another DHCP server on the network receives the request and sends a DHCPACK, what is the effect on the lease?

🔹 A. The lease is extended using the new server’s parameters
🔹 B. The client must discard the ACK and keep the old lease
🔹 C. The client will obtain a new lease with a different IP
🔹 D. The DHCP protocol rejects the ACK as invalid

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

RFC 2131 permits any DHCP server that receives a DHCPREQUEST to respond with a DHCPACK, effectively extending the lease and possibly providing updated configuration. The client accepts the ACK, updates its lease information, and continues operation, even though the original server is unavailable.

Q9. Consider a network where the DHCP server’s address pool is exhausted. A client sends a DHCPREQUEST for renewal, and the server responds with a DHCPNAK. According to RFC 2131, what should the client do next?

🔹 A. Immediately stop using the IP and restart the DHCP discovery process
🔹 B. Continue using the IP until a new lease is granted
🔹 C. Ignore the NAK and keep the old lease
🔹 D. Send a DHCPDECLINE to the server

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When a DHCPNAK is received, the client must abandon the current address and re-enter the initialization phase (INIT), sending a new DHCPDISCOVER to obtain a valid lease. Continuing to use the address or ignoring the NAK would violate the protocol and could cause address conflicts.

Q10. If a DHCP client receives multiple DHCPOFFER messages with different lease times, how should the client decide which offer to accept according to typical client implementations?

🔹 A. Choose the offer with the longest lease time
🔹 B. Choose the first offer received
🔹 C. Choose the offer with the shortest lease time
🔹 D. Randomly select an offer

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Most DHCP client implementations accept the first DHCPOFFER they receive, simplifying the selection process and reducing delay. While some clients may evaluate lease length, the default behavior is to respond quickly to the earliest offer, making option B the typical choice.

Q11. A router is configured as a DHCP relay agent forwarding DHCPDISCOVER messages from a subnet 10.0.2.0/24 to a DHCP server on 10.0.1.1. Which field in the relayed packet contains the original client’s IP address?

🔹 A. ciaddr
🔹 B. yiaddr
🔹 C. giaddr
🔹 D. chaddr

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The giaddr (gateway IP address) field is populated by the relay agent with the IP address of the interface that received the client’s broadcast. This informs the DHCP server about the originating subnet, allowing it to allocate an appropriate address. The other fields serve different purposes in the DHCP transaction.

Q12. When a DHCP client’s lease expires without renewal, what state does the client enter according to the DHCP state machine?

🔹 A. BOUND
🔹 B. RENEWING
🔹 C. INIT
🔹 D. SELECTING

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

If a lease expires and the client cannot renew it, the client returns to the INIT state, discarding any previously assigned configuration. It then restarts the discovery process by broadcasting a DHCPDISCOVER. This behavior ensures the client obtains a fresh lease before resuming normal operation.

Q13. Compare the advantages of using DHCP over static IP addressing in a large enterprise network.

🔹 A. Simplifies address management and reduces configuration errors
🔹 B. Increases manual workload
🔹 C. Prevents IP address reuse
🔹 D. Eliminates need for routers

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

DHCP automates the distribution and management of IP addresses, dramatically reducing the chance of human error, avoiding duplicate assignments, and simplifying network reconfiguration. Static addressing requires administrators to manually assign and track each address, which is labor‑intensive and error‑prone in large environments.

Q14. Which of the following best differentiates DHCPv4 from DHCPv6?

🔹 A. DHCPv4 uses UDP port 67/68, DHCPv6 uses TCP
🔹 B. DHCPv6 supports address prefix delegation, DHCPv4 does not
🔹 C. DHCPv4 can assign IPv6 addresses
🔹 D. DHCPv6 does not support lease times

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

DHCPv6 introduces support for prefix delegation, enabling the assignment of network prefixes to downstream routers—a capability absent in DHCPv4, which only provides individual IPv4 addresses. Both versions still use UDP (not TCP), and lease concepts exist in both.

Q15. Evaluate the impact of DHCP lease time length on network performance and address utilization. Which statement is most accurate?

🔹 A. Short leases increase network traffic due to frequent renewals
🔹 B. Long leases guarantee optimal address utilization
🔹 C. Short leases prevent address exhaustion in dynamic environments
🔹 D. Lease length has no effect on performance

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Short lease durations cause clients to renew more often, generating additional DHCP traffic and processing load on servers. While this can help reclaim unused addresses quickly, it also adds overhead. Longer leases reduce renewal traffic but may waste addresses if devices frequently leave the network.

Q16. Given two DHCP server configurations: Server A offers a lease time of 8 hours, Server B offers 24 hours. In a network where devices are mobile and frequently change subnets, which server’s configuration is more suitable and why?

🔹 A. Server A, because shorter leases adapt to mobility
🔹 B. Server B, because longer leases reduce renew traffic
🔹 C. Both are equally suitable
🔹 D. Neither, static IP is required

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Mobile devices that often move between subnets benefit from shorter lease times, allowing the network to reclaim addresses quickly when a device departs. This reduces the risk of stale IP assignments and improves address pool efficiency, despite the increased renewal traffic.

Q17. Contrast the behavior of a DHCP client when it receives a DHCPNAK in response to a DHCPREQUEST versus when it receives a DHCPACK. Which outcomes differ?

🔹 A. NAK causes the client to restart discovery; ACK extends the lease
🔹 B. Both cause the client to keep the old lease
🔹 C. NAK leads to immediate IP release; ACK does nothing
🔹 D. NAK and ACK have identical effects

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A DHCPACK confirms and renews the existing lease, updating any parameters as needed. A DHCPNAK indicates the server rejects the request—typically because the lease is no longer valid—forcing the client to discard the address and restart the DHCP discovery process to obtain a new lease.

Q18. Analyze the security implications of DHCP snooping in a switched network. Which of the following statements correctly describes its primary benefit?

🔹 A. Prevents unauthorized DHCP servers from assigning IPs
🔹 B. Encrypts DHCP messages
🔹 C. Ensures all clients receive the same IP
🔹 D. Eliminates the need for DHCP relay agents

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

DHCP snooping builds a trusted database of legitimate DHCP server MAC addresses on a switch. By filtering DHCP messages, it blocks rogue servers that could hand out malicious or conflicting IP configurations, thereby protecting the network from IP spoofing and related attacks.

Q19. A network administrator observes that many DHCP clients experience delays during the lease renewal phase. Which of the following root causes is most plausible?

🔹 A. DHCP server overloaded with simultaneous renewal requests
🔹 B. Clients have incorrect subnet masks
🔹 C. DHCP uses TCP which is slow
🔹 D. Lease times are set to zero

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When many clients attempt to renew at the same time, the DHCP server can become a bottleneck, leading to delayed responses. Incorrect subnet masks affect routing, not renewal timing, and DHCP already uses UDP (which is fast). Zero lease times would prevent any lease from being granted, not cause renewal delays.

Q20. Consider a scenario where a DHCP server is configured with option 66 (TFTP server name) and option 67 (Bootfile name). Which type of devices benefit most from these options?

🔹 A. Workstations needing DNS
🔹 B. Network printers
🔹 C. PXE booting computers
🔹 D. VoIP phones

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

PXE (Preboot Execution Environment) clients rely on option 66 to locate a TFTP server and option 67 to obtain the bootfile needed for network booting. These options are essential for diskless workstations, thin clients, or servers that boot via the network, whereas the other device categories typically do not require them.

Q21. Apply the DHCP four-step process to fill in the missing step: DHCPOFFER, DHCPREQUEST, __________, DHCPACK.

🔹 A. DHCPDECLINE
🔹 B. DHCPDISCOVER
🔹 C. DHCPINFORM
🔹 D. DHCPRELEASE

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The standard DHCP sequence is DHCPDISCOVER (client broadcast), DHCPOFFER (server reply), DHCPREQUEST (client selects an offer), and DHCPACK (server confirms lease). DHCPDECLINE is used to reject an offered address, while DHCPINFORM and DHCPRELEASE serve other purposes.

Q22. Explain why DHCP uses broadcast messages during the initial discovery phase.

🔹 A. Broadcast ensures the message reaches all potential servers on the local network
🔹 B. Broadcast encrypts the data
🔹 C. Broadcast limits the message to a single server
🔹 D. Broadcast reduces network load

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

During discovery, the client does not yet know the server’s IP address, so it broadcasts the DHCPDISCOVER on the local subnet. This guarantees that any DHCP server present will receive the request and can respond, enabling the client to obtain configuration without prior knowledge of server locations.

Q23. Synthesize a scenario where DHCP option 121 (Classless Static Route) would be useful. Which description fits?

🔹 A. Providing a default gateway for all hosts
🔹 B. Specifying a static route to a remote subnet for DHCP clients
🔹 C. Assigning DNS servers
🔹 D. Setting lease time

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Option 121 allows the DHCP server to deliver classless static routes to clients, enabling them to reach specific remote subnets without manual router configuration. This is valuable in environments where certain hosts need direct routes to particular networks, such as branch office links or VPN segments.

Q24. If a DHCP client is configured with a static IP address that falls within the server’s dynamic pool, what conflict may arise?

🔹 A. The client will be denied network access
🔹 B. The server may assign the same IP to another client, causing IP conflict
🔹 C. The static address will override the DHCP lease
🔹 D. No conflict occurs

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When the static address lies inside the DHCP pool, the server is unaware that the address is already in use. It may allocate the same address to another client, leading to duplicate IP situations, network communication problems, and the need for manual conflict resolution.

Q25. Design a DHCP failover mechanism that ensures high availability. Which of the following components is essential for state synchronization?

🔹 A. Primary server’s MAC address
🔹 B. Shared lease database
🔹 C. Client’s hostname
🔹 D. Router’s ARP table

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A shared lease database (or state‑sync channel) allows primary and secondary DHCP servers to keep each other's lease information consistent. This prevents duplicate address assignments and ensures that either server can take over seamlessly if the other fails. MAC addresses, hostnames, or ARP tables do not provide lease state continuity.
