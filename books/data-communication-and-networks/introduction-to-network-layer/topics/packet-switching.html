What is Packet Switching?

Packet switching is a networking method where data is divided into discrete units called packets that are independently routed through the network based on header information, allowing efficient resource sharing and statistical multiplexing compared to circuit switching.

📝 All Packet Switching MCQs

Q1. At which layer of the OSI model does packet switching primarily occur?

A.Network layer ✅
B.Transport layer
C.Data link layer
D.Physical layer
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Packet switching is a core function of the Network layer (Layer 3) in the OSI model. This layer is responsible for routing packets across multiple networks, determining optimal paths, and handling logical addressing, which distinguishes it from the Transport, Data Link, and Physical layers.

Q2. If a network adopts a datagram packet‑switching approach, which immediate effect on routing tables is most likely?

A.Routers must maintain per‑flow state
B.Routing decisions are made per packet ✅
C.Packets are assigned a fixed path before transmission
D.Congestion control is handled at the sender only
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: In a datagram system each packet is treated independently, so routers consult their routing tables for every incoming packet. This per‑packet lookup eliminates the need for maintaining state about individual flows, unlike virtual‑circuit schemes that require pre‑established state.

Q3. Which statement best contrasts datagram and virtual‑circuit packet switching regarding resource reservation?

A.Both reserve bandwidth before transmission
B.Datagram reserves no resources, virtual‑circuit reserves a path
C.Datagram reserves a path, virtual‑circuit does not ✅
D.Neither uses any reservation
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Datagram switching forwards each packet without reserving resources, allowing routes to change dynamically. Virtual‑circuit switching, by contrast, establishes a dedicated path before data transfer, reserving bandwidth and buffering along that route. Thus, only the virtual‑circuit model involves explicit resource reservation.

Q4. How does NAT alleviate IPv4 address exhaustion while preserving end‑to‑end connectivity?

A.NAT assigns each private host a unique public IP
B.NAT uses a pool of public addresses without port translation
C.NAT replaces private addresses with randomly generated ones
D.NAT maps many private IPs to a single public IP using port numbers (PAT) ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Network Address Translation (NAT) allows many devices with private IPv4 addresses to share a single public address. By translating private source addresses to the public address and differentiating flows with port numbers (Port Address Translation), NAT conserves scarce public addresses while keeping internal hosts reachable through the translation process.

Q5. When congestion occurs at a router, which immediate consequence is most likely for packets following the virtual‑circuit model?

A.All packets of the affected virtual circuit experience increased delay and potential loss ✅
B.Entire circuit is blocked until congestion clears
C.Only packets of the congested circuit experience increased delay
D.New virtual circuits cannot be established
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Virtual‑circuit traffic follows a pre‑defined path, so congestion on any link of that path directly impacts all packets belonging to that circuit. Consequently, the affected flow suffers heightened queuing delay and a higher probability of packet drops, while other circuits may continue unaffected.

Q6. Which factor most significantly influences the end‑to‑end delay in a network that uses datagram packet switching?

A.Fixed header size
B.Variable per‑hop queuing delay ✅
C.Constant propagation speed
D.Uniform processing time
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: In datagram networks each packet may encounter different queues at each hop. The variability of queuing delay, caused by fluctuating traffic loads and buffer occupancy, dominates the overall end‑to‑end latency. Header size, propagation speed, and processing time are relatively constant, so they contribute less to total delay variability.

Q7. How does the use of labels in MPLS forwarding relate to the concept of virtual‑circuit packet switching?

A.Labels replace IP addresses entirely
B.Labels increase the packet size without affecting routing
C.Labels provide a pre‑established label‑switched path that functions like a virtual circuit ✅
D.Labels are assigned randomly per packet
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Label‑Switched Paths (LSPs) in MPLS assign a short, fixed‑length label to each packet at entry. While the label itself does not define a permanent circuit, the sequence of label‑based forwarding decisions creates a path that behaves similarly to a virtual circuit, enabling fast, deterministic forwarding across the network.

Q9. Differentiate the handling of packet loss detection in UDP over a datagram network versus TCP over a virtual‑circuit network.

A.UDP uses acknowledgments per hop
B.TCP relies on end‑to‑end acknowledgments and retransmission ✅
C.Both protocols use the same loss detection mechanisms
D.UDP guarantees delivery through sequencing
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: TCP, operating over a virtual circuit, incorporates sequence numbers, acknowledgments, and timeout‑based retransmission, enabling reliable detection and recovery from lost packets. UDP, however, provides no built‑in acknowledgment or retransmission; loss is detected only by the application layer, if at all. Therefore, loss detection is intrinsic to TCP but absent in UDP.

Q10. Synthesize a strategy that combines NAT and DHCP to maximize address utilization while minimizing routing complexity in a large enterprise.

A.Assign each host a unique public IP via DHCP and disable NAT
B.Use DHCP to allocate private addresses and NAT to translate a single public IP with port mapping ✅
C.Deploy NAT without DHCP and manually configure addresses
D.Rotate public addresses among hosts without using NAT
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: By configuring DHCP to hand out private IPv4 addresses from reserved ranges, the enterprise conserves its limited public address pool. NAT then maps many internal hosts to a single public address using port address translation, simplifying external routing while preserving internal address flexibility. This combination reduces the need for extensive routing tables and eases address management.

Q11. If a router implements both store‑and‑forward and cut‑through switching, which immediate effect will be observed when traffic volume suddenly spikes?

A.Store‑and‑forward latency decreases
B.Cut‑through becomes more reliable than store‑and‑forward
C.Both methods experience identical delay
D.Store‑and‑forward incurs higher latency while cut‑through maintains lower latency ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Store‑and‑forward waits for an entire packet before forwarding, causing latency that grows with queue length during traffic spikes. Cut‑through begins forwarding after reading the header, so its per‑packet latency remains relatively low even under congestion. Consequently, the store‑and‑forward path suffers increased delay, while cut‑through continues to deliver packets faster.

Q12. Which statement correctly distinguishes classful from classless IPv4 addressing?

A.Classful uses variable-length subnet masks
B.Classless allows fixed network portions
C.Classful requires subnet masks of 255.255.255.0 only
D.Classful has predefined network classes while classless permits arbitrary prefix lengths ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Classful addressing divides the address space into fixed classes (A, B, C) with predetermined network‑host boundaries, limiting flexibility. Classless Inter‑Domain Routing (CIDR) removes these rigid class boundaries, allowing networks to be defined with any prefix length, such as /22 or /27, thereby improving address allocation efficiency.
