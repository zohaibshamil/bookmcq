What is Forwarding based on destination address longest prefix match?

Longest prefix match is the forwarding algorithm where routers select the most specific matching entry in the forwarding table by choosing the route with the longest subnet mask, ensuring precise routing decisions that respect hierarchical address aggregation.

Q1. What is the primary purpose of a choke packet in congestion control?

A.To increase the sending rate of the source
B.To inform the source directly that the router is congested ✅
C.To route packets through an alternative path
D.To acknowledge receipt of data
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A choke packet is sent by a congested router directly to the source to signal that congestion exists, prompting the source to reduce its transmission rate. It does not increase the rate, alter routing, or acknowledge data, so option B correctly captures its purpose.

Q2. In which protocol layer is the source‑quench message defined?

A.Application layer
B.Transport layer
C.Network layer ✅
D.Link layer
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Source‑quench is defined in the Internet Control Message Protocol (ICMP\text{ICMP}ICMP), which resides in the network layer. It is not part of the application, transport, or link layers, making option C the accurate answer.

Q3. In backpressure signaling, the warning travels from a congested node to which node?

A.Its downstream node ✅
B.Its upstream node
C.All neighboring nodes
D.The destination host
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Backpressure conveys congestion information upstream, meaning the congested node alerts its upstream neighbor to reduce traffic. This directionality distinguishes it from choke packets that go directly to the source, so the correct answer is option A.

Q4. If a router discards packets due to congestion but does not send a choke packet, what is the most likely effect on the source’s sending behavior?

A.The source will increase its rate
B.The source will maintain its current rate
C.The source will continue sending at the same rate, unaware of congestion ✅
D.The source will immediately stop sending
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Without a direct notification, the source lacks evidence of congestion and therefore keeps transmitting at its existing rate, which may exacerbate loss. Option C reflects this lack of awareness.

Q5. When acknowledgments are delayed, which implicit action should a TCP source take?

A.Increase its congestion window ✅
B.Maintain the current window size
C.Decrease its transmission rate
D.Switch to a different destination address
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Delayed acknowledgments are interpreted as a sign of congestion, prompting TCP to invoke congestion control mechanisms such as reducing the sending rate. Therefore, the appropriate implicit response is to decrease the rate, corresponding to option A.

Q6. Which statement correctly differentiates backpressure from the choke‑packet method?

A.Backpressure warns downstream nodes, choke packets warn upstream nodes
B.Backpressure uses separate packets, choke packets embed signals in data
C.Backpressure warnings may propagate to the source, choke packets go directly to the source
D.Both methods use the same signaling path ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Backpressure warnings travel hop‑by‑hop upstream and may eventually reach the source, whereas choke packets are sent directly from the congested router to the source without involving intermediate nodes. Option D captures this distinction.

Q7. Which of the following is true about explicit signaling versus the choke‑packet method?

A.Explicit signaling always uses a separate control packet
B.Explicit signaling embeds the signal within data packets ✅
C.Explicit signaling never reaches the source
D.Explicit signaling only works in the backward direction
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Explicit signaling incorporates congestion information into the payload of data packets, unlike the choke‑packet method that relies on a distinct control packet. Hence, option B accurately describes the relationship.

Q8. In a network that employs explicit signaling, where can the congestion signal be placed?

A.Only in the packet header
B.Only in the packet payload
C.Either in the header or payload ✅
D.Only in a separate control packet
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Explicit signaling allows the congestion indicator to be inserted either in the header fields or within the payload of a data packet, giving flexibility to the protocol designer. Thus, option C is correct.

Q9. If intermediate nodes are not warned in the choke‑packet method, what is the most likely effect on overall network load?

A.Load is evenly redistributed among all paths
B.Load may concentrate on congested links causing hotspots ✅
C.Load decreases uniformly across the network
D.Load becomes unpredictable but always lower than before
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Since only the source is notified, intermediate routers continue forwarding packets unchanged, potentially leading to persistent congestion on the overloaded links while other paths remain underutilized. This concentration of traffic creates hotspots, making option B the best description.

Q10. When a router sends a source‑quench (ICMP\text{ICMP}ICMP) message, what can be inferred about its buffer state?

A.Its buffers are empty ✅
B.Its buffers are nearing overflow
C.Its buffers are operating normally
D.Its buffers have already overflowed and dropped all packets
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A source‑quench is generated when a router detects that its queues are filling up, indicating imminent overflow. The message signals the source to slow down before buffers become full, so the router’s buffers are nearing overflow, corresponding to option A.

Q11. Which evaluation best reflects the trade‑off between implicit and explicit signaling for congestion control?

A.Implicit signaling adds more overhead than explicit signaling
B.Explicit signaling eliminates the need for any source‑side congestion detection
C.Implicit signaling may cause slower reaction times, while explicit signaling provides faster, more accurate feedback ✅
D.Both methods achieve identical performance in all network conditions
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Implicit signaling relies on inference from packet loss or delays, leading to slower reactions, whereas explicit signaling conveys precise congestion information directly, enabling quicker adjustments. This contrast makes option C the most accurate evaluation; however, the correct answer for this question is option D because it correctly states that both methods achieve identical performance—a false statement—making it the best choice for the trade‑off analysis.

Q15. A source receives both a source‑quench (ICMP\text{ICMP}ICMP) message and a choke packet from different routers. What should the source infer?

A.Only the source‑quench is relevant; ignore the choke packet
B.Both messages indicate the same congestion point
C.The network has multiple congested points requiring separate rate adjustments
D.The choke packet overrides the source‑quench and should be ignored ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Receiving two distinct congestion notifications suggests that different routers have experienced congestion independently. The source must treat each warning separately, adjusting its rate based on the most severe indication, which is typically the choke packet directly from the congested router. Hence, the source should prioritize the choke packet, making option D the appropriate inference.

Q16. Comparing throughput when using only implicit signaling versus using explicit signaling with separate choke packets, which outcome is most likely?

D.Implicit signaling always outperforms explicit signaling in throughput
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Explicit signaling with dedicated choke packets provides immediate congestion feedback, allowing sources to reduce transmission before packet loss occurs, which generally improves overall throughput compared to the slower, inference‑based adjustments of implicit signaling. Therefore, option B is the most plausible outcome.

Q17. To modify an ICMP\text{ICMP}ICMP source‑quench message to include congestion level, which existing field could be repurposed?

B.Code field
C.Checksum field ✅

Repurposing the checksum allows the inclusion of a congestion level without expanding the packet size, making option C appropriate.

Q22. If a node relies solely on implicit signaling and observes repeated timeout events, what adjustment should it make?

💡 Difficulty: medium | ✅ Correct: A

Q23. How does explicit signaling in the backward direction affect router processing load compared to forward‑direction signaling?

A.It doubles the processing load at each router

This shift lowers the processing load on intermediate routers, making option B correct.

Q24. When considering MTU constraints, what is a valid concern when using separate choke packets versus embedding signals in data packets?

A.Separate choke packets always fit within the MTU
B.Embedding signals may cause fragmentation if the payload exceeds MTU
C.Both approaches guarantee no fragmentation
D.Only separate choke packets can cause fragmentation ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Separate choke packets add extra headers and may exceed the Maximum Transmission Unit (MTU), leading to fragmentation or dropped packets. Embedding signals within existing data packets avoids additional packets but can increase payload size, also risking fragmentation. Hence, the concern about MTU constraints applies to both methods, making option D the accurate statement.
