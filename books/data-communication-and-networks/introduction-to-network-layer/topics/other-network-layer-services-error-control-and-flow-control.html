What is Other network layer services error control and flow control?

Definition:
While primarily focused on routing, the network layer also provides limited error control and flow control services. Error control involves detecting and possibly correcting errors in packet headers, while flow control manages the rate of data transmission to prevent overwhelming slow receivers or intermediate routers. However, these services are often minimal compared to the transport layer's robust mechanisms.

Working:
Error control in the network layer typically uses checksums in the IP header to detect corruption. If an error is found, the packet is usually discarded silently. Flow control is not explicitly implemented in IP but is managed indirectly through congestion control mechanisms and buffer management in routers, which drop packets when queues are full, signaling senders to slow down.

Example:
If a bit flip occurs in an IP header due to noise, the checksum calculation at the receiving router will not match. The router discards the packet. For flow control, if a router's buffer is 90%90\%90% full, it may start dropping incoming packets. This loss triggers TCP at the transport layer to reduce its sending window, effectively controlling the flow.

Reason:
The network layer keeps these services minimal to maintain high speed and simplicity. Complex error correction and flow control are better handled by the transport layer (like TCP), which has end-to-end visibility. The network layer's job is to move packets quickly; relying on higher layers for reliability allows for faster switching and simpler router designs.

Common MisConceptions:
A major misconception is that the network layer guarantees reliable delivery like TCP. In fact, IPv4 provides best-effort service with no acknowledgments or retransmissions. Students also think flow control is a primary network layer function, whereas it is mainly a transport layer responsibility, with the network layer only contributing via congestion signals.

Exam Preparation Tips: How to prepare this topic
Clarify the division of labor between layers. Know that IP header checksums exist but do not cover data. Understand that 'flow control' in network layer context often refers to congestion avoidance rather than receiver buffering. Compare IPv4 header checksum with TCP checksum coverage.

Key Terms:

  • Checksum - Value used to verify data integrity.
  • Best-Effort Service - No guarantee of delivery or order.
  • Congestion Control - Managing network traffic to prevent overload.
  • Silent Discard - Dropping erroneous packets without notification.

Q1. A frame destined for MAC 71:2B:13:45:61:42 arrives at port 1. The switch table maps that MAC to port 2. What does the switch do?

A.Forward out all ports except 1
B.Forward out port 2 only ✅
C.Broadcast to every port
D.Drop the frame
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The switch consults its MAC address table, finds the destination associated with port 2, and forwards the frame solely through that port. Because the correct egress port is known, the frame is not flooded or broadcast, which conserves bandwidth and reduces unnecessary processing.

Q2. A frame arrives at a switch with an unknown destination MAC. Which action is taken?

A.Drop the frame
B.Queue the frame for later processing
C.Flood to all ports except the incoming one ✅
D.Send to the default gateway
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When the switch lacks an entry for the destination MAC, it cannot determine the proper egress port. To ensure delivery, it floods the frame out every other port, a behavior that mimics a hub for unknown destinations and guarantees that the intended receiver will obtain the frame if present.

Q3. Two transparent switches have overlapping MAC tables. A frame is received at Switch A. How can a loop cause duplicate frames?

A.Frame discarded by Switch A
B.Duplicate frames are generated and forwarded by both switches ✅
C.Frame delayed until loop is broken
D.Switch A resets its table
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: If both switches learn the same MAC on different ports, a loop can cause each switch to forward the frame out the other’s inbound port, creating duplicate copies that circulate. This broadcast storm consumes bandwidth and illustrates why spanning‑tree protocols are required to break loops in switched LANs.

Q4. Which statement accurately describes filtering capability of a repeater versus a switch?

A.Switch cannot filter
B.Repeater can filter
C.Both can filter
D.Repeater cannot filter ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Repeaters operate purely at the physical layer; they simply amplify and retransmit signals without inspecting MAC addresses, so they have no ability to filter frames. In contrast, switches operate at the data‑link layer and maintain a MAC address table that enables them to forward or discard frames based on destination, providing essential filtering.

Q5. In a transparent switch environment, what is true about station awareness?

A.Stations are aware of the switch
B.Stations are unaware of the hub
C.Stations are unaware of the switch ✅
D.Stations are aware of the hub
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: A transparent (or “unmanaged”) switch learns MAC addresses and forwards frames without requiring any configuration on the attached stations. Because the switch does not modify frame contents or require stations to send special control messages, the end devices operate as if they were directly connected to a shared medium, remaining unaware of the switch’s presence.

Q6. When comparing a switch and a hub for a unicast frame, which description is correct?

A.Switch forwards to all ports
B.Hub forwards only to the correct port
C.Both forward to all ports
D.Switch forwards only to the correct port ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: A switch uses its MAC address table to send a unicast frame out only the port associated with the destination MAC, preventing unnecessary traffic on other segments. A hub (repeater) lacks this intelligence and repeats the frame on every port, causing the frame to be seen by all stations regardless of its intended recipient.

Q7. What is the impact on collision domains when a hub is replaced by a switch?

A.Collision domain segmented per port
B.Collision domain remains single ✅
C.Collision domain expands
D.Collision domain unchanged
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Replacing a hub with a switch isolates each physical port into its own collision domain, because the switch forwards frames based on MAC addresses rather than broadcasting them. This segmentation eliminates the chance that frames from different ports interfere, thereby reducing collisions and increasing overall network efficiency.

Q8. How does the MAC address table aging process differ from static entries?

A.Aging adds entries
B.Static entries age
C.Aging removes inactive entries ✅
D.Aging never removes entries
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Dynamic entries are removed after a configurable timeout if the switch does not see traffic from the associated MAC, preventing the table from growing indefinitely with stale information. Static entries are manually configured and persist regardless of traffic, providing a reliable mapping that is not subject to aging.

Q9. How does the learning process of a transparent switch compare with a router’s ARP cache?

A.Both learn statically
B.Both learn via ARP
C.Both learn at same layer
D.Both learn dynamically ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A transparent switch builds its MAC address table by observing source addresses of incoming frames, updating entries on the fly. Similarly, a router populates its ARP cache by learning IP‑to‑MAC mappings from ARP replies. Both mechanisms are dynamic, allowing devices to adapt to topology changes without manual configuration.

Q10. Which factor most influences the size of a switch’s MAC address table?

A.Frame size
B.Number of ports ✅
C.MAC address length
D.Number of VLANs
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The number of physical ports determines how many distinct MAC addresses can be learned simultaneously, because each active port can introduce a new source address. While frame size and address length affect individual entries, the overall capacity is primarily limited by the hardware resources allocated per port.

Q11. Why is a frame for MAC 71:2B:13:45:61:42 not sent out port 3?

A.Table maps MAC to all ports
B.Table ignores MAC addresses
C.Table maps MAC to specific port ✅
D.Table uses broadcast address
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The switch’s forwarding table contains an entry that associates the destination MAC with a particular egress port (port 2 in the example). Because the table explicitly directs traffic to that port, the switch does not forward the frame to any other ports, such as port 3, thereby preventing unnecessary traffic.

Q12. How can adding a transparent switch improve performance despite added latency?

A.It increases collisions
B.It has no effect
C.It degrades performance
D.It reduces collisions despite added latency ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A transparent switch isolates each port into its own collision domain, eliminating the broadcast nature of hubs. Although the switch introduces a small forwarding delay, the reduction in collisions and retransmissions outweighs this cost, resulting in higher effective throughput and more predictable latency for each station.

Q13. In a MAC‑flooding attack, how is the switch’s learning process exploited?

A.Overwhelms table causing broadcast
B.Prevents MAC learning ✅
C.Secures the table
D.Improves learning efficiency
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: An attacker sends frames with many forged source MAC addresses, causing the switch’s address table to fill rapidly. Once the table is full, the switch can no longer map destinations and resorts to flooding all unknown frames, effectively turning the switch into a hub and allowing the attacker to intercept traffic.

Q14. When multiple transparent switches interconnect LAN segments, what happens to the broadcast domain?

A.Broadcast domain unchanged
B.Broadcast domain splits into separate domains
C.Broadcast domains merge into one
D.Broadcast domain becomes isolated per switch ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Because transparent switches operate at layer 2 and forward broadcast frames unchanged, the overall broadcast domain remains continuous across all interconnected segments. The broadcast traffic propagates through each switch, so the domain is not divided or isolated unless a higher‑layer protocol (e.g., VLANs) is introduced.

Q15. Why does a switch forward a frame out the same port it arrived on when the destination MAC is unknown?

A.Frame is dropped
B.Frame is flooded to all other ports ✅
C.Frame is forwarded to default gateway
D.Frame is queued for later processing
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When the switch has no entry for the destination MAC, it cannot determine the correct egress port. To maximize the chance of delivery, the switch floods the frame out every port except the one on which it was received, effectively mimicking hub behavior for unknown destinations.

Q16. Why might a switch with more ports exhibit longer MAC‑address lookup times?

A.Larger table results in longer lookup
B.Larger table speeds up lookup
C.Lookup time is unchanged regardless of table size ✅
D.Lookup is not affected by table size
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Modern switches use specialized hardware (TCAM or hash tables) to achieve constant‑time lookups, so the number of ports—and consequently the size of the MAC address table—does not significantly affect the time required to locate an entry. Therefore, lookup latency remains essentially the same across switches of varying port counts.

Q17. How does a transparent switch learn MAC addresses when many devices transmit frames to new destinations simultaneously?

A.It learns from destination addresses
B.It learns from source addresses of received frames ✅
C.It learns only after ARP exchange
D.It does not learn in this scenario
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Each time a frame arrives, the switch extracts the source MAC address and records the ingress port in its table. Even when multiple devices send frames concurrently, the switch processes each frame independently, updating its mapping for each source address, thereby maintaining an up‑to‑date view of the network topology.
