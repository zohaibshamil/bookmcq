📝 All Network throughput measurement MCQs

Q1. If a VLAN is split across two physical LANs, what immediate effect on throughput can be expected?

🔹 A. increase
🔹 B. decrease
🔹 C. no change
🔹 D. unpredictable

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When a VLAN spans two physical LANs, traffic must traverse additional switches and possibly be encapsulated, adding latency and reducing effective throughput. The extra processing and potential bottlenecks lower the net data rate compared with a single LAN. Therefore throughput tends to decrease.

Q2. Compare the throughput of a single broadcast domain versus multiple VLANs on the same hardware. Which statement is most accurate?

🔹 A. higher in single broadcast domain
🔹 B. higher in multiple VLANs
🔹 C. the same for both
🔹 D. depends on traffic pattern

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

A single broadcast domain does not incur VLAN tagging overhead, so frames are forwarded directly, yielding higher raw throughput. Splitting into multiple VLANs introduces tagging and separate forwarding tables, which adds processing time and marginally reduces the maximum achievable data rate. Hence the single broadcast domain typically offers higher throughput.

Q3. VLAN tagging adds a 4‑byte header. If the original Ethernet frame payload is \(1500\) bytes, what is the new frame size after tagging?

🔹 A. 1508 bytes
🔹 B. 1496 bytes
🔹 C. 1504 bytes
🔹 D. 1520 bytes

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

VLAN tagging adds a 4‑byte header to each Ethernet frame. Starting from the standard maximum payload of \(1500\) bytes, the new frame size becomes \(1500 + 4 = 1504\) bytes. This small increase is the only change to the frame length when a VLAN tag is applied.

Q4. What is the definition of a VLAN?

🔹 A. software‑defined LAN
🔹 B. physical LAN
🔹 C. wireless LAN
🔹 D. WAN

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A VLAN is defined as a local area network that is created by software configuration rather than by physical cabling. It allows network administrators to group devices logically, independent of their physical location, providing flexibility in network design and management.

Q5. When moving stations between VLANs, which step most directly impacts throughput during the transition?

🔹 A. updating IP addresses
🔹 B. changing spanning tree
🔹 C. increasing MTU
🔹 D. updating MAC address tables

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

When stations are moved between VLANs, the switch must learn new MAC‑to‑VLAN associations. Updating the MAC address tables directly influences how frames are forwarded, and any delay or mislearning can temporarily reduce the effective throughput for the affected VLANs. Hence this step most directly impacts throughput.

Q6. If the number of VLANs increases from 3 to 10 on the same hardware, what is the expected effect on overall network throughput?

🔹 A. linear decrease
🔹 B. minimal impact
🔹 C. exponential decrease
🔹 D. increase due to segmentation

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Adding more VLANs does not change the physical bandwidth of the underlying links; it only partitions traffic logically. As long as the aggregate traffic does not exceed link capacity, the overall throughput remains largely unchanged. Therefore the impact on throughput is minimal, assuming the hardware remains the same.

Q7. A trunk link carries 4 VLANs, each averaging \(200\) Mbps traffic. What is the minimum required trunk bandwidth to avoid congestion?

🔹 A. 600 Mbps
🔹 B. 400 Mbps
🔹 C. 800 Mbps
🔹 D. 200 Mbps

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

A trunk link carries traffic for multiple VLANs simultaneously. If each of four VLANs averages \(200\) Mbps, the total required bandwidth is \(4 \times 200 = 800\) Mbps. Consequently, the trunk must support at least \(800\) Mbps to avoid congestion and preserve throughput for each VLAN.

Q8. High broadcast traffic within a VLAN reduces throughput. Which mechanism can best mitigate this loss?

🔹 A. QoS prioritization
🔹 B. VLAN pruning
🔹 C. MAC address filtering
🔹 D. Spanning tree protocol

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

High broadcast traffic within a VLAN can saturate the shared medium, reducing throughput for all frames. Applying Quality of Service (QoS) policies allows the network to prioritize critical traffic and limit broadcast storms, thereby mitigating congestion and preserving useful throughput for important applications.

Q9. Which statement correctly differentiates intra‑VLAN and inter‑VLAN traffic regarding throughput?

🔹 A. Intra‑VLAN uses routing
🔹 B. Inter‑VLAN uses switching only
🔹 C. Both have same overhead
🔹 D. Inter‑VLAN adds routing overhead

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Traffic that stays within the same VLAN (intra‑VLAN) is switched locally, incurring minimal processing delay. Inter‑VLAN traffic must be routed through a layer‑3 device, adding routing overhead and extra latency, which can reduce the effective throughput compared with pure switching.

Q10. Two engineers are moved into VLAN 3, increasing its load. How does this affect VLAN 3’s aggregate throughput?

🔹 A. Increases proportionally
🔹 B. Remains unchanged
🔹 C. Decreases due to added load
🔹 D. Doubles

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Moving two engineers into VLAN 3 increases the number of active hosts and the amount of data they generate. This added load consumes a portion of the VLAN’s available bandwidth, so the aggregate throughput available to each host is reduced unless additional capacity is provisioned.

Q11. If a switch’s MAC address table overflows, what is the likely effect on VLAN traffic throughput?

🔹 A. Dropping frames
🔹 B. Prioritizing frames
🔹 C. Encrypting frames
🔹 D. Flooding all frames

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

When a switch’s MAC address table overflows, it can no longer make precise forwarding decisions and resorts to flooding frames out all ports in the VLAN. This indiscriminate forwarding raises collision and contention levels, potentially throttling throughput as the network struggles to handle the excess traffic.

Q12. A trunk link with capacity \(800\) Mbps serves 12 VLANs each requiring \(100\) Mbps. What percentage of total demand cannot be satisfied, and what is the impact on throughput?

🔹 A. 33% unmet, leading to queuing
🔹 B. 20% unmet, leading to packet loss
🔹 C. 50% unmet, causing severe congestion
🔹 D. 0% unmet, no impact

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The twelve VLANs together demand \(12 \times 100 = 1200\) Mbps, while the trunk provides only \(800\) Mbps. The shortfall is \(1200 - 800 = 400\) Mbps, which represents \(\frac{400}{1200} \approx 33\%\) of the total demand. This unmet portion leads to queuing and packet loss, degrading overall throughput.

Q13. To maximize throughput while supporting dynamic VLAN membership, which architecture combines software‑defined networking with VLAN tagging?

🔹 A. Traditional hierarchical
🔹 B. Flat network
🔹 C. Ring topology
🔹 D. Overlay network with VXLAN

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

An overlay network using Virtual Extensible LAN (VXLAN) combines software‑defined networking principles with VLAN tagging, allowing virtual networks to be stretched over existing IP infrastructure. This architecture supports dynamic VLAN membership while preserving high throughput, because encapsulation is performed in software and the underlying physical links remain unchanged.)
