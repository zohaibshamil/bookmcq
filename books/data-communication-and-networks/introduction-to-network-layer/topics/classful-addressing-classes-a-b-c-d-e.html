What is Classful addressing classes A B C D E?

Classful addressing divides the IPv4 space into five classes where Class A supports large networks with 8-bit network prefixes, Class B medium networks with 16-bit prefixes, Class C small networks with 24-bit prefixes, Class D for multicast, and Class E reserved for experimental use.
