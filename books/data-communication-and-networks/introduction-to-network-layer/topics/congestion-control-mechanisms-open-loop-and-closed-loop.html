What is Congestion control mechanisms open loop and closed loop?

Open-loop congestion control prevents congestion through design choices like retransmission policies and windowing without feedback, while closed-loop control uses explicit feedback signals from the network to dynamically adjust sending rates based on current conditions.

Q1. Switch S1 has ID 1001, S2 has ID 1005, S3 has ID 0999. Which switch becomes the root bridge in the spanning‑tree algorithm?

A.S1
B.S2
C.S3 ✅
D.None (tie)
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The root bridge is the switch with the smallest identifier. Among the given IDs, 0999 (S3) is the lowest, so S3 is elected as the root bridge. The algorithm discards higher IDs, ensuring a unique root for the spanning‑tree.

Q2. In spanning‑tree terminology, what does the term 'blocking port' refer to?

A.Port that forwards frames
B.Port that discards frames to prevent loops ✅
C.Port used for BPDU transmission
D.Port that only receives frames
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A blocking port is deliberately placed in a non‑forwarding state so that any frames it receives are dropped. This prevents the formation of loops in the network while still allowing the port to listen for BPDUs that might change its role later.

A.LAN attached to S2
B.LAN attached to S3 ✅
C.LAN attached to S1
D.No LAN uses that path
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Starting at S1, the path cost to S3 via S2 is , which is less than the direct cost of 7. Therefore the shortest‑path tree includes the route S1‑S2‑S3, making the LAN attached to S3 use that path.

Q4. How does a blocking port differ from a forwarding port in terms of network traffic and loop prevention?

A.Blocking ports drop all frames
B.Forwarding ports forward only BPDU frames
C.Blocking ports prevent duplicate frames while forwarding ports allow them
D.Forwarding ports forward frames and block loops, while blocking ports discard frames that could create loops ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A forwarding port actively forwards data frames and BPDUs, contributing to normal traffic flow. In contrast, a blocking port does not forward regular frames; it discards them to stop potential loops, thereby preserving network stability.

Q5. If a new switch S4 with ID 0950 joins the network after the spanning tree has been built, what immediate change occurs?

A.No change; the existing tree remains
B.S4 becomes the root bridge and a new tree is recomputed ✅
C.S4 is ignored because IDs cannot change
D.All ports on S4 become blocking
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The spanning‑tree algorithm always selects the switch with the lowest ID as the root. Since 0950 is lower than the current root’s ID, S4 takes over as the root bridge, triggering a recomputation of the tree to reflect the new hierarchy.

Q6. Why is the hop count from a switch to its directly attached LAN defined as 1, while the reverse direction is 0?

A.Because frames travel only one direction
B.The counting convention treats the LAN as the destination ✅
C.Switches add one to the count when sending
D.The reverse hop is not counted in spanning‑tree calculations
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When a frame is sent from a switch toward a LAN, the switch adds one to represent the hop to the medium. In the opposite direction, the LAN is already the destination, so no additional hop is counted, resulting in a reverse count of zero.

Q7. Compare the information carried in a Bridge Protocol Data Unit (BPDU) with that in a regular Ethernet frame.

A.BPDUs contain VLAN tags, regular frames do not
B.BPDUs carry spanning‑tree parameters while regular frames carry payload data ✅
C.Both have identical structures
D.BPDUs are encrypted while regular frames are not
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A BPDU is a special control frame that includes fields such as root bridge ID, path cost, and port role. Regular Ethernet frames primarily contain the MAC addresses and the payload data. The distinct purpose of BPDUs is to exchange topology information for the spanning‑tree algorithm.

Q8. Which of the following best evaluates the trade‑off between classic STP and Rapid STP (RSTP) regarding convergence time after a topology change?

A.STP converges faster but uses more bandwidth
B.RSTP converges faster with fewer BPDU exchanges ✅
C.Both have identical convergence
D.RSTP is slower but more reliable
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: RSTP improves convergence by allowing ports to transition to forwarding state without waiting for multiple BPDU cycles, reducing the time needed after a change. It also lowers the number of BPDUs exchanged, making the process more efficient than classic STP.

Q9. A link between S2 and S3 fails. Prior to failure, S2‑port‑to‑S3 was a blocking port. After failure, which port role is most likely to change?

A.S2’s port to S3 becomes forwarding ✅
B.S3’s port to S2 becomes blocking
C.Both ports remain blocking
D.Both ports become designated forwarding ports
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: When the physical link fails, the blocked port on S2 no longer has an alternate path and must assume the role of a designated (forwarding) port to maintain connectivity, while the opposite side simply loses the link.

Q10. In a network where multiple VLANs share the same physical switch, how does the spanning‑tree algorithm ensure that frames from VLAN 10 do not cause loops in VLAN 20?

A.By using a single shared spanning tree for all VLANs
B.By assigning separate spanning trees per VLAN (MST) ✅
C.By disabling spanning tree on VLAN 20
D.By relying on MAC address filtering
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Multiple Spanning Tree (MST) allows each VLAN to have its own logical tree while sharing the same hardware. This isolation prevents frames that could create a loop in one VLAN from affecting another, preserving loop‑free operation across all VLANs.

Q11. What is the effect of assigning a higher cost to a link on the selection of the spanning‑tree ports?

A.The link is more likely to be chosen as a forwarding path
B.The link is less likely to be part of the tree ✅
C.Cost does not affect selection
D.The link becomes a root port automatically
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Spanning‑tree selects the lowest‑cost paths from the root to each switch. By increasing a link’s cost, the algorithm prefers alternative lower‑cost links, making the high‑cost link more likely to be placed in a blocking state or excluded from the tree.

Q12. When the root bridge changes from S1 to S4, what happens to the role of the port that was previously the root port on S2?

A.It becomes a designated port ✅
B.It remains the root port
C.It becomes a blocked port
D.It becomes a backup port
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The root port on a non‑root switch is the port that provides the lowest‑cost path to the root bridge. When the root changes, the former root port no longer leads to the root and is re‑evaluated, typically becoming a designated (forwarding) port on the new tree.

Q13. Explain how the principle of “only one path between any two LANs” in a spanning‑tree eliminates broadcast storms.

A.It limits the number of broadcast frames
B.It prevents duplicate frame forwarding ✅
C.It disables broadcasts entirely
D.It routes broadcasts through a central hub
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Having a single logical path means a broadcast frame can travel only once to each LAN. Any duplicate copies that would have traversed a loop are suppressed because the blocked ports stop forwarding them, thereby preventing the exponential growth characteristic of broadcast storms.

Q14. If the cost of link S1‑S2 is increased from 1 to 10, which impact is most likely on the spanning‑tree topology?

A.S1‑S2 becomes the root port
B.An alternate path may be selected ✅
C.No impact
D.The network partitions
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Raising the cost makes the S1‑S2 link less attractive for the lowest‑cost path. The algorithm will therefore look for an alternate route with a lower total cost, potentially changing which ports are designated or blocked to maintain the minimal‑cost tree.

Q15. Suppose two switches accidentally broadcast identical IDs during BPDU exchange. What inference can be drawn about the algorithm's behavior?

A.The algorithm will select both as root
B.The algorithm will reject both and wait for new IDs
C.The algorithm will break ties using MAC address ✅
D.The algorithm will cause a loop
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The spanning‑tree protocol includes a tie‑breaking rule that uses the MAC address when bridge IDs are identical. This ensures a deterministic selection of a single root bridge, avoiding ambiguity and preventing loops.

Q16. Synthesize the steps required to manually configure a spanning‑tree versus allowing switches to run the protocol dynamically. Which step is eliminated by dynamic operation?

A.Assigning port costs
B.Selecting the root bridge
C.Marking forwarding and blocking ports
D.All of the above ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: When switches run the spanning‑tree protocol automatically, they exchange BPDUs to discover IDs, compute costs, elect the root bridge, and assign port roles without human intervention. Consequently, every manual step—cost assignment, root selection, and port marking—is performed by the protocol itself.

Q17. Under what condition does a previously blocked port transition to forwarding after a topology change?

A.When it receives a BPDU with lower cost ✅
B.When the root bridge fails
C.When the link cost becomes zero
D.When the port is manually enabled
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A blocked port monitors incoming BPDUs. If a BPDU arrives indicating a lower‑cost path to the root than the current tree, the port re‑evaluates its role and may become a designated forwarding port to restore optimal connectivity.

B.LAN attached to S2 and LAN attached to S3

📖 Explanation: The total cost from S1 to S4 via S2 is , which is lower than the direct cost of 4 via S3. Therefore the shortest‑path tree connects S1 to S4 through S2, making the LANs on S1 and S4 use that route.

Q19. How does the spanning‑tree mechanism contribute to congestion control in a LAN environment?

A.By limiting the number of active paths ✅
B.By increasing bandwidth
C.By prioritizing traffic
D.By buffering frames
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Spanning‑tree removes redundant paths, ensuring that only a single logical route exists between any two points. This reduces the chance of duplicate frames and excessive traffic, which indirectly helps keep congestion levels manageable, especially under heavy broadcast or multicast loads.

Q20. What term describes the role of a port that participates in forwarding frames in the spanning‑tree algorithm?

A.Root port
B.Designated port ✅
C.Blocking port
D.Backup port
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A designated port is the forwarding port for a given LAN segment. It is responsible for transmitting frames toward the rest of the network while other ports on the same segment may be placed in a blocking state to avoid loops.

Q21. Compare the effectiveness of spanning‑tree versus link‑layer flow control (e.g., IEEE 802.3x) in preventing congestion.

A.STP prevents loops but does not control queue buildup, while flow control directly pauses transmission ✅
B.Both provide identical congestion mitigation
C.Flow control eliminates loops, STP does not
D.STP increases congestion, flow control reduces it
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Spanning‑tree’s purpose is to eliminate loops; it does not address buffer overrun or queuing issues. In contrast, link‑layer flow control can temporarily halt transmission from a congested sender, directly mitigating congestion at the physical layer.

Q22. If the hop count from a switch to its attached LAN is defined as 1, what does a hop count of 0 in the reverse direction indicate about frame processing?

A.The frame is discarded
B.The frame has already reached its destination ✅
C.The switch adds no cost when receiving
D.The LAN does not forward frames
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A hop count of 0 when moving from the LAN back to the switch signifies that the frame has arrived at its final destination; no additional traversal is required, so the count remains zero.

Q23. Design a network of five switches (S1‑S5) with link costs such that the total cost of the spanning‑tree is minimized while still providing a backup path for each LAN. Which of the following cost assignments best meets the criteria?

A.All links cost 1
B.Costs {S1‑S2=1, S2‑S3=2, S3‑S4=1, S4‑S5=2, S5‑S1=3}

📖 Explanation: Assigning low costs to the four sequential links creates a low‑cost primary tree, while the high‑cost link S5‑S1 provides a backup path without significantly raising the total cost of the primary spanning‑tree. This balances minimal cost with redundancy.
