What is Packetizing in network layer?

Packetizing is the process where the network layer encapsulates transport layer segments into packets or datagrams by adding a network header containing addressing and control information needed for delivery across interconnected networks.

Q1. If a station moves from VLAN 1 to VLAN 2, which broadcast traffic will it receive?

A. Receives broadcasts from both VLAN 1 and VLAN 2
B. Receives only broadcasts from VLAN 2 ✅
C. Receives only broadcasts from VLAN 1
D. Receives no broadcasts

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When a station is reassigned to VLAN 2, its link‑layer membership changes, so it joins the broadcast domain of VLAN 2 only. Broadcast frames are limited to the VLAN of the receiving port, therefore the station no longer sees VLAN 1 broadcasts.

Q2. Compare using interface numbers versus MAC addresses for VLAN membership. Which statement is most accurate?

A. Interface numbers are static while MAC‑address membership can be dynamic ✅
B. Interface numbers require hardware changes, MAC‑address membership uses only software
C. Both methods need the same amount of configuration effort
D. MAC addresses cannot be used to define VLANs

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Interface‑number VLANs bind a device to a specific physical port, making the assignment static. MAC‑address VLANs rely on the device’s 48‑bit address, allowing the switch to place any host with that address into the VLAN regardless of physical location, giving a dynamic, software‑driven approach.

Q3. How many broadcast domains exist in a network that implements three separate VLANs?

A. One
B. Two
C. Three ✅
D. Four

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Each VLAN defines its own broadcast domain, isolating broadcast traffic from the others. Thus, three distinct VLANs create three independent broadcast domains, regardless of the underlying physical topology. No additional domains are formed unless further segmentation mechanisms are introduced.

Q4. A backbone switch connects two access switches, each carrying VLAN 1 and VLAN 2. A frame arrives at the backbone tagged with VLAN 2. Which ports will forward the frame?

A. Only ports leading to devices that belong to VLAN 2 ✅
B. All ports on the backbone switch
C. Only ports on the same access switch where the frame entered
D. No ports; the frame is dropped

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The VLAN tag identifies the frame’s broadcast domain. The backbone switch consults its VLAN table and forwards the frame solely out ports that are members of VLAN 2, preventing leakage into VLAN 1 ports and preserving VLAN isolation.

Q5. Which characteristic gives the greatest flexibility for moving stations between VLANs without altering hardware?

A. Interface numbers
B. Port numbers
C. MAC addresses
D. IP addresses ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

IP addresses operate at Layer 3 and are independent of the physical port a device uses. By reassigning an IP subnet to a different VLAN, a station can change its VLAN membership simply by updating its IP configuration, avoiding any need to rewire or re‑port the device.

Q6. In a two‑building campus linked by a backbone, how does VLAN configuration affect broadcast traffic between the buildings?

A. Broadcasts are confined to each VLAN regardless of building ✅
B. Broadcasts cross buildings only if VLANs are separate
C. Broadcast traffic is eliminated entirely
D. Broadcasts are duplicated on both buildings

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

VLANs define logical broadcast domains that overlay the physical topology. Even when the physical links span separate buildings, a broadcast is delivered only to ports that share the same VLAN ID, so each VLAN’s broadcast remains isolated from other VLANs across the backbone.

Q7. VLAN 3 consists of ports 5, 6, 9. A device on port 5 sends an untagged frame. What must the switch do to deliver it correctly?

A. Tag the frame with VLAN 3’s identifier ✅
B. Discard the frame as invalid
C. Flood the frame to all ports
D. Forward the frame unchanged

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When a frame enters a port that belongs to a specific VLAN, the switch inserts the appropriate VLAN tag before forwarding. This tagging ensures that downstream switches recognize the frame as part of VLAN 3 and restrict delivery to ports that are members of that VLAN.

Q8. Which statement correctly contrasts the security impact of MAC‑address‑based VLANs versus IP‑address‑based VLANs?

A. MAC‑based VLANs prevent IP spoofing
B. IP‑based VLANs enable easier isolation of subnets ✅
C. MAC‑based VLANs require less processing overhead
D. IP‑based VLANs cannot be implemented on switches

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

IP‑address‑based VLANs align with Layer 3 subnet boundaries, allowing administrators to enforce access controls and firewall policies per subnet. This logical separation simplifies the creation of secure zones, whereas MAC‑address VLANs operate at Layer 2 and do not directly map to IP routing or subnet security mechanisms.

Q9. An administrator wishes to create a VLAN that includes every device using the IP multicast range 224.0.0.0/4. Which membership method should be used?

A. Interface numbers
B. MAC addresses
C. IP multicast addresses ✅
D. Port numbers

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

VLAN membership can be defined by matching packet header fields. Selecting the IP multicast address range as the criterion directly captures all hosts that send or receive traffic within that range, ensuring they share the same VLAN without needing to enumerate individual ports or MAC addresses.

Q10. Three VLANs each contain ten stations. After each VLAN sends one broadcast, how many broadcast frames will a single station in VLAN 2 receive?

A. Twenty
B. Thirty
C. Ten ✅
D. Zero

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Broadcast traffic is confined to the VLAN of the originating station. Therefore, the station in VLAN 2 only receives the broadcast originating from its own VLAN, which consists of ten stations. Broadcasts from VLAN 1 and VLAN 3 never reach it, so the total received frames equal ten.

Q11. When migrating from port‑number VLANs to MAC‑address VLANs, which network function is most likely to increase in workload?

A. Number of static configuration entries
B. Need for MAC address learning by the switch ✅
C. Overall broadcast traffic volume
D. Physical cable length between devices

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

MAC‑address‑based VLANs require the switch to examine each incoming frame’s source MAC address and map it to the appropriate VLAN. This adds processing overhead for MAC learning and VLAN lookup, whereas port‑number VLANs rely on fixed port assignments that do not depend on address inspection.

Q12. A VLAN is defined by a combination of IP address and MAC address. What primary benefit does this hybrid approach provide?

A. Simplified routing tables
B. Enhanced granularity for access control ✅
C. Reduced network latency
D. Elimination of VLAN tagging

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Combining IP and MAC criteria allows administrators to enforce policies that consider both logical (IP subnet) and physical (device identifier) attributes. This dual‑layer filtering yields finer‑grained access control, enabling scenarios such as permitting a specific host in a subnet while blocking others, thereby strengthening security.
