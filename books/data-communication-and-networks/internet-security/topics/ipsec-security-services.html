📝 IPSec security services (12 MCQs)

Security Objectives Applied to IP Datagrams

IPsec can protect IP communication against eavesdropping, packet modification, forged sources, and replay of previously captured traffic. Its available services include confidentiality, connectionless integrity, data-origin authentication, access control, and anti-replay protection. Limited traffic-flow confidentiality may also be supported. The exact combination depends on whether AH or ESP is selected and on the parameters negotiated for each Security Association. for individual directions and traffic selectors.

Confidentiality, Integrity and Peer Authentication

Confidentiality uses encryption to conceal packet contents from unauthorized observers. Integrity allows a receiver to detect unauthorized changes, while data-origin authentication links accepted traffic to a holder of the appropriate cryptographic key. Anti-replay checks use sequence information to reject repeated packets. These properties are related but distinct; encryption alone should not be treated as proof of integrity.

Applying Services Through a Security Association

An administrator defines policy for selected traffic, and IPsec uses AH or ESP under an SA to apply the required services. The sender protects each matching datagram with keys and algorithms associated with that SA. The receiver checks the applicable integrity, authentication, and sequence information, then decrypts ESP data when confidentiality has been selected.

Protecting a Confidential Business Application

A financial office sends database requests across the Internet through an ESP tunnel. Encryption prevents intermediate networks from reading the protected inner packet, while an integrity check helps the receiving gateway detect modification. Sequence-number checks reject accepted duplicates outside the replay window. Together, these mechanisms protect more than secrecy alone during packet delivery.

Services and Their Relationship to Network Architecture

IPsec security is independent of individual application formats because it operates at the IP layer. TCP sessions, UDP queries, and other IP traffic can receive the same policy-based protection. Routing still needs usable IP headers, and key management must establish the cryptographic state required by the selected services before protected traffic can flow.

Match AH and ESP capabilities to those objectives, and note optional service selection within an SA. IPsec Security-Service Terminology

  • Confidentiality - Prevents unauthorized disclosure of data.
  • Integrity - Detects changes to transmitted data.
  • Data-origin authentication - Verifies packet source using keys.
  • Anti-replay - Rejects repeated packets by sequence.
  • Access control - Applies policy to network traffic.
  • Traffic-flow confidentiality - Hides some packet timing patterns.
