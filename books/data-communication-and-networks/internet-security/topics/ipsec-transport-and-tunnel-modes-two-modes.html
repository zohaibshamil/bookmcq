Q1. What is another term for static arithmetic coding?

🔹 A. Pure coding
🔹 B. Interval coding
🔹 C. Dynamic coding
🔹 D. Adaptive coding

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Static arithmetic coding is often called pure coding because it uses a fixed probability model that does not change during encoding. The term emphasizes that the coding process is ‘pure’ in the sense that the probabilities are predetermined and remain unchanged throughout the message.

Q2. In arithmetic decoding, what does the variable 'num' represent?

🔹 A. The lower bound of the current interval
🔹 B. A random seed
🔹 C. The encoded real number within [0,1)
🔹 D. The length of the symbol alphabet

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The variable ‘num’ stores the real value that was produced by the encoder and lies in the unit interval [0,1). During decoding the algorithm repeatedly compares this value against the sub‑intervals of the current interval to determine which symbol was encoded.

Q3. If the current interval is [0,1) and the probability model assigns symbol A to subinterval [0,0.3) and symbol B to [0.3,0.7), which symbol will be output when the encoded number is 0.45?

🔹 A. Symbol A
🔹 B. Symbol B
🔹 C. Symbol C
🔹 D. Symbol D

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The encoded number 0.45 falls inside the subinterval [0.3,0.7) that corresponds to symbol B. The decoder therefore selects B as the next output symbol, because the number lies within B’s allocated range according to the probability model.

Q4. During decoding, after processing the first two symbols, the interval becomes [0.4,0.6). If the next encoded number is 0.55, which symbol's subinterval must contain 0.55 for the decoder to output the third symbol?

🔹 A. Symbol X
🔹 B. Symbol Y
🔹 C. Symbol Z
🔹 D. Symbol W

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When the current interval is narrowed to [0.4,0.6), the decoder divides this range according to the probability model. For the encoded number 0.55 to be interpreted as the third symbol, the subinterval assigned to the correct symbol must enclose 0.55. In the given model, that symbol is X.

Q5. Given the decoding loop stops when the terminating symbol '*' is encountered, and the current interval after processing symbol 'B' is [0.64,0.69), which of the following encoded numbers will cause the loop to terminate at the next iteration?

🔹 A. 0.65
🔹 B. 0.7
🔹 C. 0.68
🔹 D. 0.63

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The terminating symbol '*' is mapped to a subinterval that lies at the upper end of the current interval, for example [0.68,0.70). An encoded number of 0.68 falls inside this subinterval, so the decoder will identify '*' and exit the loop immediately.

Q6. Which statement correctly contrasts static and dynamic arithmetic coding regarding probability model updates?

🔹 A. Static coding updates probabilities after each symbol, while dynamic coding keeps them fixed.
🔹 B. Static coding uses a fixed model, while dynamic coding updates probabilities after each symbol.
🔹 C. Both modes update probabilities continuously.
🔹 D. Neither mode uses probability models.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

In static (or pure) arithmetic coding, the probability distribution is established before encoding begins and remains unchanged. Dynamic (or interval) coding, on the other hand, revises the symbol probabilities after each encoded symbol, allowing the model to adapt to the actual data stream.

Q7. For a highly skewed symbol distribution, which coding mode typically yields a smaller average code length?

🔹 A. Static coding
🔹 B. Dynamic coding
🔹 C. Both produce equal lengths
🔹 D. Neither is effective

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When one symbol dominates the distribution, dynamic coding can quickly assign it a large probability, shrinking its subinterval and reducing the number of bits needed. Consequently, dynamic coding generally achieves a shorter average code length than static coding for skewed sources.

Q8. If an error corrupts a bit in the middle of an arithmetic coded stream, how does the impact differ between static and dynamic coding on decoder synchronization?

🔹 A. Both modes immediately recover synchronization.
🔹 B. Static coding loses synchronization for the rest of the stream, while dynamic coding may recover after a few symbols.
🔹 C. Dynamic coding loses synchronization permanently, static coding may recover.
🔹 D. Both modes suffer permanent loss of synchronization.

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

An error changes the numeric value used by the decoder, causing the interval boundaries to diverge from the encoder’s. Because both static and dynamic coding rely on the same interval calculations, a single error typically desynchronizes the decoder for the remainder of the message, making recovery impossible without external error‑correction.

Q9. What is the computational complexity per symbol for static and dynamic arithmetic coding?

🔹 A. Both are O(1)
🔹 B. Static is O(1) and dynamic is O(log n)
🔹 C. Static is O(n) and dynamic is O(1)
🔹 D. Both are O(n)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Both static and dynamic arithmetic coding perform a constant number of arithmetic operations for each symbol: scaling the interval and updating bounds. Even though dynamic coding also updates the probability model, this update can be done in constant time, so the per‑symbol complexity remains O(1) for both.

Q10. When encoding a large alphabet such as Unicode, which trade‑off is most accurate between memory usage and compression efficiency for the two modes?

🔹 A. Static coding requires low memory but yields poor compression.
🔹 B. Dynamic coding uses less memory but may achieve slightly lower compression efficiency.
🔹 C. Static coding uses more memory and always gives better compression.
🔹 D. Dynamic coding uses more memory and provides worse compression.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Static coding must store a full probability table for the entire alphabet, which can be memory‑intensive for Unicode. Dynamic coding builds and updates probabilities on the fly, reducing memory demands. However, because the model adapts incrementally, the compression ratio may be marginally lower than a perfectly tuned static model.

Q11. Given the interval [0,1) and encoded number 0.68, after the first division the subinterval for symbol 'B' is [0.64,0.69). What will be the new current interval?

🔹 A. [0.64,0.69)
🔹 B. [0.68,0.70)
🔹 C. [0.6,0.7)
🔹 D. [0.5,0.8)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

When the decoder identifies that the encoded number 0.68 lies inside the subinterval assigned to symbol 'B' ([0.64,0.69)), it sets this subinterval as the new current interval for subsequent decoding steps. Hence the interval becomes exactly [0.64,0.69).}

Q12. If during arithmetic decoding the pointer moves from interval [0.4,0.6) to [0.5,0.55) after processing symbol 'A', what can be inferred about the relative probability of 'A' versus other symbols?

🔹 A. Symbol A has a relatively high probability.
🔹 B. Symbol A has a relatively low probability.
🔹 C. All symbols have equal probability.
🔹 D. No inference can be made.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A narrower interval after processing a symbol indicates that the symbol occupied a larger portion of the previous interval, which corresponds to a higher probability. The reduction from a width of 0.2 to 0.05 suggests that 'A' was assigned a comparatively high probability by the model.

Q13. In dynamic arithmetic coding, after processing three symbols the interval is [0.825,0.845) and the next encoded number is 0.83. Which statement is necessarily true?

🔹 A. The next symbol's subinterval must contain 0.83.
🔹 B. The interval will expand to include 0.83.
🔹 C. The decoder must reset the interval.
🔹 D. The encoded number is outside the interval.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The encoded number always lies within the current interval. Therefore, if the interval is [0.825,0.845) and the number is 0.83, the decoder will subdivide this interval according to the probability model, and the subinterval that contains 0.83 will correspond to the next decoded symbol.

Q14. How does the terminating symbol '*' affect the termination condition in the decoding loop?

🔹 A. It signals the end of the message.
🔹 B. It resets the current interval to [0,1).
🔹 C. It is ignored by the decoder.
🔹 D. It doubles the interval size.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When the decoder encounters the terminating symbol '*', it interprets this as a command to stop processing further symbols. In many implementations the loop exits immediately, and the current interval is often reset to its initial state [0,1) for any subsequent decoding tasks.

Q15. Suppose a static coder uses a probability model where symbol 'C' has probability 0.0. What consequence does this have for encoding a message that contains 'C'?

🔹 A. Encoding is impossible because a zero‑width subinterval would be required.
🔹 B. The interval collapses but encoding proceeds.
🔹 C. The coder substitutes another symbol automatically.
🔹 D. The probability is adjusted to a small non‑zero value.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A probability of zero creates a subinterval of zero length, which cannot contain any real number. Consequently, the arithmetic encoder cannot assign a valid code to symbol 'C', making it impossible to encode any message that includes that symbol without altering the model.
