📖 Unicast Routing

Unicast Routing And The Search For Paths

Unicast routing determines how packets travel from a source network to a specific destination across interconnected routers. Routing algorithms evaluate available paths using metrics such as hop count, cost, bandwidth, and delay. Distance Vector, Link State, and Path Vector approaches provide different methods for exchanging routing information and selecting routes. RIP and OSPF support routing within autonomous systems, while BGP-4 coordinates routing between them. These mechanisms build on IPv4 addressing and packet forwarding to establish scalable communication across the global Internet.


IP Forwarding And Network Topology Fundamentals

Students should understand IPv4 addresses, subnet masks, routers, forwarding tables, and packet delivery. Familiarity with network topology, autonomous systems, ISP connections, and routing metrics supports algorithm comparisons. Basic knowledge of binary addressing and shortest-path concepts also helps explain route calculations, prefix advertisements, and inter-domain connectivity.


Skills For Evaluating Unicast Routing Algorithms

Students should be able to explain routing metrics, compare Distance Vector, Link State, and Path Vector algorithms, and perform Bellman-Ford and Dijkstra calculations. They should distinguish autonomous systems and ISP hierarchies, identify RIP version differences, explain OSPF areas and LSAs, and describe how BGP-4 exchanges routes between autonomous systems using path attributes and routing policies.


Routing Algorithms From Local Paths To Internet

  • Routing Principles And Least-Cost Metrics - Introduces route selection using hop count, administrative cost, bandwidth, and delay measurements.
  • Distance Vector And Link State Algorithms - Explains Bellman-Ford route updates and Dijkstra shortest-path calculations through network topologies.
  • Path Vector And Internet Autonomous Systems - Describes path-based route advertisements and the hierarchical organization of autonomous systems and ISPs.
  • RIP Version One And Two - Compares hop-count routing, routing updates, classful addressing, and classless prefix support.
  • OSPF Areas And Link State Advertisements - Covers hierarchical routing areas, the backbone area, LSAs, and shortest-path computation.
  • BGP-4 Interdomain Routing - Explains external route advertisements, autonomous system paths, path attributes, and policy-based route selection.

A Learning Sequence From Metrics To BGP

Begin with routing fundamentals and least-cost metrics to understand how routers compare available paths. Study Distance Vector and Link State algorithms before examining Path Vector routing. Next, connect these algorithms with Internet autonomous systems and ISP relationships. Compare RIP versions, then study OSPF areas and LSAs. Finish with BGP-4 to understand how independent administrative networks exchange routes and apply routing policies.


How Routing Algorithms Build Global Reachability

Least-cost metrics provide the basis for comparing candidate paths. Distance Vector routers exchange destination costs, while Link State routers construct a network map for Dijkstra calculations. Path Vector adds autonomous-system path information and policy considerations. RIP implements Distance Vector routing, OSPF implements Link State routing within an autonomous system, and BGP-4 exchanges reachability information between autonomous systems.


A Packet Crossing OSPF And BGP Networks

A computer at 192.0.2.10 sends a packet to 198.51.100.20 through gateway 192.0.2.1. Inside AS 64496, OSPF calculates two candidate paths: R1-R2-R4 with costs 5 and 10, and R1-R3-R4 with costs 8 and 12. The first path has a total cost of 15 and is selected. At the AS boundary, BGP-4 selects an external route toward AS 64497 according to its routing policies and path attributes. The destination network receives the forwarded packet.


Why Routing Algorithms Enable Internet Scalability

Without routing algorithms, routers would lack an organized method for discovering reachable networks and selecting forwarding paths. Manual route management would become impractical as networks expanded. RIP, OSPF, and BGP-4 address different routing environments, supporting local network reachability, hierarchical organization, and communication between independently managed Internet networks.


Distinguishing Distance Vector Link State And BGP

Students may say 'OSPF exchanges complete routing tables like RIP'; OSPF distributes link-state information and calculates routes from a topology database. They may say 'BGP selects only the shortest physical path'; BGP considers policy and multiple path attributes. They may also say 'RIP uses bandwidth as its metric'; RIP uses hop count, with 16 representing infinity and unreachable destinations.


Route Calculations And Protocol Comparisons

Exam questions commonly require Bellman-Ford updates, Dijkstra shortest-path calculations, and least-cost route comparisons. Other questions distinguish Distance Vector, Link State, and Path Vector mechanisms. RIP problems test hop-count limits and version differences, while OSPF questions focus on areas and LSAs. BGP questions examine autonomous-system paths, inter-domain advertisements, path attributes, and policy-based route selection.


How Unicast Protocols Organize Network Reachability

Unicast routing combines path calculation, routing-information exchange, and forwarding decisions to deliver packets across networks. Distance Vector and Link State algorithms establish routes through different information-sharing methods, while Path Vector supports policy-aware inter-domain communication. RIP and OSPF serve different internal routing environments, and BGP-4 connects autonomous systems. Together, these protocols maintain reachability across networks ranging from small organizations to the global Internet.


Official Specifications For RIP OSPF And BGP

  • RFC 2453 - Defines RIP version 2, including routing updates, authentication, and classless routing information.
  • RFC 2328 - Specifies OSPF version 2, including link-state advertisements, areas, and shortest-path calculations.
  • RFC 4271 - Defines the Border Gateway Protocol version 4 and its inter-autonomous-system routing procedures.
  • RFC 4274 - Provides an overview of BGP-4 protocol analysis, operation, and implementation considerations.

Essential Terms For Unicast Routing Protocols

  • Routing Metric - A value used to evaluate the suitability of a network path.
  • Distance Vector - A routing approach that exchanges destination distances and next-hop information with neighbouring routers.
  • Link State Advertisement - An OSPF message distributing information about network links and their states.
  • Path Vector - A routing approach that advertises network reachability together with autonomous-system path information.
  • Autonomous System - A collection of IP networks managed under a common routing administration and policy.
  • RIP - A Distance Vector routing protocol that selects routes using hop count.
  • OSPF - A Link State routing protocol that calculates shortest paths using network topology information.
  • BGP-4 - An inter-domain routing protocol that exchanges network reachability information between autonomous systems.
