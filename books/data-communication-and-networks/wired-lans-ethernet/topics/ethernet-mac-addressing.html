📝 All Ethernet MAC addressing MCQs

Q1. What is the standard 8‑bit flag pattern used in bit‑oriented framing?

🔹 A. 1111110
🔹 B. 11111111
🔹 C. 0
🔹 D. 10101010

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The flag 01111110 is defined by HDLC and many bit‑oriented protocols as the unique 8‑bit delimiter that marks the start and end of a frame. The other patterns are either all ones, all zeros, or a simple alternating pattern, none of which serve as the protocol‑defined flag.

Q2. In bit‑oriented protocols, which layer interprets the data section of a frame?

🔹 A. Physical
🔹 B. Data Link
🔹 C. Network
🔹 D. Application

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The data payload of a frame is delivered to the upper protocol layer, which for most network models is the Application layer. The lower layers (Physical, Data Link, Network) handle transmission, framing, and routing, but they do not interpret the payload as user data.

Q3. If a transmitted frame contains the bit pattern 01111110 within its data, what mechanism is used to prevent misinterpretation as a flag?

🔹 A. Bit stuffing
🔹 B. Byte stuffing
🔹 C. CRC
🔹 D. Parity

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Bit stuffing inserts a complementary 0 after any occurrence of five consecutive 1s, ensuring that the flag pattern 01111110 cannot appear unintentionally inside the data. This preserves the uniqueness of the flag while allowing any user data to be transmitted.

Q4. Given that 32‑bit characters may contain the flag pattern, what is the impact on frame synchronization if bit stuffing is not applied?

🔹 A. No impact
🔹 B. Slight delay
🔹 C. Loss of synchronization
🔹 D. Improved throughput

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Without bit stuffing, a 32‑bit character that accidentally matches the flag sequence would be mistaken for a frame delimiter, causing the receiver to lose track of where frames begin and end. This loss of synchronization leads to corrupted data streams.

Q5. In a system moving from byte‑oriented to bit‑oriented protocols, what is a likely consequence for error detection mechanisms?

🔹 A. CRC can be removed
🔹 B. Need for more complex CRC polynomial
🔹 C. Bit stuffing eliminates errors
🔹 D. Frame check sequence must be recalculated per bit

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Transitioning to bit‑oriented framing often requires a CRC that operates on the bit stream rather than on byte boundaries. Consequently, a more sophisticated polynomial may be chosen to maintain detection capability across arbitrary bit patterns.

Q6. Compare the overhead introduced by byte stuffing versus bit stuffing in a high‑speed network.

🔹 A. Byte stuffing adds fewer bits
🔹 B. Bit stuffing adds fewer bits
🔹 C. Both add same overhead
🔹 D. Byte stuffing adds more bits only for control characters

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Bit stuffing only inserts a single 0 after five consecutive 1s, while byte stuffing may need to escape every occurrence of a control character, potentially adding an entire extra byte. Therefore, bit stuffing generally incurs less overhead in high‑speed traffic.

Q7. Evaluate the advantage of using an 8‑bit flag pattern versus a longer unique delimiter.

🔹 A. Shorter flag reduces overhead
🔹 B. Longer delimiter improves security
🔹 C. Shorter flag increases false positives
🔹 D. Longer delimiter reduces processing time

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A concise 8‑bit flag minimizes the number of bits transmitted solely for framing, reducing overall overhead. Although longer delimiters could lower the chance of accidental occurrence, the added bits diminish efficiency, making the short flag preferable for most applications.

Q8. Differentiate between 32‑bit character handling in byte‑oriented and bit‑oriented framing regarding delimiter detection.

🔹 A. Bit-oriented uses escape characters
🔹 B. Byte-oriented uses bit stuffing
🔹 C. Bit-oriented uses flag and stuffing
🔹 D. Byte-oriented uses CRC only

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

In bit‑oriented framing, a special flag marks frame boundaries, and bit stuffing guarantees that the flag never appears in the data. Byte‑oriented schemes rely on character‑level escape sequences, which can be less flexible when dealing with multi‑byte characters.

Q9. Analyze how the transition to bit‑oriented framing affects compatibility with legacy 8‑bit character applications.

🔹 A. No compatibility issues
🔹 B. Requires translation layers
🔹 C. Legacy apps can directly use bit‑oriented frames
🔹 D. Compatibility is automatic

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Legacy applications expect byte‑oriented streams; moving to bit‑oriented framing introduces flag bits and stuffing that these applications cannot interpret. Therefore, intermediary translation or adaptation layers are needed to bridge the gap.

Q10. Contrast the processing complexity of detecting flag patterns in bit‑oriented framing vs byte‑oriented framing.

🔹 A. Bit-oriented requires byte‑level scanning
🔹 B. Byte-oriented requires bit‑level scanning
🔹 C. Bit-oriented requires bit‑level scanning
🔹 D. Both require same complexity

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Detecting a flag in bit‑oriented protocols involves examining the stream one bit at a time to locate the 01111110 pattern, which is more granular than scanning whole bytes for a specific escape character in byte‑oriented protocols.

Q11. When data contains five consecutive 1s, how many extra bits are inserted by bit stuffing?

🔹 A. 0
🔹 B. 1
🔹 C. 2
🔹 D. 5

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Bit stuffing dictates that after any sequence of five consecutive 1s, a single 0 is inserted to break the pattern. This ensures that the flag sequence cannot be formed unintentionally, adding exactly one extra bit for each such occurrence.

Q12. How does flag delimiting combined with bit stuffing ensure reliable communication?

🔹 A. Flags mark boundaries, stuffing keeps data transparent
🔹 B. Flags encrypt data
🔹 C. Stuffing compresses data
🔹 D. Flags replace CRC

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The flag provides a clear start and end marker for each frame, while bit stuffing guarantees that the flag pattern never appears within the payload. Together they maintain data transparency and allow the receiver to reliably detect frame limits.

Q13. Synthesize a scenario where using bit‑oriented framing improves video streaming performance compared to byte‑oriented framing.

🔹 A. Bit-oriented reduces latency
🔹 B. Byte-oriented provides better compression
🔹 C. Bit-oriented increases overhead
🔹 D. Byte-oriented supports higher resolution

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Video streams consist of large, continuous bit streams where minimizing framing overhead is critical. Bit‑oriented framing introduces only a short flag and occasional stuffing bits, reducing latency and bandwidth consumption relative to byte‑oriented schemes that may add larger escape sequences.

Q14. Design a mixed‑media protocol using bit‑oriented framing. Which element is essential to maintain synchronization?

🔹 A. Fixed‑length frames
🔹 B. Unique start‑of‑packet byte
🔹 C. Flag pattern with bit stuffing
🔹 D. Time stamps

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

A flag pattern such as 01111110, together with bit stuffing, provides unambiguous frame delimiters regardless of the media type. Without this mechanism, variable‑length text, audio, or video payloads could cause loss of synchronization.

Q15. Why does moving toward bit‑oriented protocols align with increasing data rates and complex media types?

🔹 A. They are slower
🔹 B. They provide higher overhead
🔹 C. They allow efficient bit‑level packing and flexible delimiters
🔹 D. They require more hardware

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Bit‑oriented protocols operate on the raw bit stream, enabling tighter packing, reduced framing overhead, and adaptable delimiters. This efficiency is essential for high‑throughput environments and media that demand precise timing and minimal latency.

Q16. If a frame’s flag pattern changes to 01111010 due to errors, what can be inferred about error detection?

🔹 A. Error will be undetected
🔹 B. CRC will likely detect error
🔹 C. Flag will still be recognized
🔹 D. No effect on detection

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The altered pattern no longer matches the valid flag, so the frame will be rejected. A correctly computed CRC over the entire frame will almost certainly flag the inconsistency, indicating that the error will be detected.

Q17. Increasing the flag length from 8 bits to 12 bits changes the probability of accidental appearance in random data how?

🔹 A. Increases linearly
🔹 B. Decreases exponentially
🔹 C. Remains same
🔹 D. Doubles

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Each additional bit halves the chance of a random sequence matching the flag. Extending the flag from 8 to 12 bits reduces the probability by a factor of 2⁴ = 16, yielding an exponential decrease in accidental occurrences.

Q18. When transmitting a payload with 30% ones, which framing is more bandwidth‑efficient?

🔹 A. Bit-oriented
🔹 B. Byte-oriented
🔹 C. Both equal
🔹 D. Depends on CRC

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Bit‑oriented framing only adds a flag and occasional stuffing bits, whereas byte‑oriented framing may require escape characters for each control byte. With a substantial proportion of ones, bit stuffing adds fewer bits, making bit‑oriented framing more efficient.
