What is Standard Ethernet characteristics and frame format?

Standard Ethernet operates at 10 Mbps using a specific frame structure containing preamble, destination and source MAC addresses, type/length field, payload data (46–1500 bytes), and a frame check sequence for error detection, with minimum and maximum frame sizes ensuring proper collision detection and efficient transmission.

📝 All Standard Ethernet characteristics and frame format MCQs

Q1. Which of the following services is NOT provided by PPP?

A.Flow control ✅
B.Error detection via CRC
C.Frame delimiting
D.Multipoint addressing
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: PPP was designed as a simple link‑layer protocol; it does not include flow‑control mechanisms, leaving that responsibility to higher layers. The other listed functions—error detection, frame delimiting, and basic addressing—are part of PPP’s defined services.

Q2. What field does PPP use to detect errors in a transmitted frame?

A.Length field
B.Flag field
C.CRC field ✅
D.Address field
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The cyclic redundancy check (CRC) field is appended to each PPP frame. Receivers compute the CRC over the received bits and compare it to the transmitted value; a mismatch indicates corruption, prompting the frame to be discarded.

Q3. If PPP silently discards a corrupted frame, what must the upper‑layer protocol do to maintain reliable communication?

A.Retransmit the frame ✅
B.Ignore the loss
C.Request a new connection
D.Re‑encode the data
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Because PPP does not provide retransmission, the responsibility for recovering lost data falls to higher‑layer protocols such as TCP. Those protocols detect missing data (e.g., via sequence numbers) and request retransmission, ensuring end‑to‑end reliability despite PPP’s best‑effort delivery.

Q4. When a sender transmits PPP frames faster than the receiver can process, which outcome is most likely?

A.Receiver buffer overflow causing frame loss ✅
B.Automatic flow control slows the sender
C.Frames are reordered
D.CRC errors increase
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: PPP lacks flow‑control signals, so the receiver cannot tell the sender to pause. If the incoming rate exceeds the receiver’s buffer capacity, excess frames will be dropped, leading to loss without any notification to the sender.

Q5. In a multipoint network using PPP without a sophisticated addressing mechanism, what is the most probable effect on frame delivery?

A.Frames are broadcast to all nodes
B.Only the intended receiver gets the frame
C.Frames may be misdelivered or ignored ✅
D.PPP automatically resolves address conflicts
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: PPP’s simple address field is insufficient for distinguishing many endpoints. In a multipoint environment, frames may be received by nodes that cannot recognize them as intended, causing them to be discarded or ignored, which reduces reliability and requires additional protocol layers for proper addressing.

Q6. On a link where the bit error rate is 5 % and PPP discards corrupted frames, how does the effective throughput compare to a protocol that uses ARQ with retransmissions?

A.Higher throughput because PPP avoids retransmission overhead
B.Similar throughput because both discard errors
C.Lower throughput due to frequent frame loss ✅
D.Throughput is unaffected by error rate
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: With a 5 % error rate, many PPP frames are dropped, so the receiver obtains fewer useful bits. Protocols employing ARQ would retransmit lost frames, preserving data integrity and typically achieving higher effective throughput despite the added overhead, especially when errors are frequent.

Q7. Without sequence numbers, what can be inferred about the order of packets received over PPP?

A.Packets are always in order
B.Packets may arrive out of order ✅
C.Packets are reordered by PPP
D.Order is guaranteed by the physical layer
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Because PPP does not attach sequence numbers, it provides no guarantee that frames will be delivered in the same order they were sent. If the underlying medium reorders bits or frames, the receiving side may observe out‑of‑order delivery, and higher layers must handle any required reassembly.

Q8. Which statement correctly compares PPP’s error handling with a protocol that employs automatic repeat request (ARQ)?

A.PPP corrects errors via CRC while ARQ only detects them
B.PPP discards erroneous frames and relies on upper layers ✅
C.ARQ discards frames without notification
D.Both use the same retransmission strategy
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: PPP’s approach is to detect errors using a CRC field and then silently drop the corrupted frame. In contrast, ARQ‑based protocols actively request retransmission of the damaged frame, providing a built‑in recovery mechanism. Therefore, PPP depends on higher‑layer protocols to recover lost data.

Q9. How does PPP’s lack of flow control affect its suitability for a high‑latency satellite link versus a LAN?

A.It is equally suitable for both environments
B.It performs better on satellite links due to fewer retransmissions
C.It is less suitable for satellite links because sender cannot adapt to long round‑trip times ✅
D.LANs require flow control, making PPP inappropriate
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Satellite links have long round‑trip times, so a sender that cannot pause may overwhelm the receiver, causing excessive frame loss. In LANs, where propagation delays are short, the impact is less severe. Consequently, PPP without flow control is generally less appropriate for high‑latency environments.

Q10. What is the primary difference between flow control and error control in PPP?

A.Flow control limits transmission rate, whereas error control detects corrupted frames ✅
B.Both functions are combined in PPP’s CRC field
C.Flow control guarantees delivery
D.PPP provides neither flow nor error control
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Flow control manages how fast a sender may transmit, preventing buffer overflow at the receiver. Error control, on the other hand, concerns detecting corrupted frames—PPP uses a CRC for this purpose. The two mechanisms address distinct problems: rate regulation versus data integrity.

Q11. Why might PPP’s byte‑oriented framing be advantageous for certain hardware implementations?

A.It requires complex state machines
B.It aligns with character‑based serial interfaces ✅
C.It eliminates need for start‑of‑frame delimiters
D.It prevents synchronization errors
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Many legacy serial devices process data one byte at a time. PPP’s byte‑oriented (character‑oriented) frames allow these devices to detect frame boundaries using simple flag characters, reducing the need for sophisticated hardware logic and making implementation cheaper and more reliable.

Q12. If a sequence‑number field were added to PPP frames, which of the following effects would most likely occur?

A.Increased protocol complexity with improved reliability ✅
B.No change in reliability but higher overhead
C.Decreased throughput due to CRC removal
D.Simplified error detection without CRC
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Introducing sequence numbers requires additional header bits, state tracking, and processing logic, raising implementation complexity. However, it enables detection of lost or duplicated frames and supports reordering, thereby enhancing overall reliability of the link.

Q13. Applying the layering principle, why must upper‑layer protocols handle lost PPP frames?

A.Because PPP guarantees delivery
B.Because PPP provides only best‑effort service ✅
C.Because lower layers correct all errors
D.Because framing eliminates loss
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: PPP is designed as a best‑effort link‑layer protocol; it detects errors but does not recover from them. Consequently, when a frame is discarded, the responsibility to detect the loss and request retransmission falls to the transport layer or higher, preserving end‑to‑end reliability.

Q14. In a scenario where PPP’s lack of flow control causes buffer overflow, which higher‑layer protocol could mitigate the problem, and how?

A.TCP by using its sliding‑window mechanism to pace transmission ✅
B.UDP by adding checksum
C.IP by fragmenting packets
D.HTTP by caching responses
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: TCP implements flow control via a sliding‑window algorithm, which dynamically adjusts the sender’s rate based on acknowledgments from the receiver. When PPP frames overflow buffers, TCP can slow the transmission, effectively providing the missing flow‑control functionality at a higher layer.

Q15. How does the CRC field in PPP contribute to error detection, and why does it not provide error correction?

A.CRC can both detect and correct errors
B.CRC only detects errors; correction requires retransmission ✅
C.CRC prevents any errors
D.CRC replaces need for any higher‑layer checks
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The CRC computes a checksum based on the frame’s bits; a mismatch signals corruption. However, the CRC does not indicate the exact bits that are wrong, so the receiver cannot reconstruct the original data. To recover the lost information, the sender must retransmit the frame, which is handled by higher‑layer protocols.

Q16. Propose a modification to PPP that enables multipoint addressing; which trade‑off best describes the impact of this change?

A.Adding a 2‑byte address field improves scalability but increases header overhead ✅
B.Removing the CRC reduces reliability
C.Using variable‑length addresses eliminates all overhead
D.Introducing sequence numbers solves addressing without cost
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Including an explicit address field allows each frame to identify its destination, supporting multipoint topologies. The benefit is greater flexibility, but the extra bytes increase per‑frame overhead and may slightly reduce effective bandwidth, especially on low‑speed links.

Q17. Using the concept of service abstraction, why does PPP intentionally omit services such as flow control?

A.To keep the protocol simple and allow upper layers to tailor flow control ✅
B.Because flow control is unnecessary on all media
C.To force use of proprietary extensions
D.To reduce latency by eliminating all control fields
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: PPP is defined as a thin, generic link‑layer service; by omitting optional functions like flow control, it remains lightweight and adaptable. Upper layers can implement flow control mechanisms that are better suited to the specific application or network characteristics, preserving modularity.
