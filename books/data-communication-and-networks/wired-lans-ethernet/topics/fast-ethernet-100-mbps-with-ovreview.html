Q1. What is the length of the Ethernet preamble?

🔹 A. 7 bytes
🔹 B. 8 bytes
🔹 C. 6 bytes
🔹 D. 5 bytes

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The Ethernet preamble is defined as a 7‑byte (56‑bit) sequence of alternating 0s and 1s. This pattern precedes the Start Frame Delimiter and provides timing for the receiver, so the correct answer is 7 bytes.

Q2. A frame carries a payload of 30 bytes. What must the Ethernet device do before transmitting the frame?

🔹 A. Pad the payload to 46 bytes
🔹 B. Fragment the payload into two frames
🔹 C. Drop the frame
🔹 D. Transmit it unchanged

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Because Ethernet requires a minimum payload of 46 bytes, a 30‑byte payload must be padded with zeros up to 46 bytes. Fragmentation is only needed when the payload exceeds the maximum of 1500 bytes, so padding is the correct action.

Q3. If the Start Frame Delimiter (SFD) is corrupted from its standard pattern 10101011 to 10101010, what is the most likely result?

🔹 A. The receiver will still synchronize because the preamble dominates
🔹 B. The frame will be discarded as a collision error
🔹 C. The destination address will be misinterpreted causing a checksum failure
🔹 D. The receiver will treat the next byte as the destination address

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The SFD signals the exact start of the destination address. An incorrect SFD prevents the receiver from recognizing the frame boundary, causing the hardware to treat the frame as malformed and discard it. It does not trigger a collision but results in a frame error.

Q4. Which statement correctly distinguishes the Ethernet preamble from the Start Frame Delimiter (SFD)?

🔹 A. Both are part of the MAC header and carry address information
🔹 B. The preamble is 1 byte long while the SFD is 7 bytes
🔹 C. The preamble consists of 56 alternating bits and the SFD is a fixed 8‑bit flag
🔹 D. The SFD provides timing while the preamble indicates the destination MAC

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The preamble is a 56‑bit (7‑byte) alternating pattern used only for synchronization, whereas the SFD is a single 8‑bit flag (10101011) that marks the exact start of the frame. Therefore the third option correctly describes the difference.

Q5. Why does Ethernet define a minimum frame size of 64 bytes?

🔹 A. To match the MTU of IP packets
🔹 B. To ensure that the CRC field can be computed
🔹 C. To allow CSMA/CD to detect collisions on the longest cable segment
🔹 D. To simplify hardware buffer design

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

CSMA/CD requires that a transmitting station be able to detect a collision before it finishes sending the frame. The 64‑byte minimum guarantees that the signal can travel to the farthest node and back on the longest segment, ensuring collision detection.

Q6. Consider two Ethernet frames: one with a 1500‑byte payload and another with a 46‑byte payload. What are the approximate payload‑to‑total‑frame efficiencies?

🔹 A. ≈99 % for 1500‑byte payload and ≈72 % for 46‑byte payload
🔹 B. ≈95 % for 1500‑byte payload and ≈80 % for 46‑byte payload

Q7. Under CSMA/CD, what occurs when two stations detect a collision simultaneously?

🔹 A. Both stations increase their transmission speed
🔹 B. Both stations pause for a random backoff without sending a jam signal
🔹 C. Both stations continue transmitting, ignoring the collision
🔹 D. Both stations transmit a jam signal and then wait a random backoff period

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

When a collision is detected, each station sends a jam signal to ensure all nodes recognize the event, then each backs off for a random period before attempting to retransmit. This behavior matches the fourth option.

Q8. How does the 56‑bit preamble assist synchronization on a 100 Mbps Fast Ethernet link?

🔹 A. It provides a known alternating pattern that lets the receiver align its clock to the incoming bit stream
🔹 B. It encodes the source MAC address for early routing decisions
🔹 C. It carries error‑checking information to verify frame integrity
🔹 D. It signals the end of the frame to the physical layer

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The preamble’s alternating 0/1 pattern creates a regular timing reference. Receivers use it to lock onto the bit rate of the incoming signal, which is essential for accurate data recovery at 100 Mbps. The other options describe unrelated functions.

Q9. Which statement best synthesizes the impact of Ethernet frame size limits on throughput in a congested Fast Ethernet segment?

🔹 A. Smaller frames increase throughput because they reduce latency
🔹 B. Larger frames decrease throughput due to higher collision probability
🔹 C. Using the minimum frame size maximizes efficiency under heavy load, while the maximum frame size reduces overhead and improves throughput
🔹 D. Frame size has no measurable effect on throughput in a 100 Mbps network

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Small frames suffer higher relative overhead, while large frames amortize the header and CRC over more payload, improving efficiency. Under congestion, the minimum size ensures collision detection, but the maximum size reduces overhead, so the third option captures this trade‑off.

Q10. If an upper‑layer protocol generates data larger than 1500 bytes, how should a Fast Ethernet sender handle the transmission?

🔹 A. Fragment the data into multiple Ethernet frames, each respecting the payload limit
🔹 B. Increase the Ethernet payload field to accommodate the entire data
🔹 C. Drop the excess data and transmit only the first 1500 bytes
🔹 D. Pad the data to exactly 1500 bytes and discard the remainder

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Ethernet specifies a maximum payload of 1500 bytes. Data exceeding this limit must be segmented into several frames, each carrying up to 1500 bytes of payload. The other options violate the Ethernet standard.
