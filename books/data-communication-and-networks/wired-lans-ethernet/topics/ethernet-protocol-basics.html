What is Ethernet Protocol basics?

Ethernet is the most widely used wired local area network technology that defines how devices connect, communicate, and share data over physical cables using standardized rules for framing, addressing, and media access control to ensure reliable communication within a building or campus.

Q1. In HDLC's normal response mode, if a data frame is lost, what immediate action does the receiving node take?

A. Retransmit the lost frame
B. Send a NAK
C. Wait for a timeout and then send a NAK ✅
D. Ignore the loss

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The receiver cannot assume the frame was successfully received, so it waits for the sender's timeout to expire. When the timeout occurs, it generates a negative acknowledgment (NAK) to inform the sender that the frame must be retransmitted. This behavior preserves link reliability without premature retransmission.

Q2. When a sender receives three duplicate ACKs for the same Ethernet frame, which inference about the network condition is most accurate?

A. The frame was corrupted
B. A collision occurred ✅
C. The receiver's buffer is full
D. The network is idle

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Duplicate acknowledgments indicate that the same frame has been seen multiple times without progressing to a new acknowledgment, which typically results from a collision on the shared medium. The sender therefore infers that a collision has taken place and may need to back off before retransmitting.

Q3. In asynchronous balanced mode (ABM), if the timer for a transmitted I‑frame expires before an ACK is received, what can be logically deduced about the state of the link?

A. The link is down
B. The frame was received but ACK lost
C. The frame was corrupted
D. Both B and C are possible ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

When the timer expires, the sender knows that the expected acknowledgment did not arrive. This could mean the frame reached the receiver but its ACK was lost, or that the frame itself was corrupted and discarded. Both scenarios are consistent with the observed timeout, so the correct deduction includes both possibilities.

Q4. Which statement correctly contrasts Normal Response Mode (NRM) with Asynchronous Balanced Mode (ABM) in HDLC?

A. NRM requires a primary node to control the link, ABM allows either node to transmit ✅
B. NRM uses only I‑frames, ABM uses S‑frames
C. NRM supports full‑duplex, ABM only half‑duplex
D. NRM and ABM are identical except for timer values

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

In NRM a primary station governs the communication and secondary stations may only transmit when granted permission, whereas ABM treats both stations as peers, allowing either to initiate transmission at any time. This fundamental difference defines the operational flexibility of each mode.

Q5. If the Ethernet maximum frame size is increased from 1518 bytes to 9000 bytes (jumbo frames), how does this change affect the protocol efficiency assuming the same link speed?

A. Efficiency decreases due to larger collision windows
B. Efficiency remains unchanged
C. Efficiency improves because overhead per byte drops ✅
D. Efficiency improves only for low‑latency links

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Larger frames amortize the fixed header and preamble overhead over more payload bytes, reducing the proportion of non‑payload bits. Consequently, the effective data throughput rises, making the protocol more efficient despite the same raw link speed. Collision probability does not increase dramatically because modern switches segment traffic.

Q6. Compare Ethernet's CRC error detection with PPP's FCS field. Which of the following best explains a key difference in their handling of burst errors?

A. Ethernet CRC can detect longer burst errors than PPP FCS
B. PPP FCS uses a 16‑bit polynomial while Ethernet uses 32‑bit ✅
C. Ethernet discards frames on any error, PPP attempts retransmission
D. Both use identical polynomials, so there is no difference

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Ethernet typically employs a 32‑bit CRC polynomial, providing stronger detection capability for long burst errors than PPP's 16‑bit Frame Check Sequence. While both protocols reject corrupted frames, the longer polynomial in Ethernet enhances its ability to catch extended error patterns, which is the principal distinction.

Q7. In CSMA/CD, what principle ensures that a station can detect a collision while transmitting?

A. Signal strength monitoring
B. Listening to the medium while sending ✅
C. Timer expiration
D. ACK receipt

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Carrier Sense Multiple Access with Collision Detection requires each station to monitor the carrier signal continuously, even while it is transmitting its own bits. By comparing the sensed signal with its transmitted waveform, a station can recognize a superimposed signal, indicating that another station transmitted simultaneously, thus detecting a collision.

Q8. Ethernet mandates a minimum frame size of 64 bytes. Using the relation \(2 \times \text{propagation\ delay} \leq \text{frame\ transmission\ time}\), explain why this requirement exists.

A. To guarantee that a sender finishes transmitting before a collision can be detected ✅
B. To allow enough time for error checking
C. To synchronize clocks between stations
D. To limit bandwidth usage

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The minimum frame length guarantees that the transmitting station remains on the medium long enough for a signal reflecting a collision to travel to the farthest node and back. If the frame were shorter, a collision could occur after the sender had finished transmitting, and the sender would never detect it, violating reliable CSMA/CD operation.

Q9. Design a hybrid protocol that combines Ethernet's CSMA/CD with HDLC's frame sequencing. Which of the following mechanisms would be essential to preserve ordered delivery?

A. Use HDLC sequence numbers within Ethernet payload ✅
B. Replace CSMA/CD with token passing
C. Increase Ethernet minimum frame size
D. Eliminate acknowledgments

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Embedding HDLC's sequence numbers inside the Ethernet payload allows the receiver to reorder frames that may arrive out of order due to collisions and retransmissions. This combination retains Ethernet's contention management while leveraging HDLC's reliable sequencing, ensuring that higher‑layer data is delivered in the correct order.

Q10. What does ABM stand for in the context of HDLC?

A. Asynchronous Balanced Mode ✅
B. Automatic Bit Management
C. Asymmetric Binary Modulation
D. Adaptive Bandwidth Multiplexing

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

ABM is the abbreviation for Asynchronous Balanced Mode, a configuration of HDLC where both communicating stations operate as peers and may initiate transmission without needing a primary‑secondary hierarchy.

Q11. When comparing wired Ethernet (802.3) to wireless LAN (802.11) regarding collision handling, which statement accurately reflects the protocol differences?

A. 802.3 uses CSMA/CD while 802.11 uses CSMA/CA ✅
B. Both use CSMA/CD
C. 802.3 uses token ring
D. 802.11 relies on physical layer retransmission only

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Wired Ethernet employs Carrier Sense Multiple Access with Collision Detection (CSMA/CD) because collisions can be sensed directly on the shared medium. Wireless LANs cannot reliably detect collisions due to the hidden node problem, so they use Carrier Sense Multiple Access with Collision Avoidance (CSMA/CA), which mitigates collisions through acknowledgments and backoff mechanisms.
