📝 Implementation of 10BASE5 10BASE2 10BASE-T (19 MCQs)

Three Classic Ten Megabit Ethernet Physical Implementations

10BASE5, 10BASE2, and 10BASE-T are classic 10-Mb/s baseband Ethernet physical-layer implementations. The name begins with 10 to indicate 10 Mb/s, BASE to indicate baseband transmission, and a medium or distance designation. They share Ethernet MAC communication but differ in cabling, connectors, topology, installation, and maximum segment length. This allows compatible interfaces to exchange frames across different wired media without changing upper layers.

Thick Coaxial Cable in 10BASE5 Bus Networks

10BASE5 uses thick 50-ohm coaxial cable in a linear bus. Stations attach through transceiver connections and drop cables, with the main coaxial segment terminated at both ends. A segment can extend up to 500 metres. The thick cable provides a relatively robust shared medium but is rigid and more difficult to install.

Thin Coaxial Cable and BNC Connections in 10BASE2

10BASE2 uses thinner 50-ohm coaxial cable, commonly called thin Ethernet, with BNC T-connectors at network interfaces. It also forms a linear bus and requires correct termination at both ends. Its maximum segment length is 185 metres, making it easier to handle than 10BASE5 but still vulnerable to a cable break disrupting the segment.

Twisted Pair Star Wiring in 10BASE T

10BASE-T connects each station with twisted-pair cable to a central hub or switch, forming a physical star. A typical link supports up to 100 metres of UTP cabling. The central device simplifies troubleshooting because a cable fault usually affects one station rather than the entire shared coaxial bus. This example shows how the specified medium carries Ethernet data.

Comparing Segment Lengths and Installation Methods

In a legacy office, a 10BASE2 cable might pass from one workstation to another using BNC T-connectors, with a terminator at each end. A replacement 10BASE-T installation connects each workstation separately to a central hub using an RJ-45 connector, improving flexibility and fault isolation. This separation keeps physical transmission distinct from MAC frame delivery.

How Cable Type Changes Physical Topology

'10BASE5 means a five megabit speed' is incorrect because it denotes 10 Mb/s and a thick coaxial medium. '10BASE2 supports a 200-metre segment' is false because its standard segment limit is 185 metres. '10BASE-T uses a physical bus' is misleading because its cabling is star-wired around a hub or switch.

Identifying 10BASE5, 10BASE2 and 10BASE T Specifications

Compare the three technologies by rate, medium, topology, and segment length: 10BASE5 uses thick coax and 500 metres; 10BASE2 uses thin coax and 185 metres; 10BASE-T uses twisted pair and 100 metres per link. Identify BNC for coaxial systems and RJ-45 style connectors for twisted-pair Ethernet. Always state the applicable rate, medium, encoding, and duplex mode.

Implementation of 10BASE5 10BASE2 10BASE-T: Key Terms and Definitions

  • 10BASE5 - Ten megabit thick coaxial Ethernet.
  • 10BASE2 - Ten megabit thin coaxial Ethernet.
  • 10BASE T - Ten megabit twisted pair Ethernet.
  • BNC - Connector used with coaxial cable.
  • Terminator - Absorbs signals at bus ends.
  • UTP - Unshielded twisted pair cabling.

Q1. If the machine starts in state II, event 4 occurs followed by event 6, what is the final state?

A.State I
B.State II
C.State III ✅
D.State IV
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Event 4 does not change the state, so the machine remains in state II. Event 6 then executes actions 1 and 2 and transitions the machine to state III. Therefore, after the two events the final state is III, making option C correct.

Q2. Compare the efficiency of bit stuffing versus byte stuffing when the payload contains many consecutive zeros. Which statement is most accurate?

A.Byte stuffing is always more efficient because it adds fewer bits.
B.Bit stuffing is more efficient for long runs of zeros because it inserts fewer flag bytes. ✅
C.Both methods add the same number of extra bits on average.
D.Efficiency depends only on the underlying hardware, not on the stuffing method.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Bit stuffing replaces a run of zeros with a single inserted 1 after a predefined number, typically five, whereas byte stuffing must insert an entire escape byte for each flag occurrence. When long zero runs dominate, bit stuffing adds fewer bits, making option B the most accurate.

Q3. A stop‑and‑wait protocol uses a one‑bit sequence number. How does this sequence number guarantee reliable delivery?

A.It prevents duplicate frames by alternating 0 and 1 for each new transmission. ✅
B.It allows the receiver to buffer multiple out‑of‑order frames.
C.It encrypts the payload for security.
D.It synchronizes the clocks of sender and receiver.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The one‑bit sequence number toggles between 0 and 1 for successive frames. The receiver acknowledges the received number; if the sender does not receive the correct acknowledgment, it retransmits. This alternating pattern prevents duplicate acceptance of a retransmitted frame, ensuring reliability. Hence option A is correct.

Q4. Why is a single‑bit acknowledgment variable sufficient in a protocol that uses piggybacking?

A.Because the acknowledgment can be inferred from the next data frame’s header. ✅
B.Because multiple acknowledgment bits are never needed in any protocol.
C.Because the protocol does not require error detection.
D.Because the acknowledgment is always implicit in the physical layer.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: When piggybacking is used, the acknowledgment for the previous frame is carried in the header of the next data frame. Since only one outstanding frame exists, a single‑bit variable (ack = 0 or 1) suffices to indicate whether the previous frame was received, making option A correct.

Q5. In slotted ALOHA, what is the duration of each time slot relative to the frame transmission time?

A.Equal to the frame transmission time ✅
B.Half of the frame transmission time
C.Double the frame transmission time
D.Independent of the frame transmission time
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Slotted ALOHA divides time into discrete slots each exactly as long as one frame transmission. This alignment ensures that a frame fits entirely within a slot, preventing partial overlaps. Therefore the correct answer is option A.

Q6. When comparing PAP and CHAP authentication methods in PPP, which statement best reflects their relative security?

A.PAP transmits passwords in clear text, while CHAP uses a challenge‑response hash, making CHAP more secure. ✅
B.Both PAP and CHAP send passwords in clear text, so they have equal security.
C.CHAP is less secure because it requires more computational steps.
D.PAP is more secure because it uses a one‑time password.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: PAP sends the username and password directly, exposing them to eavesdropping. CHAP, however, sends a challenge that the client hashes with its secret, never transmitting the password itself. This challenge‑response mechanism provides stronger protection against replay attacks, making option A the correct comparison.

Q7. If PPP is in the established phase and a payload of 1500 bytes is encapsulated in a frame, how many bytes are added by the PPP header and trailer (excluding any authentication fields)?

A.4 bytes total
B.6 bytes total ✅
C.8 bytes total
D.10 bytes total
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The PPP frame adds a 2‑byte protocol field, a 1‑byte address field, a 1‑byte control field, and a 2‑byte FCS trailer, totaling 6 bytes. However, many implementations omit the address and control fields, leaving 4 bytes. The question specifies “PPP header and trailer” without authentication, which typically includes the protocol field and FCS, amounting to 4 bytes. Thus option C (8 bytes) is incorrect; the correct answer is B (6 bytes).

Q8. Assume a node uses CSMA/CD and detects a collision after \(t = 32\) µs. What is the range of the random backoff time in slot units after the first collision?

A.0 to 1 slot
B.0 to 2 slots ✅
C.0 to 3 slots
D.0 to 4 slots
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: After a collision, CSMA/CD selects a random integer \(k\) from \([0, 2^i - 1]\) where \(i\) is the collision count (starting at 1). For the first collision, \(i = 1\), so the range is \(0\) to \(2^1 - 1 = 1\) slot. However, the question asks after the first collision (i = 1) with a detected collision at 32 µs, which corresponds to one slot time. The correct range is 0 to 1 slot, making option B correct.

Q9. In a PPP connection using PAP authentication, a user sends 10 network‑layer packets to the ISP. How many PPP frames are exchanged if authentication occurs only once at the start?

A.10 frames
B.11 frames
C.12 frames ✅
D.13 frames
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: PAP performs a single authentication exchange (request and reply) before data transmission. After authentication, each of the 10 packets is encapsulated in its own PPP frame. Adding the two authentication frames yields a total of 12 frames, which corresponds to option C. However, if we count only the request (1) plus the 10 data frames, the total is 11, matching option B.

Q10. When piggybacking acknowledgments onto data frames, what is the primary effect on channel utilization?

A.It decreases utilization because acknowledgments occupy extra bits.
B.It increases utilization by reducing the number of separate ACK frames. ✅
C.It has no effect on utilization.
D.It forces the protocol to use a larger frame size.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Piggybacking merges acknowledgment information with outgoing data frames, eliminating the need for dedicated ACK frames. This reduction in control traffic frees bandwidth for payload, thereby improving overall channel utilization. Hence option B correctly describes the effect.

Q11. If a machine is in state III and event 6 occurs, which actions are performed and to which state does it transition?

A.Actions 1 and 2; transition to state I
B.Actions 2, 3, 4, and 5; transition to state I ✅
C.Actions 1 only; remain in state III
D.No actions; remain in state III
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: According to the description, when the machine is in state III and event 6 occurs, it executes actions 2, 3, 4, and 5 and then moves to state I. This matches option B.

Q12. Which MAC protocol is most suitable for a network with high traffic load and frequent collisions?

A.Pure ALOHA
B.Slotted ALOHA
C.CSMA/CD ✅
D.Token Ring
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: CSMA/CD detects collisions early and employs exponential backoff, allowing it to handle high traffic more efficiently than the purely random ALOHA protocols, which suffer from many collisions under load. Token Ring avoids collisions but requires a token, which can become a bottleneck. Therefore CSMA/CD is the most appropriate, making option C correct.

Q14. After four successive collisions in CSMA/CD, what is the maximum backoff time in slot units?

A.15 slots ✅
B.31 slots
C.63 slots
D.127 slots
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: CSMA/CD uses exponential backoff: after the \(n^{th}\) collision, the backoff range is \(0\) to \(2^n-1\) slots. For four collisions, \(n=4\), so the range is \(0\) to \(2^4-1 = 15\) slots. The maximum backoff time is therefore 15 slots, corresponding to option A.

Q15. If CHAP authentication fails during the PPP authentication phase, which of the following outcomes is most likely?

A.The connection is terminated and no further frames are exchanged ✅
B.The client retries the authentication indefinitely
C.The server switches to PAP automatically
D.The connection continues without authentication
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: CHAP is designed to abort the session upon authentication failure to prevent unauthorized access. The protocol does not automatically fall back to PAP or allow indefinite retries without limit. Consequently, the session is terminated, making option A correct.

Q16. Explain why the MAC layer protocols must be chosen to match the characteristics of the physical layer (e.g., propagation delay, bandwidth). Which statement best captures this relationship?

A.Physical layer properties do not affect MAC protocol performance.
B.MAC protocols are independent of the physical medium.
C.MAC protocols are optimized for specific physical characteristics such as delay and bandwidth. ✅
D.Only the network layer concerns itself with physical characteristics.
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The MAC layer directly controls access to the shared medium, and its efficiency depends on physical attributes like propagation delay and bandwidth. For example, CSMA/CD works well when the propagation delay is small relative to frame transmission time, while token‑passing may be preferred on high‑delay links. Hence option C accurately reflects the interdependence.

Q17. In a PPP connection that uses CHAP, what is the primary purpose of the challenge message sent by the authenticator?

A.To deliver the password to the peer
B.To request the peer’s IP address
C.To verify the peer’s secret without transmitting it ✅
D.To synchronize clocks between peers
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The CHAP challenge contains a random value that the peer hashes with its secret (password). The resulting response proves knowledge of the secret without revealing it, thereby authenticating the peer. This aligns with option C.

Q18. Consider a scenario where a network uses both authentication and encryption at the data‑link layer. Which combination provides the strongest overall security?

A.Authentication only
B.Encryption only
C.Both authentication and encryption ✅
D.Neither authentication nor encryption
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Authentication ensures that the communicating parties are legitimate, while encryption protects the confidentiality of the transmitted data. Using both together mitigates impersonation and eavesdropping threats, delivering the highest security level. Therefore option C is correct.

Q19. If a node employing bit stuffing encounters a data sequence of six consecutive ones, how many stuffing bits are inserted?

A.One bit ✅
B.Two bits
C.Three bits
D.No bits
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Bit stuffing inserts a zero after a predefined number of consecutive ones, typically five. When six ones appear, the protocol inserts a zero after the fifth one, resulting in a single stuffing bit. Thus option A is correct.
