Q1. What is the primary function of the poll function in a polling-access method?

🔹 A. To initiate data transmission from the primary
🔹 B. To request data from a secondary device
🔹 C. To acknowledge receipt of a frame
🔹 D. To select a secondary device for transmission

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The poll function is issued by the primary station to ask each secondary whether it has data to send. Its purpose is to solicit transmissions, not to start sending, acknowledge frames, or select a device. Therefore the option describing a request for data from a secondary is correct.

Q2. If the primary station sends a select (SEL) frame to a secondary that is not ready, what is the most likely immediate outcome?

🔹 A. The secondary sends an ACK frame
🔹 B. The primary retries the SEL immediately
🔹 C. The primary waits for a timeout and then retransmits
🔹 D. The secondary responds with a NAK frame

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

When a secondary is not prepared to receive, it cannot acknowledge readiness, so it returns a negative acknowledgment (NAK). The primary must then decide whether to retry after a timeout. An ACK would indicate readiness, which is not the case here, making the NAK response the correct immediate outcome.

Q3. Which statement correctly contrasts polling with token ring in terms of collision handling?

🔹 A. Polling eliminates collisions through central control, while token ring relies on a circulating token to prevent collisions.
🔹 B. Polling uses a token to manage access, whereas token ring uses a central controller.
🔹 C. Both polling and token ring allow multiple stations to transmit simultaneously.
🔹 D. Token ring experiences more collisions than polling because it lacks a primary station.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Polling centralizes channel control at the primary, so only the polled secondary may transmit, preventing collisions. Token ring, on the other hand, depends on a token that grants exclusive transmission rights, avoiding collisions but requiring token management. The first option accurately captures this contrast, making it the correct choice.

Q4. In a network using polling, how would adding a secondary device affect the average latency for data transmission, assuming the primary polls sequentially?

🔹 A. Latency would decrease because more devices share the load
🔹 B. Latency would remain unchanged
🔹 C. Latency would increase linearly with the number of devices
🔹 D. Latency would become unpredictable

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Each additional secondary adds another polling step before the primary can reach any given device. Because the primary must wait for each poll, the waiting time grows proportionally to the number of devices, producing a linear increase in average latency. Hence the option stating linear growth is correct.

Q5. Given that the primary station failed, which of the following statements is necessarily true about the network's operation?

🔹 A. All secondary devices can communicate directly with each other
🔹 B. The network becomes inoperable until the primary is restored
🔹 C. Secondary devices automatically assume the primary role
🔹 D. Collision frequency increases dramatically

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Polling relies on a single primary to coordinate all transmissions. If that primary fails, no secondary can be polled or granted permission to send, causing the entire link to stop functioning. The other options describe behaviors that do not occur automatically in a pure polling scheme, making the network’s inoperability the necessary conclusion.

Q6. Which of the following is a disadvantage of polling compared to CSMA/CD?

🔹 A. Higher throughput
🔹 B. Lower latency
🔹 C. Single point of failure at the primary station
🔹 D. No need for synchronization

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Polling concentrates control in one device; if that device fails, the whole network stops, representing a single point of failure. CSMA/CD distributes control among all stations, so the failure of any single node does not halt the network. The other choices are not inherent disadvantages of polling, so the correct answer highlights the vulnerability.

Q7. If a system designer wants to minimize the time the primary spends idle while waiting for secondary readiness, which modification to the polling protocol would be most effective?

🔹 A. Use selective polling based on recent activity of each secondary
🔹 B. Increase the interval between polls
🔹 C. Require secondaries to send continuous ready signals
🔹 D. Replace polling with a contention‑based scheme

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Selective polling limits the primary to query only those secondaries that have recently shown data to send, reducing unnecessary idle waiting. Extending poll intervals or demanding continuous signals would increase overhead, while switching to contention‑based access changes the protocol entirely. Therefore, targeted selective polling best reduces idle time.

Q8. Assume a polling cycle includes three secondary devices. The first returns a NAK, the second returns data, and the third is never polled. What is the impact on the third device's ability to transmit data during this cycle?

🔹 A. It can transmit after the second device’s ACK
🔹 B. It must wait for the next polling cycle
🔹 C. It can interrupt the current poll to send its data
🔹 D. Its data is automatically queued for transmission

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

During a single polling cycle the primary contacts each secondary in order. If a device is not polled, it has no opportunity to transmit until the primary reaches it in the next cycle. Consequently, the third device must wait for the subsequent polling round, making the second option correct.

Q9. When measuring channel utilization in a polling system, which factor most directly influences the utilization ratio?

🔹 A. Size of the SEL frames
🔹 B. Number of secondary devices
🔹 C. Processing speed of the primary station
🔹 D. Length of the data frames transmitted

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Utilization ratio compares the time the channel carries useful data versus overhead. Data frames typically dominate transmission time, so their length has the greatest effect on how efficiently the channel is used. SEL frames and polling overhead are relatively small, and processing speed does not affect the proportion of time the channel is occupied by payload data.

Q10. Design a hybrid protocol that combines polling and token passing to mitigate primary failure risk. Which of the following describes a viable approach?

🔹 A. The primary periodically distributes a token that all stations must hold before transmitting
🔹 B. Secondaries automatically become primary after a timeout without polls
🔹 C. A token is passed only after a successful poll, allowing the holder to transmit without further polling
🔹 D. Polling continues unchanged, but the token is used solely for error detection

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

By integrating token passing after a successful poll, the protocol ensures that the token‑holding station can send data without waiting for another poll, while the primary still coordinates token distribution. This hybrid method preserves centralized control and provides a fallback mechanism if the primary fails, matching the described approach.

Q11. If the primary station consistently receives NAK frames from all secondary devices, what can be inferred about the network traffic pattern?

🔹 A. The network is heavily loaded with data
🔹 B. No secondary has data to send at that moment
🔹 C. Secondary devices are malfunctioning
🔹 D. The primary’s SEL frames are being corrupted

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A NAK indicates that a polled secondary has no data ready for transmission. When every secondary returns NAK, the logical inference is that the network currently has no pending data to send, rather than a failure or corruption. Thus, the absence of data across all stations is the most reasonable conclusion.

Q12. Considering scalability, which statement best reflects the impact of increasing the number of secondary stations on the polling overhead?

🔹 A. Overhead grows quadratically with the number of stations
🔹 B. Overhead remains constant regardless of station count
🔹 C. Overhead grows linearly with the number of stations
🔹 D. Overhead decreases because stations can be grouped

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Each additional secondary requires an extra poll and associated control frames, adding a fixed amount of overhead per station. Consequently, the total overhead increases proportionally to the number of devices, producing a linear relationship. Quadratic growth would imply interactions between stations, which polling does not introduce, making the linear statement correct.
