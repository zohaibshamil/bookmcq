What is Addressing in the TCP/IP Protocol Suite?

Addressing in the TCP/IP protocol suite involves multiple levels of identification, including physical MAC addresses for local network delivery, logical IP addresses for global routing across networks, and port numbers for distinguishing specific applications or services running on a single host.

📝 All Addressing in the TCP/IP Protocol Suite MCQs

Q1. According to the overview, which device(s) can modify the packet after it leaves the host?

A. Only routers ✅
B. Only link‑layer switches
C. Both routers and link‑layer switches
D. Neither routers nor link‑layer switches

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Routers operate at the network layer and are the only devices that may alter an IP packet after the host creates it. Link‑layer switches forward Ethernet frames without inspecting or changing the packet contents, so the correct answer is that only routers can modify the packet.

Q2. If a router fragments a packet, what logical inference can be made about the number of packets the destination host receives compared to the number originally sent by the source host?

A. The destination receives fewer packets
B. The destination receives the same number of packets
C. The destination receives more packets
D. The number cannot be determined without knowing the MTU ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

When a router fragments, it creates additional packets that each carry a portion of the original data. Consequently the destination will receive more packets than the source sent, but the exact count depends on the MTU values involved, so the only safe inference is that the number cannot be determined without that information.

Q3. An original IP packet of total length \(1500\) bytes (including a \(20\)-byte header) traverses a router whose MTU is \(1000\) bytes. Assuming the router must fragment the packet, how many fragments will be transmitted toward the destination?

A. One fragment
B. Three fragments
C. Two fragments ✅
D. Four fragments

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The payload is \(1500-20=1480\) bytes. Each fragment can carry at most \(1000-20=980\) bytes of payload. Dividing \(1480\) by \(980\) yields \(1.51\), which requires two fragments. Therefore the router will send two fragments, making option C the correct answer.

Q4. Compare the effect of a router versus a link‑layer switch on the network‑layer source and destination addresses in a packet. Which statement is accurate?

A. Both devices rewrite the source address
B. Only the router may change the destination address
C. Only the router may change the source address
D. Neither device changes either address ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

Routers forward packets based on the destination address but do not alter the source or destination IP fields. Link‑layer switches operate below the network layer and never see IP addresses, so they also leave those fields untouched. Thus neither device changes either address.

Q5. Figure 2.7 shows identical objects below each layer for devices. Which layer’s objects remain identical across two consecutive hops despite possible fragmentation?

A. Physical layer
B. Data link layer
C. Network layer
D. Transport layer ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Fragmentation occurs at the network layer, but the transport‑layer payload (such as TCP/UDP ports and data) stays unchanged across hops. Because the transport layer is above the point where fragmentation is applied, its objects remain identical from one hop to the next.

Q6. Differentiate between the logical connection at the network layer and the physical path that includes multiple routers. Which statement correctly reflects this distinction?

A. The logical connection changes at each router
B. The logical connection stays end‑to‑end while each router creates a new physical link ✅
C. Both logical and physical connections are re‑established at every hop
D. Physical path determines IP addresses, logical connection does not

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The network‑layer logical connection is defined between the two end hosts and remains constant, even though the packet traverses many physical links created by routers. Each router adds a new physical segment, but it does not break the end‑to‑end logical connection.

Q7. When a router fragments a packet, what must the destination host do to reassemble the original data?

A. Collect all fragments and use the fragment offset fields to rebuild the packet ✅
B. Request retransmission of missing fragments from the source
C. Ignore the fragments and process each separately
D. Use the MAC addresses to reorder fragments

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

IP fragmentation includes a fragment offset and identification field in each piece. The destination host gathers all fragments that share the same identification, orders them using the offset, and then reconstructs the original packet. This process is mandatory for successful reassembly.

Q8. Synthesize how the principle of protocol layering ensures that modifications made by routers do not affect link‑layer switches.

A. Routers operate above the link layer, so switches never see altered frames
B. Link‑layer switches rewrite IP headers to match router changes
C. Each layer has its own encapsulation, so changes stay within the layer that performed them ✅
D. Routers broadcast changes to all switches in the network

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Protocol layering separates responsibilities: routers modify network‑layer headers while link‑layer switches only handle Ethernet frames. Because each layer encapsulates its own data, any change a router makes to the IP header remains invisible to the switch, which continues to forward frames based on MAC addresses alone.

Q9. Explain the relationship between network‑layer fragmentation and end‑to‑end reliability when link‑layer switches are unaware of fragmentation. Which assertion is true?

A. Fragmentation improves reliability because smaller packets travel faster
B. Reliability is unaffected because the transport layer handles reassembly and loss detection ✅
C. Link‑layer switches must buffer fragments to guarantee delivery
D. Fragmentation forces the transport layer to ignore checksum errors

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Reliability is primarily a transport‑layer concern. Even though link‑layer switches do not recognize IP fragments, the transport layer (e.g., TCP) detects missing or corrupted fragments via sequence numbers and checksums, requesting retransmission if needed. Thus fragmentation does not degrade end‑to‑end reliability.

Q10. What is the primary function of a link‑layer switch in a LAN?

A. Assign IP addresses to hosts
B. Forward Ethernet frames based on MAC addresses ✅
C. Route IP packets between subnets
D. Perform NAT translation

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A link‑layer (or Ethernet) switch operates at Layer 2, learning MAC addresses and using them to forward frames within the local network. It does not assign IP addresses, route between subnets, or perform network‑address translation, making the forwarding of frames the correct description of its primary role.

Q11. In a network where two routers separate the source and destination hosts, if the first router fragments a packet, how does this affect the second router's processing of the fragments?

A. The second router forwards each fragment unchanged, treating them as separate packets ✅
B. The second router recombines fragments before forwarding
C. The second router discards all fragments and sends an ICMP error
D. The second router adds another layer of fragmentation to each fragment

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Each fragment generated by the first router is a complete IP packet in its own right. The second router simply forwards each fragment according to its destination address, without attempting to reassemble them. Reassembly is reserved for the final destination host.

Q12. Assume Router 1 has an MTU of \(1200\) bytes and Router 2 has an MTU of \(1000\) bytes. A host sends a \(2000\)-byte IP packet (including a \(20\)-byte header). Which fragment size will be used for the final transmission toward the destination?

A. 1200‑byte fragments
B. 1000‑byte fragments
C. Fragments sized to the smallest MTU encountered ✅
D. Fragments sized to the largest MTU encountered

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The first router will fragment the packet to fit its MTU of 1200 bytes, but the second router must respect its own MTU of 1000 bytes. Consequently, any fragments that reach the second router may be further divided, resulting in fragments sized to the smallest MTU encountered along the path.

Q13. Given that identical objects exist between two hops, what implication does this have for address translation mechanisms such as NAT?

A. NAT must be applied at every hop to preserve identical objects
B. Identical objects allow NAT to be performed only at the network edge without disrupting intermediate hops ✅
C. NAT cannot be used when identical objects are present
D. Identical objects require address translation at the link layer

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When identical objects (e.g., transport‑layer ports and payload) are preserved across hops, NAT can safely be applied at the network edge—typically at the first router—without affecting the forwarding behavior of intermediate routers. The intermediate hops see unchanged transport‑layer data, so they operate normally.
