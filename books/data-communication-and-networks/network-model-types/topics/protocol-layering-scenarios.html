📝 All Protocol Layering Scenarios MCQs

Q1. In the first scenario, what rule ensures that only one person speaks at a time?

🔹 A. Turn‑taking
🔹 B. Encryption
🔹 C. Hand raising
🔹 D. Formal language

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Turn‑taking requires each participant to wait until the other has finished speaking, thereby preventing overlap. This rule directly enforces the one‑speaker‑at‑a‑time requirement and maintains an orderly dialog, which is a fundamental part of the simple face‑to‑face protocol described.

Q2. If Maria stops listening while Ann is speaking, which protocol rule is violated?

🔹 A. Vocabulary limit
🔹 B. Turn‑taking
🔹 C. Closing greetings
🔹 D. Monolog rule

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The protocol specifies that each party must refrain from speaking while the other is speaking, known as turn‑taking. By stopping listening, Maria ignores this rule, leading to potential interruptions and loss of information. The violation disrupts the dialogic nature of their communication and undermines mutual respect.

Q3. Suppose the protocol in the first scenario is changed to allow simultaneous speaking. What impact would this have on the need for an additional layer?

🔹 A. No impact
🔹 B. Reduces complexity
🔹 C. Increases complexity requiring an extra layer
🔹 D. Same as before

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Allowing simultaneous speech introduces interference and coordination problems that the original single‑layer protocol cannot resolve. According to layering principles, a new layer would be required to manage concurrency, collision detection, and ordering, thereby increasing system complexity and necessitating an additional protocol layer.

Q4. Compare the single‑layer face‑to‑face protocol with the professor‑lecture protocol. Which statement is true?

🔹 A. Both are monologs
🔹 B. Both are dialogs
🔹 C. First is dialog, second is monolog
🔹 D. Both use encryption

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

In the neighbor scenario the conversation is a dialog where each party alternates speaking, while the lecture scenario is primarily a monolog with the professor speaking most of the time. This contrast highlights how protocol rules differ based on context and participant roles.

Q5. Evaluate the primary benefit of adding an encryption layer in the second scenario.

🔹 A. Improves speed
🔹 B. Adds confidentiality
🔹 C. Reduces vocabulary
🔹 D. Eliminates turn‑taking

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Encryption transforms the letter into unreadable text for anyone lacking the key, providing confidentiality. This protects the ideas exchanged between Maria and Ann from interception, which is the main advantage of introducing a cryptographic layer on top of the existing communication protocol.

Q6. Differentiate the protocol rules for face‑to‑face conversation and postal mail with encryption. Which difference is most significant?

🔹 A. Turn‑taking
🔹 B. Vocabulary restriction
🔹 C. Encryption
🔹 D. Closing greetings

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The face‑to‑face protocol relies on turn‑taking and shared vocabulary, while the postal scenario adds encryption to secure the content. Encryption introduces a fundamentally new security requirement that does not exist in the simple dialog, making it the most significant distinction between the two protocols.

Q7. Apply the concept of protocol layering to explain why Maria and Ann need both a communication rule and an encryption rule.

🔹 A. Two separate functions
🔹 B. One replaces the other
🔹 C. Both are the same
🔹 D. No need for two

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Layering separates concerns: the communication rule governs interaction order, while the encryption rule ensures confidentiality. Treating them as distinct layers allows each to be designed, implemented, and modified independently, illustrating why both rules are necessary for secure and orderly exchange.

Q8. In the second scenario, if the encryption key is compromised, which principle of protocol design is violated?

🔹 A. Confidentiality
🔹 B. Turn‑taking
🔹 C. Vocabulary restriction
🔹 D. Greeting rule

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A compromised key means unauthorized parties can read the letters, breaking the confidentiality principle. Confidentiality is a core security property that protocols must preserve, and its loss indicates a failure in the cryptographic layer of the communication model.

Q9. Synthesize a protocol rule that could allow Maria to verify the integrity of a received letter without opening it.

🔹 A. Use a checksum
🔹 B. Use turn‑taking
🔹 C. Use hand raising
🔹 D. Use closing words

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A checksum (or hash) attached to the sealed envelope enables the receiver to compute a value and compare it to the sender’s original checksum. Matching values confirm that the content has not been altered, providing integrity verification without exposing the actual message.

Q10. Suppose the postal system adds a tracking layer that logs delivery time. How does this new layer interact with the existing encryption layer according to layering principles?

🔹 A. It bypasses encryption
🔹 B. It operates independently
🔹 C. It modifies encryption
🔹 D. It replaces encryption

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The tracking layer records metadata such as timestamps and location, which does not affect the encrypted payload. According to layering, each layer performs its own function without altering others, so the tracking layer operates independently alongside the encryption layer.

Q11. If Ann decides to send three consecutive letters without waiting for a reply, which existing protocol rule is being ignored?

🔹 A. Turn‑taking
🔹 B. Vocabulary limit
🔹 C. Closing greetings
🔹 D. Encryption

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The turn‑taking rule requires each participant to wait for the other to finish speaking (or writing) before responding. Sending multiple letters back‑to‑back disregards this rule, potentially causing confusion and breaking the expected dialogic flow of the communication.

Q12. Assume each protocol layer adds exactly one rule. Using the expression \( n = 3 \), how many layers are needed to implement three distinct rules?

🔹 A. One layer
🔹 B. Two layers
🔹 C. Three layers
🔹 D. Four layers

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The equation \( n = 3 \) indicates that three separate rules require three distinct layers if each layer contributes only one rule. Therefore, three layers are necessary to accommodate the three independent protocol specifications.

Q13. Analyze why the professor‑lecture protocol is considered a monolog rather than a dialog. Which factor is decisive?

🔹 A. Use of hand raising
🔹 B. Frequency of student speech
🔹 C. Formal language
🔹 D. Topic restriction

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The decisive factor is the low frequency of student speech; the professor dominates the communication, and students only intervene rarely by raising hands. This imbalance creates a monolog where the primary speaker controls the flow, distinguishing it from a true dialog.

Q14. What is the main advantage of separating the greeting rule into its own layer in a multi‑layer protocol?

🔹 A. Improves speed
🔹 B. Allows reuse across contexts
🔹 C. Reduces vocabulary size
🔹 D. Eliminates need for encryption

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Isolating the greeting rule into a dedicated layer makes it reusable for any interaction that requires polite openings, regardless of the underlying content or security mechanisms. This modularity simplifies design and promotes consistency across different communication scenarios.

Q15. Define protocol layering in the context of network communication.

🔹 A. A single rule for all devices
🔹 B. Multiple independent protocols stacked vertically
🔹 C. A method to encrypt data
🔹 D. A way to avoid turn‑taking

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Protocol layering means that different functional responsibilities are divided into separate protocol layers, each handling a specific aspect of communication. These layers are stacked vertically, allowing each to operate independently while cooperating to achieve end‑to‑end data exchange.

Q16. Which OSI layer is typically responsible for encryption and decryption of data?

🔹 A. Physical
🔹 B. Data Link
🔹 C. Network
🔹 D. Presentation

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The Presentation layer (layer 6) handles data representation, including encryption and decryption, to ensure that information is securely transformed before being transmitted. This layer abstracts cryptographic functions from lower layers, aligning with the concept of adding a security protocol on top of basic communication.

Q17. If the encryption algorithm used by Maria and Ann has a key length of 128 bits, how many possible keys exist? Express the answer using \( 2^{k} \).

🔹 A. \( 2^{64} \)
🔹 B. \( 2^{128} \)
🔹 C. \( 2^{256} \)
🔹 D. \( 2^{32} \)

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A 128‑bit key yields \( 2^{128} \) distinct possible keys, because each bit can be either 0 or 1. This large key space provides strong resistance against brute‑force attacks, illustrating why key length is a critical factor in cryptographic security.
