What is Layers in IEEE 802.16 protocol stack?

The IEEE 802.16 protocol stack consists of physical and MAC layers that manage how data is transmitted over radio waves and how multiple users share the wireless channel efficiently without interference.

📝 All Layers in IEEE 802.16 protocol stack MCQs

Q1. At which SONET layer does an add/drop multiplexer (ADM) operate?

A.Section layer
B.Path layer
C.Line layer ✅
D.Transport layer
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The ADM is defined to function at the line layer, where it swaps entire STS signals without generating new section or path overhead. It therefore does not belong to the section or path layers, making the line layer the correct answer.

Q2. How many bytes are contained in each ATM cell that fits within the 340‑byte payload?

A.48 bytes
B.53 bytes ✅
C.64 bytes
D.56 bytes
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A standard ATM cell carries 53 bytes (48 bytes of payload plus a 5‑byte header). The 340‑byte payload can accommodate roughly 44 of these cells, confirming that each cell is 53 bytes in size.

Q3. If an ADM replaces an STS‑3 signal with another STS‑3 signal, what happens to the total number of payload bytes?

A.The total increases
B.The total decreases
C.The total remains the same ✅
D.The total becomes zero
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Both the incoming and outgoing signals are STS‑3, which occupy identical payload space. Because the ADM only swaps bytes without adding or removing overhead, the overall payload byte count does not change, leaving the total unchanged.

Q4. Given that an ADM does not create new overhead, what can be inferred about the overhead bytes before and after the ADM?

A.They are unchanged ✅
B.They double
C.They halve
D.They are removed
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Since the ADM merely replaces the payload bytes—including any existing section and line overhead—it does not generate additional overhead. Consequently, the overhead bytes remain exactly the same before and after the ADM operation.

Q5. When an STS‑12 signal has one of its STS‑1 components swapped by an ADM, how many STS‑1 components stay unchanged?

A.11 ✅
B.12
C.1
D.0
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: An STS‑12 consists of twelve STS‑1 sub‑signals. If one of those is replaced, the remaining eleven retain their original content, so eleven STS‑1 components are unchanged.

Q6. If multiple ADMs are cascaded along a path, what is the cumulative effect on the section overhead?

A.It becomes additive
B.It becomes multiplicative
C.It remains unchanged ✅
D.It is doubled
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Each ADM only swaps payload bytes and does not introduce new section overhead. Cascading several ADMs therefore leaves the section overhead unchanged, because no additional overhead is generated at any point.

Q7. A 340‑byte payload can hold 44 ATM cells of 53 bytes each. If an ADM substitutes each cell with a larger 60‑byte cell, can the same payload still hold 44 cells?

A.Yes
B.No ✅
C.It depends on the overhead
D.Only if extra bytes are trimmed
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Replacing each 53‑byte cell with a 60‑byte cell would require 44 × 60 = 2640 bytes, far exceeding the 340‑byte payload limit. Therefore the same payload cannot accommodate the same number of larger cells.

Q8. An STS‑1 signal occupies 810 bytes of line overhead. An ADM swaps it with another STS‑1 having identical overhead. What is the net change in line overhead?

A.+810 bytes
B.‑810 bytes
C.0 bytes ✅
D.+1620 bytes
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Because both the incoming and outgoing STS‑1 signals carry the same 810‑byte line overhead, the ADM’s swap does not alter the total amount of line overhead, resulting in a net change of zero bytes.

Q9. Which statement best captures the difference between an ADM and a traditional multiplexer?

A.An ADM multiplexes several lower‑rate signals
B.An ADM demultiplexes a high‑rate signal
C.An ADM adds overhead to the payload
D.An ADM replaces payload bytes without creating new overhead ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Traditional multiplexers combine multiple lower‑rate signals into a higher‑rate stream, creating new overhead. In contrast, an ADM functions like a switch: it removes one STS signal and inserts another, swapping the payload bytes while preserving the existing overhead.

Q10. How does placing an ADM at the line layer affect network latency compared with using a path‑layer multiplexer?

A.It reduces latency
B.It slightly increases latency ✅
C.It has no effect on latency
D.It doubles the latency
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: An ADM operates at the line layer and performs a simple byte swap, which adds a small processing delay relative to a pure path‑layer multiplexer that may already be handling multiplexing. Thus, latency is slightly higher but not dramatically different.

Q11. What is the primary distinction between section overhead and line overhead in the context of ADM operation?

A.Section overhead belongs to the path layer, line overhead belongs to the line layer ✅
B.Section overhead is added by the ADM, line overhead is removed
C.Section overhead is larger than line overhead
D.Section overhead only exists in SONET, line overhead only in Ethernet
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Section overhead is associated with the path layer and remains unchanged by an ADM, while line overhead belongs to the line layer where the ADM operates. The ADM swaps payload bytes but does not alter either type of overhead.

Q12. Why does an ADM not generate new overhead bytes even when it inserts new payload data?

A.It compresses the data to fit existing overhead
B.It adds hidden overhead that is later removed
C.It replaces bytes, including the existing overhead, with new bytes ✅
D.It works at the physical layer where overhead is irrelevant
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The ADM’s function is to remove the original bytes—both payload and overhead—and replace them with new bytes that contain the same overhead structure. Because it swaps rather than adds, no additional overhead is produced.

Q13. How does the signal integrity compare when using an ADM versus demultiplexing at the path layer?

A.The ADM degrades integrity more than path‑layer demultiplexing
B.The ADM preserves integrity better because it avoids re‑encoding ✅
C.The ADM introduces random errors
D.The ADM converts the signal to analog form
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: An ADM simply swaps bytes without re‑encoding or altering the signal format, which tends to preserve integrity better than a path‑layer demultiplexer that must break and reform the signal, potentially introducing timing or encoding errors.

Q14. Assess the scalability of employing ADMs for adding and dropping STS‑n signals in a high‑capacity SONET network.

A.Scales poorly because each ADM adds significant overhead
B.Scales moderately; only a few ADMs can be used
C.Scales not at all; ADMs are unsuitable for large networks
D.Scales well because ADMs do not add overhead and can be cascaded freely ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Since ADMs do not generate additional overhead and merely replace payload bytes, they can be placed at many points in the network without increasing bandwidth consumption. This makes them highly scalable for dynamic add/drop operations in large SONET deployments.

Q15. When a 340‑byte payload is divided into 44 ATM cells versus using larger cells, which arrangement yields higher bandwidth efficiency?

A.Dividing into 44 ATM cells yields the highest efficiency ✅
B.Using larger cells yields higher efficiency
C.Both arrangements have equal efficiency
D.Neither arrangement is efficient; a different framing is needed
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The 44 ATM cells each occupy 53 bytes, using the payload fully (44 × 53 = 2332 bytes of total SONET frame). Larger cells would either waste space or exceed the payload limit, so the 44‑cell division provides the most efficient use of the available bytes.

Q16. Apply the principle of ADM operation to explain how traffic engineering can be performed without altering overhead.

A.By changing the overhead format
B.By swapping payload while preserving overhead ✅
C.By increasing the line rate
D.By reducing the section overhead
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: An ADM enables traffic engineering by removing one STS signal and inserting another of the same rate. Because the overhead bytes are part of the swapped payload, the overall overhead pattern remains unchanged, allowing bandwidth adjustments without modifying the overhead structure.

Q17. Synthesize a scenario where multiple ADMs enable dynamic bandwidth allocation across STS‑3 signals. What network behavior results?

A.Bandwidth becomes fixed and cannot change
B.No change in bandwidth distribution
C.Dynamic allocation of bandwidth among STS‑3 channels ✅
D.Reduced overall capacity of the network
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: When several ADMs are deployed, each can independently drop an existing STS‑3 and insert a different one, allowing the network to reassign bandwidth on the fly. This results in a flexible, dynamically allocated bandwidth environment that adapts to traffic demands.

Q18. Explain how the \switch‑like\ behavior of ADMs influences fault isolation in a SONET network.

A.Faults spread to all signals ✅
B.Fault stays within the swapped signal only
C.No effect on fault propagation
D.Fault causes complete network outage
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Because an ADM functions like a switch—removing one signal and inserting another—any fault introduced by the new signal is confined to that specific STS path. The rest of the network continues to operate with its original signals, simplifying fault isolation and limiting impact.

Q19. Given a 340‑byte payload holding 44 ATM cells each with a 5‑byte header, what percentage of the payload is occupied by headers?

A.0.094
B.0.125
C.0.647 ✅
D.0.353
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Each ATM cell has a 5‑byte header, so total header bytes = 44 × 5 = 220. The payload is 340 bytes, thus the header proportion = 220 / 340 ≈ 0.647, or 64.7 % of the payload.

Q20. If an ADM replaces an STS‑1 with another identical STS‑1, how does this affect the end‑to‑end delay assuming propagation delay is unchanged?

A.It increases the delay
B.It does not change the delay ✅
C.It decreases the delay
D.It doubles the delay
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The ADM’s operation adds only a negligible processing time, which is typically far smaller than propagation delay. Since the signal rate and path remain the same, the end‑to‑end delay is effectively unchanged.

Q21. Apply the concept of layer separation to justify why ADMs operate at the line layer rather than the path layer.

A.Because the path layer handles physical wiring
B.Because the line layer provides the correct overhead context for swapping signals
C.Because the section layer is reserved for routing
D.Because the physical layer cannot process bytes ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: ADMs need to replace entire STS payloads while preserving line overhead, which is defined at the line layer. Operating at the line layer ensures that the overhead bytes are correctly aligned and that the swap does not interfere with higher‑layer path functions.
