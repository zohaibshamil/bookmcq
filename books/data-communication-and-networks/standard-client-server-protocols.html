🔹 D. No network activity occurs

Q2. Which of the following best compares the GET and POST methods when a web form includes a file upload?

🔹 A. GET appends form data to the URL, making it unsuitable for large binary files, while POST includes data in the request body, allowing file uploads.
🔹 B. GET encrypts the file data, whereas POST sends it in plain text.
🔹 C. GET can only be used for retrieving resources, not for submitting any form data.
🔹 D. POST always results in a cached response, while GET never does.

💡 Difficulty: medium | ✅ Correct: A

🔹 C. Server returns 404 Not Found
🔹 D. Server returns 500 Internal Server Error
