Q1. What does the acronym LAN stand for?

🔹 A. Local Access Network
🔹 B. Local Area Network
🔹 C. Large Area Network
🔹 D. Limited Access Node

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

LAN stands for Local Area Network, a type of network that interconnects devices within a confined geographic area such as an office building or campus. The other choices either modify the meaning of the words or refer to unrelated concepts, making option B the precise definition.

Q2. If a switch forwards a frame only to the port associated with the destination MAC address, what is the most direct effect on network traffic?

🔹 A. Increases broadcast traffic
🔹 B. Creates more collisions
🔹 C. Requires each host to listen to all frames
🔹 D. Reduces unnecessary frame processing

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

By sending the frame only to the port that leads to the intended recipient, the switch eliminates the need for every host to examine the frame, thereby reducing unnecessary processing and freeing bandwidth for other traffic. This targeted forwarding directly lowers overall network load.

Q3. Which of the following best contrasts a hub and a switch in terms of collision domains?

🔹 A. A hub places all ports in one collision domain, while a switch creates a separate collision domain per port
🔹 B. Both hub and switch have the same collision domain
🔹 C. A hub forwards frames based on MAC addresses
🔹 D. A switch broadcasts all frames

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A hub operates as a multi‑port repeater, so every attached device shares a single collision domain, causing any transmission to potentially collide with others. In contrast, a switch maintains an independent collision domain for each port, isolating traffic and preventing collisions between separate host pairs, which is the key distinction.

Q4. In a star topology LAN using a single switch, what is the maximum number of simultaneous, non‑interfering full‑duplex communications that can occur among N hosts?

🔹 A. \(N-1\)
🔹 B. \(N/2\)
🔹 C. \(2N\)
🔹 D. \(N\)

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Each host connects to its own dedicated port on the switch, and a full‑duplex link can exist between any two ports simultaneously. Because the switch can handle multiple independent streams, the theoretical upper bound equals the total number of hosts, N, assuming each host participates in at most one conversation at a time.

Q5. Host A sends to Host B while Host C sends to Host D at the same time in a switched LAN. Under which condition will both transmissions succeed without collisions?

🔹 A. The switch has separate output ports for each destination
🔹 B. Both destination MAC addresses are unknown to the switch
🔹 C. A and C share the same source MAC address
🔹 D. The network uses half‑duplex mode

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When the switch receives two frames destined for different MAC addresses, it forwards each out the distinct egress port associated with that address. Because the ports are separate, the frames travel on independent physical links, preventing any collision and allowing both communications to proceed concurrently.

Q6. When broadcast traffic approaches the capacity of a switch’s backplane, which outcome is most likely?

🔹 A. Increased frame loss due to buffer overflow
🔹 B. Unchanged latency
🔹 C. Reduced latency for unicast frames
🔹 D. Switch will convert broadcasts to unicasts

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

As broadcast frames consume shared bandwidth, the switch’s internal buffers can fill quickly. When the backplane cannot forward all incoming broadcast traffic, excess frames are dropped, leading to higher loss rates. Latency typically rises rather than stays unchanged, and the switch does not alter the nature of broadcasts.

Q7. Design a LAN for 50 users requiring high availability. Which configuration best provides redundancy while minimizing additional hardware?

🔹 A. Two independent switches with separate cabling for each host
🔹 B. A single 48‑port switch plus a 2‑port uplink
🔹 C. Stacked pair of 48‑port switches with dual uplinks
🔹 D. Ring topology using repeaters

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Stacking two 48‑port switches creates a single logical device with dual uplink paths, so if one switch or uplink fails, traffic automatically shifts to the other. This provides fault tolerance without needing separate cabling for each host, meeting the redundancy requirement efficiently.

Q8. If a switch receives a frame whose destination MAC address is not in its forwarding table, what does the switch do next?

🔹 A. Flood the frame out all ports except the ingress port
🔹 B. Discard the frame immediately
🔹 C. Send an ARP request to locate the destination
🔹 D. Convert the frame to a broadcast

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When the destination MAC is unknown, the switch cannot determine the correct egress port, so it floods the frame to every port except the one it arrived on. This ensures the intended recipient receives the frame while the switch learns the correct port for future traffic.

Q9. Which statement correctly compares using VLANs on a single switch versus deploying separate physical switches for isolating departments?

🔹 A. VLANs provide less security than separate switches because traffic can still be sniffed
🔹 B. Separate switches eliminate the need for trunk links, reducing configuration complexity
🔹 C. VLANs allow logical segmentation without additional hardware, but both solutions can enforce isolation
🔹 D. Physical switches cannot support QoS policies, unlike VLANs

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

VLANs enable logical separation of traffic on the same physical device, eliminating the need for extra switches while still providing isolation comparable to physically separate switches. Both approaches can enforce security policies, but VLANs achieve this with less hardware and simpler management.

Q10. Why does a switched LAN not rely on CSMA/CD for collision avoidance?

🔹 A. Each frame is transferred point‑to‑point over dedicated ports
🔹 B. Switches use token passing
🔹 C. CSMA/CD is only for wireless networks
🔹 D. Switches convert frames to packets

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A switch creates a dedicated point‑to‑point path between the source and destination ports, so frames travel over separate physical circuits. Because there is no shared medium, the carrier‑sense multiple access with collision detection mechanism is unnecessary; collisions are avoided by design.

Q11. In a legacy LAN with a single shared cable, Host 1 sends a packet to Host 2. Which hosts will physically receive the packet?

🔹 A. Only Host 2
🔹 B. Host 2 and the network hub
🔹 C. All hosts on the cable
🔹 D. None, because the packet is addressed

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

A shared‑medium network broadcasts every transmitted frame onto the common cable, so all connected devices detect the electrical signal. The intended recipient processes the packet, while the others discard it after examining the destination address. Consequently, every host attached to the cable physically receives the transmission.

Q12. If two ports on a switch are mismatched—one set to full‑duplex and the other to half‑duplex—what is the most likely effect?

🔹 A. Both ports will operate at full‑duplex
🔹 B. The switch will automatically correct the mismatch
🔹 C. No impact on traffic
🔹 D. Increased error rates and collisions on the half‑duplex side

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The half‑duplex port will still use CSMA/CD, while the full‑duplex port expects a collision‑free stream. This mismatch causes the full‑duplex side to see unexpected collisions, leading to frame errors, retransmissions, and degraded performance on the half‑duplex link.

Q13. What is the primary reason a switch’s MAC address table employs an aging timer?

🔹 A. To increase broadcast traffic
🔹 B. To prioritize older devices
🔹 C. To free memory for new entries
🔹 D. To synchronize with DHCP leases

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

MAC address entries are kept only while they are actively used. The aging timer removes stale entries after a period of inactivity, freeing space for new devices and preventing the table from becoming full with obsolete addresses, which maintains efficient forwarding.

Q14. A switch’s MAC table can hold 100 entries. When the 101st unique host communicates, what typically occurs?

🔹 A. The oldest entry is removed to make space
🔹 B. The switch drops the frame
🔹 C. The switch expands the table automatically
🔹 D. All entries are flushed

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When the table reaches its capacity, most switches employ a least‑recently‑used (LRU) eviction policy. The oldest or least‑active entry is discarded to accommodate the new MAC address, ensuring continuous learning without requiring a full table reset.

Q15. In a switched LAN with 8 hosts, each host transmits in a given time slot with probability 0.1. Assuming the switch perfectly isolates ports, what is the probability that at least one collision occurs on the shared medium before the switch forwards frames?

🔹 A. \(1-(0.9)^8\)
🔹 B. \(0\)
🔹 C. \(0.1\)
🔹 D. \(0.8\)

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Because the switch provides a separate point‑to‑point path for each port, frames never share a common collision domain. Consequently, even if multiple hosts transmit simultaneously, the switch buffers and forwards them without collisions, making the probability of a collision on the shared medium exactly zero.
