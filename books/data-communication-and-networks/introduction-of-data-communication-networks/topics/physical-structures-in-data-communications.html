📝 All Physical Structures in data communications MCQs

Q1. What does a point-to-point connection provide?

🔹 A. A dedicated link between two devices
🔹 B. A shared link among many devices
🔹 C. A wireless broadcast
🔹 D. A virtual circuit

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A point-to-point connection reserves the entire link capacity for the two endpoints, meaning no other device can use that link while communication occurs. This exclusivity guarantees that the bandwidth is fully available to the two devices, eliminating contention and providing predictable performance.

Q2. Which topology directly connects each node to every other node?

🔹 A. Bus
🔹 B. Star
🔹 C. Ring
🔹 D. Mesh

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The mesh topology creates a direct link between every pair of nodes. This arrangement ensures that each node can communicate with any other node without passing through intermediate devices, which distinguishes it from bus, star, and ring topologies that rely on shared media or intermediary connections.

Q3. In a fully connected mesh with n nodes, how many duplex-mode links are required?

🔹 A. n(n-1)
🔹 B. n(n+1)/2
🔹 C. n(n-1)/2
🔹 D. (n-1)/2

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The formula for a fully connected mesh in duplex mode accounts for each unique pair of nodes. Since each pair needs only one bidirectional link, the total number of links equals the combination of n items taken two at a time, expressed as n × (n − 1) ÷ 2.

Q4. What term describes sharing a link’s capacity by taking turns?

🔹 A. Spatially shared
🔹 B. Timeshared
🔹 C. Duplex
🔹 D. Broadcast

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When users must take turns to use a single communication link, the link is said to be timeshared. This temporal sharing means that each device occupies the link for a fraction of time, allowing multiple devices to use the same physical medium sequentially rather than simultaneously.

Q5. If a network uses a point-to-point link, what happens to bandwidth for other devices?

🔹 A. It is reduced for all devices
🔹 B. It is exclusively reserved for the two devices
🔹 C. It is shared equally among all devices
🔹 D. It becomes unlimited for other devices

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A point-to-point link dedicates the entire capacity of that link to the two connected devices. Consequently, no other device can access that bandwidth, which prevents any competition for the channel and ensures that the two devices enjoy full, uncontested throughput.

Q6. When a multipoint link is spatially shared, what can be inferred about simultaneous transmissions?

🔹 A. Only one device can transmit at a time
🔹 B. Multiple devices can transmit simultaneously without interference
🔹 C. Devices must take turns to transmit
🔹 D. Transmission is impossible

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Spatial sharing allows several devices to occupy the same physical medium at the same time. In this mode, signals from different devices coexist, so multiple transmissions can occur concurrently. The network must handle possible collisions, but the key inference is that simultaneous use is permitted.

Q7. What is a direct logical consequence of adding a new node to a fully connected mesh?

🔹 A. The total number of links decreases
🔹 B. The number of links remains unchanged
🔹 C. The number of links increases by the current node count
🔹 D. The network becomes a star topology

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When a new node joins a fully connected mesh, it must establish a dedicated link with every existing node. Therefore, the total link count grows by exactly the number of nodes already present, reflecting the additive nature of mesh connectivity.

Q8. How does a timeshared multipoint connection affect latency compared to a spatially shared one?

🔹 A. Latency is always lower
🔹 B. Latency can increase because devices wait for their turn
🔹 C. Latency is unaffected
🔹 D. Latency becomes zero

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

In a timeshared environment, each device must wait for its allocated time slot before transmitting, which can introduce waiting periods and thus increase overall latency. Spatial sharing allows devices to send immediately, albeit with possible collisions, generally resulting in lower average latency.

Q9. If a point-to-point link is replaced by a multipoint link, what is the most likely effect on overall network capacity?

🔹 A. Capacity per device increases
🔹 B. Total capacity remains identical
🔹 C. Effective capacity per device decreases due to sharing
🔹 D. Capacity becomes unlimited

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Switching from a dedicated point-to-point link to a shared multipoint link introduces contention among multiple devices. Because the link’s total bandwidth must now be divided among all users, each individual device typically experiences a reduction in the effective capacity it can utilize.

Q10. Which factor most strongly influences the cost difference between point-to-point and multipoint connections?

🔹 A. Length of the cable
🔹 B. Number of devices sharing the link
🔹 C. Type of connector used
🔹 D. Color of the cable

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Multipoint connections allow many devices to share a single physical medium, reducing the amount of cabling and hardware needed compared with separate point-to-point links for each pair. Therefore, the primary cost driver is the number of devices that can share the same link.

Q11. Why are dedicated links in point-to-point connections generally more expensive per device than shared links?

🔹 A. Because they require more expensive protocols
🔹 B. Because each link must be installed individually for each pair of devices
🔹 C. Because they use wireless spectrum
🔹 D. Because they need special encryption

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A dedicated point-to-point link must be physically provisioned for every communicating pair, which means installing separate cables or wireless paths for each connection. This individual provisioning multiplies material and labor costs, making the per‑device expense higher than that of a shared medium where many devices use the same link.

Q12. How does a bus topology compare to a star topology in terms of fault tolerance?

🔹 A. Bus is more tolerant because a single cable carries all traffic
🔹 B. Star is more tolerant because failure of one link only isolates a single node
🔹 C. Both have identical fault tolerance
🔹 D. Star is less tolerant because the hub can fail

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

In a star topology, each node connects to a central hub; if a single link fails, only the associated node loses connectivity while the rest of the network remains operational. Conversely, a bus topology relies on a single backbone; a break in that backbone can disrupt communication for all attached devices, making the star generally more fault‑tolerant.

Q13. What distinguishes a spatially shared multipoint connection from a temporally shared one?

🔹 A. Spatial sharing allows simultaneous use while temporal sharing requires turn‑taking
🔹 B. Temporal sharing allows simultaneous use while spatial sharing requires turn‑taking
🔹 C. Both use the same method of sharing
🔹 D. Neither involves sharing at all

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Spatial sharing permits multiple devices to occupy the same medium at the same instant, often leading to possible collisions that must be managed. Temporal sharing, on the other hand, allocates distinct time slots to each device, preventing simultaneous transmission and eliminating collisions, but introducing scheduling overhead.

Q14. When the number of nodes in a mesh network doubles, how does the required number of I/O ports per device change?

🔹 A. It stays the same
🔹 B. It doubles
🔹 C. It increases by one
🔹 D. It decreases by half

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Each node in a mesh must maintain a separate physical connection to every other node. If the node count doubles, each device must now connect to twice as many peers, meaning the number of required input/output ports per device also doubles to accommodate the additional dedicated links.

Q15. For a small office with five devices, which topology usually offers the best balance of cost and performance?

🔹 A. Mesh
🔹 B. Bus
🔹 C. Star
🔹 D. Ring

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

A star topology connects each device to a central hub or switch, requiring only five short cables and providing dedicated bandwidth to each device. This arrangement is less expensive than a full mesh while delivering better performance and easier management than a bus, making it the optimal choice for a small office.

Q16. In a timeshared multipoint link, how does increasing the number of users affect individual bandwidth?

🔹 A. Each user gets more bandwidth
🔹 B. Bandwidth per user stays constant
🔹 C. Bandwidth per user decreases proportionally
🔹 D. Bandwidth becomes unlimited

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

When users share a link by taking turns, the total bandwidth is divided among all participants. Adding more users means each must occupy a smaller portion of the time schedule, causing the effective bandwidth available to each user to shrink roughly in proportion to the number of users sharing the link.

Q17. Which hybrid topology combines the redundancy of a mesh with the simplicity of a star for a campus network?

🔹 A. Star‑bus
🔹 B. Mesh‑star
🔹 C. Ring‑bus
🔹 D. Tree

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A mesh‑star hybrid connects multiple star segments together with additional inter‑star links, creating a mesh of star clusters. This design retains the straightforward cabling of star segments while adding redundant paths between clusters, providing higher resilience typical of mesh networks without the full complexity of a pure mesh.

Q18. Why does a mesh topology provide high reliability compared to other topologies?

🔹 A. Because it uses fewer cables
🔹 B. Because every node has multiple alternate paths
🔹 C. Because it relies on a single central hub
🔹 D. Because it limits traffic to one direction

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

In a mesh, each node is directly linked to every other node, offering numerous alternate routes for data. If any single link fails, traffic can be rerouted through other existing links, preserving connectivity. This multiplicity of paths makes mesh networks inherently more reliable than topologies that depend on a single backbone or central device.

Q19. How does using duplex‑mode links reduce the number of physical cables required in a fully connected mesh of n nodes?

🔹 A. It halves the number of required cables
🔹 B. It doubles the number of required cables
🔹 C. It does not affect cable count
🔹 D. It eliminates the need for cables entirely

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Duplex‑mode allows a single physical cable to carry traffic in both directions simultaneously. In a mesh where each pair of nodes needs only one bidirectional link, the count of required cables is therefore the combination n × (n − 1) ÷ 2, which is half the count that would be needed if separate unidirectional cables were required for each direction.

Q20. If a link fails in a star topology, what is the immediate impact on network connectivity?

🔹 A. All devices lose connectivity
🔹 B. Only the device attached to the failed link is isolated
🔹 C. The entire network becomes faster
🔹 D. The network automatically reconfigures to a mesh

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

In a star arrangement, each node connects individually to a central hub. When a single link between a node and the hub fails, only that node loses access to the network; the remaining nodes continue communicating through the hub unaffected.

Q21. What performance change is most likely when converting a bus topology to a ring topology?

🔹 A. Latency decreases and bandwidth increases
🔹 B. Latency increases and bandwidth decreases
🔹 C. Both latency and bandwidth remain unchanged
🔹 D. The network becomes wireless

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A ring topology typically provides a more orderly token‑passing protocol, reducing collisions and allowing higher effective bandwidth. Because each node forwards frames in a single direction, the deterministic nature of the ring can lower latency compared with the broadcast‑heavy bus, which suffers from collisions and variable delays.

Q22. Why might an infrared remote control be considered a point‑to‑point connection?

🔹 A. It broadcasts to all devices
🔹 B. It establishes a dedicated line of sight link between the remote and the TV
🔹 C. It uses a shared Wi‑Fi channel
🔹 D. It relies on satellite communication

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Infrared communication requires a direct line of sight between the transmitter (remote) and the receiver (television). This creates a dedicated, exclusive link for that moment, fitting the definition of a point‑to‑point connection where only the two devices share the communication pathway.

Q23. What are the main trade‑offs when using a satellite link as a point‑to‑point connection versus a fiber optic link?

🔹 A. Satellite offers lower latency but higher cost
🔹 B. Fiber offers higher latency but lower reliability
🔹 C. Satellite provides higher latency and susceptibility to weather, while fiber gives lower latency and greater reliability
🔹 D. Both have identical performance characteristics

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Satellite links must travel to and from orbit, introducing significant propagation delay (high latency) and being vulnerable to atmospheric conditions. Fiber optics, by contrast, transmit signals through glass at near‑light speeds, delivering low latency and high reliability, though they may involve higher installation costs in remote areas.

Q24. How would you design a time‑division multiplexed link for three devices sharing a single channel?

🔹 A. Assign each device a fixed time slot in a repeating schedule
🔹 B. Allow all devices to transmit simultaneously
🔹 C. Use separate physical cables for each device
🔹 D. Share the channel randomly without scheduling

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Time‑division multiplexing (TDM) divides a single communication channel into sequential time slots, each allocated to a different device. By giving each of the three devices a recurring slot, the link can serve all three without collisions, ensuring orderly access while making efficient use of the shared medium.

Q25. When a link in a mesh network fails, what is the most likely immediate effect on overall connectivity?

🔹 A. The entire network collapses
🔹 B. All communication stops between the two nodes only
🔹 C. The network automatically reroutes traffic through alternate paths
🔹 D. Latency becomes zero

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Because each node pair in a mesh has multiple alternate routes, the loss of a single link only removes one direct path. The network can quickly adapt by sending data via other existing links, preserving overall connectivity while possibly increasing the number of hops for affected pairs.

Q26. If you add a new node to a star topology, how does the cost compare to adding the same node to a mesh topology?

🔹 A. Both cost the same
🔹 B. Adding to a star is cheaper because only one new cable is needed
🔹 C. Adding to a mesh is cheaper because it uses existing cables
🔹 D. Adding to a star is more expensive because it requires a hub upgrade

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

In a star, the new device connects directly to the central hub with a single cable, incurring minimal expense. In a mesh, the new node must connect to every existing node, requiring many additional cables and I/O ports, which dramatically raises the cost relative to the star approach.

Q27. What advantage does a hybrid topology that combines star and bus segments provide?

🔹 A. It eliminates the need for any switches
🔹 B. It reduces cable length while preserving a central management point
🔹 C. It guarantees zero latency
🔹 D. It prevents any possible network failures

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A star‑bus hybrid uses a central hub for star segments, reducing cable runs, while the bus segment links multiple hubs together, simplifying overall layout. This structure balances the management convenience of a star with the cabling efficiency of a bus, offering scalable connectivity without excessive wiring.

Q28. How does spatial sharing affect the collision domain in a network?

🔹 A. It enlarges the collision domain because multiple devices transmit on the same medium
🔹 B. It eliminates collisions entirely
🔹 C. It reduces the collision domain to a single device
🔹 D. It has no impact on collisions

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When multiple devices share the same physical medium simultaneously (spatial sharing), any simultaneous transmissions can interfere, creating a larger collision domain where a collision can occur among any of the participating devices. Proper media access control mechanisms are required to mitigate this increased risk.

Q29. What impact does increasing the number of I/O ports on a device have on its design complexity?

🔹 A. It simplifies the device architecture
🔹 B. It has no effect on design complexity
🔹 C. It increases design complexity due to more circuitry and routing
🔹 D. It reduces power consumption

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Each additional I/O port requires extra transceiver circuitry, signal routing, and often more sophisticated switching logic. Managing a larger number of ports increases the physical layout challenges, testing requirements, and potential for signal integrity issues, thereby raising the overall design complexity of the device.

Q30. In a fully connected mesh, how does the number of links relate to the network’s diameter?

🔹 A. Diameter equals the number of links
🔹 B. Diameter is always one because each node is directly connected
🔹 C. Diameter grows exponentially with links
🔹 D. Diameter is unrelated to links

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The diameter of a network is the longest shortest path between any two nodes. In a fully connected mesh, every node pair shares a direct link, so the shortest path between any two nodes consists of a single hop, making the diameter equal to one regardless of the total number of links.

Q31. What could happen if a network designer mistakenly assumes all mesh links are duplex when some are simplex?

🔹 A. The network will operate faster
🔹 B. The estimated number of required cables will be too low, leading to insufficient physical connections
🔹 C. The network will have extra cables that are never used
🔹 D. The network will become a ring topology

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Duplex links allow bidirectional communication over a single cable, halving the count needed for a mesh. Assuming duplex mode when some links are actually simplex (unidirectional) underestimates the total cables required, potentially leaving some node pairs without a proper physical connection and causing connectivity failures.

Q32. When comparing logical reasoning and analytical approaches, which statement best describes their difference?

🔹 A. Logical reasoning deals with facts while analytical deals with emotions
🔹 B. Logical reasoning infers cause‑effect relationships; analytical evaluates and compares alternatives
🔹 C. Both are identical in method
🔹 D. Logical reasoning is always easier than analytical

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Logical reasoning focuses on deducing conclusions from premises, often examining cause‑effect or inference chains. Analytical thinking, by contrast, breaks down situations into components, compares alternatives, and evaluates trade‑offs. While both are higher‑order skills, they serve distinct purposes: one derives implications, the other assesses and contrasts options.
