What is Data Flow in data communications?

Data flow describes the direction in which information travels between two devices, categorized as simplex for one-way communication only, half-duplex for two-way communication where only one party transmits at a time, and full-duplex for simultaneous two-way transmission.

Q1. Which of the following best describes a simplex data flow mode?

A. Both devices can transmit and receive simultaneously
B. Only one device can transmit while the other receives ✅
C. Devices take turns transmitting
D. Devices share bandwidth equally

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

In simplex communication the link carries data in only one direction at any time. One endpoint is dedicated to sending, and the opposite endpoint is dedicated to receiving. This unidirectional behavior matches the description that only one device can transmit while the other receives, making option B the correct choice.

Q2. If a channel is configured for half‑duplex and both devices attempt to transmit at the same moment, what is the most likely outcome?

A. A collision occurs on the medium ✅
B. One device automatically switches to receive mode
C. Both transmissions succeed without interference
D. The channel capacity doubles temporarily

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Half‑duplex links allow only one direction of transmission at a time. When both ends try to send simultaneously, their signals interfere, producing a collision that corrupts the data. The protocol must then detect the collision and schedule a retransmission, so a collision is the expected result.

Q3. Which mode utilizes the full channel capacity for each direction of communication?

A. Simplex
B. Half‑duplex
C. None of the above
D. Full‑duplex ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

Full‑duplex communication permits both ends to send and receive at the same time, effectively giving each direction its own share of the channel’s bandwidth. Unlike simplex or half‑duplex, where only one direction can use the entire capacity, full‑duplex provides full capacity to each direction, making option D correct.

Q4. In a telephone network using full‑duplex, each direction requires \(2\text{ Mbps}\) and the physical link capacity is \(5\text{ Mbps}\). Can the link support the communication?

A. Yes, because \(2+2 < 5\)
B. No, because full‑duplex halves capacity
C. Yes, because full‑duplex doubles capacity ✅
D. No, because each direction needs a separate path

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The total demand is \(2\text{ Mbps}\) per direction, summing to \(4\text{ Mbps}\). Since the link provides \(5\text{ Mbps}\), the demand fits within the available bandwidth. Therefore the link can support the communication, which corresponds to option C.

Q5. In a walkie‑talkie (half‑duplex) network, device A is transmitting. What must device B do to respond?

A. Transmit simultaneously
B. Use a different frequency
C. Increase transmission power
D. Wait until A stops transmitting ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Walkie‑talkies operate like a one‑lane road: only one side may speak at a time. When device A is talking, device B cannot send until the channel is clear. Hence B must wait for A to finish before replying, matching option D.

Q6. A client sends a request to a server and then waits for a response. Which communication mode is most efficient for this pattern?

A. Half‑duplex ✅
B. Simplex
C. Full‑duplex
D. Broadcast

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The interaction follows a request‑then‑wait pattern, meaning only one direction is active at any moment. Half‑duplex allows the client to send the request, then the server to send the response, using the same channel without needing simultaneous transmission, making it the most efficient choice.

Q7. A link of \(10\text{ Mbps}\) is used in full‑duplex mode with equal bandwidth allocation. What is the maximum throughput per direction?

A. \(10\text{ Mbps}\)
B. \(2.5\text{ Mbps}\)
C. \(20\text{ Mbps}\)
D. \(5\text{ Mbps}\) ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Full‑duplex splits the total capacity between the two directions when the allocation is equal. Dividing \(10\text{ Mbps}\) by two yields \(5\text{ Mbps}\) for each direction. Therefore the maximum throughput per direction is \(5\text{ Mbps}\), which is option D.

Q8. When upgrading a network from half‑duplex to full‑duplex without adding extra physical paths, what must happen to the channel's capacity?

A. The capacity must be split between directions ✅
B. The capacity must be doubled
C. The capacity remains unchanged
D. The capacity becomes zero

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Converting to full‑duplex on the same physical medium requires dividing the existing bandwidth so that each direction can use a portion simultaneously. Hence the original capacity is shared, or split, between the two directions, matching option A.

Q9. Which statement correctly compares simplex and full‑duplex regarding channel utilization?

A. Simplex uses half of the channel capacity
B. Full‑duplex uses the full capacity for each direction
C. Full‑duplex uses the full capacity for each direction ✅
D. Full‑duplex cannot share capacity with simplex traffic

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

In simplex mode only one direction can occupy the entire channel, while full‑duplex allows both directions to transmit at the same time, each using the full channel capacity allocated to it. Therefore the accurate comparison is that full‑duplex uses the full capacity for each direction, option C.

Q10. A monitor receives data from a mainframe while also sending status updates back. Which communication mode is required?

A. Simplex
B. Half‑duplex
C. None
D. Full‑duplex ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Because the monitor must both receive and transmit concurrently, a mode that supports simultaneous bidirectional traffic is needed. Full‑duplex enables both ends to send and receive at the same time, satisfying the requirement, so option D is correct.

Q11. A half‑duplex link has \(8\text{ Mbps}\) capacity. Device X needs to send \(3\text{ Mbps}\) continuously, and Device Y needs to send \(5\text{ Mbps}\) intermittently. Can the link support both without collisions?

A. Yes, because the total demand is less than \(8\text{ Mbps}\)
B. No, because half‑duplex cannot handle simultaneous traffic
C. Yes, if the devices schedule their transmissions to avoid overlap ✅
D. No, because \(5+3 > 8\)

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

In half‑duplex, only one side can transmit at any instant. Although the combined bandwidth demand (\(3+5=8\) Mbps) does not exceed the link capacity, simultaneous transmission would cause a collision. By scheduling the intermittent \(5\text{ Mbps}\) bursts so they do not overlap with the continuous \(3\text{ Mbps}\) stream, both can share the link without collisions, making option C correct.

Q12. Three devices A, B, and C are connected via a hub that operates in half‑duplex. If A sends to B while C also sends to B, what is the likely outcome?

A. Both messages arrive correctly
B. A collision causing loss of both messages ✅
C. The hub converts the traffic to full‑duplex automatically
D. Only one message is queued and delivered later

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A hub repeats incoming signals to all ports without buffering. In half‑duplex mode, when A and C transmit at the same time to B, their signals interfere on the shared medium, producing a collision that corrupts both frames. The hub cannot resolve the conflict, so the collision outcome described in option B is expected.

Q13. Design a network where a central server must communicate bidirectionally with many workstations simultaneously while minimizing hardware. Which combination best meets the requirement?

A. Full‑duplex links using a switch ✅
B. Simplex links with separate cables
C. Half‑duplex links with time‑division multiplexing
D. Broadcast mode with a hub

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A modern Ethernet switch can provide full‑duplex point‑to‑point connections to each workstation, allowing simultaneous two‑way communication without requiring separate physical cables for each direction. This solution uses existing hardware efficiently and meets the need for concurrent bidirectional traffic, making option A the optimal choice.
