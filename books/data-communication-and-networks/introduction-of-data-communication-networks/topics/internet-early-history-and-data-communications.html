What is Internet Early History and data communications?

Internet early history traces back to the 1960s and 1970s with government-funded research projects like ARPANET that pioneered packet switching and host-to-host protocols, laying the theoretical and practical groundwork for decentralized data communications before commercial expansion.

Q1. Based on the description of ARPANET's initial four nodes, which inference best explains why the University of California at Los Angeles (UCLA) was chosen as one of the first sites?

A. It had the most powerful mainframe.
B. It was geographically closest to the other sites.
C. It was the only site with an IMP already built.
D. It had an existing research interest in networking. ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

UCLA was selected because it already possessed a strong computer‑science research program interested in networking, making it a logical early participant. This inference follows from the emphasis on research collaboration rather than hardware availability, aligning with ARPA’s goal to link innovative academic sites. The decision reflects strategic selection rather than mere proximity or existing equipment.

Q2. If packet switching allows bursty traffic, what can be inferred about the performance of telegraph networks when handling similar bursty data compared to ARPANET's early implementation?

A. Telegraph networks would experience higher latency and possible data loss when handling bursty traffic. ✅
B. Telegraph networks would handle bursts more efficiently than ARPANET.
C. Telegraph networks would convert bursty data into constant-rate streams automatically.
D. Telegraph networks would be unaffected because they use analog signals.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Telegraph systems of the \(1960\) era were built for steady, constant‑rate signaling. When bursty traffic arrives, they cannot buffer or reroute packets, leading to queuing delays and possible loss. ARPANET’s packet‑switching design, by contrast, spreads bursts across multiple paths, so the logical inference is that telegraph networks would suffer higher latency and data loss.

Q3. Considering Leonard Kleinrock's 1961 theory of packet switching and the later development of ARPANET, which logical chain best demonstrates the causality between theory and practical deployment?

A. Kleinrock's theory → immediate commercial routers → ARPANET's IMP design.
B. Kleinrock's theory → development of Ethernet → ARPANET's packet structure.
C. Kleinrock's theory → academic research → ARPA's funding → IMP implementation. ✅
D. Kleinrock's theory → abandonment of telegraph networks → direct creation of ARPANET.

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Kleinrock first articulated packet‑switching concepts in \(1961\). Academic researchers built on his work, prompting ARPA to fund experiments that led to the creation of Interface Message Processors (IMPs). This sequence—theory, scholarly follow‑up, agency funding, and hardware implementation—clearly links the original idea to the concrete ARPANET architecture.

Q4. Compare the communication model of telephony with that of early packet‑switched networks. Which statement accurately reflects a key difference?

A. Telephony uses variable-rate transmission, while packet networks use constant-rate.
B. Telephony requires a dedicated circuit per call; packet networks share links among many connections. ✅
C. Telephony can transmit data only in binary form, whereas packet networks use analog signals.
D. Telephony employs IMPs to route data, while packet networks rely on switches.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Traditional telephony establishes a dedicated circuit for each voice call, reserving a fixed bandwidth for the duration of the session. Packet‑switched networks, however, divide data into packets that travel over shared links, allowing many users to use the same physical infrastructure simultaneously. This fundamental contrast underlies the efficiency gains of packet switching.

Q5. Evaluate the impact of having separate Interface Message Processors (IMPs) for each host in ARPANET. Which assessment best captures the advantage of this design?

A. It eliminated the need for host computers to have networking software.
B. It increased the overall latency of the network due to extra processing steps.
C. It required each host to use the same operating system for compatibility.
D. It allowed heterogeneous host systems to interoperate despite different manufacturers. ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

By placing an IMP between each host and the network, ARPANET abstracted the communication details from the host computers. This permitted machines from different vendors, each with its own operating system, to connect and exchange data without needing uniform networking software, thereby fostering interoperability across diverse platforms.

Q6. Analyze why the early ARPANET used the Network Control Protocol (NCP) rather than the later Transmission Control Protocol (TCP). Which reasoning most plausibly explains this choice?

A. NCP provided basic host‑to‑host communication suitable for the limited scope of ARPANET, while TCP introduced features unnecessary at that stage. ✅
B. NCP was designed for reliable, connection‑oriented communication, whereas TCP was not yet defined.
C. NCP was compatible with existing IMP hardware, whereas TCP required new hardware redesign.
D. NCP allowed for multicast transmission, a feature TCP lacked.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When ARPANET was first built, its primary goal was to enable simple host‑to‑host messaging among a handful of sites. NCP offered the essential functions without the added complexity of error recovery, flow control, and multiplexing that TCP later introduced. Thus, NCP matched the network’s early, limited requirements.

Q7. Applying the concept of bursty traffic, which of the following modern applications would most benefit from packet‑switching principles?

A. Continuous analog radio broadcast.
B. Real‑time video streaming with constant bitrate.
C. Email transmission with sporadic data packets. ✅
D. Dedicated point‑to‑point telephone call.

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Email traffic typically consists of short, irregularly timed messages, creating bursty data patterns. Packet‑switching excels at handling such sporadic loads by breaking messages into packets and routing them efficiently across shared links, unlike constant‑rate services that require steady bandwidth. Hence, email transmission benefits most from packet‑switching.

Researchers funded by ARPA sought ways to reduce redundant experiments and share costly computing assets. By interconnecting computers, ARPANET allowed scientists to exchange data and software, directly addressing the goal of avoiding duplication. This collaborative motive was a primary driver, illustrating how resource sharing shaped the network’s inception.

Q9. Considering the evolution from telegraphy to packet‑switched networks, how can one explain the shift in design philosophy regarding data transmission reliability and efficiency?

A. Early designs prioritized reliability through constant‑rate channels; packet networks prioritize efficiency by allowing variable‑rate bursts and handling errors at higher layers. ✅
B. Both designs treat reliability and efficiency identically, differing only in hardware.
C. Packet networks abandoned reliability entirely, focusing only on speed, unlike telegraphy which was fully reliable.
D. Telegraphy used error‑correcting codes, whereas packet networks rely on physical layer redundancy for reliability.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Telegraph systems relied on steady, constant‑rate channels to guarantee delivery, sacrificing bandwidth efficiency. Packet‑switching introduced variable‑rate bursts, accepting occasional loss at the physical layer but compensating with higher‑layer error detection and retransmission. This shift reflects a design move from strict reliability toward overall network efficiency and flexibility.

Q12. Differentiate between the roles of an IMP and a host computer in the early ARPANET architecture. Which distinction is most accurate?

A. The IMP stored user files, while the host managed network traffic.
B. The IMP acted as a backup for the host in case of failure, while the host performed all routing.
C. The IMP performed routing and message processing, while the host generated and consumed application data. ✅
D. Both IMP and host performed identical functions, making one redundant.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

In ARPANET, each host handled its own applications and data, while the attached IMP acted as a dedicated router, handling packet forwarding and network control. This separation allowed the host to focus on computation while the IMP managed communication, embodying a clear functional division.

Q13. Apply the principle of packet switching to explain why modern internet services can handle simultaneous video streaming, file downloads, and VoIP calls without dedicated circuits for each.

A. Packet switching allocates a fixed bandwidth slice to each service, preventing interference.
B. By breaking data into packets, the network can interleave transmissions, efficiently utilizing shared links. ✅
C. Services are sent over separate physical cables, each reserved for a specific type of traffic.
D. Packet switching forces all data to travel at the same speed, eliminating latency differences.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Packet switching divides each data stream into small packets that travel independently across shared network paths. By interleaving these packets, the infrastructure can serve many concurrent applications—video, downloads, VoIP—without reserving exclusive bandwidth, maximizing utilization and accommodating variable traffic loads.
