Q1. In a 2‑bit gray‑scale scheme, which pattern represents light gray?

🔹 A. 0
🔹 B. 1
🔹 C. 10
🔹 D. 11

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

In a 2‑bit gray‑scale scheme the four possible patterns represent increasing brightness. The pattern 00 is darkest (black), 01 is dark gray, 10 is light gray, and 11 is white. Therefore the light‑gray level corresponds to the binary pattern 10, which is option C. The other patterns map to different shades.

Q2. A 1‑bit per pixel black‑white image contains 2000 pixels. How many bytes are needed to store it?

🔹 A. 250 bytes
🔹 B. 125 bytes
🔹 C. 500 bytes
🔹 D. 1000 bytes

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A 1‑bit per pixel image with 2000 pixels requires 2000 bits of storage. Since 1 byte = 8 bits, the total bytes equal \( \frac{2000}{8}=250 \) bytes. Converting to a more convenient unit, this is still 250 bytes because the size is less than 1 kilobyte. Hence option A is correct.

Q3. Unicode uses 32 bits per character. How much storage is required for 150 characters, expressed in kilobytes?

🔹 A. 0.5 KB
🔹 B. 0.59 KB
🔹 C. 0.75 KB
🔹 D. 1 KB

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Unicode allocates 32 bits for each character. For 150 characters the total bit count is \(150 \times 32 = 4800\) bits. Dividing by 8 yields 600 bytes, and dividing by 1024 gives about 0.586 kilobytes, which rounds to 0.59 KB. Option B matches this calculation.

Q4. An audio clip is recorded at 44.1 kHz, 16‑bit depth, mono for 10 seconds. Approximate storage needed?

🔹 A. 0.5 MB
🔹 B. 0.8 MB
🔹 C. 1.0 MB
🔹 D. 1.2 MB

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Audio sampled at 44.1 kHz with 16‑bit depth records \(44{,}100 \times 16 = 705{,}600\) bits each second, i.e., 88 200 bytes (≈0.084 MB). For a 10‑second clip the storage becomes \(88{,}200 \times 10 = 882{,}000\) bytes, roughly 0.84 MB, which is closest to 0.8 MB. Therefore option B is the correct choice.

Q5. Which statement about ASCII and Unicode is true?

🔹 A. ASCII uses 16 bits
🔹 B. Unicode includes ASCII as first 127 characters
🔹 C. ASCII can represent emojis
🔹 D. Unicode is limited to English only

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

ASCII defines 128 code points using 7 bits and forms the first block of Unicode. Unicode extends this set to encompass characters from virtually all writing systems, preserving the original ASCII values for compatibility. Consequently, the statement that Unicode includes ASCII as its first 127 characters is accurate, making option B correct.

Q6. For a 800×600 image, compare memory usage of 8‑bit grayscale vs 24‑bit RGB. Which is correct?

🔹 A. Grayscale uses more memory, factor 3
🔹 B. RGB uses more memory, factor 3
🔹 C. Same memory
🔹 D. RGB uses more memory, factor 2

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A grayscale image of 8 bits per pixel stores one byte for each pixel, while an RGB image stores three bytes (one for each color channel). For any given resolution, the RGB representation therefore uses three times the memory of the grayscale version, i.e., a factor of 3. Option B correctly describes this relationship.

Q7. Scheme X uses fixed 7‑bit codes; Scheme Y uses Huffman coding averaging 5 bits per character for English text. Which yields smaller files?

🔹 A. Scheme X
🔹 B. Scheme Y
🔹 C. Both equal
🔹 D. Depends on text length

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Fixed‑length 7‑bit ASCII assigns the same number of bits to every character, whereas a Huffman‑coded scheme assigns shorter codes to more frequent symbols, yielding an average of about 5 bits per character for typical English text. Fewer bits per character mean smaller files, so Scheme Y is the more efficient choice. Option B is correct.

Q8. A 1024×768 image uses 2‑bit grayscale. How does its storage compare to an 8‑bit color version?

🔹 A. 0.08402777777777781
🔹 B. 0.12569444444444455
🔹 C. 0.16736111111111107
🔹 D. 0.3340277777777778

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

With a resolution of 1024 × 768, a 2‑bit gray‑scale image uses \(1024 \times 768 \times 2 = 1{,}572{,}864\) bits. An 8‑bit color image uses four times as many bits: \(1{,}572{,}864 \times 4 = 6{,}291{,}456\) bits. The size ratio of color to gray‑scale is therefore 4 : 1. Option C matches this ratio.

Q9. Why does binary representation simplify arithmetic operations in computers?

🔹 A. Because binary aligns with decimal system
🔹 B. Because only two symbols reduce hardware complexity
🔹 C. Because binary digits are larger
🔹 D. Because binary is human readable

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Binary uses only two symbols, 0 and 1, which aligns naturally with digital circuitry that can be in one of two states (off/on). This simplicity reduces the number of transistors needed for arithmetic units, making operations faster and less power‑intensive. Hence the reduction of hardware complexity is the primary reason, corresponding to option B.

Q10. Which statement best describes the effect of increasing the sampling rate on audio quality?

🔹 A. Higher sampling rate always reduces quality
🔹 B. Higher sampling rate can capture higher frequencies, improving fidelity
🔹 C. Sampling rate irrelevant if bit depth high
🔹 D. Lower sampling rate yields larger files

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The sampling rate determines the highest audio frequency that can be accurately reproduced (Nyquist theorem). A higher rate captures more of the sound spectrum, especially high‑frequency components, leading to better fidelity. Therefore, increasing the sampling rate generally improves audio quality, as expressed in option B.

Q11. How does increasing pixel resolution affect image quality and storage requirements?

🔹 A. Improves quality, reduces storage
🔹 B. Improves quality, increases storage
🔹 C. No effect on quality, increases storage
🔹 D. Decreases quality, increases storage

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Increasing the number of pixels per unit area (resolution) adds detail, making images appear sharper and more realistic. However, each additional pixel requires storage bits, so the total file size grows proportionally with resolution. Thus higher resolution improves quality but also raises storage demands, which option B states.

Q12. Can a 30 fps video of 640×480 pixels with 24‑bit color be transmitted over a 5 Mbps link uncompressed?

🔹 A. Yes, fits within bandwidth
🔹 B. No, requires ~221 Mbps
🔹 C. Yes, requires 5 Mbps exactly
🔹 D. No, requires ~50 Mbps

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

An uncompressed frame of 640 × 480 pixels with 24‑bit color contains \(640 \times 480 \times 24 = 7{,}372{,}800\) bits. At 30 frames per second this requires \(7{,}372{,}800 \times 30 \approx 221{,}184{,}000\) bits per second, or about 221 Mbps. Since the available bandwidth is only 5 Mbps, the stream cannot be transmitted uncompressed. Option B correctly reflects this limitation.

Q13. What does ASCII stand for?

🔹 A. American Standard Code for Information Interchange
🔹 B. Automated System for Computer Integrated
🔹 C. Advanced Serial Communication Interface
🔹 D. American System for Code Integration

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

ASCII stands for American Standard Code for Information Interchange. It was created to provide a common encoding for characters used in electronic communication, defining 128 distinct symbols. This definition matches option A, making it the correct answer.
