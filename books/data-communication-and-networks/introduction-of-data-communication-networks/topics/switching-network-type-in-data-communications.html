What is Switching Network type in data communications?

Switching network types determine how data moves through intermediate nodes, including circuit switching that establishes a dedicated physical path before transmission, packet switching that breaks data into routed chunks without a dedicated path, and message switching that stores and forwards entire messages at each node.

📝 All Switching Network type in data communications MCQs

Q1. In a circuit‑switched network, what is the dedicated connection between two end systems called?

A.Circuit ✅
B.Packet
C.Channel
D.Path
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A circuit‑switched network reserves a fixed, exclusive pathway for the duration of a communication session. This dedicated pathway is referred to as a circuit, which remains unavailable to other users until the session ends, guaranteeing constant bandwidth and latency for the participants.

Q2. If all four telephone sets on each side are engaged simultaneously, what is the utilization of the high‑capacity line?

A.0.25
B.0.5
C.0.75
D.1 ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: When every telephone set on both sides is in use, the line carries four simultaneous voice streams, each occupying one‑quarter of the line’s total capacity. Consequently, the line is fully occupied, resulting in 100 % utilization, meaning no additional bandwidth remains for extra traffic.

Q3. Which statement correctly contrasts circuit‑switched and packet‑switched networks?

A.Circuit uses variable bandwidth, packet uses fixed
B.Circuit reserves resources, packet shares resources ✅
C.Circuit stores packets, packet does not
D.Circuit supports only data, packet supports voice
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Circuit‑switched networks allocate a fixed slice of bandwidth for each call, reserving that portion for the entire session. Packet‑switched networks, on the other hand, allow many flows to share the same physical link dynamically, allocating bandwidth on demand as packets arrive.

Q4. To guarantee that a circuit‑switched line can support four simultaneous voice calls each requiring 64 kbps, what minimum capacity should the line have?

A.64 kbps
B.128 kbps
C.256 kbps ✅
D.512 kbps
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Each voice call needs 64 kbps, so four concurrent calls require 4 × 64 kbps = 256 kbps. The line must provide at least this amount of bandwidth to accommodate all four calls without contention, ensuring that each call receives its required data rate.

Q5. When only one call is active on a circuit‑switched line designed for four calls, which effect is most likely?

A.Full utilization
B.Under‑utilization ✅
C.Increased latency
D.Higher error rate
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A circuit‑switched line reserves capacity for up to four calls, but if only one call uses the line, three‑quarters of the reserved bandwidth remain idle. This results in under‑utilization, where the network’s resources are not fully exploited, leading to inefficiency compared with a fully loaded scenario.

Q6. Which advantage of packet‑switched networks becomes most significant when traffic is bursty?

A.Fixed allocation
B.Statistical multiplexing ✅
C.Dedicated circuits
D.Constant latency
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Statistical multiplexing allows many users to share the same physical link by dynamically allocating bandwidth only when packets are present. During bursty traffic periods, this flexibility lets idle capacity be reclaimed quickly, improving overall efficiency and preventing the waste that occurs in circuit‑switched networks where bandwidth is pre‑reserved regardless of actual usage.

Q7. How does the store‑and‑forward capability of packet switches help in delivering data across a congested network?

A.It eliminates the need for routing
B.It allows packets to be queued and forwarded when the link becomes free ✅
C.It guarantees zero packet loss
D.It reduces packet size
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Store‑and‑forward switches temporarily hold incoming packets in a buffer until the outgoing link is available. This queuing mechanism enables the switch to manage congestion by delaying transmission rather than dropping packets, thereby preserving data integrity and allowing the network to adjust to varying traffic loads.

Q8. A high‑capacity line has a capacity of 1 Mbps. Each voice call requires 64 kbps. If five calls are active, what is the line’s utilization?

A.0.16
B.0.32 ✅
C.0.64
D.1
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Five calls consume 5 × 64 kbps = 320 kbps. Utilization is the ratio of used bandwidth to total capacity: 320 kbps ÷ 1 000 kbps = 0.32, or 32 %. This indicates that roughly one‑third of the line’s capacity is occupied while the remainder remains idle.

Q9. Which statement best describes how a high‑capacity line in a circuit‑switched network differs from packet multiplexing in a packet‑switched network?

A.Both allocate fixed bandwidth per flow
B.Circuit provides dedicated bandwidth, packet shares dynamically ✅
C.Circuit uses buffering, packet does not
D.Both require end‑to‑end acknowledgment
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: In circuit switching, each call receives a reserved slice of bandwidth that cannot be used by others, guaranteeing constant service quality. Packet switching, however, employs dynamic multiplexing where packets from many flows share the same link, allocating bandwidth on the fly based on current demand and buffer availability.

Q10. In a hybrid network that uses circuit‑switching for voice and packet‑switching for data, which mechanism ensures that voice quality remains unaffected by data traffic?

A.Quality‑of‑Service (QoS) prioritization ✅
B.Increasing packet size
C.Using the same routing table
D.Reducing line speed
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Quality‑of‑Service (QoS) mechanisms assign higher priority to voice packets, reserve bandwidth, and enforce traffic shaping policies. By giving voice traffic preferential treatment, QoS prevents data‑intensive flows from consuming resources needed for real‑time voice, thereby preserving low latency and jitter essential for clear communication.

Q11. If the number of telephone sets per side doubles while the high‑capacity line capacity remains unchanged, what happens to the probability that a new call will be blocked?

A.It halves
B.It stays the same
C.It doubles ✅
D.It becomes zero
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Doubling the number of potential callers raises the demand for circuit slots while the total number of available slots stays constant. According to Erlang‑B loss formulas, the blocking probability grows as offered traffic increases, roughly doubling when the traffic load doubles, assuming all other factors remain unchanged.

Q12. Compared to a circuit‑switched voice call, a packet‑switched voice stream experiences packet loss. Which impact is most directly associated with this loss?

A.Increased bandwidth usage
B.Reduced latency
C.Degraded audio quality ✅
D.Higher connection setup time
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When packets are lost, the receiving end misses portions of the audio stream, leading to gaps, clicks, or muffled speech. This degradation of audio quality is the most immediate and perceptible effect of packet loss for voice communication, whereas bandwidth and latency are affected in different ways.

Q13. Which combination of techniques would best enable a packet‑switched network to provide voice‑grade QoS comparable to a circuit‑switched network?

A.Large MTU and no congestion control
B.Traffic shaping, priority queuing, and RSVP ✅
C.Stateless routing and random packet drops
D.Increasing hop count
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Traffic shaping smooths bursty traffic, priority queuing ensures voice packets are transmitted before lower‑priority data, and RSVP (Resource Reservation Protocol) reserves the necessary bandwidth along the path. Together these mechanisms emulate the deterministic guarantees of circuit switching, delivering the low latency and jitter required for high‑quality voice.

Q14. Given \(N\) end systems, a circuit‑switched network can support at most \(\frac{C}{B}\) simultaneous calls where \(C\) is line capacity and \(B\) bandwidth per call. A packet‑switched network can support \(\frac{C}{B_{\text{eff}}}\) calls where \(B_{\text{eff}} = B(1-p)\) and \(p\) is packet loss probability. Which statement is true when \(p = 0.1\)?

A.Circuit supports more calls
B.Packet supports more calls ✅
C.Both support equal calls
D.Cannot determine without values
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: With \(p = 0.1\), the effective bandwidth per packet‑switched call becomes \(B_{\text{eff}} = B(1-0.1) = 0.9B\). Because the denominator is smaller, \(\frac{C}{0.9B}\) exceeds \(\frac{C}{B}\). Hence the packet‑switched network can accommodate more simultaneous calls than the circuit‑switched alternative under the same capacity.

Q15. If a packet‑switched switch has a small buffer and experiences bursty traffic, which outcome is most likely?

A.High throughput with no loss
B.Increased packet drops reducing throughput ✅
C.Constant latency
D.Unlimited queue growth
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A small buffer cannot absorb traffic spikes; when bursts arrive, packets that exceed the buffer capacity are discarded. This increase in packet loss reduces the effective throughput of the network, as retransmissions or application‑level recovery may be required, and it can also degrade overall performance.
