What is Redundancy error detecting and correcting?

Redundancy is the fundamental concept of adding extra bits to the original data stream so that the receiver can verify the integrity of the message and potentially reconstruct the original information if errors are detected during transmission.

Q1. If a burst error flips 3 consecutive bits in a byte, which of the following statements best describes the likely impact on a simple even parity check?

A.The parity check will always detect the error.
B.The parity check may fail to detect the error. ✅
C.The parity check will correct the error automatically.
D.The parity check becomes irrelevant for burst errors.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: An even parity bit only guarantees detection of an odd number of flipped bits. A burst that changes three bits introduces an odd count, but if the burst also flips the parity bit itself, the overall parity may remain even, allowing the error to go unnoticed. Therefore, parity checks are not foolproof for burst errors.

Q2. A communication link uses a 2‑bit checksum for error detection. If a burst error affecting 4 bits occurs, what can be inferred about the probability that the error goes undetected compared to a single‑bit error?

A.The probability is higher for the burst error. ✅
B.The probability is lower for the burst error.
C.The probability is the same for both error types.
D.The checksum can always detect burst errors.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A 2‑bit checksum can detect many single‑bit errors, but its limited size makes it less capable of distinguishing longer error patterns. A 4‑bit burst can produce many different error syndromes, increasing the chance that the checksum coincidentally matches the original value. Hence, the undetected‑error probability rises for burst errors relative to single‑bit errors.

Q3. Compare the ability of a single parity bit and a Hamming (7,4) code to handle a single‑bit error. Which statement is accurate?

A.Both can detect but only Hamming can correct the error. ✅
B.Both can correct the error but only Hamming can detect it.
C.Parity can correct the error while Hamming can only detect it.
D.Neither can detect nor correct a single‑bit error.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A single parity bit flags any odd‑number error but cannot locate or fix it. The Hamming (7,4) code adds three check bits, enabling both detection and precise correction of a single erroneous bit. Therefore, while both schemes detect the error, only Hamming provides the capability to correct it.

Q6. Apply redundancy principles to design a scheme that can correct any single‑bit error and also detect any burst error of length up to 3 in an 8‑bit data unit. Which combination achieves this?

A.Use a Hamming (8,4) code plus a 2‑bit checksum.
B.Use a Hamming (8,4) code plus a 3‑bit CRC. ✅
C.Use triple modular redundancy (TMR) alone.
D.Use a simple parity bit and a 4‑bit checksum.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A Hamming (8,4) code corrects any single‑bit error within the 8‑bit payload. Adding a 3‑bit CRC, whose generator polynomial degree is 3, guarantees detection of all burst errors up to length 3. The CRC does not interfere with the Hamming correction, providing the required combined capability.

Q8. Which of the following best defines redundancy in the context of error detection and correction?
