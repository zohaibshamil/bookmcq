📝 Cyclic Redundancy Check Linear Block Codes (21 MCQs)

CRC as a Linear Block-Code Error Detector

A cyclic redundancy check is a systematic error-detection code used to protect frames against transmission corruption. CRC belongs to the family of cyclic linear block codes: the sender appends a remainder calculated from the data using a generator polynomial, and the receiver repeats the division to test whether the received codeword is divisible by that generator. This distinction helps the receiver choose an appropriate integrity check for each frame.

Generator Polynomials and Binary Remainders

Binary polynomial arithmetic uses coefficients from the set zero and one. Addition and subtraction are both performed with modulo-two arithmetic, which is equivalent to bitwise XOR without carries or borrows. A generator polynomial of degree r produces an r-bit CRC remainder and an n-bit codeword from the selected data block. Both endpoints must use matching parameters for the check to be interpreted correctly.

Appending a CRC Remainder to the Dataword

The sender appends r zero bits to the dataword, divides that expanded bit string by the generator using modulo-two long division, and replaces the zeros with the r-bit remainder. The receiver divides the complete received codeword by the same generator; a nonzero remainder signals a detected error. This check takes place before the receiver accepts the protected information.

A Worked CRC Division with a Generator

Take dataword 1101 and generator 1011, whose degree is three. Append three zeros to form 1101000, then perform modulo-two division. The remainder is 001, so the transmitted CRC codeword is 1101001. Dividing that codeword by 1011 produces zero remainder. The example makes the coding rule visible through a reproducible bit sequence.

CRC Protection at the Data-Link Layer

CRC is widely used in link-layer frames because shift-register circuits can calculate it quickly and polynomial choice provides useful burst-error detection. Ethernet frames, for example, include a frame check sequence based on CRC-32. The CRC checks frame integrity; it does not authenticate the sender or correct the data. Its suitability depends on traffic type, delay limits, and acceptable redundancy overhead.

What a Zero Remainder Does and Does Not Mean

'CRC division uses ordinary subtraction' is false; it uses modulo-two XOR. 'The remainder has the same length as data' is false; its length equals the generator degree. 'Zero remainder proves a frame is authentic' is false; it only means the CRC test did not detect an error. These distinctions prevent confusion between detection, recovery, and general data integrity.

Working CRC Codeword and Remainder Problems

Be able to identify the generator degree, append the correct number of zeros, carry out XOR division, and attach the remainder. Check that a valid codeword divides evenly, distinguish generator polynomial from remainder, and explain the CRC's detection role without claiming that it repairs corrupted bits. Show intermediate steps and state assumptions behind any calculated result.

CRC and Linear-Code Terms

  • CRC - Detects polynomial division errors.
  • Generator polynomial - Defines the cyclic code.
  • Remainder - Result of polynomial division.
  • Codeword - Encoded sequence of bits.
  • Modulo-two - Binary arithmetic uses XOR.
  • Frame check sequence - Carries CRC within frames.

Q1. What is the primary purpose of a CRC in data communication?

A.Detect errors ✅
B.Correct errors
C.Compress data
D.Encrypt data
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A Cyclic Redundancy Check is designed to detect accidental changes to raw data during transmission or storage. It adds check bits derived from the data using polynomial division, allowing the receiver to verify integrity. Therefore, its main function is error detection, not correction, compression, or encryption.

Q3. Which operation is used for the division in CRC generation?

A.Integer division
B.Modulo-2 division ✅
C.Floating‑point division
D.Polynomial long division over reals
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: CRC generation employs modulo‑2 division, which is equivalent to binary polynomial division without carries. This operation treats addition and subtraction as exclusive‑or, simplifying hardware implementation and ensuring the remainder is computed correctly for error detection.

Q6. The receiver obtains a codeword whose syndrome is 0. Which statement must be true?

While this could result from no errors, it might also arise from an undetected even number of errors that cancel out. Thus, the only guaranteed fact is that the vector passes the check.

Q15. Assess the trade‑off between the number of check bits and the probability of undetected errors in a CRC scheme.

A.More check bits increase undetected error probability.
B.More check bits decrease undetected error probability. ✅
C.Check bits have no effect on error probability.
D.Fewer check bits improve detection.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Adding more check bits lengthens the generator polynomial, which expands the set of detectable error patterns. As the number of check bits grows, the chance that a random error pattern yields a zero remainder diminishes dramatically, thereby reducing the probability of an undetected error.

Q16. Derive the condition on the generator polynomial \(G(x)\) that guarantees detection of all single‑bit errors and all double‑bit errors separated by less than the degree of \(G(x)\).

A.\(G(x)\) must be primitive.
B.\(G(x)\) must have at least three terms.
C.\(G(x)\) must not divide \(x^k+1\) for any \(k\) less than its degree.
D.\(G(x)\) must be irreducible. ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: For a CRC to catch every single‑bit error, \(G(x)\) must contain more than one term, ensuring it does not divide \(x^k\). To also catch double‑bit errors whose separation is smaller than the degree \(r\), \(G(x)\) must not divide \(x^k+1\) for any \(k<r\). This dual condition secures detection of both error types.

Q18. Explain why CRC is widely used in LAN protocols.

A.It corrects errors automatically.
B.It detects burst errors efficiently.
C.It compresses network traffic. ✅
D.It encrypts data.
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: LAN environments often encounter burst errors caused by electrical noise or collisions. CRCs, with appropriately chosen generator polynomials, can reliably detect such burst errors with minimal overhead, making them ideal for ensuring data integrity without the complexity of error‑correction mechanisms.

Q19. Synthesize the steps of CRC encoding and decoding into a flowchart description.

A.Encode → Transmit → Decode → Check
B.Encode → Append zeros → Divide → Append remainder → Transmit → Receive → Divide → Check remainder ✅
C.Encode → Compress → Transmit → Decompress
D.Encode → Encrypt → Transmit → Decrypt
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The encoding process starts by appending \(n-k\) zeros to the dataword, then performing modulo‑2 division by the agreed generator polynomial. The remainder becomes the CRC bits, which are appended to form the codeword. At the receiver, the same division is performed; a zero remainder (syndrome) indicates no detected errors.

Q20. Apply the concept of cyclic shift to show that shifting a codeword yields another valid codeword.

A.Shifting changes the generator polynomial. ✅
B.Cyclic shifts preserve polynomial divisibility.
C.Shifts break the parity check.
D.Only left shifts are allowed.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A codeword can be represented as a polynomial divisible by the generator \(G(x)\). Multiplying this polynomial by \(x\) (a left cyclic shift) results in another polynomial still divisible by \(G(x)\) because the field is modulo‑2. Hence, any cyclic rotation of a valid codeword remains a codeword.

Q21. Explain how the choice of generator polynomial affects the length of the CRC and its error detection strength.

A.Longer polynomials give shorter CRCs.
B.Shorter polynomials give longer CRCs.
C.Degree of polynomial equals number of CRC bits; higher degree improves detection. ✅
D.Degree has no impact on CRC length.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The degree \(r\) of the generator polynomial determines the number of check bits appended to the dataword, i.e., the CRC length is \(r\). A higher‑degree polynomial provides more bits, expanding the space of detectable error patterns and enhancing the likelihood of catching errors, especially longer burst errors.
