📝 All Error Detection in Block Coding MCQs

Q1. Given dataword \(01\) is encoded as codeword \(011\), if a single‑bit error flips the second bit, which of the following codewords would the receiver detect as erroneous?

🔹 A. 11
🔹 B. 1
🔹 C. 10
🔹 D. 111

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When the second bit flips, the transmitted pattern becomes \(001\). The receiver recomputes the expected parity from the original dataword and finds a mismatch with the received pattern. Because \(001\) is not a valid codeword for the given encoding, the error is detected, making option B correct.

Q2. If the parity bit for a 3‑bit codeword is set to even parity, which received vector indicates a single‑bit error?

🔹 A. 110
🔹 B. 101
🔹 C. 111
🔹 D. 100

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Even parity requires an even number of 1s. The vector \(111\) contains three 1s, which is odd, signalling that one bit has been altered during transmission. The other options either preserve even parity or do not correspond to a single‑bit flip, so option C correctly identifies the error.

Q3. A block code with parameters \(k=2\) and \(n=3\) can reliably detect up to how many simultaneous bit errors?

🔹 A. 1
🔹 B. 2
🔹 C. 3
🔹 D. None

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The detection capability equals the minimum Hamming distance minus one. For a simple \((2,3)\) block code the minimum distance is 2, allowing detection of at most one erroneous bit. Therefore the code can reliably detect a single‑bit error but not two, making option A correct.

Q4. Suppose the sender uses the generator matrix \(G=\begin{bmatrix}1&0&1\\0&1&1\end{bmatrix}\). Which codeword corresponds to dataword \(10\)?

🔹 A. 101
🔹 B. 110
🔹 C. 11
🔹 D. 111

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Multiplying the dataword vector \([1\;0]\) by \(G\) yields \([1\;0]\times G = [1\;0\;1]\), i.e., codeword \(101\). This follows directly from matrix multiplication over GF(2). Hence option A correctly represents the encoded codeword.

Q5. If a transmitted codeword \(011\) suffers a burst error affecting the last two bits, which of the following received words could still pass the parity check?

🔹 A. 1
🔹 B. 10
🔹 C. 111
🔹 D. 100

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

A burst that flips the last two bits changes \(011\) to \(000\). The even‑parity check would then see zero 1s (even) and mistakenly accept the word as error‑free. Among the options, only \(100\) retains an even number of 1s, so it could erroneously pass the check, making option D correct.

Q6. When using a CRC polynomial \(x^3+x+1\) for a 3‑bit message, which remainder indicates that the received frame contains an error?

🔹 A. 0
🔹 B. 1
🔹 C. 10
🔹 D. 11

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A correct CRC leaves a remainder of zero. Any non‑zero remainder signals corruption. The polynomial division of the received frame by \(x^3+x+1\) yields a remainder; if that remainder is \(001\), it confirms that at least one error occurred. Therefore option B correctly identifies an erroneous remainder.

Q7. A system employs a two‑dimensional parity scheme on a \(2\times3\) block. If the row parity bits are all correct but the column parity bits show a discrepancy in the second column, what can be inferred?

🔹 A. A single‑bit error in column two
🔹 B. Two‑bit error in same row
🔹 C. Error in parity bits themselves
🔹 D. No error

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Two‑dimensional parity isolates errors at the intersection of the erroneous row and column. Since all row parities are satisfied, the faulty bit must lie in the column that fails its parity check. Consequently, the error is a single‑bit flip located somewhere in the second column, making option A correct.

Q8. Consider a Hamming (7,4) code with parity‑check matrix \(H\). If the syndrome computed is \([0\;1\;1]\), which statement best describes the situation?

🔹 A. Error in bit 3
🔹 B. Error in bit 5
🔹 C. No error
🔹 D. Multiple errors

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The syndrome vector points to the column of \(H\) that matches it. In a standard Hamming (7,4) layout, the column \([0\;1\;1]\) corresponds to bit position 5. Thus the receiver concludes that bit 5 is corrupted and corrects it, so option B is accurate.

Q9. A communication link uses a checksum that sums all bytes modulo 256. If the transmitted checksum is 0x5A and the receiver computes 0x5A, which conclusion is valid?

🔹 A. No error occurred
🔹 B. Exactly one bit error occurred
🔹 C. An even number of bit errors occurred
🔹 D. Error detection failed

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The checksum method declares the packet correct when the computed sum matches the transmitted checksum. A match of 0x5A indicates that the receiver’s calculation agrees with the sender’s, suggesting that no detectable error is present. Hence option A correctly reflects the outcome.

Q10. When a code with minimum Hamming distance \(d_{\min}=3\) is used, what is the maximum number of detectable errors?

🔹 A. 1
🔹 B. 2
🔹 C. 3
🔹 D. 4

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A code can detect up to \(d_{\min}-1\) errors. With \(d_{\min}=3\), the code guarantees detection of any combination of up to two erroneous bits. It cannot assure detection of three or more errors. Therefore option B, representing two detectable errors, is correct.

Q11. In a system employing a (3,2) linear block code, the syndrome for a received word is non‑zero. Which action should the decoder take?

🔹 A. Correct the error using the syndrome
🔹 B. Discard the word as uncorrectable
🔹 C. Request retransmission
🔹 D. Do nothing

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A non‑zero syndrome indicates that the received word does not belong to the code space. For a (3,2) linear block code, the syndrome uniquely identifies the erroneous bit, allowing the decoder to flip that bit and recover the original codeword. Hence the appropriate response is to correct the error, making option A correct.

Q12. If the generator matrix \(G\) for a (3,2) code is \(\begin{bmatrix}1&0&1\\0&1&1\end{bmatrix}\), which of the following statements is true about its systematic form?

🔹 A. It is already systematic
🔹 B. It can be converted to systematic by column swaps
🔹 C. It cannot be systematic
🔹 D. Systematic form is irrelevant

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A systematic generator matrix has the identity matrix as its leftmost sub‑matrix. The given \(G\) lacks this form, but by swapping the third column with the second, we obtain \(\begin{bmatrix}1&1&0\\0&1&1\end{bmatrix}\), which places an identity block on the left. Thus the matrix can be made systematic, making option B correct.

Q13. When comparing even‑parity and odd‑parity schemes for a 4‑bit block, which statement best captures their relationship?

🔹 A. They detect the same error patterns
🔹 B. Odd parity detects more errors
🔹 C. Even parity is more efficient
🔹 D. Both require the same number of extra bits

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Both schemes add a single parity bit and differ only in the rule for counting 1s. Consequently, each can detect any single‑bit error, and the set of detectable error patterns is identical; the distinction lies solely in the parity rule. Therefore option A accurately describes their relationship.

Q14. A dataword \(10\) is encoded using the generator matrix \(G\) given earlier. If the transmitted codeword suffers a single‑bit error in the third position, which of the following syndromes will the receiver compute?

🔹 A. [0 0]
🔹 B. [1 0]
🔹 C. [0 1]
🔹 D. [1 1]

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The parity‑check matrix \(H\) for this code is \(\begin{bmatrix}1&1&1\\1&0&1\end{bmatrix}\). Multiplying the error vector \([0\;0\;1]\) by \(H^T\) yields the syndrome \([0\;1]\). Hence the receiver obtains syndrome \([0\;1]\), corresponding to option C.

Q15. If a burst error of length 3 occurs in a 7‑bit codeword, which type of error‑detecting code is most likely to catch it?

🔹 A. Parity code
🔹 B. Cyclic Redundancy Check
🔹 C. Hamming code
🔹 D. Repetition code

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Cyclic Redundancy Checks are designed to detect burst errors up to a length equal to the degree of the generator polynomial. A CRC can reliably flag a three‑bit burst, whereas simple parity or Hamming codes may miss such patterns. Therefore option B is the most appropriate choice.

Q16. Consider two codes: Code X with \(d_{\min}=2\) and Code Y with \(d_{\min}=4\). Which statement correctly compares their error‑detection capabilities?

🔹 A. X detects more errors than Y
🔹 B. Y detects more errors than X
🔹 C. Both detect the same number of errors
🔹 D. Neither can detect errors

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The number of detectable errors equals \(d_{\min}-1\). Code X can detect at most one error, while Code Y can detect up to three. Hence Code Y possesses superior detection capability, making option B correct.

💡 Difficulty: hard | ✅ Correct: B

The Hamming distance between \(011\) and \(001\) is one, indicating a single‑bit discrepancy. Since the code can detect single‑bit errors, the receiver identifies exactly one erroneous bit, making option B correct.

Q18. In a two‑dimensional parity scheme, if both row and column parity checks fail at the same position, what can be deduced?

🔹 A. A single‑bit error at that position
🔹 B. Two independent errors
🔹 C. Error in the parity bits themselves
🔹 D. No error

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When the intersecting row and column both exhibit parity mismatches, the error must be located at their crossing cell, implying a solitary bit flip at that exact location. Hence option A accurately captures the deduction.

Q19. Which of the following best describes the relationship between minimum Hamming distance and error‑correction capability?

🔹 A. A code with distance \(d\) can correct up to \(\lfloor(d-1)/2\rfloor\) errors

🔹 C. Higher distance reduces correction ability
🔹 D. Distance does not affect correction

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The fundamental bound states that a code with minimum distance \(d_{\min}\) can reliably correct up to \(\lfloor(d_{\min}-1)/2\rfloor\) errors. This relationship directly links distance to correction strength, making option A the precise description.

Q21. A dataword \(01\) is encoded as \(011\). Which property ensures that any single‑bit error changes the parity of the codeword?

🔹 A. Even parity
🔹 B. Odd parity
🔹 C. Systematic encoding
🔹 D. Linear independence

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Using even parity guarantees that the total number of 1s in the codeword is even. Flipping any single bit toggles the parity from even to odd, thereby revealing the error. Hence option A correctly identifies the property.

Q22. When the Hamming distance between two valid codewords is 3, what does this imply about the code's ability to detect errors?

🔹 A. It can detect up to two errors
🔹 B. It can correct a single error
🔹 C. Both detection and correction of one error
🔹 D. All of the above

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

A minimum distance of 3 means the code can detect any combination of up to two erroneous bits (since \(d_{\min}-1=2\)). It also enables correction of a single error (\(\lfloor(d_{\min}-1)/2\rfloor=1\)). Thus all listed capabilities hold, making option D correct.

Q23. In a (3,2) linear code, which of the following statements about the parity‑check matrix \(H\) is true?

🔹 A. Rows of \(H\) are orthogonal to rows of \(G\)
🔹 B. \(H\) is the inverse of \(G\)
🔹 C. \(H\) equals \(G\)
🔹 D. \(H\) is unrelated to \(G\)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

By definition, the parity‑check matrix \(H\) satisfies \(G\,H^{T}=0\); that is, each row of \(H\) is orthogonal to each row of the generator matrix \(G\). This orthogonality condition ensures that valid codewords produce a zero syndrome. Hence option A is accurate.

Comparing the transmitted and received vectors shows that only the middle bit differs (1→0). Therefore the error pattern corresponds to a flip in bit 2, making option B correct.

Q25. Which of the following best explains why a CRC is more effective than a simple parity check for detecting burst errors?

🔹 A. CRC uses polynomial division that captures error patterns

🔹 C. CRC requires less hardware
🔹 D. Parity cannot detect any errors

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A CRC computes a remainder of the message divided by a generator polynomial, which inherently reflects the structure of burst errors up to a certain length. This mathematical property enables detection of complex error patterns that a single parity bit cannot capture. Hence option A correctly explains the advantage.

Q26. A communication system uses a (7,4) Hamming code. If the syndrome is \([1\;0\;1]\), which bit is identified as erroneous?

🔹 A. Bit 5
🔹 B. Bit 3
🔹 C. Bit 7
🔹 D. Bit 1

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The syndrome vector directly maps to the binary representation of the erroneous bit’s position. The binary number \(101_2\) equals 5, indicating bit 5 is in error. However, because Hamming code positions are numbered starting at 1, the syndrome \([1\;0\;1]\) points to bit 5. Thus option C (bit 7) is incorrect; the correct answer is bit 5, which corresponds to option A. (Correct answer: A)

Q27. When comparing two error‑detecting codes, one with minimum distance 2 and another with distance 3, which code provides higher reliability for single‑bit error detection?

🔹 D. Reliability depends on other factors

A minimum distance of 3 allows detection of any single‑bit error and also any double‑bit error, whereas a distance‑2 code can only guarantee detection of a single error. Hence the code with distance 3 offers superior reliability for detecting single‑bit errors, making option B correct.

Q28. If a block code can correct any single‑bit error, what is the minimum Hamming distance it must have?

🔹 B. 3
🔹 C. 4
🔹 D. 5

Error‑correction capability requires a minimum distance of at least \(2t+1\) where \(t\) is the number of correctable errors. For \(t=1\), the code must have \(d_{\min}\ge 3\). However, to guarantee correction of any single‑bit error, the distance must be at least 3, which corresponds to option B. (Correct answer: B)

Comparing \(101\) and \(111\) shows differences in the first and third positions. Flipping both bit 1 and bit 3 transforms the transmitted codeword into the received one, indicating a two‑bit error pattern. Therefore option C correctly describes the most probable error.

Q34. When using a parity‑check matrix \(H\) for a (3,2) code, which condition must hold for all valid codewords \(c\)?

🔹 A. \(Hc^{T}=0\)

The defining property of a parity‑check matrix is that any valid codeword, when multiplied by the transpose of \(H\), yields the zero vector, i.e., \(Hc^{T}=0\). This condition ensures that the syndrome is zero for error‑free transmissions. Hence option A is correct.

Q36. Which of the following best explains why a code with minimum distance 5 can correct up to two errors?
