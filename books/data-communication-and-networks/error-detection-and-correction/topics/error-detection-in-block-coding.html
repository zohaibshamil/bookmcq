What is Error Detection in Block Coding?

Error detection in block coding relies on the principle that only specific codewords are valid; if the receiver gets a bit pattern that does not match any valid codeword in the predefined set, it knows an error has occurred during transmission.

Q1. Given dataword 010101 is encoded as codeword 011011011, if a single‑bit error flips the second bit, which of the following codewords would the receiver detect as erroneous?

A.11
B.1 ✅
C.10
D.111
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When the second bit flips, the transmitted pattern becomes 001001001. The receiver recomputes the expected parity from the original dataword and finds a mismatch with the received pattern. Because 001001001 is not a valid codeword for the given encoding, the error is detected, making option B correct.

Q2. If the parity bit for a 3‑bit codeword is set to even parity, which received vector indicates a single‑bit error?

A.110
B.101
C.111 ✅
D.100
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Even parity requires an even number of 1s. The vector 111111111 contains three 1s, which is odd, signalling that one bit has been altered during transmission. The other options either preserve even parity or do not correspond to a single‑bit flip, so option C correctly identifies the error.

Q3. A block code with parameters k=2k=2k=2 and n=3n=3n=3 can reliably detect up to how many simultaneous bit errors?

A.1 ✅
B.2
C.3
D.None
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The detection capability equals the minimum Hamming distance minus one. For a simple (2,3)(2,3)(2,3) block code the minimum distance is 2, allowing detection of at most one erroneous bit. Therefore the code can reliably detect a single‑bit error but not two, making option A correct.

Q7. A system employs a two‑dimensional parity scheme on a 2×32\times32×3 block. If the row parity bits are all correct but the column parity bits show a discrepancy in the second column, what can be inferred?

Consequently, the error is a single‑bit flip located somewhere in the second column, making option A correct.
