📝 All Error Detection versus Correction in Data Link Layer MCQs

Q1. What is the main distinction between error detection and error correction in digital communication?

🔹 A. Detection only determines if an error occurred; correction also identifies the error’s location and value.
🔹 B. Detection corrects errors; correction only signals presence.
🔹 C. Both perform the same function but with different hardware.
🔹 D. Detection works only for burst errors.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Detection answers a simple yes/no question, while correction must pinpoint which bits are wrong. This requires additional information about the error pattern, so correction mechanisms need more redundancy and processing than pure detection schemes.

Q2. An 8‑bit data unit can have a single‑bit error. How many distinct error conditions must a detector distinguish to both detect and correct any single‑bit error?

🔹 A. 8
🔹 B. 9
🔹 C. 16
🔹 D. 256

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The detector must differentiate the case of no error plus each of the eight possible single‑bit error positions, giving a total of nine distinct conditions. This requirement drives the size of the syndrome space needed for correction.

Q3. A burst error of length 4 flips consecutive bits in an 8‑bit word. Why is detecting this burst generally easier than correcting it?

🔹 A. Detection requires only one parity check, while correction needs to locate each flipped bit.
🔹 B. There are fewer possible burst patterns than single‑bit errors.
🔹 C. The syndrome for detection can be shorter than the syndrome needed for locating the exact bits.
🔹 D. Burst errors cannot be detected at all.

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Detection can use a short checksum that flags any deviation, but correction must identify the exact positions of all flipped bits. Consequently, the syndrome for detection can be compact, whereas correction demands a larger syndrome to resolve each individual error location.

Q4. Which statement correctly compares the redundancy needed for error detection versus error correction for the same message length?

🔹 A. Detection typically needs fewer extra bits than correction.
🔹 B. Detection needs more bits because it must check multiple patterns.
🔹 C. Both require the same number of parity bits.
🔹 D. Correction needs no extra bits if the message is short.

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

Detecting errors only requires enough redundancy to signal an error, often a single parity bit. Correcting errors must also convey the error’s position, which generally demands additional bits, making correction schemes more redundant than pure detection schemes.

Q5. Why can a Hamming (7,4) code correct any single‑bit error but fail to correct a burst error of length 2?

🔹 A. The code’s parity‑check matrix can only resolve one error position at a time.
🔹 B. Burst errors affect parity bits only.
🔹 C. Hamming codes are designed for even‑length messages.
🔹 D. The syndrome becomes zero for any burst error.

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

A Hamming code’s syndrome uniquely identifies a single erroneous bit. When two adjacent bits flip, the resulting syndrome may correspond to a valid single‑bit error pattern or become ambiguous, preventing the decoder from reliably locating both errors.

Q6. How does the size of the error‑syndrome vector differ when a code is designed to detect up to \(t\) errors versus to correct up to \(t\) errors?

🔹 A. Detection and correction need the same syndrome length.
🔹 B. Correction needs one extra bit more than detection.
🔹 C. Detection requires \(\lceil \log_2 (t+1) \rceil\) bits, correction requires \(\lceil \log_2 \binom{n}{t} \rceil\).
🔹 D. Detection needs more bits because it must cover all error patterns.

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

To merely detect up to \(t\) errors, the syndrome must distinguish \(t+1\) possibilities (including no error), requiring \(\lceil \log_2 (t+1) \rceil\) bits. For correction, the syndrome must uniquely identify each combination of \(t\) error positions among \(n\) bits, leading to \(\lceil \log_2 \binom{n}{t} \rceil\) bits, which is larger.

Q7. To guarantee correction of any two‑bit error in a 16‑bit block, what is the minimum number of parity bits required?

🔹 A. 7
🔹 B. 8
🔹 C. 9
🔹 D. 6

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Using the Hamming bound for double‑error correction, we need \(2^{r} \ge n + 1 + \binom{n}{2}\) where \(n = 16 + r\). Solving yields \(r = 9\) parity bits as the smallest integer satisfying the inequality, ensuring enough syndrome space to locate any two erroneous bits.

Q8. Which simple scheme can detect burst errors up to length 3 in a 12‑bit message while not providing correction capability?

🔹 A. A 3‑bit repetition code.
🔹 B. A single parity bit covering all 12 bits.
🔹 C. A Hamming (13,9) code.
🔹 D. A 3‑bit cyclic redundancy check (CRC) with generator polynomial \(x^3 + x + 1\).

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

A 3‑bit CRC with a suitable generator polynomial can flag any burst error of length ≤3 because such bursts alter the polynomial remainder. The scheme does not give enough information to reconstruct the original data, so it serves only as a detector, not a corrector.

Q9. If a detection system can identify any single‑bit error in a message of length \(L\) using \(r\) redundancy bits, how does increasing \(L\) while keeping \(r\) constant affect the probability of an undetected error?

🔹 A. The probability stays the same because detection capability is unchanged.
🔹 B. The probability decreases because longer messages have more bits to check.
🔹 C. The probability increases because more error patterns can map to the same syndrome.
🔹 D. The probability becomes zero for any length.

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

With a fixed number of redundancy bits, the syndrome space is limited. As the message length grows, the number of possible single‑bit error patterns grows linearly, increasing the chance that distinct error patterns produce identical syndromes, thereby raising the undetected‑error probability.

Q10. In layered network protocols, how can an error‑detection mechanism serve as a foundation for an error‑correction strategy?

🔹 A. By providing syndrome information that higher layers can use to guess the original data.
🔹 B. By retransmitting the whole packet when detection signals an error, enabling correction at a higher layer.
🔹 C. By guaranteeing that no errors ever occur, eliminating the need for correction.
🔹 D. By converting detected errors into erasures that can be corrected with erasure codes.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When a lower layer detects an error, it can request a retransmission of the corrupted packet. This simple acknowledgment‑based approach turns detection into effective correction at higher layers, because the repeated transmission eventually delivers an error‑free copy.

Q11. A binary symmetric channel flips each bit with probability \(p = 0.01\). Using a Hamming (7,4) code, what is the expected proportion of transmitted 7‑bit codewords that will contain a correctable single‑bit error?

🔹 A. Approximately \(7p(1-p)^6\).
🔹 B. Approximately \(p\).
🔹 C. Approximately \(7p\).
🔹 D. Approximately \(1 - (1-p)^7\).

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The probability that exactly one of the seven bits is flipped is \(\binom{7}{1}p(1-p)^6 = 7p(1-p)^6\). This is the fraction of codewords that experience a single‑bit error, which the Hamming code can reliably correct. All other patterns are either error‑free or uncorrectable.
