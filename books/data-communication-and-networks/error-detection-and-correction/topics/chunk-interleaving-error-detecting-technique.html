What is Chunk Interleaving Error Detecting Technique?

Chunk interleaving is a technique that rearranges the order of data chunks before transmission to spread out burst errors across multiple blocks upon reassembly, effectively converting difficult-to-correct burst errors into easier-to-handle random errors for the error correction code.
