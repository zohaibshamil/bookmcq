📖 Explanation:

The number of bits per signal element is the ratio N/S = 8000 bps / 1000 baud = 8 bits per baud, so option C is correct.

📖 Explanation:

Since r = log₂L = 8, L = 2⁸ = 256, which corresponds to option B.

🔹 B. 1100 Hz

Q4. Which statement correctly compares the bandwidth requirements of ASK and FSK when both use the same baud rate?

🔹 A. ASK always needs twice the bandwidth of FSK.

📖 Explanation:

FSK adds the carrier separation to the basic bandwidth, while ASK bandwidth is proportional only to the signal rate and factor d, making statement B accurate.

📖 Explanation:

In ASK the bandwidth formula \\(B = (1+d)S\\) does not involve the number of levels L; therefore, changing L does not affect bandwidth, making option B correct.

Q6. Considering noise susceptibility, which modulation scheme—ASK or PM—is generally more robust, and why?

🔹 D. ASK, because it requires less bandwidth.

📖 Explanation:

Phase modulation encodes information in the phase of the carrier, which is less vulnerable to amplitude noise than amplitude variations, so PM is typically more robust, matching option B.
