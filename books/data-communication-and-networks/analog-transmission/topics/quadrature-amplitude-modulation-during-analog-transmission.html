What is Quadrature Amplitude Modulation during Analog Transmission?

Quadrature Amplitude Modulation (QAM) is an advanced digital-to-analog modulation scheme that combines both amplitude and phase modulation by using two carriers 90 degrees out of phase (in quadrature), allowing multiple bits to be encoded per symbol through unique combinations of amplitude and phase levels, thereby achieving high data rates within limited bandwidth during analog transmission.

Q1. What does QAM stand for?

A. Quadrature Amplitude Modulation ✅
B. Quick Access Memory
C. Quantum Angular Momentum
D. Quasi Analog Modulator

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Quadrature Amplitude Modulation is the correct expansion of the acronym QAM. It describes the technique that varies both amplitude and phase of a carrier to convey digital information. The other options refer to unrelated concepts in computer memory, physics, or a fabricated term, making them incorrect.

Q2. If a QAM system doubles the number of amplitude levels while keeping the phase levels constant, how does the number of bits per symbol change?

A. It remains the same
B. It doubles ✅
C. It increases by one bit
D. It halves

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Doubling the amplitude levels multiplies the number of possible symbols by two. Since each symbol represents \(\log_2\) of the total number of symbols, adding one binary digit doubles the bits per symbol. Therefore the bit count per symbol doubles, while the phase contribution stays unchanged.

Q3. In a 16‑QAM constellation, the minimum Euclidean distance between adjacent symbols is \(d\). If the transmit power is increased by a factor of 4, what happens to \(d\)?

A. It increases by a factor of 2 ✅
B. It increases by a factor of 4
C. It remains unchanged
D. It decreases by a factor of 2

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Transmit power is proportional to the square of the signal amplitude. Raising power by 4 means the amplitude (and thus the distance between constellation points) grows by the square‑root of 4, which is 2. Consequently the minimum Euclidean distance \(d\) doubles.

Q4. Compare the spectral efficiency of 64‑QAM and 64‑PSK when both use the same symbol rate. Which statement is accurate?

A. 64‑QAM and 64‑PSK have identical spectral efficiency
B. 64‑PSK is more spectrally efficient than 64‑QAM
C. Both have lower efficiency than BPSK
D. 64‑QAM is more spectrally efficient because it carries more bits per symbol ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Spectral efficiency is measured in bits per second per Hertz. With the same symbol rate, 64‑QAM conveys six bits per symbol (since \(2^6=64\)), whereas 64‑PSK also conveys six bits but suffers a larger Euclidean distance penalty, requiring more bandwidth for reliable transmission. Hence 64‑QAM achieves higher efficiency.

Q5. Evaluate the symbol error rate (SER) at a given \(E_b/N_0\) for 64‑QAM versus 64‑PSK. Which modulation typically yields a lower SER?

A. 64‑PSK
B. 64‑QAM ✅
C. Both have the same SER
D. It depends solely on the channel bandwidth

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

For the same \(E_b/N_0\), 64‑QAM generally exhibits a lower SER because its constellation points are spaced more widely in Euclidean distance than 64‑PSK, which clusters points around a circle. The larger spacing reduces the probability that noise will cause a symbol to cross decision boundaries, thus improving error performance.

Q6. How does Gray coding affect the bit error rate (BER) of a 16‑QAM system compared to a non‑Gray coded mapping, assuming the same minimum distance?

A. It reduces the BER because most symbol errors cause only one bit error ✅
B. It increases the BER due to more complex decoding
C. It has no impact on BER
D. It only changes the bandwidth, not BER

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Gray coding arranges symbols so that adjacent points differ by only one bit. When noise pushes a symbol to a neighboring point, only a single bit flips, reducing the overall BER relative to a mapping where multiple bits could change. The minimum distance remains unchanged, so the improvement stems solely from the bit‑to‑symbol relationship.

Q7. How many bits are represented by a single symbol in a 256‑QAM modulation scheme?

A. 6
B. 8 ✅
C. 16
D. 4

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A 256‑QAM constellation contains \(256 = 2^8\) distinct symbols. The number of bits per symbol is the base‑2 logarithm of the number of symbols, which is \(\log_2 256 = 8\). Therefore each transmitted symbol conveys eight binary bits of information.

Q8. If a QAM signal passes through an ideal low‑pass filter that removes the quadrature (90°) component, which simpler modulation type does the resulting signal resemble?

A. Frequency Shift Keying (FSK)
B. Phase Shift Keying (PSK)
C. Amplitude Shift Keying (ASK) ✅
D. Binary Phase Shift Keying (BPSK)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Eliminating the quadrature component leaves only the in‑phase amplitude variation. The resulting waveform varies solely in amplitude while the carrier frequency and phase remain constant, which is precisely the definition of Amplitude Shift Keying (ASK).

Q9. A 4‑QAM (QPSK) constellation is rotated by 45°. Which set of coordinates correctly describes the new symbol positions?

A. (±1,0) and (0,±1)
B. (±\sqrt{2},0) and (0,±\sqrt{2})
C. (±1,±1)
D. (\pm\frac{1}{\sqrt{2}},\pm\frac{1}{\sqrt{2}}) ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Rotating the standard QPSK points \((\pm1,0)\) and \((0,\pm1)\) by 45° yields coordinates where both I and Q components have equal magnitude of \(\frac{1}{\sqrt{2}}\) but opposite signs, giving the set \((\pm\frac{1}{\sqrt{2}},\pm\frac{1}{\sqrt{2}})\).

Q10. For a QAM system with symbol rate \(R_s\) and roll‑off factor \(\beta\), what is the expression for the required transmission bandwidth \(B\) using a raised‑cosine filter?

A. \(B = \frac{R_s}{2}(1+\beta)\)
B. \(B = 2R_s(1+\beta)\)
C. \(B = R_s(1+\beta)\) ✅
D. \(B = R_s\beta\)

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

A raised‑cosine filter occupies a bandwidth equal to the symbol rate multiplied by \((1+\beta)\). The factor \(\beta\) accounts for excess bandwidth beyond the Nyquist limit. Hence the total required bandwidth is \(B = R_s(1+\beta)\).

Q11. A communication link uses 64‑QAM over an AWGN channel with an SNR of 20 dB. If the SNR drops by 3 dB, approximately how many additional dB of coding gain are required to retain the original BER?

A. 1 dB
B. 3 dB ✅
C. 2 dB
D. 4 dB

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A 3 dB reduction halves the signal‑to‑noise ratio, directly degrading error performance. To compensate, the system must recover the lost 3 dB through forward error‑correcting coding, effectively providing a coding gain of about 3 dB to restore the initial BER.

Q12. When a QAM transmitter employs a non‑uniform constellation to minimize average power while keeping the minimum distance unchanged, how does the symbol error probability compare to that of a uniform constellation?

A. It is lower because the average power is reduced ✅
B. It is higher because symbol spacing becomes irregular
C. It is the same because minimum distance dominates
D. It cannot be determined without simulation

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Keeping the minimum Euclidean distance fixed ensures that the probability of confusing neighboring symbols remains unchanged. By redistributing points to lower the average power, the overall signal‑to‑noise ratio improves, leading to a reduced symbol error probability relative to a uniform constellation with the same minimum distance.
