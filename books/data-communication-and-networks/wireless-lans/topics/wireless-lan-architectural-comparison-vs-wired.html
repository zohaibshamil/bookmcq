What is Wireless LAN architectural comparison vs wired?

Definition:
Wireless LANs (WLANs) utilize radio waves for data transmission, eliminating physical cables, whereas wired LANs rely on Ethernet cables. This fundamental difference impacts mobility, installation cost, and bandwidth reliability. WLANs offer flexibility but face interference issues, while wired networks provide stable, high-speed connections with lower latency and enhanced security through physical containment.

Working:
In WLANs, devices connect via access points using IEEE 802.11 standards, transmitting data over specific frequency bands like 2.4 GHz or 5 GHz. Wired LANs use switches and routers connected by twisted-pair or fiber-optic cables. The wireless medium requires complex modulation techniques to handle signal attenuation and multipath propagation, unlike the direct electrical or optical signals in wired systems.

Example:
A university campus uses wired Ethernet for library computers ensuring 1 Gbps1 \text{ Gbps}1 Gbps stable speed for research databases. Simultaneously, students use WLAN via Wi-Fi access points in cafeterias for mobile device connectivity at 100 Mbps100 \text{ Mbps}100 Mbps, allowing movement without cable constraints despite potential signal fluctuation.

Reason:
The comparison highlights trade-offs: wired networks excel in performance and security for stationary devices, while WLANs prioritize mobility and ease of deployment. Understanding this helps network designers choose appropriate infrastructure based on user needs, budget, and environmental constraints.

Common MisConceptions:
Many believe WLANs are inherently insecure or slower than wired networks. While early Wi-Fi had vulnerabilities, modern WPA3 encryption and 802.11ax standards offer robust security and speeds comparable to wired Gigabit Ethernet in ideal conditions, though latency remains higher.

Exam Preparation Tips: How to prepare this topic
Focus on contrasting key metrics: bandwidth, latency, security, mobility, and cost. Create a comparison table. Understand scenarios where each is preferred. Review IEEE 802.11 evolution and how it bridges the gap with wired performance.

Key Terms:

  • Bandwidth - Maximum data transfer rate of a network.
  • Latency - Time delay in data transmission.
  • Interference - Signal disruption from other electronic devices.
  • Mobility - Ability to move while maintaining network connection.

Q1. How does the function of the line parity byte B2 differ from the section parity byte B1 in terms of scope and error detection?

A.B2 checks only line‑level bits while B1 checks both line and section bits
B.B2 checks bits interleaved across the entire frame, B1 checks only section overhead ✅
C.B1 is for parity of payload, B2 for overhead
D.They are identical in function and scope
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: B2 is calculated over all bytes in the previous STS‑1 frame and thus monitors line‑level interleaved bits. B1, by contrast, is confined to the section overhead and does not cover the entire line, making its scope narrower than B2.

Q2. The K1 and K2 bytes together form a 128‑kbps channel used for automatic protection switching. If each frame period is 125 µs, how many bits are transmitted per frame for APS?

A.16 bits ✅
B.32 bits
C.64 bits
D.128 bits
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: 128 kbps equals 128 000 bits per second. Multiplying by the frame period (125 µs) gives 128 000 × 125 × 10⁻⁶ = 16 bits per frame, which is the amount carried by the two APS bytes.

Q3. Which bytes are reserved for future use in the SONET line overhead?

A.K1 and K2
B.Z1 and Z2 ✅
C.H1 and H2
D.B3 and C2
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The growth bytes Z1 and Z2 are defined as reserved for future expansion. They do not carry any functional data in the current SONET standard, making them the only bytes explicitly set aside for later use.

Q4. The D4‑D12 bytes create a 576‑kbps channel. Given that each byte is 8 bits, how many bytes per frame constitute this channel?

A.9 bytes ✅
B.12 bytes
C.18 bytes
D.24 bytes
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: 576 kbps multiplied by the 125 µs frame period yields 72 bits per frame. Dividing 72 bits by 8 bits per byte results in 9 bytes, which are exactly the D4‑D12 bytes transmitted each frame.

Q5. Which statement correctly contrasts the line‑level order wire byte E2 with the section‑level order wire byte E1?

A.E2 operates at 64 kbps while E1 operates at 128 kbps
B.E2 provides ordering between multiplexers, E1 provides ordering within a section ✅
C.E2 is reserved for future use, E1 carries payload data
D.E2 and E1 are identical in function
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: E2 resides in the line overhead and signals ordering relationships between line‑terminating multiplexers. E1, located in the section overhead, performs the same logical function but only within a single SONET section, so their scopes differ while their purpose remains similar.

Q6. When an SPE is split across two consecutive STS‑1 frames, what is the primary impact on the alignment of the path overhead within the frames?

A.Path overhead must be duplicated in both frames
B.Path overhead may start at different byte positions ✅
C.Path overhead is ignored in the second frame
D.Path overhead is merged with line overhead
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Because the SPE can span two frames, the path overhead does not have to align with the same byte boundaries in each frame. The offset indicated by the pointer bytes may shift, causing the path overhead to begin at a different position in the second frame.

Q7. How many bytes constitute the path overhead in a SONET SPE?

A.5
B.7
C.9 ✅
D.12
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The path overhead is defined to contain nine distinct bytes that carry information such as parity, labeling, and status for the payload envelope. This fixed size is specified in the SONET standard and is independent of the payload content.

Q8. If B3 parity is calculated over the previous SPE, what is the effect on error detection when an SPE is divided between two frames?

A.Errors are only detectable in the first frame
B.Errors spanning the boundary may be missed ✅
C.Errors are detected independently in each frame
D.B3 parity becomes irrelevant
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Since B3 is derived from the bits of the preceding SPE, a split SPE means the parity calculation does not cover bits that cross the frame boundary. Consequently, errors that occur exactly at the split may not be captured by B3, reducing detection effectiveness at that point.

Q9. Considering that K1/K2 provide a 128‑kbps channel, how does increasing the APS channel bandwidth affect the maximum detection latency for a line fault?

A.Higher bandwidth reduces latency
B.Higher bandwidth increases latency
C.Bandwidth has no effect on latency
D.Latency depends only on frame size ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: When the APS channel can convey more bits per unit time, fault‑related signaling can be transmitted faster, thereby shortening the time required to detect and react to a line fault. This inverse relationship between bandwidth and latency is a key design consideration for protection mechanisms.

Q10. If the reserved growth bytes Z1 and Z2 are later assigned to carry a new 64‑kbps service, which of the following statements best describes the likely impact on existing line overhead functions?

A.Existing functions remain unchanged because Z1/Z2 are isolated
B.The new service will replace the APS channel
C.It may require redefining the frame format and could affect synchronization ✅
D.It will double the total line overhead bandwidth
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Reassigning reserved bytes introduces a new payload into the line overhead, which typically demands updates to the frame format, timing, and possibly synchronization mechanisms. Because the overhead bytes are interleaved with other control information, any change can cascade, affecting how devices interpret the entire overhead.

Q11. The pointer bytes H1 and H2 indicate the SPE offset. If the calculated offset exceeds the maximum allowed value, what mechanism is typically employed by SONET devices?

A.The frame is discarded
B.Justification byte H3 is used to adjust the offset ✅
C.The SPE is moved to the next frame
D.The offset is ignored
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When the offset indicated by H1/H2 is too large, the justification byte H3 provides a means to add or remove padding bits, effectively shifting the SPE position to fit within the allowed range without losing data integrity.

Q12. Which comparison correctly reflects the bandwidth and hierarchical level of the D4‑D12 channel versus the F2 channel?

A.D channel 576 kbps at line level, F2 64 kbps at path level ✅
B.D channel 64 kbps at path level, F2 576 kbps at line level
C.Both are 64 kbps but at different levels
D.Both are 576 kbps and share the same level
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The D4‑D12 bytes form a 576‑kbps line‑level channel, while the F2 bytes create a 64‑kbps channel that operates at the path level. This distinction highlights how SONET allocates different bandwidths to control information depending on whether it pertains to the line or the payload path.

Q13. How do the line parity byte B2 and the path parity byte B3 complement each other in SONET’s hierarchical error detection scheme?

A.B2 detects errors in payload, B3 detects errors in overhead
B.B2 checks line‑level bits, B3 checks SPE‑level bits ✅
C.Both perform identical checks at different times
D.B2 overrides B3 when a fault occurs
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: B2 provides parity for the entire line overhead, ensuring integrity across the link between multiplexers. B3, calculated over the SPE, protects the payload envelope itself. Together they create a two‑tiered error‑checking system: line‑level parity catches faults in the transport layer, while SPE‑level parity catches errors within the user data.

Q14. Each K1 and K2 byte is 8 bits. Over a 125 µs frame period, what fraction of the line overhead bytes does the APS channel occupy?

A.5 % of the frame
B.11 % of the frame ✅
C.20 % of the frame
D.25 % of the frame
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The line overhead consists of 18 bytes per frame. The APS channel uses 2 of those bytes (K1 and K2), which is 2 / 18 ≈ 11.1 %. Therefore, the APS channel occupies roughly eleven percent of the line overhead space in each frame.

Q15. Why is section overhead recalculated at each SONET device while line overhead remains unchanged across the link?

A.Section overhead reflects local device status, line overhead reflects end‑to‑end path ✅
B.Section overhead is for user data, line overhead is for management
C.Both are recalculated at every device
D.Line overhead is only used for error detection
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Section overhead contains information that describes the condition of the individual device (e.g., status, performance), so each regenerating or multiplexing node must update it. Line overhead, by contrast, conveys information that must be consistent across the entire optical path, so it is not altered by intermediate devices.

Q16. In an automatic protection switching scenario using the K1/K2 channel, which sequence correctly describes the steps from fault detection to traffic restoration?

A.Fault detected → APS signal sent via K1/K2 → Remote node switches to backup → Normal traffic resumes ✅
B.APS signal sent → Fault detected → Remote node switches → Traffic resumes
C.Remote node switches → Fault detected → APS signal sent → Traffic resumes
D.Fault detected → Traffic resumes → APS signal sent
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: When a fault is identified, the detecting node transmits an APS message over the K1/K2 channel. The remote node receives this signal, triggers a switch to a pre‑configured backup path, and once the protection path is stable, normal traffic is re‑established on the restored route.
