📝 All Traditional cable network architecture MCQs

Q1. Which of the following best defines an access network in the context of traditional cable networks?

🔹 A. A network that connects end‑users or small LANs to an Internet Service Provider using existing telephone or cable infrastructure.
🔹 B. A high‑speed backbone that interconnects multiple regional ISPs across continents.
🔹 C. A wireless link between a router and a mobile device.
🔹 D. A satellite link used for remote telemetry.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

An access network serves the “last mile” by linking individual customers or small LANs to an ISP, typically utilizing the pre‑existing telephone or coaxial cable infrastructure. This definition distinguishes it from backbone or wireless links, making option A the precise description.

Q2. If a home user switches from a DSL modem to a cable modem, which immediate effect is most likely?

🔹 A. The latency will increase dramatically.
🔹 B. The connection will become asymmetric, favoring downstream traffic.
🔹 C. The available downstream bandwidth will generally be higher.
🔹 D. The modem will no longer require a power source.

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Cable modems operate over coaxial cable, which supports much larger channel widths than DSL over copper pairs. Consequently, the downstream capacity increases, often delivering several megabits per second more than DSL. Latency and power requirements remain comparable, and asymmetry is already typical, so option C is correct.

Q3. Which statement correctly contrasts access networks with wide area networks (WANs)?

🔹 A. Access networks operate only over fiber‑optic cables, while WANs use copper.
🔹 B. Access networks serve the last mile to individual customers; WANs span large geographic regions connecting multiple access networks.
🔹 C. WANs provide lower data rates than access networks.
🔹 D. Access networks are always wireless, whereas WANs are always wired.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Access networks focus on delivering service to end users, covering the final segment from the provider to the premises. WANs, by contrast, interconnect many such access segments across cities, countries, or continents. This geographic and functional distinction is captured in option B.

Q4. When a cable system must carry both television signals and Internet data, which principle most effectively prevents interference between the two services?

🔹 A. Time Division Multiplexing (TDM).
🔹 B. Amplitude Modulation (AM).
🔹 C. Quadrature Phase Shift Keying (QPSK).
🔹 D. Frequency Division Multiplexing (FDM).

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

FDM allocates separate frequency bands for distinct services, allowing TV channels and broadband data to coexist on the same physical medium without overlapping. By keeping each service in its own spectral slice, interference is minimized, making option D the appropriate choice.

Q5. Because fiber‑optic cables exhibit attenuation of roughly 0.2 dB/km, compared with 2 dB/km for copper, what can be inferred about the maximum uninterrupted segment length?

🔹 A. Fiber can span about ten times longer distances before repeaters are needed.
🔹 B. Copper can span longer distances because its attenuation is lower.
🔹 C. Both media require repeaters every 5 km regardless of attenuation.
🔹 D. Attenuation does not affect segment length; only bandwidth matters.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Lower attenuation means signal loss accumulates more slowly, allowing fiber‑optic links to travel significantly farther before amplification or regeneration is required. Copper’s higher loss limits its span to a few kilometers. Therefore, the logical inference is that fiber can cover roughly ten times the distance of copper without repeaters, supporting option A.

Q6. Which of the following evaluations best captures the trade‑off between using existing telephone lines (DSL) and installing new coaxial cable for broadband access?

🔹 A. DSL offers higher downstream rates but requires extensive new infrastructure.
🔹 B. Coaxial cable provides lower latency but cannot coexist with television services.
🔹 C. DSL leverages existing wiring, reducing capital costs, but typically yields lower bandwidth than coaxial cable, which demands higher installation expense.
🔹 D. Both DSL and coaxial cable deliver identical performance, so the choice is purely aesthetic.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

DSL takes advantage of the already‑installed copper phone network, keeping deployment costs low, yet its bandwidth is limited by the physical medium. Coaxial cable, while more expensive to lay, supports much higher data rates. This balanced assessment of cost versus performance aligns with option C.

Q7. Given the relationship \( \text{Throughput} = \frac{\text{Data size}}{\text{Latency}} \), which change will most directly increase throughput in a cable network?

🔹 A. Reducing latency while keeping data size constant.
🔹 B. Increasing the data size while keeping latency constant.
🔹 C. Both increasing data size and latency proportionally.
🔹 D. Doubling latency without changing data size.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Throughput rises when the denominator (latency) decreases, assuming the numerator (data size) stays the same. Lower latency means data is delivered faster, directly boosting the rate of successful transmission. Options that increase latency or change data size without affecting latency do not guarantee higher throughput, so option A is correct.

Q8. If the number of subscribers sharing a single coaxial segment doubles, what is the most likely impact on each subscriber’s average downstream bandwidth?

🔹 A. Bandwidth per subscriber remains unchanged because the cable capacity scales automatically.
🔹 B. Each subscriber’s bandwidth will roughly halve, assuming total capacity is fixed.
🔹 C. Bandwidth per subscriber will increase due to improved network efficiency.
🔹 D. The network will automatically allocate more spectrum to maintain original bandwidth.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When a fixed‑capacity medium serves more users, the available bandwidth is divided among them. Doubling the subscriber count typically reduces the share each receives by about half, unless additional spectrum is added. Therefore, the most direct consequence is a halving of per‑user bandwidth, as described in option B.

Q9. Which distinction accurately reflects the capabilities of DOCSIS 3.0 versus DOCSIS 3.1?

🔹 A. DOCSIS 3.0 supports up to 1 Gbps downstream, while DOCSIS 3.1 is limited to 500 Mbps.
🔹 B. DOCSIS 3.1 introduces higher‑order modulation and a wider channel bandwidth, enabling downstream rates up to 10 Gbps, surpassing DOCSIS 3.0’s ~1 Gbps ceiling.
🔹 C. Both versions offer identical maximum speeds; the difference lies only in error‑correction algorithms.
🔹 D. DOCSIS 3.0 is designed for wireless links, whereas DOCSIS 3.1 is for fiber‑to‑the‑home.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

DOCSIS 3.1 expands on 3.0 by employing higher‑order QAM, broader channel bonding, and improved coding, which together raise the theoretical downstream capacity to around 10 Gbps. DOCSIS 3.0 typically caps near 1 Gbps. This performance gap matches option B.

Q10. To achieve a 1 Gbps service to a premises using a hybrid network that combines coaxial cable and fiber‑to‑the‑home (FTTH), which architecture is most appropriate?

🔹 A. Deploy pure coaxial cable throughout, using DOCSIS 3.0 for modulation.
🔹 B. Install fiber only to the neighborhood node, then use Ethernet over twisted pair to the house.
🔹 C. Implement a fiber‑to‑the‑node (FTTN) followed by DOCSIS 3.1 over coaxial cable for the final segment.
🔹 D. Use satellite uplink for upstream traffic and coaxial cable for downstream traffic.

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

A hybrid FTTN approach leverages fiber to bring high‑capacity capacity close to the subscriber, then uses the newer DOCSIS 3.1 standard on the remaining coaxial segment to achieve gigabit speeds. This combination balances cost and performance, making option C the optimal design.

Q11. When comparing a tree topology to a ring topology for a cable access network, which statement best explains the reliability advantage of the ring?

🔹 A. A ring topology eliminates the need for repeaters, reducing failure points.
🔹 B. In a ring, a single break isolates only the affected segment, while a tree can cause widespread outages due to a single node failure.
🔹 C. Ring topologies allow simultaneous bidirectional traffic without any protocol overhead.
🔹 D. Tree topologies provide automatic self‑healing, whereas rings cannot recover from failures.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Ring structures confine the impact of a fault to the immediate vicinity of the break, preventing the cascade of failures that can occur in a tree where a single upstream node’s loss disconnects all downstream branches. This localized effect underpins the reliability benefit described in option B.

Q12. If a cable network experiences increased packet loss due to electromagnetic interference, which mitigation technique is most effective?

🔹 A. Increasing the symbol rate to transmit data faster.
🔹 B. Switching from coaxial cable to twisted‑pair copper.
🔹 C. Applying forward error correction (FEC) at the physical layer.
🔹 D. Reducing the network’s bandwidth allocation.

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Forward error correction adds redundant bits that enable the receiver to detect and correct errors caused by interference, directly improving packet integrity without altering bandwidth or hardware. Adjusting symbol rates or media types does not address the underlying noise, so option C is the most effective solution.
