What is Mobile IP agents home agent and foreign agent?

A home agent is a router on the mobile node’s home network that intercepts packets destined for the mobile node and tunnels them to its current location, while a foreign agent is a router on the visited network that assists the mobile node by providing care-of addresses and decapsulating tunneled packets.

Q1. What is the primary function of a transparent switch?

A.Filter frames based on MAC addresses
B.Learn MAC addresses and forward frames accordingly ✅
C.Amplify signals
D.Convert frames to packets
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Transparent switches operate at the data‑link layer, building a forwarding table by learning source MAC addresses from incoming frames and then using that table to forward frames to the appropriate port. This learning behavior distinguishes them from repeaters.

Q2. If a frame arrives at a switch on a port whose destination MAC address is not in the forwarding table, what will the switch do?

A.Drop the frame silently
B.Forward the frame only on the incoming port
C.Broadcast the frame out all other ports ✅
D.Queue the frame for later processing
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: When the destination MAC is unknown, the switch cannot make a filtered forwarding decision, so it treats the frame as unknown and floods it out of every port except the one it arrived on. This ensures the frame reaches its intended recipient if reachable.

Q3. A network contains a repeater and a link‑layer switch. Which statement correctly compares their filtering capabilities?

A.Both devices filter frames using MAC addresses
B.Only the switch can filter frames based on learned MAC addresses ✅
C.Only the repeater can filter frames based on signal strength
D.Neither device performs any filtering
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A repeater simply regenerates and forwards electrical signals without inspecting frame contents, whereas a link‑layer switch maintains a MAC address table and uses it to decide which ports should receive a given frame, providing selective forwarding and reducing unnecessary traffic.

Q4. Three transparent switches (S1, S2, S3) are interconnected in a triangle. After hosts H1 and H2 exchange several frames, which entry will appear in S3’s forwarding table for H1’s MAC address?

A.Port leading to S1
B.Port leading to S2
C.Port leading to H1 directly
D.No entry will be created ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Because the switches learn MAC addresses from the source field of received frames, S3 will have seen H1’s MAC only when a frame traversed the S3‑S1 link. Consequently, the entry records the port that connects S3 to S1, not a direct port to H1.

Q5. When a spanning‑tree protocol (STP) blocks a port to prevent loops, what is the immediate effect on frame forwarding?

A.Frames are still forwarded but with higher latency
B.Frames destined for that port are dropped, and alternative paths are used
C.All frames are broadcast on every other port ✅
D.The blocked port becomes a repeater
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: STP’s blocking state disables the port for regular frame forwarding, causing the switch to treat the port as unavailable. To maintain connectivity, the switch will flood frames out all other active ports, effectively broadcasting them to reach the destination via an alternate route.

Q6. If a transparent switch is removed from a network, how are its MAC address entries affected in the remaining switches?

A.The entries are immediately purged from all tables
B.The entries remain until they age out or are refreshed ✅
C.The entries are transferred to the nearest switch
D.The entries cause a permanent loop
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When a switch disappears, other switches are unaware of the change. Their forwarding tables continue to hold the learned MAC entries until the aging timer expires or a new frame updates the entry, at which point the stale paths are corrected automatically.

Q7. Explain why the spanning‑tree protocol is essential for loop prevention in a network of transparent switches.

A.It assigns unique MAC addresses to each switch
B.It creates a hierarchy that disables redundant links
C.It encrypts frames to avoid duplication ✅
D.It increases the bandwidth of each link
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: STP builds a logical tree by electing a root bridge and disabling selected ports, ensuring that there is only one active path between any two devices. This eliminates broadcast storms and duplicate frames that would otherwise arise from loops in a fully meshed switch topology.

Q8. In a triangle of switches where S1–S2 link has the lowest cost, which port will STP block to break the loop?

A.The port on S1 connected to S3
B.The port on S2 connected to S3
C.The port on S3 connected to S1
D.The port on S3 connected to S2 ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: STP selects the lowest‑cost links for the spanning tree. Since S1–S2 is cheapest, those ports stay forwarding. The remaining links (S3‑S1 and S3‑S2) are equal in cost; the protocol chooses one to block—typically the one with the higher bridge ID, which in this case is the port on S3 toward S2.

Q9. How does a transparent switch differ from a source‑routing bridge in handling unknown destinations?

A.Both flood unknown frames to all ports
B.Transparent switches drop unknown frames, while source‑routing bridges flood them ✅
C.Source‑routing bridges drop unknown frames, while transparent switches flood them
D.Both drop unknown frames
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A source‑routing bridge relies on path information embedded in the frame; if the destination is unknown, it discards the frame. In contrast, a transparent switch has no prior path knowledge and therefore floods the frame out all ports except the source to discover the correct destination.

Q10. During the learning phase, a switch may temporarily broadcast a frame before its MAC address is learned. What network effect can this cause?

A.Reduced latency for all subsequent frames ✅
B.A brief increase in collision domain size
C.Permanent network segmentation
D.Immediate loop formation
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: When a frame’s destination is unknown, the switch floods it, which momentarily expands the broadcast domain and can increase contention on shared media. Once the source MAC is learned, subsequent frames are unicast, reducing the broadcast overhead.

Q11. Two hosts, H1 and H2, are configured with the same MAC address and connect to the same switch. What is the most likely outcome?

A.The switch will forward frames to both hosts equally
B.The switch will alternate forwarding between the two ports
C.Frames will be delivered to the host that sent the most recent frame ✅
D.The switch will discard all frames with that MAC address
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: A switch uses the most recent source MAC to update its forwarding table. When duplicate MACs exist, the entry flips to the port of the latest frame, causing intermittent delivery where frames may reach whichever host was last seen, leading to unpredictable behavior.

Q12. Which statement best describes the learning process of a transparent switch when it receives a frame from port 3 with source MAC 00:1A:2B:3C:4D:5E?

A.The switch records the MAC on port 1
B.The switch records the MAC on port 3 ✅
C.The switch records the MAC on all ports
D.The switch ignores the source MAC
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Upon receiving a frame, a transparent switch extracts the source MAC address and associates it with the ingress port—in this case, port 3. This entry is stored in the forwarding table, enabling the switch to direct future frames destined for that MAC out through port 3.
