📝 Security of IPv4 datagrams

📖 From Data Communication and Networks • 19. Network Layer Protocols • 18 questions available

What is Security of IPv4 datagrams?

IPv4 was originally designed without built-in security mechanisms, making datagrams vulnerable to spoofing, eavesdropping, and tampering, which necessitates additional protocols like IPsec to provide authentication, integrity, and encryption at the network layer.

Q1. Given the address 230.8.24.56 with a prefix length of /20, which of the following address blocks correctly represents its network?

A. 230.8.0.0 to 230.8.255.255
B. 230.8.16.0 to 230.8.31.255 ✅
C. 230.8.24.0 to 230.8.24.63
D. 230.8.24.56 to 230.8.24.57

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The /20 prefix means the first 20 bits are fixed, leaving 12 bits for hosts. This defines the block from 230.8.16.0 through 230.8.31.255. Only option B matches that range, making it the correct network block for the given address.

Q2. Comparing a /26 block and a /27 block that both contain the address 230.8.24.56, which prefix provides the smaller address range?

A. /26
B. /27 ✅
C. Both are equal
D. Cannot determine

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A /27 prefix uses 27 fixed bits, leaving only 5 bits for host addresses, which yields 2^5 = 32 addresses. A /26 prefix leaves 6 host bits, giving 64 addresses. Therefore the /27 block is smaller, so option B is correct.

Q3. Why must the first address of an allocated block be divisible by the number of addresses in that block?

A. Because the network address must be odd
B. Because the block size must be a power of two
C. Because the first address must have all host bits set to zero ✅
D. Because DNS requires it

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The first address of a CIDR block has the host portion filled with zeros. This requirement forces the decimal value of the first address to be a multiple of the block size, ensuring that the block aligns on a boundary where the host bits are all zero.

Q4. What does the acronym ICANN stand for?

A. Internet Corporation for Assigned Names and Numbers ✅
B. International Computer Association for Network Naming
C. Institute of Cybersecurity and Network Administration
D. International Council for Addressing and Naming

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

ICANN is the global authority that coordinates the allocation of IP address blocks and manages the DNS root zone. Its full name is Internet Corporation for Assigned Names and Numbers, which is captured by option A.

Q5. A router’s forwarding table maps the network 230.8.24.0/26 to interface 3. To which interface will a packet destined for 230.8.24.56 be sent?

A. Interface 1
B. Interface 2
C. Interface 3 ✅
D. Interface 4

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The address 230.8.24.56 falls within the /26 block 230.8.24.0‑230.8.24.63. Because the forwarding entry for that block points to interface 3, the router will forward the packet out interface 3, making option C correct.

Q6. An ISP wants to allocate a block of 2^{10} addresses. Which of the following starting addresses satisfies the divisibility requirement?

A. 230.8.0.0 ✅
B. 230.8.1.0
C. 230.8.2.0
D. 230.8.3.0

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A block of 2^{10}=1024 addresses requires the first address to be a multiple of 1024. The address 230.8.0.0 is exactly such a multiple, while the others are not aligned to a 1024‑address boundary. Therefore option A is the only valid starting point.

Q7. How does CIDR (classless inter‑domain routing) help reduce the size of global routing tables compared with classful addressing?

A. By discarding class boundaries
B. By increasing address length
C. By using NAT
D. By allowing aggregation of contiguous prefixes ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

CIDR permits aggregation of multiple contiguous prefixes into a single, shorter entry. This route summarization dramatically reduces the number of entries a router must store, unlike classful addressing where each class‑A, B, or C network appears as a separate entry. Option D captures this benefit.

Q8. With a prefix length of /29 for the address 230.8.24.56, what is the full range of host addresses in that block?

A. 230.8.24.48–230.8.24.55
B. 230.8.24.56–230.8.24.63 ✅
C. 230.8.24.0–230.8.24.7
D. 230.8.24.64–230.8.24.71

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A /29 prefix leaves 3 host bits, yielding 2^3 = 8 addresses. Starting at the network address 230.8.24.56, the block runs through 230.8.24.63. Thus option B accurately describes the host range.

Q9. In a /31 block, which of the following statements correctly distinguishes the network and broadcast addresses?

A. Network is first, broadcast is second
B. Both addresses are usable hosts ✅
C. There is no broadcast address
D. Network address is undefined

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

RFC 3021 defines a /31 as having only two addresses, both of which are usable for point‑to‑point links; the traditional network and broadcast roles are omitted. Consequently both addresses can be assigned to hosts, making option B correct.

Q10. An ISP receives a request for 3000 IPv4 addresses. According to CIDR rules, which allocation strategy is compliant?

A. Allocate exactly 3000 addresses
B. Allocate a block of 4096 addresses (2^{12}) ✅
C. Allocate a block of 2048 addresses and a separate block of 1024
D. Allocate a /24 block

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

CIDR requires the allocated size to be a power of two. The smallest power of two ≥ 3000 is 2^{12}=4096, so the ISP must allocate a /20 block containing 4096 addresses. Option B follows this rule.

Q11. A router has two overlapping entries: 230.8.24.0/24 → iface1 and 230.8.24.0/26 → iface2. For a packet to 230.8.24.45, which interface is selected?

A. iface1
B. iface2 ✅
C. Both interfaces
D. The packet is dropped

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Longest‑prefix matching selects the most specific route. The /26 entry is more specific than the /24 entry, so the packet matches iface2. Therefore option B correctly describes the forwarding decision.

📖 Explanation:

Q13. What happens to an IPv4 datagram when its TTL field reaches zero during routing?

A. It is forwarded anyway
B. Router discards it and sends ICMP Time Exceeded ✅
C. TTL is reset to default
D. Packet is broadcast to all hosts

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When the TTL counter decrements to zero, the router must drop the packet to prevent endless looping and generate an ICMP Time‑Exceeded message back to the source. This behavior matches option B.

Q14. Can 230.8.24.64 be the first address of a /26 block?

A. Yes ✅
B. No
C. Only if subnet mask is /27
D. Only with NAT

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A /26 block contains 64 addresses, so its first address must be a multiple of 64. The address 230.8.24.64 meets this criterion, making it a valid starting point for a /26 block. Therefore option A is correct.

Q15. Compared to classful addressing, how does classless addressing affect the risk of subnet‑mask manipulation attacks?

A. Increases risk because masks are variable
B. Reduces risk by enabling precise filtering ✅
C. No effect
D. Eliminates need for masks

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Classless addressing allows administrators to define exact prefix lengths, enabling tighter access‑control lists and more precise filtering of traffic. This granularity reduces opportunities for attackers to exploit ambiguous or overly broad masks, thereby lowering the risk of mask‑manipulation attacks. Option B reflects this advantage.

Q16. When an ISP reclaims a previously assigned block, what change must a router make to its forwarding table to maintain correct delivery?

A. Add a new entry without removing old
B. Delete the old entry and add a new one with updated interface ✅
C. Only update metric
D. No change needed

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Reclaimed address space must no longer be advertised on the old interface. The router therefore removes the stale entry and inserts a new entry that points to the correct interface or next‑hop for the reclaimed block. This ensures packets are routed appropriately, making option B correct.

Q18. If a packet's destination address is 230.8.24.56 and the router’s forwarding table contains an entry for 230.8.24.56/31 on interface 5, which interface will forward the packet?

A. Interface 1
B. Interface 2
C. Interface 5 ✅
D. Interface 7

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

A /31 prefix covers the two addresses 230.8.24.56 and 230.8.24.57. Since the destination matches this entry, the router forwards the packet out the associated interface, which is interface 5. Hence option C is correct.
