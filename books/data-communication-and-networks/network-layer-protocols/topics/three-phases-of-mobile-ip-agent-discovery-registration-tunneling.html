What is Three phases of Mobile IP agent discovery registration tunneling?

Mobile IP operates through agent discovery where the mobile node finds available agents, registration where it informs its home agent of its current care-of address, and tunneling where the home agent encapsulates and forwards packets to the care-of address to maintain continuous connectivity during movement.

Q1. When a frame with destination MAC 71:2B:13:45:61:42 arrives at port 1, the switch forwards it only to port 2. Which mechanism best explains why the frame is not sent to any other ports?

A.The switch’s MAC table maps that address to port 2 only. ✅
B.The switch is experiencing a broadcast storm.
C.The frame is marked as multicast and therefore ignored.
D.The switch is operating in half‑duplex mode.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The switch maintains a MAC address table that records the single port where the destination MAC was last seen. Because the entry for 71:2B:13:45:61:42 points exclusively to port 2, the switch filters the frame and forwards it only there, preventing unnecessary traffic on other ports.

Q2. What is the primary function of a link‑layer switch in an Ethernet LAN?

A.To route IP packets between subnets.
B.To filter and forward frames based on MAC addresses. ✅
C.To amplify weak signals across long distances.
D.To assign IP addresses to hosts.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A link‑layer (or Ethernet) switch operates at Layer 2 of the OSI model. Its chief responsibility is to examine the destination MAC address of each incoming frame, consult its MAC address table, and then forward the frame only to the appropriate port, thereby reducing collision domains.

Q3. A switch receives a frame destined for MAC 71:2B:13:45:61:42 on port 3, but its table has no entry for that address. What is the most logical next step?

A.Flood the frame out all ports except port 3. ✅
B.Drop the frame silently.
C.Send the frame back to port 3.
D.Convert the frame to a broadcast packet.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When a MAC address is unknown, the switch follows the learning bridge algorithm: it treats the frame as unknown‑destination and floods it to every port except the one it arrived on. This maximizes the chance that the intended recipient receives the frame while the switch continues to learn the address.

Q4. Which of the following statements correctly differentiates a repeater from a link‑layer switch?

A.A repeater forwards frames based on MAC tables, while a switch forwards on a fixed schedule.
B.A repeater amplifies electrical signals without inspecting MAC addresses, whereas a switch makes forwarding decisions using a MAC address table. ✅
C.Both devices perform address filtering, but a repeater does so at Layer 3.
D.A repeater can learn and age MAC entries, a switch cannot.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A repeater operates purely at the physical layer, regenerating and retransmitting signals without any awareness of MAC addresses. In contrast, a switch works at Layer 2, maintaining a dynamic MAC address table that it uses to decide precisely which port should receive each frame.

Q5. Assume a switch’s MAC table currently contains the entry (71:2B:13:45:61:42 → port 2). If the same MAC address is later seen on port 4, what will the switch do?

A.Replace the old entry with port 4 and forward future frames to port 4. ✅
B.Add a second entry, so the MAC maps to both ports 2 and 4.
C.Ignore the new observation and keep the original entry.
D.Delete the entry entirely.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The MAC learning process updates the table with the most recent port where the address was observed. When the same MAC appears on a different port, the switch overwrites the previous mapping, ensuring that subsequent frames are sent to the newly learned port, which reflects the current topology.

Q6. A network engineer observes that frames destined for MAC 71:2B:13:45:61:42 are always forwarded to port 2, even after a device is moved to port 5. Which inference is most plausible?

A.The switch’s MAC table has a static entry locking the address to port 2. ✅
B.The switch is malfunctioning and ignoring learning updates.
C.The device’s MAC address has been spoofed to a different value.
D.The network uses a VLAN that isolates port 5 from port 2.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Static MAC entries prevent dynamic learning from altering the mapping. If the address continues to be sent to port 2 despite physical relocation, the most reasonable conclusion is that an administrator has configured a static table entry, thereby forcing the switch to always forward frames to port 2 regardless of learned information.

Q7. Consider a scenario where a switch forwards a frame to port 2 only. Which principle of Ethernet switching does this behavior illustrate?

A.Collision detection
B.Store‑and‑forward buffering
C.Selective forwarding based on MAC address learning ✅
D.Half‑duplex operation
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Selective forwarding is a core principle of Ethernet switches. By learning which MAC addresses are reachable via which ports, the switch can forward frames only to the appropriate destination port, reducing unnecessary traffic and improving overall network efficiency.

Q8. If a link‑layer switch incorrectly forwards a frame to all ports except the incoming one, what type of network issue is most likely to arise?

A.Increased latency due to buffering
B.Broadcast storm and excessive collisions ✅
C.Reduced throughput because of link aggregation
D.Address resolution failures
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When a switch behaves like a hub and floods every frame, the network experiences a broadcast storm. This flood of traffic can saturate the medium, cause collisions (in half‑duplex environments), and dramatically degrade performance, illustrating why proper MAC filtering is critical.

Q9. A switch’s aging timer for a MAC entry is set to 300 seconds. After 5 minutes of inactivity for address 71:2B:13:45:61:42, what will the switch do with that entry?

A.It will retain the entry indefinitely.
B.It will purge the entry, treating the address as unknown. ✅
C.It will mark the entry as static.
D.It will duplicate the entry on all ports.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The aging timer causes dynamic MAC entries to be removed after a period of inactivity. Since 5 minutes (300 seconds) exceeds the configured timer, the switch will delete the entry, reverting to the unknown‑destination behavior of flooding frames until the address is learned again.

Q10. Why does a switch consult its MAC table before forwarding a frame, whereas a hub does not perform any lookup?

A.Because switches operate at Layer 3 while hubs operate at Layer 2.
B.Because switches need to enforce security policies, while hubs are designed for broadcast only.
C.Because switches maintain state about which MAC addresses are reachable via each port, while hubs simply repeat signals without any intelligence. ✅
D.Because hubs use a different encapsulation format that does not include MAC addresses.
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Switches keep a dynamic mapping of MAC addresses to ports, enabling them to make intelligent forwarding decisions. Hubs lack this capability; they merely amplify and retransmit electrical signals, treating every incoming frame as a broadcast, which is why they do not consult any table.

Q11. A network admin configures a switch to block frames destined for MAC 71:2B:13:45:61:42 on port 3. Which outcome correctly reflects this policy?

A.Frames are still forwarded to port 3 because MAC filtering is optional.
B.Frames are dropped on ingress at port 3, never reaching the forwarding engine. ✅
C.Frames are forwarded to all ports except port 3, regardless of the destination MAC.
D.The switch converts the frames to IPv6 packets before forwarding.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Port‑based MAC filtering allows an administrator to deny traffic for a specific destination MAC on a given port. When such a rule is active, any frame arriving at the blocked port with that MAC as the destination is discarded immediately, preventing it from being processed or forwarded.

Q12. During a troubleshooting session, a technician notes that frames for MAC 71:2B:13:45:61:42 are being flooded to all ports despite the switch having a correct entry (port 2). Which logical deduction is most consistent with this observation?

A.The switch’s firmware is outdated and cannot use the table.
B.The MAC entry is marked as static, forcing flooding.
C.The switch’s table entry has aged out and is being refreshed. ✅
D.The switch is operating in transparent mode, which always floods frames.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: If the entry has aged out, the switch temporarily treats the destination as unknown and floods the frame while it relearns the address. This behavior aligns with the observed flooding despite the existence of a correct entry, indicating that the aging process is the likely cause.

Q13. Compare the forwarding behavior of a switch that uses cut‑through switching versus store‑and‑forward switching. Which statement accurately reflects their difference?

A.Cut‑through forwards frames before the header is examined, while store‑and‑forward waits for the entire frame to be received and validated. ✅
B.Both methods forward frames only after the MAC address is verified, but cut‑through does so at a higher speed.
C.Store‑and‑forward floods frames to all ports, whereas cut‑through filters based on MAC tables.
D.Cut‑through requires a static MAC table, while store‑and‑forward learns dynamically.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Cut‑through switching begins forwarding a frame as soon as the destination MAC is read, reducing latency but offering limited error checking. Store‑and‑forward waits for the full frame, verifies CRC, then forwards, providing better error detection at the cost of increased delay. Both still rely on MAC tables for decision making.

Q14. A switch receives a frame on port 1 destined for MAC 71:2B:13:45:61:42, and its table shows that address is reachable via port 2. However, the frame is also sent out port 3. Which analytical error most likely explains this behavior?

A.The switch’s MAC table is corrupted, causing duplicate entries.
B.The switch is configured in a spanning‑tree loop, allowing multiple forwarding paths. ✅
C.The switch’s firmware mistakenly treats the frame as broadcast.
D.Port 3 is part of a VLAN that mirrors traffic for monitoring.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Spanning‑tree protocols prevent loops by blocking redundant paths. If the protocol is misconfigured or has not converged, the switch may forward the same frame out multiple ports, creating duplicate deliveries. This scenario best matches the analytical error of an unintended loop.

Q15. In a network with multiple VLANs, a frame destined for MAC 71:2B:13:45:61:42 arrives on port 1. The switch’s table maps that MAC to port 2, but port 2 belongs to a different VLAN. What is the most appropriate action for the switch?

A.Forward the frame to port 2 regardless of VLAN membership.
B.Drop the frame because VLAN isolation prevents cross‑VLAN forwarding. ✅
C.Flood the frame within the incoming VLAN only.
D.Encapsulate the frame with a VLAN tag and forward it.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: VLANs enforce broadcast domains, so a MAC learned in one VLAN should not be reachable from another. When a mismatch occurs, the switch must enforce isolation by discarding the frame, preventing unauthorized cross‑VLAN traffic.

Q16. A switch’s MAC address table contains the entry (71:2B:13:45:61:42 → port 2). If a malicious device spoofs its source MAC as 71:2B:13:45:61:42 on port 5, what effect does this have on legitimate traffic?

A.The switch will forward legitimate frames to both ports 2 and 5.
B.The switch will overwrite the entry, causing future frames to be sent to port 5 only. ✅

D.The switch will ignore the spoofed frame because it does not match the destination MAC.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: MAC spoofing can cause the switch to learn a false association, replacing the legitimate mapping with the attacker’s port. Consequently, subsequent frames destined for the spoofed address are misdirected to the attacker’s port, enabling potential interception or denial of service.

Q17. Which concept best explains why a switch does not need to forward a frame to all ports when it already knows the destination port?

A.Collision domain reduction ✅
B.Broadcast domain expansion
C.Address resolution protocol
D.Layer‑3 routing
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Switches reduce the size of collision domains by sending frames only to the specific port that leads to the destination MAC. This selective forwarding eliminates unnecessary traffic on other ports, differentiating switches from hubs that broadcast to every port.

📖 Explanation: When a dynamic MAC entry ages out, the switch treats the destination as unknown and resorts to flooding, sending the frame out every port except the one it arrived on. This ensures delivery while the switch relearns the correct port for the address.

Q19. A network diagram shows a link‑layer switch connecting three hosts. Host A sends a frame to Host B (MAC 71:2B:13:45:61:42). Which sequence correctly describes the switch’s actions?

A.Learn Host A’s MAC, flood the frame, then learn Host B’s MAC.

C.Drop the frame, then broadcast a request for Host B’s MAC.
D.Forward the frame to all ports, then prune the unused ports.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Upon receiving the frame, the switch first records the source MAC (Host A) with the incoming port. It then consults its table, finds the destination MAC’s associated port (Host B), and forwards the frame solely to that port. Finally, it learns Host B’s MAC when the reply arrives.

Q20. Which of the following best synthesizes the relationship between MAC address learning and frame forwarding efficiency?

A.Learning MAC addresses increases broadcast traffic, reducing efficiency.
B.Dynamic learning allows the switch to minimize unnecessary forwarding, enhancing bandwidth utilization.
C.Static MAC tables are required for any forwarding to occur. ✅
D.Learning MAC addresses has no impact on forwarding behavior.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Dynamic MAC learning enables the switch to build a map of which addresses reside on which ports, allowing it to forward frames only where needed. This selective forwarding conserves bandwidth, reduces collisions, and improves overall network efficiency compared with indiscriminate broadcasting.

Q21. A switch is configured with a maximum MAC table size of 1024 entries. If the network has 1500 active devices, what is the most likely consequence?

A.The switch will automatically upgrade its hardware to accommodate more entries.

C.The switch will block traffic from devices exceeding the limit.
D.The switch will ignore the limit and store all entries.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When the MAC table reaches its capacity, the switch must free space for new entries, typically by aging out older or less frequently used mappings. This can lead to temporary unknown‑destination situations, causing the switch to flood frames until the addresses are relearned.

Q22. In a scenario where a switch forwards a frame to port 2 only, which principle of the OSI model is being exercised?

B.Layer 2 – Data link address filtering ✅
C.Layer 3 – IP routing
D.Layer 4 – Transport‑level flow control
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The forwarding decision based on a destination MAC address occurs at the Data Link layer (Layer 2). The switch examines the MAC address, consults its table, and filters traffic accordingly, embodying Layer 2 functionality.

📖 Explanation: Duplicate MAC entries can cause the switch to believe the address is reachable via multiple ports, leading to simultaneous forwarding on both. This logical inconsistency typically arises from table corruption or misconfiguration that allows the same MAC to map to more than one port.

📖 Explanation: By defining a static MAC entry that binds the address to port 2 and activating port security, the switch will only allow traffic for that MAC on the specified port, rejecting any attempts to forward it elsewhere. This enforces strict location-based forwarding.

📖 Explanation: When a switch cannot locate a destination MAC, it behaves like a hub by flooding the frame to all ports except the one it arrived on. However, a hub inherently repeats the signal on every port for all frames, regardless of destination knowledge. This comparison highlights the switch’s conditional flooding versus the hub’s unconditional repetition.

📖 Explanation: Disabling MAC learning affects only the creation of new entries, not existing static or dynamic entries. Since the entry already maps the MAC to port 2, the switch continues to forward matching frames to that port until the entry ages out or is manually removed.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Aging out inactive entries removes outdated information that could misdirect traffic if a device moves to a different port. By periodically clearing unused mappings, the switch maintains an accurate view of the current topology, reducing the risk of forwarding frames to the wrong destination.

Q29. Which conceptual principle explains why a switch can forward a frame to a single port while a hub must broadcast to all ports?

A.Half‑duplex communication
B.Collision domain segmentation ✅
C.IP subnetting
D.Physical layer attenuation
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Switches segment collision domains by sending frames only to the specific port that leads to the destination MAC, thereby limiting the area where collisions can occur. Hubs lack this intelligence and broadcast to every port, creating a single, larger collision domain.

Q30. If a switch’s MAC table entry for MAC 71:2B:13:45:61:42 is marked as “static,” what does this imply about the entry’s behavior?

📖 Explanation: A static MAC entry is manually configured and does not age out or get replaced by dynamic learning. It stays in the table indefinitely, ensuring that frames destined for that address are always forwarded to the designated port unless the administrator removes the entry.
