What is ICMP message types error reporting and query?

ICMP messages are divided into error-reporting types such as destination unreachable, time exceeded, and parameter problem that notify senders of delivery failures, and query types such as echo request/reply and timestamp that help test connectivity and measure network performance.

Q1. When allocating subblocks from the block 14.24.74.0/24, which subblock receives the first address?

A. Largest subblock (120 addresses) ✅
B. Second largest subblock (60 addresses)
C. Smallest subblock (10 addresses)
D. Reserved for future use

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The first address of the overall /24 block is assigned to the largest required subblock because allocating the biggest subnet first guarantees that its starting address aligns with the size of the block, satisfying the divisibility rule and leaving contiguous space for the smaller subnets.

Q2. What is the subnet mask length that provides exactly 128 addresses?

A. /25 ✅
B. /26
C. /27
D. /24

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A /25 prefix leaves 7 host bits, giving \(2^{7}=128\) possible addresses. This is the smallest prefix that yields exactly 128 addresses, making /25 the correct mask length for that requirement.

Q3. Why does the smallest required subblock of 10 addresses get allocated 16 addresses?

A. Because 10 is already a power of two
B. Because of network overhead
C. Because the next power of two is 16 ✅
D. Because of broadcast address constraints

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Subnetting must use block sizes that are powers of two. Since 10 is not a power of two, the allocation rounds up to the next power, which is 16, ensuring the subnet can be expressed with an integer number of host bits.

Q4. Comparing the allocation of 128 addresses for a need of 120 versus allocating exactly 120 addresses, which statement correctly describes address waste?

A. No waste in either case
B. Allocating 128 wastes 8 addresses ✅
C. Allocating 120 wastes 0 but is not allowed
D. Both waste the same amount

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Using 128 addresses for a 120‑address requirement leaves 8 unused addresses (128 − 120 = 8). Exact 120‑address allocation would avoid waste, but subnet sizes must be powers of two, so the 128‑address block is necessary, creating the described waste.

Q5. Which principle ensures that the starting address of a subnetwork is divisible by the number of addresses in that subnetwork?

Q6. What is the network prefix length for the second largest subblock?

Q11. The subnet mask length for a subblock of 64 addresses is calculated as \( n = 32 - \log_2 64 \). What is the resulting prefix length?

A. /26 ✅
B. /27
C. /25
D. /24

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

\( \log_2 64 = 6 \); subtracting from 32 yields \(32-6 = 26\). Therefore the subnet mask is /26, which provides exactly 64 addresses.
