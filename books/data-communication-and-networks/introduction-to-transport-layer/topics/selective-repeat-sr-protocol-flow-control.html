📝 All Selective Repeat SR protocol flow control MCQs

Q1. Which of the following best explains why Selective Repeat can achieve higher throughput than Go‑Back‑N when the channel error rate is moderate?

🔹 A. Because it retransmits only the erroneous frames, reducing unnecessary retransmissions
🔹 B. Because it uses larger sequence numbers, allowing more frames in flight
🔹 C. Because it employs a cumulative ACK that acknowledges multiple frames at once
🔹 D. Because it combines error detection and correction in a single step

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Selective Repeat sends ACKs for each correctly received frame and only retransmits those identified as lost or corrupted. This targeted approach avoids the costly waste of resending a whole window of frames, which is what Go‑Back‑N does, thereby increasing effective throughput when errors are occasional.

Q2. If the sender’s window size is \(W\) and the sequence number space is \(2W\), what logical problem is avoided?

🔹 A. Sequence number wrap‑around causing ambiguous ACKs
🔹 B. Deadlock due to full buffers
🔹 C. Excessive latency because of large windows
🔹 D. Inability to detect duplicate frames

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When the sequence space is twice the window size, any outstanding frame’s sequence number remains unique, preventing the receiver from confusing a new frame for a retransmitted one. This eliminates ambiguity in ACK interpretation and ensures reliable operation of the Selective Repeat protocol.

Q3. A network engineer observes that increasing the receiver buffer size reduces the number of retransmissions in a Selective Repeat system. Which inference is most accurate?

🔹 A. Larger buffers allow the receiver to store out‑of‑order frames, decreasing the need for immediate retransmission
🔹 B. Increasing buffer size automatically increases the sender’s window size
🔹 C. Buffers have no effect on retransmission count; the observation is coincidental
🔹 D. The protocol discards out‑of‑order frames regardless of buffer size

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Selective Repeat permits the receiver to accept frames that arrive out of order and hold them until missing ones are received. A larger buffer can accommodate more such frames, reducing the frequency of NACK‑triggered retransmissions and improving overall efficiency.

Q4. Consider two hosts using Selective Repeat with a window size of 4. Host A sends frames 0‑3, then 4‑7. Host B acknowledges frames 0,2,3 but not 1. What is the most likely state at Host B?

🔹 A. Frames 0,2,3 are stored; frame 1 is missing, so B waits for 1 before delivering 2 and 3 to the application
🔹 B. All frames are delivered to the application, but ACK for 1 is delayed
🔹 C. Frames 2 and 3 are discarded because of the missing frame 1
🔹 D. Host B will request a full retransmission of the window

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Selective Repeat allows out‑of‑order storage, so frames 2 and 3 can be buffered while awaiting frame 1. Delivery to the application is deferred until the missing frame arrives, preserving order without discarding later frames.

Q5. Which scenario best illustrates a drawback of using a very large sequence number space (e.g., \(2^{16}\)) in Selective Repeat?

🔹 A. Increased memory consumption for buffer management
🔹 B. Higher probability of frame corruption
🔹 C. Longer processing time for checksum calculation
🔹 D. Reduced compatibility with older hardware

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A larger sequence space necessitates bigger buffers and more extensive bookkeeping to track each possible outstanding frame, consuming more memory and computational resources, which can be problematic for devices with limited capacity.

Q6. A student claims that Selective Repeat’s ACK packets are always cumulative. Is this statement correct?

🔹 A. No, ACKs in Selective Repeat are typically individual, acknowledging specific frames
🔹 B. Yes, all ACKs summarize the highest in‑order frame received
🔹 C. Only when the window size is one does the ACK become cumulative
🔹 D. ACKs are never used in Selective Repeat; NACKs are used instead

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Selective Repeat usually sends selective ACKs that identify each correctly received frame, allowing the sender to know precisely which frames need retransmission. Cumulative ACKs are characteristic of Go‑Back‑N, not Selective Repeat.

Q7. If the round‑trip time (RTT) doubles while the sender’s window size remains unchanged, what impact does this have on the protocol’s efficiency?

🔹 A. Efficiency decreases because fewer frames are in transit relative to the longer RTT
🔹 B. Efficiency improves as the larger RTT allows more time for processing
🔹 C. Efficiency remains unchanged because window size dominates performance
🔹 D. Efficiency is unaffected; only error rate matters

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Efficiency in ARQ protocols is tied to the product of window size and RTT. When RTT grows without a corresponding increase in window size, the pipeline becomes underutilized, leading to lower throughput and reduced protocol efficiency.

Q8. In a scenario where the probability of a frame error is \(p=0.02\) and the window size is 5, which statement best quantifies the expected number of retransmissions per window?

🔹 A. Approximately \(5p = 0.1\) frames per window
🔹 B. Approximately \(p^2 = 0.0004\) frames per window
🔹 C. Approximately \(5p^2 = 0.002\) frames per window
🔹 D. Approximately \(p = 0.02\) frames per window

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

With independent errors, the expected number of erroneous frames in a window of size 5 is the sum of individual error probabilities: \(5 \times 0.02 = 0.1\). This gives a straightforward estimate of retransmissions per window.

Q9. Why does Selective Repeat require both sender and receiver to maintain a buffer of size at least the window size?

🔹 A. To store out‑of‑order frames and track which frames have been sent but not yet acknowledged
🔹 B. To compute checksums for each frame
🔹 C. To encrypt and decrypt each frame
🔹 D. To log timestamps for timeout calculation

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Both ends must be able to hold up to \(W\) frames: the sender buffers unacknowledged frames, while the receiver buffers correctly received out‑of‑order frames until missing ones arrive, ensuring reliable in‑order delivery.

Q10. A network simulation shows that when the sender’s timeout interval is set too low, the number of duplicate ACKs rises sharply. Which logical reasoning explains this behavior?

🔹 A. Short timeouts cause premature retransmissions, leading the receiver to generate duplicate ACKs for already received frames
🔹 B. Low timeout values increase the checksum size, causing more ACKs
🔹 C. The protocol switches to Go‑Back‑N when timeout is low
🔹 D. Duplicate ACKs are unrelated to timeout settings

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

If the timeout expires before the ACK arrives, the sender retransmits the frame unnecessarily. The receiver, having already accepted the original frame, acknowledges it again, producing duplicate ACKs and inflating retransmission statistics.

Q11. Compare the memory overhead of Selective Repeat versus Go‑Back‑N for a window size of 8. Which statement is accurate?

🔹 A. Selective Repeat requires roughly twice the buffer space because it must store out‑of‑order frames
🔹 B. Go‑Back‑N needs more memory because it stores all frames until ACK
🔹 C. Both protocols need identical memory because they share the same window size
🔹 D. Selective Repeat uses less memory because it discards frames faster

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Selective Repeat must keep any correctly received frames that arrive out of order, potentially storing up to the full window of 8 frames. Go‑Back‑N, by contrast, does not retain out‑of‑order frames, needing only the current sending window, thus lower memory usage.

Q12. If a receiver using Selective Repeat detects a missing frame number 4 but receives frames 5 and 6, what action should it take?

🔹 A. Buffer frames 5 and 6 and send a NACK for frame 4
🔹 B. Discard frames 5 and 6 and request the entire window again
🔹 C. Deliver frames 5 and 6 to the application immediately
🔹 D. Send a cumulative ACK up to frame 6

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The receiver must hold onto later frames while it awaits the missing one. By sending a negative acknowledgment (or selective ACK) for frame 4, it informs the sender precisely which frame needs retransmission, preserving order without unnecessary loss.

Q13. Which of the following best characterizes the relationship between the sequence number space size \(S\) and the maximum achievable window size \(W_{max}\) in Selective Repeat?

🔹 A. \(W_{max} = \frac{S}{2}\)
🔹 B. \(W_{max} = S\)
🔹 C. \(W_{max} = \sqrt{S}\)
🔹 D. \(W_{max} = S - 1\)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

To avoid ambiguity between new frames and retransmissions, the protocol limits the window to half the sequence space, ensuring that any outstanding frame’s sequence number remains unique. This relationship is fundamental to Selective Repeat’s correct operation.

Q14. A protocol analyst argues that increasing the sender’s window size beyond the receiver’s buffer capacity will improve throughput. Which analytical conclusion is correct?

🔹 A. Throughput will likely degrade because the receiver cannot store all out‑of‑order frames, causing drops
🔹 B. Throughput will increase proportionally with window size
🔹 C. The change has no effect on throughput
🔹 D. Throughput will improve only if error rate is zero

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

If the sender’s window exceeds the receiver’s buffer, the receiver will be forced to discard excess out‑of‑order frames, leading to additional retransmissions and reduced effective throughput, negating any potential gains from a larger window.

Q15. In a scenario where the channel bandwidth is 10 Mbps and the frame size is 1,000 bits, what is the maximum theoretical throughput of Selective Repeat with a window size of 5, assuming no errors?

🔹 A. \(5 \times 1{,}000 \text{ bits} / \text{RTT}\) which simplifies to 5 kbps
🔹 B. 10 Mbps, because the protocol can fully utilize the link
🔹 C. 5 Mbps, half the link capacity
🔹 D. 2 Mbps, due to half‑duplex operation

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Throughput equals the amount of data in flight per RTT. With a window of 5 frames each 1,000 bits, the pipeline holds 5,000 bits. Dividing by the RTT yields the effective rate, which in an error‑free environment is less than the raw 10 Mbps but directly tied to the window and RTT.

Q16. Which logical deduction explains why Selective Repeat is unsuitable for highly lossy channels with loss probability > 30%?

🔹 A. Frequent missing frames cause the receiver’s buffer to fill, leading to excessive retransmissions
🔹 B. High loss rates increase checksum size, making the protocol slower
🔹 C. Selective Repeat cannot handle loss rates above 30% due to protocol design limits
🔹 D. The protocol automatically switches to Go‑Back‑N in such conditions

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When losses are very high, many frames will be missing, filling the receiver’s buffer with out‑of‑order frames while awaiting retransmissions. This situation leads to buffer overflow and a surge in retransmissions, eroding the protocol’s efficiency.

Q17. A designer proposes using a 3‑bit sequence number field for Selective Repeat with a window size of 4. What flaw does this introduce?

🔹 A. The sequence space (8) is only twice the window, violating the requirement that \(S \ge 2W\)
🔹 B. The sequence space is too large, causing unnecessary overhead
🔹 C. Three bits cannot represent window size 4
🔹 D. The protocol will not generate ACKs

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Selective Repeat mandates that the sequence number space be at least twice the window size to avoid ambiguity. With a 3‑bit space (size 8) and window 4, the condition \(S \ge 2W\) is barely met, but any larger window would breach the rule, making the design fragile.

Q18. Which conceptual advantage does Selective Repeat provide over Stop‑and‑Wait ARQ?

🔹 A. It allows multiple frames to be in transit simultaneously, improving link utilization
🔹 B. It eliminates the need for error detection
🔹 C. It requires no acknowledgment packets
🔹 D. It guarantees zero latency

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Selective Repeat’s sliding window enables pipelining of several frames, so the sender doesn’t idle while waiting for each ACK. This dramatically increases utilization of the channel compared with Stop‑and‑Wait, which sends one frame at a time.

Q19. If a receiver using Selective Repeat sends ACKs for frames 0,2,3 but not for 1, what can the sender infer about frame 1?

🔹 A. Frame 1 is likely lost or corrupted and needs retransmission
🔹 B. Frame 1 was received correctly but ACK was delayed
🔹 C. All frames were received; ACK for 1 will arrive later
🔹 D. The sender should reset the connection

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Selective Repeat’s ACKs are selective; the absence of an ACK for a particular sequence number signals that the corresponding frame was not successfully received, prompting the sender to retransmit that specific frame.

Q20. Evaluate the impact of increasing the timeout interval from 100 ms to 500 ms in a high‑latency satellite link using Selective Repeat. Which outcome is most probable?

🔹 A. Throughput may improve because premature retransmissions are reduced, but latency increases
🔹 B. Throughput will sharply decrease due to longer waiting periods
🔹 C. Error detection becomes impossible
🔹 D. The protocol will switch to Go‑Back‑N automatically

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A longer timeout aligns better with the high RTT of satellite links, preventing unnecessary retransmissions caused by early timeouts. While this can boost throughput, it also means that when losses do occur, recovery takes longer, raising end‑to‑end latency.

Q21. What is the primary function of the NACK (negative acknowledgment) in Selective Repeat?

🔹 A. To indicate precisely which frame(s) were not received correctly
🔹 B. To acknowledge all received frames cumulatively
🔹 C. To reset the connection after a timeout
🔹 D. To request a change in window size

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A NACK explicitly informs the sender about missing or corrupted frames, enabling targeted retransmission. This selective feedback is central to the efficiency gains of Selective Repeat over protocols that rely solely on cumulative ACKs.

Q22. A system implements Selective Repeat with a window size of 6 but experiences frequent duplicate ACKs for frame 4. Which logical cause is most likely?

🔹 A. Frame 4 is being lost repeatedly due to a bad link segment
🔹 B. The receiver’s buffer is too small to hold out‑of‑order frames
🔹 C. The sender’s timeout is set too high
🔹 D. The protocol is incorrectly configured to use Go‑Back‑N semantics

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Repeated duplicate ACKs for a specific frame indicate that the receiver consistently fails to obtain that frame, suggesting a persistent loss or corruption on the path, while other frames are arriving and being acknowledged.

Q23. Compare the effect of using a sliding window of size 1 (i.e., Stop‑and‑Wait) versus a sliding window of size 4 in Selective Repeat on channel utilization. Which statement is correct?

🔹 A. Utilization with size 4 is roughly four times higher, assuming the same RTT
🔹 B. Both utilizations are identical because ACK overhead dominates
🔹 C. Size 1 provides higher utilization due to lower complexity
🔹 D. Utilization does not depend on window size

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

With a larger window, the sender can keep multiple frames in flight, reducing idle time caused by waiting for ACKs. Consequently, the channel’s effective utilization scales with the window size, assuming other factors remain constant.

Q24. In a network where packet loss is bursty, lasting for several consecutive frames, how does Selective Repeat handle this compared to Go‑Back‑N?

🔹 A. It retransmits only the lost frames, preserving correctly received out‑of‑order frames
🔹 B. It discards the entire burst and restarts the transmission
🔹 C. It switches automatically to Go‑Back‑N mode
🔹 D. It cannot operate and aborts the connection

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Selective Repeat’s ability to buffer out‑of‑order frames means that when a burst of losses occurs, only the missing frames are resent, while the subsequent correctly received frames remain stored. Go‑Back‑N would require resending the entire window, leading to greater overhead.

Q25. What is the most accurate definition of the term “receiver window” in the context of Selective Repeat?

🔹 A. The range of sequence numbers the receiver is prepared to accept and buffer
🔹 B. The time interval the receiver waits before sending an ACK
🔹 C. The maximum number of ACKs the receiver can send per second
🔹 D. The size of the checksum field in the frame header

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The receiver window defines the set of sequence numbers that the receiver can accept without causing overflow, enabling it to store out‑of‑order frames until missing ones are recovered.

Q26. A developer claims that increasing the sender’s window size always linearly increases throughput in Selective Repeat. Which analytical critique refutes this claim?

🔹 A. Throughput gains plateau once the window exceeds the bandwidth‑delay product, and larger windows cause buffer overflow
🔹 B. Increasing window size reduces error detection capability
🔹 C. Larger windows increase checksum computation time, negating throughput gains
🔹 D. The claim is correct; no refutation needed

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

While a larger window initially improves throughput by keeping more data in flight, once the window surpasses the product of bandwidth and RTT, additional frames cannot be transmitted faster. Moreover, excessive window sizes may overload receiver buffers, leading to dropped frames and diminishing returns.

Q27. If the sequence number space is 8 and the sender’s window is 4, what is the maximum number of outstanding unacknowledged frames the sender can have?

🔹 A. 4
🔹 B. 8
🔹 C. 2
🔹 D. 7

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The window size directly limits the count of unacknowledged frames. With a window of 4, the sender may have up to 4 frames in flight, irrespective of the total sequence space size.

Q28. Why might a system designer choose Go‑Back‑N over Selective Repeat for a low‑bandwidth, high‑latency link?

🔹 A. Because Go‑Back‑N’s simpler buffer requirements reduce memory usage on constrained devices
🔹 B. Because Go‑Back‑N provides higher throughput in such environments
🔹 C. Because Selective Repeat cannot operate over high‑latency links
🔹 D. Because Go‑Back‑N eliminates the need for acknowledgments

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Go‑Back‑N’s minimal buffering (only the sending window) eases memory constraints, which can be advantageous on devices where storing multiple out‑of‑order frames is infeasible, even though it may sacrifice some efficiency.

Q29. In an environment where the error probability is negligible, what is the most likely effect of using Selective Repeat with a window size equal to the sequence space size?

🔹 A. The protocol behaves similarly to a pipeline with no retransmissions, maximizing throughput
🔹 B. The protocol will experience frequent timeouts due to large windows
🔹 C. The receiver will discard all frames because the window is too large
🔹 D. The sender will be forced to reset after each frame

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When errors are rare and the window spans the entire sequence space, the sender can continuously transmit frames without waiting for ACKs, effectively turning the protocol into a high‑throughput pipeline with minimal retransmission overhead.
