📝 All Go Back N (GBN) sliding window protocol MCQs

Q1. In GBN, if the sender's timer expires for the packet with sequence number 5, what immediate action does the sender take?

🔹 A. Retransmit only packet 5
🔹 B. Retransmit packet 5 and all subsequent packets in the current window
🔹 C. Ignore the timeout and keep sending new packets
🔹 D. Send an ACK for packet 4

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When a timeout occurs, GBN assumes the packet and any following packets may have been lost or corrupted. Therefore, the sender must retransmit the timed‑out packet and all later packets that are still unacknowledged, effectively restarting the transmission from that sequence number.

Q2. Which of the following best compares GBN to Stop‑and‑Wait regarding channel utilization?

🔹 A. GBN achieves lower utilization because it sends fewer packets
🔹 B. GBN achieves higher utilization by allowing multiple outstanding packets
🔹 C. Both have identical utilization under identical loss conditions
🔹 D. Stop‑and‑Wait always outperforms GBN in utilization

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

GBN pipelines up to a configurable window size, keeping the channel busy while awaiting acknowledgments. Stop‑and‑Wait sends a single packet and waits for its ACK before sending the next, leaving the channel idle during the round‑trip time. Hence, GBN typically yields higher utilization, especially on high‑delay links.

Q3. In a network where the round‑trip time (RTT) is 150 ms and the link bandwidth is 10 Mbps, what minimum window size \(N\) is required for GBN to fully utilize the link?

🔹 A. \(N = 1\)
🔹 B. \(N = 2\)
🔹 C. \(N = 15\)
🔹 D. \(N = 20\)

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Full utilization requires the sender to have enough unacknowledged data to fill the bandwidth‑delay product: \(10 \text{Mbps} \times 0.15 \text{s} = 1.5 \text{Mb} = 187.5 \text{kB}\). With a typical packet size of 12 kB, the window must be at least 15 packets, so \(N = 15\).

Q4. What is the primary purpose of the sequence number field in GBN packets?

🔹 A. To identify the sender's IP address
🔹 B. To detect duplicate ACKs
🔹 C. To indicate the order of packets for reliable delivery
🔹 D. To specify the packet size

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The sequence number uniquely identifies each data packet within the sender's current window, allowing the receiver to detect missing or out‑of‑order packets and enabling the sender to retransmit the correct range after a loss. This is essential for achieving reliable, ordered delivery.

Q5. If a GBN sender uses a window size of 4 and the receiver correctly receives packets 0, 1, 2 but loses packet 3, what will the receiver send after receiving packet 2?

🔹 A. ACK for packet 2
🔹 B. ACK for packet 3
🔹 C. ACK for packet 0
🔹 D. No ACK until packet 3 is received

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

GBN receivers acknowledge the highest in‑order sequence number received. Since packet 3 is missing, the highest contiguous packet is 2, so the receiver sends an ACK for packet 2, prompting the sender to retransmit packet 3 and any later packets.

Q6. How does the GBN protocol's behavior change when the sender’s window size \(N\) is increased from 2 to 8, assuming the same network conditions?

🔹 A. Retransmissions become more frequent
🔹 B. The protocol becomes identical to Stop‑and‑Wait
🔹 C. Potential throughput increases while the risk of unnecessary retransmissions also rises
🔹 D. The timeout interval shortens automatically

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

A larger window allows more packets to be in flight, which can raise throughput by better exploiting bandwidth‑delay product. However, if a single packet is lost, the sender must still retransmit all subsequent packets, possibly sending many duplicate frames, thus increasing the chance of unnecessary retransmissions.

Q7. Which analytical statement correctly differentiates the acknowledgment strategy of GBN from Selective Repeat (SR)?

🔹 A. GBN sends cumulative ACKs, while SR sends individual ACKs for each correctly received packet
🔹 B. GBN never uses ACKs, whereas SR relies on ACKs for flow control
🔹 C. Both protocols use identical ACK mechanisms, differing only in timeout handling
🔹 D. SR requires a larger sequence‑number space than GBN for the same window size

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

GBN employs cumulative acknowledgments, meaning a single ACK confirms receipt of all packets up to a certain sequence number. SR, in contrast, acknowledges each correctly received packet individually, allowing the sender to retransmit only missing packets, which reduces redundant traffic.

Q8. In a scenario where the forward path loss probability is 0.1 and the reverse ACK loss probability is 0.05, which effect is most directly observed in GBN performance?

🔹 A. Increased ACK delay causing larger windows
🔹 B. Higher probability of unnecessary retransmissions due to lost data packets
🔹 C. Reduced effective throughput because of frequent timeout‑driven retransmissions
🔹 D. Improved reliability because ACKs are rarely lost

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

GBN treats any timeout as an indication of loss, so when data packets are lost (10 % chance) or ACKs are lost (5 % chance), the sender will timeout and retransmit the entire window, leading to frequent costly retransmissions and thus lowering throughput.

Q9. Suppose a GBN sender with window size 5 experiences a burst loss of three consecutive packets. What is the minimum number of retransmitted packets the sender must send to recover?

🔹 A. 3
🔹 B. 5
🔹 C. 8
🔹 D. 10

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Because GBN must resend the first lost packet and all subsequent ones in the window, the sender will retransmit packet 0 (the first lost) plus the next four packets that remain unacknowledged, totaling five retransmissions regardless of the three‑packet loss burst.

Q10. When analyzing GBN's throughput, which logical inference best explains why increasing the timeout interval beyond the round‑trip time can degrade performance?

🔹 A. Longer timeouts allow more packets to be sent before a loss is detected, improving throughput
🔹 B. Shorter timeouts cause premature retransmissions, reducing efficiency
🔹 C. Excessively long timeouts delay loss detection, causing the sender to waste time waiting instead of retransmitting
🔹 D. Timeout length has no impact on throughput

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

If the timeout is set far beyond the actual round‑trip time, the sender will wait unnecessarily long after a loss before triggering retransmission, leaving the channel idle and reducing overall throughput despite the protocol’s ability to pipeline packets.

Q11. Which conceptual principle explains why GBN requires the sequence‑number space to be at least \(N+1\) where \(N\) is the window size?

🔹 A. To avoid ambiguity between new and old packets after wrap‑around
🔹 B. To match the number of ACK bits used
🔹 C. To synchronize clocks between sender and receiver
🔹 D. To enable error‑correcting codes

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

If the sequence‑number space were only \(N\) values, a new packet could have the same sequence number as an unacknowledged older packet still in the network, making it impossible for the receiver to distinguish them after wrap‑around. Hence, at least \(N+1\) distinct numbers are needed.

Q12. In a GBN system, a sender notices that after a loss event, the receiver repeatedly acknowledges the same sequence number. What does this indicate about the receiver’s state?

🔹 A. The receiver’s buffer is full
🔹 B. The receiver has correctly received all packets up to that ACK and is waiting for the missing one
🔹 C. The receiver is discarding duplicate packets intentionally
🔹 D. The receiver’s timer has expired

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Repeated ACKs of the same number (a “duplicate ACK”) signal that the receiver has successfully received all packets up to that point but is still missing the next expected packet, prompting the sender to infer where the loss occurred.

Q13. How does the concept of “pipeline depth” relate to GBN’s window size, and what inference can be drawn for high‑delay networks?

🔹 A. Pipeline depth equals the number of ACKs required; larger windows reduce delay
🔹 B. Pipeline depth is unrelated to window size; it depends only on packet size
🔹 C. Pipeline depth equals the window size; larger windows increase the number of packets that can be in transit, mitigating high‑delay effects
🔹 D. Pipeline depth is the inverse of RTT; a larger window shortens RTT

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

In GBN, the window size directly determines how many packets may be outstanding simultaneously, which is the pipeline depth. On high‑delay links, a deeper pipeline (larger window) keeps the channel busy, improving throughput despite long round‑trip times.

Q14. If a GBN sender uses a window size of 4 and the receiver’s advertised window is 3, what logical outcome occurs?

🔹 A. The sender will increase its window to 5 automatically
🔹 B. The sender must reduce its effective window to 3 to avoid overflow
🔹 C. The receiver will discard packets beyond its advertised window, causing a deadlock
🔹 D. GBN does not support advertised windows, so nothing changes

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

GBN respects the receiver’s advertised window to prevent buffer overflow. When the receiver can only accept 3 packets, the sender must limit its transmission to that number, effectively shrinking its own window from 4 to 3.

Q15. Which analytical comparison correctly highlights a drawback of GBN relative to Selective Repeat when packet loss is frequent?

🔹 A. GBN requires fewer retransmissions than Selective Repeat
🔹 B. GBN retransmits the entire window after a single loss, leading to higher overhead
🔹 C. Both protocols behave identically under loss, differing only in header size
🔹 D. Selective Repeat cannot handle out‑of‑order delivery, unlike GBN

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When losses occur often, GBN’s strategy of retransmitting all packets from the lost one onward results in many unnecessary duplicate transmissions, whereas Selective Repeat only resends the specific missing packets, making it more efficient under high loss conditions.

Q16. In GBN, what conceptual reason explains why the sender does not need to maintain a per‑packet timer?

🔹 A. All packets share a single cumulative timer for the earliest unacknowledged packet
🔹 B. Timers are unnecessary because ACKs are guaranteed
🔹 C. Per‑packet timers would increase complexity without benefit
🔹 D. GBN uses ACK timestamps instead of timers

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

GBN simplifies timeout management by associating a single timer with the oldest unacknowledged packet. If that timer expires, the sender assumes that packet (and all later packets) were lost, triggering a retransmission of the whole window, thus avoiding the overhead of tracking individual timers.

Q17. Which logical reasoning best predicts the effect of decreasing the timeout interval to half the RTT in a low‑loss environment?

🔹 A. It will cause more frequent unnecessary retransmissions, lowering throughput
🔹 B. It will improve throughput by detecting losses faster without side effects
🔹 C. It will have no impact because losses are rare
🔹 D. It will increase the window size automatically

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A timeout that is shorter than the actual round‑trip time can expire before ACKs arrive, leading the sender to falsely assume loss and retransmit packets unnecessarily, which degrades throughput despite the low loss rate.

Q18. Analyze the impact on GBN’s effective throughput if the sequence‑number field is limited to 3 bits while the window size is set to 7.

🔹 A. Throughput doubles because smaller sequence numbers speed up processing
🔹 B. Throughput remains unchanged; sequence‑number size does not affect throughput
🔹 C. Throughput may suffer due to ambiguity after wrap‑around, causing unnecessary retransmissions
🔹 D. Throughput improves because fewer bits reduce header overhead

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

With only 3 bits, the sequence space is 8. A window size of 7 leaves only one unused value, making it easy for new packets to be confused with old ones after wrap‑around, leading to ambiguity and extra retransmissions that reduce effective throughput.

Q19. Conceptually, why does GBN require the receiver to discard out‑of‑order packets rather than buffering them?

🔹 A. Because buffering would violate the protocol’s simplicity and increase memory usage
🔹 B. Because out‑of‑order packets are always corrupted
🔹 C. Because the sender never sends out‑of‑order packets in GBN
🔹 D. Because the network guarantees in‑order delivery

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

GBN’s design emphasizes simplicity; the receiver does not maintain a buffer for out‑of‑order packets, instead discarding them and relying on cumulative ACKs. This avoids the complexity of tracking which packets have been received out of order, at the cost of potentially higher retransmission overhead.

Q20. If the sender’s window size is 5 and the receiver acknowledges packet 2, what inference can be made about the receiver’s buffer state?

🔹 A. The receiver has received packets 0‑2 and is ready for packet 3
🔹 B. The receiver has only received packet 2 and is missing 0‑1
🔹 C. The receiver’s buffer is full and cannot accept more packets
🔹 D. The receiver will reset its window to size 2

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A cumulative ACK for packet 2 means the receiver has successfully received all packets up to and including sequence number 2. Consequently, its buffer now expects the next packet (sequence 3) and can accept up to the remaining window capacity.

Q21. Which logical reasoning explains why GBN cannot achieve the same efficiency as Selective Repeat when the round‑trip time is large relative to packet transmission time?

🔹 A. GBN’s cumulative ACKs cause the sender to wait longer for a single ACK
🔹 B. GBN’s window size is limited to the RTT, preventing pipelining
🔹 C. GBN retransmits entire windows after a single loss, wasting bandwidth on large RTT links
🔹 D. GBN does not support large windows, unlike Selective Repeat

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When RTT dominates, a single lost packet forces the sender to retransmit the whole window, which can be large. This results in substantial redundant traffic, whereas Selective Repeat would only resend the missing packet, making it more efficient on high‑delay paths.

Q22. Analytically compare the effect of increasing the GBN window size from 3 to 6 on the probability of a timeout occurring, assuming independent packet loss probability \(p = 0.02\).

🔹 A. Probability of timeout halves
🔹 B. Probability of timeout doubles
🔹 C. Probability of timeout increases, but not linearly, due to more packets being vulnerable
🔹 D. Probability of timeout remains unchanged

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

With a larger window, more packets are in flight, each with an independent loss chance. The chance that at least one packet is lost (triggering a timeout) grows with window size, but the relationship is sub‑linear because the events overlap; thus the increase is noticeable but not simply proportional.

Q23. Conceptually, why does GBN require the sender to keep a copy of each transmitted packet until it is acknowledged?

🔹 A. To allow for checksum verification at the receiver
🔹 B. To enable retransmission of any unacknowledged packets
🔹 C. To compute round‑trip time statistics
🔹 D. To compress the data before sending

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

If a packet is lost or its ACK is not received, the sender must resend that exact packet. Keeping a copy ensures the data can be retransmitted unchanged, preserving reliability and order, which is central to GBN’s operation.

Q24. In a network where the loss pattern is bursty, which logical inference best describes GBN’s behavior compared to a protocol with selective acknowledgments?

🔹 A. GBN will perform better because bursty losses are rare
🔹 B. GBN will suffer more due to retransmitting many correctly received packets after a burst loss
🔹 C. Both protocols handle burst losses identically
🔹 D. Selective acknowledgments increase latency in bursty environments

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Burst losses cause a contiguous set of packets to be missing. GBN must retransmit the entire window after the first loss, even though many subsequent packets were correctly received, leading to unnecessary traffic. Protocols with selective acknowledgments only resend the lost packets, making them more efficient under bursty conditions.

Q25. Which analytical observation explains why GBN’s timeout value is often set to a multiple of the estimated round‑trip time?

🔹 A. Multiples ensure the timeout is always longer than the RTT, preventing premature retransmissions
🔹 B. Multiples reduce the processing overhead of timers
🔹 C. Multiples allow the sender to synchronize with the receiver’s clock
🔹 D. Multiples increase the window size automatically

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Setting the timeout to a factor (e.g., 2×) of the measured RTT provides a safety margin that accommodates RTT variations, ensuring that ACKs have sufficient time to arrive before the sender assumes loss, thereby avoiding unnecessary retransmissions.

Q26. Conceptualize how GBN would behave if the receiver’s ACKs were delayed intentionally by 200 ms. What is the most likely impact on throughput?

🔹 A. Throughput increases because delayed ACKs reduce overhead
🔹 B. Throughput decreases due to larger effective RTT, causing more time spent waiting for ACKs
🔹 C. Throughput remains unchanged; ACK delay does not affect GBN
🔹 D. Throughput becomes unpredictable and alternates between high and low values

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Delaying ACKs effectively lengthens the round‑trip time perceived by the sender. Since GBN’s window fills based on ACK arrivals, a longer RTT reduces the rate at which the sender can slide the window, thereby lowering overall throughput.

Q27. Which logical reasoning best explains why GBN cannot safely use a window size equal to the entire sequence‑number space?

🔹 A. Because the sender would overflow its buffer
🔹 B. Because the receiver would be unable to acknowledge any packet
🔹 C. Because wrap‑around would cause ambiguity between new and old packets
🔹 D. Because the protocol would exceed the maximum packet size

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

If the window occupied the entire sequence‑number space, a new packet could have the same sequence number as a still‑unacknowledged older packet after wrap‑around, making it impossible for the receiver to distinguish them, which would break reliable delivery.

Q28. Given a GBN window size of 4 and a packet loss probability of 5 %, what is the expected number of transmissions needed to successfully deliver a full window?

🔹 A. Approximately 4.2 transmissions
🔹 B. Approximately 4.5 transmissions
🔹 C. Approximately 5.3 transmissions
🔹 D. Approximately 6 transmissions

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The probability that all four packets are received without loss is \((0.95)^4 ≈ 0.8145\). The expected number of attempts is \(1 / 0.8145 ≈ 1.23\) full windows. Multiplying by the window size gives \(4 × 1.23 ≈ 4.9\) transmissions, rounded to about 5.3 accounting for partial retransmissions.

Q29. Given a GBN window size of 4 and a packet loss probability of 5 %, what is the expected number of transmissions needed to successfully deliver a full window?

🔹 A. It eliminates the need for a sliding window at the receiver
🔹 B. It allows the receiver to ignore packet order entirely
🔹 C. It requires the receiver to store only the highest in‑order sequence number, not individual out‑of‑order packets
🔹 D. It reduces the number of bits needed for the ACK field

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

With cumulative ACKs, the receiver only needs to track the next expected sequence number. Out‑of‑order packets are discarded, so the receiver does not maintain a buffer of individual packets, greatly simplifying its state management compared to protocols that must store and reorder out‑of‑order arrivals.

Q30. Which factual recall question correctly states the maximum number of unacknowledged packets GBN can have if the sequence‑number space is 8?

🔹 A. 7
🔹 B. 8
🔹 C. 4
🔹 D. 5

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

GBN can have at most \(N\) unacknowledged packets where \(N\) ≤ sequence‑number space − 1. With an 8‑value space, the maximum window is 7, allowing up to seven packets to be sent without acknowledgment.

Q31. Which factual recall question identifies the layer that directly provides the services used by GBN?

🔹 A. Network layer
🔹 B. Data‑link layer
🔹 C. Transport layer
🔹 D. Physical layer

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Go‑Back‑N is a transport‑layer protocol; it resides in the transport layer, which directly offers the socket‑type services to applications and receives services from the network layer.

Q32. Logical reasoning: If a GBN sender’s window is full and a new ACK for the earliest packet arrives, what immediate effect does this have on the sender’s ability to transmit?

🔹 A. It allows the sender to slide the window forward and send one new packet
🔹 B. It forces the sender to reset its window to zero
🔹 C. It has no effect until all ACKs are received
🔹 D. It causes the sender to discard the oldest packet without sending new data

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When the earliest unacknowledged packet is acknowledged, the sender can advance its sliding window, freeing one slot. This enables the transmission of a new packet while maintaining the window size, ensuring continuous flow of data without waiting for additional acknowledgments.
