📝 All Network Switching and TCP/IP Layers MCQs

Q1. When end system A requests a connection to end system M, which step must occur before any user data can be transmitted?

🔹 A. Data packets are segmented
🔹 B. A dedicated channel is reserved on each link
🔹 C. IP address is resolved
🔹 D. Switch buffers are cleared

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A connection in a circuit‑switched network cannot carry user data until the network has reserved a specific channel on every link that will be used. This reservation guarantees a continuous, exclusive path, so the correct step is reserving a dedicated channel before transmission begins.

Q2. If a circuit is established but later a switch in the path experiences a hardware fault, what is the most immediate impact on the ongoing communication?

🔹 A. Increased latency
🔹 B. Reduced bandwidth
🔹 C. Automatic rerouting
🔹 D. Termination of the connection

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

When a switch fails, the dedicated physical circuit that was previously reserved can no longer carry the signal. Because circuit switching lacks alternative paths during a session, the connection is abruptly terminated, making termination the most direct consequence of the fault.

Q3. Suppose each link in the network provides n = 3 channels. If a connection uses one channel per link, what fraction of the total link capacity remains unused for that connection?

🔹 A. \( \frac{2}{3} \)
🔹 B. \( \frac{1}{3} \)
🔹 C. \( \frac{1}{2} \)
🔹 D. \( \frac{3}{4} \)

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

With three equal channels, using one leaves two channels free. The unused portion is therefore two out of three, which simplifies to \( \frac{2}{3} \). This ratio represents the remaining capacity on each link when a single dedicated channel is occupied.

Q4. During the teardown phase, which resource is NOT required to be released explicitly?

🔹 A. Physical channel
🔹 B. Switch processing time
🔹 C. IP address binding
🔹 D. Switch input port

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Teardown releases the physical channel, processing time, and input/output ports that were reserved for the circuit. An IP address binding is a logical association that persists beyond the circuit’s lifetime and does not need explicit release when the circuit is torn down.

Q5. In a circuit‑switched network, why is the data stream considered continuous rather than packetized?

🔹 A. Because packets are too large
🔹 B. Because routing tables are static
🔹 C. Because the network uses UDP
🔹 D. Because the physical layer transmits a steady signal without segmentation

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Circuit switching creates a dedicated path that remains open for the entire session, allowing the source to send an uninterrupted signal. No packet boundaries are introduced at the physical layer, so the transmission appears as a continuous flow rather than discrete packets.

Q6. Which of the following best contrasts circuit switching with packet switching regarding resource allocation?

🔹 A. Both allocate resources dynamically per packet
🔹 B. Circuit switching reserves resources end‑to‑end before transmission
🔹 C. Packet switching reserves a fixed path for the entire session
🔹 D. Circuit switching uses statistical multiplexing

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Circuit switching requires that all resources—channels, switch buffers, and ports—be reserved before any data is sent, establishing a fixed end‑to‑end path. Packet switching, in contrast, allocates resources on a per‑packet basis, allowing many flows to share the same physical infrastructure dynamically.

Q7. Consider two networks: one uses FDM to divide each link into 3 channels, the other uses TDM with 3 time slots per link. Which statement correctly evaluates their impact on latency?

🔹 A. FDM introduces higher latency due to frequency conversion
🔹 B. TDM eliminates latency entirely
🔹 C. Both have comparable latency because each provides a dedicated channel per connection
🔹 D. TDM always yields lower latency because slots are shorter

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Both FDM and TDM allocate separate, non‑overlapping resources (frequency bands or time slots) for each connection. Since each connection receives a dedicated slice of the link, the propagation delay dominates, making the latency of both schemes essentially comparable.

Q8. If a circuit‑switched network with 4 links each having 3 channels experiences a surge in call requests, which statement accurately assesses its scalability compared to a packet‑switched network?

🔹 A. Its maximum simultaneous connections are limited to 12, regardless of traffic patterns
🔹 B. It can dynamically allocate unused channels to new calls
🔹 C. It scales linearly with the number of switches
🔹 D. It benefits from statistical multiplexing to accommodate more users

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

With 4 links and 3 channels per link, the total number of distinct end‑to‑end circuits that can exist simultaneously is 3 × 3 × 3 × 3 = 81, but each call consumes one channel on every link, limiting the maximum concurrent calls to the smallest link capacity, i.e., 3 per link, yielding 12 total paths. This hard limit contrasts with packet switching, which can share bandwidth dynamically.

Q9. How does the requirement for a connection setup phase affect the suitability of circuit switching for bursty traffic patterns?

🔹 A. It improves performance because bursts are pre‑allocated
🔹 B. It has no effect
🔹 C. It reduces overhead
🔹 D. It makes circuit switching less efficient due to idle reserved resources between bursts

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Bursty traffic means periods of high activity followed by silence. Circuit switching reserves the full channel for the entire session, so during silent periods the reserved bandwidth sits idle, wasting resources. Consequently, the setup overhead and reserved capacity reduce efficiency for traffic that is not continuous.

Q10. Which layer of the TCP/IP model is directly responsible for establishing the dedicated physical path in a circuit‑switched network?

🔹 A. Network layer
🔹 B. Physical layer
🔹 C. Transport layer
🔹 D. Application layer

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Circuit‑switched networks allocate a specific physical channel at the lowest level of the protocol stack. This function belongs to the Physical layer, which handles the actual transmission medium, signal encoding, and the establishment of a dedicated path for the duration of the call.

Q11. Apply the principle of resource reservation to explain why a voice call over a circuit‑switched network experiences consistent delay, while a voice call over a packet‑switched network may experience jitter.

🔹 A. Circuit switching uses larger packets
🔹 B. Packet switching prioritizes voice
🔹 C. Dedicated bandwidth in circuit switching eliminates queuing variability
🔹 D. Both use the same mechanisms

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

In circuit switching, the reserved channel guarantees that the voice data travels without competing for bandwidth, so each sample arrives after a fixed propagation time, yielding consistent delay. Packet switching shares links among many flows, introducing variable queuing times that cause jitter, especially when the network is congested.

Q12. Synthesize the effect of increasing the number of channels per link (n) on both the setup time and the maximum number of simultaneous end‑to‑end connections in the described network.

🔹 A. Setup time increases linearly with n, while connections stay constant
🔹 B. Setup time decreases, connections decrease
🔹 C. Both remain unchanged
🔹 D. Setup time is unchanged, but maximum simultaneous connections increase proportionally to n

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Adding more channels per link does not alter the signaling protocol used for establishing a circuit, so the time required to negotiate a path remains the same. However, each additional channel creates a new possible route for a distinct connection, allowing the total number of concurrent end‑to‑end circuits to grow in direct proportion to n.

Q13. Given that circuit switching occurs at the physical layer, which of the following implications is most accurate for cross‑layer design in network protocols?

🔹 A. Physical‑layer changes can directly affect end‑to‑end reliability
🔹 B. Transport protocols must manage channel reservation
🔹 C. Application layer can control channel allocation
🔹 D. Network layer must re‑segment data for each channel

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Because the physical layer establishes the dedicated path, any modification at this level—such as altering channel bandwidth or signal timing—will immediately impact the reliability and performance of the entire communication session, influencing higher‑layer behavior.

Q14. If a network designer wants to guarantee zero packet loss for a critical data stream, which switching method should they prioritize and why?

🔹 A. Packet switching because of retransmission
🔹 B. Circuit switching because of dedicated resources
🔹 C. Hybrid switching for flexibility
🔹 D. Statistical multiplexing for efficiency

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Circuit switching provides an exclusive channel for the entire duration of the transmission, ensuring that no other traffic can preempt or interfere with the critical stream. This dedicated allocation eliminates the possibility of packet loss due to congestion, making it the preferred method for absolute reliability.

Q15. How would you apply the concept of dedicated channels to design a hybrid network that supports both voice and data services, ensuring minimal interference?

🔹 A. Allocate separate physical channels for voice and data, using circuit switching for voice and packet switching for data
🔹 B. Merge voice and data onto the same channel using time‑division
🔹 C. Use only packet switching with QoS
🔹 D. Dynamically switch between circuit and packet modes per packet

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

By assigning distinct physical channels to voice (circuit‑switched) and data (packet‑switched), each service can operate on its optimal transport mechanism. Voice benefits from a constant, low‑latency path, while data enjoys flexible bandwidth sharing, reducing cross‑traffic interference and preserving quality for both streams.

Q16. In the TCP/IP model, which layer corresponds most closely to the OSI model’s Data Link layer?

🔹 A. Network layer
🔹 B. Transport layer
🔹 C. Application layer
🔹 D. Link layer (sometimes called Network Interface layer)

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The TCP/IP model’s Link layer, also referred to as the Network Interface layer, handles functions such as framing, MAC addressing, and error detection—tasks that align closely with the Data Link layer of the OSI reference model. This mapping clarifies where physical and data link responsibilities reside in the TCP/IP stack.
