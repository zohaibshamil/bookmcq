What is Stream Control Transmission Protocol (SCTP)?

SCTP is a reliable, message-oriented transport protocol combining features of TCP and UDP, designed for telephony signaling and other applications requiring multistreaming, multihoming, and resistance to head-of-line blocking.

📝 All Stream Control Transmission Protocol (SCTP) MCQs

Q1. What does the acronym SCTP stand for?

A.Simple Connection Transfer Protocol
B.Stream Control Transmission Protocol ✅
C.Synchronous Communication Transfer Procedure
D.Secure Channel Transport Protocol
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The acronym SCTP expands to Stream Control Transmission Protocol. It was designed to provide reliable, message‑oriented transport with features such as multi‑homing and unordered delivery, distinguishing it from TCP and UDP.

Q2. In the Selective Repeat protocol, if a data segment with sequence number 4 is lost, what happens to the transmission of subsequent segments 5 and 6?

A.They are discarded and the sender must resend the entire window.
B.They are ignored by the receiver until segment 4 is retransmitted.
C.They are buffered by the receiver and delivered after segment 4 is successfully received.
D.They are transmitted normally, but the receiver cannot acknowledge them until segment 4 is received, causing a gap in acknowledgments. ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: The loss of segment 4 creates a gap in the acknowledgment sequence. SCTP’s Selective Repeat allows the receiver to keep later segments (5 and 6) in its buffer, but it cannot acknowledge them until the missing segment is retransmitted and correctly received, resulting in a temporary acknowledgment gap.

Q3. Which of the following statements best differentiates the Go-Back-N protocol from the Selective Repeat protocol in terms of retransmission strategy?

A.Go-Back-N retransmits only the missing segment, while Selective Repeat retransmits the entire window.
B.Go-Back-N requires cumulative acknowledgments, whereas Selective Repeat uses selective acknowledgments for individual packets. ✅
C.Both protocols use the same retransmission approach, but Selective Repeat adds error detection codes.
D.Go-Back-N buffers out‑of‑order packets at the receiver, while Selective Repeat discards them.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Go‑Back‑N uses cumulative acknowledgments; when a packet is missing, the sender must resend that packet and all following ones in the window. In contrast, Selective Repeat employs selective acknowledgments, so only the specific lost packets are retransmitted, making it more efficient under moderate loss.

Q4. How does SCTP's four‑way handshake enhance connection reliability compared to TCP's three‑way handshake?

A.It reduces the number of round‑trip times needed to establish a connection.
B.It allows simultaneous data transfer during the handshake.
C.It provides a verification step that confirms both endpoints have received the other's initial sequence numbers. ✅
D.It eliminates the need for sequence numbers entirely.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The four‑way handshake of SCTP adds an extra verification step after the initial SYN‑ACK exchange. Both endpoints exchange and confirm their initial Transmission Sequence Numbers (TSNs), ensuring that each side has correctly received the other's parameters before data transmission begins, thereby increasing reliability over TCP’s three‑step process.

Q5. If the propagation delay is \(T_p\) and the transmission time for a packet is \(T_t\), which expression correctly represents the maximum throughput of the Stop‑and‑Wait protocol?

A.\(\\frac{T_t}{T_p + T_t}\)
B.\(\\frac{T_t}{2T_p + T_t}\) ✅
C.\(\\frac{2T_t}{T_p + T_t}\)
D.\(\\frac{T_p}{T_p + T_t}\)
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: In Stop‑and‑Wait, a sender must wait for an acknowledgment before sending the next packet, so the cycle time includes the transmission time \(T_t\) and twice the propagation delay \(2T_p\) (forward and return). Hence, the maximum achievable throughput is \( \\frac{T_t}{2T_p + T_t} \\).

Q6. Given a window size \(N = 5\) and a packet loss probability \(p = 0.1\), which statement most accurately compares the expected number of retransmissions per window in Go‑Back‑N versus Selective Repeat?

A.Go‑Back‑N expects about \(5p = 0.5\) retransmissions, while Selective Repeat expects roughly \(p = 0.1\) retransmissions.
B.Both protocols expect the same number of retransmissions because loss probability is independent of the protocol.
C.Go‑Back‑N expects roughly \(p/(1-p) = 0.111\) retransmissions, whereas Selective Repeat expects \(5p = 0.5\).
D.Selective Repeat expects fewer retransmissions, approximately \(p = 0.1\), while Go‑Back‑N may incur up to the entire window, i.e., about \(5p = 0.5\) retransmissions. ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: For a window of five packets, Go‑Back‑N must retransmit the lost packet and all subsequent packets in the window, giving an expected retransmission count of roughly \(N \\times p = 5 \\times 0.1 = 0.5\) per window. Selective Repeat only resends the individual lost packet, so its expected retransmissions are about \(p = 0.1\). Therefore, Selective Repeat incurs fewer retransmissions.

Q7. Which scenario best illustrates the advantage of SCTP's multi‑homing capability in reducing connection disruption?

A.A server with two network interfaces detects a failure on the primary link and automatically reroutes traffic through the secondary interface without breaking the association. ✅
B.A client uses SCTP to send data over a single IPv4 address while the server uses IPv6, requiring protocol translation.
C.An application switches from SCTP to UDP when the network becomes congested, preserving throughput.
D.Two hosts negotiate a new port number during an ongoing SCTP association to avoid port conflicts.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: In a multi‑homed SCTP association, each endpoint can advertise multiple IP addresses. If the primary path fails, SCTP seamlessly switches to an alternative address without tearing down the association. This built‑in redundancy keeps the connection alive, demonstrating the protocol’s resilience compared to single‑homed transports.
