What is Transport Layer Protocols overview?

The transport layer acts as a bridge between application programs and the network, providing end-to-end communication services that ensure data is properly segmented, addressed, and delivered between processes on different hosts.

📝 All Transport Layer Protocols overview MCQs

Q1. What is the range of well‑known ports defined by ICANN?

A. 0–1023 ✅
B. 1024–49151
C. 49152–65535
D. 1024–65535

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Well‑known ports are the first block of TCP/UDP port numbers reserved for essential services. ICANN allocates ports from \(0\) through \(1023\) exclusively to these services, ensuring that clients can reliably locate servers without needing to discover the port dynamically. This range is fixed and universally recognized.

Q2. If a daytime client uses an ephemeral source port of 52,000 to contact the daytime server at well‑known port 13, what is the most likely consequence if the client mistakenly uses source port 13 instead?

A. The server will reject the connection because source ports cannot be well‑known.
B. The connection will succeed but the server will be unable to differentiate the client.
C. The server may interpret the packet as coming from itself, leading to a failed handshake. ✅
D. The client will be unable to receive any data.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When the client reuses the server’s well‑known port as its own source port, the packet appears to originate from the same endpoint the server is listening on. This confuses the TCP three‑way handshake, causing the server to treat the segment as a duplicate or self‑generated packet, and the connection typically fails to establish.

Q3. Which statement correctly contrasts well‑known ports with registered ports?

A. Well‑known ports are assigned dynamically, while registered ports are static.
B. Well‑known ports range from \(0\) to \(1023\) and are controlled by ICANN; registered ports range from \(1024\) to \(49151\) and are allocated by IANA to applications on a first‑come, first‑served basis. ✅
C. Both well‑known and registered ports are reserved for system processes and cannot be used by user applications.
D. Registered ports are always higher than dynamic ports, which start at \(49152\).

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Well‑known ports occupy the lowest range (\(0\)–\(1023\)) and are centrally managed to ensure universal service identifiers. Registered ports cover the middle range (\(1024\)–\(49151\)) and are assigned to specific applications after a registration process, allowing organizations to claim a consistent port without the strict global control applied to well‑known ports.

Q4. How does the transport layer differentiate two simultaneous connections that share the same destination IP address but have different port numbers?

A. It uses the source IP address only.
B. It relies on the destination MAC address.
C. It combines source and destination IP addresses with the protocol field.
D. It creates a unique 4‑tuple consisting of source IP, source port, destination IP, and destination port. ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

The transport layer identifies each flow by a five‑tuple: source IP, source port, destination IP, destination port, and protocol. When two connections arrive at the same host IP but use distinct destination ports, the tuple differs in the port component, allowing the OS to maintain separate socket buffers and state machines for each connection despite sharing the same IP address.

Q5. Why does TCP/IP avoid using random port numbers for server processes?

A. Random ports increase security by hiding services.
B. Random ports would require clients to discover the server’s port before communication, adding overhead. ✅
C. Random ports allow multiple servers to run on the same host without conflict.
D. Random ports are reserved for dynamic client connections only.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Server processes need a predictable address so clients can connect without a preliminary discovery step. If servers used random ports, each client would first have to locate the correct port, which would introduce extra protocol messages and latency. Fixed well‑known ports eliminate this overhead and simplify service discovery across the Internet.

Q6. Evaluate the advantages and disadvantages of assigning a server a dynamic (private) port instead of a well‑known port.

A. Advantages: easier firewall configuration; Disadvantages: clients cannot locate the service without prior coordination. ✅
B. Advantages: avoids port conflicts on the host; Disadvantages: increased connection latency due to discovery mechanisms.
C. Advantages: improves security through obscurity; Disadvantages: requires additional protocol steps for clients to learn the port.
D. Advantages: allows multiple instances of the same service; Disadvantages: non‑standard ports may be blocked by network policies.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Using a dynamic port can simplify firewall rules because the port is not predefined, but it forces every client to obtain the port number through an out‑of‑band method, such as a directory service. This extra step adds latency and complexity, while the lack of a standard port can also cause compatibility problems with existing network equipment.

Q7. A new network service wants to become a standard. Which sequence of actions is required to obtain a well‑known port number from ICANN?

A. Submit a proposal to IANA, receive approval, then register the port with the IEEE.
B. Publish the protocol, wait for community adoption, then request a port allocation from IANA.
C. Develop the protocol, submit a registration request to IANA, and upon approval, ICANN assigns the port number. ✅
D. Directly request a port from ICANN without any prior documentation.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The process begins with a fully defined protocol specification. The service provider then files a request with IANA, the Internet Assigned Numbers Authority, which evaluates the need and potential conflicts. If approved, ICANN, through IANA, assigns an unused well‑known port, making the service globally recognizable and allowing clients to connect using that standard port.

Q8. In a NAT environment, multiple clients behind the same public IP address connect to a single server. How do port numbers facilitate correct delivery of responses to each client?

A. The NAT device maps each internal client’s IP to a unique public IP address.
B. The NAT device replaces the destination IP with the server’s IP while keeping the source ports unchanged.
C. The NAT device assigns a distinct external source port for each internal client, creating a unique mapping for return traffic. ✅
D. Port numbers are irrelevant; the NAT relies solely on packet timestamps.

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The NAT device creates a unique external source port for each internal client connection. This external port, together with the public IP, forms a distinct 4‑tuple that the server uses to reply. When the response returns, the NAT translates the external port back to the appropriate internal client’s IP and original port, ensuring each client receives its intended data.
