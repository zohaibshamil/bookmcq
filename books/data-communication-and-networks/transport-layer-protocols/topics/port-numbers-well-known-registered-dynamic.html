What is Port numbers well known registered dynamic?

Port numbers are 16-bit identifiers used to distinguish specific processes, categorized into well-known ports (0-1023) for standard services, registered ports (1024-49151) for user applications, and dynamic or ephemeral ports (49152-65535) assigned temporarily to client connections.

Q1. If a server is configured to listen on port 80 and a packet arrives addressed to port 443, what is the most likely outcome?

A. The packet is processed as a normal request
B. The packet is discarded because the port does not match ✅
C. The server automatically switches its listening port to 443
D. The packet is forwarded to a different server on the same host

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Since the server only accepts traffic on the port it is bound to (80), any packet targeting a different port such as 443 will not match the listening socket. The operating system therefore discards the packet, and no application receives it. This behavior protects the service from unintended traffic.

Q2. In a sliding‑window protocol with sequence numbers modulo \(16\) and a window size of \(7\), the sender has just received acknowledgments for packets 0, 1, 2, and 3. What is the new base (lowest unacknowledged) sequence number?

A. 4 ✅
B. 5
C. 0
D. 7

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Acknowledgments for 0‑3 free those slots, so the earliest outstanding packet becomes 4. Because sequence numbers wrap at 16, the base simply advances to the next unacknowledged number, which is 4. The window then covers 4‑10, maintaining the size of 7.

Q3. A NAT device maps an internal host’s source port 50000 to external port 40000. If the same internal host quickly opens a second TCP connection, which situation most likely causes a port‑collision error?

A. The NAT reassigns external port 40001, which is already in use elsewhere
B. The internal host reuses port 50000 before the first connection closes
C. The NAT discards the SYN packet due to firewall rules
D. The NAT attempts to reuse external port 40000 before the previous mapping times out ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

NAT devices maintain a translation table that pairs internal (IP, port) with external (IP, port). When a new connection is initiated before the old mapping expires, the NAT may try to allocate the same external port (40000). If the previous mapping is still active, this creates a collision, causing the new connection to fail or be misrouted. Proper timeout handling avoids this problem.

Q4. Which of the following statements correctly distinguishes well‑known ports from registered ports?

A. Well‑known ports are above 49152, while registered ports are 0‑1023
B. Both ranges are identical
C. Well‑known ports range from 0 to 1023, and registered ports range from 1024 to 49151 ✅
D. Registered ports are reserved for system services only

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The IANA defines well‑known ports as the range 0‑1023, typically assigned to core services like HTTP (80) and SSH (22). Ports from 1024 to 49151 are called registered ports and are allocated for less common applications. Ports above 49151 are dynamic or private. This categorization helps avoid conflicts between critical and user‑level services.

Q5. Using dynamic (private) ports for client‑side connections mainly improves security by which mechanism?

A. It encrypts the payload
B. It makes it harder for attackers to predict the exact source port ✅
C. It disables all inbound traffic
D. It forces the use of TLS

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Dynamic ports are chosen from a large range (49152‑65535), providing a high degree of randomness. This unpredictability reduces the success rate of blind port‑scanning attacks that rely on guessing a service’s listening port. However, the data itself is not encrypted, and other security measures such as TLS are still required to protect confidentiality.

Q6. Given the throughput formula \( \text{Throughput}= \frac{\text{Window size}\times\text{Packet size}}{\text{RTT}} \), which statement best describes the effect of doubling the sliding‑window size while keeping packet size and RTT constant?

A. Throughput doubles until the network becomes congested ✅
B. Throughput remains unchanged because RTT dominates
C. Throughput halves due to increased queuing delay
D. Throughput becomes unpredictable and may drop to zero

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Doubling the window size directly doubles the numerator, so ideal throughput would double. In practice, the network may reach capacity, causing packet loss and retransmissions, which can limit or even reduce throughput. Therefore the theoretical increase holds only while the path remains uncongested.

Q7. Which port range is typically recommended for short‑lived or temporary services on a host?

A. 0‑1023
B. 1024‑49151
C. 49152‑65535 ✅
D. 65536‑70000

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The dynamic or private port range (49152‑65535) is reserved for temporary allocations such as client‑side connections. Because these ports are not permanently assigned to any specific service, they are ideal for short‑lived processes that need a unique identifier without risking conflict with well‑known or registered services.

Q8. A protocol uses 12‑bit sequence numbers. What is the maximum number of distinct sequence numbers, and what is the largest window size that can be used without risking ambiguity?

A. 4096 distinct numbers; window ≤ 2048 ✅
B. 2048 distinct numbers; window ≤ 1024
C. 4096 distinct numbers; window ≤ 4096
D. 8192 distinct numbers; window ≤ 4096

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

With 12 bits, the total count of unique sequence numbers is \(2^{12}=4096\). To avoid the sender’s window overlapping with previously transmitted numbers that may still be in transit, the window size must be at most half the sequence space, i.e., \( \le 4096/2 = 2048\). This ensures that any acknowledgment can be interpreted unambiguously.

Q9. How does the port number contribute to transport‑layer multiplexing on a single host?

A. It uniquely identifies each application process, allowing multiple sockets to coexist ✅
B. It encrypts the data for each application
C. It determines the routing path across the Internet
D. It replaces the need for IP addresses

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The transport layer uses the combination of IP address and port number to form a socket identifier. Different applications on the same machine listen on distinct ports, enabling the operating system to direct incoming packets to the correct process. This multiplexing allows many concurrent network connections without address conflicts.

Q10. What is the IANA‑assigned port number for the Domain Name System (DNS) service?

A. 25
B. 110
C. 80
D. 53 ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The DNS protocol operates over UDP and TCP using port number 53, as designated by the Internet Assigned Numbers Authority (IANA). This well‑known port allows clients to query name servers for domain resolution. The other listed ports correspond to SMTP (25), POP3 (110), and HTTP (80).
