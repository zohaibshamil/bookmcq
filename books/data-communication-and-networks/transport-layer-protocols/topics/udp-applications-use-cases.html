📝 All UDP applications use cases MCQs

Q1. What is the recommended minimum value for an ephemeral port number in UDP client programs?

🔹 A. 1024
🔹 B. 2048
🔹 C. 4096
🔹 D. 8192

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Ephemeral ports are intended for short‑lived client sockets. Operating systems typically reserve the well‑known range (0‑1023) for privileged services, so choosing a number greater than 1024 avoids conflicts with those services and reduces the chance of permission‑related errors. Hence 1024 is the usual lower bound.

Q2. Which of the following protocols commonly uses UDP for its transport layer?

🔹 A. HTTP
🔹 B. FTP
🔹 C. DNS
🔹 D. SMTP

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Domain Name System (DNS) relies on UDP because most queries fit within a single datagram, allowing fast, connectionless exchanges without the overhead of establishing a TCP session. This design reduces latency and network traffic, making UDP the preferred transport for typical DNS lookups.

Q3. If a UDP packet is lost during transmission, what is the most likely outcome for the application?

🔹 A. Automatic retransmission
🔹 B. Connection reset
🔹 C. Application receives incomplete data
🔹 D. Application receives no data

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

UDP provides no built‑in reliability or retransmission mechanisms. When a datagram is dropped, the receiving application simply never sees that piece of data. It must either tolerate the loss, request a resend at the application layer, or handle the missing information according to its own protocol logic.

Q4. A client sends a UDP datagram to a server on port 53, but the server does not respond. Which inference is most plausible?

🔹 A. Server is down
🔹 B. Port number is incorrect
🔹 C. Network firewall blocks UDP
🔹 D. All of the above

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Port 53 is the standard DNS service, so the client is using the correct destination. If no reply arrives, a common cause is that a firewall or NAT device is silently dropping UDP traffic, preventing the server's response from reaching the client.

Q5. Suppose a UDP‑based video streaming app uses an ephemeral port of 5000, which is below the recommended threshold. What effect might this have on the client's ability to receive data?

🔹 A. Higher latency
🔹 B. Potential permission errors
🔹 C. Increased bandwidth
🔹 D. No effect

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Ports below 1024 are traditionally reserved for privileged services. On many operating systems, a non‑privileged process attempting to bind to such a low port will be denied, causing the client to fail to open the socket or to encounter permission‑related errors that prevent data reception.

Q6. Given that UDP provides no flow control, if a client sends datagrams faster than the network can handle, what is the most likely consequence?

🔹 A. Datagrams are queued indefinitely
🔹 B. Datagrams are dropped
🔹 C. TCP fallback occurs
🔹 D. Server will send ACKs

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When the transmission rate exceeds the network's capacity, intermediate routers and the receiver cannot buffer all incoming packets. UDP lacks congestion‑avoidance mechanisms, so excess datagrams are simply discarded, leading to packet loss that the application must tolerate or recover from on its own.

Q7. A UDP server binds to port 0 (zero). What is the result of this operation according to the socket API semantics?

🔹 A. Server listens on all ports
🔹 B. System assigns an arbitrary available port
🔹 C. Operation fails
🔹 D. Server uses port 0 for communication

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

In most socket APIs, binding to port 0 signals the operating system to select an unused ephemeral port automatically. This allows the server to obtain a unique, available port without manually specifying one, facilitating dynamic service deployment while avoiding collisions with existing bindings.

Q8. If two UDP applications on the same host use overlapping ephemeral port ranges, what conflict may arise?

🔹 A. Port collision causing misdelivery
🔹 B. Increased throughput
🔹 C. Encryption errors
🔹 D. No conflict

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When two processes bind to the same port number, the kernel cannot distinguish which datagram belongs to which application. This ambiguity can cause packets intended for one process to be delivered to the other, resulting in data misdelivery, unexpected behavior, and potential security concerns.

Q9. Compare the reliability of UDP with TCP. Which statement correctly reflects their difference?

🔹 A. UDP guarantees delivery
🔹 B. TCP provides ordering
🔹 C. UDP provides flow control
🔹 D. Both are connectionless

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

TCP establishes a connection and ensures that data arrives in the order sent, using acknowledgments and retransmissions. UDP, by contrast, is connectionless and does not guarantee delivery, ordering, or flow control, making it less reliable but faster for applications that can tolerate occasional loss.

Q10. Evaluate why DNS prefers UDP over TCP for typical queries.

🔹 A. Lower overhead
🔹 B. Built‑in reliability
🔹 C. Persistent connections
🔹 D. Large payload support

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A DNS query and its response usually fit within a single 512‑byte datagram, allowing the entire exchange to occur without the three‑way handshake and state management required by TCP. This reduces processing time and network traffic, making UDP the more efficient choice for the vast majority of DNS lookups.

Q11. Differentiate between an ephemeral port and a well‑known port in terms of range and typical usage.

🔹 A. Ephemeral ports are 0‑1023, used for well‑known services
🔹 B. Well‑known ports are 1024‑49151, used for temporary connections
🔹 C. Ephemeral ports are 49152‑65535, used for short‑lived client connections
🔹 D. Both ranges overlap

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Well‑known ports occupy the 0‑1023 range and are assigned to standard services (e.g., HTTP 80, DNS 53). Ephemeral ports reside in the high‑numbered range 49152‑65535 and are allocated by the OS for transient client sockets, ensuring that short‑lived connections do not interfere with reserved service ports.

Q12. Assess the impact of increasing the size of a UDP datagram beyond the typical MTU on network performance.

🔹 A. Fragmentation leads to higher loss
🔹 B. No impact
🔹 C. Improves speed
🔹 D. Switches to TCP

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When a UDP packet exceeds the path MTU, IP fragmentation occurs. Each fragment must arrive intact; loss of any fragment forces the whole datagram to be discarded, dramatically increasing the probability of packet loss and retransmission at the application level, thus degrading performance.

Q13. Contrast the behavior of a UDP‑based VoIP application when encountering packet loss versus a TCP‑based file transfer application.

🔹 A. VoIP tolerates loss, file transfer retries
🔹 B. Both delay until all packets arrive
🔹 C. VoIP switches to TCP automatically
🔹 D. File transfer continues despite loss

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

VoIP streams are time‑sensitive; occasional lost packets are acceptable and simply result in brief audio glitches. In contrast, a TCP file transfer expects reliable delivery, so any loss triggers retransmission and flow control, potentially causing significant delays until the missing data is recovered.

Q14. Given two UDP services, one using fixed ports and another using dynamically assigned ephemeral ports, which design offers better scalability in a large data center?

🔹 A. Fixed ports
🔹 B. Ephemeral ports
🔹 C. Both equal
🔹 D. Neither

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Dynamic allocation of ephemeral ports reduces the chance of port exhaustion and eliminates the need for manual coordination of port numbers across many services. This flexibility allows a data center to deploy many instances of the same service without risking collisions, thereby supporting higher scalability than a fixed‑port scheme.

Q15. Apply the principle of statelessness: In UDP, what must an application do to match responses to requests?

🔹 A. Maintain connection state
🔹 B. Use source port and payload identifiers
🔹 C. Rely on TCP handshake
🔹 D. Ignore source address

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Because UDP carries no session information, the application itself must embed identifiers—such as the source port number, transaction IDs, or sequence numbers—within the payload. By examining these fields in incoming datagrams, the program can correlate each reply with the original request it sent.

Q16. Synthesize a scenario where a game client uses UDP for real‑time position updates but falls back to TCP for critical events. Which design principle does this illustrate?

🔹 A. Layered architecture
🔹 B. Hybrid transport
🔹 C. Encryption
🔹 D. Multiplexing

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Combining UDP for low‑latency, loss‑tolerant data (e.g., player positions) with TCP for reliable, ordered transmission of essential events (e.g., item purchases) exemplifies a hybrid transport approach. It leverages the strengths of each protocol while mitigating their weaknesses, providing a balanced solution for interactive applications.

Q17. Explain how NAT traversal techniques such as STUN rely on UDP characteristics.

🔹 A. They exploit UDP's connectionless nature
🔹 B. They require TCP three‑way handshake
🔹 C. They depend on IP fragmentation
🔹 D. They use ICMP messages

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

STUN (Session Traversal Utilities for NAT) sends a small UDP packet to a public server, which reflects the packet's source address and port back to the client. Because UDP does not maintain state, the NAT device creates a temporary binding that the client can reuse, allowing peer‑to‑peer communication without a prior TCP session.

Q18. Apply the concept of port randomization: Why does increasing the range of ephemeral ports improve security against port prediction attacks?

🔹 A. Larger space reduces predictability
🔹 B. It encrypts the payload
🔹 C. It disables NAT
🔹 D. It forces TCP fallback

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When the pool of possible ephemeral ports is expanded, an attacker attempting to guess a future port number faces a vastly larger search space. This makes successful port‑prediction attacks far less likely, thereby strengthening the system's resistance to unauthorized probing or session hijacking.

Q19. Design a UDP‑based sensor data collector that must ensure data integrity without built‑in reliability. Which additional mechanism should be incorporated?

🔹 A. Checksum verification
🔹 B. Three‑way handshake
🔹 C. Sequence numbers with ACKs
🔹 D. Encryption

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Because UDP lacks acknowledgments, the application should add its own reliability layer, such as sequence numbers paired with explicit ACK messages. This enables the collector to detect missing or out‑of‑order packets and request retransmission, thereby achieving data integrity despite UDP's inherent unreliability.
