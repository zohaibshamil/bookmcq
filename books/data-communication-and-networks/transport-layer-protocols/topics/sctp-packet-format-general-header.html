What is SCTP packet format general header?

An SCTP packet begins with a common header containing source/destination ports, verification tag, and checksum, followed by one or more chunks that carry control information or user data in a type-length-value format.

Q1. In Selective Repeat ARQ, what is the maximum size of the receive window expressed in terms of the sequence number field length \(m\)?

A.\(2^{m}\)
B.\(2^{m}-1\) ✅
C.\(2^{m-1}\)
D.\(m-1\)
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The receive window cannot exceed the range of sequence numbers available. With an \(m\)-bit sequence field, the total number of distinct sequence numbers is \(2^{m}\). To avoid ambiguity, the protocol limits the window to \(2^{m}-1\) slots, ensuring unique identification of each outstanding packet.

Q2. If the sender's window size equals the receiver's window size, which of the following must be true for a packet that arrives out of order?

A.It is immediately delivered to the application layer.
B.It is discarded.
C.It is stored in the receiver buffer until missing packets arrive. ✅
D.It triggers a reset of the connection.
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Selective Repeat permits out‑of‑order arrivals, but the receiver cannot present them to the application until the missing lower‑numbered packets are received. Therefore the packet is placed in a buffer, preserving ordering while awaiting the missing sequence numbers that will enable consecutive delivery.

Q3. Which statement correctly contrasts the behavior of Go-Back-N and Selective Repeat regarding out‑of‑order packets?

A.Selective Repeat can buffer out‑of‑order packets, while Go‑Back‑N discards them and retransmits from the missing packet. ✅
B.Go‑Back‑N buffers out‑of‑order packets, while Selective Repeat discards them.
C.Both protocols discard out‑of‑order packets.
D.Both protocols store all out‑of‑order packets indefinitely.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Go‑Back‑N assumes that any loss forces the sender to retransmit the lost packet and all subsequent ones, so the receiver discards any out‑of‑order data. Selective Repeat, by contrast, maintains a receive buffer that can hold out‑of‑order packets until the missing ones arrive, enabling efficient recovery.

Q4. A receiver using Selective Repeat receives packets numbered 0,2,1 in that order. After processing, which packet(s) can be delivered to the application layer?

A.Only packet 0.
B.Only packet 1.
C.Packets 0 and 1. ✅
D.All three packets.
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Packet 0 arrives first and can be delivered immediately. Packet 2 is stored because packet 1 is missing. When packet 1 arrives, the receiver now has a consecutive sequence (0,1) and can deliver both 0 and 1; packet 2 remains buffered until packet 3 arrives.

Q5. Suppose the send window size is set to \(2^{m-1}\). If a packet with sequence number \(k\) is lost, what is the earliest sequence number that the sender may retransmit according to Selective Repeat?

A.\(k\) ✅
B.\(k+1\)
C.\(k-(2^{m-1})\)
D.None, sender waits for timeout.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Selective Repeat allows the sender to retransmit only the specific lost packet. Because the sender tracks acknowledgments individually, the earliest retransmission candidate is the exact missing sequence number \(k\). The protocol does not require advancing to \(k+1\) or any other number until the lost packet is recovered.

Q6. How does the requirement that the receive window size equals the send window size affect the maximum number of outstanding unacknowledged packets in a network with high latency?

A.It limits the number to half of the window size.
B.It allows up to the full window size of packets to be in flight. ✅
C.Sender stops after a single packet.
D.It doubles the effective throughput regardless of latency.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When the sender and receiver windows match, the sender can fill the entire window with unacknowledged packets. In high‑latency environments this maximizes utilization because the pipeline can contain up to \(W\) packets, where \(W\) is the common window size, before awaiting acknowledgments.

Q7. In a scenario where the sender's window is fully utilized and the receiver's buffer is partially full, which action best preserves protocol efficiency?

A.Sender reduces its window size to match the receiver's remaining buffer.
B.Receiver sends a NACK for each missing packet.
C.Sender continues transmitting, relying on future ACKs to free space. ✅
D.Receiver discards the oldest stored packet to make room.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Selective Repeat is designed for pipelined transmission. Even if the receiver's buffer is not completely empty, the sender can keep sending new packets; as acknowledgments arrive, buffer space is freed. This avoids unnecessary throttling and maintains high throughput while still respecting the window limits.

Q8. Compare the impact on bandwidth utilization when the receive window is set to its maximum \(2^{m}-1\) versus a smaller window of size \(2^{m-2}\). Which outcome is most likely?

A.The larger window always leads to higher utilization regardless of error rate.
B.The smaller window reduces utilization but improves error recovery speed.
C.Both windows give identical utilization in error‑free channels.
D.The larger window can cause more retransmissions, lowering utilization under high error rates. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A larger window permits more packets in flight, boosting throughput when the channel is clean. However, in noisy conditions more packets may be lost or arrive out of order, prompting additional retransmissions. This overhead can outweigh the benefit, resulting in lower effective utilization compared with a more conservative window size.

Q9. If a receiver using Selective Repeat has already stored packets with sequence numbers 5 through 9, and a new packet with sequence number 4 arrives, what is the immediate effect?

A.Packet 4 is discarded because it is out of order.
B.Packet 4 is stored and the receiver can now deliver packets 4‑9 consecutively. ✅
C.Packet 4 triggers a reset of the receive window.
D.Packet 4 is stored but delivery is still blocked until packet 10 arrives.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When packet 4 arrives, it fills the gap at the start of the buffered block. The receiver now holds a contiguous sequence from 4 to 9, allowing it to forward all those packets to the application layer in order. No reset is needed, and further packets can continue to be buffered.

Q10. When designing a packet format for Selective Repeat, which field is essential to enable the receiver to correctly reorder out‑of‑order packets?

A.Checksum field.
B.Sequence number field. ✅
C.Timestamp field.
D.Source address field.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The sequence number uniquely identifies each packet's position in the transmitted stream. Without it, the receiver cannot determine the correct order of out‑of‑order arrivals. While checksums verify integrity and timestamps may aid timing, the sequence number is the fundamental element for reordering in Selective Repeat.

Q11. Assume a channel with packet loss probability \(p\) and a sender window size \(W = 2^{m}-1\). Derive which of the following expressions best approximates the expected number of retransmissions per successful packet in Selective Repeat?

A.\(\frac{p}{1-p}\)
B.\(\frac{pW}{1-pW}\) ✅
C.\(\frac{p}{(1-p)W}\)
D.\(\frac{pW^{2}}{1-p}\)
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Selective Repeat allows multiple outstanding packets; the probability that at least one of the \(W\) packets is lost is roughly \(pW\) (for small \(p\)). The expected retransmissions per successful packet follow a geometric distribution with success probability \(1-pW\), giving an average of \(\frac{pW}{1-pW}\) retransmissions.

Q12. Consider a network where the round‑trip time (RTT) is large relative to packet transmission time. How should the packet format be modified to maximize throughput under Selective Repeat?

A.Increase the sequence number field size to allow a larger window. ✅
B.Add a larger checksum field.
C.Include a priority field to reorder packets.
D.Reduce the header size by eliminating the sequence number.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A larger sequence number field expands the range of distinct sequence identifiers, permitting a larger sliding window. With a long RTT, more packets must be in flight to keep the pipeline full. Enlarging the window directly improves throughput, whereas checksum or priority fields do not address the fundamental limitation imposed by RTT.

Q13. If a sender mistakenly uses a receive window size larger than its send window size, what is the most likely protocol violation that will occur?

A.Duplicate ACKs will be generated for every packet.
B.The receiver may accept packets it cannot buffer, causing overflow and loss. ✅
C.The sender will never time out, leading to deadlock.
D.All packets will be delivered out of order to the application layer.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When the receiver advertises a window larger than the sender's actual sending capacity, the sender may transmit more packets than the receiver can store. This mismatch can cause the receiver's buffer to overflow, forcing it to discard incoming packets or generate errors, which violates the protocol's guarantee of reliable, ordered delivery.
