What is SCTP features TSN SI SSN chunks?

SCTP organizes data using Transmission Sequence Numbers (TSN) for reliability, Stream Identifiers (SI) for stream separation, Stream Sequence Numbers (SSN) for intra-stream ordering, and structured chunks for flexible message handling.

Q6. Which of the following best explains why Selective‑Repeat uses a smaller send window than Go‑Back‑N?

📖 Explanation: The smaller window ensures that the sequence numbers of outstanding frames never overlap with those of new frames, preventing the receiver from confusing a delayed packet for a newly transmitted one. 📖 Explanation: Matching the receive window to the send window size gives the receiver enough buffer space to hold any frames that arrive within the sender’s outstanding window but out of order.
