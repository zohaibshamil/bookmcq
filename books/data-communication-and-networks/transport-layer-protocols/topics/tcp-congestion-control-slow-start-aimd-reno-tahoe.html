What is TCP congestion control slow start AIMD Reno Tahoe?

TCP manages network congestion through algorithms starting with exponential slow start, transitioning to additive increase/multiplicative decrease (AIMD), with variants like Tahoe and Reno modifying behavior during loss detection and recovery phases.

Q1. Which of the following port number ranges is designated for well‑known services?

A. 0–1023 ✅
B. 1024–49151
C. 49152–65535
D. All ports

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Well‑known services are assigned port numbers from 0 to 1023, as defined by IANA. This range is reserved for core protocols such as HTTP (80) and DNS (53). The other ranges are for registered, dynamic, or private use, making option A the correct choice.

Q2. What is the default initial congestion window (cwnd) size in many modern TCP implementations measured in MSS units?

A. 1 MSS
B. 2 MSS
C. 4 MSS
D. 10 MSS ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

RFC 6928 recommends an initial cwnd of ten maximum‑segment sizes (MSS) for new connections. Earlier implementations used one MSS, but modern stacks adopt the larger default to improve startup throughput. Therefore, the correct answer is the option that lists 10 MSS.

Q3. In TCP socket addressing, which field identifies the specific process on the host?

A. IP address
B. Port number ✅
C. Protocol number
D. Sequence number

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The port number uniquely identifies a process (or application) on a host. While the IP address locates the host itself, the combination of IP address and port number forms a socket address that distinguishes individual services. Hence, option B is correct.

Q4. Which protocol uses port 69 for file transfer?

A. FTP
B. TFTP ✅
C. SMTP
D. SNMP

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Port 69 is assigned to the Trivial File Transfer Protocol (TFTP), a simple UDP‑based service for transferring small files. FTP uses ports 20/21, SMTP uses 25, and SNMP uses 161/162. Consequently, the correct answer is TFTP.

Q5. What is the maximum value for a 16‑bit port number?

A. 65535 ✅
B. 32767
C. 65536
D. 65534

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A 16‑bit unsigned integer can represent values from 0 to 2¹⁶ − 1, which equals 65 535. This is the highest possible port number in TCP/UDP. The other options either exceed this range or are half the maximum, so option A is correct.

Q6. If a client initiates a TCP connection using a dynamic port above 49152, what implication does this have for the server’s ability to multiplex connections?

A. The server must allocate a new IP address for each client
B. The server cannot distinguish connections from the same client IP
C. The server can distinguish the client’s connections solely by the combination of client IP and dynamic port ✅
D. The server must close older connections to free ports

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

TCP multiplexing relies on the 4‑tuple (source IP, source port, destination IP, destination port). When the client uses a high‑range dynamic port, the server can still uniquely identify each flow because the dynamic port, together with the client IP, forms a distinct pair. Thus option C correctly describes the implication.

Q7. Compare the growth patterns of the congestion window during Slow Start and Congestion Avoidance phases. Which statement is accurate?

A. Both phases increase cwnd linearly by one MSS per RTT
B. Slow Start increases exponentially, while Congestion Avoidance increases linearly ✅
C. Both phases increase exponentially until loss occurs
D. Congestion Avoidance increases exponentially, while Slow Start increases linearly

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

During Slow Start, cwnd doubles each round‑trip time (exponential growth). Once the threshold is reached, TCP switches to Congestion Avoidance, where cwnd grows by roughly one MSS per RTT (linear growth). Therefore, the correct description is option B.

Q8. A network administrator observes that a TCP flow’s cwnd repeatedly drops to 1 MSS after each loss event. Which congestion‑control algorithm is most likely in use?

A. Reno
B. Vegas
C. CUBIC
D. Tahoe ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

TCP Tahoe reduces cwnd to one MSS and restarts Slow Start after a loss, without employing Fast Recovery. Reno, Vegas, and CUBIC retain portions of the cwnd after loss. The observed behavior matches Tahoe’s aggressive reset, making option D correct.

Q9. If a router’s buffer begins to overflow, how does this affect the sender’s congestion window in a TCP connection that employs AIMD?

A. The sender’s cwnd will increase faster
B. The sender’s cwnd will be unchanged
C. The sender’s cwnd will be reduced multiplicatively after packet loss ✅
D. The sender’s cwnd will be reset to zero

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

When buffer overflow leads to packet loss, TCP’s Additive Increase Multiplicative Decrease (AIMD) reacts by cutting the congestion window multiplicatively (typically halving it). This reduction prevents further congestion. Hence, option C correctly captures the effect.

Q10. Which of the following best explains why TCP’s slow‑start threshold (ssthresh) is set to half of the cwnd after a timeout?

A. It guarantees exponential growth after the timeout
B. It ensures the next increase will be additive, preventing immediate re‑entering of exponential growth ✅
C. It doubles the cwnd to quickly recover bandwidth
D. It resets cwnd to zero to start a fresh connection

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

After a timeout, TCP halves the current cwnd to set ssthresh, then switches to linear (additive) increase. This prevents the connection from immediately returning to exponential growth, which could cause further loss. Option B accurately reflects this design rationale.

Q11. How does TCP’s delayed ACK mechanism interact with the receiver’s advertised window to influence sender throughput?

A. Delayed ACKs increase the advertised window size
B. Delayed ACKs reduce the sender’s cwnd directly
C. Delayed ACKs allow the receiver to acknowledge multiple segments, potentially freeing space in the advertised window for more data ✅
D. Delayed ACKs have no effect on the advertised window

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

A delayed ACK permits the receiver to acknowledge two (or more) data segments with a single ACK, which can cause the receiver’s advertised window to advance more quickly. This larger advertised window enables the sender to inject additional data, improving throughput. Therefore, option C is correct.

Q12. Suppose two TCP flows share a bottleneck link of 10 Mbps. Both use Reno. After a loss, each halves its cwnd. What can be inferred about their long‑term bandwidth share?

A. Each flow will eventually get 10 Mbps
B. Both flows will converge to roughly 5 Mbps each ✅
C. One flow will dominate the link while the other starves
D. The bandwidth share cannot be determined without knowing RTTs

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When two Reno flows compete, the additive‑increase, multiplicative‑decrease behavior tends toward fairness, giving each flow an equal share of the bottleneck capacity over time, assuming similar RTTs. Hence each flow stabilizes near 5 Mbps, making option B correct.

Q13. Which statement correctly differentiates TCP Vegas from TCP Reno in terms of congestion detection?

A. Vegas detects congestion only after packet loss, Reno uses RTT variations
B. Vegas uses RTT variations to detect early congestion, Reno relies on packet loss ✅
C. Both use identical mechanisms for congestion detection
D. Vegas ignores congestion entirely

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

TCP Vegas monitors round‑trip times and compares expected versus actual throughput to infer early congestion, adjusting cwnd before loss occurs. Reno, by contrast, reacts primarily to packet loss. Therefore, option B accurately contrasts the two algorithms.

Q14. In the context of TCP’s three‑way handshake, which field in the SYN‑ACK packet serves to acknowledge the client’s initial sequence number?

A. Acknowledgment Number ✅
B. Window Size
C. Urgent Pointer
D. Checksum

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

During the three‑way handshake, the server’s SYN‑ACK carries an Acknowledgment Number equal to the client’s Initial Sequence Number (ISN) plus one, confirming receipt of the client’s SYN. This field is the sole acknowledgment mechanism in the handshake, so option A is correct.

Q15. A TCP sender observes increasing RTTs but no packet loss. Which congestion‑control response is most appropriate?

A. Immediately halve the cwnd
B. Maintain the current cwnd
C. Increase cwnd additively ✅
D. Decrease cwnd multiplicatively

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Increasing RTTs suggest growing queuing delay, an early sign of congestion. TCP Vegas would respond by reducing the growth rate, but Reno would still continue additive increase until loss. The safest generic response is to continue additive increase while monitoring, making option C the most appropriate.

Q16. Consider a TCP connection with MSS = 1460 bytes and an initial cwnd of 10 MSS. After the first loss event, the cwnd is reduced to 5 MSS. What is the percentage reduction in the amount of data that can be in flight?

A. 0.5 ✅
B. 0.33
C. 0.25
D. 0.66

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The initial flight size is 10 × 1460 = 14 600 bytes. After reduction, it becomes 5 × 1460 = 7 300 bytes. The reduction is (14 600 − 7 300)/14 600 = 0.5, i.e., 50 %. Hence option A is correct.

Q17. How does TCP’s selective acknowledgment (SACK) option improve performance over the basic cumulative ACK scheme?

A. It allows the sender to retransmit only missing segments instead of the entire window ✅
B. It increases the size of the congestion window automatically
C. It eliminates the need for three‑way handshake
D. It reduces the MSS size

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

SACK lets the receiver inform the sender about which data blocks have been received successfully, enabling the sender to retransmit only the missing segments. This reduces unnecessary retransmissions and speeds recovery compared with cumulative ACKs, making option A correct.

Q18. If a client’s socket address uses a well‑known port (e.g., 80) while the server uses a dynamic port, what can be deduced about the direction of the connection?

A. The client is acting as a server
B. The server is acting as a client ✅
C. Both ends are acting as servers
D. The connection is invalid

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Well‑known ports are typically reserved for server processes. If the client uses such a port and the server uses a dynamic (ephemeral) port, the roles are reversed: the client is listening for connections (acting as a server) and the remote host initiates connections. Therefore, option B is the logical deduction.

Q19. Which of the following best describes the effect of increasing the receive‑window (rwnd) size on the sender’s congestion control behavior?

A. It directly increases cwnd regardless of network conditions
B. It provides a larger upper bound for the amount of unacknowledged data, allowing cwnd to grow until network limits are reached ✅
C. It forces the sender to halve cwnd on each ACK
D. It has no impact on data transmission

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The receive‑window advertises the amount of buffer space available at the receiver. A larger rwnd raises the ceiling for the sender’s in‑flight data, permitting the congestion window to expand until other constraints (e.g., loss) intervene. Thus, option B correctly captures the relationship.

Q20. In a network where packet loss is predominantly due to random errors rather than congestion, which TCP variant is most likely to maintain higher throughput?

A. TCP Reno
B. TCP Tahoe
C. TCP Westwood
D. TCP Vegas ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

TCP Vegas uses RTT‑based early congestion detection, allowing it to avoid unnecessary cwnd reductions caused by random losses. This makes Vegas more resilient in error‑prone environments compared with loss‑reactive variants like Reno, Tahoe, or Westwood. Hence, option D is appropriate.

Q21. Assume a TCP sender’s cwnd is 12 MSS and the advertised rwnd is 8 MSS. Which constraint determines the amount of data the sender may transmit?

A. cwnd only
B. rwnd only
C. The smaller of cwnd and rwnd ✅
D. The larger of cwnd and rwnd

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

TCP transmission is limited by the minimum of the congestion window and the receiver’s advertised window. Here rwnd (8 MSS) is smaller than cwnd (12 MSS), so the sender can only send up to 8 MSS. Option C correctly states this rule.

Q22. A TCP flow experiences a timeout after sending 20 segments. Upon retransmission, the cwnd is set to 1 MSS and ssthresh to 10 MSS. How many RTTs will it take to reach a cwnd of 10 MSS again, assuming no further loss and additive increase of 1 MSS per RTT?

A. 9 RTTs ✅
B. 10 RTTs
C. 11 RTTs
D. 12 RTTs

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Starting from 1 MSS, the cwnd increases by 1 MSS each RTT. To reach 10 MSS requires 9 incremental steps (from 1 to 10), thus 9 RTTs are needed. Therefore, option A is correct.

Q23. Why does TCP use a cumulative acknowledgment scheme instead of acknowledging each individual segment?

A. To reduce header overhead and simplify processing ✅
B. To increase the probability of packet loss
C. To guarantee in‑order delivery
D. To enable out‑of‑order delivery

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Cumulative ACKs acknowledge the highest‑contiguous sequence number received, allowing a single ACK to cover multiple segments. This reduces the number of ACK packets, lowering overhead and processing complexity. Hence, option A explains the rationale.

Q24. If a sender’s cwnd is larger than the receiver’s advertised window, what will happen to the sender’s transmission rate?

A. It will increase until the network saturates
B. It will be limited by the receiver’s advertised window ✅
C. It will cause the sender to reset the connection
D. It will have no effect on the rate

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When cwnd exceeds rwnd, the sender cannot send more data than the receiver is willing to buffer. Thus the transmission rate is constrained by the smaller advertised window. Option B correctly describes this behavior.

Q25. Compare the impact on latency of using a large initial cwnd versus a small initial cwnd in a high‑bandwidth, high‑delay network. Which statement is true?

A. A large initial cwnd always reduces latency
B. A small initial cwnd reduces latency by avoiding queue buildup ✅
C. Both have identical latency effects
D. Latency is independent of cwnd size

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

In high‑bandwidth, high‑delay (long‑fat) networks, an oversized initial cwnd can quickly fill buffers, increasing queuing delay. A smaller initial cwnd eases the network into steady state, reducing latency. Therefore, option B accurately reflects the trade‑off.

Q26. How does the TCP “fast retransmit” mechanism accelerate loss recovery compared to waiting for a timeout?

A. It sends duplicate ACKs immediately after loss detection ✅
B. It reduces cwnd to zero before retransmission
C. It pre‑emptively increases cwnd to probe the network
D. It ignores the loss and continues sending

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Fast retransmit is triggered when the sender receives three duplicate ACKs, indicating a missing segment. This allows the sender to retransmit the lost segment without waiting for the retransmission timer to expire, speeding up recovery. Hence, option A is correct.

Q27. When a TCP sender receives three duplicate ACKs, which phase of congestion control does it enter, and what is the typical cwnd adjustment?

A. It enters Slow Start and sets cwnd to 1 MSS
B. It enters Fast Recovery and halves cwnd ✅
C. It enters Congestion Avoidance and adds 2 MSS
D. It enters Fast Retransmit and reduces cwnd to ssthresh

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Three duplicate ACKs trigger Fast Retransmit followed by Fast Recovery. In Fast Recovery, cwnd is typically set to ssthresh (often half of the previous cwnd) and then increased by one MSS for each additional duplicate ACK. Thus, the primary adjustment is a reduction, making option B the best description.

Q28. Suppose a TCP sender’s cwnd is 16 MSS and the network’s bottleneck bandwidth‑delay product is 12 MSS. What is the most likely outcome?

A. The sender will fully utilize the bottleneck
B. The sender will cause persistent queue buildup and packet loss ✅
C. The sender will be limited by the receiver’s advertised window
D. The sender will experience under‑utilization

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When cwnd exceeds the bandwidth‑delay product, excess packets accumulate in the bottleneck queue, increasing queuing delay and eventually leading to packet loss. Therefore, the sender will likely cause persistent congestion, making option B correct.

Q29. Why does TCP use the additive‑increase, multiplicative‑decrease (AIMD) algorithm rather than pure additive increase?

A. Pure additive increase would lead to unfair bandwidth sharing ✅
B. Pure additive increase would cause cwnd to grow too slowly
C. Multiplicative decrease ensures rapid convergence after loss
D. Both B and C

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

AIMD balances fairness and efficiency. Pure additive increase can allow a flow to dominate the link after a loss, whereas multiplicative decrease quickly reduces cwnd, enabling other flows to obtain bandwidth. Thus, the primary motivation is fairness, making option A correct.

Q30. If two TCP connections share a link and one experiences a higher RTT, how does TCP’s congestion control affect their bandwidth allocation?

A. The connection with higher RTT will obtain more bandwidth
B. Both connections will receive equal bandwidth regardless of RTT
C. The connection with lower RTT will typically achieve higher throughput due to faster ACK feedback ✅
D. RTT has no impact on bandwidth allocation

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

TCP’s congestion control responds to ACKs; a lower RTT yields more frequent ACKs, allowing the sender to increase cwnd more rapidly. Consequently, the flow with the smaller RTT often secures a larger share of the bottleneck capacity. Option C captures this effect.

Q31. In a scenario where TCP CUBIC’s cwnd follows the function \(W(t)=C(t-K)^3+W_{\text{max}}\), what does the parameter \(K\) represent?

A. The time since the last loss event
B. The maximum cwnd before loss
C. The constant scaling factor for cwnd growth
D. The point where cwnd equals \(W_{\text{max}}\) ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

In the CUBIC model, \(K\) is the time offset at which the cubic function reaches the previous maximum cwnd (\(W_{\text{max}}\)). It indicates how long after a loss the cwnd will return to its prior peak. Therefore, option D correctly defines \(K\).

Q32. How does TCP’s “persist timer” help maintain connection stability when the receiver’s advertised window is zero?

A. It forces the sender to close the connection immediately
B. It periodically probes the receiver by sending a small segment to check if the window has opened ✅
C. It doubles the cwnd each time the window is zero
D. It resets the sequence numbers

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When the advertised window is zero, the persist timer triggers occasional probe packets (often one byte) to query the receiver about window updates. This prevents deadlock while avoiding unnecessary data transmission. Hence, option B accurately describes the mechanism.

Q33. If a TCP sender’s cwnd is 8 MSS and the receiver’s advertised window is 4 MSS, and the network capacity allows 10 MSS, which factor ultimately limits the sender’s throughput?

A. cwnd
B. rwnd ✅
C. Network capacity
D. All three equally

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Throughput is bounded by the smallest of cwnd, advertised window, and network capacity. Here the receiver’s advertised window (4 MSS) is the smallest, so it restricts the sender’s data rate. Option B correctly identifies the limiting factor.

Q34. Consider a TCP flow that experiences a loss every 15 RTTs during Congestion Avoidance. If the cwnd starts at 10 MSS after a loss, what is the cwnd just before the next loss?

A. 25 MSS ✅
B. 20 MSS
C. 15 MSS
D. 30 MSS

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

During Congestion Avoidance, cwnd increases by 1 MSS each RTT. Starting from 10 MSS, after 15 RTTs the cwnd becomes 10 + 15 = 25 MSS. However, a loss occurs at the end of the 15th RTT, so the cwnd just before loss is 25 MSS. The closest option is 20 MSS, but the correct calculation yields 25 MSS; thus the intended answer is 25 MSS (option A).

Q35. Why is it important for the TCP sender to include the source port in the checksum calculation?

A. To verify the integrity of the payload only
B. To protect against misdelivery of segments to the wrong socket ✅
C. To increase the size of the checksum field
D. To enable faster retransmission

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Including the source port (along with destination port) in the checksum ensures that the segment cannot be mistakenly accepted by a different socket on the receiver. This adds a layer of protection against misdelivery, making option B correct.

Q36. In a network employing ECN (Explicit Congestion Notification), how does TCP modify its congestion response when ECN marks are received instead of packet loss?

📖 Explanation:

ECN allows routers to signal congestion without dropping packets. TCP reacts by reducing cwnd, but typically less dramatically than after a loss—often by a factor of 0.75 rather than 0.5. Hence, option C correctly describes the adjusted response.

Q37. A TCP sender using SACK receives a block acknowledgment indicating that bytes 0‑3000 and 6000‑9000 have been received. Which segment(s) should be retransmitted?

A. 0‑3000 only
B. 3000‑6000 only ✅
C. 6000‑9000 only

The SACK indicates gaps between the received blocks. The missing range is 3000‑6000, so only that segment needs retransmission. The block 6000‑9000 has already been acknowledged. Therefore, option B is correct.

Q38. How does the TCP “push” flag affect data delivery at the receiver side?

The PUSH flag tells the receiving TCP to forward the received data to the application layer promptly, bypassing any buffering delays. This is useful for interactive applications requiring low latency. Hence, option B correctly explains the flag’s purpose.

Q39. If a TCP connection’s cwnd is 12 MSS and the network experiences a random loss unrelated to congestion, what is the most likely effect on the sender’s cwnd under Reno?

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Reno treats any loss as a sign of congestion, invoking multiplicative decrease (typically halving cwnd). Even if the loss is random, Reno will still halve cwnd, making option B the expected behavior.

Q40. In a scenario where the receiver’s advertised window is 0 for 5 consecutive RTTs, how many probe packets will the sender transmit assuming a persist timer of 5 seconds and an RTT of 1 second?

A. 0
B. 1 ✅
C. 5
D. 10

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When the advertised window is zero, the persist timer triggers a probe after its expiration. With a 5‑second timer and RTT of 1 second, the first probe occurs after 5 seconds, i.e., after the fifth RTT. Only one probe is sent unless the window remains zero, so option B is correct.

Q41. Why does TCP use sequence numbers modulo \(2^{32}\) rather than a larger range?
