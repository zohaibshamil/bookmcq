What is Generic and country domains in DNS?

Generic top-level domains like .com, .org, and .edu categorize websites by purpose or organization type, while country-code top-level domains like .uk, .jp, and .ca identify geographic regions, together forming the first level of DNS hierarchy below the root.

Q1. If a recursive resolver receives a DNS response with a TTL of 0 seconds, what is the most likely effect on subsequent queries for the same domain name?

A. The resolver will cache the record indefinitely.
B. The resolver will discard the record immediately and query again. ✅
C. The resolver will treat the record as a negative cache entry for 5 minutes.
D. The resolver will ignore the TTL and use its default caching time.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A TTL of 0 signals that the data is no longer valid; the resolver must purge it from its cache right away. Consequently, any later request for that name will trigger a fresh lookup to an authoritative server, ensuring up‑to‑date information.

Q2. When a DNSSEC‑signed response fails validation, what response does the resolver typically return to the client?

A. The resolver retries the query without DNSSEC validation.
B. The resolver falls back to an insecure DNS query.
C. The resolver returns a SERVFAIL error to the client. ✅
D. The resolver returns an NXDOMAIN error to the client.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

DNSSEC validation ensures cryptographic integrity. If the signature cannot be verified, the resolver treats the data as suspicious and, per RFC 4035, returns a SERVFAIL to indicate a server‑side failure rather than fabricating an answer. This prevents the client from accepting potentially forged records while preserving the distinction from a true non‑existence response (NXDOMAIN).

Q3. An iterative resolver receives referrals from the root, then from the .com TLD, and finally from the authoritative server for example.com. If the total number of hops is denoted by \( n \), which statement best describes the relationship between \( n \) and query latency?

A. Latency grows linearly with \( n \) because each hop adds a fixed processing delay.
B. Latency grows exponentially with \( n \) due to recursive lookups at each step.
C. Latency is independent of \( n \) because all servers respond simultaneously.
D. Latency decreases as \( n \) increases because later servers are closer to the client. ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

In an iterative resolution, each hop is performed sequentially: the resolver contacts the root, then the TLD, then the authoritative server. Because each step adds network round‑trip time, the total latency is roughly the sum of the individual delays, so more hops increase latency rather than decrease it. The only way latency could drop is if later servers happen to be geographically nearer, which is not guaranteed.

Q4. Which of the following best contrasts recursive and iterative DNS queries?

A. Recursive resolvers complete the entire lookup on behalf of the client, while iterative resolvers provide referrals to the next server. ✅
B. Iterative resolvers cache all answers, whereas recursive resolvers never cache results.
C. Recursive queries are only used for IPv6, while iterative queries are used for IPv4.
D. Iterative queries always return a CNAME record, while recursive queries never do.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A recursive resolver takes full responsibility for resolving the name, contacting root, TLD, and authoritative servers as needed, then returns the final answer to the client. In contrast, an iterative resolver returns the best information it currently has (often a referral) and expects the client or another resolver to continue the process. This fundamental distinction defines their behavior.

Q5. A large web service distributes its traffic using DNS round‑robin across four IP addresses. How does this load‑balancing method most likely affect average client latency?

A. It guarantees lower latency for every client.
B. It reduces average latency but may increase variance among clients. ✅
C. It increases average latency because of additional DNS lookups.
D. It has no impact on latency because DNS does not affect network paths.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Round‑robin DNS returns one of several IP addresses in a rotating fashion, which can direct clients to different server instances. While some clients may be routed to a nearby server, others might reach a more distant one, so the overall average latency tends to drop, yet the spread (variance) of latency values grows due to the nondeterministic assignment.

Q6. Which statement correctly distinguishes caching behavior between a stub resolver and a recursive resolver?

A. Stub resolvers cache only positive answers, while recursive resolvers cache only negative answers.
B. Stub resolvers cache both positive and negative answers, but recursive resolvers cache only positive answers.
C. Stub resolvers typically cache only negative responses, whereas recursive resolvers cache both positive and negative records. ✅
D. Both stub and recursive resolvers cache only TTL‑expired records.

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Stub resolvers, often part of the operating system, minimally cache negative responses (e.g., NXDOMAIN) to avoid repeated futile queries. Recursive resolvers, which perform full resolution, maintain caches for both successful (positive) and unsuccessful (negative) answers, respecting each record’s TTL. This distinction influences how quickly repeated queries can be answered locally.

Q7. When a client requests the address for www.example.com, which sequence of DNS zones is consulted according to the hierarchical model?

A. Root → .org → example.com → www
B. Root → .com → example.com → www ✅
C. Root → .net → example.com → www
D. Root → .edu → example.com → www

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The DNS hierarchy starts at the root zone, which delegates control of top‑level domains. For www.example.com, the resolver first contacts the root server, receives a referral to the .com TLD servers, then queries those for the example.com zone, and finally obtains the www host record from the authoritative server for example.com.

Q8. A DNS query for mail.example.org encounters a CNAME pointing to mailhost.example.net, followed by an MX record for mailhost.example.net. Which ordered steps correctly describe the resolver’s actions?

A. Resolve CNAME → Retrieve MX → Resolve MX target → Return A record
B. Resolve MX → Resolve CNAME → Retrieve A record → Return MX
C. Retrieve MX → Resolve CNAME → Resolve MX target → Return A record
D. Resolve CNAME → Resolve MX target → Retrieve MX → Return MX ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The resolver first follows the CNAME to mailhost.example.net, then looks up the MX record for that canonical name. After obtaining the MX, it resolves the target host’s A (or AAAA) record to obtain the actual IP address. The final answer returned to the client includes the MX record and its associated address.

Q9. How does the Time‑to‑Live (TTL) value of a DNS record influence consistency during a zone transfer between primary and secondary name servers?

A. A shorter TTL forces secondary servers to refresh more frequently, improving consistency. ✅
B. TTL has no impact on zone transfers because they use separate protocols.
C. A longer TTL reduces the need for zone transfers, causing stale data on secondaries.
D. TTL determines the number of secondary servers that can cache the record.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

TTL defines how long a cached record is considered valid. When a primary server updates a zone, secondary servers must fetch the new data. A short TTL means caches expire quickly, prompting secondary servers to perform zone transfers more often, thereby keeping their copies more consistent with the primary. Longer TTLs delay updates, increasing the risk of stale information.

Q10. Which of the following best defines an authoritative name server?

A. A server that only forwards queries to other servers without storing any records.
B. A server that holds the definitive DNS records for a zone and can answer queries about that zone without recursion.
C. A server that caches responses from other servers for faster lookup. ✅
D. A server that encrypts DNS traffic using TLS.

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

An authoritative name server is the source of truth for a particular DNS zone; it stores the zone’s actual records and can respond directly to queries about those records without needing to query any other server. This contrasts with caching or recursive resolvers, which may rely on other servers to obtain the data.

Q11. When a client issues a DNS query over IPv6 instead of IPv4, what is the most likely effect on the resolution process?

A. The client receives both A and AAAA records simultaneously regardless of query type.
B. The resolver must contact separate root servers for IPv6, potentially adding an extra hop.
C. The query is routed through a NAT device, causing additional delay.
D. There is no difference; DNS operates identically for both address families. ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

DNS itself is agnostic to the underlying IP version; the same logical steps are followed whether the query travels over IPv4 or IPv6. The only variation is the transport protocol (UDP/TCP) and the address family of the servers involved, but the resolution algorithm and number of hops remain unchanged.

Q12. Deploying DNS‑over‑HTTPS (DoH) primarily impacts which aspect of user privacy?

A. It hides the queried domain names from the ISP but does not affect the DNS server’s view.
B. It prevents the DNS server from seeing the query content, encrypting it end‑to‑end.
C. It obscures DNS traffic from network observers, reducing visibility to third parties, while the resolver still sees the domain name. ✅
D. It eliminates the need for caching, thereby improving privacy.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

DoH encapsulates DNS queries inside HTTPS, encrypting the payload and making it indistinguishable from regular web traffic to external observers. While the resolver still receives the plaintext domain name (so it can answer the query), eavesdroppers such as ISPs or Wi‑Fi providers cannot easily infer which domains are being looked up, enhancing privacy.
