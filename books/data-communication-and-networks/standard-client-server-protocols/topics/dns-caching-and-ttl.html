Q1. If a CPU accesses an address that is not present in the L1 cache, which of the following is the most immediate consequence?

🔹 A. The CPU stalls while fetching the line from the L2 cache.
🔹 B. The data is written to main memory.
🔹 C. The cache line is evicted from L1.
🔹 D. The address is stored in the TLB.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

When a requested address is absent from L1, the processor cannot supply the data and must retrieve the missing cache line from the next level, typically L2. This fetch introduces a stall while the line is transferred, after which the line is placed in L1 and the instruction can resume. No write‑back or TLB update occurs at this point.

Q2. Given a system with a write-back cache, which inference can be drawn when a dirty cache line is evicted?

🔹 A. The line is discarded without memory update
🔹 B. The line is copied to L2 cache only
🔹 C. The line triggers a cache coherence protocol
🔹 D. The line is written to main memory

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

In a write‑back cache, modified (dirty) lines are kept in the cache until they are evicted. Upon eviction, the dirty line must be written back to main memory to preserve the latest data state. The write‑back occurs before the line is discarded, ensuring memory coherence. No additional copy to L2 is required if the line already resides there.

Q3. Suppose a processor's cache line size is increased from 32 bytes to 128 bytes while keeping the total cache size constant. Deduce the effect on the cache's miss rate for a workload with high spatial locality.

🔹 A. Miss rate slightly increases
🔹 B. Miss rate remains unchanged
🔹 C. Miss rate significantly decreases
🔹 D. Miss rate may increase due to higher conflict misses

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Expanding the cache line from \(32\) bytes to \(128\) bytes while keeping total cache capacity fixed reduces the number of lines, but each line now contains more contiguous bytes. For workloads exhibiting high spatial locality, successive accesses often fall within the same enlarged line, turning many potential misses into hits. Consequently, the overall miss rate tends to drop significantly.

Q4. Which statement best contrasts direct-mapped and 4-way set-associative caches?

🔹 A. Direct-mapped caches have larger line sizes than set-associative
🔹 B. Set-associative caches suffer more conflict misses
🔹 C. Direct-mapped uses a replacement policy while set-associative does not
🔹 D. Set-associative caches reduce conflict misses compared to direct-mapped

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

In a direct‑mapped cache each memory block maps to exactly one line, so different blocks that map to the same line compete, causing conflict misses. A 4‑way set‑associative cache allows four blocks to occupy the same set, providing flexibility in placement and dramatically lowering conflict misses, which improves the hit rate compared with a direct‑mapped design.

Q5. Evaluating write-through vs. write-back policies, which scenario favors write-back?

🔹 A. Workloads with frequent writes and low read frequency
🔹 B. Workloads with read‑most operations
🔹 C. Systems where data consistency across cores is critical
🔹 D. Environments with limited main memory bandwidth

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Write‑back caches defer writing modified data to main memory until eviction, reducing the number of write traffic operations. This is advantageous for workloads that perform many writes because each write updates only the cache line, avoiding repeated memory writes. Read‑heavy or coherence‑critical scenarios usually prefer write‑through to keep memory consistent.

Q6. Differentiate the impact of LRU and FIFO replacement policies on temporal locality. Which statement is true?

🔹 A. FIFO better preserves temporal locality than LRU
🔹 B. LRU better preserves temporal locality than FIFO
🔹 C. Both policies have identical effect on temporal locality
🔹 D. FIFO always results in fewer cache misses than LRU

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Temporal locality means recently accessed data is likely to be reused soon. LRU replaces the least recently used line, directly preserving recently accessed items, thus better exploiting temporal locality. FIFO discards the oldest line regardless of recent accesses, which can evict still‑useful data, leading to higher miss rates when temporal locality is strong.

Q7. Apply the LRU principle: In a 3‑way set-associative cache, after accessing blocks X, Y, Z, and then X again, which block becomes the candidate for replacement on the next miss?

🔹 A. Y
🔹 B. X
🔹 C. Z
🔹 D. None, need to be loaded

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

In a 3‑way set‑associative cache, the three blocks X, Y, and Z occupy the set. Accessing X again updates its recency, making Y the least recently used block. When the next miss occurs, the replacement policy will select Y for eviction because it has not been referenced since the earlier accesses, preserving X and Z.

Q8. Synthesize a caching strategy for a web server that serves both static images and dynamic API responses. Which combination best balances latency and freshness?

🔹 A. Cache all content with long TTL
🔹 B. Do not cache any content
🔹 C. Cache dynamic responses only
🔹 D. Cache static images with long TTL and dynamic responses with short TTL

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Static images change rarely, so assigning them a long time‑to‑live (TTL) maximizes cache hits and reduces server load. Dynamic API responses often contain fresh data; a short TTL ensures clients receive up‑to‑date information while still benefiting from brief caching for repeated calls. This mixed approach balances low latency for static content with data freshness for dynamic content.

Q9. Explain the relationship between a multi‑level cache hierarchy and effective memory bandwidth. Which statement is accurate?

🔹 A. Adding more cache levels always reduces bandwidth
🔹 B. Higher‑level caches increase perceived bandwidth by reducing miss penalties
🔹 C. Bandwidth is independent of cache hierarchy
🔹 D. Only L1 cache affects bandwidth

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Effective memory bandwidth perceived by the CPU is the rate at which data can be supplied for execution. Higher‑level caches (L2, L3) act as buffers that capture a large fraction of accesses, shortening the average memory access time and effectively increasing bandwidth. Adding well‑designed cache levels reduces miss penalties, which improves overall throughput.

Q10. What term describes the smallest unit of data that can be transferred between main memory and cache?

🔹 A. Page
🔹 B. Block
🔹 C. Segment
🔹 D. Cache line

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

A cache line, also called a cache block, is the smallest contiguous chunk of memory that can be transferred between main memory and the cache in a single operation. All caches are organized around lines; when a miss occurs, the entire line containing the requested address is fetched and stored, enabling spatial locality exploitation.
