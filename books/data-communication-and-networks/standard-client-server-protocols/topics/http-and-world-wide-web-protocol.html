📝 All HTTP and World Wide Web protocol MCQs

Q1. If a web page contains a hyperlink to another page on a different server, what is the most direct effect on the user’s request?

🔹 A. Browser sends a DNS query to resolve the original site’s address
🔹 B. The original server redirects the request to the target server
🔹 C. Browser initiates a new HTTP request to the target server
🔹 D. No network activity occurs

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

When the user clicks the link, the browser must locate the target resource. It does this by creating a new HTTP request directed at the server that hosts the linked page, using the URL provided. This request is independent of the original page’s connection, so the correct effect is a new HTTP request to the target server.

Q2. Which of the following best compares the GET and POST methods when a web form includes a file upload?

🔹 A. GET appends form data to the URL, making it unsuitable for large binary files, while POST includes data in the request body, allowing file uploads.
🔹 B. GET encrypts the file data, whereas POST sends it in plain text.
🔹 C. GET can only be used for retrieving resources, not for submitting any form data.
🔹 D. POST always results in a cached response, while GET never does.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

GET places all form data in the query string of the URL, which is limited in length and visible to observers, so it cannot reliably carry large binary files. POST places the data in the request body, supporting arbitrarily large payloads and keeping the URL clean, making it the appropriate method for file uploads.

Q3. HTTP is described as a stateless protocol. Which mechanism most effectively allows a web application to maintain a user’s login state across multiple requests?

🔹 A. Using cookies with session identifiers
🔹 B. Embedding user credentials in every URL
🔹 C. Relying on the client’s IP address
🔹 D. Keeping a persistent TCP connection

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Because HTTP does not retain information between requests, the server issues a cookie containing a unique session identifier. The browser returns this cookie with each subsequent request, allowing the server to associate the request with the previously authenticated session. This approach preserves login state without violating HTTP’s stateless nature.

Q4. What does the acronym URL stand for?

🔹 A. Uniform Resource Locator
🔹 B. Universal Retrieval Link
🔹 C. Unified Resource List
🔹 D. Unique Reference Link

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The term URL is a standard abbreviation in web technology that means Uniform Resource Locator. It specifies the address used to access a resource on the Internet, indicating the protocol, host, and path needed to retrieve the resource.

Q5. A browser has cached a resource with ETag \abc123\. The server later updates the resource. The browser sends a conditional GET with If-None-Match \abc123\. What is the most likely server response?

🔹 A. Server returns 200 OK with new content
🔹 B. Server returns 304 Not Modified
🔹 C. Server returns 404 Not Found
🔹 D. Server returns 500 Internal Server Error

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When the server detects that the ETag supplied by the client does not match the current version of the resource, it knows the cached copy is stale. Consequently, it sends a fresh representation with a 200 OK status, providing the updated content to the browser.

Q6. Which statement best explains why HTTPS provides better security than HTTP?

🔹 A. HTTPS uses larger packet sizes
🔹 B. HTTPS encrypts the payload using TLS, ensuring confidentiality and integrity
🔹 C. HTTPS disables caching
🔹 D. HTTPS forces browsers to use IPv6

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

HTTPS adds a TLS (or SSL) layer on top of HTTP, encrypting the entire request and response payload. This encryption protects data from eavesdropping, while TLS also provides authentication of the server and integrity checks, preventing tampering and man‑in‑the‑middle attacks.

Q7. In HTTP/1.1 persistent connections, which sequence correctly describes a client retrieving two resources from the same server without closing the connection?

🔹 A. Open connection → GET resource1 → Close → Open new → GET resource2 → Close
🔹 B. Open connection → GET resource1 → GET resource2 → Close
🔹 C. Open connection → GET resource1 → Wait for server to close → GET resource2
🔹 D. Open connection → POST resource1 → GET resource2 → Close

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

HTTP/1.1 allows a single TCP connection to stay open for multiple requests. After establishing the connection, the client can issue a GET for the first resource, immediately follow it with a second GET for the next resource, and finally close the socket when all transfers are complete.

Q8. How does hypermedia extend the concept of hypertext in the modern Web?

🔹 A. Hypermedia includes text, images, audio, and video as linked resources
🔹 B. Hypermedia restricts links to only textual content
🔹 C. Hypermedia eliminates the need for URLs
🔹 D. Hypermedia requires proprietary browsers to function

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Originally, hypertext referred only to linked textual documents. Modern hypermedia expands this idea by allowing any type of media—pictures, sound, video, and interactive content—to be linked and retrieved via hyperlinks. This broader definition reflects the diverse nature of contemporary web pages, which often combine multiple media types in a single navigable experience.
