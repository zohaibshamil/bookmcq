What is Is FTP secure or insecure protocol?

Traditional FTP is considered insecure because it transmits usernames, passwords, and file contents in plain text without encryption, making it vulnerable to eavesdropping, which is why secure alternatives like SFTP or FTPS are recommended.

Q1. If an FTP server is switched from plain FTP to explicit FTPS, what is the most direct effect on the data transferred between client and server?

A.Only the login credentials are encrypted
B.All data remains unencrypted but the control channel is secured
C.Encryption is optional and must be negotiated per file
D.Both control and data channels become encrypted after AUTH TLS ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Explicit FTPS requires the client to issue the AUTH TLS command, after which the server negotiates TLS for both the control and subsequent data connections. Consequently, all traffic, including file contents, is protected by encryption, unlike plain FTP where data travels in clear text.

Q2. An organization enables anonymous FTP access but sets the upload directory permissions to read‑only for the anonymous user. What can be logically inferred about the risk of malicious file upload?

A.The risk is eliminated because the user cannot write
B.The risk is reduced but a attacker could still exploit directory traversal to overwrite existing files ✅
C.The risk remains unchanged because read‑only does not affect upload
D.The risk shifts to client‑side attacks only
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Even though the anonymous account cannot directly write new files, a malicious actor may use directory‑traversal techniques or exploit misconfigurations to target existing writable files. Therefore, the overall risk is lowered but not completely removed, and additional safeguards such as monitoring and strict path validation remain necessary.

Q3. When an FTP client uses active mode behind a NAT device, the server initiates the data connection to the client’s external IP address. Which chain of events most likely leads to a data‑exposure vulnerability?

A.The NAT rewrites the IP, causing the server to connect to a wrong host
B.The firewall blocks the connection, preventing any data transfer
C.The server connects to the NAT’s public address, and the NAT forwards the data to the internal client, exposing the transmission if the channel is unencrypted ✅
D.The client switches to passive mode automatically
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: In active mode, the server attempts to open a data connection to the client’s public address. The NAT translates this to the internal host, allowing the connection to succeed. If the FTP session is not encrypted, the data traverses the NAT in clear text, giving any eavesdropper on the path the opportunity to capture sensitive information.

Q4. Which statement correctly differentiates implicit FTPS from explicit FTPS?

A.Implicit FTPS always starts TLS negotiation on connection, while explicit FTPS begins in clear text and upgrades with AUTH TLS ✅
B.Implicit FTPS uses port 21, explicit FTPS uses port 990
C.Implicit FTPS requires client certificates, explicit FTPS does not
D.Implicit FTPS only encrypts the control channel
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Implicit FTPS expects the TLS handshake immediately after the TCP connection is established, typically on port 990, and all subsequent communication is encrypted. Explicit FTPS, by contrast, begins with an unencrypted session on the standard FTP port (21) and the client explicitly requests encryption using the AUTH TLS command before any sensitive data is exchanged.

Q5. Considering authentication mechanisms, encryption strength, and firewall friendliness, which assessment best compares SFTP and FTPS?

A.SFTP uses SSH for encryption and authentication, typically requiring only one port, which simplifies firewall rules, while FTPS relies on TLS and may need multiple ports for data connections, complicating firewall configuration. ✅
B.FTPS encrypts data using TLS but often requires opening a range of ports for passive mode, making it harder to secure compared to SFTP’s single‑port approach.
C.Both SFTP and FTPS provide identical security levels, differing only in the underlying protocol.
D.SFTP cannot provide authentication beyond password, whereas FTPS supports client certificates.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: SFTP runs over the SSH protocol on a single, well‑known port (22), making it easier to permit through firewalls while still providing strong encryption and robust authentication. FTPS, which relies on TLS, often uses separate ports for control and passive data connections, requiring a broader port range to be opened, increasing the potential attack surface.

Q6. When upgrading an FTP server from TLS 1.0 to TLS 1.2, which of the following statements most accurately describes the security impact?

A.TLS 1.2 provides no practical security benefit over TLS 1.0 for FTP
B.TLS 1.2 introduces stronger cipher suites and eliminates known downgrade attacks, significantly improving confidentiality and integrity ✅
C.TLS 1.2 forces the use of legacy ciphers, reducing security
D.TLS 1.2 only affects the handshake speed, not the encryption strength
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: TLS 1.2 supports modern cipher suites such as AES‑GCM and provides forward secrecy, while also addressing vulnerabilities like POODLE and BEAST that affect older versions. Upgrading eliminates these weaknesses, ensuring that both control and data streams are protected with up‑to‑date cryptographic algorithms.

Q7. Applying the principle of least privilege to FTP user accounts, which configuration best satisfies this principle?

A.Grant every user read, write, and delete rights on all directories
B.Allow anonymous users full access to the root directory
C.Create individual accounts with read‑only access to only the directories they need ✅
D.Give all users admin rights on the FTP server
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The principle of least privilege dictates that users receive only the permissions necessary to perform their tasks. By assigning each account a read‑only role limited to specific directories, the organization reduces the chance that a compromised credential can be used to modify or delete critical files.

Q8. How do firewall rules interact with passive FTP data ports to maintain secure connections?

A.The firewall must allow inbound connections on the range of ports advertised by the server in response to PASV, otherwise data transfer fails ✅
B.Passive FTP does not require any firewall changes because all traffic is outbound
C.Firewalls block passive FTP entirely, forcing active mode
D.Port 21 is the only port needed for passive FTP
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: In passive mode, the FTP server tells the client which high‑number ports it will listen on for data connections. The firewall therefore needs to permit inbound traffic to those ports; otherwise the client cannot establish the data channel, causing the transfer to fail or be forced into an insecure mode.

Q9. Design a secure FTP deployment that integrates authentication, encryption, and logging. Which of the following plans best synthesizes these requirements?

A.Use anonymous FTP, enable TLS, and ignore logs to reduce overhead
B.Configure user‑specific accounts, enforce explicit FTPS, require strong password policies, and enable detailed audit logging of all commands and transfers ✅
C.Deploy only SFTP without any logging, relying on SSH security
D.Enable plain FTP with IP‑based access control and periodic manual log reviews
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A robust deployment creates individual credentials for each user, mandates explicit FTPS so that encryption is started only after authentication, enforces complex password rules, and records every command and file transfer in immutable logs. This combination ensures accountability, confidentiality, and the ability to detect anomalous activity.

Q10. What is an FTP bounce attack?

A.A technique where the attacker uses FTP to bounce traffic through a third‑party server to hide their source IP
B.An attack that exploits the FTP PORT command to cause the server to connect to arbitrary ports on other hosts ✅
C.A denial‑of‑service method that floods the FTP server with login attempts
D.A method of encrypting FTP data using a bounce buffer
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The FTP bounce attack abuses the PORT command, which tells the server to open a data connection to a user‑specified IP and port. By supplying arbitrary target addresses, an attacker can induce the FTP server to connect to and potentially interact with services on other machines, facilitating port scanning or proxying attacks.
