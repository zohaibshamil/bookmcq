What is FTP control and data connection?

FTP uses two distinct TCP connections where the control connection on port 21 handles commands and responses while a separate data connection on port 20 or a dynamic port is opened only when actual file transfer or directory listing occurs.

Q1. If a peer-to-peer service first uses a lightweight client‑server request to locate a peer’s address and that request fails, what is the most likely immediate outcome for the user?

A.The service automatically retries the peer discovery indefinitely.
B.The user receives an error indicating the service cannot be reached. ✅
C.The system switches to a centralized server without user notification.
D.The application continues using cached data from a previous session.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When the discovery step fails, the client cannot determine which peer holds the desired resource. Without an address, the application cannot initiate the peer‑to‑peer transfer, so it must inform the user of the failure. This error feedback is the typical immediate response, rather than silent retries or fallback to a server.

Q2. Because security is a major challenge in pure peer‑to‑peer architectures, which inference best explains why distributed services are harder to secure than centralized ones?

A.Distributed nodes lack a single point of control, making policy enforcement inconsistent.
B.Each peer must manage its own encryption keys, increasing the chance of misconfiguration.
C.Attack surfaces multiply as every participating node can be a potential entry point. ✅
D.Centralized servers can easily update security patches across all users.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: In a pure P2P system, every participant acts as both client and server, expanding the attack surface. Each node may have varying security postures, and an adversary can target any of them. Centralized architectures limit exposure to a few managed servers, allowing uniform security updates and monitoring, which simplifies protection.

Q3. When a mixed paradigm combines client‑server discovery with peer‑to‑peer data transfer, what is the most likely effect on overall network traffic compared to a pure client‑server model?

A.Traffic remains roughly the same because discovery adds negligible load.
B.Traffic increases significantly due to duplicated data paths.
C.Traffic decreases because most data bypasses the central server after discovery.
D.Traffic fluctuates unpredictably, making it impossible to compare. ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: The mixed approach introduces an initial client‑server exchange to locate peers, then shifts the bulk of data to direct peer connections. While the discovery step adds a small overhead, the overall traffic pattern becomes more variable: some sessions may see large savings, others may still involve substantial server traffic, depending on peer availability.

Q4. Which statement best compares the scalability of pure peer‑to‑peer systems with traditional client‑server architectures?

A.Peer‑to‑peer scales linearly with the number of participants, while client‑server scales poorly as users increase. ✅
B.Both models scale equally because bandwidth is the limiting factor.
C.Client‑server scales better because central servers can be upgraded faster than adding peers.
D.Peer‑to‑peer cannot scale beyond a few hundred nodes due to coordination overhead.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: In a P2P network, each new participant contributes resources, so the system’s capacity grows roughly in proportion to the number of peers. Conversely, a client‑server model relies on a fixed set of servers; as more clients connect, the servers become bottlenecks unless additional infrastructure is provisioned, making scalability less natural.

Q5. Why is BitTorrent generally more cost‑effective than traditional server‑hosted file distribution?

A.It uses compression to reduce file size before transmission.
B.It distributes the hosting load among many peers, reducing the need for expensive central servers.
C.It requires fewer network hops, saving on bandwidth costs. ✅
D.It operates only during off‑peak hours, lowering electricity usage.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: BitTorrent splits files into small pieces and exchanges them among peers, meaning each participant both downloads and uploads. This shared responsibility dramatically cuts the bandwidth that a single server would otherwise need to provide, lowering operational expenses while still delivering the file efficiently to many users.

Q6. How do security implications differ between a pure peer‑to‑peer model and a mixed client‑server/peer‑to‑peer paradigm?

A.Pure P2P offers built‑in encryption, eliminating security concerns.
B.Mixed models inherit the strongest security guarantees of both architectures without trade‑offs. ✅
C.Pure P2P must rely on each node’s security, increasing vulnerability, whereas the mixed approach can use a trusted server for authentication before peer exchange.
D.Both models have identical security profiles because data ultimately travels between the same endpoints.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: In a pure P2P system, every node is responsible for its own security measures, creating inconsistent protection levels. A mixed paradigm can centralize critical functions such as authentication and key distribution on a trusted server, while still leveraging P2P for data transfer, thereby improving overall security while preserving decentralization benefits.

Q7. Applying the principle of minimizing latency, which design choice best supports a hybrid file‑sharing system?

A.Route all traffic through a central server to guarantee consistent paths.
B.Select the nearest peer based on network‑level metrics after initial discovery.
C.Cache files locally on each client regardless of demand.
D.Use a round‑robin scheduler to distribute requests evenly among peers. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A round‑robin scheduler balances load across multiple peers, preventing any single node from becoming a bottleneck. By distributing requests evenly, the system reduces the chance that a user will experience high latency due to an overloaded peer, thereby improving overall responsiveness while still benefiting from peer‑to‑peer distribution.

Q8. To improve security in peer‑to‑peer internet telephony without sacrificing decentralization, which mechanism is most effective?

A.Introduce a lightweight, decentralized public‑key infrastructure that peers use to verify each other's identities. ✅
B.Require all peers to connect through a single trusted gateway for encryption.
C.Replace peer communication with a fully centralized VoIP service.
D.Disable encryption to simplify the protocol and avoid key management issues.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A decentralized public‑key infrastructure (PKI) allows each participant to generate and share cryptographic keys without a central authority. Peers can then authenticate one another and establish encrypted channels, preserving the peer‑to‑peer nature while mitigating eavesdropping and impersonation risks.
