Q1. What is the purpose of the function \( \text{htons}() \) when setting the server port in the code snippet?

🔹 A. It encrypts the port number for security.
🔹 B. It converts the port number from host byte order to network byte order.
🔹 C. It validates that the port number is within the allowed range.
🔹 D. It initializes the socket descriptor.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The htons function converts a 16‑bit port number from the host's native byte order to network byte order (big‑endian). Network protocols expect values in this standardized format, so without the conversion the server may interpret an incorrect port, preventing successful communication. Therefore option B correctly describes its purpose.

Q4. How does an echo service implemented with UDP differ from one implemented with TCP in terms of reliability and ordering?

🔹 A. UDP guarantees ordered delivery, while TCP does not.
🔹 B. Both protocols guarantee delivery, but only TCP provides encryption.
🔹 C. TCP ensures reliable, ordered delivery; UDP does not guarantee either.
🔹 D. UDP provides flow control, whereas TCP lacks it.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

TCP establishes a virtual circuit, ensuring that data arrives intact, in order, and without duplication, while UDP transmits independent datagrams without such guarantees. An echo service over TCP can rely on reliable, ordered delivery, whereas a UDP‑based echo may lose or reorder packets, so option C correctly captures this distinction.

Q5. Why is it important to call \( \text{perror}() \) followed by \( \text{exit}(1) \) after a socket creation failure, rather than merely continuing execution?

🔹 A. Continuing would automatically retry socket creation.
🔹 B. Skipping error handling may lead to undefined behavior when later using an invalid descriptor.
🔹 C. The program would automatically close any opened sockets.
🔹 D. The operating system would terminate the process for you.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

If the program ignores a failed socket creation and proceeds, subsequent calls that use the invalid descriptor may behave unpredictably, potentially causing segmentation faults or silent data loss. By invoking perror, the error is reported, and exit halts execution, preventing undefined behavior. Thus option B correctly explains the necessity of this error handling.

🔹 A. It compresses the port number to save memory.
🔹 B. It swaps the bytes to match the little-endian architecture of the client.
🔹 C. It ensures the port is represented in network byte order, which is big-endian.
🔹 D. It encrypts the port number to prevent eavesdropping.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Network protocols transmit multi‑byte values in big‑endian order, known as network byte order. Since many host machines use little‑endian representation, directly assigning a host‑order port can lead to reversed bytes on the wire. Applying htons ensures the port number is correctly ordered for transmission, making option C accurate.
