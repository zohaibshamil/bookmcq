What is Polling protocol in data link layer?

Polling is a centralized controlled access protocol where a primary station sequentially queries each secondary station to determine if it has data to send, granting transmission permission only when polled, which eliminates collisions but introduces overhead and dependency on the primary station.

Q1. In the flow‑control scheme described, what is the primary purpose of the 'note' sent by the receiving data‑link layer when its single slot is empty?

A.To request the sender to stop transmitting
B.To signal the sender to send the next frame ✅
C.To acknowledge the previous frame
D.To indicate a transmission error
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When the receiver’s single‑slot buffer is empty, it informs the network layer that it is ready for more data. This note tells the sender that the next frame can be transmitted without risking overflow. It does not serve as an acknowledgment or error indication; its sole function is to prompt the sender to forward the subsequent frame.

Q2. If the receiving buffer becomes full, what immediate effect does the flow‑control feedback have on the sender's behavior?

A.The sender increases its transmission rate
B.The sender continues transmitting at the same rate
C.The sender pauses or reduces its transmission rate ✅
D.The sender discards the buffered frames
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When the receiver signals that its buffer is full, the sender must honor the feedback by either pausing transmission or throttling its sending rate. Continuing at the same speed would cause overflow, while increasing the rate would exacerbate the problem. Therefore the correct response is to stop or slow down until space becomes available.

Q3. Suppose a sender uses a single‑slot buffer and the receiver's buffer is full for two consecutive cycles. What inference can be made about the network's capacity relative to the sender's production rate?

A.Network capacity exceeds the production rate
B.Production rate exceeds network capacity ✅
C.Both are equal
D.Buffer size is irrelevant to capacity
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: If the receiver cannot accept new frames for two successive cycles, the sender is producing frames faster than the network can deliver them to the receiver. This persistent full‑buffer condition indicates that the effective bandwidth or processing capability of the network is lower than the sender’s generation rate, leading to a bottleneck.

Q4. Compare the error‑control method used in Ethernet (silent discard) with the method that sends acknowledgments. Which statement best captures the trade‑off?

A.Silent discard reduces latency but may lose data
B.Acknowledgment method improves reliability but adds overhead ✅
C.Both methods have identical performance
D.Silent discard requires larger buffers
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Ethernet’s silent‑discard approach simply drops corrupted frames, which keeps latency low but can result in lost data. Sending an acknowledgment after a correct frame introduces extra control traffic and processing time, increasing overhead, but it provides reliable delivery by allowing the sender to retransmit lost or corrupted frames. This trade‑off balances speed against reliability.

Q5. Evaluate the impact of using two separate buffers (one at the sender and one at the receiver) versus a single shared buffer on throughput and latency.

A.Two buffers double throughput and halve latency
B.Two buffers increase latency but keep throughput unchanged
C.Two buffers can improve throughput while slightly increasing latency ✅
D.A single shared buffer always outperforms two buffers
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Having distinct buffers at each end decouples sending and receiving rates, allowing the sender to continue transmitting while the receiver processes earlier frames. This separation can raise overall throughput because each side can work independently. However, the extra storage introduces a small amount of additional latency as frames wait in the buffers before being processed.

Q6. Differentiate between flow‑control feedback that signals a 'buffer full' condition and one that signals a 'vacancy' condition. What effect does each have on the sender's transmission window?

A.Full signal contracts the window; vacancy expands it ✅
B.Full signal expands the window; vacancy contracts it
C.Both signals keep the window unchanged
D.Neither signal influences the window size
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: When a receiver indicates its buffer is full, the sender must shrink its transmission window to avoid sending more data that cannot be stored, effectively contracting the window. Conversely, a vacancy notification tells the sender that space is available, allowing it to enlarge the window and transmit additional frames. Thus the two signals have opposite effects on the sender’s permissible burst size.

Q7. Which of the following scenarios best illustrates polling in a data‑link layer context?

A.Sender continuously streams frames without checking the receiver
B.Receiver sends acknowledgments for every frame
C.Sender waits for a periodic 'ready' signal before transmitting each frame ✅
D.Both nodes transmit simultaneously in a full‑duplex mode
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Polling means the sender does not transmit arbitrarily; instead, it periodically checks whether the receiver is prepared to accept a new frame. The sender waits for a specific 'ready' or 'poll' signal from the receiver, ensuring that the receiver’s buffer has space. This controlled approach matches the definition of polling, unlike continuous streaming or simultaneous transmission.

Q8. If the polling interval is increased, what is the most likely effect on the sender's buffer occupancy?

A.Buffer occupancy decreases because the sender transmits less frequently
B.Buffer occupancy increases, raising the risk of overflow ✅
C.Buffer occupancy remains unchanged
D.The buffer is cleared automatically
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A longer polling interval means the receiver asks the sender for permission less often, so the sender must wait longer before it can send the next frame. While waiting, newly generated data continues to accumulate in the sender’s buffer, causing its occupancy to grow. If the interval becomes too large, the buffer may fill and overflow, leading to dropped frames.

Q9. Design a simple protocol that uses polling to manage both flow control and error recovery for a single‑slot buffer system. Which sequence correctly represents the protocol steps?

A.Sender transmits → Receiver acknowledges → Sender polls → Receiver sends frame
B.Receiver polls → Sender transmits → Receiver checks CRC → Receiver acknowledges or requests retransmission ✅
C.Sender polls → Receiver transmits → Sender checks CRC → Sender acknowledges
D.Receiver acknowledges → Sender transmits → Receiver polls → Sender checks CRC
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The receiver initiates the exchange by polling the sender, indicating it is ready for a frame. The sender then transmits the frame, after which the receiver performs a CRC check. If the CRC is valid, the receiver sends an acknowledgment; otherwise, it requests a retransmission. This sequence integrates both flow‑control (the poll) and error‑control (the CRC and acknowledgment).

Q10. If bit stuffing inserts an extra '0' after five consecutive '1's, how does this affect detection of the flag pattern \(01111110\) when a transmission error flips a stuffed '0' to '1'?

A.The flag may be falsely detected, causing frame misinterpretation ✅
B.The flag detection remains unchanged because stuffing is ignored
C.The error is automatically corrected by the CRC
D.The receiver discards the frame without checking the flag
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Bit stuffing prevents the flag pattern from appearing in data by inserting a '0' after five '1's. If a transmission error changes that inserted '0' to a '1', the receiver could interpret the altered sequence as the flag \(01111110\). This false flag detection would cause the receiver to believe a frame boundary exists where none does, leading to misinterpretation of the data stream.

Q11. In a network where the sender's buffer is larger than the receiver's, which strategy most effectively minimizes packet loss while keeping channel utilization high?

A.Implement dynamic polling intervals based on receiver's vacancy notifications ✅
B.Use fixed‑size frames regardless of buffer status
C.Ignore flow control and rely on retransmissions
D.Increase the sender's transmission power
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Adapting the polling interval to the receiver’s real‑time vacancy signals allows the sender to transmit only when the receiver can store the frame, preventing overflow. This dynamic approach aligns transmission bursts with available buffer space, reducing loss while maintaining high utilization because the channel is used whenever the receiver is ready.

Q12. Consider a scenario where the polling interval is too long, causing the sender's buffer to overflow. Which modification to the polling mechanism would most directly address this issue?

A.Increase the size of the sender's buffer
B.Add error‑control bits to each frame
C.Shorten the polling interval so the receiver signals readiness more frequently ✅
D.Switch to a push‑based flow control model
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: A longer polling interval delays the receiver’s readiness signal, forcing the sender to hold data longer and eventually overflow its buffer. By shortening the interval, the receiver queries the sender more often, allowing the sender to offload frames before the buffer fills. This direct adjustment to the polling timing mitigates overflow without altering buffer sizes or changing the overall flow‑control strategy.
