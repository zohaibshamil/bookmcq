Q1. In Multilink PPP, why is a sequence number added to each actual PPP frame carrying a fragment of the logical frame?

🔹 A. To indicate the total length of the original IP datagram.
🔹 B. To identify the order of fragments for correct reassembly.
🔹 C. To authenticate the sender of each fragment.
🔹 D. To specify the protocol type of the payload.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The sequence number tells the receiver the exact position of each fragment within the original logical PPP frame, allowing it to reorder out‑of‑sequence fragments and reconstruct the complete datagram. Without this ordering information, the receiver could not determine how to assemble the pieces, leading to data corruption or loss.

Q2. What hexadecimal value is set in the Protocol field to show that an actual PPP frame carries a fragment of a logical PPP frame?

🔹 A. 33
🔹 B. 61
🔹 C. 49185
🔹 D. 32801

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

In Multilink PPP the Protocol field is assigned the value 0x003d (hex) to indicate that the frame contains a fragment of a larger logical PPP frame. This special identifier distinguishes fragmented frames from regular PPP payloads, ensuring the receiver processes them with the appropriate reassembly logic.

Q3. How does Multilink PPP increase effective bandwidth compared to a single‑link PPP connection?

🔹 A. By compressing headers
🔹 B. By aggregating multiple physical channels into one logical link
🔹 C. By encrypting data
🔹 D. By reducing frame size

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Multilink PPP spreads a logical PPP frame across several physical channels, transmitting fragments in parallel. By using the combined capacity of all channels, the aggregate throughput exceeds that of any single channel, effectively increasing bandwidth and allowing higher‑rate data transfer without changing the underlying PPP protocol.

Q4. Compare PAP and CHAP as authentication protocols in PPP. Which statement correctly reflects their differences?

🔹 A. PAP sends passwords in clear text, while CHAP uses a challenge‑response hash.
🔹 B. PAP requires multiple round‑trips, CHAP authenticates in a single step.
🔹 C. Both PAP and CHAP encrypt the password before transmission.
🔹 D. CHAP can only be used after IPCP negotiation.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

PAP (Password Authentication Protocol) transmits the password in clear text during a single request/ack exchange, making it simple but less secure. CHAP (Challenge‑Handshake Authentication Protocol) issues a challenge and expects a hashed response, providing stronger security through a challenge‑response mechanism and avoiding plain‑text exposure.

Q5. If a fragment with sequence number 3 is received before fragments 1 and 2, what is the most likely outcome for the receiver?

🔹 A. The receiver will discard fragment 3.
🔹 B. The receiver will wait for missing fragments before delivering any data.
🔹 C. The receiver will deliver fragment 3 immediately and reorder later.
🔹 D. The receiver will request retransmission of fragment 3.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

PPP receivers buffer out‑of‑order fragments and hold them until the missing earlier fragments arrive. This ensures that data is delivered to higher layers only when the full logical frame can be reconstructed in the correct order, preserving data integrity and preventing premature processing of incomplete information.

Q6. What is the primary purpose of the IPCP (IP Control Protocol) phase in PPP link establishment?

🔹 A. To negotiate encryption algorithms.
🔹 B. To assign IP addresses and configure IP parameters.
🔹 C. To establish MAC address mapping.
🔹 D. To test the physical layer throughput.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

IPCP is used after the link is up to negotiate IP‑specific options such as the local and remote IP addresses, DNS server information, and other IP parameters. This configuration enables the PPP link to carry IP traffic correctly, ensuring that the network layer can route packets over the newly created point‑to‑point connection.

Q7. Suppressing the Address and Control fields in PPP frames reduces overhead. Which trade‑off best describes this optimization?

🔹 A. Lower overhead but loss of compatibility with legacy devices.
🔹 B. Higher overhead but increased security.
🔹 C. No impact on bandwidth but adds latency.
🔹 D. Improved error detection at the cost of frame size.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Removing the two one‑byte fields saves two bytes per frame, which is significant on low‑bandwidth links. The trade‑off is that devices expecting the full PPP header may not interoperate, so the optimization is suitable only when both ends agree to omit those fields.

Q8. Which flag byte value is used to delimit the start and end of a PPP frame?

🔹 A. 126
🔹 B. 255
🔹 C. 0
🔹 D. 170

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

PPP frames are framed by the flag byte 0x7E, which marks both the beginning and the end of each frame on the physical medium. This distinctive pattern allows the receiver to detect frame boundaries and separate successive PPP frames for processing.

Q9. Assume fragments of a logical PPP frame are numbered \(1\) to \(4\). The receiver obtains fragments 2, 4, and 1 in that order. Which fragment must still be requested to complete the frame?

🔹 A. Fragment 1
🔹 B. Fragment 3
🔹 C. Fragment 2
🔹 D. Fragment 4

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The missing piece is fragment 3, as fragments 1, 2, and 4 have already been received. The receiver’s reassembly logic, guided by the sequence numbers, will identify the gap and request the absent fragment to achieve a complete and correctly ordered logical frame.

Q10. Explain how Multilink PPP ensures that the reassembled logical frame respects the original IP datagram’s checksum integrity.

🔹 A. Each fragment carries a separate checksum that is combined by XOR.
🔹 B. The original checksum is transmitted unchanged and verified after reassembly.
🔹 C. Checksums are ignored because PPP adds its own FCS.
🔹 D. Fragments are encrypted, making checksum irrelevant.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The IP header checksum calculated at the source remains unchanged across all fragments. After the receiver reassembles the fragments into the original IP datagram, it recomputes the checksum over the reconstructed header and compares it to the transmitted value, confirming integrity before passing the packet upward.

Q11. Evaluate the impact of using Multilink PPP on latency compared to a single‑link PPP when the physical channels have differing transmission rates.

🔹 A. Latency is always reduced because of parallelism.
🔹 B. Latency may increase due to out‑of‑order arrival of fragments.
🔹 C. Latency remains unchanged because reassembly waits for the slowest channel.
🔹 D. Latency is unpredictable and depends on the number of channels only.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When channels have unequal speeds, faster channels may deliver fragments earlier than slower ones, causing the receiver to wait for missing pieces. This waiting can increase overall latency despite the higher aggregate bandwidth, especially if the reassembly must hold data until the last fragment arrives.

Q12. Why does Multilink PPP require the protocol field value (003d)16 instead of the standard IP protocol identifier?

🔹 A. To indicate that the payload contains a fragment.
🔹 B. To request a new link establishment.
🔹 C. To signal the end of transmission.
🔹 D. To enable encryption mode.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The special protocol identifier 0x003d tells the receiving PPP entity that the frame does not contain a complete higher‑layer packet but a fragment of a logical PPP frame. This distinction is necessary so the receiver applies the fragment‑reassembly process rather than treating the payload as a standalone protocol payload.

Q13. In the context of PPP, what does FCS stand for and what is its role?

🔹 A. Frame Check Sequence; it detects transmission errors.
🔹 B. Fast Control Signal; it speeds up negotiations.
🔹 C. File Compression Scheme; it reduces payload size.
🔹 D. Fragment Control Segment; it orders fragments.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

FCS (Frame Check Sequence) is a cyclic redundancy check appended to each PPP frame. It enables the receiver to verify that the bits of the entire frame were transmitted without errors. If the computed FCS does not match the received value, the frame is discarded and may be retransmitted.

Q14. Contrast the behavior of LCP (Link Control Protocol) termination versus IPCP termination in a PPP session.

🔹 A. LCP termination closes the data link, IPCP termination only ends IP configuration.
🔹 B. LCP termination encrypts data, IPCP termination compresses it.
🔹 C. Both terminate the same layers simultaneously.
🔹 D. LCP termination is optional, IPCP termination is mandatory.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

LCP manages the data‑link layer; terminating LCP brings down the entire PPP link, ending all traffic. IPCP operates at the network‑layer level; its termination merely stops IP configuration while the underlying link may remain active for other protocols. Thus, the two terminations affect different layers.

Q15. If a Multilink PPP session uses three channels with capacities 64 kbps, 128 kbps, and 256 kbps, what is the theoretical aggregate bandwidth?

🔹 A. 448 kbps
🔹 B. 384 kbps
🔹 C. 512 kbps
🔹 D. 256 kbps

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The aggregate bandwidth is the sum of the individual channel capacities: \(64 + 128 + 256 = 448\) kbps. This combined capacity represents the maximum data rate achievable when the three channels are used concurrently for a single logical PPP stream.

Q16. Which NCP is used to configure IP parameters before data transfer in PPP?

🔹 A. LCP
🔹 B. IPCP
🔹 C. CHAP
🔹 D. PAP

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

IPCP (IP Control Protocol) is the Network Control Protocol responsible for negotiating IP‑layer options such as IP addresses, DNS servers, and compression settings. It runs after the link is established by LCP and before user data is encapsulated in PPP frames.

Q17. Synthesize how the combination of LCP, PAP, and IPCP stages ensures secure and reliable delivery of an email over a PPP link.

🔹 A. LCP establishes link, PAP authenticates user, IPCP configures IP, together they provide a trusted path.
🔹 B. LCP encrypts data, PAP compresses it, IPCP routes it.
🔹 C. All three stages are redundant and serve the same purpose.
🔹 D. Only PAP is needed; LCP and IPCP are optional.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

First, LCP negotiates and brings up the data‑link connection, guaranteeing a functional link. PAP then verifies the user’s credentials, providing basic authentication. Finally, IPCP configures IP addresses and related parameters, enabling proper routing of the email. Together, these layers create a sequentially verified and configured path for reliable delivery.

Q18. Given that Multilink PPP fragments are reordered at the receiver, which mechanism primarily guarantees correct reassembly?

🔹 A. Use of the FCS field alone.
🔹 B. Sequence numbers embedded in each fragment.
🔹 C. The size of the payload.
🔹 D. The flag bytes surrounding each frame.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Each fragment carries a sequence number that indicates its position within the original logical frame. The receiver uses these numbers to sort fragments regardless of arrival order, ensuring that the reassembled frame matches the original byte sequence before higher‑layer processing.

Q19. During the PPP establishment phase, if the Configure‑Request from the user is rejected, what is the most probable next step?

🔹 A. Terminate the link immediately.
🔹 B. Send a Configure‑Nak indicating acceptable options.
🔹 C. Proceed with data transfer regardless.
🔹 D. Switch to a different protocol field value.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When a Configure‑Request is not acceptable, the peer replies with a Configure‑Nak (negative acknowledgment) that lists the options it can accept. This allows the initiator to modify its request and retry, facilitating a graceful negotiation rather than abrupt termination.

Q20. What advantage does suppressing the Address and Control fields provide when using Multilink PPP over low‑bandwidth channels?

🔹 A. It reduces per‑frame overhead, allowing more payload per frame.
🔹 B. It increases security by hiding address information.
🔹 C. It enables use of larger flag bytes.
🔹 D. It allows simultaneous transmission of multiple protocols.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Removing these two one‑byte fields saves bandwidth on each frame, which is especially valuable on low‑speed links. The saved bytes can be used for actual payload, improving efficiency without altering the core PPP functionality, provided both ends agree to the omission.

Q21. Compare the error detection capabilities of PPP’s FCS with the IP header checksum. Which statement is accurate?

🔹 A. Both detect errors in the same way and have identical coverage.
🔹 B. FCS checks the entire PPP frame, while IP checksum only covers the IP header.
🔹 C. IP checksum is more robust than FCS.
🔹 D. FCS is optional, IP checksum is mandatory.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The PPP FCS is computed over the whole frame, including header, payload, and padding, offering detection of any bit errors in the transmitted frame. In contrast, the IP header checksum only covers the IP header fields, leaving the payload unchecked. Thus, FCS provides broader error detection.

Q22. If a Multilink PPP frame’s payload is padded to meet the minimum frame size, how does this affect the sequence number interpretation?

🔹 A. Padding bytes are counted as part of the sequence number.
🔹 B. Sequence numbers remain unchanged; padding is ignored.
🔹 C. Padding forces the sequence number to reset.
🔹 D. Padding causes the protocol field to change.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Padding is added after the payload to satisfy size constraints and does not alter the fragment’s metadata. The sequence number, which is part of the fragment header, stays the same regardless of any extra padding bytes, allowing the receiver to correctly order fragments without confusion.

Q23. Which protocol field value (in hex) identifies a standard IP payload in a PPP frame?

🔹 A. 33
🔹 B. 61
🔹 C. 49185
🔹 D. 32801

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The standard PPP protocol identifier for IP is 0x0021. When this value appears in the Protocol field, the receiver knows that the payload carries an IP datagram and processes it according to the IP layer specifications.

Q24. Explain why Multilink PPP must maintain per‑channel ordering when fragments are distributed across channels with different latency characteristics.

🔹 A. To avoid deadlocks in the link layer.
🔹 B. To ensure the reassembled IP datagram preserves original byte order.
🔹 C. Because each channel uses a distinct encryption key.
🔹 D. To synchronize clock drift between channels.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Even though fragments travel on separate channels that may arrive at different times, the original byte sequence of the IP datagram must be preserved. Maintaining per‑fragment ordering via sequence numbers guarantees that, after reassembly, the packet reflects the exact order intended by the sender, preventing corruption.

Q25. Assess the effect of enabling PAP authentication versus disabling authentication on the overall setup time of a PPP link.

🔹 A. PAP adds negligible delay because it uses a single round‑trip.
🔹 B. Disabling authentication always speeds up setup by at least 50 %.
🔹 C. PAP doubles the setup time due to extra frames.
🔹 D. Authentication has no impact on setup time.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

PAP requires only one request and one acknowledgment exchange, adding at most a single round‑trip time to the link establishment. This overhead is minimal compared with the total time needed for LCP negotiation and IPCP configuration, so enabling PAP does not significantly increase overall setup duration.

Q26. When the PPP frame flag byte (0x7E) appears in the payload, what technique is used to prevent frame delimiter confusion?

🔹 A. Bit stuffing
🔹 B. Byte stuffing (escaping)
🔹 C. Checksum insertion
🔹 D. Frame compression

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

If the flag pattern 0x7E occurs within the data, PPP uses byte stuffing (escaping) by inserting a preceding escape character (0x7D) and modifying the byte. This ensures the receiver does not mistake payload data for a frame delimiter, preserving frame boundary integrity.
