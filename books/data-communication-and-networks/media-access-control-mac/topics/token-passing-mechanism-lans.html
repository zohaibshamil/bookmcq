What is Token passing mechanism LANs?

Token passing is a distributed controlled access method where a special control frame called a token circulates among stations in a logical ring, and only the station holding the token is permitted to transmit data, ensuring orderly and collision-free access to the shared medium.

Q1. What is the protocol field value used in a PPP frame that carries PAP packets?

A.49187 ✅
B.49185
C.49186
D.49188
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The protocol field identifies the higher‑level protocol encapsulated in the PPP frame. For PAP packets the standard specifies the hexadecimal value 0xC023, which tells the receiver that the payload follows the PAP format. Recognizing this value is essential for correct processing of authentication messages.

Q2. If a CHAP system reuses the same challenge value for multiple authentication attempts, which security risk is most increased?

A.Man-in-the-middle attack
B.Denial of service attack
C.Password cracking attack
D.Replay attack ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Reusing a static challenge allows an attacker to capture a legitimate response and later replay it to gain unauthorized access. Because the challenge does not change, the previously computed hash (the response) remains valid, making replay attacks the most likely threat in this scenario.

Q3. Which statement best describes the security difference between PAP and CHAP?

A.PAP encrypts the password before transmission
B.CHAP never sends the password in clear text ✅
C.PAP uses a three‑way handshake while CHAP uses a two‑way handshake
D.CHAP uses a static challenge value for all sessions
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: CHAP improves security by never transmitting the password itself; instead, it sends a hashed result derived from the password and a challenge. PAP, by contrast, sends the password in clear text, exposing it to anyone who can capture the packet.

Q4. Which step in the CHAP process ensures that the password remains secret?

A.The user sends the password directly to the system
B.The system stores the password in a hash table
C.The result of a hash function applied to the password and challenge is sent ✅
D.The challenge value is encrypted before transmission
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: In CHAP, the password is combined with a random challenge and processed by a predefined hash function. Only the resulting hash (the response) is transmitted, so the actual password never appears on the wire, preserving its confidentiality.

Q5. If a user receives an authenticate‑ack packet, what can be inferred about the authentication outcome?

A.The user’s credentials were rejected
B.The system granted access ✅
C.The system requested additional information
D.The authentication process timed out
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: An authenticate‑ack packet is sent by the server to indicate successful verification of the supplied credentials. Its receipt means the server has accepted the username and password (or the CHAP response) and the user may now proceed with the network session.

Q6. What is the impact of disabling protocol field compression on PAP packet transmission?

A.It increases the size of each PPP frame ✅
B.It reduces transmission latency
C.It prevents packet loss
D.It has no effect on PAP packets
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When protocol field compression is turned off, the two‑byte protocol identifier is transmitted in full for every frame. This adds overhead to each PAP packet, slightly enlarging the frame and potentially reducing overall throughput, especially on links with limited bandwidth.

Q7. When the challenge value changes for each CHAP session, which of the following is true about the response result?

A.The result remains identical for every session
B.The result varies unpredictably from session to session ✅
C.The password must be changed each time
D.The system cannot verify the response
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A new random challenge means the hash input differs each time, so even with the same password the computed response will be different. This unpredictability prevents attackers from reusing captured responses, enhancing the protocol’s resistance to replay attacks.

Q8. If an eavesdropper captures a PAP authenticate‑request packet, what can they learn?

A.They learn the user’s password in clear text ✅
B.They learn only the username
C.They cannot decode the packet because it is encrypted
D.The packet is automatically discarded by the receiver
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: PAP transmits both username and password in clear text within the authenticate‑request packet. An eavesdropper who intercepts this packet can directly read the password, making PAP vulnerable to credential theft on insecure links.

Q9. How do PAP and CHAP differ in handling authentication failures?

A.Both send a NAK packet to the client
B.PAP automatically retries, while CHAP does not retry
C.PAP denies access immediately, whereas CHAP may issue a new challenge for another attempt ✅
D.Both use the same packet type for failure notification
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When PAP authentication fails, the server sends an authenticate‑nak packet and typically terminates the session. CHAP, however, can respond to a failed verification by sending a new challenge, allowing the client another opportunity to prove its identity without immediate disconnection.

Q10. In which situation would choosing CHAP over PAP be most advantageous for a corporate VPN?

A.When bandwidth is extremely low
B.When network latency is high
C.When password secrecy is required ✅
D.When static IP addresses are used
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Corporate VPNs often require strong security to protect sensitive credentials. CHAP’s design keeps the password hidden by transmitting only a hashed response, making it far more suitable than PAP for environments where protecting password confidentiality is a priority.

Q11. After receiving a PAP authenticate‑nak packet, what is the most likely next step for the client?

A.Resend the same credentials without changes
B.Terminate the PPP session immediately
C.Prompt the user to enter new credentials ✅
D.Switch to CHAP authentication automatically
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: An authenticate‑nak indicates that the server rejected the supplied credentials. The typical client reaction is to inform the user of the failure and request new or corrected username/password information before attempting authentication again.

Q12. Why does continuously changing the CHAP challenge value lower the risk of replay attacks compared with a static challenge?

A.A static challenge allows reuse of captured responses
B.A dynamic challenge encrypts the password
C.Changing the challenge invalidates any previously captured response hashes ✅
D.It does not affect replay risk at all
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When the challenge changes each session, any response that an attacker previously recorded becomes useless because the hash will be recomputed with the new challenge. This forces an attacker to obtain a fresh challenge and recompute the response, effectively mitigating replay attacks.

Q13. How do the three PAP packet types interact to complete an authentication cycle?

A.Request → Ack → NAK
B.Request → NAK → Ack
C.Request → Ack or NAK → termination ✅
D.Ack → Request → NAK
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The client initiates authentication by sending an authenticate‑request. The server then either acknowledges success with an authenticate‑ack or rejects the credentials with an authenticate‑nak. After either response, the session proceeds accordingly, ending the authentication exchange.

Q14. If a CHAP implementation hashes the password before appending the challenge value, what vulnerability is introduced?

A.It weakens hash collision resistance
B.It allows password dictionary attacks ✅
C.It enables replay of the challenge
D.It exposes the password in clear text
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Hashing the password alone before combining it with the challenge reduces the entropy of the final input, making it easier for an attacker to pre‑compute a dictionary of hashed passwords. This mistake can be exploited to recover the original password more efficiently.

Q15. What effect on authentication latency is expected when the MRU is increased from 1500 to 3000 bytes on a PPP link using CHAP?

A.Latency is halved
B.Latency doubles
C.Latency slightly increases due to larger frames ✅
D.There is no change in latency
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Increasing the MRU allows larger payloads per frame, which can reduce the number of frames needed but also means each frame takes longer to transmit and process. The net effect is a modest increase in latency, especially noticeable when the link is already near its capacity limits.

Q16. Design a CHAP modification that enables mutual authentication without revealing passwords, and identify which new packet must be added.

A.Add an authenticate‑ack from the client
B.Introduce a challenge from the client ✅
C.Use a PAP authenticate‑request packet
D.Replace the challenge with a token
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Mutual authentication can be achieved by having the client also send a challenge to the server. The server then computes a response using its secret and the client‑provided challenge, sending this back in a new packet type. Introducing a client‑originated challenge fulfills this requirement.

Q17. Given that PAP transmits credentials in clear, which link‑layer mitigation can be applied without altering the PAP packet format?

A.Enable protocol field compression
B.Apply link‑layer encryption such as PPP encryption ✅
C.Increase the MRU size
D.Disable address and control field compression
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Adding link‑layer encryption (for example, PPP's built‑in encryption mechanisms) encrypts the entire PPP frame, including the PAP payload, thereby protecting the credentials from eavesdropping while leaving the PAP packet structure unchanged.
