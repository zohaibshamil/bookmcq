📝 Reservation method in controlled access

📖 From Data Communication and Networks • 12. Media Access Control (MAC) • 9 questions available

What is Reservation method in controlled access?

The reservation method is a controlled access technique where stations must reserve future time slots or bandwidth through a separate reservation phase before transmitting data, ensuring collision-free communication by guaranteeing exclusive access during the reserved interval.

Q1. What hexadecimal value identifies the Link Control Protocol (LCP) in the PPP protocol field?

A. 49185 ✅
B. 49187
C. 32801
D. 33

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The PPP protocol field uses a two‑byte identifier. The LCP is defined by the value 0xC021, as shown in the standard and the figure. The other values correspond to authentication (0xC023), network control (0x8021) or generic data (0x0021). Therefore option A is correct.

Q2. If an endpoint receives a Configure‑request that contains an option it does not support, which LCP packet should it send back?

A. Configure‑ack
B. Configure‑nak
C. Configure‑reject ✅
D. Terminate‑request

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

When an option is unknown or unsupported, the LCP specification requires the receiver to send a Configure‑reject packet listing the offending option. This indicates that the option cannot be used and forces the peer to remove it. An ack would accept all options, and a nak suggests alternative values, which is not appropriate here.

Q3. Which statement best differentiates the purpose of LCP packet type 0x05 (Terminate‑request) from type 0x06 (Terminate‑ack)?

A. Terminate‑request initiates link shutdown; Terminate‑ack confirms receipt of the shutdown request
B. Terminate‑request confirms receipt; Terminate‑ack initiates shutdown ✅
C. Both packets perform the same function but are sent by opposite endpoints
D. Terminate‑request carries configuration options while Terminate‑ack carries debugging data

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Terminate‑request is sent by an endpoint that wishes to close the link, signalling the intention to terminate. The peer responds with Terminate‑ack to acknowledge that it has received the request and will comply. Thus the request starts the process and the ack finalizes it. The other options misrepresent the flow or mix unrelated functions.

Q4. Two endpoints propose different Maximum‑Receive‑Unit (MRU) values. Which LCP exchange leads to a successful agreement?

A. Configure‑request with MRU=1500, peer replies Configure‑ack
B. Configure‑request with MRU=1500, peer replies Configure‑nak suggesting MRU=1400, then request is resent with 1400 and acked ✅
C. Configure‑request with MRU=1500, peer replies Configure‑reject, then both use default MRU
D. Terminate‑request followed by Terminate‑ack and then re‑establishing the link

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When the peer cannot accept the proposed MRU, it sends a Configure‑nak containing a suggested alternative (e.g., 1400). The initiator then resends a Configure‑request with the new value, which the peer can acknowledge with a Configure‑ack. This negotiation loop yields a mutually acceptable MRU. Direct rejection or termination would not achieve agreement.

Q5. If a peer sends an Echo‑request and never receives an Echo‑reply, what can be inferred about the PPP link?

A. The link is likely down or unresponsive ✅
B. The peer will automatically resend the request indefinitely
C. The link is functioning but the Echo‑reply is optional
D. The LCP layer must be re‑initialized

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The Echo‑request is a keep‑alive probe; lack of a corresponding Echo‑reply indicates that the remote endpoint is not responding, which typically means the physical or data‑link layer is down or the link has become unresponsive. Therefore the safest inference is that the link is down.

Q6. What is the likely consequence of sending a Configure‑nak instead of a Configure‑reject when an unknown option is received?

A. The peer may attempt to adjust the option, leading to prolonged negotiation ✅
B. The unknown option will be silently ignored, causing no impact
C. The link will be immediately terminated
D. The negotiation will fail because the peer expects a reject for unknown options

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A Configure‑nak suggests that the option is understood but its value is unacceptable, prompting the peer to modify it. For an unknown option, the correct response is a Configure‑reject. Using nak misleads the peer into trying to negotiate a nonexistent option, which can extend the negotiation unnecessarily and may never converge, whereas a reject would terminate the exchange promptly.

Q7. How does LCP multiplexing enable multiple Network Control Protocols (NCPs) such as IPCP and OSI CP to coexist on a single PPP link?

A. LCP assigns separate channel numbers to each NCP
B. LCP encapsulates each NCP packet with a distinct protocol identifier, allowing the receiver to demultiplex based on the protocol field ✅
C. LCP merges all NCP data into a single stream without identifiers
D. LCP uses time‑division to alternate NCP traffic

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

LCP provides a framework where each higher‑level protocol, including various NCPs, is carried in its own PPP frame identified by a unique protocol field (e.g., 0x8021 for IPCP). The receiver examines this field to demultiplex the payload, effectively allowing several NCPs to share the same physical link without interference. This design avoids the need for separate channels or time‑division schemes.

Q8. A PPP frame carries a protocol field value of 0xC023. Which type of protocol is being transported?

A. Link Control Protocol (LCP)
B. Authentication Protocol (AP) ✅
C. Network Control Protocol (NCP)
D. User data payload

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The hexadecimal value 0xC023 is reserved for authentication protocols such as PAP or CHAP. LCP uses 0xC021, while NCPs use values like 0x8021. Therefore a frame with 0xC023 indicates that an authentication protocol is being exchanged between the peers.

Q9. Which description correctly distinguishes the roles of the ID field and the Length field in an LCP packet header?

A. The ID field carries the packet sequence number; the Length field indicates the size of the information field only
B. The ID field matches requests with replies; the Length field specifies the total size of the LCP packet including header ✅
C. Both fields together encode the packet type and options
D. The ID field is used for error detection; the Length field is used for flow control

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The ID field is a one‑byte identifier that the sender places in a request and expects to see unchanged in the corresponding reply, enabling correlation of messages. The Length field is a two‑byte value representing the entire LCP packet length, header plus information, allowing the receiver to know where the packet ends. This distinction is essential for correct parsing and matching.
