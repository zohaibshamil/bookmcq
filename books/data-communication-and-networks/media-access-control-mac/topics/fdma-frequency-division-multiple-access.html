What is FDMA Frequency Division Multiple Access?

Frequency Division Multiple Access divides the total available bandwidth into distinct non-overlapping frequency channels, assigning each user a dedicated frequency band for simultaneous communication, preventing interference through spectral separation rather than time or code coordination.

Q1. In a PPP frame, CHAP packets use the protocol field value C223 (hex). If a sender mistakenly sets this field to C222, what is the most likely outcome for the receiver?

A.The receiver treats the packet as a PAP packet
B.The receiver discards the packet as unknown protocol ✅
C.The receiver processes it as CHAP but reports an error
D.The receiver accepts it and proceeds normally
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The protocol field tells the receiver which Network Control Protocol to invoke. A value that does not match any defined protocol, such as C222, is unrecognised, so the receiver will drop the frame as an unknown protocol rather than attempting to interpret it as PAP or CHAP.

Q2. Which of the following correctly describes the purpose of the CHAP \challenge\ packet in PPP?

A.It carries the user’s password in clear text
B.It initiates a three‑way handshake for link establishment
C.It provides a random value that the peer must hash with its secret ✅
D.It signals the end of the PPP session
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The CHAP challenge packet contains a nonce generated by the authenticator. The peer combines this nonce with its secret (usually a password) and computes a hash, which is returned in the response packet. This mechanism ensures that the password itself is never transmitted in clear text.

Q3. Considering the PPP frame structures shown for PAP and CHAP, which statement best captures a key difference in how authentication data is protected?

A.PAP includes a FCS while CHAP does not
B.CHAP embeds a challenge value that is not present in PAP ✅
C.PAP uses a longer Code field than CHAP
D.CHAP frames are always larger than PAP frames due to padding
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: CHAP introduces a challenge value that the peer must combine with its secret to produce a response hash. PAP simply sends the username and password directly. This challenge‑response design provides protection against eavesdropping, a capability absent from PAP’s straightforward credential transmission.

Q4. Suppose a network administrator wants to enhance security by replacing PAP with CHAP in an existing PPP link. Which change in the authentication workflow best reflects the advantage of CHAP over PAP?

A.The user’s password is transmitted only once at link start
B.The password is never sent over the link ✅
C.The system no longer needs to store user credentials
D.Authentication is performed without any cryptographic operations
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: CHAP’s design ensures that the password itself never traverses the link; instead, a hash of the password combined with a random challenge is sent. This eliminates exposure of the clear‑text password, a fundamental security improvement over PAP, which transmits credentials in plaintext.

Q5. If a CHAP \response\ packet contains a hash that does not match the expected value for the given challenge, what should the system do according to the CHAP protocol specification?

A.Accept the user but log a warning
B.Send a \failure\ packet and terminate the link ✅
C.Resend the original challenge
D.Switch to PAP authentication automatically
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When the computed hash differs from the expected result, the authenticator must reject the peer. The protocol dictates that a CHAP Failure packet be sent, after which the link is typically terminated or the authentication is retried a limited number of times, preserving security integrity.

Q6. In the PPP encapsulation, both PAP and CHAP packets include an ID field. How does the role of the ID field differ between the two protocols?

A.In PAP the ID identifies the user, while in CHAP it identifies the packet sequence
B.In PAP the ID is fixed, while in CHAP it varies per challenge ✅
C.In PAP the ID is used for error detection, while in CHAP it is ignored
D.In PAP the ID is optional, while in CHAP it is mandatory for each packet
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: PAP uses a static identifier for the authentication request, whereas CHAP generates a new ID for each challenge‑response exchange. This per‑exchange ID allows the receiver to match responses to the correct challenge, ensuring proper sequencing and preventing confusion between concurrent authentication attempts.

Q7. Design a PPP authentication sequence that uses CHAP's challenge‑response mechanism to protect against replay attacks. Which additional step is essential to achieve this protection?

A.Include a timestamp in the challenge value ✅
B.Encrypt the entire PPP frame with a symmetric key
C.Use a static secret shared by all peers
D.Send the challenge twice before expecting a response
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Adding a timestamp (or any nonce that changes each session) to the challenge guarantees that each hash value is unique. Even if an attacker captures a previous response, the altered challenge will render the old hash useless, thereby preventing replay attacks while still using the standard CHAP process.

Q8. Assume a PPP link using CHAP where the challenge value is 128 bits long. If an attacker captures a \response\ packet, what is the probability that the attacker can correctly guess the original password in a single attempt, assuming a uniformly random password space of size \(2^{64}\)?

A.\(2^{-128}\)
B.\(2^{-64}\) ✅
C.\(2^{-192}\)
D.\(2^{-32}\)
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The response hash is a function of the 128‑bit challenge and the password. Even though the challenge is known, the attacker must still guess the password. With a password space of \(2^{64}\), the chance of a correct guess on one try is \(1/2^{64}=2^{-64}\), independent of the challenge size.

Q9. Compare the overhead introduced by PAP and CHAP within a PPP frame. Which statement accurately reflects the impact on bandwidth when authenticating 100 users sequentially?

A.PAP requires fewer bytes per authentication, thus lower total overhead
B.CHAP’s challenge‑response adds extra bytes, increasing overhead proportionally ✅
C.Both protocols have identical overhead because they share the same header fields
D.CHAP reduces overall bandwidth usage because it eliminates the need for retransmissions
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: CHAP adds both a challenge packet and a response packet for each authentication, each containing additional fields (challenge value, hash, IDs). Consequently, the cumulative byte count grows compared with PAP’s single request‑response exchange, leading to higher bandwidth consumption when many users are authenticated in succession.

Q10. In the context of PPP, the Network Control Protocol (NCP) is responsible for configuring network‑layer protocols. How does the existence of NCPs influence the choice between using PAP or CHAP for authentication?

A.NCPs mandate the use of PAP for all IPv4 links
B.NCPs provide a framework that allows either PAP or CHAP to be selected independently ✅
C.NCPs automatically upgrade PAP to CHAP after link establishment
D.NCPs replace authentication entirely, making PAP and CHAP obsolete
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: NCPs operate at a layer above the link‑layer authentication mechanisms. They merely configure how network‑layer packets are carried, leaving the choice of authentication protocol (PAP or CHAP) to be negotiated separately during link establishment, so either method may be employed regardless of the NCP in use.

Q11. If a PPP link negotiates the use of CHAP but the peer device only implements PAP, what is the most likely result during the authentication phase?

A.The link will fall back to PAP automatically
B.Authentication will fail and the link will be terminated ✅
C.The peer will ignore the CHAP packets and continue data transfer
D.The CHAP packets will be interpreted as IP packets
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: During negotiation, both ends must agree on the authentication protocol. If one side cannot process CHAP, the authentication cannot succeed, and the standard response is to abort the link after sending a CHAP Failure packet, leading to termination of the session.

Q12. Which field in the PPP frame directly indicates that the payload is a CHAP packet?

A.Flag
B.Address
C.Protocol ✅
D.Control
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The Protocol field in a PPP frame specifies the type of payload that follows. For CHAP, the protocol identifier is C223 (hex), which is recognized by the receiver as indicating a CHAP packet. The other fields (Flag, Address, Control) serve framing and control purposes but do not identify the encapsulated protocol.

Q13. Imagine a scenario where a PPP link must support both IPv4 and IPv6 traffic. How can CHAP be integrated with multiple NCPs (e.g., IPCP and IPv6CP) without compromising authentication integrity?

A.Use a separate CHAP exchange for each NCP
B.Perform a single CHAP exchange before any NCP configuration ✅
C.Embed the NCP identifier inside the CHAP challenge
D.Disable CHAP and use PAP for each NCP separately
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: CHAP is designed to authenticate the peer before any network‑layer configuration occurs. By completing a single CHAP challenge‑response exchange at the start of the link, the authenticator can verify the peer once, after which multiple NCPs (IPCP, IPv6CP) can be configured without re‑authenticating, preserving both security and efficiency.

Q14. During a PPP session, after a successful CHAP authentication, the system sends a \success\ packet. If the receiving peer mistakenly discards this packet, what is the most probable effect on the link state?

A.The link will remain up but the peer will not know authentication succeeded
B.The link will be terminated due to missing acknowledgment ✅
C.The peer will request a new challenge
D.The session will switch to PAP automatically
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: CHAP relies on the explicit success packet to confirm that the responder has accepted the authentication. If this packet is lost, the peer will not receive confirmation, will eventually time out waiting for acknowledgment, and the protocol dictates that the link be terminated to avoid an unauthenticated session.
