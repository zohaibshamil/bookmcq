What is Routers network layer functionality?

Routers function at the network layer to connect different networks by examining IP addresses in packet headers, making routing decisions based on logical addressing and routing tables to forward data between distinct subnets while isolating broadcast domains.

Q1. When a router receives a frame belonging to VLAN 10 but its routing table has no entry for that VLAN, what is the most likely action?

A.Forward the frame unchanged to all ports
B.Drop the frame and generate an ICMP unreachable message ✅
C.Encapsulate the frame in a new VLAN tag
D.Broadcast the frame on the native VLAN
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The router cannot forward a frame for an unknown VLAN, so it discards the frame and typically sends an ICMP Destination Unreachable message back to the source. This prevents the frame from propagating incorrectly and preserves network integrity.

Q2. If a switch creates a loop and a router is connected to the looped network, which protocol helps the router to avoid forwarding duplicate packets?

A.ARP
B.DHCP
C.DNS
D.Spanning Tree Protocol ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Spanning Tree Protocol (STP) detects network loops and disables redundant paths, ensuring that only a single active route exists. By doing so, it prevents the router from receiving and retransmitting duplicate frames caused by the loop, maintaining efficient and loop‑free forwarding.

Q3. A router interfaces with two LANs using subnets 192.168.1.0/24 and 192.168.1.0/25. A host in the /25 network sends a packet to a host in the /24 network. Which rule does the router use to select the appropriate route?

A./24 mask
B./25 mask
C.Both masks are considered
D.It uses the longest prefix match ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Routers perform longest‑prefix matching during route lookup. Although the destination belongs to the larger /24 network, the router evaluates all available routes and selects the one with the most specific (longest) matching prefix. In this case, the /24 route is chosen because it directly matches the destination address.

Q4. Which statement best distinguishes a hub from a switch regarding traffic handling?

A.Both broadcast all incoming frames to every port
B.A hub forwards frames based on MAC addresses
C.A hub regenerates signals without inspecting frame contents ✅
D.A switch creates a separate collision domain per port
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: A switch operates at the data‑link layer and maintains a MAC address table, allowing it to forward frames only to the intended destination port. In contrast, a hub is a physical layer device that simply repeats incoming electrical signals to all other ports, resulting in a single collision domain.

Q5. Replacing a traditional router with a layer‑3 switch in a VLAN‑rich environment primarily affects which of the following?

A.Reduces latency due to faster hardware forwarding ✅
B.Eliminates the need for IP routing
C.Increases the number of broadcast domains
D.Simplifies VLAN tagging on end devices
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Layer‑3 switches integrate routing functions into switch ASICs, providing hardware‑based forwarding that is typically faster than software routing on a conventional router. This reduction in processing delay can improve overall network performance, especially in environments with many VLANs that require frequent inter‑VLAN traffic.

Q6. Compared to static routing, dynamic routing protocols improve scalability because they

A.Require manual configuration on each router
B.Automatically adjust routes as the network topology changes ✅
C.Only work in small networks
D.Are less secure
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Dynamic routing protocols such as OSPF or EIGRP automatically exchange topology information among routers, enabling them to compute optimal paths without human intervention. This automation allows networks to grow and change without the overhead of updating static routes on every device, thereby enhancing scalability.

Q7. Why does a router maintain a MAC address table even though its primary function is layer‑3 routing?

A.To resolve IP addresses to MAC addresses for ARP ✅
B.To forward frames within the same broadcast domain
C.To support VLAN tagging
D.To enable NAT translation
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Routers must encapsulate routed packets into Ethernet frames before sending them out an interface. To do this, they need the MAC address of the next‑hop or final destination on that LAN segment. The router therefore learns and stores MAC addresses in a table, enabling efficient ARP resolution and frame forwarding.

Q8. How does a router separate broadcast domains?

A.By assigning different IP subnets to each interface ✅
B.By using the same subnet mask on all interfaces
C.By disabling ARP on its ports
D.By merging VLANs into a single domain
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A router creates a distinct broadcast domain for each of its interfaces, typically by assigning each interface a unique IP subnet. Broadcast frames received on one interface are not forwarded to another, thereby isolating broadcast traffic and preventing it from crossing between separate logical networks.

Q9. What is the relationship between VLAN trunking and the router‑on‑a‑stick configuration?

A.Trunking allows multiple VLANs to share a single physical link, while router‑on‑a‑stick uses a sub‑interface per VLAN on the router ✅
B.Trunking eliminates the need for a router
C.Router‑on‑a‑stick replaces VLAN tagging entirely
D.Both concepts are unrelated
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: In a router‑on‑a‑stick design, a single physical link between the switch and router is configured as a trunk, carrying traffic for several VLANs. The router then creates a sub‑interface for each VLAN, enabling inter‑VLAN routing while using only one physical connection.

Q10. Enabling inter‑VLAN routing on a router impacts security segmentation in which way?

A.It merges all VLANs into a single broadcast domain
B.It allows selective traffic flow between VLANs based on ACLs ✅
C.It disables VLAN tagging on switches
D.It creates additional VLANs automatically
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Inter‑VLAN routing permits traffic to move between VLANs, but the router can enforce access‑control lists (ACLs) to restrict which flows are allowed. This selective control preserves the logical separation of VLANs while still providing necessary communication, thereby balancing connectivity and security requirements.

Q11. A router has three physical interfaces, each assigned to a different VLAN. How many distinct broadcast domains exist in this configuration?

A.\(1\)
B.\(3\) ✅
C.\(4\)
D.\(6\)
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Each router interface defines its own broadcast domain because broadcast frames are not forwarded between interfaces. With three interfaces each on separate VLANs, there are exactly three independent broadcast domains, represented mathematically as \(3\). This isolation is a core reason routers are used to segment networks.

Q12. What is the primary function of a router in an IP network?

A.To amplify signals over long distances
B.To assign MAC addresses to devices
C.To forward packets between different network segments based on IP addresses ✅
D.To store user credentials
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The essential role of a router is to examine the destination IP address of incoming packets and forward them toward the appropriate next‑hop or network. By doing so, routers enable communication across separate IP subnets and connect disparate networks, forming the backbone of the Internet.
