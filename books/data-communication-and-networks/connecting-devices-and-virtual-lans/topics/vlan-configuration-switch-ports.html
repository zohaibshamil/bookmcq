What is VLAN configuration switch ports?

Switch ports are configured as either access ports that belong to a single VLAN for end devices or trunk ports that carry multiple VLAN traffic simultaneously using tagging protocols, allowing proper segregation and inter-VLAN communication within the network infrastructure.

📝 All VLAN configuration switch ports MCQs

Q1. What is the primary function of a network hub in a LAN?

A.Repeat incoming signals to all other ports ✅
B.Filter frames based on MAC addresses
C.Segment collision domains
D.Provide routing between subnets
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A hub works at the physical layer and simply copies any electrical signal it receives on one port to all other ports. This behavior means it repeats incoming signals to every other port, creating a single shared collision domain for all devices attached to the hub.

Q2. In a LAN where a broadcast storm occurs due to a switching loop, which feature should be enabled to prevent the storm?

A.Spanning Tree Protocol is disabled
B.VLAN tagging is required
C.Port security must be configured
D.Enable Spanning Tree Protocol ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Spanning Tree Protocol (STP) detects loops in the network topology and blocks redundant paths, thereby preventing broadcast storms caused by switching loops. By enabling STP, the switch automatically determines a loop‑free tree structure, ensuring that broadcast frames do not circulate endlessly.

Q3. If a host in VLAN 10 attempts to communicate with a host in VLAN 20 without any routing device present, what is the most likely outcome?

A.Communication succeeds via the switch
B.Frames are forwarded to VLAN 20
C.Frames are dropped by the switch ✅
D.ARP requests fail
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Switches forward frames based on MAC addresses within the same VLAN. Because VLAN 10 and VLAN 20 are separate broadcast domains, the switch has no routing capability to move traffic between them. Consequently, frames from VLAN 10 are discarded when they encounter a VLAN 20 destination, preventing communication.

Q4. Which statement correctly differentiates a hub from a switch?

A.A hub operates at layer 2 while a switch operates at layer 1
B.A switch forwards frames based on MAC addresses ✅
C.A hub creates separate collision domains for each port
D.A switch broadcasts all traffic to every port
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A switch examines the destination MAC address of each incoming Ethernet frame and consults its MAC address table to forward the frame only to the appropriate port. This selective forwarding contrasts with a hub, which indiscriminately repeats the signal to all ports, causing a single shared collision domain.

Q5. When VLAN trunking is enabled on an inter‑switch link, which outcome is most accurate?

A.It reduces the number of broadcast domains in the network
B.It allows traffic from multiple VLANs to travel over a single physical link ✅
C.It completely isolates each VLAN from the others
D.It disables Spanning Tree Protocol on the trunk
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: VLAN trunking (typically using 802.1Q) adds a tag to each frame indicating its VLAN ID, enabling a single physical connection to carry traffic for several VLANs simultaneously. This preserves the separation of broadcast domains while optimizing link utilization, as multiple VLANs share the same physical medium.

Q6. Connecting two switches with three parallel links but without link aggregation is most likely to cause which problem?

A.Loop formation leading to broadcast storms ✅
B.Increased bandwidth for all traffic
C.MAC address table instability
D.No noticeable effect on network performance
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Three parallel links create multiple redundant paths between the switches. Without a protocol such as LACP to aggregate them, the switches may treat each link as separate, forming a loop. This loop can cause broadcast frames to circulate indefinitely, resulting in a broadcast storm and potential network collapse.

Q7. In VLAN configuration, which tag is added to Ethernet frames to identify the VLAN membership?

A.MAC address
B.IP address
C.TCP port
D.VLAN ID (802.1Q tag) ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: The IEEE 802.1Q standard defines a four‑byte tag inserted into the Ethernet frame header. This tag carries the VLAN Identifier (VID), which uniquely identifies the VLAN to which the frame belongs, allowing switches to segregate traffic according to VLAN membership.

Q8. How does a switch learn MAC addresses, and how does this learning affect its forwarding decisions?

A.By broadcasting ARP requests for every destination
B.By inspecting the source MAC address of incoming frames and updating its MAC table ✅
C.Through static configuration only
D.By consulting a routing table similar to a router
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When a frame arrives on a switch port, the switch records the source MAC address and the associated port in its MAC address table. Future frames destined for that MAC are then forwarded directly to the recorded port, reducing unnecessary flooding and improving efficiency.

Q9. A trunk port is configured with native VLAN 1 and allowed VLANs 10, 20, 30. If a host in VLAN 20 sends an untagged frame due to a misconfiguration, what does the switch do with that frame?

A.The frame is assigned to the native VLAN 1 ✅
B.The frame is dropped immediately
C.The frame is broadcast to all allowed VLANs
D.The switch triggers a Spanning Tree recalculation
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Untagged frames received on a trunk port are placed into the native VLAN, which by default is VLAN 1 unless otherwise specified. Therefore, a mis‑tagged frame from VLAN 20 will be treated as belonging to VLAN 1 and processed accordingly, potentially causing connectivity issues for the originating host.

Q10. If an access port is set for VLAN 40 but receives a frame tagged for VLAN 30, what action will the switch take?

A.Forward the frame to VLAN 40
B.Forward the frame to VLAN 30
C.Drop the frame entirely ✅
D.Send an ICMP Destination Unreachable message
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Access ports are designed to handle untagged frames belonging to a single VLAN. When a tagged frame arrives that does not match the configured VLAN, the switch treats it as an invalid packet and discards it to maintain VLAN integrity and prevent accidental cross‑VLAN traffic.
