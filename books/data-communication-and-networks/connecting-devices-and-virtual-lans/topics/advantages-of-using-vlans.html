📝 Advantages of using VLANs

📖 From Data Communication and Networks • 17. Connecting Devices and Virtual LANs • 10 questions available

What is Advantages of using VLANs?

VLANs provide enhanced security by isolating sensitive traffic, improve network performance by reducing broadcast domains, simplify network management through logical grouping independent of physical layout, and offer cost savings by eliminating the need for separate physical networks for different departments or functions.

📝 All Advantages of using VLANs MCQs

Q1. Which of the following best defines a hub in a LAN?

A. A device that forwards frames based on MAC addresses
B. A simple repeater that broadcasts incoming signals to all ports ✅
C. A Layer 3 device that routes IP packets
D. A device that creates virtual LANs

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A hub operates at the physical layer and simply repeats electrical signals to every port. It does not examine MAC addresses or IP information, so it broadcasts any incoming frame to all connected devices. This basic behavior distinguishes it from switches or routers, which perform selective forwarding.

Q2. When a hub connects multiple devices, which statement about the broadcast domain is true?

A. The broadcast domain is divided per port
B. Broadcast frames are blocked
C. Each device forms a separate broadcast domain
D. All devices share the same broadcast domain ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

A hub does not segment traffic; it forwards broadcast frames to every port. Consequently, all devices attached to the hub belong to a single broadcast domain, meaning a broadcast sent by any one device is received by all others. This lack of segmentation is a key limitation of hubs.

Q3. A network uses a switch that inadvertently creates a loop between two ports. What immediate consequence is most likely?

A. MAC address table becomes unstable, leading to broadcast storms ✅
B. Switch will drop all frames
C. Loop will be automatically resolved by the switch
D. Only unicast traffic is affected

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When a loop exists, frames can circulate indefinitely, causing the switch’s MAC address table to learn incorrect locations. This instability generates excessive broadcast traffic, known as a broadcast storm, which can saturate the network and degrade performance. Protocols such as STP are designed to prevent this condition.

Q4. Given a LAN where a broadcast domain is split into two VLANs using a layer‑2 switch, if a device in VLAN 1 sends an ARP request, which of the following statements is correct?

A. The ARP request is flooded to all ports, including VLAN 2
B. The ARP request is sent only to the switch’s CPU and not to any host
C. The ARP request is confined to VLAN 1 and will not reach VLAN 2 ✅
D. The ARP request triggers a spanning‑tree recalculation

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

VLANs partition a physical LAN into separate logical broadcast domains. An ARP request is a broadcast frame, so it is confined to the VLAN of the originating device. Devices in other VLANs never see the request unless inter‑VLAN routing is explicitly provided, preserving isolation.

Q5. Compare the impact on network performance when using a hub versus a switch in a LAN of 10 devices. Which statement accurately reflects the difference?

A. Both devices forward frames to all ports, causing the same level of collisions
B. A switch forwards frames only to the destination port, reducing collisions and enabling higher throughput compared to a hub that broadcasts to all ports ✅
C. A hub provides full‑duplex communication, while a switch only supports half‑duplex
D. Switches increase latency due to MAC address learning, whereas hubs have zero latency

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A switch learns MAC addresses and sends frames only to the intended recipient, dramatically reducing the chance of collisions and allowing multiple simultaneous conversations. In contrast, a hub repeats every frame to all ports, forcing all devices to share the medium and creating frequent collisions.

Q6. Evaluate the advantages of implementing VLANs over using separate physical LANs. Which of the following best captures a key benefit?

A. VLANs eliminate the need for any routing
B. VLANs increase the number of required network cables
C. VLANs provide better physical security by isolating devices in different rooms
D. VLANs allow logical segmentation without additional hardware, simplifying management ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

VLANs enable administrators to partition a single physical switch into multiple logical networks, reducing the need for extra cabling, switches, or routers. This logical segmentation simplifies configuration, lowers equipment costs, and makes it easier to apply policies uniformly across devices that share the same physical infrastructure.

Q7. Differentiate between a broadcast domain and a collision domain in a switched network that employs VLANs. Which statement correctly distinguishes them?

A. A broadcast domain is limited by VLAN membership, while a collision domain exists per switch port ✅
B. Collision domains are defined by VLAN tags, whereas broadcast domains are defined by MAC addresses
C. Both domains are identical in a switched environment
D. VLANs merge multiple collision domains into a single broadcast domain

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

In a switched environment, each port constitutes its own collision domain because frames are buffered and transmitted without contention. Broadcast domains, however, are defined by VLAN membership; all ports belonging to the same VLAN share a single broadcast domain. This separation allows simultaneous, collision‑free communication while still controlling broadcast propagation.

Q8. Apply the principle of VLAN tagging to design a network where two departments share the same physical switch but must remain isolated. Which configuration achieves this?

A. Assign both departments to the same VLAN and enable port security
B. Use a router to filter traffic between the departments without VLANs
C. Create separate VLAN IDs for each department and configure trunk ports to carry both tags ✅
D. Disable spanning‑tree on the switch to prevent inter‑department traffic

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

By assigning each department a unique VLAN ID, the switch can tag frames accordingly. Trunk ports carry traffic for multiple VLANs, preserving isolation while using the same physical infrastructure. Devices in one VLAN never receive frames from the other VLAN, ensuring logical separation without additional hardware.

Q9. Explain how VLANs can enhance network security in a campus environment. Which mechanism directly contributes to this improvement?

A. VLANs increase the speed of Ethernet frames
B. VLANs restrict broadcast traffic to specific groups, limiting exposure of sensitive data ✅
C. VLANs replace the need for firewalls
D. VLANs convert Layer 2 frames into Layer 3 packets

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

By confining broadcast traffic to the members of a particular VLAN, sensitive information is less likely to be disseminated across the entire campus network. This containment reduces the attack surface, as potential eavesdroppers outside the VLAN cannot receive the broadcasts, thereby strengthening overall security posture.

Q10. Which advantage of using a link‑layer switch over a hub directly supports the creation of virtual LANs?

A. Switches can operate at Layer 3 to route between VLANs
B. Switches provide higher voltage output for longer cables
C. Switches automatically encrypt all traffic
D. Switches support VLAN tagging, enabling logical separation without additional devices ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

Link‑layer switches understand IEEE 802.1Q tagging, allowing administrators to assign ports to specific VLANs. This capability creates distinct logical networks on the same hardware, something hubs cannot achieve because they lack any intelligence to process tags or manage separate broadcast domains.
