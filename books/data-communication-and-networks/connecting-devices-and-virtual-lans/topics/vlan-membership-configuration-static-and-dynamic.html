Q1. Which device uses a forwarding table to make filtering decisions?

🔹 A. Link-layer switch
🔹 B. Repeater
🔹 C. Hub
🔹 D. Router

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A link-layer switch maintains a MAC address table that maps each address to a specific port, allowing it to filter frames and forward them only where needed. Repeaters and hubs simply repeat signals without any table, while routers operate at a higher layer and use routing tables, not MAC forwarding tables.

Q2. Why does a transparent switch appear invisible to connected stations?

🔹 A. It disables MAC address learning.
🔹 B. It forwards all frames to every port.
🔹 C. It learns MAC addresses but forwards frames only to the appropriate port.
🔹 D. It encrypts frames before forwarding.

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

A transparent switch learns the source MAC address of each incoming frame and updates its table, but it forwards frames only to the port associated with the destination MAC. Because stations receive frames exactly as they would from a hub, they do not detect the presence of the switch, making it \transparent.\

Q3. Which of the following statements correctly contrasts a repeater with a link-layer switch?

🔹 A. Both devices maintain MAC address tables to filter traffic.
🔹 B. A repeater forwards frames to all ports, while a switch forwards frames only to the destination port.
🔹 C. A switch amplifies signals, whereas a repeater only forwards frames based on MAC addresses.
🔹 D. Both devices can block broadcast frames.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A repeater operates at the physical layer and simply regenerates incoming signals to all other ports, providing no filtering capability. In contrast, a link-layer switch works at layer 2, maintains a forwarding table, and directs each frame to the specific port associated with the destination MAC address, reducing unnecessary traffic.

Q4. A frame destined for MAC address \(71:2B:13:45:61:42\) arrives at port 1 of a switch whose table maps this address to port 2. What will the switch do with the frame?

🔹 A. Flood the frame out of all ports except port 1.
🔹 B. Discard the frame.
🔹 C. Forward the frame only out of port 2.
🔹 D. Send the frame back out of port 1.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Since the switch’s table indicates that the destination MAC is reachable via port 2, the switch will forward the frame exclusively to that port, avoiding unnecessary duplication on other ports. Flooding is reserved for unknown destinations, and discarding would violate correct forwarding behavior.

Q5. If a switch receives a frame for MAC address \(64:2B:13:45:61:13\) and this address is absent from its forwarding table, what action does the switch take?

🔹 A. Forward the frame only to the port where the source MAC was learned.
🔹 B. Flood the frame out of all ports except the incoming port.
🔹 C. Drop the frame silently.
🔹 D. Send an ARP request for the missing MAC.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When the destination MAC is unknown, the switch cannot determine the correct outgoing port, so it resorts to flooding: sending the frame out of every port except the one it arrived on. This ensures the frame reaches its destination while the switch learns the correct port from any reply.

Q6. A network adds a new station with MAC \(AA:BB:CC:DD:EE:FF\) connected to port 3. After the station sends a frame, how does the switch’s table change?

🔹 A. An entry for \(AA:BB:CC:DD:EE:FF\) is added mapping to port 3.
🔹 B. All existing entries are removed.
🔹 C. The switch creates a broadcast entry for all ports.
🔹 D. The switch forwards the frame to port 2 only.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When a station transmits, the switch observes the source MAC and the incoming port, updating its forwarding table with a new entry that associates that MAC address with port 3. This learning process does not affect existing entries or create broadcast entries; it simply expands the table.

Q7. How does MAC address learning influence the switch’s ability to reduce unnecessary traffic on a LAN?

🔹 A. It enables the switch to encrypt frames, preventing eavesdropping.
🔹 B. It allows the switch to forward frames only to the port where the destination resides.
🔹 C. It forces the switch to broadcast all frames to every port.
🔹 D. It makes the switch operate as a router.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

By learning which MAC addresses are reachable through which ports, the switch can direct each frame precisely to the destination’s port, eliminating the need to broadcast or flood frames across all ports. This selective forwarding minimizes collision domains and improves overall network efficiency.

Q8. In a LAN with four stations connected to a link-layer switch, how many frames will be transmitted on the wire when the switch receives a broadcast frame?

🔹 A. One frame, because the switch forwards it only once.
🔹 B. Four frames, one out each port.
🔹 C. Three frames, out all ports except the incoming one.
🔹 D. Zero frames, broadcast frames are dropped.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

A broadcast frame is destined for all stations, so the switch forwards it out every port except the one on which it was received. With four ports total, the incoming port is excluded, resulting in three copies being transmitted, ensuring every other station receives the broadcast.

Q9. Given a switch table: {MAC → Port} = {71:2B:13:45:61:41 → 1, 71:2B:13:45:61:42 → 2, 64:2B:13:45:61:12 → 3}. If a frame for MAC \(64:2B:13:45:61:12\) arrives at port 4, what will be the state of the table after processing the frame?

🔹 A. The entry for \(64:2B:13:45:61:12\) changes to port 4.
🔹 B. A new entry for the source MAC is added mapping to port 4, while the destination entry stays as port 3.
🔹 C. The table remains unchanged because the destination MAC is already known.
🔹 D. All entries are cleared and rebuilt.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When the switch receives a frame, it updates the source MAC entry, not the destination. The destination MAC \(64:2B:13:45:61:12\) is already present and continues to map to port 3. The switch will therefore add a new entry for the frame’s source address pointing to port 4, leaving the existing destination mapping unchanged.

Q10. Two frames arrive simultaneously: Frame 1 at port 1 destined for MAC \(71:2B:13:45:61:41\) and Frame 2 at port 2 destined for MAC \(71:2B:13:45:61:42\). The switch’s table maps \(71:2B:13:45:61:41\) → 1 and \(71:2B:13:45:61:42\) → 2. What is the outcome?

🔹 A. Both frames are flooded to all ports.
🔹 B. Frame 1 is forwarded to port 2 and Frame 2 to port 1.
🔹 C. Each frame is forwarded back out the same port it arrived on.
🔹 D. Each frame is forwarded out the port indicated by the table, so Frame 1 stays on port 1 and Frame 2 stays on port 2.

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

The switch consults its forwarding table for each destination MAC. Since both MAC addresses are already associated with the ports on which the frames arrived, the switch forwards each frame out the same port, effectively delivering them to the intended recipients without flooding. This demonstrates correct table-driven forwarding even under simultaneous arrivals.
