Q1. Which of the following is NOT one of the three criteria that a system with transparent switches must satisfy according to the 802.1d specification?

🔹 A. Frames must be forwarded from one station to another.
🔹 B. The forwarding table must be manually configured by the administrator.
🔹 C. Loops in the system must be prevented.
🔹 D. The forwarding table is automatically built by learning frame movements.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The 802.1d specification requires automatic learning, proper forwarding, and loop prevention. Manual configuration of the forwarding table contradicts the automatic learning requirement, making option B the statement that does NOT belong among the three criteria.

Q2. If a station never transmits any frame, what is the most likely result regarding its entry in a switch’s dynamic MAC table?

🔹 A. The entry will be created after the switch receives a frame addressed to the station.
🔹 B. The entry will be created immediately after the switch powers on.
🔹 C. No entry will ever be created for that station.
🔹 D. The switch will broadcast an ARP request to discover the station.

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Dynamic learning relies on observing source MAC addresses in incoming frames. When a station never sends a frame, the switch never sees its source address, so it cannot create a mapping. Consequently, the station will have no entry in the MAC table, which matches option C.

Q3. In a network with two redundant switches forming a loop, what is the immediate effect when a broadcast frame is sent from a host?

🔹 A. The frame will circulate indefinitely, causing a broadcast storm.
🔹 B. The frame will be blocked by the switches due to MAC address changes.
🔹 C. The frame will be forwarded only once and then discarded.
🔹 D. The frame will be delivered to the destination host without duplication.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Because transparent switches do not alter MAC addresses, a broadcast frame received on one side of the loop is forwarded out the other side, re‑entering the first switch and repeating the process. This endless circulation creates a broadcast storm, which is described by option A.

Q4. Which statement best contrasts static MAC address tables with dynamic learning tables in switches?

🔹 A. Static tables require periodic refresh, while dynamic tables never expire entries.
🔹 B. Static tables are populated automatically, whereas dynamic tables need manual entry.
🔹 C. Static tables need manual configuration for each address, while dynamic tables learn addresses from traffic.
🔹 D. Static tables support VLAN tagging, whereas dynamic tables do not.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Static tables are built by an administrator who manually enters each MAC‑port mapping, making them inflexible when devices change. Dynamic tables, by contrast, observe source addresses in passing frames and automatically create or update entries, providing adaptability. Option C captures this fundamental contrast.

Q5. Why is the Spanning Tree Protocol (STP) essential in a network that employs redundant transparent switches?

🔹 A. It encrypts MAC addresses to prevent loops.
🔹 B. It disables all redundant links permanently.
🔹 C. It dynamically blocks selected ports to eliminate loops while preserving redundancy.
🔹 D. It converts MAC addresses to IP addresses for routing.

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

STP builds a logical tree by electing a root bridge and disabling certain ports (blocking them) so that only one active path exists between any two LAN segments. This eliminates loops while still allowing the redundant links to be re‑enabled automatically if a primary link fails, matching option C.

Q6. When a switch receives a frame whose destination MAC address is unknown, what action does it take according to the learning process?

🔹 A. Drop the frame silently.
🔹 B. Forward the frame out only the port where the source MAC was learned.
🔹 C. Flood the frame out of all ports except the one it arrived on.
🔹 D. Send an ICMP unreachable message to the source.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

If the destination MAC is not found in the forwarding table, the switch cannot make a directed forwarding decision. The standard behavior is to flood the frame out of every port except the inbound one, ensuring the frame reaches its destination if reachable. This behavior is described by option C.

Q7. Assume a network has 5 stations (A‑E) each connected to a single switch. Each station sends one frame to a different station before any entries exist. After these frames, how many MAC entries will the switch have?

🔹 A. 5 entries, because each source MAC is learned.
🔹 B. 4 entries, because the destination of the last frame is unknown.
🔹 C. 10 entries, because both source and destination are learned.
🔹 D. 0 entries, because learning only occurs after a broadcast.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

During each transmission, the switch learns the source MAC address and associates it with the incoming port. Five stations each send a frame, providing five distinct source MACs. Destinations are not learned from the frame’s destination field, so only the five source addresses are stored, yielding five entries as stated in option A.

Q8. If a switch already has an entry mapping MAC address X to port 2, and later receives a frame with source MAC X arriving on port 3, what will the switch do?

🔹 A. Ignore the frame as a duplicate.
🔹 B. Update the entry to map X to port 3.
🔹 C. Create a new entry for X on port 3 without removing the old one.
🔹 D. Drop the frame due to MAC address conflict.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Switches continuously refresh their MAC tables. When the same source MAC appears on a different port, the switch assumes the device has moved and updates the existing entry to reflect the new port. This dynamic updating prevents stale mappings and matches option B.

Q9. What is the primary difference between flooding a frame and forwarding it based on a learned MAC entry?

🔹 A. Flooding sends the frame to all ports, forwarding sends it only to the specific port associated with the destination MAC.
🔹 B. Flooding encrypts the frame, forwarding does not.
🔹 C. Flooding occurs only on routers, forwarding only on switches.
🔹 D. Flooding requires a VLAN tag, forwarding does not.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

When a destination MAC is unknown, the switch floods the frame out every port except the inbound one, ensuring it reaches the correct destination. Once the MAC is learned, the switch forwards the frame solely through the port mapped to that address, which is precisely the distinction described in option A.

Q10. Explain why loops cause broadcast storms in a network of transparent switches that do not modify MAC addresses.

🔹 A. Loops cause frames to be duplicated and forwarded endlessly because each switch treats the frame as new, leading to exponential growth of broadcasts.
🔹 B. Loops cause switches to drop all frames, preventing communication.
🔹 C. Loops force switches to change MAC addresses, which creates address conflicts.
🔹 D. Loops cause the spanning tree protocol to disable all ports.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Transparent switches forward frames unchanged; when a broadcast frame enters a loop, each switch repeatedly forwards it out all other ports, causing the same frame to re‑enter the loop multiple times. This recursive forwarding multiplies the number of copies exponentially, generating a broadcast storm as described in option A.
