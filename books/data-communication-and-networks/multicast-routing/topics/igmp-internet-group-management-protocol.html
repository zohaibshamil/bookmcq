📝 IGMP (Internet Group Management Protocol) (8 MCQs)

IGMP Role in IPv4 Multicast Group Management

Internet Group Management Protocol (IGMP) is the IPv4 mechanism through which hosts signal interest in receiving multicast traffic on a directly connected network. Multicast routers use IGMP queries and membership reports to learn which groups have listeners on each interface. This local information helps routers and switches avoid forwarding group traffic onto links without interested receivers. This distinction also shapes multicast path selection and receiver delivery decisions at routers.

Versions and Membership Reporting Behavior

IGMPv1 supports membership queries and reports, while IGMPv2 adds an explicit Leave Group message and group-specific queries. IGMPv3 adds source filtering, allowing a host to request traffic from selected sources or exclude specified sources. IGMP operates locally and uses IPv4 rather than UDP as its encapsulating protocol. These details determine how multicast routers maintain usable group state.

Router Querier and Host Membership Timers

A multicast router periodically sends general queries, and hosts respond with reports for groups they still want. In IGMPv2 and later, a host may send a leave message when its last local application leaves a group. The querier can issue a group-specific query and remove membership after response timers expire.

Joining and Maintaining a Multicast Group

A computer starts an application that joins 239.4.4.4. Its host sends a membership report, and the LAN's querier records listener interest. If the application leaves, IGMPv2 can send a Leave Group message; after checking for other members, the router removes the interface from that group's outgoing list when appropriate. How IGMP Supports Multicast Routing and Switching

IGMP informs IPv4 multicast routers about receivers on local links; multicast routing protocols such as PIM use that state to build trees between routers. Ethernet switches may inspect IGMP messages through snooping to direct multicast frames only to interested ports, but IGMP itself does not route packets between subnets. This relationship keeps membership management separate from data forwarding.

Misconceptions About IGMP Protocol Operation

'IGMP is a transport-layer protocol' is incorrect because it is carried directly in IPv4. 'IGMP sends the multicast application stream' is incorrect because it manages membership only. 'Every host must send a leave message' is incorrect because older versions and normal timeout-based membership expiry do not require explicit leaving in every case.

Comparing IGMP Versions and Membership State

Compare IGMPv1, IGMPv2 and IGMPv3 by their query, report, leave and source-filtering capabilities. Identify the router querier, explain membership timers, and distinguish host-to-router signalling from router-to-router multicast routing and switch-level IGMP snooping. These points help students trace protocol behavior in examination scenarios. Questions often test these details through short packet-forwarding scenarios.

IGMP Version and Membership Terms

  • IGMPv1 - Basic query and report version.
  • IGMPv2 - Adds explicit group leaving.
  • IGMPv3 - Adds source-specific filtering.
  • Querier - Router sending membership queries.
  • Listener - Host receiving group traffic.
  • Source filter - Selects allowed multicast senders.

📝 All IGMP (Internet Group Management Protocol) MCQs

Q1. A host receives an IGMP Membership Query for group 224.0.0.1 but does not send a Membership Report. What can be logically inferred about the host's membership status?

A.The host is still a member of the group
B.The host has left the group or never joined ✅
C.The host will receive the next query only
D.The router will immediately prune the group
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Since the host did not respond, the most reasonable inference is that it is no longer a member of that multicast group. IGMP relies on hosts to report membership; lack of a report signals the router to consider the host absent from the group.

Q2. Which of the following best distinguishes IGMPv2 from IGMPv3 regarding source‑specific multicast handling?

A.IGMPv2 supports source filters, IGMPv3 does not
B.IGMPv3 adds a timeout field absent in IGMPv2
C.IGMPv3 introduces INCLUDE and EXCLUDE mode for source lists ✅
D.Both versions use identical message formats
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: IGMPv3 adds the ability to specify source filters using INCLUDE and EXCLUDE modes, enabling source‑specific multicast. IGMPv2 lacks this capability and only indicates group membership without source information, making option C the accurate distinction.

Q3. Router R receives IGMP Membership Reports for group 224.1.1.1 from hosts on interfaces I1 and I3. How should R construct its multicast forwarding entry for this group?

A.Create a single (S,G) entry with outgoing interfaces I1 and I3 ✅
B.Create separate (S,G) entries for each interface
C.Forward only on I1, ignoring I3
D.Drop the packet until a PIM join is received
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The router aggregates the reports into one (S,G) forwarding state, listing all interfaces where interested receivers exist. This single entry allows efficient replication of multicast packets to both I1 and I3, matching the IGMP design of group‑wide forwarding.

Q4. What does IGMP stand for?

A.Internet Group Management Protocol ✅
B.Internet General Multicast Procedure
C.Interconnected Gateway Management Process
D.Integrated Group Messaging Protocol
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The acronym IGMP expands to Internet Group Management Protocol, which is the standard protocol used by hosts and adjacent routers to manage multicast group memberships on an IP network.

Q5. If the IGMP Query Interval is set to \( \frac{125}{\text{seconds}} \) and the last query was sent at time t=0, at what time will the next query be transmitted?

A.t = 125 seconds ✅
B.t = 250 seconds
C.t = 62.5 seconds
D.t = 500 seconds
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The Query Interval defines the period between successive IGMP queries. With a value of 125 seconds, the next query occurs exactly 125 seconds after the previous one, i.e., at t = 125 s.

Q6. How does IGMP snooping in a Layer‑2 switch affect unnecessary broadcast traffic compared to a switch without snooping?

A.It increases broadcast by replicating IGMP messages
B.It filters multicast frames to only ports with interested receivers ✅
C.It converts multicast to unicast for all ports
D.It has no effect on broadcast traffic
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: IGMP snooping allows the switch to listen to IGMP membership reports and maintain a table of interested ports. Consequently, it forwards multicast frames only to those ports, reducing superfluous broadcast traffic that would otherwise be sent to all ports.

Q7. In a network using PIM Sparse Mode, which statement accurately reflects IGMP's role in establishing multicast distribution trees?

A.IGMP directly builds the source tree, while PIM builds the shared tree
B.IGMP informs routers of group membership, enabling PIM to create (S,G) branches ✅
C.IGMP replaces the need for PIM join/prune messages
D.IGMP only works with dense mode, not sparse mode
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: IGMP provides routers with information about which hosts have joined a particular multicast group. PIM Sparse Mode uses this membership data to construct (S,G) branches of the distribution tree, ensuring packets are forwarded only toward routers with downstream receivers.

Q8. On a multi‑access LAN with multiple routers, how is the IGMP Querier elected and what determines its election timer?

A.The router with the highest IP address becomes the querier, using a 60‑second timer
B.The router with the lowest IP address becomes the querier, using the Query Interval timer ✅
C.Routers randomly select a querier each 30 seconds
D.All routers become queriers simultaneously, causing duplicate queries
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: All routers on the LAN compare their IP addresses; the one with the lowest address assumes the querier role. The elected querier then uses the configured Query Interval timer to schedule periodic IGMP queries, preventing multiple routers from sending redundant queries.
