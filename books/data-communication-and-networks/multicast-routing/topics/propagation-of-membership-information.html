Q1. Which of the following best describes the split horizon rule in distance‑vector routing?

🔹 A. A node advertises the full routing table to all neighbors.
🔹 B. A node never advertises routes learned from a neighbor back to that same neighbor.
🔹 C. A node advertises only the routes that have a cost of 1.
🔹 D. A node advertises routes with increased metric to avoid loops.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Split horizon prevents a node from sending back to a neighbor any route that was originally learned from that neighbor. By suppressing this information, the neighbor does not reinterpret its own advertisement as a new path, which eliminates the feedback loop that can cause routing instability. This rule is the core of the split‑horizon technique.

Q2. If the link between A and X fails and both A and B believe the other can reach X, what immediate behavior will a packet destined for X exhibit?

🔹 A. It will be delivered to X via a new path.
🔹 B. It will be dropped by A.
🔹 C. It will bounce between A and B forming a loop.
🔹 D. It will be rerouted through a third node.

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

When A and B each think the other provides the shortest path to X, a packet sent toward X is forwarded to the other node, which then forwards it back. This creates a two‑node forwarding loop, causing the packet to circulate indefinitely until TTL expires or the loop is broken by a routing update.

Q3. Which statement correctly contrasts split horizon with poison reverse in handling stale routes?

🔹 A. Split horizon removes the route entry, while poison reverse advertises the route with infinite metric.
🔹 B. Poison reverse removes the route, while split horizon advertises infinite metric.
🔹 C. Both techniques advertise the route with a metric of zero.
🔹 D. Both techniques suppress all advertisements for the route.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Split horizon simply omits the route when sending updates to the neighbor that originally supplied it, leaving the neighbor without that entry. Poison reverse, on the other hand, explicitly advertises the route with a metric of \( \infty \) (or a designated unreachable value) to the same neighbor, signalling that the path should not be used.

Q4. When node A uses poison reverse after the A‑X link fails, what metric does A advertise to neighbor B for destination X?

🔹 A. 1
🔹 B. 2
🔹 C. ∞
🔹 D. 0

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Poison reverse requires the node to announce the unreachable status of a destination by advertising an infinite metric. After the A‑X link fails, A sends an update to B indicating that the cost to reach X is \( \infty \), thereby preventing B from selecting A as a path to X and breaking the potential loop.

Q5. After receiving A’s update that the distance to X is ∞, what distance will node B set for X in its own table before any further updates?

🔹 A. 1
🔹 B. 2
🔹 C. ∞
🔹 D. 0

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When B receives an advertisement stating that the cost to X is \( \infty \), B adopts the same value for its own route to X because distance‑vector protocols propagate the advertised metric directly. This immediate adoption stops B from using any path through A to X, ensuring both nodes agree that X is unreachable.

Q6. If the update timer T is increased substantially while using split horizon, which effect is most likely on network stability after a link failure?

🔹 A. Faster convergence because fewer updates are sent
🔹 B. Slower convergence leading to longer periods of routing loops
🔹 C. Immediate detection of unreachable destinations
🔹 D. No change in convergence time

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A larger timer interval delays the propagation of new routing information. With split horizon, the suppression of certain routes remains in effect longer, so stale information persists. Consequently, nodes may continue to rely on outdated paths, extending the duration of routing loops and slowing overall convergence.

Q7. In a three‑node network A‑B‑C where the link A‑X fails, which combination of techniques guarantees that no two‑node loop will form?

🔹 A. Split horizon only
🔹 B. Poison reverse only
🔹 C. Both split horizon and poison reverse
🔹 D. Neither technique; rely on hold‑down timers

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Using both split horizon and poison reverse together provides complementary protection: split horizon stops a node from advertising a route back to its source, while poison reverse explicitly marks that route as unreachable with an infinite metric. The combined effect ensures that neither A nor B will mistakenly select each other as a path to X, eliminating the two‑node loop.

Q8. What is the term commonly used to describe the phenomenon where distance‑vector routers gradually increase the cost to an unreachable destination until it becomes infinite?

🔹 A. Route flapping
🔹 B. Count‑to‑infinity
🔹 C. Blackhole routing
🔹 D. Metric overflow

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The gradual escalation of a route’s metric until it reaches \( \infty \) is known as the count‑to‑infinity problem. It arises in distance‑vector protocols when routers repeatedly advertise increasingly larger costs for a destination that has become unreachable, often leading to temporary routing loops before the destination is finally declared unreachable.
