📝 All Multicast Distance Vector (DVMRP) MCQs

Q1. Which equation is employed by DVMRP to recompute distance entries after receiving a neighbor’s vector?

🔹 A. Dijkstra’s shortest‑path equation
🔹 B. Bellman‑Ford equation
🔹 C. Floyd‑Warshall recurrence
🔹 D. Link‑state advertisement rule

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

DVMRP uses the Bellman‑Ford relaxation step, as shown in line 19 of the pseudocode: \( D[y] = \min\bigl(D[y],\,c[\text{myself}][w] + D_w[y]\bigr) \). This equation updates each destination’s distance by comparing the current cost with the cost through neighbor w, ensuring the smallest metric is retained. The other equations belong to different routing families.

Q2. When a node sends its updated distance vector to a neighbor before receiving that neighbor’s latest vector, what primary problem can arise?

🔹 A. Faster convergence
🔹 B. Reduced bandwidth usage
🔹 C. Temporary routing loops
🔹 D. Increased security

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

If a node forwards its new vector before learning the neighbor’s most recent information, it may adopt a stale path that appears valid. The neighbor then incorporates this incorrect metric, causing both nodes to believe they have a viable route when none exists, which creates a temporary routing loop and destabilizes the multicast tree.

Q3. Which statement correctly differentiates DVMRP from traditional unicast distance‑vector routing?

🔹 A. DVMRP forwards vectors only to directly connected routers
🔹 B. DVMRP maintains separate tables per multicast group
🔹 C. DVMRP uses source‑specific trees for unicast traffic
🔹 D. DVMRP relies on link‑state advertisements

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Unlike unicast distance‑vector protocols that keep a single routing table for all destinations, DVMRP keeps distinct distance vectors for each multicast group, allowing the protocol to manage group‑specific forwarding trees. This per‑group state is essential for efficient multicast distribution, whereas the other statements describe unrelated routing behaviors.

Q4. If the cost \(c[\text{myself}][w]\) of a link to neighbor w increases, what immediate operation does the node perform according to the algorithm?

🔹 A. Broadcast a network‑wide error message
🔹 B. Re‑evaluate each destination using the Bellman‑Ford equation
🔹 C. Discard all entries for destinations reachable via w
🔹 D. Reset its entire distance vector to infinity

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When a link cost changes, the node must recompute the metric for every destination that could use that link. It does this by applying the Bellman‑Ford update: \( D[y] = \min\bigl(D[y],\,c[\text{myself}][w] + D_w[y]\bigr) \). This step ensures that any increased cost is reflected in the distance vector without discarding valid routes outright.

Q5. In the DVMRP pseudocode, the 'wait' step (line 16) primarily represents which of the following?

🔹 A. A fixed timer that expires every 30 seconds
🔹 B. An asynchronous background thread that periodically polls neighbors
🔹 C. A blocking call that pauses execution until a new vector or link change arrives
🔹 D. A checksum verification process for incoming packets

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The 'wait' construct indicates that the node suspends further processing until it either receives a new distance vector \(D_w\) from a neighbor or detects a change in any of its links. This blocking behavior prevents unnecessary CPU cycles and aligns with the event‑driven nature of the distance‑vector update mechanism.

Q6. Consider a network where link A‑X fails and node B sends its updated vector to A before A has processed its own failure. Which logical outcome best describes the ensuing behavior?

🔹 A. A immediately discards B’s update, preserving its old routes
🔹 B. Both A and B enter a deadlock state and stop forwarding packets
🔹 C. A adopts B’s possibly stale path, causing a temporary routing loop
🔹 D. B’s update triggers an instant network‑wide reconvergence

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Because B’s vector still contains a path through the failed link, A incorporates that stale information and believes a route to X exists via B. A then advertises this erroneous path back to B, creating a loop where each node repeatedly trusts the other’s outdated metric until further updates break the cycle.

Q7. Evaluate the impact of using periodic (timer‑driven) updates versus event‑driven (on‑change) updates in DVMRP on convergence speed and bandwidth consumption.

🔹 A. Event‑driven updates are slower and use less bandwidth
🔹 B. Periodic updates are faster but consume more bandwidth
🔹 C. Periodic updates reduce convergence time without affecting bandwidth
🔹 D. Event‑driven updates improve both convergence speed and bandwidth efficiency

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Periodic updates broadcast the full distance vector at regular intervals, allowing nodes to learn about failures quickly, which speeds convergence. However, this regular transmission consumes more bandwidth even when the network is stable. Event‑driven updates only send information after a change, reducing traffic but potentially delaying awareness of failures, resulting in slower convergence.

Q8. Node A has current distance \(D[y]=10\) to destination y. It receives from neighbor w a distance \(D_w[y]=5\) and the link cost \(c[\text{myself}][w]=2\). According to the Bellman‑Ford step, what will be the new value of \(D[y]\)?

🔹 A. 10
🔹 B. 12
🔹 C. 5
🔹 D. 7

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Applying the Bellman‑Ford relaxation: \(D[y] = \min(10,\;2+5) = \min(10,7) = 7\). The algorithm selects the smaller metric, so the distance to destination y is reduced from 10 to 7 after incorporating the neighbor’s advertised cost plus the local link cost.

Q9. How does increasing the number of destinations \(N\) affect the computational complexity of the DVMRP update loop for a single node?

🔹 A. Complexity remains constant regardless of N
🔹 B. Complexity grows linearly with N
🔹 C. Complexity grows quadratically with N
🔹 D. Complexity decreases as N increases

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The algorithm contains a loop that iterates from \(y = 1\) to \(N\) (lines 17‑20). Each iteration performs a constant‑time Bellman‑Ford relaxation, so the total work scales proportionally to the number of destinations. Therefore, the per‑node computational effort grows linearly with \(N\).

Q10. When a node receives conflicting distance vectors for the same destination from multiple neighbors, which rule does DVMRP apply to select the preferred entry?

🔹 A. Randomly select one of the received entries
🔹 B. Choose the entry with the highest hop count
🔹 C. Pick the entry that yields the smallest metric after adding the respective link cost
🔹 D. Select the entry advertised by the neighbor with the lowest interface index

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

DVMRP follows the Bellman‑Ford principle: for each destination it computes \(c[\text{myself}][w] + D_w[y]\) for every neighbor w and retains the minimum result. This metric‑based comparison ensures the most efficient path is chosen, regardless of which neighbor supplied it.

Q11. To prevent routing loops in multicast traffic, which conceptual modification could be integrated into the DVMRP algorithm?

🔹 A. Disable the Bellman‑Ford update step
🔹 B. Replace distance vectors with static routes only
🔹 C. Introduce split horizon with poison reverse for multicast entries
🔹 D. Broadcast the entire network topology to all nodes

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Applying split horizon with poison reverse means a node will not advertise a route back to the neighbor from which it originally learned that route, and will explicitly mark it as unreachable. This technique eliminates the possibility that two neighboring routers repeatedly convince each other that a failed path still exists, thereby breaking the loop formation.

Q12. Given a simple network: A—1—B—2—C (link costs shown). Initially, all nodes have distances to C set to infinity except C (zero). After one iteration of the DVMRP update, what is A’s distance to C?

🔹 A. 2
🔹 B. Infinity
🔹 C. 1
🔹 D. 3

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

During the first iteration, B learns from C that \(D_C[C]=0\) and updates its own distance to C as \(1+0=2\). A then receives B’s updated distance (2) and adds the cost of the A‑B link (1), yielding \(1+2=3\). Hence, after one round, A’s distance to C becomes 3.

Q13. Why does DVMRP transmit the entire distance vector to all neighbors only after detecting a change, rather than after every receipt of a neighbor’s vector?

🔹 A. To ensure that every neighbor receives the same vector simultaneously
🔹 B. To allow neighbors to aggregate vectors before forwarding
🔹 C. To comply with a fixed schedule mandated by the protocol
🔹 D. To minimize unnecessary processing and reduce routing update traffic

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Sending updates only when a metric actually changes avoids redundant transmissions, which conserves bandwidth and CPU cycles on both the sender and receivers. This event‑driven behavior aligns with the protocol’s design goal of efficiency, whereas unconditional forwarding after each reception would generate excessive traffic without adding new information.

Q14. Design an extension to DVMRP that supports Quality of Service (QoS) by incorporating bandwidth reservations. Which of the following changes is essential?

🔹 A. Replace the distance vector mechanism with a link‑state advertisement
🔹 B. Use a single shared vector for all QoS classes without modification
🔹 C. Eliminate the 'wait' condition and send updates continuously
🔹 D. Append a bandwidth field to each distance vector entry and modify the Bellman‑Ford comparison to consider both cost and available bandwidth

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

QoS‑aware DVMRP must convey not only cost but also the amount of residual bandwidth a path can provide. By adding a bandwidth attribute to each vector entry and adjusting the selection rule to prefer routes that satisfy both cost and bandwidth constraints, the protocol can make informed multicast forwarding decisions that honor reservation requirements.

Q15. Prove that, in a network without negative‑cost cycles, the Bellman‑Ford update used by DVMRP converges to the optimal distances after at most \(N-1\) iterations. Which key property underlies this guarantee?

🔹 A. The triangle inequality holds for all link costs
🔹 B. Each iteration can improve the distance of at most one destination
🔹 C. Link costs are always prime numbers
🔹 D. A shortest path contains at most \(N-1\) edges

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

In any graph with \(N\) nodes, a simple shortest path cannot contain more than \(N-1\) edges; otherwise a cycle would exist. The Bellman‑Ford relaxation propagates optimal distances along paths of increasing length, and after each iteration paths of length \(k\) are correctly evaluated. Consequently, after \(N-1\) iterations all possible simple paths have been examined, guaranteeing convergence to the true shortest‑path metrics.

Q16. In a scenario where A and B simultaneously exchange updated vectors after a link failure, leading to instability, what is the root cause and what mitigation strategy does the algorithm recommend?

🔹 A. Root cause is simultaneous updates causing count‑to‑infinity; mitigation is to use a hold‑down timer before accepting new information
🔹 B. Root cause is incorrect cost calculation; mitigation is to reset all vectors
🔹 C. Root cause is lack of authentication; mitigation is to encrypt vectors
🔹 D. Root cause is hardware failure; mitigation is to replace the router

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When both routers update each other before confirming the failure, they may continually advertise increasingly larger metrics—a count‑to‑infinity problem. The standard remedy is to employ a hold‑down timer that suppresses acceptance of new routes for a destination until the timer expires, allowing the network to stabilize and preventing the loop from persisting.
