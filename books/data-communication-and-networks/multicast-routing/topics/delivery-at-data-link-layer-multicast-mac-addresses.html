What is Delivery at Data Link Layer multicast MAC addresses?

At the data link layer, multicast IP addresses are mapped to special multicast MAC addresses that begin with 01:00:5E so that network interface cards can recognize and accept frames destined for a multicast group without processing every frame on the segment.

Q1. What is the primary function of the data‑link layer in the OSI model?

A. To provide reliable node‑to‑node data transfer ✅
B. To route packets between networks
C. To encrypt data for security
D. To assign IP addresses to hosts

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The data‑link layer is responsible for framing, error detection, and reliable transmission between directly connected nodes, which matches option A. Routing (option B) belongs to the network layer, encryption (option C) to the presentation layer, and IP address assignment (option D) to the network layer. Therefore, option A correctly describes its primary function.

Q2. Node B currently has a cost of 3 to reach destination X via neighbor A. It receives a vector from neighbor E indicating a cost of 5 to X. Assuming B uses the Bellman‑Ford update rule, what cost will B store for X after processing the received vector?

A. 8
B. 5
C. 3 ✅
D. 6

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

According to the Bellman‑Ford rule, a node selects the minimum cost among its current entry and the sum of the neighbor’s advertised cost plus the link cost to that neighbor. Since B already has a cost of 3, which is lower than the new path cost (5 plus the link cost, assumed 1), B retains the value 3. Thus option C is correct.

Q3. Which statement best explains why distance‑vector routing suffers from the count‑to‑infinity problem while link‑state routing does not?

A. Distance‑vector updates propagate instantly, while link‑state requires periodic flooding
B. Link‑state protocols avoid count‑to‑infinity by maintaining a complete topology map ✅
C. Both protocols suffer equally from slow convergence after a link failure
D. Distance‑vector protocols use Dijkstra’s algorithm, unlike link‑state

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Link‑state protocols maintain a full view of the network topology, allowing each router to recompute shortest paths instantly when a link changes, thereby preventing the gradual increase of costs seen in distance‑vector protocols. This complete map eliminates the count‑to‑infinity phenomenon, making option B the accurate description.

Q4. In split horizon with poison reverse, what effect does the technique have on a router’s advertised vector for a destination learned from a particular neighbor?

A. It doubles the convergence time
B. It eliminates the need for periodic updates
C. It prevents a node from advertising a route back to the neighbor from which it was learned ✅
D. It causes the cost to be set to zero for all destinations

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Poison reverse modifies split horizon by advertising an infinite metric (e.g., \( \infty \)) back to the neighbor that originally supplied the route, thus preventing that neighbor from using the route and creating a loop. This directly corresponds to option C, which describes the preventive advertising behavior.

Q5. If the cost of link AB increases from 2 to 7, what immediate effect does this have on the vector advertised by node A?

A. A will immediately send a vector with cost 7 for destinations reachable via B ✅
B. A will keep sending the old cost until the next timer expires
C. A will discard all entries in its vector
D. A will broadcast the change to all nodes in the network

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

When a link cost changes, the originating router updates its distance vector to reflect the new metric. Node A therefore advertises the increased cost of 7 for any destination that uses link AB, which is precisely described in option A.

Q6. How does the order in which nodes initialize their distance vectors influence the overall convergence time of the network?

A. Initializing vectors in alphabetical order guarantees fastest convergence
B. Random initialization can increase the number of update cycles ✅
C. The order does not affect convergence because updates are asynchronous
D. Initializing with maximum costs leads to immediate count‑to‑infinity

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When nodes start with arbitrary costs, some may already have accurate paths while others do not, causing extra propagation of updates. Random or suboptimal ordering can therefore require more cycles before all routers agree on the shortest paths, making option B the correct assessment.

Q7. Which statement correctly contrasts half‑duplex and full‑duplex operation regarding collision handling at the data‑link layer?

A. Half‑duplex uses CSMA/CD while full‑duplex disables collision detection ✅
B. Full‑duplex requires CSMA/CD
C. Both use token passing
D. Half‑duplex cannot detect collisions

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

In half‑duplex Ethernet, stations share the medium and employ CSMA/CD to detect and recover from collisions. Full‑duplex links provide separate transmit and receive channels, eliminating collisions and therefore disabling CSMA/CD. Option A captures this distinction accurately.

Q8. Consider a linear network A‑B‑C where A’s vector lists a cost of 2 to reach C via B. If the B‑C link fails, after how many update cycles will A correctly set its cost to infinity for C?

A. After the first update cycle
B. After two update cycles ✅
C. After three update cycles
D. It never learns the correct cost

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When B detects the loss of its link to C, it advertises an infinite metric for C. In the next cycle A receives this update and revises its entry to infinity. Therefore, A learns the correct cost after two update cycles, matching option B.

Q9. Regarding memory consumption, which statement accurately compares distance‑vector and link‑state routing?

A. Distance‑vector requires \( O(N) \) entries per router, while link‑state needs \( O(N^2) \) total
B. Link‑state stores a full adjacency matrix, consuming more memory per router ✅
C. Distance‑vector stores the entire network topology on each router
D. Both protocols have identical memory requirements

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Link‑state protocols maintain a complete view of the network topology, typically as an adjacency list or matrix, which consumes more memory on each router than the simple distance vectors that only store a single cost per destination. Hence option B correctly describes the memory difference.

Q10. How does a MAC address facilitate delivery at the data‑link layer?

A. MAC addresses are used by the data‑link layer to deliver frames within the same broadcast domain ✅
B. MAC addresses are assigned by the network layer
C. MAC addresses change at each hop
D. MAC addresses are only used in routing tables

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The data‑link layer encapsulates packets into frames that contain source and destination MAC addresses. Switches use these addresses to forward frames within the local network segment (broadcast domain). This role is captured in option A, making it the correct answer.

Q11. In a three‑node network A‑B‑C, A’s vector shows a cost of 2 to C via B. After the B‑C link fails, what will A’s vector indicate after two update cycles?

A. A will still believe it can reach C via B
B. A will update cost to infinity ✅
C. A will discover an alternate path through another neighbor
D. A will stop sending any frames to C

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When B learns that its link to C is down, it advertises an infinite metric for C. A receives this information in the subsequent update cycle and changes its cost entry for C to infinity. After two cycles the update is confirmed, so option B is correct.

Q12. Which of the following best differentiates broadcast from unicast at the data‑link layer?

A. Broadcast frames are sent to a single MAC address, unicast to all
B. Broadcast uses a special MAC address FF:FF:FF:FF:FF:FF, unicast uses a specific destination MAC ✅
C. Unicast frames are duplicated, broadcast are not
D. Both are identical at the data‑link layer

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Broadcast frames employ the reserved MAC address FF:FF:FF:FF:FF:FF, causing all devices on the LAN to process the frame, whereas unicast frames contain a unique destination MAC address intended for a single recipient. This distinction is correctly described in option B.

Q13. To design a hybrid routing protocol that combines distance‑vector and link‑state advantages, which property is essential?

A. The hybrid must support periodic full‑mesh updates
B. It must combine distance‑vector’s periodic updates with link‑state’s topology awareness ✅
C. It must eliminate all vector exchanges
D. It must rely solely on MAC address learning

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A hybrid protocol seeks to retain the fast convergence of link‑state (through topology awareness) while preserving the simplicity of distance‑vector’s periodic updates. Therefore, integrating both periodic vector exchanges and topology information, as described in option B, is the key requirement.
