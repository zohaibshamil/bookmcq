What is Protocol Independent Multicast (PIM) sparse and dense mode?

PIM operates independently of any unicast routing protocol and offers dense mode, which floods traffic everywhere and prunes unwanted branches for densely populated groups, and sparse mode, which uses explicit join messages toward a rendezvous point for sparsely distributed receivers to conserve bandwidth.

Q1. What does PIM stand for?

A.Protocol Independent Multicast ✅
B.Peer Interface Management
C.Packet Interchange Method
D.Primary Internet Module
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The acronym PIM expands to Protocol Independent Multicast. It is a family of routing protocols that operate independently of any specific unicast routing protocol, allowing multicast distribution without being tied to a particular underlying algorithm. The other options are fabricated and do not correspond to the standard definition.

Q2. Which PIM mode builds a shortest‑path tree rooted at the source?

A.Dense Mode
B.Sparse Mode ✅
C.Source‑Specific Multicast
D.Bidirectional Mode
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: PIM Sparse Mode (PIM‑SM) creates a shortest‑path tree (SPT) that is rooted at the source when a source‑specific join is performed. Dense Mode initially floods the network and then prunes, while Source‑Specific Multicast is a variant of Sparse Mode that restricts joins to specific sources. The correct answer is Sparse Mode.

Q3. A router receives a Join message on an interface that previously sent a Prune for the same (S,G). What does this indicate about downstream traffic?

A.The traffic has ceased permanently
B.The source has moved to a different network
C.New receivers have joined downstream, prompting the router to request the source again ✅
D.The previous Prune was erroneous and will be ignored
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Receiving a Join after a Prune signals that downstream hosts have newly expressed interest in the (S,G) flow. The router therefore reinstates the upstream path by sending a Join toward the source, ensuring that packets resume delivery. This reflects a change in downstream demand, not a permanent cessation of traffic.

Q4. Compare PIM Dense Mode and Sparse Mode in terms of initial packet propagation strategy. Which statement is accurate?

A.Dense Mode builds a shared tree first, Sparse Mode builds source‑specific trees immediately
B.Dense Mode uses explicit Join messages, Sparse Mode relies on flooding
C.Both modes flood the network initially then prune based on demand
D.Dense Mode floods initially then prunes, while Sparse Mode builds trees only after explicit Join messages ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: PIM Dense Mode (PIM‑DM) starts by flooding multicast traffic to all routers and then removes unnecessary branches through Prune messages. In contrast, PIM Sparse Mode (PIM‑SM) constructs distribution trees only after receivers send explicit Join messages toward a Rendezvous Point, avoiding unnecessary flooding. Therefore option D correctly captures the differing initial strategies.

Q5. In a PIM Sparse Mode deployment, configuring a single RP influences the multicast distribution tree how?

A.All (S,G) traffic first converges to the RP, forming a shared tree before possibly switching to a source‑specific tree ✅
B.Traffic is sent directly from source to receivers without any RP involvement
C.Each receiver independently selects its own RP, creating multiple parallel trees
D.The RP acts only as a backup and is ignored unless the primary fails
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: When a single Rendezvous Point (RP) is configured in PIM‑SM, every (S,G) flow initially uses a shared tree (RPT) that converges at the RP. Receivers join this tree via Join messages, and after the source is reached, the network may switch to a source‑specific tree for efficiency. The other options misrepresent the RP’s role in the default multicast distribution process.

Q6. If a router discovers that its designated router (DR) for a LAN is also the RP for a given multicast group, what logical consequence follows for Join/Prune processing on that LAN?

A.The router will suppress Join messages because the DR already represents the RP
B.The router will send a Join toward the RP, consolidating Join processing into a single message ✅
C.Prune messages will be ignored, ensuring the tree remains intact
D.The router will generate duplicate Join messages, one for the DR and another for the RP, causing unnecessary traffic
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When the DR and RP coincide, the router can combine their responsibilities, but it must still send a Join toward the RP to build the shared tree. Because the DR is also the RP, the Join does not need to be duplicated; instead, the router sends a single Join that satisfies both roles. This avoids unnecessary traffic while preserving correct tree construction.

Q7. Evaluate the trade‑off between PIM‑DM and PIM‑SM in a bandwidth‑constrained environment. Which choice best minimizes unnecessary traffic?

A.PIM‑DM, because its initial flooding quickly reaches all potential receivers
B.PIM‑SM, because it only creates trees after explicit Join requests ✅
C.A hybrid approach that starts with DM and switches to SM after a threshold
D.Neither, since both modes generate equal traffic regardless of bandwidth
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: In bandwidth‑limited networks, the goal is to avoid flooding traffic that many receivers will discard. PIM Sparse Mode (PIM‑SM) builds distribution trees only after receivers explicitly request them via Join messages, thereby preventing the large amount of unnecessary traffic characteristic of PIM Dense Mode (PIM‑DM). Hence option B best minimizes superfluous traffic.

Q8. When adding a new multicast source to an existing PIM‑SM network, which sequence of steps correctly integrates the source into the shared tree?

A.Configure the RP, send a Prune, then issue a Join toward the RP
B.Register the source with the RP, send a Register message, then the RP forwards the data on the shared tree ✅
C.Directly send data to receivers without contacting the RP
D.First flood the network, then prune unused branches
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The correct integration process in PIM‑SM involves the new source sending a Register message to the RP, which then places the source's traffic onto the shared tree (RPT). Receivers that have expressed interest via Join messages will then receive the data. Option B captures the essential steps of source registration and tree incorporation.

Q9. A router's prune timer expires before a new Join arrives for (S,G). What effect does this have on packet forwarding on the downstream interface?

A.The interface will stop forwarding packets, creating a temporary blackout ✅
B.The router will continue forwarding using the last known state until a Join is received
C.The router will send a gratuitous Join to the upstream neighbor
D.The downstream interface will be marked as inactive but will resume automatically after a fixed interval
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When the prune timer expires without a subsequent Join, the router assumes that no downstream receivers are interested in the (S,G) traffic and therefore ceases forwarding on that interface. This creates a brief period during which packets are not delivered downstream until a new Join re‑establishes the branch, matching option A.

Q10. Contrast Anycast RP and Bootstrap Router (BSR) mechanisms for RP redundancy. Which statement correctly describes a key difference?

A.Anycast RP uses multiple RPs sharing the same IP address, while BSR elects a single RP per group range ✅
B.BSR requires manual configuration of all RPs, whereas Anycast RP discovers RPs automatically
C.Anycast RP provides per‑source filtering, while BSR does not support source‑specific joins
D.Both mechanisms rely on the same underlying protocol and are functionally identical
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Anycast RP works by assigning the same virtual IP address to multiple RP instances; routers select the nearest RP based on unicast routing, providing redundancy without a separate election process. In contrast, the Bootstrap Router (BSR) protocol dynamically elects a single RP for each multicast group range and distributes this information via BSR messages. Therefore option A accurately captures the fundamental distinction.

Q11. Explain how PIM relies on the underlying unicast routing table to determine the outgoing interface for a multicast packet. Which principle best captures this relationship?

A.The multicast forwarding decision is made independently of unicast routes
B.PIM uses the unicast routing table to perform a reverse‑path check and select the IIF for (S,G) traffic ✅
C.PIM builds its own separate topology and ignores unicast information
D.The outgoing interface is always the same as the interface used for the RP address
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: PIM leverages the unicast routing table to perform a Reverse Path Forwarding (RPF) check, which identifies the incoming interface (IIF) that would be used to reach the source. Once the IIF is known, the router selects the appropriate outgoing interface(s) for forwarding the multicast packet. This dependency on unicast routes is captured by option B.

Q12. An incorrect incoming interface (IIF) is configured on a PIM router for a particular source. What is the most likely impact on multicast delivery?

A.Multicast packets will be duplicated on multiple interfaces
B.The router will drop all (S,G) packets, causing a loss of service downstream
C.The router will forward packets but may create routing loops ✅
D.The tree will still function correctly because IIF is optional
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: If the IIF is set incorrectly, the router may forward packets out interfaces that do not lead toward the source, potentially creating loops or forwarding loops. This misconfiguration typically results in inefficient delivery and can cause duplicate traffic or loss, making option C the most accurate description of the impact.
