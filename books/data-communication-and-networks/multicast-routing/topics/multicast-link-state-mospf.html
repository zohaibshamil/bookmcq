Q1. In the MOSPF Bellman‑Ford update shown, what does the term \(c[\text{myself}][w]\) denote?

🔹 A. Cost of the direct link from the current router to neighbor w
🔹 B. Delay incurred by processing the packet
🔹 C. Available bandwidth on the link
🔹 D. Identifier of neighbor w

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The term \(c[\text{myself}][w]\) represents the cost associated with the direct link between the router executing the algorithm (myself) and its neighbor w. This cost is used in the Bellman‑Ford equation to evaluate alternative paths that travel through w, allowing the router to compare link‑level expenses with other possible routes.

Q2. If a router receives a new distance vector from neighbor w that reduces \(D[w][y]\) for some destination y, which of the following statements is most likely true about the router’s own distance \(D[y]\) after applying the Bellman‑Ford equation?

🔹 A. It will always increase
🔹 B. It remains unchanged
🔹 C. It may decrease if the new path through w is shorter
🔹 D. It becomes infinite

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When the neighbor’s advertised distance \(D[w][y]\) becomes smaller, the sum \(c[\text{myself}][w]+D[w][y]\) may drop below the router’s current \(D[y]\). The Bellman‑Ford step then selects the minimum of the old and new values, so the router’s distance can only stay the same or decrease if the new path offers a lower total cost.

Q3. Assume a router has two neighbors w1 and w2 with link costs \(c[\text{myself}][w_1]=2\) and \(c[\text{myself}][w_2]=2\). Both neighbors report \(D[w_i][y]=5\) for destination y. After the Bellman‑Ford update, what is the resulting \(D[y]\) and why?

🔹 A. 5, because the router adopts the neighbor’s distance directly
🔹 B. 2, because the link cost dominates
🔹 C. Infinity, due to ambiguity
🔹 D. 7, because the sum of link cost and neighbor distance is taken

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Each neighbor contributes a candidate cost equal to its link cost plus the advertised distance: \(2+5=7\). The Bellman‑Ford rule selects the smallest candidate, which in this symmetric case is 7. Thus the router updates its distance to y to 7, reflecting the combined cost of reaching the neighbor and then the destination.

Q4. The algorithm sends the updated vector to all neighbors only if any entry in the distance vector changes. Which of the following best explains why this condition helps to limit routing traffic in MOSPF?

🔹 A. It reduces unnecessary transmissions while still propagating needed updates
🔹 B. It prevents loops
🔹 C. It ensures shortest paths are always recomputed
🔹 D. It balances load across the network

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

By transmitting only when a distance entry actually changes, the router avoids sending redundant updates that convey no new information. This selective propagation curtails the volume of routing messages on the network while guaranteeing that any genuine topology or cost change is communicated, thereby maintaining efficiency without sacrificing correctness.

Q5. Consider a network where a link cost suddenly increases from 3 to 8 for the link between the router and neighbor w. According to the Bellman‑Ford step, which immediate effect will be observed on the router’s distance vector entries that previously used w as the next hop?

🔹 A. All such entries will increase by 5
🔹 B. No entries will change until a timeout expires
🔹 C. Only entries where \(c[\text{myself}][w] + D[w][y]\) becomes the new minimum will change
🔹 D. All entries become undefined

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When the link cost rises, the total cost of any path that routes through w becomes higher. The Bellman‑Ford calculation recomputes each candidate as the sum of the new link cost and the neighbor’s distance. Only those entries whose new sum is still the smallest among all alternatives will be retained; others will be replaced by cheaper alternatives, if any exist.

Q6. Suppose a router has three neighbors w1, w2, w3 with link costs 1, 4, and 6 respectively. Their reported distances to destination y are 10, 6, and 3. Using the Bellman‑Ford equation, which neighbor will be selected as the next hop for y and what will be the new \(D[y]\)?

🔹 A. w1 with \(D[y]=11\)
🔹 B. w2 with \(D[y]=10\)
🔹 C. w3 with \(D[y]=9\)
🔹 D. w2 with \(D[y]=6\)

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

For each neighbor, compute the candidate cost: w1 → \(1+10=11\), w2 → \(4+6=10\), w3 → \(6+3=9\). The smallest sum is 9, contributed by w3. Therefore the router selects w3 as the next hop for destination y and updates its distance to 9, reflecting the cheapest known path through w3.

Q7. In MOSPF, the distance vector is sent to all neighbors after any change. How does this behavior interact with the multicast tree construction process, especially regarding loop prevention?

🔹 A. It ensures each router has up‑to‑date path costs, allowing the multicast tree to be built using the shortest‑path tree without loops
🔹 B. It creates redundant data that the tree algorithm ignores
🔹 C. It directly encodes the multicast tree edges
🔹 D. It prevents any multicast traffic from being forwarded

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

By disseminating fresh distance information whenever a change occurs, every router maintains an accurate view of the network’s link costs. The multicast tree can then be derived from the shortest‑path tree, which by definition contains no cycles. Consequently, the timely vector exchanges help prevent loops that could otherwise arise from stale or inconsistent routing data.

Q8. If a router’s current distance to destination y is 15, and a neighbor w advertises \(D[w][y]=12\) with a link cost of 1, what will be the router’s new distance after the update, assuming no other neighbor offers a lower cost?

🔹 A. It will stay at 15
🔹 B. It will become 14
🔹 C. It will become 12
🔹 D. It will become 13

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The candidate cost through w is the sum of the link cost and the neighbor’s distance: \(1+12=13\). Since the router’s existing distance is 15, the Bellman‑Ford rule selects the minimum of 15 and 13, resulting in an updated distance of 13 for destination y.

Q9. When the Bellman‑Ford equation is applied, which of the following operations is performed on each entry of the distance vector?

🔹 A. Addition of link cost to neighbor distance and taking the minimum
🔹 B. Multiplication of link cost and neighbor distance
🔹 C. Division of neighbor distance by link cost
🔹 D. Subtraction of link cost from neighbor distance

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

For every destination, the router computes a candidate cost by adding the cost of the direct link to a neighbor (\(c[\text{myself}][w]\)) and that neighbor’s advertised distance (\(D[w][y]\)). It then compares this sum with its current stored distance and retains the smallest value, effectively performing addition followed by a minimum selection.

Q10. Explain why the term \(\min[ D[y], (c[\text{myself}][w] + D[w][y]) ]\) is crucial for achieving convergence in MOSPF routing.

🔹 A. It guarantees that distances never increase
🔹 B. It provides a way to detect and discard stale updates
🔹 C. It eliminates the need for periodic updates
🔹 D. It ensures each router adopts the shortest known path at each iteration

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The minimum operator forces each router to keep the lowest cost path known at any iteration. By continuously comparing the existing distance with the cost of a new candidate path, the algorithm discards longer routes and adopts shorter ones, driving the network toward a stable set of shortest‑path distances and ensuring eventual convergence.

Q11. Assume a router detects a change in its vector and sends the updated vector to all neighbors. One neighbor, however, does not receive the update due to a temporary link failure. How might this missed update affect the global convergence of MOSPF, and what mechanism helps recover from it?

🔹 A. The neighbor will eventually recompute its vector when the link recovers and the periodic hello messages trigger a resend
🔹 B. The network will never converge; MOSPF lacks recovery
🔹 C. The missed update creates a permanent routing loop
🔹 D. The algorithm ignores the neighbor, treating it as permanently down

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

If a neighbor misses an update, its view becomes outdated, potentially causing a temporary inconsistency. However, MOSPF relies on periodic hello or keep‑alive messages that trigger retransmission of the latest vector once the link is restored. This mechanism ensures the missed information is eventually delivered, allowing the network to reconverge to correct distances.

Q12. What is the primary purpose of the Bellman‑Ford step in the MOSPF algorithm?

🔹 A. To discover multicast group members
🔹 B. To allocate bandwidth for multicast streams
🔹 C. To compute the shortest‑path distances to all destinations
🔹 D. To encrypt routing updates

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The Bellman‑Ford step iteratively updates each router’s distance vector by considering the cost of reaching each destination through each neighbor. Its core function is to calculate the minimum‑cost (shortest‑path) distance to every node in the network, providing the fundamental metric used by MOSPF for efficient multicast routing.
