Q1. What is the primary function of the Bellman‑Ford equation in the distance‑vector routing algorithm?

🔹 A. To discover network topology
🔹 B. To compute the shortest‑path cost to each destination
🔹 C. To encrypt routing updates
🔹 D. To assign IP addresses

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The Bellman‑Ford equation updates each entry D[y] by taking the minimum of the current distance and the sum of the cost to a neighbor plus that neighbor’s distance to y. This process iteratively finds the lowest‑cost paths, which is the core purpose of the algorithm.

Q2. If link (A,X) fails and node A immediately sends its updated table to neighbor B, but B had already sent its old table to A, what is the most likely immediate effect on routing decisions?

🔹 A. A will adopt a longer path through B
🔹 B. B will discard its table
🔹 C. A will experience a temporary routing loop
🔹 D. No effect

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

When B’s outdated table reaches A before A’s new information, A may temporarily believe a path through B is still valid, creating a loop that routes packets back and forth until the newer update supersedes the stale information.

Q3. If a node B sends its forwarding table to A before receiving A’s latest update, which inference best explains why the system may become unstable?

🔹 A. B’s table overrides A’s routes permanently
🔹 B. The network topology changes automatically
🔹 C. A’s routing table is never updated
🔹 D. Updates arrive out of order causing inconsistent distance vectors

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The premature transmission causes A to base its calculations on inconsistent data, leading to mismatched distance vectors. This inconsistency can trigger oscillations or loops until the correct updates propagate, illustrating why ordering of updates matters for stability.

Q4. Which statement correctly contrasts distance‑vector routing with link‑state routing regarding convergence speed after a link failure?

🔹 A. Distance‑vector converges faster because it only updates neighbors
🔹 B. Link‑state converges faster because each node has a complete map
🔹 C. Both converge at the same rate
🔹 D. Distance‑vector never converges

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Link‑state protocols disseminate a full view of the network to every node, allowing each router to recompute shortest paths immediately after a failure. Distance‑vector relies on incremental neighbor updates, which can take many iterations to propagate the change, making convergence slower.

Q5. How does increasing the number of destinations N affect the message overhead in the distance‑vector algorithm?

🔹 A. Overhead grows quadratically with N
🔹 B. Overhead remains constant
🔹 C. Overhead grows linearly with N
🔹 D. Overhead decreases as N increases

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Each routing update carries a vector of size N, and every neighbor receives this vector. Consequently, the total amount of data transmitted grows proportionally to N, yielding linear growth in overhead as the number of destinations expands.

Q6. Which modification to the algorithm best implements the split‑horizon rule to prevent routing loops?

🔹 A. Always send full vector to all neighbors
🔹 B. Do not send a route back to the neighbor from which it was learned
🔹 C. Increase cost of all routes by 1
🔹 D. Broadcast routes only once per minute

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Split horizon forbids a router from advertising a route back to the neighbor from which it originally learned that route. By omitting such entries, the possibility of a loop caused by reciprocal updates is eliminated, enhancing stability.

Q7. Consider a network of three nodes A, B, C with link costs: c[A][B]=2, c[B][C]=3, c[A][C]=10. Initially, each node’s D vector contains only direct costs (∞ for unknown). After one iteration where A receives B’s vector, what is the updated value D_A[C]?

🔹 A. 10
🔹 B. ∞
🔹 C. 2
🔹 D. 5

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

When A processes B’s vector, it computes D_A[C] = min(D_A[C], c[A][B] + D_B[C]) = min(∞, 2 + 3) = 5. This demonstrates the Bellman‑Ford relaxation step, where indirect paths can replace previously unknown or higher‑cost routes.

Q8. What is the key difference between triggered updates and periodic updates in terms of their impact on routing stability?

🔹 A. Periodic updates send all entries at fixed intervals, guaranteeing stability
🔹 B. Triggered updates cause more loops than periodic updates
🔹 C. Triggered updates send only changed entries immediately, reducing convergence time
🔹 D. Periodic updates require no bandwidth

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Triggered updates react instantly to a change, transmitting only the altered entries, which speeds up convergence and reduces the window for inconsistent routes. Periodic updates, while predictable, may delay propagation of critical changes, potentially prolonging instability.

Q9. To collect group information efficiently in a large network, which hybrid approach combines distance‑vector simplicity with link‑state accuracy?

🔹 A. Replace distance‑vector with static routing
🔹 B. Apply only link‑state globally
🔹 C. Never exchange routing information
🔹 D. Use distance‑vector within clusters and link‑state between cluster heads

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

By employing distance‑vector inside each cluster, the protocol remains lightweight, while using link‑state between cluster heads provides a precise global view. This hybrid reduces intra‑cluster overhead yet preserves accurate inter‑cluster routing, balancing scalability and correctness.

Q10. If a node’s distance vector does not change after processing a received vector, what action does the algorithm prescribe?

🔹 A. Send the unchanged vector to all neighbors
🔹 B. Do nothing
🔹 C. Reset all distances to ∞
🔹 D. Broadcast a network failure

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The algorithm includes a conditional check: if no entry in the distance vector is altered, the node refrains from sending any update. This prevents unnecessary traffic and avoids flooding the network with redundant information.

Q11. How does an asynchronous update schedule compare to a synchronous schedule regarding convergence speed in distance‑vector routing?

🔹 A. Synchronous always converges faster due to coordinated rounds
🔹 B. Both have identical convergence characteristics
🔹 C. Asynchronous never converges
🔹 D. Asynchronous can converge faster because updates propagate as soon as they arrive

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

In an asynchronous scheme, a node forwards its updated vector immediately after a change, allowing neighboring nodes to react without waiting for a global round. This continuous flow often shortens the time needed for all routers to achieve consistent distance vectors.

Q12. When a new node joins the network, which step in the distance‑vector algorithm ensures that existing nodes eventually learn routes to the newcomer?

🔹 A. Existing nodes broadcast a reset message
🔹 B. All nodes recalculate shortest paths from scratch
🔹 C. The newcomer sends its initial vector to its neighbors, triggering updates
🔹 D. No action is required

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Upon joining, the new node advertises its initial distance vector (with zero cost to itself) to its immediate neighbors. Those neighbors treat the received information as a change, propagate updated vectors, and the iterative Bellman‑Ford process eventually informs all nodes of routes to the newcomer.
