What is Unicasting vs Multicasting vs Broadcasting?

Unicasting sends data from one source to one specific destination, multicasting sends data from one source to a selected group of destinations, and broadcasting sends data from one source to all devices on the network, with multicasting being more efficient than broadcasting for group communication because it avoids unnecessary traffic.

Q1. Router A is directly connected to Router B with cost 2 and to Router C with cost 5. In the least‑cost tree rooted at A, which edge will definitely not appear?

A. A‑B
B. A‑C ✅
C. Both A‑B and A‑C
D. Neither edge is excluded

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Because the tree must contain the cheapest‑cost path from the root to each node, the edge with the higher cost (A‑C = 5) will be omitted if a cheaper alternative exists. Since A‑B = 2 provides a lower‑cost connection, the algorithm selects it, leaving A‑C out of the tree.

Q2. Consider two possible least‑cost trees for the same network: Tree X has total edge cost \(45\) and Tree Y has total edge cost \(52\). Which statement is correct about the routing efficiency of the two trees?

A. Tree X uses more bandwidth than Tree Y
B. Tree Y provides shorter individual paths than Tree X
C. Both trees are equally efficient because they span all nodes
D. Tree X yields lower overall routing cost than Tree Y ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The total cost of a spanning tree reflects the sum of all link weights used to reach every node. A lower sum means that, on average, routes traverse cheaper links, reducing overall resource consumption. Therefore Tree X, with total cost \(45\), offers a more efficient routing solution than Tree Y, whose cost is higher.

Q3. How does maintaining a separate least‑cost tree for each router simplify the forwarding decision process in unicasting?

A. The next‑hop is always the first edge on the tree rooted at the source ✅
B. Routers can broadcast a single table to all destinations
C. It eliminates the need for any routing tables
D. It merges all paths into a single multicast group

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When each router stores its own shortest‑path tree, the forwarding decision reduces to a simple lookup: the packet’s destination appears somewhere in that tree, and the first edge on the unique path from the root to the destination is the next hop. This deterministic rule removes ambiguity and speeds up packet forwarding.

Q4. What best defines a least‑cost tree in the context of IP routing?

A. A spanning tree that maximizes link utilization
B. A tree that connects only a subset of routers
C. A tree rooted at a source where the path to every other node is of minimum total cost ✅
D. A tree that uses only wireless links

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

A least‑cost tree (also called a shortest‑path tree) is a spanning structure rooted at a particular router such that the cost of the path from the root to any other router equals the minimum possible cost in the underlying network. It therefore guarantees that every node is reached via its cheapest route from the root.

Q5. If a single edge of cost 3 fails in a 10‑router network, what can be inferred about the impact on the least‑cost tree rooted at the source router?

A. The tree will lose exactly one path and must be rebuilt for the affected node ✅
B. All paths that used the failed edge increase by at most the cost of the next‑best alternative
C. The tree remains unchanged because alternative paths are pre‑computed
D. Only the paths to nodes directly incident to the failed edge are affected

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When an edge that is part of the current least‑cost tree fails, the unique path that relied on that edge is broken. Consequently, the tree no longer spans all nodes, and the affected destination (and possibly others that depended on that link) must be recomputed to restore a valid spanning tree.

Q6. Between Dijkstra’s algorithm and Bellman‑Ford for constructing least‑cost trees, which is more suitable for a network where all edge weights are non‑negative and why?

A. Bellman‑Ford, because it handles negative cycles
B. Dijkstra, because it runs in \(O(E + V\log V)\) with a priority queue ✅
C. Both are equally efficient in this scenario
D. Bellman‑Ford, because it requires fewer iterations

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Dijkstra’s algorithm exploits the fact that all edge weights are non‑negative, allowing it to settle nodes permanently once extracted from the priority queue. This yields a time complexity of \(O(E + V\log V)\), which is typically faster than Bellman‑Ford’s \(O(VE)\) approach that must relax all edges repeatedly, making Dijkstra the preferred choice for such networks.

Q7. In a network of 10 routers, why are exactly 10 distinct least‑cost trees sufficient to represent all 90 ordered source‑destination shortest paths?

A. Each tree encodes the shortest path from its root to every other router, covering all ordered pairs ✅
B. Ten trees can be combined to form a single super‑tree that contains all paths
C. Only ten paths are needed because the network is symmetric
D. The number 90 is a misprint; only 10 trees are needed

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A least‑cost tree rooted at a particular router contains the minimum‑cost path from that router to every other router. Since there are 10 possible roots, the collection of 10 trees captures every ordered pair (source, destination) exactly once, yielding \(10 \times 9 = 90\) unique shortest‑path routes.

Q8. Given the following edge costs: A‑B=1, A‑C=4, B‑C=2, B‑D=5, C‑D=1. Build the least‑cost tree rooted at A. Which node will have the longest path cost from A in that tree?

A. Node B
B. Node C
C. Node D ✅
D. All nodes have equal cost

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The tree starts with the cheapest edge A‑B (cost 1). The cheaper route to C is A‑B‑C (1 + 2 = 3) rather than the direct A‑C (4). Adding C‑D (1) gives the path A‑B‑C‑D with total cost 4. Thus path costs are B = 1, C = 3, D = 4, making D the node with the longest distance from A.

Q9. When edge costs change frequently, which approach minimizes recomputation of the 10 least‑cost trees?

A. Run Dijkstra from each root after every change
B. Use incremental updates such as the dynamic shortest‑path algorithm ✅
C. Recompute a single global spanning tree and reuse it
D. Ignore the changes until a threshold is reached

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Dynamic shortest‑path algorithms maintain previously computed trees and adjust only the portions affected by a cost change, often using techniques like queue‑based relaxation. This incremental method avoids rebuilding each tree from scratch, dramatically reducing computational overhead compared with repeatedly executing Dijkstra for every router.

Q10. If a router needs to forward a packet to destination X, how does it use its own least‑cost tree to determine the next hop?

A. It looks up X in its tree and selects the first edge on the unique path from the root to X ✅
B. It broadcasts the packet to all neighbors
C. It chooses the neighbor with the highest link cost
D. It consults a separate multicast tree

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The router consults its shortest‑path tree, which already contains the optimal route from the router (the root) to every possible destination. By tracing the unique path to X and taking the first edge on that path, the router identifies the correct next hop, ensuring the packet follows the minimum‑cost route without additional calculations.

Q11. What does the term \count to infinity\ refer to in distance‑vector routing?

A. A rapid convergence of routing tables after a link cost decrease
B. A slow propagation of increased link costs leading to indefinite metric growth ✅
C. The process of assigning infinite addresses to multicast groups
D. A method for compressing routing vectors

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Count to infinity describes the situation where, after a link cost increases (or a link fails), routers continue to advertise increasingly larger distances for the affected destination. Because distance‑vector protocols only share neighbor information, the bad news spreads slowly, causing the metric to climb toward an arbitrarily large value (treated as infinity) before the network stabilizes.

Q17. Evaluating the use of a maximum hop count of 16 to mitigate count‑to‑infinity, which statement is true?

Setting a hop‑count ceiling caps the numerical distance a router can advertise, preventing metrics from growing without bound. However, the technique does not stop routing loops; if a loop contains more than the allowed number of hops, the metric can still wrap around, so the problem is mitigated but not fully resolved.

Q18. Apply the update rule \( \text{new}_i = \min(\text{old}_i,\ \text{received}_i + c) \). If a node receives vector \([2,5,\infty]\) from a neighbor whose link cost \(c = 3\), what is the updated entry for destination 3?

B. 8
C. 5
D. 3

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The received entry for destination 3 is \(\infty\). Adding the link cost yields \(\infty + 3 = \infty\). The minimum between the node’s current entry (assumed also \(\infty\)) and \(\infty\) remains \(\infty\). Consequently, the distance to destination 3 does not change and stays at an infinite metric, indicating unreachable status.

Q20. Contrast distance‑vector routing with link‑state routing regarding convergence after a link failure. Which option correctly describes the difference?

A. Distance‑vector converges faster because it updates only neighbor tables.

D. Link‑state requires periodic full‑vector broadcasts, slowing convergence.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Link‑state protocols flood the entire network with updated link‑state advertisements, allowing every router to recompute shortest paths using a complete topology view. This global knowledge leads to rapid convergence after a failure, whereas distance‑vector routers must wait for incremental neighbor updates to propagate, resulting in slower stabilization.

📖 Explanation:

With split horizon and poisoned reverse, a node refrains from advertising a route back to the neighbor from which it learned that route, instead sending an infinite metric. In a two‑node loop, each router tells the other that the destination is unreachable, thereby breaking the feedback that would otherwise cause the metric to increase indefinitely.

Q23. Assess the impact on routing table size if each node stores a full vector of size \(N\) versus storing only next‑hop information. Which statement is accurate?

A. Full vectors require \(O(N)\) space per node, while next‑hop tables need \(O(1)\) space.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Both distance‑vector and next‑hop representations maintain a distance entry for every reachable destination, resulting in linear space complexity \(O(N)\) per router. Triggered updates require the router to generate an advertisement the moment it detects a metric change, such as a link cost rising to infinity. By instantly notifying all adjacent routers, the information spreads without waiting for the next scheduled update, thereby preventing the prolonged count‑to‑infinity phenomenon.

📖 Explanation:

When the A‑B link fails, A and B first mark each other as unreachable and advertise an infinite metric. Q26. Compare convergence time of distance‑vector routing with and without hold‑down timers after a transient link failure. Which statement best reflects the trade‑off?

A. Hold‑down timers speed up convergence but may accept false routes.

C. Hold‑down timers eliminate count‑to‑infinity entirely.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Hold‑down timers suppress rapid acceptance of potentially unstable routes, giving the network time to settle after a failure. Removing the timer allows routers to adopt new information immediately, which can speed up convergence but also increases the chance of transient loops or incorrect routes before the network stabilizes.

Q27. If a node mistakenly applies the update rule as \( \text{new}_i = \max(\text{old}_i,\ \text{received}_i + c) \) instead of using the minimum, what routing anomaly is most likely to arise?

A. Rapid convergence to optimal paths.

C. Immediate detection of link failures.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Using the maximum instead of the minimum causes distance metrics to grow whenever a neighbor advertises a higher cost, leading to ever‑increasing values that can circulate indefinitely. This behavior creates routing loops and the classic count‑to‑infinity problem, undermining the stability of the distance‑vector protocol.

Because the failure is first detected locally, only the router directly connected to the failed link learns that the metric is now infinite. Other routers continue to use their previously stored values until they receive an updated vector, so the change is not propagated instantly.

Q30. Consider three nodes A, B, and C with initial costs \(c_{AB}=1\), \(c_{BC}=1\), and \(c_{AC}=5\). If the link A–B fails, how many update cycles are required before A finally records the cost to C as \( \infty \) using a plain distance‑vector algorithm without split horizon?

A. 1
B. 2
C. 3 ✅
D. 4

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

After the failure, A still believes it can reach C via B, so it sets its cost to 6 (1+5). B, unaware of the failure, reports a cost of 1 to C, causing A to increase its estimate each cycle by the stale metric. The cost increments until it reaches the predefined maximum (often 16), which typically requires three full update rounds before A finally marks the route as \( \infty \).

Q31. Which statement correctly describes the difference between split horizon and poison reverse techniques for mitigating count‑to‑infinity?

A. Both eliminate count to infinity completely.
B. Poison reverse sets cost to \( \infty \), split horizon stops updates to neighbor that sent the route. ✅

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Split horizon prevents a router from advertising a route back to the neighbor from which it learned that route, thereby avoiding a feedback loop. Poison reverse goes further by explicitly advertising the route with a metric of \( \infty \) to that same neighbor, ensuring the neighbor knows the path is no longer usable.

Q36. What best describes the phenomenon known as \count to infinity\ in distance‑vector routing?

A. An algorithm for fast convergence.

📖 Explanation:

Count to infinity occurs when a link fails and routers, lacking immediate knowledge of the failure, repeatedly advertise increasingly larger metrics for the affected destination. This process continues until the metric reaches a predefined maximum (often considered infinity), at which point the route is discarded. The term captures the gradual escalation of costs.
