📝 Multicast forwarding reverse path broadcasting

📖 From Data Communication and Networks • 21. Multicast Routing • 12 questions available

What is Multicast forwarding reverse path broadcasting?

Reverse path broadcasting is a multicast forwarding technique where a router accepts and forwards a packet only if it arrives on the interface that lies on the shortest path back to the source, preventing loops and ensuring data flows along an optimal distribution tree.

💡 Difficulty: easy | ✅ Correct: C

Line 12 explicitly contains the command to send the vector {D[1],…,D[N]} to all neighbors, which is the step that propagates the node’s distance information throughout the network.

Q2. Suppose node A detects that the cost to neighbor B increases. According to the algorithm, what is the immediate effect on A’s distance vector D[y] for any destination y?

A. It is recomputed using the Bellman‑Ford update in line 19. ✅
B. It is unchanged until a timer expires.
C. A discards the entire vector.
D. It sends an immediate update without recomputation.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

When a link cost changes, the algorithm proceeds to the waiting state and then executes the for‑loop, applying the Bellman‑Ford equation on line 19, which immediately recomputes each D[y] based on the new cost.

Q3. Compare the stability of distance‑vector multicast forwarding when updates are sent immediately after a change versus when updates are delayed. Which statement best reflects the impact on routing loops?

A. Immediate updates guarantee loop‑free operation, while delayed updates may cause temporary loops. ✅
B. Both immediate and delayed updates have equal risk of loops.
C. Delayed updates improve stability by allowing convergence before propagation.
D. Immediate updates increase the chance of count‑to‑infinity problems.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Sending updates right after a change lets neighbors adjust their tables before using outdated information, preventing inconsistent routes that can form loops; delayed propagation allows stale data to circulate, creating transient loops before convergence.

Q4. If node X receives a distance vector from neighbor W where \(c[\text{myself}][W] = 2\) and \(D_W[y] = 5\), what is the new tentative distance to destination y after applying line 19?

A. 2
B. 5
C. 7 ✅
D. 10

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Line 19 computes \(D[y] = \min\big(D[y],\,c[\text{myself}][W] + D_W[y]\big)\). Substituting the given values yields \(2 + 5 = 7\), which becomes the new tentative distance if it is lower than the current entry.

Q5. During execution, node A receives an updated vector from neighbor B that does not change any entry in A’s table. According to the algorithm, what action does A take?

A. It still broadcasts its vector to all neighbors.
B. It discards the received vector.
C. It checks for any change and, finding none, does not send its own vector. ✅
D. It resets its table to default values.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The algorithm includes a conditional (line 21) that sends the vector only if any entry changed. Since no entry changed, the condition fails and A refrains from transmitting its own vector.

Q6. Evaluate the effect of a simultaneous failure of two links (A‑X and B‑Y) on the convergence time of the distance‑vector multicast algorithm. Which factor most significantly influences the slowdown?

A. Frequency of update messages.
B. Size of routing tables.
C. Number of destinations N.
D. Propagation of changed vectors through neighbors. ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

When multiple links fail, each affected node must inform its neighbors, and those neighbors must further propagate the changes. The time taken for these updated vectors to traverse the network (propagation) dominates the overall convergence delay.

Q7. In multicast forwarding, why is it advantageous to send the entire distance vector \(\{D[1], D[2], …, D[N]\}\) to all neighbors rather than only the changed entries?

A. It reduces overall bandwidth consumption.
B. It simplifies the implementation of the Bellman‑Ford update at the receiver.
C. It ensures that all nodes have consistent full knowledge, preventing stale routes. ✅
D. It allows routers to ignore link cost changes.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Transmitting the full vector guarantees that every neighbor possesses the latest complete view of all destinations, eliminating inconsistencies that could arise if only incremental changes were sent and some entries became outdated.

Q8. If node A’s link cost to neighbor W becomes infinite (\(c[\text{myself}][W] = \infty\)), what will line 19 compute for \(D[y]\) assuming \(D_W[y]\) is finite?

A. \(\infty\) ✅
B. Finite value
C. Zero
D. Unchanged

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The expression \(c[\text{myself}][W] + D_W[y]\) evaluates to \(\infty + \text{finite} = \infty\). The min‑operator then compares this infinite value with the current \(D[y]\); unless the current entry is also infinite, the result will be \(\infty\).

Q9. Contrast the behavior of the algorithm when a node detects a link cost increase versus a link cost decrease. Which statement correctly describes the difference?

A. Both trigger an immediate broadcast of the vector.
B. Increase causes removal of routes, decrease may only improve existing distances. ✅
C. Decrease leads to resetting all distances to infinity.
D. Increase does not affect the vector until a timeout occurs.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A cost increase can make previously optimal paths invalid, forcing the node to discard or raise those distances; a cost decrease simply provides a potentially better path, so only the affected entries are lowered, not removed.

Q10. Synthesize how the distance‑vector multicast algorithm ensures loop‑free forwarding in a dynamic network. Which mechanism is central to preventing loops?

A. Periodic full-table exchanges.
B. The min‑operator in line 19 that always selects the shortest path. ✅
C. Use of sequence numbers in updates.
D. Flooding of all possible paths.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The algorithm continuously chooses the minimum cost among all advertised paths; by always preferring the shortest metric, it avoids forming circular routes that would otherwise create forwarding loops.

Q11. Assume node A receives two different vectors from neighbors W1 and W2. For a destination y, \(c[\text{myself}][W1] + D_{W1}[y] = 8\) and \(c[\text{myself}][W2] + D_{W2}[y] = 6\). After processing both updates, what value will \(D[y]\) hold?

A. 8
B. 6 ✅
C. 14
D. 0

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Line 19 takes the minimum of the current distance and each newly computed path cost. Between 8 and 6, the smaller value is 6, so after considering both neighbors, \(D[y]\) is set to 6.

Q12. Given a network of N destinations, what is the computational complexity per update for a node executing line 19 for all y? Choose the most accurate description.

A. \(O(1)\)
B. \(O(N)\) ✅
C. \(O(N^2)\)
D. \(O(\log N)\)

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The for‑loop iterates over each destination y (from 1 to N) and performs a constant‑time min operation per iteration, resulting in linear time proportional to N, i.e., \(O(N)\).
