Q1. If a node receives a vector \(v_{\text{nbr}}\) from its immediate neighbor and adds it to its own vector \(v_{\text{self}}\), which expression correctly represents the updated vector?

🔹 A. \(v_{\text{self}} - v_{\text{nbr}}\)
🔹 B. \(v_{\text{self}} + v_{\text{nbr}}\)
🔹 C. \(v_{\text{nbr}}\)
🔹 D. \(v_{\text{self}}\)

💡 Difficulty: easy | ✅ Correct: B

Q2. In a ring of 5 processes, each process updates its vector by adding the vector received from its clockwise neighbor once. Which inference is true about the system after this single iteration?

🔹 A. All vectors become identical
🔹 B. Vectors remain unchanged
🔹 C. Each vector contains contributions from three original vectors
🔹 D. Each vector now includes its own original vector plus the neighbor’s original vector

💡 Difficulty: medium | ✅ Correct: D

Q3. Consider a for‑loop that sequentially processes neighbors 1 through N, updating the local vector after each receive. If the loop order is reversed, which statement best describes the impact on the final vector after one full pass?

🔹 A. The final vector is independent of order
🔹 B. The vector will be the sum of neighbor vectors in reverse order
🔹 C. The vector may differ because updates use already‑modified values
🔹 D. The loop will cause a deadlock

💡 Difficulty: hard | ✅ Correct: A
