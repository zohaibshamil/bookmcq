What is Multicast addresses Class D IPv4?

Class D IPv4 addresses range from 224.0.0.0 to 239.255.255.255 and are reserved exclusively for multicast groups, allowing routers and hosts to identify packets intended for multiple recipients rather than individual unicast or broadcast destinations.

Q1. What is the IPv4 multicast address range?

A.224.0.0.0 – 239.255.255.255 ✅
B.240.0.0.0 – 255.255.255.255
C.192.168.0.0 – 192.168.255.255
D.10.0.0.0 – 10.255.255.255
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The IPv4 multicast space is defined by the class D address block, which starts at 224.0.0.0 and ends at 239.255.255.255. All addresses in this range are reserved for multicast traffic, so option A correctly identifies the multicast address range.

Q2. If node A detects a failure on its link to node X and immediately broadcasts its updated distance vector to neighbor B, what is the most direct effect on the multicast routing tree convergence?

A.The convergence time will increase
B.The convergence time will decrease ✅
C.A routing loop will be created
D.No change in convergence
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When a node promptly shares its new distance vector, neighboring routers can recalculate their paths without waiting for timeout events. This rapid dissemination shortens the period during which outdated routes are used, thereby decreasing the overall convergence time for the multicast tree.

Q3. Compare the number of IP addresses required to deliver the same data to 100 receivers using unicast versus multicast. Which statement is accurate?

A.Unicast needs 1 address, multicast needs 100
B.Both need 100 addresses
C.Unicast needs 100 addresses, multicast needs 1 ✅
D.Both need 1 address
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Unicast creates an individual flow for each receiver, requiring a distinct source‑destination pair for all 100 receivers. Multicast, by contrast, uses a single group address shared by all receivers, so only one address is needed to reach the entire set.

Q4. Which statement best describes the Reverse Path Forwarding (RPF) check used in multicast routing?

A.A packet is forwarded only if it arrives on the interface that has the shortest path to the source
B.All interfaces forward the packet regardless of source
C.Packets are dropped only when TTL expires
D.RPF drops a packet if it arrives on an interface that is not the one used to reach the source ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: RPF verifies that a packet arrived on the interface that the router would use to reach the packet’s source. If the arrival interface differs, the packet is discarded to prevent loops and unnecessary traffic, making option D the correct description.

Q5. Consider a network where node S has two neighbors N1 (cost 2) and N2 (cost 5). Using the Bellman‑Ford update \, which neighbor will first advertise a lower distance to destination Y after the initial iteration?

A.N1 ✅
B.N2
C.Both will advertise equal distances
D.Neither will advertise a lower distance
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The Bellman‑Ford equation adds the link cost to the neighbor’s known distance. Since N1’s cost (2) is smaller than N2’s cost (5), N1 will produce a lower total metric for Y on the first update, causing it to advertise the reduced distance first.

Q6. Evaluate the scalability impact of Source‑Specific Multicast (SSM) compared to Any‑Source Multicast (ASM). Which effect is most significant?

A.SSM increases per‑source state in routers
B.SSM reduces the amount of state because each source‑group pair is known a priori ✅
C.Both have identical scalability characteristics
D.ASM reduces state by using a single shared tree
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: SSM limits multicast traffic to a known source‑group pair, allowing routers to maintain state only for those explicit pairs. This eliminates the need for shared‑tree management and reduces the amount of routing information stored, making SSM far more scalable than ASM.

Q7. Synthesize how the multicast address 224.0.0.1 interacts with the Protocol Independent Multicast – Sparse Mode (PIM‑SM) to build the shared tree.

A.PIM‑SM uses 224.0.0.1 as the rendezvous point address
B.PIM‑SM ignores 224.0.0.1 and builds trees per source
C.All routers join the all‑routers group 224.0.0.1, allowing the RP to be discovered and the shared tree to be constructed ✅
D.224.0.0.1 is reserved for IPv6 and is not used by PIM‑SM
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: In PIM‑SM, the address 224.0.0.1 represents the all‑routers multicast group. Routers join this group to learn about the rendezvous point (RP). Once the RP is known, a shared distribution tree rooted at the RP is built for the multicast source, enabling efficient delivery to all receivers.

Q8. If a link cost in a multicast network suddenly increases, what can be inferred about the stability of the existing multicast distribution tree?

A.The tree becomes more stable because higher cost discourages traffic
B.Stability is unaffected; only packet loss changes
C.The tree will automatically shrink without any protocol action
D.The tree may become unstable until routers recompute shortest‑path metrics ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: An increase in link cost makes the current shortest‑path calculations obsolete. Until routers exchange updated metrics and recompute the optimal paths, some routers may continue using the now‑suboptimal tree, leading to temporary instability and possible packet loss.

Q9. How does the Time‑to‑Live (TTL) field affect the scope of a multicast packet compared to a unicast packet?

A.TTL limits the number of hops a multicast packet can travel, effectively controlling its geographical scope ✅
B.TTL has no effect on multicast packets
C.TTL is ignored for multicast and always set to maximum
D.Unicast packets use TTL, while multicast packets use a separate hop‑limit field
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The TTL value is decremented at each hop for both unicast and multicast packets. When TTL reaches zero, the packet is discarded, which restricts how far a multicast packet can propagate and thus defines its geographic or network scope.

Q10. Which IGMP message is used by a host to indicate that it wishes to leave a multicast group?

A.IGMP Membership Query
B.IGMP Leave Group ✅
C.IGMP Membership Report
D.IGMP General Query
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When a host no longer wishes to receive traffic for a specific multicast group, it sends an IGMP Leave Group message to inform the local router of its departure. This allows the router to prune the group from its forwarding state if no other members remain.

Q11. When two routers receive conflicting distance‑vector updates for the same multicast group, what is the most likely immediate outcome?

A.Both routers will merge the vectors into a larger table
B.The routers will ignore the conflict and continue using the old vector
C.Each router will select the lower cost entry, potentially causing a temporary routing inconsistency ✅
D.The network will halt until manual intervention resolves the conflict
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Each router independently applies the Bellman‑Ford rule, choosing the path with the lower metric. If the metrics differ, the routers may temporarily disagree on the best route, creating a brief inconsistency that is resolved once subsequent updates converge.

Q12. Differentiate PIM‑Dense Mode (PIM‑DM) from PIM‑Source Specific Multicast (PIM‑SSM) in terms of tree construction and state maintenance.

A.PIM‑DM builds a shared tree using a rendezvous point, while PIM‑SSM creates source‑specific trees
B.Both protocols rely on the same shared tree mechanism
C.PIM‑SSM does not support source‑specific trees
D.PIM‑DM floods the network initially and prunes, whereas PIM‑SSM builds a source‑specific tree directly, reducing state ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: PIM‑DM starts by flooding multicast traffic throughout the network and then prunes branches without receivers, which creates considerable state. PIM‑SSM, by contrast, constructs a tree only for the explicit source‑group pair, eliminating the need for shared‑tree state and scaling more efficiently.

Q13. Explain how the Bellman‑Ford update equation combined with split‑horizon prevents loops in multicast routing.

A.Split‑horizon stops a node from advertising a route back to the neighbor from which it learned the route, and the min operation in Bellman‑Ford ensures only shorter paths are adopted, breaking potential loops ✅
B.The equation alone guarantees loop‑free operation
C.Split‑horizon is irrelevant for multicast
D.Loops are prevented by increasing TTL values
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Split‑horizon forbids a router from sending a route back to the neighbor that originally advertised it, preventing immediate two‑node loops. The Bellman‑Ford update then selects only the minimum‑cost path, so any longer or cyclic paths are ignored, together ensuring loop‑free multicast routing.

Q14. Assess the impact of delayed propagation of distance‑vector updates on multicast packet loss during a network failure.

A.Delays cause immediate packet loss but improve long‑term stability
B.Delayed updates can increase packet loss because routers continue forwarding along a broken path until they receive the new information ✅
C.Delays have no effect on packet loss
D.Delays reduce packet loss by allowing routers more time to recompute routes
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When a failure occurs, routers keep using the outdated distance vector until the new information arrives. This continuation of forwarding on the failed link results in lost packets. The longer the propagation delay, the greater the window of loss, making timely updates essential for minimizing disruption.
