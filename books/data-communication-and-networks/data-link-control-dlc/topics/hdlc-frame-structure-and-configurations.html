Q1. In bit stuffing, an extra 0 is inserted after which bit pattern?

🔹 A. Five consecutive 1 bits
🔹 B. A 0 followed by five consecutive 1 bits
🔹 C. Six consecutive 1 bits
🔹 D. A 1 followed by five consecutive 0 bits

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The bit‑stuffing rule states that whenever a 0 is followed by five consecutive 1s, a single 0 is inserted. This prevents the pattern from mimicking the flag sequence. Recognizing this rule allows the receiver to later remove the inserted bit, restoring the original data.

Q2. A transmitter sends the bit sequence \(0111110\) using bit stuffing. What will be the transmitted sequence?

🔹 A. \(0111110\)
🔹 B. \(01111110\)
🔹 C. \(01111100\)
🔹 D. \(011111010\)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The original pattern contains a 0 followed by five 1s, so a 0 is stuffed after the five 1s. The resulting sequence becomes \(0\,11111\,0\,0\), which is \(01111100\). This extra bit is later removed by the receiver during decoding.

Q3. If a receiver detects the flag pattern \(01111110\) within a frame, what can be logically inferred about the transmitted data?

🔹 A. A stuffed bit was removed, restoring the flag.
🔹 B. The frame contains an error and must be discarded.
🔹 C. The sender failed to apply bit stuffing.
🔹 D. The flag pattern is part of the payload data.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When the receiver sees the flag pattern, it knows that any preceding stuffed bits have already been removed. The presence of the flag indicates proper bit‑stuffing processing, not an error, because the protocol guarantees that the flag can only appear after de‑stuffing.

Q4. Which statement best compares the overhead introduced by bit stuffing versus byte stuffing for a frame containing 1000 bits with an average of 2 occurrences of the flag pattern?

🔹 A. Bit stuffing adds roughly 2 bits, while byte stuffing adds 2 bytes.
🔹 B. Bit stuffing adds roughly 2 bytes, while byte stuffing adds 2 bits.
🔹 C. Both add the same number of bits.
🔹 D. Bit stuffing adds no overhead.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Each flag occurrence triggers one stuffed bit, so two flags add 2 bits. Byte stuffing would replace each flag with an escape byte plus the flag byte, adding roughly 2 bytes (16 bits). Thus bit stuffing incurs far less overhead for the same number of flag occurrences.

Q5. A frame of 1024 bits contains 8 occurrences of the flag pattern. Using bit stuffing, each occurrence adds one stuffed bit. What is the transmission efficiency (payload/original bits) expressed as a percentage?

🔹 A. 0.992
🔹 B. 0.985
🔹 C. 0.97
🔹 D. 0.95

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The frame carries 1024 payload bits and 8 stuffed bits, so total transmitted bits = 1024 + 8 = 1032. Efficiency = (1024 / 1032) × 100 ≈ 99.22%, which rounds to 99.2 %. This shows that bit stuffing incurs very low overhead for a modest number of flags.

Q6. How does the receiver identify and remove stuffed bits during frame decoding?

🔹 A. It scans for the flag pattern and deletes preceding bits.
🔹 B. It removes any 0 that follows five consecutive 1s.
🔹 C. It replaces every occurrence of 0 with 1.
🔹 D. It ignores the first bit of each frame.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The receiver monitors the incoming bit stream for the specific pattern of five consecutive 1s followed by a 0. When this pattern is found, the trailing 0 is recognized as a stuffed bit and is discarded, thereby reconstructing the original data without the artificial insertion.

Q7. Design a protocol that avoids the need for bit stuffing while still preventing the flag sequence from appearing in payload. Which mechanism best achieves this?

🔹 A. Use a length field to specify frame size instead of delimiters.
🔹 B. Escape the flag sequence with a special escape character.
🔹 C. Transmit data only in ASCII characters.
🔹 D. Require the sender to encrypt the payload.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Escaping replaces any occurrence of the flag sequence in the payload with an escape character followed by a transformed version of the flag. This guarantees that the flag pattern never appears unintentionally, eliminating the need for bit stuffing while preserving frame boundary detection.

Q8. In asynchronous transfer mode, frames are delimited by:

🔹 A. A start and stop bit pair.
🔹 B. A fixed-length header.
🔹 C. A unique flag sequence.
🔹 D. A checksum field.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Asynchronous communication sends each character (or frame) framed by a start bit to signal the beginning and one or more stop bits to signal the end. This method provides clear delimiters without requiring a separate flag sequence, contrasting with synchronous modes that rely on shared timing or explicit flags.
