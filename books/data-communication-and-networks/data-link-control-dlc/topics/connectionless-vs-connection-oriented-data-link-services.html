What is Connectionless vs Connection-oriented data link services?

Connectionless services transmit frames independently without establishing a prior link or guaranteeing delivery, whereas connection-oriented services set up a dedicated logical connection before transfer to ensure sequenced and reliable data delivery.

📝 All Connectionless vs Connection-oriented data link services MCQs

Q1. If a network switches from a connection-oriented service to a connectionless service, which immediate effect on packet delivery is most likely?

A. Increased latency due to setup time
B. Possible out-of-order delivery of packets ✅
C. Guaranteed delivery of every packet
D. Reduced header size for each packet

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When a connectionless service is used, the network no longer maintains a dedicated session, so packets are sent independently. This can result in packets arriving out of sequence because there is no ordering mechanism, whereas connection‑oriented services preserve order. The other choices describe effects that are either opposite or unrelated to the change.

Q2. Which statement best contrasts the overhead of connection‑oriented versus connectionless protocols?

A. Connection‑oriented protocols add session‑setup headers, while connectionless protocols have minimal per‑packet headers ✅
B. Connectionless protocols require more acknowled‑gment frames than connection‑oriented protocols
C. Connection‑oriented protocols never retransmit, unlike connectionless protocols
D. Both types have identical overhead because they use the same physical layer

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Connection‑oriented protocols must establish a session, which introduces additional control frames and state information, increasing overhead. In contrast, connectionless protocols send each packet independently with only a lightweight header, keeping overhead low. The other options misstate the mechanisms of acknowledgments and retransmissions.

Q3. Applying the principle of flow control, how does a connection‑oriented DLC typically manage buffer overflow compared to a connectionless DLC?

A. It drops excess frames without notification
B. It relies on higher‑layer protocols to signal congestion
C. It uses stop‑and‑wait or sliding‑window techniques to pause transmission ✅
D. It ignores overflow, assuming physical layer reliability

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Connection‑oriented DLC maintains state and can employ flow‑control mechanisms such as stop‑and‑wait or sliding‑window protocols, allowing the sender to pause when the receiver’s buffer is full. Connectionless DLC lacks such coordination and generally cannot prevent overflow, often resulting in dropped frames. The other options either describe behaviors of connectionless services or are inaccurate.

Q4. Given that a connection‑oriented link establishes a session before data transfer, what can be inferred about its suitability for bursty traffic patterns?

A. It is ideal because the session can absorb bursts efficiently
B. It performs equally well for steady and bursty traffic
C. Bursty traffic benefits from connectionless services that avoid setup delay ✅
D. The session setup eliminates any burstiness in the traffic

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Because a connection‑oriented DLC must first negotiate parameters and may enforce a fixed window size, sudden spikes in data can be throttled or delayed, making it less responsive to bursty patterns. Connectionless services transmit each frame immediately without session constraints, handling bursts more naturally. Therefore the logical inference is that bursty traffic benefits from connectionless communication.

Q5. Evaluate the trade‑off between reliability and latency when choosing between connectionless and connection‑oriented services for real‑time video streaming.

A. Connectionless provides lower latency but reduced reliability ✅
B. Connection‑oriented offers higher reliability with increased latency
C. Both provide identical latency and reliability for video
D. Connectionless guarantees both low latency and high reliability

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Real‑time video demands minimal delay; using a connectionless DLC avoids the handshake and acknowledgment steps, reducing latency. However, without built‑in reliability mechanisms, packet loss may increase, lowering overall reliability. A connection‑oriented DLC would add acknowledgments and possible retransmissions, improving reliability but introducing delay, which can degrade video smoothness. Thus the trade‑off favors connectionless for latency‑critical applications.

Q6. Synthesize a scenario where a hybrid approach uses connectionless control frames with connection‑oriented data frames; which benefit does this architecture primarily provide?

A. It reduces overall bandwidth consumption by sharing headers
B. It optimizes latency for control messages while preserving reliability for data ✅
C. It eliminates the need for error detection entirely
D. It simplifies implementation by using a single protocol for all frames

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

In a hybrid design, short control frames may be sent connectionlessly to benefit from immediate transmission, while larger data frames use a connection‑oriented session that provides acknowledgments and retransmission capabilities. This combination leverages the low‑latency advantage of connectionless communication for control information, yet retains the reliability needed for bulk data transfer. The other statements either misrepresent the purpose or incorrectly claim elimination of error handling.

Q7. If a node experiences frequent packet loss, what cause is most directly linked to using a connectionless service without acknowledgment?

A. Excessive checksum calculation at sender
B. Over‑provisioned buffer sizes at receiver
C. Lack of acknowledgment and retransmission mechanisms ✅
D. Use of three‑way handshake for each frame

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Connectionless DLC transmits frames without establishing a session and typically does not implement acknowledgment or automatic retransmission. Consequently, when a frame is corrupted or lost on the medium, the sender is unaware and does not resend it, leading directly to higher observed packet loss. The other options either describe unrelated mechanisms or are characteristic of connection‑oriented services.

Q8. Analyze why a connection‑oriented DLC requires a three‑way handshake at the data link layer, while a connectionless DLC does not, focusing on state maintenance.

A. To synchronize clocks between nodes
B. To exchange encryption keys for security
C. To advertise supported physical layer rates
D. To establish and confirm state information before data exchange ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

A three‑way handshake in connection‑oriented DLC serves to negotiate parameters, allocate resources, and confirm that both ends have recorded the session state, ensuring reliable ordered delivery. Connectionless DLC lacks this exchange because it does not maintain state, sending frames independently. The handshake is not primarily for clock sync, encryption, or rate advertisement, though some of those may be negotiated later.

Q9. Apply the concept of error control to explain how a connectionless DLC can achieve comparable error detection to a connection‑oriented DLC without establishing a session.

A. By appending a CRC to each frame for detection ✅
B. By using a persistent connection identifier for error tracking
C. By relying on physical‑layer retransmission only
D. By establishing a hidden session at the network layer

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Even without a session, a connectionless DLC can achieve strong error detection by computing a cyclic redundancy check (CRC) for each individual frame. The receiver validates the CRC and discards corrupted frames. This per‑frame approach provides comparable detection capability to connection‑oriented DLC, which may also use CRCs, but without the overhead of maintaining session state. The other options either depend on session state or delegate error handling elsewhere.

Q10. Given a network where the physical layer provides reliable bit transmission, what logical deduction can be made about the necessity of connection‑oriented DLC for error control?

A. Connection‑oriented DLC is still required for flow control
B. Connection‑oriented DLC becomes unnecessary for error control ✅
C. Physical layer reliability forces the use of connectionless DLC
D. Both services become redundant when the physical layer is reliable

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When the physical layer guarantees error‑free bit transmission, the primary motivation for a connection‑oriented DLC—providing error detection and correction—diminishes. While flow control may still be needed, the specific error‑control function can be omitted, making a connection‑oriented DLC optional for that purpose. The other statements either overstate the impact or misinterpret the relationship between layers.

Q11. Differentiate the impact on network scalability when deploying connectionless versus connection‑oriented DLC across a large mesh of nodes.

A. Connection‑oriented DLC scales better because sessions are pre‑allocated
B. Connectionless DLC limits scalability due to lack of addressing
C. Connectionless DLC scales more efficiently because it avoids per‑session state ✅
D. Both have identical scalability characteristics in a mesh

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

In a large mesh network, maintaining a separate session for each node pair (as required by connection‑oriented DLC) leads to significant state overhead, limiting the number of concurrent connections. Connectionless DLC, by transmitting independent frames without session state, reduces memory and processing demands on each node, enabling the network to scale to many more links. The other options misrepresent the scaling behavior.

Q12. What term describes a DLC service that does not require a prior session establishment?

A. Connectionless ✅
B. Connection‑oriented
C. Reliable
D. Broadcast

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A DLC service that operates without establishing a session beforehand is defined as connectionless. It sends frames independently, without the overhead of connection setup, making it distinct from connection‑oriented services that require a session. The other terms refer to different characteristics, such as reliability or transmission mode, not the presence or absence of a session.
