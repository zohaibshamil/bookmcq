📝 Data Link Control services overview (9 MCQs)

Link-Level Control Between Adjacent Network Nodes

Data Link Control (DLC) coordinates the transfer of frames between two directly connected nodes. It turns the network layer's packets into link-specific frames and manages how those frames use a communication link. Its central concerns are framing, flow control, and error control. Together, these functions help a sender and receiver exchange data in an orderly manner over a physical connection.

Framing, Flow Control and Error Control Functions

Framing marks the boundaries of each data unit and adds control information. Flow control regulates the sender's rate so a receiver can process incoming frames. Error control detects damaged or missing frames and, when the protocol supports it, uses acknowledgements and retransmissions. Physical addressing and medium access are also provided by many link technologies, although their exact mechanisms differ.

How a DLC Exchange Proceeds Across One Link

The sender accepts a packet from the network layer, builds a frame, and applies the link protocol's transmission rules. The receiver identifies the frame boundary, checks its control fields and error-detection value, and processes any acknowledgement requirement. It then extracts the packet for the network layer. If another router is involved, that router creates a new frame for its next link.

Ethernet Delivery with Frame Checking

A workstation sends an IP packet across an Ethernet LAN. Ethernet places the packet in a frame with source and destination MAC addresses and a frame check sequence. A switch forwards the frame using its MAC address table. The destination interface checks the frame check sequence and, if valid, passes the enclosed IP packet to its network layer.

How Link Control Relates to Other Protocol Layers

DLC operates hop by hop, whereas IP provides logical addressing and routing across multiple networks. TCP may provide end-to-end reliability above IP even when an individual link protocol offers only error detection. HDLC and PPP illustrate different link-control designs: HDLC supports link procedures and numbered frames, while basic PPP focuses on point-to-point encapsulation and link configuration.

Misunderstandings About Link-Level Control

'DLC routes packets across the internet' confuses local frame transfer with network-layer routing. 'Every data link protocol retransmits damaged frames' is false because some detect errors and discard frames without recovery. 'Flow control prevents network congestion' mixes receiver protection on one link with congestion control, which responds to traffic load across a network path.

Identifying DLC Functions in Protocol Questions

For examinations, associate framing with frame boundaries, flow control with receiver capacity, and error control with damaged or lost frames. Trace a frame from sender to adjacent receiver, and distinguish MAC addresses from IP addresses. When comparing protocols, check whether acknowledgements, sequence numbers, retransmission, and medium-access rules are actually specified rather than assuming every link provides them.

Data Link Control Service Terminology

  • DLC - Controls frames on a link.
  • Framing - Marks frame boundaries.
  • Flow control - Limits sender rate to receiver capacity.
  • Error control - Handles loss and corruption.
  • ACK - Confirms frame receipt.
  • Retry - Resends a failed frame.

📝 All Data Link Control services overview MCQs

Q1. If a large frame experiences a single-bit error, what is the impact on retransmission compared to using smaller frames?

A.Only the erroneous bit is retransmitted
B.Entire large frame must be retransmitted ✅
C.No retransmission is needed
D.Only the destination address is retransmitted
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When a single-bit error occurs in a large frame, the protocol cannot isolate the error to a small portion, so the entire frame must be resent. Smaller frames limit the loss to the corrupted frame only, reducing wasted bandwidth and improving efficiency.

Q2. How does fixed‑size framing differ from variable‑size framing regarding delimiters and bandwidth usage?

A.Fixed‑size eliminates the need for explicit delimiters but may waste bandwidth due to padding ✅
B.Variable‑size eliminates delimiters but increases processing complexity
C.Fixed‑size requires explicit delimiters and is less efficient
D.Variable‑size always uses larger frames than fixed‑size
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Fixed‑size framing uses the known length of each cell as an implicit delimiter, so no start‑ or end‑markers are required. However, if the payload does not fill the cell, unused space is padded, leading to potential bandwidth waste. Variable‑size frames need delimiters but can match payload size more closely.

Q3. Why does adding sender and destination addresses to each frame support many‑to‑many communication?

A.It allows routing decisions at the physical layer
B.It enables acknowledgment and proper delivery across a shared medium ✅
C.It encrypts the data for security
D.It compresses the payload for efficiency
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Including source and destination addresses in every frame gives the receiving node enough information to acknowledge receipt and to forward the frame correctly, even when many nodes share the same physical link. This address information is essential for distinguishing traffic in a many‑to‑many environment.

Q4. When a broadcast link is used, why is flow control more challenging than on a dedicated link?

A.Broadcast links have higher latency
B.Multiple receivers may have different processing speeds causing bottlenecks ✅
C.Broadcast links cannot carry addresses
D.Flow control is unnecessary on broadcast links
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: In a broadcast environment, each receiver may process incoming frames at a different rate. The sender must prevent fast receivers from overwhelming slower ones, which requires more sophisticated flow‑control mechanisms than on a point‑to‑point link where only one receiver’s capacity must be considered.

Q5. Evaluate the impact of using ATM cells (fixed 53‑byte) for transmitting variable‑length messages versus using variable‑size frames. Which statement is most accurate?

A.ATM reduces header overhead but may cause fragmentation and reassembly complexity ✅
B.Variable‑size frames always outperform ATM in latency
C.ATM eliminates the need for error control
D.Variable‑size frames cannot be used on WANs
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: ATM’s fixed‑size cells simplify hardware design and provide predictable timing, but when the payload does not fit neatly into 48‑byte data portions, the message must be split across multiple cells and later reassembled, adding complexity. Variable‑size frames can carry the entire message in one unit, avoiding fragmentation but requiring more flexible processing.

Q6. Synthesize a protocol that uses fixed‑size framing for control messages and variable‑size framing for data payloads. Which advantage does this hybrid approach provide?

A.Simplifies address translation
B.Balances low latency for control with efficient bandwidth use for data ✅
C.Removes the need for error detection
D.Guarantees constant throughput
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A hybrid scheme lets time‑critical control information be sent in small, predictable frames, ensuring rapid processing, while bulk data can be packed into larger, variable‑size frames that reduce overhead. This combination optimizes both responsiveness and bandwidth efficiency, addressing the differing requirements of control and data traffic.

Q7. What is the primary purpose of framing in the data‑link layer?

A.Encrypt data
B.Separate bits into identifiable units ✅
C.Increase signal strength
D.Manage routing tables
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Framing groups a stream of bits into discrete units called frames, each of which can be recognized by the receiver. This delimitation allows the data‑link layer to detect frame boundaries, apply error checking, and manage addressing, which is essential for reliable node‑to‑node communication.

Q8. Which type of error is most likely to be detected by a CRC placed in the frame trailer?

A.Single‑bit error ✅
B.Reordering of frames
C.Loss of an entire frame
D.Duplicate frames
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A cyclic redundancy check (CRC) is designed to catch common transmission errors, especially single‑bit flips. The polynomial algorithm produces a checksum that changes if even one bit in the payload is altered, making single‑bit errors highly detectable, whereas frame loss or duplication require other mechanisms.

Q9. Compare the effect on error recovery when using stop‑and‑wait ARQ versus a sliding‑window protocol for DLC. Which statement is correct?

A.Stop‑and‑wait requires less memory but lower throughput ✅
B.Sliding window eliminates the need for acknowledgments
C.Both have identical performance
D.Sliding window always causes more errors
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Stop‑and‑wait ARQ sends one frame and waits for an acknowledgment before sending the next, which keeps memory usage low but limits channel utilization, reducing throughput. Sliding‑window protocols allow multiple frames to be in transit simultaneously, improving efficiency but requiring more buffer space to track outstanding frames.
