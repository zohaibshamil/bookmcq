What is PPP transition phases LCP IPCP?

PPP establishes connections through sequential phases starting with Link Control Protocol (LCP) for link setup and testing, followed optionally by authentication, and then Network Control Protocols like IPCP to configure network layer parameters such as IP addresses.

Q1. According to the flow diagram in Figure 11.12, if a data frame is lost, what immediate action does the sending node take?

A.Stop the timer and wait for a timeout.
B.Restart a time‑out timer and resend the lost frame. ✅
C.Send an ACK for the next frame.
D.Discard the frame and continue with the next one.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When a frame is lost, the sender detects the absence of an acknowledgment. The protocol specifies that the sender must restart its timeout timer and retransmit the same frame to ensure reliable delivery. Stopping the timer would prevent detection of the loss, while sending an ACK or discarding the frame would break the reliability mechanism.

Q2. Which statement correctly contrasts Normal Response Mode (NRM) with Asynchronous Balanced Mode (ABM) in HDLC?

A.NRM uses a balanced configuration, while ABM uses an unbalanced one.
B.In NRM, any station can initiate commands; in ABM only the primary can.
C.NRM has one primary and multiple secondaries; ABM allows each station to act as both primary and secondary. ✅
D.ABM is limited to multipoint links, whereas NRM is only point‑to‑point.
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: NRM is defined by an unbalanced hierarchy: a single primary controls one or more secondary stations, which can only respond to commands. ABM, by contrast, is balanced; each station can act as both primary and secondary, enabling peer‑to‑peer communication on a point‑to‑point link. The other options misrepresent these structural differences.

Q3. Why can the ending flag of one HDLC frame serve as the beginning flag of the next frame without causing ambiguity?

A.Because the flag pattern 01111110 is unique and the receiver discards any bit‑stuffed sequence.
B.Because the receiver treats any occurrence of the flag as a delimiter regardless of position. ✅
C.Because the flag includes a length field that tells the receiver where the next frame starts.
D.Because the flag is followed by a unique address field that differentiates frames.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The flag sequence 01111110 is reserved solely as a delimiter. HDLC receivers interpret each occurrence of this pattern as the end of the current frame and the start of the next, regardless of its position. This design eliminates ambiguity, allowing the same flag to close one frame and open the next without needing additional length or address information.

Q4. In the scenario where Frame 0 is lost and the receiver expects Frame 1, which timer state will the sender be in after receiving the duplicate ACK for Frame 0?

A.Timer is stopped because the ACK was for a lost frame.
B.Timer is running for Frame 0 and will be restarted when the timeout expires.
C.Timer is restarted for Frame 1 after the duplicate ACK is processed. ✅
D.Timer is paused until a new frame is transmitted.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When the sender receives a duplicate ACK for Frame 0, it recognizes that the receiver is still awaiting Frame 1. The protocol therefore restarts the timer associated with Frame 1, preparing to retransmit it if no further acknowledgment arrives. The timer is not stopped or paused; it is specifically reset for the next expected frame.

Q5. Which type of HDLC frame is exclusively reserved for system management functions such as link initialization?

A.I‑frame
B.S‑frame
C.U‑frame ✅
D.Control‑frame
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Unnumbered frames (U‑frames) are designated for system‑level control tasks, including link establishment, configuration, and termination. They do not carry user data and are not part of the sequence‑numbered flow, distinguishing them from I‑frames (which carry data) and S‑frames (which carry supervisory control). Thus, U‑frames are the correct choice for management operations.

Q6. If two stations operate in ABM over a point‑to‑point link and a data frame is corrupted, how does the protocol recover using piggybacked ACKs?

A.The corrupted frame is ignored and the receiver sends a separate ACK‑frame.
B.The receiver discards the frame and does not send any ACK, causing the sender to timeout.
C.The receiver sends a negative acknowledgment (NACK) within the next I‑frame, prompting retransmission.
D.The receiver includes a positive ACK for the previous good frame in the next I‑frame, and the sender retransmits the corrupted frame after timeout. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: In ABM, acknowledgments are often piggybacked onto subsequent I‑frames. When a data frame is corrupted, the receiver cannot acknowledge it, so it acknowledges the last correctly received frame in the next I‑frame. The sender, lacking a positive ACK for the corrupted frame, will timeout and then retransmit the lost data, preserving reliable delivery.

Q7. When a duplicate packet is detected at the receiving node in the flow diagram of Figure 11.13, what state transition occurs in the HDLC protocol state machine?

A.The state moves from ‘Receive’ to ‘Error‑Recovery’ and the duplicate is discarded. ✅
B.The state stays in ‘Receive’ but the sequence number is ignored, and the timer is reset.
C.The state advances to ‘Wait‑for‑ACK’ and a new timer is started for the duplicate.
D.The state reverts to ‘Idle’, awaiting a new frame from the primary.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A duplicate packet indicates that the receiver has already processed that sequence number. The HDLC state machine therefore transitions from the normal receiving state to an error‑recovery routine, discarding the duplicate and preparing to handle the next expected frame. The other options either keep the state unchanged or move to inappropriate states.

Q8. How does the use of NRM versus ABM affect throughput when the link experiences a 10 % frame loss rate?

A.NRM maintains higher throughput because the primary can suppress ACKs, reducing overhead.
B.ABM yields higher throughput because both stations can send frames without waiting for explicit permission, minimizing idle time. ✅
C.Both modes provide identical throughput since frame loss dominates performance.
D.NRM provides better throughput only when the number of secondary stations exceeds three.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: ABM’s balanced nature allows each station to transmit frames and piggyback acknowledgments without waiting for a primary‑issued poll, reducing idle periods and improving channel utilization. Under a 10 % loss condition, this ability to keep the link busy outweighs NRM’s structured polling, which can introduce additional waiting time and lower overall throughput.

Q9. Explain how piggybacking in I‑frames improves channel efficiency, and what consequence occurs if the ACK portion of a piggybacked I‑frame is lost.

A.Piggybacking reduces the number of separate ACK frames, saving bandwidth; loss of the ACK forces the sender to wait for a timeout before retransmitting. ✅
B.Piggybacking doubles the payload size, increasing efficiency; loss of the ACK causes immediate retransmission of the data frame.
C.Piggybacking eliminates the need for sequence numbers; loss of the ACK leads to discarding the next data frame.
D.Piggybacking allows simultaneous transmission of control and data; loss of the ACK results in the receiver ignoring subsequent frames.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: By attaching an acknowledgment to a data‑carrying I‑frame, HDLC eliminates the need for a dedicated ACK frame, thereby conserving bandwidth and reducing protocol overhead. If the ACK component of that piggybacked frame is lost, the sender interprets the lack of acknowledgment as a failure and must wait for its timeout timer to expire before retransmitting, potentially delaying delivery.
