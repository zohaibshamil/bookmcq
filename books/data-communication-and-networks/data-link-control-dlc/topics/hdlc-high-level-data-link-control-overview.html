📝 HDLC (High level Data Link Control) Overview (9 MCQs)

A Bit-Oriented Protocol for Link Management

High-Level Data Link Control (HDLC) is a bit-oriented data link protocol family used to provide framing and link control over point-to-point and multipoint links. It defines a flag-based frame format, address and control fields, and a frame check sequence. HDLC supports information transfer and supervisory control, with operating modes suited to different station relationships and link arrangements depending on the selected station configuration and operating mode.

Information, Supervisory and Unnumbered Frames

HDLC defines three broad frame types. Information (I) frames carry user data and sequence information. Supervisory (S) frames support flow and error control, including acknowledgements. Unnumbered (U) frames carry link-management commands and responses. The control field identifies the frame type and includes relevant sequence or supervisory information for reliable operation.

Flag Detection and Control-Field Processing

A frame begins and ends with the flag pattern 01111110. Between the flags, the receiver interprets the address and control fields, checks the frame check sequence, and processes the information field when present. Bit stuffing prevents the flag pattern from appearing as data. The specific control-field layout depends on whether the frame is I, S, or U type.

An I-Frame Followed by a Supervisory Acknowledgement

A primary or combined station sends an HDLC information frame carrying data and a send sequence number. The receiving station checks the frame and can return a supervisory frame carrying a receive sequence value that acknowledges correctly received information. The exchange illustrates how HDLC separates user-data transfer from acknowledgement and link-control functions.

Balanced and Unbalanced Station Configurations

HDLC supports unbalanced configurations, with one primary station controlling one or more secondary stations, and balanced configurations, where two combined stations can initiate transmissions. Modes such as Normal Response Mode and Asynchronous Balanced Mode specify how stations access the link. These concepts describe control relationships, not the electrical type of cable.

Avoiding Confusion Between HDLC Frame Types

'Every HDLC frame carries user data' is false because S and U frames carry control information. 'The flag is the address of a station' confuses frame delimitation with addressing. 'HDLC is only for point-to-point links' is incorrect because its configurations can also support multipoint arrangements with primary and secondary stations.

What HDLC Questions Usually Require

For examinations, recognize the flag pattern, address, control, information, and FCS fields. Distinguish I, S, and U frames, and compare primary-secondary unbalanced operation with balanced combined stations. Relate N(S) and N(R) to sending and acknowledgement sequence values, and explain the purpose of bit stuffing in frame transparency and synchronization.

HDLC Link-Control Terminology

  • HDLC - Bit-oriented link protocol for framed communication.
  • I-frame - Carries numbered user data and sequence information.
  • S-frame - Provides supervisory control and acknowledgement.
  • U-frame - Carries unnumbered link commands and responses.
  • FCS - Detects frame corruption.
  • Flag - Marks frame boundaries.

📝 All HDLC (High level Data Link Control) Overview MCQs

Q1. In HDLC, if a receiver detects a frame with a CRC error, what is the most likely immediate effect on the sender's transmission sequence?

A.Sender immediately retransmits the same frame
B.Sender receives a REJ and retransmits the erroneous frame ✅
C.Sender ignores the error and proceeds with the next frame
D.Sender resets the entire link
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When a CRC error is detected, the receiver sends a REJ (Reject) control frame. The primary station interprets the REJ as a request to retransmit the specific frame that failed the CRC check, ensuring reliable delivery despite the error.

Q2. How does HDLC's bit‑stuffing mechanism differ from PPP's use of escape characters in handling special flag patterns?

A.Both insert a 0 after five consecutive 1s
B.Both replace the flag with an escape sequence
C.HDLC inserts a 0 after five 1s, while PPP prefixes an escape character to any flag or control byte
D.PPP uses no special handling for flag patterns ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: HDLC inserts a 0 after any occurrence of five consecutive 1 bits to prevent accidental flag creation, whereas PPP employs a byte‑oriented escape mechanism that prefixes an escape character (0x7D) before any flag (0x7E) or control octet. This distinction reflects their differing design philosophies.

Q3. Applying the bit‑stuffing rule, how many extra bits are inserted when the payload contains the pattern 01111110?

A.0
B.1 ✅
C.2
D.3
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The pattern 01111110 includes five consecutive 1 bits (bits 2–6). HDLC’s rule inserts a 0 after any run of five 1s to avoid emulating the flag 01111110. Therefore, only one stuffing bit is added, increasing the transmitted bit count by a single bit.

Q4. If an HDLC frame carries 1000 payload bytes and includes a 1‑byte address, 1‑byte control, 2‑byte FCS, and two flag bytes, what is the total frame size in bytes?

A.1004
B.1005
C.1006 ✅
D.1007
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The overhead consists of address (1) + control (1) + FCS (2) + flags (2) = 6 bytes. Adding this to the 1000‑byte payload yields a total frame length of 1006 bytes, which is the size transmitted on the link.

Q5. In HDLC's normal‑response mode, which condition causes the primary station to enter the \awaiting response\ state?

A.After sending a command frame ✅
B.After receiving a response frame
C.After a timeout expires
D.After the link is disconnected
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: When the primary station issues a command frame (e.g., an Information or Supervisory frame) in normal‑response mode, it must wait for the corresponding response from the secondary. Consequently, it transitions to the awaiting‑response state immediately after transmitting the command.

Q6. What is the effect on throughput when HDLC’s window size is increased from 1 to 7, assuming propagation delay equals transmission time?

A.Throughput is cut in half
B.Throughput triples
C.Throughput can increase up to seven‑fold ✅
D.Throughput remains unchanged
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: With a window size of 1, HDLC behaves like Stop‑and‑Wait, limiting throughput to one frame per round‑trip time. Expanding the window to 7 allows up to seven frames to be in transit simultaneously, potentially raising throughput by a factor close to the window size, provided the link can sustain the load.

Q7. The control field of an HDLC frame is 0x03. What type of frame does this represent?

A.Unnumbered frame
B.Supervisory frame ✅
C.Information frame
D.Command frame
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: In HDLC, a control field value of 0x03 corresponds to the Receive Ready (RR) supervisory frame. Supervisory frames manage flow control and error recovery, and the RR indicates that the receiver is ready to accept more information frames, distinguishing it from unnumbered or information frames.

Q8. A link using HDLC repeatedly generates a \frame abort\ signal after every three frames. Which of the following is the most plausible cause?

A.Incorrect bit stuffing
B.Mismatched flag sequences ✅
C.CRC mismatch
D.Incorrect address field
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A frame abort is issued when the receiver cannot locate the expected flag pattern that delimits a frame. If the flag sequence is corrupted or mismatched, the receiver will abort the current frame, producing the observed periodic aborts after a few correctly received frames.

Q9. In a multi‑point HDLC network, what is the primary purpose of the secondary address field?

A.To identify the primary station
B.To identify the destination station ✅
C.To provide error‑correction information
D.To indicate the frame type
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: In multi‑point configurations, the secondary address field specifies the intended recipient of the frame among several secondary stations. This allows the primary station to address a particular node, enabling selective communication while sharing the same physical link.
