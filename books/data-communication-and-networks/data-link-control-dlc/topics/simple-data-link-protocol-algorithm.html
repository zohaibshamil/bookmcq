Q1. In a simple character‑oriented data‑link protocol, what primary function does the escape character serve?

🔹 A. Marks the start of a frame
🔹 B. Indicates error detection
🔹 C. Allows special control bytes to be transmitted as data
🔹 D. Synchronizes sender and receiver clocks

💡 Difficulty: easy | ✅ Correct: C

Q2. Consider a scenario where the escape character 0x7D appears twice consecutively in the payload. If the protocol only adds one extra escape before each occurrence, what inference can be made about the receiver’s interpretation of the subsequent bytes?

🔹 A. Both escape characters will be removed, causing loss of data
🔹 B. The first escape will be treated as a data byte, and the second will trigger removal of the following byte
🔹 C. The receiver will misidentify the frame boundary, potentially merging two frames
🔹 D. The receiver will correctly reconstruct the original payload

💡 Difficulty: medium | ✅ Correct: B

Q3. Differentiate between bit‑stuffing and byte‑stuffing as mechanisms for delimiting frames. Which statement correctly reflects their impact on error propagation?

🔹 A. Bit‑stuffing can cause a single bit error to corrupt multiple subsequent bits, while byte‑stuffing isolates errors to the affected byte
🔹 B. Byte‑stuffing spreads a single bit error across the entire frame, whereas bit‑stuffing confines it to the stuffed bit
🔹 C. Both techniques have identical error propagation characteristics, differing only in implementation complexity
🔹 D. Bit‑stuffing generally results in less error propagation because errors are detected at the bit level before byte reconstruction

💡 Difficulty: hard | ✅ Correct: A
