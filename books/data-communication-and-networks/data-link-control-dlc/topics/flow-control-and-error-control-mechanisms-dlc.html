📝 Sample Questions

Q1. If a bit-oriented protocol uses the flag pattern 011111 to delimit frames, what is the most likely consequence when the data payload contains the same pattern without bit stuffing?

🔹 A. The receiver will treat the payload as a frame delimiter and truncate the frame
🔹 B. The transmission will be automatically corrected by error control
🔹 C. The frame will be ignored but the payload remains intact
🔹 D. The protocol will switch to byte-oriented mode

💡 Difficulty: easy | ✅ Correct: A

Q2. Given that bit stuffing inserts a '0' after five consecutive '1's, how does this mechanism prevent false flag detection when the original data contains the sequence 011111?

🔹 A. It replaces the sequence with a different flag pattern
🔹 B. It inserts a '0' after the five '1's, breaking the flag
🔹 C. It discards the offending bits
🔹 D. It changes the flag to a longer pattern

💡 Difficulty: medium | ✅ Correct: B

Q3. A transmission contains the bit sequence ...10111110... where the flag is 011111. Assuming correct bit stuffing, which statement must be true about the bits surrounding the flag?

🔹 A. The flag is preceded by at least six '1's
🔹 B. A '0' follows every run of five consecutive '1's
🔹 C. The flag appears only at the start of a frame
🔹 D. No bit stuffing is required before the flag

💡 Difficulty: hard | ✅ Correct: D
