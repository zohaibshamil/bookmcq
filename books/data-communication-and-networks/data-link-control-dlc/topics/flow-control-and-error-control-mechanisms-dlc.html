What is Flow control and error control mechanisms DLC?

Flow control prevents a fast sender from overwhelming a slow receiver by regulating data transmission rates, while error control detects and corrects corrupted or lost frames using acknowledgments and retransmissions.

Q1. If a bit-oriented protocol uses the flag pattern 011111 to delimit frames, what is the most likely consequence when the data payload contains the same pattern without bit stuffing?

A.The receiver will treat the payload as a frame delimiter and truncate the frame ✅
B.The transmission will be automatically corrected by error control
C.The frame will be ignored but the payload remains intact
D.The protocol will switch to byte-oriented mode
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Because the receiver relies on the unique flag to detect frame boundaries, an identical pattern in the payload will be mistaken for a delimiter. Without bit stuffing to break the pattern, the receiver will prematurely end the frame, causing loss of the remaining payload data.

Q2. Given that bit stuffing inserts a '0' after five consecutive '1's, how does this mechanism prevent false flag detection when the original data contains the sequence 011111?

A.It replaces the sequence with a different flag pattern
B.It inserts a '0' after the five '1's, breaking the flag ✅
C.It discards the offending bits
D.It changes the flag to a longer pattern
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Bit stuffing works by inserting a '0' after any run of five '1's, which disrupts the exact 011111 pattern that identifies a flag. Consequently, the receiver never sees five consecutive '1's without an intervening '0', eliminating the chance of mistakenly detecting a flag inside the payload.

Q3. When a frame error is detected due to a missing flag, which recovery action aligns best with the protocol's flow‑control strategy?

A.Retransmit only the corrupted frame
B.Discard the frame and request a new one
C.Resynchronize by searching for the next flag pattern ✅
D.Terminate the connection
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Flow control aims to keep the communication channel synchronized. If a flag is missing, the most appropriate step is to search the bit stream for the next valid flag, thereby re‑establishing alignment without unnecessarily discarding data or ending the session.

Q4. A transmission contains the bit sequence ...10111110... where the flag is 011111. Assuming correct bit stuffing, which statement must be true about the bits surrounding the flag?

C.The flag appears only at the start of a frame
D.No bit stuffing is required before the flag ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Because the flag itself is defined as 011111, any occurrence of five consecutive '1's inside payload would be broken by a stuffed '0'. Therefore, the flag can appear without preceding stuffing, and the surrounding bits do not need additional manipulation; the flag is recognized directly.

Q5. If a receiver repeatedly detects the flag pattern 011111 inside data despite bit stuffing, what inference can be drawn about the sender's implementation?

A.The sender is correctly applying bit stuffing

C.The receiver is misinterpreting the flag
D.The protocol uses a different flag pattern
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Repeated false flag detections indicate that the sender is not inserting the required '0' after five consecutive '1's. Without this insertion, the raw data can contain the flag pattern, leading the receiver to falsely identify delimiters and cause framing errors.

Q6. Compare bit‑oriented framing with byte‑oriented framing in terms of overhead and flexibility. Which statement best captures the trade‑off?

A.Bit‑oriented framing has higher overhead but less flexibility
B.Byte‑oriented framing reduces overhead but limits payload types
C.Bit‑oriented framing offers lower overhead and greater flexibility ✅
D.Byte‑oriented framing provides both lower overhead and higher flexibility
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Bit‑oriented framing works at the individual bit level, allowing precise control of delimiters and efficient use of the channel, which reduces overhead. It also accommodates any type of payload because it does not depend on byte boundaries, giving it superior flexibility compared with byte‑oriented schemes.

Q9. What is a key difference between flag detection in bit‑oriented protocols and character detection in byte‑oriented protocols?

A.Bit‑oriented uses start‑stop bits
B.Byte‑oriented relies on parity bits
C.Bit‑oriented searches for a specific bit pattern, while byte‑oriented looks for a unique byte value ✅
D.Both use identical detection mechanisms
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Bit‑oriented protocols identify frame boundaries by scanning for a predefined sequence of bits (e.g., 011111). In contrast, byte‑oriented protocols use a distinct byte value as a delimiter, which aligns with the natural byte boundaries of the data and simplifies detection but reduces flexibility.

Q15. If a transmission error flips the sixth bit of the flag pattern 011111 to '0', how will this affect the receiver's framing process?
