What is Stop and Wait ARQ protocol?

Stop and Wait ARQ is a basic error control mechanism where the sender transmits one frame at a time and must wait for a positive acknowledgment before sending the next frame, automatically retransmitting if a timeout occurs or a negative acknowledgment is received.

📝 All Stop and Wait ARQ protocol MCQs

Q1. What is the primary purpose of the Stop-and-Wait ARQ protocol?

A.Provide flow control
B.Ensure error detection
C.Achieve reliable data transfer ✅
D.Increase throughput
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The protocol is designed to guarantee that every transmitted frame is correctly received before the next one is sent, which provides reliable data transfer over an unreliable link. This reliability is achieved through acknowledgments and possible retransmissions, distinguishing it from merely controlling flow or boosting throughput.

Q2. In Stop-and-Wait, how many frames can the sender have outstanding at any time?

A.One ✅
B.Two
C.Unlimited
D.Zero
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Stop-and-Wait allows only a single frame to be transmitted and await its acknowledgment before sending another. This single outstanding frame characteristic simplifies error recovery but limits throughput, especially on links with large propagation delays.

Q3. If the round‑trip time (RTT) doubles while the frame transmission time remains constant, what is the effect on protocol utilization?

A.Utilization doubles
B.Utilization halves ✅
C.Utilization unchanged
D.Utilization becomes zero
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Utilization is defined as the fraction of time the link carries useful data. When RTT grows, the sender spends more time waiting for acknowledgments, so the proportion of useful transmission time falls roughly by half, reducing overall utilization.

Q4. Suppose a Stop-and-Wait link has frame size \(L=8000\) bits, transmission rate \(R=1\) Mbps, and propagation delay \(t=20\) ms. If the ACK is lost and the sender times out after \(2t+L/R\), how many extra frames will be transmitted?

A.0
B.1 ✅
C.2
D.3
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The frame transmission time is \(L/R = 8000/10^6 = 8\) ms. The round‑trip time is \(2t + L/R = 40 + 8 = 48\) ms. After the timeout the sender retransmits the same frame once, resulting in exactly one additional transmission.

Q5. Given a Stop-and-Wait link where the probability of a frame error is \(p=0.1\) and ACK loss probability is also \(p\), derive the expected number of transmissions per successfully delivered frame.

A.\(1/(1-p)^2\) ✅
B.\(1/(1-p)\)
C.\(1/(1-p^2)\)
D.\(1/(1-2p+p^2)\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A successful exchange requires both the data frame and its ACK to be error‑free, which occurs with probability \((1-p)^2\). The expected number of attempts for a Bernoulli trial with success probability \((1-p)^2\) is the reciprocal, yielding \(1/(1-p)^2\).

Q6. If the sender’s timeout interval is set exactly to the sum of the frame transmission time and the round‑trip propagation time, what type of error does the protocol become most vulnerable to?

A.Duplicate frames ✅
B.Lost frames
C.Out‑of‑order delivery
D.Buffer overflow
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: When the timeout matches the round‑trip time, any slight delay can cause the sender to believe the frame was lost, prompting a retransmission. The receiver may then see two copies of the same frame, creating duplicate‑frame errors.

Q7. Consider a Stop-and-Wait link with frame length \(L\) bits, bandwidth \(B\) bits/s, and propagation delay \(d\). The link utilization \(U\) is given by \(U = \frac{L}{L+2Bd}\). If the bandwidth is doubled while \(L\) and \(d\) stay constant, by what factor does \(U\) change?

A.Increases by factor 2
B.Increases but less than 2
C.Decreases ✅
D.Remains unchanged
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Doubling \(B\) makes the term \(2Bd\) become \(4Bd\). The new utilization is \(L/(L+4Bd)\), which is smaller than the original \(L/(L+2Bd)\). Hence utilization actually decreases when bandwidth grows without altering frame size or delay.

Q8. Which of the following best contrasts Stop-and-Wait ARQ with Go‑Back‑N ARQ regarding channel utilization?

A.Stop-and-Wait has higher utilization
B.Go‑Back‑N allows multiple outstanding frames ✅
C.Both have same utilization
D.Go‑Back‑N uses less bandwidth
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Go‑Back‑N employs a sliding window that permits several frames to be sent before acknowledgments arrive, dramatically improving channel utilization compared with Stop‑and‑Wait, which must wait after each frame.

Q9. Evaluate the impact of increasing the ACK timeout value on throughput and latency in a Stop-and-Wait protocol.

A.Throughput increases, latency unchanged
B.Throughput decreases, latency increases ✅
C.Throughput unchanged, latency decreases
D.Throughput decreases, latency unchanged
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A longer timeout means the sender waits longer before retransmitting lost frames, reducing the rate of successful transmissions (lower throughput) and adding extra waiting time for each loss event (higher latency).

Q10. A network designer must choose between Stop-and-Wait and Selective Repeat ARQ for a satellite link with long propagation delay. Which factor most strongly justifies selecting Selective Repeat?

A.Higher error rate ✅
B.Need for in‑order delivery
C.Desire for low memory usage
D.Requirement for minimal protocol complexity
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Satellite links often suffer higher bit‑error rates; Selective Repeat can retransmit only erroneous frames, preserving bandwidth, whereas Stop‑and‑Wait would waste the long round‑trip time on each retransmission, making Selective Repeat far more efficient.

Q11. Compare the effect of frame size on efficiency in Stop-and-Wait versus Sliding Window protocols.

A.Larger frames improve efficiency for both ✅
B.Larger frames only improve Sliding Window
C.Frame size has no effect
D.Smaller frames improve Stop-and-Wait only
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Increasing frame size raises the proportion of time spent transmitting data relative to waiting for acknowledgments, boosting efficiency for both protocols. However, the benefit is more pronounced for Stop‑and‑Wait because its waiting overhead is fixed per frame.

Q12. Differentiate the role of sequence numbers in Stop-and-Wait ARQ compared to Go‑Back‑N ARQ.

A.Stop-and-Wait uses 1‑bit, Go‑Back‑N uses multiple bits ✅
B.Both use the same number of bits
C.Go‑Back‑N does not use sequence numbers
D.Stop-and-Wait uses larger sequence space
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Stop‑and‑Wait only needs to distinguish between the current frame and the next one, so a single‑bit sequence number suffices. Go‑Back‑N must track a larger window of outstanding frames, requiring several bits to represent the sequence numbers.

Q13. If a Stop-and-Wait link experiences a 5% frame loss rate, what is the expected increase in average transmission time compared to an error‑free link? Assume timeout equals one RTT.

A.5% increase
B.10% increase
C.Approximately 5/(0.95) ≈ 5.26% increase
D.Approximately 1/0.95 ≈ 5.26% increase ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: The expected number of transmissions per successful frame is \(1/(1-p) = 1/0.95 ≈ 1.0526\), meaning about a 5.26 % increase in average transmission time over an error‑free scenario.

Q14. In Stop-and-Wait, what mechanism prevents the receiver from accepting duplicate frames?

A.CRC check
B.Sequence number verification ✅
C.Flow control
D.Window size
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Each frame carries a sequence number (typically 0 or 1). The receiver checks this number against the last correctly received frame; if it matches the previously acknowledged number, the frame is identified as a duplicate and discarded.

Q15. Apply the Stop-and-Wait protocol to a scenario where the sender’s buffer can hold 10 frames but the protocol only allows one outstanding frame. What is the consequence for buffer utilization?

A.Full utilization
B.Underutilization ✅
C.Overflow
D.No effect
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Even though the sender can store many frames, Stop‑and‑Wait restricts transmission to one frame at a time, leaving most of the buffer idle while waiting for acknowledgments, thus underutilizing the available storage.

Q16. Synthesize a strategy to improve throughput of Stop-and-Wait on a high‑delay link without changing physical layer parameters.

A.Increase frame size ✅
B.Reduce propagation delay
C.Use pipelining with multiple frames
D.Decrease error rate
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: By enlarging the frame size, the proportion of time spent transmitting data relative to waiting for acknowledgments grows, raising utilization. This change works within the existing physical layer, unlike adding pipelining, which would alter the protocol itself.

Q17. Explain how the Stop-and-Wait protocol ensures flow control between sender and receiver.

A.By limiting the number of unacknowledged frames to one ✅
B.By adjusting window size dynamically
C.By using congestion notifications
D.By employing priority queues
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The protocol’s rule that the sender must wait for an acknowledgment before sending the next frame inherently caps the number of in‑flight frames, preventing the receiver from being overwhelmed and providing simple, effective flow control.

Q18. Which of the following best illustrates the relationship between Stop-and-Wait ARQ and the concept of a ‘handshaking’ protocol?

A.Sender transmits continuously
B.Receiver sends ACK before next frame ✅
C.Both parties send data simultaneously
D.No acknowledgments are used
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Stop‑and‑Wait embodies a handshake: after the sender transmits a frame, the receiver replies with an acknowledgment, and only then does the sender proceed with the next frame. This explicit exchange characterizes handshaking behavior.

Q19. Given a Stop-and-Wait link where the ACK transmission time is negligible, derive the expression for channel utilization \(U\) in terms of frame transmission time \(T_f\) and round‑trip propagation time \(T_p\).

A.\(U = \frac{T_f}{T_f + 2T_p}\) ✅
B.\(U = \frac{T_f}{T_f + T_p}\)
C.\(U = \frac{2T_f}{T_f + 2T_p}\)
D.\(U = \frac{T_f}{2T_f + T_p}\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: When ACK time is ignored, each cycle consists of sending the frame (\(T_f\)) and then waiting for the round‑trip propagation (\(2T_p\)). Utilization is the fraction of time spent transmitting data: \(U = T_f/(T_f+2T_p)\).

Q20. If the ACK transmission time is not negligible and equals half the frame transmission time, how does the utilization formula change?

A.\(U = \frac{L}{L + 2Bd + L/2}\) ✅
B.\(U = \frac{L}{L + 2Bd}\)
C.\(U = \frac{L}{L + 2Bd + L}\)
D.\(U = \frac{L}{L + Bd}\)
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The total cycle now includes the data transmission (\(L/B\)), the round‑trip propagation (\(2d\)), and the ACK transmission (\(L/(2B)\)). Converting to bits yields \(U = L / (L + 2Bd + L/2)\), reflecting the added ACK overhead.

Q21. Compare the effect of increasing the timeout interval on the probability of unnecessary retransmissions in Stop-and-Wait.

A.Increases probability
B.Decreases probability ✅
C.No effect
D.Causes buffer overflow
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A longer timeout gives the sender more time to wait for a legitimate acknowledgment before assuming loss, thereby reducing the chance that a correctly received frame triggers an unnecessary retransmission.

Q22. Which of the following best explains why Stop-and-Wait is unsuitable for high‑bandwidth, high‑delay networks?

A.Low utilization due to waiting ✅
B.Excessive error detection
C.Complex sequence numbers
D.Requires large buffers
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When bandwidth and delay are both large, the sender spends a substantial portion of time idle while awaiting acknowledgments, leading to very low link utilization—a primary drawback of Stop‑and‑Wait in such environments.

Q23. Assume a Stop-and-Wait link where the probability of a frame being corrupted is 0.2, and ACKs are always correctly received. What is the expected number of transmissions needed for one successful frame?

A.1.2
B.1.25 ✅
C.1.5
D.2
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Success occurs with probability \(0.8\). The expected number of trials for a Bernoulli process is \(1/0.8 = 1.25\). Thus, on average 1.25 transmissions are required for each correctly received frame.
