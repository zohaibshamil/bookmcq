What is Link Layer Addressing in Data Link Layer?

Link Layer Addressing uses unique physical addresses, commonly known as MAC addresses, assigned to each network interface card to identify devices on the same local network segment so that frames can be correctly delivered from source to destination within a single hop.

Q1. When a frame leaves host A with source link address L1L_1L1​ and destination L2L_2L2​ and reaches router R, which statement must be true about the next frame’s link addresses on the outgoing link?

A.The source address stays L1L_1L1​.
B.The source address becomes the router’s outgoing‑interface address. ✅
C.The destination address becomes L1L_1L1​.
D.Both source and destination addresses remain unchanged.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The router replaces the source MAC with its own address on the outgoing interface, because the frame now originates from the router on that link. The destination MAC is set to the next hop’s MAC, while the original source MAC is no longer used beyond the inbound link.

Q2. If a frame’s destination MAC address is mistakenly set to a host that is not on the next link, what is the most likely effect on packet delivery?

A.The frame will be broadcast to all nodes on the link.
B.The frame will be dropped by the switch/router.
C.The frame will be forwarded to the incorrect host, causing a routing loop.
D.The frame will be queued until the correct MAC is learned. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Switches forward frames based on MAC learning; a mismatched destination MAC that does not belong to any device on the link will cause the switch to flood the frame. However, if the link uses point‑to‑point media, the frame will be discarded because the destination cannot be reached, preventing delivery.

Q3. Consider three consecutive links with MAC pairs (L1,L2)(L_1,L_2)(L1​,L2​), (L4,L5)(L_4,L_5)(L4​,L5​), and (L7,L8)(L_7,L_8)(L7​,L8​). If a frame is observed on the third link with source L7L_7L7​ and destination L8L_8L8​, which inference is logically valid?

A.The frame originated at the first host. ✅
B.The frame has traversed exactly two routers.
C.The original IP source address must be N1N_1N1​.
D.The MAC address L5L_5L5​ is still present in the frame.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Since MAC addresses are rewritten at each hop, the source MAC on the third link (L7L_7L7​) must belong to the router interface that sent the frame onto that link. Therefore the frame has passed through two routers, but the only guaranteed fact is that the frame originated from the original source host, whose MAC was replaced at each hop.

Q4. Which statement best compares link‑layer addressing on a broadcast Ethernet segment versus a point‑to‑point link?

A.Both use the same MAC address for all frames.
B.Broadcast segments require a unique MAC per frame, while point‑to‑point links reuse the same MAC.
C.Broadcast segments allow a single destination MAC to reach multiple hosts, whereas point‑to‑point links have a unique destination MAC for the single peer. ✅
D.Point‑to‑point links never use MAC addresses.
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: On a broadcast Ethernet, the destination MAC can be a multicast or broadcast address that many hosts recognize, enabling one‑to‑many delivery. In contrast, a point‑to‑point link connects exactly two interfaces, each with its own unique MAC, so frames are addressed to that single destination MAC.

Q5. A network administrator observes that increasing the ARP cache timeout from 30 seconds to 5 minutes reduces the number of ARP requests but increases the number of stale‑address errors. Which evaluation best explains this trade‑off?

A.Longer timeouts always improve performance. ✅
B.Shorter timeouts eliminate stale entries but cause more broadcast traffic.
C.Longer timeouts reduce broadcast overhead but risk using outdated MAC‑IP mappings, leading to delivery failures.
D.Cache size, not timeout, determines stale‑address occurrences.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Extending the ARP cache lifetime means entries stay longer, decreasing the frequency of ARP request broadcasts. However, if a host’s MAC changes (e.g., due to NIC replacement), the cached mapping becomes stale, causing frames to be sent to the wrong MAC address, which results in communication failures until the cache expires or is refreshed.

Q6. When a router forwards a frame from link 1 to link 2, which change to the frame’s link‑layer addresses is required?

A.Both source and destination MACs remain unchanged.
B.Only the source MAC is replaced with the router’s outgoing‑interface address. ✅
C.Only the destination MAC is replaced with the next‑hop’s MAC.
D.Both MAC addresses are swapped with the router’s interface addresses.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The router must replace the source MAC with its own address on the outgoing interface, indicating that the frame now originates from the router. The destination MAC is set to the MAC of the next hop (or final host) on link 2. The original source MAC is discarded after the inbound link.

Q7. If two different interfaces on the same router are manually configured with the identical MAC address, what is the most likely outcome?

A.Both interfaces will forward frames correctly.
B.Frames destined for either interface may be delivered to the wrong port, causing collisions.
C.The router will reject the configuration and refuse to start.
D.MAC address duplication is ignored by the router. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Routers typically allow duplicate MAC addresses on separate interfaces but the underlying switch fabric may deliver frames to the wrong interface, leading to ambiguous forwarding. In practice, many devices will log a warning but continue operating, potentially causing occasional misdelivery rather than a complete failure.

Q8. Why must link‑layer addresses be rewritten at each hop in a connectionless Internet?

A.To keep the IP header unchanged. ✅
B.To ensure that each link can uniquely identify the next hop.
C.To hide the original source MAC for security.
D.To comply with Ethernet standards.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The network layer’s IP addresses remain constant throughout the packet’s journey, while the data‑link layer’s MAC addresses are local to each link. Rewriting the MAC at each hop allows the frame to be correctly delivered on the next physical segment without altering the IP header, preserving end‑to‑end semantics.

Q9. In a network with three links and two routers, which principle ensures that the same IP datagram can traverse all links despite changing MAC addresses?

A.MAC addresses are globally unique.
B.IP addresses are immutable across hops. ✅
C.Each router caches the MAC of the next hop.
D.Frames are encrypted at every hop.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The IP layer treats the datagram as an immutable payload, using source and destination IP addresses that do not change. The data‑link layer adapts to each physical link by updating MAC addresses, allowing the same IP datagram to be carried across heterogeneous media without modification.

Q10. A designer must create a topology with three links, two routers, and hosts Alice and Bob. Which set of MAC address assignments correctly reflects the address changes as frames move from Alice to Bob?

A.L1L_1L1​→L2L_2L2​, L2L_2L2​→L3L_3L3​, L3L_3L3​→L4L_4L4​
B.LAL_ALA​→LR1L_R1LR​1, LR1L_R1LR​1→LR2L_R2LR​2, LR2L_R2LR​2→LBL_BLB​ ✅
C.LAL_ALA​→LR1L_R1LR​1, LR2L_R2LR​2→LR1L_R1LR​1, LBL_BLB​→LR2L_R2LR​2
D.LAL_ALA​→LBL_BLB​ on all links
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The correct sequence follows the pattern: source MAC of Alice, then router 1’s outgoing interface MAC, then router 2’s outgoing interface MAC, and finally Bob’s MAC. This mirrors the example where each hop replaces the source MAC with its own interface address while preserving the ultimate destination MAC for the final host.

Q11. When IPv6 nodes communicate on the same link, which link‑layer address type is primarily used for neighbor discovery?

A.Global unicast MAC addresses
B.Link‑local MAC addresses derived from the IPv6 prefix
C.Multicast MAC addresses corresponding to the solicited‑node multicast group
D.Broadcast MAC addresses ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: IPv6 neighbor discovery relies on solicited‑node multicast addresses, which map to specific multicast MAC addresses. Hosts listen on these multicast MACs to receive neighbor‑solicitation and advertisement messages, enabling address resolution without broadcast, which is not used in IPv6.

Q12. In a switched Ethernet environment, how does link‑layer addressing differ from a bridged network regarding frame forwarding?

A.Switches use IP addresses to forward frames, while bridges use MAC addresses.
B.Switches maintain a MAC address table per port, whereas bridges flood frames to all ports except the incoming one.
C.Both switches and bridges always flood frames to all ports. ✅
D.Bridges perform ARP on behalf of switches.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Both switches and bridges operate at the data‑link layer and forward frames based on MAC addresses. However, a switch builds a forwarding table that maps MAC addresses to specific ports, enabling selective forwarding. A bridge, particularly in older implementations, may simply flood unknown destination frames, though modern bridges often incorporate similar learning mechanisms.

Q13. If a frame arrives at a host with the correct destination MAC but an incorrect destination IP address, what is the host’s expected behavior?

A.The frame is dropped silently. ✅
B.The frame is processed and an ICMP error is sent back.
C.The frame is processed normally, ignoring the IP mismatch.
D.The host updates its ARP table with the wrong IP.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The data‑link layer delivers the frame to the host because the MAC matches. The network layer then examines the IP header; finding the destination IP does not match any of its interfaces, the host discards the packet and typically does not generate an error, preserving end‑to‑end integrity.

Q14. Given three consecutive frames observed on links 1, 2, and 3 with source MACs L1L_1L1​, L4L_4L4​, and L7L_7L7​ respectively, which router most likely forwarded the frame from link 2 to link 3?

A.Router A connected to links 1 and 2 ✅
B.Router B connected to links 2 and 3
C.Router C connected to links 1 and 3
D.The source host itself
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The source MAC on link 2 (L4L_4L4​) belongs to the interface of the router that sent the frame onto that link. Since the next observed source MAC on link 3 is L7L_7L7​, it must be the outgoing interface of the router connected to links 2 and 3. Therefore, the router that forwarded from link 2 to link 3 is the one whose outgoing MAC is L7L_7L7​, indicating Router A’s role in the earlier hop.

Q15. On an Ethernet LAN, which MAC address is used to send a frame to all hosts on the segment?

A.The unicast address of the sender
B.The broadcast address FF:FF:FF:FF:FF:FFFF:FF:FF:FF:FF:FFFF:FF:FF:FF:FF:FF
C.The multicast address of the first host
D.The router’s MAC address ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Ethernet defines a special broadcast MAC address consisting of all ones (FF:FF:FF:FF:FF:FFFF:FF:FF:FF:FF:FFFF:FF:FF:FF:FF:FF). When a frame is addressed to this MAC, every host on the LAN receives and processes the frame. Unicast addresses target a single host, while multicast addresses target a specific group.

Q16. Why is MAC address spoofing considered a security risk in LAN environments?

A.It allows attackers to change IP addresses.
B.It enables denial‑of‑service by exhausting ARP tables.
C.It lets malicious devices masquerade as legitimate ones, intercepting traffic. ✅
D.It disables DHCP services.
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: By falsifying its MAC address, an attacker can impersonate another device, causing switches to forward frames intended for the legitimate host to the attacker. This enables man‑in‑the‑middle attacks, traffic interception, and potential data exfiltration, making MAC spoofing a serious security concern.

Q17. In Ethernet, how do unicast, multicast, and broadcast MAC addresses differ in their usage?

A.Unicast addresses are reserved for routers only ✅
B.Broadcast addresses target a single host
C.Multicast addresses are a subset of unicast addresses
D.Broadcast addresses reach all nodes, multicast reaches a group, and unicast targets one node
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Unicast MACs identify a single network interface, multicast MACs identify a group of interfaces that have expressed interest, and the broadcast MAC (FF:FF:FF:FF:FF:FFFF:FF:FF:FF:FF:FFFF:FF:FF:FF:FF:FF) reaches every node on the LAN. This distinction determines how frames are delivered across the link.

Q18. When a VPN encapsulates an IP packet inside another IP packet, what role does the original packet’s link‑layer address play?

A.It is preserved and used for routing inside the tunnel.
B.It is replaced by the VPN endpoint’s MAC address for the outer frame.
C.It is converted to an IPv6 address.
D.It is ignored entirely. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The original packet’s MAC addresses are irrelevant once the packet is encapsulated for tunneling; the outer IP header and its own data‑link frame carry the MAC addresses of the VPN endpoints. Inside the tunnel, the inner packet is treated as payload, and its link‑layer fields are not examined for forwarding.

Q19. In a network using proxy ARP, how does the router’s link‑layer address translation affect host communication?

A.Hosts exchange original MACs directly, bypassing the router.
B.The router answers ARP requests with its own MAC, acting as a bridge between different subnets.
C.Proxy ARP eliminates the need for IP routing. ✅
D.Hosts use IPv6 link‑local addresses exclusively.
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Proxy ARP allows a router to respond to ARP requests on behalf of a host in another subnet, supplying its own MAC address. This makes the host believe it is on the same link, enabling communication without explicit routing. The router then forwards packets appropriately, effectively translating link‑layer addresses.

Q20. What is a Media Access Control (MAC) address?

A.A 32‑bit identifier used by the network layer. ✅
B.A globally unique 48‑bit hardware address assigned to a network interface.
C.A dynamic address assigned by DHCP.
D.An IPv6 link‑local address.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A MAC address is a 48‑bit (sometimes 64‑bit) identifier burned into a network interface card. It uniquely identifies the hardware on the link layer and is used for frame delivery within a local network segment.

Q21. How many MAC addresses does a router typically have if it is connected to three distinct network links?

A.One, shared across all links
B.Two, one for inbound and one for outbound traffic ✅
C.Three, one per link
D.Four, including a management interface
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Each physical interface on a router requires its own MAC address for link‑layer communication. Therefore, a router with three separate links will have three distinct MAC addresses, one for each interface, enabling proper frame forwarding on each segment.
