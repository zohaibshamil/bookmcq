What is Two Categories of Links in Data Link Layer?

Links in the Data Link Layer are categorized into point-to-point links, where two devices communicate directly over a dedicated connection, and broadcast links, where multiple devices share a common channel and must use protocols to avoid collisions when transmitting data.

📝 All Two Categories of Links in Data Link Layer MCQs

Q1. Which of the following best describes the two primary categories of data‑link layer links?

A.Point‑to‑point and multicast
B.Point‑to‑point and broadcast ✅
C.Unicast and anycast
D.Circuit‑switched and packet‑switched
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The data‑link layer classifies links mainly as point‑to‑point, where a single dedicated connection exists between two nodes, and broadcast, where a single medium is shared among multiple nodes. This distinction is fundamental and matches option B, making it the correct choice.

Q2. Alice is shown connected to routers R1 and R2 via separate lines. What type of link does each line most likely represent?

A.Broadcast link shared among all routers
B.Point‑to‑point link dedicated to Alice and the router ✅
C.Virtual circuit established over a WAN
D.Multipoint link that aggregates traffic from several sources
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The diagram shows distinct physical lines from Alice to each router, indicating no sharing of the medium with other devices. Such dedicated connections are characteristic of point‑to‑point links, so option B correctly identifies the link type.

Q3. Compared with broadcast links, point‑to‑point links generally provide which of the following benefits?

A.Higher collision probability
B.Simpler MAC address management ✅
C.Reduced bandwidth per connection
D.Increased need for network segmentation
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Because point‑to‑point links connect only two devices, there is no need to coordinate access to a shared medium, eliminating collisions and simplifying MAC address handling. This advantage is captured in option B, making it the correct answer.

Q4. If a new router R5 is added and shares the same physical medium as R1 and R2, what logical change occurs to the classification of Alice’s links?

A.Both links become broadcast links
B.Both links remain point‑to‑point
C.Alice now has one point‑to‑point and one broadcast link ✅
D.All links become multipoint links
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When a new router shares the same physical medium as the existing routers, the medium becomes shared among multiple devices. Consequently, the link that continues to be a dedicated connection remains point‑to‑point, while the other becomes a broadcast link that multiple routers can access. Option C captures this logical transition.

Q5. Which statement best evaluates the impact of using point‑to‑point links on the size of collision domains in a LAN?

A.Collision domains expand because each link adds more nodes
B.Collision domains shrink, often to a single link segment ✅
C.Collision domains are unaffected by link type
D.Collision domains become irrelevant in point‑to‑point environments
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Point‑to‑point links isolate each connection to two endpoints, preventing other devices from contending for the same medium. This isolation reduces the collision domain to the individual link segment, effectively shrinking it compared to shared media where many nodes share a single domain. Therefore, option B is correct.

Q6. Applying the principle of link selection, which category is most appropriate for inter‑ISP communication that requires dedicated bandwidth and low latency?

A.Broadcast link
B.Multipoint link
C.Point‑to‑point link ✅
D.Anycast link
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Inter‑ISP connections often demand guaranteed bandwidth and predictable latency, which are best achieved with dedicated, non‑shared media. Point‑to‑point links provide an exclusive channel between two endpoints, meeting these requirements, so option C correctly identifies the suitable category.

Q7. Synthesize a network design where Alice connects to both R3 and R4 using the same link type. Which link category should be chosen to minimize configuration complexity while supporting multiple routers?

A.Point‑to‑point links to each router separately
B.A single broadcast link shared among R3 and R4 ✅
C.A virtual circuit over a packet‑switched network
D.A multipoint link with dynamic routing
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Using a broadcast link allows Alice to communicate with multiple routers over one shared medium, reducing the number of separate interfaces and configuration steps. This approach simplifies network setup while still enabling connectivity to both R3 and R4, making option B the appropriate choice.

Q8. If the sole broadcast link in the network fails, what is the most likely effect on Alice’s ability to reach other ISPs through routers R2 and R4?

A.Alice can still communicate via point‑to‑point links to R2 and R4
B.All communication to other ISPs is disrupted ✅
C.Only communication to R4 is lost, while R2 remains reachable
D.Alice must reroute traffic through a newly established point‑to‑point link
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When the only broadcast medium fails, any links that depend on that shared channel become non‑functional. Since Alice’s connections to the routers rely on this broadcast link, she loses the ability to send packets to those routers, effectively cutting off access to other ISPs. Hence, option B accurately describes the outcome.

Q9. Differentiate the expected throughput of a point‑to‑point link versus a broadcast link when both carry identical traffic loads of \(100\ \text{Mbps}\). Which statement is most accurate?

A.Both links achieve the same throughput because load is identical
B.The point‑to‑point link sustains near‑full \(100\ \text{Mbps}\) while the broadcast link experiences contention, reducing effective throughput ✅
C.The broadcast link outperforms the point‑to‑point link due to shared resources
D.Throughput is unpredictable for both link types under identical loads
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A point‑to‑point link provides a dedicated channel, so it can deliver close to the full \(100\ \text{Mbps}\) capacity to its two endpoints. In contrast, a broadcast link must arbitrate access among multiple devices, leading to collisions or scheduling delays that lower the effective throughput below the nominal rate. Option B captures this distinction.

Q10. Design a hybrid network that combines both categories of links to balance cost and performance. Which configuration best meets this goal?

A.Use point‑to‑point links for all internal connections and broadcast links only for external ISP links
B.Employ broadcast links for high‑traffic core segments and point‑to‑point links for edge devices
C.Implement point‑to‑point links for critical ISP connections and broadcast links for intra‑LAN communication ✅
D.Deploy only point‑to‑point links throughout the network
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Critical ISP connections benefit from dedicated bandwidth and low latency, characteristics of point‑to‑point links, while intra‑LAN traffic can efficiently share a broadcast medium, reducing cabling costs. This hybrid approach leverages the strengths of each category, aligning with the design goals described in option C.

Q11. Given that a link is shared by routers R1, R2, and R3, and Alice communicates with R1 over a separate cable, what can be deduced about the classification of Alice’s link to R1?

A.It is a broadcast link because the medium is shared among multiple routers
B.It is a point‑to‑point link as it connects only Alice and R1 directly ✅
C.It is a multipoint link that aggregates traffic from R1, R2, and R3
D.It cannot be classified without additional information
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Even though the surrounding network includes a shared medium among several routers, the direct cable between Alice and R1 connects only those two devices, fulfilling the definition of a point‑to‑point link. The presence of other shared links elsewhere does not alter this classification, making option B correct.

Q12. Evaluate the security implications of using broadcast links versus point‑to‑point links in the context of eavesdropping risks. Which statement is most accurate?

A.Broadcast links inherently provide better security due to shared authentication
B.Point‑to‑point links reduce eavesdropping risk because the medium is not accessible to other nodes ✅
C.Both link types have equal vulnerability to interception
D.Security depends solely on encryption, not on link type
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Broadcast links expose transmitted frames to all devices on the shared medium, making it easier for an unauthorized node to capture traffic. In contrast, point‑to‑point links confine communication to two endpoints, limiting physical access and thereby decreasing the likelihood of eavesdropping. Thus, option B correctly reflects the security advantage.
