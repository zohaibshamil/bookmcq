What is Three Types of addresses in Link Layer Addressing?

In Link Layer Addressing, unicast addresses deliver frames to a single specific device, multicast addresses send frames to a selected group of devices, and broadcast addresses transmit frames to all devices on the local network segment simultaneously.

📝 All Three Types of addresses in Link Layer Addressing MCQs

Q1. Which layer provides node-to-node service in the Internet architecture?

A. Physical layer
B. Data-link layer ✅
C. Network layer
D. Transport layer

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The data-link layer sits between the physical and network layers and is responsible for delivering frames from one node to the next node on a link, which is precisely the node‑to‑node service described. The physical layer merely transmits bits, while the network layer handles end‑to‑end routing, so the correct answer is the data‑link layer.

Q2. What is the hardware address called that operates at the data‑link layer?

A. IP address
B. MAC address ✅
C. Port number
D. Subnet mask

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

At the data‑link layer, devices are identified by their Media Access Control (MAC) addresses. These addresses are burned into network interface cards and used for frame delivery on a local network segment. IP addresses and port numbers belong to higher layers, making MAC the correct choice.

Q3. If a router receives a frame on a link that uses a different data‑link protocol than the next link, what must the router do?

A. Forward the frame unchanged
B. Encapsulate the frame anew without decapsulation
C. Decapsulate the incoming frame and then re‑encapsulate it for the next link ✅
D. Drop the frame immediately

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Because each link may employ a distinct protocol and frame format, the router must first remove (decapsulate) the frame it received, extract the network‑layer packet, and then encapsulate that packet into a new frame that conforms to the protocol of the outgoing link.

Q4. Given that each intermediate node must both encapsulate and decapsulate, what can be inferred about frame format uniformity across a multi‑link path?

A. All frames on the path have identical formats
B. Some frames on the path differ in format ✅
C. All frames on the path differ in format
D. No inference can be drawn

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Since routers must perform both encapsulation and decapsulation at every hop, it follows that the frames arriving from one link are not guaranteed to match the format required by the next link. Therefore, at least some frames differ, prompting the router to translate between formats.

Q5. A switch operates solely at the data‑link layer. What impact does this have on the need for address translation?

A. Address translation is required at each hop
B. Address translation is not required ✅
C. Partial address translation is performed only for WAN links
D. Translation is performed only by routers, not switches

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Switches forward frames based on MAC addresses without interpreting higher‑layer addresses. Because they do not change the frame’s addressing scheme, there is no need for address translation when a frame passes through a switch. Only routers, which connect different link‑layer technologies, may need to translate addresses.

Q6. A path consists of three LANs and two WANs, each using a distinct data‑link protocol. How many encapsulation/decapsulation operations occur from source to destination?

A. 8
B. 10 ✅
C. 12
D. 14

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The source host encapsulates once (1). Each of the four intermediate routers performs a decapsulation and a re‑encapsulation (2 × 4 = 8). Finally, the destination host decapsulates (1). Total operations = 1 + 8 + 1 = 10.

Q7. An ISP replaces a WAN link’s protocol with one identical to the preceding LAN. What change occurs in the data‑link processing at the adjacent router?

A. Both encapsulation and decapsulation are eliminated ✅
B. Only decapsulation is eliminated
C. Only encapsulation is eliminated
D. No change in processing

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When two consecutive links share the same data‑link protocol, the router can forward the incoming frame unchanged, removing the need to decapsulate the old frame and encapsulate a new one. This eliminates both operations, simplifying processing and reducing overhead.

Q8. How does a MAC address differ from an IP address in terms of network scope?

A. MAC is local, IP is global ✅
B. MAC is global, IP is local
C. Both are local
D. Both are global

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A MAC address uniquely identifies a network interface within a single physical network segment (local scope). In contrast, an IP address is designed for routing across multiple networks and therefore has a global scope, enabling communication beyond the local LAN.

Q9. Why does using point‑to‑point networks reduce the number of data‑link layers involved compared with LANs?

A. Because only one node is present
B. Because only one protocol is used on the link ✅
C. Because switches are not needed
D. Because frames are not required

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A point‑to‑point link connects exactly two endpoints, so a single data‑link protocol can be used for the entire link. This eliminates the need for multiple data‑link layers that would otherwise be required to handle different LAN protocols or switch operations.

Q10. Which statement best distinguishes a router’s data‑link layer function from a host’s data‑link layer function?

A. Routers only encapsulate frames
B. Hosts only decapsulate frames
C. Routers both encapsulate and decapsulate frames ✅
D. Hosts both encapsulate and decapsulate frames

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

A host sends a frame onto its attached link (encapsulation) and receives a frame from that link (decapsulation). An intermediate router, however, must decapsulate the incoming frame to extract the packet and then encapsulate it again for the next link, performing both actions at each hop.

Q11. Contrast the role of switches versus routers at the data‑link layer in handling address information.

A. Switches use MAC addresses, routers use MAC addresses only
B. Switches forward based on MAC, routers forward based on MAC and IP ✅
C. Switches encapsulate frames, routers decapsulate frames
D. Switches operate at the network layer, routers at the data‑link layer

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Switches operate entirely within a LAN, forwarding frames solely on the basis of destination MAC addresses. Routers, while also using MAC addresses to move frames onto the next link, additionally consult IP addresses at the network layer to determine the appropriate outbound interface, making their forwarding decision dependent on both MAC and IP information.

Q12. Given the three address types (MAC, IP, and port), which combination is essential for end‑to‑end delivery of a TCP segment across multiple networks?

A. MAC address only
B. IP address only
C. MAC address plus IP address
D. IP address plus port number ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

For a TCP segment to travel across several networks, the IP address directs the packet through routers, while the port number identifies the specific application endpoint on the destination host. MAC addresses are required only on each local link, so the essential pair for end‑to‑end delivery is IP plus port.

Q13. If a host sends a frame to a destination on the same LAN, which address type is used as the destination address in the frame?

A. MAC address ✅
B. IP address
C. Port number
D. Subnet mask

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

When communication stays within a single LAN, the frame’s destination field contains the MAC address of the target interface. The IP address is used by the network layer for routing decisions, but the data‑link layer relies on MAC addresses to deliver the frame locally.

Q14. Explain how encapsulation at each router enables communication over heterogeneous links.

A. It standardizes the payload size
B. It changes the payload’s content
C. It adds routing information
D. It converts the frame to the protocol required by the next link ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Each router extracts the network‑layer packet from the incoming frame (decapsulation) and then encapsulates that packet into a new frame that conforms to the protocol of the outgoing link. This conversion allows the packet to traverse links that use different frame formats, ensuring interoperability across heterogeneous media.

Q15. Design a scenario where three different data‑link protocols are used in a path. Which sequence of address types does a packet encounter from source to destination?

A. MAC → IP → MAC → IP → MAC
B. MAC → MAC → MAC → MAC → MAC
C. MAC → MAC → MAC → MAC → MAC (different protocols) ✅
D. MAC → MAC → MAC → MAC → MAC (same protocol)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

In a multi‑hop path using three distinct data‑link protocols, the packet is always carried inside a MAC‑addressed frame at each hop, regardless of the underlying protocol. The sequence therefore consists of a series of MAC addresses, one for each link, while the network‑layer IP address remains unchanged throughout the journey.

Q16. Predict the impact on latency if each intermediate router must perform both encapsulation and decapsulation, assuming each operation adds 0.5 ms. Four intermediate routers are present. What is the total added latency?

A. 1 ms
B. 2 ms
C. 3 ms
D. 4 ms ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Each router performs two operations (decapsulation + encapsulation), each adding 0.5 ms, for a total of 1 ms per router. With four routers, the added latency is 4 × 1 ms = 4 ms.

Q17. Why is the data‑link layer said to provide node‑to‑node service rather than end‑to‑end service?

A. Because it only cares about the local link ✅
B. Because it handles routing decisions
C. Because it uses IP addressing
D. Because it ensures reliable delivery

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The data‑link layer’s responsibility is confined to delivering frames between directly connected nodes on a single link. It does not manage the overall path across multiple networks; that responsibility belongs to the network layer, which provides end‑to‑end service. Hence, the data‑link layer is characterized as offering node‑to‑node service.
