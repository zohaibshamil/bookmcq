What is Services in Data Link Layer?

The Data Link Layer provides essential services including framing, which organizes bits into manageable units; error detection and correction to ensure data integrity; flow control to prevent receiver overload; and media access control to coordinate how multiple devices share the same link.

Q1. If a frame is corrupted during transmission between Alice and router R2, which data‑link service will most likely prevent the error from propagating to the network layer?

A.Error detection using CRC ✅
B.Flow control
C.Address resolution
D.Broadcast
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The data‑link layer provides error detection, typically using a cyclic redundancy check (CRC). When a corrupted frame is detected, the layer discards it, preventing erroneous data from reaching the network layer. Flow control, address resolution, and broadcasting do not address corruption directly, making CRC the correct service.

Q2. When Alice sends a frame to Bob via routers R2 and R4, the frame must be re‑encapsulated at each hop. If the frame size exceeds the MTU of the link between R2 and R4, what logical consequence follows?

A.The frame will be fragmented at the network layer
B.The frame will be dropped and an ICMP message sent ✅
C.The frame will be padded to fit the MTU
D.The frame will be transmitted unchanged
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Because the data‑link layer cannot fragment frames, the network layer must handle an oversized packet. It drops the packet and sends an ICMP Destination Unreachable (Fragmentation Needed) message back to the sender, prompting retransmission at a suitable size.

Q4. If a data‑link layer protocol provides both error detection and correction, which of the following statements is logically implied?

A.All errors are corrected before delivery
B.Only detectable errors are corrected
C.Undetectable errors are still possible ✅
D.Correction eliminates the need for retransmission

Q5. Alice’s Ethernet interface implements a MAC address table that ages out entries after 300 seconds of inactivity. What inference can be drawn about the effect of a prolonged idle period on subsequent frame delivery?

A.Frames will be broadcast until the entry is relearned ✅
B.Frames will be dropped immediately
C.Frames will be queued indefinitely
D.Frames will be sent with a zero‑TTL
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When the MAC table entry expires, the switch no longer knows the destination port. Consequently, it floods the frame to all ports (broadcast) until the destination replies, allowing the switch to relearn the correct forwarding entry.

Q6. Consider two data‑link protocols: one uses a sliding‑window mechanism with a window size of 4, and the other uses a stop‑and‑wait approach. Which analytical comparison best describes their relative efficiency on a high‑latency link?

A.Sliding‑window achieves higher utilization because it keeps multiple frames in flight ✅
B.Both achieve equal utilization because they use the same acknowledgment scheme
C.Stop‑and‑wait is more efficient due to lower overhead
D.Sliding‑window is less efficient because it requires larger buffers
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A sliding‑window protocol can transmit up to four frames before awaiting acknowledgment, keeping the link busy during the long latency period. Stop‑and‑wait sends only one frame per round‑trip, leaving the link idle for most of the latency, thus reducing utilization.

Q7. A network administrator observes that frames between Alice and R2 are consistently delayed by 5 ms beyond the expected propagation time. Which conceptual explanation most plausibly accounts for this delay?

A.Excessive collision back‑off in CSMA/CD ✅
B.Incorrect checksum calculation
C.Insufficient buffer space at R2’s data‑link layer
D.Physical layer attenuation requiring repeaters
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: CSMA/CD introduces random back‑off periods after collisions, adding extra delay. If collisions are frequent, the cumulative back‑off can cause a consistent 5 ms increase. Incorrect checksums, buffer shortages, or repeaters affect error handling or signal strength, not systematic timing delays.

Q10. During a network upgrade, the MTU of the link between R2 and R4 is increased from 1500 bytes to 9000 bytes. Which analytical impact does this change have on the data‑link layer’s frame processing?

📖 Explanation: A larger MTU allows bigger frames, decreasing the frequency of fragmentation and reassembly, which reduces processing overhead and improves throughput. Error detection complexity and collision probability are not directly affected by MTU size, nor does it require extra MAC entries.

Q11. Alice’s network uses a token‑ring protocol at the data‑link layer. If the token is lost, what is the most likely logical consequence for the network’s operation?

📖 Explanation: Token‑ring networks rely on a single token to control access. Loss of the token means no station can acquire permission to send, causing the entire network to become idle until a token recovery procedure regenerates the token.

Q15. When comparing Ethernet’s CSMA/CD with Wi‑Fi’s CSMA/CA, which analytical difference best explains their suitability for wired versus wireless media?

A.CSMA/CD detects collisions after they occur, which is feasible on wired media; CSMA/CA attempts to avoid collisions, essential for wireless ✅
B.Both use identical collision handling mechanisms
C.CSMA/CA is faster than CSMA/CD in all scenarios
D.CSMA/CD works only with half‑duplex links
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Wired Ethernet can detect collisions directly because the medium is shared and collisions are observable, while wireless signals cannot be reliably detected after they occur due to the hidden node problem. Hence CSMA/CA uses avoidance techniques, making it more appropriate for wireless environments.

Q16. If a frame arriving at router R4 fails its CRC check, what is the most probable logical action taken by the data‑link layer?

A.Discard the frame and request retransmission ✅
B.Forward the frame anyway
C.Correct the error using the CRC
D.Log the error and continue processing
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A failing CRC indicates that the frame is corrupted. The data‑link layer typically discards such frames and relies on higher‑layer protocols (e.g., TCP) to request retransmission, rather than attempting correction or forwarding erroneous data.

Q17. A network designer wants to ensure that frames traveling between Alice and Bob are encrypted at the data‑link layer. Which conceptual service should be enabled?

B.IPsec at the network layer
C.TLS at the transport layer
D.Application‑level encryption
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: MACsec provides confidentiality, integrity, and authentication at the data‑link layer, encrypting frames end‑to‑end across the link. IPsec, TLS, and application‑level encryption operate at higher layers and do not protect the data‑link layer directly.

Q25. If a data‑link protocol provides both error detection and flow control, which analytical statement best reflects the interplay between the two services?

C.Flow control increases the error rate due to added overhead

📖 Explanation: Flow control regulates the rate of transmission, ensuring that the receiver’s buffers do not overflow. By preventing congestion, it reduces the likelihood that frames are corrupted due to loss or queuing delays, thereby complementing error‑detection mechanisms.
