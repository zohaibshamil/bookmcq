📝 Two Sublayers in Data Link Layer

What is Two Sublayers in Data Link Layer?

The Data Link Layer is divided into the Logical Link Control (LLC) sublayer, which handles flow control, error checking, and interface with the network layer, and the Media Access Control (MAC) sublayer, which manages hardware addressing and controls how devices access the shared transmission medium.

Q1. What is the primary function of the data-link sublayer in a router?

A. To route packets between different autonomous systems
B. To encapsulate network-layer packets into frames for transmission on the local link ✅
C. To encrypt data for secure transport
D. To assign IP addresses to hosts

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The data‑link sublayer’s main job is to take a network‑layer packet, add MAC addresses, and create a frame that can be placed on the specific physical medium. It does not perform routing, encryption, or address allocation, which belong to higher‑layer protocols.

Q2. When a frame arrives at router R4’s data-link layer destined for network X, what must the router do before forwarding it to the next link?

A. Replace the destination MAC address with the MAC of the next‑hop interface and recalculate the frame checksum
B. Leave the MAC addresses unchanged and simply forward the frame
C. Strip the frame entirely and send only the payload
D. Insert a new destination MAC of the next hop while updating the source MAC to the router’s outbound interface ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The router must decapsulate the incoming frame, discard the original source MAC, and then encapsulate the packet into a new frame. This involves inserting the router’s own MAC as the source address and the next‑hop’s MAC as the destination, followed by recomputing the frame checksum to ensure integrity.

Q3. Given that each router uses two data-link layers, what can be inferred about the role of MAC addresses when a frame traverses router R5?

A. The source MAC becomes the destination MAC on the outbound interface
B. The original source MAC is retained throughout the entire path
C. A new source MAC is inserted for the outbound link, while the destination MAC is set to the next hop’s MAC ✅
D. MAC addresses are irrelevant at the router level

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When a frame enters R5, the inbound MAC addresses are discarded. For the outbound interface, R5 inserts its own MAC as the source and the MAC address of the next‑hop device as the destination. Thus the original source MAC never appears beyond the first link, and each hop rewrites both addresses.

Q4. If the link between R2 and R3 fails and frames are rerouted through R4, how does this affect the number of data-link layer processing steps for a packet from Alice to Bob?

A. The number of processing steps remains the same because each router still uses two data-link layers
B. The number increases by two because the packet now passes through an additional router ✅
C. The number decreases because the failed link is bypassed
D. Processing steps are unrelated to the path taken

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Each router contributes two data‑link processing stages: one for the inbound interface and one for the outbound interface. Adding R4 introduces an extra router, thereby adding two more data‑link operations (receive and transmit) to the end‑to‑end journey, increasing the total count.

Q5. If a router mistakenly copies the source MAC address from the incoming frame into the destination MAC field of the outgoing frame, which network‑level consequence is most likely?

A. The frame will be delivered to the original sender, causing a loop
B. The frame will be discarded by the next‑hop device due to MAC mismatch ✅
C. The frame will be broadcast to all hosts on the segment
D. The frame will reach the correct destination but with corrupted payload

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A next‑hop device expects the destination MAC to match one of its own interfaces. Using the source MAC as the destination creates a mismatch, causing the frame to fail the address check and be dropped. This prevents delivery and may generate an error log, but it does not cause looping or broadcasting.

Q6. Which statement correctly distinguishes the responsibilities of the data-link layer at Alice’s computer from those at router R6?

A. Alice’s data-link layer adds MAC addresses for a single link; R6 adds MAC addresses for both inbound and outbound links
B. Both Alice and R6 perform routing decisions based on IP addresses
C. Alice’s data-link layer encrypts frames, while R6 only forwards them
D. Alice’s data-link layer handles framing for one network segment, whereas R6 must handle framing for two distinct network segments, inserting a new source MAC and destination MAC for each hop ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

Alice’s host is attached to only one physical network, so its data‑link layer creates a frame with a single source and destination MAC. Router R6 sits between two networks; it must receive a frame on one interface, strip its MACs, then generate a new frame with its own source MAC for the outbound interface and the next‑hop’s destination MAC, effectively performing two separate data‑link operations.

Q7. How does using a point‑to‑point WAN link instead of a LAN switch between R3 and R4 affect the data‑link sublayer’s framing overhead?

A. WAN links always use the same Ethernet framing as LAN switches, so overhead is identical
B. WAN links require no framing at all, eliminating overhead
C. WAN links often add additional encapsulation (e.g., PPP or HDLC), increasing overhead relative to Ethernet switching ✅
D. Switches add more headers than WAN links, so using a WAN reduces overhead

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Point‑to‑point WAN technologies such as PPP, HDLC, or MPLS require their own header fields in addition to the standard Ethernet header. This extra encapsulation adds bytes to each frame, raising the per‑packet overhead compared with a simple Ethernet switch that forwards frames using only the native Ethernet header.

Q8. In what way does error detection at the data‑link layer differ when a frame passes through multiple routers versus when it remains within a single LAN?

A. Each router recalculates the CRC for its outbound frame, providing fresh error detection per hop
B. Error detection is performed only once at the source and never again
C. Routers ignore error detection, relying on end‑to‑end checks
D. When a frame traverses multiple routers, each router replaces the CRC, ensuring detection of errors introduced on each segment, whereas within a single LAN the original CRC is sufficient unless the frame is altered ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Every time a router creates a new frame for the next link, it must compute a new cyclic redundancy check (CRC) over the new header and payload. This means errors that occur on any individual hop can be detected locally. In a single LAN, the original CRC remains unchanged, and only one detection point exists unless the frame is modified.
