What is Address Resolution Protocol(ARP) in Link Layer Addressing?

Definition:
Address Resolution Protocol (ARP) is a protocol that maps IP addresses to MAC addresses within a local network. When a device knows the destination IP address but not the corresponding MAC address, it uses ARP to discover the hardware address. ARP maintains a cache table storing recent IP-to-MAC mappings to reduce the need for repeated broadcast queries and improve network efficiency.

Working:
When Host A wants to send data to Host B's IP address but doesn't know Host B's MAC address, Host A broadcasts an ARP request asking \Who has IP address X?\" All devices receive this but only Host B responds with an ARP reply containing its MAC address. Host A stores this mapping in its ARP cache for future use typically for 2-20 minutes depending on the system.

Example:
Your computer (IP: 192.168.1.10192.168.1.10192.168.1.10) wants to ping another computer (IP: 192.168.1.20192.168.1.20192.168.1.20). It checks its ARP cache—if no entry exists it broadcasts: \"ARP Request: Who has 192.168.1.20192.168.1.20192.168.1.20? Tell 192.168.1.10192.168.1.10192.168.1.10.\" The target computer replies: \"ARP Reply: 192.168.1.20192.168.1.20192.168.1.20 is at MAC 00:1B:44:11:3A:B700:1B:44:11:3A:B700:1B:44:11:3A:B7.\" Your computer caches this and sends the ping frame directly to that MAC address.

Reason:
ARP bridges the gap between Network Layer (IP addresses) and Data Link Layer (MAC addresses). Since IP addresses are logical and can change while MAC addresses are physical and fixed ARP provides dynamic mapping. Without ARP devices would need manual MAC address configuration making networks impractical to manage and scale.

Common MisConceptions:
Students think ARP works across routers—it doesn't as ARP is limited to local networks. Another misconception is that ARP is secure; it's vulnerable to ARP spoofing/poisoning attacks where attackers send fake ARP replies. Also ARP cache entries aren't permanent and expire requiring periodic renewal.

Exam Preparation Tips: How to prepare this topic
Understand the ARP request/reply message format. Practice tracing ARP operations in network scenarios. Know ARP cache timeout values and how to view/clear ARP tables (using commands like `arp -a`). Study ARP security issues and mitigation techniques. Differentiate ARP from RARP (Reverse ARP) and Inverse ARP.

Key Terms:

  • ARP Request - Broadcast query asking for MAC address corresponding to an IP.
  • ARP Reply - Unicast response providing the requested MAC address.
  • ARP Cache - Local table storing recent IP-to-MAC address mappings.
  • ARP Spoofing - Attack sending fake ARP messages to redirect traffic.

📝 All Address Resolution Protocol(ARP) in Link Layer Addressing MCQs

Q1. What is the primary purpose of ARP in an IPv4 network?

A.To map an IP address to its corresponding MAC address ✅
B.To assign IP addresses to hosts
C.To encrypt data at the data‑link layer
D.To route packets between subnets
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: ARP’s core function is to resolve a known IPv4 address into the hardware address used on the local Ethernet segment. When a host knows the destination IP but not the MAC, it broadcasts an ARP request; the reply provides the needed MAC, enabling frame delivery on the LAN.

Q2. At which OSI layer does ARP operate?

A.Physical
B.Data Link ✅
C.Network
D.Transport
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: ARP works between the Network layer (where IP addresses reside) and the Data Link layer (where MAC addresses are used). It translates layer‑3 addresses to layer‑2 addresses, so it is considered a protocol of the Data Link layer, even though it interacts closely with the Network layer.

Q3. In IPv4, ARP resolves IP addresses to what type of address?

A.IPv6 address
B.Subnet mask
C.MAC address ✅
D.Port number
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The ARP protocol is designed specifically for IPv4 networks to map a 32‑bit IP address to a 48‑bit Ethernet MAC address. This mapping allows the host to encapsulate IP packets inside Ethernet frames for delivery on the local LAN.

Q4. If host A sends an ARP request for IP X and receives no reply, what can be inferred about host X?

A.Host X is offline or does not exist
B.Host X is using IPv6 only
C.Host X has a static ARP entry
D.Host X is on a different subnet ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: An ARP request is a broadcast limited to the local broadcast domain. If no reply arrives, it usually means the target IP is not present on the same LAN segment; hosts on a different subnet would not receive the broadcast, so the request times out without a reply.

Q5. A network uses an ARP cache timeout of 20 minutes. If a host changes its MAC address, after how many minutes will other hosts likely have an outdated mapping?

A.20 minutes ✅
B.10 minutes
C.5 minutes
D.0 minutes
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: ARP caches retain entries until the timeout expires. When a host changes its MAC address, other hosts will continue using the old mapping until the cached entry ages out. With a 20‑minute timeout, the stale entry persists for up to 20 minutes, after which a new ARP request refreshes the mapping.

Q6. When a router receives an ARP request destined for its own IP address, what is the cause‑effect of its reply?

A.It updates its routing table
B.It provides its MAC address to the requester ✅
C.It forwards the request to the next hop
D.It discards the request
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The router recognizes that the target IP matches one of its own interfaces. In response, it sends an ARP reply containing its MAC address, enabling the requesting host to direct frames to the router for subsequent IP communication. This reply does not alter routing tables or forward the request further.

Q7. Suppose two hosts A and B have the same IP address due to misconfiguration. What will ARP behavior indicate?

A.Both hosts will ignore ARP
B.ARP will resolve to the MAC of the first responder
C.ARP will broadcast an error message ✅
D.ARP will fail entirely
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: When duplicate IP addresses exist, ARP requests may elicit responses from both hosts, causing address‑conflict detection mechanisms (such as Gratuitous ARP) to generate error notifications. The resulting confusion often leads to network instability, and hosts may log duplicate‑address warnings.

Q8. If ARP spoofing is performed to redirect traffic, what is the logical consequence for the victim's network traffic?

A.Traffic is encrypted
B.Traffic is dropped
C.Traffic is forwarded to the correct gateway
D.Traffic is sent to the attacker’s MAC address ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: In an ARP spoofing attack, the attacker sends forged ARP replies that associate the victim’s IP (often the default gateway) with the attacker’s MAC address. Consequently, the victim’s frames are mistakenly delivered to the attacker, allowing interception, modification, or redirection before possibly being forwarded onward.

Q9. In a switched network, ARP broadcasts are limited to which segment?

A.The local broadcast domain ✅
B.All VLANs
C.The entire campus
D.The router’s routing table
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Switches forward broadcast frames, such as ARP requests, only within the VLAN to which the originating port belongs. This containment defines the broadcast domain, ensuring that ARP traffic does not traverse unrelated VLANs or network segments unless a router or bridge explicitly forwards it.

Q10. When a host’s ARP cache is full, what happens to the oldest entry?

A.It is retained indefinitely
B.It is removed to make space ✅
C.It is marked as permanent
D.It triggers a network reboot
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: ARP caches have limited storage; when the cache reaches capacity, the host typically employs a least‑recently‑used (LRU) eviction policy. The oldest or least‑used entry is discarded, freeing space for a new mapping obtained via a fresh ARP request, maintaining cache freshness.

Q11. If a host receives an ARP reply that does not match any pending request, what can be deduced?

A.The reply is a gratuitous ARP ✅
B.The network is down
C.The host is misconfigured
D.The reply is malformed
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: An unsolicited ARP reply, when no corresponding request was sent, often indicates a gratuitous ARP used for address conflict detection or a malicious attempt such as ARP spoofing. The host may treat it as suspicious, potentially logging a warning, because legitimate ARP replies are expected only after a request.

Q12. Compare the behavior of ARP in IPv4 with Neighbor Discovery in IPv6.

A.Both use broadcast frames
B.IPv6 uses multicast instead of broadcast
C.ARP is faster than ND
D.ND does not resolve MAC addresses ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: ARP in IPv4 relies on Ethernet broadcast frames, while IPv6’s Neighbor Discovery replaces broadcast with link‑local multicast, reducing unnecessary traffic. Both protocols map network‑layer addresses to link‑layer addresses, but ND also incorporates router discovery and address autoconfiguration, offering richer functionality than ARP.

Q13. Evaluate the security implications of static ARP entries versus dynamic entries.

A.Static entries prevent spoofing but are inflexible ✅
B.Dynamic entries are more secure
C.Both are equally vulnerable
D.Static entries increase network latency
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Static ARP entries lock an IP‑MAC binding, eliminating the chance for forged ARP replies, but they require manual updates whenever a device changes its MAC, making network management cumbersome. Dynamic entries adapt automatically but can be targeted by spoofing attacks, so administrators must balance security with operational flexibility.

Q14. Differentiate between gratuitous ARP and a regular ARP request.

A.Gratuitous ARP is sent after a reboot
B.Gratuitous ARP announces an IP‑MAC binding without being asked ✅
C.Regular ARP uses unicast
D.Both are identical
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A gratuitous ARP is broadcast without a preceding request, typically to announce a new IP‑MAC association or to detect address conflicts. In contrast, a regular ARP request is sent when a host needs to discover the MAC address for a known IP, awaiting a specific reply from the owner of that IP.

Q15. Analyze the impact on network performance of ARP cache timeout values being too short.

A.Increases bandwidth usage due to frequent broadcasts ✅
B.Reduces latency
C.Eliminates ARP spoofing
D.Has no effect
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When timeout values are excessively short, hosts discard valid entries quickly, forcing repeated ARP requests for the same destinations. This generates additional broadcast traffic, consumes bandwidth, and can degrade overall network performance, especially on congested LANs, while offering little benefit in terms of freshness.

Q16. Contrast the use of ARP proxy in routers versus ARP proxy in bridges.

A.Routers never use ARP proxy ✅
B.Bridges use proxy ARP to hide networks
C.Routers use proxy ARP to forward traffic across subnets
D.Both perform the same function
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Routers can employ proxy ARP to answer ARP requests on behalf of hosts in another subnet, effectively making the remote network appear local. Bridges may also use proxy ARP to conceal entire segments, but the primary distinction lies in the router’s ability to route packets after responding, whereas a bridge simply forwards frames.

Q17. Assess how ARP cache poisoning differs from DHCP rogue server attacks.

A.Both target IP‑MAC mapping
B.ARP poisoning manipulates MAC addresses while DHCP rogue assigns false IP configurations ✅
C.DHCP attacks use ARP
D.They are identical
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: ARP cache poisoning directly corrupts the IP‑to‑MAC table, causing traffic to be misdirected to an attacker’s MAC. A DHCP rogue server, however, supplies incorrect IP configuration parameters (such as DNS or default gateway), influencing traffic at a higher layer. Both undermine network integrity but operate at different protocol layers.

Q18. Compare the overhead introduced by ARP in a LAN with 100 hosts versus 1000 hosts.

A.Overhead grows linearly with host count
B.Overhead grows quadratically ✅
C.Overhead is negligible in both cases
D.Overhead decreases with more hosts
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: ARP traffic scales with the square of the number of hosts because each host may broadcast an ARP request that all others receive. Consequently, a LAN with 1000 hosts generates roughly ten times more ARP broadcast frames than one with 100 hosts, leading to significantly higher processing and bandwidth consumption.

Q19. Evaluate the effectiveness of port security features that limit ARP entries.

A.They completely prevent ARP attacks
B.They reduce risk but can cause legitimate traffic loss ✅
C.They have no impact
D.They increase latency
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Port security can restrict the number of MAC addresses learned on a switch port, limiting the impact of ARP spoofing by preventing unknown MACs from being accepted. However, overly strict limits may block legitimate devices, resulting in connectivity issues, so administrators must balance security with operational requirements.

Q20. Apply the ARP process to explain how a host discovers the MAC address of the default gateway.

A.Sends a DHCP request
B.Uses static routing table
C.Sends an ICMP echo
D.Broadcasts an ARP request for the gateway’s IP ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: When a host needs to send traffic to an external network, it first determines the MAC address of its configured default gateway. It does this by broadcasting an ARP request that contains the gateway’s IP address; the gateway replies with its MAC, allowing the host to encapsulate subsequent frames for outbound delivery.

Q21. Synthesize a scenario where ARP and VLAN tagging interact, describing the sequence of frames.

A.ARP request is sent untagged, then switch adds VLAN tag ✅
B.VLAN tag is stripped before ARP
C.ARP bypasses VLAN
D.VLAN tag is irrelevant to ARP
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A host in VLAN 10 sends an ARP request without a tag; the switch receives the frame on the access port, inserts the VLAN 10 tag, and forwards it to other ports in the same VLAN. The ARP reply follows the reverse path, with the switch removing the tag before delivering it to the originating host.

Q22. Explain how ARP can be used to implement load balancing across multiple servers sharing a virtual IP.

A.By assigning the same MAC to all servers
B.By rotating the MAC address in ARP replies ✅
C.By disabling ARP
D.By using static routes
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When several servers share a virtual IP, each can respond to ARP requests with its own MAC address in a round‑robin fashion. Clients cache the returned MAC for a short period, causing traffic to be distributed among the servers as the ARP cache expires and new replies are received, achieving simple load balancing.

Q23. Apply the principle of ARP cache expiration to design a timer algorithm that balances freshness and overhead.

A.Fixed 5‑second timer
B.Exponential back‑off
C.Adaptive timer based on traffic volume ✅
D.No timer needed
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: An adaptive algorithm monitors the rate of ARP traffic and adjusts the timeout dynamically: high traffic shortens the timer to keep entries fresh, while low traffic extends it to reduce broadcast frequency. This approach maintains up‑to‑date mappings without overwhelming the network with unnecessary ARP requests.

Q24. Explain why ARP operates on a broadcast medium and discuss implications for network segmentation.

A.Because MAC addresses are unique
B.Because IPv4 addresses are hierarchical
C.Because broadcast ensures all hosts receive the request ✅
D.Because switches block ARP
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: ARP uses Ethernet broadcast because the requesting host does not know which device holds the target IP, so it must reach every node in the local segment. This reliance on broadcast underscores the importance of segmentation (e.g., VLANs) to confine ARP storms and limit unnecessary traffic across the broader network.

Q25. Synthesize the steps a switch takes when it learns MAC addresses via ARP traffic, and how this influences forwarding tables.

A.Switch updates its CAM table with source MAC from ARP request ✅
B.Switch ignores ARP
C.Switch forwards ARP only to unknown ports
D.Switch deletes entries on ARP
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: When an ARP request arrives, the switch records the source MAC and incoming port in its Content‑Addressable Memory (CAM) table. This learning enables the switch to forward subsequent frames directly to the correct port, reducing flooding. ARP thus indirectly populates the forwarding database, improving overall efficiency.

Q26. Apply the concept of ARP spoofing to outline a mitigation strategy using Dynamic ARP Inspection.

A.Enable DHCP snooping and bind IP‑MAC pairs ✅
B.Disable all ARP traffic
C.Use static ARP entries only
D.Increase ARP timeout
💡 Difficulty: hard | ✅ Correct: A
