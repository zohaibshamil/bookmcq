What is Internet structure AS and ISP hierarchy?

The Internet structure organized by Autonomous Systems and ISP hierarchy consists of tiered networks where Tier-1 ISPs form the global backbone, Tier-2 ISPs connect regionally and purchase transit, and Tier-3 ISPs provide local access, with each AS operating under a single administrative domain and unique identifier for scalable inter-domain routing.

Q1. If a router in an autonomous system uses OSPF to compute shortest paths, what is the most direct effect on the forwarding tables of that router?

A.They are updated based on link‑state advertisements ✅
B.They are updated using distance‑vector updates
C.They remain unchanged when topology changes
D.They are flooded only to directly connected routers
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: OSPF disseminates link‑state advertisements (LSAs) throughout its area. Each router processes the LSAs, runs Dijkstra’s algorithm, and rebuilds its shortest‑path tree. The resulting tree directly populates the forwarding table, so the entries reflect the current network topology.

Q2. Which of the following best defines a path‑vector routing protocol?

A.It exchanges complete network maps
B.It advertises the entire path as a sequence of AS numbers ✅
C.It uses hop count only
D.It relies on link‑state packets
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A path‑vector protocol, such as BGP, propagates routes by attaching the list of autonomous systems (ASes) traversed. This vector of AS identifiers enables routers to make policy decisions and avoid loops, distinguishing it from pure distance‑vector or link‑state approaches.

Q3. Compared to OSPF, BGP differs in which of the following aspects?

A.OSPF uses AS‑wide advertisements while BGP uses area‑wide
B.OSPF is a distance‑vector protocol
C.BGP does not support route aggregation
D.BGP selects routes based on policy attributes ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: BGP is designed for inter‑domain routing and makes routing decisions using a rich set of policy attributes (local preference, MED, communities, etc.). OSPF, in contrast, focuses on intra‑domain shortest‑path computation and does not incorporate policy‑driven selection, making BGP’s attribute‑based decision process the key difference.

Q4. In hierarchical routing, the default router in a local network forwards a packet to a backbone router. What inference can be made about the scalability of this approach?

A.It reduces routing table size in edge routers ✅
B.It increases latency proportionally to number of hops
C.It eliminates the need for any routing protocol
D.It requires each router to store the complete Internet topology
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Hierarchical routing partitions the network into regions, allowing edge routers to maintain only a summary (default route) toward the backbone. This dramatically shrinks their routing tables, because they do not need entries for every remote network, thereby enhancing scalability while keeping forwarding decisions efficient.

Q5. If an OSPF link has a bandwidth of 100 Mbps, what is the default OSPF cost for that link?

A.10
B.1 ✅
C.100
D.1000
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: OSPF calculates link cost as the reference bandwidth (default 100 Mbps) divided by the link’s bandwidth. With a 100 Mbps link, the cost = 100 Mbps / 100 Mbps = 1. Therefore the default OSPF cost assigned to that link is 1, reflecting its high capacity relative to the reference.

Q6. When two BGP routes to the same prefix have identical local preference and AS‑PATH length, which attribute is examined next to break the tie?

A.MED
B.Origin type
C.IGP metric to next hop ✅
D.Router ID
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: After local preference and AS‑PATH length, BGP evaluates the IGP metric to the next hop (the lowest metric wins). This metric reflects the internal cost to reach the BGP next‑hop router, ensuring that the path with the most efficient intra‑domain reachability is preferred when other attributes are equal.

Q7. Suppose a backbone router running OSPF fails, causing its area‑0 LSDB to be lost. Which of the following statements best describes the impact on intra‑area routing for routers in that area?

A.All routers recompute shortest‑path trees using remaining LSAs ✅
B.Routing stops until LSDB is rebuilt from scratch
C.Routers switch to distance‑vector fallback
D.Packets are dropped until manual reconfiguration
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: When a backbone router crashes, its LSAs disappear, but the remaining routers still possess LSAs from other routers. They run Dijkstra again with the updated LSDB, quickly converging to new shortest‑path trees. Thus, intra‑area routing continues without a total outage.

Q8. Design a routing policy where edge routers prefer OSPF routes for internal traffic but fall back to BGP for external destinations. Which combination of mechanisms correctly implements this policy?

A.Use route‑maps that set higher administrative distance for OSPF
B.Set OSPF as default route and filter BGP
C.Apply route‑redistribution from OSPF into BGP with lower metric
D.Use prefix‑lists to prefer OSPF and a higher metric for BGP ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: By applying prefix‑lists that match internal networks and assigning a lower metric (or higher preference) to OSPF routes, while giving BGP routes a higher metric, the router will select OSPF for internal destinations. When no OSPF match exists, the higher‑metric BGP routes become the chosen path for external traffic.

Q9. Assume an Internet with 10 000 autonomous systems, each containing on average 200 routers. If hierarchical routing reduces the average routing table entries per router by a factor of 50, approximately how many entries does a typical edge router store?

A.200 ✅
B.40
C.4000
D.8000
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Each AS can be represented by a single summary entry in a hierarchical scheme. With 10 000 ASes, an edge router would need roughly 10 000 entries. Dividing the original full‑mesh count (≈2 000 000 entries) by 50 yields about 40 000 entries, but using AS‑level summarization the realistic figure is close to 200 entries, matching the factor‑50 reduction.

Q10. Why does a host not need a forwarding table to send a packet to a remote host?

A.Because the host uses ARP to discover the next hop MAC address
B.Because the host relies on the default router to perform next‑hop resolution ✅
C.Because IPv6 eliminates the need for forwarding tables
D.Because hosts store the entire Internet topology
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A host forwards its packet to the default gateway on its local network. The gateway, which possesses a full routing table, determines the next hop. The host therefore only needs to know the MAC address of its default router (via ARP), not the entire forwarding information for remote destinations.

Q11. What is the primary purpose of OSPF area 0 (the backbone area) in a multi‑area OSPF deployment?

A.To aggregate all external routes
B.To provide a common routing domain for inter‑area communication ✅
C.To run a different routing algorithm
D.To store only host routes
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Area 0 serves as the central hub that interconnects all other OSPF areas. It ensures that LSAs from one area can be exchanged with another, enabling consistent and loop‑free routing across the entire OSPF domain. Without a backbone, inter‑area routing would be impossible.

Q12. Which BGP attribute is most commonly used by ISPs to influence inbound traffic engineering?

A.Local Preference
B.MED
C.Community ✅
D.Atomic Aggregate
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: ISPs frequently employ BGP community attributes (standard or extended) to tag routes with policy information that downstream networks can interpret. By assigning specific communities, an ISP can request peers to prepend AS numbers, set local preference, or apply other actions that shape inbound traffic, making communities the primary tool for inbound engineering.

Q13. In a three‑level hierarchical routing scheme (local, area, backbone), a packet destined for a remote AS traverses which sequence of routing domains?

A.Local → Backbone → Area → Destination AS
B.Area → Local → Backbone → Destination AS
C.Local → Area → Backbone → Destination AS ✅
D.Backbone → Area → Local → Destination AS
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The packet first leaves the source host via its local router, then moves into the area router that aggregates local routes, proceeds to the backbone router for inter‑area communication, and finally reaches the destination AS. This sequence reflects the Hard progression from the most specific to the most general routing domain.
