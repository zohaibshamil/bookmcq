What is Least cost routing metrics?

Least cost routing metrics are quantitative values such as hop count, bandwidth, delay, or monetary cost assigned to network links that algorithms use to calculate and select the optimal path with the minimum total expense between two nodes.

Q1. What is the main goal of least-cost routing in unicast networks?

A.To minimize the number of hops regardless of link costs
B.To maximize bandwidth usage
C.To select a path whose total link cost is minimal ✅
D.To ensure equal load distribution across all paths
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The objective of least‑cost routing is to choose the route whose sum of individual link costs is the smallest, ensuring efficient use of network resources while delivering the packet to its destination.

Q2. Given a network where the cost of link A‑B is 2, B‑C is 3, and A‑C is 7, which path will a least‑cost routing algorithm select to forward a packet from A to C?

A.A → B → C ✅
B.A → C directly
C.Both paths have equal cost
D.The algorithm will split traffic between both paths
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Adding the costs of the two‑hop path yields \(2+3=5\), which is lower than the direct link cost of 7. Therefore the algorithm selects the path A‑B‑C because it provides the minimum total cost.

Q3. In a network, the current least‑cost path from X to Z is X‑Y‑Z with total cost \(4+5=9\). If the cost of link Y‑Z increases to 10, which of the following becomes the new least‑cost path?

A.X → Y → Z (cost 9)
B.X → W → Z (cost 8) ✅
C.X → V → Z (cost 10)
D.X → Y → W → Z (cost 12)
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When Y‑Z becomes 10, the original path costs \(4+10=14\). The alternative X‑W‑Z has a total cost of \(6+2=8\), which is now the smallest among the listed options, making it the new least‑cost path.

Q4. Which set of links forms the least‑cost spanning tree rooted at A for the graph with links A‑B (1), A‑C (4), B‑C (2), B‑D (5), and C‑D (1)?

A.{A‑B, A‑C, B‑D}
B.{A‑C, B‑C, C‑D}
C.{A‑B, B‑C, B‑D}
D.{A‑B, B‑C, C‑D} ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: The tree must connect all nodes with minimal total cost. Selecting A‑B (1), B‑C (2), and C‑D (1) yields a total cost of 4, which is lower than any other combination that still connects every node, thus it is the least‑cost spanning tree.

Q5. When evaluating convergence speed after a link failure, which statement best distinguishes distance‑vector routing from link‑state routing in the context of least‑cost routing?

A.Distance‑vector updates only the affected routers, so convergence is instantaneous
B.Link‑state floods the entire network with updated topology, leading to faster convergence than distance‑vector ✅
C.Distance‑vector may suffer from count‑to‑infinity, causing slower convergence
D.Link‑state requires each router to recompute routes independently, which always takes longer than distance‑vector
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Link‑state protocols propagate the new topology to all routers via flooding, allowing each router to recompute shortest paths immediately. Distance‑vector protocols rely on incremental updates and can experience delayed convergence, especially with count‑to‑infinity problems.

Q6. Considering scalability and cost granularity, which of the following accurately reflects a trade‑off between OSPF (link‑state) and RIP (distance‑vector)?

A.RIP supports finer‑grained cost metrics than OSPF, improving path selection
B.OSPF limits the number of hops, making it less scalable than RIP
C.RIP’s simple hop‑count metric reduces computational overhead but cannot differentiate link quality, whereas OSPF’s configurable cost allows more precise least‑cost decisions at the expense of larger routing tables
D.OSPF updates are less frequent than RIP, causing slower adaptation to network changes ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: OSPF’s link‑state approach generates larger LSDBs and more frequent updates, which consume more memory and CPU, especially in large networks. RIP’s hop‑count metric is coarse but keeps routing information minimal, illustrating the classic scalability versus precision trade‑off.

Q7. Which characteristic uniquely identifies path‑vector routing compared to distance‑vector routing?

A.It carries the entire path (sequence of ASes) in each update ✅
B.It uses only hop count as its metric
C.It updates routing tables only when a link fails
D.It does not prevent routing loops
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Path‑vector protocols attach the full autonomous‑system path to each route advertisement, enabling detection of loops and policy enforcement, which is a distinctive feature not present in traditional distance‑vector protocols that only convey destination and metric.

Q8. If a network administrator wants to discourage use of a heavily congested link currently assigned a cost of 1, which adjustment to the cost metric is most appropriate to achieve least‑cost routing that prefers alternative paths?

A.Decrease the cost to 0 to attract more traffic
B.Leave the cost unchanged; congestion will self‑resolve
C.Increase the cost to a higher value, e.g., 10, making alternative routes cheaper overall ✅
D.Set the cost to a negative value to force avoidance
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Raising the link’s cost raises its contribution to the total path cost, causing the least‑cost algorithm to favor other routes with lower aggregate costs, thereby reducing traffic on the congested link.

Q9. Which sequence correctly describes the steps of Dijkstra’s algorithm when computing the least‑cost path from node S to all other nodes?

A.Initialize distances, repeatedly select the unvisited node with smallest tentative distance, update neighbors, mark node visited ✅
B.Broadcast the current distance vector to all neighbors, then update tables based on received vectors
C.Perform a depth‑first search, recording cumulative costs, then choose the minimum
D.Flood the entire network with link‑state packets, then each router runs Bellman‑Ford
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Dijkstra’s algorithm starts by setting the source distance to zero and all others to infinity, then repeatedly picks the closest unvisited node, relaxes its outgoing edges, and marks it visited until all nodes have their final shortest‑path costs.

Q10. How do changes in link cost values directly affect the entries in a router’s forwarding table in a least‑cost routing protocol?

A.The forwarding table remains static; only the metric values change
B.Only routes that use the changed link are removed, others stay unchanged
C.The router recomputes shortest‑path trees, updating next‑hop entries for any destination whose optimal path includes the altered link
D.Cost changes are ignored until a manual configuration update ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: When a link cost changes, the routing algorithm recalculates the least‑cost paths. Any destination whose optimal route traverses the modified link will have its next‑hop entry updated, while unaffected destinations retain their existing entries.

Q11. If a distance‑vector protocol mistakenly allows a link cost of –2, what is the most likely impact on the routing tables?

A.Routes will become more stable because negative costs reduce overall path length
B.The protocol will ignore the negative cost and treat it as zero
C.Routing loops may appear, and the protocol could repeatedly advertise decreasing path costs, leading to instability ✅
D.The network will automatically correct the negative cost to a positive value
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Distance‑vector protocols assume non‑negative metrics; a negative cost can cause the algorithm to continually lower advertised distances, producing routing loops and persistent instability, which is why protocols enforce non‑negative cost constraints.

Q12. Using the Bellman‑Ford algorithm, which path will be identified as the least‑cost route from node P to node T in the following directed graph: P‑Q (cost 3), P‑R (cost 2), Q‑S (cost 4), R‑S (cost 1), S‑T (cost 2), Q‑T (cost 10)?

A.P → Q → T (cost 13)
B.P → Q → S → T (cost 9)
C.P → R → S → T (cost 5) ✅
D.P → R → T (no direct link, considered infinite)
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Bellman‑Ford relaxes edges iteratively. The cheapest accumulated cost to T is via P‑R (2), R‑S (1), and S‑T (2), giving a total of \(2+1+2=5\), which is lower than any alternative route, so the algorithm selects the path P‑R‑S‑T.
