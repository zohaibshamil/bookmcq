What is Routing Information Protocol (RIP) version 1 and 2?

Routing Information Protocol versions 1 and 2 are distance-vector protocols where RIPv1 uses classful addressing and broadcast updates without authentication, while RIPv2 adds support for classless CIDR notation, multicast updates, and simple password authentication to improve efficiency and security in small to medium networks.

Q1. What is the maximum hop count allowed by RIP?

A.15
B.16 ✅
C.30
D.255
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: RIP limits its metric to a maximum value of 16 hops; a metric of 16 is interpreted as unreachable. Consequently, the highest permissible hop count before a route is considered invalid is 16, so option B correctly reflects the protocol's limit.

Q2. If a router receives a RIP update indicating a path cost of 4 to network X and the cost to the neighbor that sent the update is 1, what total metric will the router record?

A.4
B.5 ✅
C.6
D.7
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: RIP adds the received metric to the cost of reaching the neighbor. Here the neighbor’s cost is 1 and the advertised cost is 4, giving a total of 1 + 4 = 5 hops. Therefore the router records a metric of 5, which corresponds to option B.

Q3. Given N = 5 routers, how many ordered least‑cost paths are required for the whole internet?

A.20 ✅
B.25
C.30
D.40
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The formula for ordered least‑cost paths is N × (N − 1). Substituting N = 5 yields 5 × 4 = 20. Hence the network needs 20 distinct source‑destination paths, making option A the correct answer.

Q4. Which technique reduces routing loops by preventing a router from advertising a route back onto the interface from which it was learned?

A.Split horizon ✅
B.No split horizon
C.Both equally
D.Neither
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Split horizon forbids a router from sending information about a route back out through the same interface it received it, thereby breaking the feedback loop that can cause routing loops. This behavior directly addresses loop formation, so option A is correct.

Q5. When a link fails, which RIP mechanism delays the re‑advertisement of the failed route to avoid flapping?

A.Poison reverse
B.Split horizon
C.Triggered updates
D.Hold‑down timers ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Hold‑down timers keep a route in a suppressed state for a configurable period after it becomes unreachable, preventing immediate reinstatement and reducing instability. The other mechanisms either mark the route as unreachable or expedite updates, but only hold‑down timers provide the described delay, making D correct.

Q6. For N routers, the number of distinct least‑cost trees that can be formed equals which mathematical expression?

A.\(N^{\,N-2}\) ✅
B.\((N-1)!\)
C.\(N!\)
D.\(2^{\,N-1}\)
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Cayley’s formula states that the number of labeled trees on N vertices is \(N^{N-2}\). In the context of least‑cost trees, each tree corresponds to a distinct spanning tree, so the correct expression is \(N^{N-2}\), matching option A.

📖 Explanation: The hop‑count limit only caps the maximum metric a route can have; it does not alter the topology or the count of distinct least‑cost paths, which is determined solely by the number of routers. Hence the number of paths remains unchanged, making option C correct.

Q12. How do hold‑down timers and split horizon together improve network stability?

C.Split horizon prevents loops while hold‑down delays reinstatement ✅

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Split horizon stops a router from advertising a route back onto the interface it learned it from, breaking potential loops. Hold‑down timers then keep the route suppressed for a period after a failure, preventing premature reinstatement. Their combined effect is described in option C.
