📝 All Link State Routing algorithm Dijkstra MCQs

Q1. What is the primary purpose of a link‑state advertisement (LSA) in link‑state routing?

🔹 A. To broadcast distance vectors
🔹 B. To describe the state of directly attached links
🔹 C. To elect a router as a backup
🔹 D. To synchronize clocks

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

An LSA carries information about each link that a router directly knows, including the cost and status of those links. This data enables every router to build a consistent view of the network topology, which is essential for computing shortest‑path trees. Therefore, the LSA’s main role is to describe the state of directly attached links.

Q2. Which algorithm is most commonly used by link-state routers to compute shortest‑path trees?

🔹 A. Bellman‑Ford
🔹 B. Dijkstra
🔹 C. Floyd‑Warshall
🔹 D. RIP

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Link‑state routers use Dijkstra’s algorithm to compute the shortest‑path tree from the perspective of each router. The algorithm systematically selects the minimum‑cost node not yet processed and updates neighboring costs, guaranteeing the least‑cost paths. Consequently, Dijkstra’s algorithm is the standard method for constructing link‑state routing tables.

Q3. If router A’s least‑cost tree shows a path A→B→E→F with total cost 7, and router B’s tree shows a path B→E→F with total cost 5, what can be inferred about the cost of link (A,B)?

🔹 A. 2
🔹 B. 0
🔹 C. 1
🔹 D. 3

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The total cost from A to F is 7, while from B to F it is 5. Since the path from B to F is a sub‑path of the A‑to‑F route, the extra cost incurred when starting at A is the cost of the link (A,B). Subtracting the two totals gives 7 − 5 = 2, so the link cost is 2.

Q4. Given that all routers compute identical shortest‑path trees, which of the following statements must be true?

🔹 A. All routers will select the same next hop for any destination
🔹 B. Some routers may select different next hops
🔹 C. Paths may differ in cost
🔹 D. Trees may have cycles

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

When every router runs the same shortest‑path algorithm with identical link costs, the resulting trees are consistent. For any destination, the algorithm selects the unique minimum‑cost neighbor, guaranteeing that all routers agree on the next hop for that destination. Hence, identical next‑hop selections across routers must hold.

Q5. Suppose the cost of link (C,D) increases from 3 to 6. How does this affect the total cost of the least‑cost path from A to D?

🔹 A. Increases by 3
🔹 B. Decreases by 1
🔹 C. Remains unchanged
🔹 D. Increases by 6

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Increasing the cost of a single link on the current shortest‑path adds exactly that increase to the overall path cost, provided no alternative route becomes cheaper. The original path A→…→D included the (C,D) link with cost 3; raising it to 6 adds 3 to the total, so the least‑cost path cost rises by 3.

Q6. The total cost of the path G→A→B→F is 9 and cost(A,B)=2. What is the minimum possible value of the sum of the costs of links (G,A) and (F,B)?

🔹 A. 5
🔹 B. 6
🔹 C. 7
🔹 D. 8

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The total cost of the path G→A→B→F is 9, which can be expressed as cost(G,A)+2+cost(B,F). Thus cost(G,A)+cost(B,F)=7. The smallest possible sum of two non‑negative link costs that satisfies this equation is 7, making option C the correct answer.

Q7. Compare the least‑cost trees rooted at routers A and D. Which statement correctly describes their relationship?

🔹 A. They are identical
🔹 B. They share the same total cost for every destination
🔹 C. They may have different parent nodes for the same destination
🔹 D. They cannot both be shortest‑path trees

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Least‑cost trees are rooted at different routers, so while they share the same underlying graph, the parent‑child relationships can differ. For example, a node may choose a different neighbor as its parent depending on the root’s perspective. Therefore, the trees may have different parent nodes for the same destination.

Q8. If a link failure occurs on edge (E,F), how will routers recompute their least‑cost trees?

🔹 A. They will immediately discard all LSAs containing (E,F) and run Dijkstra again
🔹 B. They will wait for a periodic update before recomputing
🔹 C. They will use distance‑vector updates
🔹 D. They will keep the old tree unchanged

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When a link fails, the routers that detect the failure generate new LSAs that omit the failed edge. These LSAs are flooded throughout the network, causing every router to recompute its shortest‑path tree using Dijkstra’s algorithm with the updated topology. This immediate reaction ensures that routing tables reflect the new network state.

Q9. Router C’s tree shows a path to G with cost 8 via D, while router D’s tree shows a path to G with cost 7 via C. Assuming symmetric link costs, what is the cost of edge (C,D)?

🔹 A. 1
🔹 B. 2
🔹 C. 3
🔹 D. 4

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Both routers report total costs that differ by 1 while sharing the same intermediate edge (C,D). Assuming symmetric costs, the only way for the totals to differ by 1 is if the cost of the edge (C,D) itself accounts for that difference. Therefore, the cost of (C,D) must be 1.

Q10. Which scenario would cause the least‑cost trees of all routers to change?

🔹 A. Increase cost of a non‑critical edge
🔹 B. Adding a new router with zero‑cost links
🔹 C. Decreasing cost of an existing edge that lies on at least one shortest path
🔹 D. Removing a LAN that is not part of any shortest path

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When the cost of an edge that lies on at least one shortest‑path is reduced, the affected paths become cheaper, prompting all routers to recalculate their trees. This change propagates throughout the network, altering the least‑cost trees of every router. Hence, decreasing the cost of such an edge triggers a global update.

Q11. In a network where all link costs are integers, what can be said about the uniqueness of least‑cost trees if all edge costs are distinct?

🔹 A. The tree is guaranteed unique
🔹 B. Multiple trees may still exist
🔹 C. Uniqueness depends on the root
🔹 D. Uniqueness is unrelated to edge costs

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

If all edge costs are distinct integers, the ordering of path costs becomes strict, eliminating ties. Dijkstra’s algorithm will then select a unique minimum‑cost neighbor at each step, producing a single spanning tree for each root. Consequently, the least‑cost tree is guaranteed to be unique under these conditions.

Q12. How does the concept of ‘consistent criteria’ affect the formation of least‑cost trees across routers?

🔹 A. It ensures identical total costs for all destinations
🔹 B. It forces routers to select the same root
🔹 C. It guarantees that each router’s tree is a spanning tree
🔹 D. It aligns the metric used for cost calculation

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Consistent criteria refer to using the same metric (e.g., hop count, bandwidth, delay) across all routers when evaluating link costs. By aligning the cost calculation method, each router builds its tree based on comparable values, ensuring that the resulting trees are coherent and can be correctly interpreted by every router in the network.

Q14. If router A detects that the cost of edge (A,G) has doubled from 1 to 2, and all other costs remain unchanged, which destinations will experience a change in their next‑hop selection in A’s least‑cost tree?

🔹 A. Only destination G
🔹 B. Destinations G and F
🔹 C. All destinations reachable via G
🔹 D. No destinations change

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Doubling the cost of (A,G) directly affects any route that uses this link. Destinations that are reachable only through G will now have a higher total cost, causing the router to consider alternative next hops. Therefore, every destination whose shortest path traverses the (A,G) edge will see a change in next‑hop selection.

Q15. Consider a network where LSAs are flooded reliably. If a malicious router injects a false LSA indicating a zero‑cost link to every other router, what is the most likely impact on the network’s routing tables?

🔹 A. All routers will select the malicious router as next hop
🔹 B. The network will detect and discard the LSA
🔹 C. Routing loops will form
🔹 D. No impact because LSAs are authenticated

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Without authentication, a malicious router can advertise a zero‑cost link to all peers. Since LSAs are trusted, every router will incorporate this link into its topology database and compute shortest‑path trees that favor the malicious router as the next hop for all destinations, effectively hijacking traffic.
