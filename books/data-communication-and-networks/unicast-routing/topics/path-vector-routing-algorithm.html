📝 Path Vector Routing algorithm

📖 From Data Communication and Networks • 20. Unicast Routing • 17 questions available

What is Path Vector Routing algorithm?

The Path Vector Routing algorithm is an inter-domain routing method that determines routes based on the complete sequence of autonomous systems (AS path) a packet must traverse, enabling policy-based routing decisions and loop prevention by examining the full path history rather than just metric costs.

📝 All Path Vector Routing algorithm MCQs

Q1. If a router receives an update that contains its own AS number in the AS_PATH, what action should it take?

A. Discard the update ✅
B. Forward the update to other peers
C. Modify the AS_PATH and accept
D. Accept the update without changes

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The presence of the router’s own AS number indicates a loop. BGP specifications require the router to reject such an update to avoid forming a routing loop, so the update is discarded and never installed in the routing table.

Q2. A network operator wants to prefer routes that avoid a certain autonomous system. Which attribute in path‑vector routing can be used to enforce this?

A. NEXT_HOP
B. LOCAL_PREF
C. AS_PATH ✅
D. MED

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The AS_PATH attribute records every autonomous system a route traverses. By examining the AS_PATH, the operator can filter out any route that contains the undesired AS, ensuring that only routes without that AS are considered for forwarding.

Q3. Suppose AS1 learns two routes to prefix X: one via AS2‑AS3 and another via AS4. If AS2 announces a higher MED than AS4, how will AS1's decision process be affected assuming other attributes are equal?

A. Prefer the AS2 path
B. Prefer the AS4 path ✅
C. Select a route at random
D. Discard both routes

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

MED (Multi‑Exit Discriminator) is used to influence inbound traffic; a lower MED is preferred. Since the AS2 path has a higher MED, AS1 will choose the AS4 path, which presents the lower MED value, assuming LOCAL_PREF and other attributes are identical.

Q4. Router R receives an update from neighbor S that lists AS numbers [R, T, U]. What does this indicate?

A. A valid path to the destination
B. A routing loop ✅
C. A policy violation
D. The destination is unreachable

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

If the AS_PATH includes the receiving router’s own AS number (R), the route would create a loop if installed. BGP detects this condition and treats the update as invalid, preventing the formation of a routing loop.

Q5. If a route has LOCAL_PREF 200, AS_PATH length 3, and MED 50, while another route has LOCAL_PREF 100, AS_PATH length 2, and MED 20, which route will be selected by the BGP decision process?

A. The first route ✅
B. The second route
C. Both routes are considered equal
D. Selection depends on the router ID

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

BGP evaluates attributes in a fixed order. LOCAL_PREF has the highest priority among the listed attributes, and the first route’s LOCAL_PREF of 200 outweighs the second route’s 100. Therefore, despite a longer AS_PATH and higher MED, the first route is chosen.

Q6. Which statement best differentiates path‑vector from distance‑vector routing?

A. Path‑vector includes the complete AS_PATH ✅
B. Distance‑vector includes the AS_PATH
C. Both use simple hop count metrics
D. Path‑vector does not prevent routing loops

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Path‑vector protocols, such as BGP, attach the full sequence of autonomous system identifiers (AS_PATH) to each advertised route, enabling loop detection and policy enforcement. Distance‑vector protocols typically only advertise a scalar metric like hop count and lack this detailed path information.

Q7. An ISP applies a routing policy that adds the AS number 65010 to the AS_PATH of all outbound routes to a customer. What is the primary effect of this policy?

A. It increases the perceived path length ✅
B. It decreases latency for the customer
C. It causes a routing loop
D. It improves load balancing across paths

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Appending an AS number to the AS_PATH makes the route appear longer to downstream autonomous systems. This increased path length can make the route less attractive, influencing traffic engineering decisions without altering actual network performance.

Q8. When both LOCAL_PREF and MED attributes differ between two competing routes, which attribute has higher precedence in the BGP decision process?

A. MED
B. LOCAL_PREF ✅
C. They are considered equal
D. Precedence depends on router ID

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

BGP first compares LOCAL_PREF values; the route with the higher LOCAL_PREF is preferred regardless of MED. Only if LOCAL_PREF values are identical does the decision move to compare MED, making LOCAL_PREF the dominant attribute in this scenario.

Q9. If a router implements route flap damping based on the number of times a path is withdrawn within a 60‑second window, how does this mechanism affect convergence time in a highly dynamic network?

A. It speeds up convergence
B. It slows convergence because unstable paths are suppressed ✅
C. It has no effect on convergence
D. It causes permanent loss of routes

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Route flap damping penalizes frequently withdrawn routes, causing them to be suppressed for a period. In a network where routes change often, this suppression delays the re‑advertisement of those routes, thereby increasing the overall convergence time.

Q10. An AS prepends its own number twice before advertising a route to a neighboring AS. How does this affect inbound traffic from that neighbor?

A. It makes the path less preferred, reducing inbound traffic ✅
B. It makes the path more preferred, increasing inbound traffic
C. It has no effect on inbound traffic
D. It causes a routing loop

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Prepending adds extra AS numbers to the AS_PATH, artificially lengthening the path. Neighboring ASes interpret the longer path as less attractive, so they are more likely to send traffic via alternate routes, decreasing the amount of inbound traffic received.

Q11. What attribute in path‑vector routing directly prevents routing loops?

A. NEXT_HOP
B. AS_PATH ✅
C. COMMUNITY
D. ORIGIN

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The AS_PATH attribute records each autonomous system a route traverses. When a router sees its own AS number within the AS_PATH, it knows the route would create a loop and therefore discards it, providing a built‑in loop‑prevention mechanism.

Q12. How does the LOCAL_PREF attribute influence the selection among multiple routes received from different internal BGP peers?

A. Routes with lower LOCAL_PREF are preferred
B. Routes with higher LOCAL_PREF are preferred ✅
C. LOCAL_PREF is ignored for internal peers
D. It is only used for external routes

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

LOCAL_PREF is a numeric value assigned within an autonomous system to indicate route preference. Higher values denote greater preference, so when multiple routes exist, the one with the highest LOCAL_PREF is selected before considering other attributes.

Q13. If two routes to the same prefix have identical LOCAL_PREF and MED values, which attribute is considered next in the BGP decision process?

A. AS_PATH length ✅
B. NEXT_HOP IP address
C. ORIGIN type
D. Router ID

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

After evaluating LOCAL_PREF and MED, BGP compares the length of the AS_PATH. The route with the shorter AS_PATH—meaning it traverses fewer autonomous systems—is considered more direct and is therefore preferred.

Q14. Why does path‑vector routing scale better than link‑state routing in large inter‑domain environments?

A. Because it carries the full network topology
B. Because updates are limited to policy changes rather than whole topology ✅
C. Because it uses hop count as the sole metric
D. Because it requires less memory on routers

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Path‑vector protocols exchange only route advertisements and policy‑related changes, not the entire network graph. This reduces the volume of routing information exchanged between autonomous systems, making it far more scalable for the Internet’s vast and dynamic inter‑domain topology.

Q15. When AS A exports a route to AS B with a COMMUNITY tag that AS B's import policy strips, what is the likely outcome for the route's attributes in AS B?

A. The attribute remains unchanged
B. The attribute is removed from the route ✅
C. The route is rejected entirely
D. The AS_PATH is altered

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Import policies can delete specific COMMUNITY attributes from received routes. When the COMMUNITY tag is stripped, the route continues to be propagated, but the particular attribute no longer influences subsequent routing decisions within AS B.

Q16. In BGP, what does the AS_PATH attribute contain?

A. A list of IP hops
B. A list of autonomous system numbers ✅
C. A list of MAC addresses
D. A list of VLAN IDs

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The AS_PATH attribute records the sequence of autonomous system identifiers that a route has traversed. This list enables routers to detect loops and apply policy decisions based on the path’s composition.

Q17. Which BGP attribute indicates the origin of a route?

A. LOCAL_PREF
B. AS_PATH
C. ORIGIN ✅
D. MED

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The ORIGIN attribute specifies how the route was learned—whether it was originated by the router itself (IGP), learned from another AS (EGP), or is incomplete. It is one of the fundamental attributes used in BGP path selection.
