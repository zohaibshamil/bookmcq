What is Application layer services in computer networks?

Application layer services are the specific functions provided to end-user programs, such as reliable data transfer, security, naming, and message formatting, which allow diverse applications to exchange information over a network without needing to understand the complex details of lower-layer transmission.

Q6. Considering performance, how does using blocking I/O in a C server compare with Java’s non‑blocking NIO channels when handling many simultaneous clients?

A.Blocking I/O in C generally yields lower latency because it avoids context switches.
B.Non‑blocking NIO in Java reduces the number of threads needed, improving scalability. ✅

💡 Difficulty: medium | ✅ Correct: B

Option B correctly reflects this performance advantage.

D.Monitoring the virtual IP with a separate health‑check service that attempts a TCP connect. ✅
💡 Difficulty: hard | ✅ Correct: D
