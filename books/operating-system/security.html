Q1. A company stores payroll data on a server. An employee accidentally copies the file to a USB drive and loses it. Which type of security violation does this represent?

🔹 A. Breach of confidentiality
🔹 B. Breach of integrity
🔹 C. Breach of availability
🔹 D. Breach of non‑repudiation

💡 Difficulty: easy | ✅ Correct: A

Q2. A malicious attacker exploits a buffer overflow to gain root privileges. Which security principle is being violated?

🔹 A. Least privilege
🔹 B. Defense in depth
🔹 C. Confidentiality
🔹 D. Availability

💡 Difficulty: medium | ✅ Correct: B

Q3. A system uses discretionary access control (DAC). An attacker gains privileges by convincing a user to run malicious code. Which security principle is compromised?

🔹 A. Principle of least privilege
🔹 B. Principle of need‑to‑know
🔹 C. Principle of accountability
🔹 D. Principle of separation of duties

💡 Difficulty: hard | ✅ Correct: A
