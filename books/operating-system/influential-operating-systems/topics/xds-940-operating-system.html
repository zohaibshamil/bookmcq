What is XDS-940 operating system?

Definition:
The XDS-940 operating system was among the first to support time-sharing with hardware-enforced protection, providing multiple user terminals with isolated virtual machines where each user perceived a dedicated system with private address space \( V_i \cap V_j = \emptyset \).

Example:
Using modified SDS-940 hardware, it supported up to 32 simultaneous users with protected supervisor calls, ensuring that user bug \( B_u \) could not crash the monitor or corrupt another user's data.

Reason:
It demonstrated that commercial time-sharing required hardware support for memory protection and privileged instructions to ensure reliability and security in multi-user environments beyond what software-only solutions could provide.

📝 All XDS-940 operating system MCQs

Q1. If a CPU can process input twice as fast as a single card reader can read cards, how many card readers working simultaneously are needed to keep the CPU continuously busy?

A.1
B.2 ✅
C.3
D.4
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The CPU runs at \(2\times\) the speed of one reader, so one reader would supply only half the needed data rate. Two readers together provide exactly the required input rate, preventing the CPU from idling. Option B matches this calculation. Options A, C, and D either under‑supply or over‑supply data, leading to idle time or unnecessary hardware. This reflects the principle that matching I/O throughput to CPU speed maximizes system efficiency.

Q2. Why is magnetic tape classified as a sequential‑access device?

A.Because the tape head must move linearly from the beginning to the end of the media ✅
B.Because data is stored in multiple magnetic layers
C.Because magnetic polarity determines access order
D.Because the device uses random‑access algorithms
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Tape storage requires the read/write head to travel along the length of the tape, so data can only be accessed in the order it was written. This linear motion makes it sequential‑access. The other options describe characteristics of other media types or unrelated concepts, which do not explain the sequential nature of tape I/O.

Q3. A batch system has three card readers and one tape drive. The CPU can process data at three times the speed of a single card reader. Will the CPU be idle while jobs are being prepared?

A.Yes, it will be idle
B.No, it will not be idle ✅
C.It depends on the tape drive speed
D.Cannot be determined from the information given
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Since the CPU processes data at \(3\times\) the rate of one reader, the combined input from three readers provides a data rate equal to the CPU’s capacity. Therefore the CPU will have sufficient input and will not idle. Option B reflects this balance. Option A assumes insufficient input, while C and D introduce unrelated factors not needed for the conclusion.

Q4. What is the primary disadvantage of off‑line operation compared with on‑line I/O?

A.A longer delay before a specific job runs ✅
B.Higher hardware cost
C.Reduced reliability of the system
D.Increased power consumption
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Off‑line operation requires jobs to be read onto tape, batched, rewound, transported, and mounted before the CPU can execute them, creating a noticeable delay. This delay is the chief drawback. Higher cost, reliability issues, and power use are not intrinsic to the off‑line method, making options B, C, and D incorrect.

Q5. Which device eliminated the sequential‑access limitation of magnetic‑tape systems?

A.Disk ✅
B.Printer
C.Card punch
D.Plotter
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Disk storage provides random access, allowing the read/write head to jump directly to any location without scanning sequentially. This capability removed the bottleneck inherent in tape systems. Printers, punches, and plotters are output devices and do not affect how data is accessed, so options B, C, and D are incorrect.

Q6. A CPU reads from tape at 100 MB/s while a card reader writes at 30 MB/s. Approximately how many simultaneous card readers are required to keep the CPU fully utilized?

A.2
B.3
C.4 ✅
D.5
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: To match the CPU’s 100 MB/s demand, divide the CPU speed by one reader’s 30 MB/s rate: \(100/30 \approx 3.33\). Since a fraction of a reader is impossible, four readers are needed to exceed the required bandwidth and ensure continuous CPU operation. Option C correctly reflects this calculation. Options A and B under‑provide data, while D adds unnecessary hardware.

Q7. How does the random‑access nature of disks improve job turnaround time compared with tape?

A.It allows a specific job to be retrieved without reading the entire medium ✅
B.It reduces the power needed for I/O operations
C.It speeds up the printing of job results
D.It improves magnetic integrity of stored data
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Random access lets the system locate and load a particular job directly, skipping unrelated data that would otherwise have to be read sequentially on tape. This dramatically shortens the waiting period before execution. The other options describe unrelated benefits that do not directly affect turnaround time.

Q8. A system processes 200 jobs per hour using tape. If disk technology reduces the off‑line delay by 40 % while the CPU speed stays the same, approximately how many jobs per hour can now be processed?

A.240
B.280
C.333 ✅
D.400
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: A 40 % reduction in delay means each job takes 60 % of its original time. The new throughput is \(200 \div 0.60 \approx 333\) jobs per hour. Option C matches this calculation. Options A and B underestimate the gain, and D overestimates it, because they do not apply the correct proportional increase.
