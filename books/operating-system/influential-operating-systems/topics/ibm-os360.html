What is IBM OS/360?

Definition:
IBM OS/360 was a family of operating systems spanning multiple hardware models with upward compatibility, introducing standardized I/O interfaces and spooling where software abstraction layer Asw A_{sw} Asw​ decoupled applications from device specifics.

Example:
OS/360 MFT and MVT variants ran on System/360 models from small to large, using JCL for job control and VSAM for data management, though development suffered from Brooks' Law delays.

Reason:
It established the business model of compatible OS families protecting software investments across hardware upgrades, defining enterprise computing standards and demonstrating both benefits and pitfalls of large-scale OS projects.

📝 All IBM OS/360 MCQs

Q1. A programmer needs to submit a batch job on an IBM OS/360 system that prints a report after processing. Which JCL statement should be used to specify the output device?

A.//SYSOUT ✅
B.//OUTPUT
C.//PRINTER
D.//DEST
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The //SYSOUT statement tells the system to route the job's output to a printer or display defined in the system configuration. //OUTPUT is not a valid JCL keyword, //PRINTER is used in older IBM systems but not in OS/360 JCL, and //DEST is a placeholder not recognized by the supervisor. By selecting //SYSOUT, the job correctly communicates its output destination, ensuring the report is printed as intended.

Q2. When using the GETMAIN macro to allocate a 4 KB buffer, which parameter correctly specifies the size?

A.LENGTH=4096 ✅
B.SIZE=4K
C.BYTES=4096
D.SIZE=4096
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: GETMAIN requires the LENGTH parameter to define the number of bytes to allocate, so LENGTH=4096 accurately requests a 4 KB buffer. The other options use non‑standard keywords or formats that the macro does not recognize, leading to allocation errors. Providing the correct LENGTH ensures the operating system reserves the needed memory, allowing the program to store data safely.

Q3. Why did IBM introduce multiprogramming in OS/360?

A.To reduce CPU idle time and improve throughput ✅
B.To simplify programming language syntax
C.To enable graphical user interfaces
D.To increase disk storage capacity
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Multiprogramming allows several jobs to reside in memory simultaneously, so the CPU can switch to another job when one is waiting for I/O. This reduces idle periods and raises overall system throughput. Changing language syntax or adding GUIs does not directly affect CPU utilization, and disk capacity is unrelated to the scheduling strategy. Hence, the primary motivation was performance improvement.

Q4. What is the primary role of the Supervisor component in OS/360?

A.Managing hardware resources and job scheduling ✅
B.Providing a graphical desktop environment
C.Executing user applications directly
D.Handling network packet routing
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The Supervisor, also called the control program, orchestrates CPU allocation, memory management, and I/O handling for all jobs, ensuring orderly execution. It does not present a graphical interface, run user programs without mediation, or perform networking tasks, which are handled by other system modules or later operating systems. Its central responsibility is resource coordination and job control.

Q5. In what year was IBM OS/360 first released?

A.1964
B.1966 ✅
C.1968
D.1970
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: IBM announced OS/360 in 1964, but the first major release occurred in 1966, marking the debut of the widely used mainframe operating system. The later years listed correspond to subsequent updates or unrelated systems. Recognizing the 1966 release date helps place OS/360 in the historical timeline of computing development.

Q6. A system administrator must boot a mainframe from the DASD volume labeled 'SYS1'. Which IPL command correctly initiates the load?

A.IPL SYS1 ✅
B.START SYS1
C.BOOT SYS1
D.LOAD SYS1
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: IPL (Initial Program Load) is the command used to start the operating system from a specified volume; providing the volume label after IPL tells the firmware where to locate the bootstrap loader. START, BOOT, and LOAD are not valid IPL syntax on OS/360 and would result in a failed start. Using IPL SYS1 correctly directs the system to load OS/360 from the designated disk.

Q7. A developer must choose between a sequential VSAM file and an indexed VSAM KSDS for a dataset that will be searched by key values. Which choice is most appropriate?

A.Indexed KSDS ✅
B.Sequential ESDS
C.Relative RRDS
D.Direct Access VSAM
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: An indexed KSDS (Key Sequenced Data Set) stores records with a key and maintains an index for fast key‑based retrieval, matching the requirement for frequent searches. A sequential ESDS lacks an index and would require full scans, while RRDS uses relative record numbers and does not support key searches. Direct Access VSAM is not a standard VSAM type. Therefore, an indexed KSDS best satisfies the need.

Q8. What purpose does the Linkage Editor (IEWL) serve in OS/360 development?

A.It combines object modules into an executable program ✅
B.It manages virtual memory paging
C.It provides a graphical debugging interface
D.It encrypts source code for security
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The Linkage Editor reads compiled object modules, resolves external references, and produces a loadable executable, enabling modular programming and code reuse. It does not handle paging, GUI debugging, or encryption, which are responsibilities of other system components. By producing a single program image, IEWL streamlines deployment and ensures that all referenced symbols are correctly linked.

Q9. In a system with an 18‑bit segment number and a 16‑bit offset, what is the maximum size of a single segment?

📖 Explanation: The offset field determines the addressable range within a segment. With 16 bits, the offset can represent values from 0 to 216−12^{16}-1216−1, giving a maximum segment size of 2162^{16}216 bytes (65,536 bytes). Q10. Why was the second‑chance page‑replacement algorithm chosen for MULTICS, and how did it influence OS/360 design decisions?

A.It provided a balance between simplicity and reduced page‑fault frequency, influencing OS/360 to adopt similar fair‑swap strategies ✅
B.It was the only algorithm compatible with hardware at the time, forcing OS/360 to use it exclusively
C.It minimized memory usage by avoiding any reference bits, leading OS/360 to discard this concept
D.It required complex hardware support, which OS/360 could not implement
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The second‑chance algorithm scans pages, giving each a “second chance” before replacement, which is simple to implement yet often lowers fault rates compared to pure FIFO. This pragmatic approach inspired OS/360 designers to create comparable swap mechanisms that were easy to code while improving performance. The other options misstate the algorithm’s characteristics or hardware requirements.

Q11. A programmer must decide between a VSAM KSDS and an ESDS for a log file that only ever appends new records. Which type is most efficient?

A.ESDS ✅
B.KSDS
C.RRDS
D.ISAM
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: An ESDS (Entry Sequenced Data Set) is ideal for append‑only workloads because it stores records sequentially without maintaining an index, reducing overhead. A KSDS maintains a key index, which is unnecessary for simple appends and adds extra processing. RRDS requires fixed‑length records, and ISAM is an older, less flexible format. Therefore, ESDS offers the most efficient solution for a growing log.

Q12. When debugging a program that fails due to protection violations, which protection ring should user applications normally execute in?

A.Ring 3 ✅
B.Ring 0
C.Ring 1
D.Ring 2
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: In IBM’s hierarchical protection model, Ring 0 is reserved for the most privileged kernel code, while Ring 3 is the least privileged level intended for user programs, isolating them from critical system resources. Executing in Ring 0 would expose the system to security risks, and Rings 1 and 2 are intermediate levels used for system services. Placing user code in Ring 3 prevents unauthorized access and helps identify protection faults during debugging.

Q13. How did OS/360’s multiprogramming concepts influence later time‑sharing systems such as MULTICS?

A.They introduced the idea of overlapping I/O and CPU work, which became a foundation for time‑sharing ✅
B.They provided a graphical user interface that MULTICS later adopted
C.They eliminated the need for virtual memory, which MULTICS later re‑introduced
D.They mandated the use of punched cards, which MULTICS replaced with terminals
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Multiprogramming allowed OS/360 to keep the CPU busy while jobs waited for I/O, a principle that time‑sharing systems extended to support many interactive users simultaneously. This overlapping of processing and I/O laid the groundwork for the responsive, concurrent environment of MULTICS. The other statements describe features not related to OS/360’s influence on MULTICS.

Q14. A developer wants to generate a conditional branch in assembly that jumps to label CHECK if register R2 equals zero. Which macro should be used?

A.BC 0,CHECK ✅
B.BNR R2,CHECK
C.BALR R2,CHECK
D.BCT R2,CHECK
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The BC (Branch on Condition) macro tests a condition code; BC 0 branches when the zero condition code is set, which occurs after comparing R2 to zero. BNR is not a standard macro, BALR performs an unconditional branch and link, and BCT decrements a register before testing. Using BC 0,CHECK correctly implements the desired conditional jump.
