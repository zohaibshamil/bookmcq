📝 All Network operating systems MCQs

Q1. Which term describes software that manages resources across multiple computers in a network?

🔹 A. Network operating system
🔹 B. Distributed file system
🔹 C. Hypervisor
🔹 D. Virtual machine monitor

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A network operating system (NOS) is the software layer that coordinates hardware and software resources among several computers, providing services such as file sharing, user authentication, and communication. Option A matches this definition, so it is correct. Options B, C, and D refer to other concepts: a distributed file system handles only file storage, a hypervisor creates virtual machines, and a virtual machine monitor manages those VMs. Understanding the NOS role helps administrators select the appropriate platform for multi‑computer environments.

Q2. What is the primary benefit of incorporating site redundancy into a distributed network operating system?

🔹 A. Increased latency
🔹 B. Improved fault tolerance
🔹 C. Higher operational cost
🔹 D. Reduced security

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Redundancy means that multiple sites can provide the same services, so if one site fails the others continue operating, preserving system availability. This improved fault tolerance is the key advantage, making option B correct. Increased latency (A) is a performance drawback, not a benefit. Higher cost (C) and reduced security (D) are potential disadvantages, not reasons for adding redundancy.

Q3. A distributed system detects that Site 3 has stopped responding. What should the system do first to maintain correct operation?

🔹 A. Immediately reboot Site 3
🔹 B. Redirect all traffic to a backup site
🔹 C. Stop using services from Site 3 and log the failure
🔹 D. Ignore the failure and continue normal operation

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The first step after detecting a failure is to cease using the faulty site’s services to avoid corrupted data or unavailable resources, which aligns with option C. Rebooting (A) may be premature without confirming the issue. Redirecting traffic (B) comes after the failure is isolated. Ignoring the failure (D) would compromise system reliability. This sequence ensures that the system remains consistent while recovery actions are planned.

Q4. After repairing a previously failed site, which mechanism most efficiently reintegrates it into the distributed network?

🔹 A. Manual reinstallation of all software
🔹 B. Automatic reconfiguration and synchronization
🔹 C. Shutting down the entire network for a restart
🔹 D. Leaving the site offline until manual checks are completed

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Automatic reconfiguration and synchronization (option B) sounds appealing, but most distributed OS designs require a controlled reintegration process to verify data integrity and avoid conflicts, often performed manually by administrators. Therefore, the safest and most efficient approach described is leaving the site offline until manual checks are completed (option D). Manual reinstallation (A) is unnecessary if software remains intact, and a full network shutdown (C) would cause unnecessary downtime. Proper reintegration protects overall system stability.

Q5. In a distributed environment that uses remote procedure calls (RPC) across three sites, which strategy best minimizes service disruption when one site experiences a sudden overload?

🔹 A. Route all RPCs through the overloaded site
🔹 B. Implement dynamic load balancing that redirects calls to less‑busy sites
🔹 C. Disable RPC functionality until the overload clears
🔹 D. Increase the timeout interval for all RPC calls

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Dynamic load balancing (option B) actively monitors site loads and redirects RPCs to nodes with spare capacity, thereby preventing bottlenecks and keeping services responsive. Routing all calls through the overloaded site (A) would exacerbate the problem. Disabling RPCs (C) eliminates a core service, harming users. Simply increasing timeouts (D) delays error detection without addressing the overload. Effective load balancing preserves performance and user experience during spikes.

Q6. A company plans to replace its mainframe with a network of workstations. Which factor most strongly influences the decision to ensure a cost‑effective transition?

🔹 A. Available bandwidth between workstations
🔹 B. Processing power per individual workstation
🔹 C. Total cost of ownership including maintenance
🔹 D. Physical space occupied by the mainframe

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Total cost of ownership (option C) captures hardware acquisition, licensing, maintenance, and energy expenses, providing a comprehensive view of financial impact. While bandwidth (A) and processing power (B) affect performance, they are secondary to overall cost considerations. Physical space (D) is a minor logistical factor. Focusing on total cost ensures the organization evaluates long‑term savings versus initial investment, guiding a financially sound migration.

Q7. How does message passing in a distributed operating system enable higher‑level functions such as remote login and file transfer?

🔹 A. It encrypts all data automatically
🔹 B. It provides a fundamental communication primitive that other services build upon
🔹 C. It limits communication to local machines only
🔹 D. It replaces the need for any networking hardware

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Message passing supplies a basic mechanism for exchanging data between nodes, allowing higher‑level services like remote login and file transfer to be constructed on top of this capability, making option B correct. Automatic encryption (A) is a security feature, not the core mechanism. Restricting communication to local machines (C) contradicts the distributed nature. Replacing networking hardware (D) is unrealistic; hardware is still required for physical transmission. Understanding this layering helps developers design robust distributed services.

Q8. Which characteristic best distinguishes a network operating system from a single‑computer operating system?

🔹 A. It supports only one user at a time
🔹 B. It manages resources across multiple interconnected machines
🔹 C. It cannot run applications
🔹 D. It lacks file system capabilities

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A network operating system (NOS) is defined by its ability to manage resources across multiple interconnected machines, which is captured in option B and thus the correct answer. Supporting only one user (A) is a limitation unrelated to networking. Inability to run applications (C) is false; NOSes run applications just like any OS. Lacking file system capabilities (D) is incorrect because file sharing is a core NOS feature. Recognizing this distinction clarifies the expanded scope of NOS environments.)

Q9. What is the primary purpose of remote login in a networked computing environment?

🔹 A. To physically move a computer to another location
🔹 B. To allow a user to access and control a computer from a different site
🔹 C. To backup data automatically
🔹 D. To increase the speed of local processing

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Remote login lets a user operate a computer that is not physically present, enabling tasks such as file management, program execution, and system configuration from afar. Option B describes this function accurately. Option A confuses remote login with physical relocation, which is unrelated. Option C describes backup, a separate service. Option D suggests performance improvement, which remote login does not provide. Therefore, B is correct, reflecting the core purpose of remote login in practice.

Q10. Why is remote login considered essential for maintaining continuity in distributed systems?

🔹 A. It provides a way to physically repair hardware remotely
🔹 B. It enables administrators to manage resources and troubleshoot across sites without being on‑site
🔹 C. It automatically replicates data across all nodes
🔹 D. It eliminates the need for any network security measures

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

In a distributed environment, components are spread across many locations, and administrators must be able to intervene without traveling to each site. Remote login gives them the ability to configure services, diagnose problems, and apply patches from any location, preserving system uptime. Option B captures this need. Option A misstates hardware repair, which requires physical access. Option C describes data replication, not login. Option D falsely claims security is unnecessary. Hence, B is the correct answer.

Q11. How does encrypting remote login sessions protect against eavesdropping?

🔹 A. Encryption transforms data into unreadable ciphertext, making intercepted packets useless
🔹 B. Encryption speeds up the login process
🔹 C. Encryption reduces the need for passwords
🔹 D. Encryption duplicates the login credentials

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When a session is encrypted, every byte transmitted is converted into ciphertext using a cryptographic algorithm, so an interceptor sees only random‑looking data that cannot be interpreted without the decryption key. This prevents attackers from reading usernames, passwords, or commands. Option A states this effect directly. Option B is unrelated to security. Option C suggests passwords are unnecessary, which is false. Option D claims duplication of credentials, which does not occur. Therefore, A is the correct choice.

Q12. A system administrator wants to configure key‑based remote login for a Linux server using SSH. Which sequence of actions will correctly set up password‑less authentication for a user named alice?

🔹 A. Generate a key pair on the server, copy the private key to alice’s workstation, and add the public key to /etc/passwd
🔹 B. Create a new user alice, generate a key pair on alice’s workstation, copy the public key to the server’s ~/.ssh/authorized_keys, and set proper permissions
🔹 C. Generate a key pair on alice’s workstation, copy the public key to the server’s ~/.ssh/authorized_keys for alice, and ensure the .ssh directory and file have restrictive permissions
🔹 D. Install a third‑party password manager on the server, then enable password‑less login globally

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Key‑based authentication requires the client to hold a private key and the server to store the matching public key in the user’s authorized_keys file. The private key never leaves the client machine. Option C describes generating the key pair on alice’s workstation, copying the public key to the server’s authorized_keys, and securing the .ssh directory—exactly the required steps. Option A reverses the direction of keys. Option B mixes user creation with key placement but omits permission tightening. Option D introduces an unrelated password manager. Thus, C is correct.

Q13. During a site failure in a distributed environment, remote login requests must be redirected to a standby node. Which mechanism most reliably ensures that users are automatically connected to the backup server without manual reconfiguration?

🔹 A. Update the client’s /etc/hosts file manually after the failure
🔹 B. Configure a DNS failover record that points the login hostname to the standby node’s IP address
🔹 C. Rely on the original server’s firewall to forward login traffic to the backup
🔹 D. Use a static IP address for both primary and backup servers

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A DNS failover record can be set to automatically resolve the login hostname to the backup server’s IP when the primary becomes unreachable, allowing clients to continue using the same hostname without any configuration changes. Option B provides this automated redirection. Option A requires manual editing on each client, which is impractical. Option C depends on the failed server’s firewall, which cannot forward traffic if it is down. Option D creates address conflicts and does not direct traffic intelligently. Therefore, B is the correct answer.

Q14. After a previously failed site is repaired, the network must reintegrate it while preserving secure remote login. Which of the following procedures best restores trust and prevents credential reuse attacks?

🔹 A. Keep the old host key, re‑enable the site, and instruct users to ignore host key warnings
🔹 B. Generate a new host key, distribute the new key to all clients via a secure channel, and revoke the old key in the known‑hosts database
🔹 C. Delete all user accounts on the repaired site and require users to create new passwords
🔹 D. Disable encryption temporarily to speed up the reintegration process

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When a server returns from failure, its previous host key may have been compromised or cached by clients. Generating a fresh host key and securely distributing it ensures that clients can verify the server’s identity, while revoking the old key removes any lingering trust that could be exploited. Option B follows this secure practice. Option A asks users to ignore warnings, which defeats the purpose of host key verification. Option C changes passwords but does not address the host key issue. Option D removes encryption, exposing all traffic. Hence, B is the correct choice.

Q15. Which statement best compares telnet and SSH regarding security and functionality for remote login?

🔹 A. Telnet encrypts data while SSH does not, making telnet more secure
🔹 B. Both telnet and SSH provide identical security, but SSH offers better file transfer capabilities
🔹 C. SSH encrypts the session and supports strong authentication, whereas telnet transmits data in plain text and offers only basic login
🔹 D. Telnet supports public‑key authentication, while SSH relies solely on passwords

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

SSH was designed to replace telnet by providing encrypted communication and robust authentication methods such as public‑key and certificate‑based logins. Telnet sends all data, including passwords, in clear text, making it vulnerable to interception. Option C accurately captures this contrast. Option A flips the encryption relationship. Option B incorrectly claims identical security. Option D misstates telnet’s capabilities and SSH’s reliance on passwords only. Therefore, C is the correct answer.

Q16. A developer needs to invoke a remote procedure on a server after establishing an SSH login. Which approach ensures the RPC call is both authenticated and confidential?

🔹 A. Send the RPC command over the same SSH channel after login
🔹 B. Open a separate unencrypted TCP socket for the RPC after login
🔹 C. Encode the RPC payload in base64 and transmit it via email
🔹 D. Use telnet to issue the RPC after the SSH session ends

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Once an SSH session is active, the channel is already encrypted and the server has authenticated the client. Sending the RPC command through that same channel inherits the confidentiality and integrity guarantees of SSH. Option A leverages this secure tunnel. Option B creates an insecure path. Option C merely encodes data without protection. Option D reverts to telnet, which lacks encryption. Consequently, A is the correct choice.

Q17. A user needs to transfer a 2 GB file over a network that provides a steady 10 Mbps bandwidth. Which approach will most directly reduce the total transfer time?

🔹 A. Compress the file before sending
🔹 B. Use plain FTP without compression
🔹 C. Send the file as an email attachment
🔹 D. Split the file into smaller pieces but send sequentially

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Compressing the file reduces the amount of data that must travel across the link. A 2 GB file equals about 16 000 Mb; at 10 Mbps the transfer would take roughly 1 600 seconds (≈27 minutes). If compression halves the size to 8 000 Mb, the transfer time drops to about 800 seconds (≈13 minutes). The other options either add overhead or do not change the data volume, so they do not shorten the transfer time.

Q18. What is the standard term for moving a file from a local computer to a remote server over a network?

🔹 A. Remote file transfer
🔹 B. Local copy
🔹 C. Data mirroring
🔹 D. Network caching

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The phrase “remote file transfer” specifically describes the action of sending a file from a local machine to a remote system across a network. “Local copy” refers to duplicating a file on the same machine, while “data mirroring” usually involves keeping two locations identical for redundancy. “Network caching” stores copies temporarily to improve access speed, not to describe the act of transferring a file to a remote host.

Q19. Why is authentication considered a critical component of remote file transfer protocols?

🔹 A. It verifies the identity of the parties involved
🔹 B. It speeds up the transfer rate
🔹 C. It compresses the data automatically
🔹 D. It eliminates the need for error checking

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Authentication ensures that only authorized users can initiate or receive a file transfer, preventing unauthorized access or data leakage. Without verification, an attacker could impersonate a legitimate user and intercept or alter files. The other options describe unrelated features: speed, compression, and error checking are performance or reliability mechanisms, not security measures that protect the integrity and confidentiality of transferred data.

Q20. A company currently uses plain FTP for transferring confidential design files. Which protocol should they adopt to add strong security while preserving file‑transfer functionality?

🔹 A. SFTP (SSH File Transfer Protocol)
🔹 B. FTPS (FTP over SSL)
🔹 C. HTTP
🔹 D. Telnet

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

SFTP encrypts both commands and data using SSH, providing confidentiality and integrity for sensitive files. FTPS also adds security but requires separate SSL/TLS negotiation and can be blocked by firewalls more often. HTTP and Telnet do not natively support file transfer and lack the necessary security features for confidential data. Therefore, SFTP best meets the requirement of secure, reliable file transfer.

Q21. How does system redundancy improve the reliability of remote file transfers in a distributed environment?

🔹 A. It allows failed nodes to be bypassed and transfers to continue
🔹 B. It increases the maximum file size that can be sent
🔹 C. It reduces the need for authentication
🔹 D. It speeds up the compression algorithm

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Redundancy means multiple nodes can perform the same function; if one node fails, another can take over, so ongoing file transfers are not interrupted. This fault‑tolerance keeps the network operational and maintains data flow. Redundancy does not directly affect file size limits, authentication requirements, or compression speed, which are governed by protocol design and hardware capabilities.

Q22. During a site outage, a manager must ensure that ongoing file transfers are rerouted to an alternate server without manual reconfiguration. Which mechanism most appropriately handles this situation?

🔹 A. Failover routing
🔹 B. Load balancing
🔹 C. DNS round‑robin
🔹 D. Network address translation (NAT)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Failover routing detects a failed node and automatically redirects traffic, including file‑transfer sessions, to a pre‑designated backup server, preserving continuity. Load balancing distributes traffic across multiple servers but does not specifically react to failures. DNS round‑robin provides multiple IPs but lacks real‑time health checks. NAT changes address translation but does not manage failover logic. Hence, failover routing directly addresses the need for automatic rerouting after a failure.

Q23. Compare FTP and SCP in terms of security and performance. Which statement is most accurate?

🔹 A. SCP encrypts data and commands, often slower than FTP which sends data in clear text
🔹 B. SCP sends data in clear text while FTP encrypts both commands and data
🔹 C. Both FTP and SCP provide identical security levels, but SCP is always faster
🔹 D. FTP offers stronger authentication than SCP, but SCP cannot transfer directories

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

SCP (Secure Copy) uses SSH to encrypt both commands and file data, ensuring confidentiality, whereas traditional FTP transmits data and credentials in clear text, making it less secure. Encryption adds overhead, so SCP can be slower than FTP, especially on high‑latency links. The other options reverse the security properties or incorrectly claim identical security or performance, which does not reflect the actual behavior of these protocols.

Q24. A network has 150 ms latency and 2 % packet loss. Which technique will most effectively improve large‑file transfer throughput?

🔹 A. Increase the TCP window size using window scaling
🔹 B. Switch to UDP without any reliability mechanisms
🔹 C. Apply compression before sending the file
🔹 D. Add a stronger checksum to each packet

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Increasing the TCP window size allows more unacknowledged data to be in flight, mitigating the impact of high latency and modest loss on throughput. UDP removes reliability but does not solve loss; compression reduces data size but does not address latency; a stronger checksum adds overhead without improving speed. Window scaling directly tackles the bandwidth‑delay product, making it the most effective method for this scenario.

Q25. What role do remote procedure calls (RPC) play in facilitating file transfer between distributed systems?

🔹 A. They allow a program on one machine to invoke file‑handling functions on another as if local
🔹 B. They compress files before sending them across the network
🔹 C. They provide a graphical user interface for file selection
🔹 D. They replace the need for any network protocol

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

RPC abstracts the network layer, letting an application invoke file‑related operations (open, read, write) on a remote host as if they were local calls. This simplifies programming and hides communication details, while the underlying transport protocol still moves the actual data. RPC does not perform compression, UI rendering, or eliminate the need for transport protocols; it merely provides a convenient call mechanism for remote file operations.

Q26. A 1 GB dataset must be transferred using two parallel TCP streams, each limited to 5 Mbps. Ignoring overhead, what is the approximate total transfer time?

🔹 A. \( \frac{8\,\text{Gb}}{10\,\text{Mbps}} \approx 800 \text{ s} \)
🔹 B. \( \frac{8\,\text{Gb}}{5\,\text{Mbps}} \approx 1600 \text{ s} \)
🔹 C. \( \frac{1\,\text{GB}}{10\,\text{Mbps}} \approx 800 \text{ s} \)
🔹 D. \( \frac{1\,\text{GB}}{5\,\text{Mbps}} \approx 1600 \text{ s} \)

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The dataset size is 1 GB = 8 Gb. Two streams each at 5 Mbps give a combined throughput of 10 Mbps. Transfer time = total bits ÷ throughput = 8 Gb ÷ 10 Mbps = 800 seconds (≈13 minutes). Option A shows the correct calculation. Options B and D use only a single 5 Mbps stream, and option C incorrectly treats gigabytes as gigabits, leading to an underestimation of the required time.

Q27. How does authentication differ between FTP and SFTP?

🔹 A. FTP typically uses plain text usernames and passwords, while SFTP authenticates via SSH keys or encrypted credentials
🔹 B. FTP encrypts credentials, whereas SFTP sends them in clear text
🔹 C. Both FTP and SFTP use the same authentication mechanism by default
🔹 D. SFTP does not require any authentication

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

FTP often transmits usernames and passwords without encryption, exposing them to interception. SFTP, built on SSH, can use password authentication encrypted within the SSH tunnel or stronger methods such as public‑key authentication, providing better protection. The other statements reverse the security properties or claim no authentication, which is inaccurate because both protocols require authentication, though SFTP’s methods are inherently more secure.

Q28. A user’s download is interrupted after 30 % of a large file has been received. Which feature should the transfer protocol support to allow the download to resume without restarting from the beginning?

🔹 A. Restart/resume capability (e.g., FTP REST command)
🔹 B. Automatic re‑encryption of the entire file
🔹 C. Compression of the remaining data only
🔹 D. Switching to a different protocol mid‑transfer

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A restart or resume feature lets the client request the remaining portion of a file starting from the last byte received, saving time and bandwidth. FTP’s REST command, HTTP’s Range header, and similar mechanisms provide this capability. Re‑encryption, compressing only the remainder, or changing protocols do not directly enable continuation of the partially transferred file.
