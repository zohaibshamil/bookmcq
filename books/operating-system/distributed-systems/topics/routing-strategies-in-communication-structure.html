Q1. What is the standard data transfer rate of a T3 line used in WAN connections?

🔹 A. 1.544 Mbps
🔹 B. 45 Mbps
🔹 C. 622 Mbps
🔹 D. 10 Gbps

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A T3 line is defined as a bundle of 28 T1 circuits. Each T1 carries 1.544 Mbps, so the combined rate is roughly \(28 \times 1.544 \approx 45\) Mbps. Therefore option B correctly reflects the standard T3 speed. Option A describes a single T1, option C corresponds to an OC‑12 link, and option D far exceeds typical T3 capacity. Knowing these standard rates helps engineers choose appropriate WAN technologies for required throughput.

Q2. Which WAN technology provides a standard transfer rate of 622 megabits per second?

🔹 A. OC-3
🔹 B. T1
🔹 C. OC-12
🔹 D. DSL

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

OC‑12 is a standardized optical carrier that delivers 622 Mbps, making it the correct answer. OC‑3 offers only 155 Mbps, T1 provides 1.544 Mbps, and DSL speeds vary but are far below 622 Mbps. Recognizing the specific capacity of OC‑12 enables network planners to match bandwidth needs with the right technology, especially when inter‑city links require high‑speed transport.

Q3. Why is hierarchical routing commonly employed in large‑scale networks?

🔹 A. It reduces routing table size by aggregating routes
🔹 B. It increases the number of routing updates
🔹 C. It eliminates the need for any routing protocol
🔹 D. It forces every router to store every possible path

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Hierarchical routing groups routers into regions, allowing each region to summarize its internal routes into a single entry. This aggregation dramatically shrinks the size of routing tables and reduces the amount of routing information exchanged. Option B is incorrect because hierarchical designs actually lower update traffic. Options C and D are false; protocols are still needed and routers do not store every path. The reduction in table size improves scalability and speeds up lookup operations.

Q4. How does source routing differ from hop‑by‑hop routing in terms of packet handling?

🔹 A. Each router decides the next hop based on its own table
🔹 B. The destination node selects the path
🔹 C. The packet carries the complete path information
🔹 D. Routers broadcast the packet to all neighbors

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

In source routing, the originating host embeds the entire sequence of intermediate addresses inside the packet, so each router simply follows the next address in the list. This contrasts with hop‑by‑hop routing, where each router independently looks up the best next hop. Option A describes traditional hop‑by‑hop behavior, option B is inaccurate because the source, not the destination, defines the path, and option D is unrelated to standard routing methods. Source routing gives the sender precise control over the route, useful for testing or policy enforcement.

Q5. What is the main advantage of link‑state routing over distance‑vector routing regarding loop prevention?

🔹 A. Link‑state uses smaller update packets
🔹 B. Distance‑vector updates are sent more frequently
🔹 C. Link‑state maintains a complete view of the network, preventing loops
🔹 D. Distance‑vector requires less computational power

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Link‑state protocols (e.g., OSPF) require each router to construct a full map of the network topology, enabling it to compute shortest paths and detect potential loops before they form. Distance‑vector methods only know the cost to destinations via neighbors, which can lead to temporary loops (the count‑to‑infinity problem). Options A and D describe unrelated characteristics, and option B is opposite to reality—distance‑vector typically sends updates less often. The comprehensive view of link‑state is why it avoids loops more reliably.

Q6. A company with three geographically separated sites needs a routing method that minimizes overhead while still supporting inter‑site communication. Which strategy is most appropriate?

🔹 A. Flat distance‑vector routing
🔹 B. Hierarchical routing
🔹 C. Source routing
🔹 D. Static routing

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Hierarchical routing divides the network into regions, allowing each site to maintain a small internal table while summarizing routes to other regions. This reduces the amount of routing information exchanged compared with a flat distance‑vector approach, which would require every router to know every path. Source routing imposes per‑packet overhead, and static routing lacks adaptability to changes. Therefore, hierarchical routing best balances low overhead and scalability for multi‑site environments.

Q7. If a T3 line composed of 28 T1 circuits fails, how much total bandwidth is lost?

🔹 A. 45 Mbps
🔹 B. 28 Mbps
🔹 C. 1.544 Mbps
🔹 D. 622 Mbps

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A T3 line aggregates 28 individual T1 connections, each providing 1.544 Mbps. The total capacity is therefore \(28 \times 1.544 \approx 45\) Mbps. When the entire T3 fails, the whole aggregated bandwidth disappears, matching option A. Option B mistakenly treats the number of circuits as a bandwidth value, option C reflects a single T1 line, and option D describes an OC‑12 link. Understanding this relationship helps engineers evaluate the impact of link failures on overall network throughput.

Q8. When a router uses a default route to a backbone WAN and receives a packet whose destination is not in its routing table, what will the router do?

🔹 A. Drop the packet immediately
🔹 B. Send an ICMP Destination Unreachable message
🔹 C. Broadcast the packet on all interfaces
🔹 D. Forward the packet to the default gateway

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

A default route acts as a catch‑all entry pointing to a next‑hop router (the backbone gateway). If a destination is unknown, the router forwards the packet to this default gateway, giving the backbone a chance to resolve the address. Dropping the packet (A) would discard useful traffic, sending an ICMP error (B) is not typical for forwarding, and broadcasting (C) would cause unnecessary traffic. Hence, option D correctly describes the default‑route behavior.

Q9. Which routing protocol is best suited for fast convergence across a WAN that interconnects LANs and cellular tower networks?

🔹 A. RIP
🔹 B. OSPF
🔹 C. BGP
🔹 D. Static routing

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

OSPF is a link‑state protocol designed for rapid convergence and supports hierarchical areas, making it effective for mixed environments that include high‑speed LANs, WAN links, and cellular backbones. RIP converges slowly, BGP is optimized for inter‑domain routing rather than rapid interior changes, and static routing cannot adapt to topology changes. Therefore, OSPF (option B) provides the quickest and most reliable updates across diverse link types.

Q10. A network designer needs a backup path that provides at least 80 % of the primary T3 bandwidth (45 Mbps). Which alternative satisfies this requirement?

🔹 A. Two T1 lines
🔹 B. One OC‑12 line
🔹 C. One T1 and one OC‑12 line
🔹 D. Three T1 lines

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Eighty percent of 45 Mbps equals \(0.8 \times 45 = 36\) Mbps. An OC‑12 link supplies 622 Mbps, far exceeding the 36 Mbps threshold, so a single OC‑12 line alone meets the requirement (option B). Two T1 lines together give only about \(2 \times 1.544 \approx 3.1\) Mbps, well below the target. Combining a T1 with an OC‑12 (option C) also works but is unnecessary, and three T1 lines still fall short. Thus, the simplest solution is one OC‑12 line.

Q11. When a router employs source routing, how does it ensure packets follow the shortest physical path regardless of administrative domains?

🔹 A. Source routing
🔹 B. Hierarchical routing
🔹 C. Distance‑vector routing
🔹 D. Static routing

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Source routing places the complete list of intermediate hops inside the packet, allowing the sender to specify the exact sequence of routers that constitute the shortest physical route. This bypasses any domain‑level policies that might otherwise divert traffic. Hierarchical routing aggregates routes and does not guarantee the absolute shortest path, distance‑vector relies on local metrics, and static routing cannot adapt to changing topologies. Hence, option A correctly identifies the strategy that provides precise path control.

Q12. How does aggregating multiple T1 lines into a single T3 link affect the size of routing tables and the frequency of routing updates compared to using a single high‑capacity link?

🔹 A. Routing tables become larger and updates more frequent
🔹 B. Routing tables shrink but updates become slower
🔹 C. Both table size and update frequency decrease
🔹 D. There is no impact on routing information

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

When many lower‑capacity circuits are bundled into one logical T3 link, the network can treat the bundle as a single adjacency. Consequently, routers store only one entry for the T3, reducing the number of routes (smaller tables) and decreasing the number of update messages, because changes are reported for the aggregated link rather than each individual T1. Options A and B describe opposite effects, and D ignores the real simplification that occurs. Therefore, both table size and update frequency are reduced.

Q13. What is the primary reason that WAN links typically exhibit higher latency than LAN links, even when their bandwidths are comparable?

🔹 A. WAN equipment uses slower processors
🔹 B. LAN cables have lower resistance
🔹 C. WAN protocols add extra encryption
🔹 D. Physical distance and multiple intermediate devices increase propagation delay

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

WAN connections often span long geographic distances and traverse many intermediate devices such as repeaters, switches, and routers. Each hop adds propagation and processing delay, which accumulates to higher overall latency. While equipment speed and encryption can affect performance, the dominant factor is the sheer distance and the number of hops. Therefore, option D correctly identifies the main cause of increased WAN latency.

Q14. A home office needs low latency for video conferencing. Which ISP connection type should be chosen?

🔹 A. Dial‑up (56 kbps)
🔹 B. Cable (100 Mbps)
🔹 C. Fiber (1 Gbps)
🔹 D. Any of the above

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Fiber offers the highest capacity and typically the lowest latency among the listed options because it uses light‑speed transmission and minimal electrical interference. Cable can provide high bandwidth but often introduces higher latency due to shared medium contention. Dial‑up is both slow and latency‑prone. Selecting fiber (option C) ensures the most responsive video conferencing experience, aligning with the requirement for low latency.
