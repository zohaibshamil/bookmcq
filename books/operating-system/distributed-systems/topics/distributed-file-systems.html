What is Distributed File Systems?

Definition:
Distributed file systems provide unified namespace and transparent access to files stored across multiple networked servers, hiding distribution details from users.

Example:
HDFS storing petabytes of data across commodity clusters with automatic replication and fault tolerance.

Reason:
They enable scalable, reliable storage for big data applications while presenting familiar file interface, abstracting underlying distribution complexity.

📝 All Distributed File Systems MCQs

Q1. Which protocol is used to translate a host name into an IP address in a networked file system?

A. DHCP
B. DNS ✅
C. ARP
D. NTP

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

DNS is the dedicated service that maps human‑readable host names to numeric IP addresses, enabling applications to locate remote file servers. DHCP assigns IP addresses, ARP resolves MAC addresses, and NTP synchronizes clocks, none of which perform name‑to‑address translation. Using DNS ensures that a client can reliably find the correct server, a fundamental step before any file operation.

Q2. A workstation tries to send a file to a server whose MAC address is still cached but the server has been replaced. What is the most likely outcome?

A. Packet delivered correctly
B. Packet discarded due to checksum error
C. Packet sent to wrong MAC and fails ✅
D. ARP request refreshed automatically

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The stale ARP entry points the Ethernet frame to the old MAC address, which now belongs to a different device or is unused. Consequently the frame never reaches the intended server, causing the transfer to fail. The other options are incorrect: the checksum does not detect this routing error, and the ARP cache is not automatically refreshed without a request.

Q3. What is the primary purpose of the trailer checksum in an Ethernet frame?

A. Verify source IP
B. Detect frame corruption ✅
C. Encrypt payload
D. Identify frame type

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The checksum placed in the Ethernet trailer allows the receiving NIC to verify that the bits of the frame were not altered during transmission. If the computed checksum differs from the transmitted value, the frame is discarded as corrupted. It does not authenticate the source, perform encryption, or indicate the protocol type, which are handled by other header fields.

Q4. When a packet moves from subnet A to subnet B via a router, the router updates the Ethernet header. What must the router change to ensure delivery?

A. To update MAC addresses for next hop ✅
B. To hide original source
C. To encrypt data
D. To change IP address

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Routers operate at the network layer and forward packets across subnets, but each hop requires a new data‑link header containing the MAC address of the next device. By replacing the destination MAC with the address of the downstream router (or host) and the source MAC with its own, the frame can be correctly received on the new link. Changing IP addresses or encrypting data is unrelated to this step.

Q5. A distributed file system client frequently accesses a server on the same LAN. The admin pins the server's MAC address in the ARP cache. What performance benefit does this provide?

A. Reduces DNS lookups
B. Eliminates need for routing
C. Compresses file data
D. Stores MAC addresses ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Pinning the MAC address prevents the client from issuing ARP requests each time it sends a packet, eliminating the small delay associated with cache misses. This speeds up communication within the LAN, especially for high‑frequency file operations. DNS lookups, routing decisions, and data compression are unrelated to MAC address resolution, so they do not explain the observed latency reduction.

Q6. At which OSI layer does Ethernet operate?

A. Data‑link ✅
B. Network
C. Physical
D. Transport

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Ethernet frames are defined by the IEEE 802.3 standard, which resides in the Data‑link layer (Layer 2) of the OSI model. This layer is responsible for framing, MAC addressing, and error detection. The Network layer (Layer 3) handles IP addressing, the Physical layer (Layer 1) deals with raw bit transmission, and the Transport layer (Layer 4) provides end‑to‑end communication. Recognizing Ethernet’s layer is essential for troubleshooting network issues.

Q7. A database server frequently communicates with a storage node. To reduce latency, the admin pins the storage node's MAC address in the ARP cache. Which effect is most expected?

A. Faster ARP resolution ✅
B. Increased packet loss
C. Higher CPU usage
D. Need for manual DNS updates

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

By pinning the MAC address, the server bypasses the ARP request/reply cycle for each packet, achieving immediate address resolution and thus lower round‑trip time. This does not inherently cause packet loss, nor does it raise CPU consumption significantly. DNS updates remain unrelated because MAC addresses are resolved locally, not via name services.

Q8. When a client initiates a file request, the DNS lookup takes 150 ms before the IP is known. Which strategy can most effectively reduce overall file access time?

A. Increase Ethernet frame size
B. Use larger checksum
C. Cache DNS entries locally ✅
D. Disable ARP

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Caching DNS results on the client or a nearby resolver eliminates the repeated 150 ms lookup for subsequent requests, directly cutting the latency before the file transfer can begin. Changing frame size or checksum does not affect name resolution time, and disabling ARP would break address mapping, making caching the only practical improvement.

Q9. Why do Ethernet frames include both a preamble and a start‑of‑frame delimiter before the destination MAC address?

A. For synchronization ✅
B. For error correction
C. To indicate packet length
D. To encrypt payload

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The preamble (a series of alternating bits) and the start‑of‑frame delimiter allow receiving hardware to synchronize its clock and detect the exact beginning of a frame, ensuring that the following MAC address and payload are interpreted correctly. They do not provide error‑correction codes, length information, or encryption; those functions are handled elsewhere in the protocol stack.

Q10. A file request must travel from Host A in subnet X to Host B in subnet Z via routers R1 and R2. If the ARP cache on R2 is empty for Host B, what will R2 do?

A. Drop packet
B. Send ICMP redirect
C. Broadcast ARP request ✅
D. Change destination IP

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

When R2 lacks a MAC address for the final host, it issues an ARP broadcast on its local segment to discover the destination's hardware address. The request reaches Host B, which replies with its MAC, allowing R2 to forward the frame. Dropping the packet or sending an ICMP redirect would break connectivity, and altering the IP address would violate routing correctness.

Q11. How does the use of a WAN affect the role of ARP in a distributed file system accessing remote files?

A. ARP is used across WAN
B. ARP only resolves MAC on local segment ✅
C. ARP replaces DNS
D. ARP encrypts data

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

ARP operates only within a broadcast domain; a WAN spans multiple domains, so ARP cannot resolve addresses beyond the local LAN. Consequently, routers use IP routing across the WAN, while each local segment still uses ARP for final‑hop delivery. ARP does not substitute DNS, nor does it provide encryption, making the local‑segment limitation the key distinction.

Q12. During file transfer, a corrupted Ethernet frame is detected by its checksum. What is the typical response of the receiving host?

A. Retransmit entire file
B. Discard frame and request retransmission ✅
C. Ignore error
D. Modify checksum to match data

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When the checksum verification fails, the receiver discards the damaged frame and signals the sender (often via a higher‑layer protocol) to retransmit the missing data. This preserves data integrity. Automatically retransmitting the whole file would be inefficient, ignoring the error would corrupt the file, and altering the checksum would be a security breach, none of which are standard practices.

Q13. Why might a distributed file system choose to pin ARP entries for heavily used hosts rather than relying on dynamic aging?

A. To prevent MAC address changes
B. To reduce ARP traffic and latency ✅
C. To increase security
D. To enable multicast

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Pinning prevents the cache from expiring, so the system avoids periodic ARP requests for frequently contacted hosts, cutting both network chatter and the microsecond‑level delay of address resolution. This improves throughput for high‑frequency file operations. The other options—preventing MAC changes, enhancing security, or enabling multicast—are unrelated to the performance goal of ARP pinning.
