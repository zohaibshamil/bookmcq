What is Resource sharing in distributed system?

Definition:
Resource sharing is the capability allowing geographically dispersed users to access remote hardware, software, or data resources as if they were local, often modeled as Ravailable=⋃jRj R_{\text{available}} = \bigcup_{j} R_j Ravailable​=⋃j​Rj​.

Example:
Multiple researchers accessing a centralized high-performance database or shared printer over a university network.

Reason:
Sharing eliminates redundant resource procurement and ensures expensive specialized equipment is utilized efficiently across the organization.

📝 All Resource sharing in distributed system MCQs

Q1. What is the definition of resource sharing in a distributed system?

A.The process of duplicating data across all nodes
B.Providing a node's local resources for use by remote nodes ✅
C.Encrypting communications between sites
D.Scheduling tasks on a single machine
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The correct answer is B because resource sharing means that a node makes its locally available resources—such as files, printers, or processing power—accessible to other nodes in the system. Option A describes replication, not sharing. Option C refers to security, which is unrelated. Option D is about local scheduling only. By sharing resources, distributed systems allow remote users to utilize capabilities they do not own, which is the core idea of resource sharing.

Q2. Why does resource sharing typically improve overall system utilization in a distributed environment?

A.It reduces the number of nodes needed
B.It speeds up individual processors
C.It allows idle resources to be used by other nodes ✅
D.It eliminates network communication
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The correct answer is C because sharing resources lets idle or under‑used devices be employed by other nodes, raising overall system utilization. When a printer at site B is used by a user at site A, the device spends less time idle, and the network gains efficiency. Option A mentions faster processors, which is a speed‑up reason, not utilization. Option B suggests lower cost, which is a benefit but not the direct cause of better utilization. Option D claims reduced security risk, which is unrelated to utilization.

Q3. How does resource sharing enhance reliability of a distributed system?

A.By providing redundant access to the same resource ✅
B.By increasing processor clock speed
C.By lowering power consumption
D.By simplifying programming models
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The correct answer is A because resource sharing can provide redundancy; if one node fails, another node can access the same resource, improving system reliability. For example, two sites may hold copies of a critical file, so loss at one site does not make the data unavailable. Option B describes faster computation, which is a speed‑up benefit. Option C mentions lower power consumption, which is not directly linked to reliability. Option D suggests easier programming, which is a convenience, not a reliability factor.

Q4. What is a primary downside of resource sharing related to communication?

A.It eliminates all network traffic
B.It adds security vulnerabilities only
C.It reduces overall bandwidth usage
D.It introduces additional latency and bandwidth consumption ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The correct answer is D because while resource sharing enables remote access, it also introduces communication overhead; each request must travel across the network, consuming bandwidth and latency. Option A claims sharing eliminates overhead, which is false. Option B suggests overhead is only a security issue, ignoring performance impact. Option C states that sharing reduces overhead, which contradicts the need for data transfer. Understanding that sharing improves functionality but can increase communication cost helps designers balance performance and resource availability.

Q5. A user at site A wants to print a document on a laser printer located at site B. Which action best illustrates resource sharing?

A.Sending the document to the printer at site B for printing ✅
B.Installing a new printer at site A
C.Saving the document locally and printing later
D.Emailing the document to a colleague
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The correct answer is A because sending the document to the remote printer uses the printer’s resource from another site, which is the essence of resource sharing. Option B describes adding a local device, not sharing. Option C keeps the printing task local and does not involve remote resources. Option D merely transmits the file without using the printer resource. By directing the job to the printer at site B, the user leverages a shared device across the network.

Q6. Company X has a site with a GPU cluster and another site with large‑scale storage. To process a data‑intensive analytics job efficiently, which strategy best uses resource sharing?

A.Transfer all data to the GPU site, run the job, then send results back
B.Keep data at the storage site, send compute tasks to the GPU site, and stream intermediate results ✅
C.Duplicate both data and GPU resources at each site
D.Perform the entire job at the storage site using its CPUs
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The correct answer is B because it keeps the massive dataset where it resides, minimizing costly data movement, while sending the compute‑intensive tasks to the site that offers the GPU cluster, thus exploiting both resources through sharing. Option A would require moving the entire dataset across the network, incurring high latency and bandwidth use. Option C duplicates expensive hardware unnecessarily, increasing cost. Option D ignores the high‑performance GPU advantage, leading to slower execution. Using shared resources as described in B balances I/O and compute efficiency.

Q7. When designing a distributed system for a multinational corporation, which factor should most influence the decision to centralize a specialized hardware device versus replicate it at multiple sites for resource sharing?

A.The device’s power consumption
B.The cost of network bandwidth
C.The frequency of device usage across sites ✅
D.The brand reputation of the device manufacturer
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The correct answer is C because if the specialized device is needed frequently by many sites, replicating it reduces access latency and network load, making resource sharing more effective. Centralizing a rarely used device can be more cost‑effective, but high usage demands local availability. Option A, power consumption, affects operational cost but not the placement decision. Option B, bandwidth cost, is a secondary concern compared to usage patterns. Option D, brand reputation, does not impact performance or accessibility. Therefore, usage frequency is the primary driver for replication versus centralization.
