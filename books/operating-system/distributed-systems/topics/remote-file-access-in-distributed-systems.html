Q1. A computer on a local Ethernet network wants to transfer a file to another computer whose IP address is known. Its ARP cache already contains the correct Ethernet (MAC) address. Which of the following actions will the sending host take next?

A.Broadcast an ARP request to find the MAC address
B.Send the Ethernet frame directly to the cached MAC address ✅
C.Forward the packet to the default router
D.Drop the packet due to missing ARP entry
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The host already knows the destination MAC, so it simply builds an Ethernet frame using that address and places it on the wire. Option B describes this exact step. Option A would be unnecessary because the MAC is cached; Option C would only be used if the destination were on a different network; Option D is incorrect because a missing ARP entry is not the case here. In real file‑transfer scenarios, using the cached MAC eliminates latency and speeds up the transfer.

Q2. Host A (192.168.1.10) wants to access a remote file on Host B (10.0.0.5). Host A’s ARP cache lacks B’s MAC, but it knows the default gateway 192.168.1.1. What is the correct sequence of actions?

A.Send an ARP request for B’s MAC, then send directly
B.Send the packet to the default gateway’s MAC, which routes it onward ✅
C.Drop the packet because the ARP entry is missing
D.Broadcast the packet on the LAN
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Because B is on a different network, Host A cannot resolve B’s MAC locally. It therefore sends the IP packet to its default gateway, first looking up the gateway’s MAC via ARP, and the gateway forwards the packet toward B. Option B captures this process. Option A would work only for a same‑network host; Option C is unnecessary as ARP will be performed for the gateway; Option D misuses broadcasting, which is not used for routing to remote networks.

Q3. A server frequently accesses a backup server. To improve performance, the admin pins the backup server’s entry in the ARP cache. What is the primary benefit of pinning this entry?

A.It prevents the MAC address from changing, ensuring consistent routing
B.It eliminates the need for ARP requests for that address, reducing latency ✅
C.It forces the server to use a static IP address
D.It disables DHCP for that host
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Pinning locks the IP‑to‑MAC mapping in the cache, so the server never has to broadcast an ARP request each time it sends data, cutting down on delay and network chatter. Option B states this benefit. Option A is not the main effect; MAC addresses generally do not change often. Option C confuses IP configuration with ARP caching, and Option D incorrectly suggests DHCP control, which is unrelated to ARP entries.

Q4. Host X has an ARP cache entry mapping IP 203.0.113.20 to MAC AA:BB:CC:DD:EE:FF. The actual device with that IP has been replaced, but the stale entry remains. Host X attempts to retrieve a file from the new device. What is the most likely outcome?

📖 Explanation: Since the cached MAC points to the old hardware, the frame is sent to that MAC address, which no longer corresponds to the intended host, so the transfer fails. Option B reflects this result. Option A is incorrect because routers do not rewrite the Ethernet source MAC for end‑to‑end delivery. Option C assumes a timeout mechanism that may not trigger immediately; many systems rely on higher‑level protocols to detect failures. Option D would only happen if the MAC were unknown, not when a stale entry exists.

Options B, C, and D describe unrelated mechanisms: pinning does not create a separate routing table, does not affect DNS resolution, and applies to IPv4 ARP, not exclusively IPv6.

Q9. A host on a LAN needs to send a packet to another host whose MAC address is not in its ARP cache. What should the host do first?

A.Use the stale entry and send the packet anyway. ✅
B.Broadcast an ARP request to learn the correct MAC address.
C.Send the packet to the default gateway.
D.Wait for the destination host to initiate contact.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The correct action is to broadcast an ARP request because the host lacks a valid IP‑to‑MAC mapping. An ARP request asks all devices on the local segment to identify the MAC address associated with the target IP, allowing the sender to update its cache and deliver the packet. Using a stale entry (option A) risks sending to the wrong address, sending to the gateway (option C) is unnecessary on the same LAN, and waiting (option D) would delay communication. This behavior matches how Ethernet devices resolve unknown addresses in real networks.

Q10. What is the primary purpose of an ARP cache in an Ethernet network?

A.Store IP‑to‑MAC address mappings for quick lookup.
B.Translate domain names to IP addresses. ✅
C.Encrypt Ethernet frames.
D.Manage routing tables.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The ARP cache exists to keep recent IP‑to‑MAC mappings so a host can retrieve the destination MAC address without broadcasting a new ARP request each time. This speeds up local communication and reduces unnecessary traffic. Translating domain names (option B) is done by DNS, not ARP. Encryption (option C) is unrelated to ARP’s function, and routing tables (option D) are handled by the IP layer. By caching these mappings, real‑world devices achieve faster packet delivery on LANs while limiting broadcast overhead.

Q11. A network administrator pins ARP entries for a set of frequently accessed servers. Which immediate benefit is most likely to be observed on the client machines?

A.Lower CPU utilization on the client. ✅
B.Reduced latency for connections to those servers.
C.Increased security against ARP spoofing.
D.Higher bandwidth availability.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Pinning ARP entries means the client already knows the MAC addresses of the target servers, so it can skip the ARP request step each time it initiates a connection. Skipping this broadcast reduces the time needed to resolve the address, which appears as lower latency for the first packets of a session. CPU usage (option A) is not noticeably affected, and pinning does not add security (option C) – in fact it can make spoofing easier. Bandwidth (option D) is unchanged because the ARP traffic saved is minimal compared with data traffic. Thus the most direct effect is reduced latency.

Q12. How does the aging mechanism of an ARP cache contribute to overall network stability?

A.It prevents duplicate IP addresses on the network. ✅

C.It accelerates DNS lookups.
D.It encrypts ARP packets.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: ARP cache entries have a lifetime after which they are discarded. This aging process ensures that if a device changes its MAC address or leaves the network, old entries are not used indefinitely, which would otherwise cause packets to be sent to the wrong hardware address. By clearing stale mappings, the network avoids misdelivery and reduces the chance of communication failures. ARP aging does not manage IP address duplication (option A), speed up DNS (option C), or provide encryption (option D). In practice, aging keeps local address resolution accurate, supporting stable LAN operation.

Q13. When a packet destined for a remote network reaches the destination router, which device uses its ARP cache to deliver the packet to the final host?

B.The intermediate router on the path.
C.The destination router on the remote network.
D.The final host itself.

📖 Explanation: When the packet arrives at the remote network’s edge, the destination router must place it onto the local Ethernet segment. To do that it needs the MAC address of the final host, which it looks up in its ARP cache if a recent entry exists, otherwise it sends an ARP request. The source host (option A) already sent the packet to the router, and intermediate routers (option B) work at the IP layer and do not require Ethernet addresses of end hosts. The final host (option D) merely receives the packet. Thus the destination router uses its ARP cache.

As the number of pinned entries grows, the switch may run out of space for other critical tables, leading to evictions or slower lookup times. While each entry is small, the cumulative effect on a constrained device can be noticeable. The action does not directly improve security (option C) nor does it lower latency for unrelated traffic (option D). Q16. Why does the Ethernet header often change when a packet is forwarded by a router, while the payload remains unchanged?

A.The router encrypts the header for each hop. ✅
B.Each link‑layer segment requires its own source and destination MAC addresses.
C.The payload is rewritten at each hop to include routing information.
D.Ethernet headers are immutable and never change.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: When a router forwards a packet, it builds a new Ethernet frame for the next hop. The new frame must contain the router’s outgoing interface MAC as the source and the MAC of the next device as the destination, so the Ethernet header changes. The IP payload stays the same because routing decisions are made at the IP layer, not the data‑link layer. Encryption of the header (option A) and rewriting the payload (option C) do not happen in normal forwarding, and Ethernet headers are not immutable (option D). Thus the header changes to reflect link‑layer addresses.

Q17. Host A wants to send data to a local device but its ARP cache lacks an entry for the destination IP. What will Host A do next?

A.Drop the packet
B.Broadcast an ARP request for the IP ✅
C.Send the packet to the default gateway
D.Perform a DNS lookup
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When the IP‑to‑MAC mapping is missing, the host cannot address the Ethernet frame, so it issues a broadcast ARP request asking, “Who has this IP?” All devices on the LAN receive the request, and the owner replies with its MAC address. This allows the host to fill its ARP cache and transmit the packet. Dropping the packet would halt communication, sending to the gateway is only for off‑network destinations, and DNS resolves domain names, not MAC addresses. The broadcast ARP behavior is standard in Ethernet networks.

Q18. What is the typical size, in bits, of an Ethernet MAC (Media Access Control) address?

D.128 bits
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: An Ethernet MAC address uniquely identifies a network interface and is defined by the IEEE standard as a 48‑bit identifier. Q20. In a network with two subnets separated by a router, Host A wishes to send a packet to Host B on the other subnet. Which device’s ARP cache will be consulted first by Host A?

Dropping the packet silently would be inefficient, and TTL expiration concerns only routing hops, not link‑layer address resolution.

Q22. How does increasing the size of an ARP cache affect performance in a large local area network?

Fewer broadcasts reduce network congestion and speed up packet delivery. While an excessively large cache could consume memory, typical system resources handle reasonable sizes without issue. Therefore, the primary effect is a performance gain, not a degradation or security change.

Q23. An administrator pins ARP entries for a server that processes 10,000 requests per second. After the server’s NIC is replaced, its MAC address changes. What immediate effect will clients with pinned entries experience?

📖 Explanation: Pinned ARP entries prevent the client from issuing new ARP requests, so the stored MAC address remains unchanged even after the server’s NIC replacement. Consequently, frames are addressed to the old MAC, which no longer belongs to the server, resulting in failed delivery and loss of communication. Manual cache clearance or a DHCP update would be required to restore connectivity; routers do not intervene at the link‑layer address level.

Q24. Which statement best describes the relationship between an ARP cache in Ethernet networks and a routing table in IP networks?

A.Both store next‑hop information for packet forwarding
B.The ARP cache stores MAC addresses for IPs, while the routing table stores next‑hop IP addresses
C.The ARP cache replaces the need for a routing table
D.The routing table is a subset of the ARP cache entries ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: The ARP cache operates at Layer 2, mapping each known IP address to its corresponding MAC address so frames can be addressed on the local link. In contrast, the routing table works at Layer 3, determining the next‑hop IP address (or interface) for packets destined for remote networks. Thus, the ARP cache and routing table serve complementary but distinct purposes: one resolves link‑layer addresses, the other resolves network‑layer paths. They do not replace each other, nor is one a subset of the other.

Q30. An ARP cache entry is pinned for a host that later changes its network interface card, acquiring a new MAC address. What is the most likely immediate effect on communication?

If the host’s MAC changes, the pinned entry still points to the old address, so frames are sent to a non‑existent MAC and are dropped. Communication therefore fails until an administrator intervenes and clears or updates the entry. Automatic rerouting does not occur, and routers do not modify pinned entries without explicit action.

Q31. Explain how a router’s ARP cache interacts with the cache‑update policy of downstream switches when a packet traverses multiple Ethernet segments.

📖 Explanation: Both routers and switches maintain separate ARP caches, each governed by its own timeout or update rules. When a router learns a next‑hop MAC address, it stores it locally; downstream switches independently learn the same MAC via their own ARP processes. There is no automatic synchronization of timeouts, so each device may expire or refresh entries at different moments, which can lead to temporary inconsistencies but does not require coordinated updates.

Q32. A cache timeout is set to 60 seconds. Host X moves to a new subnet after 30 seconds. How many ARP requests will the original subnet’s router generate before the stale entry expires?

Because the entry is still valid (timeout not reached), the router will send the frame to the old MAC and receive no response. Detecting the failure, it will issue a new ARP request to resolve the current MAC. This results in exactly one additional ARP request before the 60‑second timeout finally discards the stale entry.

Q33. Why do routers maintain their own ARP caches even though they operate at layer 3?

Keeping a local cache avoids repeated ARP broadcasts for the same next hop, speeding up forwarding. DNS storage, encryption, and VLAN tagging are unrelated to the router’s need to map IP addresses to MAC addresses on its attached links.

Q34. A network uses a 120‑second ARP cache timeout. After a security breach, an attacker spoofs the MAC address of a critical server. Which cache‑update policy would most quickly mitigate the spoofing risk?

📖 Explanation: A validation mechanism that monitors for anomalous ARP activity and flushes suspect entries immediately removes the malicious mapping, limiting the window for exploitation. Extending the timeout or pinning the entry would preserve the spoofed address, worsening the problem. Disabling ARP caching would force a broadcast for every lookup, which is inefficient and still vulnerable to immediate spoofing. Therefore, dynamic validation is the fastest mitigation.

C.Advanced Resource Pointer
D.Application Relay Program
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The acronym ARP expands to Address Resolution Protocol, which is the mechanism used to map a known IP address to its corresponding MAC address on a local Ethernet segment. Options B, C, and D are invented phrases that do not describe any standard networking function, so they are incorrect. Recognizing the full name helps students recall that ARP operates at the data‑link layer and is essential when troubleshooting connectivity issues, because a missing or wrong ARP entry can prevent frames from reaching their intended destination.

Q39. A workstation needs to send data to a server located on a different network. Which device is responsible for forwarding the packet toward the destination network?

A.Switch
B.Router ✅
C.Hub
D.Repeater
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Routers operate at the network layer and forward packets between different subnets, so option B is correct. Switches (A) operate at the data‑link layer and only forward frames within the same LAN. Hubs (C) and repeaters (D) are physical‑layer devices that merely repeat signals and cannot make routing decisions. In real deployments, the router determines the next hop toward the remote server.

Q40. When a packet travels through multiple routers, why does the data‑link‑layer header often change while the higher‑layer headers remain the same?

A.Routers encrypt the payload
B.Each router replaces source/destination MAC addresses for the next hop ✅
C.The IP header is rewritten at each hop
D.The Ethernet type field is altered to indicate routing
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Each router discards the incoming Ethernet frame and builds a new one with MAC addresses appropriate for the next link, while the IP header and payload stay unchanged. Therefore option B is correct. Routers do not encrypt payloads as a routine action, so A is wrong. The IP header is only adjusted for TTL and routing metrics, not completely rewritten, making C inaccurate. The Ethernet type field remains constant to indicate the encapsulated protocol, so D is incorrect. This process preserves end‑to‑end consistency of higher‑layer data while allowing each hop to deliver the frame correctly.

Q41. A router’s ARP cache is full and a new host on the same LAN needs its MAC address resolved. Which mechanism allows the router to learn the new address?

A.Increase cache size
B.Use static ARP entries
C.Evict the least‑recently‑used entry after its timeout expires ✅
D.Disable ARP entirely
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: When the cache reaches capacity, the router removes the entry that has not been used recently once its timeout expires, freeing space for the new ARP reply—option C describes this standard behavior. Simply increasing the cache size (A) is not a dynamic solution and may not be feasible. Static entries (B) require manual configuration and do not address the dynamic need. Disabling ARP (D) would break address resolution altogether. In operational networks, cache eviction ensures fresh mappings while preserving consistency.

Q42. If an administrator pins an ARP entry for a heavily used host, how does this affect the consistency of address resolution across the network?

A.It guarantees the entry never expires, preventing stale mappings ✅
B.It forces the router to broadcast ARP requests for every packet
C.It allows the entry to be overwritten by newer information
D.It removes the need for DNS lookups
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Pinning an ARP entry keeps it fixed in the cache, so it never expires and avoids the risk of a stale mapping—option A is correct. Broadcasting ARP requests for every packet (B) would cause unnecessary traffic and is not the effect of pinning. Pinning does not allow overwriting (C); the entry remains locked. DNS lookups (D) operate at a different layer and are unrelated to ARP pinning. Consistent MAC resolution is crucial for high‑traffic hosts, and pinning provides that stability.
