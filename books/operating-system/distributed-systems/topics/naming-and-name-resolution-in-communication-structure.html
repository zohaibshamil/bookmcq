📝 Naming and name resolution in Communication Structure

📖 From Operating System • 17. Distributed Systems • 23 questions available

What is Naming and name resolution in Communication Structure?

Definition:
Naming and name resolution map human-readable identifiers to network addresses or object references, functioning as \( \text{name} \rightarrow \text{address} \) binding.

Example:
DNS translating 'www.example.com' to IP address 192.0.2.1 before establishing HTTP connection.

Reason:
Abstraction through naming decouples service identity from physical location, enabling mobility, replication, and flexible reconfiguration without client changes.

Q1. What is the transfer rate of a T1 line?

A. \(1.544\) Mbps ✅
B. \(45\) Mbps
C. \(622\) Mbps
D. \(40\) Gbps

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A T1 line carries data at \(1.544\) megabits per second, which is the standard rate defined for T1 services. The other options describe higher‑speed technologies: T3 provides \(45\) megabits per second, OC‑12 offers \(622\) megabits per second, and backbone links can reach \(40\) gigabits per second. Knowing the exact rate helps students choose the appropriate line for bandwidth‑critical applications.

Q2. Which WAN technology aggregates twenty‑eight T1 lines to achieve a higher bandwidth?

A. T1
B. Ethernet
C. T3 ✅
D. OC-12

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

A T3 is formed by combining twenty‑eight T1 circuits, resulting in a total capacity of \(45\) megabits per second. T1 alone provides only \(1.544\) megabits per second, Ethernet is a LAN technology, and OC‑12 is an optical carrier that supplies \(622\) megabits per second. Recognizing the aggregation concept is essential for designing networks that need more throughput than a single T1 can deliver.

Q3. Why are WAN connections generally slower than LAN connections, even though some backbone WAN links can exceed \(40\) Gbps?

A. Because of longer physical distances and more routing devices ✅
B. Because WAN uses lower‑quality cables
C. Because LAN uses wireless only
D. Because WAN has fewer users

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

WAN links must traverse longer distances, often passing through multiple routers, switches, and protocol converters, which adds latency and reduces effective throughput. In contrast, LANs are confined to a single building or campus, allowing high‑speed media and minimal hops. Even though some backbone WANs can reach very high speeds, typical WAN segments still experience slower rates than LANs due to these distance‑related constraints.

Q4. How does name resolution differ between a local LAN environment and a wide‑area network that spans multiple administrative domains?

A. LAN uses broadcast ARP while WAN relies on hierarchical DNS ✅
B. LAN uses DNS only
C. WAN uses ARP only
D. Both use the same method

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

In a LAN, devices often resolve names using broadcast ARP, which works because all hosts share the same broadcast domain. Across a WAN, broadcast traffic cannot cross routers, so hierarchical DNS servers are used to translate names to addresses. This distinction ensures scalability and prevents broadcast storms. The other options mischaracterize the protocols: LANs also use DNS, WANs do not rely on ARP for name resolution, and the methods are not identical.

Q5. In the context of distributed systems, what is the primary advantage of using a hierarchical naming scheme for resources across a WAN?

A. Reduces lookup latency
B. Eliminates need for routing
C. Ensures unique names globally ✅
D. Simplifies hardware design

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

A hierarchical naming scheme assigns names that reflect the resource’s position in the network, guaranteeing global uniqueness without collisions. While it may not directly reduce lookup latency, it enables organized DNS zones that can be delegated to regional servers, improving scalability. It does not eliminate routing or hardware concerns, but it does provide a clear structure for administrators to manage large, dispersed environments.

Q6. What role does a communication processor (CP) play in a WAN architecture that includes multiple communication subsystems?

A. It directly processes user application data
B. It routes packets between networks and handles protocol conversion ✅
C. It provides power supply
D. It stores user files

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A communication processor acts as an intelligent forwarding element that moves packets across different network segments and translates between protocols such as T1, T3, or OC‑12. It does not execute application‑level code, supply power, or serve as storage. By handling routing and conversion, the CP enables heterogeneous WAN components to interoperate, which is crucial for maintaining end‑to‑end connectivity.

Q7. Why might a company choose to implement a private WAN instead of relying solely on the public Internet?

A. To increase latency
B. To improve security, performance, and reliability ✅
C. To reduce bandwidth
D. To avoid using routers

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A private WAN gives the organization control over routing policies, encryption, and quality‑of‑service mechanisms, leading to better security, higher performance, and more reliable service than the public Internet can guarantee. Increased latency would be a disadvantage, not a benefit, and bandwidth is typically higher on dedicated links, not lower. Routers are still needed in a private WAN to direct traffic.

Q8. How does the aggregation of multiple T1 lines into a T3 affect the naming and addressing of the resulting logical link?

A. It creates a new IP subnet
B. It retains the same MAC address
C. It uses a composite identifier managed by higher‑level protocols ✅
D. It requires no change

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When several T1 circuits are combined into a T3, the logical link is treated as a single high‑capacity channel. Higher‑level protocols (e.g., MPLS or IP) assign a composite identifier to the aggregated link, while the underlying physical identifiers (such as MAC addresses) may remain unchanged. The link does not automatically generate a new IP subnet, nor does it keep the exact same MAC for all constituent circuits.

Q9. Explain how the concept of “name resolution” interacts with routing decisions in a network that includes both LAN and WAN segments, such as a cellular data network.

A. Name resolution occurs after routing
B. Routing decisions are made before name resolution
C. Both processes are independent
D. Name resolution informs routing tables directly ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Name resolution provides the IP address that routing algorithms need to forward packets, so the resolved address must be known before a router can select the appropriate next hop. In practice, a device queries DNS (or another naming service) first, then uses the returned address to perform routing across LAN and WAN segments. The other statements invert the order or claim independence, which contradicts how IP forwarding relies on resolved addresses.

Q10. A small business needs a connection that provides at least \(45\) Mbps for video conferencing. Which technology from the list should they select?

A. T1
B. T3 ✅
C. OC-12
D. Ethernet over phone line

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A T3 line is built from twenty‑eight T1 circuits and delivers a total bandwidth of \(45\) megabits per second, matching the business’s requirement for video conferencing. T1 offers only \(1.544\) megabits per second, which is insufficient. OC‑12 provides a much higher rate of \(622\) megabits per second, which would be overkill and more costly. Ethernet over a phone line cannot achieve the needed speed.

Q11. An engineer must design a naming scheme for devices across three regional offices connected via a WAN. Which approach best ensures unique names while allowing local admin?

A. Flat naming with random strings
B. Hierarchical naming using office codes as prefixes ✅
C. Use only MAC addresses
D. Centralized DNS without subdomains

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Hierarchical naming adds a prefix that identifies the office (e.g., nyc‑printer01), guaranteeing global uniqueness while enabling each region to manage its own namespace. Flat random names can collide, MAC addresses are hardware‑specific and not user‑friendly, and a single centralized DNS without subdomains makes delegation and local control difficult.

Q12. A network admin observes that devices on a LAN can resolve each other's names instantly, but devices across the WAN experience delays. Which change is most likely to reduce the delay?

A. Increase T1 bandwidth
B. Deploy a distributed DNS cache in each region ✅
C. Replace routers with switches
D. Disable ARP

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Placing DNS caching servers closer to each WAN segment reduces the round‑trip time for name queries, cutting latency. Simply increasing bandwidth does not address name‑resolution latency, and switches cannot replace routers for inter‑network traffic. Disabling ARP would break local address resolution and is unrelated to WAN name‑resolution delays.

Q13. If a T3 line composed of 28 T1 connections fails, what is the most effective way to maintain partial service while repairing the line?

A. Shut down the entire link
B. Reroute traffic through remaining functional T1 channels ✅
C. Convert T1 to OC-12
D. Use wireless backup

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When part of a T3 fails, the remaining operational T1 circuits can still carry traffic, so the network should reroute data through those active channels to preserve service. Turning off the whole link would cause a total outage, and converting T1 to OC‑12 is not feasible without additional equipment. Wireless backup may be an option but is generally slower and less reliable than using the surviving T1 circuits.

Q14. A mobile user moves from one cellular tower to another. How should the naming system handle the user's IP address to avoid interruption?

A. Keep the same IP address using Mobile IP ✅
B. Assign a new IP each tower
C. Use MAC address only
D. Disable name resolution

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Mobile IP allows a device to retain its original IP address while changing its point of attachment, providing seamless connectivity during handoffs between towers. Assigning a new IP at each tower would break ongoing sessions, and MAC addresses are not routable across IP networks. Disabling name resolution would prevent any network communication.

Q15. A company wants to prioritize voice traffic over a WAN that uses OC-12 links. Which technique should they implement at the naming resolution layer?

A. DNS weighting
B. QoS tagging based on service names ✅
C. Increase bandwidth
D. Change MAC addresses

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Quality‑of‑Service (QoS) tags can be attached to packets based on the resolved service name (e.g., VoIP), ensuring voice packets receive priority handling across the WAN. DNS weighting influences resolution order but does not affect packet priority. Simply increasing bandwidth does not guarantee voice quality, and MAC address changes have no effect on WAN‑level QoS.

Q16. An enterprise network uses a private WAN with multiple T3 links and an OC-12 backbone. A new data center requires a unique identifier that reflects its position in the hierarchy. Which naming format best satisfies this requirement?

A. Flat numeric ID
B. Hierarchical ID like region.site.datacenter ✅
C. Random UUID
D. MAC address of the first router

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A hierarchical identifier (e.g., us‑east‑site1‑dc2) encodes the data center’s location within the network, making it easy to locate, manage, and apply policies. A flat numeric ID or random UUID lacks contextual information, and a MAC address is hardware‑specific and unsuitable for logical naming across a WAN.

Q17. A distributed application must locate a remote service across a WAN that may traverse both LAN and cellular segments. Which sequence of steps correctly uses naming and routing to reach the service?

A. Resolve name locally, then route across WAN ✅
B. Route first, then resolve name
C. Simultaneously resolve and route
D. Skip name resolution

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The client first queries a DNS (or similar) service to obtain the service’s IP address, then uses routing protocols to forward packets across LAN, WAN, and cellular segments. Routing cannot occur without an address, and simultaneous resolution and routing is not feasible. Skipping name resolution would require the user to know the exact IP, which defeats the purpose of a naming system.

Q18. During a network upgrade, an engineer replaces several T1 lines with a single OC-12 link. How does this change affect the naming resolution process for devices previously reachable via the T1 network?

A. Names must be re‑registered in a new DNS zone
B. No change needed because IP addresses remain ✅
C. MAC addresses must be rewritten
D. All devices lose connectivity

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The underlying physical transport changes from T1 to OC‑12, but the logical IP addressing scheme can stay the same, so existing DNS records remain valid. Only the transport layer details differ. Changing DNS zones or MAC addresses is unnecessary, and connectivity is preserved if routing is updated.

Q19. A telecom provider offers both T3 and OC-12 services. A customer needs a connection that guarantees at least \(622\) Mbps but also wants the flexibility to scale to \(40\) Gbps. Which service should the provider recommend and why?

A. T3 because it meets \(622\) Mbps
B. OC-12 because it provides \(622\) Mbps and can be aggregated for higher speeds ✅
C. T1 because it is cheap
D. Ethernet because it is wireless

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

OC‑12 delivers \(622\) megabits per second and can be combined with additional OC‑12 or higher‑order optical carriers to reach tens of gigabits per second, satisfying both the current and future bandwidth needs. T3 caps at \(45\) megabits per second, which is far below the requirement, while T1 is even slower and Ethernet over wireless cannot guarantee the needed rates.

Q20. A residential user connects to the Internet via a cable modem that provides a downstream rate of \(45\) Mbps. Which term best describes this connection type?

A. T1
B. T3
C. OC-12
D. Cable broadband ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

Cable broadband uses hybrid fiber‑coaxial infrastructure to deliver high‑speed Internet, often around \(45\) megabits per second for downstream traffic. T1 and T3 refer to telephony‑based leased lines with different capacities, and OC‑12 is an optical carrier offering much higher speeds. The description matches typical cable broadband service.

Q21. In a scenario where a LAN uses broadcast ARP for name resolution, but the network is extended over a WAN, what mechanism replaces broadcast ARP to resolve names efficiently?

A. DNS ✅
B. DHCP
C. NAT
D. ICMP

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When a network spans a WAN, broadcast ARP cannot cross routers, so DNS is employed to translate hostnames to IP addresses across the larger topology. DHCP assigns addresses but does not resolve names, NAT modifies address translation, and ICMP is used for control messages, not name resolution.

Q22. A cloud service provider assigns virtual machines names that include the region and zone identifiers. How does this naming convention help with fault isolation across WAN links?

A. It allows routing protocols to avoid faulty zones
B. It enables administrators to quickly locate and isolate problems ✅
C. It reduces bandwidth usage
D. It eliminates the need for DNS

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Including region and zone in VM names gives administrators immediate context about where a machine resides, making it easier to pinpoint and isolate faults that may be confined to a specific WAN segment. Routing protocols do not use these names directly, and the naming scheme does not affect bandwidth or remove the necessity for DNS.

Q23. Consider a distributed file system that relies on a global naming service to locate replicas across multiple WANs. If a WAN segment experiences a latency increase from \(1.544\) ms to \(45\) ms per hop, what impact does this have on the system’s name resolution performance, and what mitigation strategy should be employed?

A. Ignore the latency because naming is instant
B. Deploy caching name servers closer to each WAN segment ✅
C. Reduce the number of replicas
D. Switch to MAC‑based resolution

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Higher per‑hop latency dramatically slows DNS queries across the WAN, increasing the time to locate file replicas. Deploying regional caching name servers brings the resolution service nearer to clients, reducing query round‑trip time and preserving system responsiveness. Ignoring the latency is unrealistic, reducing replicas harms availability, and MAC‑based resolution is not feasible across IP networks.
