Q1. What is the term used to describe the reduction in execution time when a task is divided among multiple processors in a distributed system?

A.Computation speedup
B.Load balancing
C.Fault tolerance ✅
D.Latency hiding
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Computation speedup refers to the decrease in total execution time achieved by distributing a workload across several processors. It is distinct from load balancing, which merely spreads work evenly, and from fault tolerance or latency hiding, which address reliability and response time, respectively. By parallelizing work, the overall job finishes faster, which is the core idea of speedup. Therefore the correct answer is Computation speedup, while the other options describe different system properties.

Q2. Why does adding more nodes to a distributed system not always result in proportional computation speedup?

A.Because processors become faster
B.Because memory increases
C.Because of better security
D.Because of communication overhead ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The primary limiting factor is the communication overhead that grows as more nodes exchange data. Even if each node can process its share quickly, the time spent sending and receiving messages can offset the gains, preventing a linear speedup. Options about faster processors, more memory, or better security describe unrelated improvements and therefore do not explain the slowdown. Hence the correct choice highlights communication overhead as the key constraint.

Q3. According to Amdahl's law, if 30% of a program cannot be parallelized, what is the maximum theoretical speedup achievable regardless of the number of nodes?

A.1.43
B.2
C.3.33 ✅
D.5
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Amdahl's law states that the overall speedup S = 1 / ( (1‑p) + p/N ), where p is the parallelizable fraction and N is the number of nodes. When N approaches infinity, the term p/N becomes zero, leaving S = 1 / (1‑p). With 30% non‑parallelizable (1‑p = 0.3), the maximum speedup is 1 / 0.3 = 3.33. The other numbers arise from incorrect calculations or ignoring the serial portion, so the correct answer is 3.33.

Q4. A task takes 1000 seconds on a single node. If 80% of the work can be parallelized and communication adds 0.1 seconds per node, what is the total execution time using 5 nodes?

A.260.5 seconds
B.360.5 seconds ✅
C.460.5 seconds
D.560.5 seconds
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: First separate the work: the sequential part is 20% × 1000 = 200 s, and the parallel part is 80% × 1000 = 800 s. Dividing the parallel portion among 5 nodes yields 800 / 5 = 160 s. Adding the sequential 200 s gives 360 s, then include the communication overhead of 0.1 s × 5 = 0.5 s, resulting in 360.5 s total. The other options mis‑add or mis‑divide the components, making B the correct choice.

Q5. A company wants at least a 4× speedup for a job where 70% of the work is parallelizable. Which statement is correct?

A.At least 8 nodes are required
B.Exactly 4 nodes will achieve the goal
C.Not possible regardless of the number of nodes ✅
D.At least 10 nodes are required
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Using Amdahl's law, the speedup S = 1 / (0.3 + 0.7/N). To reach S ≥ 4, the denominator must be ≤0.25, which would require 0.7/N ≤ ‑0.05—an impossible condition because the term cannot be negative. Therefore no amount of nodes can provide a 4× speedup when 30% of the program is serial. The other options assume feasible node counts, which contradict the mathematical limit, so the correct answer states the goal cannot be met.

Q7. Which factor most directly limits the scalability of computation speedup in a distributed system?

A.Network bandwidth
B.Serial fraction of the program ✅
C.Number of CPUs
D.Disk I/O
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The serial fraction—code that must run sequentially—sets a hard ceiling on speedup according to Amdahl's law, because no amount of additional processors can accelerate that part. While network bandwidth, CPU count, and disk I/O affect performance, they are secondary to the inherent sequential portion, which directly caps how much total execution time can be reduced. Thus the serial fraction is the primary limiting factor.

Q8. A task that takes 200 seconds on one machine is 60% parallelizable. Using two identical nodes with negligible communication overhead, what is the expected execution time?

A.120 seconds
B.140 seconds ✅
C.160 seconds
D.180 seconds
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Separate the workload: 40% remains sequential (0.4 × 200 = 80 s) and 60% is parallel (0.6 × 200 = 120 s). The parallel portion is split evenly between two nodes, giving 120 / 2 = 60 s. Adding the sequential 80 s results in a total of 140 seconds. The other options either ignore the parallel division or mis‑calculate the sequential share, so 140 seconds is the correct execution time.
