📝 All Advantages of Distributed Systems MCQs

Q1. A small business has a single laser printer at site B, but employees at site A need to print documents. Which advantage of a distributed system enables this remote printing capability?

A.Resource sharing ✅
B.Computation speedup
C.Reliability
D.Communication
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Resource sharing allows a user at one site to use devices located at another site, such as a printer. In the scenario, employees at site A can send jobs to the laser printer at site B because the system shares that resource across the network. Option A describes this advantage, making it correct. Options B, C, and D refer to speedup, fault tolerance, and data exchange, which do not directly enable remote printing. Thus, resource sharing is the key benefit that solves the problem.

Q2. Why does computation speedup occur when tasks are executed across multiple nodes in a distributed system?

A.Centralized processing
B.Parallel execution of tasks across nodes ✅
C.Reduced network traffic
D.Increased storage capacity
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Parallel execution of tasks across multiple nodes leads to computation speedup because work is divided and processed simultaneously. When a distributed system runs parts of a program on different machines, the overall execution time can be reduced dramatically. Option B states this mechanism, so it is correct. Option A suggests centralized processing, which would actually slow down performance. Option C mentions reduced network traffic, which is unrelated to speedup, and Option D refers to increased storage, which does not affect computation time. Therefore, parallel execution is the primary cause of speedup.

Q3. What term denotes the physical location of a machine in a distributed system?

A.Node
B.Host
C.Site ✅
D.Processor
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: In distributed computing terminology, the term that identifies the physical location of a machine is “site.” A site denotes where a node or host is situated, distinguishing it from the node itself, which refers to the system at that location. Option C correctly names this term. Options A and B describe the node and host, which are different concepts, while Option D, processor, refers to the internal component rather than the location. Hence, “site” is the appropriate answer for the definition of a machine’s location.

Q4. An application requires 48 hours on a single computer. If the workload is evenly divided among eight identical nodes with linear speedup, how many hours will the job take?

A.6 hours ✅
B.8 hours
C.12 hours
D.24 hours
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: If a task requiring 48 hours on a single machine is divided equally among eight identical nodes, the ideal (linear) speedup reduces the execution time to 48/8=648/8 = 648/8=6 hours. This assumes no overhead and perfect parallelism. Option A reflects this calculation, making it correct. Option B (8 h) would result from a slower speedup, Option C (12 h) represents a half‑speedup, and Option D (24 h) would be a modest improvement. Therefore, the linear division predicts a six‑hour completion time.

Q5. How does reliability improve when several nodes can provide the same service in a distributed system?

A.Increased latency
B.Failover capability ✅
C.Higher cost
D.Reduced security
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Reliability in a distributed system is enhanced when multiple nodes can provide the same service, allowing the system to switch to a backup node if one fails. This failover capability ensures continuous operation. Option B describes this mechanism, so it is correct. Option A mentions increased latency, which is a performance issue, not reliability. Option C suggests higher cost, which is a drawback, and Option D refers to reduced security, which does not describe reliability. Hence, failover capability is the primary way reliability is achieved.

Q6. A company’s database is hosted at site A, while sites B and C run application and backup servers respectively. If site A fails, which advantage and mechanism keep the service running?

A.Reliability with replication ✅
B.Computation speedup with load balancing
C.Resource sharing with remote printing
D.Communication with message passing
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: When site A, which hosts a critical database, fails, the distributed system’s reliability advantage ensures that services continue through replication of data on other sites. Replication creates copies of the database on backup servers, so the application can read from or write to an alternate node without interruption. Option A correctly identifies reliability with replication as the mechanism. Options B, C, and D describe other advantages—speedup, remote printing, and messaging—but they do not address fault tolerance. Thus, replication provides the needed continuity.

Q7. Which statement correctly distinguishes the communication advantage from the resource‑sharing advantage in a distributed system?

A.Communication focuses on security, while resource sharing focuses on redundancy
B.Communication focuses on latency, while resource sharing focuses on cost
C.Communication focuses on data exchange between nodes, while resource sharing focuses on using remote hardware ✅
D.Communication focuses on synchronization, while resource sharing focuses on data storage
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Communication and resource sharing are distinct advantages. Communication primarily concerns the exchange of messages, data, and coordination between nodes, enabling them to work together. Resource sharing, on the other hand, focuses on using hardware or data located at remote sites, such as printers or files. Option C captures this distinction by stating that communication deals with data exchange while resource sharing involves remote hardware usage. Options A and B mix concepts incorrectly, and Option D misattributes latency and cost, so they are wrong.

Q8. An e‑commerce site distributes order processing across many servers to handle traffic spikes. Which advantage primarily enables the system to cope with sudden load increases?

A.Resource sharing
B.Reliability
C.Communication
D.Computation speedup ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: During periods of high traffic, an e‑commerce platform can distribute order‑processing tasks across several servers, allowing many requests to be handled at once. This leverages the computation speedup advantage, which reduces response time by parallelizing work. Option D correctly identifies computation speedup as the key benefit. Resource sharing (Option A) relates to using remote devices, reliability (Option B) to fault tolerance, and communication (Option C) to data exchange—none directly address handling traffic spikes. Hence, speedup is the primary advantage for peak loads.
