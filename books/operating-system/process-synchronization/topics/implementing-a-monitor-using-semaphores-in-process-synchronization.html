Q1. What is the initial value of the mutex semaphore used in implementing a monitor?

📖 Explanation:

The mutex semaphore is initialized to 1 to allow the first process to enter the monitor. A binary semaphore with value 1 ensures mutual exclusion, as only one process can decrement it to 0 and enter, while others must wait.

Q2. Which operation must a process execute before entering the monitor in the semaphore-based implementation?

🔹 D. wait(next)

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A process must execute wait(mutex) before entering the monitor. This decrements the mutex semaphore from 1 to 0, blocking other processes from entering and ensuring mutual exclusion within the monitor.
