What is Peterson's Solution?

Definition:
Peterson's solution is a software-based algorithm for two-process mutual exclusion using shared variables turn turn turn and flag[2] flag[2] flag[2] to enforce critical section entry without hardware support.

Example:
Process P0 P_0 P0​ sets flag[0]=true flag[0]=true flag[0]=true and turn=1 turn=1 turn=1, then waits in while(flag[1]∧turn==1) while(flag[1] \land turn==1) while(flag[1]∧turn==1) before entering the critical section.

Reason:
It provides a provably correct software solution demonstrating that mutual exclusion, progress, and bounded waiting can be achieved purely through shared memory algorithms for N=2 N=2 N=2.
