What is The Bounded Buffer Problem in Process Synchronization?

The bounded buffer problem models producer-consumer coordination using three semaphores: \( mutex = 1 \) for buffer access, \( empty = n \) for available slots, and \( full = 0 \) for filled slots, ensuring producers wait when the buffer is full and consumers wait when it is empty while maintaining mutual exclusion.
