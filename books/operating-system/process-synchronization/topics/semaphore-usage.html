What is Semaphore Usage?

Definition:
Semaphore usage involves applying wait() and signal() operations to solve synchronization problems like mutual exclusion and resource management. Proper usage requires initializing semaphores correctly and placing wait/signal calls around critical sections or resource requests to ensure orderly process execution.

Working:
For mutual exclusion, initialize a binary semaphore to 1. Wrap the critical section with wait() and signal(). For resource counting, initialize to N. Processes call wait() before using a resource and signal() after releasing it. This controls access based on availability.

Example:
To protect a shared file, use a binary semaphore `mutex=1`. Process P executes `wait(mutex)`, writes to file, then `signal(mutex)`. Any other process trying to write will block at `wait(mutex)` until P signals, ensuring only one writer at a time.

Reason:
Correct usage prevents race conditions and ensures data consistency. It allows flexible control over resource allocation. By adjusting the initial value, you can limit concurrency to any number, making it suitable for various scenarios from single locks to pool management.

Common MisConceptions:
Students often place signal() inside the critical section, which is incorrect. Signal() must be outside to allow others to enter. Another error is forgetting to initialize semaphores, leading to undefined behavior. Also, swapping wait and signal can cause immediate deadlock.

Exam Preparation Tips: How to prepare this topic
Practice identifying where to place wait() and signal() in code snippets. Solve problems involving multiple resources. Understand the consequences of missing a signal() or adding an extra wait(). Review classical problems to see standard usage patterns.

Key Terms:

  • Mutual Exclusion - using semaphore to allow one process at a time.
  • Resource Counting - using semaphore to manage N resources.
  • Initialization - setting initial semaphore value correctly.

📝 All Semaphore Usage MCQs

Q1. A system uses a counting semaphore initialized to 4 to control access to four identical printers. Three processes acquire permits, and one process finishes printing and releases its permit. Assuming no other operations occur, how many permits are available afterward?

A.0
B.1 ✅
C.2
D.4
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The initial count is 4. Three successful wait operations reduce it to 1, and the completed process performs one signal operation, increasing it to 2. Therefore, two permits are available for other processes.

Q2. A developer uses a semaphore initialized to 1 to protect a shared configuration file. Process P acquires it and begins updating the file. Process Q attempts to acquire it while P is working. What should happen with a correctly implemented blocking semaphore?

A.Q proceeds immediately because reads are harmless
B.Q waits until P releases the semaphore ✅
C.Q resets the semaphore to 1 before proceeding
D.Q enters only if P performs another wait operation
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A semaphore initialized to 1 provides one permit. When P acquires it, no permit remains, so Q must block until a signal operation releases the permit. Allowing Q to enter immediately would defeat the intended mutual exclusion.

Q3. A program creates a semaphore initialized to 0 for a worker that must wait until a producer finishes preparing a data structure. The producer signals once after preparation. What is the main purpose of the initial value?

A.To let the worker consume the data before preparation
B.To ensure the worker waits for the producer's notification ✅
C.To guarantee that the producer executes after the worker
D.To permit two workers to prepare the same structure simultaneously
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A zero-valued semaphore has no available permits, so the worker blocks when it waits. The producer's signal makes a permit available, allowing the worker to continue after the required preparation event.

Q4. A resource pool contains three identical database connections. A counting semaphore begins at 3. Five client processes request connections simultaneously, and each holds a connection until its transaction ends. What property does the semaphore enforce?

A.At most three clients can hold connections simultaneously ✅
B.Exactly three clients must execute every instruction together
C.All five clients receive connections before any transaction finishes
D.A client holding a connection can never be delayed
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The semaphore represents the number of currently available connections. Each successful wait consumes one permit, so no more than three clients can hold connections at once. Additional clients must wait until a connection is released.

Q5. A programmer writes wait(S), performs a shared update, and then signals S. During testing, an exception can occur after wait(S) but before signal(S). What is the principal synchronization risk?

A.The semaphore automatically creates an extra permit
B.Other processes may remain blocked because the permit was never released ✅
C.The semaphore changes into a binary semaphore permanently
D.The shared update becomes atomic even if it contains multiple steps
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: If execution exits the protected region without signaling, the permit remains consumed. Waiting processes may then block indefinitely, even when the resource is no longer in use. Reliable cleanup or structured locking is needed to avoid this failure.

Q6. A program uses a semaphore to ensure that task B starts a calculation only after task A has produced its input. Which arrangement correctly models this dependency when the semaphore starts at 0?

A.A waits, computes, and signals; B waits before reading the input ✅
B.A signals before computing; B reads the input without waiting
C.B signals after reading; A waits before computing
D.Both tasks signal first and then read the input
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The zero initial value prevents B from passing its wait before A announces completion. A computes the input and then signals, enabling B to proceed. Signaling before producing the input would allow B to read incomplete data.

Q7. A system uses a counting semaphore initialized to 5 for a pool of licenses. Seven processes each acquire one license, and none releases a license during the interval. How many processes can be blocked after all possible acquisitions are attempted?

A.0
B.1
C.2 ✅
D.5
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The five available permits allow five processes to acquire licenses. The remaining two processes cannot acquire a permit and must wait, assuming each process requests only one license and no permit is released during this interval.

Q8. A semaphore is intended to protect a shared counter. A programmer checks whether S equals 1 and then separately changes S to 0 before updating the counter. Two processes can interleave these operations. Why is this design unsafe?

A.The counter must always be negative before updating
B.The separate check and update are not atomic, so both processes may enter ✅
C.A semaphore initialized to 1 cannot protect a counter
D.Changing S to 0 makes every later signal operation invalid
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Two processes may both observe S equal to 1 before either changes it to 0. Both can then enter the critical section. A proper semaphore wait operation must perform the test and permit acquisition atomically.

Q9. A server limits active file transfers to four. Its semaphore is initialized to 4. A transfer finishes, but the code signals the semaphore twice by mistake. What is the likely consequence if the implementation permits the count to exceed its intended limit?

A.The server may allow more than four simultaneous transfers ✅
B.All active transfers immediately become mutually exclusive
C.The semaphore count must become exactly zero
D.The extra signal guarantees that no client will wait
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A signal should correspond to releasing a permit that was previously acquired. An unmatched extra signal inflates the available count, potentially allowing more than four transfers to proceed and violating the capacity limit.

Q10. Two tasks must execute in order: task A writes a report, and task B uploads it. The semaphore starts at 0. Which sequence correctly prevents B from uploading an incomplete report?

A.B uploads first, then waits; A writes and signals afterward
B.A signals, then writes; B waits and uploads
C.B waits; A writes the report and signals; B uploads after waking ✅
D.Both tasks wait before either writes or uploads
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: B's initial wait blocks because the semaphore starts at zero. A must finish writing before signaling, so B can only continue after the report is ready. Signaling before writing would not establish the necessary ordering.

Q11. A developer uses one semaphore initialized to 1 for both mutual exclusion and counting available jobs in a queue. Each producer and consumer waits on this same semaphore before accessing the queue. What is the central design flaw?

A.A semaphore can never be initialized to 1
B.The same permit is being used for distinct conditions, so job availability is not represented correctly ✅
C.A queue must always use a semaphore initialized to its capacity
D.Consumers should signal only when the queue is empty
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Mutual exclusion and job availability are separate synchronization requirements. A single semaphore used indiscriminately cannot reliably express both exclusive access and whether work exists. A sound design separates queue protection from the count of available jobs.

Q12. A monitoring graph shows the available permits for a pool falling from 8 to 5, remaining at 5, then rising to 7. No permits are created or destroyed except through wait and signal operations. Which net activity occurred across the entire interval?

A.Five more waits than signals
B.Three more signals than waits
C.One more wait than signal ✅
D.Equal numbers of waits and signals
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The count falls from 8 to 5 and then rises to 7, so the overall change is 7 minus 8, which equals minus one. Waits decrease the count and signals increase it, so waits exceeded signals by one, which is option C.

Q13. A task pool semaphore starts at 2. Process A acquires one permit, process B acquires another, and process C blocks. A then signals once. Which statement is guaranteed, without assuming a particular scheduling policy?

A.C must finish its entire task before B resumes
B.A permit becomes available, allowing a waiting process to proceed according to semaphore semantics ✅
C.Both A and B must release their permits automatically
D.C and a new process must acquire the same permit simultaneously
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: After A signals, one permit is released. If C is waiting, the semaphore implementation can make that permit available to a waiting process, but the exact scheduling order and completion time are not generally guaranteed by the semaphore alone.

Q14. A program uses a semaphore initialized to 1. Process P waits successfully, then crashes before signaling. Process Q waits and remains blocked. Which recovery strategy best addresses the failure while preserving the intended exclusive access?

A.Let every waiting process decrement the semaphore repeatedly
B.Use a robust recovery design that detects owner failure and safely restores access ✅
C.Initialize the semaphore to a large positive number
D.Allow Q to enter whenever it has waited long enough
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A lost permit can leave a semaphore permanently unavailable after a process crashes. Recovery must determine whether the protected resource is safe to use and restore availability without admitting concurrent access to inconsistent state. Blindly increasing permits or using time alone is unsafe.

Q15. A semaphore tracks free parking spaces in a garage with capacity 10. Initially, all spaces are free. Three cars enter and two leave. Assuming each entry waits once and each exit signals once, what is the available count?

A.3
B.5
C.7
D.9 ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: The semaphore begins at 10. Three entering cars consume three permits, reducing the count to 7. Two departing cars release two permits, restoring the count to 9. Therefore, nine spaces are available, which is option D.

Q16. A consumer waits on a semaphore that represents completed tasks. The producer signals once for each completed task. The semaphore is initialized to 0, and the producer completes three tasks before the consumer runs. If no task notifications are lost, how many successful waits can the consumer perform before needing another signal?

A.0
B.1
C.2
D.3 ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Each signal adds one available notification, and the initial count is zero. Three completed tasks therefore provide three permits. The consumer can successfully perform three waits without another signal, assuming each permit represents one completed task.

Q17. A semaphore initialized to 1 protects a shared balance. Process P waits, subtracts 20, and signals. Process Q then waits and adds 10. If the initial balance is 100 and both operations complete, what final balance is expected?

A.70
B.80
C.90 ✅
D.110
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The semaphore serializes the two updates so that each operation completes without another process entering the protected region concurrently. The balance changes from 100 to 80 after subtraction, then to 90 after addition. Thus the final balance is 90.

Q18. A developer claims that a semaphore initialized to 1 guarantees fairness because only one process can enter the critical section at a time. Which assessment is most accurate?

A.Correct, because mutual exclusion always implies FIFO scheduling
B.Incorrect, because mutual exclusion does not by itself guarantee which waiting process gets the next permit ✅
C.Correct, because the semaphore permanently records process arrival order
D.Incorrect, because a semaphore initialized to 1 cannot enforce mutual exclusion
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A binary semaphore can enforce mutual exclusion, but fairness depends on the implementation's queueing and scheduling policy. Some implementations may wake waiting processes in a particular order, while others do not promise FIFO service. Mutual exclusion alone is not fairness.

Q19. A service has five worker slots. A counting semaphore starts at 5. Four workers acquire slots; one worker finishes and signals; then two new workers each request a slot. Assuming the first four workers had no other releases, how many of the two new workers can acquire immediately?

A.0
B.1
C.2 ✅
D.3
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Four acquisitions reduce the count from 5 to 1. One completion signal increases it to 2, so both new workers can acquire one permit each. Two workers can acquire immediately, which is option C.

Q20. A consumer must remove an item from a queue, but the code performs wait(empty) before removing it. The empty semaphore counts empty slots. What conceptual mistake does this reveal?

A.The consumer is waiting for free capacity instead of waiting for available data ✅
B.The producer should never signal any semaphore
C.The empty semaphore must always begin at zero
D.The consumer should signal the empty semaphore before every wait
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A consumer needs an item to remove, so it should wait on the semaphore representing occupied slots or available items. Waiting on empty capacity models the producer's requirement instead and can block the consumer when the queue is full or mismanage counts.

Q21. A semaphore S is initialized to 3. Six processes each call wait(S) once, and no process calls signal(S). Assuming all requests are made and blocked requests do not complete, how many processes can proceed beyond wait?

A.2
B.3 ✅
C.4
D.6
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Three initial permits permit three successful wait operations. After those permits are consumed, the remaining three processes cannot pass their waits and must block. Thus exactly three processes proceed, while the others wait for a signal.

Q22. A developer wants to ensure that a data-processing stage begins only after two independent preprocessing tasks have both completed. A semaphore starts at 0, and each preprocessing task signals once at completion. How many successful waits should the processing stage perform before starting?

A.One, because any signal means both tasks are done
B.Two, because each completion contributes one permit ✅
C.Three, because one permit is needed for each task and one for startup
D.Zero, because the semaphore already represents a dependency
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Each independent preprocessing task signals once, producing two permits in total. The processing stage must consume both completion notifications before proceeding, thereby ensuring that neither task's completion is overlooked. One wait would only establish that at least one task finished.

Q23. A program uses a semaphore as an event counter. The initial value is 2. Three signal operations occur, followed by four wait operations, with no blocking waits counted as completed. What happens during the fourth wait?

A.It succeeds, leaving one permit available ✅
B.It blocks, because only three permits are available
C.It blocks, because the initial count is ignored after signaling
D.It fails, because signals cannot be counted
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The initial count of 2 plus three signals gives 5 permits. Four waits consume four of them, leaving one. The fourth wait therefore succeeds and leaves one permit available.

Q24. A program controls access to a shared log using a semaphore initialized to 1. A developer adds a signal operation immediately before entering the critical section, then signals again after leaving it. What is the main danger?

A.The semaphore may gain an extra permit, allowing concurrent entry ✅
B.The semaphore necessarily becomes initialized to 0
C.The program becomes deadlock-free under every possible schedule
D.The critical section becomes read-only
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A signal before entry releases a permit that the process did not acquire for that entry. The later signal releases another permit, potentially raising the count above one. This breaks the intended exclusive-access invariant and may allow multiple processes to enter.

Q25. A data pipeline has three stages. Stage B may start after stage A finishes, and stage C may start after B finishes. Each dependency uses a separate zero-initialized semaphore. Which signaling sequence preserves the intended order?

A.A signals B's semaphore before starting; C signals A's semaphore
B.B signals both semaphores before A completes
C.A signals B's semaphore after finishing, and B signals C's semaphore after finishing ✅
D.C signals B's semaphore when it begins
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The first notification must be sent by A after A finishes so that B can proceed. The second must be sent by B after B finishes so that C can proceed. Signaling earlier would permit a downstream stage to run before its prerequisite has completed.

Q26. A service limits simultaneous downloads to 2. Its semaphore starts at 2. Two downloads acquire permits, and a third request blocks. One download finishes but mistakenly signals before releasing the network slot. What is the synchronization issue?

A.The signal may allow another download while the actual slot remains occupied ✅
B.The semaphore automatically detects that the network slot is busy
C.The third request must remain blocked forever regardless of the signal
D.The initial value should have been zero
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A semaphore is only a correct model of resource availability if its permit is released when the resource is genuinely available. Signaling before the slot is released can allow a new download to start while both physical slots remain occupied, exceeding the intended limit.

Q27. A queue implementation uses a semaphore for the number of available items and a separate lock for queue structure. A developer removes the lock but retains the item semaphore. Why may the queue still become corrupted?

A.The item semaphore counts available work but does not necessarily serialize structural modifications by multiple consumers ✅
B.The item semaphore always prevents every consumer from running
C.The lock was needed only to initialize the semaphore
D.Counting semaphores cannot represent item availability
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The item semaphore coordinates whether work is available, but multiple consumers may still modify shared queue pointers or indices concurrently after acquiring separate item permits. A distinct mutual-exclusion mechanism is needed to protect the queue's internal structure.

Q28. A graph of semaphore availability shows the count at 4, then 3, then 2, then 3, then 4. Which sequence of operations is consistent with the graph, assuming each step changes the count by exactly one?

A.Signal, signal, wait, wait
B.Wait, wait, signal, signal ✅
C.Wait, signal, wait, signal
D.Signal, wait, signal, wait
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The count first decreases twice, from 4 to 3 and then 2, indicating two wait operations. It subsequently increases twice, from 2 to 3 and then 4, indicating two signal operations. The sequence is therefore wait, wait, signal, signal.

Q29. A program uses a semaphore initialized to 1 to protect a resource. Process P acquires it. Process Q waits and blocks. P signals, and then process R attempts to acquire the semaphore. What can be concluded without a specified fairness policy?

A.Q must acquire and finish before R can run
B.R must acquire before Q because it arrived later
C.The implementation's wake-up and scheduling policy determines which waiting or newly arriving process proceeds ✅
D.Both Q and R are guaranteed to enter simultaneously
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Signaling releases a permit and may wake a blocked process, but the exact ordering depends on the semaphore's queueing semantics and scheduler. Without a fairness guarantee, it is unsafe to conclude that Q must finish first or that R must overtake Q.

Q30. A resource manager uses a semaphore initialized to 7. Six resources are acquired, then three resources are released. What is the resulting semaphore count if all operations correspond correctly to resource acquisition and release?

A.1
B.3
C.4 ✅
D.5
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Six successful acquisitions reduce the count from 7 to 1. Three release signals then increase the count to 4. The correct result is 4, which is option C.

Q31. A developer uses a semaphore initialized to 0 to indicate that a cache has been populated. The cache is populated, and a signal occurs. Later, a client waits and reads the cache. What additional requirement is important beyond simply having a permit?

A.The cache must be populated before the signal, and the synchronization must provide the required memory visibility ✅
B.The client must signal before reading the cache
C.The semaphore must be initialized to 1 after the cache is populated
D.The cache must be modified by the client before waiting
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Correct ordering requires the producer to finish writing the cache before signaling. The synchronization implementation must also provide appropriate memory-ordering guarantees so the client observes those writes after waiting. A permit alone is not a substitute for correctly ordered data publication.

Q32. A semaphore is used to limit a service to one active administrator session. The semaphore is initialized to 1, and each session acquires it on login and releases it on logout. A session crashes without releasing. Which design principle best prevents indefinite unavailability?

A.Treat the permit as permanently lost and reject all future sessions
B.Use a recovery mechanism that safely detects abandoned ownership and restores the resource ✅
C.Let every new session signal twice before acquiring
D.Allow unlimited sessions after a timeout without checking the previous session
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A crashed session can leave the permit unavailable indefinitely. A robust design must detect abandonment and determine whether the resource can safely be reclaimed. Automatically increasing permits or allowing unrestricted entry could violate the one-session limit or corrupt shared state.

Q33. Two processes use a semaphore to protect a shared variable. Process P performs wait(S), reads the variable, and signals S before computing a new value. Process Q updates the variable during P's computation. Why can P's final write be incorrect?

A.P released protection before completing the read-modify-write operation, allowing an interleaving update ✅
B.Q cannot access a variable protected by any semaphore
C.The semaphore must always be initialized to 0
D.A signal operation permanently freezes the shared variable
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The full read-modify-write sequence must be protected if correctness depends on its operations being indivisible relative to other processes. Releasing the semaphore after the read allows Q to change the variable before P writes its computed result, potentially overwriting Q's update.

Q34. A task scheduler uses a semaphore initialized to 0 to count ready tasks. Four tasks become ready and each signals once. A dispatcher then performs three successful waits and starts three tasks. How many permits remain, assuming no other operations?

A.0
B.1 ✅
C.2
D.4
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Four signals raise the semaphore count from 0 to 4. The dispatcher consumes three permits with three successful waits, leaving one permit available to represent the remaining ready task. Therefore, the final count is 1.

Q35. A developer replaces a semaphore wait with a loop that repeatedly checks the count until it becomes positive, then decrements it. Two processes execute the loop simultaneously. What is the most important flaw if the check and decrement are separate operations?

A.Both processes may observe a positive count and decrement it, violating the permit limit ✅
B.The loop guarantees FIFO order among all processes
C.The semaphore count can never become zero
D.The replacement automatically makes each critical section shorter
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A separate check followed by decrement is not atomic. Both processes can observe the same available permit before either decrements the count, allowing more acquisitions than permitted. The wait operation must make checking and consuming a permit indivisible.

Q36. A system has two independent resources, X and Y, each with one permit. Process P acquires X and then waits for Y. Process Q acquires Y and then waits for X. Which outcome is possible if both acquire their first resource before either releases it?

A.Both processes necessarily finish because each semaphore has one permit
B.P and Q can deadlock while each holds one resource and waits for the other ✅
C.The semaphores automatically transfer permits between resources
D.One process must release its resource whenever another process waits
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: P can hold X while waiting for Y, and Q can hold Y while waiting for X. Neither can proceed to release its held resource, producing a circular wait. This demonstrates that individually correct semaphore operations can still create system-level deadlock.

Q37. A counting semaphore initialized to 6 tracks free slots. Three processes acquire slots, and then five signal operations occur. What is the arithmetic result, and what should a correct resource model check?

A.The count is 8, and the model should check whether signals correspond to legitimate releases ✅
B.The count is 4, and no further validation is needed
C.The count is 3, because signals cancel all previous waits
D.The count is 6, because semaphores cannot exceed their initial value
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Arithmetic gives 6 minus 3 plus 5, which equals 8. However, if the resource pool has only six slots, the five signals may include unmatched releases. The implementation should verify ownership and resource invariants rather than blindly accepting an impossible availability count.

Q38. A graph of the number of blocked consumers shows 0, 1, 2, 1, 0 while producers continue adding work. Which interpretation best fits this pattern?

A.Consumers first block as work becomes unavailable, then resume as notifications or items arrive ✅
B.The graph proves that all consumers ran simultaneously at every point
C.The semaphore count necessarily equals the number of blocked consumers
D.The queue must have been full throughout the interval
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The blocked-consumer count rises when consumers cannot obtain available work and falls when they are awakened or can proceed. The graph alone does not reveal the exact semaphore count or prove simultaneous execution, but it is consistent with changing item availability.

Q39. A process pool uses a semaphore initialized to 3. Two processes acquire permits, and one of them signals twice when it finishes. A third process then acquires a permit. What is the likely state if the implementation accepts both signals?

A.The count is 2 after the third acquisition, but the pool's accounting is invalid ✅
B.The count is 3 and the pool is guaranteed correct
C.The count is 1 and the pool is guaranteed to respect capacity
D.The count is negative because one process signaled twice
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The count starts at 3, falls to 1 after two acquisitions, and rises to 3 after two signals. A third acquisition reduces it to 2. The duplicate signal has inflated availability, so the accounting is invalid even though the count shows 2.

Q40. A student argues that because a semaphore's wait and signal operations are atomic, any program using semaphores is free from race conditions. What is the best correction?

A.Atomic semaphore operations guarantee that every shared-data access is automatically protected
B.Race conditions can still occur if the program uses semaphores incorrectly or leaves shared operations outside the protected region ✅
C.Race conditions occur only when semaphores are initialized to zero
D.Atomicity means that all processes execute in a fixed order
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Atomicity applies to the semaphore operation itself, not automatically to every shared-data operation in the program. Incorrect placement, missing waits, premature signals, or unprotected accesses can still permit conflicting interleavings and race conditions.

Q41. A semaphore initialized to 1 protects a shared structure. Process P acquires it and performs a long computation that does not touch the structure. During this time, Q needs to update the structure. Which change best improves concurrency without weakening correctness?

A.Release the semaphore during the unrelated computation and reacquire it only for structure accesses, if the data dependencies permit ✅
B.Increase the semaphore count to 2 permanently
C.Make Q ignore the semaphore because P is computing
D.Delete every signal operation to avoid context switching
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The semaphore should cover only operations that require exclusive access. If the long computation is independent of the shared structure, moving it outside the critical section lets Q update the structure safely during that time. Correctness still depends on reacquiring protection for shared accesses.

Q42. A semaphore begins at 2. Four processes each request one permit, and exactly two requests succeed before the remaining processes block. One permit is then released. How many processes can have completed acquisition operations at that moment, counting the original two?

A.1
B.2
C.3 ✅
D.4
