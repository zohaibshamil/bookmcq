What is Priority Inversion in Semaphore?

Priority inversion occurs when a high-priority process is indirectly preempted by a low-priority process holding a needed semaphore, especially if a medium-priority process runs during the hold period, which can be mitigated using priority inheritance protocols where the holder temporarily inherits the higher priority.

This delays the low-priority process from releasing the resource, causing the high-priority process to wait longer and worsening the priority inversion.
