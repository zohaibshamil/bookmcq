📝 Computer System Organization in Operating System (21 MCQs)

Definition:

Computer system organization describes how processors, main memory, storage devices, and input/output controllers are connected and cooperate to execute programs. It explains the hardware foundation on which an operating system operates. Without coordinated communication between these components, data transfers could become inconsistent and processor operations could remain incomplete.

Working:

The processor executes instructions and accesses data stored in memory. Device controllers manage particular input/output devices and communicate with the processor through system interconnections. When a device completes an operation, it can generate an interrupt. The processor then handles the event through an appropriate interrupt service routine.

Example:

A computer reads a 100 MB file from storage. The storage controller transfers the requested data into memory, potentially using DMA. After completing the transfer, the controller generates an interrupt. The processor handles the notification, allowing the application to continue processing the received data.

Reason:

Organized hardware communication is preferred over requiring the processor to control every device operation individually. Programmed input/output can consume processor time through continuous checking. Interrupts and DMA can reduce unnecessary processor involvement, although their availability and implementation depend on hardware architecture.

Common Misconceptions:

'The processor performs every data transfer itself.' Correction: Controllers and DMA can transfer data independently. 'Interrupts always indicate errors.' Correction: They also signal normal events such as completed operations. 'All devices communicate identically.' Correction: Controllers and communication interfaces differ across devices.

Exam Preparation Tips: How to prepare this topic

Draw a basic computer organization diagram showing the processor, memory, and controllers. Explain interrupt handling and DMA step by step. Compare programmed I/O, interrupt-driven I/O, and DMA. Exams commonly test controller functions and data-transfer sequences.

Key Terms:

  • CPU - Executes instructions and controls processing.
  • Device Controller - Manages communication with a hardware device.
  • Interrupt - A signal requesting processor attention.
  • DMA - Direct Memory Access transfers data without continuous CPU involvement.

📝 All Computer System Organization in Operating System MCQs

Q1. A computer contains a CPU, main memory, and several input/output devices connected through a shared communication pathway. The CPU needs to transfer data between memory and a storage controller. Which hardware component provides this communication pathway?

A.System bus ✅
B.Arithmetic logic unit
C.Control unit
D.Cache register
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The system bus provides communication pathways for transferring data, addresses, and control signals among the CPU, memory, and I/O devices. The ALU performs arithmetic and logical operations rather than connecting components. Remember that a system bus typically includes data, address, and control buses.

Q2. A processor executes an instruction that adds two integers and stores the result. Which CPU component performs the actual arithmetic operation?

A.Control unit
B.Memory management unit
C.Arithmetic logic unit ✅
D.Input/output controller
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The arithmetic logic unit performs arithmetic operations such as addition and subtraction, along with logical comparisons. The control unit coordinates instruction execution but does not perform the calculation itself. Remember that arithmetic and logical calculations are primary ALU responsibilities.

Q3. While a program is running, the CPU needs to retrieve an instruction from main memory. What normally happens first in the instruction execution cycle?

A.The result is written to secondary storage
B.The next instruction is fetched from memory ✅
C.The operating system terminates the process
D.The ALU performs the final calculation
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The fetch-decode-execute cycle begins when the processor fetches an instruction from memory using the address in the program counter. Decoding and execution occur afterward. Writing results to storage is not the first step. Remember the standard sequence: fetch, decode, execute, and store when required.

Q4. A processor has a clock frequency of 3 GHz. Assuming one clock cycle takes the same duration throughout execution, approximately how long does one clock cycle last?

A.3 nanoseconds
B.0.3 nanoseconds
C.30 nanoseconds
D.0.33 nanoseconds ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A 3 GHz processor performs \(3 \\times 10^9\) clock cycles per second. The duration of one cycle is \(1/(3 \\times 10^9)\) seconds, approximately 0.33 nanoseconds. Confusing frequency with cycle duration produces 3 nanoseconds. Remember that clock period equals the reciprocal of clock frequency.

Q5. A computer has separate data and address buses. Its address bus contains 16 lines, and each line can represent either 0 or 1. How many distinct memory addresses can the processor generate?

A.65536 ✅
B.32768
C.16384
D.131072
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A 16-bit address bus can represent \(2^{16}\) distinct binary combinations, giving 65,536 addresses. Selecting \(2^{15}\) would incorrectly use one fewer address bit. The concept is address bus capacity. Remember that an n-bit address bus can identify \(2^n\) unique locations.

Q6. A processor needs to read a value from RAM. The memory controller receives the requested address and returns the stored data. Which bus primarily carries the requested memory address from the processor toward memory?

A.Data bus
B.Control bus
C.Address bus ✅
D.Expansion bus
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The address bus carries the location that the processor wants to access in memory or an I/O device. The data bus carries the actual information being transferred, while the control bus carries signals such as read and write commands. Remember: address identifies where, data carries what, and control specifies how.

Q7. A computer executes instructions using a CPU clocked at 2 GHz. An instruction requires an average of 4 clock cycles. Approximately how many instructions can the processor complete per second under these assumptions?

A.250 million
B.500 million ✅
C.1 billion
D.2 billion
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A 2 GHz processor provides \(2 \\times 10^9\) cycles per second. If each instruction requires four cycles, throughput is \(2 \\times 10^9 / 4 = 500\) million instructions per second. Assuming one instruction per cycle would overestimate performance. Remember to divide clock frequency by average cycles per instruction.

Q8. A storage controller transfers a large block of data directly from an SSD to RAM without requiring the CPU to move every individual byte. Which mechanism enables this transfer?

A.Interrupt-driven polling
B.Cache mapping
C.Programmed I/O
D.Direct Memory Access ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Direct Memory Access allows an I/O controller to transfer data directly between a device and main memory with limited CPU involvement. The CPU typically configures the transfer and receives notification when it completes. Programmed I/O requires more direct CPU involvement. Remember that DMA is especially useful for large data transfers.

Q9. A keyboard controller receives a keypress while the CPU is executing another application. The controller sends a signal requesting processor attention. What is this signal called?

A.Interrupt ✅
B.Memory address
C.Cache miss
D.Instruction opcode
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: An interrupt is a signal that requests CPU attention when an event requires handling. The processor temporarily changes its execution flow to service the event, often through an interrupt handler. A cache miss concerns data retrieval from memory. Remember that hardware interrupts allow devices to notify the CPU asynchronously.

Q10. A processor has an interrupt request pending while it is executing a user program. Before handling the interrupt, the processor must preserve enough information to resume the interrupted program afterward. What should be saved?

A.The complete contents of secondary storage
B.Only the current system clock frequency
C.The interrupted execution context ✅
D.Only the connected device addresses
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The processor or operating system saves the interrupted execution context, including the program counter and relevant processor registers. These values allow the original program to resume correctly after interrupt handling. Saving only device addresses is insufficient. Remember that context preservation is essential for correct interrupt handling.

Q11. A computer uses a DMA controller to transfer 8 MB of data from a storage device into RAM. The CPU initializes the transfer and performs other work while the controller operates. When the transfer finishes, what normally informs the CPU?

A.A permanent change in the processor clock
B.A hardware interrupt ✅
C.A modification to the instruction set
D.A forced shutdown of the storage device
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: After completing a DMA transfer, the controller commonly generates an interrupt to notify the CPU. This avoids requiring the processor to continuously check the transfer status. Polling would require repeated status checks. Remember that DMA completion interrupts improve CPU efficiency during I/O operations.

Q12. A processor contains a small, fast memory located close to its execution units. Frequently accessed instructions and data are stored there to reduce average memory access time. What is this memory called?

A.Secondary storage
B.Virtual memory
C.Main memory
D.Cache memory ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Cache memory stores frequently accessed instructions and data close to the CPU, reducing the need to access slower RAM. Virtual memory provides an extended address space, while secondary storage provides persistent storage. Remember that cache memory exploits temporal and spatial locality to improve performance.

Q13. A processor uses a cache with an access time of 2 ns and main memory with an access time of 50 ns. If the cache hit ratio is 80%, and a cache miss requires an additional main-memory access, what is the average access time?

A.10 ns
B.12 ns ✅
C.11.6 ns
D.40.4 ns
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The average access time is \(0.8(2)+0.2(2+50)=12\) ns when a miss includes the initial cache lookup. Therefore, 12 ns is the correct result, corresponding to option B rather than C. This tests effective memory access time. Always include the initial cache lookup when calculating miss penalties.

Q14. A system has RAM containing 16 GB and a secondary storage device containing 1 TB. The computer loses power unexpectedly. Which statement correctly explains what happens to these two storage types?

A.Both retain their contents without power
B.RAM retains data, but secondary storage loses it
C.RAM loses volatile contents, but secondary storage retains persistent data ✅
D.Both lose their contents because the CPU stops
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: RAM is volatile memory, so its contents are generally lost when power is removed. Secondary storage such as an SSD or HDD is nonvolatile and retains stored information. Assuming both memories are volatile confuses their storage characteristics. Remember that volatility determines whether memory retains information without electrical power.

Q15. A CPU has a 32-bit data bus and transfers one complete data word per bus cycle. Assuming no additional overhead, how many bytes can it transfer in one cycle?

A.2 bytes
B.4 bytes ✅
C.8 bytes
D.32 bytes
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A 32-bit data bus transfers 32 bits in one cycle. Since one byte contains 8 bits, the transfer size is \(32/8=4\) bytes per cycle. Confusing bus width measured in bits with bytes produces an incorrect result. Remember to divide the data bus width by eight to obtain bytes.

Q16. An operating system receives a request to read data from a disk. The CPU issues the command to the disk controller, which operates independently while the processor executes another task. What hardware organization feature makes this possible?

A.The CPU must remain idle during every I/O operation
B.The ALU directly stores data on the disk
C.The program counter controls the disk motor
D.I/O controllers operate independently of CPU instruction execution ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: I/O controllers can manage device operations independently after receiving commands from the CPU. This allows the processor to execute other instructions while the device performs its operation. Requiring the CPU to remain idle would waste processing capacity. Remember that independent I/O operation supports overlapping computation and input/output.

Q17. A computer uses memory-mapped I/O. The graphics controller is assigned a specific range of addresses within the processor's address space. How does the CPU communicate with the controller?

A.By reading and writing the assigned addresses ✅
B.By executing only arithmetic instructions
C.By accessing the controller exclusively through secondary storage
D.By changing the processor clock frequency
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Memory-mapped I/O assigns device registers to addresses within the processor's address space. The CPU communicates with the device by performing ordinary memory read and write operations to those addresses. Separate I/O instructions are not necessary. Remember that memory-mapped I/O uses address-based access to control device registers.

Q18. A computer has a 64-bit processor, 8 GB of RAM, and a 32-bit address bus. Assuming byte-addressable memory and no reserved address regions, what is the maximum physical memory space directly addressable through that bus?

A.2 GB
B.4 GB ✅
C.8 GB
D.64 GB
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A 32-bit address bus represents \(2^{32}\) unique addresses. With byte-addressable memory, each address identifies one byte, giving \(2^{32}\) bytes or 4 GB. The processor's 64-bit architecture does not automatically expand a 32-bit physical address bus. Remember to distinguish processor word size from address bus width.

Q19. A CPU receives an interrupt from a network controller while executing process P1. The processor saves the current state, executes the interrupt handler, and then resumes P1. What determines the address from which the interrupt handler begins execution in a typical vectored interrupt system?

A.The current stack pointer value alone
B.The size of the network packet
C.The interrupt vector associated with the interrupt ✅
D.The total number of active processes
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: A vectored interrupt system uses an interrupt vector to identify the appropriate interrupt service routine or its address. The processor uses this information to transfer control to the correct handler. The stack pointer supports context management but does not identify the handler. Remember that interrupt vectors associate interrupt types with service routines.

Q20. A computer has a CPU capable of executing 4 billion clock cycles per second. A particular workload requires 8 billion cycles to complete. Ignoring all overhead and assuming a constant clock rate, how long will execution take?

A.0.5 seconds
B.1 second
C.4 seconds
D.2 seconds ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Execution time is calculated by dividing the required CPU cycles by the clock rate: \(8 \\times 10^9 / 4 \\times 10^9 = 2\) seconds. Confusing the number of cycles with the clock frequency can produce an incorrect result. Remember that CPU execution time equals instruction-related cycles divided by cycles per second.

Q21. A computer uses a hierarchical memory system containing CPU registers, cache, RAM, and an SSD. A program repeatedly accesses the same variable inside a tight loop. Which storage level is generally expected to provide the fastest access when the variable is available there?

A.CPU registers ✅
B.SSD storage
C.Main memory
D.Secondary disk cache
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: CPU registers are located inside the processor and generally provide faster access than cache, RAM, or SSD storage. A frequently used variable may be kept in a register by the compiler or processor. Cache is faster than RAM but slower than registers. Remember the typical speed hierarchy: registers, cache, RAM, then secondary storage.
