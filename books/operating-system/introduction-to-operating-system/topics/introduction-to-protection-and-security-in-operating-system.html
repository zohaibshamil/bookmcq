What is Introduction to Protection and Security in Operating System?

Definition:
Protection controls access to resources via mechanisms like access matrices \( A[i,j] \) specifying rights of domain \( i \) over object \( j \), while security defends against external and internal threats.

Example:
Unix-style permissions using read-write-execute bits for owner, group, and others to restrict file modification and prevent privilege escalation attacks.

Reason:
These mechanisms enforce policy compliance and multi-user safety, ensuring that buggy or malicious code cannot compromise system integrity or access unauthorized sensitive data.

📝 All Introduction to Protection and Security in Operating System MCQs

Q1. What is the fundamental distinction between 'protection' and 'security' in operating system design?

A.Protection controls access to resources by authorized users, while security defends against malicious attacks from unauthorized entities. ✅
B.Security is an internal mechanism for resource allocation, while protection handles external network threats.
C.Protection deals with hardware faults, while security deals with software bugs.
D.There is no significant difference; the terms are used interchangeably in modern OS literature.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Protection is a mechanism for controlling access of programs, processes, or users to computer-system resources. Security involves defending the system from external and internal attacks, such as viruses and denial-of-service.

Q2. Which principle dictates that a program, user, or system should be granted only those privileges necessary to perform its task?

A.Principle of Least Privilege ✅
B.Principle of Maximum Access
C.Principle of Open Design
D.Principle of Fail-Safe Defaults
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The Principle of Least Privilege minimizes the potential damage from accidents, errors, or unauthorized use by limiting the scope of authority.

Q3. In the context of an Access Matrix model, what do the rows and columns typically represent?

A.Rows represent domains (or subjects), and columns represent objects. ✅
B.Rows represent objects, and columns represent domains (or subjects).
C.Rows represent rights, and columns represent users.
D.Rows represent users, and columns represent groups.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The access matrix is a conceptual model where each row represents a domain (which may contain multiple processes/users) and each column represents an object. The entry [i,j] defines the access rights domain i has over object j.

Q4. Why is the 'global table' implementation of an access matrix generally considered inefficient for large systems?

A.It requires complex cryptographic hashing for every lookup.
B.It consumes excessive memory because most entries are empty (sparse matrix). ✅
C.It cannot support dynamic revocation of rights.
D.It forces all accesses to go through a single bottleneck processor.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: In most real-world systems, a specific domain does not have access to most objects. Therefore, the matrix is sparse. Storing it as a global 2D array wastes vast amounts of memory on null entries.

Q5. How do Capability Lists differ from Access Control Lists (ACLs) regarding where the authorization information is stored?

A.Capabilities are associated with the domain (subject), while ACLs are associated with the object. ✅
B.Capabilities are associated with the object, while ACLs are associated with the domain.
C.Capabilities are stored in the kernel registry, while ACLs are stored in user space.
D.Capabilities are static, while ACLs are dynamic.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A capability list is a set of capabilities held by a domain (like a key ring). An ACL is a list attached to an object specifying which domains can access it (like a guest list).

Q6. What is the primary security vulnerability associated with using passwords for authentication?

A.Passwords can be easily guessed if they are short or based on personal information. ✅
B.Passwords require expensive hardware tokens to store.
C.Passwords cannot be changed once compromised.
D.Passwords are susceptible to buffer overflow attacks during entry.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Human-chosen passwords are often weak, making them vulnerable to dictionary attacks, brute-force enumeration, or social engineering.

Q7. How does the use of a 'salt' value enhance the security of stored password hashes?

A.It ensures that two users with the same password have different hash values, preventing pre-computed rainbow table attacks. ✅
B.It encrypts the password so it can be decrypted by the administrator.
C.It reduces the length of the password required for secure storage.
D.It allows the system to store passwords in plain text securely.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Salt is a random value added to the password before hashing. This prevents attackers from using pre-computed tables (rainbow tables) of common password hashes, as they would need to compute a table for every possible salt value.

Q8. In a capability-based system, why must capabilities be protected from modification by user processes?

A.If a user could modify a capability, they could forge access rights to objects they are not authorized to access. ✅
B.Modification would cause the capability to expire immediately.
C.User processes do not have enough memory to hold capabilities.
D.Capabilities are read-only by hardware design and cannot be modified anyway.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Capabilities act as unforgeable tokens of authority. If a process could alter the bits within a capability structure, it could grant itself access to restricted resources, bypassing the protection system.

Q9. What is the main advantage of implementing 'stack canaries' or 'guard pages' in memory management?

A.They detect buffer overflow attacks by triggering an exception when memory outside the allocated buffer is accessed. ✅
B.They increase the speed of stack operations by caching frequent values.
C.They compress the stack data to save memory.
D.They prevent the stack from growing dynamically.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Buffer overflows often overwrite adjacent memory. Guard pages (marked no-access) or canaries (specific values) allow the system to detect when a write operation has exceeded the intended bounds, indicating a potential exploit.

Q10. Which type of malware replicates itself across a network without requiring user intervention to spread?

A.Virus
B.Worm ✅
C.Trojan Horse
D.Spyware
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Worms are standalone malware that replicate themselves to spread to other computers, often exploiting security holes. Viruses typically require attaching to a host program and user action (like executing the file) to spread.

Q11. What is a 'Man-in-the-Middle' attack?

A.An attacker secretly relays and possibly alters the communication between two parties who believe they are directly communicating with each other. ✅
B.An attacker physically intercepts hardware components during shipping.
C.An attacker gains root access by guessing the administrator's password.
D.An attacker floods the network with traffic to deny service.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: In a MitM attack, the attacker positions themselves between the victim and the destination, allowing them to eavesdrop or modify data in transit, often by spoofing identities or hijacking sessions.

Q12. Why is 'Address Space Layout Randomization' (ASLR) an effective countermeasure against code injection attacks?

A.It makes it difficult for an attacker to predict the memory addresses of critical system functions or injected code. ✅
B.It encrypts the code segment so it cannot be read by attackers.
C.It prevents any code from being executed in the heap or stack.
D.It increases the size of the address space to dilute the attack surface.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Many exploits rely on knowing the exact memory location of system libraries or shellcode. ASLR randomizes these locations at runtime, causing exploit attempts to jump to invalid addresses and crash rather than execute malicious code.

Q13. In the context of Java security, what is the purpose of the 'Security Manager'?

A.It enforces access control policies by checking permissions before allowing sensitive operations like file I/O or network connections. ✅
B.It manages the garbage collection process to prevent memory leaks.
C.It compiles Java bytecode into native machine code for faster execution.
D.It handles the threading synchronization within the JVM.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The Security Manager acts as the gatekeeper in Java, applying a security policy to determine if a running applet or application has the right to perform a specific privileged operation.

Q14. What is the primary function of a 'Trusted Computing Base' (TCB)?

A.It is the set of all hardware, firmware, and software components that are critical to the security of the system. ✅
B.It is a database of trusted users and their public keys.
C.It is a backup system that restores data after a security breach.
D.It is a network firewall that filters incoming packets.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The TCB encompasses all protection mechanisms within a computer system that are responsible for enforcing the security policy. If the TCB is compromised, the entire system's security is violated.

Q15. How does 'Role-Based Access Control' (RBAC) simplify administration in large organizations?

A.It assigns permissions to roles (e.g., 'Doctor', 'Nurse') rather than individual users, making it easier to manage changes in personnel. ✅
B.It allows users to create their own access rules dynamically.
C.It eliminates the need for passwords by using biometric data.
D.It automatically grants all users access to all resources unless explicitly denied.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: RBAC reduces administrative overhead. Instead of updating permissions for every individual when job functions change, administrators simply assign or remove users from roles.

Q16. What is a 'Zero-Day' exploit?

A.An attack that targets a previously unknown vulnerability in software or hardware, for which no patch exists yet. ✅
B.An attack that occurs exactly at midnight on New Year's Day.
C.An exploit that takes zero seconds to execute.
D.A virus that deletes zero files but corrupts the boot sector.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Zero-day refers to the fact that the developers have had 'zero days' to fix the vulnerability since it became known to attackers. These are highly dangerous because there are no immediate defenses.

Q17. Why is 'Denial of Service' (DoS) particularly difficult to prevent completely?

A.It often exploits legitimate protocol features (like connection requests) rather than a specific software bug, making it hard to distinguish from normal traffic. ✅
B.It requires physical access to the server room.
C.It only affects encrypted connections.
D.It can only be performed by insiders with administrative privileges.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: DoS attacks often overwhelm resources (bandwidth, CPU) by sending valid-looking requests. Filtering them without blocking legitimate users is a complex challenge of traffic analysis and rate limiting.

Q18. In a multilevel security model (e.g., Bell-LaPadula), what does the 'No Read Up' property enforce?

A.A subject at a lower security level cannot read an object at a higher security level (Simple Security Property). ✅
B.A subject at a higher security level cannot read an object at a lower security level.
C.A subject can only read objects created by the same user.
D.A subject must have clearance equal to the object's classification to read it.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: This property prevents information leakage from high-security domains to low-security domains, ensuring confidentiality.

Q19. What is the risk associated with 'Time-of-Check to Time-of-Use' (TOCTOU) vulnerabilities?

A.The state of a resource may change between the time its permissions are checked and the time it is actually accessed, leading to unauthorized access. ✅
B.The system clock can be manipulated to bypass expiration dates on licenses.
C.Long-running processes consume too much CPU time, causing denial of service.
D.Encryption keys expire before the data can be decrypted.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: TOCTOU is a race condition. An attacker might swap a file or change permissions after the check passes but before the use occurs, tricking the system into performing an operation on an unintended target.

Q20. How does 'Non-Executable Stack' protection mitigate buffer overflow attacks?

A.It marks the stack memory segment as non-executable, so even if an attacker injects code via an overflow, the CPU will refuse to run it. ✅
B.It prevents any data from being written to the stack.
C.It automatically detects and removes injected code.
D.It encrypts the return addresses on the stack.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Traditional overflows overwrite the return address to point to shellcode on the stack. By marking the stack as non-executable (NX bit), the hardware traps any attempt to execute instructions from that region.

Q21. What is the primary purpose of 'Audit Logs' in a secure system?

A.To record security-relevant events for later analysis, accountability, and forensic investigation. ✅
B.To speed up system performance by caching frequent operations.
C.To store user passwords in an encrypted format.
D.To manage the allocation of disk space to users.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Audit trails provide a history of actions. They are crucial for detecting intrusions, understanding how a breach occurred, and holding users accountable for their actions.

Q22. Why is 'Social Engineering' considered a significant threat to computer security?

A.It targets human psychology and trust rather than technical vulnerabilities, bypassing even robust technical defenses. ✅
B.It involves hacking social media APIs to steal data.
C.It uses social networks to distribute viruses automatically.
D.It relies on weak encryption algorithms used in chat applications.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Attackers manipulate people into divulging confidential information (like passwords) or performing actions that compromise security. Technical firewalls cannot stop a user from voluntarily handing over credentials.

Q23. In the context of secure boot, what is the role of 'Digital Signatures'?

A.They verify that the bootloader and kernel code have not been tampered with and originate from a trusted vendor. ✅
B.They encrypt the hard drive to prevent physical theft.
C.They compress the operating system files to speed up booting.
D.They allocate memory addresses for the kernel modules.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Secure boot checks the cryptographic signature of each component in the boot chain. If the signature doesn't match the trusted key, the system refuses to boot, preventing rootkits or malware from loading early.

Q24. What is a 'Honeypot' in network security?

A.A decoy system designed to attract attackers, allowing administrators to study their methods and divert them from real assets. ✅
B.A secure storage vault for encryption keys.
C.A type of firewall that blocks all incoming traffic.
D.A software tool that patches vulnerabilities automatically.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Honeypots mimic vulnerable services. They serve as an early warning system and a research tool to understand attacker behavior without risking production data.

Q25. Why is 'Separation of Privilege' important in system design?

A.It requires multiple conditions or approvals to perform sensitive operations, reducing the risk of a single point of failure or compromise. ✅
B.It separates user data from system data on different hard drives.
C.It ensures that every user has a unique login name.
D.It divides the CPU time equally among all processes.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Similar to two-factor authentication, separation of privilege ensures that no single entity (user or process) has complete control over a critical resource, requiring collaboration or multiple keys to access it.

Q26. What is the main disadvantage of 'Biometric Authentication' compared to passwords?

A.Biometric data cannot be changed if compromised, and false positives/negatives can affect usability. ✅
B.Biometrics are easier to guess than passwords.
C.Biometric scanners are always slower than keyboard input.
D.Biometrics require internet connectivity to function.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: If a password is stolen, you can change it. If your fingerprint template is stolen, you cannot change your fingerprint. Additionally, environmental factors can lead to rejection of legitimate users.

Q27. How does 'Encryption at Rest' protect data?

A.It ensures that data stored on disk or other media is unreadable without the decryption key, protecting against physical theft of the storage device. ✅
B.It protects data while it is being transmitted over the network.
C.It prevents users from deleting files.
D.It compresses data to save storage space.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Encryption at rest protects data when the system is powered off or the drive is removed. It is essential for laptops and mobile devices that may be lost or stolen.

Q28. What is a 'Rootkit'?

A.Malware designed to hide the existence of certain processes or programs from normal methods of detection and enable continued privileged access. ✅
B.A toolkit for system administrators to manage root accounts.
C.A virus that specifically targets the root directory of the file system.
D.A hardware device used to reset passwords.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Rootkits operate at a deep level (often kernel mode) to conceal their presence and other malicious software, making them extremely difficult to detect and remove.

Q29. In a capability system, what happens when a capability is revoked?

A.The system must locate and invalidate all copies of that capability held by various domains, which can be complex and costly. ✅
B.The capability automatically deletes itself from the user's disk.
C.The object associated with the capability is destroyed.
D.The domain loses all its capabilities instantly.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Unlike ACLs, where removing an entry from the object's list is simple, capabilities are distributed. Revoking them requires a mechanism to find and disable all existing instances (e.g., using indirection or keys).

Q30. What is the purpose of 'Input Validation' in secure programming?

A.To ensure that data entered by users conforms to expected formats and ranges, preventing injection attacks like SQL injection or XSS. ✅
B.To speed up data processing by filtering out unnecessary characters.
C.To compress user input to save bandwidth.
D.To translate user input into different languages.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Many attacks rely on sending malformed or unexpected data to trigger bugs. Rigorous validation ensures that only safe, expected data is processed by the application logic.

Q31. Why is 'Kernel Mode' execution restricted to trusted code?

A.Because code running in kernel mode has unrestricted access to hardware and memory, so a bug or exploit can crash the entire system or bypass all protection. ✅
B.Because kernel mode is slower than user mode.
C.Because user mode does not support floating-point calculations.
D.Because kernel mode requires a special graphics card.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The kernel is the core of the OS. If malicious code executes in kernel mode, it can disable security mechanisms, read any memory, and take full control of the machine.

Q32. What is 'Phishing'?

A.A fraudulent attempt to obtain sensitive information by disguising as a trustworthy entity in electronic communication. ✅
B.A method of filtering spam emails using AI.
C.A technique for optimizing network routing.
D.A type of fishing simulation game for training.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Phishing relies on deception, often via email or fake websites, to trick users into revealing passwords or credit card numbers.

Q33. How does 'Mandatory Access Control' (MAC) differ from 'Discretionary Access Control' (DAC)?

A.In MAC, the system (policy) determines access rights, and users cannot override them. In DAC, the resource owner determines access rights. ✅
B.MAC is used only for military systems, while DAC is used for commercial systems.
C.MAC allows users to share files freely, while MAC restricts all sharing.
D.DAC is enforced by the kernel, while MAC is enforced by user applications.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: DAC gives owners control (e.g., chmod in UNIX). MAC imposes a system-wide policy (e.g., labels like Top Secret) that owners cannot change, providing stricter security.

Q34. What is a 'Side-Channel Attack'?

A.An attack that extracts information from the physical implementation of a cryptosystem (e.g., timing, power consumption, electromagnetic leaks) rather than brute-forcing the algorithm. ✅
B.An attack that uses a side door in the building to steal servers.
C.An attack that targets the secondary network interface.
D.An attack that exploits unused variables in the code.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: These attacks bypass theoretical security by observing how the system behaves physically. For example, measuring how long an encryption operation takes can reveal details about the key.

Q35. Why is 'Regular Patching' critical for system security?

A.It fixes known vulnerabilities in software that attackers could exploit. ✅
B.It increases the storage capacity of the hard drive.
C.It improves the graphical user interface responsiveness.
D.It resets user passwords periodically.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Software vendors release patches to close security holes. Unpatched systems are easy targets for automated attacks scanning for known weaknesses.

Q36. What is the function of a 'Firewall'?

A.It monitors and controls incoming and outgoing network traffic based on predetermined security rules. ✅
B.It scans files for viruses on the local disk.
C.It encrypts all data stored on the server.
D.It backs up data to the cloud automatically.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Firewalls act as a barrier between a trusted internal network and untrusted external networks, filtering traffic to block malicious connections.

Q37. In the context of secure coding, what is 'Sanitization'?

A.The process of cleaning user input to remove potentially harmful characters or scripts before processing or displaying it. ✅
B.Deleting old log files to free up space.
C.Removing unused variables from the source code.
D.Formatting the hard drive to remove malware.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Sanitization is crucial for preventing Cross-Site Scripting (XSS) and injection attacks by ensuring that input data is treated as data, not executable code.

Q38. What is the primary goal of 'Integrity' in the CIA triad of security?

A.Ensuring that data has not been altered or tampered with by unauthorized parties. ✅
B.Ensuring that data is available when needed.
C.Ensuring that data is kept secret from unauthorized users.
D.Ensuring that the system runs quickly.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Integrity guarantees accuracy and consistency. Hashing and digital signatures are common techniques to verify integrity.

Q39. Why is 'Defense in Depth' recommended for security architecture?

A.It employs multiple layers of security controls so that if one layer fails, others remain to protect the system. ✅
B.It focuses all resources on a single, strong perimeter defense.
C.It relies solely on user training for security.
D.It uses only open-source software for transparency.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: No single security measure is perfect. Layering defenses (physical, network, host, application) reduces the likelihood of a successful breach.

Q40. What is a 'Privilege Escalation' attack?

A.An exploit that allows a user with limited privileges to gain higher-level permissions (e.g., root or admin) on the system. ✅
B.An attack that increases the network bandwidth available to a user.
C.An attack that upgrades the hardware of the server remotely.
D.An attack that forces the system to run more processes simultaneously.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Attackers often start with low-level access (e.g., via a web app) and use vulnerabilities in the OS or applications to escalate to administrative privileges, gaining full control.
