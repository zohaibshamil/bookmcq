📝 Introduction to Protection and Security in Operating System (25 MCQs)

Definition:

Protection and security are operating system responsibilities that control access to resources and defend systems against unauthorized activities. Protection governs which users and processes may perform particular operations, while security addresses broader threats and safeguards. Without these mechanisms, unauthorized programs could read private files, modify data, or damage system resources.

Working:

The operating system identifies users and processes, checks permissions, and enforces access rules. Authentication verifies an identity, while authorization determines permitted operations. Protection mechanisms isolate processes and restrict privileged actions. Security mechanisms may additionally include encryption, auditing, secure updates, and defenses against malicious software.

Example:

Suppose User A owns a document and grants read permission to User B but denies write permission. When B opens the document, the operating system permits reading. If B attempts to modify it, the access-control mechanism rejects the operation.

Reason:

Protection and security provide controlled access compared with unrestricted resource sharing. Without access controls, any process might modify sensitive information or interfere with other applications. Authentication alone is insufficient because verifying identity does not automatically establish permission to perform every operation.

Common Misconceptions:

'Authentication and authorization are identical.' Correction: Authentication verifies identity, whereas authorization checks permissions. 'Protection prevents every security attack.' Correction: It controls access but cannot eliminate all vulnerabilities. 'A password guarantees complete security.' Correction: Additional safeguards are necessary.

Exam Preparation Tips: How to prepare this topic

Distinguish protection from security, authentication from authorization, and access control from encryption. Practice permission-based scenarios involving users and files. Understand process isolation and privilege levels. Exams commonly ask security mechanisms, access-control principles, and threat prevention.

Key Terms:

  • Authentication - Verification of a user's claimed identity.
  • Authorization - Determination of permitted resource operations.
  • Access Control - Enforcement of resource-access permissions.
  • Encryption - Transforming readable information into protected ciphertext.

📝 All Introduction to Protection and Security in Operating System MCQs

Q1. A university computer lab allows students to log in using individual accounts. One student attempts to open another student's private examination files without permission. Which operating system mechanism should prevent this access?

A.CPU scheduling
B.Access control ✅
C.Memory compaction
D.Disk caching
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Access control determines which users can access particular resources and what operations they may perform. The operating system checks the student's permissions before allowing access. CPU scheduling only manages processor time. This tests resource protection. Remember that access control enforces permissions associated with users, groups, and resources.

Q2. A process attempts to modify a memory address belonging to another process. The operating system detects that the address lies outside its permitted memory region. What should happen?

A.The operating system should terminate the protection violation or signal an exception ✅
B.The operating system should automatically increase the process memory limit
C.The operating system should transfer the address to disk
D.The operating system should allow the operation temporarily
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Memory protection prevents a process from accessing memory outside its authorized address space. An invalid access should trigger a protection exception or an appropriate process termination. Increasing the memory limit would incorrectly grant unauthorized access. This tests process isolation. Remember that hardware-supported address checking helps enforce memory boundaries.

Q3. A company assigns employees different permissions on a shared document. Some can read it, while only managers can modify it. What security principle does this arrangement demonstrate?

A.Disk scheduling
B.Virtual memory
C.Least privilege ✅
D.File fragmentation
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The principle of least privilege gives users only the permissions necessary for their responsibilities. Employees receive read access, while managers receive additional modification rights. Granting everyone modification access would unnecessarily increase risk. This tests security privilege management. Always assign the minimum permissions required to perform a specific job.

Q4. An operating system stores passwords using a cryptographic hash function with a unique random salt for each account. Why is the salt used?

A.To make every password shorter
B.To encrypt the password using the username
C.To eliminate the need for password verification
D.To make identical passwords produce different stored hashes ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A unique salt is combined with each password before hashing, so identical passwords produce different stored hash values. This makes precomputed attacks such as rainbow-table attacks less effective. The salt does not shorten passwords or eliminate verification. This tests password hashing. Remember that salts should be unique and stored alongside password hashes.

Q5. A user enters the correct password but is denied access because the account does not have permission to open a protected folder. Which security distinction explains this situation?

A.Authentication succeeded, but authorization failed ✅
B.Authorization succeeded, but authentication failed
C.Encryption succeeded, but hashing failed
D.Identification failed, but auditing succeeded
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Authentication verifies the user's identity, while authorization determines whether that verified user may perform a requested operation. The correct password establishes identity, but insufficient folder permissions prevent access. This tests authentication and authorization. Remember the distinction: authentication asks who you are; authorization asks what you are allowed to do.

Q6. A system administrator grants a temporary employee administrator privileges to install one application. What is the main security concern with this decision?

A.The application will automatically become encrypted
B.The employee receives broader permissions than the task requires ✅
C.The operating system disables all user accounts
D.The employee loses access to the application after installation
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Administrator privileges usually allow extensive system modifications, making misuse or compromise more damaging. Installing one application rarely requires unrestricted access for an ordinary employee. This violates least privilege. This tests privilege management. Prefer controlled installation mechanisms or temporary, narrowly scoped elevation instead of permanent administrator access.

Q7. A process running in user mode attempts to execute a privileged instruction that directly controls hardware. What should the processor do?

A.Execute the instruction after checking the process name
B.Move the process into kernel mode automatically
C.Generate a protection exception or trap ✅
D.Terminate every process currently running
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: User mode restricts access to privileged instructions that could compromise system stability or security. Attempting such an instruction causes a trap or protection exception, allowing the operating system to handle the violation. Automatic elevation would defeat protection. This tests dual-mode operation. Remember that privileged instructions normally execute only in kernel mode.

Q8. A security system requires an employee to enter a password and then approve a login notification on a registered phone. What security mechanism is being used?

A.Single sign-on
B.Access control list
C.Data compression
D.Multi-factor authentication ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: The system requires two different authentication factors: something the employee knows, a password, and something the employee possesses, a registered phone. This is multi-factor authentication. Using two passwords would still involve only one factor category. Remember that authentication factors include knowledge, possession, and inherence.

Q9. A file has permissions represented as 754 in Unix-style octal notation. What permissions does the group receive?

A.Read and write
B.Read and execute ✅
C.Write and execute
D.Read only
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: In octal permissions, the middle digit represents group permissions. The digit 5 equals \(4 + 1\), representing read and execute permissions. Choosing read and write incorrectly interprets 5 as 6. This tests Unix file permissions. Remember the values: read = 4, write = 2, and execute = 1.

Q10. An administrator executes chmod 640 report.txt on a Unix system. What permissions are assigned to the file owner?

A.Read and write ✅
B.Read and execute
C.Write only
D.Read only
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The first octal digit controls the owner's permissions. The value 6 equals \(4 + 2\), granting read and write access. The remaining digits control group and others. This tests Unix permission representation. Convert each octal digit independently using read = 4, write = 2, and execute = 1.

Q11. A company stores confidential customer records on a server. An attacker intercepts network traffic and reads the records while they are being transferred. Which security measure most directly protects the confidentiality of this communication?

A.Disk defragmentation
B.File compression
C.Encryption in transit ✅
D.CPU privilege scheduling
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Encryption in transit protects information while it travels across a network by converting readable data into ciphertext. An attacker intercepting properly encrypted traffic cannot ordinarily read the original records without the necessary keys. File compression does not provide confidentiality. This tests data confidentiality. Use secure transport protocols such as TLS for network communications.

Q12. A system administrator configures a firewall to block incoming connections from an unauthorized external IP address. Which security objective is primarily supported by this action?

A.Improving file allocation
B.Reducing memory fragmentation
C.Increasing disk throughput
D.Restricting unauthorized network access ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: A firewall filters network traffic according to configured security rules, blocking connections that do not satisfy permitted conditions. This helps prevent unauthorized access to system services. It does not directly manage memory or disk allocation. This tests network security controls. Remember that firewalls enforce traffic policies at network boundaries or individual hosts.

Q13. A malicious program modifies a system executable so that it performs unauthorized operations whenever users run it. What type of security threat does this represent?

A.System integrity compromise ✅
B.Availability improvement
C.Memory allocation failure
D.Authentication success
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Modifying an executable without authorization violates system integrity because the software no longer behaves as its trusted original version. Availability improvement and authentication success do not describe unauthorized modification. This tests the integrity component of information security. Use trusted software sources, integrity checks, and restricted write permissions to reduce this risk.

Q14. A server records every successful and unsuccessful login attempt, including timestamps and account names. What is the primary purpose of maintaining these records?

A.Increasing processor speed
B.Supporting security auditing and incident investigation ✅
C.Reducing the size of user files
D.Automatically granting administrator permissions
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Security logs provide records of system events that administrators can examine to identify suspicious activity, investigate incidents, and establish accountability. They do not directly improve processor performance. This tests security auditing. Remember that useful logs should include relevant event details and be protected against unauthorized modification.

Q15. A user receives an email containing a link to a fake login page that imitates the company's official website. The user enters their password on that page. What attack has occurred?

A.Denial of service
B.Buffer overflow
C.Phishing ✅
D.Privilege escalation
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Phishing uses deceptive communications or websites to trick users into revealing sensitive information, such as passwords. A fake login page imitates a legitimate service to capture credentials. Buffer overflow exploits memory handling errors instead. This tests social engineering. Verify website addresses and avoid entering credentials through suspicious email links.

Q16. A process exploits a programming error by writing beyond the boundary of a memory buffer, potentially overwriting adjacent memory. What vulnerability is being exploited?

A.Disk scheduling failure
B.Password spraying
C.File permission inheritance
D.Buffer overflow ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A buffer overflow occurs when a program writes more data into a memory buffer than it can hold, potentially overwriting adjacent memory and control information. This can lead to crashes or unauthorized code execution. Password spraying targets authentication systems. This tests memory-related security vulnerabilities. Validate input lengths and use bounds-checked memory operations.

Q17. An attacker repeatedly tries thousands of different passwords against one user account until a valid password is discovered. Which attack is being performed?

A.Brute-force password attack ✅
B.SQL injection
C.ARP spoofing
D.Session fixation
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A brute-force attack systematically attempts many possible passwords until one succeeds. The attacker relies on repeated guesses rather than exploiting a software vulnerability. SQL injection targets database queries. This tests authentication security. Strong passwords, account lockout policies, rate limiting, and multi-factor authentication reduce brute-force risks.

Q18. A web application accepts user input and inserts it directly into an SQL query. An attacker enters specially crafted input that changes the query's intended logic. What vulnerability is involved?

A.Buffer overflow
B.SQL injection ✅
C.Privilege separation
D.Password hashing
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: SQL injection occurs when untrusted input is interpreted as part of an SQL command instead of ordinary data. This can allow attackers to retrieve or modify database information. Buffer overflow involves memory boundaries rather than query construction. This tests application security. Use parameterized queries instead of concatenating user input into SQL statements.

Q19. A company allows employees to access only the files assigned to their department. An employee changes the URL of a document to access another department's confidential file. What security weakness would allow this attack to succeed?

A.Strong password hashing
B.Encrypted network communication
C.Improper authorization checks ✅
D.Automatic memory relocation
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Improper authorization occurs when an application fails to verify whether the authenticated user has permission to access a requested resource. Changing a URL must not bypass server-side access checks. Encryption alone does not solve this problem. This tests access control enforcement. Always validate permissions for every protected resource on the server.

Q20. A system uses access control lists. A file has the following entries: Alice can read and write, Bob can read only, and the Administrators group has full control. Bob belongs to the Administrators group. What access does Bob receive if group permissions are additive?

A.Read only
B.Read and write only
C.Full control ✅
D.No access
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Bob receives read permission through his individual entry and full control through group membership. Under the stated additive-permission model, the effective permissions include the group's full control. Choosing read only ignores group membership. This tests access control list evaluation. Always consider both individual and group permissions when determining effective access.

Q21. A process runs with user ID 1001 and attempts to modify a protected system configuration file owned by root. The file permissions allow writing only by the owner. What should the operating system do?

A.Allow the modification because the process is active
B.Deny the write because the process lacks owner privileges ✅
C.Change the file owner automatically
D.Grant temporary root privileges
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The process runs under user ID 1001, while the protected file belongs to root. Since writing is restricted to the owner, the process lacks the required permission and must be denied. Running processes do not automatically receive ownership privileges. This tests Unix ownership and access control. Check the effective user identity against file ownership and permissions.

Q22. An operating system assigns a process a temporary elevated privilege to perform one protected operation, then removes that privilege immediately afterward. What security approach does this demonstrate?

A.Temporary privilege elevation ✅
B.Permanent administrator assignment
C.Unrestricted resource sharing
D.Disabling access control
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Temporary privilege elevation grants additional permissions only for the duration of an authorized operation. Removing those permissions afterward reduces the time during which misuse is possible. Permanent administrator assignment creates unnecessary exposure. This tests least privilege and privilege management. Grant elevated access only when needed and revoke it immediately afterward.

Q23. A security administrator discovers that an attacker has modified system logs to hide unauthorized access attempts. Which security property has been directly compromised?

A.Availability
B.Integrity ✅
C.Authentication
D.Confidentiality
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Integrity ensures that information remains accurate and has not been modified without authorization. Altering logs destroys confidence in their accuracy and weakens incident investigation. Confidentiality concerns unauthorized disclosure, not modification. This tests the security properties of information systems. Protect audit logs using restricted permissions, centralized storage, and tamper-evident mechanisms.

Q24. A company server experiences a denial-of-service attack. Thousands of external requests overwhelm its network service, preventing legitimate customers from connecting. Which security objective is primarily affected?

A.Confidentiality
B.Integrity
C.Availability ✅
D.Authentication
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Availability ensures that authorized users can access systems and services when needed. A denial-of-service attack consumes resources until legitimate requests cannot be served. Confidentiality concerns information disclosure, while integrity concerns unauthorized modification. This tests the CIA security triad. Remember that availability attacks target service accessibility rather than necessarily stealing or modifying data.

Q25. An administrator wants to ensure that a downloaded operating system update has not been modified during distribution. The administrator calculates its cryptographic hash and compares it with a trusted published hash. What property is primarily being verified?

A.Data integrity ✅
B.User authorization
C.Network availability
D.Memory isolation
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A cryptographic hash produces a fixed-length digest that changes significantly when the input data changes. Matching the downloaded file's hash with a trusted reference provides evidence that the file has not been modified. This tests integrity verification. Obtain the reference hash through a trusted channel because an attacker could replace both files and hashes.
