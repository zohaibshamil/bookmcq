📝 Introduction to Storage Management in Operating Systems (22 MCQs)

Definition:

Storage management is the operating system function responsible for organizing, allocating, accessing, and maintaining data on storage devices. It distinguishes temporary main memory from persistent secondary storage. Without storage management, files could become difficult to locate, storage space could be wasted, and concurrent access could damage stored information.

Working:

The operating system manages files, directories, storage allocation, and free-space information. When a program requests a file, the file system identifies its metadata and storage locations. The device controller performs the requested transfer, and the operating system reports completion or an error.

Example:

A user saves a 20 MB document to a storage device with 500 MB of available space. After successful allocation, the remaining available space becomes \( 500 - 20 = 480 \) MB. The file system records the document's name, location, and associated metadata.

Reason:

Storage management provides persistent and organized data access instead of relying exclusively on volatile RAM. RAM loses its contents when power is removed, while persistent storage retains information. Storage devices offer different capacities, access speeds, and costs, requiring suitable management strategies.

Common Misconceptions:

'RAM and secondary storage are interchangeable.' Correction: RAM primarily supports active execution, while secondary storage retains data. 'Deleting a file always immediately erases its contents.' Correction: File deletion commonly releases storage allocation first. 'Every file occupies consecutive blocks.' Correction: Allocation methods vary.

Exam Preparation Tips: How to prepare this topic

Understand file systems, directories, free-space management, and storage allocation. Compare RAM with secondary storage. Practice calculating remaining capacity after file allocation. Exams commonly ask file-management responsibilities, persistence, and differences between storage technologies.

Key Terms:

  • File System - Organizes and manages stored files.
  • Directory - Maintains information about files and their organization.
  • Free-Space Management - Tracks unused storage blocks.
  • Persistent Storage - Retains information without continuous power.

📝 All Introduction to Storage Management in Operating Systems MCQs

Q1. A computer has a 1 TB hard disk divided into three partitions of 300 GB, 400 GB, and 300 GB. The operating system needs to format the second partition without affecting the other two. What should the administrator do?

A.Format the entire physical disk
B.Format only the 400 GB partition ✅
C.Delete all existing partitions
D.Reinstall the operating system
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Formatting the second partition prepares only the selected 400 GB partition for storing files. The other partitions remain unchanged when the operation targets the correct partition. Formatting the entire disk would affect all partitions. This tests partition-level storage management. Always verify the selected partition before performing destructive disk operations.

Q2. A student saves a document named report.docx on an SSD. Later, the student opens the document through the file manager. Which operating system component organizes the document's name, location, and associated storage information?

A.CPU scheduler
B.Memory management unit
C.File system ✅
D.Device driver
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The file system manages files and directories, including names, locations, metadata, and access permissions. The CPU scheduler allocates processor time, while the memory management unit handles memory addresses. This tests the role of file systems in storage management. Remember that file systems provide the logical structure through which users access stored data.

Q3. A hard disk contains 1,000 available blocks, each holding 4 KB. How much data can these blocks store in total?

A.2 MB
B.3 MB
C.4 MB ✅
D.8 MB
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The total capacity is \(1,000 \times 4 = 4,000\) KB, equivalent to approximately 3.91 MB using 1 MB = 1,024 KB. The 4 MB option uses decimal megabytes as an approximation. This tests block-based storage capacity. Multiply the number of blocks by block size before converting units.

Q4. A system administrator creates separate partitions for the operating system, personal files, and backup data. What is the main advantage of this arrangement?

A.It eliminates the need for file permissions
B.It increases the processor clock speed
C.It makes every partition physically independent
D.It separates storage areas for easier organization and management ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Separate partitions organize data into distinct storage regions, making administration, backup, and operating system maintenance easier. They do not automatically increase processor speed or provide physical disk independence. This tests disk partitioning. Remember that partitions provide logical separation, even when they share the same physical drive.

Q5. A database server writes records repeatedly to an SSD. Compared with a traditional magnetic hard disk, which characteristic generally gives the SSD faster access to randomly located data?

A.It has no moving mechanical read/write components ✅
B.It stores every file in a single continuous region
C.It uses larger physical storage platters
D.It requires mechanical head positioning for each request
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: SSDs use flash memory and have no mechanical read/write heads, allowing them to access randomly located data without waiting for physical head movement. HDDs depend on mechanical positioning and rotational delays. This tests storage-device performance. For random-access workloads, remember that eliminating mechanical movement significantly reduces access latency.

Q6. A hard disk uses 4 KB blocks. A file occupies 10,000 bytes and is stored using whole blocks. How many blocks are required to store the file?

A.2 blocks
B.3 blocks ✅
C.4 blocks
D.5 blocks
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Each block holds 4,096 bytes. Dividing 10,000 by 4,096 gives approximately 2.44, so the file requires 3 complete blocks. Choosing 2 blocks ignores the remaining data. This tests storage block allocation. Use the ceiling of file size divided by block size whenever partial blocks cannot be allocated.

Q7. A user deletes a file from a file system. The operating system marks its storage blocks as available, but the actual data has not yet been overwritten. What does this imply?

A.The file is immediately erased from every physical sector
B.The storage device automatically creates a backup
C.The file system can reuse the blocks even though old data may remain ✅
D.The deleted file permanently occupies its original blocks
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Deleting a file commonly removes its directory entry or allocation references and marks its blocks as free. The underlying data may remain until overwritten or securely erased. Assuming immediate physical erasure confuses logical deletion with data destruction. This tests file deletion and storage allocation. Distinguish removing file references from securely wiping stored contents.

Q8. A file system allocates disk space using linked allocation. A file consists of five blocks, and each block contains a pointer to the next block. What information must the directory entry typically maintain to locate the file's contents?

A.The first block's location ✅
B.The physical location of every block
C.The last block's size only
D.The number of CPU instructions in the file
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Linked allocation connects file blocks through pointers, so the directory entry typically stores the starting block. The operating system follows the pointers to retrieve subsequent blocks. Storing every block address is associated with indexed allocation. This tests file allocation methods. Remember that linked allocation needs the starting block to traverse the file.

Q9. A file system uses contiguous allocation. A file occupies blocks 20 through 27. If each block holds 4 KB, what is the file's storage capacity?

A.24 KB
B.28 KB
C.30 KB
D.32 KB ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The file occupies eight blocks because both endpoints are included: \(27 - 20 + 1 = 8\). Multiplying by 4 KB gives 32 KB. Using 28 minus 20 without adding one causes an off-by-one error. This tests contiguous file allocation. Count both the starting and ending blocks when calculating occupied capacity.

Q10. An administrator notices that a file stored using linked allocation takes longer to access its final block than its first block. What is the most likely reason?

A.Every block must be loaded into RAM simultaneously
B.The operating system must follow intermediate block pointers ✅
C.The file is automatically compressed during access
D.The directory entry contains every block's physical address
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Linked allocation requires the operating system to follow pointers from one block to the next. Reaching the final block therefore involves traversing several intermediate blocks. Directly locating the final block would be easier with indexed allocation. This tests sequential access overhead. Remember that linked allocation supports easy expansion but makes random access inefficient.

Q11. A file system uses indexed allocation with one index block containing 100 block addresses. Each address requires 4 bytes. What is the maximum data capacity addressed by this index block if each data block is 2 KB?

A.100 KB
B.150 KB
C.200 KB ✅
D.400 KB
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The index block can store \(100 / 4 = 25\) addresses only if 100 represents bytes, but here it contains 100 block addresses, each requiring 4 bytes. Therefore, it addresses 100 data blocks, providing \(100 \times 2 = 200\) KB. This tests indexed allocation capacity. Multiply the number of stored addresses by data-block size.

Q12. A storage device has an average seek time of 5 ms and an average rotational latency of 4 ms. Ignoring transfer time, what is the average access time for a disk request?

A.1 ms
B.5 ms
C.9 ms ✅
D.20 ms
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Average disk access time without transfer time is the sum of seek time and rotational latency. Therefore, \(5 + 4 = 9\) ms. Selecting 1 ms subtracts the two delays instead of adding them. This tests magnetic disk access performance. Remember the three components of disk access: seek time, rotational latency, and transfer time.

Q13. A hard disk rotates at 7,200 revolutions per minute. Assuming uniform rotational positioning, what is its average rotational latency?

A.2.08 ms
B.4.17 ms ✅
C.8.33 ms
D.16.67 ms
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A rotation takes \(60,000 / 7,200 = 8.33\) ms. Average rotational latency is half a revolution, giving approximately \(8.33 / 2 = 4.17\) ms. Choosing 8.33 ms represents a full rotation rather than the average waiting time. This tests disk rotational latency. Calculate one full revolution first, then divide by two.

Q14. A file system uses FAT-style allocation. The allocation table shows that block 12 points to block 18, block 18 points to block 25, and block 25 contains an end-of-file marker. What is the next block to read after block 18?

A.12
B.18
C.25 ✅
D.The first free block
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The allocation table records the next block in a file's chain. Since block 18 points to block 25, the operating system reads block 25 next. Returning to block 12 would move backward in the chain. This tests file allocation table traversal. Follow the stored pointer rather than assuming that file blocks are physically consecutive.

Q15. A storage administrator wants to improve sequential file access on a magnetic disk. Which technique can reduce the number of separate physical locations that must be accessed?

A.File fragmentation
B.Disk defragmentation ✅
C.Increasing rotational latency
D.Disabling the file system cache
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Disk defragmentation reorganizes fragmented file blocks into more contiguous locations, reducing unnecessary seek movements during sequential access. Increasing rotational latency would make performance worse. This tests disk optimization. Remember that defragmentation primarily benefits magnetic hard disks, while SSDs generally do not require traditional defragmentation.

Q16. A disk has 200 cylinders numbered 0 through 199. The head is at cylinder 100, moving toward higher-numbered cylinders. Requests are pending at 20, 60, 110, 150, and 180. Under SCAN scheduling, which request will be serviced first?

A.20
B.60
C.110 ✅
D.180
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: SCAN initially continues in its current direction. The pending requests above cylinder 100 are 110, 150, and 180, so cylinder 110 is reached first. Choosing 60 would require reversing direction prematurely. This tests elevator-style disk scheduling. Follow the current direction until the requests in that direction are serviced.

Q17. A disk head begins at cylinder 50 and services requests at 70, 90, and 120 while moving upward. Under C-SCAN scheduling, what happens after the head reaches the final cylinder at 199?

A.It reverses direction and services lower requests immediately
B.It moves directly to cylinder 0 and continues upward ✅
C.It stops until a new request arrives
D.It moves to cylinder 120 and repeats the same request
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: C-SCAN services requests in one direction and then returns to the beginning without servicing requests during the return movement. After reaching cylinder 199, the head moves to cylinder 0 and resumes upward service. Reversing direction to service requests is characteristic of SCAN. Remember that C-SCAN provides more uniform waiting times.

Q18. A system administrator configures RAID 1 using two 2 TB drives. What usable storage capacity is available for mirrored data?

A.1 TB
B.2 TB ✅
C.3 TB
D.4 TB
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: RAID 1 mirrors the same data across both drives. Therefore, two 2 TB drives provide 2 TB of usable capacity, while the other 2 TB stores the duplicate copy. Counting both drives as usable capacity confuses mirroring with striping. This tests RAID redundancy. For mirrored pairs, usable capacity generally equals the capacity of the smaller drive.

Q19. A database server uses RAID 0 with four 1 TB drives. What is the main characteristic of this configuration?

A.It provides 4 TB of striped storage without redundancy ✅
B.It provides 2 TB of mirrored storage with redundancy
C.It provides 3 TB of parity-protected storage
D.It provides 1 TB of storage with complete duplication
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: RAID 0 stripes data across all four drives, giving a combined capacity of \(4 \times 1 = 4\) TB. It does not provide redundancy, so one drive failure can destroy the array's data. The mirrored-capacity option confuses RAID 0 with RAID 1. Remember that striping improves performance but does not protect against drive failure.

Q20. A storage system uses RAID 5 with four 2 TB drives. Assuming equal-sized drives and one drive's capacity reserved for distributed parity, what is the usable storage capacity?

A.4 TB
B.6 TB ✅
C.8 TB
D.2 TB
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: RAID 5 uses the equivalent of one drive's capacity for distributed parity. With four 2 TB drives, usable capacity is \((4 - 1) \times 2 = 6\) TB. Choosing 8 TB ignores parity overhead. This tests RAID 5 capacity and fault tolerance. For RAID 5, subtract one drive's capacity from the total array capacity.

Q21. A company wants a storage configuration that can continue operating after one drive fails while distributing data and parity across multiple drives. Which RAID level meets this requirement?

A.RAID 0
B.RAID 1
C.RAID 5 ✅
D.JBOD
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: RAID 5 distributes both data and parity across at least three drives and can tolerate one drive failure. RAID 0 offers no redundancy, while RAID 1 uses mirroring instead of distributed parity. This tests RAID fault tolerance. Remember that RAID 5 survives one drive failure, but it is not a substitute for backups.

Q22. A computer suddenly loses power while cached disk writes are waiting to be transferred to permanent storage. Which technology is specifically designed to protect pending writes against this failure?

A.Disk defragmentation
B.Write-back caching without protection
C.Volatile RAM caching
D.Battery-backed or non-volatile write cache ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Battery-backed or non-volatile cache preserves pending writes when normal power is lost, allowing them to be safely committed later. Ordinary volatile RAM loses its contents during a power failure. This tests write caching and storage reliability. Always distinguish performance caching from protected write caching when evaluating data-loss risks.
