What is Computer System Architecture in Operating System?

Definition:
Computer system architecture defines the attributes of a system visible to a programmer or those attributes that have a direct impact on the logical execution of a program. It includes the instruction set, data types, addressing modes, and register organization that the operating system utilizes to manage hardware resources effectively.

Working:
The architecture provides the interface between software and hardware. The OS uses specific instructions defined by the architecture, such as privileged instructions for mode switching (user to kernel). It relies on the architecture's memory model to implement virtual memory and protection mechanisms through base and limit registers.

Example:
In x86 architecture, the `INT` instruction is used to trigger a software interrupt. When the OS needs to perform a system call, it executes this instruction, which saves the current state, switches to kernel mode, and jumps to the predefined interrupt vector table to execute the OS service routine.

Reason:
Architecture determines the capabilities and limitations of the system. The OS must be designed specifically for the underlying architecture to utilize features like multi-level paging or hardware-assisted virtualization. It ensures compatibility and efficient execution of binary code.

Common MisConceptions:
A common mistake is thinking architecture changes frequently. In reality, architectures are stable to maintain backward compatibility. Students also confuse RISC and CISC architectures, not realizing that modern processors often blend both approaches internally while maintaining a specific architectural interface.

Exam Preparation Tips: How to prepare this topic
Study the difference between RISC and CISC. Understand the concept of privileged vs. non-privileged instructions. Learn how the architecture supports dual-mode operation (user/kernel) which is fundamental to OS security. Review specific architecture examples like ARM or x86.

Key Terms:

  • Instruction Set Architecture (ISA) - The part of the computer architecture related to programming, including data types, registers, and instructions.
  • Privileged Instruction - An instruction that can only be executed in kernel mode to prevent user programs from harming the system.
  • Mode Bit - A hardware bit indicating whether the system is in user mode or kernel mode.

📝 All Computer System Architecture in Operating System MCQs

Q1. A company needs a computer to execute several independent computational tasks simultaneously. Which hardware configuration most directly supports true parallel execution?

A.A single CPU core with a larger monitor
B.A single CPU core with additional keyboard ports
C.A single CPU core with more disk partitions
D.Multiple CPU cores capable of executing independent instruction streams simultaneously ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Multiple CPU cores can execute independent instruction streams at the same time, enabling true parallelism. A single core can support concurrency through context switching, but it cannot execute two independent instruction streams simultaneously on that same core.

Q2. A computer uses one processor with a single core to run a browser, a music player, and a text editor. All applications appear to make progress. Which explanation best describes this behavior?

A.Each application necessarily has a dedicated physical CPU
B.The operating system switches CPU execution among processes, creating the appearance of simultaneous activity ✅
C.The RAM independently executes application instructions
D.The storage controller performs all application computations
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: On a single-core processor, the operating system can use time-sharing and context switching to allow several processes to make progress. Although only one instruction stream executes on the core at a time, rapid switching creates the appearance of simultaneous execution.

Q3. A computer designer wants to reduce the average time required to access frequently used instructions and data without purchasing extremely expensive memory for the entire system. Which design is most appropriate?

A.Use a memory hierarchy with small, fast caches backed by larger main memory and secondary storage ✅
B.Replace all main memory with a mechanical hard disk
C.Store all frequently used instructions exclusively on a USB drive
D.Remove cache memory and increase the number of input devices
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A memory hierarchy balances speed, capacity, and cost. Small, fast cache memories keep frequently accessed data close to the processor, while main memory and secondary storage provide larger capacities at lower cost per unit. Effective caching reduces average memory access time.

Q4. A processor spends much of its time waiting for data from main memory. The designer adds a cache that frequently contains the requested data. What is the most likely performance improvement?

A.Every instruction will require zero clock cycles
B.The processor will no longer need registers
C.The average memory access time may decrease because many accesses are served by the faster cache ✅
D.Secondary storage will automatically become faster than main memory
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When the requested data is present in cache, the processor can often access it more quickly than data in main memory. A higher cache hit rate can reduce average memory access time and improve performance, although cache misses and other bottlenecks still introduce delays.

Q5. A computer has one CPU, multiple processors' worth of work, and a single shared main memory. Two independent processes execute on separate CPU cores and frequently access the same memory locations. Which challenge is most relevant?

A.The computer must stop using its operating system
B.Each core must permanently own the entire physical memory
C.Parallel execution automatically prevents every memory conflict
D.The system must coordinate shared-memory access and handle synchronization where necessary ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Multiple cores can execute concurrently while sharing physical memory. When processes or threads access shared data, synchronization mechanisms such as locks or atomic operations may be needed to prevent race conditions. Cache coherence and memory-ordering rules also influence correct shared-memory behavior.

Q6. A student claims that a computer with four CPU cores will always run every application four times faster than a single-core computer. Which assessment is most accurate?

A.Correct, because every program automatically divides into four independent tasks
B.Incorrect, because speedup depends on parallelizable work, synchronization overhead, memory bandwidth, and other bottlenecks ✅
C.Correct, because CPU cores eliminate all input/output delays
D.Incorrect, because multiple cores cannot execute instructions simultaneously
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Multiple cores can improve performance when a workload contains independent tasks that can run in parallel. However, serial sections, synchronization, communication overhead, memory bandwidth limits, and input/output delays restrict speedup. Four cores therefore do not guarantee a fourfold reduction in execution time.

Q7. A processor uses a 32-bit address to identify individual byte locations in a flat address space. Ignoring reserved regions and hardware limitations, what is the largest addressable space?

A.2322^{32}232 bytes, equivalent to 4 GiB ✅
B.2162^{16}216 bytes, equivalent to 64 KiB
C.2322^{32}232 bits, equivalent to 4 GiB of bits only
D.32232^2322 bytes, equivalent to 1 KiB
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A 32-bit address can represent 2322^{32}232 distinct address values. If each address identifies one byte, the theoretical address space is 2322^{32}232 bytes, or 4 GiB. Actual usable memory can be smaller because hardware and operating system mappings reserve portions of that space.

Q8. A CPU executes an instruction that adds two values stored in registers. Which component is primarily responsible for carrying out the arithmetic operation?

A.The system clock alone
B.The disk controller
C.The arithmetic logic unit ✅
D.The memory management unit alone
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The arithmetic logic unit, or ALU, performs arithmetic and logical operations such as addition, subtraction, comparisons, and Boolean logic. Registers provide fast storage for operands and results, while control circuitry coordinates instruction execution.

Q9. A processor's clock frequency increases from 2 GHz to 3 GHz, but the program's execution time barely changes. Which explanation is most plausible?

A.Clock frequency has no relationship to processor operation
B.The operating system has permanently disabled the processor
C.Every instruction now takes exactly the same number of seconds on every processor
D.The workload may be limited by memory access, input/output, dependencies, or other factors rather than raw clock frequency ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: A higher clock frequency can allow more clock cycles per second, but it does not guarantee proportional performance improvement. Programs may be limited by memory latency, input/output, instruction dependencies, cache misses, or inefficient code. Instructions per cycle and processor architecture also affect performance.

Q10. A graph shows cache hit rates of 60%, 75%, 90%, and 95% across four configurations. The corresponding average memory access times steadily decrease. What is the most reasonable interpretation?

A.Higher cache hit rates can reduce average access time when cache hits are faster than misses ✅
B.The graph proves that the processor no longer requires main memory
C.A cache miss is always faster than a cache hit
D.Cache hit rate determines the number of CPU cores in the system
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: If cache hits are faster than accesses that require main memory, increasing the proportion of hits generally reduces average memory access time. The exact improvement depends on hit latency, miss penalty, cache hierarchy, and other factors, so hit rate alone does not determine overall system performance.

Q11. A processor fetches an instruction, determines what operation it represents, and then performs the required operation. Which sequence best matches the basic instruction cycle?

A.Execute, permanently delete memory, and shut down
B.Decode, shut down the processor, and restart the computer
C.Fetch, decode, and execute ✅
D.Store, print, and format
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The basic instruction cycle is commonly described as fetch, decode, and execute. The processor fetches an instruction from memory, decodes its operation and operands, and executes it. Additional stages, such as memory access and write-back, may appear in more detailed processor pipelines.

Q12. A processor uses pipelining to overlap different stages of several instructions. One instruction depends on the result of an earlier instruction that has not yet completed. What problem can arise?

A.All instructions are guaranteed to complete in one clock cycle
B.A data hazard may require forwarding, a stall, or another dependency-handling mechanism ✅
C.Pipelining automatically doubles the number of physical CPU cores
D.The dependency forces the computer to erase main memory
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Pipelining overlaps instruction stages to improve throughput, but dependencies can create hazards. A later instruction may need a value that an earlier instruction has not yet produced. Processors can use forwarding, stalls, scheduling, or related mechanisms to preserve correct execution.

Q13. A system has separate instruction and data caches, allowing instruction fetches and data accesses to proceed through separate cache paths. Which architectural idea does this resemble?

A.A disk-only memory hierarchy
B.A system with no processor registers
C.A processor that cannot execute instructions
D.A Harvard-style organization with separate instruction and data paths at the relevant level ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Harvard architecture distinguishes instruction storage and data storage or their access paths. Modern processors often use a modified Harvard design with separate instruction and data caches while sharing main memory. This can allow instruction fetches and data accesses to occur concurrently.

Q14. A system designer compares a single-core processor running one task with a multicore processor running four independent CPU-bound tasks. The multicore processor completes the tasks in less total time. Which explanation is strongest?

A.Independent tasks can execute in parallel on separate cores, reducing total completion time when other bottlenecks are limited ✅
B.The multicore processor never needs an operating system
C.A single-core processor cannot execute any arithmetic instructions
D.The multicore processor automatically increases the storage capacity of each task
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Independent CPU-bound tasks can run simultaneously on different cores, reducing their combined completion time. The degree of improvement depends on workload independence, core performance, scheduling, memory bandwidth, and synchronization. Multicore hardware still relies on the operating system for resource management.

Q15. A computer has a 64-bit processor but runs an operating system configured with a restricted virtual address space for each process. Which statement is correct?

A.A 64-bit processor guarantees that every process can use all physical RAM without restrictions
B.The operating system cannot use virtual memory on a 64-bit processor
C.The architecture's address width does not by itself guarantee that all possible addresses are available to every process ✅
D.Every process must receive exactly 64 GB of RAM
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: A 64-bit processor can represent a very large theoretical address space, but usable virtual addresses depend on the processor implementation and operating system. Physical memory capacity, address translation, process limits, and reserved address regions can restrict what an individual process can access.

Q16. A CPU has a cache access time of 2 ns, a main-memory access time of 50 ns, and a cache hit rate of 90%. Assuming one-level caching, a hit takes 2 ns, and every miss adds a 50 ns memory access, what is the average access time?

A.7 ns
B.5 ns
C.52 ns
D.12 ns ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: With a 90% hit rate, 90% of accesses take 2 ns and 10% take approximately 52 ns under the stated assumption that a miss requires the additional main-memory access. The average is 0.9(2)+0.1(52)=70.9(2)+0.1(52)=70.9(2)+0.1(52)=7 ns. This illustrates how frequent cache hits reduce average access time.

Q17. An operating system runs on a system where several devices can generate interrupts. Why does the processor need a mechanism to identify and handle the appropriate interrupt source?

A.Every interrupt must be handled by the same application
B.Different interrupt sources may require different handlers and response actions ✅
C.Interrupts always mean that the CPU has physically failed
D.The processor cannot resume normal execution after an interrupt
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Interrupts can originate from different devices or events, and each may require a different response. Interrupt vectors, controller information, and operating system handlers help identify and process the event. After handling it, the processor can resume suitable work according to the architecture and scheduling rules.

Q18. A computer's memory subsystem can deliver 20 GB/s, while two active devices together request 30 GB/s of sustained data transfers. What is the most likely result if they share that same limited path?

A.Both devices will automatically receive 30 GB/s each
B.The operating system will permanently double the physical bus speed
C.Neither device will need main memory
D.The combined transfers will be limited by the shared bandwidth, potentially causing contention or delays ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: If the shared memory path can sustain only 20 GB/s, it cannot continuously deliver the requested combined 30 GB/s. The devices must share the available capacity, causing contention, reduced transfer rates, or queuing. Improving performance may require a faster path or reducing traffic.

Q19. A designer wants to reduce the number of memory accesses required to execute a program that repeatedly uses the same small set of values. Which processor feature is most directly helpful?

A.CPU registers that hold frequently used operands and intermediate results ✅
B.A larger monitor with a higher refresh rate
C.An additional printer connected to the computer
D.A larger file-system directory table alone
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: CPU registers provide extremely fast storage for operands, addresses, and intermediate results. Keeping frequently used values in registers can reduce the need to access cache or main memory. Register allocation and instruction scheduling help compilers and processors use these limited resources effectively.

Q20. A processor executes a conditional branch. If the branch direction is predicted incorrectly, some instructions that entered the pipeline may need to be discarded. Which mechanism helps reduce the average performance penalty of branches?

A.Removing all conditional instructions from software
B.Disabling the processor's clock during every branch
C.Branch prediction combined with recovery mechanisms for incorrect predictions ✅
D.Replacing registers with secondary storage
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Branch prediction estimates which path a conditional instruction will take so the processor can continue fetching instructions without waiting for the branch to resolve. If the prediction is wrong, speculative work may be discarded and execution redirected, causing a performance penalty.

Q21. A computer uses virtual memory so each process sees a large, private address space, even though physical RAM is shared. Which hardware component commonly translates virtual addresses into physical addresses?

A.The monitor controller
B.The memory management unit ✅
C.The audio controller
D.The keyboard buffer
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The memory management unit, or MMU, performs address translation and enforces memory-access permissions using operating system-managed mappings. Virtual memory allows processes to use separate address spaces and supports protection, flexible memory allocation, and mechanisms such as paging.

Q22. A system's performance graph shows instruction throughput rising as pipeline stages are added, then leveling off despite further increases in pipeline depth. Which explanation is most plausible?

A.Every additional pipeline stage must double instruction throughput
B.Pipeline depth eliminates all data dependencies and branch penalties
C.The graph proves that the clock frequency has fallen to zero
D.Hazards, stage overhead, dependencies, and other bottlenecks can limit the benefits of deeper pipelining ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Pipelining can improve throughput by overlapping instruction execution stages, but additional stages introduce overhead and may increase the penalties of branches and dependencies. Uneven stage delays, register overhead, and limited parallelism can prevent deeper pipelines from producing further gains.

Q23. A program contains 80% parallelizable work and 20% strictly sequential work. Assuming ideal execution and no overhead, what is the maximum speedup possible with an unlimited number of processor cores?

A.5 times
B.10 times
C.5 times is the limit because only 20% can remain sequential ✅
D.Unlimited, because parallel work has no execution time
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Amdahl's law states that the sequential portion limits total speedup. If 20% of execution remains sequential, the ideal maximum with unlimited cores is 1/0.2=51/0.2=51/0.2=5. The parallel portion can approach zero execution time in the ideal model, but the sequential portion remains.

Q24. A processor supports both user mode and kernel mode. A user application attempts to change a hardware control register directly, and the processor rejects the instruction. What architectural purpose does this restriction serve?

A.It prevents applications from bypassing privileged operating system control and damaging system integrity ✅
B.It guarantees that every application uses the same amount of RAM
C.It ensures that all programs execute only from secondary storage
D.It prevents the operating system from handling hardware interrupts
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Processor privilege modes restrict sensitive operations to authorized kernel code. By rejecting privileged instructions from user mode, the hardware helps prevent applications from changing critical control settings or bypassing operating system protection. Controlled system calls allow approved services to perform these operations.

Q25. A server contains two physical processors, each with multiple cores, but its workload consists mainly of a single-threaded task with little parallelism. Which conclusion is most accurate?

A.The server must execute the single thread on every core simultaneously
B.The operating system cannot schedule the task because multiple processors exist
C.The task will always run faster than a parallel workload
D.The additional cores may provide limited speedup for this task, although they can help other concurrent workloads ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A largely single-threaded task cannot automatically divide its sequential instructions across many cores. It may benefit from faster individual-core performance or other architectural improvements, but additional cores are more useful for independent concurrent workloads and parallelizable sections.

Q26. A computer uses a write-back cache. A processor updates a cached memory block, but the updated data is not immediately written to main memory. What must the cache system generally ensure?

A.The modified block is discarded immediately after every write
B.The modified data is eventually propagated to the required memory level according to the cache-coherence and write-back policy ✅
C.The CPU must stop executing until the computer is restarted
D.Every other cache must permanently store an unrelated copy
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: In a write-back cache, modified data can remain in cache and be written to lower memory levels later. The system must track dirty blocks and ensure that updated values are propagated correctly when required. In multicore systems, coherence mechanisms help maintain an appropriate view of shared data.

Q27. A processor design improves single-thread execution but reduces the bandwidth available between CPU cores and main memory. A workload performs many memory-intensive operations across multiple cores. Which outcome is most plausible?

A.The workload must become faster because single-thread performance improved
B.The operating system will eliminate every memory access
C.The workload may slow down under heavy contention because memory bandwidth limits parallel performance ✅
D.The processor will no longer require caches
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Memory-intensive parallel workloads can saturate the available bandwidth between cores and memory. Improving single-thread execution does not guarantee better multicore throughput if the shared memory subsystem becomes the bottleneck. Cache behavior, access patterns, locality, and bandwidth must be considered together.
