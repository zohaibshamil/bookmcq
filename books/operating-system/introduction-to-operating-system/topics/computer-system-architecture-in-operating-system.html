📝 Computer System Architecture in Operating System (23 MCQs)

Definition of Computer System Architecture:

Computer system architecture describes the arrangement of processors and their relationships with memory and other hardware components. Operating systems use architectural characteristics to determine how processing resources are managed. It distinguishes single-processor, multiprocessor, and multicore systems. Without appropriate architectural support, parallel workloads may remain inefficient or execute incorrectly.

How Computer System Architecture Works:

A single-processor system uses one general-purpose processor for instruction execution. A multiprocessor system contains multiple processors that can execute tasks concurrently. In symmetric multiprocessing, processors generally share memory and operating system responsibilities. Asymmetric multiprocessing assigns different responsibilities to processors. Multicore processors integrate multiple processing cores within one physical processor.

Computer System Architecture Example:

Consider a system containing four processing cores. Process A executes on Core 1, Process B on Core 2, Process C on Core 3, and Process D on Core 4. If all processes are ready and resources are available, four instructions streams can execute concurrently.

Why Computer System Architecture Matters:

Multiprocessor architecture provides greater potential processing throughput than a single processor. A single processor cannot execute multiple instruction streams simultaneously. However, parallel execution introduces synchronization, scheduling, and communication overhead, so adding processors does not guarantee proportional performance improvement.

Common Misconceptions About Computer System Architecture:

'Four cores always provide four times the performance.' Correction: Dependencies and resource contention limit scaling. 'Multicore and multiprocessor mean exactly the same thing.' Correction: They describe different hardware arrangements. 'All processors must share one memory.' Correction: Architecture determines memory organization.

Exam Tips for Computer System Architecture:

Compare single-processor and multiprocessor systems. Understand symmetric and asymmetric multiprocessing. Distinguish physical processors from processing cores. Exams commonly ask architecture comparisons, parallel execution scenarios, and advantages and limitations of multiprocessor systems.

Key Terms in Computer System Architecture:

  • Multiprocessing - Using multiple processors for computation.
  • Multicore - Multiple processing cores integrated into one processor.
  • SMP - Symmetric multiprocessing with shared responsibilities.
  • AMP - Asymmetric multiprocessing with differentiated processor responsibilities.

📝 All Computer System Architecture in Operating System MCQs

Q1. A university purchases a computer with one processor containing eight independent processing cores. Each core can execute instructions independently, allowing several tasks to run simultaneously. How should this computer be classified in terms of processor architecture?

A.Single-processor system
B.Multiprocessor system ✅
C.Single-user system
D.Batch-processing system
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A processor containing multiple independent cores provides multiple execution units capable of parallel processing. In operating system architecture, this is commonly treated as a multicore multiprocessor system. A single-user system describes user access rather than processor organization. Remember that multiple cores can execute different instruction streams simultaneously.

Q2. A server contains four separate CPU sockets, each holding an independent processor. The operating system distributes application workloads across these processors. What architectural configuration does this represent?

A.Single-core architecture
B.Distributed architecture
C.Multiprocessor architecture ✅
D.Uniprogramming architecture
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: A computer with four independent processors is a multiprocessor system because multiple CPUs share the computer's resources and execute tasks concurrently. Distributed architecture generally involves separate networked computers. Remember that multiple physical processors or processor cores provide opportunities for parallel execution.

Q3. Two processors in a computer share the same physical memory and communicate through a common interconnection system. A process running on either processor can access the shared memory. What type of architecture is being used?

A.Symmetric multiprocessing ✅
B.Distributed-memory multiprocessing
C.Single-user processing
D.Asymmetric multiprocessing
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Symmetric multiprocessing uses multiple processors that share main memory and generally have equal access to operating system resources. Distributed-memory systems use separate local memories, while asymmetric systems may assign different responsibilities to processors. Remember that shared memory and peer-like processor roles are key indicators of SMP.

Q4. A server has two processors. Processor 0 handles operating system activities and assigns specific tasks to processor 1, which performs dedicated calculations. Which multiprocessing arrangement does this represent?

A.Symmetric multiprocessing
B.Time-sharing architecture
C.Distributed-memory architecture
D.Asymmetric multiprocessing ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Asymmetric multiprocessing assigns different responsibilities to processors, often with one processor controlling the system and another performing assigned tasks. In symmetric multiprocessing, processors generally have equal roles. Remember that a master-worker or master-slave processor arrangement indicates asymmetric multiprocessing.

Q5. A graphics application performs 80% of its workload sequentially and 20% in parallel. It is moved from a single-core processor to a four-core processor. Assuming the parallel portion is divided equally among the four cores and ignoring overhead, what is the approximate maximum speedup?

A.1.18 times ✅
B.1.29 times
C.1.67 times
D.2.50 times
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Using Amdahl's law, speedup is \(1/[0.8+(0.2/4)] = 1/0.85 \\approx 1.18\). The sequential portion limits the benefit of additional cores. The 4-core count does not produce fourfold speedup. Remember that Amdahl's law evaluates parallel performance by considering the serial fraction.

Q6. A computer contains multiple processors connected to one shared memory module. Two processors attempt to update the same memory location simultaneously. What major issue must the operating system and hardware manage?

A.Instruction decoding
B.Disk fragmentation
C.Memory consistency and synchronization ✅
D.File system formatting
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When multiple processors access shared memory concurrently, synchronization and memory consistency become important to prevent incorrect results. Locks, atomic operations, and memory-ordering mechanisms help coordinate access. Instruction decoding does not resolve competing memory updates. Remember that shared-memory multiprocessing requires synchronization for shared data.

Q7. A company operates several independent computers connected through a network. Each computer has its own processor and local memory, but they cooperate to provide a computing service. Which architecture does this describe?

A.Distributed system ✅
B.Symmetric multiprocessing
C.Single-core system
D.Uniform memory access system
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A distributed system consists of independent computers connected through a network that cooperate to perform tasks or provide services. Each computer maintains its own processor and local memory. SMP instead involves processors sharing a computer's memory. Remember that network-connected independent machines indicate distributed architecture.

Q8. A multiprocessor server has four CPUs sharing memory. The operating system assigns a process to CPU 1, but later moves it to CPU 3 because of workload balancing. What is the main advantage of this capability?

A.It eliminates all memory access delays
B.It prevents every context switch
C.It removes the need for process scheduling
D.It improves processor utilization and workload distribution ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Moving processes between processors allows the operating system to balance workloads and use available processing capacity more effectively. This is a form of load balancing. It does not eliminate context switches or memory delays. Remember that processor scheduling in multiprocessor systems considers workload distribution and processor availability.

Q9. A system has four processors, each with access to the same main memory. However, accessing memory takes different amounts of time depending on which processor requests it. What memory architecture is being used?

A.Uniform Memory Access
B.Non-Uniform Memory Access ✅
C.Distributed file system
D.Single-level caching
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Non-Uniform Memory Access, or NUMA, provides shared address-space access but with different memory access times depending on the processor and memory location. Uniform Memory Access provides approximately equal access latency. Remember that unequal memory access times across processors are the defining characteristic of NUMA.

Q10. A computer uses NUMA architecture with two processor nodes. Each processor can access its local memory faster than memory attached to the other node. An application frequently accesses data stored in the other node's memory. What is the likely performance consequence?

A.Reduced processor clock frequency
B.Increased instruction set size
C.Higher memory access latency ✅
D.Automatic elimination of cache misses
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: In NUMA systems, remote memory access generally takes longer than local memory access because data must travel through an interconnection system. Frequent remote accesses can therefore reduce application performance. Cache misses are not automatically eliminated. Remember that NUMA-aware memory allocation attempts to keep frequently accessed data near the processor using it.

Q11. A computer contains two processor cores that share a last-level cache but have separate private L1 caches. Core 0 modifies a memory location, and Core 1 still has an older copy in its L1 cache. What mechanism is needed to maintain correct shared-memory behavior?

A.Cache coherence protocol ✅
B.Disk scheduling algorithm
C.Virtual memory paging
D.Interrupt prioritization
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A cache coherence protocol ensures that multiple cached copies of shared data remain consistent when one processor modifies a value. Without coherence, Core 1 could read stale data from its private cache. Disk scheduling and paging address different problems. Remember that cache coherence is essential when processors maintain private caches of shared memory.

Q12. A computer has four cores, but a program consists of a single execution thread that cannot be parallelized. How many cores can normally execute that thread's instructions simultaneously?

A.Four cores
B.Two cores
C.Three cores
D.One core ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: A single execution thread follows one sequential instruction stream and normally executes on only one core at a time. Additional cores can execute other threads or processes but cannot automatically parallelize dependent instructions. Remember that multicore hardware improves parallelism only when suitable concurrent workloads exist.

Q13. A cloud service distributes incoming requests among eight independent servers connected through a network. Each server processes requests using its own CPU and memory. What is the primary architectural advantage of this arrangement?

A.Elimination of network communication
B.Scalability through distributed processing ✅
C.Guaranteed identical execution time
D.Removal of all synchronization requirements
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Distributed processing allows workloads to be divided among independent computers, making it possible to increase capacity by adding servers. Network communication and coordination may still be necessary. Identical execution times are not guaranteed. Remember that horizontal scaling increases capacity by adding independent computing nodes.

Q14. A multiprocessor computer has six processors, but its operating system can use only four because of a configuration restriction. If each processor can independently execute one task at a time, what is the maximum number of tasks that can execute simultaneously?

A.Two
B.Six
C.Four ✅
D.Twenty-four
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Although six processors are physically installed, the operating system can schedule execution on only four under the stated configuration. Therefore, at most four tasks can execute simultaneously, assuming one task per processor. The physical processor count alone does not determine usable parallelism. Remember to consider operating system restrictions when calculating effective processing capacity.

Q15. A system administrator compares two servers. Server A has one CPU with eight cores, while Server B has two CPUs with four cores each. Both have eight cores in total. Which conclusion is justified from the information provided?

A.Both have the same total number of processing cores, but their processor organization differs ✅
B.Server A must execute every application twice as fast
C.Server B necessarily has twice the memory bandwidth
D.Server A cannot support multiprocessing
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Both servers contain eight processing cores, but Server A organizes them in one physical CPU while Server B uses two physical CPUs. Their performance may differ because of cache, memory, and interconnection designs. Equal core counts do not guarantee identical performance. Remember to distinguish physical CPU packages from processing cores.

Q16. A processor architecture provides separate memory spaces for each processor. When one processor needs data from another processor, it must request the data through an explicit communication mechanism. What type of multiprocessing architecture is this?

A.Shared-memory architecture
B.Uniform memory access architecture
C.Symmetric multiprocessing
D.Distributed-memory architecture ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Distributed-memory architecture gives each processor its own local memory rather than a single directly shared memory space. Processors exchange information through explicit communication mechanisms such as message passing. Shared-memory systems allow processors to access common memory. Remember that separate address spaces indicate distributed-memory organization.

Q17. A computer has eight processors. During a workload, four processors remain idle while the other four are heavily occupied. The operating system can move ready processes between processors. What scheduling strategy could improve resource utilization?

A.Load balancing ✅
B.Disk defragmentation
C.Memory compaction
D.Batch job grouping
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Load balancing distributes processes or threads among processors to avoid situations where some CPUs are overloaded while others remain idle. Moving ready work to less busy processors can improve overall utilization. Memory compaction reorganizes memory rather than CPU workloads. Remember that load balancing aims to distribute computational work more evenly.

Q18. A parallel application executes on four processors. Its sequential fraction is 25%, while the remaining 75% can be divided equally among the processors. Ignoring overhead, what is its maximum speedup according to Amdahl's law?

A.1.60 times
B.2.29 times ✅
C.3.00 times
D.4.00 times
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Amdahl's law gives \(S=1/[0.25+(0.75/4)] = 1/0.4375 \\approx 2.29\). The sequential portion limits the achievable speedup even when four processors are available. A fourfold improvement incorrectly assumes the entire program is parallelizable. Remember to divide only the parallel fraction by the processor count.

Q19. A NUMA-based server has four processor nodes, each with local memory. An operating system schedules a process on node 2 but allocates most of its frequently accessed memory on node 0. Which change would most likely improve performance?

A.Move the process to the slowest available processor
B.Disable all memory caches
C.Allocate frequently accessed memory near node 2 ✅
D.Increase the number of system interrupts
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: NUMA performance improves when a process accesses memory attached to its local processor node. Moving frequently used data closer to node 2 reduces remote memory access latency. Disabling caches would generally worsen performance. Remember that NUMA-aware scheduling and memory allocation should preserve locality.

Q20. A system contains two processors that share the same physical memory. Processor 0 executes a process that frequently accesses data modified by processor 1. The processors use separate private caches. Why can frequent cache invalidations reduce performance?

A.They increase the number of physical CPU sockets
B.They eliminate the need for main memory
C.They increase the processor clock frequency
D.They create additional cache-coherence traffic and memory delays ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: When one processor modifies shared data, coherence protocols may invalidate copies held in other processors' caches. Repeated invalidations generate coherence traffic and force additional memory accesses, reducing performance. Cache invalidation does not increase CPU frequency. Remember that frequent sharing of writable cache lines can cause cache-coherence overhead.

Q21. A system uses a master processor to control scheduling and assign work to three worker processors. One worker becomes unavailable because of a hardware failure, but the master continues assigning tasks to the remaining workers. What architectural property is demonstrated?

A.Asymmetric multiprocessing with centralized control ✅
B.Symmetric multiprocessing with identical processor roles
C.Distributed memory with independent operating systems
D.Single-core execution with time-sharing
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Asymmetric multiprocessing uses processors with different assigned responsibilities, such as a master coordinating worker processors. The master can continue managing available workers when one becomes unavailable. SMP generally gives processors more equal responsibilities. Remember that centralized task assignment and specialized processor roles indicate asymmetric multiprocessing.

Q22. A research application runs on a 16-core computer. Its workload contains 10% sequential instructions and 90% parallel instructions. Assuming ideal parallel execution and no overhead, what is the approximate maximum speedup?

A.4.00 times
B.6.40 times ✅
C.8.42 times
D.16.00 times
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Applying Amdahl's law gives \(S=1/[0.10+(0.90/16)] = 1/0.15625 = 6.4\). Therefore, option B is correct, not C. The sequential 10% limits the maximum speedup despite 16 cores. Remember that even a small sequential fraction can significantly restrict parallel performance.

Q23. A computer has two processors sharing memory, but one processor has a much larger cache than the other. The operating system assigns a memory-intensive workload to the processor with the larger cache. Why might this improve performance?

A.The larger cache can reduce slower main-memory accesses ✅
B.The larger cache increases the physical address bus width
C.The larger cache eliminates process scheduling
D.The larger cache converts secondary storage into RAM
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A larger cache can hold more frequently accessed instructions and data, potentially increasing cache hit rates and reducing expensive RAM accesses. However, the benefit depends on workload locality and cache organization. Cache size does not change address bus width. Remember that cache effectiveness depends on access patterns, not capacity alone.
