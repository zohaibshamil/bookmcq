📝 Computer System Architecture in Operating System (30 MCQs)

Single-Processor, Multiprocessor, and Clustered Systems

Computer system architecture describes how processing units are arranged and coordinated to execute operating system workloads. A traditional single-processor system has one general-purpose CPU, whereas multiprocessor systems contain multiple processing units sharing or coordinating access to resources. Modern multicore processors integrate several execution cores, while clustered systems connect separate computers to provide coordinated services, availability, or computational capacity.

Why Multiple Processing Units Improve Computing Capacity

Increasing processor speed alone faces power, heat, and hardware-design limitations. Multiple cores allow independent instruction streams to execute simultaneously, improving throughput when workloads contain parallel tasks. Multiprocessor designs introduce coordination requirements, including shared-memory access, synchronisation, scheduling, and cache consistency. Clustered systems address different needs by connecting complete computers, although network communication and partial failures complicate coordination.

SMP, AMP, and NUMA Resource Organisation

In symmetric multiprocessing (SMP), processors generally share memory and operating system responsibilities, allowing work to be scheduled across available CPUs. Asymmetric multiprocessing assigns specialised or master-worker responsibilities to particular processors. Non-uniform memory access (NUMA) systems organise memory into locality domains, making access to nearby memory faster than remote memory. Kernel schedulers and memory managers must consider these architectural differences.

Scheduling Work Across Four Processor Cores

Consider four independent ready processes on a machine with four available CPU cores. Subject to scheduling decisions and resource availability, the operating system can dispatch one process to each core. They may execute simultaneously rather than taking turns on a single CPU. Shared-memory conflicts, synchronisation requirements, and uneven workloads can still prevent ideal fourfold speedup.

Parallel Throughput, Scalability, and Coordination Costs

Multiprocessing can improve throughput, responsiveness, and computational capacity, particularly in servers and parallel workloads. However, speedup is limited by sequential program sections, lock contention, memory bandwidth, and scheduling overhead. SMP offers flexible resource sharing, while NUMA-aware scheduling can reduce remote memory access. Clusters additionally provide opportunities for fault tolerance, but network delays and distributed coordination remain significant limitations.

Misconceptions About Multicore and Multiprocessor Systems

'Four cores guarantee four times the performance' is incorrect because sequential work and shared-resource contention limit speedup. 'Multicore and multiprocessor always describe the same hardware arrangement' is incorrect because cores may reside within one processor package or across multiple processors. 'A cluster is simply a multicore CPU' is incorrect because a cluster connects separate computer systems.

Exam Focus: Comparing Processor and Cluster Architectures

Be able to distinguish single-processor, multicore, SMP, AMP, NUMA, and clustered architectures. Explain symmetric scheduling, memory locality, shared-memory coordination, and the limitations of parallel speedup. Questions may present processor counts, core arrangements, or workload characteristics and ask which architecture provides simultaneous execution, scalability, or improved availability.

Key Terms of Computer System Architecture

  • Multicore - Multiple cores within one processor.
  • SMP - Symmetric shared-memory multiprocessing architecture.
  • AMP - Asymmetric processor responsibility arrangement.
  • NUMA - Memory access with unequal locality costs.
  • Cluster - Networked computers working together.
  • Scalability - Ability to handle increased workloads.

📝 All Computer System Architecture in Operating System MCQs

Q1. A workstation contains one general-purpose CPU and a graphics processor that handles rendering. How should its processor organization be classified?

A.A single-processor system with a special-purpose processor ✅
B.A symmetric multiprocessor system
C.A non-uniform memory access system
D.A clustered multiprocessor system
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: One general-purpose CPU controls overall execution, while the graphics processor performs a specialized workload. This remains a single-processor system in the operating-system sense; the tempting SMP option requires multiple peer general-purpose processors.

Q2. A database server contains four equivalent processors sharing main memory. The operating system can schedule user and kernel threads on any processor. Which architecture does this describe?

A.Asymmetric multiprocessing
B.Symmetric multiprocessing ✅
C.Distributed-memory multiprocessing
D.Active-standby clustering
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Symmetric multiprocessing gives processors comparable roles and access to shared memory under one operating-system image. The tempting asymmetric option assigns master and subordinate responsibilities rather than treating all processors as peers.

Q3. A computing system designates one processor to handle system-wide control and scheduling, while other processors execute assigned workloads. Which architecture is being implemented?

A.Symmetric multiprocessing
B.Distributed-memory multiprocessing
C.Asymmetric multiprocessing ✅
D.Multicore processing
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: In asymmetric multiprocessing, a designated master processor handles system control and assigns work to subordinate processors. The tempting symmetric option is wrong because it assumes every processor has the same operating-system responsibilities.

Q4. A manufacturer integrates eight independent processing cores onto one silicon chip. Each core can execute instructions independently, while some cache resources are shared. Which hardware organization is this?

A.A clustered system
B.A distributed-memory system
C.An asymmetric multiprocessor system
D.A multicore processor ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: A multicore processor places multiple processing cores on one physical chip, potentially sharing cache and memory interfaces. The tempting multiprocessor description usually refers to multiple processor packages or sockets, not merely multiple cores.

Q5. An online banking service operates two servers. One actively processes customer requests, while the second monitors its condition and assumes responsibility when the active server fails. What cluster arrangement is used?

A.Active-standby clustering ✅
B.Symmetric multiprocessing
C.Distributed-memory computing
D.Active-active clustering
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: An active-standby cluster keeps one node ready to assume service when the active node fails. The tempting active-active description instead has multiple nodes providing service concurrently, rather than reserving one solely for takeover.

Q6. A scientific computing system has eight processors. Four processors have long queues, while the remaining four are nearly idle. Which operating-system strategy can improve overall processor utilization?

A.Disable processor migration permanently
B.Assign every process to the busiest processor
C.Distribute executable work among overloaded and underused processors ✅
D.Reserve all processors for kernel execution
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Load balancing distributes work among available processors so one does not remain overloaded while others are idle. The tempting processor-affinity choice can preserve cache locality, but strict affinity may prevent useful redistribution during imbalance.

Q7. An industrial control cluster loses one processing node, but the remaining nodes continue operating with reduced processing capacity. Which system property does this demonstrate?

A.Linear scalability
B.Graceful degradation ✅
C.Perfect fault prevention
D.Uniform memory access
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Graceful degradation means a system continues providing reduced service after a component fails. The tempting fault-free option describes perfect reliability, not the ability to remain useful when some capacity is unavailable.

Q8. A research institution uses a computer in which each processor owns separate local memory. Programs exchange information between processors through an interconnection network. Which memory architecture is present?

A.Uniform shared-memory architecture
B.Single-processor memory architecture
C.Cache-only architecture
D.Distributed-memory architecture ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: In a distributed-memory architecture, each processor has its own local memory, so processors exchange data through messages or an interconnect. The tempting shared-address-space choice describes a different memory organization across processors.

Q9. A data center installs compact independent server modules inside a common enclosure that supplies shared power, cooling, and network connections. What hardware arrangement is being described?

A.Blade server architecture ✅
B.Single-core architecture
C.Non-uniform memory architecture
D.Asymmetric multiprocessing
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Blade servers package multiple compact server modules in a shared chassis that can provide power, cooling, and networking. The tempting cluster description concerns coordinated computers, not the physical packaging arrangement itself.

Q10. A computer contains a dedicated processor for encryption and another for graphics calculations. What is the primary architectural advantage of these specialized processors?

A.They eliminate the need for general-purpose processors
B.They guarantee identical execution speeds for all programs
C.They offload specialized workloads from general-purpose CPUs ✅
D.They automatically increase the computer's RAM capacity
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Special-purpose processors can offload tasks such as graphics, encryption, or storage operations from general-purpose CPUs. The tempting replacement claim is wrong because specialized units normally complement rather than eliminate general-purpose processors.

Q11. A database server uses NUMA architecture. Processor P0 accesses memory attached to P0 more quickly than memory attached to P1. Which design consideration follows from this arrangement?

A.All memory accesses must pass through one central processor
B.Processes and their frequently accessed memory should preferably remain near each other ✅
C.Remote memory must always be faster than local memory
D.The operating system must disable processor scheduling
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: NUMA systems provide faster access to a processor's local memory than to memory attached to another processor. The tempting uniform-latency assumption ignores this locality difference, which makes processor and memory placement important.

Q12. Two processors have private caches and access the same shared variable. Processor P0 updates the variable, but P1 may continue reading its previously cached value. Which mechanism addresses this problem?

A.Increasing the processor clock frequency
B.Adding another CPU without changing cache organization
C.Using separate executable files for both processors
D.Implementing a cache-coherence protocol ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Cache coherence ensures processors do not indefinitely rely on inconsistent cached copies of shared data. The tempting shared-memory assumption is insufficient because separate private caches can each hold an outdated copy of the same memory location.

Q13. A multiprocessor server initially gains throughput when processors are added. Eventually, all processors compete for a shared memory bus that cannot transfer additional data. What limits further performance improvement?

A.Memory-bus contention ✅
B.Processor instruction decoding
C.The bootstrap loading process
D.Directory-tree organization
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A shared bus limits aggregate memory traffic even when additional processors are installed. The tempting linear-scaling assumption ignores contention: once the bus saturates, extra CPUs cannot obtain the memory bandwidth needed to keep executing efficiently.

Q14. A parallel application contains 25% serial instructions and 75% parallel instructions. Four processors execute the parallel portion perfectly. What maximum speedup is predicted by Amdahl's law?

A.1.75
B.2
C.2.29 ✅
D.3
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Amdahl's law gives speedup as \(1/[0.25+0.75/4]\). The denominator is \(0.4375\), so speedup is about \(2.29\) for this workload. The tempting value four incorrectly assumes the serial quarter also runs in parallel.

Q15. A database process repeatedly accesses data already cached by processor P2. The scheduler frequently migrates it between P2 and P3, increasing cache misses. Which scheduling mechanism could reduce this overhead?

A.Unrestricted processor migration
B.Processor affinity ✅
C.Increasing the number of disk partitions
D.Disabling all hardware caches
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Processor affinity keeps a process on a preferred CPU, preserving useful cache contents and reducing migration costs. The tempting unrestricted-migration policy may balance queues, but repeated movement can discard locality and increase cache misses.

Q16. A clustered web service sends periodic heartbeat messages between its active server and standby server. The standby detects that the active server has stopped responding. What is the principal purpose of this mechanism?

A.Increasing the active server's processor clock speed
B.Reducing the size of the shared storage device
C.Synchronizing every CPU instruction across both servers
D.Detecting possible node failure so service can be transferred ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Heartbeat messages let cluster nodes detect when a peer may have failed, after which a standby node can take over. The tempting shared-storage assumption alone cannot detect failure or coordinate takeover safely.

Q17. An eight-processor database server generates a memory traffic demand of 12 GB/s per processor. Its shared memory bus can supply only 70 GB/s. Ignoring other limitations, what maximum aggregate memory transfer rate can the system sustain?

A.70 GB/s ✅
B.80 GB/s
C.96 GB/s
D.120 GB/s
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The processors request \(8\\times12=96\) GB/s, but the shared memory system supplies only 70 GB/s. Therefore aggregate transfers are capped at 70 GB/s; the tempting 96 GB/s ignores the shared bandwidth limit.

Q18. A NUMA database records memory latency of 80 ns for local accesses and 140 ns for remote accesses. If 75% of accesses are local and 25% are remote, what is average access latency?

A.90 ns
B.92 ns
C.95 ns ✅
D.110 ns
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Three quarters of accesses are local and one quarter remote, so average latency is \(0.75(80)+0.25(140)=95\) ns. The tempting 110 ns reverses the local and remote proportions under these access conditions.

Q19. A parallel server has twelve independent jobs, each requiring four milliseconds of CPU time. Two equivalent processors execute them with perfect distribution and no overhead. What is the minimum completion time for all jobs?

A.12 ms
B.24 ms ✅
C.48 ms
D.96 ms
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: With two processors, twelve equal jobs of four milliseconds require six waves. The makespan is \(6\\times4=24\) ms, assuming ideal distribution and no overhead; the tempting 48 ms assumes only one processor executes jobs.

Q20. A student estimates that a program with 20% serial instructions and 80% parallel instructions achieves an eightfold speedup on eight processors. Which correction identifies the error and gives the proper result?

A.The serial portion should be divided by eight, producing a speedup of 8
B.The parallel portion must remain unchanged, producing a speedup of 1.25
C.The total execution time becomes eight times longer, producing a speedup of 0.125
D.The serial portion remains unchanged, producing a speedup of approximately 3.33 ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The flawed step is multiplying speedup directly by eight. Amdahl's law gives \(1/[0.2+0.8/8]=3.33\), because the serial fifth remains unchanged; the tempting eightfold result assumes no serial work in the program.

Q21. A processor uses a write-through cache. A student claims that writing every modified cache value to main memory automatically guarantees that other processors cannot read stale copies. What is wrong with this reasoning?

A.Write-through updates memory but does not necessarily invalidate or update another processor's cached copy ✅
B.Write-through prevents all processors from accessing the same memory address
C.Write-through disables the cache-coherence hardware automatically
D.Write-through converts private caches into shared registers
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The flawed step is assuming write-through alone invalidates other private caches. It updates main memory, but another CPU may still hit a stale line; a coherence protocol must invalidate or update that copy.

Q22. A system contains several processors capable of executing general-purpose instructions. A student classifies it as symmetric multiprocessing solely because every processor has similar hardware. However, one processor performs system-wide control and assigns tasks to the others. Which classification is correct?

A.Distributed-memory architecture
B.Multicore architecture only
C.Asymmetric multiprocessing ✅
D.Uniform shared-memory architecture only
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The student's classification is wrong because processor capability does not determine whether a system is symmetric. In asymmetric multiprocessing, one processor has designated control duties; the tempting SMP label ignores this unequal organization.

Q23. Two active cluster nodes access the same database files on shared storage. A network partition prevents them from communicating, and each node assumes the other has failed. Which mechanism most directly prevents both nodes from independently becoming active database writers?

A.Increasing the shared disk capacity
B.Fencing or quorum-based ownership coordination ✅
C.Using a faster processor on each node
D.Increasing the heartbeat frequency without ownership control
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The flawed step is treating shared storage as an ownership lock. During a network partition, both nodes might activate; fencing or quorum-based ownership prevents simultaneous writers, while the tempting shared-disk assumption does not.

Q24. A parallel server records throughput against processor count: (1, 100 jobs/s) ; (2, 180 jobs/s) ; (4, 300 jobs/s) ; (8, 420 jobs/s) ; (16, 440 jobs/s). What happens when processors increase from eight to sixteen?

A.Throughput decreases by 20 jobs/s
B.Throughput increases by 110 jobs/s
C.Throughput doubles to 840 jobs/s
D.Throughput increases by only 20 jobs/s, showing diminishing returns ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Throughput rises from 420 to 440 jobs per second when processors double from eight to sixteen, a gain of only 20. The tempting linear-scaling interpretation ignores the clear plateau at higher processor counts.

Q25. A NUMA server records remote-memory percentage and average access latency: (0, 80 ns) ; (20, 92 ns) ; (40, 104 ns) ; (60, 116 ns) ; (80, 128 ns). What is the average latency when 60% of accesses are remote?

A.116 ns ✅
B.104 ns
C.128 ns
D.140 ns
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: At 60% remote accesses, 40% remain local: \(0.4(80)+0.6(140)=116\) ns. The tempting 104 ns corresponds to 40% remote accesses, not the 60% stated in the table for this requested point.

Q26. A multiprocessor server records processor count and average memory latency: (1, 70 ns) ; (2, 75 ns) ; (4, 90 ns) ; (8, 130 ns) ; (16, 210 ns). Between which successive processor counts does latency increase the most?

A.1 to 2 processors
B.2 to 4 processors
C.4 to 8 processors
D.8 to 16 processors ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Successive increases are 5, 15, 40, and 80 ns, so the largest occurs from eight to sixteen processors. The tempting claim of constant latency ignores the sharp rise as contention grows.

Q27. A storage controller uses DMA to transfer incoming data into shared memory and generates an interrupt when the transfer finishes. The operating system keeps the interrupt handler and its consumer thread near the same processor. Which statement is correct?

A.DMA performs the transfer and eliminates all CPU interrupt handling
B.DMA performs the transfer, while processor affinity can improve cache locality for the handler and consumer ✅
C.DMA requires the CPU to copy every transferred byte
D.Processor affinity prevents the storage controller from accessing memory
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: DMA transfers data into shared memory, but interrupt handling still runs on a CPU. Pinning the device interrupt and its consumer near the same processor can improve cache locality; the tempting claim that DMA removes interrupts is false.

Q28. A two-processor server protects a shared critical section. A programmer disables interrupts on processor P0 and assumes processor P1 cannot enter the same critical section. What is the correct solution?

A.Disable interrupts permanently on both processors
B.Use a timer interrupt instead of synchronization
C.Allow P1 to enter because each processor has a separate cache
D.Use a shared atomic synchronization mechanism such as a test-and-set lock ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Disabling interrupts affects only the local processor and cannot stop another CPU from entering the same shared critical section. A shared atomic lock is required; the tempting interrupt-only solution fails on multiprocessors.

Q29. A NUMA server has two processor groups, each with nearby memory. A workload is running on P0 but frequently accesses memory attached to P1. The scheduler considers moving it to P1. Which consideration should guide this decision?

A.Balance processor load against the improved memory locality that migration may provide ✅
B.Always migrate every process to the least busy processor
C.Avoid considering memory placement because all NUMA accesses have equal latency
D.Move the process to P0 permanently regardless of processor utilization
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: In NUMA, migration can improve CPU balance but make a process access remote memory more often. Keeping it near its allocated memory preserves locality; the tempting unconditional migration policy may increase total execution time.

Q30. A program takes 100 time units on one processor. Forty percent is serial and 60% is parallel. Four processors reduce parallel execution time by a factor of four, but remote-memory stalls add 25% to that reduced parallel time. What is the resulting speedup?

A.1.6
B.2
C.1.7 ✅
D.2.29
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The original time is 100 units: serial work is 40, and parallel work is 60. Four CPUs reduce it to 15; a 25% stall adds 3.75, yielding \(100/58.75\\approx1.70\) speedup. The tempting 2.29 ignores stalls.
