📝 Introduction to Computing Environments in Operating Systems (31 MCQs)

Computing Environment Models and Operating System Roles

Computing environments describe the hardware, network arrangements, and execution models in which operating systems provide services. Traditional desktop environments support individual users, while server environments handle requests from many clients. Mobile, distributed, virtualised, and cloud environments introduce different requirements for connectivity, resource allocation, portability, and scalability. Operating systems adapt process management, networking, storage, and security facilities to these conditions.

How Connectivity and Workload Requirements Shape System Design

Computing environments evolved beyond isolated computers as organisations required shared information, remote services, mobility, and scalable processing capacity. Networked systems must coordinate communication across separate machines, whereas mobile devices impose energy and hardware constraints. Virtualised and cloud environments require flexible resource allocation and isolation. These differences influence scheduling, network protocols, storage organisation, fault handling, and security policies.

Distributed, Client-Server, Peer-to-Peer, and Virtualised Models

Client-server systems assign service responsibilities to servers that respond to client requests, while peer-to-peer systems allow participating nodes to provide and consume services. Distributed systems coordinate multiple independent computers through network communication. Virtual machines execute guest operating systems using virtualised hardware, whereas containers isolate applications while generally sharing the host kernel. Cloud computing supplies configurable computing resources over networks.

Running an Application in a Virtual Machine

Suppose a physical server has 16 CPU cores and 64 GiB of RAM. A hypervisor can assign a virtual machine four virtual CPUs and 8 GiB of memory, allowing it to run a guest operating system and applications. Other virtual machines can share the physical host, subject to resource limits and hypervisor scheduling.

Scalability, Availability, Isolation, and Environmental Costs

Distributed and cloud environments support resource sharing, remote access, scalability, and service availability. Virtualisation improves hardware utilisation and isolates guest workloads, while mobile systems prioritise energy efficiency and responsiveness. Nevertheless, network latency, communication failures, virtualisation overhead, resource contention, and security misconfiguration create challenges. A distributed application also requires suitable failure handling because remote components cannot be assumed to remain continuously available.

Misconceptions About Distributed and Virtual Computing

'A distributed system is one computer with several processors' is incorrect because its components operate across separate networked machines. 'A virtual machine and a container are identical' is incorrect because traditional virtual machines run guest operating systems, whereas containers generally share the host kernel. 'Cloud computing eliminates physical hardware' is incorrect because cloud services depend on data-centre infrastructure.

Exam Focus: Comparing Modern Computing Environments

Compare desktop, server, mobile, distributed, peer-to-peer, client-server, virtualised, and cloud environments by architecture, resource ownership, and workload characteristics. Explain the responsibilities of hypervisors and the distinction between virtual machines and containers. Questions may assess network dependence, scalability, isolation, fault tolerance, resource sharing, and the limitations of remote communication.

Key Terms of Computing Environments

  • Client-server - Model separating service providers and requesters.
  • Distributed system - Networked computers coordinating their activities.
  • Peer-to-peer - Model where nodes share responsibilities.
  • Hypervisor - Software managing virtual machines.
  • Container - Isolated application sharing the host kernel.
  • Cloud computing - On-demand network-accessible computing resources.

📝 All Introduction to Computing Environments in Operating Systems MCQs

Q1. An employee uses a desktop computer where applications, the operating system, and primary data storage are maintained on the same machine. Which computing environment does this represent?

A.Traditional personal computing ✅
B.Cloud computing
C.Client-server computing
D.Distributed computing
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The application, operating system, and primary storage execute on the local workstation, which characterizes traditional personal computing. The tempting client-server option assumes processing or services are supplied by a remote server.

Q2. A university website receives requests from student computers. A central machine processes login requests, retrieves records, and returns results. What computing model is being used?

A.Peer-to-peer computing
B.Client-server computing ✅
C.Embedded computing
D.Standalone computing
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A client-server environment separates service providers from requesting applications: the server manages or supplies a resource, while clients initiate requests. The tempting peer-to-peer option is wrong because it does not require a dedicated service provider.

Q3. A group of computers shares files and processing resources directly. Each computer can act as both a resource provider and a resource requester without depending on a permanently dedicated central server. Which environment is described?

A.Centralized computing
B.Mainframe computing
C.Peer-to-peer computing ✅
D.Thin-client computing
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Peer-to-peer computing allows participating machines to provide and request resources directly. The tempting client-server model normally assigns dedicated service responsibilities to servers, whereas peer nodes can perform both roles within the same environment.

Q4. A mobile application must operate on a smartphone with limited battery capacity, variable wireless connectivity, and restricted memory. Which design consideration is particularly important?

A.Maximize background processing regardless of battery consumption
B.Assume continuous high-bandwidth network connectivity
C.Use unlimited memory allocations for cached information
D.Optimize power consumption and tolerate intermittent network connections ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Mobile environments require efficient resource usage because batteries, memory, and wireless connectivity are constrained. The tempting continuous-connectivity assumption is unreliable because mobile devices frequently move between networks or temporarily lose connectivity.

Q5. A digital washing machine contains a processor running software dedicated to controlling water levels, temperature, and washing cycles. Which computing environment best describes this device?

A.Embedded computing ✅
B.Grid computing
C.Cloud computing
D.General-purpose desktop computing
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: An embedded system performs specialized functions within a larger device, usually under resource and operational constraints. The tempting desktop-computing option describes a general-purpose environment that supports many unrelated applications rather than dedicated control.

Q6. An aircraft control system must process sensor information and produce control signals before strict deadlines. A missed deadline could cause a dangerous outcome. Which computing environment is most appropriate?

A.Batch computing
B.Hard real-time computing ✅
C.Interactive time-sharing
D.Peer-to-peer computing
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Hard real-time systems must satisfy critical timing deadlines because late results can be unacceptable or dangerous. The tempting batch-computing option prioritizes completing jobs rather than guaranteeing that results arrive within strict operational deadlines.

Q7. A software developer runs Linux inside a virtual machine on a computer whose physical operating system is Windows. The virtual machine behaves like an independent computer. What technology enables this arrangement?

A.File compression
B.Disk partitioning
C.Hardware virtualization ✅
D.Network address translation
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Hardware virtualization provides an isolated virtual machine with virtualized processor, memory, and device resources. The tempting disk-partitioning option divides storage but does not create an independent execution environment with its own operating system.

Q8. A company deploys inexpensive computers that perform minimal local processing. Applications execute mainly on centralized servers, while users interact through remote displays and input devices. Which environment is being used?

A.Embedded computing
B.Peer-to-peer computing
C.Grid computing
D.Thin-client computing ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Thin clients rely primarily on centralized servers for application execution and data processing, reducing local hardware requirements. The tempting peer-to-peer option distributes resource provision among participating machines rather than centralizing most application execution.

Q9. A startup rents computing resources from an online provider and can increase virtual-machine capacity when demand rises. Resources are accessed over a network and charged according to usage. Which environment is described?

A.Cloud computing ✅
B.Standalone computing
C.Single-user batch computing
D.Embedded computing
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Cloud computing provides network-accessible computing resources that can be provisioned and released according to demand. The tempting standalone option relies on locally managed hardware and lacks the flexible remote resource provisioning described.

Q10. An organization connects several independent computers through a network so that they cooperate to perform a larger computational task. Each computer has its own processor and memory. What is the broadest classification of this environment?

A.Single-processor computing
B.Distributed computing ✅
C.Standalone computing
D.Single-user computing
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Distributed computing coordinates independent computers connected through a network to perform tasks or provide services collectively. The tempting single-processor option describes one processing unit rather than multiple autonomous machines collaborating across a network.

Q11. A company wants to rent virtual machines, storage, and networking from a cloud provider while maintaining responsibility for installing the operating system and configuring applications. Which service model best meets this requirement?

A.Software as a Service
B.Platform as a Service
C.Infrastructure as a Service ✅
D.Desktop as a Service
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Infrastructure as a Service provides virtualized computing, storage, and networking while customers manage their operating systems and applications. The tempting Platform as a Service option supplies a managed application platform and reduces customer control over underlying software configuration.

Q12. A university subscribes to an online accounting application. Employees access the application through a browser without installing or maintaining its underlying operating system, database, or application servers. Which cloud service model is being used?

A.Infrastructure as a Service
B.Platform as a Service
C.Hardware as a Service
D.Software as a Service ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Software as a Service delivers complete applications through a network, with the provider managing the underlying infrastructure and software. The tempting Infrastructure as a Service option provides virtual resources rather than a fully managed application.

Q13. A data center installs a hypervisor directly on physical server hardware. Several guest operating systems execute independently on the same machine. What type of hypervisor is being used?

A.Type 1 hypervisor ✅
B.Type 2 hypervisor
C.Application-level emulator only
D.Container runtime
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A Type 1 hypervisor runs directly on physical hardware and manages virtual machines without requiring a conventional host operating system underneath. The tempting Type 2 option runs as an application within a host operating system.

Q14. An organization compares containers with virtual machines. Which statement correctly describes their usual architectural difference?

A.Every container requires a separate physical processor
B.Containers generally share the host operating-system kernel, while virtual machines run separate guest operating systems ✅
C.Virtual machines cannot run different operating systems on one host
D.Containers always provide stronger hardware isolation than virtual machines
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Containers isolate applications while generally sharing the host kernel, whereas virtual machines provide separate guest operating systems. The tempting separate-kernel assumption confuses containers with virtual machines and ignores their different isolation mechanisms.

Q15. A bank operates two servers in a cluster. One processes customer requests, while the second monitors it and takes over when the active server fails. Which cluster configuration is being used?

A.Active-active load balancing
B.Peer-to-peer clustering
C.Active-standby clustering ✅
D.Distributed file allocation
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Active-standby clustering maintains a backup node that can assume service when the active node becomes unavailable. The tempting active-active configuration uses multiple nodes to provide service concurrently rather than reserving one primarily for failover.

Q16. A research organization divides thousands of independent scientific calculations among computers located at several universities. Each computer contributes available processing capacity to the shared research workload. Which environment is most closely associated with this arrangement?

A.Standalone computing
B.Mobile computing
C.Embedded computing
D.Grid computing ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Grid computing coordinates geographically distributed resources to solve large computational problems, often using independently managed systems. The tempting clustered-computing option usually involves more tightly coordinated machines within a common administrative environment.

Q17. A hospital processes data from medical sensors using nearby computing devices before sending summarized information to a central cloud platform. Why is this edge-computing design beneficial?

A.It eliminates every requirement for centralized storage
B.It reduces communication latency and network traffic by processing data near its source ✅
C.It guarantees unlimited processing power on sensor devices
D.It requires all processing to occur inside distant data centers
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Edge computing processes information close to the devices generating it, reducing network traffic and response latency. The tempting centralized-processing option may provide large-scale resources but requires transmitting more data across the network.

Q18. A field technician uses a mobile application without network connectivity. The application records changes locally and synchronizes them when connectivity returns. What capability makes this arrangement practical?

A.Local data caching with later synchronization ✅
B.Permanent dependence on a remote database connection
C.Disabling local storage during network outages
D.Requiring continuous communication with the central server
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Local caching allows the application to continue operating during network interruptions, while synchronization transfers accumulated changes after reconnection. The tempting continuous-server requirement would make the application unusable whenever connectivity disappears.

Q19. A web application is tested under increasing numbers of simultaneous users. Measured average response times are: 10 users: 20 ms ; 20 users: 22 ms ; 40 users: 28 ms ; 60 users: 65 ms ; 80 users: 120 ms. At which tested workload does response time first exceed 50 ms?

A.20 users
B.40 users
C.60 users ✅
D.80 users
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The response times remain below 50 ms through 40 users, then reach 65 ms at 60 users. Therefore 60 users is the first measured workload exceeding the threshold; the tempting 80-user answer is later.

Q20. A cloud application can increase its number of virtual machines during peak demand and remove unnecessary instances when demand decreases. Which property specifically describes this ability to adjust allocated resources dynamically?

A.Portability
B.Virtual memory
C.Fault isolation
D.Elasticity ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Elasticity is the ability to increase or decrease allocated resources as workload demand changes. The tempting scalability option concerns handling increased workload through additional capacity, but does not necessarily include automatic resource reduction afterward.

Q21. A company deploys identical web servers in two availability zones and places them behind a load balancer. However, both servers depend on one database instance. A student claims the entire service has no single point of failure. What is the flaw?

A.The load balancer prevents database failures automatically
B.The shared database remains a single point of failure despite redundant web servers ✅
C.Two web servers cannot operate in different availability zones
D.Adding another web server always reduces service availability
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The flawed reasoning considers only web-server redundancy. Both servers still depend on one database, whose failure can interrupt the entire service; the tempting load-balancer option cannot eliminate this database dependency.

Q22. An aircraft controller must complete every critical control calculation within 50 milliseconds. A measurement table records execution times: Task A: 42 ms ; Task B: 47 ms ; Task C: 51 ms ; Task D: 38 ms. Which task violates the hard deadline?

A.Task A
B.Task B
C.Task C ✅
D.Task D
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The deadline is 50 milliseconds, and Task C requires 51 milliseconds. It therefore misses the hard deadline; the tempting Task B answer is close to the limit but still completes within the allowed time.

Q23. A program executes in 80 milliseconds on physical hardware and in 92 milliseconds inside a virtual machine. What percentage execution-time overhead does virtualization introduce relative to native execution?

A.0.1
B.0.12
C.0.15 ✅
D.0.2
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The additional execution time is 92−80=1292-80=1292−80=12 milliseconds. Relative overhead is (12/80)times100=15(12/80)\\times100=15\\%(12/80)times100=15. The tempting 12% uses the overhead as a percentage of virtual execution time rather than native execution time.

Q24. A cloud provider uses pre-copy live migration to move a running virtual machine. The VM continuously modifies memory pages while the network transfers previously copied pages. What condition helps the migration converge?

A.The dirty-page generation rate should remain below the effective page-transfer rate ✅
B.The VM must generate dirty pages faster than the network transfers them
C.The network must be disconnected during copying
D.All virtual-machine memory must remain permanently unchanged
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Pre-copy migration repeatedly transfers modified pages before final switchover. It converges more readily when memory dirtying is slower than network transfer; the tempting faster-dirtying condition causes repeated copying and potentially prevents completion.

Q25. A financial institution uses a hybrid cloud. Customer records subject to strict regulatory controls must remain within its private infrastructure, while temporary public website capacity can be obtained from a cloud provider. Which deployment strategy is most appropriate?

A.Move all regulated records to public storage without restrictions
B.Keep regulated records in the private environment and use public resources for permitted workload expansion ✅
C.Avoid all network connections between the two environments
D.Run every customer transaction exclusively on employee laptops
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A hybrid cloud combines private infrastructure with public cloud resources according to workload and compliance requirements. Keeping regulated records private while expanding permitted public-facing capacity addresses both governance and demand; the tempting unrestricted migration risks compliance.

Q26. A company operates a network operating system where users access machines by their individual network names and interact with their separate resources. How does this typically differ from a distributed operating system offering a single-system image?

A.A network operating system eliminates all remote communication
B.A distributed operating system requires every computer to have identical hardware
C.A network operating system hides every machine boundary automatically
D.A distributed operating system attempts to present coordinated resources as one integrated computing environment ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: A distributed operating system aims to provide a unified view of resources across multiple machines, whereas a network operating system exposes separate networked systems more explicitly. The tempting identical-hardware requirement is unnecessary.

Q27. A cloud provider hosts applications belonging to several unrelated customers on shared physical infrastructure. Which architectural requirement is especially important to prevent one customer's workload from accessing another customer's data?

A.Tenant isolation through virtualization, access controls, and resource separation ✅
B.Allowing every customer to use the same administrator account
C.Disabling authentication between virtual machines
D.Giving all applications unrestricted access to host memory
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Multi-tenant environments require isolation so one customer's processes and data remain protected from others. Virtualization boundaries and access controls support this goal; the tempting shared-administrator approach removes accountability and increases cross-customer exposure.

Q28. A distributed application communicates with a remote payment service. Sometimes the network fails after the payment service processes a request but before the client receives confirmation. What design most safely supports retrying the uncertain request?

A.Send a new payment with a different amount
B.Disable network timeouts permanently
C.Use idempotency keys or unique request identifiers to prevent duplicate processing ✅
D.Assume every communication failure means the original request was not processed
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The remote service may complete an operation even when its response is lost. Idempotency keys let it recognize repeated requests and avoid duplicate payments; the tempting assumption that failure means non-execution is unsafe.

Q29. A distributed computing platform records throughput as the number of participating nodes increases: 1 node: 100 jobs/s ; 2 nodes: 190 jobs/s ; 4 nodes: 350 jobs/s ; 8 nodes: 520 jobs/s ; 16 nodes: 540 jobs/s. What conclusion is best supported?

A.Throughput doubles every time node count doubles
B.The platform becomes slower whenever another node is added
C.Sixteen nodes provide exactly sixteen times the single-node throughput
D.Throughput continues rising, but additional nodes provide sharply diminishing returns beyond eight nodes ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Throughput rises from 520 to 540 jobs per second when nodes increase from eight to sixteen, a gain of only 20. The tempting linear-scaling assumption ignores coordination costs and resource bottlenecks.

Q30. A cloud provider records average CPU utilization during successive monitoring intervals: Interval 1: 45% ; Interval 2: 65% ; Interval 3: 82% ; Interval 4: 91% ; Interval 5: 72%. Its autoscaling policy adds capacity when utilization first exceeds 80%. At which interval should scaling first occur?

A.Interval 1
B.Interval 2
C.Interval 3 ✅
D.Interval 5
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The first measured utilization exceeding 80% is 82% during interval 3. The tempting interval 4 answer identifies a later and higher measurement, but autoscaling begins as soon as the threshold is first crossed.

Q31. An agricultural monitoring system collects sensor readings across remote farms. Irrigation valves must continue responding safely even when internet access to the cloud disappears, while long-term analytics can use centralized resources. Which architecture best satisfies these requirements?

A.Perform all control decisions exclusively in a distant cloud data center
B.Use nearby edge devices for immediate control and cloud services for historical analysis ✅
C.Disable local decision-making whenever network connectivity is lost
D.Transmit every sensor reading to a central server before operating a valve
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Edge devices can execute time-sensitive irrigation controls locally during network outages, while cloud infrastructure supports large-scale historical analysis. The tempting cloud-only design introduces communication delays and makes essential local operation dependent on connectivity.
