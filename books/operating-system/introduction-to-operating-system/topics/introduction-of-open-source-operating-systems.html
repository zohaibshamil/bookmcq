Q1. A software developer in 1983 wishes to distribute a compiler that allows users to modify and redistribute the code, provided any derived works remain free. Which licensing mechanism best supports this goal?

🔹 A. Public Domain dedication
🔹 B. Copyright with no license
🔹 C. BSD License
🔹 D. GNU General Public License (GPL)

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The GPL uses 'copyleft' to ensure that derivative works must also be distributed under the same license terms, preserving the freedom of the code.

🔹 D. Dennis Ritchie

📖 Explanation:

Q13. A system experiences high context-switch overhead on a Linux server. Which scheduler feature might be contributing to this if the time slice is too small?

🔹 C. Real-time FIFO scheduling
🔹 D. The buddy allocator

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

CFS aims for fairness by dividing CPU time among tasks. If the target latency is set very low relative to the number of tasks, time slices become small, increasing context switches.

Q17. A Linux kernel panics with 'Out of Memory'. Which kernel thread is responsible for killing processes to reclaim memory?
