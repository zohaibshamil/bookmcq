📝 Introduction to Kernel Data Structures in Operating Systems (27 MCQs)

Definition of Kernel Data Structures:

Kernel data structures are organized memory representations used by an operating system kernel to store and manage information about processes, memory, devices, files, and system resources. They enable efficient tracking and retrieval. Without suitable structures, the kernel could lose resource information, make incorrect scheduling decisions, or fail to locate processes.

How Kernel Data Structures Works:

The kernel creates and updates data structures as system activities occur. It uses linked lists to connect related records, queues to organize waiting processes, trees to represent hierarchical information, and hash tables to support efficient lookup. Operations modify these structures whenever processes or resources change state.

Kernel Data Structures Example:

Consider a ready queue containing Processes A, B, and C in that order. The scheduler removes A for execution. When A blocks for input/output, it leaves the ready queue, while B becomes the next process selected for execution.

Why Kernel Data Structures Matters:

Kernel data structures provide organized information management instead of repeatedly searching unstructured memory. An array offers efficient indexed access but may require shifting elements during deletion. Linked lists simplify insertion and removal but require traversal for locating particular elements.

Common Misconceptions About Kernel Data Structures:

'A queue always executes the highest-priority process.' Correction: That depends on the scheduling policy. 'Linked lists provide constant-time searching.' Correction: Searching generally requires traversal. 'Kernel data structures never change.' Correction: They are updated continuously during system operations.

Exam Tips for Kernel Data Structures:

Understand arrays, linked lists, queues, trees, and hash tables. Identify which structure suits a particular kernel operation. Trace insertion and deletion sequences. Exams commonly ask data-structure comparisons, process queues, and efficiency-related questions.

Key Terms in Kernel Data Structures:

  • Linked List - Connected records linked through references.
  • Queue - A structure following first-in, first-out ordering.
  • Tree - A hierarchical structure containing connected nodes.
  • Hash Table - A structure supporting key-based information lookup.

📝 All Introduction to Kernel Data Structures in Operating Systems MCQs

Q1. An operating system maintains information about every process, including its process ID, current state, CPU registers, and scheduling information. A process is interrupted and later resumed. Which kernel data structure stores the information needed to manage its execution?

A.File allocation table
B.Process control block ✅
C.Page table
D.Interrupt vector table
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The process control block (PCB) stores essential information about a process, including its state, registers, process ID, and scheduling data. The kernel uses this information to manage and resume execution. A page table manages address translation instead. Remember that each process has an associated PCB.

Q2. A kernel maintains a linked list of all processes currently waiting for CPU time. A newly created process must be added to this list. Which data structure operation is primarily required?

A.Sorting the process identifiers
B.Translating virtual addresses
C.Inserting a new list element ✅
D.Compacting the process memory
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: A linked list represents elements through nodes connected by pointers. Adding a newly created process requires inserting a node into the appropriate position in the list. Address translation belongs to memory management. This tests basic kernel data structure operations. Identify whether an operation requires insertion, deletion, traversal, or searching.

Q3. An operating system frequently checks whether a particular process ID exists among thousands of active processes. The kernel uses a hash table indexed by process ID. What is the main performance advantage?

A.Fast average-case lookup ✅
B.Guaranteed sequential access
C.Automatic memory compaction
D.Constant-time sorting
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A hash table maps a process ID to an index using a hash function, providing average-case lookup close to O(1)O(1)O(1). Sequential searching may require examining many entries. This tests hash-based kernel data structures. Remember that hash tables provide fast average lookup, although collisions can increase search time.

Q4. A kernel stores processes in a queue. Process P1 enters first, followed by P2 and P3. If the queue uses FIFO ordering, which process is removed first?

A.P3
B.P2
C.The process with the highest priority
D.P1 ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: A FIFO queue removes elements in the same order they were inserted. Since P1 entered before P2 and P3, it is removed first. Selecting P3 would describe stack-like LIFO behavior. This tests queue operations in operating systems. Remember that queues use enqueue at the rear and dequeue at the front.

Q5. A kernel maintains a list of free physical memory blocks. When a process releases a block, the kernel must return it to the free-memory collection. Which operation is required?

A.Insertion ✅
B.Binary search
C.Sorting
D.Hash collision resolution
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Releasing a memory block requires adding its corresponding entry to the free-memory collection. In a linked-list implementation, this is an insertion operation. Binary search is used for searching sorted data, not adding an entry. This tests memory-management data structures. Identify the collection operation that matches the resource being released.

Q6. A process is created, and the kernel assigns it PID 2450. The process is then represented by a structure containing its PID, state, and resource information. What is the purpose of the PID field?

A.To identify the process uniquely within the operating system ✅
B.To identify its physical memory starting address
C.To determine its disk transfer rate
D.To specify its maximum execution time
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The process identifier provides a unique identifier that the operating system uses to distinguish one process from another. It is not a physical memory address or execution-time limit. This tests process identification within kernel structures. Remember that the PCB stores the PID along with other process-management information.

Q7. A kernel uses a doubly linked list to maintain open file entries. Each node contains pointers to both the previous and next nodes. What advantage does this provide over a singly linked list?

A.Each node requires no pointer storage
B.Traversal is possible only in the forward direction
C.Searching always takes constant time
D.The list can be traversed in either direction ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A doubly linked list stores both previous and next pointers, allowing traversal in both directions. A singly linked list normally supports only forward traversal. This flexibility requires additional pointer memory. This tests linked-list organization. Remember that doubly linked lists simplify backward traversal and deletion when a node reference is already available.

Q8. A kernel uses a binary search tree to store process IDs. Values smaller than a node are stored in its left subtree, while larger values are stored in its right subtree. If the root contains 50, where should PID 30 be inserted?

A.Right subtree of 50
B.At the root
C.Left subtree of 50 ✅
D.Outside the tree
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: A binary search tree places smaller values in the left subtree and larger values in the right subtree. Since 30<5030 < 5030<50, PID 30 belongs in the left subtree. Placing it on the right reverses the ordering rule. This tests binary search tree insertion. Compare each new key with the current node and follow the appropriate branch.

Q9. A kernel maintains a ready queue using a circular array of capacity 5. The rear index is currently 4, and a new process must be inserted. If the queue has an available slot, what should the next rear index become?

A.0 ✅
B.1
C.4
D.5
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A circular array wraps around when its index reaches the array boundary. The next rear index is (4+1) mod 5=0(4 + 1) \bmod 5 = 0(4+1)mod5=0. Using index 5 would exceed the valid array range. This tests circular queue implementation. Apply modulo the array capacity whenever an index advances beyond the final position.

Q10. A kernel stores 64 process records in an array. Each record occupies 128 bytes. How much memory is required for the complete array, excluding additional metadata?

A.4 KB
B.6 KB
C.8 KB ✅
D.16 KB
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The total storage is 64×128=8,19264 \times 128 = 8,19264×128=8,192 bytes, equivalent to 8 KB. Choosing 4 KB would account for only half the required records. This tests array-based kernel data structures and memory calculation. Multiply the number of elements by the size of each element.

Q11. A kernel maintains a priority queue of pending processes. Process P1 has priority 4, P2 has priority 1, and P3 has priority 3. Assuming smaller numerical values represent higher priority, which process should be selected first?

A.P1
B.P2 ✅
C.P3
D.The process with the latest arrival time
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A priority queue selects the element with the highest priority according to its configured ordering. Here, smaller numerical values indicate higher priority, so P2 with priority 1 is selected. Choosing P3 confuses the numerical ordering. This tests priority queues. Always determine whether smaller or larger values represent higher priority.

Q12. A kernel stores 1,000 process records in a linked list. To locate a process at the final position, the kernel starts at the head and follows each next pointer. What is the worst-case time complexity of this search?

A.O(1)O(1)O(1)
B.O(log⁡n)O(\log n)O(logn)
C.O(n)O(n)O(n) ✅
D.O(n2)O(n^2)O(n2)
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: A linked-list search may need to examine every node when the required process is at the final position. Therefore, its worst-case complexity is O(n)O(n)O(n). Constant-time lookup would require direct indexing or an appropriate hash table. This tests algorithmic complexity. Remember that linked-list traversal is linear in the number of nodes.

Q13. A kernel maintains a process list containing P1, P2, P3, P4, and P5. It receives a request to remove P3, and the kernel already has a direct pointer to P3's node. In a doubly linked list, what is the expected time complexity of removing P3?

A.O(1)O(1)O(1) ✅
B.O(log⁡n)O(\log n)O(logn)
C.O(n)O(n)O(n)
D.O(nlog⁡n)O(n \log n)O(nlogn)
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When the node pointer is already available, a doubly linked list can remove that node by updating its previous and next pointers. This requires a constant number of operations, giving O(1)O(1)O(1) complexity. Searching for P3 would take linear time. Remember that direct node access changes deletion complexity.

Q14. A kernel uses a hash table with separate chaining. One bucket contains five process records because their IDs produced the same hash index. What happens when another process maps to that bucket?

A.The kernel must reject the process
B.The entire hash table must be rebuilt
C.The new process is automatically assigned another PID
D.The new record is added to the existing chain ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Separate chaining resolves collisions by storing multiple records in the same bucket using a linked structure or another collection. The new process record can be added to the existing chain. Rejecting the process is unnecessary. This tests collision resolution. Remember that chaining allows multiple keys to share one hash bucket.

Q15. A kernel maintains a binary heap as a priority queue. The highest-priority process is stored at the root. After removing the root, what operation restores the heap property?

A.Linear search
B.Heapify ✅
C.Hashing
D.Depth-first traversal
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Removing the root disrupts the heap structure. The kernel moves the final element to the root and performs heapify, restoring the required parent-child ordering. Linear search does not restore heap structure. This tests heap-based priority queues. Remember that heapify maintains the heap property after insertion or removal.

Q16. A kernel uses a min-heap to schedule tasks, where smaller numbers indicate higher priority. The heap contains 12, 5, 18, 9, and 7. Which value must be at the root?

A.12
B.18
C.5 ✅
D.7
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: A min-heap guarantees that the smallest element is stored at the root. Among the given values, 5 is the minimum. The other values may appear in different valid positions depending on insertion order. This tests heap ordering. Remember that a min-heap guarantees the root value, not a complete sorted sequence.

Q17. A kernel stores free memory regions in a balanced binary search tree ordered by starting address. An allocation request requires the smallest free region that can accommodate 120 KB. What additional information must the kernel examine when searching?

A.Only the process ID
B.The region size as well as its starting address ✅
C.Only the previous process state
D.The number of CPU cores
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Ordering the tree by starting address supports efficient address-based searches, but finding a sufficiently large region also requires checking region sizes. The starting address alone cannot identify the smallest suitable block. This tests the use of kernel data structures for memory allocation. Identify which stored fields are necessary for the required search condition.

Q18. A kernel uses a circular buffer of capacity 8 to record incoming device events. The buffer uses one empty slot to distinguish full from empty. How many events can it store simultaneously?

A.7 ✅
B.8
C.9
D.6
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A circular buffer that reserves one slot to distinguish full from empty can store one fewer element than its total capacity. Therefore, an eight-slot buffer stores 8−1=78 - 1 = 78−1=7 events. Assuming all eight slots are usable ignores the empty-slot convention. This tests circular buffer implementation. Subtract one when the design uses an empty slot to distinguish states.

Q19. A process scheduler stores ready processes in a queue. A new high-priority process arrives, but the scheduler always removes the process at the front. What limitation does this queue design create?

A.It guarantees the highest-priority process runs first
B.It automatically sorts processes by priority
C.It prevents process insertion
D.It may select an older low-priority process before the new high-priority process ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: A standard FIFO queue preserves arrival order rather than priority order. Consequently, an older low-priority process may remain ahead of a newly arrived high-priority process. A priority queue would select according to priority. This tests the relationship between scheduling policy and data structure. Match the queue organization to the scheduler's selection rule.

Q20. A kernel maintains a stack for nested system calls. The stack currently contains A, B, and C, with C at the top. A new operation D is pushed, followed by one pop operation. What element is removed?

A.A
B.D ✅
C.C
D.B
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A stack follows last-in, first-out ordering. D is pushed after C, so D becomes the top element and is removed by the next pop operation. Removing C would ignore the most recent insertion. This tests stack operations in kernel execution. Track the top element after every push or pop operation.

Q21. A kernel maintains a queue using a linked list with front and rear pointers. Initially, the queue is empty. After inserting process P1, what should the front and rear pointers reference?

A.Both should reference P1 ✅
B.Front should reference null and rear should reference P1
C.Front should reference P1 and rear should remain null
D.Both should remain null until a second insertion
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When the first node is inserted into an empty linked queue, it becomes both the first and last element. Therefore, both front and rear must reference P1. Leaving either pointer null would make subsequent queue operations inconsistent. This tests linked queue initialization. Handle the empty-to-nonempty transition separately in queue implementations.

Q22. A kernel stores process records in a hash table with 1,024 buckets. The hash function uses the lower 10 bits of each process ID. Two process IDs differ only in their upper bits. What is the likely outcome?

Differences in upper bits do not affect the result, so collisions may occur. This tests hash function design. Evaluate exactly which key bits influence the hash value when analyzing collision behaviour.

Q24. A kernel stores 16 pending I/O requests in a binary heap. A new request with the highest priority arrives. What is the expected time complexity of inserting this request into the heap?

A.O(1)O(1)O(1)
B.O(log⁡n)O(\log n)O(logn) ✅
C.O(n)O(n)O(n)
D.O(nlog⁡n)O(n \log n)O(nlogn)
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Heap insertion first places the new element at the next available position, then moves it upward until the heap property is restored. The height of a binary heap is O(log⁡n)O(\log n)O(logn), so insertion has logarithmic complexity. Constant time describes the initial placement only. Remember that heap insertion may require upward adjustments along the tree height.

Q25. A kernel uses a linked list to maintain free memory blocks in ascending order of starting address. A newly released block must be inserted into its correct position. A.O(1)O(1)O(1)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: A linked list has no direct positional access, so the kernel may need to traverse all 1,000 entries to find the correct insertion position. The worst-case search complexity is O(n)O(n)O(n). Binary search requires efficient access to middle elements, which linked lists do not provide. Remember that maintaining sorted order does not make linked-list searching logarithmic.

💡 Difficulty: medium | ✅ Correct: B

Choosing 1,024 bytes incorrectly assumes one byte per frame. This tests bitmap-based resource tracking. Convert bits into bytes by dividing the total bit count by eight.

Q27. A kernel maintains a doubly linked list of 100 active device requests. It already has a pointer to request R50. The kernel must remove R50 and then insert a replacement node at the same position. Assuming the replacement node is already allocated, how many neighboring links need updating for each operation?

📖 Explanation: Removing an interior node requires reconnecting its predecessor and successor, while inserting a replacement between them requires updating those neighboring links and the new node's pointers. The number of operations remains constant regardless of list length. This tests doubly linked list manipulation. Remember that direct node access makes local insertion and deletion O(1)O(1)O(1).
