What is Operating System Operations?

Definition:
Operations involve fundamental mechanisms like interrupts, traps, and dual-mode execution, where state transitions occur based on events \( E \) triggering handler \( H(E) \) to switch from user to kernel mode.

Example:
A system call trap occurring when a process requests file I/O, causing the CPU to save user context, load kernel context, execute the service routine, and restore user state upon return.

Reason:
These operations provide the essential controlled entry points into the kernel, ensuring that user programs cannot corrupt system state while still accessing necessary privileged services securely.

Q1. Why is the distinction between user mode and kernel mode fundamental to operating system security?

A. It allows the OS to run faster by ignoring user requests.
B. It prevents user programs from executing privileged instructions that could compromise system integrity. ✅
C. It enables the CPU to switch between different physical processors.
D. It allows multiple users to share the same memory space without isolation.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The hardware-enforced mode bit ensures that only the OS (in kernel mode) can execute sensitive operations like I/O control or interrupt management, protecting the system from errant or malicious user code.

Q2. What mechanism triggers the transition from user mode to kernel mode when a process needs an operating system service?

B. A software trap or system call instruction. ✅
C. A manual reset of the mode bit by the user program.
D. A direct memory access (DMA) request.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

User programs cannot directly switch modes. They must invoke a specific instruction (trap/syscall) that causes the hardware to save state and jump to a predefined kernel handler, switching the mode bit to kernel.

Q3. If a user program attempts to execute a privileged instruction, such as disabling interrupts, what is the immediate hardware response?

D. The instruction is ignored and the program continues.

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Privileged instructions are restricted to kernel mode. Attempting them in user mode violates protection rules, causing a hardware exception (trap) that transfers control to the OS, which typically terminates the offending process.

B. It doesn't apply.
C. Capabilities replace the need for hardware.
D. User mode is eliminated.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Even with capabilities, the kernel must manage the validity and distribution of capabilities. The data structures holding these rights must be protected in kernel mode to prevent users from forging capabilities.

Q54. What is the impact of 'Tickless Kernels' on timer operations?

A. The kernel programs the timer to fire only when the next event (timeout or schedule) is due, rather than at a fixed periodic rate. ✅
B. The kernel removes the timer hardware.
C. The kernel ignores all timers.
D. The kernel uses a software-only timer.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Traditional kernels wake up every 1ms (tick). Tickless kernels calculate the exact time until the next needed action and set the timer for that duration. This allows the CPU to sleep longer, saving power.
