📝 Operating System Operations (16 MCQs)

Definition:

Operating system operations describe how an operating system controls execution, responds to events, handles interrupts, and maintains system protection. They explain the transition between user-level applications and privileged kernel activities. Without controlled execution modes, ordinary applications could execute privileged instructions and directly compromise hardware resources or other programs.

Working:

The processor executes application instructions in user mode. When an application requests a protected service, a system call transfers control to kernel mode. The kernel performs the authorized operation and returns control to user mode. Interrupts and exceptions also transfer execution to appropriate operating system handlers.

Example:

A user-mode application requests a file read operation. It invokes a system call, causing execution to enter kernel mode. The kernel validates the request, accesses the file through storage services, and returns the requested data and operation status to the application.

Reason:

Dual-mode operation provides controlled execution compared with allowing every application unrestricted hardware access. Without privilege separation, a faulty program could modify protected memory or execute dangerous instructions. Kernel-mode execution enables essential system operations while user mode limits application privileges.

Common Misconceptions:

'Every system call is an interrupt generated by hardware.' Correction: System calls generally use a controlled software-generated transition. 'User mode cannot execute instructions.' Correction: It executes ordinary permitted instructions. 'Kernel mode means unlimited physical resources.' Correction: Hardware and software protections still apply.

Exam Preparation Tips: How to prepare this topic

Trace a system call from user mode into kernel mode and back. Distinguish interrupts, exceptions, and system calls. Understand privileged instructions and the mode bit. Exams commonly test execution-mode transitions and protection mechanisms.

Key Terms:

  • User Mode - Restricted processor execution mode for applications.
  • Kernel Mode - Privileged execution mode for operating system operations.
  • Mode Bit - Indicates the current processor execution mode.
  • Exception - An event caused by an instruction during execution.

📝 All Operating System Operations MCQs

Q1. An operating system is running on a computer where a user launches a text editor, saves a document, and prints it. During these activities, the OS manages the CPU, memory, storage, and printer. What makes this coordination possible?

A.The OS directly replaces application instructions with hardware instructions.
B.The OS coordinates hardware resources and provides services to applications. ✅
C.The OS allows each application to control hardware independently.
D.The OS executes applications without interacting with hardware devices.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The operating system acts as an intermediary between applications and hardware while managing shared resources. It provides services such as file access, memory allocation, and device communication. Independent hardware control would create conflicts between applications. Remember that resource management and service provision are core OS responsibilities.

Q2. A program requests data from a disk while another program is using the CPU. The operating system switches execution to the second program while the disk operation continues. What OS capability enables this behaviour?

A.Batch processing
B.Memory compaction
C.File system indexing
D.Interrupt-driven I/O management ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Interrupt-driven I/O allows the processor to perform other work while a device completes an operation. When the disk finishes, it generates an interrupt to notify the CPU. A common mistake is assuming the CPU must wait throughout the entire I/O operation. Remember that asynchronous I/O improves processor utilization.

Q3. A computer starts executing its operating system after being powered on. Which component typically loads the initial operating system code into memory?

A.Bootstrap program stored in firmware ✅
B.Application program stored on disk
C.File system management utility
D.Command interpreter stored in RAM
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The bootstrap program, usually stored in firmware, initializes essential hardware and loads the operating system kernel into memory. An application or command interpreter normally requires the OS to be loaded first. Remember the startup sequence: firmware initialization, bootloader execution, and kernel loading.

Q4. A user application attempts to access a protected memory location belonging to the operating system. The processor prevents the access and transfers control to the OS. What mechanism makes this protection possible?

A.Disk scheduling
B.Spooling
C.Dual-mode operation ✅
D.File compression
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Dual-mode operation distinguishes user mode from kernel mode using a hardware-supported mode bit. Privileged memory operations are restricted to kernel mode, preventing ordinary applications from modifying protected OS memory. Disk scheduling and spooling do not provide memory protection. Remember that privileged instructions require kernel-mode execution.

Q5. A computer has two processors, and both execute operating system instructions simultaneously while handling different system activities. Which statement correctly explains this situation?

A.The operating system must use separate kernels for every process.
B.Only user applications can execute simultaneously on different processors.
C.The operating system can support concurrent kernel execution on multiple processors. ✅
D.One processor must remain inactive whenever the kernel is running.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: On a multiprocessor system, the operating system can execute kernel code concurrently on multiple CPUs. This improves throughput but requires synchronization to protect shared kernel data structures. Assuming one processor must remain idle ignores multiprocessor OS design. Remember that parallel kernel execution requires careful synchronization.

Q6. An operating system detects that a running process has attempted an illegal arithmetic operation, such as division by zero. The processor transfers control to a handler. What type of event has occurred?

A.DMA transfer
B.Context switch
C.Timer expiration
D.Exception ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: An exception is a processor-generated event caused by an instruction during execution, such as division by zero or an invalid memory access. A timer expiration is an interrupt associated with time-based scheduling. Remember that exceptions are generally synchronous with the instruction that causes them.

Q7. A process requests a file-reading operation using a system call. The OS validates the request and accesses the file system. During this operation, which execution mode normally handles the protected file-system operations?

A.User mode
B.Kernel mode ✅
C.Idle mode
D.Batch mode
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Kernel mode provides the privileges needed to access protected hardware and operating system data structures. A system call transfers execution from user mode into kernel mode so the OS can safely perform the requested operation. Remember that system calls provide controlled access to privileged kernel services.

Q8. A processor runs a program for 10 milliseconds before a timer interrupt occurs. The OS saves the program's execution state and schedules another process. What is the primary purpose of the timer interrupt?

A.To prevent a process from monopolizing the CPU. ✅
B.To permanently terminate the running process.
C.To transfer all process data to secondary storage.
D.To reset the operating system's system clock.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A timer interrupt ensures that the operating system regains control after a specified interval, allowing it to enforce CPU scheduling and time sharing. The saved execution state supports later resumption. The process is not necessarily terminated. Remember that timer interrupts enable preemptive multitasking.

Q9. A developer writes an application that requests network access through an operating system library. The library eventually invokes a protected kernel service. What is the main purpose of this arrangement?

A.To allow applications to bypass processor protection.
B.To eliminate communication between applications and the kernel.
C.To provide a controlled mechanism for requesting privileged services. ✅
D.To ensure every network operation executes in user mode.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Libraries can provide convenient interfaces that invoke system calls when privileged operations are required. The kernel validates requests and performs protected services. This arrangement preserves security while making OS functionality accessible to applications. Remember that an API may wrap system calls without itself executing privileged operations.

Q10. A system receives a hardware interrupt while a process is executing. The processor transfers control to the appropriate interrupt handler. Which sequence most accurately represents the essential handling process?

A.Execute the next application instruction, delete the process, and restart the CPU.
B.Load a new process, erase the interrupt source, and shut down the device.
C.Save the interrupted context, execute the handler, and resume or schedule execution. ✅
D.Switch to user mode, ignore the interrupt, and restart the application.
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Interrupt handling requires preserving the interrupted execution context, identifying and executing the appropriate handler, and then restoring execution or allowing scheduling decisions. Deleting the process is not a normal interrupt response. Remember the essential sequence: save context, handle event, restore or reschedule.

Q11. A file-copy application requests a 4 MB transfer from storage. The system uses DMA, and the controller generates one interrupt after completing the transfer. If the same transfer were performed using an interrupt for every 4 KB block, how many completion-related interrupts would occur?

A.64
B.128
C.256
D.1024 ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: A 4 MB transfer contains \(4,096\) KB, so dividing by 4 KB gives \(4,096/4=1,024\) block transfers. Therefore, the block-by-block method generates 1,024 interrupts, compared with one completion interrupt for the DMA transfer. Remember to convert MB into KB before dividing.

Q12. A process executes a system call and enters kernel mode. While the kernel is processing the request, a higher-priority hardware interrupt arrives. The processor and OS support interrupt nesting. What can happen next?

A.The processor must terminate the system call immediately.
B.The interrupt is permanently discarded because the kernel is active.
C.The process returns to user mode before the interrupt is handled.
D.The higher-priority interrupt can temporarily interrupt kernel execution. ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: With supported interrupt nesting, a higher-priority interrupt can preempt a lower-priority kernel activity, provided interrupt priorities and masking rules permit it. The interrupted kernel context must be preserved so execution can resume afterward. Remember that kernel mode does not automatically prevent all hardware interrupts.

Q13. A computer uses a 32-bit physical address space. The operating system maps physical memory using 4 KB pages. How many page frames can the physical address space contain if the entire address range is available?

A.65536
B.1048576 ✅
C.4194304
D.16777216
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A 32-bit address space contains \(2^{32}\) bytes, while a 4 KB page contains \(2^{12}\) bytes. Dividing gives \(2^{32}/2^{12}=2^{20}=1,048,576\) page frames. A common mistake is confusing the number of bytes with the number of frames. Remember to divide address-space size by page size.

Q14. An OS handles a disk interrupt while process P1 is running. The interrupt handler completes, and P1 continues without another process being selected. Has a context switch necessarily occurred?

A.Yes, because every interrupt changes the running process.
B.Yes, because interrupt handling always replaces the process.
C.No, because an interrupt can be handled without changing the running process. ✅
D.No, because disk interrupts execute only during idle time.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: An interrupt transfers control to an interrupt handler, but this does not necessarily change the currently running process. If scheduling does not select another process, P1 can resume after the handler finishes. Remember that interrupt handling and context switching are distinct operations.

Q15. A system supports user mode and kernel mode. A process makes a system call, and the kernel completes the request before returning control. Which sequence correctly describes the mode transitions?

A.User mode, kernel mode, user mode ✅
B.Kernel mode, user mode, kernel mode
C.User mode, idle mode, kernel mode
D.Kernel mode, interrupt mode, idle mode
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A system call begins while the application executes in user mode, transfers control to the kernel for protected service execution, and returns to user mode when the service completes. The process does not need to enter idle mode. Remember the standard transition sequence: user, kernel, user.

Q16. A computer has three processes, P1, P2, and P3. P1 triggers a system call, P2 triggers a timer interrupt, and P3 causes a division-by-zero exception. Which classification correctly identifies these events?

A.All three are hardware interrupts generated asynchronously.
B.The system call is a controlled software trap, the timer is a hardware interrupt, and division by zero is an exception. ✅
C.The system call is an exception, the timer is a system call, and division by zero is a hardware interrupt.
D.All three are ordinary instructions that execute without transferring control.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A system call deliberately transfers control to the kernel, typically through a trap instruction. A timer interrupt is generated by hardware, while division by zero causes a synchronous exception during instruction execution. Remember to distinguish intentional kernel requests, asynchronous hardware events, and instruction-related exceptions.
