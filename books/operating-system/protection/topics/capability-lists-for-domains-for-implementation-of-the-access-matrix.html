What is Capability lists for domains for Implementation of the Access Matrix?

Definition:
Capability lists implement the access matrix by associating each domain with a list of capabilities, where each capability is a protected token granting specific access to an object.

Example:
Process P holds capability , presented to kernel for validation instead of naming the object directly.

Reason:
Capabilities enable decentralized access control and support delegation, but revocation becomes challenging since tokens may be copied or stored externally.

Q1. A process executing in domain D2 copies the read right for file F2 to domain D3. Which type of copy right is being exercised?

A.transfer
B.copy ✅
C.limited copy
D.owner
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The correct answer is B because the operation described copies an existing right without removing it from the original entry, which matches the definition of the copy right. A transfer right would move the right, deleting it from the source, and a limited copy would create only the basic right, not the copy‑right token. The owner right is unrelated to copying rights; it governs adding or deleting rights. Therefore, D2’s action exemplifies a plain copy, preserving the original permission for F2 while granting D3 the same access.

Q2. What distinguishes a limited copy right from a regular copy right in a capability list?

A.It removes the original right ✅
B.It allows propagation to any domain
C.It creates only the basic right without the copy‑right token
D.It grants owner privileges
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The limited copy right differs because it creates only the basic right (e.g., read) in the target entry and does not propagate the copy‑right itself, preventing further duplication. Option A describes a transfer right, which deletes the source right. Option B describes the unrestricted copy right, which can be propagated indefinitely. Option D confuses it with the owner right, which controls addition and removal of rights. Hence, the key feature of a limited copy is the lack of the copy‑right token in the new entry, limiting further copying.

Q3. Domain D1 is the owner of file F1. To grant domain D2 the write right on F1, which capability must D1 possess?

A.owner ✅
B.copy
C.transfer
D.limited copy
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Because D1 is the owner of F1, it holds the owner capability, which authorizes adding or removing any valid right in the column for F1. The copy, transfer, and limited copy rights only deal with duplicating existing permissions and cannot create new rights that the owner can. Therefore, D1 must use its owner right to insert the write permission for D2. This reflects the principle that only the owner can modify the access matrix entries for objects it controls.

Q4. Which right in an access matrix allows a domain to remove rights from any entry in its column?

A.owner ✅
B.copy
C.transfer
D.limited copy
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The owner right grants a domain the authority to add or delete rights in any entry of the column associated with an object it owns. Copy, transfer, and limited copy rights only enable propagation of existing permissions and do not provide deletion capabilities. Consequently, only the owner capability can remove rights from entries, ensuring that control over an object's access list remains with its designated owner.

Q5. Why does limiting the propagation of a copy right improve system security?

A.It reduces the number of rights that can be granted ✅
B.It prevents the owner from adding new rights
C.It allows domains to copy rights without restriction
D.It eliminates the need for transfer rights
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Limiting propagation means that when a copy right is used, only the base permission (e.g., read) is created and the copy‑right token is not transferred. This prevents a domain from repeatedly copying the same right to many other domains, thereby reducing the total number of entities that can further disseminate the permission. Options B and C describe opposite effects, and D is unrelated because transfer rights serve a different purpose. Thus, the primary security benefit is the reduction in the spread of rights.

Q6. Domain D2 holds a copy right for read* on file F2 and copies it to domain D3. Later, D3 attempts to copy the same right to D4. Which outcome correctly describes the system's behavior?

A.D3 cannot copy because it lacks
B.D3 can copy, creating another ✅
C.The copy creates only the basic read right, preventing further copying
D.The owner right overrides the copy restriction
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When D2 uses the copy right to grant D3 the read* permission, only the basic read right is placed in D3’s entry; the copy‑right token is not transferred. Consequently, D3 does not possess and cannot further duplicate the permission to D4. Option B is incorrect because the copy token is not propagated. Option C describes the limited copy scenario, which would have been chosen explicitly. Option D is irrelevant because the owner right is unrelated to this specific copy operation. Therefore, D3 is blocked from copying the right.

Q7. How does the owner right interact with copy, transfer, and limited copy rights in maintaining the integrity of an access matrix?

A.Owner right can replace any copy right ✅
B.Owner right controls addition and removal of rights, while copy rights only propagate existing permissions
C.Copy rights override owner rights when conflicts arise
D.Limited copy rights grant full control like the owner
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The owner right provides the authority to add or delete any valid right in the column of an object it owns, ensuring that the matrix can be updated securely. In contrast, copy, transfer, and limited copy rights merely allow existing permissions to be duplicated or moved without altering the set of possible rights. Therefore, the owner governs structural changes, while the copy‑related rights handle propagation. Option A is false because the owner does not replace copy rights; Option C is incorrect since copy rights never supersede owner decisions; Option D mischaracterizes limited copy as full control.

Q8. Given an access matrix where domain D1 owns file F1 and holds copy right for write on F2, and domain D2 holds transfer right for execute on F3, which entries can D1 modify after using its owner right to add a read permission to D2 for F1?

A.Only the entry (D2, F1)
B.Entries (D2, F1) and (D1, F2)
C.All entries in column F1 ✅
D.No entries can be changed because copy rights block owner actions
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Because D1 is the owner of F1, it can add or delete any right in the column corresponding to F1, regardless of other rights present elsewhere. Using its owner capability, D1 can insert a read permission for D2 in the (D2, F1) cell, and it could also modify other cells in the same column, such as (D3, F1) if needed. The copy right on F2 and the transfer right on F3 belong to different domains and do not restrict D1’s owner actions on F1. Therefore, D1 may change all entries within column F1.
