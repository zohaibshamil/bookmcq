What is Domain structure for protection in Operating System?

Definition:
The domain structure organizes protection domains hierarchically or in rings, defining transitions between privilege levels and specifying how access rights propagate across different execution contexts.

Example:
In x86 architecture, ring 0 (kernel) has full access while ring 3 (user) is restricted, with transitions occurring via instructions.

Reason:
This structured approach prevents lower-privilege code from directly manipulating higher-privilege resources, enforcing isolation and system stability.

Q1. An operator needs to mount backup tapes for a single shift. Which method best follows the principle of least privilege?

A.Assign a role with mount permission only during the shift
B.Give the operator a permanent administrator account ✅
C.Disable all privileges for the operator
D.Provide a root account with full rights
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The correct answer gives the operator only the specific permission needed and only for the required time, embodying least privilege. A permanent admin account (B) grants far more rights than necessary, increasing risk. Disabling all privileges (C) prevents the task from being done. Providing a full‑rights root account (D) is excessive and violates the principle. Limiting rights to the exact task and duration reduces attack surface and aligns with secure practice.

Q2. A company wants to limit remote access to a database service to only the finance team during business hours. Which control implements this most directly?

A.An access‑control list on the IP address
B.Role‑based access control with time constraints ✅
C.Disabling the database service entirely
D.Encrypting all database traffic
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: RBAC with time constraints (B) lets the organization assign the finance role the needed database permission and restricts it to business‑hour windows, matching the requirement. An ACL on IP (A) does not enforce time limits or role membership. Disabling the service (C) would prevent legitimate use. Encryption (D) protects data in transit but does not control who can connect or when.

Q3. If an audit log shows a privileged function was invoked without prior enablement, what is the most likely security issue?

A.A misconfigured access‑control list
B.Insufficient logging of user actions
C.A privilege‑escalation bug ✅
D.An unused service still running
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The log indicates a privileged operation occurred unexpectedly, which most often points to a privilege‑escalation bug (C) that allowed a user to obtain rights they should not have. A misconfigured ACL (A) could block access but would not explain an unexpected invocation. Insufficient logging (B) would hide the event, not produce it. An unused service (D) is unrelated to the observed privileged call.

Q4. A server runs web, FTP, and email services. To reduce attack surface, which combination aligns with the principle of least privilege?

A.Keep all services enabled at all times
B.Disable the FTP service entirely
C.Enable only the web service during daytime hours
D.Enable web and email services, disable FTP ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Disabling the unnecessary FTP service (D) removes a potential entry point while keeping needed web and email services operational, directly applying least privilege. Keeping all services (A) provides no reduction. Disabling FTP alone (B) is good but does not consider that the web service may also be unnecessary at certain times. Enabling only web during the day (C) neglects needed email functionality.

Q5. A system administrator creates a role that can only read system logs but not modify them. Which principle does this illustrate?

A.Separation of duties
B.Least privilege ✅
C.Defense in depth
D.Fail‑safe defaults
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Granting a role only the read permission needed for its task exemplifies the principle of least privilege (B), ensuring users have no more access than required. Separation of duties (A) involves dividing responsibilities to prevent fraud, which is not the focus here. Defense in depth (C) refers to layered security controls, and fail‑safe defaults (D) describe secure default settings, neither of which directly describe the limited read‑only role.

Q6. During scheduled maintenance, a backup script requires root rights for ten minutes. Which mechanism should be used to grant these rights?

A.Use sudo with a time‑limited rule ✅
B.Create a permanent root account for the script
C.Disable all privileges for the duration
D.Change file ownership to root permanently
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Sudo with a time‑limited rule (A) provides the needed elevated rights just for the short maintenance window, adhering to least privilege. A permanent root account (B) would give ongoing excessive rights. Disabling all privileges (C) would prevent the script from running. Changing file ownership permanently (D) gives ongoing elevated rights, violating the principle.

Q7. An ACL entry \userX:rw\ is added to a file. What does this permit?

A.Read only access
B.Write only access
C.Read and write access ✅
D.Execute access
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The \rw\ notation in an ACL signifies both read and write permissions (C), allowing the user to view and modify the file. \Read only\ (A) would be represented by \r\ alone, while \write only\ (B) would be \w\ alone. Execute permission (D) is indicated by \x\ and is not included in the given entry.

Q8. Given two operating systems, one with 5 million lines of code and 30 services, another with 2 million lines and 12 services, which factor most likely contributes to a higher number of security vulnerabilities?

A.Code size alone
B.Number of services alone
C.Code size only
D.Both code size and number of services ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Both the larger code base and the greater number of services (D) increase the attack surface and the likelihood of bugs, leading to more vulnerabilities. Code size alone (A) ignores the impact of many services, while services alone (B) overlooks the complexity of extensive code. Stating only code size (C) is incomplete. The combination of both factors creates more opportunities for security flaws.

Q9. An audit system records every privileged function call but does not record the invoking user ID. What security risk does this create?

A.Loss of accountability ✅
B.Increased performance overhead
C.Data redundancy
D.Weak encryption of logs
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Without the user ID, it is impossible to attribute privileged actions to a specific individual, resulting in loss of accountability (A). Performance overhead (B) concerns system resources, not security. Data redundancy (C) is a storage issue, and weak encryption (D) relates to confidentiality, none of which address the missing user identification.

Q10. What is the main goal of the principle of least privilege?

A.To maximize user rights
B.To minimize rights to only what is needed ✅
C.To simplify system administration
D.To increase overall system performance
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The principle aims to give users only the minimal permissions required to perform their tasks (B), thereby reducing the chance of accidental or malicious misuse. Maximizing rights (A) does the opposite. Simplifying administration (C) may be a side effect but is not the primary goal. Improving performance (D) is unrelated to permission management.

Q11. How does role‑based access control help enforce least privilege?

A.By assigning many roles per user
B.By grouping permissions into roles
C.By removing all permissions from users ✅
D.By encrypting role definitions
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: RBAC groups related permissions into roles (C), allowing administrators to assign only the roles a user needs, thus limiting excess rights. Assigning many roles (A) would increase privileges. Removing all permissions (B) defeats functionality. Encrypting roles (D) protects data but does not control permission granularity.

Q12. Why might a system with many services be harder to secure than one with fewer services, even if both use similar access controls?

A.It has more code paths that can be exploited ✅
B.It runs on faster processors
C.It requires larger storage capacity
D.It benefits from better documentation
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Each additional service adds new code paths and interfaces that attackers can target, making the system harder to secure (A). Processor speed (B) and storage size (C) are unrelated to security complexity. Better documentation (D) might aid security but does not explain increased difficulty.

Q13. In the context of domain protection, what does enabling a privilege mean?

A.Permanently granting rights
B.Temporarily activating rights for a specific task
C.Deleting the rights entirely
D.Encrypting the rights for storage ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Enabling a privilege activates the necessary rights only for the duration of a task (D), aligning with the principle of granting only what is needed when it is needed. Permanently granting (A) provides continuous rights, deletion (B) removes them, and encryption (C) addresses confidentiality, not activation.

Q14. Which statement best describes how audit trails complement the principle of least privilege in detecting policy violations?

A.They replace the need for least privilege
B.They provide evidence of misuse when privileges are exercised ✅
C.They automatically adjust privileges based on usage
D.They hide privileged actions from administrators
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Audit trails record each use of privileged functions, supplying concrete evidence when a violation occurs (B). They do not replace least privilege (A); instead, they verify its proper use. Automatic adjustment (C) is not typical of audit logs, and hiding actions (D) would undermine accountability.

Q15. Which of the following best illustrates a violation of least privilege?

A.A user given only read access to a needed file
B.An administrator granted full root access to perform a simple log view
C.A role that contains exactly the permissions required for its tasks ✅
D.A service disabled when not in use
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Giving an administrator full root rights for a simple log view (C) greatly exceeds the necessary permission, violating least privilege. Providing only read access (A) respects the principle. A role with exact permissions (B) also follows it. Disabling unused services (D) is a security best practice.

Q16. When implementing time‑based access controls, which condition must be enforced to maintain least privilege?

A.Access granted at any time
B.No authentication needed
C.Access only on weekends
D.Access only during authorized windows ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Limiting access to authorized time windows (D) ensures users have privileges only when needed, embodying least privilege. Granting access at any time (A) removes temporal restrictions. Skipping authentication (B) eliminates verification. Allowing only weekend access (C) is a specific schedule but may not align with business needs.

Q17. What does RBAC stand for?
