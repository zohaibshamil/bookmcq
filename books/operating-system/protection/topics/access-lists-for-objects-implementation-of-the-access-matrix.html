📖 From Operating System • 14. Protection • 8 questions available

What is Access lists for objects Implementation of the Access Matrix?

Definition:
Access lists implement the access matrix by attaching a list of (domain, permissions) pairs to each object, storing only non-empty entries per column.

Example:
File /data/report.txt contains entries \( [(\text{alice}, rw), (\text{bob}, r)] \), checked during \( \text{open()} \) system calls.

Reason:
This column-oriented storage efficiently handles sparse matrices and aligns with object-centric management, though checking requires scanning potentially long lists.

Q1. What does the owner right allow a domain to do in an access matrix?

A. Add new rights only
B. Remove any rights only
C. Add and remove any rights in its column ✅
D. Copy rights to other domains

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The owner right gives a domain full control over the column that corresponds to the object it owns. With that right the domain can both insert new permission entries and delete existing ones for any other domain listed in that column. Options A and B describe only half of the capability, and D describes a different right (copy). Therefore the correct choice is that the domain can add and remove any rights in its column.

Q2. Why does the limited copy right stop a domain from further copying the transferred right?

A. It removes the original right ✅
B. It creates a non‑propagating version of the right
C. It changes the right into an owner right
D. It only works for write rights

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Limited copy is defined to create a new right while leaving the original unchanged, but the newly created right lacks the copy capability itself. Consequently, a domain that receives a right through limited copy cannot use that right to copy again. Option A describes transfer, option C invents a new right type, and option D limits the effect to a specific operation, none of which match the definition of limited copy.

Q3. How do the three copy‑type rights—copy, transfer, and limited copy—differ in terms of right retention after the operation?

A. Copy retains source, transfer removes source, limited copy retains source but not the right ✅
B. Copy retains source, transfer removes source, limited copy retains source but only creates a non‑propagating right
C. All three remove the source right
D. Only transfer creates a new right

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The copy right duplicates a permission and leaves the original unchanged. Transfer copies the permission and then deletes it from the source entry. Limited copy also copies the permission but the copy lacks the ability to be copied again; the source entry remains unchanged. Option A incorrectly says the limited copy does not keep the right, option C misstates all three, and option D ignores the copy and transfer behaviors.

Q4. A process in domain D2 holds a read* right on file F2 and wants to give domain D3 a simple read right using the copy right. Which rights must D2 possess in the matrix to perform this action?

A. Copy right on (D2,F2) and read* right ✅
B. Transfer right on (D2,F2) only
C. Limited copy right on (D2,F2) only
D. Owner right on (D2,F2)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

To copy a right, the source entry must contain both the specific permission (read*) and the copy right that authorizes duplication. The copy right allows the process to create a new entry for D3 without removing the original from D2. Transfer would remove the original, limited copy would create a non‑propagating right, and owner rights are unrelated to this specific copy operation.

Q5. Domain D1 is the owner of file F1 and wishes to delete the write* right from domain D2. Which right must D1 have in the access matrix to carry out this deletion?

A. Owner right on (D1,F1) ✅
B. Copy right on (D1,F1)
C. Transfer right on (D1,F1)
D. Limited copy right on (D1,F1)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Only the owner right grants a domain the authority to modify any entry in the column of an object it owns. With the owner right, D1 can remove the write* permission from D2’s row. The copy, transfer, and limited copy rights are used for propagating permissions, not for revoking them, so they cannot be used to delete an existing right.

Q6. Consider the following chain: D1 (owner of F1) grants a copy right for read* to D2; D2 copies read* to D3; D3 then attempts to copy read* to D4. Which policy prevents D3 from succeeding?

A. Transfer right only
B. Limited copy right ✅
C. Copy right without restriction
D. Owner right required

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Limited copy is designed so that the right created by the copy operation cannot itself be copied further. When D2 uses a limited copy to give D3 the read* permission, D3 receives a non‑propagating version of the right, which blocks any subsequent copy attempts. Transfer would remove the source right, and unrestricted copy would allow further copying, while an owner right is unrelated to this propagation rule.

Q7. What is the primary security risk of allowing the transfer right without any limitation?

A. It enables unlimited propagation of rights ✅
B. It prevents any propagation of rights
C. It only affects write rights
D. It requires owner approval each time

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The transfer right moves a permission from one domain to another and deletes it from the source. Without limits, a domain that receives a transferred right could immediately transfer it again, creating a cascade that spreads the permission far beyond its intended scope. This uncontrolled propagation is the main security concern. Options B and C describe opposite or narrow effects, and D adds an unnecessary approval step that does not reflect the inherent risk.

Q8. Scenario: D1 owns F1 and grants a transfer right for read* to D2. D2 then uses limited copy to give D3 read* on F1. After these steps, which statement is true?

A. D3 can further copy the read* right
B. D2 still retains the original read* right ✅
C. D1 loses the owner right
D. D2 cannot grant any rights to D3

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When D1 grants a transfer right, D2 receives a copy of the read* permission and the original is removed from D1. D2 then employs limited copy, which creates a new read* entry for D3 but does not remove D2’s own copy. Therefore D2 continues to hold the read* right, while D3 receives a non‑propagating version. The other options misrepresent the effects of transfer and limited copy or the ownership status.
