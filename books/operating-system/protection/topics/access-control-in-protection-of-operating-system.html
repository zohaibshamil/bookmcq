What is Access Control in protection of Operating System?

Definition:
Access control enforces protection policies by mediating every request to access system resources, verifying authorization before permitting operations like read, write, or execute.

Example:
Kernel intercepts \( \text{write(fd, buf, len)} \), checks fd’s access rights against current domain, and returns \( \text{-EACCES} \) if denied.

Reason:
Consistent mediation ensures policy compliance regardless of application behavior, forming the trusted computing base upon which all higher-level security depends.

Q1. A new employee needs to install software on a workstation but must not change system configurations. Which assignment best follows the principle of least privilege?

A. Give the employee full administrative rights
B. Add the employee to the administrators group
C. Grant only the specific install privilege ✅
D. Provide no privileges at all

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The correct answer is C because granting only the install privilege gives the employee exactly what is required, nothing more, which embodies least privilege. Option A and B provide broad rights that exceed the task, increasing risk of accidental or malicious changes. Option D leaves the employee unable to perform the needed installation. In real environments, limiting rights to the precise function prevents unnecessary exposure and aligns with security best practices.

Q2. What is the primary objective of applying the principle of least privilege in an operating system?

A. To maximize overall system performance
B. To reduce the system's attack surface ✅
C. To simplify user account management
D. To increase convenience for end users

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The correct answer is B because the principle of least privilege aims to give each user or process only the minimum rights needed, thereby shrinking the number of exploitable entry points and reducing the attack surface. Option A is unrelated; limiting privileges can sometimes reduce performance. Option C oversimplifies management but is not the main goal. Option D conflicts with security, as more convenience often means broader access. In practice, fewer privileges mean fewer opportunities for attackers to compromise the system.

Q3. During a security audit of a Windows 2000 server, the auditor suggests disabling services that are not needed. Which action best aligns with the principle of least privilege?

A. Turn off unnecessary services to limit potential exploits ✅
B. Install additional antivirus software on the server
C. Upgrade the server's hardware components
D. Increase the complexity of user passwords

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is A because disabling services that are not required removes unnecessary functionality that could be targeted by attackers, directly applying least privilege by reducing the system's exposure. Option B, while beneficial, does not eliminate privileged pathways. Option C improves performance but does not affect privilege levels. Option D strengthens authentication but does not limit the services a process can access. In real deployments, trimming the attack surface by turning off unused services is a core step in hardening a system.

Q4. How does the need‑to‑know principle differ from the principle of least privilege in controlling access to system resources?

A. Need‑to‑know restricts access to resources required for the current task, while least privilege defines the minimal rights a user should ever have ✅
B. Need‑to‑know grants temporary administrator rights, whereas least privilege grants permanent rights
C. Both principles are identical and can be used interchangeably
D. Need‑to‑know applies only to confidential data, while least privilege applies to all objects

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is A because need‑to‑know limits a process to the resources it must use at that moment, whereas least privilege sets the smallest set of rights a user or process should possess overall. Option B misstates the concepts; neither principle specifically grants administrator rights. Option C is false because the principles address different aspects of access control. Option D incorrectly limits need‑to‑know to data only. Understanding both helps administrators enforce precise, minimal access, reducing potential misuse.

Option D, Linux, inherits UNIX design but typically incorporates modern security modules. Recognizing the historical context helps security professionals assess legacy system risks and plan appropriate hardening measures.

Q6. A process attempts to write data to a CD‑ROM. According to typical object operation rules, what should happen?

A. The write operation succeeds because all objects support writing
B. The write operation fails because CD‑ROMs are read‑only devices ✅
C. The system automatically converts the CD‑ROM to a writable format
D. The process is terminated immediately

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The correct answer is B because CD‑ROMs are inherently read‑only media; their defined operations allow only reading, so any write attempt must be denied. Option A is incorrect as not all objects support write operations. Option C is false; the system cannot change the physical nature of the media on the fly. Option D is extreme; the process is typically returned an error rather than being killed. This behavior illustrates how access control enforces appropriate object permissions.

Q7. Why might a system with more code and services, such as Windows 2000, be less secure even if it has a complex protection scheme?

A. More code expands the attack surface, providing more opportunities for vulnerabilities ✅
B. Complex protection schemes always fail regardless of implementation
C. Users tend to ignore security settings on larger systems
D. Hardware limitations prevent effective security enforcement

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The correct answer is A because each additional line of code and each extra service introduces new interfaces and potential bugs, enlarging the attack surface that attackers can probe. Option B overstates reality; complex schemes can be effective if correctly implemented. Option C may be true in some cases but is not the primary technical reason for reduced security. Option D is unrelated; hardware limits affect performance more than security. Understanding that quantity of code correlates with risk helps designers prioritize minimalism and thorough testing.

Q8. An organization is migrating from Solaris to Windows 2000. To maintain security, which combination of practices is most effective?

A. Enable all Windows services for compatibility and rely on antivirus
B. Apply least privilege to user accounts and disable unnecessary Windows services ✅
C. Use only the need‑to‑know principle without changing service configurations
D. Rely solely on firewall rules to protect the new system

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The correct answer is B because assigning the smallest necessary rights to each account limits what users can do, and turning off services that are not needed removes potential entry points, both essential for a secure migration. Option A defeats security by exposing many services. Option C applies need‑to‑know but ignores the risk from unused services. Option D places all trust on the network perimeter, ignoring host‑level vulnerabilities. Combining privilege reduction with service minimization provides layered defense in the new environment.

Q9. Granting excessive privileges to a process violates which principle, and what type of damage can this cause?

A. It violates the need‑to‑know principle and can allow the process to corrupt unrelated files
B. It violates the principle of least privilege and may increase the system's performance
C. It violates both need‑to‑know and least privilege, leading to potential data leakage or system compromise ✅
D. It violates no principle and has no impact on security

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The correct answer is C because giving a process more rights than necessary breaches both need‑to‑know (access beyond current task) and least privilege (minimum rights overall), opening pathways for data leakage, unauthorized modifications, or full system compromise. Option A mentions only need‑to‑know and limits damage to file corruption, missing the broader impact. Option B incorrectly states that excess rights improve performance, which is unrelated to security. Option D is false; excessive privileges directly weaken security. Recognizing these violations helps administrators enforce strict access controls.

Q10. A developer writes a program that reads memory segments and writes to a tape drive. Which set of operations is correctly allowed for each object type?

A. Memory: execute only; Tape: read and write only
B. Memory: read and write; Tape: read, write, and rewind ✅
C. Memory: read only; Tape: execute
D. Memory: delete only; Tape: write only

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The correct answer is B because memory segments can be both read from and written to, while tape drives support reading, writing, and rewinding as defined operations. Option A incorrectly limits memory to execution, which is not a typical operation for a memory segment. Option C assigns an execute operation to tape, which is invalid. Option D suggests deletion of memory, which does not apply to memory segments. Matching allowed operations to object types ensures programs respect access control rules.
