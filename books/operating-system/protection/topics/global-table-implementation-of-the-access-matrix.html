📝 Global Table Implementation of the Access Matrix

📖 From Operating System • 14. Protection • 8 questions available

What is Global Table Implementation of the Access Matrix?

Definition:
The global table implementation stores the entire access matrix as a single centralized data structure containing all domain-object-permission triples for lookup during access checks.

Example:
A hash table maps \( (\text{domainID}, \text{objectID}) \to \text{permissions} \), requiring \( O(1) \) average lookup but consuming significant memory.

Reason:
While conceptually simple, this approach suffers from poor scalability and cache performance in large systems due to sparse matrix representation.

Q1. What is the definition of the owner right in an access matrix?

A. The ability to copy a right to another domain
B. The ability to add or remove rights in a column ✅
C. The ability to read an object only
D. The ability to execute an object only

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The owner right gives a domain full control over the rights associated with a particular object column. This means the domain can insert new rights or delete existing ones for that object. Options A, C, and D describe other specific capabilities such as copying or simple read/execute permissions, which are not what the owner right provides. Therefore the correct choice is B.

Q2. How does the limited copy right affect further propagation of a right after it is copied?

A. It allows unlimited further copying ✅
B. It creates the original right only
C. It creates only the non‑propagating version of the right
D. It removes the original right

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The limited copy right copies a right from one entry to another but deliberately prevents the newly created right from being copied again. Thus the right exists in the target entry but cannot be propagated further. Option A describes the unrestricted copy right, option B misstates the effect, and option D suggests removal, which is not the behavior of limited copy. Hence option C correctly captures the limitation.

Q3. Which variant of the copy mechanism corresponds to the 'transfer' right?

A. Copy then remove the original ✅
B. Copy without removing the original
C. Limited copy
D. Owner right

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The transfer variant copies a right from one domain to another and then removes the right from the source entry, effectively moving the permission. This matches the description of the transfer right. Option B describes the basic copy right, option C refers to the limited copy variant, and option D is unrelated to copying semantics. Consequently, the correct answer is A.

Q4. Domain D2 holds a copy right for read* on object F2 and wants to give D3 the same right while keeping its own right intact. Which right should D2 use?

A. copy ✅
B. transfer
C. limited copy
D. owner

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

If D2 wants to retain its existing read* right while also granting the same right to D3, it must use the copy right, which duplicates the permission without removing it from the source domain. The transfer right would delete D2's original right, limited copy would prevent D3 from further copying, and the owner right is unnecessary for this simple duplication. Therefore the appropriate choice is the copy right.

Q5. A system wishes to prevent domain D4 from further copying a right after it receives that right. Which right should be granted to D4?

A. copy
B. transfer
C. limited copy ✅
D. owner

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The limited copy right creates a copy of a permission but explicitly blocks any additional propagation from the recipient. This ensures D4 can use the right but cannot pass it on. The regular copy right would allow D4 to copy again, transfer removes the original from the giver, and owner grants broader authority than needed. Hence the limited copy right best satisfies the requirement.

Q6. Domain D1 is the owner of object F1 and wants domain D5 to have write* on F1 and also allow D5 to later add read* rights on the same object. Which combination of rights should D1 grant to D5?

A. only write*
B. write* and owner ✅
C. write* and copy
D. write* and limited copy

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

To let D5 both use write* and later modify the rights column for F1, D1 must give D5 the owner right in addition to write*. The owner right enables D5 to add or remove any valid rights, including read*, while write* provides the immediate permission needed. Options C and D involve copying rights, which do not give authority to change the matrix, and option A lacks the ability to add new rights. Thus the correct answer is B.

Q7. What is the primary difference between the copy right and the limited copy right regarding transitive propagation?

A. Both allow unlimited propagation ✅
B. Copy allows transitive propagation while limited copy does not
C. Limited copy allows transitive propagation while copy does not
D. Neither allows any propagation

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The standard copy right permits a domain that receives a copied permission to copy it again, creating a transitive chain of propagation. In contrast, the limited copy right deliberately blocks this second‑level copying, so the permission cannot be further propagated. Option A incorrectly states both behave the same, option C reverses the roles, and option D denies any copying, which is not accurate for the basic copy right. Therefore option B correctly describes the distinction.

Q8. In a system with domains D1, D2, D3 and objects F1, F2, D1 owns F1 and grants D2 a copy right for read*. D2 then grants D3 the same right. Which statement is true?

A. D3 can further copy the right to another domain
B. D3 cannot copy because only copy right was transferred
C. D3 now has owner rights on F1 ✅
D. D3 can read but cannot copy

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When D2 uses the copy right, it creates a duplicate read* permission for D3 while retaining its own copy. The copy right inherently allows the recipient (D3) to copy the permission again, establishing a transitive chain. Therefore D3 can indeed propagate the right further. Options B and D incorrectly limit D3's ability, and option C incorrectly assigns owner status. Hence the accurate statement is option A.
