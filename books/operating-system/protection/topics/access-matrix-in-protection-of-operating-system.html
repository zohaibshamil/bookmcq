What is Access Matrix in protection of Operating System?

Definition:
The access matrix is an abstract model representing protection state as a two-dimensional table where rows are domains, columns are objects, and entries specify allowed operations.

Example:
Entry indicates userA can read and write fileX but not execute it.

Reason:
This formal model provides a clear foundation for analyzing and implementing protection policies, though direct storage is impractical due to sparsity.

Q1. What does the setuid bit on a Unix file indicate?

A.File is executable only by owner
B.Execute with owner's privileges ✅
C.File is read‑only
D.File is hidden
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The setuid bit signals that when the file is executed, the process adopts the file owner's UID, granting the owner’s privileges temporarily. Option B captures this behavior. Option A confuses setuid with the ordinary executable permission, C describes read‑only status unrelated to setuid, and D mischaracterizes it as a hidden attribute. Understanding this helps administrators control privilege elevation in multi‑user environments.
