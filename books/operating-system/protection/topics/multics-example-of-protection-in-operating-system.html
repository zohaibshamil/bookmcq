Q1. An administrator must grant a user temporary admin rights to install software and then revoke them. Which mechanism best supports this temporary privilege change?

🔹 A. Role‑based access control (RBAC)
🔹 B. Discretionary access control (DAC)
🔹 C. Mandatory access control (MAC)
🔹 D. Capability‑based access control

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

RBAC allows the administrator to assign a specific role that includes admin privileges and later remove that role, providing a clean, auditable way to grant temporary rights. DAC relies on object owners and would not centrally manage temporary elevation. MAC enforces fixed policies that are hard to change on a per‑user basis. Capability systems are less common in typical OS environments. RBAC therefore matches the need for controlled, reversible privilege elevation.

Q2. What is the primary purpose of audit trails in a protection domain?

🔹 A. To increase system speed
🔹 B. To detect unauthorized privilege use
🔹 C. To reduce storage usage
🔹 D. To simplify user login

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Audit trails record events such as privileged function calls, enabling administrators to trace who performed which action and when. Detecting unauthorized use relies on this recorded evidence. Increasing speed or reducing storage are unrelated effects, and simplifying login does not involve logging. Thus, the main purpose is to provide a reliable record for detecting misuse of privileges.

Q3. Which statement best defines the principle of least privilege?

🔹 A. All users receive administrator rights
🔹 B. Users receive only the privileges needed to perform their tasks
🔹 C. No privileges are assigned to any user
🔹 D. All users share a single generic account

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The principle of least privilege dictates that each user should have just enough access to accomplish their responsibilities, minimizing the chance of accidental or malicious misuse. Giving everyone admin rights violates the principle, as does assigning no privileges or using a shared account, which would obscure accountability. Therefore, the correct definition is that users receive only the privileges needed for their tasks.

Q4. Which access control method best enforces that backup operators can mount tapes but cannot modify system files?

🔹 A. Role‑based access control (RBAC)
🔹 B. Mandatory access control (MAC)
🔹 C. Access control lists (ACL) per file
🔹 D. Discretionary access control (DAC)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

RBAC lets the administrator create a dedicated backup role that includes tape‑mount commands while excluding file‑modification permissions, ensuring consistent enforcement across all backup staff. MAC would impose rigid, classification‑based rules that are not tailored to this specific job function. ACLs could be used but would require managing many individual file entries, increasing complexity. DAC depends on file owners and would not centrally restrict the operator’s capabilities. Hence RBAC is the most appropriate solution.

Q5. Why might a system with more lines of code have more security holes despite using similar protection mechanisms?

🔹 A. More code introduces more opportunities for bugs
🔹 B. Larger code reduces system performance
🔹 C. Users tend to forget passwords on larger systems
🔹 D. Hardware limitations cause vulnerabilities

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A larger codebase typically contains more functions, interactions, and edge cases, each of which can harbor defects that become security vulnerabilities. Performance degradation, password habits, or hardware constraints do not directly create additional holes; they affect other aspects of system behavior. Therefore, the primary reason for increased security issues is the higher probability of bugs arising from the greater amount of code.

Q6. A company wants to ensure that backup operators can only mount tapes and cannot modify system files. Which access control method best enforces this?

🔹 A. Role‑based access control (RBAC)
🔹 B. Mandatory access control (MAC)
🔹 C. Access control lists (ACL) per file
🔹 D. Discretionary access control (DAC)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

RBAC allows the definition of a role specifically for backup operators, granting tape‑mount capabilities while explicitly denying file‑modification rights, providing a clear, maintainable policy. MAC would apply fixed classifications that might be too restrictive or inflexible for this job. ACLs would require setting permissions on each file individually, leading to administrative overhead. DAC relies on file owners and cannot enforce a consistent restriction across all backup staff. Thus RBAC is the optimal choice.

Q7. How does enabling privileges only when needed improve security?

🔹 A. Reduces the window of opportunity for attackers
🔹 B. Increases CPU usage
🔹 C. Eliminates the need for passwords
🔹 D. Improves network bandwidth

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

When a system grants elevated rights only at the moment they are required, the time during which an attacker could exploit those rights is minimized, thereby lowering risk. This does not inherently affect CPU usage, password policies, or network throughput. By limiting exposure, the approach directly enhances security, making the reduction of attack windows the key benefit of on‑demand privilege activation.

Q9. An auditor sees a privileged function called at 02:00 AM, outside normal admin hours. What should be the next step?

🔹 A. Ignore the entry as benign
🔹 B. Investigate for possible misuse
🔹 C. Delete the log entry
🔹 D. Grant additional privileges to the user

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A log entry showing privileged activity at an unusual time warrants further investigation to determine whether it represents unauthorized access or a legitimate but undocumented operation. Ignoring it could miss a breach, deleting the log destroys evidence, and granting more privileges would exacerbate risk. Therefore, the appropriate response is to investigate the anomaly to assess its legitimacy.

Q10. In the context of MULTICS, how did the concept of rings of protection influence modern OS design?

🔹 A. Introduced hierarchical privilege levels
🔹 B. Created a flat memory model
🔹 C. Eliminated the need for authentication
🔹 D. Made all processes equal in rights

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

MULTICS introduced a ring‑based model where each ring represented a different privilege level, establishing a hierarchy that modern operating systems emulate with kernel and user modes. This structure does not flatten memory, remove authentication, or equalize process rights; instead, it provides a layered approach to security that separates critical system functions from ordinary user tasks.

Q11. A multinational corporation uses a centralized RBAC system. They need to allow a user in the Europe office temporary access to a US‑only database for a project, but only between 09:00‑17:00 GMT. Which combination of controls best satisfies the requirement?

🔹 A. Role assignment plus time‑based ACL
🔹 B. Mandatory labeling
🔹 C. Capability tokens without time constraints
🔹 D. Discretionary access control

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Assigning the user a role that includes database access and coupling it with a time‑based ACL ensures that the permission is both functionally appropriate and limited to the specified hours. Mandatory labeling would not address temporal restrictions, capability tokens lack built‑in time limits, and discretionary control depends on individual owners, making it unsuitable for centrally enforced, time‑restricted access.

Q12. Explain why the principle of least privilege might fail to improve security if not coupled with proper monitoring.

🔹 A. Because privileges cannot be revoked
🔹 B. Because users may still abuse granted rights unnoticed
🔹 C. Because it slows down the system
🔹 D. Because it removes all privileges

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Even when users are given only the minimum necessary rights, those rights can be misused if there is no way to detect or audit their actions. Without monitoring, an insider could exploit their limited privileges to cause damage, and administrators would lack evidence to respond. The other options misrepresent the principle: privileges can be revoked, system performance is not the main concern, and the principle does not eliminate privileges entirely.

Q14. A system administrator configures an audit trail that records every invocation of a privileged system call. Later, a security breach is detected. Which statement is true regarding the usefulness of the audit trail?

🔹 A. It can pinpoint the exact user and time of the privileged call
🔹 B. It prevents the breach from occurring
🔹 C. It replaces the need for firewalls
🔹 D. It encrypts all data automatically

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

An audit trail that logs each privileged call provides precise information about who executed the call and when, which is vital for forensic analysis after a breach. While the trail does not stop attacks, replace firewalls, or encrypt data, its primary value lies in enabling investigators to reconstruct events and attribute actions to specific accounts.

Q15. Compare the security implications of using role‑based access control versus discretionary access control in a multi‑tenant cloud environment.

🔹 A. RBAC provides centralized policy, DAC relies on individual owners
🔹 B. DAC is more secure than RBAC
🔹 C. RBAC cannot be audited
🔹 D. DAC eliminates the need for authentication

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

RBAC allows the cloud provider to define and enforce consistent access policies across all tenants, simplifying compliance and reducing the risk of misconfiguration. DAC, by contrast, depends on each resource owner to set permissions, which can lead to inconsistent security settings and potential oversharing. RBAC can be audited, and DAC does not remove authentication requirements, making the first option the accurate comparison.

Q16. A developer writes code that checks a user’s role before performing a privileged operation. Which security principle does this code exemplify?

🔹 A. Defense in depth
🔹 B. Principle of least privilege
🔹 C. Security through obscurity
🔹 D. Fail‑open

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Checking a user’s role to ensure they have the necessary permissions embodies the principle of least privilege, granting only the rights required for the operation. Defense in depth involves multiple layers of protection, security through obscurity hides details without providing real security, and fail‑open describes a system that remains functional when a security check fails—all of which do not describe the role‑checking behavior.

Q18. An operating system provides a system call to temporarily elevate a process’s privileges. Which term best describes this mechanism?

🔹 A. Privilege escalation
🔹 B. Privilege de‑escalation
🔹 C. Privilege elevation
🔹 D. Privilege revocation

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The mechanism that allows a process to gain higher privileges for a short period is called privilege elevation. Escalation implies an unauthorized or malicious increase, de‑escalation reduces privileges, and revocation removes them entirely. Therefore, the appropriate term for a controlled, temporary increase is privilege elevation.

Q19. What is an access control list (ACL) used for?

🔹 A. Listing users’ passwords
🔹 B. Defining which users or groups may access a resource
🔹 C. Storing system logs
🔹 D. Allocating memory

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

An ACL is a data structure attached to a resource that specifies which users or groups are permitted to read, write, or execute that resource. It does not store passwords, logs, or manage memory allocation. By defining access rights, ACLs help enforce security policies at the level of individual objects.
