What is UNIX example of protection in Operating System?

Definition:
UNIX implements protection through user/group identifiers and file permission bits that determine read, write, and execute access based on ownership and group membership.

Example:
A file with mode \( 754 \) grants owner rwx, group rx, and others r-only, enforced by the kernel on every \( \text{open()} \) call.

Reason:
This simple yet effective model enables multi-user security without complex capability systems, balancing usability and protection in early timesharing systems.

Q1. What is the principle of least privilege?

A.Grant all users full system rights
B.Give each user only the rights needed to perform their tasks ✅
C.Allow users to share passwords
D.Disable all user accounts
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The principle of least privilege means that a user receives only the minimum permissions required to accomplish their job. Option B states this directly, making it correct. Option A gives too many rights, violating the principle. Option C suggests sharing passwords, which undermines security. Option D disables accounts entirely, which is not the intent. By limiting rights, systems reduce the chance of accidental or malicious misuse, a core security practice.

Q2. Why does implementing role‑based access control help enforce the principle of least privilege?

A.It automatically grants all permissions to every role
B.It groups users so they share the same password
C.It assigns specific permissions to each role based on job functions ✅
D.It removes the need for any access control lists
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Role‑based access control (RBAC) defines roles that correspond to job functions and assigns only the permissions needed for those functions. Option C captures this idea, making it correct. Option A gives all permissions, contradicting least privilege. Option B focuses on passwords, unrelated to RBAC. Option D ignores RBAC entirely. By matching roles to required privileges, RBAC limits excess access and simplifies management.

Q3. A backup operator must mount tapes and copy files but should not modify system settings. Which configuration best applies the principle of least privilege?

A.Give the operator root access and trust they will not change settings
B.Create a separate account with only tape‑mount and copy commands permitted ✅
C.Allow the operator to use sudo for any command when needed
D.Provide no account and require the operator to work as a guest
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Providing a dedicated account with only the necessary commands (Option B) would be the ideal least‑privilege solution, but the question asks for the best configuration among the listed choices. Option D limits the operator to guest access, preventing any privileged actions, thus ensuring the operator cannot change system settings. Option A gives excessive rights, Option C allows unrestricted sudo use, and Option C (the other) still grants too much authority.

Q4. How do audit trails contribute to detecting misuse of privileged functions?

A.They record every privileged call and who invoked it ✅
B.They automatically block any privileged command
C.They encrypt all system logs so no one can read them
D.They replace the need for access control lists
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Audit trails log each invocation of privileged functions along with the user identity, enabling administrators to review who performed sensitive actions. This makes Option A correct. Option B describes prevention, not detection. Option C suggests encryption which would hide the logs, defeating their purpose. Option D implies audit trails substitute for ACLs, which is incorrect; they complement, not replace, access controls. Analyzing logs helps uncover unauthorized privilege use.

Q5. A system administrator needs temporary privilege to mount a new tape drive. Which method follows best practice?

A.Give the admin permanent root rights
B.Use sudo to allow the mount command only for the needed session ✅
C.Create a new user with full root access
D.Disable all logging during the operation
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Using sudo to grant permission for a specific command during a limited session (Option B) follows the principle of granting only needed privileges temporarily. Option A provides permanent high rights, violating least privilege. Option C creates an unnecessary full‑privilege account. Option D disables logging, removing audit capability and increasing risk. By restricting the command and duration, the admin minimizes exposure while still accomplishing the task.

Q6. An administrator wants to allow a group of developers read‑only access to a shared library while preventing any modifications. Which mechanism should be used?

A.Set the file owner to root and give everyone write permission
B.Apply an access control list that grants read rights to the developers group ✅
C.Create a new role that includes write permission for the library
D.Remove all permissions from the file
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Applying an ACL that specifically grants read rights to the developers group (Option B) provides fine‑grained control without giving write access. Option A gives write permission to everyone, which is insecure. Option C adds write rights, contradicting the requirement. Option D removes all access, preventing even the needed read operation. ACLs enable precise permission settings, aligning with the principle of least privilege.

Q10. How does an access control list (ACL) complement role‑based access control (RBAC) in enforcing least privilege?

A.ACLs replace RBAC entirely by assigning permissions to individual users
B.ACLs provide fine‑grained permissions for objects that RBAC cannot express at the role level ✅
C.ACLs make RBAC unnecessary because they are more flexible
D.ACLs and RBAC are unrelated and cannot be used together
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: ACLs allow specific permissions on files or resources that may not fit neatly into a role definition, thereby enhancing RBAC’s broader role assignments. Option B correctly describes this complementary relationship. Option A is false because ACLs do not replace RBAC. Option C misstates that RBAC becomes unnecessary, which is incorrect. Option D claims they are unrelated, ignoring how many systems combine both to achieve precise, least‑privilege controls.

Q11. A script needs temporary elevated rights to copy a protected file, then should drop those rights. Which command sequence follows best practice?

A.chmod 777 /protected/file; cp /protected/file /tmp/; chmod 644 /protected/file
B.Use setuid root on the script and run it directly
C.Run the script with sudo for the copy operation only, then exit ✅
D.Copy the file as root and never change permissions again
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Running the script with sudo for just the copy operation (Option C) ensures the script gains elevated rights only when needed and relinquishes them afterward, matching least‑privilege principles. Option A permanently changes permissions, creating a security hole. Option B makes the script constantly setuid root, which is risky. Option D does not drop privileges after the operation. By limiting elevation to the specific command, the system remains more secure.

Maintaining an audit trail helps detect misuse, support investigations, and enforce accountability in a protected environment.
