What is Storage area network?

Definition:
A storage area network (SAN) is a high-speed dedicated network providing block-level storage access between servers and storage arrays using Fibre Channel or iSCSI protocols.

Example:
A Fibre Channel SAN delivers frames with payload size bytes at 32 Gbps with lossless delivery guarantees.

Reason:
SANs decouple storage from servers enabling flexible resource pooling, high availability, and enterprise-grade performance for mission-critical databases and virtualization.

📝 All Storage area network MCQs

Q1. What does the acronym SAN stand for in the context of storage networking?

A.Storage Area Network ✅
B.System Access Node
C.Secure Allocation Network
D.Serial Attached Network
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The correct answer is A because SAN is defined as Storage Area Network, a dedicated high‑speed network that provides block‑level storage to servers. Option B describes a generic term not used in storage contexts, Option C is fabricated, and Option D refers to a different technology (Serial Attached SCSI). Knowing the definition helps students recognize SAN’s role in separating storage resources from the host, enabling flexible, scalable data access in enterprise environments.

Q2. Why does a Fibre Channel (FC) switched fabric with a 24‑bit address space better support multiple hosts and storage devices than an FC arbitrated loop (FC‑AL)?

A.It allows longer cables, reducing latency.
B.It provides error‑checking capabilities.
C.It offers a larger address space and non‑blocking switching. ✅
D.It uses fewer ports, simplifying configuration.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Option C is correct because a 24‑bit address space can uniquely identify up to devices, and a switched fabric provides dedicated paths that prevent traffic contention, allowing many hosts to communicate simultaneously. Option A is irrelevant; cable length does not determine scalability. Option B describes a feature common to both topologies but not the key differentiator. Option D is opposite—FC‑AL typically requires more ports for loop formation. Understanding these differences clarifies why SANs favor switched fabrics for large deployments.

Q3. How does constant angular velocity (CAV) affect data density across a hard‑disk platter?

A.Data density is higher on outer tracks than inner tracks.
B.Data density is uniform across all tracks.
C.Data density decreases from inner to outer tracks. ✅
D.Data density fluctuates randomly.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The correct answer is C because with CAV the platter rotates at a constant speed, so the linear velocity is greater on outer tracks; to keep the data rate constant, fewer bits are packed per unit length, resulting in lower density on outer tracks compared to inner tracks. Option A reverses this relationship, Option B ignores the physics of constant angular speed, and Option D suggests randomness which does not occur. Recognizing this effect helps students predict performance variations across disk zones.

Q4. What is the primary advantage of using a SAN over traditional network‑attached storage (NAS) when multiple servers require block‑level access to the same storage devices?

A.SAN provides file‑level access, simplifying file sharing.
B.SAN enables high‑speed, low‑latency block access with centralized management. ✅
C.SAN reduces the need for any networking hardware.
D.SAN automatically encrypts all data without additional software.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Option B is correct because SANs deliver block‑level storage over a high‑speed fabric, giving servers fast, low‑latency access and allowing centralized management of LUNs. Option A describes NAS, which works at the file level. Option C is false; SANs still require networking components like switches and HBAs. Option D is inaccurate; encryption is optional and not inherent to SAN architecture. Understanding this advantage explains why enterprises choose SANs for performance‑critical, multi‑host environments.

Q5. A data center needs to connect 8 servers to 4 storage arrays using Fibre Channel. Which topology minimizes latency while allowing each server to access any array?

A.Point‑to‑point connections
B.FC‑AL loop
C.Switched fabric ✅
D.Daisy‑chain wiring
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The correct answer is C because a switched fabric provides a dedicated path between each server and storage array, eliminating the bottlenecks of loops or daisy‑chains and keeping latency low. Point‑to‑point would require many individual links, becoming impractical. FC‑AL loops introduce contention as traffic shares a single loop. Daisy‑chain wiring creates sequential hops that increase delay. Recognizing the benefits of a switched fabric helps students design efficient SAN architectures.

Q6. If a SAN uses a 24‑bit address space, what is the maximum number of unique devices it can address?

A. ✅
B.
C.126
D.255
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Option A is correct because a 24‑bit address can represent distinct values, allowing that many unique devices to be addressed on the fabric. Option B corresponds to a 16‑bit space, which is far smaller. Option C reflects the limit of an FC‑AL loop, not a switched fabric. Option D is unrelated to the given address width. Knowing the address capacity is essential for planning SAN scalability and avoiding address exhaustion.

Q7. An organization wants to upgrade from an IDE‑based host‑attached storage to a Fibre Channel SAN. Which of the following steps is essential to ensure compatibility with existing servers?

A.Replace server CPUs
B.Install FC Host Bus Adapters (HBAs) ✅
C.Convert SATA drives to FC drives
D.Remove all Ethernet switches
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The correct answer is B because servers need Fibre Channel HBAs to communicate with the SAN fabric; without them, the servers cannot send or receive FC frames. Replacing CPUs (Option A) is unnecessary. Converting SATA drives (Option C) does not address the host‑side interface; drives are typically attached to FC storage arrays. Removing Ethernet switches (Option D) would break any existing network connectivity. Understanding this step highlights the hardware changes required for SAN migration.

Q8. A company experiences performance bottlenecks because its SAN fabric is overloaded with traffic. Which of the following strategies would most effectively balance the load?

A.Increase the rotation speed of disks
B.Implement zoning to segment traffic ✅
C.Convert FC to USB connections
D.Decrease the number of LUNs
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Option B is correct because zoning partitions the fabric into logical groups, directing traffic only to relevant devices and reducing unnecessary load, thus improving performance. Increasing disk rotation speed (Option A) does not address network congestion. Converting FC to USB (Option C) would drastically reduce bandwidth and is impractical. Decreasing LUNs (Option D) might limit resources but does not directly alleviate fabric overload. Understanding zoning helps students optimize SAN traffic flow.

Q9. During a SAN migration, an administrator must map logical unit numbers (LUNs) to physical disks. Which mapping method ensures that multiple hosts can share a single LUN without data corruption?

A.Exclusive LUN mapping
B.Multi‑initiator access with proper locking ✅
C.Single‑host zoning
D.RAID‑0 striping only
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The correct answer is B because multi‑initiator access combined with coordinated locking mechanisms allows several hosts to read/write the same LUN safely, preventing race conditions. Exclusive LUN mapping (Option A) restricts a LUN to one host, defeating sharing. Single‑host zoning (Option C) isolates hosts, not enabling shared access. RAID‑0 (Option D) provides striping but does not address concurrent host access. Knowing proper LUN sharing techniques is vital for reliable SAN deployments.

Q10. A small office uses a single SATA drive connected directly to a PC. Which storage architecture does this represent?

A.Network‑attached storage
B.Host‑attached storage ✅
C.Storage‑area network
D.Cloud storage
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Option B is correct because the drive is attached locally to the computer via a SATA interface, meaning it is accessed through the host’s I/O ports—a classic example of host‑attached storage. Network‑attached storage (Option A) involves a separate device accessed over a network. Storage‑area network (Option C) requires a dedicated fabric and HBAs. Cloud storage (Option D) refers to remote services accessed over the Internet. Recognizing this distinction helps students classify storage solutions.

Q11. Why does the ability of a SAN to support many hosts and storage devices improve overall system reliability?

A.It forces all devices to use the same firmware version
B.It enables redundant paths and failover capabilities ✅
C.It reduces the need for power supplies
D.It eliminates the need for backups
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The correct answer is B because a SAN’s fabric can provide multiple physical paths between hosts and storage, so if one path fails the traffic can be rerouted, maintaining availability. Option A is unrelated to reliability; firmware uniformity is not required. Option C misrepresents power redundancy, which is a separate concern. Option D is false; backups are still needed for data protection. Understanding path redundancy clarifies how SANs enhance fault tolerance in enterprise environments.
