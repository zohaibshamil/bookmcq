What is Disk Structure overview?

Definition:
Disk structure refers to the physical and logical organization of storage media including platters, tracks, sectors, cylinders, and zones that determine addressing and performance characteristics.

Example:
A multi-zone disk uses variable sector counts per track where outer zones have \( S_{outer} > S_{inner} \) sectors to maintain constant linear density.

Reason:
Understanding this hierarchical structure is essential for optimizing file system allocation, scheduling algorithms, and predicting I/O performance bottlenecks.

📝 All Disk Structure overview MCQs

Q1. What is the most common size of a logical block on modern magnetic disks?

A. 1024 bytes
B. 512 bytes ✅
C. 2048 bytes
D. 4096 bytes

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The typical logical block size is 512 bytes, which has been the standard for many years. Option B states this size, making it correct. Option A (1024 bytes) is used only on some specialized formats, not the common case. Options C and D are larger sizes that are rarely used for a single logical block. Understanding the default size helps when calculating how many blocks a file will occupy.

Q2. Why does the number of sectors per track typically decrease from the outermost to the innermost zone on a disk that uses constant linear velocity?

A. Because outer tracks have higher linear speed
B. Because inner tracks have larger radius
C. Because outer tracks are longer and can hold more sectors ✅
D. Because inner tracks are reserved for system data

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Constant linear velocity keeps the linear speed of the disk surface constant, so the length of each track determines how many sectors fit. Outer tracks have a larger circumference, allowing more sectors, while inner tracks are shorter and thus hold fewer sectors. Option C captures this relationship. The other options misstate the physics or refer to unrelated conventions.

Q3. How does increasing the rotation speed when moving the head toward inner tracks help maintain data transfer rate?

A. It reduces the time between sector passes
B. It compensates for the shorter track length ✅
C. It increases magnetic field strength
D. It lowers power consumption

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When the head moves inward, the track circumference shrinks, so fewer bits pass under the head per revolution. By raising the rotation speed, the disk ensures the same linear bit rate, preserving the data transfer rate. Option B correctly describes this compensation. Option A confuses timing with speed, Option C is unrelated to rotation, and Option D is the opposite of what actually occurs.

Q4. A file system needs to allocate 3,072 bytes. How many logical blocks of 512 bytes are required?

A. 4
B. 5
C. 6 ✅
D. 7

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Dividing the total bytes by the block size gives 3,072 ÷ 512 = 6 blocks. Option C matches this calculation, making it correct. Options A, B, and D either underestimate or overestimate the needed blocks, which would either truncate the file or waste space. Knowing how to convert bytes to blocks is essential for efficient storage allocation.

Q5. What is the primary reason that defective sectors are hidden from the logical block addressing scheme?

A. Defective sectors are skipped and never used
B. Spare sectors are mapped in place of defective ones ✅
C. The disk firmware marks them as read‑only
D. Operating systems automatically repair them

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When a sector is found to be defective, the disk controller substitutes a spare sector from elsewhere on the platter, preserving the logical block sequence. This substitution is transparent to the operating system, which continues to address blocks sequentially. Option B describes this mechanism. Options A and C suggest the OS deals with defects directly, which is not typical, and D misrepresents the repair process.

Q6. How does the mapping of logical block numbers to cylinder, track, and sector simplify the interface for operating systems?

A. It hides physical geometry details ✅
B. It speeds up data encryption
C. It reduces the need for error checking
D. It enables direct memory access

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Logical block mapping abstracts away the complex physical layout of cylinders, tracks, and sectors, presenting a simple linear address space to the OS. This abstraction (Option A) lets software read and write data without needing to know exact head positions. Options B, C, and D describe unrelated functionalities that are not achieved by the logical‑to‑physical mapping.

Q7. A disk has outer zone tracks holding 40% more sectors than inner zone tracks. If an inner track holds 100 sectors, how many sectors does a typical outer track hold?

A. 120
B. 130
C. 140 ✅
D. 150

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

A 40 % increase over 100 sectors gives 100 × 1.40 = 140 sectors. Option C reflects this calculation. Options A and B underestimate the increase, while D overestimates it. Understanding the proportional relationship helps when estimating capacity differences between zones.

Q8. During a format, a disk reports 2% of its sectors as defective. If the disk contains 10,000 sectors, how many spare sectors are needed to replace them?

A. 100
B. 150
C. 200 ✅
D. 250

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Two percent of 10,000 equals 0.02 × 10,000 = 200 sectors, so 200 spare sectors are required. Option C provides the correct number. The other options represent lower or higher estimates that would either leave some defects uncovered or waste space. Accurate calculation of spare sectors ensures reliable operation after formatting.

Q9. A storage engineer must calculate the logical block number for cylinder 5, track 3, sector 12 on a disk where each cylinder has 4 tracks and each track in that cylinder contains 200 sectors. What is the logical block number?

A. 4612 ✅
B. 4620
C. 4600
D. 4700

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Logical block number = ((cylinder × tracks_per_cylinder) + track) × sectors_per_track + sector. Substituting the values gives ((5 × 4) + 3) × 200 + 12 = 23 × 200 + 12 = 4,600 + 12 = 4,612. Option A matches this result. The other options arise from arithmetic errors such as forgetting the final addition or using an incorrect multiplier.

Q10. If a disk uses constant linear velocity and the outermost track has 250 sectors while the innermost track has 180 sectors, what percentage increase does the outer track represent over the inner track?

A. 0.3
B. 0.35
C. 0.39 ✅
D. 0.45

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The percentage increase is ((250 − 180) / 180) × 100 ≈ 38.9 %, which rounds to 39 %. Option C reflects this value. Options A, B, and D are lower or higher estimates that do not match the calculated increase. Knowing how sector counts vary across zones aids in capacity planning.

Q11. Explain why variable sectors‑per‑track complicates the translation from logical block numbers to physical addresses on some drives.

A. Because the mapping must account for differing sector counts per track ✅
B. Because all tracks have identical lengths
C. Because it eliminates the need for spare sectors
D. Because it standardizes rotation speed

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When sectors per track vary, the simple formula (cylinder × tracks × sectors + offset) no longer applies uniformly; the translation must adjust for each track’s specific sector count, making the computation more complex. Option A captures this issue. Options B, C, and D describe conditions that either simplify the problem or are unrelated to sector variability.

Q12. What advantage does mapping logical blocks sequentially across tracks within a cylinder provide for read/write performance?

A. It minimizes head movement between consecutive blocks ✅
B. It maximizes power consumption
C. It increases error‑correction overhead
D. It reduces rotational latency only for outer tracks

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Sequential mapping within a cylinder keeps the read/write head on the same cylinder for many consecutive accesses, reducing the need for frequent seeks and thus improving performance. Option A states this benefit. Options B and C describe negative effects that are not advantages, while D limits the benefit to outer tracks, which is inaccurate.

Q13. A system writes a 1 MiB file using 512‑byte logical blocks. Approximately how many blocks are needed?

A. 1024
B. 2048 ✅
C. 4096
D. 8192

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

One mebibyte equals 1,048,576 bytes. Dividing by the block size gives 1,048,576 ÷ 512 = 2,048 blocks. Option B matches this calculation. Options A, C, and D represent half, double, or quadruple the correct count, leading to under‑ or over‑allocation of space.

Q14. During a performance test, a disk rotates at 7200 rpm. How many revolutions occur in one second?

A. 100
B. 110
C. 120 ✅
D. 130

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Rotations per second = 7200 rpm ÷ 60 seconds = 120 rev/s. Option C is correct. Options A and B are lower, while D is higher than the actual value. Converting rpm to rev/s is a basic step in evaluating rotational latency.

Q15. If a drive replaces each defective sector with a spare located 5 cm outward on the same platter, how might this affect average seek time compared to random spare placement?

A. It slightly increases average seek time because the head must travel farther ✅
B. It dramatically decreases average seek time by clustering spares
C. It has no effect because seek time depends only on rotation
D. It reduces power consumption

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Placing spares outward adds a modest extra distance for the head to travel when accessing a replaced sector, leading to a slight increase in average seek time versus randomly distributed spares that may be closer on average. Option A describes this effect. Options B and C misstate the impact, and D addresses power rather than latency.
