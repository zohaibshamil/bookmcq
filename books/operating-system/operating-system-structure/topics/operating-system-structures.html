What is Operating System Structures?

Definition:
OS structures refer to organizational models such as monolithic, layered, microkernel, or hybrid architectures, each defining component interactions via interfaces I={(Ci,Cj,protocol)} \mathcal{I} = \{(C_i, C_j, \text{protocol})\} I={(Ci​,Cj​,protocol)}.

Example:
Mach uses a microkernel structure where only IPC and basic scheduling reside in kernel space, while file systems run as user-space servers.

Reason:
Structural choices impact performance, fault isolation, and extensibility, guiding trade-offs during system development.
