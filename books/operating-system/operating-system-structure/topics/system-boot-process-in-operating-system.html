What is System boot process in operating system?

The system boot process in an operating system is the sequence of events that occurs when power is applied, starting with firmware like BIOS or UEFI performing hardware checks, then loading a bootloader from storage into memory address \( 0x7C00 \), which subsequently loads the OS kernel into RAM and transfers control to it, initializing essential subsystems until the login prompt or GUI appears for user interaction.
