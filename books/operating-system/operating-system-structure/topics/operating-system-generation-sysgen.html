📝 Operating system generation SYSGEN (30 MCQs)

System-Specific Operating System Configuration

System generation, commonly called SYSGEN, refers to configuring or preparing an operating system for the hardware and requirements of a particular computer system. Traditionally, the process involved identifying processor characteristics, available memory, attached devices, and required kernel components. The resulting configuration determines which hardware support, system parameters, and device facilities are available when the operating system is installed and executed.

Why Operating Systems Need Hardware-Specific Configuration

Computers differ in processor architecture, memory capacity, device controllers, storage systems, and peripheral arrangements. A single fixed configuration may include unnecessary components or lack support for required hardware. SYSGEN addresses these differences by selecting appropriate system components and configuration parameters, allowing the operating system to match its environment while avoiding unnecessary resource consumption and compatibility problems.

Hardware Detection, Configuration Parameters, and Kernel Preparation

The generation process identifies relevant hardware characteristics and required system facilities. Configuration tools or build procedures select appropriate kernel options, drivers, memory parameters, and device support. Depending on the operating system, this may produce a configured kernel, installation settings, or a hardware-specific system description. Modern systems also use automatic detection and modular drivers, reducing the need for traditional manual generation.

Preparing a Kernel Configuration for a Storage Controller

Consider a computer using a particular storage controller and a specified processor architecture. During system generation, the required controller support and suitable kernel configuration options are selected. The resulting system includes the components necessary to communicate with that hardware. Without appropriate driver support or configuration, the operating system may fail to detect the storage device or access its contents.

Configuration Efficiency, Compatibility, and Maintenance

System generation can produce configurations tailored to available hardware, reducing unnecessary components and improving compatibility. It also allows administrators to prepare systems for specialised environments. However, incorrect hardware descriptions or missing drivers may prevent successful booting. Modern automatic hardware detection, modular kernels, and configuration tools simplify deployment, although kernel options and compatibility still require careful management.

Misconceptions About SYSGEN and Runtime Hardware Detection

'SYSGEN always occurs every time a computer boots' is incorrect because traditional generation prepares a system configuration before normal startup. 'Every modern operating system requires manual kernel generation' is incorrect because automatic detection and prebuilt kernels are common. 'Changing one hardware setting always requires rebuilding the entire operating system' is incorrect because many systems support runtime configuration.

Exam Focus: Hardware Identification and System Generation

Explain why SYSGEN is performed and identify the hardware information required for system configuration. Trace the relationship between processor architecture, memory, device controllers, drivers, and kernel options. Questions may distinguish system generation from booting, installation, and runtime device detection, or ask how incorrect configuration affects hardware recognition and operating system compatibility.

Key Terms of System Generation

  • SYSGEN - Hardware-specific operating system generation.
  • Configuration - Selected system settings and components.
  • Device driver - Software controlling hardware devices.
  • Kernel option - Selectable kernel configuration feature.
  • Hardware detection - Identification of installed devices.
  • Compatibility - Ability to operate with hardware.

📝 All Operating system generation SYSGEN MCQs

Q1. A computer manufacturer prepares an operating-system installation for a workstation containing a specific processor, memory capacity, and set of peripheral devices. What is the primary purpose of system generation?

A.To create a customized operating-system configuration for the target hardware ✅
B.To replace the computer's firmware
C.To convert every application into assembly language
D.To remove the need for device drivers
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: System generation prepares an operating-system configuration for a particular hardware environment. It identifies available resources and devices so that suitable kernel components, drivers, and configuration parameters can be selected for the target computer.

Q2. During system generation, an administrator is asked to identify the processor model, available memory, installed disks, and connected controllers. Why is this information collected?

A.To determine which applications users prefer
B.To configure the operating system according to the machine's hardware characteristics ✅
C.To calculate the CPU burst time of every process
D.To construct the file system directory hierarchy automatically
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Hardware information determines the operating-system components and parameters required by the target machine. Processor capabilities, memory size, controllers, and devices influence kernel configuration and help prevent incompatibilities during initialization and normal operation.

Q3. A system administrator installs an operating system on a computer containing a network adapter that is not installed in other machines in the organization. Which configuration activity is most relevant?

A.Changing the CPU scheduling algorithm
B.Reformatting every application
C.Selecting or configuring the appropriate network device driver ✅
D.Changing the system clock frequency
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: Device-driver configuration ensures that the operating system can communicate with installed hardware. Selecting the appropriate network driver allows kernel services and applications to use the network adapter through supported device interfaces.

Q4. A system administrator selects only the drivers required by the target computer and includes them directly in the kernel during its generation. What is this approach called?

A.Dynamic device discovery
B.Virtual memory allocation
C.Runtime driver replacement
D.Static driver inclusion ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Static driver inclusion places selected driver code inside the generated kernel image. The drivers are available as part of the kernel after booting, but unnecessary components increase image size and may require rebuilding the kernel when configurations change.

Q5. A company maintains a standard operating-system installation for hundreds of computers with different hardware configurations. Which approach reduces the need to generate a completely separate kernel for every machine?

A.Use a generic kernel with hardware detection and suitable dynamically loadable drivers ✅
B.Compile every possible device driver into every application
C.Assign identical physical memory addresses to all computers
D.Disable hardware identification during startup
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A generic kernel can support different machines through hardware detection and dynamically loadable drivers. This reduces the need for separate customized kernel images while allowing the operating system to activate components appropriate to each computer.

Q6. A technician changes the boot configuration so that the computer starts its operating system from a newly installed solid-state drive. Which configuration property is being changed?

A.Process synchronization order
B.Boot-device selection ✅
C.Page replacement policy
D.CPU scheduling quantum
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Boot-device selection identifies the storage device from which the system should locate its boot files or operating-system image. Correct configuration allows firmware and boot software to locate the intended installation during startup.

Q7. A university prepares an operating-system image for computers containing four processors instead of one. Which hardware characteristic must the generated system appropriately support?

A.Single-task file processing
B.Fixed disk directory names
C.Multiprocessor capabilities ✅
D.Text editor configuration
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: A multiprocessor configuration must support the available processors and appropriate kernel synchronization and scheduling facilities. The operating system needs suitable processor initialization and resource-management capabilities to use multiple CPUs correctly.

Q8. A system generation utility asks an administrator to specify the amount of physical memory available in the target machine. Why is this parameter important?

A.It determines the user's password length
B.It identifies the computer's network hostname
C.It determines the number of files in each directory
D.It helps configure memory-management limits and kernel memory parameters ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: Physical memory information helps configure the operating system's memory-management structures and resource limits. Accurate information supports appropriate kernel initialization, memory allocation, and management of physical memory available to processes.

Q9. A computer manufacturer records processor details, memory capacity, storage controllers, and installed devices in a configuration description before building an operating-system image. What is this description primarily used for?

A.Supplying hardware configuration information to the system-generation process ✅
B.Recording the execution history of every application
C.Calculating the waiting time of processes
D.Storing the contents of user documents
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A hardware configuration description provides the information needed to select and configure operating-system components. It helps the generation process establish compatible drivers, resource assignments, processor support, and other machine-specific settings.

Q10. An administrator adds a supported printer after installing an operating system that already provides dynamically loadable drivers. What may happen without rebuilding the entire kernel?

A.The processor must be replaced
B.The appropriate printer driver can be loaded during runtime ✅
C.All existing system files must be recompiled
D.The operating system must permanently disable device discovery
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Dynamic driver loading allows supported hardware components to be activated without rebuilding the complete kernel. When a compatible driver is available, the operating system can load it and configure the newly detected device during operation.

Q11. A system-generation project uses a powerful Linux workstation to produce an operating-system image intended for a smaller embedded computer with a different processor architecture. What is this process called?

A.Runtime scheduling
B.Demand paging
C.Cross-system generation or cross-compilation ✅
D.File-system journaling
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Cross-system generation uses a build environment on one computer to produce an operating-system image for another target architecture. The compiler, configuration tools, and libraries must support the target machine's instruction set and environment.

Q12. A kernel image contains a basic kernel of 10 MB and three statically included drivers occupying 1.5 MB, 2 MB, and 0.5 MB. What is the resulting image size, ignoring other overhead?

A.12 MB
B.13 MB ✅
C.13.5 MB
D.14 MB
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Static components become part of the generated kernel image. The total is 10+1.5+2+0.5=1410+1.5+2+0.5=1410+1.5+2+0.5=14 MB, representing the combined kernel and three selected drivers before additional metadata or alignment overhead.

Q13. A company generates an operating-system image for a computer with one processor. The machine is upgraded to four processors, and the existing kernel lacks multiprocessor support. What is the appropriate action?

A.Continue using the original configuration without checking compatibility
B.Disable three processors permanently
C.Regenerate or update the operating system with suitable multiprocessor support ✅
D.Delete the processor initialization routines
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: A kernel generated without the required multiprocessor capabilities may not initialize or manage additional processors correctly. The configuration must be updated to provide suitable processor initialization, scheduling, and synchronization support.

Q14. An administrator selects a storage controller driver during system generation but specifies an incorrect interrupt request line. What is a likely consequence?

A.The operating system may fail to communicate correctly with the controller because interrupt handling is misconfigured ✅
B.The system automatically increases physical memory
C.Every application receives additional process identifiers
D.The file system automatically changes to linked allocation
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Interrupt configuration connects hardware notifications with appropriate operating-system handlers. An incorrect interrupt assignment can prevent expected device notifications or create resource conflicts, disrupting controller operation and potentially affecting system startup.

Q15. A system supports dynamically loaded device drivers. Why might an administrator still choose static inclusion for a critical storage driver?

A.Static inclusion always reduces the total kernel image size
B.Static inclusion removes the need for storage hardware
C.Static inclusion guarantees that no device failure can occur
D.The driver is available as part of the kernel without requiring a separate runtime loading step ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Statically including a critical driver makes its code available within the kernel image during startup. This can simplify early hardware access when the operating system must use a device before normal module-loading facilities become available.

Q16. A computer has two non-shareable devices assigned to the same interrupt request line, but the controller hardware does not support interrupt sharing. What should the system-generation configuration do?

A.Assign an identical interrupt line to every device
B.Resolve the interrupt-resource conflict by assigning compatible available resources ✅
C.Disable all device interrupt handling
D.Assign both devices the same DMA channel regardless of hardware requirements
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Hardware resource assignments must respect controller capabilities and sharing rules. Non-shareable interrupt lines cannot safely be assigned to conflicting devices, so the configuration must select compatible resources before generating or installing the system.

Q17. A system administrator changes the configuration file to include a new statically linked device driver. What additional action is normally necessary before the new driver becomes part of the bootable kernel image?

A.Only change the desktop wallpaper
B.Restart the text editor
C.Run the appropriate kernel-generation or build process and install the resulting image ✅
D.Delete the processor configuration
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Changing a configuration file does not automatically insert new code into an existing statically built kernel. The generation process must rebuild the kernel image, after which the updated image must be installed and selected for booting.

Q18. A computer detects its installed memory and PCI devices automatically during startup. Which statement best describes the relationship between this capability and system generation?

A.Runtime hardware discovery can reduce the amount of machine-specific information that must be fixed during generation ✅
B.Automatic discovery makes kernel configuration unnecessary in every operating system
C.Hardware discovery replaces the boot loader
D.System generation is performed after every individual process terminates
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Runtime hardware discovery allows the operating system to identify devices and resources during startup or operation. This reduces dependence on fixed hardware descriptions, although the system still requires suitable drivers and compatible kernel support.

Q19. A configuration engineer maintains two kernel builds: one includes only essential drivers, while the other includes many optional drivers. What is the main trade-off?

A.The larger image always executes every application faster
B.Including optional drivers eliminates the need for hardware detection
C.The smaller image cannot execute user programs
D.The larger image offers broader built-in hardware support but consumes more storage and potentially memory ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Including additional drivers increases the functionality available immediately within the kernel image but also increases its size. A minimal image saves resources, while optional hardware support may require separate configuration or dynamic loading.

Q20. A company must reproduce the exact kernel configuration used for a previous production deployment. Which practice is most useful?

A.Change configuration parameters randomly before every build
B.Preserve configuration files, build-tool versions, compiler settings, and selected source revisions ✅
C.Store only the final desktop screenshot
D.Remove the hardware identification records after installation
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Reproducible system generation requires preserving the inputs that determine the resulting kernel. Configuration files, source revisions, compiler versions, and build settings allow engineers to reconstruct and investigate a previous operating-system image.

Q21. A generated operating-system image is tested on a machine with 8 GB RAM, but the deployment machine has 2 GB RAM. Why should the configuration and memory requirements be reviewed?

A.The kernel automatically doubles the deployment machine's physical memory
B.System generation always ignores memory information
C.Memory-related configuration and minimum resource requirements may not match the deployment machine ✅
D.The deployment machine will automatically acquire the build machine's memory configuration
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: A system image may depend on memory limits, kernel parameters, or minimum hardware requirements established during configuration. Deployment on a machine with less physical memory requires compatibility checks and potentially adjusted settings.

Q22. A build engineer generates a kernel using the wrong target processor architecture. The image compiles successfully on the build workstation but cannot execute on the intended embedded device. What caused the problem?

A.The selected target architecture does not match the deployment processor ✅
B.The build workstation has too much memory
C.The device has an incorrect directory name
D.The kernel contains too many file descriptors
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A successful build does not guarantee compatibility with the target processor. The generated machine instructions must match the target architecture, and cross-compilation settings must correctly identify the intended processor and its supported features.

Q23. A storage device requires a specific driver during early boot to access the partition containing the remaining operating-system modules. The driver is configured only as a runtime-loaded module stored on that partition. What is the main problem?

A.The driver consumes too little memory
B.The boot process may need the storage driver before it can access the location containing that driver ✅
C.The system must convert all files into indexed allocation
D.The storage device cannot support interrupts
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: This creates a bootstrapping dependency: the operating system needs the driver to access the storage containing the driver itself. Including the driver in the early boot image or providing suitable initial loading support resolves the dependency.

Q24. A system configuration contains these assignments: Disk controller A = IRQ 5 ; Network controller B = IRQ 5 ; Printer controller C = IRQ 7. Both controllers A and B require exclusive interrupt lines. Which configuration problem exists?

A.The printer and disk controllers have different IRQ values
B.The network controller has no DMA address
C.Controllers A and B have a conflicting assignment because both require exclusive IRQ 5 ✅
D.The configuration contains too many processors
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Exclusive interrupt resources cannot be assigned to two devices simultaneously. Both disk and network controllers use IRQ 5, so one must receive another compatible interrupt line before the configuration can operate correctly.

Q25. A generic kernel detects supported devices at startup and loads their drivers dynamically. A technician installs an additional supported network adapter while the system is running. Which sequence is most appropriate?

A.Rebuild the complete kernel immediately and reinstall the operating system
B.Erase all existing device configuration information
C.Disable the network service and replace the processor
D.Detect the adapter, identify its compatible driver, load it, and configure its resources ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Dynamic hardware management identifies the newly installed adapter, selects a compatible driver, and activates the required device configuration. This avoids rebuilding the entire kernel when the hardware and driver are already supported.

Q26. An organization creates two kernel images from the same source code. Image X includes five optional drivers totaling 6 MB, while Image Y includes only one required driver totaling 1.2 MB. If both have an 18 MB base kernel, what is the difference in image size?

A.3.6 MB
B.4.8 MB
C.6 MB
D.7.2 MB ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Image X occupies 18+6=2418+6=2418+6=24 MB, while Image Y occupies 18+1.2=19.218+1.2=19.218+1.2=19.2 MB. Their difference is 24−19.2=4.824-19.2=4.824−19.2=4.8 MB, showing the storage cost of additional statically included drivers.

Q27. A cross-generation project uses a host compiler that produces instructions for the wrong processor architecture. Which correction is required?

A.Change the target compiler configuration and rebuild using the intended target architecture ✅
B.Increase the host computer's disk scheduling quantum
C.Change the destination computer's user password
D.Disable all hardware-specific configuration
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Cross-compilation requires a toolchain configured for the target processor rather than merely the machine running the build. Correcting the target architecture ensures generated instructions and binary formats match the deployment hardware.

Q28. An engineer generates a kernel using configuration parameters for a machine with 16 GB RAM, four CPUs, and a specific storage controller. The image is then installed on a different computer with 4 GB RAM, one CPU, and another controller. What is the best next step?

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: An operating-system image may contain hardware-dependent assumptions about processors, memory, and device controllers. Deployment on different hardware requires checking compatibility and updating the generated configuration or using supported runtime detection.

Q29. A manufacturer wants identical operating-system builds for 500 computers with the same hardware configuration. Which practice best improves consistency?

A.Manually configure every computer differently
B.Use random device assignments for each installation
C.Maintain one validated configuration template and automate the generation and deployment process ✅
D.Remove all configuration records after the first installation
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: A validated configuration template standardizes processor support, memory parameters, and device assignments. Automating generation and deployment reduces configuration differences, simplifies testing, and improves consistency across machines with identical hardware.

Q30. A system-generation configuration specifies a boot controller, its driver, an interrupt handler, and a DMA channel. During startup, the controller is detected, but data transfers fail because the configured DMA channel is already reserved by another device. What is the most appropriate diagnosis?

A.The operating system has selected an invalid or conflicting hardware resource assignment ✅
B.The CPU scheduling algorithm is necessarily incorrect
C.The boot device must be changed to a network adapter
D.The system has automatically entered a deadlock state
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: DMA channels are hardware resources that must be assigned according to controller capabilities and sharing restrictions. A conflicting reservation can prevent expected transfers even when the controller and its driver are correctly detected and initialized.
