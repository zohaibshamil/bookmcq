What is Operating system generation SYSGEN?

Definition:
SYSGEN (system generation) is the process of configuring and building a customized OS instance for specific hardware, where configuration parameters determine included drivers and features.

Example:
During mainframe OS installation, SYSGEN prompts for CPU type, memory size, and I/O devices, then compiles a tailored matching those specs.

Reason:
It optimizes resource usage and compatibility by excluding unnecessary components, ensuring the OS matches the target platform exactly.

Q33. The module selection approach to SYSGEN involves linking selected modules. This approach is a compromise between recompilation and table-driven methods because it:
