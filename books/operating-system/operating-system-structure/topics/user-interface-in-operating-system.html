What is User interface in operating system?

Definition:
The user interface (UI) is the layer through which users interact with the OS, either via command-line interfaces (CLI) or graphical user interfaces (GUI), where interaction can be modeled as a function \( I: U \rightarrow A \) mapping user inputs \( U \) to system actions \( A \).

Example:
In Windows, clicking the ‘Save’ icon triggers the GUI to call underlying file-write services, translating visual action into \( \text{write(fd, buf, count)} \).

Reason:
A well-designed UI reduces cognitive load and makes complex OS operations accessible to non-expert users while maintaining consistency across applications.
