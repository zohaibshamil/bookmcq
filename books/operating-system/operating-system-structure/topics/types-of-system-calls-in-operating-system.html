What is Types of System Calls in operating system?

Definition:
System calls are categorized into types such as process control, file management, device manipulation, information maintenance, and communication, each type Tk T_k Tk​ serving a specific domain where k∈{1,2,3,4,5} k \in \{1,2,3,4,5\} k∈{1,2,3,4,5}.

Example:
open() \text{open()} open() and close() \text{close()} close() belong to file management, while send() \text{send()} send() and receive() \text{receive()} receive() fall under inter-process communication.

Reason:
Categorization simplifies OS design, aids documentation, and helps developers select appropriate calls based on functional requirements.
