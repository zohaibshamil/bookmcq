What is Single level directory File in Operating System?

Definition:
A single-level directory stores all files in one flat table where every filename must be globally unique across all users, lacking any hierarchical subdivision.

Example:
Early CP/M systems used a single directory containing entries like and ; two users could not both have a file named without conflict.

Reason:
While extremely simple to implement with minimal search overhead, this structure fails to scale beyond trivial usage because it provides no grouping mechanism and creates naming collisions in multi-user environments.

Q1. Which extension is used for a compiled Java class file?

A..java
B..class ✅
C..jar
D..py
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When Java source code is compiled, the resulting bytecode is stored in a file with the .class extension. This tells the JVM that the file contains executable Java bytecode. The .java suffix refers to source files, .jar to archive packages, and .py to Python scripts. Understanding the .class extension ensures that developers and tools correctly locate compiled Java code, enabling successful execution of Java applications.

Q2. A user attempts to run a script named \backup.sh\ on a Windows machine. Which outcome is most likely?

A.The script runs without issues
B.Windows prompts for a program to open the file
C.The script fails because .sh is not recognized as an executable extension on Windows ✅
D.Windows automatically converts .sh to .exe and runs it
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Windows recognises executable files primarily by extensions such as .exe, .com, and .bat. The .sh extension denotes a shell script, which is native to Unix-like environments, not to Windows. Consequently, when the user double‑clicks the file, Windows cannot treat it as an executable and will either display an error or ask the user to choose an application. This illustrates the importance of matching file extensions to the operating system’s expectations.

Q3. A system administrator wants the command interpreter to recognize all executable files. Which set of extensions should be added to the PATHEXT environment variable?

A..txt, .doc, .pdf, .jpg
B..com, .exe, .sh, .txt
C..com, .exe, .sh, .bat ✅
D..exe, .dll, .sys, .bin
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: PATHEXT defines which file extensions the command interpreter treats as executable without requiring the user to type the extension. Adding .com, .exe, .sh, and .bat covers the common binary executables (.com, .exe), shell scripts (.sh), and batch files (.bat). The other sets include non‑executable types like .txt or .dll, which would not enable execution. Properly configuring PATHEXT streamlines command usage and reduces typing errors.

Q4. A developer saves a source file without an extension and then runs gcc to compile it. What problem is most likely to occur?

A.gcc will automatically detect the language
B.gcc will refuse to compile because it cannot determine the file type ✅
C.gcc will treat the file as a binary and link it
D.gcc will compile but produce warnings
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The GNU Compiler Collection relies on file extensions such as .c, .cpp, or .java to infer the programming language and appropriate compilation flags. Without an extension, gcc cannot automatically select the correct language mode, leading to an error or the need for explicit flags (e.g., -x c). This demonstrates why extensions serve as crucial hints, helping tools apply the right processing steps and avoiding compilation failures.

Q5. In a single-level directory containing files report.docx, image.jpg, and script.sh, which command lists only the script file on a Unix‑like system?

A.ls *.sh ✅
B.dir *.sh
C.list script.sh
D.show script.sh
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The Unix command ls combined with a wildcard pattern *.sh instructs the shell to display all entries whose names end with .sh. Since script.sh matches this pattern, it appears in the output, while report.docx and image.jpg are excluded. The dir command is typical of Windows, and the other options are not valid commands, making them incorrect. Using globbing with ls is a standard way to filter files by extension.

Q6. A backup program expects archive files to have a .zip extension. A user renames a tar archive from \data.tar\ to \data.zip\ without converting its format. What is the most likely result?

A.The program will successfully extract the archive
B.The program will treat the file as a zip and likely report an error ✅
C.The program will automatically detect the actual format and proceed
D.The program will corrupt the original tar file
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Backup utilities rely on the file extension to select the appropriate decompression algorithm. Renaming a tar file to have a .zip suffix misleads the program into using zip‑specific logic, which cannot interpret tar structures. Consequently, the program will attempt to unzip the file, encounter unexpected data, and report a failure. This scenario underscores why extensions should accurately reflect file formats to prevent processing errors.

Q7. In an operating system that uses extensions as hints, what risk arises if two different applications assign the same extension to distinct file formats?

A.Increased storage efficiency
B.User confusion and potential opening of files with the wrong application ✅
C.Improved compatibility between applications
D.Automatic conversion of files between formats
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When the same extension represents multiple, unrelated formats, the operating system cannot reliably determine which application should open a given file. Users may double‑click a file expecting one program, but another unrelated program may launch, leading to errors, data loss, or security concerns. This risk highlights the need for unique, well‑defined extensions to serve as clear hints for applications.

Q8. Why do many operating systems rely on file extensions rather than inspecting file contents to identify file types?

A.Because inspecting contents is faster
B.Because extensions provide a simple, legacy‑compatible method ✅
C.Because extensions are required by the hardware
D.Because content inspection is illegal in some jurisdictions
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: File extensions offer a lightweight, backward‑compatible way to convey type information without the overhead of reading file headers or performing content analysis. This approach simplifies file handling, reduces I/O, and aligns with long‑standing conventions in software design. While content inspection can be more accurate, it demands additional processing time and complexity, which many systems avoid in favor of the straightforward extension convention.

Q9. How does a single-level directory limit file organization compared to hierarchical directories?

A.It allows unlimited nesting of folders
B.It forces all files to reside in one flat namespace, causing name collisions ✅
C.It provides automatic grouping by file type
D.It improves search speed for large numbers of files
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A single-level directory places every file directly within the same folder, eliminating subfolders that could categorize files by project, type, or date. This flat structure increases the chance of name conflicts, makes it harder to locate related files, and reduces overall manageability, especially as the number of files grows. Hierarchical directories, by contrast, enable logical grouping and easier navigation.

Q10. What is the relationship between file extensions and the concept of “hints” to applications?

A.Extensions are mandatory OS identifiers
B.Extensions are optional clues that guide applications in selecting appropriate handlers ✅
C.Extensions encrypt file contents
D.Extensions determine file size limits
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Extensions act as optional metadata that applications use to infer the intended file format. While the operating system may not enforce them, programs often rely on these hints to decide which parser or viewer to invoke. If an extension is missing or misleading, the application may need to guess or prompt the user, which can lead to errors. Thus, extensions serve as helpful, but not compulsory, guidance for software.

Q11. How does the existence of multiple executable extensions (.com, .exe, .sh) affect system security?

A.It reduces the attack surface
B.It increases the attack surface by providing more avenues for malicious code execution ✅
C.It has no impact on security
D.It automatically blocks all scripts
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Having several extensions recognized as executable means that malicious actors can disguise harmful code in any of those formats. For example, a script with a .sh extension might be executed on Unix systems, while .exe files can run on Windows. This variety expands the potential vectors for attacks, requiring administrators to implement broader controls, such as restricting execution permissions or validating file types, to maintain system security.

Q12. In a system where extensions are optional, how might an application locate its required file if the user omits the extension?

A.It will search the entire disk for a matching name
B.It will append its expected extensions to the provided base name and search the directory ✅
C.It will generate a random file name
D.It will abort the operation immediately
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When a user supplies a name without an extension, many applications attempt to resolve the request by appending known extensions they support (e.g., .txt, .docx) and checking for existence. This heuristic allows the program to locate the correct file without requiring the user to type the full name, improving usability while still relying on extension conventions as hints.

Q13. Suppose a user creates two files named \report.docx\ and \report.pdf\ in a single-level directory. If the user double‑clicks \report\ without specifying an extension, what is the most likely behavior?

A.The OS will open the .docx file by default
B.The OS will open the .pdf file by default
C.The OS will prompt the user to select which file to open ✅
D.The OS will display an error because the name is ambiguous
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: When a filename without an extension is provided, the operating system cannot uniquely identify which file the user intends, as both files share the same base name. Consequently, most GUIs will present a dialog asking the user to choose the desired file, or they may display an error indicating ambiguity. This situation underscores the importance of using full filenames, including extensions, to avoid confusion.

Q14. A system administrator wants only .exe files to be executable from a specific directory, while .sh scripts should be ignored. Which configuration approach best achieves this in a single-level directory environment?

A.Remove execute permission from all files in the directory
B.Modify the PATHEXT variable to exclude .sh for that directory ✅
C.Rename all .sh files to .txt
D.Create a wrapper script that checks extensions before execution
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: PATHEXT controls which extensions the command interpreter treats as executable without an explicit extension. By customizing PATHEXT for the target directory to include only .exe (and possibly .com) while omitting .sh, the system will ignore shell scripts when a user attempts to run them directly. Changing file permissions would affect all executable types, and renaming files or using wrappers adds unnecessary complexity. Adjusting PATHEXT provides a precise, directory‑scoped solution.
