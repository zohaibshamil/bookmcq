What is General graph file directory in Operating System?

General graph directories allow unrestricted linking including cycles, providing maximum sharing flexibility but requiring garbage collection algorithms to detect unreachable nodes and prevent infinite loops during recursive directory traversal or backup operations.

Q1. Which file extension is commonly used for Microsoft Word documents?

A. .docx ✅
B. .exe
C. .zip
D. .sh

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The extension .docx is the default format for recent Microsoft Word documents. It signals to the operating system and to Word that the file contains formatted text, images, and other document elements. Extensions such as .exe, .zip, and .sh serve completely different purposes—executables, archive files, and shell scripts respectively. Because programs rely on the extension to decide how to open a file, selecting .docx correctly enables Word to load the file without error.

Q2. What is the primary purpose of a file extension in most operating systems?

A. To determine file size
B. To indicate file type ✅
C. To encrypt file contents
D. To set file permissions

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A file extension provides a short textual hint that tells the operating system and applications what kind of data the file holds. This information guides the system in choosing the appropriate program to open or process the file. Extensions do not describe the file’s size, encrypt its contents, or set permissions; those attributes are stored elsewhere in the file system metadata.

Q3. How does the operating system typically handle a file with an unknown extension when a user attempts to open it?

A. Opens with a default text editor
B. Prompts the user to choose a program ✅
C. Deletes the file
D. Executes it as a script

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When the OS cannot match an unknown extension to a known file type, it does not assume a specific action. Instead, it presents a dialog asking the user to select an application capable of handling the file. This prevents accidental execution or data loss. Opening with a default editor, deleting, or executing the file would be unsafe actions that the OS deliberately avoids without explicit user direction.

Q4. Why might two different applications use the same file extension for distinct file formats, and what problems can this cause?

A. Because extensions are assigned by hardware
B. Because extensions are mandatory standards
C. Because extensions are optional hints ✅
D. Because extensions are encrypted

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

File extensions are merely informal labels; they are not enforced by the operating system. Consequently, developers may choose the same extension for unrelated formats, leading to ambiguity. When a user double‑clicks a file, the OS may launch the wrong program, causing errors or data corruption. Properly distinguishing files using MIME types or internal file headers helps avoid such conflicts.

Q5. A user tries to run a file named 'script.sh' on a Windows system without installing a Unix shell interpreter. What is the most likely result?

A. The script runs successfully
B. Windows converts it to a .exe
C. The file opens in Notepad
D. The system reports that the file cannot be executed ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

Windows does not natively understand shell scripts, which require a Unix‑like environment such as Bash. Without an interpreter, the OS cannot execute the commands inside the .sh file, so it returns an error indicating the file is not a valid executable. The script will not run, nor will Windows automatically convert it or open it in a text editor unless the user manually chooses a program.

Q6. A backup utility is configured to archive only executable files. Given the list: program.exe, readme.txt, archive.zip, launch.com, script.sh, which file will be excluded from the archive?

A. program.exe
B. launch.com
C. script.sh ✅
D. All of them are executable

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The .sh extension denotes a shell script, which is executable on Unix‑like systems but not on Windows without a compatible interpreter. Since the backup tool is likely running on a Windows platform and targets native executables, it will skip the .sh file. The .exe and .com files are recognized as Windows executables, so they will be included, while the other non‑executable files are irrelevant to the specified filter.

Q7. Which command will compile only the C++ source files in a directory using the GNU compiler?

A. gcc *.c
B. gcc *.cpp
C. g++ *.cpp ✅
D. javac *.java

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The GNU C++ compiler is invoked with the command g++. Using the wildcard *.cpp selects all files that end with the .cpp extension, which are typical C++ source files. The command gcc targets C files, and javac is for Java sources, so they would either compile the wrong language or fail. By issuing g++ *.cpp, the developer ensures that only the intended C++ files are compiled into object code or executables.

Q8. Which of the following file extensions are recognized by most operating systems as directly executable?

A. .exe, .com, .sh ✅
B. .doc, .pdf, .txt
C. .zip, .rar, .tar
D. .mp3, .wav, .aac

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Extensions .exe and .com are traditional Windows binary executables, while .sh identifies a shell script that can be run directly on Unix‑like systems with an appropriate interpreter. These three extensions signal to the OS that the file contains code ready for execution. The other listed groups—document formats, archive formats, and audio formats—are not inherently executable and require separate applications to open or process them.

Q9. An application expects a document named 'report' to have a .docx extension. If the user saves the file without an extension, what sequence should the application follow to locate the correct file?

A. Search for 'report' only
B. Append .txt and search
C. Open any file named 'report'
D. Append the expected .docx extension and search for that exact name ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Because the application knows the required extension, it should construct the full expected filename by adding .docx to the base name. Searching for just 'report' could return unrelated files, and appending .txt would look for the wrong format. By generating 'report.docx' and checking the directory, the program reliably finds the intended Word document, even when the user omitted the extension.

Q10. A directory contains 5 files with the .docx extension each sized at 120 KB, 3 files with the .zip extension each sized at 2 MB, and 2 files with the .mp3 extension each sized at 5 MB. What is the total storage size in megabytes?

A. 15.6 MB
B. 16.6 MB ✅
C. 17.6 MB
D. 18.6 MB

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

First convert the .docx sizes: 5 × 120 KB = 600 KB = 0.6 MB. The .zip files total 3 × 2 MB = 6 MB. The .mp3 files total 2 × 5 MB = 10 MB. Adding them together gives 0.6 + 6 + 10 = 16.6 MB. Therefore the directory occupies 16.6 MB of storage space, matching option B.

Q11. Both .com and .exe files are binary executables, yet they often appear distinct. What is the main technical difference between them?

A. .com files are text scripts
B. .exe files are always larger than .com files
C. .com files have a fixed size limit and lack a header ✅
D. .exe files cannot be run on Windows

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

A .com file is a simple binary format limited to 64 KB and does not contain a header describing sections or relocation information. In contrast, a .exe file includes a rich header that defines segments, entry points, and can be much larger. This structural difference explains why .com files are often smaller and why they were used in early DOS environments, while .exe files support more complex programs.

Q12. How do operating systems and applications differ in their reliance on file extensions versus MIME types for identifying file content?

A. Both use only extensions
B. OS uses extensions while applications may prefer MIME types ✅
C. Applications ignore extensions entirely
D. MIME types are stored inside the file name

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Operating systems typically use the filename extension as a quick lookup to decide which program to launch. Applications, especially web browsers and email clients, often examine the MIME type—a standardized label that describes the actual content of the file—because extensions can be misleading. By checking both the extension and the MIME type, software can more accurately handle files across diverse platforms and avoid errors caused by ambiguous naming.

Q13. If a user double‑clicks a file named 'install.sh' on a Windows desktop, which outcome is most likely?

A. The file opens in a web browser
B. The file is deleted
C. Windows prompts to choose a program to open it ✅
D. The script runs automatically

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Windows does not recognize the .sh extension as an executable type. When a user double‑clicks such a file, the OS presents the Open With dialog, asking the user to select an appropriate program—often a text editor or a third‑party shell interpreter. The script will not run automatically, nor will it be opened by a web browser or deleted without user action.

Q14. Which extension typically denotes a shared library on Linux systems?

A. .dll
B. .so ✅
C. .lib
D. .exe

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Linux uses the .so (shared object) extension for dynamically linked libraries that can be loaded by programs at runtime. The .dll extension is used on Windows for similar libraries, while .lib is a static library format on Windows, and .exe denotes executable binaries. Recognizing .so files allows developers to link against them or load them programmatically, facilitating modular software design on Unix‑like platforms.

Q15. What type of media is usually stored in a file with the .mp3 extension?

A. Audio ✅
B. Video
C. Document
D. Archive

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The .mp3 extension stands for MPEG‑1 Audio Layer III, a widely used compression format for digital audio. Files with this extension contain sound recordings such as music, podcasts, or voice notes. They do not hold video, document text, or archive data; those formats use extensions like .mp4, .pdf, and .zip respectively. Knowing the media type helps users and applications select appropriate playback or editing tools.

Q16. A user wants to rename 'report.docx' to 'report' to type faster, but still have the file open correctly in Word. Which approach guarantees the file remains recognized as a Word document?

A. Keep the name as 'report.docx' ✅
B. Change the name to 'report' and rely on file content
C. Change the extension to .txt
D. Store the file in a special Word folder

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The operating system and Word rely on the .docx extension to identify the file as a Word document. Removing the extension eliminates that cue, causing Word to treat the file as an unknown type. By keeping the filename unchanged—'report.docx'—the file retains its association with Word, ensuring it opens correctly without requiring additional configuration.

Q17. When sharing files across different operating systems, why can relying solely on extensions be problematic, and what practice mitigates this issue?

A. Extensions are encrypted on some systems; using passwords solves it
B. Extensions are ignored on mobile devices; using cloud storage solves it
C. Different systems may associate the same extension with different applications; including MIME type or file header information reduces ambiguity ✅
D. Extensions cause files to become larger; compressing them solves it

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

File extensions are not universally interpreted; for example, .txt may open in a simple editor on one system but be associated with a spreadsheet program on another. This can lead to confusion or data loss when files move between platforms. Adding explicit MIME type declarations or embedding format‑specific headers inside the file provides a more reliable way for applications to detect the true content type, reducing reliance on ambiguous extensions.
