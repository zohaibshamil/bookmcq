📝 All Thread cancellation in operating system MCQs

Q1. What is thread cancellation in operating systems?

🔹 A. Creating a new thread
🔹 B. Terminating a thread before completion
🔹 C. Suspending thread execution
🔹 D. Increasing thread priority

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Thread cancellation involves terminating a thread before it has completed its intended execution. This is a common operation in multithreaded programs where certain threads become unnecessary before their natural completion point.

Q2. What is a target thread in the context of thread cancellation?

🔹 A. The thread that initiates cancellation
🔹 B. The thread that is to be canceled
🔹 C. The main thread of the process
🔹 D. The highest priority thread

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A target thread is the thread that is to be canceled. When a cancellation request is made, the target thread is the one identified to be terminated either immediately or at a later safe point, depending on the cancellation mode used.

Q3. What is asynchronous cancellation?

🔹 A. A thread checks periodically if it should terminate
🔹 B. A thread immediately terminates the target thread
🔹 C. A thread waits for a cancellation point
🔹 D. A thread ignores cancellation requests

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Asynchronous cancellation occurs when one thread immediately terminates the target thread without waiting for the target thread to check for cancellation. This type of cancellation happens instantly upon request, regardless of the target thread's current state.

Q4. What is deferred cancellation?

🔹 A. Immediate termination of the target thread
🔹 B. The target thread periodically checks whether it should terminate
🔹 C. The target thread cannot be canceled
🔹 D. The cancellation request is ignored

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Deferred cancellation allows the target thread to periodically check whether it should terminate. This gives the thread an opportunity to terminate itself in an orderly fashion, releasing resources and ensuring consistency before exiting.

Q5. Which type of cancellation allows a thread to perform cleanup before termination?

🔹 A. Asynchronous cancellation
🔹 B. Immediate cancellation
🔹 C. Deferred cancellation
🔹 D. Forced cancellation

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Deferred cancellation allows a thread to perform cleanup before termination because the thread can check for cancellation at safe points. At these points, the thread can release resources, unlock mutexes, and perform other cleanup operations before terminating.

Q6. What is the primary difficulty with thread cancellation?

🔹 A. Creating new threads is difficult
🔹 B. Resources may not be properly reclaimed
🔹 C. Cancellation requires kernel intervention
🔹 D. Threads cannot be created fast enough

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The primary difficulty with cancellation occurs when resources have been allocated to a canceled thread or when a thread is canceled while updating shared data. These situations can lead to resource leaks and data inconsistencies if not handled properly.

Q7. Why is asynchronous cancellation particularly troublesome?

🔹 A. It is too slow
🔹 B. It may not free necessary system-wide resources
🔹 C. It requires too much code
🔹 D. It cannot be implemented in Pthreads

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Asynchronous cancellation is troublesome because the operating system may reclaim system resources from the canceled thread but may not reclaim all resources. This can leave system-wide resources in an inconsistent state, causing resource leaks and potential system problems.

Q8. In deferred cancellation, when does cancellation occur?

🔹 A. Immediately upon request
🔹 B. At the next thread creation
🔹 C. When the target thread checks a flag at a safe point
🔹 D. When the process terminates

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

In deferred cancellation, cancellation occurs after the target thread checks a flag to determine whether it should be canceled. The thread performs this check at a point where it can be safely terminated, ensuring that resources are properly released.

Q9. What is the purpose of the pthread_cancel() function?

🔹 A. To create a new thread
🔹 B. To initiate cancellation of a target thread
🔹 C. To suspend a thread
🔹 D. To terminate the entire process

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The pthread_cancel() function initiates cancellation of a target thread by passing the thread's identifier as a parameter. It indicates a request to cancel the target thread, but actual cancellation depends on the target thread's cancellation state and type settings.

Q10. What are the two components of Pthreads cancellation modes?

🔹 A. State and priority
🔹 B. State and type

🔹 D. Priority and signal

💡 Difficulty: medium | ✅ Correct: B

Pthreads supports cancellation modes defined by a state and a type. The state can be disabled or enabled, while the type can be deferred or asynchronous. These two components together determine how the thread responds to cancellation requests.

Q11. What is the default cancellation type in Pthreads?

🔹 D. Forced cancellation

The default cancellation type in Pthreads is deferred cancellation. This means cancellation occurs only when a thread reaches a cancellation point, allowing the thread to check for pending cancellation requests at safe locations in its execution.

Q12. What is a cancellation point in Pthreads?

📖 Explanation:

A cancellation point is a location in a thread's execution where it checks for pending cancellation requests. At these points, the thread can safely terminate if cancellation has been requested, allowing for orderly cleanup before termination.

Q13. What does the pthread_testcancel() function do?

Q18. How does asynchronous cancellation differ from deferred cancellation in terms of resource cleanup?

Q22. What is the effect of setting a thread's cancellation state to disabled?
