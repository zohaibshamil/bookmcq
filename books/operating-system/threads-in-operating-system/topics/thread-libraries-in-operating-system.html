Q1. What is a thread library?

🔹 B. An API for creating and managing threads
🔹 C. A kernel module for process scheduling
🔹 D. A compiler optimization tool

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A thread library provides programmers with an API for creating and managing threads. It offers functions for thread creation, synchronization, and management, abstracting the underlying implementation details and providing a consistent programming interface for multi-threaded applications.
