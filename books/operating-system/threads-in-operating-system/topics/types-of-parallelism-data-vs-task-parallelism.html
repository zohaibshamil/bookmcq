What is Types of parallelism data vs task parallelism?

Definition:
Data parallelism distributes subsets of the same data across cores performing identical operations, while task parallelism distributes different functions or tasks across cores, expressed as vs .

Example:
Data parallelism applies a filter to image pixels in chunks; task parallelism runs audio decoding and UI updates concurrently.

Reason:
Choosing the right model maximizes core utilization—data parallelism suits regular workloads, task parallelism suits heterogeneous or pipeline-based applications.
