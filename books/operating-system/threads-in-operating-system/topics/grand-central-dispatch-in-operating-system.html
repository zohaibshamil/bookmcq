Q56. What happens when a block submitted to a concurrent queue attempts to modify a variable used by blocks in another concurrent queue?

When blocks on different concurrent queues modify shared variables, race conditions can occur without proper synchronization. GCD does not automatically handle this, and developers must use synchronization mechanisms like dispatch barriers, locks, or atomic operations to ensure thread safety.

Q57. How does GCD ensure fair scheduling among different priority concurrent queues?

GCD uses a scheduling algorithm that balances priorities to ensure fair execution among different priority queues. While higher priority queues receive preference, lower priority queues still make progress, preventing starvation and ensuring all tasks eventually execute.
