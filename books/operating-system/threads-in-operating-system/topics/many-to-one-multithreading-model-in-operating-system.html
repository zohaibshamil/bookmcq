Q1. What is the fundamental characteristic of the many-to-one threading model?

🔹 A. Many kernel threads map to one user thread
🔹 B. Many user threads map to one kernel thread
🔹 C. One user thread maps to many kernel threads
🔹 D. One kernel thread maps to one user thread

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The many-to-one model maps many user-level threads to a single kernel thread. This means multiple threads created at the user level are all associated with one kernel thread, which is the only entity the operating system kernel recognizes and schedules.

Q2. Where does thread management occur in the many-to-one model?

🔹 B. In user space by the thread library
🔹 C. In the hardware processor
🔹 D. In the device drivers

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Thread management in the many-to-one model occurs in user space by the thread library. The thread library handles all thread creation, scheduling, and synchronization operations without involving the kernel, which contributes to the model's efficiency.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The primary advantage of the many-to-one model is efficient thread management in user space. Since thread operations are handled by the user-level thread library without kernel intervention, thread creation, scheduling, and context switching are performed quickly without system call overhead.

Q4. What happens when a thread in the many-to-one model makes a blocking system call?
