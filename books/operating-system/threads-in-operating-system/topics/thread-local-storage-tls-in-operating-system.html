Q1. What is Thread Local Storage (TLS)?

🔹 A. Data shared by all threads in a process
🔹 B. Data unique to each thread
🔹 C. Data visible only in a single function
🔹 D. Data stored in the kernel

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Thread Local Storage (TLS) refers to data that is unique to each thread. While threads typically share process data, TLS provides each thread with its own copy of certain data that remains private and isolated from other threads.
