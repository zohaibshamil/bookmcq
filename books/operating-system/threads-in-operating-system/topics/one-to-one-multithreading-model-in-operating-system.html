Q1. What is the fundamental characteristic of the one-to-one threading model?

🔹 A. Many user threads map to one kernel thread
🔹 B. Each user thread maps to a kernel thread
🔹 C. Many kernel threads map to one user thread
🔹 D. One user thread maps to many kernel threads

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The one-to-one model maps each user thread to a corresponding kernel thread. This means every user-level thread has a direct kernel-level counterpart, allowing the operating system kernel to recognize and manage each thread independently.

Q2. How does the one-to-one model handle blocking system calls?

🔹 A. The entire process blocks
🔹 B. Another thread can run when a thread blocks
🔹 C. All threads block simultaneously
🔹 D. The system call is ignored

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

In the one-to-one model, when a thread makes a blocking system call, another thread can run. Since each user thread has its own kernel thread, the kernel can schedule other threads while one thread is blocked, providing better concurrency than the many-to-one model.
