Q1. Which benefit allows an application to continue running even if a part is blocked?

🔹 A. Resource sharing
🔹 B. Responsiveness
🔹 C. Economy
🔹 D. Scalability

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Responsiveness allows applications to continue running even if a part is blocked. When one thread performs a lengthy operation or is waiting, other threads can continue executing, maintaining the application's responsiveness to users. This is particularly valuable in interactive applications.

Q2. What is a key benefit of multithreading in user interface design?

🔹 A. Increased memory usage
🔹 B. Improved responsiveness to user actions
🔹 C. Reduced processor utilization
🔹 D. Simpler programming model

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Responsiveness is a key benefit in user interface design. When a time-consuming operation runs in a separate thread, the application remains responsive to user actions. This prevents the interface from becoming unresponsive, significantly improving user experience.

Q3. How do threads compare to processes in terms of resource sharing?

🔹 A. Threads cannot share resources
🔹 B. Threads share resources by default
🔹 C. Processes share resources by default
🔹 D. Neither shares resources automatically

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Threads share resources by default. They share memory, code, data, and operating-system resources like open files. This is a major advantage over processes, which require explicit techniques like shared memory or message passing to share resources.

Q4. What is the primary economy benefit of using threads over processes?

📖 Explanation:

The primary economy benefit is that thread creation and context switching are less expensive than process creation and switching. Threads share resources, reducing the overhead of memory allocation and resource duplication. In Solaris, process creation is about thirty times slower than thread creation.
