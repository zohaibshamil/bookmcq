📝 Why threads are used in operating system

📖 From Operating System • 4. Threads in Operating System • 45 questions available

What is Why threads are used in operating system?

Definition:
Threads are used to allow a process to perform multiple tasks concurrently, leveraging parallelism on multicore systems and improving application responsiveness through lightweight context switching where overhead \( t_{switch} \ll t_{process\_switch} \).

Example:
A word processor uses one thread for typing and another for background spell checking so the UI remains responsive.

Reason:
Creating and switching threads is faster than processes because threads share memory space, reducing the cost of inter-task communication and synchronization.
