Q1. What characterizes a multicore system architecture?

🔹 A. Multiple CPU chips on a single motherboard
🔹 B. Multiple computing cores placed on a single chip
🔹 C. Multiple computers connected via network
🔹 D. Multiple operating systems running simultaneously

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A multicore system places multiple computing cores on a single chip. Each core appears as a separate processor to the operating system. This contrasts with earlier multi-CPU systems that used separate physical CPU chips on the motherboard.

Q2. How does the operating system perceive each core in a multicore processor?

🔹 A. As a single logical processor
🔹 B. As a separate processor
🔹 C. As a virtual machine
🔹 D. As a cache memory unit

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Each core in a multicore processor appears as a separate processor to the operating system. The OS can schedule threads to run on individual cores independently, enabling true parallel execution of multiple threads simultaneously.

Q3. What is the fundamental difference between concurrency and parallelism in computing?

🔹 A. Concurrency uses multiple CPUs; parallelism uses one CPU
🔹 B. Concurrency enables multiple tasks to make progress; parallelism performs multiple tasks simultaneously
🔹 C. Concurrency is faster than parallelism
🔹 D. Concurrency requires multicore systems; parallelism does not

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Concurrency supports multiple tasks by allowing them to make progress through interleaving, while parallelism performs multiple tasks simultaneously. A system can be concurrent without being parallel, as seen on single-core systems with time-slicing.

Q10. If an application has 75% parallel and 25% serial components, what is the maximum speedup on a system with two processing cores?

🔹 D. 2.5 times
