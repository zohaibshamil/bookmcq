Q1. What defines a user thread?

🔹 B. A thread supported above the kernel and managed without kernel support
🔹 C. A thread that executes only in kernel mode
🔹 D. A thread that requires hardware support for context switching

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

User threads are supported above the kernel and are managed without kernel involvement. This means the thread library handles all thread creation, scheduling, and management in user space without requiring operating system kernel support for these operations.

Q2. Which operating system component directly manages kernel threads?

🔹 C. The operating system kernel
🔹 D. The hardware processor

📖 Explanation:

Kernel threads are supported and managed directly by the operating system kernel. The kernel performs thread creation, scheduling, and management operations. This is in contrast to user threads which are managed by user-level libraries without kernel intervention.

Q111. Which of the following is a true statement about the relationship between user threads and kernel thread scheduling?
