What is Thread Pools in operating system?

Definition:
A thread pool maintains a set of pre-created worker threads that execute submitted tasks from a queue, avoiding repeated thread creation/destruction overhead where amortized cost \( C_{pool} \ll C_{create} \).

Example:
A web server uses a fixed-size pool to handle incoming HTTP requests without spawning a new thread per request.

Reason:
Limits resource exhaustion, improves response time by reusing threads, and provides backpressure control under high load, enhancing stability and performance.
