What is I/O hardware summary?

Definition:
This concept synthesizes the fundamental mechanisms of polling, interrupts, and DMA that govern how hardware communicates with the processor.

Example:
Modern systems combine these techniques, using for bulk storage and polling only for ultra-fast, low-latency registers.

Reason:
Summarizing hardware primitives clarifies the trade-offs between CPU utilization, latency, and complexity that drive OS design decisions.

📝 All I/O hardware summary MCQs

Q1. What term describes a set of wires together with a defined protocol that allows multiple devices to communicate?

A.bus ✅
B.port
C.driver
D.controller
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A bus is defined as a collection of wires together with a protocol that specifies how messages are formatted and transmitted. This definition matches the description of a set of wires and a rigidly defined protocol. Ports, drivers, and controllers serve different roles such as providing connection points or managing device operation, but they do not combine wires and protocol into a single communication medium. Therefore, option A is correct, while B, C, and D describe unrelated concepts.

Q2. Why does a daisy‑chain arrangement usually behave like a bus rather than a point‑to‑point link?

A.Because each device repeats the signal
B.Because all devices share the same physical wires ✅
C.Because the OS treats it as a bus
D.Because it uses wireless signals
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: In a daisy‑chain, each device plugs into the next, but the electrical conductors are common to all devices, so they all transmit on the same set of wires. This shared‑wire architecture is the defining characteristic of a bus. The other options describe behaviors that are not inherent to daisy‑chains: signal repetition is not required, the operating system does not change the physical layer, and wireless communication involves a different medium altogether. Thus, option B correctly explains the bus‑like behavior.

Q3. A technician needs to connect three external hard drives and a printer to a computer that has only one USB port. Which solution most effectively uses the I/O concepts described?

A.Use a USB hub ✅
B.Connect drives in series (daisy chain)
C.Replace USB with a serial port
D.Use Bluetooth for all devices
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A USB hub expands a single port into multiple downstream ports, allowing several devices to share the same bus while preserving the USB protocol and power distribution. Daisy‑chaining external drives is not supported by USB, and replacing USB with a serial port would drastically reduce bandwidth, making the drives unusable. Bluetooth could provide wireless connectivity but cannot supply the power and speed required for external hard drives. Therefore, option A is the optimal solution.

Q4. An embedded system for a factory robot requires fast data transfer for sensor arrays but slower communication for a status LED panel. Which bus configuration is most appropriate?

A.Connect sensors to PCI bus and LEDs to expansion bus ✅
B.Connect both to the same PCI bus
C.Use only an expansion bus
D.Use wireless for sensors
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Fast sensor data benefits from the high bandwidth and low latency of a system bus such as PCI, while the LED panel generates minimal traffic and can be placed on a slower expansion bus without affecting overall performance. Placing both on the PCI bus would waste bandwidth, using only the expansion bus would throttle sensor data, and wireless would add unnecessary complexity and potential latency. Hence, option A best matches the differing speed requirements.

Q5. When adding a new graphics card that requires high bandwidth, which existing bus should be used to avoid performance bottlenecks?

A.Expansion bus
B.PCI bus ✅
C.USB bus
D.Serial port
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Graphics cards generate large volumes of data that must be transferred quickly between the processor and memory. The PCI bus is designed for fast peripherals and provides the necessary throughput, whereas the expansion bus is intended for slower devices like keyboards. USB and serial ports have far lower data rates and would severely limit graphics performance. Consequently, the PCI bus is the correct choice, making option B the best answer.

Q6. Designing the control system for a jet’s flight surfaces, engineers need near‑instantaneous response from joystick inputs to motor commands. Which bus characteristic is most critical to meet this real‑time requirement?

A.High throughput
B.Low latency ✅
C.Large address space
D.Bidirectional signaling
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Real‑time flight control demands that input signals be processed and acted upon with minimal delay; thus, low latency— the time between sending a command and its receipt—is essential. High throughput matters for large data volumes but not for the small, time‑critical messages typical of joystick inputs. A large address space and bidirectional signaling are useful features but do not directly address the need for swift response. Therefore, option B correctly identifies the crucial bus attribute.

Q7. How do defined voltage patterns and timing specifications ensure reliable communication on a bus?

A.They encode data as analog signals
B.They synchronize sender and receiver to interpret bits correctly ✅
C.They increase power consumption
D.They allow devices to ignore errors
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A bus transmits binary information by applying specific voltage levels for defined time intervals. The timing rules tell each device when a bit starts and ends, allowing the receiver to align its sampling with the sender’s signal and decode the bits accurately. Encoding data as analog signals would be ambiguous, higher power consumption is a side effect not a reliability mechanism, and ignoring errors would lead to corrupted data. Hence, option B explains the essential role of timing and voltage patterns.

Q8. A computer’s expansion bus connects a keyboard and a serial port. If a user plugs a high‑speed network card into this bus, what is the most likely outcome?

A.The network card will operate at full speed
B.The network card will be limited by the slower bus speed ✅
C.The bus will automatically upgrade
D.The keyboard will stop working
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Expansion buses are engineered for low‑speed peripherals; they cannot provide the bandwidth needed by a high‑speed network interface. When such a card is attached, it inherits the bus’s limited data rate, causing reduced network performance. The bus does not dynamically increase its capabilities, and attaching the card does not affect the operation of existing devices like the keyboard. Therefore, option B accurately describes the expected limitation.

Q9. What is the primary advantage of separating fast devices onto a system bus from slower peripherals on an expansion bus?

A.Reduces overall cost
B.Improves overall system performance by preventing slow devices from throttling fast ones ✅
C.Simplifies software drivers
D.Eliminates need for ports
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Placing high‑performance components on a dedicated system bus ensures they can communicate at the speeds they require without being slowed down by low‑speed devices sharing the same pathway. This segregation prevents bandwidth contention and maintains optimal throughput for demanding peripherals. Cost reduction, driver simplification, and port elimination are secondary considerations and do not directly address the performance benefit. Consequently, option B captures the main reason for the two‑bus architecture.
