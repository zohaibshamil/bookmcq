Q1. Which vector numbers are non‑maskable in the Intel Pentium architecture?

🔹 A. 0‑15
🔹 B. 0‑31
🔹 C. 0‑63
🔹 D. 32‑255

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The non‑maskable range consists of vectors 0 through 31, which are reserved for critical error conditions that the CPU cannot ignore. Option A limits the range incorrectly, option C extends beyond the defined non‑maskable set, and option D describes the maskable range. Recognizing the correct range is essential when designing interrupt handling because non‑maskable events must be serviced immediately, ensuring system stability in real hardware.

Q2. Why does the CPU implement interrupt priority levels?

🔹 A. To allow low‑priority interrupts to be ignored entirely
🔹 B. To assign each device a unique vector number
🔹 C. To enable high‑priority interrupts to preempt low‑priority ones
🔹 D. To reduce the number of interrupt vectors needed

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Interrupt priority levels let the processor handle urgent requests without disabling all interrupts. When a high‑priority interrupt arrives, it can interrupt the current low‑priority routine, ensuring timely response to critical events. Option A suggests complete ignoring, which is not the purpose; option B confuses priority with vector assignment; option D misstates the effect on vector count. Understanding this mechanism helps developers design responsive systems.

Q3. What is the primary purpose of installing interrupt handlers during system boot?

🔹 A. To map device vectors to appropriate service routines
🔹 B. To allocate memory for user programs
🔹 C. To initialize the CPU’s cache hierarchy
🔹 D. To enable virtual memory paging

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

During boot, the operating system discovers hardware devices and registers their corresponding service routines in the interrupt vector table. This mapping ensures that when a device raises an interrupt, the CPU can jump directly to the correct handler. Options B and D relate to unrelated system tasks, while option C concerns cache, not interrupt handling. Proper handler installation is vital for reliable I/O operations in real machines.

Q4. How does a maskable interrupt differ from a non‑maskable interrupt?

🔹 A. Maskable interrupts can be disabled by software, non‑maskable cannot
🔹 B. Maskable interrupts have higher priority than non‑maskable
🔹 C. Maskable interrupts use vector numbers above 255
🔹 D. Non‑maskable interrupts are generated only by I/O devices

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Maskable interrupts are those the CPU can ignore temporarily using the interrupt‑flag, allowing critical sections to run without interruption. Non‑maskable interrupts bypass this flag and must be serviced immediately. Option B reverses the typical priority relationship, option C misstates the vector range, and option D limits the source incorrectly. Recognizing this distinction is crucial when protecting sensitive code from unexpected hardware events.

Q5. A device raises interrupt vector 45 while the CPU is executing a handler for vector 20. What is the most likely outcome?

🔹 A. The CPU finishes the vector 20 handler then services vector 45
🔹 B. The CPU ignores vector 45 until the vector 20 handler returns
🔹 C. The CPU immediately preempts the current handler and jumps to vector 45
🔹 D. The CPU initiates a system reset

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When a higher‑priority interrupt arrives, the CPU saves the state of the current low‑priority routine and jumps to the new handler, ensuring that critical events are addressed promptly. Option A would delay the urgent request, option B would discard it, and option D is an extreme reaction not typical of normal interrupt handling. This behavior illustrates how priority levels maintain system responsiveness.

Q6. Which interrupt vector should be assigned to handle a divide‑by‑zero exception?

🔹 A. 0
🔹 B. 6
🔹 C. 13
🔹 D. 19

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The divide‑by‑zero condition generates the divide error exception, which is defined at vector 0 in the Pentium architecture. Assigning the handler to this vector ensures the CPU jumps to the correct routine whenever the fault occurs. Options B, C, and D correspond to other exceptions such as overflow, invalid task state, and machine check, respectively, and would not catch a divide error. Properly mapping this exception is essential for maintaining correct arithmetic operations in applications.

Q7. If a system reports frequent machine check exceptions, which type of interrupt is being triggered?

🔹 A. Maskable interrupt
🔹 B. Non‑maskable interrupt
🔹 C. Software interrupt
🔹 D. Debug exception

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Machine check exceptions are classified as non‑maskable events, meaning they cannot be disabled by the interrupt‑flag and indicate serious hardware faults. Choosing maskable (option A) would imply the CPU could ignore them, which is incorrect. Software interrupts (option C) are generated by programs, not hardware faults, and debug exceptions (option D) relate to debugging conditions. Recognizing the non‑maskable nature of machine checks helps engineers diagnose critical hardware problems.

Q8. A programmer wants to temporarily ignore keyboard interrupts while updating a shared data structure. Which instruction should be used?

🔹 A. Set the interrupt‑flag (STI)
🔹 B. Clear the interrupt‑flag (CLI)
🔹 C. Enable maskable interrupts
🔹 D. Install a new keyboard handler

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Clearing the interrupt‑flag with the CLI instruction disables maskable interrupts, including keyboard signals, allowing the critical section to execute without interruption. Setting the flag (STI) would enable interrupts, option C repeats that effect, and installing a new handler does not prevent the interrupt from occurring. Using CLI ensures data integrity during the update, a common technique in low‑level programming.

Q9. Two devices generate interrupts at the same priority level. How does the CPU decide which one to service first?

🔹 A. It selects the interrupt with the lower vector number
🔹 B. It services the interrupt that arrived first
🔹 C. It randomly chooses one of the interrupts
🔹 D. It generates a priority‑violation exception

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When multiple interrupts share the same priority, the CPU typically services them in the order they are received, using the arrival time to break the tie. Option A would impose an artificial ordering unrelated to timing, option C would lead to nondeterministic behavior, and option D describes a condition that does not occur in standard interrupt handling. Understanding this ordering helps developers predict response times in concurrent I/O scenarios.

Q10. Why does the operating system probe hardware buses during boot rather than rely on a static configuration?

🔹 A. To reduce power consumption
🔹 B. To enable multi‑threading support
🔹 C. To initialize the graphics display mode
🔹 D. To dynamically detect which devices are present

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Probing the buses allows the OS to discover actual hardware components, assign appropriate interrupt vectors, and load necessary drivers, ensuring the system works with any configuration. Option A is unrelated to detection, option B concerns CPU scheduling, and option C deals with video initialization, not interrupt handling. Dynamic detection is essential for flexible and portable operating system deployment.

Q11. What interrupt vector number is assigned to a page‑fault exception?

🔹 A. 14
🔹 B. 12
🔹 C. 13
🔹 D. 15

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

In the Pentium interrupt vector table, the page‑fault exception occupies vector 14, following the general‑protection fault. Option B corresponds to a stack fault, option C to a segment‑not‑present fault, and option D to a floating‑point error. Knowing the exact vector for page faults is important for developers who need to implement custom page‑fault handlers or debug memory‑management issues.
