What is I/O Hardware in I/O Systems?

Definition:
I/O hardware encompasses the physical electronic components, including device controllers, buses, and ports, that facilitate communication between the computer and external peripherals.

Example:
A USB controller chip manages data packets traveling over the bus at a rate of \( v = 5 \, \text{Gbps} \) for USB 3.0 devices.

Reason:
Understanding the physical layer is essential because all software abstractions ultimately rely on the capabilities and limitations of this underlying circuitry.

📝 All I/O Hardware in I/O Systems MCQs

Q1. What is the term for a set of wires that multiple devices share for communication?

A. Port
B. Bus ✅
C. Hub
D. Switch

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A bus is a collection of conductors that allows several devices to transmit data over the same physical medium. Unlike a single port, which connects one device, a bus carries signals for many components using a defined protocol. Hubs and switches perform similar functions in networking, but they operate at higher layers and are not the basic wiring concept described here. Understanding a bus helps designers decide how to interconnect peripherals efficiently.

Q2. Which component typically connects the processor‑memory subsystem to fast peripherals such as graphics cards?

A. Expansion bus
B. PCI bus ✅
C. USB port
D. Serial port

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The PCI (Peripheral Component Interconnect) bus is designed for high‑speed communication between the CPU, memory, and fast devices like graphics adapters and network cards. Expansion buses handle slower peripherals, while USB ports serve external devices and serial ports are for legacy communication. Recognizing the role of PCI helps students identify why certain devices need dedicated high‑bandwidth pathways.

Q3. In a daisy‑chain configuration, which statement is true?

A. All devices share a single clock signal
B. Only the first device can initiate communication
C. Each device forwards data to the next device on the chain ✅
D. The chain must terminate with a resistor

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

A daisy chain links devices sequentially, where each unit receives data and passes it onward, forming a linear topology. The first device does not have exclusive control; any device can start a transmission, and timing is coordinated by the bus protocol, not by a single clock. Termination may be required for signal integrity, but the key characteristic is the forwarding behavior described in option C.

Q4. Why is a bus protocol said to be “rigidly defined”?

A. Because it uses fixed voltage levels only
B. Because it specifies exact message formats and timing rules ✅
C. Because it cannot be changed once hardware is built
D. Because it only works with one type of device

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A bus protocol defines the structure of each message, the sequence of bits, and the timing constraints for transmitting and receiving data. This rigidity ensures that all devices interpret signals consistently, preventing errors. Voltage levels may vary, and protocols can be updated in newer hardware revisions, but the core definition of message format and timing remains essential for reliable communication.

Q5. Which of the following best describes a serial port’s primary advantage over a parallel port?

A. Higher data rate
B. Simpler cabling and longer cable length ✅
C. Support for multiple devices simultaneously
D. Built‑in error correction

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Serial ports send bits one after another, allowing the use of fewer wires, which reduces cost and enables longer cables without significant signal degradation. Parallel ports transmit multiple bits simultaneously, requiring more conductors and limiting cable length. Although serial connections may achieve high speeds today, their main historical benefit was the simplicity and distance capability described in option B.

Q6. A computer needs to add a new high‑speed storage device. Which bus is most appropriate for this addition?

A. USB 2.0
B. PCI Express ✅
C. ISA bus
D. FireWire

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

PCI Express (PCIe) provides high bandwidth, low latency, and direct connection to the processor, making it ideal for fast storage such as SSDs. USB 2.0 and FireWire are external interfaces with lower throughput, while the ISA bus is an outdated, slow internal bus unsuitable for modern high‑speed devices. Selecting PCIe aligns with the need for rapid data transfer.

Q7. If a joystick sends a signal that is interpreted incorrectly by the flight computer, which layer of the I/O system is most likely at fault?

A. Physical connector
B. Device driver ✅
C. Operating system scheduler
D. Application software

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The device driver translates raw electrical signals from the joystick into a format the operating system can understand. An error in this translation often leads to misinterpretation of input. While a faulty connector could cause loss of signal, the driver is responsible for decoding the data. The scheduler and application layers operate above the driver and would not directly cause signal misreading.

Q8. A system designer wants to connect three temperature sensors to a microcontroller using the fewest pins possible. Which topology should they choose?

A. Star topology
B. Ring topology
C. Daisy‑chain bus ✅
D. Mesh topology

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

A daisy‑chain bus allows each sensor to attach to the same two wires, passing data along the chain, minimizing pin usage on the microcontroller. Star and mesh topologies require a separate line for each sensor, increasing pin count. Ring topology also needs dedicated connections and can be more complex to manage. Therefore, the daisy‑chain approach best meets the goal of using few pins.

Q9. During troubleshooting, a technician discovers that data on the expansion bus is corrupted only when a USB device is attached. Which cause is most plausible?

A. USB device is drawing too much power
B. USB shares the same bus lines causing electrical contention ✅
C. USB driver is outdated
D. USB device uses a different protocol

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

If the USB device shares physical lines with the expansion bus, simultaneous signaling can cause contention, leading to corrupted data. Power draw or driver issues would affect functionality but not directly corrupt bus data. Different protocols generally coexist via separate controllers, so contention on shared lines is the most likely explanation.

Q10. In an aircraft control system, why might designers prefer a dedicated motor‑control bus over using the general‑purpose PCI bus?

A. Because it is cheaper to implement
B. Because it provides deterministic timing and isolation ✅
C. Because it supports higher bandwidth
D. Because it is easier to program

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Dedicated motor‑control buses are engineered for predictable, low‑latency communication, ensuring that control commands reach actuators within strict time windows. General‑purpose buses like PCI can introduce variable delays due to arbitration and shared traffic, which is unsuitable for safety‑critical real‑time control. The deterministic nature of a specialized bus is essential for reliable aircraft operation.

Q11. A student is designing a simple computer that uses a parallel port for keyboard input. Which limitation must they consider?

A. Parallel ports cannot detect key presses
B. Parallel ports have limited bandwidth for high‑speed data
C. Parallel ports require more wires than serial ports ✅
D. Parallel ports cannot be daisy‑chained

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Parallel ports transmit multiple bits simultaneously, which means they need a larger number of conductors compared to serial interfaces. This increased wiring complexity can be a design constraint, especially in a simple system. Bandwidth is generally sufficient for keyboard data, and parallel ports can be daisy‑chained, so the primary issue is the wiring requirement.

Q12. What is the main reason that USB ports are classified as an expansion bus rather than a system bus?

A. They connect only external devices
B. They operate at lower voltage levels
C. They use a standardized protocol that supports hot‑plugging ✅
D. They cannot transfer data faster than 12 Mbps

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

USB (Universal Serial Bus) provides a standardized protocol that allows devices to be added or removed while the system is running (hot‑plugging). This flexibility distinguishes it from internal system buses, which are typically fixed and not intended for dynamic device changes. The classification as an expansion bus reflects its role in extending system capabilities without being part of the core processor‑memory pathway.

Q13. Which of the following best explains why a device driver is essential for a serial port?

A. It provides physical connectors for the device
B. It converts high‑level commands into electrical signals ✅
C. It manages power distribution to the port
D. It encrypts data transmitted over the port

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

A device driver interprets operating‑system requests and translates them into the appropriate voltage patterns and timing sequences required by the serial port hardware. Without this translation layer, the OS cannot communicate with the port. Physical connectors, power management, and encryption are handled elsewhere, making option B the correct explanation.

Q14. If an I/O device requires a clock signal that is not supplied by the bus, what must the system provide?

A. A voltage regulator
B. An external oscillator ✅
C. A DMA controller
D. A higher‑level API

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When a device needs a timing reference that the bus does not generate, an external oscillator must be added to supply the required clock. Voltage regulators manage power, DMA controllers handle direct memory transfers, and APIs operate at software level. Therefore, the correct solution is to include an oscillator that provides the needed clock signal.

Q15. A developer writes code that polls a keyboard every 10 ms. Which drawback is most likely?

A. The keyboard will miss key presses
B. The CPU will waste cycles on polling ✅
C. The operating system cannot schedule other tasks
D. The keyboard will generate interrupt storms

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Polling at a fixed interval forces the CPU to repeatedly check the device state, consuming processing time that could be used elsewhere. Interrupt‑driven designs allow the CPU to respond only when needed, improving efficiency. Missed key presses or interrupt storms are not typical results of regular polling, and the OS can still schedule tasks, albeit with reduced performance.

Q16. When connecting a high‑resolution camera to a computer, which bus is generally preferred for minimal latency?

A. PCI Express
B. USB 2.0
C. FireWire (IEEE 1394) ✅
D. Serial ATA

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

FireWire (IEEE 1394) was designed for real‑time data streams such as video, offering isochronous transfer modes that guarantee consistent timing and low latency. While PCI Express provides high bandwidth, it is more commonly used for internal devices. USB 2.0 and SATA are not optimized for continuous, time‑sensitive video streams. Therefore, FireWire is the typical choice for low‑latency camera connections.

Q17. A system uses a daisy‑chain of three LED controllers on a single bus. If the middle controller fails, what is the most likely outcome?

A. All LEDs will turn off
B. Only the middle LED will stop working
C. The LEDs after the failed controller will not receive data ✅
D. The system will reboot automatically

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

In a daisy‑chain, each device passes data to the next. If the middle controller fails, it cannot forward the signal, so downstream devices (the LEDs after it) will not receive commands, while upstream devices remain functional. The entire chain does not necessarily shut down, and automatic reboot is unrelated to bus failure.

Q18. Why might an engineer choose a parallel bus over a serial bus for a legacy memory module?

A. Parallel buses are cheaper to manufacture
B. Parallel buses provide higher data rates for short distances ✅
C. Parallel buses support longer cable lengths
D. Parallel buses are more energy efficient

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Parallel buses can transfer multiple bits simultaneously, yielding higher throughput over short distances, which is advantageous for memory modules that require rapid access. Although serial buses have become dominant due to lower pin counts and longer reach, the speed benefit of parallel communication makes it suitable for legacy memory designs where distance is limited.

Q19. Which scenario illustrates the need for a device’s interrupt line rather than polling?

A. A printer that prints a page every few seconds
B. A temperature sensor that updates every minute
C. A network card that receives packets at unpredictable intervals
D. A keyboard that sends a character after each key press ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Interrupts allow the CPU to be notified immediately when an event occurs, such as a key press, without constantly checking (polling). While printers and temperature sensors operate on predictable, slow intervals where polling may be acceptable, network traffic can be bursty, but keyboards benefit most from interrupt-driven input to ensure responsiveness. Hence, the keyboard scenario best demonstrates the advantage of interrupts.

Q20. In a system where multiple devices share a common bus, what mechanism prevents data collisions?

A. Error‑correcting codes
B. Bus arbitration ✅
C. Signal amplification
D. Clock synchronization

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Bus arbitration is the process by which devices negotiate access to the shared medium, ensuring that only one device transmits at a time and thereby preventing collisions. Error‑correcting codes detect and fix errors after they occur, while amplification and synchronization address signal quality and timing but do not resolve simultaneous transmission conflicts.

Q21. Which statement correctly describes the relationship between a port and a bus?

A. A port is a type of bus
B. A bus is a collection of ports
C. A port connects a single device to a bus ✅
D. A bus connects multiple ports to multiple devices

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

A port serves as the physical interface through which a single device attaches to a bus, allowing communication with the rest of the system. The bus itself is the shared set of wires that interconnects many ports and devices. Therefore, the correct description is that a port connects a single device to a bus.

Q22. A programmer needs to ensure that data from a high‑speed sensor is stored without loss. Which I/O technique is most suitable?

A. Polling at a fixed interval
B. Direct Memory Access (DMA) ✅
C. Interrupt‑driven I/O with a small buffer
D. Polling with busy‑wait loops

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

DMA allows the sensor to transfer data directly into memory without CPU intervention, minimizing the chance of data loss due to CPU latency. Interrupt‑driven I/O can also be effective but may still involve CPU handling that could miss bursts. Fixed‑interval polling and busy‑wait loops are less reliable for high‑speed streams.

Q23. If a new USB device is added and the system slows down, which underlying cause is most plausible?

A. The device draws too much power from the bus
B. The USB controller is sharing bandwidth with other devices ✅
C. The device uses an incompatible protocol
D. The device requires a different driver version

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

USB controllers allocate bandwidth among all connected devices. Adding a new device can reduce the available bandwidth for existing devices, leading to perceived system slowdown. Excessive power draw typically triggers protection mechanisms, while protocol incompatibility would prevent operation altogether, and driver issues affect functionality rather than overall system speed. Thus, bandwidth sharing is the most plausible explanation.

Q24. A student argues that because a bus carries electrical signals, its speed is limited only by the voltage level. Which flaw is in this reasoning?

A. Higher voltage always means higher speed
B. Signal integrity, rise time, and protocol overhead also affect speed ✅
C. Buses do not use voltage levels
D. Speed is determined solely by the CPU clock

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

While voltage level influences signal strength, the actual data rate is constrained by factors such as signal rise/fall times, noise immunity, encoding schemes, and protocol overhead. Simply increasing voltage does not guarantee higher speed, as timing, synchronization, and error handling also play critical roles. Therefore, the student's reasoning overlooks these essential considerations.
