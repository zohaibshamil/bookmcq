🔹 A. Replace the entire I/O subsystem with a new one

🔹 C. Encapsulate the robot’s specifics in a dedicated driver module
🔹 D. Standardize the robot’s commands to match existing drivers

💡 Difficulty: medium | ✅ Correct: C

🔹 C. Portability across different operating systems
🔹 D. Security considerations of user processes
