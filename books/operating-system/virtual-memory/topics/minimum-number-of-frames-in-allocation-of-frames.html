Q1. What is the term used for the count of physical frames a process must have to guarantee that it never experiences a page fault after its working set is loaded?

🔹 A. Minimum number of frames
🔹 B. Maximum number of frames
🔹 C. Working set size
🔹 D. Page fault rate

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The correct answer is “Minimum number of frames” because that phrase directly describes the smallest number of physical frames needed to hold all pages that will be referenced, eliminating further faults. Option B describes an upper bound, which is unrelated. Option C is the size of the working set itself, not the frame requirement. Option D is a performance metric, not a count. Understanding this term helps students see why allocating enough frames is crucial in real systems to keep programs running smoothly.

Q2. Why does marking a page invalid have no effect if the process never accesses that page?

🔹 A. The hardware still checks the bit on every instruction fetch
🔹 B. The operating system ignores the bit for that page
🔹 C. No memory reference triggers a check of the valid‑invalid bit
🔹 D. The page is automatically swapped in

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The correct answer is that no memory reference triggers a check of the valid‑invalid bit, because the CPU only examines the bit when a page is actually referenced. Option A is false because the hardware only checks on accesses, not arbitrarily. Option B is incorrect; the OS does not ignore the bit, it relies on it when needed. Option D is wrong because swapping occurs only after a fault, not pre‑emptively. This explains why an unused page can be left invalid without harming program execution.

Q3. A process needs to reference five distinct pages repeatedly. The system currently has three free frames. What is the minimum number of frames that must be allocated to this process to guarantee zero page faults after the working set is initially loaded?

🔹 A. 3
🔹 B. 4
🔹 C. 5
🔹 D. 6

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is 5 frames because the process’s working set contains five unique pages; allocating fewer frames forces at least one page to be evicted, causing a fault on the next reference. Option A (3) and B (4) are insufficient, leading to continual evictions. Option D (6) provides more frames than necessary, which is wasteful but still works. Knowing the minimum frames needed helps system designers allocate memory efficiently while avoiding unnecessary page faults in real workloads.

Q4. How does the concept of “minimum number of frames” relate to the working‑set model in demand paging?

🔹 A. It is the exact size of the working set at any instant
🔹 B. It is a lower bound on the working‑set size
🔹 C. It represents the smallest number of frames that can hold the working set without causing extra faults
🔹 D. It is unrelated to the working set and only depends on total program size

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is that the minimum number of frames represents the smallest number of frames that can hold the working set without causing extra faults. Option A is wrong because the working set can change over time. Option B misstates the relationship; the minimum frames is a bound on the working set, not the other way around. Option D disconnects the concepts, which are actually tightly linked. Relating these ideas lets students predict how many frames a process needs to run efficiently under demand paging.

Q5. Given the reference string 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5, what is the smallest number of frames that can be allocated so that, after the initial loading phase, the process incurs no more than two additional page faults?

🔹 A. 2
🔹 B. 3
🔹 C. 4
🔹 D. 5

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is 3 frames. With three frames, after the first four cold faults (pages 1‑4), the optimal replacement algorithm can keep pages 1, 2, 5 in memory; the remaining references cause only two more faults when page 3 and 4 are needed again. Option A (2) would generate many more faults, while Option C (4) exceeds the requirement, and Option D (5) is unnecessary. This scenario shows how calculating the minimum frames helps reduce fault overhead in realistic memory‑access patterns.

Q6. If a system correctly guesses every page a process will need and marks only those pages as valid, how does the process’s execution compare to a situation where all pages are pre‑loaded into memory?

🔹 A. It will run slower because of extra bookkeeping
🔹 B. It will run at the same speed as if all pages were loaded
🔹 C. It will experience more page faults than the pre‑loaded case
🔹 D. It will deadlock due to missing pages

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is that the process will run at the same speed as if all pages were loaded because the guessed pages are exactly those that will be referenced, eliminating any faults. Option A is false; there is no extra overhead once the pages are valid. Option C contradicts the premise that the guess is perfect, and Option D is unrelated because no missing pages exist. This illustrates why accurate working‑set prediction can make demand paging behave like pure paging without performance loss.

Q7. A system has 8 physical frames. A process owns 4 distinct pages. Using the optimal replacement policy, what is the minimum number of frames that must be assigned to this process so that after the first fault each subsequent reference hits a resident page?

🔹 A. 2
🔹 B. 3
🔹 C. 4
🔹 D. 5

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The correct answer is 4 frames because the process’s four distinct pages must all reside simultaneously to avoid any further faults after the initial loading; any fewer frames would force a replacement, causing a fault on the next reference. Option A (2) and B (3) are insufficient, leading to repeated evictions. Option D (5) provides an extra frame that is unnecessary. Recognizing this lower bound helps students allocate just enough memory to guarantee fault‑free execution after warm‑up.

Q8. Why can the minimum number of frames required for a process be less than the total number of pages the process may eventually need?

🔹 A. Because some pages are never referenced
🔹 B. Because pages can be shared with other processes
🔹 C. Because the operating system can compress pages in memory
🔹 D. Because the process’s working set may be smaller than its total size

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The correct answer is that the process’s working set may be smaller than its total size, so only the actively used pages need frames at any moment. Option A is partially true but does not capture the dynamic nature of the working set. Option B describes sharing, which is a different mechanism. Option C (compression) is not part of the basic demand‑paging model. Understanding this distinction explains why allocating frames based on working‑set size, not total pages, saves memory in real systems.

Q9. A process’s working set size fluctuates between 3 and 5 pages during execution. To avoid thrashing, what is the safest minimum number of frames to allocate to this process?

🔹 A. 3
🔹 B. 4
🔹 C. 5
🔹 D. 6

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The correct answer is 5 frames because allocating the maximum possible working‑set size ensures that even when the process temporarily needs five pages, all of them can reside in memory, preventing the rapid page replacement characteristic of thrashing. Option A (3) and B (4) would be insufficient during peaks, and Option D (6) adds unnecessary overhead. This decision‑making mirrors real‑world capacity planning where administrators provision enough frames to cover worst‑case working‑set demands.

The correct answer is the subset of pages a process is actively referencing during a recent time interval, because the working set captures the pages needed for near‑term execution. Option A describes program size, not usage. Option B is vague and does not consider activity. Option D is a performance metric, not a set of pages. Knowing this definition lets students relate working‑set concepts to frame allocation strategies.

Q11. When a page is marked invalid in the page table and the process later accesses that page, which sequence of events occurs?

🔹 A. The CPU raises a trap, the OS loads the page, updates the valid bit, and resumes the instruction
🔹 B. The OS immediately swaps out another page without a trap
🔹 C. The invalid bit is ignored and the instruction proceeds using stale data
🔹 D. The process is terminated due to an illegal memory access

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The correct answer is that the CPU raises a trap, the operating system loads the required page, updates the valid bit, and then resumes the interrupted instruction. Option B is incorrect because swapping occurs only after a fault is handled. Option C is false; the invalid bit prevents use of stale data. Option D is extreme; a page fault is recoverable, not a fatal error. This flow demonstrates how demand paging reacts to invalid pages, reinforcing why correct frame allocation avoids costly traps.
