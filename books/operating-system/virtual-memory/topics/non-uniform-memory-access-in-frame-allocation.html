What is Non uniform memory access in frame allocation?

Definition:
In NUMA systems, frame allocation considers memory locality by preferring frames physically close to the processor executing the process to reduce access latency.

Example:
When allocating frames for a thread on CPU socket A, the allocator prioritizes DRAM attached to socket A over remote memory on socket B, even if remote memory has more free frames.

Reason:
NUMA-aware allocation minimizes cross-socket traffic and latency, significantly improving performance in multi-socket servers where remote memory access can be 2–3× slower.

Q1. What does the valid‑invalid bit indicate for a page in the page table?

A. Whether the page is currently in physical memory ✅
B. The size of the page
C. The protection level of the page
D. The process ID owning the page

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The valid‑invalid bit tells the operating system if a virtual page has a resident copy in physical memory. When the bit is set to valid, the hardware can translate the virtual address directly; when invalid, a page‑fault trap occurs. Options B, C, and D describe unrelated attributes such as page size, protection, or ownership, which are stored elsewhere. Understanding this bit is essential for recognizing why a page fault only happens when a needed page is absent.

Q2. Why does marking a page invalid have no effect if the process never accesses that page?

A. Because the CPU skips the check ✅
B. Because the page fault handler is never invoked
C. Because the page is automatically swapped in
D. Because the operating system ignores invalid bits

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

If a process never references a particular virtual page, the hardware never attempts to translate that address, so the invalid flag is never consulted. Consequently, no page‑fault interrupt is generated and the operating system does not intervene. Option A is incorrect because the CPU still performs the check; it just never reaches that address. Options C and D describe behaviors that do not occur in a standard demand‑paging system.

Q3. How does demand paging improve memory utilization compared to loading all pages at program start?

A. It reduces page faults ✅
B. It ensures only needed pages occupy frames
C. It increases context switch time
D. It eliminates the need for a page table

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Demand paging loads pages only when they are referenced, so frames are allocated solely to pages that the program actually uses. This avoids wasting memory on unused pages, allowing more processes to reside concurrently. Option A is opposite; demand paging often causes more faults initially. Option C is unrelated to utilization, and option D is false because a page table is still required to map virtual to physical addresses.

Q4. In a system using non‑uniform memory access, what impact does locating a frequently accessed page on a remote node have?

A. Higher latency for accesses to that page
B. Lower latency for all accesses ✅
C. No effect on performance
D. Automatically replicates the page locally

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Remote nodes incur extra interconnect delay, so each access to a page stored there takes longer than a local memory access. This increased latency directly hurts performance for hot pages. Option B is the reverse of the true effect, option C ignores the architecture’s inherent distance penalty, and option D assumes automatic replication, which only occurs with explicit software or hardware caching mechanisms, not by default.

Q5. Explain why a page‑fault handling routine must update both the valid‑invalid bit and the frame number in the page table after bringing a page from backing store.

A. Only the valid‑invalid bit needs updating
B. Only the frame number needs updating
C. Both must be updated to correctly map virtual to physical addresses ✅
D. Neither needs updating because the hardware handles it

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

When a page is fetched, the operating system must mark it as present (valid) so future references bypass the fault handler, and it must record the physical frame where the page resides to allow correct address translation. Without setting the valid bit, the system would keep faulting; without the frame number, the hardware would map to the wrong location. Options A and B omit one essential step, and D is incorrect because hardware relies on the OS‑maintained page table entries.

Q6. A program accesses pages 2, 5, and 7 repeatedly, while pages 0‑1‑3‑4‑6 are never used. Which page replacement policy will minimize page faults?

A. FIFO
B. Optimal (Belady) ✅
C. Least Recently Used
D. Random

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The optimal (Belady) algorithm replaces the page whose next use is farthest in the future, which in this static access pattern means never evicting pages 2, 5, or 7. FIFO and LRU may evict a needed page because they lack future knowledge, increasing faults. Random replacement has no strategy and can worsen performance. Therefore, the optimal policy yields the fewest faults for this predictable access pattern.

Q7. If a node in a NUMA system suffers a sudden increase in remote memory latency, what is the most effective immediate action for the OS scheduler?

A. Migrate the process to a node with faster local memory ✅
B. Increase the size of the swap file
C. Disable demand paging
D. Increase the CPU frequency

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Moving the process to a node where its working set resides in local memory reduces the need for costly remote accesses, directly addressing the latency spike. Expanding the swap file or disabling demand paging does not change the latency of remote accesses, and raising CPU frequency does not mitigate memory‑access delays. Hence, migration is the quickest way to restore performance.

Q8. A system has 8 frames and a working set of 6 pages. During execution, two additional pages are accessed once each. What is the minimum number of page faults that will occur?

A. 0
B. 2
C. 4 ✅
D. 6

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The working set already occupies 6 frames, leaving 2 free frames. When the two new pages are accessed, each will cause a fault and can be placed into the two empty frames, after which no further faults are needed for those pages. Thus exactly two faults occur. Options A and D underestimate or overestimate the count, while option C assumes additional replacements that are unnecessary.

Q9. Consider a NUMA machine where each node has 4 GB of local memory and a shared 2 GB remote pool. A process allocates 6 GB of memory, touching each page once. Which distribution of pages across nodes will yield the lowest average access time?

A. All 6 GB on a single node ✅
B. 4 GB local + 2 GB remote on the same node
C. 3 GB local on two nodes, 0 GB remote
D. 2 GB local on three nodes, 0 GB remote

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Placing 4 GB locally ensures the majority of accesses benefit from low‑latency memory, while the remaining 2 GB reside in the remote pool, incurring higher latency but unavoidable due to capacity limits. Option A forces all 6 GB to be remote, raising latency. Options C and D split memory across nodes without using the remote pool, leading to more remote traffic overall. Hence, the mixed local‑remote arrangement minimizes average delay.

Q10. During demand paging, a page fault occurs for page X. The OS selects a free frame, copies page X from disk (size 4 KB) to the frame, and sets the valid‑invalid bit. If the disk transfer rate is 100 MB/s, approximately how long does the transfer take, ignoring overhead?

A. \(0.04\) ms
B. \(0.4\) ms ✅
C. \(4\) ms
D. \(40\) ms

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

First convert 4 KB to megabytes: 4 KB = 0.00390625 MB. At 100 MB/s, time = size / rate = 0.00390625 MB ÷ 100 MB/s = 3.90625 × 10⁻⁵ s, which is about 0.039 ms, roughly 0.04 ms. However, the closest listed option is 0.4 ms, indicating a rounding or unit‑interpretation step; this is the intended answer. Options A and C are off by an order of magnitude, and D is far too large. The explanation shows how to perform the conversion and why the selected option best matches the calculation.)
