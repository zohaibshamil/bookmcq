📝 All Optimal page replacement MCQs

Q1. A program accesses pages in the order 1,2,3,4,1,2,5,1,2,3,4,5 and the system has three page frames. Using the optimal page‑replacement algorithm, how many page faults occur?

🔹 A. 6
🔹 B. 7
🔹 C. 8
🔹 D. 9

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The optimal algorithm looks ahead to see when each resident page will be used next. Starting with three empty frames, faults happen on references 1,2,3,4,5,3,4, giving a total of seven. Option B matches this count. Options A, C, and D are incorrect because they underestimate or overestimate the required faults. This illustrates how optimal replacement minimizes faults by evicting the page whose next use is farthest in the future, which directly reduces unnecessary swaps.

Q2. Why is the optimal page‑replacement algorithm considered impractical for real operating systems?

🔹 A. It requires knowledge of future references.
🔹 B. It needs more than three frames.
🔹 C. It swaps whole processes.
🔹 D. It cannot handle invalid pages.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The optimal algorithm assumes the system knows every future page request, which is impossible in practice; therefore it cannot be implemented. Option A states this requirement. Options B, C, and D describe unrelated constraints: the algorithm works with any number of frames, deals with individual pages, and uses the same valid‑invalid bits as other policies. Understanding this limitation explains why heuristics like LRU are used instead of the theoretically perfect algorithm.

Q3. What is the definition of the optimal page‑replacement algorithm in demand‑paging systems?

🔹 A. Replace the page that has been in memory the longest.
🔹 B. Replace the page whose next reference occurs farthest in the future.
🔹 C. Replace a randomly chosen page.
🔹 D. Replace the page with the smallest page number.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The optimal algorithm selects the page that will not be needed for the longest period of time, i.e., whose next reference is farthest away, guaranteeing the fewest faults. Option B captures this definition. Options A and C describe FIFO and random policies, respectively, while D is arbitrary and unrelated. Recognizing the optimal criterion helps students compare it with practical approximations such as LRU or CLOCK.

Q4. A system has four page frames and accesses pages in the order 7,0,1,2,0,3,0,4,2,3,0,3,2. When the reference to page 4 occurs, which page will the optimal algorithm evict?

🔹 A. 0
🔹 B. 1
🔹 C. 2
🔹 D. 7

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

At the moment of the reference to 4, the frames contain {7,0,1,2}. Looking ahead, page 7 never appears again, while 0 appears soon, 1 never appears again, and 2 appears later. The optimal choice is to evict a page with the farthest future use; both 7 and 1 qualify, but the algorithm may evict 7. Option D reflects this decision. The other options incorrectly assume nearer‑future pages are removed.

Q5. How does the optimal page‑replacement algorithm relate to Belady’s anomaly, the phenomenon where increasing the number of frames can increase page faults?

🔹 A. Optimal algorithm exhibits Belady’s anomaly.
🔹 B. Optimal algorithm never exhibits Belady’s anomaly because it always yields the minimum possible faults for any frame count.
🔹 C. Optimal algorithm sometimes shows the anomaly depending on reference strings.
🔹 D. Optimal algorithm is unrelated to frame count.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Belady’s anomaly occurs with sub‑optimal policies like FIFO; the optimal algorithm, by definition, produces the smallest possible fault count for each frame configuration, so the anomaly cannot appear. Option B states this property. Options A and C incorrectly suggest the optimal algorithm can suffer the anomaly, and D mischaracterizes the relationship. Understanding this connection underscores why optimal replacement is a theoretical benchmark.

Q6. A workload causes 15 page faults under the optimal algorithm and 25 faults under FIFO. If each page‑in from disk takes 10 ms, what is the total reduction in swap‑in time (in milliseconds) when using the optimal algorithm?

🔹 A. 50
🔹 B. 75
🔹 C. 100
🔹 D. 125

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Each fault requires a 10 ms disk read. Optimal: 15 × 10 = 150 ms; FIFO: 25 × 10 = 250 ms. The difference is 250 − 150 = 100 ms, so option C is correct. Options A, B, and D give incorrect differences. This calculation shows how an algorithm that reduces faults directly cuts I/O latency, which is crucial for system performance when disk access dominates execution time.

Q7. Why does the optimal page‑replacement algorithm guarantee the smallest possible number of page faults among all deterministic algorithms?

🔹 A. Because it replaces the page with the smallest page number.
🔹 B. Because it always evicts the page that will be used farthest in the future, minimizing future misses.
🔹 C. Because it randomly chooses a page, which on average reduces faults.
🔹 D. Because it uses the valid‑invalid bit to track pages.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The optimal algorithm’s guarantee follows from its look‑ahead rule: by removing the page whose next use is farthest away, it ensures that no other deterministic choice could produce fewer future faults. Option B correctly describes this reasoning. Options A and C describe unrelated strategies, and D merely mentions a hardware mechanism that does not affect the replacement decision. This principle forms the basis for evaluating other policies.

Q8. For the reference string 1,2,3,4,1,2,5,1,2,3,4,5 with three page frames, what is the difference in the number of page faults between the optimal algorithm and LRU?

🔹 A. 2
🔹 B. 3
🔹 C. 4
🔹 D. 5

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Using optimal replacement yields 7 faults, while LRU produces 10 faults for the same string and frame count. The difference is therefore 10 − 7 = 3, matching option B. Options A, C, and D give incorrect differences. This comparison demonstrates how an optimal policy can substantially outperform a common heuristic, highlighting the impact of replacement choices on overall fault rates.

Q9. Using the optimal algorithm for a two‑level memory hierarchy where the cache holds 2 pages, how many cache misses occur for the reference string 1,2,3,4,1,2,5,1,2,3,4,5?

🔹 A. 6
🔹 B. 7
🔹 C. 8
🔹 D. 9

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Tracking the cache with optimal decisions gives misses at references 1,2,3,4,2,5,2,3,4, totaling nine misses. Option D reflects this count. Options A‑C underestimate the misses by ignoring optimal evictions in later steps. This scenario shows how even with optimal replacement, a small cache can still incur many misses, emphasizing the importance of cache size in performance.
