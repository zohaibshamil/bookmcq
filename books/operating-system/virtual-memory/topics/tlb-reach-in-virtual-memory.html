What is TLB reach in Virtual Memory?

TLB reach defines the total amount of virtual memory that can be mapped without TLB misses, calculated as \( \text{number of TLB entries} \times \text{page size} \), making it a critical performance metric because exceeding this range causes frequent translation lookups that stall the pipeline and degrade effective \( \text{memory bandwidth} \).
