Q1. In POSIX shared memory, the shared memory region is organized using:

🔹 A. Message queues
🔹 B. Memory-mapped files
🔹 C. Pipes
🔹 D. Sockets

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

POSIX shared memory uses memory-mapped files. This means the shared memory region is associated with a file, and processes map this file into their virtual address space to access the shared memory.

Q2. Which system call is used to create or open a POSIX shared-memory object?

🔹 A. mmap()
🔹 B. shm_open()
🔹 C. ftruncate()
🔹 D. open()

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The shm_open() system call is specifically designed to create and open a shared-memory object in POSIX systems. It returns a file descriptor that can be used for subsequent operations.

Q3. The first parameter of the shm_open() function specifies:

🔹 A. The size of the shared memory object
🔹 B. The file descriptor for the object
🔹 C. The name of the shared-memory object
🔹 D. The permissions of the object

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The first parameter to shm_open() is the name of the shared-memory object. Processes that want to access the same shared memory must refer to this name to identify the object.

Q4. The flag O_CREAT in the shm_open() call specifies that:

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The O_CREAT flag instructs the operating system to create the shared-memory object if it does not already exist. This is essential for the first process that sets up the shared memory.

Q5. The flag O_RDWR in the shm_open() call indicates that:

📖 Explanation:

O_RDWR stands for open for reading and writing." This flag allows the process to both read from and write to the shared-memory object, which is necessary for most IPC scenarios."

shm_open() returns an integer file descriptor upon success. This file descriptor is then used with other system calls like ftruncate() and mmap() to configure and map the shared memory.

The mmap() function establishes a memory-mapped file containing the shared-memory object. It returns a pointer to the mapped memory, which the process uses to access the shared memory.

MAP_SHARED allows all mapping processes to see changes. If both producer and consumer have write permissions and attempt to modify the same regions concurrently, data races can occur, leading to corrupted or inconsistent data. Proper synchronization mechanisms are required.

Q28. What would be the effect of calling ftruncate() on a shared memory object that is already mapped by another process?

If a shared memory object is resized with ftruncate() while other processes have it mapped, the behavior can be unpredictable. Proper coordination is required to resize shared memory safely.

Q46. What is the primary problem that the Mach message system attempts to solve with virtual-memory-management techniques?

🔹 B. Message ordering
🔹 C. Double copying of messages
🔹 D. Message queuing

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The major performance problem with message systems is double copying: copying from sender to mailbox and then from mailbox to receiver. Mach uses virtual-memory techniques to map the sender's address space into the receiver's address space, avoiding copying.

Q47. Which type of messages in Mach cannot benefit from the virtual-memory optimization that avoids double copying?

The virtual-memory optimization that maps the sender's address space into the receiver's address space works only for intrasystem messages. Messages sent between different systems (intersystem) cannot use this technique and must be copied.
