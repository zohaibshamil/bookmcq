Q155. What is the primary advantage of using message passing over shared memory for interprocess communication in a multi-core system?

🔹 C. It is less expensive to implement in hardware
🔹 D. It is more secure

📖 Explanation:

Q156. In a system with a bounded buffer, a producer sends messages faster than the consumer can consume them. What is a potential system-wide consequence if the producer does not handle 'queue full' errors properly?

🔹 A. The system will become faster
🔹 B. The producer will always be blocked
🔹 C. The producer might enter a busy-wait loop, consuming CPU cycles unnecessarily
🔹 D. The system's memory will be freed

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

If a producer uses a nonblocking send and does not handle the 'queue full' error gracefully, it might simply retry the send immediately in a loop. This constitutes a busy-wait, where the producer is constantly checking the queue status and consuming CPU cycles without making progress, leading to wasted CPU resources and potential system slowdown.
