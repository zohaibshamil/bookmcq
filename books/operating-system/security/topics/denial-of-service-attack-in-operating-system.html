What is Denial of service attack in Operating System?

Definition:
A denial of service (DoS) attack overwhelms system resources or network bandwidth to render services unavailable to legitimate users, either through volume-based flooding or protocol exploitation.

Example:
A SYN flood attack exhausting connection table entries where \( \text{half\_open\_connections} > \text{max\_backlog} \) prevents new legitimate TCP handshakes from completing.

Reason:
DoS attacks target availability rather than confidentiality or integrity, requiring resource reservation, traffic filtering, and redundant infrastructure since complete prevention is impossible against sufficiently large-scale distributed attacks.

Q1. What is masquerading in network security?

A.Pretending to be another host or user ✅
B.Intercepting traffic without alteration
C.Flooding a server with traffic
D.Encrypting data for confidentiality
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Masquerading means an attacker pretends to be a legitimate entity, such as a user or host, to bypass authentication. Option A describes this directly, while B describes passive eavesdropping, C describes a denial‑of‑service technique, and D describes encryption for confidentiality. By impersonating a trusted party, the attacker can gain unauthorized access, which aligns with the definition of masquerading in security contexts.

Q2. How does a man‑in‑the‑middle attack differ from simple eavesdropping?

A.It only records traffic without alteration
B.It modifies or injects messages between parties ✅
C.It blocks communication entirely
D.It occurs only after a successful login
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A man‑in‑the‑middle (MITM) attacker sits between two communicating parties and can alter or inject messages, unlike simple eavesdropping which merely records traffic. Option B captures this capability. Option A describes pure listening, C describes denial‑of‑service, and D is inaccurate because MITM can happen before authentication. The ability to change data is what distinguishes MITM attacks.

Q3. Why does replaying a previously captured authentication token allow an attacker to bypass security?

A.The token is time‑stamped and thus always valid
B.The token contains encrypted user credentials
C.The token is accepted as proof of a fresh login ✅
D.The token expires after one use
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: When an authentication token is replayed, the system treats it as a fresh credential because it cannot distinguish the original from the duplicate, granting access. Option C correctly states that the token is accepted as proof of a new login. Option A is false because timestamps can make tokens expire; B is irrelevant to replay; D contradicts the premise that the token is reused successfully.

Q4. A company notices a sudden surge of HTTP requests that saturate its web server, causing legitimate users to experience timeouts. Which immediate response is most effective for mitigating the denial‑of‑service impact while preserving service for real users?

A.Block all incoming traffic from the Internet
B.Implement rate‑limiting and traffic shaping on the server edge ✅
C.Shut down the web application temporarily
D.Increase server CPU frequency
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Rate‑limiting and traffic shaping allow the server to accept a controlled number of requests per client, filtering out excess traffic without completely cutting off legitimate users. Option B provides a balanced mitigation. Blocking all traffic (A) would deny service to everyone, shutting down (C) stops all activity, and increasing CPU (D) does not address the bandwidth overload, making those choices ineffective.

Q5. During an online banking session, an attacker hijacks the user’s session cookie and then initiates a fund transfer. Which security control would have prevented the attacker from succeeding?

A.Using static IP address filtering
B.Encrypting the entire session with TLS
C.Implementing short‑lived, one‑time transaction tokens ✅
D.Requiring a password change every 90 days
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Short‑lived, one‑time transaction tokens add an additional verification step for each transfer, rendering a hijacked session insufficient for completing the operation. Option C directly addresses the vulnerability. TLS encryption (B) protects data in transit but does not stop a stolen cookie from being used. IP filtering (A) is too coarse, and periodic password changes (D) do not affect an active session.

Q6. An attacker records a legitimate “transfer $500” message sent from a client to a server, then replays it three times to cause multiple unauthorized payments. Which additional technique would most likely enable the attacker to succeed without detection?

A.Appending a random nonce to each message ✅
B.Changing the destination account number each time
C.Encrypting the message with the server’s public key
D.Compressing the message before transmission
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Including a random nonce ensures each message is unique, preventing replay attacks. By omitting a nonce, the attacker can resend the identical message and have it accepted. Option A describes the missing safeguard. Changing the account (B) would alter the transaction, encryption (C) does not stop replay, and compression (D) is unrelated to replay detection.

Q7. A malicious insider creates a fake administrative account by masquerading as a senior manager in the company directory. Which principle of security is violated by this action?

A.Least privilege
B.Separation of duties
C.Authentication integrity ✅
D.Auditability
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Masquerading directly attacks authentication integrity, allowing the insider to appear as an authorized user. Option C captures this violation. Least privilege (A) concerns limiting rights, which is not the primary issue here. Separation of duties (B) deals with role distribution, and auditability (D) concerns logging, making those choices incorrect.

Q8. How does authentication differ from authorization in the context of network security?

A.Authentication verifies identity; authorization decides access rights ✅
B.Authentication decides access rights; authorization verifies identity
C.Both are identical processes performed simultaneously
D.Authorization encrypts data while authentication decrypts it
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Authentication is the process of confirming that a user is who they claim to be, whereas authorization determines what resources that verified user may access. Option A correctly separates the two concepts. Option B reverses the definitions, and the other options describe unrelated functions, making them inaccurate.

Q9. Why is it said that absolute protection against malicious abuse is unattainable in practice?

A.Attackers can always find a zero‑day vulnerability
B.Security budgets are unlimited
C.All software is inherently insecure ✅
D.Defenders have perfect knowledge of attacker motives
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: No software can be proven free of flaws; vulnerabilities may exist or be introduced over time, making perfect security impossible. Option C reflects this reality. While zero‑day exploits (A) are a factor, they are not the sole reason for unattainability. Unlimited budgets (B) are unrealistic, and defenders never possess perfect knowledge (D).

Q10. In a sophisticated attack, an adversary first performs a man‑in‑the‑middle interception, then modifies the authentication token before forwarding it to the server, gaining admin privileges. Which layered defense strategy would most effectively detect and block this attack?

A.Only use password‑based authentication
B.Deploy endpoint intrusion detection on client devices
C.Implement mutual TLS with token signing and verification ✅
D.Rely on network firewalls to filter traffic
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Mutual TLS ensures both parties present verified certificates, and token signing adds integrity checks that reveal any alteration. Option C combines cryptographic binding and verification, exposing the modified token. Simple password authentication (A) lacks integrity protection, endpoint IDS (B) may miss network‑level tampering, and firewalls (D) cannot inspect encrypted payloads, making them insufficient.

Q11. A security team designs a detection system for DoS attacks that triggers an alarm when incoming traffic exceeds the 95th percentile of normal bandwidth for five consecutive minutes. Which statistical flaw could cause this system to miss a slowly escalating attack?

A.Using the mean instead of median
B.Relying on a fixed percentile threshold
C.Not accounting for traffic variance over time ✅
D.Applying a too‑short observation window
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: If traffic naturally fluctuates, a slowly rising attack may stay below the 95th percentile while still being abnormal. Ignoring temporal variance (option C) means the system cannot distinguish gradual changes from normal patterns. Using mean versus median (A) is unrelated, a fixed percentile (B) is the intended design, and a short window (D) actually makes detection more sensitive, not less.

Q12. When evaluating the cost‑benefit of making denial‑of‑service attacks more expensive for attackers, which factor most directly influences the deterrence effect?

A.The monetary value of the target's data
B.The computational effort required to launch the attack ✅
C.The legal penalties for the attacker
D.The public awareness of the attack
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Increasing the computational effort raises the resources an attacker must commit, making the attack less attractive and thereby deterring attempts. Option B directly addresses the cost side of the equation. The value of data (A) affects impact, not deterrence; legal penalties (C) rely on enforcement, and public awareness (D) influences perception rather than actual cost.

Q13. Why might an organization choose to focus on detecting a denial‑of‑service attack rather than attempting to block it entirely?

A.Detection is cheaper than prevention
B.DoS attacks cannot be blocked by any technology
C.Blocking may disrupt legitimate traffic ✅
D.Detection eliminates the need for any response
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Blocking traffic often requires filtering that can inadvertently affect legitimate users, leading to service degradation. Option C captures this trade‑off. While detection can be less costly (A), the primary reason is to avoid collateral damage. Claiming that DoS attacks are unblockable (B) is false, and detection alone does not remove the need for response (D).

Q14. What distinguishes a session hijacking attack from a man‑in‑the‑middle attack?

A.Session hijacking reuses an existing session token; MITM inserts itself into the communication channel ✅
B.Session hijacking only occurs on wireless networks; MITM works on wired networks
C.Session hijacking modifies data; MITM only reads data
D.Session hijacking requires physical access; MITM is remote
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: In session hijacking, the attacker takes over a previously established session by stealing its token, whereas a MITM actively positions itself in the communication path to intercept and possibly alter messages. Option A correctly describes this distinction. The other options mischaracterize the attacks regarding network medium, data modification, or physical access, making them incorrect.
