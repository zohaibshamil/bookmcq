📖 From Operating System • 15. Security • 9 questions available

What is Trap door backdoor in operating system?

Definition:
A trap door or backdoor is a hidden mechanism intentionally or accidentally inserted into system code that bypasses normal authentication and security controls to provide unauthorized access.

Example:
A hardcoded password \( p_{admin} = \text{master123"} \) in a login module that grants administrative privileges regardless of user credentials illustrates a dangerous backdoor vulnerability.

Reason:
Backdoors undermine the entire security architecture because they create persistent, undetectable access paths that survive password changes and standard security audits, requiring thorough code review and formal verification to eliminate."

Q1. What is a trap door (also called a backdoor) in computer security?

A. A: A hidden method that allows unauthorized access bypassing normal authentication ✅
B. B: A type of firewall that blocks traffic
C. C: An encryption technique for data at rest
D. D: A network protocol for routing

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A trap door is a hidden method that lets an attacker bypass normal authentication and gain unauthorized access, often left in software deliberately or unintentionally. Option A correctly describes this. Option B describes a firewall, which blocks traffic rather than providing secret entry. Option C describes encryption, which protects data but does not grant access. Option D describes a routing protocol, unrelated to covert access. Understanding the definition helps recognize why trap doors are a serious security concern.

Q2. Why do attackers prefer to install a trap door rather than rely solely on exploiting a vulnerability each time?

A. A: Trap doors are easier to detect
B. B: They provide persistent access even if the original exploit is patched ✅
C. C: They require no privileges
D. D: They improve system performance

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Attackers favor installing a trap door because it gives them persistent access even after the original vulnerability is patched. Option B captures this advantage. Option A is incorrect because trap doors are designed to be stealthy, not easy to detect. Option C is wrong; trap doors usually require some level of privilege to be useful. Option D is irrelevant as trap doors do not improve performance. Recognizing the persistence benefit explains why defenders must look for hidden backdoors after a breach.

Q3. How does the principle of least privilege mitigate the risk posed by trap doors embedded in legitimate programs?

A. A: By allowing all programs full system access
B. B: By restricting program permissions so a compromised program cannot perform privileged actions ✅
C. C: By encrypting all program code
D. D: By disabling user accounts

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The principle of least privilege limits each program to only the rights it needs, so even if a program contains a trap door, its ability to cause damage is constrained. Option B correctly states that restricting permissions prevents a compromised program from performing privileged actions. Option A is opposite, granting full access, which would amplify risk. Option C describes encryption, unrelated to privilege. Option D suggests disabling accounts, which does not address program-level rights. Understanding least privilege shows how it reduces the impact of hidden malicious code.

Q4. A system administrator discovers that a text editor installed on workstations copies any edited file containing the keyword 'confidential' to a hidden directory. Which immediate action should the administrator take?

A. A: Update the editor’s license
B. B: Reboot the machines
C. C: Isolate the affected workstations and remove the editor ✅
D. D: Increase the password length

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Isolating the workstations and removing the compromised editor stops the trap door from copying files and prevents further data leakage. Option C is the correct immediate response. Option A (updating the license) does not address the malicious behavior. Option B (rebooting) may temporarily stop the process but the editor will run again. Option D (increasing password length) does not affect the editor’s ability to exfiltrate files. This action directly eliminates the vector, protecting confidential information.

B. B: Checking file permissions
C. C: Verifying user passwords
D. D: Scanning for malware signatures only

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Monitoring outbound network traffic can reveal unexpected connections to unknown servers, which is a common sign of a trap door uploading data. Option A correctly identifies the most effective detection method. Option B (checking file permissions) may not show the hidden network activity. Option C (verifying passwords) is unrelated to data exfiltration. Option D (scanning only for known malware signatures) could miss a custom backdoor. By focusing on anomalous traffic, analysts can spot covert channels introduced by modified scripts.

B. B: Using proprietary compilers

Implementing thorough review processes directly reduces the chance that a trap door is introduced into production software.

A. A: Deleting the daemon binary
B. B: Capturing a memory dump and analyzing open sockets ✅
C. C: Changing the server’s DNS records
D. D: Reinstalling the OS without backups

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Capturing a memory dump and analyzing open sockets allows the analyst to see the hidden privileged socket and trace its originating process, which is essential for isolating the malicious component. Option B is correct because it provides concrete evidence of the backdoor’s activity. Option A (deleting the binary) removes evidence and may not stop the already running service. Option C (changing DNS) does not affect the local socket. Option D (reinstalling the OS without backups) is extreme and unnecessary when targeted forensic analysis can pinpoint the issue. Memory analysis directly reveals the trap door’s operation.

Q8. During a penetration test, you gain user‑level access on a machine. You find a hidden scheduled task that runs a script with SYSTEM privileges every hour. What is the most effective way to exploit this trap door to achieve full control?

A. A: Modify the script to open a reverse shell ✅
B. B: Delete the task
C. C: Change your user password
D. D: Disable the firewall

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Modifying the privileged script to open a reverse shell gives the attacker a direct channel to the system, effectively exploiting the trap door for full control. Option A is correct because it leverages the existing elevated execution context. Option B (deleting the task) would remove the backdoor but also eliminate the foothold. Option C (changing the user password) does not affect the scheduled task’s privileges. Option D (disabling the firewall) may expose the system but does not provide the needed remote access. Using the script to spawn a reverse shell is the most direct exploitation method.

Q9. In the context of operating‑system security, how does a trap door differ from a traditional virus?

A. A: A trap door requires no execution
B. B: A trap door provides a hidden entry point while a virus replicates to spread ✅
C. C: A trap door encrypts data
D. D: A trap door is always hardware‑based

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A trap door provides a hidden entry point, while a traditional virus focuses on replicating itself to spread to other systems. Option B correctly captures this distinction. Option A (requires no execution) is false because a trap door still needs to be executed or triggered. Option C (encrypts data) describes a different security function. Option D (hardware‑based) is inaccurate; trap doors are usually software constructs. Understanding this difference helps security professionals prioritize detection strategies for covert access versus widespread infection.
