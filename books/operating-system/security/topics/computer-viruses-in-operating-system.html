What is Computer viruses in operating system?

Definition:
Computer viruses are self-replicating malicious programs that attach themselves to legitimate host files or boot sectors and spread when infected hosts are executed or transferred between systems.

Example:
A file infector virus that appends its code to executable files and activates when demonstrates parasitic replication behavior characteristic of traditional viruses.

Reason:
Viruses require human action to propagate unlike worms, making user awareness and email filtering important, but their ability to mutate and hide within legitimate files necessitates heuristic and signature-based antivirus solutions.

Q1. What defines a computer virus?

A.Self‑replicating code that attaches to legitimate programs and spreads to other systems
B.A program that modifies the BIOS to cause hardware failure ✅
C.A network scanner that discovers open ports
D.An encryption tool used for data‑at‑rest protection
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: A computer virus is characterized by its ability to replicate itself and embed within legitimate software, allowing it to propagate to other machines. Option B describes a firmware attack, not a virus. Option C is a scanning tool, while option D is encryption software—both unrelated to viral behavior. Recognizing this definition helps students differentiate viruses from other malicious utilities in practical security contexts.

Q2. Why do Trojan horse programs often evade detection by traditional antivirus software?

A.They masquerade as trusted applications, blending with legitimate processes
B.They encrypt their payload using strong cryptography ✅
C.They only activate during system boot
D.They delete system logs after execution
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Trojan horses hide by appearing as trusted or useful software, which lets them run without raising suspicion from signature‑based scanners that focus on known malicious code. Option B describes ransomware techniques, not evasion. Option C is about boot‑time malware, while option D suggests log manipulation, which is a separate stealth method. Understanding this evasion tactic explains why behavior‑based detection is needed in real‑world defenses.

Q3. A user downloads a free PDF editor that unexpectedly copies edited documents to an external server. Which type of threat does this behavior illustrate?

A.Trojan horse ✅
B.Worm
C.Rootkit
D.Logic bomb
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The described behavior matches a Trojan horse: a seemingly benign program that surreptitiously performs malicious actions, such as exfiltrating files. A worm spreads autonomously, a rootkit hides its presence at the kernel level, and a logic bomb triggers under specific conditions. Identifying the Trojan horse pattern helps administrators implement application whitelisting and monitor outbound traffic for data leakage.

Q4. If a virus modifies a system's registry to run at startup, which mitigation strategy is most effective?

A.Implementing startup‑program monitoring and restricting registry edits ✅
B.Installing a firewall to block outbound traffic
C.Using disk encryption to protect files
D.Disabling USB ports on all workstations
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Monitoring startup entries and limiting registry modifications directly address the virus’s persistence mechanism, preventing it from auto‑executing after reboot. A firewall controls network traffic but does not stop a locally stored virus from launching. Disk encryption protects data at rest, not execution pathways. Disabling USB ports reduces removable media threats but does not affect registry‑based persistence.

Q5. Which of the following best describes a polymorphic virus?

A.A virus that changes its code each infection to avoid signature detection
B.A virus that spreads only through email attachments ✅
C.A virus that targets only mobile operating systems
D.A virus that self‑destructs after a single execution
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Polymorphic viruses encrypt or rewrite their own code with each replication, making static signatures ineffective. Option B describes a delivery vector, not the polymorphic nature. Option C limits the platform, while option D describes a logic bomb. Recognizing polymorphism is crucial for deploying heuristic or behavior‑based detection in environments where signatures quickly become obsolete.

Q6. An organization notices a sudden increase in network traffic to an unfamiliar IP address after employees open a seemingly harmless document. Which virus behavior does this indicate?

A.Data exfiltration via a back‑door Trojan ✅
B.Rapid replication like a worm
C.System shutdown triggered by a logic bomb
D.Privilege escalation using a rootkit
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The spike in outbound traffic suggests a back‑door Trojan that silently sends data to a remote server, a classic exfiltration pattern. Worms cause rapid internal spread, not necessarily external traffic spikes. Logic bombs wait for a trigger, and rootkits hide malicious activity but do not inherently cause unusual outbound connections. Understanding this behavior guides incident responders to isolate the compromised host and block the malicious IP.

Q7. Why is it important for an operating system to enforce the principle of least privilege in the context of virus containment?

A.It limits the damage a virus can cause by restricting its access rights
B.It prevents viruses from being installed in the first place ✅
C.It ensures all processes run with administrator rights
D.It automatically updates antivirus definitions
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Least privilege ensures that even if a virus gains execution, it cannot modify critical system components or access sensitive data, thereby containing potential harm. Option B confuses prevention with containment; viruses can still be introduced despite safeguards. Option C would grant excessive rights, amplifying risk. Option D pertains to signature updates, not privilege management. This principle is foundational for reducing attack impact in real‑world deployments.

A Trojan horse disguises malicious intent as legitimate functionality, a worm spreads autonomously, and a back‑door provides persistent remote access. Recognizing the spyware nature helps security teams implement data‑loss‑prevention policies and monitor for unauthorized file‑access patterns.

Q10. Which of the following is a primary reason that viruses often target executable files rather than data files?

A.Executable files can run code, allowing the virus to propagate
B.Data files are always read‑only and cannot be altered
C.Executable files are larger and store more information ✅
D.Data files are automatically backed up by most systems
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Viruses need to execute code to replicate; targeting executables ensures their payload runs when the file is opened. Data files typically contain static information and do not trigger code execution, limiting viral spread. Option C is irrelevant to propagation, while option D assumes backup practices that do not affect the initial infection vector. Understanding this targeting helps in designing file‑type filtering rules.

Q11. A system administrator discovers that a recently installed driver is causing unexpected network scans. Which type of malicious code is most likely responsible?

A.Rootkit ✅
B.Worm
C.Trojan horse
D.Adware
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Rootkits embed themselves deep within the operating system, often modifying drivers to hide malicious activity such as covert network scanning. Worms spread independently, Trojan horses disguise malicious intent but usually rely on user interaction, and adware displays unwanted advertisements. Identifying a rootkit informs the admin that deeper system components must be examined and possibly reinstalled to eradicate hidden threats.

Q12. Why might a virus that encrypts files and demands payment be classified differently from a traditional virus?

A.It is a ransomware, a subtype that focuses on extortion rather than replication
B.It does not replicate at all, so it cannot be a virus ✅
C.It only targets mobile devices
D.It uses social engineering instead of code execution
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Ransomware encrypts data and extorts victims, distinguishing it from classic viruses whose primary goal is replication. While some ransomware can also replicate, its defining characteristic is the ransom demand, not spread. Option B misstates that replication is required for all viruses; many modern ransomware families incorporate spreading mechanisms. Options C and D describe platform or delivery aspects, not the core functional difference.

Q13. In a corporate network, a virus spreads via shared network drives without user interaction. Which propagation mechanism does this exemplify?

A.Worm ✅
B.Trojan horse
C.Logic bomb
D.Rootkit
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Worms autonomously propagate across network resources, such as shared drives, without needing user execution. Trojan horses require a user to run the malicious program, logic bombs await a trigger condition, and rootkits conceal their presence after installation. Recognizing worm behavior guides the implementation of network segmentation and access controls to limit automatic spread.

Q14. Which security control is most effective at preventing the execution of a virus that relies on macro scripts in office documents?

A.Disabling macros by default and allowing only signed macros ✅
B.Installing a hardware firewall at the network perimeter
C.Enabling full‑disk encryption on all workstations
D.Using a VPN for remote access
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: By disabling macros and permitting only digitally signed ones, organizations block the primary execution path used by macro‑based viruses, reducing the risk of infection. A hardware firewall filters network traffic but does not stop malicious macros from running locally. Full‑disk encryption protects data at rest, and VPNs secure remote connections; neither directly addresses macro execution.

Q15. A researcher observes that a virus modifies its code to appear different each time it infects a new host. Which detection technique is most likely to identify this virus?

A.Behavior‑based anomaly detection ✅
B.Signature‑based scanning
C.Static file hash comparison
D.Port scanning
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Behavior‑based anomaly detection monitors actions such as file writes, process creation, and network connections, allowing it to flag malicious activity even when the virus’s code changes. Signature‑based scanning fails because the code is constantly altered. Static hash comparison also relies on unchanged code, and port scanning assesses network services, not code behavior. Understanding detection methods helps in selecting appropriate security tools against polymorphic threats.

D.It forces the system to use a stronger encryption algorithm

📖 Explanation: Administrative rights allow a user to install or run any program, including malware downloaded from the internet, giving the virus unrestricted access to the system. Higher privileges do not affect browsing speed, nor do they block updates or enforce encryption. Recognizing this risk emphasizes the principle of least privilege as a key defensive measure in everyday computing environments.

Q20. A company implements a whitelist that only allows approved executables to run. Which type of virus is most likely to be blocked by this measure?

A.Trojan horse that masquerades as a legitimate program ✅
B.Polymorphic virus that changes its signature
C.Worm that spreads via email attachments
D.Rootkit that hides kernel modifications
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: A whitelist permits only known, trusted executables; a Trojan horse that pretends to be a legitimate application will be blocked because its binary is not on the approved list. Polymorphic viruses may still execute if their code matches an allowed file, and worms or rootkits can operate through legitimate system utilities, bypassing the whitelist. This illustrates the strength of application control in preventing masqueraded threats.

Understanding obfuscation informs the need for dynamic or heuristic detection methods.

Q23. Which of the following best characterizes a logic bomb?

A.A piece of code that triggers a malicious action when a specific condition is met ✅
B.A self‑replicating program that spreads across networks
C.A hidden program that provides remote access to an attacker
D.A virus that encrypts files for ransom
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A logic bomb lies dormant until a predefined condition—such as a date or specific user action—activates its payload. Worms replicate, back‑doors enable remote access, and ransomware encrypts data, none of which rely on a conditional trigger. Understanding the conditional nature of logic bombs aids in designing monitoring rules that detect unusual behavior when trigger conditions are approached.

Q25. A virus spreads by exploiting a vulnerability in a web server’s input validation routine. Which phase of the attack lifecycle does this represent?

A.Exploitation ✅
B.Delivery
C.Installation
D.Command and control
💡 Difficulty: hard | ✅ Correct: A

Understanding the exploitation phase helps prioritize patch management and input sanitization as critical defenses.
