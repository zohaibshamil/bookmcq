Q1. What is the definition of a polymorphic virus?

🔹 A. A virus that encrypts its code before execution
🔹 B. A virus that changes its signature each time it infects a system
🔹 C. A virus that only infects macro-enabled documents
🔹 D. A virus that replaces the boot sector with its own code

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A polymorphic virus alters its code appearance on each infection, creating a new signature while preserving its core functionality. This makes signature‑based antivirus tools ineffective. Option A describes an encrypted virus, not a polymorphic one. Option C refers to macro viruses, which target high‑level scripting environments. Option D describes a boot‑sector virus. In practice, attackers use polymorphic techniques to stay hidden across multiple attacks.

Q2. Why do encrypted viruses include decryption routines alongside encrypted payloads?

🔹 A. To hide the payload from static analysis tools
🔹 B. To increase the speed of infection
🔹 C. To allow the virus to modify user passwords
🔹 D. To bypass network firewalls

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Encrypted viruses embed decryption code so the malicious payload remains unreadable until runtime, preventing static scanners from matching known byte patterns. This does not affect infection speed (B) nor does it directly target passwords (C) or firewalls (D). By disguising their code, they evade detection, illustrating why organizations must employ behavior‑based defenses alongside signature checks.

Q3. How does a stealth virus avoid detection when a protected file is read?

🔹 A. It overwrites the file with random data
🔹 B. It returns the original uninfected version of the file on read system calls
🔹 C. It encrypts the file contents each time it is accessed
🔹 D. It deletes the file after reading

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Stealth viruses intercept the read system call and supply the original clean data, so any inspection sees an unaltered file while the infected version remains hidden on disk. Overwriting with random data (A) would be obvious, encryption on each access (C) would degrade performance, and deletion (D) would cause data loss. This technique shows how attackers can hide malicious modifications from routine checks.

Q4. What is the primary distinction between macro viruses and source‑code viruses?

🔹 A. Macro viruses target low‑level assembly code, while source‑code viruses target high‑level scripts
🔹 B. Macro viruses are written in high‑level languages and spread via document macros; source‑code viruses modify and embed themselves in program source files
🔹 C. Macro viruses only affect operating system kernels, whereas source‑code viruses affect user applications
🔹 D. Macro viruses require internet connectivity, source‑code viruses do not

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Macro viruses are created in languages like Visual Basic and propagate through macro‑enabled files such as spreadsheets. Source‑code viruses search for source files (e.g., .c, .java) and insert malicious code to spread when the program is compiled. Option A reverses the language levels, C mischaracterizes their targets, and D is unrelated to their propagation mechanism. Understanding these differences helps developers implement appropriate file‑type defenses.

Q5. Why does a boot‑sector virus replace the original boot block at system start‑up?

🔹 A. To increase the computer's processing speed
🔹 B. To ensure the virus loads before the operating system, gaining control early in the boot process
🔹 C. To delete all user files immediately
🔹 D. To encrypt network traffic

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A boot‑sector virus overwrites the boot block so that when the BIOS loads the first sector, the malicious code executes before any legitimate OS components, granting the virus full system control. Enhancing speed (A) is not a motive, nor is immediate file deletion (C) or traffic encryption (D) typical of boot‑sector attacks. This early execution explains why protecting the boot sector is critical for system integrity.

Q6. A technician inserts a new removable read/write USB drive into a workstation. Which virus behavior is most likely to cause the drive to become infected immediately?

🔹 A. The virus monitors disk read‑write interrupts and blocks other programs from writing the boot sector
🔹 B. The virus encrypts all files on the drive using a symmetric key
🔹 C. The virus copies its boot sector to an unused location on the drive
🔹 D. The virus changes its signature to match the drive's file system

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

When a virus attaches to disk read‑write interrupts, it can monitor every disk operation and infect new removable media as soon as it is accessed, often by altering the boot sector. Simply copying the boot sector (C) may not happen instantly without interrupt monitoring. Encryption (B) is a payload action, not an infection mechanism. Changing its signature (D) does not cause spread. This scenario illustrates how interrupt‑hooking viruses propagate via removable media.

Q7. An organization relies solely on signature‑based antivirus software. Which type of virus is most likely to evade detection?

🔹 A. Boot‑sector virus
🔹 B. Polymorphic virus
🔹 C. Macro virus
🔹 D. Source‑code virus

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Polymorphic viruses continuously modify their code, producing new signatures that signature‑based tools cannot match, allowing them to slip past detection. Boot‑sector viruses (A) can be identified by known signatures, as can macro (C) and source‑code viruses (D) when their patterns are known. This highlights the limitation of signature‑only defenses and the need for heuristic or behavior‑based analysis to catch evolving threats.

Q8. If a system’s interrupt‑handler chain is compromised, which virus technique is most probably responsible?

🔹 A. Stealth virus
🔹 B. Tunneling virus
🔹 C. Encrypted virus
🔹 D. Macro virus

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Tunneling viruses embed themselves within the interrupt‑handler chain, hijacking hardware or software interrupts to execute malicious code covertly. Stealth viruses modify system calls to hide their presence (A), while encrypted viruses focus on obscuring payloads (C). Macro viruses (D) operate at the application level. When interrupts are altered, the system’s core response mechanisms are affected, demonstrating why protecting the interrupt chain is vital for system security.

Q9. A company wants to protect its computers from boot‑sector viruses. Which preventive measure offers the greatest protection?

🔹 A. Disabling USB ports entirely
🔹 B. Installing a BIOS password and enabling Secure Boot
🔹 C. Regularly updating macro scripts
🔹 D. Using encrypted file systems for user data

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Secure Boot verifies the integrity of the boot loader and firmware using cryptographic signatures, preventing unauthorized boot‑sector code from executing. Disabling USB ports (A) limits removable media but does not stop boot‑sector infection from other vectors. Updating macros (C) and encrypting user data (D) address different threats. Secure Boot directly addresses the boot‑sector attack vector, making it the most effective defense.

Q10. During a system audit, an analyst notices a sudden drop in available physical memory after boot. Which virus behavior does this observation most likely indicate?

🔹 A. The virus encrypts user files causing memory fragmentation
🔹 B. The virus copies the boot sector to an unused location, consuming memory above the new limit
🔹 C. The virus attaches to disk read‑write interrupts, consuming memory resources
🔹 D. The virus decreases physical memory usage to hide its presence

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When a virus hooks into disk read‑write interrupts, it often allocates additional memory for monitoring and processing disk activity, leading to a noticeable reduction in available RAM. Encrypting files (A) affects storage, not RAM. Copying the boot sector (B) uses disk space, not memory. Decreasing memory usage (D) is contradictory; viruses typically increase memory consumption. This scenario underscores how resource monitoring can reveal hidden malicious activity.

Q11. Explain how a polymorphic virus can alter its signature without changing its core functionality, and why this hampers detection. (Select the best description)

🔹 A. It rewrites its entire code base each time, creating unrelated functionality
🔹 B. It swaps out non‑essential instruction sequences with equivalent ones, preserving behavior while changing byte patterns
🔹 C. It hides its code inside user passwords to avoid detection
🔹 D. It deletes its own code after execution to leave no trace

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A polymorphic virus replaces dispensable instruction sequences (e.g., using different registers or nop padding) with functionally equivalent alternatives, thereby producing a new byte pattern while maintaining the same operational logic. This obfuscation defeats signature‑based scanners that rely on fixed byte sequences. Rewriting the entire code (A) would break functionality, hiding inside passwords (C) is unrelated, and self‑deletion (D) does not address signature changes. Understanding this technique helps security teams develop behavior‑based detection.

Q12. A forensic analyst discovers that a boot‑sector virus encrypts its payload and decrypts it only at runtime. Which investigative method is most likely to reveal the hidden code?

🔹 A. Analyzing network traffic for encrypted payloads
🔹 B. Performing live memory forensics to capture the decrypted code in RAM
🔹 C. Scanning the hard drive for known virus signatures
🔹 D. Inspecting macro scripts in office documents

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Live memory forensics (B) can capture the decrypted payload while it resides in RAM, allowing analysts to examine the active code. However, scanning for known signatures (C) is less effective because the payload is encrypted on disk. Network traffic analysis (A) and macro inspection (D) are unrelated to boot‑sector behavior. This illustrates why dynamic analysis is essential for uncovering encrypted, runtime‑only malware.

Q13. Compare stealth and tunneling viruses regarding detection difficulty and system impact. Which statement is most accurate?

🔹 A. Stealth viruses are easier to detect because they modify system calls, while tunneling viruses never affect system performance
🔹 B. Both types are equally easy to detect using signature scanners, but stealth viruses cause more data loss
🔹 C. Stealth viruses hide their code by returning clean data on reads, making them hard to spot; tunneling viruses embed in interrupt chains, making them difficult to locate and capable of persistent control
🔹 D. Tunneling viruses only affect network traffic, whereas stealth viruses only affect file permissions

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Stealth viruses intercept read operations and serve uninfected data, concealing modifications and evading file‑based scanners. Tunneling viruses integrate into interrupt handlers, granting them deep, persistent control and making them hard to trace without low‑level analysis. Option A incorrectly claims stealth viruses are easier to detect. Option B misstates detection ease and impact. Option D confuses their targets. Recognizing these differences guides defenders in selecting appropriate detection tools and response strategies.
