Q1. What is the definition of a macro virus?

🔹 A. A macro virus is written in a low‑level language such as assembly.
🔹 B. A macro virus is written in a high‑level language such as Visual Basic.
🔹 C. A macro virus replaces the original boot block at system start.
🔹 D. A macro virus encrypts its code to avoid detection.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The correct answer is B because a macro virus is created using a high‑level scripting language like Visual Basic and spreads when the host application runs the macro. Option A is wrong; macro viruses are not typically written in assembly. Option C describes a boot‑sector virus, not a macro virus. Option D describes encryption, which is a technique used by encrypted viruses, not the definition of a macro virus. Understanding the language level helps identify how the virus is triggered in real environments.

Q2. Why do polymorphic viruses evade detection by antivirus software?

🔹 A. They change their signature each time they are installed.
🔹 B. They hide in memory above the new limit.
🔹 C. They modify the read system call to return original code.
🔹 D. They install themselves in the interrupt‑handler chain.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is A because polymorphic viruses rewrite their code on each infection, altering the byte pattern that signature‑based scanners look for, while keeping functionality unchanged. Option B describes a stealth technique that masks memory usage, not the primary evasion method of polymorphism. Option C refers to stealth viruses that alter read operations, which is a different strategy. Option D describes tunneling, another evasion approach. Recognizing polymorphism is crucial for designing behavior‑based detection in real‑world security tools.

Q3. In a stealth virus that modifies the read system call, what is the typical result when an infected file is read?

🔹 A. The infected code is returned to the application.
🔹 B. The original, uninfected code is returned to the application.
🔹 C. The operating system crashes immediately.
🔹 D. The virus logs the read operation for later analysis.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The correct answer is B because a stealth virus intercepts the read call and substitutes the original clean code, hiding its presence from the user and detection tools. Option A would expose the infection, defeating the stealth purpose. Option C describes a crash scenario not typical of stealth behavior. Option D suggests logging, which is unrelated to the concealment mechanism. This concept illustrates how stealth techniques manipulate system calls to remain undetected in practical attacks.

Q4. A boot‑sector virus copies the original boot sector to an unused location X before infecting a new removable R/W disk. Which action best describes this behavior?

🔹 A. It copies the boot sector to an unused location.
🔹 B. It overwrites the master boot record directly.
🔹 C. It installs itself in the interrupt‑handler chain.
🔹 D. It modifies the file‑system allocation table.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The correct answer is A because the virus preserves the original boot sector by copying it to an unused area, allowing later restoration or concealment of the infection. Option B describes a direct MBR overwrite, which is a different infection method. Option C refers to tunneling, unrelated to boot‑sector copying. Option D involves file‑system structures, not boot‑sector manipulation. Knowing this behavior helps analysts detect hidden boot‑sector viruses by checking for unexpected copies in unused disk regions.

Q5. How do encrypted viruses differ from polymorphic viruses?

🔹 A. Encrypted viruses change their signature, while polymorphic viruses encrypt their payload.
🔹 B. Encrypted viruses include decryption code, while polymorphic viruses change their code without encryption.
🔹 C. Both use the same technique of code obfuscation.
🔹 D. Encrypted viruses only affect macro files.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The correct answer is B because encrypted viruses embed decryption routines and store the payload in an encrypted form, whereas polymorphic viruses rewrite their code to produce a new signature without necessarily encrypting the payload. Option A swaps the characteristics of the two types. Option C incorrectly claims they are identical. Option D limits encrypted viruses to macro files, which is inaccurate. Distinguishing these techniques is essential for selecting appropriate detection methods in real security deployments.

Q6. Which detection method is most effective for identifying a tunneling virus that resides in the interrupt‑handler chain?

🔹 A. Monitoring changes to the interrupt vector table.
🔹 B. Scanning files for known virus signatures.
🔹 C. Analyzing network traffic for anomalies.
🔹 D. Verifying the BIOS checksum at boot.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is A because a tunneling virus modifies the interrupt vector table to insert its code, so monitoring those tables for unexpected changes reveals the infection. Option B focuses on file signatures, which a tunneling virus may avoid. Option C looks at network behavior, unrelated to interrupt handling. Option D checks BIOS integrity, which does not directly expose changes in the operating system’s interrupt chain. This knowledge guides defenders to implement integrity checks on critical system tables.

Q7. An organization wants to detect an encrypted virus that decrypts itself before execution. Which approach offers the highest likelihood of discovery?

🔹 A. Static signature scanning of files.
🔹 B. Heuristic analysis of program behavior.
🔹 C. Checksum comparison of executable files.
🔹 D. Requiring users to enter complex passwords.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The correct answer is B because heuristic or behavior‑based analysis can observe the decryption routine and the subsequent actions, catching the virus even when its static signature is hidden. Option A relies on known byte patterns, which are concealed by encryption. Option C compares checksums, but the file changes after decryption, making this ineffective. Option D addresses user authentication, not virus detection. Applying heuristic monitoring aligns with real‑world practices for uncovering encrypted malware.

Q8. Why are logic bombs that trigger on a specific date particularly dangerous?

🔹 A. They spread rapidly across networks.
🔹 B. They remain dormant until the date, evading detection.
🔹 C. They encrypt all user data immediately.
🔹 D. They replace the boot sector with malicious code.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The correct answer is B because a logic bomb can lie inactive for months or years, avoiding typical scans, and then activate at the predetermined time, causing damage when defenses are least prepared. Option A describes worm‑like propagation, not a timed trigger. Option C refers to ransomware behavior, unrelated to date‑based activation. Option D describes boot‑sector infection, a different technique. Understanding this timing threat helps security teams implement time‑based monitoring and integrity checks.

Q9. How does a source‑code virus affect the software supply chain?

🔹 A. It introduces a backdoor early in development.
🔹 B. It increases the compile time of programs.
🔹 C. It reduces the memory footprint of applications.
🔹 D. It improves overall software performance.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is A because a source‑code virus injects malicious code into the original source files, allowing the attacker to embed backdoors or vulnerabilities that persist through compilation and distribution, compromising the supply chain. Option B incorrectly suggests performance impact. Option C claims memory reduction, which is not typical. Option D mistakenly states an improvement, which is contrary to the malicious intent. Recognizing this risk is vital for secure code review and repository monitoring.

Q10. What is the most robust defense against a boot‑sector virus that copies the boot sector to an unused location?

🔹 A. Enable secure boot that verifies boot‑sector integrity at startup.
🔹 B. Install user‑level antivirus software only.
🔹 C. Disable all USB ports on the system.
🔹 D. Increase system RAM to exceed the virus memory limit.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The correct answer is A because secure boot checks the integrity of the boot sector before handing control to the operating system, preventing malicious code that resides in hidden copies from executing. Option B provides only endpoint scanning, which may miss low‑level boot modifications. Option C eliminates removable media but does not verify existing boot sectors. Option D addresses memory limits, unrelated to boot‑sector integrity. Implementing secure boot aligns with industry best practices for protecting against sophisticated boot‑sector infections.
