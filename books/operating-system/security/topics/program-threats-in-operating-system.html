📝 All Program Threats in Operating System MCQs

Q1. What is a Trojan horse in the context of program threats?

🔹 A. A type of malware that encrypts files
🔹 B. A program that appears legitimate but contains hidden malicious code
🔹 C. A firewall configuration
🔹 D. An authentication protocol

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The correct answer is B because a Trojan horse is a program that looks benign while secretly performing malicious actions. Option A describes ransomware, which encrypts files rather than disguising itself. Option C refers to a firewall, a network device, not a malicious program. Option D describes an authentication protocol, unrelated to deceptive software. Recognizing the definition helps users spot deceptive applications in real environments.

Q2. Why are Trojan horses particularly effective at bypassing user‑based security controls?

🔹 A. They exploit zero‑day vulnerabilities in the operating system
🔹 B. They masquerade as trusted software, convincing users to grant permissions
🔹 C. They use advanced encryption to hide their code
🔹 D. They require physical access to the machine

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The correct answer is A because Trojan horses rely on users trusting the appearance of the software, leading them to grant elevated permissions. Option B describes a generic malicious program but does not explain the trust factor. Option C mentions encryption, which is more characteristic of ransomware. Option D requires physical access, which is not typical for Trojan horse attacks. Understanding this trust exploitation explains why user education is crucial.

Q3. How does a back‑door daemon left by an attacker differ from a typical Trojan horse?

🔹 A. A back‑door provides persistent remote access, while a Trojan horse only executes once
🔹 B. A back‑door runs invisibly after installation, whereas a Trojan horse may be noticed by users
🔹 C. A back‑door is a hardware component, while a Trojan horse is software
🔹 D. A back‑door encrypts data, whereas a Trojan horse steals it

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The correct answer is C because a back‑door daemon is a software process that runs silently to maintain access, whereas a Trojan horse is a deceptive program that may be detected during execution. Option A incorrectly claims a Trojan horse executes only once; many Trojans persist. Option B reverses the visibility distinction. Option D confuses hardware with software. Knowing this distinction helps defenders focus on detecting hidden services rather than only obvious malicious executables.

Q4. An administrator discovers a custom text‑editor that copies any edited file containing a keyword to a secret directory accessible to the editor’s creator. Which mitigation is most effective?

🔹 A. Disable all user‑installed software on the system
🔹 B. Deploy file‑integrity monitoring to alert on unexpected copies
🔹 C. Apply strict network segmentation separating user workstations
🔹 D. Implement least‑privilege controls so the editor cannot write to the secret directory

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The correct answer is D because enforcing least‑privilege ensures the editor lacks permission to write to unauthorized locations, directly stopping the exfiltration behavior. Option A is overly restrictive and impractical. Option B detects the activity after it occurs but does not prevent it. Option C isolates network traffic but does not stop local file copying. Applying least‑privilege aligns with the principle of minimizing access, reducing the risk of malicious code abusing legitimate applications.

Q5. An intrusion detection system relies on signatures, but an attacker uses polymorphic code to evade detection. Which type of IDS is most likely to identify this threat?

🔹 A. Signature‑based IDS
🔹 B. Anomaly‑based IDS
🔹 C. Network firewall
🔹 D. Standard antivirus software

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The correct answer is B because anomaly‑based IDS monitors deviations from normal behavior, allowing it to detect unknown or mutated code that signature systems miss. Option A depends on known patterns, which polymorphic code changes to avoid. Option C filters traffic but does not analyze payload behavior. Option D typically uses signatures similar to option A and struggles with rapidly changing code. Understanding detection methods shows why behavioral analysis is essential for emerging threats.

Q6. A system uses password authentication, but a Trojan horse logs keystrokes to capture passwords. Which layered defense most effectively reduces this risk?

🔹 A. Multi‑factor authentication requiring a second token
🔹 B. Enforcing complex password policies
🔹 C. Regularly applying software patches
🔹 D. Isolating the system on a separate VLAN

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The correct answer is A because multi‑factor authentication adds a second verification step that a keystroke logger cannot provide, mitigating credential theft. Option B improves password strength but does not stop capture. Option C addresses software vulnerabilities, not credential interception. Option D limits network exposure but does not protect local input. Implementing multiple authentication factors directly counters the Trojan’s ability to reuse captured passwords, illustrating the value of defense‑in‑depth.

Q7. What is the primary reason that program threats can persist even after the initial vulnerability is patched?

🔹 A. Attackers may have installed back‑doors providing ongoing access
🔹 B. System administrators often ignore patch notifications
🔹 C. Users frequently reuse weak passwords
🔹 D. Hardware components tend to fail unexpectedly

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The correct answer is A because once an attacker gains a foothold, they often leave back‑doors that remain functional after the original flaw is fixed, allowing continued exploitation. Option B describes a common issue but is not the main persistence mechanism. Option C relates to authentication, not program threats. Option D concerns hardware reliability, unrelated to software persistence. Recognizing the role of hidden back‑doors explains why organizations must search for and remove malicious artifacts after patching.

Q8. A breach is caused by a Trojan horse exploiting an OS kernel vulnerability. Which response step should be taken first to contain the incident?

🔹 A. Reboot the affected machines immediately
🔹 B. Isolate the compromised systems from the network
🔹 C. Update antivirus signatures on all endpoints
🔹 D. Notify customers about the breach

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The correct answer is B because isolating compromised systems prevents the Trojan from communicating with external command‑and‑control servers and stops further spread. Option A may erase volatile evidence and does not stop network activity. Option C updates detection but does not contain the active threat. Option D is a later communication step after containment. Immediate network isolation aligns with incident‑response best practices, limiting damage while investigators analyze the Trojan.
