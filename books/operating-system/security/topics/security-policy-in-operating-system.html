What is Security policy in operating system?

Definition:
Security policy defines organizational rules, standards, and procedures governing acceptable use, access controls, incident response, and compliance requirements that guide technical security implementation and enforcement.

Example:
Mandatory access control policy specifying enforces Bell-LaPadula model for classified information handling.

Reason:
Technical controls without clear policy lack direction and accountability, while policy without enforcement is ineffective; alignment ensures security measures support business objectives and regulatory compliance rather than impeding operations arbitrarily.

Q1. Which UNIX utility did the Morris worm exploit to execute remote commands without requiring a password?

A.ssh
B.rsh ✅
C.telnet
D.ftp
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The worm leveraged the rsh utility because it reads .rhosts files that list trusted host‑login pairs, allowing password‑less logins. SSH requires authentication, telnet also prompts for credentials, and FTP is used for file transfer rather than command execution. Consequently, rsh was the only tool matching the worm’s need for unattended remote command execution, demonstrating how insecure defaults can be abused in real attacks.

Q2. Why was the finger service an attractive target for the Morris worm’s buffer‑overflow attack?

A.It stored user passwords in plain text
B.The service accepted unchecked input that could overflow its buffer ✅
C.It was rarely used so detection was unlikely
D.It logged all network traffic for analysis
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Finger accepted a long string without proper bounds checking, enabling a buffer‑overflow that let the worm overwrite the stack and inject code. This vulnerability allowed the worm to spawn a remote shell on the target machine. The other options are incorrect: finger does not store passwords, its rarity does not guarantee stealth, and it does not log traffic, so only the unchecked input explanation fits.

Q3. A system administrator discovers several .rhosts files contain entries for unknown hosts. Which immediate action should the admin take to reduce the risk of worm propagation?

A.Delete all .rhosts files
B.Replace rsh with ssh
C.Remove unknown host entries from .rhosts ✅
D.Disable network interfaces
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Removing unknown host entries directly eliminates the trust relationship that lets rsh connect without passwords, cutting the worm’s easiest path for remote execution. Deleting all .rhosts would break legitimate trusted connections, while replacing rsh with ssh does not address existing .rhosts entries. Disabling interfaces is overly disruptive and does not specifically target the vulnerability.

Q4. How does allowing password‑less logins via .rhosts files conflict with a strong security policy?

A.It bypasses authentication, making unauthorized access easier ✅
B.It encrypts traffic, preventing eavesdropping
C.It requires multi‑factor authentication
D.It logs all commands
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Password‑less logins skip the fundamental step of verifying a user’s identity, so anyone who can spoof a trusted host can gain access without credentials. Encryption, multi‑factor authentication, and command logging are security controls that enhance protection, not weaken it. Therefore, the primary conflict is the lack of authentication, which directly undermines confidentiality and integrity guarantees of a robust policy.

Q5. An organization patches the finger daemon to fix the buffer‑overflow bug. Which of the following best describes the impact on the Morris worm’s infection ability?

A.The worm can still exploit finger
B.The worm loses one of its three infection vectors ✅
C.The worm gains new capabilities
D.No impact because the worm uses only rsh
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Fixing the buffer‑overflow removes the vulnerability the worm exploited in finger, eliminating that specific infection path. The worm still retains its other two methods—rsh‑based remote execution and the sendmail bug—but loses the finger vector, reducing overall spread potential. The other options are inaccurate because the worm cannot exploit a patched service, does not gain new abilities, and does not rely solely on rsh.

Q6. A network is being scanned and the worm attempts to use rsh to spread. Which mitigation provides the greatest reduction in worm propagation?

A.Disable rsh service on all hosts ✅
B.Implement host‑based firewalls that block port 514
C.Regularly rotate passwords
D.Install intrusion detection system
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Disabling rsh removes the fundamental mechanism the worm uses for password‑less remote execution, effectively cutting off that propagation channel. Blocking port 514 only limits traffic but may be bypassed if rsh runs on another port; password rotation does not affect a service that does not require credentials; and IDS can detect but not prevent the initial exploitation. Thus, service shutdown offers the most decisive protection.

Q7. What primary security policy principle is violated when a system permits remote execution without password verification?

A.Confidentiality
B.Integrity
C.Authentication ✅
D.Availability
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Allowing remote commands without verifying who is issuing them directly breaches the authentication principle, which requires proof of identity before granting access. Confidentiality concerns data secrecy, integrity ensures data is unaltered, and availability focuses on system uptime; none of these address the core issue of unchecked identity verification. Hence, the lack of authentication is the fundamental policy violation exploited by the worm.

Q8. To limit the spread of a worm that exploits rsh and finger, a company segments its network. Which segmentation strategy is most effective?

A.Place all UNIX servers on a single VLAN
B.Separate UNIX servers from other workstations and restrict inter‑VLAN traffic ✅
C.Merge all devices into one flat network
D.Use wireless only for UNIX servers
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Isolating UNIX servers on their own VLAN and controlling traffic between VLANs prevents the worm from easily reaching vulnerable hosts across the broader network. Keeping them together on one VLAN or a flat network offers no barrier, and using wireless exclusively does not address the underlying protocol vulnerability. Proper segmentation thus reduces the attack surface and limits lateral movement.

Q9. During monitoring, an analyst observes a sudden increase in outbound connections to port 514 on many hosts. Which conclusion is most consistent with a worm using rsh for propagation?

A.The network is experiencing a DDoS attack
B.Users are logging in via SSH
C.A new web service is being deployed
D.The worm is likely attempting remote command execution via rsh ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Port 514 is the default rsh service port; a spike in outbound connections from many hosts suggests automated attempts to contact other machines for password‑less execution, matching worm behavior. A DDoS would target a victim rather than many internal hosts, SSH uses port 22, and a web service deployment would involve HTTP ports, not 514.

Q10. How does the combination of three infection methods in the Morris worm illustrate the defense‑in‑depth concept?

A.It shows that relying on a single control leaves gaps ✅
B.It proves that multiple attacks are always successful
C.It indicates that only one method is needed
D.It demonstrates that security policies are unnecessary
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The worm’s use of rsh, finger, and sendmail vulnerabilities demonstrates that if an organization depends on just one protective measure, attackers can bypass it through another vector. Defense‑in‑depth advocates layered controls so that compromising one layer does not grant full access. The other statements misinterpret the principle, as multiple attacks are not guaranteed to succeed and security policies remain essential.
