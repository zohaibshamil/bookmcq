What is Recovery in window 7?

Definition:
Recovery mechanisms include Startup Repair, System Restore, and Windows Recovery Environment (WinRE) that diagnose and repair boot failures where recovery success probability \( P_r \) depends on backup availability and corruption extent.

Example:
Startup Repair automatically fixes missing bootmgr or corrupted BCD store using offline servicing tools.

Reason:
Automated recovery reduces downtime and support costs by enabling self-healing for common failure modes without requiring expert intervention or complete reinstallation.

Q1. What does a zero value in the valid bit of a page‑table entry indicate?

A. The page is not currently resident in physical memory ✅
B. The page is read‑only
C. The page is locked in memory
D. The page is shared

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

A zero valid bit tells the operating system that the page is not present in RAM, so any access causes a page‑fault and the page must be brought in from the page file or another source. The other options describe protection or sharing attributes, which are controlled by different bits. Recognizing the meaning of the valid bit helps understand why a fault occurs and how the system recovers the needed data.

Q2. Why does Windows increment the age of pages that have not been marked as referenced since the last sweep?

A. To keep them locked in cache
B. To signal they are dirty
C. To increase their protection level
D. To identify them for possible trimming ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

When a page’s reference bit stays clear, the system assumes the page has not been used recently. Incrementing its age flags it as a candidate for removal during a trimming operation, freeing physical memory for active pages. The other choices describe unrelated behaviors: cache locking, dirty status, and protection changes, none of which are driven by the aging mechanism.

Q3. A process has a working set of 150 MB and the system is low on memory. The VM manager must trim 30 MB from this process. Which pages will be removed first?

A. Pages with the highest protection bits
B. Pages that were most recently referenced
C. Pages with the oldest age counters ✅
D. Pages that are currently locked

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The trimming algorithm targets pages that have the greatest age because they have not been referenced for the longest time, making them the best candidates for eviction. Recently referenced pages are kept to preserve performance, and protected or locked pages are typically exempt from trimming. Selecting the oldest pages aligns with the LRU policy and ensures minimal impact on active work.

Q4. If the page‑file offset field is 32 bits and each page is 4 KB, what is the maximum number of distinct pages that can be addressed?

A. \(2^{20}\) pages ✅
B. \(2^{22}\) pages
C. \(2^{24}\) pages
D. \(2^{26}\) pages

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A 32‑bit offset counts bytes, so the total addressable space is \(2^{32}\) bytes. Dividing by the page size of 4 KB (\(2^{12}\) bytes) yields \(2^{32‑12}=2^{20}\) pages. The other options represent larger numbers that would require more offset bits than are available. Understanding this calculation shows how the offset field limits the number of pages the OS can track in the page file.

Q5. How does the per‑working‑set LRU policy differ from a global LRU policy in terms of page‑replacement decisions?

A. It tracks ages only for the most active process
B. It trims pages based on each process’s individual usage patterns ✅
C. It ignores page references
D. It uses random selection

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

A per‑working‑set LRU keeps separate age counters for each process, allowing the system to trim pages that are idle within that specific process rather than affecting other processes. This isolation prevents one heavy user from causing unrelated processes to lose pages. The other choices describe inaccurate behaviors: focusing on a single process, ignoring references, or selecting pages randomly, none of which reflect the per‑process LRU strategy.

Q6. A Windows 7 system has a process whose working set is growing rapidly despite ample RAM. Which VM‑manager behavior will most likely improve overall system responsiveness?

A. Increase the process’s hard limit
B. Disable page trimming
C. Trim the rapidly growing process’s working set ✅
D. Allocate a dedicated paging file

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Even when memory is plentiful, Windows 7 may still trim a fast‑growing working set to keep the system responsive for other applications. Trimming removes older pages from that process, freeing RAM for more active tasks. Raising limits or disabling trimming would worsen responsiveness, and adding a dedicated paging file does not directly address the immediate need to rebalance memory usage.

Q7. During a periodic sweep, a page’s reference bit is cleared but its age counter is not incremented. What does this indicate about the page’s recent activity?

A. The page was referenced after the sweep started
B. The page has been idle for two sweeps ✅
C. The page is dirty
D. The page is protected

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

If the reference bit is cleared yet the age does not increase, the page must have been referenced again after the sweep, causing the reference bit to be set and preventing the age increment. This shows the page is still in active use. The other options describe states unrelated to the observed combination of reference and age behavior.

Q8. What is the purpose of the 4 bits that select the paging file in a page‑file PTE?

A. To identify the physical frame
B. To choose among multiple paging files ✅
C. To set protection levels
D. To indicate dirty status

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Windows can maintain more than one paging file, and the 4‑bit field tells the OS which file contains the stored page. This enables flexible storage across different drives. The other options refer to functions handled by other fields: physical frame numbers, protection bits, and dirty flags, none of which are encoded in the paging‑file selector.

Q9. A system with 8 GB RAM experiences a sudden memory pressure spike. The VM manager decides to trim 10 % of each process’s working set. Process X has a working set of 2 GB with an average page age of 5 sweeps. Which action will most likely be taken for Process X?

A. Remove the newest pages first
B. Remove pages with age ≥ 5 ✅
C. Remove pages randomly
D. Remove pages that are currently locked

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When trimming, the manager prefers the oldest pages because they have not been used recently. An average age of 5 sweeps means many pages meet or exceed that threshold, so those pages are prime candidates for removal. Newer pages are kept to preserve performance, random removal would be inefficient, and locked pages are typically exempt from trimming.

Q10. An administrator configures a hard limit of 500 MB for a critical service. The service’s working set has grown to 600 MB while the system still has free memory. What will the VM manager do?

A. Allow the service to keep 600 MB because memory is free
B. Trim the service’s working set down to the hard limit ✅
C. Increase the hard limit automatically
D. Swap out the entire service to disk

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A hard limit caps the amount of physical memory a process may use regardless of overall system availability. When the service exceeds 500 MB, the VM manager will trim the excess pages to enforce the limit, ensuring fairness and preventing a single process from monopolizing memory. The other options either ignore the limit, adjust it without policy, or take extreme actions not required by the hard‑limit rule.

Q11. Why does Windows encode a pointer to the section object in PTEs for pages mapped through section objects?

A. To quickly locate the backing file for the page ✅
B. To increase protection bits
C. To prevent paging
D. To mark the page as dirty

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Section objects represent memory‑mapped files or images. Storing a pointer to the section object in the PTE allows the OS to instantly find the file or image that backs a given page, facilitating fast fault handling and sharing. The other choices describe unrelated functions: protection bits are separate, paging is still allowed, and dirty status is tracked elsewhere.

Q12. Explain how the 20 reserved bits in a page‑file PTE could be utilized by the OS without affecting existing functionality.

B. They are unused and remain zero

The other options assign specific, currently unsupported purposes that would require redesign of the PTE handling.
