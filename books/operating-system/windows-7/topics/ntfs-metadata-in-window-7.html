Q1. Which of the following bits are always zero for a page‑file PTE?

🔹 A. T, P, and V bits
🔹 B. Only the T bit
🔹 C. Only the V bit
🔹 D. All protection bits

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The page‑file PTE type is defined with its T (transition), P (present), and V (valid) bits cleared, meaning the entry does not point to a resident page. Option A correctly lists those three bits. Options B and C mention only one of the three bits, which is incomplete. Option D is wrong because protection bits are still used for access rights. Keeping these bits zero tells the VM manager the page resides on disk, not in RAM.

Q2. Why does the VM manager increment the age of pages that have not been marked as referenced since the last pass?

🔹 A. To free up space for new processes
🔹 B. To identify pages that are candidates for trimming
🔹 C. To increase their priority for future use
🔹 D. To reset their protection attributes

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The age counter is used to track how long a page has gone without being referenced. Pages with higher age values are less recently used, making them prime candidates for trimming when memory pressure occurs. Option B captures this purpose. Option A confuses the goal; the manager does not immediately free space, only later when trimming. Option C is opposite—older pages get lower priority, not higher. Option D is unrelated; protection attributes are unchanged by aging.

Q3. A process has been assigned a hard limit of 200 MB of physical memory. Its working set has grown to 250 MB while the system still has abundant free RAM. What action will the VM manager most likely take?

🔹 A. Increase the process's hard limit automatically
🔹 B. Swap the entire process to the page file
🔹 C. Trim the working set by removing the oldest pages
🔹 D. Suspend the process until memory becomes available

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When a process exceeds its hard limit, the VM manager enforces the restriction by trimming pages, starting with the oldest according to the LRU policy. Option C describes this behavior. Option A is incorrect because limits are not adjusted without administrator input. Option B is extreme; only selective pages are swapped, not the whole process. Option D is not how Windows handles memory limits; it trims rather than suspends.

Q4. How does the least‑recently‑used (LRU) replacement policy decide which pages to remove from a working set?

🔹 A. It selects pages with the highest age counters, meaning they have not been referenced recently
🔹 B. It removes pages with the lowest protection level
🔹 C. It chooses pages that are currently locked in memory
🔹 D. It prefers pages that are marked as dirty

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The LRU algorithm tracks how long each page has gone without a reference; the highest age indicates the longest period of inactivity, making those pages the first to be removed. Option A correctly explains this. Option B confuses protection with usage. Option C is opposite; locked pages are protected from removal. Option D focuses on dirty state, which influences write‑back but not the primary selection criterion.

Q5. A page‑file PTE reserves 32 bits for the page‑file offset. What is the maximum byte size that can be addressed if each page is 4 KB?

🔹 A. \(2^{30}\) bytes (1 GB)
🔹 B. \(2^{44}\) bytes (16 TB)
🔹 C. \(2^{36}\) bytes (64 GB)
🔹 D. \(2^{40}\) bytes (1 TB)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The offset field can represent \(2^{32}\) distinct page numbers. Multiplying by the page size (4 KB = \(2^{12}\) bytes) yields \(2^{32} \times 2^{12} = 2^{44}\) bytes, which equals 16 TB. Option B matches this calculation. Option A under‑estimates by ignoring the page‑size factor. Option C and D use incorrect exponent combinations, leading to 64 GB and 1 TB respectively, which do not reflect the full addressable range.

Q6. How many bits in a page‑file PTE are reserved for additional bookkeeping?

🔹 A. 10 bits
🔹 B. 16 bits
🔹 C. 20 bits
🔹 D. 24 bits

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The specification states that a page‑file PTE includes 20 bits set aside for extra bookkeeping information. Option C correctly identifies this count. Options A, B, and D give lower or higher values that do not match the defined structure, making them incorrect.

Q7. When the VM manager uses heuristics to decide how much of a working set to trim, which factor has the greatest influence on the amount trimmed?

🔹 A. The total number of processes on the system
🔹 B. The current CPU utilization level
🔹 C. The rate at which the process's working set is growing
🔹 D. The amount of free disk space

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Heuristics consider several metrics, but the dominant factor is how quickly a process's working set expands; rapid growth signals potential memory pressure, prompting larger trims. Option D is the correct choice. Option A is peripheral; the number of processes does not directly dictate trim size. Option B relates to CPU, not memory management. Option C, while plausible, is less decisive than the growth rate in the Windows 7 policy described.

Q8. What does it indicate when the T, P, and V bits of a PTE are all zero?

🔹 A. The page is stored in the page file and not currently resident in RAM
🔹 B. The page is read‑only and cannot be modified
🔹 C. The page is locked and cannot be swapped out
🔹 D. The page is allocated but not yet initialized

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

All three bits cleared signal that the entry does not refer to a physical frame; instead, the page resides on disk in the page file. Option A captures this meaning. Option B misinterprets protection flags, which are separate from T, P, and V. Option C describes a locked state, which would set the P bit. Option D confuses allocation status with residency.

Q9. Three processes have working sets of 150 MB, 300 MB, and 500 MB. The VM manager must trim pages. Assuming ages are equal, which process's pages will be removed first?

🔹 A. The 150 MB process
🔹 B. The 300 MB process
🔹 C. The 500 MB process
🔹 D. All processes will be trimmed equally

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

When ages are identical, the VM manager prefers to trim from the largest working set to free the most memory with the fewest pages removed. Therefore, the 500 MB process (Option C) is selected first. Option A would free less memory, making it inefficient. Option B is intermediate and not the optimal choice. Option D contradicts the policy of targeting the biggest set first.

Q10. Why does Windows 7 trim processes that are growing rapidly even when plenty of memory is available?

🔹 A. To reduce CPU usage caused by large working sets
🔹 B. To improve overall system responsiveness for other processes
🔹 C. To prevent disk fragmentation in the page file
🔹 D. To enforce a strict per‑process memory quota

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Rapidly expanding working sets can delay memory allocation for other applications, causing perceived sluggishness. By trimming these aggressive processes early, Windows 7 ensures that responsive applications receive memory promptly, enhancing overall system performance. Option B describes this rationale. Option A focuses on CPU, which is not directly impacted by working‑set size. Option C addresses page‑file fragmentation, unrelated to the trimming policy. Option D suggests a fixed quota, which is not the primary reason for the proactive trimming in Windows 7.
