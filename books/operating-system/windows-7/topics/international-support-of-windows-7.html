Q1. Which version of Windows first shipped a 64‑bit edition for both IA‑64 and AMD64 architectures?

🔹 A. Windows XP
🔹 B. Windows Vista
🔹 C. Windows 7
🔹 D. Windows 8

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The correct answer is Windows XP because it was the first Windows release to provide official 64‑bit builds for both IA‑64 (2001) and later AMD64 (2005). The other options arrived later, with Vista and Windows 7 introducing additional features but not the initial 64‑bit support. This matters for understanding how operating‑system evolution introduced broader hardware compatibility, allowing users to exploit larger memory capacities when the OS first supported them.

Q2. What primary advantage does fast user switching provide to users of Windows 7?

🔹 A. Allows multiple users to be logged in simultaneously without logging off
🔹 B. Enables remote desktop connections
🔹 C. Improves graphics rendering performance
🔹 D. Reduces hard‑disk usage

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Fast user switching lets each logged‑on user keep their session active while another user takes control of the console, eliminating the need to log off and lose unsaved work. This is distinct from remote desktop, which accesses a separate session over the network, and it does not directly affect graphics or storage usage. Understanding this feature helps users maintain productivity when sharing a single workstation.

Q3. How does locating the Desktop Window Manager (DWM) in user mode influence system stability compared with a kernel‑mode implementation?

🔹 A. It isolates DWM crashes to user space, preserving the kernel
🔹 B. It speeds up graphics rendering dramatically
🔹 C. It prevents any graphical glitches
🔹 D. It eliminates the need for DirectX

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Placing DWM in user mode means that if the compositor fails, the failure is contained within user space, allowing the kernel and other processes to continue running. This isolation improves overall system stability. The other options are inaccurate: DWM’s position does not inherently speed up rendering, it cannot guarantee glitch‑free output, and DirectX still operates in kernel mode regardless of DWM’s location.

Q4. A company runs several virtual machines on a single Windows 7 host. Which Windows feature most directly enables the efficient execution of multiple operating systems on that hardware?

🔹 A. Fast user switching
🔹 B. Terminal Services
🔹 C. Machine‑virtualization technologies
🔹 D. Desktop Window Manager

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Machine‑virtualization technologies, such as Hyper‑V‑compatible solutions, allow a single physical machine to host multiple isolated operating‑system instances, sharing CPU, memory, and I/O resources efficiently. Fast user switching and Terminal Services manage multiple interactive sessions but do not provide the hardware abstraction needed for full virtual machines. DWM concerns visual composition and does not affect the core ability to run separate OS kernels.

Q5. A workstation with 32 GB of RAM is upgraded from a 32‑bit to a 64‑bit edition of Windows 7. What change in addressable memory does the user experience?

🔹 A. The system can now address the full 32 GB of RAM
🔹 B. The addressable memory remains limited to 4 GB
🔹 C. Only 8 GB becomes usable
🔹 D. Memory addressing is unchanged but performance improves

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A 64‑bit Windows 7 edition can use the full 32 GB of installed memory because the virtual address space expands to \(2^{64}\) addresses, far exceeding the 4 GB limit of a 32‑bit OS. The other choices incorrectly claim the limit stays at 4 GB or that only a portion becomes usable. Recognizing this difference explains why moving to a 64‑bit environment is essential for memory‑intensive workloads.

Q6. An administrator must configure a Windows 7 server to support exactly 20 concurrent remote desktop sessions. Which combination of settings will achieve this requirement?

🔹 A. Install Server edition, enable Terminal Services, set max sessions to 20
🔹 B. Use Desktop edition, enable Fast user switching, limit to 20 users
🔹 C. Install Server edition, disable Terminal Services, rely on Fast user switching
🔹 D. Use Desktop edition, enable Terminal Services, set max sessions to 20

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Only the Server edition of Windows 7 includes the Terminal Services role that can host multiple simultaneous remote sessions. After installing the role, the administrator can set the maximum concurrent sessions to 20. Fast user switching does not provide networked remote sessions, and the Desktop edition cannot host more than one remote session, making the other options invalid.

Q7. Why did Windows Vista relocate the graphical user interface back to user mode after it had been moved into kernel mode in Windows NT 4.0?

🔹 A. To enhance security by reducing kernel‑level attack surface
🔹 B. To increase graphics performance
🔹 C. To simplify driver development
🔹 D. To enable DirectX to run in user mode

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Moving the GUI to user mode lowers the risk that a graphical fault or malicious code can compromise the kernel, thereby strengthening system security. While performance and driver simplicity are considerations, the primary driver was the desire to limit kernel exposure. DirectX continues to operate in kernel mode, so the shift does not affect its location. Understanding this design decision illustrates how OS architecture balances functionality with protection.

Q8. A developer optimizing a DirectX‑intensive application notices performance drops when the Desktop Window Manager (DWM) is active. Considering that DirectX runs in kernel mode while DWM runs in user mode, which strategy is most likely to improve performance?

🔹 A. Reduce the number of user‑to‑kernel transitions by batching draw calls
🔹 B. Disable DWM and rely on GDI
🔹 C. Move DWM to kernel mode
🔹 D. Increase screen resolution

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Batching draw calls minimizes the costly context switches between user‑mode DWM and kernel‑mode DirectX, reducing overhead and improving frame rates. Simply disabling DWM or switching to GDI would sacrifice visual effects and does not address the transition cost. Moving DWM into kernel mode would re‑introduce stability concerns, and increasing resolution generally lowers performance. Therefore, consolidating rendering commands is the most effective optimization.
