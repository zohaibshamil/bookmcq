What is Security in Windows 7?

Definition:
Security in Windows 7 encompasses integrated mechanisms like User Account Control (UAC), BitLocker Drive Encryption, and AppLocker that enforce least-privilege access and protect data at rest and in transit using cryptographic primitives where protection strength is often measured in bits such as \( \text{AES-256} \).

Example:
UAC prompts only appear when an application attempts to write to protected system directories or registry hives, reducing prompt fatigue compared to Vista.

Reason:
Balancing security with usability ensures users do not disable protective features, thereby maintaining the integrity of the security boundary without hindering productivity.

📝 All Security in Windows 7 MCQs

Q1. A shared workstation allows fast user switching. Which security risk is highest when users switch without logging off?

A.Unauthorized file access ✅
B.Malware persistence
C.Credential leakage
D.Network sniffing
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Fast user switching lets a new user take control of the console while the previous user's processes and open files remain active. The most immediate threat is that the new user can access files left open or stored in the previous session, leading to unauthorized file access. Malware persistence and credential leakage are possible but less direct, and network sniffing is unrelated to local session switching.

Q2. What primary security benefit does running each operating system instance in a separate virtual machine provide?

A.Improved graphics performance
B.License compliance ✅
C.Isolation of processes and data
D.Simpler user interface
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Virtual machines create distinct virtualized hardware environments, ensuring that processes and data in one VM cannot directly affect another. This isolation limits the impact of a compromise to the affected VM only. Enhanced graphics, licensing, and UI simplicity are advantages of virtualization but do not directly address security; isolation is the core protective mechanism.

Q3. In which Windows version was the Desktop Window Manager first introduced as a user‑mode process?

A.Windows XP
B.Windows 8
C.Windows Vista ✅
D.Windows 7
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Microsoft moved the Desktop Window Manager (DWM) out of kernel mode starting with Windows Vista, making it a user‑mode process that handles desktop compositing. This shift helped reduce the kernel’s attack surface. Windows XP never included DWM, Windows 7 later refined it, and Windows 8 continued the user‑mode design, but the initial introduction was in Vista.

Q4. An admin wants to allow simultaneous terminal‑service sessions while keeping each session isolated. Which Windows feature must be enabled?

A.Fast user switching
B.Remote Desktop Services ✅
C.User Account Control
D.Credential Guard
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Remote Desktop Services (formerly Terminal Services) provides the infrastructure for multiple concurrent user sessions, assigning each its own session ID and security context. Fast user switching only alternates the console user, UAC manages privilege elevation, and Credential Guard protects credentials, but none guarantee session isolation for simultaneous connections.

Q5. How does moving the graphical user interface back to user mode in Windows Vista improve system security?

A.It reduces the kernel's attack surface ✅
B.It enhances 3D rendering speed
C.It simplifies driver development
D.It enables higher screen resolutions
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: By running GUI components like the Desktop Window Manager in user mode, Windows Vista limits the amount of code executing with kernel privileges. This reduction in privileged code decreases opportunities for attackers to exploit kernel vulnerabilities. Faster rendering, driver simplicity, and higher resolutions are performance or usability benefits, not security improvements.

Q6. A kernel‑mode driver is exploited to execute arbitrary code on a 64‑bit Windows 7 system with DWM optimized. Which built‑in defense most likely blocks this attack?

A.Secure Boot
B.Address Space Layout Randomization (ASLR)
C.Credential Guard
D.PatchGuard ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: PatchGuard, also known as Kernel Patch Protection, monitors critical kernel structures and prevents unauthorized modifications, thwarting many kernel‑mode code‑execution exploits. Secure Boot ensures only trusted bootloaders run, ASLR randomizes addresses but does not stop a driver from writing to them, and Credential Guard protects credentials, not kernel integrity. Therefore PatchGuard is the primary barrier against this type of attack.

Q7. When a server runs a 64‑bit Windows OS with large physical memory, what security implication becomes most critical?

A.Need for faster CPUs
B.Increased risk of pointer‑overflow attacks ✅
C.Higher licensing costs
D.More frequent hardware failures
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Large physical memory expands the addressable space, giving attackers a broader target for memory‑corruption techniques such as pointer overflows. Proper access controls for kernel objects and careful memory management become essential to prevent exploitation. Faster CPUs, licensing, and hardware reliability are operational concerns but do not directly affect the security posture related to memory size.

Q8. A public kiosk uses fast user switching. After a user logs off, a background process from the previous session remains running. Which Windows mechanism can automatically end such stray processes?

A.Task Scheduler
B.Group Policy “Logoff scripts” ✅
C.Windows Defender
D.Session 0 Isolation
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Group Policy can be configured to run logoff scripts that terminate any processes owned by the departing user, ensuring no residual code persists that could be misused. Task Scheduler runs tasks on a schedule, Defender focuses on malware detection, and Session 0 Isolation separates services from user sessions, none of which specifically clean up stray user processes at logoff.

Q9. How does terminal services multiplexing of keyboard, mouse, and monitor affect confidentiality of each user's input?

A.It shares input devices among sessions
B.It encrypts all keystrokes by default
C.It isolates input per session ✅
D.It logs every key press for auditing
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Multiplexing assigns each active session its own virtual input channel, so keystrokes, mouse movements, and display output are kept separate. This isolation preserves confidentiality because one user cannot see or capture another's input. Sharing devices without isolation would be insecure, encryption is not automatic, and logging every key press would raise privacy concerns, making option C the correct description.

Q10. A developer wants a custom graphics component to run in user mode rather than kernel mode to avoid privilege escalation. Which Windows API should they use?

A.Direct3D
B.GDI+
C.Win32k
D.Desktop Window Manager (DWM) ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The Desktop Window Manager operates as a user‑mode process that handles compositing and visual effects, allowing developers to leverage its services without entering kernel mode. Direct3D and GDI+ can also run in user mode but often rely on kernel‑mode drivers for rendering. Win32k is a kernel component. Using DWM thus minimizes privileged code execution, reducing escalation risk.

Q11. Why can fast user switching on a multi‑user workstation lead to privilege escalation if session data is not cleared?

A.It allows multiple users to edit the same file simultaneously
B.It enables one user to inherit the security tokens of the previous session ✅
C.It forces the system to run all processes as Administrator
D.It disables all firewall rules during switching
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When fast user switching does not properly purge the previous session’s security context, the new user may inadvertently inherit elevated tokens or handles left open, providing a pathway to privilege escalation. Simultaneous file editing is a collaboration issue, forcing processes to run as Administrator is not a default behavior, and firewall rules remain active, making option B the accurate security concern.
