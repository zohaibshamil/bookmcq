What is Sharing objects between processes in Window 7?

Definition:
Inter-process object sharing uses named objects, handle duplication, or section mapping where shared memory region size is page-aligned with proper synchronization primitives.

Example:
CreateFileMapping with named section enables multiple processes to map same physical pages into their virtual address spaces.

Reason:
Controlled object sharing enables efficient IPC, shared caches, and cooperative processing while maintaining isolation and preventing unauthorized access through explicit sharing mechanisms.

Q1. A process creates an APC to notify another process that an asynchronous read has finished. Which condition must be true for the target thread to execute the APC?

A.The thread must be in a non‑alertable wait state.
B.The thread must be in an alertable wait state. ✅
C.The thread must be running in user mode.
D.The thread must have a pending I/O request.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The correct answer is B because an APC is only delivered when the target thread is waiting in the kernel and marked alertable. If the thread is not alertable (option A), the APC remains queued. Options C and D describe states that do not affect APC delivery. Understanding this rule helps developers design inter‑process notifications that reliably trigger code execution at the right moment.

Q2. Which of the following best defines an Asynchronous Procedure Call (APC) in Windows?

A.A kernel‑mode routine that runs immediately after an interrupt.
B.A user‑mode routine that can be queued to a specific thread and runs when the thread is alertable. ✅
C.A low‑priority thread that processes I/O after the ISR finishes.
D.A timer‑driven callback that preempts the current thread.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: An APC is a user‑mode routine that is queued to a particular thread and executes only when that thread enters an alertable wait state. Option B captures this definition precisely. Option A confuses APCs with immediate interrupt handling, option C describes a DPC, and option D describes a timer callback. Knowing the exact definition prevents misuse of APCs for tasks that require immediate or timed execution.

Q3. Why does the dispatcher schedule Deferred Procedure Calls (DPCs) at a priority lower than device‑interrupt priority but higher than normal thread priority?

A.To ensure DPCs never preempt each other. ✅
B.To allow urgent ISR work to finish before any DPC runs, while still preventing ordinary threads from delaying DPC execution.
C.To give DPCs the same priority as user‑mode APCs.
D.To guarantee that DPCs run only on a separate processor core.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The dispatcher places DPCs below hardware interrupt priority so that the ISR can complete critical work first, but above normal thread priority so that DPCs are not delayed by regular scheduling. This ordering balances responsiveness with system stability. Option A is incorrect because DPCs can preempt each other based on their own priority levels. Option C misstates the relation to APCs, and option D is not how Windows schedules DPCs.

Q4. A thread is waiting on a synchronization object without the alertable flag set. An APC is queued to this thread. What will happen to the APC?

A.It will execute immediately, bypassing the wait state.
B.It will remain pending until the thread becomes alertable or exits. ✅
C.It will be discarded by the dispatcher.
D.It will be converted into a DPC and run later.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When a thread is not in an alertable state, any queued APC cannot be delivered; the system simply discards it rather than converting it. Option B suggests the APC will wait, which is false because the dispatcher does not retain APCs for later conversion. Option A is wrong because APCs never run while a thread is in a non‑alertable wait. Understanding this behavior prevents accidental loss of notifications.

Q5. Two processes share a named event object. Process A queues a DPC that sets the event after processing a timer. Process B is waiting on the event in an alertable state. Which outcome is most likely?

A.Process B will resume immediately after the DPC runs.
B.Process B will never resume because DPCs cannot signal events.
C.Process B will resume only after the DPC completes and the scheduler picks a new thread. ✅
D.Process B will resume only if an APC is also queued.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When the DPC runs, it sets the event, making the wait condition true. However, the waiting thread will not be scheduled until the current quantum ends and the scheduler selects a new thread, which is described in option C. Option A ignores the scheduling step, option B incorrectly claims DPCs cannot signal events, and option D mixes APC behavior with DPC signaling. This illustrates proper synchronization across processes using shared kernel objects.

Q6. What is the primary reason the dispatcher may forward work from an ISR or DPC to a pool of worker threads?

A.To avoid violating the DPC’s restriction against paging operations.
B.To increase the priority of the work above device interrupts. ✅
C.To allow the work to run in user mode with full privileges.
D.To guarantee the work executes on a separate CPU core.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The dispatcher forwards work to worker threads when the operation cannot be completed quickly enough within the ISR/DPC context, often because the work needs a higher priority than the DPC can safely have. Option B captures this reason. Option A is a secondary concern (DPCs cannot page), but the main driver is priority management. Options C and D are unrelated to the dispatcher’s design goals.

Q7. A system requires two processes to share a memory‑mapped file and be notified instantly when the other process writes new data. Which combination provides the lowest latency notification?

A.Use a named mutex plus a user‑mode APC.
B.Use a named event plus a DPC queued by the writer’s ISR.
C.Use a named semaphore plus a worker‑thread callback.
D.Use a memory‑mapped file with a kernel‑mode APC queued by the writer’s thread. ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: A kernel‑mode APC queued by the writer’s thread can execute as soon as the reader thread becomes alertable, delivering notification with minimal delay. Option D therefore yields the lowest latency. Option A introduces mutex overhead and requires the thread to be alertable. Option B relies on a DPC, which runs at a lower priority than the ISR but still may be delayed by other DPCs. Option C adds unnecessary semaphore handling and a worker thread, increasing latency.

Q8. When the scheduler reaches the end of a thread’s quantum, it queues a DPC to preempt the thread. At which priority level must the DPC be placed to guarantee it runs before any normal thread on the same processor?

A.Higher than all hardware interrupt priorities.
B.Between the highest hardware interrupt priority and the lowest DPC priority.
C.Above normal thread priority but below all device‑interrupt priorities. ✅
D.Equal to normal thread priority.
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The DPC must be scheduled above normal thread priority so it preempts regular threads, yet still below any hardware interrupt priority to avoid interfering with critical ISR work. Option C describes this exact placement. Option A would disrupt interrupt handling, option B misplaces the DPC relative to other DPCs, and option D would allow normal threads to run before the DPC, defeating the preemptive purpose.

Q9. Which statement correctly describes how sharing a kernel object, such as a file mapping, between processes interacts with APC delivery?

A.APCs can only be delivered to threads that own the kernel object.
B.The kernel object’s reference count is increased for each APC that accesses it. ✅
C.When an APC accesses a shared object, the object is automatically duplicated for each process.
D.The APC runs in the context of the target thread, allowing it to safely use the shared object without additional synchronization.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When an APC is queued to a thread that will use a shared kernel object, the object's reference count is incremented to ensure it remains valid while the APC executes. Option B captures this mechanism. Option A is false because APCs can be delivered to any thread with appropriate rights. Option C incorrectly suggests duplication, and option D ignores the need for reference counting to protect the object during APC execution.
