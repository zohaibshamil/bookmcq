Q1. A page-file PTE reserves 32 bits for the page‑file offset. What is the maximum offset value (in bytes) that can be represented if each offset unit corresponds to a 4‑KB page?

🔹 A. 2^{32} bytes
🔹 B. 2^{44} bytes
🔹 C. 2^{20} bytes
🔹 D. 2^{28} bytes

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The offset field counts pages, not bytes. With 32 bits you can address up to 2^{32} pages. Multiplying by the page size of 4 KB (2^{12} bytes) gives 2^{32+12}=2^{44} bytes as the highest representable offset. Option B states this value, making it correct. The other options either ignore the page‑size multiplication or use the wrong exponent, so they do not match the maximum byte offset that the PTE can encode.

Q2. A server process has a working set of 120 MB. The system detects low free memory and decides to trim 15 % of the working set. Approximately how many megabytes will be removed?

🔹 A. 12 MB
🔹 B. 15 MB
🔹 C. 18 MB
🔹 D. 20 MB

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Fifteen percent of 120 MB is calculated as 0.15 × 120 = 18 MB. Option C matches this result, so it is the correct answer. Option A (12 MB) corresponds to a 10 % trim, Option B (15 MB) would be a 12.5 % reduction, and Option D (20 MB) reflects a 16.7 % cut. Understanding percentage calculations helps administrators predict memory reclamation during low‑memory conditions.

Q3. Process A frequently accesses pages 1‑4, while Process B accesses pages 5‑8 intermittently. If the VM manager must free 2 pages using the per‑working‑set LRU policy, which pages are most likely selected?

🔹 A. Pages 1‑2
🔹 B. Pages 3‑4
🔹 C. Pages 5‑6
🔹 D. Pages 7‑8

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The LRU policy removes pages that have not been used recently. Because Process B’s pages (5‑8) are accessed intermittently, they become older than the constantly referenced pages of Process A. Therefore the two oldest pages are most likely among 5‑6, making option C correct. Options A and B contain frequently used pages, so they are unlikely to be chosen. Option D could also be old, but the first two older pages are typically 5‑6.

Q4. Process X has a hard limit of 64 MB on its working set but currently uses 70 MB. Which action will the VM manager take?

🔹 A. Increase the limit
🔹 B. Trim pages until usage ≤64 MB
🔹 C. Swap the entire process to disk
🔹 D. Do nothing until memory is low

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When a process exceeds its hard limit, the VM manager actively trims pages to bring usage back within the allowed range. Option B describes this behavior and is therefore correct. The manager does not raise the limit automatically (Option A), nor does it swap the whole process (Option C). Ignoring the limit until memory pressure occurs (Option D) would violate the hard‑limit contract.

Q5. A PTE contains 4 bits to select the paging file. How many distinct paging files can the system address?

🔹 A. 4
🔹 B. 8
🔹 C. 12
🔹 D. 16

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Four bits provide 2^{4}=16 different combinations, allowing the system to address up to 16 separate paging files. Option D reflects this calculation and is correct. Options A, B, and C correspond to 2^{2}, 2^{3}, and an incorrect linear count, respectively, and thus underestimate the addressable range.

Q6. Process Y's working set grows from 200 MB to 350 MB within a minute while memory is abundant. What policy does Windows 7 employ that may still trigger trimming?

🔹 A. Only trim when memory low
🔹 B. Trim based on hard limit
🔹 C. Trim rapidly growing processes
🔹 D. Never trim once started

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Windows 7 introduced a policy that monitors the rate of working‑set growth. Even when overall memory is plentiful, a process that expands quickly can be trimmed to protect system responsiveness. Option C captures this behavior. The other options describe older or nonexistent policies: trimming solely on low memory (A), relying only on hard limits (B), or never trimming (D) are not accurate for Windows 7.

Q7. The VM manager makes a pass through a working set every 5 seconds, incrementing the age of pages not marked referenced. If a page has not been referenced for 20 seconds, what is its age value assuming the initial age is 0?

🔹 A. 2
🔹 B. 3
🔹 C. 4
🔹 D. 5

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

A pass occurs at 5‑second intervals: at 5 s, 10 s, 15 s, and 20 s. Each pass adds one to the age for pages that remain unreferenced, resulting in four increments. Therefore the age becomes 4, matching option C. Options A and B underestimate the number of passes, while Option D adds an extra increment that does not occur within the 20‑second window.

Q8. Why are the T, P, and V bits set to zero in a page‑file PTE?

🔹 A. Indicates page is in RAM
🔹 B. Marks page as invalid and not present
🔹 C. Signals page is read‑only
🔹 D. Denotes a system‑reserved entry

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

In a page‑file PTE, the T (Transition), P (Present), and V (Valid) bits being zero signals that the page is not currently resident in physical memory. This status tells the memory manager that the page must be fetched from the paging file when accessed. Option B correctly describes this meaning. The other choices either imply the page is present (A), assign read‑only status (C), or suggest a reserved purpose (D), none of which align with the zero‑bit semantics.

🔹 D. To move them to a separate file

📖 Explanation:

Increasing the age of unreferenced pages creates a metric that the VM manager uses to decide which pages are least recently used. Older pages become prime candidates for trimming, helping reclaim memory. Option B captures this intention. Options A and C misinterpret the age as a positive attribute, and Option D suggests a file‑management action not performed by the aging mechanism.

Q10. How does using a per‑working‑set LRU replacement policy improve overall system responsiveness?

🔹 A. Guarantees equal memory for all processes
🔹 B. Removes most frequently used pages first
🔹 C. Frees pages that are least likely to be needed soon
🔹 D. Increases CPU speed

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The per‑working‑set LRU policy selects pages that have not been used recently, freeing those that are least likely to be needed again soon. By removing such pages, the system avoids swapping out heavily used data, reducing latency and keeping interactive tasks responsive. Option C accurately describes this benefit. The other options either misstate the policy’s effect (A, B) or refer to unrelated hardware performance (D).

Q12. What is the most likely use of the 20 reserved bits in a page‑file PTE?

The other options describe concrete information that already has dedicated fields elsewhere (physical address, process ID, file path) and would not be placed in reserved bits.

Q14. Which bit in a PTE is cleared when a page is not referenced during a VM manager pass?

🔹 A. Valid (V) bit
🔹 B. Modified (M) bit
🔹 C. Referenced (R) bit
🔹 D. Dirty (D) bit

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The Referenced (or Accessed) bit records whether a page has been accessed since the last scan. During each VM manager pass, pages that remain unreferenced have this bit cleared, allowing the age counter to increase. Option C correctly identifies this bit. The Valid bit indicates presence, the Modified bit tracks writes, and the Dirty bit is a synonym for Modified; none of these are cleared solely due to lack of reference.
