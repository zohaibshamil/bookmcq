What is NTFS file system B+ tree in window 7?

Definition:
NTFS uses B+ trees for indexing directory contents and metadata streams where search complexity is with branching factor optimized for cluster-sized I/O operations.

Example:
Directory enumeration traverses B+ tree index nodes to retrieve filenames in sorted order without linear scanning.

Reason:
B+ tree indexing enables fast name lookups, range queries, and ordered enumeration even in directories containing millions of entries, maintaining performance scalability.

Q1. A Windows system is running low on physical memory. Which of the following actions will the VM manager most likely take first to free memory?

A.Increase each process's minimum working set
B.Trim the oldest pages from each process's working set ✅
C.Disable the LRU aging mechanism
D.Move all pages to the standby list
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The VM manager follows a per‑working‑set LRU policy, so when memory is scarce it looks for the least‑recently used pages in each process. Trimming the oldest pages removes memory that has not been accessed recently, freeing space quickly. Option B describes this behavior. Options A and D would increase memory pressure, while C would stop the aging mechanism, preventing the manager from identifying candidates for removal.

Q2. If a process has a hard limit on its physical memory usage, what will happen when the system has plenty of free memory?

A.The process's working set will automatically expand
B.The process will be forced to swap out pages despite free memory
C.The VM manager will ignore the limit
D.The process will be prevented from growing beyond the limit, even though memory is available ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A hard limit caps the amount of physical memory a process may occupy, regardless of overall system availability. Therefore the process cannot exceed that cap, and the VM manager will enforce the limit by refusing to allocate additional pages, even if free RAM exists. Option D correctly reflects this enforcement. Option A is opposite, B would cause unnecessary swapping, and C suggests the limit is ignored, which contradicts the definition of a hard limit.

Option C is inaccurate because the CPU overhead is comparable. Option D is false because limits still exist; the policy does not remove memory caps.

Q7. When the T, P, and V bits are all zero in a PTE, what does this indicate about the page?

D.The page is a system page
💡 Difficulty: easy | ✅ Correct: C
