What is Basic hardware in Main memory?

Definition:
Main memory hardware consists of RAM chips organized into banks that store data and instructions as binary values accessible via address and data buses.

Example:
A system with 8 GB DDR4 RAM uses multiple DIMM modules where each module contains memory cells arranged in rows and columns addressed by the memory controller.

Reason:
This physical organization determines access speed, capacity, and bandwidth which directly impacts CPU performance since main memory serves as the primary workspace for active processes.

Q1. What does a base register contain in a protected memory system?

A.The smallest legal physical memory address
B.The size of the allowed address range ✅
C.The process identifier
D.The interrupt vector address
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The base register holds the lowest physical address a process may reference, establishing the start of its allowed memory region. This ensures the CPU cannot access memory below that point. Option B describes the limit register, not the base. Options C and D are unrelated to memory protection. In practice, the base value lets the OS map a process’s logical addresses to safe physical locations, preventing accidental overwrites.

Q2. What is the primary purpose of a CPU cache?

A.Increase storage capacity ✅
B.Speed up access to frequently used memory
C.Handle interrupts
D.Store program code permanently
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: A cache stores copies of recently accessed memory lines close to the processor, making future accesses much faster. This reduces the number of costly trips to main memory. Option A describes adding more RAM, which a cache does not do. Option B is a true description but is placed under a different letter; the correct answer is the one that matches the cache’s speed‑up role. Options C and D relate to unrelated hardware functions.

💡 Difficulty: easy | ✅ Correct: A

Option B is essentially the correct concept but is labeled differently; the chosen answer reflects the core benefit. Options C and D are unrelated to address translation.
