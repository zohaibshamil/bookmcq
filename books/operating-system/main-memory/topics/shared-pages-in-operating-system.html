Q1. What term describes the address generated by a program before any relocation is applied?

🔹 A. Physical address
🔹 B. Logical address
🔹 C. Virtual address
🔹 D. Absolute address

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The correct answer is Logical address because it is the value a program creates before the MMU adds the relocation offset. Physical address is the result after relocation, Virtual address is a broader concept that may involve paging, and Absolute address implies a fixed physical location. Understanding this term is essential for recognizing how programs refer to memory without knowing actual hardware locations.

Q2. If the relocation register holds value R, which interval correctly describes the possible physical addresses for a process whose logical addresses range from 0 to max?

🔹 A. 0 to max
🔹 B. R to R+max
🔹 C. R+max to 2R
🔹 D. max to R

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Physical addresses are obtained by adding the base (relocation register) R to each logical address. Therefore the lowest physical address is R+0 = R and the highest is R+max. The other intervals either omit the base offset or place the range incorrectly, which would misrepresent where the process can actually reside in memory.

Q3. Why does using a relocation register allow the final physical address of a reference to be determined at execution time rather than at load time?

🔹 A. The base value is hard‑coded into the program
🔹 B. The addition of the base occurs when the address is sent to memory
🔹 C. Logical addresses are converted to virtual addresses first
🔹 D. The OS pre‑computes all addresses before execution

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When a relocation register is used, the MMU adds the current base value to each logical address at the moment the instruction reaches memory. This runtime addition means the same logical address can map to different physical locations if the base changes, unlike load‑time binding where addresses are fixed. The other options describe static or unrelated mechanisms.

Q4. How does a relocation register affect the ability of two processes to share a page of memory?

🔹 A. It forces both processes to use identical logical addresses
🔹 B. It requires both processes to have the same base value to map the same logical address to the same physical page
🔹 C. It automatically creates a shared page regardless of base values
🔹 D. It prevents any sharing of pages

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Sharing a page requires that the same logical address map to the same physical location in both processes. If each process has a different relocation register value, the same logical address will resolve to different physical addresses, breaking sharing. Identical logical addresses alone are insufficient; the base must also match. The other statements either ignore the base effect or claim universal sharing, which is incorrect.

Q5. Process A has a relocation register of 14000. It stores pointer value 346 in memory and later uses it for an indirect load. What physical address is accessed?

🔹 A. 14346
🔹 B. 14046
🔹 C. 14646
🔹 D. 13446

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The physical address is obtained by adding the base 14000 to the logical pointer 346, giving \(14000 + 346 = 14346\). Option A reflects this calculation. Option B subtracts 1000, option C adds 600, and option D subtracts 600, none of which follow the correct relocation rule. This demonstrates the straightforward arithmetic the MMU performs during address translation.

Q6. Process X has base 20000 and Process Y has base 30000. Both generate logical address 500. Which statement is true about the physical addresses they access?

🔹 A. Both access physical address 500
🔹 B. Both access the same physical address because logical addresses are identical
🔹 C. They access different physical locations, preventing sharing
🔹 D. X accesses 20500 while Y accesses 500

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Adding the respective bases gives physical addresses \(20000+500 = 20500\) for X and \(30000+500 = 30500\) for Y. Thus they access different locations, which means the same logical address does not guarantee sharing when bases differ. Options A and B ignore the base offset, and option D misstates Y’s address, making C the only correct description.

Q7. A system wants two processes to share a page at logical address 1024. Their relocation registers are 15000 and 25000. Can they share the same physical page? If not, what must change?

🔹 A. Yes, because logical addresses are identical
🔹 B. No, because their bases differ; they must use the same base value
🔹 C. No, because sharing requires identical physical addresses; they need a common page‑table entry mapping
🔹 D. Yes, sharing is automatic regardless of base values

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The two processes will map logical address 1024 to physical addresses \(15000+1024 = 16024\) and \(25000+1024 = 26024\), which are different. To share the same physical page, both must resolve the logical address to the same physical location, achievable by using a common base or a shared page‑table entry that overrides the relocation register. Options A and D ignore the base effect, and B suggests merely matching bases without mentioning the mapping mechanism.

Q8. A process uses a relocation register initially set to 12000. Mid‑execution, the OS changes the register to 18000 without altering the program. How will subsequent accesses to logical address 0 be affected?

🔹 A. They will still refer to physical address 12000
🔹 B. They will now refer to physical address 18000
🔹 C. They will cause a segmentation fault
🔹 D. The logical address will be doubled

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When the base changes to 18000, the MMU adds this new value to any logical address. Therefore a subsequent access to logical address 0 will resolve to physical address \(18000 + 0 = 18000\). The original address 12000 is no longer used, and no fault occurs because the new address is still within the process's allocated region. Options C and D describe unrelated error conditions.

Q9. What is a primary benefit of having programs use logical addresses instead of physical addresses regarding system protection?

🔹 A. It allows programs to modify hardware directly
🔹 B. It isolates each process, preventing it from accessing memory outside its allocated region
🔹 C. It speeds up address translation
🔹 D. It eliminates the need for a memory management unit

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Logical addresses keep a process unaware of actual hardware locations, so the operating system can enforce boundaries by translating only permitted ranges. This isolation stops a program from reading or writing outside its assigned memory, enhancing security. Direct hardware access, speed, or removal of the MMU are not advantages of logical addressing; they either reduce protection or are unrelated to the concept.
