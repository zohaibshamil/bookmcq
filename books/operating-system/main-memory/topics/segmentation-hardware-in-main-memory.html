📝 Segmentation hardware in Main Memory

📖 From Operating System • 8. Main Memory • 0 questions available

What is Segmentation hardware in Main Memory?

Segmentation hardware uses a segment table to map two-dimensional logical addresses \( (s, d) \) to linear physical addresses, where each entry contains a base address \( b_s \) and length \( l_s \); the MMU checks that \( d < l_s \) to prevent illegal access and computes the physical address as \( b_s + d \), often supported by a segment-table base register \( STBR \) and segment-table length register \( STLR \).
