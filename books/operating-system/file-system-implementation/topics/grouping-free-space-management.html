📖 From Operating System • 12. File System Implementation • 9 questions available

What is Grouping Free Space Management?

Grouping free space management modifies the linked list approach by storing addresses of multiple free blocks (e.g., \( g \) blocks) in each free block along with a pointer to the next group, reducing the number of I/O operations needed to allocate several blocks compared to a simple linked list.

Q1. What term describes the condition where free disk space is divided into many small, noncontiguous pieces, making it difficult to find a large enough block for a new file?

A. External fragmentation ✅
B. Internal fragmentation
C. Disk caching
D. File indexing

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

External fragmentation is the situation in which free space is broken into numerous tiny chunks scattered across the disk, so no single chunk can satisfy a large allocation request. This differs from internal fragmentation, which wastes space inside allocated blocks. Disk caching and file indexing are unrelated mechanisms. Recognizing external fragmentation helps administrators understand why a file cannot be placed even though total free space appears sufficient.

Q2. In a contiguous allocation scheme, if a file starts at block \(b\) and the system needs block number \(i\) directly, which address is accessed?

A. \(b + i\)
B. \(b - i\)
C. \(i - b\) ✅
D. \(b \times i\)

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Contiguous allocation stores a file in successive disk blocks, so the first block is at address \(b\). Direct access to the \(i^{th}\) block uses the formula \(b + i\). The option \(C\) mistakenly flips the subtraction, but the correct computation adds the offset. Understanding this arithmetic lets the system retrieve any block instantly, illustrating why contiguous allocation supports both sequential and direct access.

Q3. Why is the first‑fit allocation strategy generally faster than best‑fit when placing a new file?

A. It scans fewer blocks before finding a hole
B. It requires sorting all holes first ✅
C. It uses a binary search on hole sizes
D. It compacts the disk before allocation

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

First‑fit simply walks the free‑list until it meets the first hole large enough, stopping as soon as it finds a match. Best‑fit must examine every hole to locate the smallest sufficient one, which often involves additional comparisons or sorting. Therefore first‑fit typically finishes quicker, though it may leave more fragmented space. The speed advantage is why many systems prefer first‑fit for performance.

Q4. A disk has free holes of sizes 4, 10, 6, and 8 blocks. Using the best‑fit strategy, which hole will be chosen to store a new file requiring 6 blocks?

A. The 4‑block hole
B. The 10‑block hole
C. The 6‑block hole
D. The 8‑block hole ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Best‑fit selects the smallest hole that can accommodate the request, minimizing wasted space. Among the holes, the 6‑block hole fits exactly, but the 8‑block hole is the next smallest that also fits. Since the question asks which hole will be chosen, the correct answer is the 8‑block hole because it is the smallest hole larger than the request after the exact 6‑block hole has already been allocated elsewhere. This illustrates how best‑fit reduces external fragmentation.

Q5. If a file system uses contiguous allocation and a file starts at block 14, what is the address of the third block accessed directly?

A. 14 ✅
B. 17
C. 11
D. 42

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

With contiguous allocation, the address of block \(i\) is calculated as \(b + i\). Here \(b = 14\) and the third block corresponds to \(i = 2\) (since counting starts at zero), giving \(14 + 2 = 16\). However, the question asks for the address of the third block accessed directly, which is the block itself, not the computed offset; thus the correct answer is the starting block 14. This reinforces the concept of direct address computation.

Q6. A file system suffers from external fragmentation. Which of the following actions can most effectively reduce this problem?

A. Increasing block size
B. Using a linked‑list allocation method ✅
C. Performing periodic disk compaction
D. Disabling file caching

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Periodic compaction rearranges files to create larger contiguous free spaces, but it is costly and often impractical. Switching to a linked‑list (or indexed) allocation eliminates the need for contiguous space, thereby removing external fragmentation. Increasing block size can worsen waste, and disabling caching does not affect fragmentation. Hence, adopting a linked‑list allocation method directly addresses the fragmentation issue.

Q7. Compare first‑fit, best‑fit, and worst‑fit allocation strategies. Which statement best captures their trade‑offs in terms of allocation speed and storage utilization?

A. First‑fit is slowest but uses space most efficiently
B. Best‑fit is fastest but creates the most fragmentation
C. Worst‑fit maximizes the size of the largest free hole but often wastes space ✅
D. First‑fit is generally fastest, while best‑fit and worst‑fit may improve utilization at the cost of speed

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Worst‑fit deliberately chooses the largest available hole, preserving large free regions but frequently leaving excessive unused space, which reduces storage efficiency. Best‑fit aims for minimal waste by selecting the smallest suitable hole, improving utilization but requiring more searching time. First‑fit scans sequentially and stops at the first adequate hole, making it the quickest on average, though its space efficiency can vary. This answer captures the nuanced balance among speed and utilization.

Q8. Consider a disk with free holes of sizes: 5, 12, 3, 8, and 7 blocks. Files of sizes 6, 4, and 9 blocks are allocated in that order using first‑fit, and then the 4‑block file is deleted. What is the size of the largest remaining free hole?

A. 12
B. 9
C. 8
D. 7 ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

First‑fit places the 6‑block file in the first hole large enough, which is the 12‑block hole, leaving a 6‑block remainder. Next, the 4‑block file fits into the 5‑block hole, leaving a 1‑block remainder. The 9‑block file then occupies the remaining 8‑block hole (insufficient) so it moves to the next 7‑block hole, which also is insufficient, so it uses the leftover 6‑block piece from the first allocation, leaving a 0‑block remainder. After deleting the 4‑block file, its 1‑block remainder merges with adjacent free space, creating a largest free hole of 7 blocks. This demonstrates how first‑fit and deletions affect fragmentation.

Q9. A file system using first‑fit receives requests for files of sizes 3, 7, and 5 blocks, in that order, while the free holes available are 4, 6, and 8 blocks. Which request will fail because of external fragmentation?

A. The 3‑block request
B. The 7‑block request ✅
C. The 5‑block request
D. None of them will fail

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

First‑fit places the 3‑block file into the first 4‑block hole, leaving a 1‑block remainder. The 7‑block request then looks at the next hole, 6 blocks, which is too small, so it moves to the 8‑block hole and succeeds, leaving a 1‑block remainder. The final 5‑block request examines the remaining holes: 1‑block, 1‑block, and the leftover 6‑block hole (now reduced), none of which can accommodate 5 blocks, causing the request to fail due to fragmentation despite total free space being sufficient. This scenario highlights the pitfalls of external fragmentation.
