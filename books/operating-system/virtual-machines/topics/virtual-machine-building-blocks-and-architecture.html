Q1. A virtual machine needs to perform disk I/O on a host that supports hardware-assisted virtualization. Which building block most directly enables this capability?

🔹 A. Binary translation
🔹 B. Paravirtualization
🔹 C. Hardware-assisted virtualization
🔹 D. Emulated drivers

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The correct answer is C because hardware‑assisted virtualization provides CPU extensions that allow a guest to execute I/O instructions directly, reducing the need for software emulation. Binary translation (A) converts instructions but adds overhead; paravirtualization (B) requires guest modifications; emulated drivers (D) simulate devices in software, which is slower. Using hardware support lets the VM access disks efficiently, matching real‑world performance expectations.

Q2. In a dual‑mode CPU (user and kernel), a hypervisor must handle privileged instructions issued by a guest OS. Which technique allows the hypervisor to correctly manage these instructions without modifying the guest?

🔹 A. Binary translation
🔹 B. Trap‑and‑emulate
🔹 C. Direct execution
🔹 D. Shadow paging

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The correct answer is B. Trap‑and‑emulate intercepts privileged instructions issued in kernel mode, transfers control to the hypervisor, and emulates the intended effect, preserving isolation without altering the guest OS. Binary translation (A) rewrites code but is less efficient for frequent privileged ops; direct execution (C) would run the instruction unchecked, breaking isolation; shadow paging (D) deals with memory mapping, not instruction handling.

Q3. A cloud provider wants to run a hypervisor inside a guest VM to support nested virtualization. Which building block is essential to maintain performance and isolation for the inner guest?

🔹 A. Virtual CPU scheduler
🔹 B. I/O virtualization layer
🔹 C. Nested page tables
🔹 D. Hypervisor API

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The correct answer is C. Nested page tables extend the hardware paging mechanism to translate guest‑physical addresses to host‑physical addresses, allowing an inner guest to run with minimal overhead while preserving memory isolation. A virtual CPU scheduler (A) decides which VCPU runs but does not address address translation; an I/O virtualization layer (B) handles device access; a hypervisor API (D) provides management functions but does not implement the core memory mapping needed for nested virtualization. Therefore, nested page tables are essential for performance and isolation.

Q4. Why do type 0 hypervisors not require the same set of building blocks as type 1 hypervisors?

🔹 A. They run directly on hardware
🔹 B. They rely on a host operating system
🔹 C. They lack support for virtual machines
🔹 D. They operate only in user mode

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is A because a type 0 hypervisor, also called a bare‑metal hypervisor, runs directly on the physical hardware and therefore does not need the additional abstraction layers required by hosted hypervisors. Option B is false; type 0 does not rely on a host OS. Option C is incorrect because type 0 does support virtual machines. Option D misstates its mode of operation; it can manage both user and kernel modes. Hence, running on hardware eliminates many building‑block requirements.

Q5. Requiring an exact duplicate of the underlying machine increases which aspect of virtual machine monitor design?

🔹 A. Complexity of instruction‑set translation
🔹 B. Need for simple memory management
🔹 C. Ease of I/O handling
🔹 D. Ability to use high‑level languages

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The correct answer is A. Providing an exact replica of the underlying machine forces the VMM to translate every guest instruction to an equivalent host instruction, which greatly increases the complexity of the instruction‑set translation module. Simple memory management (B) becomes more difficult, not easier; I/O handling (C) remains a separate challenge; and using high‑level languages (D) does not alleviate the need for precise translation. Thus, the demand for exactness primarily impacts instruction translation complexity.

Q6. When virtualizing a system with distinct user and kernel modes, which statement best describes the hypervisor’s role?

🔹 A. It must trap privileged instructions
🔹 B. It can ignore mode differences
🔹 C. It only runs in user mode
🔹 D. It eliminates kernel mode

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The correct answer is A. To preserve isolation, a hypervisor must intercept (trap) any privileged instruction that would affect kernel state and then emulate its effect safely for the guest. Ignoring mode differences (B) would allow the guest to corrupt the host; running only in user mode (C) is impossible for a hypervisor that must control kernel resources; and eliminating kernel mode (D) contradicts the architecture of most CPUs. Therefore, trapping privileged instructions is essential.

Q7. What is the primary function of a hypervisor?

🔹 A. Software that creates and manages virtual machines
🔹 B. Physical server hardware
🔹 C. Network routing device
🔹 D. Database management system

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The correct answer is A. A hypervisor is software that creates, runs, and manages virtual machines, allowing multiple operating systems to share the same physical hardware. Options B, C, and D describe unrelated hardware or software components: a physical server, a network router, and a database system respectively. Understanding the hypervisor’s role is fundamental for any virtualization discussion today globally.
