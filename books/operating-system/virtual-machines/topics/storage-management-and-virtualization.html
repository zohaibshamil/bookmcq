📝 Storage management and Virtualization

📖 From Operating System • 16. Virtual Machines • 12 questions available

What is Storage management and Virtualization?

Definition:
Virtualized storage management abstracts physical disks into virtual volumes with features like thin provisioning, snapshots, and replication, decoupling VM storage from underlying hardware topology and enabling dynamic capacity adjustment.

Example:
vSphere VAAI primitives offload \( \texttt{WRITE\_SAME} \) operations to SAN arrays, reducing clone time of a \( 100 \) GB VM from \( 45 \) minutes to \( < 2 \) minutes by avoiding host-side data copying.

Reason:
Storage abstraction enables advanced data services independent of vendor hardware, simplifies capacity planning through overprovisioning, and accelerates VM lifecycle operations essential for agile infrastructure and disaster recovery.

Q1. What term describes the uncontrolled proliferation of virtual machines on a host?

A. Virtual machine sprawl ✅
B. Hypervisor
C. Partitioning
D. Guest OS

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Virtual machine sprawl is the term for an uncontrolled increase in the number of VMs on a host. It occurs when cloning and easy creation let administrators provision many machines without tracking their purpose. The other options describe different concepts: a hypervisor is the software layer that creates VMs; partitioning refers to dividing hardware; a guest OS is the operating system inside a VM. Recognizing the term helps IT staff design policies to limit unnecessary VMs and manage storage efficiently.

Q2. Why does a type 0 hypervisor typically provide each guest with dedicated CPU, memory, and I/O devices?

A. Because hardware enforces isolation
B. Because the OS manages resources
C. Because the VMM emulates devices
D. Because guests share resources ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

A type 0 hypervisor runs directly in firmware and assigns each guest its own physical CPU, memory, and I/O resources. Because the hardware itself isolates these components, the guest perceives dedicated hardware, simplifying driver design and eliminating the need for complex resource multiplexing. Options suggesting OS management or VMM emulation are incorrect because the hypervisor does not rely on software layers for isolation. Understanding this hardware‑based isolation explains why storage and device allocation are straightforward in type 0 environments.

Q3. A host has two physical Ethernet ports but must run four VMs each needing network access. Which solution best avoids performance bottleneck?

A. Assign each VM a dedicated port
B. Use I/O sharing via virtual NICs ✅
C. Install additional NICs
D. Disable network for two VMs

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When only two physical NICs exist but four VMs need network connectivity, the most scalable solution is to create virtual NICs that share the physical adapters through the hypervisor’s I/O‑sharing mechanisms. This allows each VM to appear to have its own network interface while the host efficiently multiplexes traffic. Assigning dedicated ports is impossible with only two NICs, installing more NICs adds hardware cost, and disabling network for some VMs defeats the requirement. Therefore, virtual NIC sharing best avoids performance bottlenecks.

Q4. How does cloning a virtual machine simplify deployment compared to building a physical machine?

A. Reduces hardware cost
B. Eliminates need for OS installation
C. Provides identical configuration quickly ✅
D. Increases security

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Cloning a virtual machine copies the entire disk image and configuration in a single operation, producing a new instance that is ready to run immediately. This eliminates the time‑consuming steps of installing an operating system, configuring storage, and setting up applications that are required when building a physical server from scratch. While reducing hardware cost is a benefit of virtualization, the speed and consistency of identical configurations are the primary reasons cloning simplifies deployment. The other options either describe unrelated advantages or do not directly address deployment efficiency.

Q5. When a VM is deleted, which order of operations ensures no leftover resources?

A. Remove config then free disk
B. Free disk then remove config ✅
C. Only remove config
D. Only free disk

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When a virtual machine is deleted, the VMM should first release the storage blocks that the VM's virtual disks occupy, ensuring that the physical disk space becomes available for other workloads. After the space is reclaimed, the VMM can safely remove the VM’s configuration files, network settings, and metadata. Deleting the configuration before freeing disk space could leave orphaned files that continue to occupy storage, while skipping the configuration removal would leave stale entries that complicate management. Therefore, freeing disk space then removing the configuration is the correct order.

Q6. A data center experiences storage exhaustion because many VMs retain large snapshots. Which policy would most effectively mitigate this?

A. Enforce snapshot size limit
B. Schedule regular VM deletions
C. Use thin provisioning ✅
D. Disable cloning

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Thin provisioning allocates virtual disk space on demand rather than reserving the full size up front, allowing many VMs to share the same physical storage pool efficiently. By limiting each VM to only the space it actually uses, the risk of exhausting host storage due to large, unused snapshots is reduced. Enforcing snapshot size limits helps but does not address already allocated space; scheduling deletions is reactive; disabling cloning removes a valuable feature. Hence, thin provisioning directly mitigates storage exhaustion while maintaining flexibility.

Q7. Explain why type 0 hypervisors have a smaller feature set than type 1 hypervisors.

A. Because they rely on firmware
B. Because they run in user space
C. Because they lack virtualization extensions
D. Because they are limited by hardware ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Type 0 hypervisors are implemented in firmware and rely on the processor’s virtualization extensions, which provide only the most basic mechanisms for partitioning resources. Because the hardware dictates what can be virtualized, the feature set is limited to essential functions such as allocating dedicated CPU, memory, and I/O. In contrast, type 1 hypervisors run as privileged software and can add advanced capabilities like live migration, sophisticated scheduling, and extensive device emulation. Therefore, the reliance on hardware constraints explains the smaller feature set of type 0 hypervisors.

Q8. A administrator wants to migrate a VM to another host without downtime. Which storage management technique should be used?

A. Live migration with shared storage ✅
B. Cold migration after shutdown
C. Snapshot export/import
D. Clone and redeploy

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Live migration moves a running VM’s memory and state to another host while keeping the VM operational, provided both hosts share the same storage repository. This technique avoids downtime because the VM continues to serve requests during the transfer. Cold migration requires shutting down the VM first, which introduces service interruption. Exporting a snapshot and importing it later also incurs downtime, and cloning creates a new VM rather than moving the existing one. Consequently, live migration with shared storage is the optimal method for moving a VM without downtime.

Q9. If a VM's virtual disk grows to fill the host's physical disk, what immediate action prevents data loss?

A. Increase host storage ✅
B. Shrink VM disk
C. Delete VM
D. Move VM to another host

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

If a VM’s virtual disk expands until the host’s physical storage is full, the immediate step is to increase the host’s available capacity, either by adding more disks or expanding existing storage arrays. Shrinking the VM disk while it is still in use risks data loss, and deleting the VM discards valuable workloads. Moving the VM to another host is possible but still requires additional storage on that host and does not address the root cause on the original server. Therefore, expanding host storage directly resolves the shortage.

Q10. How does virtual machine sprawl affect storage management policies?

A. Increases need for backup ✅
B. Reduces need for monitoring
C. Simplifies capacity planning
D. Decreases snapshot usage

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Virtual machine sprawl creates a large number of VMs, each with its own virtual disks, snapshots, and logs, dramatically increasing the amount of data the storage system must protect and retain. This growth forces administrators to allocate more backup windows, implement stricter retention policies, and monitor capacity more closely. While sprawl does not directly reduce the need for monitoring, it does not simplify capacity planning; instead, it makes forecasting storage requirements more complex and raises the risk of running out of space. Hence, sprawl directly impacts storage management policies.

Q11. A company uses type 0 hypervisor with four partitions, each with dedicated CPU and memory. They need to add a fifth VM. Which is the most feasible approach?

A. Add a new physical CPU
B. Reallocate memory from existing partitions ✅
C. Convert to type 1 hypervisor
D. Use nested virtualization

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

With a type 0 hypervisor that already dedicates CPU and memory to four partitions, adding a fifth VM cannot be done by simply attaching new physical CPUs unless the hardware is upgraded. The most practical approach is to rebalance memory among existing partitions, reducing the allocation to less‑critical VMs and freeing enough RAM for the new VM. Converting to a type 1 hypervisor or using nested virtualization would require significant redesign and may not be supported on the current firmware. Therefore, memory reallocation is the feasible solution.

Q12. What is the primary benefit of freeing disk space before removing VM configuration?

A. Prevents orphaned files ✅
B. Speeds up boot
C. Improves network latency
D. Enhances CPU performance

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Freeing the disk space occupied by a VM’s virtual disks before deleting its configuration ensures that no orphaned blocks remain on the physical storage, which could otherwise waste capacity and complicate future allocations. Removing the configuration first would leave those blocks allocated, making it appear that storage is still in use. While freeing space does not directly affect boot speed, network latency, or CPU performance, it preserves efficient storage utilization and simplifies subsequent provisioning. Thus, the primary benefit is preventing orphaned files.
