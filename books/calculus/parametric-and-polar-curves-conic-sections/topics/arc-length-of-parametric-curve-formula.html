What is Arc length of parametric curve formula?

Definition: For a parametric curve x=f(t),y=g(t) x=f(t), y=g(t) x=f(t),y=g(t) from t=a t=a t=a to t=b t=b t=b, the arc length is L=∫ab(f′(t))2+(g′(t))2 dt=∫ab(dx/dt)2+(dy/dt)2 dt L = \int_a^b \sqrt{(f'(t))^2 + (g'(t))^2} \, dt = \int_a^b \sqrt{(dx/dt)^2 + (dy/dt)^2} \, dt L=∫ab​(f′(t))2+(g′(t))2​dt=∫ab​(dx/dt)2+(dy/dt)2​dt.

Example: For x=3cos⁡t,y=3sin⁡t x = 3\cos t, y=3\sin t x=3cost,y=3sint (circle radius 3), dx/dt=−3sin⁡t,dy/dt=3cos⁡t dx/dt=-3\sin t, dy/dt=3\cos t dx/dt=−3sint,dy/dt=3cost, so L=∫02π9sin⁡2t+9cos⁡2t dt=∫02π3 dt=6π L = \int_0^{2\pi} \sqrt{9\sin^2 t + 9\cos^2 t} \, dt = \int_0^{2\pi} 3 \, dt = 6\pi L=∫02π​9sin2t+9cos2t​dt=∫02π​3dt=6π.

Reason: This formula sums infinitesimal straight-line distances (Pythagorean theorem) along the curve, giving total path length independent of parameterization.
