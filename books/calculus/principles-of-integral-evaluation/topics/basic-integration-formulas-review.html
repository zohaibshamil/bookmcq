What is Basic integration formulas review?

Definition:
Basic integration formulas are fundamental rules derived from differentiation that allow direct computation of antiderivatives for common functions like polynomials, exponentials, and trigonometric terms. Key formula: \( \int x^n \, dx = \frac{x^{n+1}}{n+1} + C \) for \( n \neq -1 \).

Example:
Integrating \( \int 3x^2 \, dx \) yields \( 3 \cdot \frac{x^3}{3} + C = x^3 + C \) by applying the power rule directly.

Reason:
These formulas serve as the foundational building blocks for calculus, enabling quick solutions for standard functions without needing complex decomposition or advanced techniques.

Q1. A student claims that \( \int \frac{1}{x} dx = \ln|x| + C \) and \( \int \frac{1}{x^2} dx = \frac{-1}{x} + C \) are both derived from the same power rule formula. Which of the following correctly analyzes this claim?

A.The claim is incorrect because the power rule \( \int u^r du = \frac{u^{r+1}}{r+1}+C \) only applies when \( r eq -1 \), and \( r=-1 \) is a special case handled by the logarithmic rule. ✅
B.The claim is correct because both integrals are derived from the power rule by choosing appropriate values of \( r \).
C.The claim is incorrect because the first integral is derived from the chain rule, while the second is from the power rule.
D.The claim is partially correct; both are derived from the power rule, but the constant of integration differs.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The power rule for integration is \( \int u^r du = \frac{u^{r+1}}{r+1} + C \), which is valid for all real numbers \( r eq -1 \). The case \( r=-1 \) gives \( \int \frac{1}{u} du = \ln|u| + C \), which is a separate formula. The student's claim is incorrect because the power rule formula fails at \( r=-1 \) due to division by zero. Recognizing this exceptional case is crucial for avoiding a common error.

Q2. Evaluate \( \int \frac{3x^2 - 2x + 1}{x} dx \).

A.\( x^3 - 2x + \ln|x| + C \) ✅
B.\( x^3 - 2x^2 + x + C \)
C.\( \frac{3}{2}x^2 - 2x + \ln|x| + C \)
D.\( x^3 - 2x + \frac{x^2}{2} + C \)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: To solve this, we first simplify the integrand by dividing each term in the numerator by \( x \): \( \frac{3x^2}{x} - \frac{2x}{x} + \frac{1}{x} = 3x - 2 + \frac{1}{x} \). Then, we integrate term by term: \( \int 3x dx = \frac{3x^2}{2} \), \( \int -2 dx = -2x \), and \( \int \frac{1}{x} dx = \ln|x| \). Combining these gives \( \frac{3}{2}x^2 - 2x + \ln|x| + C \). Thus, option A is correct.

Q3. Which of the following is the correct antiderivative of \( \sec^2(2x) \)?

Q4. A particle moves with acceleration \( a(t) = e^{2t} \). If its velocity at \( t=0 \) is 0, what is its velocity function?

💡 Difficulty: easy | ✅ Correct: A

Using the initial condition \( v(0)=0 \), we get \( 0 = \frac{1}{2}e^{0} + C = \frac{1}{2} + C \), so \( C = -\frac{1}{2} \). Therefore, \( v(t) = \frac{1}{2}e^{2t} - \frac{1}{2} \). Option A is correct. This problem combines integration with an initial condition, a common Easy in physics.

Q6. Which of the following integrals requires an algebraic manipulation before it can be directly integrated using the basic power rule?

Q7. Let \( F(x) \) be an antiderivative of \( f(x) \). If \( f(x) = \frac{d}{dx} [x \ln x - x] \), what is \( F(x) \)?

A.\( \ln x \)
B.\( x \ln x - x + C \) ✅
C.\( \frac{1}{x} \)
D.\( x \ln x + C \)
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: If \( f(x) = \frac{d}{dx} [x \ln x - x] \), then \( F(x) \) is the antiderivative of \( f(x) \). Since \( f(x) \) is the derivative of \( x \ln x - x \), the antiderivative is \( x \ln x - x + C \). The derivative of \( x \ln x - x \) is \( \ln x + 1 - 1 = \ln x \). Thus, \( f(x) = \ln x \), and \( \int \ln x dx = x \ln x - x + C \). Option B is correct, testing the inverse relationship between differentiation and integration.
