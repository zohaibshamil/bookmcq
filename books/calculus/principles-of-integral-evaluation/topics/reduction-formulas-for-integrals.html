📖 Explanation: When using reduction formulas, the focus is on reducing the integral to a simpler form. The constant of integration is not added during the intermediate steps. Once the final integral is evaluated, the constant of integration, +C, is added to the final antiderivative to represent the most general solution. Adding it at each step is unnecessary and can complicate the process.

Q33. A student is evaluating ∫tan⁴x dx. Which of the following represents the first Easy of the reduction formula?

A.(tan³x)/3 - ∫tan²x dx ✅
B.(tan³x)/3 + ∫tan²x dx
C.(tan⁴x)/4 - ∫tan²x dx
D.(tan²x)/2 - ∫tan²x dx
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The reduction formula for tanⁿ is ∫tanⁿx dx = (tanⁿ⁻¹x)/(n-1) - ∫tanⁿ⁻²x dx. For n=4, this gives (tan³x)/3 - ∫tan²x dx. Option A is correct. Option B has the wrong sign. Option C uses the wrong coefficient. Option D uses the formula for n=3 instead of n=4. This tests the ability to correctly apply the formula for a given n.

Q34. A student is evaluating ∫sin⁶x dx. They decide to rewrite it as ∫(sin²x)³ dx and integrate using the power rule. What is the error in this approach?

A.The power rule for integration cannot be applied to a function raised to a power.
B.The power rule for integration applies only to xⁿ, not to sinⁿx. ✅
C.The power rule for integration applies only to polynomials.
D.There is no error; this is a valid technique.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The power rule for integration, ∫uⁿ du = uⁿ⁺¹/(n+1) + C, applies when the variable of integration is u. In ∫sin⁶x dx, the variable of integration is x, but the base of the power is sinx. To use the power rule, the integrand would need to be sin⁶x * cosx, so that du = cosx dx. The student is incorrectly treating sinx as the variable of integration. Option B correctly identifies this misconception.

Q35. A reduction formula for ∫xⁿ sinx dx is given. How would you use it to evaluate ∫x³ sinx dx?

When n=0, the integral becomes ∫sinx dx, which is a standard integral. Option A describes this iterative process correctly. The power of x, not sinx, is being reduced.

Q36. When deriving the reduction formula for ∫cosⁿx dx, what is the purpose of the identity sin²x = 1 - cos²x?

A.To eliminate sin²x from the expression after integration by parts. ✅
B.To substitute sin²x for cos²x.
C.To simplify the coefficient of the integral.
D.To change the variable of integration.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: After applying integration by parts with u=cosⁿ⁻¹x and dv=cosx dx, we get an integral with sin²x cosⁿ⁻²x. To express this entirely in terms of cosx, we replace sin²x with 1 - cos²x. This allows us to combine terms with cosⁿx and cosⁿ⁻²x, which is necessary to solve for the original integral. This step is crucial for deriving the formula.
