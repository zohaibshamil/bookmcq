What is Integral Tables?

Definition:
Integral tables list standard forms and their solutions, serving as a reference for matching given integrals to known patterns, often requiring minor algebraic adjustments to fit the table format.

Example:
Matching \( \int \frac{dx}{\sqrt{a^2-x^2}} \) to the table entry \( \arcsin(\frac{x}{a}) + C \) provides the immediate solution without derivation.

Reason:
Tables offer quick access to common results, bypassing repetitive derivations and ensuring accuracy for standard integral forms encountered frequently in calculus.

Q1. A student is evaluating \(\int x^2 \sin x \, dx\) and uses the Endpaper Integral Table. The table entry is \(\int u^2 \sin u \, du = -u^2 \cos u + 2u \sin u + 2 \cos u + C\). What is the correct antiderivative?

A.\(-x^2 \cos x + 2x \sin x + 2 \cos x + C\) ✅
B.\(-x^2 \cos x + 2x \sin x - 2 \cos x + C\)
C.\(x^2 \cos x + 2x \sin x - 2 \cos x + C\)
D.\(-x^2 \cos x - 2x \sin x - 2 \cos x + C\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The table formula is a perfect match with \(u = x\). The integral of \(u^2 \sin u\) is correctly given as \(-u^2 \cos u + 2u \sin u + 2 \cos u + C\). Students often make sign errors with the cosine term or forget the factor of 2 in the \(\sin\) term, so this tests the ability to correctly apply a standard formula.

Q2. To evaluate \(\int x \sqrt{x^2 - 4x + 5} \, dx\), a student completes the square: \(x^2 - 4x + 5 = (x-2)^2 + 1\). Which of the following is the correct first step after the substitution \(u = x - 2\)?

A.\(\int (u+2) \sqrt{u^2 + 1} \, du\) ✅
B.\(\int u \sqrt{u^2 + 1} \, du\)
C.\(\int (u-2) \sqrt{u^2 + 1} \, du\)
D.\(\int (u^2 + 4u + 4) \sqrt{u^2 + 1} \, du\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Letting \(u = x-2\) gives \(x = u+2\) and \(dx = du\). The integral becomes \(\int (u+2) \sqrt{u^2+1} \, du\). This is the correct setup to split into two integrals, \(\int u \sqrt{u^2+1} \, du + 2 \int \sqrt{u^2+1} \, du\). A common mistake is forgetting to change the factor \(x\) to \(u+2\), leading to option B, which would be incorrect.

Q3. An engineer is evaluating \(\int \frac{dx}{x^2 \sqrt{x^2 - 2}}\) and uses the substitution \(x = \sqrt{2} \sec \theta\). The integral transforms to \(\frac{1}{2} \int \sin \theta \, d\theta\). The result from the table is \(-\frac{1}{2} \cos \theta + C\). Which of the following is the final answer in terms of \(x\)?

A.\(-\frac{\sqrt{x^2 - 2}}{2x} + C\) ✅
B.\(-\frac{x}{2\sqrt{x^2 - 2}} + C\)
C.\(\frac{\sqrt{x^2 - 2}}{2x} + C\)
D.\(\frac{x}{2\sqrt{x^2 - 2}} + C\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: After integrating, we get \(-\frac{1}{2} \cos \theta + C\). From the triangle for \(x = \sqrt{2} \sec \theta\), \(\cos \theta = \frac{\sqrt{2}}{x}\). Substituting gives \(-\frac{\sqrt{2}}{2x} + C\), but this simplifies to \(-\frac{\sqrt{x^2-2}}{2x} + C\) after rationalizing. Students often incorrectly invert the trigonometric ratio or fail to simplify.

Q4. A CAS returns \(\int e^{2x} \cos x \, dx = \frac{e^{2x}}{5}(2 \cos x + \sin x) + C\). The Endpaper Integral Table has \(\int e^{au} \cos bu \, du = \frac{e^{au}}{a^2+b^2}(a \cos bu + b \sin bu) + C\). Which of the following is the correct Easy?

A.\(a=2, b=1\) ✅
B.\(a=1, b=2\)
C.\(a=2, b=-1\)
D.\(a=1, b=-2\)
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The integral is \(\int e^{2x} \cos x \, dx\). Comparing to \(\int e^{au} \cos(bu) \, du\), we have \(a=2\) and \(b=1\). The formula gives \(\frac{e^{2x}}{4+1}(2\cos x + \sin x) + C\). Option A is correct. A common error is to confuse the coefficients of the exponential and the trigonometric functions, leading to option B. The sign of \(b\) is handled by the formula, so options C and D are also common mistakes.

Q5. Which of the following substitutions is most appropriate to evaluate \(\int \frac{dx}{x(4x+3)}\) using an integral table?

A.\(u = 4x+3\) ✅
B.\(u = \sqrt{x}\)
C.\(u = \tan(x/2)\)
D.\(u = \sin x\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The integral is a rational function in \(x\). The substitution \(u = 4x+3\) simplifies the denominator to a linear term, but the \(x\) in the denominator remains. However, it is a standard technique to use partial fractions or a substitution like \(u = 4x+3\) to reduce it to a form that matches the table entry \(\int \frac{du}{u(a+bu)}\). The other substitutions are for trigonometric or radical forms, which are not appropriate here.

Q6. A student is evaluating \(\int \cos 5x \cos 3x \, dx\). The Endpaper Integral Table has \(\int \cos mx \cos nx \, dx = \frac{\sin(m-n)x}{2(m-n)} + \frac{\sin(m+n)x}{2(m+n)} + C\). What is the correct result for \(m=5, n=3\)?

A.\(\frac{\sin 2x}{4} + \frac{\sin 8x}{16} + C\) ✅
B.\(\frac{\sin 2x}{2} + \frac{\sin 8x}{8} + C\)
C.\(\frac{\sin 2x}{4} - \frac{\sin 8x}{16} + C\)
D.\(\frac{\sin 2x}{2} - \frac{\sin 8x}{8} + C\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Substituting \(m=5, n=3\) into the formula gives \(\frac{\sin(2x)}{2(2)} + \frac{\sin(8x)}{2(8)} + C = \frac{\sin 2x}{4} + \frac{\sin 8x}{16} + C\). The most common mistakes are forgetting to multiply by 2 in the denominator or using the wrong sign. This tests the ability to correctly use a standard product-to-sum formula.

Q7. To evaluate \(\int \frac{x}{x^2 - 6x + 13} \, dx\), completing the square gives \(x^2 - 6x + 13 = (x-3)^2 + 4\). What is the correct result?

A.\(\frac{1}{2} \ln(x^2 - 6x + 13) + \frac{3}{2} \tan^{-1}\left(\frac{x-3}{2}\right) + C\) ✅
B.\(\ln(x^2 - 6x + 13) + \tan^{-1}(x-3) + C\)
C.\(\frac{1}{2} \ln(x^2 - 6x + 13) + \tan^{-1}(x-3) + C\)
D.\(\ln(x^2 - 6x + 13) + \frac{3}{2} \tan^{-1}\left(\frac{x-3}{2}\right) + C\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Let \(u = x-3\). Then \(x = u+3\) and \(dx = du\), so the integral becomes \(\int \frac{u+3}{u^2+4} du = \frac{1}{2} \ln(u^2+4) + \frac{3}{2} \tan^{-1}(u/2) + C\). Substituting back gives option A. Common errors include forgetting the constant multiplier in the \(\ln\) term (option D) or in the \(\tan^{-1}\) term (option C), or both (option B).

Q8. Which of the following integrals is most efficiently evaluated using an integral table by first applying a \(u\)-substitution?

A.\(\int \sin(\ln x) \, dx\) ✅
B.\(\int x \cos x \, dx\)
C.\(\int \frac{x}{x^2+1} \, dx\)
D.\(\int \sin^2 x \, dx\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The integral \(\int \sin(\ln x) \, dx\) is not a simple table match. A substitution like \(u = \ln x\) transforms it to \(\int e^u \sin u \, du\), which is a standard form in integral tables (exponential times sine/cosine). The others are either direct table matches or simple substitutions. This question tests the student's ability to recognize when a preliminary substitution is necessary to make an integral match a table form.

Q9. A student incorrectly evaluates \(\int \tan^2 x \sec^4 x \, dx\) as \(\frac{\tan^5 x}{5} + \frac{\tan^3 x}{3} + C\). What error did they make?

A.They used the substitution \(u = \tan x\) but forgot to include a factor of \(\sec^2 x\).
B.They used the wrong reduction formula.
C.They failed to apply the identity \(\sec^2 x = \tan^2 x + 1\).
D.They correctly evaluated the integral. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The integral \(\int \tan^2 x \sec^4 x \, dx = \int \tan^2 x \sec^2 x \sec^2 x \, dx\). Let \(u = \tan x\), then \(\sec^2 x \, dx = du\) and \(\sec^2 x = u^2 + 1\). The integral becomes \(\int u^2 (u^2+1) du = \frac{u^5}{5} + \frac{u^3}{3} + C = \frac{\tan^5 x}{5} + \frac{\tan^3 x}{3} + C\). The student's result is correct. The question is designed to test the understanding of the method. Option A describes a common error but doesn't apply here.

Q10. The graph of \(y = \sin x\) from \(x=0\) to \(x=\pi\) is revolved about the x-axis. The volume is \(V = \pi \int_0^\pi \sin^2 x \, dx\). Using the table, \(\int \sin^2 x \, dx = \frac{x}{2} - \frac{\sin 2x}{4} + C\). What is the volume?

A.\(\frac{\pi^2}{2}\) ✅
B.\(\frac{\pi}{2}\)
C.\(\pi^2\)
D.\(\frac{\pi^2}{4}\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The integral \(\int_0^\pi \sin^2 x \, dx = \left[\frac{x}{2} - \frac{\sin 2x}{4}\right]_0^\pi = \frac{\pi}{2}\). Therefore, \(V = \pi \cdot \frac{\pi}{2} = \frac{\pi^2}{2}\). A common mistake is to compute the integral as \(\frac{\pi}{2}\) and forget to multiply by the factor of \(\pi\) from the volume formula, leading to option B. Others may make errors in the antiderivative evaluation.

Q11. To evaluate \(\int \sqrt{1-x^2} \, dx\) using a table, one can substitute \(x = \sin \theta\). The integral becomes \(\int \cos^2 \theta \, d\theta\). The table gives \(\int \cos^2 \theta \, d\theta = \frac{\theta}{2} + \frac{\sin 2\theta}{4} + C\). Which of the following is the final answer?

A.\(\frac{1}{2} \sin^{-1} x + \frac{x}{2} \sqrt{1-x^2} + C\) ✅
B.\(\frac{1}{2} \sin^{-1} x + \frac{x}{2} \sqrt{1-x^2} + C\)
C.\(\sin^{-1} x + x \sqrt{1-x^2} + C\)
D.\(\frac{1}{2} \sin^{-1} x + \frac{x}{2} \sqrt{1-x^2} + C\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: After integrating, we get \(\frac{\theta}{2} + \frac{\sin 2\theta}{4} + C\). Using \(\sin 2\theta = 2\sin\theta \cos\theta = 2x\sqrt{1-x^2}\), we get \(\frac{1}{2}\sin^{-1}x + \frac{x\sqrt{1-x^2}}{2} + C\). Option A is correct. Option B is the same. Option C is missing the factor of \(1/2\) and the inverse sine term is incorrect. This tests the ability to convert back from \(\theta\) to \(x\) correctly.

Q12. A student uses the table formula \(\int \frac{du}{\sqrt{a^2 - u^2}} = \sin^{-1}\left(\frac{u}{a}\right) + C\) to evaluate \(\int \frac{dx}{\sqrt{4 - 9x^2}}\). What should they set \(u\) and \(a\) to?

A.\(u = 3x, a = 2\) ✅
B.\(u = 2x, a = 3\)
C.\(u = 9x, a = 4\)
D.\(u = 4x, a = 9\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: To match \(\int \frac{du}{\sqrt{a^2 - u^2}}\), we need \(a^2 = 4\) so \(a=2\), and \(u^2 = 9x^2\) so \(u=3x\). Then \(du = 3 \, dx\), and the integral becomes \(\frac{1}{3} \int \frac{du}{\sqrt{4-u^2}} = \frac{1}{3} \sin^{-1}(u/2) + C\). A common error is to take \(u=2x\) and \(a=3\) or to not account for the \(du\) factor, making option A the correct choice.

Q13. Which of the following is NOT a valid approach to evaluate \(\int \sqrt{x^2 - a^2} \, dx\) using an integral table?

A.Use the substitution \(x = a \cosh u\) and the identity \(\cosh^2 u - \sinh^2 u = 1\).
B.Use the substitution \(x = a \sec \theta\).
C.Look up the formula directly in the table.
D.Use the substitution \(x = a \sin \theta\). ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The expression \(\sqrt{x^2 - a^2}\) is typically handled using the trigonometric substitution \(x = a \sec \theta\) or the hyperbolic substitution \(x = a \cosh u\). The substitution \(x = a \sin \theta\) is used for \(\sqrt{a^2 - x^2}\). Option D is incorrect because it would lead to a simplification to \(\sqrt{a^2 \sin^2 \theta - a^2} = a\sqrt{-\cos^2 \theta}\), which is not a real function.

Q14. A physics student is evaluating \(\int \frac{dx}{x^2 - 4x + 8}\) and completes the square to get \(\int \frac{dx}{(x-2)^2 + 4}\). Which table formula should they use?

A.\(\int \frac{du}{u^2 + a^2} = \frac{1}{a} \tan^{-1}\left(\frac{u}{a}\right) + C\) ✅
B.\(\int \frac{du}{u^2 - a^2} = \frac{1}{2a} \ln\left|\frac{u-a}{u+a}\right| + C\)

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: After completing the square, the integral is of the form \(\int \frac{du}{u^2 + a^2}\) where \(u = x-2\) and \(a=2\). This matches the table formula for the arctangent. Option B is for a difference of squares, C for a reciprocal square root, and D for a reciprocal square root of the form \(\sqrt{a^2-u^2}\). This tests the ability to classify integrands and select the correct table entry.

Q15. The table formula \(\int \frac{du}{u\sqrt{u^2 + a^2}} = -\frac{1}{a} \ln\left|\frac{a + \sqrt{u^2 + a^2}}{u}\right| + C\) is used to evaluate \(\int \frac{dx}{x\sqrt{x^2 + 9}}\). What is the correct antiderivative?

A.\(-\frac{1}{3} \ln\left|\frac{3 + \sqrt{x^2 + 9}}{x}\right| + C\) ✅

C.\(\frac{1}{3} \ln\left|\frac{3 + \sqrt{x^2 + 9}}{x}\right| + C\)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Matching the integral to the formula, we have \(a=3\) and \(u=x\). The antiderivative is \(-\frac{1}{3} \ln\left|\frac{3 + \sqrt{x^2+9}}{x}\right| + C\). Option B is incorrect because it inverts the fraction, and option C has the wrong sign. Students often make sign errors or forget the factor of \(1/a\).

Q16. A student is evaluating \(\int x^3 e^{x^2} \, dx\). The table has \(\int u e^{au} \, du = \frac{e^{au}}{a^2}(au-1) + C\). Which substitution is needed?

A.\(u = x^2\) ✅
B.\(u = x^3\)
C.\(u = e^{x^2}\)
D.\(u = x\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Let \(u = x^2\). Then \(du = 2x \, dx\) and \(x^3 \, dx = x^2 \cdot x \, dx = u \cdot \frac{du}{2} = \frac{u}{2} du\). The integral becomes \(\frac{1}{2} \int u e^{u} \, du\), which matches the table with \(a=1\). A common mistake is to not see the needed substitution or to incorrectly transform the differential. This tests the ability to combine substitution with table formulas.

Q17. Which of the following integrals would require using the LIATE rule to choose \(u\) and \(dv\) for integration by parts, but the table formula itself is the result of integration by parts?

A.\(\int x \ln x \, dx\)
B.\(\int \ln x \, dx\) ✅

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The integral \(\int \ln x \, dx\) is a classic example where integration by parts is used with \(u = \ln x\) and \(dv = dx\). The result is \(x \ln x - x + C\). The table formula for \(\int \ln u \, du\) is derived from integration by parts. While the others also use integration by parts, the \(\int \ln x \, dx\) is the most direct and fundamental Easy. This tests the understanding of where table formulas come from.

Q18. To approximate \(\int_0^1 e^{-x^2} \, dx\) using Simpson's rule, a student uses \(n=10\). They first approximate \(\int_0^K e^{-x^2} \, dx\) and then use a truncation error. The truncation error is \(E = \int_K^\infty e^{-x^2} \, dx\). Which of the following correctly describes the total error?

A.Total error = Simpson's rule error + Truncation error ✅
B.Total error = Simpson's rule error - Truncation error
C.Total error = Truncation error - Simpson's rule error
D.Total error = Simpson's rule error \(\times\) Truncation error
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: When using numerical integration for an improper integral, the total error is the sum of the approximation error (Simpson's rule) and the truncation error from discarding the tail of the infinite interval. These errors are additive in a worst-case sense. Option A is correct. This question connects two concepts: improper integrals and numerical integration.

The other options are not efficient or appropriate first steps. This tests the ability to recognize the need for completing the square.

Q20. The Endpaper Integral Table lists \(\int \sec x \, dx = \ln|\sec x + \tan x| + C\). Another formula is \(\int \sec x \, dx = \ln|\tan(\pi/4 + x/2)| + C\). Are these two formulas equivalent?

This question tests the understanding that different-looking results can be equivalent, a key concept when using tables or CAS. Option C is tempting but the identity holds for all \(x\) where both are defined.

Q21. A student is evaluating \(\int \frac{dx}{x\sqrt{4-x^2}}\) and uses a table formula incorrectly, getting \(-\frac{1}{2} \ln\left|\frac{2 + \sqrt{4-x^2}}{x}\right| + C\). The correct formula is \(\int \frac{du}{u\sqrt{a^2-u^2}} = -\frac{1}{a} \ln\left|\frac{a + \sqrt{a^2-u^2}}{u}\right| + C\). What did they do wrong?

The student's result has a factor of \(1/2\) but it should be \(1/2\) not \(1\). The coefficient in front of the logarithm should be \(-1/2\). The student might have thought \(a=1\), which is a common error when the integrand is not perfectly matched. This tests the ability to identify constants in table formulas.

Q22. The integral \(\int \frac{dx}{x^2+4x+5}\) is evaluated. Which substitution would transform it into a form that matches the table formula for arctangent?

Option C would introduce a factor of 2, but \(u = (x+2)/2\) would make \(du = dx/2\) and the denominator would be \(4u^2+1\), requiring an extra factor. The simplest substitution is \(u=x+2\).

Q23. A student uses the table formula \(\int \frac{du}{u^2-a^2} = \frac{1}{2a} \ln\left|\frac{u-a}{u+a}\right| + C\) to evaluate \(\int \frac{dx}{x^2-4}\). They get \(\frac{1}{4} \ln\left|\frac{x-2}{x+2}\right| + C\). Is this correct?

Option B is incorrect because it uses \(\frac{1}{2}\), which would be for \(a=1\). Option C has the fraction inverted. This tests the correct Easy of the formula and the ability to calculate \(1/(2a)\).

Q24. Which of the following is the correct identity to use when evaluating \(\int \sin^2 x \cos^2 x \, dx\) using an integral table?

A.\(\sin^2 x \cos^2 x = \frac{1}{4} \sin^2 2x\)

💡 Difficulty: medium | ✅ Correct: D

The third option is also correct because \(\sin^2 2x = 1 - \cos^2 2x\), so \(\frac{1}{4}(1 - \cos^2 2x)\) is also valid. This question tests the ability to use and manipulate trigonometric identities to make an integral match a table form. Option D is correct because all are true identities.

Q25. An economist uses the integral \(\int_0^\infty e^{-st} t^n \, dt = \frac{n!}{s^{n+1}}\) in a model. This formula is not in a basic table but can be derived using integration by parts. Which of the following is the correct derivation step?

A.\(\int_0^\infty e^{-st} t^n \, dt = \left[-\frac{t^n}{s} e^{-st}\right]_0^\infty + \frac{n}{s} \int_0^\infty e^{-st} t^{n-1} \, dt\) ✅
B.\(\int_0^\infty e^{-st} t^n \, dt = \left[-\frac{t^n}{s} e^{-st}\right]_0^\infty - \frac{n}{s} \int_0^\infty e^{-st} t^{n-1} \, dt\)
C.\(\int_0^\infty e^{-st} t^n \, dt = \left[\frac{t^n}{s} e^{-st}\right]_0^\infty + \frac{n}{s} \int_0^\infty e^{-st} t^{n-1} \, dt\)
D.\(\int_0^\infty e^{-st} t^n \, dt = \left[\frac{t^n}{s} e^{-st}\right]_0^\infty - \frac{n}{s} \int_0^\infty e^{-st} t^{n-1} \, dt\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Using integration by parts with \(u = t^n\) and \(dv = e^{-st} dt\), we get \(du = n t^{n-1} dt\) and \(v = -\frac{1}{s} e^{-st}\). The integral becomes \(\left[-\frac{t^n}{s} e^{-st}\right]_0^\infty - \int_0^\infty \left(-\frac{1}{s} e^{-st}\right) (n t^{n-1}) dt = \left[-\frac{t^n}{s} e^{-st}\right]_0^\infty + \frac{n}{s} \int_0^\infty e^{-st} t^{n-1} dt\). Option A is correct. This is a difficult problem involving an improper integral, integration by parts, and a reduction formula.

Q26. A student is evaluating \(\int \frac{x}{\sqrt{x^2+1}} \, dx\) using a table. The table has \(\int \frac{du}{\sqrt{u^2+a^2}} = \ln(u+\sqrt{u^2+a^2}) + C\). To use it, they should let \(u = x^2+1\). Is this correct?

A.No, the derivative of \(u = x^2+1\) is \(2x\), not \(\frac{x}{2\sqrt{x^2+1}}\).
B.Yes, because \(du = 2x \, dx\) and the integral becomes \(\frac{1}{2} \int \frac{du}{\sqrt{u}}\).
C.Yes, but they must first use the substitution \(u = \sqrt{x^2+1}\).
D.No, the integral is a direct derivative and doesn't need a table. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The integral \(\int \frac{x}{\sqrt{x^2+1}} \, dx\) can be solved by a simple substitution \(u = x^2+1\), giving \(\frac{1}{2} \int \frac{du}{\sqrt{u}} = \sqrt{u} + C = \sqrt{x^2+1} + C\). It is a direct match to a power rule and does not require the more complex logarithmic table formula. Option D is correct. A common mistake is to overcomplicate the problem and use an inappropriate table formula. This tests the ability to recognize simple integrals.

Q27. The graph of \(y = \frac{1}{x}\) from \(x=1\) to \(x=b\) has an area \(\ln b\). For the improper integral \(\int_1^\infty \frac{1}{x} \, dx\), which of the following is true?

A.The integral diverges because \(\lim_{b\to\infty} \ln b = \infty\). ✅
B.The integral converges to 1.
C.The integral converges to 0.
D.The integral diverges because the area under the curve is infinite.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The area under \(y=1/x\) from 1 to \(b\) is \(\ln b\). As \(b \to \infty\), \(\ln b \to \infty\). Therefore, the improper integral diverges. Option A is correct. Option B is incorrect because it confuses the integral with \(\int_1^\infty 1/x^2 \, dx\), which converges to 1. This tests the ability to interpret graphical area as an improper integral and to understand divergence.

Q28. A student uses the table formula \(\int \frac{du}{u(a+bu)} = \frac{1}{a} \ln\left|\frac{u}{a+bu}\right| + C\) to evaluate \(\int \frac{dx}{x(2+3x)}\). What is the correct antiderivative?

A.\(\frac{1}{2} \ln\left|\frac{x}{2+3x}\right| + C\) ✅
B.\(\frac{1}{3} \ln\left|\frac{x}{2+3x}\right| + C\)
C.\(\ln\left|\frac{x}{2+3x}\right| + C\)
D.\(\frac{1}{2} \ln\left|2+3x\right| + C\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Here \(a=2\) and \(b=3\). The formula gives \(\frac{1}{a} \ln\left|\frac{u}{a+bu}\right| = \frac{1}{2} \ln\left|\frac{x}{2+3x}\right| + C\). Option A is correct. Option B uses \(1/b\) instead of \(1/a\). Option C misses the \(1/2\) factor. This tests the correct substitution of constants into a formula.

Q29. A student is using a table of integrals and finds the entry \(\int \frac{du}{\sqrt{u^2 \pm a^2}}\). They are confused about the sign. Which of the following is true?

A.For \(\sqrt{u^2 - a^2}\), the substitution is \(u = a \sec \theta\). ✅
B.For \(\sqrt{u^2 + a^2}\), the substitution is \(u = a \sin \theta\).
C.For \(\sqrt{a^2 - u^2}\), the substitution is \(u = a \tan \theta\).
D.For \(\sqrt{u^2 - a^2}\), the result is \(\sin^{-1}(u/a) + C\).
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: For \(\sqrt{u^2 - a^2}\), the standard trigonometric substitution is \(u = a \sec \theta\), leading to \(\tan \theta\). For \(\sqrt{u^2 + a^2}\), it's \(u = a \tan \theta\). For \(\sqrt{a^2 - u^2}\), it's \(u = a \sin \theta\). Option A is correct. The other options are common mis-matches of substitutions to forms. This tests the foundational knowledge of trigonometric substitutions.

Q30. The integral \(\int \frac{dx}{x^2+2x+2}\) is evaluated. Which of the following is the correct result after completing the square?

A.\(\tan^{-1}(x+1) + C\) ✅
B.\(\tan^{-1}\left(\frac{x+1}{\sqrt{2}}\right) + C\)
C.\(\tan^{-1}(x+1) + C\)
D.\(\frac{1}{2} \tan^{-1}\left(\frac{x+1}{2}\right) + C\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Completing the square: \(x^2+2x+2 = (x+1)^2 + 1\). The integral becomes \(\int \frac{dx}{(x+1)^2+1} = \tan^{-1}(x+1) + C\). Option A is correct. Option B would be for \((x+1)^2+2\). Option D is for \(x^2+2x+5\). This tests the ability to complete the square and correctly use the arctangent formula.

Q31. Which of the following is a valid method to evaluate \(\int \frac{dx}{a+b \sin x}\) using an integral table?

A.Use the substitution \(u = \tan(x/2)\) and then use partial fractions. ✅
B.Use the substitution \(x = \sin \theta\).
C.Use the substitution \(u = \sin x\).
D.Use the substitution \(u = \cos x\).
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The integral of a rational function of \(\sin x\) and \(\cos x\) can be tackled by the Weierstrass substitution \(u = \tan(x/2)\). This transforms it into an integral of a rational function of \(u\), which can be evaluated using partial fractions and table formulas. The other substitutions are not generally applicable to this form. This tests the knowledge of special substitutions for trigonometric integrals.

Q32. A student is evaluating \(\int \frac{\sqrt{x^2-4}}{x} \, dx\) using a table. They use the formula \(\int \frac{\sqrt{u^2-a^2}}{u} du = \sqrt{u^2-a^2} - a \sec^{-1}(u/a) + C\). With \(a=2\), what is the correct antiderivative?

A.\(\sqrt{x^2-4} - 2 \sec^{-1}(x/2) + C\) ✅
B.\(\sqrt{x^2-4} - \frac{1}{2} \sec^{-1}(x/2) + C\)
C.\(\sqrt{x^2-4} - 2 \sec^{-1}(x) + C\)
D.\(\sqrt{x^2-4} + 2 \sec^{-1}(x/2) + C\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: With \(a=2\), the formula gives \(\sqrt{x^2-4} - 2 \sec^{-1}(x/2) + C\). Option A is correct. Option B has the wrong coefficient for the inverse secant. Option C uses \(x\) instead of \(x/2\). Option D has the wrong sign. This tests the correct Easy of a formula and the substitution of constants.

Q33. The table formula \(\int \ln u \, du = u \ln u - u + C\) is used to evaluate \(\int \ln(x+1) \, dx\). Which of the following is the correct antiderivative?

A.\((x+1)\ln(x+1) - (x+1) + C\) ✅
B.\(x \ln(x+1) - x + C\)
C.\((x+1)\ln(x+1) - x + C\)
D.\(\ln(x+1) - 1 + C\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Let \(u = x+1\), then \(du = dx\). The integral becomes \(\int \ln u \, du = u \ln u - u + C = (x+1)\ln(x+1) - (x+1) + C\). Option A is correct. Option B is a common mistake where the student incorrectly integrates without changing the variable. This tests the understanding of the substitution in a table formula.

Q34. A student uses a CAS to evaluate \(\int e^{x^2} \, dx\) and gets an answer involving the error function (erf). This is an example of:

A.An integral that cannot be expressed in terms of elementary functions. ✅
B.An error in the CAS algorithm.
C.An improper integral.
D.An integral that requires integration by parts.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The integral \(\int e^{x^2} \, dx\) is a classic example of a non-elementary integral. It cannot be expressed in terms of polynomials, exponentials, logarithms, trigonometric functions, etc. The error function is a special function defined for this purpose. This question tests the understanding of the limitations of elementary functions and the role of CAS and tables. Option A is correct.

Q35. Which of the following integrals would be most appropriately solved by first making the substitution \(u = e^x\) and then using an integral table?

A.\(\int \sqrt{1+e^x} \, dx\) ✅
B.\(\int \frac{e^x}{e^{2x}+1} \, dx\)
C.\(\int e^x \sin x \, dx\)
D.\(\int \frac{1}{e^x + e^{-x}} \, dx\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The integral \(\int \sqrt{1+e^x} \, dx\) becomes \(\int \frac{\sqrt{1+u}}{u} du\) after \(u = e^x\). This is a standard form in tables (e.g., \(\int \frac{\sqrt{a+bu}}{u} du\)). The others are either direct matches, simple substitutions, or standard forms. This tests the ability to recognize when a substitution will bring an integral into a table form.

Q36. The integral \(\int \frac{dx}{x^2 \sqrt{9-x^2}}\) is evaluated using a trigonometric substitution. The table formula \(\int \csc^2 \theta \, d\theta = -\cot \theta + C\) is used. What is the correct final answer in terms of \(x\)?

A.\(-\frac{\sqrt{9-x^2}}{9x} + C\) ✅
B.\(-\frac{\sqrt{9-x^2}}{3x} + C\)
C.\(\frac{\sqrt{9-x^2}}{3x} + C\)
D.\(\frac{\sqrt{9-x^2}}{9x} + C\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Let \(x = 3\sin \theta\). Then \(dx = 3\cos \theta \, d\theta\) and \(\sqrt{9-x^2} = 3\cos \theta\). The integral becomes \(\int \frac{3\cos \theta \, d\theta}{9\sin^2 \theta (3\cos \theta)} = \frac{1}{9} \int \csc^2 \theta \, d\theta = -\frac{1}{9} \cot \theta + C = -\frac{1}{9} \frac{\cos \theta}{\sin \theta} + C = -\frac{\sqrt{9-x^2}}{9x} + C\). Option A is correct. This tests multiple steps: substitution, integration, and back-substitution.

Q37. A student incorrectly evaluates \(\int \frac{x}{x^2+1} \, dx\) as \(\frac{1}{2} \ln(x^2+1) + C\). What is the error?

A.There is no error; the antiderivative is correct. ✅
B.They forgot the constant of integration.
C.They used the wrong formula; it should be \(\tan^{-1} x + C\).
D.They misapplied the substitution.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The derivative of \(\frac{1}{2} \ln(x^2+1) + C\) is \(\frac{x}{x^2+1}\). So the student's answer is correct. Option A is the correct choice. This question tests the student's ability to recognize a correct answer even when it might look different from expected, and to verify by differentiation.

Q38. To evaluate \(\int \frac{1}{x^2+4x+13} \, dx\), completing the square gives \((x+2)^2+9\). The table formula for \(\int \frac{du}{u^2+a^2}\) gives \(\frac{1}{3} \tan^{-1}\left(\frac{x+2}{3}\right) + C\). What is the value of the definite integral from \(x=0\) to \(x=1\)?

A.\(\frac{1}{3}(\tan^{-1}1 - \tan^{-1}(2/3))\) ✅
B.\(\frac{1}{3}(\tan^{-1}1 - \tan^{-1}(2/3))\)
C.\(\tan^{-1}1 - \tan^{-1}(2/3)\)
D.\(\frac{1}{3}(\tan^{-1}1 - \tan^{-1}(2/3))\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The antiderivative is \(\frac{1}{3} \tan^{-1}\left(\frac{x+2}{3}\right) + C\). Evaluating from 0 to 1 gives \(\frac{1}{3}[\tan^{-1}(1) - \tan^{-1}(2/3)]\). Option A is correct. Option B is incorrect because it misses the \(\frac{1}{3}\) factor. This tests the ability to evaluate a definite integral after finding the antiderivative.

Q39. The integral \(\int \frac{dx}{x \ln x}\) can be evaluated by substitution \(u = \ln x\). The resulting integral \(\int \frac{du}{u}\) is a basic integral. What is the role of integral tables in this process?

A.The table provides the formula for \(\int \frac{du}{u} = \ln|u| + C\). ✅
B.The table provides the substitution rule.
C.The table is not needed because the integral is trivial.
D.The table provides the formula for \(\int \frac{dx}{x} = \ln|x| + C\).
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: After the substitution \(u = \ln x\), the integral becomes \(\int \frac{du}{u}\), which is a standard form in integral tables (\(\int \frac{du}{u} = \ln|u| + C\)). While the integral is elementary, the table provides the formula. The table does not provide substitution rules (B). Option C is partially true but misses the point that tables are a resource. Option D is the same as A but with \(x\) instead of \(u\). This tests the role of tables in providing basic formulas.

Q40. A student is evaluating \(\int \frac{x+1}{x^2-2x+5} \, dx\). They split it into \(\int \frac{x}{x^2-2x+5} \, dx + \int \frac{1}{x^2-2x+5} \, dx\). Which of the following is a correct next step?

A.Complete the square for both integrals: \(x^2-2x+5 = (x-1)^2+4\). ✅
B.Use partial fractions on both integrals.
C.Use the substitution \(u = x^2-2x+5\) for both.
D.Use the substitution \(u = x-1\) for both.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The denominator \(x^2-2x+5\) can be completed as \((x-1)^2+4\). For the first integral, the numerator \(x\) can be written as \((x-1)+1\), allowing it to be split into \(\int \frac{x-1}{(x-1)^2+4} \, dx + \int \frac{1}{(x-1)^2+4} \, dx\). The first is a \(\ln\) form and the second is an arctan form. Option A is the correct first step. The other options are not appropriate. This tests the ability to split and complete the square.
