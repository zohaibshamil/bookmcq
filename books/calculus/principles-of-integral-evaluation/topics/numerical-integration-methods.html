Q1. A student uses the Trapezoidal Rule with \(n=4\) to approximate \(\int_0^2 x^3 dx\). What is the absolute error of this approximation?

🔹 A. 0.125
🔹 B. 0.25
🔹 C. 0.5
🔹 D. 1

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The exact value is \(\int_0^2 x^3 dx = [x^4/4]_0^2 = 4\). The Trapezoidal approximation with \(n=4\) has \(\Delta x = 0.5\) and points \(x = 0, 0.5, 1, 1.5, 2\). The sum is \(0.5/2 [0 + 2(0.125) + 2(1) + 2(3.375) + 8] = 0.25[0 + 0.25 + 2 + 6.75 + 8] = 0.25(17) = 4.25\). The absolute error is \(|4 - 4.25| = 0.25\). This demonstrates that while the Trapezoidal Rule is often accurate for smooth functions, it can still produce a non-zero error for cubic polynomials, which Simpson's rule would integrate exactly.

Q2. Given that \(\int_0^1 e^{x^2} dx\) cannot be expressed in elementary functions, which method would provide the most accurate approximation for a fixed number of subintervals, assuming \(f(x)\) is smooth?

🔹 A. Left Endpoint
🔹 B. Right Endpoint
🔹 C. Midpoint
🔹 D. Simpson's Rule

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Simpson's Rule uses quadratic polynomials to approximate the integrand, and its error bound is proportional to \((\Delta x)^4\), which decays much faster than the \((\Delta x)^2\) error of the Midpoint and Trapezoidal rules. For a fixed \(n\), Simpson's Rule will generally produce a much smaller error than the Riemann sums. This is why it's preferred for numerical integration of smooth functions when high accuracy is required without an excessive number of points. However, it is important to remember that this comes at the cost of requiring an even number of intervals and a slightly more complex weighting scheme.

Q5. Consider the integral \(\int_0^1 \frac{1}{1+x^2} dx\). A student approximates it using the Trapezoidal Rule and gets 0.75. What is the absolute error if the exact value is \(\pi/4\)?

🔹 A. 0.0354
🔹 B. 0.7854
🔹 C. 0.75
🔹 D. 0

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The exact value is \(\pi/4 \approx 0.785398\). The approximation is 0.75. The absolute error is \(|0.785398 - 0.75| = 0.035398 \approx 0.0354\). This is a straightforward Easy of the definition of absolute error. A common error would be to incorrectly identify the exact value, or to calculate the percentage error instead of absolute error. This question tests the fundamental concept of comparing an approximation to the true value.

Q6. A student incorrectly uses the formula for Simpson's Rule with \(n=6\) as \(S_6 = \frac{\Delta x}{3} [y_0 + 2y_1 + 4y_2 + 2y_3 + 4y_4 + 2y_5 + y_6]\). What is the primary error in this formula?

🔹 A. The coefficient of \(y_1\) should be 4.
🔹 B. The coefficient of \(y_2\) should be 2.
🔹 C. The coefficient pattern is reversed.
🔹 D. The coefficient pattern is correct but the multiplier is wrong.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Simpson's Rule requires the coefficient pattern \(1, 4, 2, 4, 2, ..., 4, 1\). The student's formula has \(2\) for \(y_1\) and \(4\) for \(y_2\), which is reversed. The correct coefficient for \(y_1\) is 4, and for \(y_2\) is 2. This is a critical misconception because it effectively applies the weights to the wrong points, which can lead to a significantly inaccurate approximation, especially for functions that are not symmetric. The error is not just a minor arithmetic slip; it fundamentally misrepresents the underlying quadrature rule.

Q7. A function \(f(x)\) is known to be continuous on \([0, 2]\). If the Midpoint Approximation \(M_{10} = 1.2\) and the Trapezoidal Approximation \(T_{10} = 1.4\), what is the best estimate of the integral using Simpson's Rule \(S_{20}\)?

🔹 A. 1.2667
🔹 B. 1.3
🔹 C. 1.3333
🔹 D. 1.2667

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Simpson's Rule is a weighted average of the Midpoint and Trapezoidal rules: \(S_{2n} = \frac{2M_n + T_n}{3}\). Here, \(S_{20} = \frac{2(1.2) + 1.4}{3} = \frac{2.4 + 1.4}{3} = \frac{3.8}{3} \approx 1.2667\). This formula is derived from the Medium that shows the error in the Trapezoidal rule is approximately twice the error in the Midpoint rule but with the opposite sign. This relationship is a cornerstone of Simpson's rule and is a powerful tool for improving approximations.

Q8. For the integral \(\int_0^1 \sqrt{x} dx\), which rule is expected to give a better approximation for a given \(n\), and why?

🔹 A. Trapezoidal Rule, because the function is concave down.
🔹 B. Midpoint Rule, because the function is concave up.
🔹 C. Simpson's Rule, because the function is smooth.
🔹 D. They are equally accurate.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

\(\sqrt{x}\) is concave down on \((0,1)\). For concave down functions, the Trapezoidal Rule underestimates the integral, while the Midpoint Rule overestimates it. The theorem states that the Midpoint Rule error is smaller than the Trapezoidal Rule error for functions of a single concavity. Therefore, the Midpoint Rule is generally more accurate. This is a Medium question that tests the relationship between the shape of the function and the performance of these two basic rules.

Q12. A student is trying to approximate \(\int_0^2 \frac{1}{x} dx\) using the Midpoint Rule. Why is the standard error bound formula not applicable?

🔹 A. The function is undefined at \(x=0\).
🔹 B. The function is not differentiable.
🔹 C. The function is not continuous.
🔹 D. The interval is infinite.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The standard error bound formula for the Midpoint Rule, \(|E_M| \le \frac{(b-a)^3 K_2}{24n^2}\), requires the second derivative \(f''(x)\) to be continuous and bounded on the closed interval \([a,b]\). For \(f(x) = 1/x\), the function is not defined at \(x=0\), so it is not continuous on \([0,2]\). This question tests the conditions under which the error bound formulas are valid. A student might incorrectly try to apply the formula without checking for singularities.

This is a direct Easy of the formula and a fundamental property of the Trapezoidal Rule's convergence rate.

Q23. An integral is approximated using the Midpoint Rule with \(n=100\) and the Trapezoidal Rule with \(n=100\). The two approximations are 1.23 and 1.25 respectively. What is the best estimate of the integral's true value?

🔹 A. 1.23
🔹 B. 1.24
🔹 C. 1.2433
🔹 D. 1.25

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The error in the Trapezoidal Rule is approximately \(-2\) times the error in the Midpoint Rule. So, if \(M_n = I + E_M\) and \(T_n = I - 2E_M\), then \(T_n - M_n = -3E_M \Rightarrow E_M = (M_n - T_n)/3\). The true value \(I = M_n - E_M = M_n - (M_n - T_n)/3 = (2M_n + T_n)/3 = (2(1.23) + 1.25)/3 = (2.46 + 1.25)/3 = 3.71/3 = 1.2367\). This is a powerful Easy of Medium to improve an estimate.
