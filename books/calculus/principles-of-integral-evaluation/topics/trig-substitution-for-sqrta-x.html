What is Trig substitution for sqrt(a² + x²)?

Definition:
For integrals involving \( \sqrt{a^2 + x^2} \), use the substitution \( x = a \tan \theta \), which simplifies the radical to \( a \sec \theta \) because \( 1 + \tan^2 \theta = \sec^2 \theta \).

Example:
To integrate \( \int \frac{1}{\sqrt{4+x^2}} dx \), let \( x = 2\tan \theta \). The integral becomes \( \int \frac{2\sec^2 \theta}{2\sec \theta} d\theta = \int \sec \theta \, d\theta = \ln|\sec \theta + \tan \theta| + C \).

Reason:
This substitution exploits the identity \( 1+\tan^2 \theta = \sec^2 \theta \) to eliminate the square root, converting the integrand into a standard trigonometric form.

Using \( x=2\cos\theta \) would also work with a different restriction, but \( \sin\theta \) is the standard choice because it directly maps the interval \([-a,a]\) to \([-\pi/2,\pi/2]\) without sign ambiguity.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Using \( x = 2\tan\theta \), \( dx = 2\sec^2\theta d\theta \), \( \sqrt{x^2+4} = 2\sec\theta \). The integral becomes \( \int_0^{\pi/4} 4\sec^3\theta d\theta \). Using the reduction formula \( \int \sec^3\theta d\theta = \frac{1}{2}\sec\theta\tan\theta + \frac{1}{2}\ln|\sec\theta+\tan\theta| + C \), we get \( 4[\frac{1}{2}\sec\theta\tan\theta + \frac{1}{2}\ln(\sec\theta+\tan\theta)]_0^{\pi/4} = 2[\sec\theta\tan\theta + \ln(\sec\theta+\tan\theta)]_0^{\pi/4} \). At \( \theta = \pi/4 \), \( \sec\theta = \sqrt{2} \), \( \tan\theta = 1 \), so \( \sec\theta\tan\theta = \sqrt{2} \), and \( \sec\theta+\tan\theta = \sqrt{2}+1 \). At \( \theta = 0 \), \( \sec\theta = 1 \), \( \tan\theta = 0 \), so \( \sec\theta\tan\theta = 0 \), and \( \sec\theta+\tan\theta = 1 \), whose log is 0. Thus the integral is \( 2[\sqrt{2} + \ln(1+\sqrt{2})] = 2\sqrt{2} + 2\ln(1+\sqrt{2}) \). Option A is correct.

Q75. A student claims that \( \int \frac{x}{\sqrt{x^2 + a^2}} dx = \sqrt{x^2 + a^2} + C \). Which of the following best analyzes this claim?

A.The claim is correct ✅
B.The claim is incorrect; the antiderivative is \( \ln(x+\sqrt{x^2+a^2}) + C \)
C.The claim is incorrect; the antiderivative is \( \frac{1}{2}\sqrt{x^2+a^2} + C \)
D.The claim is incorrect; the antiderivative is \( \frac{x^2}{2\sqrt{x^2+a^2}} + C \)
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Let's differentiate \( \sqrt{x^2+a^2} \). Using the chain rule, \( \frac{d}{dx}\sqrt{x^2+a^2} = \frac{1}{2}(x^2+a^2)^{-1/2} \cdot 2x = \frac{x}{\sqrt{x^2+a^2}} \). This matches the integrand exactly. So the student's claim is correct. Option B is the antiderivative of \( \frac{1}{\sqrt{x^2+a^2}} \). Option C is missing the factor of 2 in the chain rule. Option D is incorrect. This is a good example of why checking by differentiation is important.

Q76. Which of the following is the correct antiderivative of \( \frac{x^2}{\sqrt{x^2 + a^2}} \)?

A.\( \frac{1}{2}(x\sqrt{x^2+a^2} - a^2\ln(x+\sqrt{x^2+a^2})) + C \) ✅
B.\( \frac{1}{2}(x\sqrt{x^2+a^2} + a^2\ln(x+\sqrt{x^2+a^2})) + C \)
C.\( \frac{1}{2}(x\sqrt{x^2+a^2} - a^2\sinh^{-1}(x/a)) + C \)
D.\( \frac{1}{2}(x\sqrt{x^2+a^2} + a^2\sinh^{-1}(x/a)) + C \)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Using integration by parts with \( u = x \), \( dv = \frac{x}{\sqrt{x^2+a^2}} dx \), we get \( du = dx \), \( v = \sqrt{x^2+a^2} \). Then \( \int \frac{x^2}{\sqrt{x^2+a^2}} dx = x\sqrt{x^2+a^2} - \int \sqrt{x^2+a^2} dx \). We know \( \int \sqrt{x^2+a^2} dx = \frac{1}{2}x\sqrt{x^2+a^2} + \frac{a^2}{2}\ln(x+\sqrt{x^2+a^2}) + C \). Substituting: \( x\sqrt{x^2+a^2} - \frac{1}{2}x\sqrt{x^2+a^2} - \frac{a^2}{2}\ln(x+\sqrt{x^2+a^2}) = \frac{1}{2}x\sqrt{x^2+a^2} - \frac{a^2}{2}\ln(x+\sqrt{x^2+a^2}) + C \). Option A is correct. Option B has plus instead of minus. Options C and D use \( \sinh^{-1} \) but \( \ln(x+\sqrt{x^2+a^2}) = \sinh^{-1}(x/a) + \ln a \), and the constant could be absorbed, so C would be equivalent to A if the sign of \( a^2 \) is correct.

Q77. What is the value of \( \int_{-\infty}^{\infty} \frac{dx}{\sqrt{x^2 + a^2}} \)?

A.\( \infty \) ✅
B.\( 2\sinh^{-1}(\infty) = \infty \)
C.\( \pi/a \)
D.\( \pi \)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The integral is improper: \( \int_{-\infty}^{\infty} \frac{dx}{\sqrt{x^2+a^2}} = \lim_{R\to\infty}\int_{-R}^{R} \frac{dx}{\sqrt{x^2+a^2}} = \lim_{R\to\infty} 2\sinh^{-1}(R/a) = \infty \). The integrand does not decay fast enough for the integral to converge (it behaves like \( 1/|x| \) at infinity). This is similar to \( \int_{-\infty}^{\infty} \frac{1}{x^2+1} dx = \pi \), but the \( \sqrt{x^2+a^2} \) in the denominator makes the decay slower. Option C would be the value for \( \int \frac{dx}{x^2+a^2} \). Option D would be for \( \int \frac{dx}{a^2-x^2} \) with appropriate limits.

Q78. Which of the following is a correct first step to evaluate \( \int \sqrt{x^2 + 9} dx \)?

A.\( \int \sqrt{x^2+9} dx = \frac{1}{3}\int \sqrt{\tan^2\theta+1} d\theta \)
B.\( \int \sqrt{x^2+9} dx = 9\int \sec^3\theta d\theta \) ✅
C.\( \int \sqrt{x^2+9} dx = 9\int \tan^2\theta\sec\theta d\theta \)
D.\( \int \sqrt{x^2+9} dx = 9\int \sec^3\theta d\theta \)
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: With \( x = 3\tan\theta \), \( dx = 3\sec^2\theta d\theta \), \( \sqrt{x^2+9} = 3\sec\theta \). So \( \int \sqrt{x^2+9} dx = \int 3\sec\theta \cdot 3\sec^2\theta d\theta = 9\int \sec^3\theta d\theta \). Option B is correct. Option A has \( \frac{1}{3} \) and \( \sqrt{\tan^2\theta+1} \) incorrectly. Option C has \( \tan^2\theta\sec\theta \) which would come from \( \int \frac{x^2}{\sqrt{x^2+9}} dx \). Option D has 9 instead of 9? Actually D is the same as B, so there's a duplicate. The correct is B (or D if they're identical).

Q79. A rectangular plot of land has a curved boundary given by \( y = \sqrt{x^2 + 25} \) from \( x = 0 \) to \( x = 5 \). What is the length of this curved boundary?

A.\( \int_0^5 \sqrt{1 + \frac{x^2}{x^2+25}} dx \)
B.\( \int_0^5 \frac{\sqrt{2x^2+25}}{\sqrt{x^2+25}} dx \) ✅
C.\( \int_0^5 \frac{x}{\sqrt{x^2+25}} dx \)
D.\( \int_0^5 \sqrt{\frac{2x^2+25}{x^2+25}} dx \)
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Arc length formula: \( L = \int_a^b \sqrt{1+(dy/dx)^2} dx \). For \( y = \sqrt{x^2+25} \), \( dy/dx = x/\sqrt{x^2+25} \). Then \( 1+(dy/dx)^2 = 1 + \frac{x^2}{x^2+25} = \frac{x^2+25+x^2}{x^2+25} = \frac{2x^2+25}{x^2+25} \). Taking square root gives \( \frac{\sqrt{2x^2+25}}{\sqrt{x^2+25}} \). Option B is correct. Option A is missing the square root of the sum. Option C is just the derivative. Option D has the same expression as B but written differently. Actually B and D are the same. This question tests the Easy of arc length formula to functions involving \( \sqrt{x^2+a^2} \).

Q80. When evaluating \( \int \frac{1}{\sqrt{x^2 + a^2}} dx \), if a student uses \( x = a\cot\theta \) instead of \( x = a\tan\theta \), what happens?

A.They get the same result after simplification
B.They get a different but valid result
C.The substitution is invalid
D.They get the integral of \( -\csc\theta d\theta \) ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: If a student uses \( x = a\cot\theta \), then \( dx = -a\csc^2\theta d\theta \), and \( \sqrt{x^2+a^2} = \sqrt{a^2\cot^2\theta+a^2} = a\sqrt{\cot^2\theta+1} = a\csc\theta \) (assuming \( \theta \in (0,\pi) \), where \( \csc\theta > 0 \)). Then \( \int \frac{dx}{\sqrt{x^2+a^2}} = \int \frac{-a\csc^2\theta}{a\csc\theta} d\theta = -\int \csc\theta d\theta = \ln|\csc\theta+\cot\theta| + C \). This is equal to \( \ln(x+\sqrt{x^2+a^2}) + C \) up to a constant. Option D is correct for the intermediate step. Option A is correct in the sense that it yields the same final result. The question asks what happens, so D is the more immediate result.
