Q1. What is the most appropriate first step to evaluate \( \int \tan^3 x \sec^3 x \, dx \)?

🔹 A. Split off \( \sec^2 x \) and substitute \( u = \tan x \)
🔹 B. Split off \( \sec x \tan x \) and substitute \( u = \sec x \)
🔹 C. Use the identity \( \sec^2 x = \tan^2 x + 1 \) to rewrite the integrand in terms of \( \tan x \)
🔹 D. Apply the reduction formula for \( \int \sec^n x \, dx \) directly

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The exponent of tangent (\( m = 3 \)) is odd, so the standard procedure is to split off \( \sec x \tan x \) and use the identity \( \tan^2 x = \sec^2 x - 1 \) with the substitution \( u = \sec x \). This reduces the integral to a polynomial in \( u \). Splitting off \( \sec^2 x \) is appropriate when the exponent of secant is even.

The first term integrates to \( \frac{\tan^{n-1} x}{n-1} \), leaving the negative of the integral of \( \tan^{n-2} x \).

Q18. Evaluate \( \int \tan^3 x \sec^5 x \, dx \).

🔹 A. \( \frac{1}{5} \sec^5 x - \frac{1}{7} \sec^7 x + C \)

Q19. What is the derivative of \( \frac{1}{3} \tan^3 x + \tan x \)?

🔹 A. \( \tan^4 x \sec^2 x \)
🔹 B. \( \tan^4 x \)
🔹 C. \( \tan^2 x \sec^2 x \)
🔹 D. \( \tan^4 x + \tan^2 x \)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The derivative of \( \tan^3 x \) is \( 3 \tan^2 x \sec^2 x \), so the derivative of \( \frac{1}{3} \tan^3 x \) is \( \tan^2 x \sec^2 x = \tan^2 x (1 + \tan^2 x) = \tan^2 x + \tan^4 x \). The derivative of \( \tan x \) is \( \sec^2 x = 1 + \tan^2 x \). Summing gives \( \tan^2 x + \tan^4 x + 1 + \tan^2 x = \tan^4 x + 2\tan^2 x + 1 \). But wait, \( \frac{d}{dx}(\frac{1}{3}\tan^3 x + \tan x) = \tan^2 x \sec^2 x + \sec^2 x = \sec^2 x (\tan^2 x + 1) = \sec^4 x \). However, \( \sec^4 x = (1+\tan^2 x)^2 = 1 + 2\tan^2 x + \tan^4 x \). But \( \int \sec^4 x dx = \int (1+\tan^2 x)\sec^2 x dx = \tan x + \frac{1}{3}\tan^3 x + C \). The derivative of \( \frac{1}{3}\tan^3 x + \tan x \) is \( \tan^2 x \sec^2 x + \sec^2 x = \sec^2 x(\tan^2 x + 1) = \sec^4 x \). So the derivative is \( \sec^4 x = (1+\tan^2 x)^2 = 1 + 2\tan^2 x + \tan^4 x \). The provided options are not correct; the correct derivative is \( \sec^4 x \). But if the student made an error, they might think the derivative is \( \tan^4 x \).

Q25. Evaluate \( \int_0^{\pi/4} \sec^4 x \, dx \).

🔹 A. \( \frac{4}{3} \)
🔹 B. \( \frac{1}{3} \)
🔹 C. \( \frac{2}{3} \)
🔹 D. \( \frac{4}{3} \)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Let \( u = \tan x \). Then \( du = \sec^2 x dx \). We also need to convert one \( \sec^2 x \) to \( 1 + \tan^2 x \). So \( \sec^4 x dx = \sec^2 x \sec^2 x dx = (1+\tan^2 x)\sec^2 x dx = (1+u^2) du \). The limits: when \( x=0 \), \( u=0 \); when \( x=\pi/4 \), \( u=1 \). So the integral becomes \( \int_0^1 (1+u^2) du = [u + \frac{1}{3} u^3]_0^1 = 1 + \frac{1}{3} = \frac{4}{3} \).

Q26. Evaluate \( \int_{-\pi/4}^{\pi/4} \tan^3 x \sec^2 x \, dx \).

📖 Explanation:

Let \( u = \tan x \). Then \( du = \sec^2 x dx \). The limits: \( x=0 \to u=0 \), \( x=\pi/4 \to u=1 \). The integral becomes \( \int_0^1 u^3 du = [\frac{1}{4} u^4]_0^1 = \frac{1}{4} \). So the area is \( \frac{1}{4} \).

Q29. A student tries to evaluate \( \int \tan^3 x \sec^3 x dx \) by letting \( u = \tan x \). Why is this not a good choice?

🔹 A. The derivative of \( \tan x \) is \( \sec^2 x \), but the integrand has \( \sec^3 x \), leaving an extra \( \sec x \) factor that cannot be expressed in terms of \( u \)
🔹 B. The derivative of \( \tan x \) is \( \sec^2 x \), but the integrand has \( \sec^3 x \), leaving an extra \( \sec x \) factor that cannot be expressed in terms of \( u \)
🔹 C. The derivative of \( \tan x \) is \( \sec^2 x \), which is present, so the substitution works
🔹 D. The integral is not a product of powers of tangent and secant

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The substitution \( u = \tan x \) requires the presence of \( \sec^2 x dx \). Here, we have \( \sec^3 x dx = \sec x \cdot \sec^2 x dx \). The extra \( \sec x \) cannot be expressed as a function of \( u = \tan x \) alone, so the substitution is not effective. The correct approach is to split off \( \sec x \tan x \) and use \( u = \sec x \).

Q30. Evaluate \( \int \tan^5 x \sec^2 x \, dx \).

🔹 A. \( \frac{1}{6} \tan^6 x + C \)
🔹 B. \( \frac{1}{6} \tan^6 x + C \)
🔹 C. \( \frac{1}{4} \tan^4 x + C \)
🔹 D. \( \frac{1}{6} \tan^6 x + C \)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Let \( u = \tan x \), then \( du = \sec^2 x dx \). The integral becomes \( \int u^5 du = \frac{1}{6} u^6 + C = \frac{1}{6} \tan^6 x + C \). This is a straightforward Easy of the substitution method.

Q31. What is the value of \( \int_{\pi/4}^{\pi/3} \sec^2 x \, dx \)?

🔹 A. \( \sqrt{3} - 1 \)
🔹 B. \( \sqrt{3} - 1 \)
🔹 C. \( \sqrt{3} \)
🔹 D. \( 1 - \sqrt{3} \)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The integral of \( \sec^2 x \) is \( \tan x \). Therefore, \( \int_{\pi/4}^{\pi/3} \sec^2 x dx = [\tan x]_{\pi/4}^{\pi/3} = \tan(\pi/3) - \tan(\pi/4) = \sqrt{3} - 1 \).

Q32. Which of the following is NOT a valid method to evaluate \( \int \tan^2 x \sec^2 x \, dx \)?

🔹 A. Substitute \( u = \tan x \)
🔹 B. Substitute \( u = \sec x \)
🔹 C. Rewrite \( \tan^2 x = \sec^2 x - 1 \), then use \( u = \sec x \)
🔹 D. Substitute \( u = \tan^2 x \)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The substitution \( u = \sec x \) would require \( du = \sec x \tan x dx \), but the integrand has \( \sec^2 x \), not \( \sec x \tan x \). The substitution \( u = \tan x \) works perfectly because \( du = \sec^2 x dx \). Rewriting in terms of \( \sec x \) and then using the reduction formula would also work but is unnecessary. Substituting \( u = \tan^2 x \) is also not efficient as \( du = 2\tan x \sec^2 x dx \), leaving an extra \( \tan x \) factor. So the invalid method is \( u = \sec x \).

Q33. Evaluate \( \int \sec^6 x \, dx \) using the reduction formula.

🔹 A. \( \frac{1}{5} \sec^4 x \tan x + \frac{4}{15} \sec^2 x \tan x + \frac{8}{15} \tan x + C \)
🔹 B. \( \frac{1}{5} \sec^4 x \tan x + \frac{4}{15} \sec^2 x \tan x + \frac{8}{15} \tan x + C \)
🔹 C. \( \frac{1}{5} \sec^4 x \tan x + \frac{4}{15} \sec^2 x \tan x + \frac{8}{15} \tan x + C \)
🔹 D. \( \frac{1}{5} \sec^4 x \tan x + \frac{4}{15} \sec^2 x \tan x + \frac{8}{15} \tan x + C \)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Using the reduction formula \( \int \sec^n x dx = \frac{\sec^{n-2} x \tan x}{n-1} + \frac{n-2}{n-1} \int \sec^{n-2} x dx \). For \( n=6 \): \( \int \sec^6 x dx = \frac{\sec^4 x \tan x}{5} + \frac{4}{5} \int \sec^4 x dx \). For \( n=4 \): \( \int \sec^4 x dx = \frac{\sec^2 x \tan x}{3} + \frac{2}{3} \int \sec^2 x dx = \frac{\sec^2 x \tan x}{3} + \frac{2}{3} \tan x \). Substituting back: \( \int \sec^6 x dx = \frac{1}{5} \sec^4 x \tan x + \frac{4}{5} [\frac{1}{3} \sec^2 x \tan x + \frac{2}{3} \tan x] + C = \frac{1}{5} \sec^4 x \tan x + \frac{4}{15} \sec^2 x \tan x + \frac{8}{15} \tan x + C \).

Q34. Which of the following integrals is best solved by first rewriting the integrand using \( \tan^2 x = \sec^2 x - 1 \)?

🔹 A. \( \int \tan^2 x \sec^3 x dx \)
🔹 B. \( \int \tan^3 x \sec^3 x dx \)
🔹 C. \( \int \tan^2 x \sec^4 x dx \)
🔹 D. \( \int \tan^3 x \sec^2 x dx \)

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

For \( \int \tan^2 x \sec^3 x dx \), neither the exponent of tangent is odd nor the exponent of secant is even. The recommended method is to rewrite \( \tan^2 x = \sec^2 x - 1 \), resulting in \( \int (\sec^2 x - 1) \sec^3 x dx = \int \sec^5 x dx - \int \sec^3 x dx \), which requires the reduction formula. The other integrals can be solved with direct substitutions.

Q35. Evaluate \( \int \tan^2 x \sec^2 x \, dx \).

🔹 A. \( \frac{1}{3} \tan^3 x + C \)
🔹 B. \( \frac{1}{3} \tan^3 x + C \)
🔹 C. \( \frac{1}{3} \sec^3 x + C \)
🔹 D. \( \frac{1}{3} \tan^3 x + C \)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Let \( u = \tan x \), then \( du = \sec^2 x dx \). The integral becomes \( \int u^2 du = \frac{1}{3} u^3 + C = \frac{1}{3} \tan^3 x + C \).

Q36. The integral \( \int \sec^3 x \tan x \, dx \) can be evaluated by:

🔹 A. Letting \( u = \sec x \)
🔹 B. Letting \( u = \tan x \)
🔹 C. Using integration by parts
🔹 D. Using the reduction formula

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The integrand is \( \sec^2 x \cdot \sec x \tan x \). Let \( u = \sec x \), then \( du = \sec x \tan x dx \). The integral becomes \( \int u^2 du = \frac{1}{3} u^3 + C = \frac{1}{3} \sec^3 x + C \).

Q37. A student evaluates \( \int \tan^3 x \sec x dx \) and gets \( \frac{1}{3} \sec^3 x \tan x + C \). Is this correct?

🔹 A. No, the derivative of \( \frac{1}{3} \sec^3 x \tan x \) is not \( \tan^3 x \sec x \)
🔹 B. No, the derivative of \( \frac{1}{3} \sec^3 x \tan x \) is \( \sec^2 x \tan^4 x + \sec^4 x \tan^2 x \)
🔹 C. Yes, the derivative of \( \frac{1}{3} \sec^3 x \tan x \) is \( \tan^3 x \sec x \)
🔹 D. Yes

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The derivative of \( \frac{1}{3} \sec^3 x \tan x \) requires the product rule: \( \frac{1}{3} [3 \sec^2 x \sec x \tan x \cdot \tan x + \sec^3 x \cdot \sec^2 x] = \frac{1}{3} [3 \sec^3 x \tan^2 x + \sec^5 x] = \sec^3 x \tan^2 x + \frac{1}{3} \sec^5 x \). This is not \( \tan^3 x \sec x \). The correct antiderivative is \( \frac{1}{3} \sec^3 x - \sec x + C \).

Q38. Evaluate \( \int \tan^2 x \sec^3 x \, dx \) using the reduction formula.

🔹 A. \( \frac{1}{4} \sec x \tan x - \frac{1}{8} \ln|\sec x + \tan x| + \frac{1}{4} \sec^3 x \tan x + C \)
🔹 B. \( \frac{1}{4} \sec x \tan x + \frac{1}{8} \ln|\sec x + \tan x| + \frac{1}{4} \sec^3 x \tan x + C \)
🔹 C. \( \frac{1}{4} \sec x \tan x - \frac{1}{8} \ln|\sec x + \tan x| + \frac{1}{4} \sec^3 x \tan x + C \)
🔹 D. \( \frac{1}{4} \sec x \tan x + \frac{1}{8} \ln|\sec x + \tan x| + \frac{1}{4} \sec^3 x \tan x + C \)

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Rewrite \( \tan^2 x = \sec^2 x - 1 \), so the integral becomes \( \int \sec^5 x dx - \int \sec^3 x dx \). Use the reduction formula for \( \sec^n x \): \( \int \sec^3 x dx = \frac{1}{2} \sec x \tan x + \frac{1}{2} \ln|\sec x + \tan x| \). \( \int \sec^5 x dx = \frac{1}{4} \sec^3 x \tan x + \frac{3}{4} \int \sec^3 x dx = \frac{1}{4} \sec^3 x \tan x + \frac{3}{8} \sec x \tan x + \frac{3}{8} \ln|\sec x + \tan x| \). Subtracting: \( \frac{1}{4} \sec^3 x \tan x + \frac{3}{8} \sec x \tan x + \frac{3}{8} \ln|\sec x + \tan x| - \frac{1}{2} \sec x \tan x - \frac{1}{2} \ln|\sec x + \tan x| = \frac{1}{4} \sec^3 x \tan x - \frac{1}{8} \sec x \tan x - \frac{1}{8} \ln|\sec x + \tan x| + C \).

Q39. What is the integral of \( \int \tan^5 x \sec^5 x \, dx \)?

🔹 A. \( \frac{1}{7} \sec^7 x - \frac{2}{5} \sec^5 x + \frac{1}{3} \sec^3 x + C \)
🔹 B. \( \frac{1}{7} \sec^7 x - \frac{2}{5} \sec^5 x + \frac{1}{3} \sec^3 x + C \)
🔹 C. \( \frac{1}{7} \sec^7 x + \frac{2}{5} \sec^5 x + \frac{1}{3} \sec^3 x + C \)
🔹 D. \( \frac{1}{7} \sec^7 x - \frac{2}{5} \sec^5 x + \frac{1}{3} \sec^3 x + C \)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Let \( u = \sec x \). Then \( du = \sec x \tan x dx \). Split off \( \sec x \tan x \) and rewrite \( \tan^4 x = (\sec^2 x - 1)^2 \).
