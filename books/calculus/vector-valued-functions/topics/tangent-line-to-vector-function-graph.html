What is Tangent line to vector function graph?

Definition:
The tangent line to the curve r(t) at t=t0​ passes through r(t0​) with direction vector r′(t0​), given by L(s)=r(t0​)+sr′(t0​).

Example:
At t=π/4 on the helix ⟨cost,sint,t⟩, the tangent line uses direction ⟨−22​​,22​​,1⟩.

Reason:
Tangent lines provide local linear approximations essential for optimization, error estimation, and understanding instantaneous motion.
