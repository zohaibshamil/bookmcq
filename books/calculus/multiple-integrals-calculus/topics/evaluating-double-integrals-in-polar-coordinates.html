What is Evaluating Double integrals in polar coordinates?

Definition:
Evaluation follows the same iterated process as Cartesian, but with the extra factor of \( r \) in the integrand. We integrate with respect to \( r \) first (usually), then \( \theta \).

Example:
For \( \iint_R y \, dA \) over the upper half-disk, we compute \( \int_0^\pi \int_0^1 (r\sin\theta) \, r \, dr \, d\theta = \int_0^\pi \sin\theta \, d\theta \int_0^1 r^2 \, dr = 2 \cdot \frac{1}{3} = \frac{2}{3} \).

Reason:
The Jacobian factor \( r \) accounts for the stretching of area elements as we move away from the origin, ensuring accurate accumulation of values across the polar grid.

Q1. A student evaluates \( \int_0^{2\pi} \int_0^1 r^3 \sin\theta \, dr \, d\theta \) and gets 0. Is this correct, and if so, why?

A.Yes, because the integrand is odd in \(r\)
B.Yes, because the angular integral of \(\sin\theta\) over \([0,2\pi]\) is zero ✅
C.No, because the integrand is always positive
D.No, because the limits of integration are incorrect
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The integral is zero because the inner \(r\)-integral gives \(1/4 \sin\theta\), and the \(\theta\)-integral of \(\sin\theta\) from 0 to \(2\pi\) is indeed 0. The student's result is correct. The reason is the symmetry of the sine function over a full period, not because the integrand is odd in \(r\). This tests understanding that zero result can arise from angular symmetry even when the radial part is positive.

Q2. Which of the following correctly converts the area inside the circle \(r = 2a\cos\theta\) (for \(a>0\)) into a polar double integral?

A.\(\int_{-\pi/2}^{\pi/2} \int_0^{2a\cos\theta} r \, dr \, d\theta\) ✅
B.\(\int_0^{2\pi} \int_0^{2a\cos\theta} r \, dr \, d\theta\)
C.\(\int_0^{\pi} \int_0^{2a\cos\theta} r \, dr \, d\theta\)
D.\(\int_{-\pi}^{\pi} \int_0^{2a\cos\theta} dr \, d\theta\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The circle \(r = 2a\cos\theta\) is traced for \(\theta \in [-\pi/2, \pi/2]\) because \(\cos\theta\) must be non-negative for \(r \ge 0\). The area element in polar is \(r \, dr \, d\theta\). Option B uses wrong \(\theta\) limits, C misses the negative side, D omits the Jacobian \(r\). This requires recognizing both the correct bounds from the polar equation and the Jacobian.

Q3. A student computes the volume under \(z = x^2 + y^2\) over the unit disk using polar coordinates as \( \int_0^{2\pi} \int_0^1 r^2 \, dr \, d\theta \) and gets \(2\pi/3\). What error did they make?

A.They forgot the Jacobian \(r\) in the integrand ✅
B.They used wrong limits for \(r\)
C.They used wrong limits for \(\theta\)
D.They forgot to square the radius in \(z\)
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The correct integrand is \((x^2+y^2) \cdot r = r^2 \cdot r = r^3\). The student omitted the Jacobian \(r\), which is a common error when converting to polar coordinates. The correct integral is \(\int_0^{2\pi} \int_0^1 r^3 \, dr \, d\theta = \pi/2\). Option A identifies the exact misconception. This is a classic error analysis question.

Q4. Consider the integral \( I = \int_0^{\pi/2} \int_0^{\sin 2\theta} r \, dr \, d\theta \). Which region in the xy-plane does this represent?

A.The region inside the lemniscate \(r^2 = \sin 2\theta\) in the first quadrant
B.The region inside the circle \(x^2+y^2 = \sin 2\theta\)
C.The region inside the rose curve \(r = \sin 2\theta\) in first quadrant ✅
D.The region inside the cardioid \(r = 1+\sin\theta\)
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The inner limit \(r = \sin 2\theta\) and \(\theta\) from 0 to \(\pi/2\) describes the polar curve. Since \(r^2 = x^2+y^2\) and \(r \sin 2\theta = 2xy/r\)? Actually \(r = \sin 2\theta\) implies \(r^2 = r \sin 2\theta = 2xy\), so \(x^2+y^2 = 2xy\), which is not a standard curve. But the integral \(\int r \, dr\) means the region is bounded by \(r = \sin 2\theta\). This is the polar rose with 4 petals, but only the first-quadrant petal. So the correct interpretation is the region inside the curve \(r = \sin 2\theta\) in the first quadrant. Option A incorrectly mentions lemniscate; actually it's a rose curve. The correct is C. Let's check: \(r = \sin 2\theta\) is a four-petal rose. With \(\theta \in [0,\pi/2]\), it's the petal in first quadrant. So answer is C.

Q5. Evaluate \( \int_0^{\pi} \int_0^{1+\cos\theta} r \, dr \, d\theta \) and identify the shape of the region.

A.\(3\pi/2\), cardioid ✅
B.\(3\pi/4\), cardioid
C.\(\pi\), circle
D.\(3\pi/2\), limaçon
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Inner integral: \(\int_0^{1+\cos\theta} r \, dr = \frac12 (1+\cos\theta)^2\). Then integrate \(\frac12 \int_0^\pi (1 + 2\cos\theta + \cos^2\theta) d\theta\). The \(\cos\theta\) term integrates to 0, \(\cos^2\theta\) integrates to \(\pi/2\), so result = \(\frac12 (\pi + 0 + \pi/2) = 3\pi/4\). Wait recalc: \(\int_0^\pi 1 d\theta = \pi\), \(\int_0^\pi 2\cos\theta d\theta = 0\), \(\int_0^\pi \cos^2\theta d\theta = \pi/2\). Sum = \(3\pi/2\). Half = \(3\pi/4\). So result is \(3\pi/4\). The curve \(r = 1+\cos\theta\) is a cardioid. So answer B.

Q6. Which of the following is the correct setup to find the area of the region that lies inside both circles \(r = 1\) and \(r = 2\sin\theta\)?

A.\(\int_0^{\pi/6} \int_0^{2\sin\theta} r \, dr \, d\theta + \int_{\pi/6}^{\pi/2} \int_0^1 r \, dr \, d\theta\)
B.\(\int_0^{\pi/3} \int_0^{1} r \, dr \, d\theta + \int_{\pi/3}^{\pi/2} \int_0^{2\sin\theta} r \, dr \, d\theta\)
C.\(\int_0^{\pi/3} \int_0^{2\sin\theta} r \, dr \, d\theta + \int_{\pi/3}^{\pi/2} \int_0^1 r \, dr \, d\theta\) ✅
D.\(\int_0^{\pi/2} \int_0^{\min(1,2\sin\theta)} r \, dr \, d\theta\)
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: The two curves intersect when \(1 = 2\sin\theta \Rightarrow \sin\theta = 1/2 \Rightarrow \theta = \pi/6, 5\pi/6\). For the region inside both in first quadrant, we need \(\theta\) from 0 to \(\pi/6\): \(r\) is limited by \(2\sin\theta\) (which is <1). From \(\pi/6\) to \(\pi/2\): \(r\) is limited by 1. So option C is correct. Option D is tempting but \(\min\) must be piecewise, not a single integral. This tests intersection and piecewise bounds.

Q7. A student claims that for any function \(f(r,\theta)\), \(\int_0^{2\pi} \int_0^1 f(r,\theta) r \, dr \, d\theta = \int_0^1 \int_0^{2\pi} f(r,\theta) r \, d\theta \, dr\). Is this always valid?

A.Yes, by Fubini's theorem, since the integrand is continuous on a rectangle in polar coordinates ✅
B.Only if \(f\) is independent of \(\theta\)
C.Only if \(f\) is bounded
D.No, because polar coordinates have a singularity at \(r=0\)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Fubini's theorem allows interchange of order of integration if the integrand is continuous on the rectangular domain \([0,1] \times [0,2\pi]\) in the \((r,\theta)\) plane. The Jacobian \(r\) is continuous there. The singularity at \(r=0\) is removable since \(r\) times a continuous function is still continuous and integrable. So the student is correct. Option A is the right reasoning. This tests understanding of Fubini's theorem in polar coordinates.

Q8. The integral \(\int_{-\pi/2}^{\pi/2} \int_0^{\cos\theta} r^2 \, dr \, d\theta\) is equal to which of the following?

A.\(\frac{1}{3} \int_{-\pi/2}^{\pi/2} \cos^3\theta \, d\theta = \frac{4}{9}\) ✅
B.\(\frac{1}{3} \int_{-\pi/2}^{\pi/2} \cos^3\theta \, d\theta = \frac{2}{3}\)
C.\(\frac{1}{3} \int_{-\pi/2}^{\pi/2} \cos^2\theta \, d\theta = \frac{\pi}{6}\)
D.\(\frac{1}{2} \int_{-\pi/2}^{\pi/2} \cos^2\theta \, d\theta = \frac{\pi}{4}\)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Inner integral: \(\int_0^{\cos\theta} r^2 dr = \frac{\cos^3\theta}{3}\). Then integrate over \(\theta\): \(\frac13 \int_{-\pi/2}^{\pi/2} \cos^3\theta d\theta\). Since \(\cos^3\theta\) is even, = \(\frac23 \int_0^{\pi/2} \cos^3\theta d\theta = \frac23 \cdot \frac{2}{3} = \frac{4}{9}\). Option A has correct value. Option B has wrong value, C and D use wrong power or missing factor. This requires both integration and symmetry.

C.\(\int_{-\pi/3}^{\pi/3} \int_{a}^{2a\cos\theta} dr \, d\theta\)
D.\(\int_0^{2\pi} \int_{a}^{2a\cos\theta} r \, dr \, d\theta\)
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The circles intersect when \(a = 2a\cos\theta \Rightarrow \cos\theta = 1/2 \Rightarrow \theta = \pm \pi/3\). For the region outside the smaller circle and inside the larger, \(r\) goes from \(a\) to \(2a\cos\theta\), and \(\theta\) from \(-\pi/3\) to \(\pi/3\). Option A has correct limits and includes Jacobian \(r\). Option B uses wrong intersection, C omits Jacobian, D wrong θ range. This tests ability to find intersection and set up piecewise bounds.
