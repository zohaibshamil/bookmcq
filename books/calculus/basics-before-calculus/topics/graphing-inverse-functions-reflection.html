What is Graphing inverse functions reflection?

Definition:
The graph of an inverse function \( f^{-1} \) is the reflection of the graph of \( f \) across the line \( y = x \), meaning that if \( (a,b) \) lies on \( f \), then \( (b,a) \) lies on \( f^{-1} \), swapping coordinates.

Example:
For \( f(x)=x^3 \), graph passes through (2,8); its inverse \( f^{-1}(x)=\sqrt[3]{x} \) passes through (8,2), and the two curves are symmetric about \( y=x \).

Reason:
This geometric relationship provides a visual check and aids in sketching inverse graphs without algebraic computation.

Q1. What is the domain of the inverse function \(f^{-1}\) expressed in terms of the original function \(f\)?

A.The same set as the domain of \(f\)
B.The same set as the range of \(f\) ✅
C.All real numbers
D.None of the above
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The domain of an inverse function consists exactly of the values that the original function outputs. Since the range of \(f\) is the set of all possible outputs, those values become the permissible inputs for \(f^{-1}\). Therefore the domain of \(f^{-1}\) equals the range of \(f\).

Q2. If \(f(x)=2x\) and its inverse is \(f^{-1}(x)=\frac{1}{2}x\), what is the value of \(f^{-1}(f(3))\)?

A.6
B.0
C.3 ✅
D.1.5
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: First compute the inner function: \(f(3)=2\cdot3=6\). Then apply the inverse: \(f^{-1}(6)=\frac{1}{2}\cdot6=3\). The composition \(f^{-1}(f(x))\) always returns the original input \(x\). Hence the correct result is 3, which appears as option C.

Q3. Which of the following best describes the symmetry between the graphs of \(f(x)=x^{3}\) and its inverse \(f^{-1}(x)=\sqrt[3]{x}\)?

A.They are symmetric about the x‑axis
B.They coincide exactly
C.They have no particular symmetry
D.They are symmetric about the line \(y = x\) ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: An inverse function is obtained by reflecting the original graph across the line \(y=x\). For \(f(x)=x^{3}\) and its inverse, the two curves are mirror images about that line. The statement that captures this relationship is that they are symmetric about the line \(y=x\).

Q4. A one‑to‑one function \(g\) passes through the point \((4,9)\). Which point must appear on the graph of \(g^{-1}\)?

A.(-9,-4)
B.-94 ✅
C.(4,-9)
D.49
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: By definition of an inverse, the ordered pair \((a,b)\) on \(g\) becomes \((b,a)\) on \(g^{-1}\). Swapping the coordinates of \((4,9)\) yields \((9,4)\). This point must lie on the inverse’s graph, making option B the correct choice.

Q5. Given an invertible function \(h\) with \(h(0)=5\), what is \(h^{-1}(5)\)?

A.5
B.-5
C.Undefined
D.0 ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: The equation \(h(0)=5\) tells us that the input 0 maps to the output 5. The inverse function reverses this mapping, sending 5 back to the original input. Hence \(h^{-1}(5)=0\), which is listed as option D.

Q6. If a function \(p\) has domain \([-2,3]\) and range \([0,7]\), what is the domain of its inverse \(p^{-1}\)?

A.[-2,3]
B.All real numbers
C.[0,7] ✅
D.[-7,0]
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The domain of an inverse function is precisely the range of the original function. Since \(p\) outputs values in \([0,7]\), those become the allowable inputs for \(p^{-1}\). Therefore the domain of \(p^{-1}\) is \([0,7]\), which corresponds to option C.

Q7. For the function \(q(x)=\frac{1}{x}\) (with \(x\neq0\)), which statement about its graph and the line \(y=x\) is true?

A.The graph coincides with \(y=x\)
B.The graph is symmetric about \(y=x\) ✅
C.The graph is orthogonal to \(y=x\)
D.There is no special relationship
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The function \(q(x)=1/x\) is its own inverse, meaning its graph is unchanged when reflected across the line \(y=x\). This property implies symmetry about that line. The graph does not coincide with the line, nor is it orthogonal; the correct description is symmetry about \(y=x\).

Q8. If an invertible function \(r\) satisfies \(r(2)= -3\), what is \(r^{-1}(-3)\)?

A.2 ✅
B.0
C.-3
D.Undefined
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Because \(r\) is invertible, the inverse function undoes the original mapping. The statement \(r(2)=-3\) tells us that input 2 yields output \(-3\). Applying the inverse to \(-3\) returns the original input, so \(r^{-1}(-3)=2\), which is option A.

Q9. At \(x=1\), the derivative of \(f(x)=\sqrt{x}\) is \(\frac{1}{2}\) and the derivative of its inverse \(f^{-1}(x)=x^{2}\) is 2. What relationship do these slopes exhibit?

A.They are equal
B.They are reciprocals of each other ✅
C.They are negatives of each other
D.No simple relationship
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The derivative of an inverse function at a point equals the reciprocal of the original function’s derivative at the corresponding point, provided both derivatives exist. Here \(\frac{1}{2}\) and 2 are reciprocal numbers (\(\frac{1}{2}\times2=1\)). Hence the slopes are reciprocals, making option B correct.

Q10. Consider the piecewise function \(s(x)=\begin{cases}x+1,& x\le0\\2x,& x>0\end{cases}\). Does \(s\) have an inverse, and if so, what is the domain of \(s^{-1}\)?

A.Inverse exists; domain is \((- \infty,1]\cup(0,\infty)\)
B.Inverse does not exist because \(s\) is not one‑to‑one ✅
C.Inverse exists; domain is \((- \infty,1]\)
D.Inverse exists; domain is \((-\infty,\infty)\)
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: For an inverse to exist, the original function must be one‑to‑one. On the interval \((- \infty,0]\) the rule \(x+1\) maps to \((- \infty,1]\); on \((0,\infty)\) the rule \(2x\) maps to \((0,\infty)\). The overlap \((0,1]\) means two different inputs produce the same output, violating injectivity. Hence no inverse exists, option B.

Q11. Let \(f\) be invertible with \(f(a)=b\). Define \(g(x)=f^{-1}(x)+a\). What is \(g(b)\)?

A.\(a+b\)
B.\(a\)
C.\(b\)
D.\(2a\) ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: First compute \(g(b)=f^{-1}(b)+a\). Since \(f(a)=b\), the inverse satisfies \(f^{-1}(b)=a\). Substituting gives \(g(b)=a+a=2a\). Therefore the value of \(g(b)\) is twice \(a\), which matches option D.

Q12. If \((p,q)\) lies on the graph of an invertible function \(f\) and \((q,p)\) lies on the graph of \(f^{-1}\), what is \((f\circ f^{-1})(q)\)?

A.\(q\) ✅
B.\(p\)
C.\(p+q\)
D.Undefined
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The composition \(f\circ f^{-1}\) applied to any element of the domain of \(f^{-1}\) (which is the range of \(f\)) returns that element unchanged, because the inverse undoes the original function. Since \(q\) is in the range of \(f\), \((f\circ f^{-1})(q)=q\). Option A is correct.

Q13. Which geometric transformation relates the graph of a function to the graph of its inverse?

A.Reflection across the x‑axis
B.Translation by \((1,1)\)
C.Reflection across the line \(y=x\) ✅
D.Rotation \(90^\circ\) about the origin
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The graph of an inverse function is obtained by reflecting the original graph across the line \(y=x\). This mirror operation swaps each point \((x,y)\) with \((y,x)\). No translation, rotation, or reflection across the x‑axis achieves this effect, so option C accurately describes the relationship.
