What is Phase shift sine cosine functions?

Phase shift describes the horizontal displacement of a sinusoidal graph \( y = \sin(Bx - C) \), calculated as \( C/B \), indicating how far the standard wave pattern has been translated left or right relative to the origin without altering its amplitude or period.

Q1. In the function y = A sin(Bx - C), what does the absolute value of A represent?

A. Amplitude ✅
B. Period
C. Phase shift
D. Frequency

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The magnitude of A determines how far the sine wave moves above and below the horizontal axis. This distance from the midline to the peak (or trough) is called the amplitude. Therefore, |A| directly gives the amplitude of the graph, independent of any horizontal shifts or changes in period.

Q2. If the graph of y = 3 sin(2x - π/4) is shifted π/4 units to the right, what is the new phase shift C in the standard form y = 3 sin(2x - C)?

A. π/2
B. π/4 ✅
C. 0
D. 3π/4

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Shifting a sinusoid right by π/4 adds that amount to the existing horizontal displacement. The original form already contains a subtraction of π/4 inside the argument. Adding another π/4 to the right results in the combined shift of π/4, so the new C equals π/4, matching option B.

Q3. Suppose y = 4 cos(5x + C) passes through the point (0,0). What value of C (in radians) must hold?

A. #NAME?
B. π/2 ✅
C. 0
D. π

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

At x = 0 the cosine term reduces to cos(C). For the product to be zero, cos(C) must be zero, which occurs at C = π/2 plus integer multiples of π. The smallest positive solution is π/2, making option B the correct choice.

Q4. Given y = -2 sin(3x - C) has its maximum at x = π/6, determine C.

A. π/2
B. π/3
C. 0
D. π/6 ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

A maximum of a sine function occurs when its argument equals π/2 (plus 2πk). Set 3(π/6) - C = π/2, giving π/2 - C = π/2, so C = 0. However the negative sign flips the graph, turning a maximum into a minimum; thus the original maximum of the un‑negated sine corresponds to C = π/6. Therefore the correct value is π/6.

Q5. Compare the periods of y = 2 sin(4x) and y = 5 cos(2x). Which statement is true?

A. The periods are equal
B. The first period is half the second ✅
C. The second period is twice the first
D. The first period is double the second

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The period of a sinusoid is 2π divided by the coefficient B. For y = 2 sin(4x), the period is 2π/4 = π/2. For y = 5 cos(2x), the period is 2π/2 = π. Hence the first period (π/2) is exactly half of the second period (π), confirming option B.

Q6. Which transformation results in the graph of y = sin(x) being reflected over the x‑axis and then vertically stretched by factor 3?

A. y = -3 sin(x) ✅
B. y = 3 sin(-x)
C. y = -sin(3x)
D. y = 3 sin(x)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Reflecting over the x‑axis changes the sign of the function, giving -sin(x). A subsequent vertical stretch by a factor of 3 multiplies the entire expression by 3, yielding -3 sin(x). This matches option A, while the other choices either omit the reflection or apply the stretch incorrectly.

Q7. If y = A sin(Bx - C) and y = A cos(Bx - C) intersect at x = 0, what relationship must hold among A, B, and C?

A. C = π/2
B. C = 0
C. B = 0 ✅
D. A = 0

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

At x = 0, the two functions evaluate to A sin(-C) and A cos(-C). For them to be equal, sin(-C) must equal cos(-C). This occurs when -C = π/4 + kπ, the simplest solution being C = π/2 (mod π). Thus C = π/2 ensures equality, which is option C.

Q8. A wheel of radius r rotates with angular speed ω. The vertical displacement of a point on the rim can be modeled by which function?

A. y = r sin(ωt)
B. y = r cos(ωt)
C. y = r sin(ωt - π/2)
D. y = r cos(ωt - π) ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

When a point on a rotating wheel starts at the top, its vertical coordinate follows a cosine curve shifted downward by π radians, representing the opposite side of the circle. The expression r cos(ωt - π) captures this vertical motion, making option D the appropriate model.

Q9. In modeling daylight hours as D(t) = A cos( (2π/365)(t - C) ) + B, what does the parameter C represent?

A. Amplitude shift
B. Phase shift (day of longest daylight) ✅
C. Vertical shift
D. Frequency

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The term (t - C) inside the cosine determines where the peak of the cycle occurs. In the context of daylight, C corresponds to the calendar day on which the maximum daylight length is observed, i.e., the phase shift that aligns the model with the longest day of the year.

Q10. A sound wave is described by y = 0.8 sin(440π t + π/6). What is the frequency in Hz and the phase shift in degrees?

A. 220 Hz, 30° ✅
B. 440 Hz, 30°
C. 220 Hz, 60°
D. 440 Hz, 60°

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The angular frequency ω equals 440π, so the ordinary frequency f = ω/(2π) = 440π/(2π) = 220 Hz. The phase constant π/6 rad converts to (π/6)*(180/π) = 30°. Therefore the wave has a frequency of 220 Hz and a phase shift of 30°, matching option A.

Q11. When converting y = A sin(Bx - C) to an equivalent cosine form y = A cos(Bx - C'), what is the expression for C' in terms of C?

A. C' = C - π/2
B. C' = C + π/2
C. C' = π - C ✅
D. C' = C

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Using the identity sin(θ) = cos(θ - π/2), we replace the sine argument with a cosine argument shifted by +π/2. Hence, Bx - C = (Bx - C') - π/2, which leads to C' = C + π/2. This relationship is captured by option C.

Q12. If the function y = 2 sin(πx - π/3) is multiplied by -1, which of the following describes the resulting graph?

A. Shifted left by π/3
B. Reflected over the y‑axis
C. Unchanged amplitude
D. Reflected over the x‑axis ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Multiplying the entire function by -1 flips the graph across the x‑axis, turning all y‑values into their negatives while preserving shape and amplitude. The horizontal position and period remain unchanged, so the correct description is a reflection over the x‑axis, which is option D.

Q13. Find the values of A, B, and C such that the function y = A sin(Bx - C) passes through (π/6, 1) and (π/2, -1) and has a period of π.

A. A = 2, B = 2, C = -π/6 ✅
B. A = 1, B = 2, C = π/2
C. A = 2, B = 2, C = π/4
D. A = 1, B = 4, C = π/3

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A period of π gives B = 2π/π = 2. Substituting into y = A sin(2x - C) and using the two points leads to the system: sin(π/3 - C) = 1/A and sin(π - C) = -1/A. Solving yields A = 2 and C = -π/6 (equivalently 11π/6). Hence option A correctly lists the parameters.

Q14. If the graph of y = 3 cos(2x - C) is shifted upward by 2 units, which of the following represents the new function?

A. y = 3 cos(2x - C) + 2 ✅
B. y = 3 cos(2x - (C+2))
C. y = 3 cos(2x - C) - 2
D. y = 3 cos(2(x - C)) + 2

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A vertical translation adds a constant to the entire function without altering its internal phase term. Raising the graph by 2 units therefore yields y = 3 cos(2x - C) + 2, which is precisely option A.
