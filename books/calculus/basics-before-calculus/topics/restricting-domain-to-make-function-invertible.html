What is Restricting domain to make function invertible?

Definition:
Restricting the domain of a non-one-to-one function to a subset where it becomes one-to-one ensures invertibility, by choosing an interval where the function is strictly monotonic (increasing or decreasing).

Example:
For f(x)=sin⁡xf(x)=\sin xf(x)=sinx, restrict domain to [−π/2,π/2][-\pi/2, \pi/2][−π/2,π/2] to make it one-to-one, yielding inverse sin⁡−1(x)\sin^{-1}(x)sin−1(x) with range [−π/2,π/2][-\pi/2, \pi/2][−π/2,π/2].

Reason:
Domain restriction is practical in defining inverse trigonometric functions and in applications where only a specific branch is meaningful.
