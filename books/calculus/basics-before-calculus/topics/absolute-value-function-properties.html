What is Absolute value function properties?

Definition:
The absolute value function \( f(x) = |x| \) outputs the non-negative magnitude of \( x \), defined as \( x \) if \( x \geq 0 \) and \( -x \) if \( x < 0 \), with properties including evenness, non-negativity, and the triangle inequality.

Example:
For \( x = -3 \), \( | -3 | = 3 \), and for \( x = 4 \), \( |4| = 4 \); its graph is V-shaped with vertex at (0,0).

Reason:
These properties are essential in distance calculations, error bounds, and optimization problems, as the absolute value measures magnitude regardless of direction.
