What is Inverse trig identities formulas?

Definition:
Inverse trig identities relate inverse trigonometric functions to each other, such as \( \arcsin(x) + \arccos(x) = \pi/2 \), \( \arctan(x) + \arccot(x) = \pi/2 \), and \( \sin(\arcsin(x)) = x \), with domain restrictions, used for simplification.

Example:
For \( x = 0.5 \), \( \arcsin(0.5) + \arccos(0.5) = \pi/6 + \pi/3 = \pi/2 \), confirming the identity.

Reason:
These identities help in solving equations involving inverse trig functions and in transforming expressions for calculus or algebraic manipulation.

📝 All Inverse trig identities formulas MCQs

Q1. What is \(\sin^{-1}(0)\)?

A. 0 ✅
B. \(\frac{\pi}{2}\)
C. \(-\frac{\pi}{2}\)
D. \(\pi\)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Since \(\sin 0 = 0\) and the principal value of \(\sin^{-1}\) returns the angle in \([-\,\frac{\pi}{2},\frac{\pi}{2}]\) whose sine is the argument, the only angle satisfying this is \(0\). Hence \(\sin^{-1}(0)=0\).

Q2. Given \(x=\frac12\), what is \(\sin^{-1}x + \cos^{-1}x\)?

A. \(\frac{\pi}{4}\)
B. \(\pi\)
C. \(\frac{\pi}{2}\) ✅
D. 0

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The fundamental identity \(\sin^{-1}x+\cos^{-1}x=\frac{\pi}{2}\) holds for any \(x\) in \([-1,1]\). Substituting \(x=\frac12\) does not change the sum, so the result is \(\frac{\pi}{2}\).

Q3. Which expression equals \(\tan(\sin^{-1}x)\) for \(-1\le x\le1\)?

A. \(\sqrt{1-x^{2}}\)
B. \(\frac{\sqrt{1-x^{2}}}{x}\)
C. \(x\sqrt{1-x^{2}}\)
D. \(\frac{x}{\sqrt{1-x^{2}}}\) ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

Let \(\theta=\sin^{-1}x\); then \(\sin\theta=x\) and \(\cos\theta=\sqrt{1-x^{2}}\) (non‑negative). By definition \(\tan\theta=\frac{\sin\theta}{\cos\theta}=\frac{x}{\sqrt{1-x^{2}}}\). Hence the correct expression is \(\frac{x}{\sqrt{1-x^{2}}}\).

Q4. For which interval does \(\sin^{-1}(\sin x)=x\) hold true?

A. \([-\,\frac{\pi}{2},\frac{\pi}{2}]\) ✅
B. [0,\(\pi\)]
C. \([-\,\pi,\pi]\)
D. \([\frac{\pi}{2},\frac{3\pi}{2}]\)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The inverse sine returns the principal angle in \([-\,\frac{\pi}{2},\frac{\pi}{2}]\). Only when the original angle \(x\) lies in that interval does \(\sin^{-1}(\sin x)\) equal \(x\); otherwise the value is adjusted by adding or subtracting multiples of \(\pi\).

Q5. Using the identity \(\sec(\tan^{-1}x)=\sqrt{1+x^{2}}\), what is \(\sec(\tan^{-1}3)\)?

A. \(\sqrt{13}\)
B. \(\sqrt{10}\) ✅
C. \(\sqrt{5}\)
D. \(\sqrt{2}\)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Apply the identity directly with \(x=3\): \(\sec(\tan^{-1}3)=\sqrt{1+3^{2}}=\sqrt{10}\). This avoids constructing a triangle; the formula already gives the required value.

Q6. For \(x\ge1\), which formula gives \(\sin(\sec^{-1}x)\)?

A. \(\frac{\sqrt{x^{2}-1}}{x}\) ✅
B. \(\frac{x}{\sqrt{x^{2}-1}}\)
C. \(\sqrt{x^{2}-1}\)
D. \(\frac{1}{\sqrt{x^{2}-1}}\)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Let \(\theta=\sec^{-1}x\); then \(\sec\theta=x\) and \(\cos\theta=\frac{1}{x}\). By the Pythagorean theorem, \(\sin\theta=\sqrt{1-\cos^{2}\theta}=\sqrt{1-\frac{1}{x^{2}}}=\frac{\sqrt{x^{2}-1}}{x}\).

Q7. If \(\theta=\sin^{-1}x\), what is \(\cos\theta\) in terms of \(x\)?

A. \(-\sqrt{1-x^{2}}\)
B. \(1-x^{2}\)
C. \(\sqrt{1-x^{2}}\) ✅
D. \(x\)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Because \(\theta\) is defined to be in \([-\,\frac{\pi}{2},\frac{\pi}{2}]\), its cosine is non‑negative. Using the identity \(\sin^{2}\theta+\cos^{2}\theta=1\) and \(\sin\theta=x\), we obtain \(\cos\theta=\sqrt{1-x^{2}}\).

Q8. Let \(x=\frac{3\pi}{4}\). What is \(\sin^{-1}(\sin x)\)?

A. \(\frac{3\pi}{4}\)
B. \(\frac{\pi}{4}\) ✅
C. \(-\frac{\pi}{4}\)
D. \(-\frac{3\pi}{4}\)

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Since \(x\) lies in \([\frac{\pi}{2},\frac{3\pi}{2}]\), the principal value is \(-\,(x-\pi)=\pi-x\). Substituting \(x=\frac{3\pi}{4}\) gives \(\pi-\frac{3\pi}{4}=\frac{\pi}{4}\). Thus \(\sin^{-1}(\sin x)=\frac{\pi}{4}\).

Q9. For \(x>0\), how does \(\tan^{-1}x\) compare to \(\sin^{-1}\!\left(\frac{x}{\sqrt{1+x^{2}}}\right)\)?

A. They are equal ✅
B. \(\tan^{-1}x\) is larger
C. \(\tan^{-1}x\) is smaller
D. Cannot be determined without numerical evaluation

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Starting with a right triangle where opposite side is \(x\) and adjacent side is \(1\), the hypotenuse is \(\sqrt{1+x^{2}}\). The angle whose tangent is \(x\) is \(\tan^{-1}x\). The same angle has sine \(\frac{x}{\sqrt{1+x^{2}}}\), so \(\sin^{-1}\) of that ratio equals the same angle. Hence the two expressions are equal.

Q10. What is the principal value range of \(\cos^{-1}x\)?

A. [0,\(\pi\)] ✅
B. [-\(\frac{\pi}{2}\),\(\frac{\pi}{2}\)]
C. [0,2\(\pi\)]
D. [-\(\pi\),\(\pi\)]

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

By definition, the inverse cosine returns the unique angle \(\theta\) in \([0,\pi]\) whose cosine equals the given number. This interval ensures the function is one‑to‑one and covers all possible cosine values from \(-1\) to \(1\).

Q11. Using \(\sin^{-1}x = \tan^{-1}\!\left(\frac{x}{\sqrt{1-x^{2}}}\right)\), what is \(\sin^{-1}\!\left(\frac{1}{\sqrt{2}}\right)\)?

A. \(\frac{\pi}{6}\)
B. \(\frac{\pi}{3}\)
C. \(\frac{\pi}{2}\)
D. \(\frac{\pi}{4}\) ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Compute \(\frac{x}{\sqrt{1-x^{2}}}\) with \(x=\frac{1}{\sqrt{2}}\): the denominator becomes \(\sqrt{1-\frac12}=\frac{1}{\sqrt{2}}\), so the fraction equals \(1\). Hence \(\sin^{-1}\!\left(\frac{1}{\sqrt{2}}\right)=\tan^{-1}(1)=\frac{\pi}{4}\).

Q12. If \(\sin^{-1}x = \alpha\) and \(\cos^{-1}x = \beta\), what is \(\alpha - \beta\)?

A. 0
B. \(\frac{\pi}{2}\)
C. \(-\frac{\pi}{2}\)
D. It depends on the value of \(x\) ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

From the identity \(\alpha+\beta=\frac{\pi}{2}\), we can solve for \(\alpha-\beta = 2\alpha-\frac{\pi}{2}\). Since \(\alpha\) varies with \(x\), the difference is not a constant; it changes according to the specific \(x\) chosen.

Q13. Given the extended identity \(\sin(\sec^{-1}x)=\frac{\sqrt{x^{2}-1}}{|x|}\) for \(|x|\ge1\), what is \(\sin(\sec^{-1}(-2))\)?

A. \(-\frac{\sqrt{3}}{2}\)
B. \(\frac{\sqrt{3}}{2}\) ✅
C. \(-\frac{\sqrt{3}}{-2}\)
D. \(\frac{\sqrt{3}}{-2}\)

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Apply the formula with \(x=-2\): \(|x|=2\) and \(\sqrt{x^{2}-1}=\sqrt{4-1}=\sqrt{3}\). The expression becomes \(\frac{\sqrt{3}}{2}\), which is positive because the absolute value in the denominator removes the sign of \(x\).

Q14. Which of the following statements is true for all \(x\) with \(|x|\ge1\)?

A. \(\sin(\sec^{-1}x)=\frac{x}{\sqrt{x^{2}-1}}\)
B. \(\sin(\sec^{-1}x)=\frac{\sqrt{x^{2}-1}}{x}\)
C. \(\sin(\sec^{-1}x)=\frac{\sqrt{x^{2}-1}}{|x|}\) ✅
D. \(\sin(\sec^{-1}x)=\sqrt{x^{2}-1}\)

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The correct form must handle both positive and negative \(x\). The identity \(\sin(\sec^{-1}x)=\frac{\sqrt{x^{2}-1}}{|x|}\) does exactly that, because the absolute value in the denominator ensures the result is always non‑negative, matching the range of the sine function for the principal angle.
