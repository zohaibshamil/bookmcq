📝 All Domain and range of a function MCQs

Q1. What is the domain of a function?

🔹 A. Set of all possible outputs
🔹 B. Set of all possible inputs
🔹 C. Set of y‑values where the function is continuous
🔹 D. Set of x‑values where the function equals zero

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The domain consists of every x‑value for which the function produces a real output. It is the collection of admissible inputs, i.e., all possible x‑values that can be substituted into the rule without causing undefined operations such as division by zero or taking square roots of negatives.

Q2. The vertical line test states that a curve in the xy‑plane represents a function of x if and only if…

🔹 A. every horizontal line meets the curve at most once
🔹 B. no vertical line intersects the curve more than once
🔹 C. the curve is symmetric about the y‑axis
🔹 D. the curve passes through the origin

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The vertical line test checks each vertical line x = c for multiple intersections. If any vertical line meets the curve at two or more points, the relation cannot assign a unique y‑value to that x, violating the definition of a function. Hence the test requires at most one intersection for each vertical line.

Q3. If a vertical line at \(x = a\) intersects a curve at two points \((a,b)\) and \((a,c)\) with \(b \neq c\), what can be concluded about the relation?

🔹 A. It is a function
🔹 B. It fails the vertical line test
🔹 C. It is bijective
🔹 D. It has an inverse

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Two distinct points sharing the same x‑coordinate mean the relation assigns two different y‑values to a single input. This directly violates the definition of a function, which requires exactly one output for each input. Therefore the relation fails the vertical line test and cannot be a function.

Q4. A curve passes the vertical line test everywhere except at \(x = 2\), where it touches the line at a single point. Does the relation define a function on \(\mathbb{R}\)?

🔹 A. Yes, because the line meets the curve at most once
🔹 B. No, because any intersection violates the test
🔹 C. It depends on the y‑values at \(x=2\)
🔹 D. Insufficient information to decide

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The vertical line test permits at most one intersection per vertical line. Touching the line at a single point still satisfies the “at most once” condition, so the relation meets the criteria for a function across its entire domain, including \(x = 2\).

Q5. Find the domain of \(f(x)=\frac{1}{x-3}\).

🔹 A. All real numbers
🔹 B. All real numbers except 3
🔹 C. All real numbers except 0
🔹 D. x>3

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The denominator \(x-3\) cannot be zero because division by zero is undefined. Setting \(x-3=0\) yields \(x=3\). Consequently every real number except 3 is permissible, giving the domain \(\mathbb{R}\setminus\{3\}\).

Q6. A function \(f\) passes the vertical line test but fails the horizontal line test. Which statement about its inverse \(f^{-1}\) is true?

🔹 A. The inverse exists and is a function
🔹 B. The inverse does not exist as a function
🔹 C. The inverse exists but is not unique
🔹 D. The inverse is also not a function

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Passing the vertical line test guarantees \(f\) is a function, but failing the horizontal line test means \(f\) is not one‑to‑one. Without the one‑to‑one property, an inverse relation cannot assign a unique x‑value to each y, so \(f^{-1}\) is not a function.

Q7. Given that a function fails the vertical line test at \(x = -1\) but passes elsewhere, what can be said about its invertibility?

🔹 A. It is not invertible on its whole domain
🔹 B. It becomes invertible after restricting its domain
🔹 C. It is always invertible
🔹 D. It is invertible only if the range excludes certain values

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The failure at \(x = -1\) indicates the function is not one‑to‑one over the entire domain. By removing or restricting the problematic x‑value (or the corresponding y‑values), the remaining portion can become one‑to‑one, allowing an inverse function to exist on that restricted domain.

Q8. Compare the domains of \(f(x)=\sqrt{x-2}\) and \(g(x)=\frac{1}{x-2}\). Which statement is correct?

🔹 A. Both have domain \(x>2\)
🔹 B. \(f\) requires \(x\ge 2\) while \(g\) requires \(x\neq 2\)
🔹 C. Both require \(x\neq 2\)
🔹 D. \(f\) domain is all real numbers, \(g\) domain \(x\neq 2\)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The square‑root function demands the radicand be non‑negative, giving \(x-2\ge0\) or \(x\ge2\). The rational function cannot have a zero denominator, so \(x-2\neq0\) or \(x\neq2\). Thus \(f\) allows \(x=2\) while \(g\) excludes it, matching option B.

Q9. What is the range of \(f(x)=-(x-3)^2+4\)?

🔹 A. All real numbers
🔹 B. All numbers ≤ 4
🔹 C. All numbers ≥ 4
🔹 D. All numbers between \(-\infty\) and 4

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The expression \(-(x-3)^2\) is always non‑positive, attaining its maximum value 0 when \(x=3\). Adding 4 shifts this maximum to 4. Therefore the function never exceeds 4 and can take any value less than or equal to 4, giving the range \((-\infty,4]\).

Q10. When solving \(x^2 = 9\) by squaring both sides of \(x = \sqrt{9}\), why might extraneous solutions appear?

🔹 A. Squaring is reversible
🔹 B. Squaring introduces sign ambiguity
🔹 C. The square‑root function is multi‑valued
🔹 D. No extraneous solutions appear

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Squaring eliminates the distinction between positive and negative roots. Starting from \(x = \sqrt{9}=3\) and squaring yields \(x^2=9\), which also admits \(x=-3\) as a solution. The squaring step therefore creates an extra solution that was not present in the original equation, leading to extraneous roots.

Q11. If \(f(x)=x^2\) has range \([0,\infty)\), what is the range of \(g(x)=f(x)+5\)?

🔹 A. [5,\(\infty\))
🔹 B. \((-\infty,5]\)
🔹 C. [0,5)
🔹 D. All real numbers

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Adding a constant shifts every output upward by that constant. Since the smallest value of \(f(x)\) is 0, the smallest value of \(g(x)=x^2+5\) becomes \(0+5=5\). All larger values are also increased by 5, so the range becomes \([5,\infty)\).

Q12. Which of the following relations definitely satisfies the vertical line test?

🔹 A. \(y = x^3 - x\)
🔹 B. \(x^2 + y^2 = 4\)
🔹 C. \(y^2 = x\)
🔹 D. \(y = \sqrt{x} + \sqrt{-x}\)

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The polynomial \(y = x^3 - x\) gives a single y‑value for each x, so no vertical line can intersect it more than once. The circle equation, the sideways parabola, and the expression involving \(\sqrt{-x}\) each produce at least one vertical line intersecting the curve twice, violating the test.

Q13. Does the relation defined by \(x^2 + y^2 = 9\) represent a function \(y = f(x)\)?

🔹 A. Yes, because each x has a unique y
🔹 B. No, because the vertical line test fails
🔹 C. Yes, after solving for y
🔹 D. No, because the domain is empty

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The equation describes a circle centered at the origin. A vertical line with \(|x|<3\) meets the circle at two points, providing two different y‑values for the same x. This violates the vertical line test, so the relation cannot be expressed as a single‑valued function of x.

Q14. For the composition \(h(x)=\sqrt{1 - x^2}\), what is the domain and range?

🔹 A. Domain \([-1,1]\), range \([0,1]\)
🔹 B. Domain \((-\infty,\infty)\), range \([0,1]\)
🔹 C. Domain \([-1,1]\), range \((-\infty,0]\)
🔹 D. Domain \([0,1]\), range \([0,1]\)

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The radicand \(1 - x^2\) must be non‑negative, giving \(-1\le x\le 1\). The square root then yields values from 0 up to the square root of 1, i.e., 1. Hence the domain is \([-1,1]\) and the range is \([0,1]\).

Q15. Why does the function \(f(x)=\frac{1}{x}\) have range \(\mathbb{R}\setminus\{0\}\)?

🔹 A. Because the denominator never zero
🔹 B. Because the output can never be zero
🔹 C. Because the domain excludes zero
🔹 D. Because the function is even

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

For any non‑zero real number \(y\), we can solve \(y = 1/x\) to obtain \(x = 1/y\), which is defined as long as \(y\neq0\). However, there is no real \(x\) that yields \(f(x)=0\) because \(1/x\) is never zero. Thus the range excludes only 0.

Q16. Determine the domain of the piecewise function \(f(x)=\begin{cases}\sqrt{x}, & x\ge0 \\ \ln(x), & x>0\end{cases}\).

🔹 A. \(x>0\)
🔹 B. \(x\ge0\)
🔹 C. \(x\neq0\)
🔹 D. All real numbers

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Both pieces require positive arguments: \(\sqrt{x}\) allows \(x=0\) but \(\ln(x)\) does not. Since the function must be defined for every x in its domain, the stricter condition \(x>0\) governs, excluding zero and negative numbers.

Q17. Explain how the one‑to‑one property relates to the vertical line test and the existence of an inverse function.

🔹 A. One‑to‑one ensures each y maps to a single x, making the inverse a function
🔹 B. One‑to‑one is unrelated
🔹 C. Vertical line test checks horizontal lines
🔹 D. Inverse exists only if the range is all real numbers

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A function is one‑to‑one when no two distinct x‑values share the same y‑value. This is equivalent to the graph passing the vertical line test without any vertical line intersecting more than once. When the function is one‑to‑one, each y corresponds to exactly one x, allowing the inverse relation to assign a unique input to each output, thus forming a proper function.

Q18. If a graph is intersected twice by the vertical line \(x=4\), what does this imply about representing the relation as a function?

🔹 A. It can be a function after redefining at \(x=4\)
🔹 B. It cannot be a function on any domain containing 4
🔹 C. It is always a function
🔹 D. It is a function only if the two points have the same y‑value

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Two distinct points sharing the same x‑coordinate mean the relation assigns two different y‑values to that x. This violates the definition of a function for any domain that includes \(x=4\). Therefore the relation cannot be expressed as a function on any set containing that x‑value.
