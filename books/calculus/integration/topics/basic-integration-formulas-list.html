Q1. A student uses the power rule to evaluate \( \int x^{-1} \, dx \) and obtains \( \frac{x^{0}}{0} + C \). What is the fundamental error in this approach?

🔹 A. The power rule is invalid for \( r = -1 \) because it leads to division by zero, so the integral should be evaluated as \( \ln|x| + C \).
🔹 B. The student should have used the product rule instead.
🔹 C. The constant of integration should be zero in this case.
🔹 D. The error is that the variable of integration was not specified correctly.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The power rule for integration, \( \int x^r \, dx = \frac{x^{r+1}}{r+1} + C \), fails when \( r = -1 \) because it results in division by zero. This is the foundational reason why the integral of \( 1/x \) is a special case, resulting in the natural logarithm function \( \ln|x| + C \). The student's attempt to apply the power rule in this case shows a lack of understanding of its limitations and the exceptional nature of the reciprocal function.

Q2. A student evaluates \( \int \sec x \tan x \, dx \) and gets \( \ln|\sec x| + C \). Is this correct, and if not, what is the correct result?

🔹 A. No, the correct result is \( \sec x + C \).
🔹 B. No, the correct result is \( \csc x + C \).
🔹 C. No, the correct result is \( \ln|\sec x + \tan x| + C \).
🔹 D. Yes, it is correct.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The derivative of \( \sec x \) is \( \sec x \tan x \). Therefore, the antiderivative of \( \sec x \tan x \) is \( \sec x + C \). The student's answer, \( \ln|\sec x| + C \), is the antiderivative of \( \tan x \). This is a Easy question testing the knowledge of standard trigonometric derivatives and their corresponding integration formulas, which are fundamental to integral calculus.

Q3. Given the derivative formula \( \frac{d}{dx}[ \tan^{-1} x ] = \frac{1}{1 + x^2} \), what is the correct corresponding integration formula?

🔹 A. \( \int \frac{1}{1 + x^2} \, dx = \tan^{-1} x + C \)
🔹 B. \( \int \tan^{-1} x \, dx = \frac{1}{1 + x^2} + C \)
🔹 C. \( \int \frac{1}{1 + x^2} \, dx = -\cot^{-1} x + C \)
🔹 D. \( \int \sec^{-1} x \, dx = \frac{1}{1 + x^2} + C \)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The integration formula is the inverse operation of differentiation. If the derivative of \( \tan^{-1} x \) is \( 1/(1+x^2) \), then the integral of \( 1/(1+x^2) \) is \( \tan^{-1} x \). The constant of integration, \( C \), is essential to represent the family of all antiderivatives. This question tests the fundamental relationship between differentiation and integration, a core concept in calculus.

Q4. What is the general antiderivative of \( f(x) = \frac{1}{\sqrt{1 - x^2}} \)?

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The derivative of \( \sin^{-1} x \) is \( 1/\sqrt{1-x^2} \), and the derivative of \( -\cos^{-1} x \) is also \( 1/\sqrt{1-x^2} \). Since antiderivatives can differ by a constant, both \( \sin^{-1} x + C \) and \( -\cos^{-1} x + C \) are correct. This highlights the fact that antiderivatives are not unique and can be expressed in multiple ways due to trigonometric identities, which is a key Medium in integration.

Q5. Evaluate the integral \( \int 4 \cos x \, dx \).

🔹 D. \( \sin 4x + C \)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Using the constant multiple rule and the basic integral of cosine, \( \int 4 \cos x \, dx = 4 \int \cos x \, dx = 4 \sin x + C \). The constant \( C \) is a single arbitrary constant. Option C is incorrect because it introduces an unnecessary constant \( 4C \), which is still just an arbitrary constant and should be simplified. This question assesses the ability to apply a standard formula and the property of constants in integration.

Q6. A student claims that \( \int (x^2 + 1) \, dx = \int x^2 \, dx + \int 1 \, dx \) because integration distributes over sums. Is this a valid Easy of the properties of indefinite integrals?

🔹 A. Yes, it is valid and it simplifies to \( \frac{x^3}{3} + x + C \).
🔹 B. No, this is incorrect; integration does not distribute over sums.
🔹 C. Yes, it is valid, but the constant of integration must be zero.
🔹 D. No, the correct way is to use the product rule.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The sum/difference rule for indefinite integrals states that the integral of a sum is the sum of the integrals. This is a direct consequence of the sum rule for derivatives. The student's statement is a correct Easy of this property. The correct evaluation is \( \frac{x^3}{3} + x + C \). This question tests the understanding of the linearity of integration, a fundamental property.

Q7. A student evaluates \( \int \frac{1}{\sqrt{x}} \, dx \) as \( \frac{1}{-\frac{1}{2}} x^{-\frac{1}{2}} + C = -2x^{-\frac{1}{2}} + C \), but a friend gets \( 2\sqrt{x} + C \). Who is correct?

🔹 A. The friend is correct; the student made an error in the exponent.
🔹 B. The student is correct; the friend made an error.
🔹 C. Both are correct because they differ by a constant.
🔹 D. Neither is correct; the correct answer is \( \frac{2}{\sqrt{x}} + C \).

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The function \( 1/\sqrt{x} = x^{-1/2} \). Applying the power rule, \( \int x^{-1/2} \, dx = \frac{x^{1/2}}{1/2} + C = 2x^{1/2} + C = 2\sqrt{x} + C \). The student incorrectly added 1 to the exponent \( -1/2 \) to get \( 1/2 \) but then used the derivative rule instead of the integration rule. This is a classic error in applying the power rule for integration.

Q8. Consider the integral \( I = \int x \sin(x^2) \, dx \). Which of the following statements correctly identifies the need for a specific integration technique?

🔹 A. No special technique is needed; the integral is a standard formula \( -\cos(x^2) + C \).
🔹 B. A \( u \)-substitution is needed with \( u = x^2 \), turning it into a standard sine integral.
🔹 C. Integration by parts is required because it's a product of two functions.
🔹 D. This integral is impossible to evaluate in terms of elementary functions.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

This integral is a perfect candidate for \( u \)-substitution. Let \( u = x^2 \), then \( du = 2x \, dx \). The integral becomes \( \frac{1}{2} \int \sin u \, du = -\frac{1}{2} \cos u + C = -\frac{1}{2} \cos(x^2) + C \). Recognizing the composition of functions where the derivative of the inner function is present is the skill being tested here, linking substitution to standard formulas.

Q9. Which of the following is the correct evaluation of \( \int \frac{x^2 + 1}{x^2} \, dx \) by first simplifying the integrand?

🔹 A. \( \int (1 + x^{-2}) \, dx = x - \frac{1}{x} + C \)
🔹 B. \( \int (1 + 1) \, dx = 2x + C \)
🔹 C. \( \int (x^2 + 1) \cdot x^{-2} \, dx = -\frac{1}{3}x^{-3} - x^{-1} + C \)

💡 Difficulty: easy | ✅ Correct: A

This is a multi-step problem. First, simplify the integrand by dividing each term in the numerator by \( x^2 \), giving \( 1 + x^{-2} \). Then apply the power rule: \( \int 1 \, dx + \int x^{-2} \, dx = x - \frac{1}{x} + C \). Option A is correct. This tests the ability to manipulate an algebraic expression to make it integrable using basic formulas, a crucial skill in calculus.

We need to find the antiderivative of each term. The antiderivative of \( \sec^2 x \) is \( \tan x \). The antiderivative of \( \csc x \cot x \) is \( -\csc x \). This question tests the student's ability to recognize derivatives of trigonometric functions in reverse, which is the basis of integration, and to apply the sum rule.

The natural logarithm function \( \ln x \) is only defined for positive real numbers. The integral \( \int \frac{1}{x} \, dx \) requires the absolute value to extend the domain to \( x < 0 \). Q14. A particle's velocity is given by \( v(t) = \cos t \). Given that its initial position is \( s(0) = 0 \), what is its position function \( s(t) \) based on the integral of velocity?

🔹 A. \( \sin t \)

🔹 C. \( \sin t + 1 \)
🔹 D. \( -\cos t \)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Position is the antiderivative of velocity. \( \int \cos t \, dt = \sin t + C \). Using the initial condition \( s(0) = 0 \), we have \( 0 = \sin(0) + C \), so \( C = 0 \). Therefore, \( s(t) = \sin t \). This applies the integral of cosine to solve a classic physics problem, linking calculus to rectilinear motion.

Q17. A student applies the formula \( \int \frac{1}{1+x^2} \, dx = \tan^{-1} x + C \) to evaluate \( \int \frac{1}{4+x^2} \, dx \) and incorrectly obtains \( \tan^{-1}(x/2) + C \). What is the correct result?

Q19. The derivative of \( e^x \) is \( e^x \). What is the integral of \( 5e^x \), and how does the constant factor affect the antiderivative?

🔹 A. \( 5e^x + C \), the constant factor is pulled out of the integral.

This question tests the understanding of the constant multiple rule and the meaning of the constant of integration. Option B is a common mistake where students think constants multiply within the function.

Q20. A velocity function is modeled by \( v(t) = \frac{1}{1+t^2} \). What is the displacement function \( s(t) \) if \( s(0) = 0 \), and how does this relate to the area under the curve?

🔹 A. \( s(t) = \tan^{-1} t \), which represents the area under \( v \) from 0 to \( t \).
🔹 B. \( s(t) = \tan^{-1} t + 1 \), because you must add 1.
🔹 C. \( s(t) = \sec^{-1} t \), which represents the area under \( v \).
🔹 D. \( s(t) = \ln(1+t^2) \), which represents the area under \( v \).

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Displacement is the antiderivative of velocity. \( \int \frac{1}{1+t^2} \, dt = \tan^{-1} t + C \). With \( s(0) = 0 \), \( C = 0 \). Thus \( s(t) = \tan^{-1} t \). By the Fundamental Theorem of Calculus, \( s(t) = \int_0^t v(u) \, du \), which is the area under the velocity curve from 0 to \( t \). This directly links the integration formula for \( 1/(1+x^2) \) to a physical interpretation.

Q21. Given that the derivative of \( \sec x \) is \( \sec x \tan x \), what is the derivative of \( \int \sec x \tan x \, dx \) if the constant of integration is \( C \)?

🔹 A. \( \sec x \tan x \)
🔹 B. \( \sec x + C \)
🔹 C. \( \sec x \tan x + C \)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The Fundamental Theorem of Calculus states that if \( F(x) = \int f(x) \, dx \), then \( F'(x) = f(x) \). Since \( \int \sec x \tan x \, dx = \sec x + C \), its derivative is \( \sec x \tan x \). The constant \( C \) disappears upon differentiation. This question tests the inverse relationship between differentiation and integration, a core concept.

Q22. A curve has the property that its slope at any point \( (x, y) \) is \( 3x^2 \). What is the equation of the curve if it passes through \( (1, 2) \)?

The slope is \( dy/dx = 3x^2 \). Integrating gives \( y = x^3 + C \). Using the point \( (1, 2) \): \( 2 = 1^3 + C \), so \( C = 1 \). Thus \( y = x^3 + 1 \). This applies integration formulas to solve a geometric problem, connecting calculus to curves and slopes.

Q23. A student integrates \( \int \frac{x}{x^2+1} \, dx \) and gets \( \ln(x^2+1) + C \). Analyze the error and provide the correct solution.

🔹 A. The student forgot the factor \( \frac{1}{2} \); the correct answer is \( \frac{1}{2} \ln|x^2+1| + C \).
🔹 B. The student used the wrong formula; the correct answer is \( \tan^{-1} x + C \).

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Let \( u = x^2+1 \), then \( du = 2x \, dx \). So \( \int \frac{x}{x^2+1} \, dx = \frac{1}{2} \int \frac{1}{u} \, du = \frac{1}{2} \ln|u| + C = \frac{1}{2} \ln(x^2+1) + C \). The student forgot the factor \( 1/2 \) from the chain rule. This is a classic \( u \)-substitution error, testing the ability to apply the technique correctly.

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The student's understanding is incomplete. While the derivative of \( \ln x \) is \( 1/x \) for \( x > 0 \), the function \( 1/x \) is defined for all \( x \neq 0 \). The antiderivative must be valid for all \( x \neq 0 \). The function \( \ln|x| \) satisfies this because its derivative is \( 1/x \) for both positive and negative \( x \). This highlights the importance of domain when finding antiderivatives. The constant of integration \( C \) is also crucial, as it represents the entire family of functions whose derivative is \( 1/x \).

Q30. Evaluate the following integral by first rewriting the integrand using a trigonometric identity: \( \int \sec^2 x \tan x \, dx \).

🔹 A. \( \frac{1}{2} \sec^2 x + C \)
🔹 B. \( \frac{1}{2} \tan^2 x + C \)
🔹 C. \( \sec x + C \)
🔹 D. Both A and B are correct.

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

This integral can be solved using two different substitutions. If \( u = \sec x \), \( du = \sec x \tan x \, dx \), the integral becomes \( \int u \, du = \frac{1}{2} u^2 + C = \frac{1}{2} \sec^2 x + C \). If \( u = \tan x \), \( du = \sec^2 x \, dx \), the integral becomes \( \int u \, du = \frac{1}{2} u^2 + C = \frac{1}{2} \tan^2 x + C \). Since \( \frac{1}{2} \sec^2 x = \frac{1}{2} (\tan^2 x + 1) \), the two results differ by a constant, and both are valid antiderivatives. This question tests the student's ability to see multiple solution paths and understand that antiderivatives are families of functions.
