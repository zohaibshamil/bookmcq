Q1. The Fresnel sine function is defined as \(S(x) = \int_{0}^{x} \sin\left(\frac{\pi t^2}{2}\right)\,dt\). What is the instantaneous rate of change of \(S(x)\) at \(x = 2\)?

🔹 A. \(\sin(2\pi)\)
🔹 B. \(\sin(\pi)\)
🔹 C. \(\sin(4\pi)\)
🔹 D. \(\cos(2\pi)\)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The Fundamental Theorem of Calculus Part 2 states that \(S'(x) = \sin\left(\frac{\pi x^2}{2}\right)\). Substituting \(x=2\) gives \(\sin\left(\frac{\pi \cdot 4}{2}\right) = \sin(2\pi)\). This tests whether students can correctly apply the theorem rather than attempting to evaluate the integral itself, which is impossible using elementary functions.

Q2. Consider the function \(F(x) = \int_{0}^{x} e^{-t^2}\,dt\). Which statement about \(F(x)\) is true?

🔹 A. \(F(x)\) is an elementary function
🔹 B. \(F(x)\) is always positive for \(x > 0\)
🔹 C. \(F(x)\) has a relative maximum at \(x=0\)
🔹 D. \(F(x)\) is decreasing on \((0, \infty)\)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The integrand \(e^{-t^2}\) is positive for all \(t\), so the integral from 0 to \(x\) is positive for \(x>0\). By the FTC, \(F'(x) = e^{-x^2} > 0\), so \(F\) is increasing, not decreasing. \(F(0)=0\), so \(x=0\) is an absolute minimum, not a maximum. The function is not elementary as it cannot be expressed using elementary functions.

Q3. A student claims that the function \(G(x) = \int_{2}^{x} \frac{1}{t}\,dt\) is the same as \(\ln x\). What is the error in this reasoning?

🔹 A. The student forgot the constant of integration
🔹 B. The student used the wrong lower limit
🔹 C. The student confused \(dt\) with \(dx\)
🔹 D. The function should be \(\ln x - \ln 2\)

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The integral \(\int_{2}^{x} \frac{1}{t}\,dt = [\ln t]_{2}^{x} = \ln x - \ln 2\). The student's claim would only be true if the lower limit was 1. This error highlights the importance of the lower limit of integration when defining functions via integrals. The constant difference is \(\ln 2\), not an arbitrary integration constant.

Q4. The error function is defined as \(\text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_{0}^{x} e^{-t^2}\,dt\). Which of the following is the correct derivative of \(\text{erf}(x)\)?

🔹 A. \(\frac{2}{\sqrt{\pi}} e^{-x}\)
🔹 B. \(\frac{2}{\sqrt{\pi}} e^{-x^2}\)
🔹 C. \(\frac{2}{\sqrt{\pi}} \int_{0}^{x} e^{-t^2}\,dt\)
🔹 D. \(\frac{2}{\sqrt{\pi}} x e^{-x^2}\)

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The derivative of an integral with a constant lower limit and a variable upper limit is found by substituting the upper limit into the integrand. Since the constant factor \(\frac{2}{\sqrt{\pi}}\) multiplies the integral, the derivative is \(\frac{2}{\sqrt{\pi}} e^{-x^2}\). Option B correctly applies the FTC, while other options confuse the integrand or forget the chain rule.

Q5. Given \(H(x) = \int_{0}^{x^2} \cos(t)\,dt\), what is \(H'(x)\)?

🔹 A. \(\cos(x^2)\)
🔹 B. \(2x\cos(x^2)\)
🔹 C. \(\cos(x^2) - 1\)
🔹 D. \(\sin(x^2)\)

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

This requires applying the chain rule to the FTC. The upper limit is \(g(x) = x^2\), so \(H'(x) = \cos(g(x)) \cdot g'(x) = \cos(x^2) \cdot 2x\). Students often forget the chain rule and incorrectly choose option A. This tests the understanding of differentiating functions defined by integrals with variable limits.

Q6. Let \(F(x) = \int_{1}^{x} \frac{\sin t}{t}\,dt\). Which of the following is NOT a correct statement?

🔹 A. \(F'(x) = \frac{\sin x}{x}\)
🔹 B. \(F(x)\) is differentiable on \((0, \infty)\)
🔹 C. The function \(F(x)\) is an elementary function
🔹 D. \(F''(x) = \frac{x\cos x - \sin x}{x^2}\)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The function \(F(x) = \int_{1}^{x} \frac{\sin t}{t}\,dt\) is the sine integral, a non-elementary function. It is differentiable by the FTC on its domain \((0, \infty)\), and its derivative is \(\frac{\sin x}{x}\). The second derivative can be computed by differentiating \(\frac{\sin x}{x}\). Only the claim that it is elementary is false.

Q7. A particle's velocity is given by \(v(t) = \int_{0}^{t} \cos(s^2)\,ds\). What is the particle's acceleration at \(t = \sqrt{\pi}\)?

🔹 A. \(-1\)
🔹 B. \(0\)
🔹 C. \(1\)
🔹 D. \(\cos(\pi)\)

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Acceleration \(a(t) = v'(t)\). By the FTC, \(v'(t) = \cos(t^2)\). At \(t = \sqrt{\pi}\), \(a = \cos(\pi) = -1\). This problem connects the concept of derivatives of integral-defined functions to physics, requiring students to apply the FTC in a modeling context. Option B is a common distractor if one assumes acceleration is zero.

Q8. Which of the following is a valid antiderivative of \(f(x) = \ln x\)?

🔹 A. \(\int_{1}^{x} \ln t\,dt\)
🔹 B. \(x\ln x - x\)
🔹 C. \(x\ln x + C\)
🔹 D. Both B and C

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

An antiderivative of \(\ln x\) is \(x\ln x - x + C\). Option A is a definite integral, not an antiderivative (it is a specific number for a given x). Option B is a valid antiderivative, and Option C represents its general family. This question tests the distinction between definite integrals, indefinite integrals, and the fundamental theorem's Easy to find antiderivatives.

Q9. The graph of \(y = f(t)\) is shown. Which statement about \(F(x) = \int_{0}^{x} f(t)\,dt\) is correct? (Assume graph shows a positive function on (0,2) and negative on (2,4))

🔹 A. \(F(x)\) is increasing on (2,4)
🔹 B. \(F(x)\) has a local maximum at \(x=2\)
🔹 C. \(F(x)\) is concave down on (0,2)
🔹 D. \(F(x)\) is always positive on (0,4)

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

If \(f(t)\) changes from positive to negative at \(x=2\), then \(F'(x) = f(x)\) changes sign from positive to negative, so \(F\) has a local maximum at \(x=2\). \(F\) decreases where \(f\) is negative, so (2,4) is decreasing. Concavity depends on \(f'(x)\), not directly from the sign of f. This requires interpreting the behavior of an integral-defined function based on its derivative.

Q10. Let \(F(x) = \int_{0}^{x} \frac{1}{1+t^2}\,dt\) and \(G(x) = \int_{0}^{x} \frac{1}{1+t^2}\,dt + 3\). Which statement is correct?

🔹 A. \(F(x)\) and \(G(x)\) are both antiderivatives of \(\frac{1}{1+x^2}\)
🔹 B. \(F'(x) = G'(x)\)
🔹 C. \(G(x) = F(x) + 3\)
🔹 D. All of the above

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Since \(F'(x) = \frac{1}{1+x^2}\) and \(G'(x) = F'(x) + 0\), both are antiderivatives. By definition, \(G(x) = F(x) + 3\). This consolidates the understanding that adding a constant to an integral-defined function produces another function with the same derivative, illustrating the general antiderivative concept.

Q11. A common mistake is to write \(\int_{0}^{x} f(t)\,dt = F(x) - F(0)\). What is the correct interpretation of \(F(0)\)?

🔹 A. It is the constant of integration
🔹 B. It represents the value of the original function at \(x=0\)
🔹 C. It is the area from 0 to 0
🔹 D. All of the above

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

\(F(0) = \int_{0}^{0} f(t)\,dt = 0\). It is often thought of as the 'constant' that disappears when evaluating a definite integral, but here it's a specific value from the antiderivative. This clarifies the relationship between definite and indefinite integrals and the role of the lower limit. Mistaking it for an arbitrary constant is a common misconception.

Q12. The function \(L(x) = \int_{1}^{x} \frac{1}{t}\,dt\) is defined for \(x > 0\). Which of the following is the most accurate description of \(L(x)\)?

🔹 A. It is a continuous function
🔹 B. It is differentiable on \((0, \infty)\)
🔹 C. It is the natural logarithm function
🔹 D. All of the above

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

The integral \(\int_{1}^{x} \frac{1}{t}\,dt\) is the definition of the natural logarithm. By the FTC, it is differentiable (and therefore continuous) on its domain. Options A, B, and C are all correct characterizations. This question tests the foundational definition of logarithms via integrals and the resulting properties.

Q13. For \(F(x) = \int_{0}^{x} \cos(t^2)\,dt\), what is the limit \(\lim_{x \to 0} \frac{F(x)}{x}\)?

🔹 A. \(0\)
🔹 B. \(1\)
🔹 C. \(\cos(0)\)
🔹 D. \(-1\)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

By the definition of the derivative and the FTC, \(\lim_{x \to 0} \frac{F(x) - F(0)}{x} = F'(0) = \cos(0^2) = 1\). Since \(F(0)=0\), this limit is exactly \(F'(0)\). This problem combines the definition of the derivative with the FTC, testing a deeper understanding of both concepts. Options A and D are common misconceptions.

Q14. A population model uses \(P(t) = 1000 + \int_{0}^{t} \frac{500}{1+s^2}\,ds\). What is the population growth rate at \(t = 1\)?

🔹 A. \(500\)
🔹 B. \(250\)
🔹 C. \(500\) people per year
🔹 D. \(250\) people per year

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The growth rate is \(P'(t) = \frac{500}{1+t^2}\). At \(t=1\), \(P'(1) = 250\). This is an Easy problem that requires differentiating the integral-defined function and interpreting the result in a real-world context (people per year). Students must also handle the units correctly, recognizing that the derivative gives a rate.

Q15. Which of the following functions is a valid antiderivative of \(f(x) = e^{x^2}\)?

🔹 A. \(\int_{0}^{x} e^{t^2}\,dt\)
🔹 B. \(\frac{1}{2x} e^{x^2}\)
🔹 C. \(e^{x^2} + C\)
🔹 D. \(\int e^{x^2}\,dx\)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The function \(F(x) = \int_{0}^{x} e^{t^2}\,dt\) has derivative \(e^{x^2}\) by the FTC, so it is an antiderivative. This is a key Easy of Part 2 of the FTC, showing that even when an antiderivative cannot be expressed in elementary terms, it can be defined as an integral. Option A is the correct conceptual representation of an antiderivative.

Q16. You are evaluating \(\frac{d}{dx}\int_{x}^{1} \sin(t^3)\,dt\). What is the correct first step?

🔹 A. \(\sin(1) - \sin(x^3)\)
🔹 B. \(-\sin(x^3)\)
🔹 C. \(\sin(x^3)\)
🔹 D. \(\int_{x}^{1} \cos(t^3)\,dt\)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The integral limits need to be reversed or the property of definite integrals applied. The derivative is \(-\sin(x^3)\). This is a common error because students often forget to apply the negative sign when the variable is in the lower limit. Correct Easy is: \(\frac{d}{dx}\int_{x}^{1} f(t)\,dt = -f(x)\).

Q17. The function \(F(x) = \int_{0}^{x} f(t)\,dt\) represents the area under a curve \(y=f(t)\). If \(f(t)\) is negative on \((0,2)\), what is true about \(F(x)\) on that interval?

🔹 A. \(F(x)\) is increasing
🔹 B. \(F(x)\) is negative and decreasing
🔹 C. \(F(x)\) is decreasing
🔹 D. \(F(x)\) is constant

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

If \(f(t)\) is negative, then \(F'(x) = f(x) < 0\), so \(F(x)\) is decreasing. The value of \(F(x)\) will be negative (since integrating negative values yields a negative cumulative area), but the question specifically asks about its behavior, which is decreasing. This interprets the geometric meaning of the derivative of an area function.

Q18. Let \(F(x) = \int_{0}^{x} \sqrt{1+t^2}\,dt\). What is \(F''(x)\)?

🔹 A. \(\sqrt{1+x^2}\)
🔹 B. \(\frac{x}{\sqrt{1+x^2}}\)
🔹 C. \(2x\sqrt{1+x^2}\)
🔹 D. \(\frac{1}{\sqrt{1+x^2}}\)

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

\(F'(x) = \sqrt{1+x^2}\). The second derivative is the derivative of this, which is \(\frac{x}{\sqrt{1+x^2}}\). This question requires applying the FTC to find the first derivative and then differentiating again. It tests understanding of higher-order derivatives of integral-defined functions. Option A is a common mistake if one forgets to differentiate the derivative.

Q19. A student defines a new function \(F(x) = \int_{0}^{x} \sin(t)\,dt\) and states that the area under \(y=\sin t\) from 0 to \(x\) is \(-1\) when \(x = \pi\). What is the error?

🔹 A. The student misinterpreted the lower limit
🔹 B. The area is always positive, but the integral gives signed area
🔹 C. The student used radians incorrectly
🔹 D. The integral is \(\cos x - 1\)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The definite integral \(\int_{0}^{\pi} \sin t\,dt = 2\), which is positive. The student's conclusion of \(-1\) is incorrect. The integral gives the net signed area. While the total positive area from 0 to \(\pi\) is 2. The error lies in not evaluating the integral correctly or misunderstanding signed vs. total area.

Q20. Which of the following is a correct interpretation of \(F(x) = \int_{a}^{x} f(t)\,dt\)?

🔹 A. \(F(x)\) is the antiderivative of \(f\) that passes through \((a, 0)\)
🔹 B. \(F(x)\) is the antiderivative of \(f\) with constant \(C = -F(a)\)
🔹 C. \(F(x)\) is the cumulative net area from \(a\) to \(x\)
🔹 D. All of the above

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

By the FTC, \(F(x)\) is indeed the antiderivative of \(f(x)\) with \(F(a) = \int_{a}^{a} f(t)\,dt = 0\). Any other antiderivative \(G(x) = F(x) + C\) will have \(G(a) = C\). Therefore, \(F(x) = G(x) - G(a)\), so the constant is \(C = -F(a)\). It is also the cumulative net area. This question ties together the multiple interpretations of a function defined by an integral.

Q21. The function \(F(x) = \int_{0}^{x} \frac{1}{1+t^4}\,dt\) is known to be bounded. Why?

🔹 A. The integrand is always positive
🔹 B. The integrand is continuous on \([0,\infty)\)
🔹 C. The integrand approaches 0 as \(t \to \infty\)
🔹 D. All of the above

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The integrand is positive, continuous, and \(\lim_{t\to\infty} \frac{1}{1+t^4}=0\). This implies the improper integral converges, so \(F(x)\) is bounded above. This is a conceptual question that uses the properties of the integral-defined function to reason about its behavior at infinity. It requires synthesizing multiple facts about the integrand to make a global statement.

Q22. If \(F(x) = \int_{0}^{x} \cos(t)\,dt\), what is the equation of the tangent line to \(F(x)\) at \(x = \pi\)?

🔹 A. \(y = 0\)
🔹 B. \(y = -x + \pi\)
🔹 C. \(y = \pi\)
🔹 D. \(y = -x\)

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

\(F'(x) = \cos x\), so \(F'(\pi) = -1\). \(F(\pi) = \int_{0}^{\pi} \cos t\,dt = 0\). The tangent line is \(y - 0 = -1(x - \pi)\), or \(y = -x + \pi\). This problem combines the FTC with finding tangent lines, requiring students to find both the function value and the derivative at a point.

Q23. A common mistake is to evaluate \(\frac{d}{dx}\int_{0}^{x^2} \sin(t)\,dt\) as \(\sin(x^2)\). What is the missing factor?

🔹 A. \(2\)
🔹 B. \(2x\)
🔹 C. \(x\)
🔹 D. \(\sin(x^2)\)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The derivative is \(\sin(x^2) \cdot 2x\). The missing factor is \(2x\), which comes from the chain rule. This is a classic error in applying the FTC with variable limits. The question targets this specific misconception by making the incorrect answer a tempting distractor and asking to identify the missing piece.

Q24. Consider the function \(F(x) = \int_{1}^{x} \frac{1}{t}\,dt\). Without calculating directly, what is \(F(e^3)\)?

🔹 A. \(1\)
🔹 B. \(2\)
🔹 C. \(3\)
🔹 D. \(e\)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

\(F(x) = \ln x\). Therefore, \(F(e^3) = \ln(e^3) = 3\). This question tests whether students recognize the integral as the definition of the natural logarithm. It avoids direct computation, focusing on the fundamental relationship between the integral and the logarithmic function. Option C is the correct conceptual answer.

Q25. For the Fresnel cosine function \(C(x) = \int_{0}^{x} \cos\left(\frac{\pi t^2}{2}\right)\,dt\), at what values of \(x\) does \(C(x)\) have a relative extremum?

🔹 A. \(\sqrt{2n+1}\) for integers \(n\)
🔹 B. \(\sqrt{4n+1}\) for integers \(n\)
🔹 C. \(x = 0\) only
🔹 D. \(\sqrt{2n}\) for integers \(n\)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Relative extrema of \(C(x)\) occur when \(C'(x) = \cos\left(\frac{\pi x^2}{2}\right) = 0\). This occurs when \(\frac{\pi x^2}{2} = \frac{\pi}{2} + n\pi\), so \(x^2 = 1 + 2n\), and \(x = \sqrt{2n+1}\). This question demands solving the derivative equation, interpreting the trigonometric condition, and correctly identifying all critical points. It's a Easy problem.

Q26. A function is defined as \(F(x) = \int_{0}^{x} f(t)\,dt\). If the graph of \(f\) is a straight line passing through the origin with slope 2, what is \(F(x)\)?

🔹 A. \(x^2\)
🔹 B. \(\frac{1}{2}x^2\)
🔹 C. \(2x\)
🔹 D. \(x^2 + C\)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

If \(f(t) = 2t\), then \(F(x) = \int_{0}^{x} 2t\,dt = [t^2]_{0}^{x} = x^2\). This requires finding the function from its derivative's geometric description, applying the FTC, and evaluating the integral. It connects geometry, algebra, and calculus concepts to determine the specific function.
