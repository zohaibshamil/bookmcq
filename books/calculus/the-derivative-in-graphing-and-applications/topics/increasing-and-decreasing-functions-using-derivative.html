What is Increasing and decreasing functions using derivative?

Definition:
A function f(x)f(x)f(x) is increasing on an interval if f′(x)>0f'(x) > 0f′(x)>0 and decreasing if f′(x)<0f'(x) < 0f′(x)<0. This derivative test determines monotonicity by analyzing the sign of the first derivative across specific domains to understand rate of change behavior.

Example:
For f(x)=x2f(x) = x^2f(x)=x2, f′(x)=2xf'(x) = 2xf′(x)=2x. Since 2x<02x < 02x<0 for x<0x < 0x<0, the function decreases on (−∞,0)(-\infty, 0)(−∞,0).

Reason:
The sign of the slope indicates direction; positive slope means rising values while negative slope means falling values as xxx increases.
