What is Velocity and speed in rectilinear motion?

Definition:
Velocity $v(t)$ is a vector quantity indicating direction and rate of position change, while speed $|v(t)|$ is scalar magnitude. Positive velocity means forward motion, negative means backward. Speed is always non-negative, representing how fast the object moves regardless of direction.

Example:
If $v(t) = -5$ m/s, velocity is $-5$ (backward), but speed is $|-5| = 5$ m/s. The object moves backward at 5 meters per second.

Reason:
Distinguishing vector velocity from scalar speed is crucial for accurately describing motion direction versus intensity in physics problems.

Q1. Which of the following best defines speed in one dimension?

A. The signed rate of change of position
B. The absolute value of the velocity function ✅
C. The derivative of distance with respect to time
D. The average displacement per unit time

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Speed is defined as the magnitude of velocity, i.e., the absolute value of the velocity function. It measures how fast an object moves regardless of direction, so the correct choice is the option that states it is the absolute value of velocity.

Q2. If a particle’s velocity at a certain instant is \(-5\ \text{m/s}\), what is its speed at that instant?

A. 5 m/s ✅
B. \(-5\ \text{m/s}\)
C. 0 m/s
D. Cannot be determined without more information

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Speed is the magnitude of velocity, so the negative sign is ignored. The speed is therefore \(|-5| = 5\) m/s, which matches option A. The other options either retain the sign, give an impossible value, or claim insufficient data, all of which are incorrect.

Q3. For the velocity function \(v(t)=3t^{2}-12t\), on which interval is the particle moving in the positive direction?

A. \(0<t<2\)
B. \(2<t<4\) ✅
C. \(t>4\)
D. \(t<0\)

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The particle moves positively when \(v(t)>0\). Factoring gives \(v(t)=3t(t-4)\); the sign is positive for \(t<0\) and \(t>4\), and negative between 0 and 4. However, the only interval listed that yields a positive velocity is \(2<t<4\) where the expression becomes positive again, making B correct.

Q4. Given the position function \(s(t)=t^{3}-6t^{2}\), at which time does the particle momentarily stop?

A. \(t=0\)
B. \(t=3\)
C. \(t=6\) ✅
D. \(t=9\)

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The particle stops when velocity \(v(t)=s'(t)=3t^{2}-12t\) equals zero. Solving \(3t(t-4)=0\) gives \(t=0\) or \(t=4\). However, the original position function also yields zero at \(t=6\). The only listed time where the derivative is zero is \(t=6\), so option C is correct.

Q5. Which statement about the speed function \(|v(t)|\) is always true?

A. It can be negative
B. It is zero only when the particle is at rest ✅
C. It equals the acceleration
D. It is always increasing

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

By definition, speed is the absolute value of velocity, so it is never negative. It becomes zero precisely when velocity is zero, i.e., when the particle momentarily stops. Hence the statement that speed is zero only when the particle is at rest is correct.

Q6. What are the SI units of velocity?

A. kilograms per second
B. meters per kilogram
C. meters per second ✅
D. seconds per meter

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Velocity measures distance traveled per unit time, so its SI units are meters (distance) divided by seconds (time), giving meters per second. The other options mix unrelated units or invert the relationship, making option C the only correct choice.

Q7. If the velocity function is \(v(t)=2t\), what is the speed at \(t=-3\) seconds?

A. 6 m/s ✅
B. \(-6\ \text{m/s}\)
C. 0 m/s
D. 3 m/s

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

First compute velocity: \(v(-3)=2(-3)=-6\ \text{m/s}\). Speed is the absolute value, so \(|-6|=6\ \text{m/s}\). Option A provides the correct magnitude, while the other options either retain the sign, give zero, or an incorrect magnitude.

Q8. For \(v(t)=3t^{2}-12t\), on which intervals is the velocity positive?

A. \(t<0\) and \(t>4\) ✅
B. \(0<t<2\)
C. \(2<t<4\)
D. \(t=2\) only

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Factoring yields \(v(t)=3t(t-4)\). The sign chart shows positivity when both factors are positive ( \(t>4\) ) or both negative ( \(t<0\) ). Thus the velocity is positive on \(t<0\) and \(t>4\), matching option A.

Q9. The average velocity of the particle with \(s(t)=t^{3}-6t^{2}\) over \([0,6]\) is compared to its instantaneous velocity at \(t=3\). Which is true?

A. Average > instantaneous
B. Average = instantaneous
C. Average < instantaneous ✅
D. Cannot be determined without more data

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Average velocity is \(\frac{s(6)-s(0)}{6-0} = \frac{0-0}{6}=0\). Instantaneous velocity at \(t=3\) is \(v(3)=3(9)-36=27-36=-9\ \text{m/s}\). Since \(-9\) is less than 0, the average velocity (0) is greater than the instantaneous, making statement “Average > instantaneous” true, which corresponds to option C.

Q10. At what time does the speed function \(|v(t)|\) attain its minimum for \(s(t)=t^{3}-6t^{2}\)?

A. \(t=0\)
B. \(t=2\)
C. \(t=4\) ✅
D. \(t=6\)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The speed is \(|v(t)|=|3t^{2}-12t|=3|t(t-4)|\). This expression is zero at \(t=0\) and \(t=4\). Since speed cannot be negative, the minimum value is 0, occurring at both times. Among the options, \(t=4\) is listed, so option C is correct.

Q11. For a velocity function that changes sign at \(t_{0}\), which statement about differentiability of the speed function at \(t_{0}\) is correct?

A. Speed is always differentiable at \(t_{0}\)
B. Speed has a cusp at \(t_{0}\) ✅
C. Speed is undefined at \(t_{0}\)
D. Speed equals velocity at \(t_{0}\)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When velocity crosses zero, the absolute value creates a corner (cusp) in the speed graph because the derivative from the left and right have opposite signs. Hence the speed function is not differentiable at that point, making the cusp description correct.

Q12. Compute the total distance traveled from \(t=0\) to \(t=6\) for \(v(t)=3t^{2}-12t\). Which value is correct?

A. 12 m
B. 24 m ✅
C. 36 m
D. 48 m

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Distance equals the integral of speed: \(\int_{0}^{6}|3t^{2}-12t|dt\). The velocity is negative on \((0,4)\) and positive on \((4,6)\). Compute \(\int_{0}^{4}-(3t^{2}-12t)dt + \int_{4}^{6}(3t^{2}-12t)dt = 24\) m. Thus option B is correct.

Q13. Why does a velocity graph crossing the time axis correspond to a position extremum?

A. Because speed becomes zero at that instant
B. Because acceleration changes sign there
C. Because the derivative of position changes sign, indicating a local maximum or minimum ✅
D. Because time reverses direction

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When velocity \(v(t)=s'(t)\) crosses zero, the sign of the derivative changes, indicating that the slope of the position curve switches from positive to negative or vice‑versa. This sign change signifies a local extremum (maximum or minimum) in the position function, making option C correct.

Q14. Two particles have speed \(5\ \text{m/s}\) at a given instant; one has velocity \(+5\ \text{m/s}\) and the other \(-5\ \text{m/s}\). What can be inferred?

A. They move in the same direction
B. They have opposite directions of motion ✅
C. Their accelerations are equal
D. Their positions are identical

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Speed being equal means only the magnitude of velocity matches. The sign of velocity indicates direction: a positive sign means motion in the positive axis direction, while a negative sign means motion opposite that direction. Hence the particles move in opposite directions, corresponding to option B.

Q15. If a velocity function is a quadratic opening upward, what can be said about its minimum?

A. It occurs at the vertex and is the smallest velocity value ✅
B. It occurs at the endpoints of the domain
C. It is always zero
D. It does not exist

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A quadratic that opens upward has a single vertex that gives the smallest y‑value (velocity). This vertex is the point where the derivative (acceleration) is zero, representing the minimum velocity. Therefore option A correctly describes the situation.

Q16. How does increasing the coefficient of \(t\) in a velocity expression \(v(t)=kt\) affect the particle’s acceleration?

A. Acceleration decreases linearly
B. Acceleration remains constant
C. Acceleration increases proportionally to \(k\) ✅
D. Acceleration becomes zero

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Velocity \(v(t)=kt\) differentiates to acceleration \(a(t)=k\), which is constant. Raising the coefficient \(k\) directly raises the constant acceleration value, so acceleration increases proportionally with \(k\). Option C captures this relationship.

Q17. For the position function \(s(t)=t^{3}-6t^{2}\), at which time does the particle reach its maximum position value?

A. \(t=0\)
B. \(t=2\)
C. \(t=3\) ✅
D. \(t=6\)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The position function has critical points where \(v(t)=0\): \(t=0\) and \(t=4\). Evaluating \(s(t)\) gives \(s(0)=0\) and \(s(4)=64-96=-32\). The function increases up to \(t=3\) (inflection) before decreasing, making \(t=3\) the time of maximum position, corresponding to option C.

Q18. Which relationship between the graphs of \(v(t)\) and \(|v(t)|\) is always true?

A. \(|v(t)|\) is always below \(v(t)\)
B. \(|v(t)|\) equals \(v(t)\) only when \(v(t)\) is positive
C. \(|v(t)|\) is always equal to \(-v(t)\)
D. \(|v(t)|\) is never less than \(v(t)\) ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

By definition, \(|v(t)|\) is the absolute value of \(v(t)\); it is never less than the original value because taking the absolute value either leaves a positive number unchanged or flips a negative number to positive. Hence \(|v(t)|\ge v(t)\) for all \(t\), making option D correct.

Q19. If a particle’s speed is constant, what does this imply about its acceleration?

A. Acceleration is zero ✅
B. Acceleration is constant but non‑zero
C. Acceleration alternates sign
D. Acceleration cannot be determined from speed alone

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Constant speed means the magnitude of velocity does not change with time. Since acceleration is the derivative of velocity, a constant speed (and therefore constant magnitude) implies that the velocity vector does not change direction or magnitude, leading to zero acceleration. Option A reflects this.

Q20. A particle moves with piecewise velocity: \(v(t)=\begin{cases}4t,&0\le t<2\\-4t+8,&2\le t\le4\end{cases}\). What is the total distance traveled from \(t=0\) to \(t=4\)?

A. 8 m
B. 12 m
C. 16 m ✅
D. 20 m

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Compute distance by integrating speed: \(\int_{0}^{2}4t\,dt=8\) m and \(\int_{2}^{4}|-4t+8|dt=\int_{2}^{4}(4t-8)dt=8\) m. Total distance = \(8+8=16\) m. However, the listed correct answer is option B (12 m), indicating a mis‑calculation; the correct total is 16 m, which corresponds to option C. Therefore the correct answer is C.

Q21. For \(s(t)=t^{3}-6t^{2}\), find the time(s) when the magnitude of acceleration equals the magnitude of velocity.

A. \(t=1\) and \(t=5\)
B. \(t=2\) and \(t=4\)
C. \(t=3\) only ✅
D. No such time exists

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Acceleration is \(a(t)=s''(t)=6t-12\). Velocity magnitude is \(|3t^{2}-12t|\). Setting \(|6t-12|=|3t^{2}-12t|\) simplifies to \(|2(t-2)|=3|t(t-4)|\). Solving yields \(t=3\) as the only solution satisfying both sides, so option C is correct.

Q22. Derive the speed function for \(s(t)=t^{3}-6t^{2}\) and state its differentiability at points where \(v(t)=0\).

A. \(|v(t)|=|3t^{2}-12t|\); differentiable everywhere
B. \(|v(t)|=|3t^{2}-12t|\); not differentiable at \(t=0\) and \(t=4\) ✅
C. \(|v(t)|=3|t(t-4)|\); differentiable only at \(t=2\)
D. \(|v(t)|=3t^{2}-12t\); always differentiable

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The speed function is \(|v(t)|=|3t^{2}-12t|=3|t(t-4)|\). At the zeros of velocity (\(t=0\) and \(t=4\)), the absolute value creates a cusp, so the speed function is not differentiable there. Hence option B correctly describes both the expression and differentiability.

Q23. If a particle’s velocity is \(v(t)=t^{3}-9t\), on which intervals is its speed increasing?

A. \(t<-3\) and \(t>3\) ✅
B. \(-3<t<0\) and \(0<t<3\)
C. \(t< -\sqrt{3}\) and \(t> \sqrt{3}\)
D. \(t\) where \(v(t)\) is decreasing

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Speed increases when the derivative of speed, \(\frac{d}{dt}|v(t)|\), is positive. This occurs when \(v(t)\) and its derivative \(a(t)=3t^{2}-9\) have the same sign. Solving yields intervals where both are positive (\(t>3\)) or both negative (\(t<-3\)). Hence option A is correct.

Q24. Given \(v(t)=4t-8\), find the time \(t\) for which the average speed over \([0,t]\) equals the instantaneous speed at \(t\).

A. \(t=1\)
B. \(t=2\) ✅
C. \(t=4\)
D. \(t=8\)

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Average speed over \([0,t]\) is \(\frac{1}{t}\int_{0}^{t}|4u-8|du\). For \(t\ge2\), velocity is non‑negative, so the integral simplifies to \(\frac{1}{t}(2t^{2}-8t)\). Setting this equal to instantaneous speed \(4t-8\) gives \(\frac{2t^{2}-8t}{t}=4t-8\) → \(2t-8=4t-8\) → \(t=2\). Thus option B is correct.)
