What is Absolute extrema on open intervals?

Definition:
On open intervals , endpoints are excluded, so absolute extrema must occur at critical points inside the interval. If the function approaches higher/lower values near endpoints, absolute extrema may not exist, requiring careful limit evaluation at boundaries.

Example:
For on , there is no absolute max or min because values approach and but never reach them.

Reason:
Excluding endpoints removes guaranteed bounds, making existence of global extrema dependent solely on internal critical points and asymptotic behavior near boundaries.

Q1. Which limit behavior guarantees that a continuous function on (a,b) has an absolute maximum but no absolute minimum?

A.lim f(x)→a⁺ = −∞ and lim f(x)→b⁻ = +∞ ✅
B.lim f(x)→a⁺ = +∞ and lim f(x)→b⁻ = −∞
C.lim f(x)→a⁺ = +∞ and lim f(x)→b⁻ = +∞
D.lim f(x)→a⁺ = −∞ and lim f(x)→b⁻ = −∞
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The combination of a left‑hand limit of −∞ and a right‑hand limit of +∞ forces the function to rise without bound near the right endpoint while dropping without bound near the left. Consequently the function can attain a highest finite value inside the interval, giving an absolute maximum, but it cannot attain a lowest value, so no absolute minimum exists.

Q2. What is the definition of an absolute maximum of a function on an open interval (a,b)?

A.A point c in (a,b) where f(c) ≥ f(x) for every x in (a,b) ✅
B.A point c in (a,b) where f(c) ≤ f(x) for every x in (a,b)
C.A point c in [a,b] where f(c) ≥ f(x) for every x in [a,b]
D.A point c where f'(c)=0
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: An absolute maximum is a location inside the interval at which the function’s value is greater than or equal to its value at every other point of the interval. The definition does not involve derivatives or closed endpoints; it simply compares the function’s values throughout the open interval.

Q3. If a continuous function f on (0,2) satisfies lim f(x)→0⁺ = +∞ and lim f(x)→2⁻ = −∞, what can be concluded about its absolute extrema?

A.It has an absolute minimum but no absolute maximum ✅
B.It has an absolute maximum but no absolute minimum
C.It has both an absolute maximum and an absolute minimum
D.It has neither an absolute maximum nor an absolute minimum
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Since the function blows up to +∞ near the left endpoint and drops to −∞ near the right endpoint, the graph must descend from arbitrarily large values to arbitrarily small values. Hence a lowest finite value is attained somewhere inside, giving an absolute minimum, while no highest finite value can exist.

Q4. For f(x)=1/(x^2−x) on the interval (0,1), at which point does the absolute maximum occur?

A.x = ½ ✅
B.x = ¼
C.x = ¾
D.x = ⅓
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Differentiating gives f'(x)=−(2x−1)/(x^2−x)^2, which is zero only at x=½. Because the limits at the endpoints are both −∞, the only candidate for an absolute extremum is this interior critical point, and evaluating f(½)=−4 shows it is indeed the absolute maximum.

Q5. Compare f(x)=1/(x^2−x) with g(x)=1/(x−½) on (0,1). Which statement is correct?

A.f has an absolute maximum, g has none ✅
B.Both have absolute maxima
C.Both have absolute minima only
D.g has an absolute maximum, f has none
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The function f approaches −∞ at both ends of (0,1) and possesses a single interior critical point at x=½ where it reaches its highest finite value, giving an absolute maximum. In contrast, g(x) tends to −∞ as x→½⁻ and +∞ as x→½⁺, so it never attains a finite highest or lowest value on the interval.

Q6. If lim f(x)→a⁺ = +∞ and lim f(x)→b⁻ = +∞ for a continuous f on (a,b), which of the following must be true?

A.f has an absolute minimum
B.f has an absolute maximum
C.f has both an absolute maximum and minimum
D.f has neither an absolute maximum nor an absolute minimum ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: When the function diverges to +∞ at both ends, it may dip down to a finite low point inside the interval, but the theorem does not guarantee such a dip. Therefore no conclusion about the existence of extrema can be drawn; the function might have none.

Q7. When lim f(x)→a⁺ = −∞ and lim f(x)→b⁻ = −∞, what can be concluded about absolute extrema?

A.Both absolute maximum and minimum exist
B.Only an absolute maximum exists
C.Only an absolute minimum exists
D.Neither an absolute maximum nor an absolute minimum exists ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Both one‑sided limits head to negative infinity, so the function is unbounded below near each endpoint. It can never achieve a greatest finite value (maximum) because values become arbitrarily large negative, and it likewise cannot achieve a least finite value (minimum). Hence neither extremum is guaranteed.

Q8. For a continuous f on (a,b) with lim f(x)→a⁺ = +∞ and lim f(x)→b⁻ = +∞, which statement is always correct?

A.f must have an absolute minimum
B.f must have an absolute maximum
C.f must have both absolute extrema
D.f need not have any absolute extrema ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The limits indicate the function grows without bound at both ends, but this does not force the existence of a finite lowest or highest value inside the interval. The function could dip to a finite low point or could stay above every finite bound, so no extremum is guaranteed.

Q9. If f is continuous on (a,b) and has a critical point c where f'(c)=0, which statement about absolute extrema is correct?

A.Any absolute extremum must occur at a critical point
B.An absolute extremum can occur only at endpoints
C.If an absolute extremum exists, it must occur at a critical point ✅
D.Absolute extrema never occur at critical points
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: On an open interval the only places where a continuous function can achieve a highest or lowest value are interior points where the derivative vanishes or fails to exist. Since endpoints are excluded, any absolute extremum that does exist must be located at a critical point.

Q10. Consider f(x)=sin x on (0,π). Which of the following describes its absolute extrema?

A.Absolute maximum at π/2, no absolute minimum ✅
B.Absolute minimum at π/2, no absolute maximum
C.Both absolute maximum and minimum exist inside the interval
D.Neither absolute maximum nor absolute minimum exist
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The sine function reaches its highest value 1 at x=π/2, which lies inside (0,π). Near the endpoints the function approaches 0 but never attains it, so there is no absolute minimum within the open interval.

Q11. For h(x)=tan x on (−π/2,π/2), what absolute extrema does the function possess?

A.An absolute maximum but no minimum
B.An absolute minimum but no maximum
C.Both an absolute maximum and minimum
D.Neither an absolute maximum nor an absolute minimum ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: As x approaches −π/2⁺, tan x → −∞, and as x approaches π/2⁻, tan x → +∞. Because the function is unbounded in both directions and attains every real value, it cannot have a greatest or least finite value; thus it has no absolute extrema.

Q12. For f(x)=ln x on (0,e), which absolute extrema exist?

A.Both an absolute maximum and minimum
B.Only an absolute maximum
C.Only an absolute minimum
D.Neither an absolute maximum nor an absolute minimum ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: The limit as x→0⁺ is −∞, so no absolute minimum can exist. As x→e⁻ the function approaches ln e = 1, but the endpoint e is not included, so the supremum 1 is never attained. Hence the function has neither an absolute maximum nor an absolute minimum on the interval.

Q13. If a continuous f on (a,b) has finite limits L and M with L < M, must f have an absolute minimum on (a,b)?

A.Yes, the minimum must be L
B.No, the minimum may occur inside the interval ✅
C.Yes, the minimum must be at a critical point
D.No, the minimum cannot exist
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Finite one‑sided limits only give the behavior near the endpoints; the function could dip below L inside the interval or stay above L. Therefore the existence of an absolute minimum is not guaranteed solely by the limits, and it may occur at an interior point or not at all.

Q14. Let f(x)=x/(x^2+1) on the interval (−1,2). Which statement correctly describes its absolute extrema?

A.Absolute maximum at x=1, no absolute minimum ✅
B.Absolute minimum at x=−1, no absolute maximum
C.Both absolute maximum and minimum exist inside the interval
D.Neither absolute maximum nor absolute minimum exist
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The derivative vanishes at x=±1; only x=1 lies in (−1,2) and gives f(1)=½, the highest value. As x→−1⁺, f approaches −½ but never attains it, so there is no absolute minimum. Hence the function has an absolute maximum at x=1 and no absolute minimum.

Q15. Why can a continuous function on (a,b) with both one‑sided limits equal to +∞ never have an absolute extremum?

A.Because the function is bounded above
B.Because the function is unbounded below
C.Because the function is unbounded in both directions ✅
D.Because the Extreme Value Theorem requires closed intervals
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: When the limits at both ends are +∞, the function grows without bound toward each endpoint. It may still dip to a finite low point, but the theorem does not guarantee such a dip, and any candidate for a maximum would be surpassed by values arbitrarily close to the endpoints. Hence no absolute extremum is forced.

Q16. Which limit behavior is compatible with a function having an absolute maximum but no absolute minimum?

A.lim f→a⁺ = −∞ and lim f→b⁻ = +∞ ✅
B.lim f→a⁺ = +∞ and lim f→b⁻ = −∞
C.lim f→a⁺ = +∞ and lim f→b⁻ = +∞
D.lim f→a⁺ = −∞ and lim f→b⁻ = −∞
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The combination of a left limit of −∞ and a right limit of +∞ forces the function to be arbitrarily low near the left endpoint and arbitrarily high near the right endpoint. Consequently a highest finite value can be attained inside the interval (giving an absolute maximum), while no lowest finite value can exist, precluding an absolute minimum.

Q17. For f(x)=e^{−1/x^{2}} on (0,1), which absolute extrema are present?

A.Absolute maximum at x=1, no absolute minimum ✅
B.Absolute minimum at x=0, no absolute maximum
C.Both absolute maximum and minimum exist
D.Neither absolute maximum nor absolute minimum exist
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The function is increasing on (0,1); as x→0⁺ it approaches 0, and at x=1 it equals e^{−1}≈0.368. Thus the greatest value is attained at x=1, giving an absolute maximum, while the infimum 0 is never reached, so there is no absolute minimum.

Q18. Summarize the possible absolute‑extrema scenarios for a continuous function on (a,b) and identify which applies to f(x)=1/(x^{2}−x) on (0,1).

A.Both extrema exist; scenario with finite limits applies
B.Only absolute maximum exists; scenario with limits −∞ and +∞ applies ✅
C.Only absolute minimum exists; scenario with limits +∞ and −∞ applies
D.No extrema exist; scenario with both limits +∞ applies
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The table shows four cases: (i) max only (limits −∞,+∞), (ii) min only (limits +∞,−∞), (iii) neither (both limits +∞ or both −∞), (iv) both (finite limits with appropriate ordering). For f(x)=1/(x^{2}−x), the limits at both ends are −∞, so the function falls into case (iii) where only an absolute maximum exists (at the interior critical point) and no absolute minimum.

Q19. Which statement is FALSE regarding absolute extrema on open intervals?

A.An absolute maximum must occur at a critical point
B.An absolute minimum may occur at an endpoint ✅
C.The Extreme Value Theorem does not apply to open intervals
D.If limits at both ends are infinite, the function cannot have any absolute extrema
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Endpoints are not part of an open interval, so an absolute extremum cannot occur at an endpoint. The false statement is that an absolute minimum may occur at an endpoint; in fact, endpoints are excluded, making this claim incorrect.

Q20. What is a critical point for a function defined on an open interval?

A.A point where f(x)=0
B.A point where f'(x)=0 or f' does not exist ✅
C.A point where the function attains its maximum
D.A point where the limit of f does not exist
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A critical point is any interior point of the domain where the derivative is zero or fails to exist. Such points are the only candidates for absolute extrema on an open interval because the interval has no endpoints to consider.

Q21. How does the Extreme Value Theorem differ for closed versus open intervals?

A.It guarantees extrema only on closed intervals ✅
B.It guarantees extrema only on open intervals
C.It guarantees both maxima and minima on any interval
D.It does not apply to continuous functions
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The Extreme Value Theorem states that a continuous function on a closed, bounded interval [a,b] must attain both an absolute maximum and an absolute minimum. When the interval is open, the theorem no longer guarantees any extrema because the function may approach but never reach extreme values at the omitted endpoints.

Q22. For f(x)=x^{3} on (−1,1), which absolute extrema exist?

A.Absolute maximum at x=1 and absolute minimum at x=−1
B.Absolute maximum at x=0, no absolute minimum
C.No absolute maximum nor absolute minimum ✅
D.Both absolute maximum and minimum occur at interior points
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The cubic function is odd and strictly increasing; as x→1⁻, f approaches 1 but never attains it, and as x→−1⁺, f approaches −1 but never attains it. Hence the function has no absolute maximum or minimum on the open interval.

Q23. If a continuous function on (a,b) satisfies lim f(x)→a⁺ = +∞ and lim f(x)→b⁻ = −∞, which conclusion is mandatory?

A.It has an absolute maximum but no minimum
B.It has an absolute minimum but no maximum ✅
C.It has both an absolute maximum and minimum
D.It has neither an absolute maximum nor an absolute minimum
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When the left limit diverges to +∞ and the right limit to −∞, the function must descend from arbitrarily large positive values to arbitrarily large negative values, guaranteeing the existence of a lowest finite value (absolute minimum) somewhere inside, while no highest finite value can exist.

Q24. Consider f(x)=x/√(x^{2}+1) on (−2,3). Which statement about its absolute extrema is correct?

A.It has an absolute maximum at x→3⁻ and an absolute minimum at x→−2⁺
B.It has an absolute maximum at x=3 and an absolute minimum at x=−2
C.It has both absolute extrema at interior critical points
D.It has neither an absolute maximum nor an absolute minimum ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: The derivative of f is always positive, so the function is strictly increasing. As x approaches −2⁺, f approaches −2/√5≈−0.894, and as x approaches 3⁻, f approaches 3/√10≈0.949. Neither endpoint value is attained, and there are no interior critical points, so the function possesses no absolute maximum or minimum on the interval.
