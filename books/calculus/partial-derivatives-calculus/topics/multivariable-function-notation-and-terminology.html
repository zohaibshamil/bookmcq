What is Multivariable function notation and terminology?

Definition:
Standard notation f:D⊆Rn→Rf: D \subseteq \mathbb{R}^n \to \mathbb{R}f:D⊆Rn→R specifies the domain DDD, independent variables (x1,...,xn)(x_1, ..., x_n)(x1​,...,xn​), and dependent variable zzz.

Example:
For w=f(x,y,z)=x2+y2+z2w = f(x, y, z) = \sqrt{x^2 + y^2 + z^2}w=f(x,y,z)=x2+y2+z2​, the domain is R3\mathbb{R}^3R3 and the range is [0,∞)[0, \infty)[0,∞).

Reason:
Precise terminology prevents ambiguity regarding which variables are inputs versus outputs and defines the valid region for evaluation.
