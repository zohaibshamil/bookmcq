About 2. Limits and Continuity an Introduction

Limits are the cornerstone of calculus because they describe how a function behaves as it gets closer and closer to a specific point, even if it never actually reaches that value. Instead of asking "what is the function at this exact spot," limits ask "what value is the function approaching," which allows us to handle tricky situations like division by zero or infinite behavior. This concept provides the precise mathematical language needed to define instantaneous change and area under a curve, bridging the gap between static algebra and dynamic calculus.

Continuity builds directly upon limits by defining what it means for a function to be unbroken and smooth without any jumps, holes, or vertical asymptotes. A continuous function is one where you can draw the entire graph without lifting your pencil, meaning the limit at every point matches the actual function value at that point. Understanding continuity is crucial because most of the powerful theorems in calculus, such as the Intermediate Value Theorem and the Fundamental Theorem of Calculus, only work reliably when functions are continuous.
