What is Squeeze theorem for sequences?

If three sequences satisfy an≤bn≤cn a_n \le b_n \le c_n an​≤bn​≤cn​ for all large n n n, and both outer sequences converge to the same limit L L L (i.e., lim⁡an=L \lim a_n = L liman​=L and lim⁡cn=L \lim c_n = L limcn​=L), then the middle sequence also converges to L L L, written lim⁡bn=L \lim b_n = L limbn​=L, which is useful for tricky sequences like bn=sin⁡nn b_n = \frac{\sin n}{n} bn​=nsinn​ squeezed between −1n -\frac{1}{n} −n1​ and 1n \frac{1}{n} n1​.
