What is Eventually properties of sequences?

A sequence has an 'eventually' property if it holds for all sufficiently large nn (beyond some index NN), like 'eventually increasing' means an+1≥anan+1​≥an​ for all n≥Nn≥N, which is enough for convergence tests since the first few terms don't affect the limit.
