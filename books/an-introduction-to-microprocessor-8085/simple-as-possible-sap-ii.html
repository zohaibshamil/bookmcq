📖 Simple as Possible (SAP) - II

Chapter Overview:

SAP-II advances the SAP-I teaching model into a more capable eight-bit stored-program computer. Its 64K-byte memory and 16-bit addressing support larger programs, while a bidirectional internal bus, additional registers, input/output ports, and an expanded instruction set provide greater programming flexibility. The architecture introduces more complex instruction execution involving multiple machine cycles. Addressing modes, instruction formats, status flags, assembly programming, and delay calculations establish how instructions control processor operations and how execution time can be analyzed quantitatively.

Prerequisites:

Students should understand SAP-I architecture, program counter operation, memory and accumulator transfers, fetch and execution cycles, binary and hexadecimal conversion, basic register operations, and arithmetic and logical instructions. Familiarity with eight-bit data representation, hexadecimal memory addresses, machine instructions, clock pulses, and T-states is necessary for understanding SAP-II architecture and timing calculations.

Learning Objectives:

Students should be able to explain the SAP-II architecture, identify its registers and input/output organization, describe its 16-bit addressing and 64K-byte memory, classify its 42 instructions into their five categories, distinguish machine cycles from instruction cycles, identify four addressing modes and three instruction lengths, interpret sign and zero flags, write assembly language programs, trace conditional jumps and subroutine operations, and calculate execution time and software-generated delays using clock frequency and instruction T-states.

Topics Covered:

  • Architecture of SAP-II Computer - Explains its eight-bit datapath, 64K memory, 16-bit addressing, registers, and ports.
  • Instruction Set of SAP-II Computer - Groups 42 operations into memory-reference, register, jump/call, logical, and miscellaneous instructions.
  • Machine Cycle and Instruction Cycle - Distinguishes T-states, machine cycles, and complete instruction-cycle timing.
  • Addressing Modes and Instruction Types - Covers direct, register, immediate, implied modes and one-, two-, three-byte formats.
  • Flags of SAP-II Computer - Explains sign and zero flag updates after applicable arithmetic and logical operations.
  • Assembly Language Programming - Uses mnemonics, operands, labels, memory locations, branching, subroutines, and I/O.
  • Delay Calculations - Computes software delays from instruction T-state totals and clock frequency.

Chapter Learning Path:

Begin with the SAP-II architecture, identifying its registers, memory organization, buses, and input/output ports. Study the instruction set next to understand the available operations and their classifications. Proceed to machine-cycle and instruction-cycle timing before examining addressing modes and instruction lengths. Learn how arithmetic and logical operations affect the sign and zero flags. Apply these concepts through assembly language programs involving data transfer, arithmetic, branching, and subroutines. Finish with delay calculations, using instruction timing and clock frequency to determine actual execution time.

How the Topics Connect:

SAP-II architecture establishes the available registers, memory range, ports, and data paths. Its instruction set defines operations, while addressing modes specify where operands originate and instruction lengths determine how many bytes must be fetched. These choices shape instruction-cycle timing. Arithmetic and logical operations update the S and Z flags, which conditional jumps can test. Assembly programs combine these mechanisms, and their T-state totals provide the foundation for delay calculations.

End-to-End Flow:

Consider a program that calculates 38 + 64 - 3 and stores the result at 2100H. The instructions are MVI A,26H; MVI B,40H; MVI C,03H; ADD B; SUB C; STA 2100H; HLT. Immediate, register, and direct addressing handle the operands. The accumulator progresses from 26H to 66H and then 63H, leaving both S and Z clear. The instructions require 47 T-states altogether, so at 2 MHz the complete sequence takes 23.5 microseconds, including HLT.

Why This Chapter Matters:

SAP-II demonstrates how a larger instruction set, expanded memory, conditional execution, and multiple machine cycles make programming more flexible. Without understanding instruction timing and flag conditions, program execution and delay calculations become difficult to predict. These concepts establish important foundations for the SAP-III programming model, Intel 8085 instruction execution, and subsequent microprocessor programming.

Common Confusions Across Topics:

'An instruction cycle is always one machine cycle' is incorrect because an instruction cycle includes all machine cycles required to complete an instruction. 'Immediate and direct addressing both place data inside the instruction' is incorrect: immediate addressing embeds the operand, whereas direct addressing specifies its memory or port address. 'The S flag is a carry flag' is incorrect because SAP-II uses separate sign and zero indicators, not a carry flag.

Exam Focus Areas:

Frequently tested problems include drawing SAP-II architecture, identifying instruction categories, determining addressing modes, and calculating instruction lengths. Students should trace register and memory contents during assembly programs, distinguish machine-cycle timing from complete instruction timing, evaluate sign and zero flag conditions, and identify conditional branch outcomes. Numerical questions commonly involve T-state totals, clock frequency, instruction execution time, and software-generated delays using register loops.

Chapter Summary:

SAP-II expands the basic stored-program model through additional registers, larger memory, more instructions, and flexible addressing. Its execution mechanism connects instruction fetching with machine-cycle timing, while the sign and zero flags support conditional decisions. Assembly language brings these features together in practical programs. Delay calculations then translate instruction execution into measurable time, linking software operations with processor clock behavior.

Key Terms:

  • SAP-II Computer - An eight-bit conceptual computer with 64K-byte memory and an expanded instruction set.
  • Program Counter - A 16-bit register that holds the address of the next instruction.
  • Memory Address Register - A register that holds the address of the memory location being accessed.
  • Memory Data Register - A register that temporarily holds data transferred between memory and the computer.
  • Addressing Mode - The method used by an instruction to specify its operand.
  • Machine Cycle - A group of T-states used to perform a specific basic operation.
  • Instruction Cycle - The complete sequence of machine operations required to fetch and execute an instruction.
  • Sign and Zero Flags - Status indicators representing the sign and zero condition of applicable results.
