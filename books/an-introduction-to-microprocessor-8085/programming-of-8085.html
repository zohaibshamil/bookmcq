📖 Programming of 8085

Chapter Overview:

8085 programming applies the processor's registers, flags, memory addressing, and instruction set to solve practical data-processing problems. Programs begin with fundamental data manipulation and arithmetic, then extend to number-system conversions, character-code transformations, searching and arranging numerical series, multiplication, and eight-bit division. Each task requires selecting appropriate instructions, organizing operands and results in memory, and controlling repetition through counters and conditional branches. These programming exercises develop the ability to translate numerical problems and data-processing requirements into executable assembly-language routines.

Prerequisites:

Students should understand the 8085 register organization, accumulator operations, status flags, hexadecimal addressing, instruction formats, and basic assembly-language syntax. Familiarity with eight-bit addition and subtraction, binary and decimal representations, BCD digits, ASCII codes, memory locations, register-indirect addressing, loops, comparisons, and conditional jumps is particularly important for developing and tracing practical programs.

Learning Objectives:

Students should be able to write and trace basic 8085 assembly programs, convert BCD numbers into binary and binary numbers into unpacked BCD, perform ASCII-to-binary and binary-to-ASCII conversions, implement addition and subtraction routines, identify the largest and smallest elements in a numerical series, arrange data in ascending or descending order, implement multiplication and eight-bit division, determine quotient and remainder, and analyze register contents, memory changes, and status flags during program execution.

Topics Covered:

  • Simple Programs in 8085 - Introduces assembly program structure, data movement, loops, and memory storage.
  • BCD-to-Binary and Binary-to-Unpacked-BCD Conversion - Converts decimal digits and binary values between numerical representations.
  • Binary-to-ASCII and ASCII-to-Binary Conversion - Transforms numerical values into character codes and back.
  • Addition and Subtraction Programs - Performs arithmetic operations while tracking results, carries, borrows, and status flags.
  • Largest, Smallest, and Series Arrangement Programs - Compares numerical elements and arranges series in the required order.
  • Multiplication and Eight-Bit Division Programs - Implements arithmetic algorithms and determines products, quotients, and remainders.
  • Miscellaneous 8085 Programs - Applies instruction combinations, comparisons, branching, and repetitive operations to practical problems.

Chapter Learning Path:

Start with simple programs to understand instruction sequencing, register usage, memory addressing, and program termination. Progress to BCD and binary conversions before studying ASCII transformations, since these exercises establish how numerical values differ from their encoded representations. Move to addition and subtraction programs to strengthen arithmetic programming. Next, study comparison-based routines for identifying extreme values and arranging numerical series. Continue with multiplication and eight-bit division, then complete the sequence with miscellaneous programs that combine data manipulation, looping, and conditional branching.

How the Topics Connect:

Simple programs establish the instruction sequences and memory operations required by more advanced routines. Number-system and character-code conversions build on arithmetic and data-transfer instructions. Addition and subtraction provide the computational foundation for multiplication and division algorithms. Comparison and conditional branching extend these operations into searching and sorting programs. Repeated execution through counters and loops connects individual instructions into complete numerical-processing routines.

End-to-End Flow:

Consider a routine that receives the ASCII characters '4' and '5' at successive memory locations. The ASCII-to-binary conversion removes the digit offset and accumulates \(4 \times 10 + 5 = 45\), producing 2DH. An addition program adds 13H, representing decimal 19, producing 40H, or decimal 64, without an eight-bit carry. The binary-to-unpacked-BCD routine converts 40H into 06H and 04H. Both digits are stored in successive memory locations for subsequent display as 64.

Why This Chapter Matters:

Practical 8085 programming demonstrates how individual instructions become complete solutions to numerical and data-processing problems. Without conversion routines, arithmetic algorithms, comparisons, and controlled loops, handling real-world numerical data would require repetitive manual operations. These techniques establish essential foundations for microprocessor-based calculators, measurement systems, data processing, and more advanced assembly-language applications.

Common Confusions Across Topics:

'BCD and binary represent decimal numbers identically' is incorrect because BCD encodes each decimal digit separately, while binary represents the entire numerical value. 'ASCII 35H directly represents binary 35H' is incorrect because 35H is the character code for the digit 5, not the numerical value five. 'Division produces only a quotient' is also incorrect because integer division can produce both a quotient and a remainder.

Exam Focus Areas:

Important examination problems involve tracing assembly instructions, completing number-conversion routines, calculating arithmetic results, and following register and memory changes. Students should write programs to identify the largest or smallest element, arrange a numerical series, perform multiplication and division, and determine quotient and remainder. Conversion questions frequently test ASCII codes, BCD representations, hexadecimal values, carry conditions, loop counters, and conditional branching.

Chapter Summary:

8085 assembly programming transforms processor instructions into practical numerical-processing solutions. Data representation and conversion routines establish the correct format for computation, while arithmetic instructions perform numerical operations. Comparisons and conditional branches support searching and arranging data, whereas repeated execution enables multiplication and division algorithms. Together, these programming techniques demonstrate how registers, memory, flags, and instruction sequencing cooperate to solve increasingly complex computational problems.

Key Terms:

  • BCD - A numerical representation in which each decimal digit is encoded separately using four bits.
  • Unpacked BCD - A representation in which each decimal digit occupies a separate byte.
  • ASCII Code - A character-encoding system that assigns numerical codes to letters, digits, and symbols.
  • Accumulator - An eight-bit register used extensively for arithmetic, logical operations, and data manipulation.
  • Carry Flag - A status flag indicating a carry or borrow condition in applicable arithmetic operations.
  • Conditional Jump - An instruction that changes program execution according to the current flag conditions.
  • Quotient - The integer result obtained when one numerical value is divided by another.
  • Remainder - The value left after completing integer division.

Further Reading:

  • 8080/8085 Assembly Language Programming by Lance A. Leventhal - Provides practical programming examples involving arithmetic, number conversions, comparisons, loops, and data manipulation.
  • Intel 8085 Microprocessor User's Manual - Provides instruction descriptions, addressing information, flag effects, and processor operations needed for developing assembly routines.
  • Intel 8085A Instruction Set and Programming Reference - Use instruction opcode tables and operation descriptions to practice program tracing, instruction selection, and assembly-language problem solving.
