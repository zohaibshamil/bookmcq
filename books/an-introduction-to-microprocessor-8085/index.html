About An Introduction To Microprocessor 8085

Think of the Microprocessor 8085 as the "brain" of a simple computer, all packed onto a single tiny silicon chip. Before we can understand this brain, we must understand its history and how it evolved from larger, room-sized computers to this powerful chip. To make learning easier, the journey starts with three chapters on a concept called Simple as Possible (SAP) . These are like training wheels. SAP-I is the most basic computer that can only perform a few tasks. SAP-II adds more memory and instructions, and SAP-III adds a stack and subroutines. By understanding how these simple computers are built, you learn the fundamental building blocks—like memory, registers, and an arithmetic logic unit—that all computers, including the 8085, are made of.

Now that you understand the basics, we move to the star of the course: The 8085 Microprocessor. This is an 8-bit microprocessor, meaning it can process 8 bits of data at a time. Unlike its predecessor, the 8080, the 8085 has a major advantage—it uses a single +5-volt power supply, making it simpler to use (the "5" in 8085 refers to this). It has 40 pins and is the Central Processing Unit (CPU) for many early personal computers. The 8085 works by fetching instructions from memory, decoding them, and then executing them. To do this, it uses internal "registers" as temporary storage and follows a specific "programming model" which dictates how we, as programmers, can tell it what to do.

To make the 8085 work, we must give it instructions, which is the topic of Programming of 8085. This involves writing code using the processor's specific set of commands, called its "Instruction Set." These instructions are often written in a low-level language called Assembly Language. But a microprocessor doesn't just process data; it also needs to handle events that happen unexpectedly, like when you press a key on a keyboard. This is done using Interrupt Instructions. Interrupts are like a doorbell; they pause the main program, tell the 8085 to handle an urgent task (like reading the key pressed), and then resume the main program. This ability to react to external events is crucial for a microprocessor to be interactive and useful.

A microprocessor on its own is useless; it needs to "talk" to other devices like screens, keyboards, and motors. This "talking" is called Interfacing, and it's the subject of the final chapters. To manage this communication, the 8085 uses specialized support chips. For example, the PPI 8255A is a general-purpose interface for connecting keyboards and LEDs. The 8253 acts as a timer to create precise delays. The 8279 manages keyboard input and display output, while the 8259 handles multiple interrupts. The 8257 allows devices to access memory directly (DMA) for fast data transfer. Finally, we can even connect the 8085 to the analog world using A/D and D/A Converters and communicate with other computers using Serial Communication chips. All these components come together to build a complete working system, showcasing the powerful Applications of Microprocessors in everything from washing machines to early personal computers.
