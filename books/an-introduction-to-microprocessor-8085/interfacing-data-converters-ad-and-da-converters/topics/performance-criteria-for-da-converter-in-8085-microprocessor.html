Q1. A system requires a D/A converter that can produce an output step size no larger than 0.1% of the full‑scale voltage. Which minimum resolution in bits satisfies this requirement?

🔹 A. 8 bits
🔹 B. 10 bits
🔹 C. 12 bits
🔹 D. 14 bits

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The step size equals the full‑scale voltage divided by \(2^{n}\). To keep the step below 0.1 % (0.001 FS), we need \(1/2^{n}\le0.001\), which gives \(2^{n}\ge1000\). The smallest integer n meeting this is 10 because \(2^{10}=1024\). Therefore a 10‑bit converter meets the requirement. Options A, C, and D provide either too coarse or unnecessarily fine resolution, making B the correct choice.

Q2. A motor‑control loop uses a 12‑bit D/A converter with a specified settling time of 5 µs. If the control algorithm updates the output every 8 µs, will the converter meet the timing requirement?

🔹 A. Yes, because 5 µs < 8 µs
🔹 B. No, because 5 µs > 8 µs
🔹 C. It depends on the load capacitance
🔹 D. The converter must be re‑programmed

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Settling time is the period needed for the output to stabilize after a code change. Since the algorithm allows 8 µs between updates and the converter settles in only 5 µs, there is ample margin, so the timing requirement is satisfied. Option B reverses the inequality, C introduces an irrelevant factor, and D suggests unnecessary re‑programming, leaving A as the correct answer.

Q3. An audio synthesizer requires a D/A converter that is monotonic over its entire range. Which characteristic must be verified to guarantee monotonicity?

🔹 A. Integral non‑linearity (INL) less than ±1 LSB
🔹 B. Differential non‑linearity (DNL) ≤ 1 LSB
🔹 C. Zero‑scale error ≤ 0.5 LSB
🔹 D. Gain error ≤ 2 %

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Monotonicity means the output never decreases when the input code increases. This is ensured when the differential non‑linearity does not exceed one least‑significant bit, preventing code gaps or overlaps. INL affects overall linearity but not monotonic steps, zero‑scale error and gain error affect offset and slope, not step‑by‑step behavior. Hence DNL ≤ 1 LSB (option B) is the correct condition.

Q4. A microcontroller uses an 8257 DMA controller to transfer a waveform buffer of 2048 samples to a 10‑bit D/A converter at a rate of 250 kS/s. Which DMA configuration ensures continuous output without underrun?

🔹 A. Mode word set to single‑cycle, terminal count 2047
🔹 B. Mode word set to block‑transfer, terminal count 2048
🔹 C. Mode word set to demand‑transfer, terminal count 2047
🔹 D. Mode word set to cascade, terminal count 2048

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Demand‑transfer mode lets the DMA respond to each request from the D/A converter, providing data exactly when needed, which is essential for a high‑rate waveform. The terminal count must be one less than the number of samples because counting starts from the loaded value down to zero, so 2047 is correct. Single‑cycle and block modes cannot keep up with the sample rate, and cascade mode bypasses data transfer, making option C the only viable choice.

Q5. A temperature‑control system uses a 16‑bit D/A converter with an offset error of 2 LSB. If the full‑scale output is 5 V, what is the maximum voltage error introduced by the offset?

🔹 A. 0.152 mV
🔹 B. 0.305 mV
🔹 C. 0.610 mV
🔹 D. 1.22 mV

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

One LSB equals full‑scale divided by \(2^{16}\): \(5\text{ V}/65536≈0.0763\text{ mV}\). Two LSBs therefore produce an error of about \(0.1526\text{ mV}\). The other options represent multiples of this value and thus overestimate the error. Consequently, the maximum offset‑induced voltage error is approximately 0.152 mV, corresponding to option A.

Q6. A D/A converter specified with a gain error of +0.5 % and INL of ±0.8 LSB is used to generate a reference voltage of 3.3 V. What is the worst‑case output voltage at full scale?

🔹 A. 3.3165 V
🔹 B. 3.3175 V
🔹 C. 3.3185 V
🔹 D. 3.3195 V

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

A gain error of +0.5 % raises the ideal full‑scale voltage by \(0.005\times3.3\text{ V}=0.0165\text{ V}\). The INL contribution is at most \(0.8\) LSB, where one LSB is \(3.3\text{ V}/65535≈0.0000503\text{ V}\); 0.8 LSB adds about \(0.000040\text{ V}\). Adding this to the gain‑error increase gives roughly \(3.3165\text{ V}+0.00004\text{ V}=3.31654\text{ V}\), which rounds to 3.3165 V. The other choices are higher than this worst‑case value.

Q7. When programming the 8257 DMA controller for a transfer to a D/A converter, which register must be loaded with the address of the converter’s data register?

🔹 A. Mode Set Register
🔹 B. Terminal Count Register
🔹 C. DMA Address Register
🔹 D. Page Register

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The DMA Address Register holds the starting memory address from which the DMA engine reads or writes data. To send data to the D/A converter, the address of the converter’s data register is placed in this register so each DMA transfer writes directly to the converter. The Mode Set Register defines transfer mode, the Terminal Count Register defines the transfer length, and the Page Register is used for high‑order address bits, none of which specify the data register address.

Q8. How is the resolution of a D/A converter defined?

🔹 A. Number of bytes it can output
🔹 B. Size of the smallest change in output voltage it can produce
🔹 C. Maximum output voltage
🔹 D. Speed of conversion

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Resolution describes the smallest distinguishable step in the analog output, often expressed as the voltage difference corresponding to one least‑significant bit. It determines how finely the converter can represent a continuous signal. The other options refer to data size, range, or conversion speed, which are distinct specifications. Therefore, the correct definition is the size of the smallest output change, option B.

Q9. Why is monotonicity important in a D/A converter used for closed‑loop control?

🔹 A. Prevents output jumps that could destabilize the loop
🔹 B. Increases conversion speed
🔹 C. Reduces power consumption
🔹 D. Allows higher voltage range

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Closed‑loop controllers rely on smooth, predictable feedback; any sudden decrease in output when the command code rises can cause the controller to react incorrectly, potentially leading to oscillations or instability. Monotonic behavior guarantees that increasing digital codes never produce decreasing analog voltages, preserving loop stability. Options B, C, and D describe unrelated benefits, making option A the correct explanation.

Q10. What is the primary reason that decreasing the settling time of a D/A converter often degrades its linearity?

🔹 A. Faster internal switches cause increased charge injection
🔹 B. Higher clock frequencies reduce bit depth
🔹 C. Larger reference resistors increase thermal noise
🔹 D. Shorter settling time reduces the number of conversion cycles

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Reducing settling time typically requires faster switching of internal transistors, which can inject charge into the output node and disturb the voltage, leading to non‑linear errors such as differential non‑linearity. While clock speed, resistor size, and conversion cycle count affect other aspects, the dominant effect on linearity stems from charge injection caused by rapid switching, making option A correct.

Q11. In the 8257 Mode Set Register, setting D7=1 and D6=0 configures the channel for which type of transfer?

🔹 A. Block transfer
🔹 B. Demand transfer
🔹 C. Single transfer
🔹 D. Cascade

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Bit D7 enables the channel, while bits D6‑D5 select the transfer mode: 00 for Single, 01 for Block, 10 for Demand, and 11 for Cascade. With D7=1 and D6=0 (and assuming D5=0), the mode bits form 00, indicating a Single transfer where one byte is moved per request. The other options correspond to different bit patterns, so the correct answer is Single transfer, option C.

Q12. If a terminal count register is loaded with the value 0x03FF, how many bytes will the DMA controller transfer before generating a terminal‑count interrupt?

🔹 A. 1023 bytes
🔹 B. 1024 bytes
🔹 C. 2047 bytes
🔹 D. 2048 bytes

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The terminal count register holds the count‑minus‑one value. Loading 0x03FF (decimal 1023) means the controller will count down from 1023 to 0, performing 1024 transfers in total. Therefore, the DMA engine will move 1024 bytes before raising the interrupt. Options A, C, and D represent incorrect interpretations of the counting mechanism.

Q13. What term describes the maximum analog output voltage a D/A converter can produce?

🔹 A. Zero‑scale
🔹 B. Full‑scale
🔹 C. Reference voltage
🔹 D. Bias voltage

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Full‑scale denotes the highest voltage the converter can generate when all digital bits are set to one. It defines the upper bound of the output range. Zero‑scale refers to the minimum output, reference voltage is the stable voltage used for scaling, and bias voltage is an offset added to the output. Hence, the correct term is full‑scale, option B.

Q14. What does the abbreviation INL stand for in D/A converter specifications?

🔹 A. Integral Non‑Linearity
🔹 B. Input Noise Level
🔹 C. Internal Network Latency
🔹 D. Integrated Normalized Load

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

INL is a standard metric that quantifies the deviation of the actual transfer function from an ideal straight line, expressed in least‑significant bits. It captures cumulative non‑linear errors across the converter’s range. The other choices describe unrelated concepts, making option A the accurate definition.
