What is ADC 0808/0809 in 8085 Microprocessor?

The ADC 0808/0809 is an 8-bit successive approximation ADC with an integrated 8-channel multiplexer, allowing the 8085 to select one of eight analog inputs via address lines A,B,CA, B, CA,B,C, start conversion with a pulse on STARTSTARTSTART, and read the result after EOCEOCEOC goes high, with conversion time ≈100 μs\approx 100 \, \mu s≈100μs and direct compatibility with the 8085 data bus for multi-sensor acquisition.

Q1. What is the typical conversion time of the ADC0808 when operating at its maximum clock frequency?

A.130 µs ✅
B.100 µs
C.150 µs
D.200 µs
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The ADC0808 is specified to finish one analog‑to‑digital conversion in about 130 microseconds when driven at its highest clock rate of 640 kHz. This matches option A, making it the correct choice. Option B underestimates the guaranteed conversion time, while options C and D are longer than necessary and would slow the overall system. Choosing the correct conversion time is essential for accurate timing calculations in designs that incorporate the ADC.

Q2. Which pin on the ADC0808 initiates a conversion when a low‑to‑high transition occurs?

A.CS
B.RD
C.WR
D.START ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: The START pin on the ADC0808 triggers a conversion when it receives a low‑to‑high edge, so option D is correct. CS (chip select) merely enables the device, RD (read) and WR (write) are used for data bus operations and do not start a conversion. Understanding the role of the START pin helps designers correctly sequence control signals for reliable analog‑to‑digital conversion.

Q3. Why must the Mode Set Register be programmed before loading the terminal count in the 8257 DMA controller?

A.The controller ignores counts until mode is set
B.Mode determines how counts are interpreted for the selected channel ✅
C.Loading counts automatically sets the mode
D.Mode register contains the address of the count register
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The 8257 uses the mode bits to decide whether the count applies to a read, write, or verify operation and which channel is affected. Therefore the mode must be defined before the count is loaded, making option B correct. The controller does not ignore counts (A), nor does loading a count set the mode (C). Option D confuses the purpose of the mode register with address mapping.

Q4. A system needs to transfer 1024 bytes from memory address 0x3000 to a floppy using channel 1. Which sequence of OUT instructions correctly programs the Mode Set Register (address 0x28) for a read operation, the terminal‑count registers (addresses 0x23 LS, 0x24 MS), and the DMA address registers (addresses 0x22 LS, 0x23 MS)?

A.MVI A,41H;OUT 28H;MVI A,00H;OUT 23H;MVI A,04H;OUT 24H;MVI A,00H;OUT 22H;MVI A,30H;OUT 23H ✅
B.MVI A,41H;OUT 28H;MVI A,04H;OUT 23H;MVI A,00H;OUT 24H;MVI A,30H;OUT 22H;MVI A,00H;OUT 23H
C.MVI A,01H;OUT 28H;MVI A,00H;OUT 23H;MVI A,04H;OUT 24H;MVI A,00H;OUT 22H;MVI A,30H;OUT 23H
D.MVI A,41H;OUT 28H;MVI A,00H;OUT 24H;MVI A,04H;OUT 23H;MVI A,30H;OUT 22H;MVI A,00H;OUT 23H
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Option A follows the required order: first set the mode word 0x41 for a read on channel 1, then load the LS count (0x00) followed by the MS count (0x04) to make a total of 1024 bytes, and finally load the LS address (0x00) and MS address (0x30) of the source memory. The other options either swap LS/MS bytes or use an incorrect mode word, leading to wrong transfer size or direction.

Q5. When programming the 8257, why is the LS byte of the terminal count loaded before the MS byte?

A.The LS byte contains the most significant bits
B.The controller latches the LS byte first to start the count ✅
C.The LS byte must be zero for proper operation
D.The order does not matter; both bytes are equivalent
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The 8257 latches the first byte it receives as the least‑significant part of the count, so loading the LS byte first ensures the correct 16‑bit value is formed. Option B describes this behavior accurately. Option A reverses the significance, option C imposes an unnecessary condition, and option D is false because the order directly affects the resulting count value.

Q6. In the terminal‑count register, bits D15 and D14 are set to 1 0 to indicate a memory‑read operation. What would happen if these bits were mistakenly set to 0 1?

A.The DMA would attempt a memory‑write instead of a read ✅
B.The DMA would halt with an error
C.The transfer would continue but data would be corrupted
D.The operation would be ignored and no transfer would start
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Setting D15‑D14 to 0 1 tells the 8257 to perform a memory‑write (output) rather than a memory‑read (input). Consequently, the controller would try to send data to memory, which is opposite of the intended operation, so option A is correct. The controller does not automatically halt (B) or ignore the command (D), and while corruption (C) could occur, the primary effect is the wrong direction of data flow.

A.Mode=0x41; Count LS=0x00, MS=0x02; Addr LS=0x00, MS=0x30 ✅
B.Mode=0x01; Count LS=0x02, MS=0x00; Addr LS=0x30, MS=0x00
C.Mode=0x41; Count LS=0x02, MS=0x00; Addr LS=0x30, MS=0x00
D.Mode=0x00; Count LS=0x00, MS=0x02; Addr LS=0x00, MS=0x30
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Option A uses the correct mode word 0x41 (enable channel 0, read, auto‑initialize), loads the count LS byte 0x00 and MS byte 0x02 to represent 512 bytes, and sets the address LS to 0x00 and MS to 0x30 for the start address 0x3000. The other options either misuse the mode word, swap LS/MS bytes, or place address bytes in the wrong order, leading to incorrect transfer size or location.

Q8. If the LS byte of the terminal count is loaded after the MS byte, what effect does this have on the transfer length?

A.The count becomes the sum of the two bytes
B.The count is interpreted as MS << 8 + LS, producing a much larger value ✅
C.The count is ignored and defaults to zero
D.The transfer length remains correct because the controller reorders the bytes
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: When the MS byte is loaded first, the controller treats it as the LS part, so the final count becomes (MS << 8) + LS, which is typically far larger than intended. Option B captures this behavior. The controller does not automatically sum the bytes (A), nor does it ignore the count (C). It also does not reorder the bytes (D), so the transfer length would be erroneous.

Q9. A programmer writes a mode word of 0x00 to the Mode Set Register before starting a DMA transfer. What is the most likely outcome?

A.The DMA channel will be disabled and no transfer occurs ✅
B.The DMA will operate in cascade mode
C.The transfer will proceed but with maximum speed
D.The DMA will generate an interrupt immediately
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: A mode word of 0x00 clears all enable and direction bits, effectively disabling the selected DMA channel. Therefore no transfer will start, making option A correct. Cascade mode (B) requires specific bits to be set, and the controller does not increase speed (C) or generate an interrupt (D) simply because the mode word is zero.

Q10. When using the ADC0809, which address line determines the selected channel for conversion?

A.A0 ✅
B.A1
C.A2
D.A3
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The ADC0809 uses the least‑significant address line A0 to select between its two analog input channels (IN0 when A0=0, IN1 when A0=1). Therefore option A0 is correct. Lines A1‑A3 are not used for channel selection; they may be tied to ground or used for other purposes. Recognizing the correct address line prevents misreading the wrong analog input.

Q11. Why is it necessary to load the LS byte before the MS byte into the terminal‑count register?

A.Because the LS byte contains the most significant bits
B.Because the controller automatically combines the two bytes in the order received ✅
C.Because the LS byte must be zero for proper operation
D.Because the order determines the direction of data flow
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The 8257 captures the first byte it receives as the least‑significant portion of the 16‑bit count, so loading the LS byte first ensures the intended count value is formed. Option B describes this mechanism. The LS byte does not hold the most significant bits (A), it is not required to be zero (C), and the order does not affect data direction (D).

Q12. How does the terminal‑count value relate to the automatic‑initialize feature of the 8257?

A.When the count reaches zero, the controller reloads the original count if auto‑initialize is set ✅
B.The terminal count disables auto‑initialize
C.Auto‑initialize doubles the terminal count
D.The terminal count has no effect on auto‑initialize
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: If the auto‑initialize bit is set, the 8257 reloads the original terminal‑count value each time the count reaches zero, allowing continuous transfers without further CPU intervention. This is described by option A. Options B and C incorrectly state the relationship, and D ignores the functional link between count and auto‑initialize.

Q13. A system requires channel 2 of the 8257 to operate in cascade mode with auto‑initialization for a block‑transfer of 256 bytes. Which mode word correctly configures this setting?

A.194 ✅
B.130
C.98
D.66
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: In cascade mode the mode bits D7‑D5 are set to 1 1 0 (binary 110), and auto‑initialize requires D2=1. Combining these with channel 2 selection (bits D1‑D0 = 10) yields the hexadecimal value 0xC2. Therefore option A is correct. The other options miss either the cascade bits, the auto‑initialize bit, or the channel selection, resulting in an incorrect configuration.

Q14. During a DMA setup, the programmer mistakenly swaps the LS and MS bytes of the terminal count for a 256‑byte transfer. What count will the controller actually use?

A.256
B.16
C.4096 ✅
D.255
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Swapping the bytes means the LS byte (0x00) is loaded as the MS part and the MS byte (0x01) as the LS part, producing a count of (0x01 << 8) + 0x00 = 0x0100, which equals 256 decimal. However, because the LS byte is interpreted as the most significant part, the controller will treat the value as 0x1000 (4096 decimal). Option C reflects this erroneous large count, while the other options represent the intended count or other miscalculations.

Q15. In the 8257 Mode Set Register, what is the purpose of setting bit D7 (Enable) to 1?

A.It selects the DMA channel number
B.It enables the DMA controller to respond to requests ✅
C.It determines the direction of data transfer
D.It clears the terminal‑count register
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Bit D7 is the global enable bit; when set to 1 it allows the DMA controller to acknowledge and process request signals from the peripheral. This makes option B correct. Selecting a channel (A) uses other bits, direction (C) is controlled by D6, and clearing the terminal count (D) is not performed by the enable bit.

Q16. What is the effect of leaving bit D0 (TC stop) cleared in the mode word?

A.The DMA transfer stops automatically when the terminal count reaches zero
B.The DMA continues indefinitely, ignoring the terminal count ✅
C.The controller generates an interrupt on every byte transferred
D.The DMA channel is disabled completely
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: When D0 is cleared, the controller does not halt the channel after the terminal count expires; instead it continues the transfer, which can lead to overrunning the intended buffer. Therefore option B is correct. Setting D0 (A) would cause the stop, generating an interrupt (C) requires additional configuration, and disabling the channel (D) involves the enable bit, not TC stop.

Q17. Why does the 8257 provide separate LS and MS ports for the DMA address register?

A.To allow independent programming of high‑order and low‑order address bits ✅
B.To increase the speed of address loading
C.Because the LS port is used for read operations only
D.To match the 8‑bit data bus width of the CPU
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The DMA address register is 16 bits wide, but the 8257 interfaces with an 8‑bit data bus. Providing separate LS and MS ports lets the programmer load the low‑order byte and high‑order byte independently, ensuring the full address is correctly assembled. Option A captures this design reason. Options B, C, and D describe unrelated or inaccurate motivations.
