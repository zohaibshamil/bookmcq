Q1. What hexadecimal value is loaded into the Mode Set Register to enable channel 0 and start a DMA transfer?

A.41H ✅
B.42H
C.43H
D.44H
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The 8257 DMA controller uses the mode word 0x41H (binary 0100 0001) to enable channel 0, select a memory‑read operation, and start the transfer. Option A matches this value, so it is correct. Options B‑D represent different configurations: 0x42H would set a different channel, 0x43H adds auto‑initialize, and 0x44H disables the channel. Understanding the bit pattern links the hexadecimal code to the intended hardware behavior, which is essential for correct initialization.

Q2. Why must the terminal count be loaded first with the LS byte and then the MS byte when initializing the 8257 DMA controller?

A.Because the controller automatically increments the MS byte after the LS byte is written
B.Because the LS byte contains the most significant part of the count ✅
C.Because the hardware latches the LS byte before the MS byte to avoid overflow errors
D.Because the order does not matter; both bytes are stored simultaneously
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The 8257 expects the least‑significant byte before the most‑significant byte because its internal counter is built as a little‑endian register. Loading the LS byte first ensures the lower 8 bits are correctly placed before the higher bits are latched, preventing an accidental carry that could corrupt the count. Option B describes this required sequencing; the other options misstate the hardware behavior or claim irrelevant effects.

Q3. Which of the following instruction sequences correctly programs channel 0 to transfer 512 bytes from a peripheral to memory locations starting at 3000H?

A.Load MS byte of count, then LS byte, then address MS, then address LS
B.Load LS byte of count, then MS byte, then address LS, then address MS
C.Load LS byte of count, then MS byte, then address MS, then address LS ✅
D.Load address LS, then address MS, then LS count, then MS count
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: To move 512 bytes the terminal count must be set to 0x0200 (LS = 00H, MS = 02H). The DMA address registers require the high byte first (30H) then low byte (00H). Option C follows the required order: LS count → MS count → address MS → address LS, matching the 8257 programming protocol. Options A and B reverse the byte order, causing incorrect counts, while D loads the address before the count, which the controller would ignore until the count is programmed.

Option D matches the required bit pattern; the other values either select the wrong channel, indicate a write operation, or leave the controller disabled, leading to failed transfers.
