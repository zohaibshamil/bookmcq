Q1. A system uses DMA channel 0 of the 8257 to transfer 512 bytes from memory address 3000H to a peripheral. Which I/O write sequence correctly loads the Mode Set Register for a memory‑read operation?

🔹 A. OUT 28H, A = 41H
🔹 B. OUT 28H, A = 21H
🔹 C. OUT 28H, A = 81H
🔹 D. OUT 28H, A = 01H

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The mode word for a memory‑read operation must have bits D15‑D14 = 10 and the enable bit for channel 0 set to 1, which yields the hexadecimal value 41H (0100 0001b). Writing this value to the Mode Set Register (address 28H) tells the controller to read from memory and to enable channel 0. The other options either clear the enable bit or set the wrong operation mode, so they would not start the transfer.

Q2. What is the primary reason for loading the terminal count register’s LS byte before its MS byte when programming the 8257?

🔹 A. The controller expects the low‑order byte first
🔹 B. The high‑order byte contains the channel number
🔹 C. Loading order determines interrupt priority
🔹 D. It prevents overflow errors

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The 8257 reads the terminal count as a 16‑bit value in little‑endian form, meaning the least‑significant byte must be supplied before the most‑significant byte. Supplying the LS byte first ensures the internal counter is built correctly; otherwise the controller would interpret the bytes in reverse order, resulting in an incorrect transfer length. The other choices describe unrelated functions that the controller does not perform during count loading.

Q3. To perform a memory‑read DMA of 2 K bytes using channel 2, the mode word must encode D15‑D14 = 10 and D10‑D0 = 11111111111. Which hexadecimal value represents this mode word?

🔹 A. 87FFH
🔹 B. 07FFH
🔹 C. 87F0H
🔹 D. 87EFH

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A 2 K byte transfer corresponds to a 11‑bit binary field of all ones (11111111111₂), which equals 0x7FF. Placing this field in bits D10‑D0 and setting D15‑D14 to 10 for a memory‑read operation produces the 16‑bit pattern 1000 0111 1111 1111₂, or 0x87FFH. The other options either clear the required bits or alter the count field, so they would not configure the controller for the intended 2 K transfer.

Q4. In the example where channel 0’s DMA address register is at I/O port 20H, what is the address of the terminal count register for the same channel?

🔹 A. 20H
🔹 B. 21H
🔹 C. 28H
🔹 D. 73H

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The DMA address register for channel 0 is assigned to port 20H, and the terminal count register for that channel follows consecutively at the next I/O address, which is 21H. This mapping is defined by the 8257’s register layout. Port 28H belongs to the Mode Set Register, and 73H is used for the terminal count of a different channel, so those choices do not correspond to the terminal count register for channel 0.

Q5. Why must the LS byte of the starting address be written before the MS byte to the DMA address register?

🔹 A. Because the 8257 uses little‑endian ordering
🔹 B. Because the LS byte contains the channel identifier
🔹 C. Because the MS byte is ignored if written first
🔹 D. Because it triggers an automatic reset

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The 8257 stores multi‑byte addresses in little‑endian format, meaning the low‑order byte must be presented first followed by the high‑order byte. This ordering allows the controller to assemble the full address correctly as it receives the bytes. The LS byte does not hold a channel identifier, and the controller does not discard the MS byte or reset when the order is reversed; those statements describe unrelated behavior.

Q6. A designer needs to move 1024 bytes from a peripheral to memory starting at 4000H using channel 1, with auto‑initialization disabled. Which of the following I/O write sequences correctly sets the mode word, terminal count, and address registers?

🔹 A. OUT 28H, A=41H; OUT 21H, A=00H; OUT 21H, A=04H; OUT 20H, A=00H; OUT 20H, A=40H
🔹 B. OUT 28H, A=41H; OUT 21H, A=04H; OUT 21H, A=00H; OUT 20H, A=40H; OUT 20H, A=00H
🔹 C. OUT 28H, A=01H; OUT 21H, A=00H; OUT 21H, A=04H; OUT 20H, A=00H; OUT 20H, A=40H
🔹 D. OUT 28H, A=41H; OUT 21H, A=00H; OUT 21H, A=04H; OUT 20H, A=40H; OUT 20H, A=00H

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The correct sequence follows the required order: first write the mode word (41H enables channel 1 for a memory‑read), then load the terminal‑count LS byte (00H) followed by the MS byte (04H) to represent 0x0400 = 1024 bytes, and finally write the address LS byte (00H) and MS byte (40H) for the start location 0x4000. Options B and D reverse the LS/MS order for either count or address, breaking the little‑endian requirement, while option C uses an incorrect mode word, so only option A establishes the transfer correctly.

Q7. How does setting the 'TC stop' bit in the mode word influence the DMA channel after the terminal count is reached?

🔹 A. The channel halts and will not accept new requests until re‑programmed
🔹 B. The channel automatically restarts the transfer
🔹 C. The channel generates a system reset
🔹 D. The channel ignores the terminal count and continues

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

When the TC stop (terminal‑count stop) bit is asserted, the 8257 ceases operation on that channel as soon as the programmed count expires. No further DMA requests are serviced until the programmer rewrites the registers, providing precise control over the transfer length. The other choices describe behaviors that the controller does not exhibit: it does not automatically restart, issue a reset, or continue ignoring the count when the TC stop bit is active.

Q8. If the terminal count register receives LS byte 0xFF and MS byte 0x01, how many bytes will the DMA controller transfer before stopping?

🔹 A. 511
🔹 B. 255
🔹 C. 256
🔹 D. 512

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The two bytes combine to form the 16‑bit value 0x01FF, which equals \(1 \times 256 + 255 = 511\) decimal. The DMA controller decrements this count each time a byte is transferred, stopping when it reaches zero, so it will move exactly 511 bytes. The other options correspond to different hexadecimal values (0x00FF, 0x0100, and 0x0200) and therefore do not match the loaded count. This calculation shows how the controller interprets the terminal‑count registers to determine transfer length.
