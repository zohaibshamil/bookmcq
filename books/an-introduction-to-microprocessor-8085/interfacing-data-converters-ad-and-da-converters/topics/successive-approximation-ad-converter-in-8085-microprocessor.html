Q1. What hexadecimal value is loaded into the Mode Set Register for the example initialization?

🔹 A. 42H
🔹 B. 41H
🔹 C. 87H
🔹 D. 00H

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The example program uses the instruction MVI A, 42 H to place the mode word in the accumulator before sending it to the Mode Set Register, so 42H is the value loaded. Option B (41H) is a different mode word used in another scenario, C (87H) is the MS byte of the terminal count, and D (00H) is the low byte of the starting address. Selecting the correct mode word is critical because an incorrect value disables the DMA channel or sets wrong transfer characteristics, preventing the intended data movement.

Q2. Which bit in the Mode Set Register determines the transfer direction for a channel?

🔹 A. D7
🔹 B. D6
🔹 C. D1
🔹 D. D0

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Bit D6 of the Mode Set Register selects the direction of the transfer (memory‑to‑peripheral or peripheral‑to‑memory). Choosing D6 correctly configures the DMA controller to move data in the desired direction. Bit D7 merely enables the channel, D1 is used for auto‑initialization, and D0 often controls terminal‑count behavior. Misinterpreting the direction bit would cause data to be written to the wrong location, leading to corrupted files or system crashes.

Q3. If the terminal count LS byte is loaded with 00H and the MS byte with 04H for channel 1, what total count will the DMA controller use?

🔹 A. 256
🔹 B. 512
🔹 C. 1024
🔹 D. 4096

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The LS byte (00H) represents the low‑order 8 bits and the MS byte (04H) the high‑order bits, forming the 16‑bit value 0x0400. Converting to decimal gives 4 × 256 = 1024, which is the number of bytes the controller will transfer. Options A (256) and B (512) correspond to smaller counts, while D (4096) would require an MS byte of 0x10. Using the correct count ensures that exactly the intended block of memory is moved, avoiding overflow or underrun.

Q4. Why must the LS byte of the terminal count be loaded before the MS byte when initializing the DMA controller?

🔹 A. Because the LS byte triggers a reset of the counter
🔹 B. Because the MS byte contains control bits
🔹 C. Because the hardware ignores the LS byte if loaded later
🔹 D. Because the controller expects the LS byte first due to its little‑endian register design

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The 8257 DMA controller reads the count in the order the bytes are presented, treating the first byte as the least significant portion. Loading the LS byte first matches the internal little‑endian sequencing, allowing the controller to correctly assemble the full 16‑bit count. The other statements are incorrect: the LS byte does not reset the counter, the MS byte does not hold control bits, and the controller does not ignore a later LS byte. Following the proper sequence prevents an incorrect count that could cause premature termination or excessive data transfer.

Q5. A 10‑bit successive‑approximation ADC with a 5 V reference receives the code 0x2A3. What input voltage does this code represent?

🔹 A. 3.30 V
🔹 B. 2.75 V
🔹 C. 1.35 V
🔹 D. 4.57 V

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The code 0x2A3 equals 675 in decimal. For a 10‑bit converter, the full‑scale count is 2^10 − 1 = 1023. The voltage is therefore (675 / 1023) × 5 V ≈ 3.30 V. Option B (2.75 V) would correspond to a lower count, C (1.35 V) far lower, and D (4.57 V) near full scale. Accurately converting the digital output to an analog voltage is essential for control loops that rely on precise sensor readings; an error would lead to incorrect actuation.

Q6. If the terminal count MS byte is mistakenly loaded with FFH while the LS byte is 00H, what unintended behavior occurs during a 256‑byte transfer?

🔹 A. Transfer stops after 255 bytes
🔹 B. Transfer continues beyond the intended region, overwriting memory
🔹 C. Transfer will attempt to move 65 536 bytes
🔹 D. Transfer causes bus contention and halts the CPU

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Loading FFH as the MS byte creates a count of 0xFF00 = 65 280, far larger than the required 256 bytes. The DMA engine will keep decrementing the count, pulling data from addresses beyond the allocated buffer and potentially overwriting adjacent memory, which can corrupt program data or system structures. Option A would only happen if the count were one less than needed, C describes the exact large count but the controller stops at zero, and D is unrelated to count size. Proper count programming protects memory integrity.

Q7. How does the successive‑approximation process guarantee monotonic conversion, and why is this important for control systems?

🔹 A. By successive averaging of samples
🔹 B. By integrating the input signal over time
🔹 C. By random sampling of the input
🔹 D. By performing a binary search that never revisits a previous decision

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

A successive‑approximation ADC tests each bit from most to least significant, deciding each based on whether adding that weighted value would exceed the input voltage. This binary‑search method ensures that once a decision is made it is never changed, producing a monotonic relationship between input voltage and digital output. Options A, B, and C describe other conversion techniques that do not provide this guarantee. Monotonicity is vital in control loops because non‑monotonic behavior could cause oscillations or instability in the feedback response.

Q8. An SAR ADC operates with a 1 MHz clock and needs a conversion time of 10 µs per sample. How many clock cycles does each conversion require?

🔹 A. 10
🔹 B. 11
🔹 C. 12
🔹 D. 13

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A conversion time of 10 µs at 1 MHz corresponds to 10 clock periods, but a successive‑approximation converter also needs one additional cycle for the sample‑and‑hold phase, giving a total of N + 1 cycles for an N‑bit conversion. For a 10‑bit ADC this yields 11 cycles. Option A omits the extra cycle, C and D assume extra cycles beyond the required count. Knowing the exact cycle count helps designers match ADC speed to system timing constraints.

Q9. When the Mode Set Register is programmed with the value 0x41 for channel 0, which bit indicates that channel 0 is enabled?

🔹 A. D0
🔹 B. D3
🔹 C. D6
🔹 D. D7

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The binary form of 0x41 is 0100 0001; the bit in position D6 is set to 1, which enables channel 0. D7 is the global enable bit, D0 often controls terminal‑count behavior, and D3 is unused in this context. Recognizing the correct enable bit is essential when configuring DMA channels; activating the wrong bit could leave the channel disabled, preventing any data transfer and leading to system‑level failures.

Q10. What advantage does a successive‑approximation ADC have over a counter‑type ADC regarding conversion speed?

🔹 A. It requires fewer clock cycles per conversion
🔹 B. It uses a ramp signal that speeds up conversion
🔹 C. It can operate without a reference voltage
🔹 D. It provides higher resolution than a counter‑type ADC

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A successive‑approximation converter determines each bit by a binary decision, needing only one clock cycle per bit plus a sample phase, so the total cycles grow linearly with resolution. Counter‑type ADCs must count through every possible level, which can require thousands of cycles for high resolution, making them much slower. Options B, C, and D describe unrelated characteristics. Faster conversion is critical in applications like audio sampling where high throughput is required.

Q11. What is the hexadecimal address of the DMA address register for channel 0 as used in the initialization example?

🔹 A. 21H
🔹 B. 28H
🔹 C. 73H
🔹 D. 20H

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The example specifies that the address of the DMA address register for channel 0 is 20H, and the program writes to this address to load the low and high bytes of the start address. Option A (21H) is the address of the terminal‑count register, B (28H) is the Mode Set Register address, and C (73H) is the terminal‑count register for another channel. Using the correct register address ensures that the DMA controller knows where to fetch the starting memory location, which is essential for successful data transfers.
