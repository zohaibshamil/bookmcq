📝 All Interrupt Modes of 8259A MCQs

Q1. A system designer wants to generate periodic interrupts using counter 0 of the 8253. Which pin must be connected to the interrupt request line of the 8259A to ensure the interrupt is triggered?

🔹 A. CLK0 (Pin 9)
🔹 B. OUT0 (Pin 10)
🔹 C. GATE0 (Pin 11)
🔹 D. CS (Pin 21)

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

OUT0 is the output terminal of counter 0. When the counter reaches its terminal count, it toggles OUT0, which can be wired to the interrupt request (IRQ) input of the 8259A. CLK0 only provides the timing signal, and GATE0 merely enables or disables counting; they do not produce an interrupt. CS is used for chip selection, not for interrupt signaling. Therefore connecting OUT0 to the IRQ line ensures the interrupt is generated when the counter expires.

Q2. Which combination of control signals CS, RD, WR, A1, and A0 causes the 8253 to write a mode word into its mode register?

🔹 A. CS=0, RD=0, WR=1, A1=1, A0=1
🔹 B. CS=0, RD=1, WR=1, A1=0, A0=0
🔹 C. CS=0, RD=1, WR=0, A1=1, A0=1
🔹 D. CS=1, RD=0, WR=0, A1=0, A0=0

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The table of control‑signal actions shows that writing a mode word requires CS low, RD high, WR low, and the address lines selecting the mode register (A1=1, A0=1). In option C the signals match this pattern, so the 8253 interprets the bus cycle as a mode‑word write. Option A has WR high, which indicates a read operation. Option B sets WR high, also preventing a mode‑word write. Option D sets CS high, which disables the device entirely. Thus only option C correctly triggers a mode‑word write.

Q3. During configuration of the 8259A in level‑triggered mode, a designer keeps pin GATE2 low while also enabling counter 2. What is the most likely result on interrupt generation from counter 2?

🔹 A. Counter 2 will never generate an interrupt request.
🔹 B. Counter 2 will continuously assert the interrupt request.
🔹 C. Counter 2 will generate an interrupt only after a system reset.
🔹 D. There will be no effect on interrupt generation.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Keeping GATE2 low disables the counting operation of counter 2, regardless of its enable bit. In level‑triggered mode the interrupt request is generated only when the counter produces an active output on its OUT2 pin. Because GATE2 prevents the counter from counting, OUT2 never becomes active, so the 8259A never receives an interrupt request from this source. Option B describes continuous interrupts, which would require the output to be permanently asserted, not the case here. Therefore the correct outcome is that counter 2 will never generate an interrupt request.
