📝 Polled Mode of 8259A (5 MCQs)

Software-Controlled Interrupt Identification Without Normal INT Response

Polled Mode allows the processor to identify pending interrupt requests by reading the 8259A rather than depending on the normal interrupt-response sequence. The controller continues to collect and prioritize requests, but software issues a poll command and reads the result. This approach is useful when a program needs to inspect and service requests through a common polling routine.

OCW3 Poll Command and Processor Interrupt Handling

Software selects polling by setting the P bit in OCW3. The INT output continues to operate normally, but the processor should ignore it, for example by keeping its interrupt response disabled or leaving the INT connection unused. The next read operation from the selected controller acts as an interrupt acknowledgement rather than an ordinary status-register read.

Information Returned by the Poll Read Operation

During the poll read, the most significant returned bit indicates whether a valid interrupt request is present. When that bit is one, bits D2–D0 identify the highest-priority request level. The controller acknowledges the selected level and records its service state, allowing software to use the returned number to select the corresponding routine.

Example of Identifying a Pending IR3 Request

Suppose IR3 is the highest-priority eligible request when software performs a poll read. The returned byte has D7 set to indicate a valid request and D2–D0 equal to 011, identifying level 3. The program can then branch to the IR3 service routine and issue an appropriate EOI after service is complete.

Applications Where a Common Software Service Routine Is Preferred

Polling is useful when several interrupt levels can share a common software dispatch routine or when the system needs explicit control over the order in which requests are examined. It avoids the normal INTA vector-transfer sequence, but it requires software to perform the poll read and interpret its result. Request priority selection remains the responsibility of the 8259A.

Misconceptions About Polling and Interrupt Acknowledgement

'Poll mode disables the IR inputs' is incorrect because requests are still received and recorded. 'The poll result is always a valid interrupt number' is incorrect because D7 indicates whether any request is available. 'Polling uses the normal three-pulse 8085 INTA sequence' is incorrect because the poll read itself performs the acknowledgement function.

Poll Command, Returned Bits and Service Tracking in Exams

Recognize OCW3 and its P bit as the poll-mode control. Interpret D7 as the request-present indicator and D2–D0 as the selected level when D7 is one. Explain why the processor ignores normal INT response, how the poll read acknowledges a request, and why service completion still requires appropriate EOI handling.

Polling and Request Identification Terms

  • Poll Mode - Software reads to identify requests.
  • P Bit - Enables the poll command.
  • D7 - Indicates a valid pending request.
  • D2–D0 - Identify the selected interrupt level.
  • IRR - Holds pending interrupt requests.
  • ISR - Records an acknowledged service level.

📝 All Polled Mode of 8259A MCQs

Q1. Which pin provides the clock input for counter 0 in the 8253 timer chip?

A.Pin 10
B.Pin 9 ✅
C.Pin 11
D.Pin 12
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The clock input for counter 0 is found on pin 9, labeled CLK 0. Pin 10 carries the output of counter 0, and pin 11 is the gate input, so they are not the clock source. Pin 12 is the ground terminal, which provides reference voltage but does not carry signals. Knowing the exact pin assignments is essential when wiring the 8253 in a circuit, because connecting the clock to the wrong pin would prevent the counter from counting, leading to malfunction.

Q2. What is the primary function of the CS (Chip Select) signal in the 8253 when it is asserted low?

A.It disables all counters
B.It selects the address bus
C.It enables the device so that it can respond to further control signals ✅
D.It provides power to the chip
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The CS line is active‑low, meaning that a logical 0 enables the 8253. When CS is low, the chip listens to the other control signals (RD, WR, A0, A1) and can perform loads, reads, or mode‑word writes. It does not disable the counters; instead, it powers the device’s ability to respond. Selecting the address bus is performed by A0 and A1, not by CS. Therefore the primary role of CS is to enable the device so that subsequent control signals are interpreted correctly.

Q3. A microcontroller needs to read the current count from counter 2. Which combination of control signals must be set according to the 8253 control table?

A.CS=0, RD=0, WR=1, A1=1, A0=0 ✅
B.CS=0, RD=1, WR=0, A1=1, A0=0
C.CS=0, RD=0, WR=1, A1=0, A0=1
D.CS=1, RD=0, WR=1, A1=1, A0=0
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Reading counter 2 requires the chip to be selected (CS = 0) and the read line asserted low (RD = 0) while the write line stays high (WR = 1) to avoid a write operation. The address bits A1 = 1 and A0 = 0 uniquely identify counter 2 in the 8253’s internal map. This combination matches the table entry for ‘Read counter 2’. Any other pattern would either target a different counter, perform a write, or result in no operation, preventing the microcontroller from obtaining the correct count value.

Q4. Why does the 8253 use the A0 and A1 lines to select counters and the control word register rather than dedicated separate pins for each function?

A.It reduces the number of pins required
B.It allows the device to be addressed using the CPU’s existing address bus ✅
C.It enables simultaneous operation of all counters
D.It provides a way to increase the clock frequency
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Using only two address lines (A0 and A1) to select among the three counters and the mode‑word register lets the 8253 share the CPU’s existing address bus, saving pins and simplifying board layout. This approach reduces the total pin count compared with having separate select lines for each function, which would increase wiring complexity. It also allows software to address the desired counter by setting the appropriate binary value on A0/A1, making the device flexible and easy to integrate into systems that already use a two‑bit address space for peripheral selection.

Q5. To load a new mode word into the 8253 while keeping the counters inactive, which control‑signal pattern should be applied?

A.CS=0, RD=1, WR=0, A1=0, A0=0
B.CS=0, RD=1, WR=0, A1=1, A0=1 ✅
C.CS=0, RD=0, WR=1, A1=1, A0=1
D.CS=1, RD=1, WR=0, A1=1, A0=1
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Loading a new mode word requires the chip to be selected (CS = 0), the write line held low (WR = 0) to indicate a write operation, and the read line kept high (RD = 1) so that no read occurs. The address bits A1 = 1 and A0 = 1 specifically address the control word register according to the 8253’s decoding scheme. With this pattern the counters remain idle because no load or read command is issued, allowing the mode word to be programmed safely. Any other combination would either address a counter or perform a no‑operation, preventing proper mode configuration.)
