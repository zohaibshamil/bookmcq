What is Control Word Format of 8253?

The control word is an \(8\)-bit command written to the control register where bits \(D7-D6\) select the counter, bits \(D5-D4\) define the read/write format (LSB only, MSB only, or both), and bits \(D3-D1\) specify one of the six operating modes while bit \(D0\) selects binary or BCD counting.

📝 All Control Word Format of 8253 MCQs

Q1. What is the size of the control word that must be written to the 8253 timer?

A. 8 bits ✅
B. 16 bits
C. 24 bits
D. 32 bits

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The 8253 requires a single byte (8 bits) for its control word because each field—counter select, read/load, mode, and BCD/binary—fits within one byte. A 16‑bit word would be unnecessary and would not match the chip’s register layout. Likewise, 24‑ and 32‑bit sizes are far larger than needed and would never be accepted by the hardware.

Q2. Which field in the control word is responsible for selecting which counter (0, 1, or 2) is being programmed?

A. Mode bits
B. Counter select bits ✅
C. BCD/Binary bit
D. Read/Load bits

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The two most‑significant bits of the control word identify the counter: 00 for counter 0, 01 for counter 1, and 10 for counter 2. Mode bits choose the operating mode, the BCD/Binary bit chooses counting base, and the Read/Load bits control how the count value is accessed. Selecting the correct counter is essential for independent timer operation.

Q3. A designer wants a 1 kHz square‑wave output from counter 0. Which mode bits should be set in the control word?

A. Mode 0 (interrupt on terminal count)
B. Mode 3 (square‑wave generator)
C. Mode 2 (rate generator) ✅
D. Mode 5 (hardware trigger)

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Mode 2, the rate generator, produces a periodic output that can be divided by two to obtain a 1 kHz square wave when the appropriate count is loaded. Mode 0 only generates a single pulse, Mode 3 creates a square wave directly but with a different duty cycle, and Mode 5 is for hardware‑triggered counting, none of which suit the 1 kHz requirement.

Q4. How does the BCD/Binary select bit affect the counting operation of an 8253 counter?

A. It determines the counting base (binary or BCD)
B. It selects the clock source frequency
C. It enables the gate input
D. It sets the operating mode ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

When the BCD/Binary bit is 0, the counter counts in pure binary; when it is 1, the counter counts in packed BCD, meaning each four‑bit nibble represents a decimal digit. This choice does not change the clock source, gate behavior, or mode selection, but it directly influences how the loaded count value is interpreted and how overflow is detected.

Q5. With a 1.19318 MHz clock, what 16‑bit value must be loaded into counter 1 (binary mode, mode 0) to obtain a 10 ms delay?

A. 11844 ✅
B. 12032
C. 11520
D. 11776

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The required count equals clock × delay: \(1.19318\times10^{6}\times0.01\approx11932\) decimal, which is 0x2E44 in hexadecimal. Loading this value causes the counter to decrement from 11932 to zero, taking exactly 10 ms. The other options are off by several hundred counts, producing noticeably longer or shorter delays, which would be unacceptable for precise timing.

Q6. Why does the control word contain separate Read/Load bits for LSB and MSB?

A. To allow sequential access to the low and high bytes of the count value
B. To enable direct memory access (DMA) transfers ✅
C. To set the operating mode of the counter
D. To select which counter is being programmed

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Separate Read/Load bits let the processor first write (or read) the least‑significant byte and then the most‑significant byte, matching the 8‑bit data bus of many microprocessors. This sequential approach simplifies hardware design and avoids the need for a 16‑bit bus. DMA, mode selection, and counter selection are handled by other fields in the control word.

Q7. If the control word is 0b00110101, which combination of fields does it represent?

A. Counter 2, LSB only, Mode 3, binary
B. Counter 0, LSB then MSB, Mode 2, BCD
C. Counter 1, MSB only, Mode 5, binary
D. Counter 0, LSB then MSB, Mode 2, BCD ✅

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Bits 7‑6 = 00 select counter 0; bits 5‑4 = 11 indicate a LSB‑then‑MSB read/write operation; bits 3‑1 = 010 encode mode 2 (rate generator); bit 0 = 1 selects BCD counting. This decoding shows how each part of the byte maps to a specific function, enabling precise configuration of the timer. The other options misinterpret one or more fields, leading to incorrect operation.

Q8. Which hexadecimal control word should be written to configure counter 2 for mode 3 (square‑wave), binary counting, with a LSB‑then‑MSB load sequence?

A. 182 ✅
B. 166
C. 150
D. 198

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Counter 2 is identified by bits 7‑6 = 10 (0x80). A LSB‑then‑MSB load uses bits 5‑4 = 11 (0x30). Mode 3 is encoded as 011 in bits 3‑1 (0x06). The BCD bit is 0 for binary counting. Adding the components gives 0x80 + 0x30 + 0x06 = 0xB6. The other hexadecimal values change one or more fields, resulting in a different counter, mode, or counting base.

Q9. What is the primary purpose of the gate input on each 8253 counter?

A. To select the operating mode of the counter
B. To provide power to the counter circuit
C. To start or stop the counting process ✅
D. To reset the counter to zero

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The gate input acts as an enable signal: when asserted, the counter receives clock pulses and begins counting; when de‑asserted, counting pauses while the current count is held. It does not change the mode, supply power, or reset the counter—those functions are controlled by other pins. Proper gating is crucial when timers must be synchronized with external events.

Q10. A system with a 500 kHz clock needs an interrupt every 5 ms using counter 0 in binary mode. Which value should be loaded into the counter?

A. 2560
B. 2500 ✅
C. 3840
D. 2244

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The required count is clock × interval: \(500{,}000\times0.005 = 2{,}500\) decimal, which converts to 0x09C4 in hexadecimal. Loading this value makes the counter roll over after exactly 5 ms, generating the interrupt. The other options correspond to counts that are either too large or too small, producing longer or shorter interrupt periods that would not meet the timing requirement.
