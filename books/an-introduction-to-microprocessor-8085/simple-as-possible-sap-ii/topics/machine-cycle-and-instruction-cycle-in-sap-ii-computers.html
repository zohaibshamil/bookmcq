Q1. In which year was the Intel 4004 microprocessor introduced?

🔹 A. 1970
🔹 B. 1971
🔹 C. 1972
🔹 D. 1973

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The Intel 4004 was released in 1971, marking the first commercially available microprocessor. This date is the correct answer because historical records show its launch that year. The other years listed either precede the development of the 4004 or follow it, making them inaccurate. Knowing the introduction year helps understand the timeline of microprocessor evolution and why early computers began shifting from discrete components to integrated CPU designs.

Q2. What does the term “word size” refer to in a microprocessor?

🔹 A. Number of pins
🔹 B. Number of bits processed as a unit
🔹 C. Clock speed
🔹 D. Voltage level

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

Word size refers to the number of bits a microprocessor processes as a single unit, which also determines the width of its data bus. This definition is correct because it directly describes the fundamental characteristic of a processor. The other options—number of pins, clock speed, and voltage level—describe physical or performance attributes, not the concept of word size. Understanding word size is essential for matching processors to applications that require specific data widths.

Q3. Why does the control unit need to coordinate timing of communication between CPU and memory?

🔹 A. To ensure each component receives signals at the correct moment
🔹 B. To increase power consumption
🔹 C. To reduce the instruction set
🔹 D. To simplify arithmetic operations

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The control unit must coordinate timing because it ensures that each component—memory, ALU, and I/O—receives signals at the correct moment, preventing data collisions and guaranteeing correct instruction execution. This reason is correct as timing synchronization is the core function of the control unit. Options suggesting increased power consumption, reduced instruction sets, or simplified arithmetic are unrelated to the timing role and therefore incorrect. Proper timing is vital for reliable operation of any computer system.

Q4. How does increasing the word size of a microprocessor affect the width of the data bus?

🔹 A. It reduces the bus width
🔹 B. It leaves the bus width unchanged
🔹 C. It increases the bus width proportionally
🔹 D. It makes the bus bidirectional

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Increasing the word size expands the number of bits handled per operation, which directly enlarges the data bus width to match the processor’s capability. Therefore, the bus width grows proportionally with word size, making option C correct. Reducing the bus width or leaving it unchanged would create a bottleneck, while making the bus bidirectional does not address width. Aligning bus width with word size enables faster data transfer and efficient system design.

Q5. What is the main advantage of integrating the CPU onto a single large‑scale integrated circuit compared to using discrete components?

🔹 A. It slows down execution
🔹 B. It increases power consumption
🔹 C. It makes programming harder
🔹 D. It reduces size, cost, and improves reliability

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Integrating the CPU onto a single large‑scale integrated circuit reduces physical size, lowers manufacturing cost, and improves reliability by eliminating numerous discrete components and interconnections. This advantage is captured in option D, making it correct. The other options—slowing execution, increasing power consumption, or complicating programming—are false because integration typically speeds up operation, reduces power usage, and does not affect programming complexity. These benefits drove the shift to microprocessor‑based computers.

Q6. In the instruction cycle, what is the purpose of the fetch phase?

🔹 A. Retrieve the next instruction from memory
🔹 B. Decode the operand
🔹 C. Execute the operation
🔹 D. Store the result

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The fetch phase’s purpose is to retrieve the next instruction from memory and place it in the instruction register, preparing the CPU for decoding. This description matches option A and is therefore correct. Decoding the operand, executing the operation, and storing the result are distinct phases that occur after fetching, so options B, C, and D are incorrect. Accurate fetching is essential for the instruction cycle to progress correctly in any processor.

The CPU, embodied by the microprocessor, performs the core computational tasks such as arithmetic and logic operations, while input/output devices handle communication with the external world. Recognizing this separation helps engineers design balanced systems where the CPU focuses on processing and peripherals manage interaction.

Q9. A designer needs to select a microprocessor for a system that must handle 16‑bit data values and interface with a 16‑bit data bus. Which microprocessor characteristic is most critical?

🔹 A. Clock speed
🔹 B. Number of pins
🔹 C. Word size matching the bus width
🔹 D. Power consumption

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

When designing a system that must handle 16‑bit data values and interface with a 16‑bit data bus, the most critical microprocessor characteristic is its word size matching the bus width, ensuring efficient data transfer without extra slicing or merging. Q10. If a system uses an 8‑bit microprocessor with a 8‑bit data bus but needs to process 32‑bit integers, what technique can be employed?

🔹 A. Use multiple 8‑bit operations to combine the parts
🔹 B. Increase the clock speed dramatically
🔹 C. Employ DMA to transfer 32‑bit blocks
🔹 D. Change the voltage level to support larger words

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

To process 32‑bit integers on an 8‑bit microprocessor, the programmer can break the operation into multiple 8‑bit steps, using sequences of instructions to combine the parts into a full 32‑bit result. This technique is described in option A and is correct. Increasing the clock speed, employing DMA, or changing the voltage level do not address the fundamental limitation of the processor’s data width, making those options incorrect. Such multi‑step handling is common in low‑bit embedded designs.

Q11. A programmer writes an assembly loop that repeatedly reads a memory location, increments the value, and writes it back. Which phase of the instruction cycle is executed most frequently?

🔹 A. Fetch
🔹 B. Decode
🔹 C. Execute
🔹 D. Write‑back

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

In a loop that reads, increments, and writes back a memory location, the write‑back phase occurs each iteration after the arithmetic operation, making it the most frequently executed stage in that specific scenario. Option D correctly identifies this phase. While fetching, decoding, and executing also repeat each iteration, the write‑back is directly tied to the memory update and therefore dominates the cycle count for this pattern. Understanding which phase is most active aids in optimizing loop performance.

Q12. Suppose a microprocessor's control unit is redesigned to reduce the number of clock cycles per instruction from four to three. What impact does this have on overall execution time, assuming clock frequency unchanged?

🔹 A. It reduces execution time proportionally
🔹 B. It increases execution time
🔹 C. It has no effect on execution time
🔹 D. It reduces clock frequency

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Reducing the number of clock cycles per instruction from four to three shortens the time needed to complete each instruction, thereby decreasing the overall execution time proportionally, assuming the clock frequency stays the same. This outcome is captured in option A, the correct answer. Increasing execution time or having no change would contradict the effect of fewer cycles, and lowering the clock frequency would actually increase execution time, making those options incorrect. Faster instruction throughput improves program efficiency.

Q13. In a microcomputer, the CPU must communicate with a peripheral that operates at a slower speed. Which control unit strategy ensures correct data transfer?

🔹 A. Increase the CPU clock speed
🔹 B. Ignore the slower device
🔹 C. Use DMA to bypass the CPU
🔹 D. Insert wait states to pause the CPU

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

When a peripheral operates slower than the CPU, the control unit can insert wait states—deliberate idle cycles—so that the CPU pauses until the peripheral is ready, ensuring correct data transfer. Option D correctly describes this strategy. Increasing the CPU clock speed would exacerbate the mismatch, ignoring the slower device would cause errors, and using DMA bypasses the CPU but does not solve timing alignment, so those options are wrong. Wait states are a common technique for handling speed differences.

Q14. A microprocessor based system requires both high speed arithmetic and large memory addressing. Which word size would best satisfy both needs, and why?

🔹 A. 8‑bit
🔹 B. 16‑bit
🔹 C. 32‑bit
🔹 D. 64‑bit

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

A 32‑bit word size provides a balance: it allows fast arithmetic on large numbers and offers a sizable address space for accessing extensive memory, making it the most suitable choice for systems requiring both capabilities. Option C correctly reflects this trade‑off. An 8‑bit word limits arithmetic speed and addressable memory; a 16‑bit word improves somewhat but still falls short for large data sets; a 64‑bit word, while powerful, may be unnecessary and increase cost for many applications. Hence, 32‑bit is optimal.

Q15. During debugging, a student observes that a program stalls after the fetch stage. Which of the following is the most likely cause?

🔹 A. Corrupted instruction memory
🔹 B. Faulty ALU
🔹 C. Missing decode logic
🔹 D. Power failure

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

If a program stalls after the fetch stage, the most common cause is a corrupted or inaccessible instruction memory, preventing the CPU from retrieving the next opcode. Option A correctly identifies this issue. A faulty ALU, missing decode logic, or power failure would manifest later in the cycle or affect the entire system, making those choices inaccurate. Detecting fetch‑stage problems often involves checking memory integrity and address lines, which is essential for debugging.
