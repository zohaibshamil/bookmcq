Q1. In which year was the Intel 4004 microprocessor introduced?

A.1971 ✅
B.1974
C.1978
D.1980
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The Intel 4004 debuted in 1971, marking the first commercially available microprocessor. This date is a factual datum, so the answer is straightforward. Options 1974, 1978, and 1980 are later dates that correspond to other early chips (e.g., 8080, 8086) and are therefore incorrect. Knowing the correct year helps place the microprocessor in its historical context, showing how it launched the microcomputer era.

Q2. What does the term “word size” of a microprocessor refer to?

A.The number of transistors on the chip
B.The number of bits processed as a single unit ✅
C.The voltage level required for operation
D.The physical dimensions of the package
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Word size indicates how many bits the CPU handles together, such as 8‑bit or 16‑bit. It determines the width of the data bus and the size of registers. The other options describe unrelated characteristics: transistor count, voltage, and package size do not define word size. Understanding word size is essential for matching software expectations with hardware capability.

Q3. Why is the control unit essential in a microprocessor‑based system?

A.It generates the system clock
B.It manages the timing of communication between CPU and peripherals
C.It stores program data permanently ✅
D.It supplies power to the processor
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The control unit orchestrates the sequence of operations, ensuring that each instruction fetch, decode, and execution step occurs in the correct order. Generating the clock is the clock generator’s job, not the control unit. Permanent storage is handled by memory, and power delivery is a hardware supply issue. Without proper control sequencing, the CPU cannot reliably interact with memory or I/O devices.

Q4. A designer must choose between an 8‑bit and a 16‑bit microprocessor for a simple sensor interface that only sends 8‑bit readings but occasionally needs to compute a 16‑bit checksum. Which choice minimizes instruction overhead while meeting the requirements?

A.8‑bit processor with software‑implemented checksum
B.16‑bit processor with built‑in 16‑bit arithmetic ✅
C.8‑bit processor with external co‑processor
D.16‑bit processor but limit data bus to 8‑bit
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A 16‑bit processor already includes registers and ALU capable of handling 16‑bit arithmetic, so computing the checksum requires fewer instructions than emulating the operation on an 8‑bit device. Using an 8‑bit processor would force the programmer to split the checksum into multiple steps, increasing code size and execution time. The external co‑processor adds complexity, and limiting the bus does not change the internal word size.

Q5. If a system must process 32‑bit integers efficiently, which microprocessor word size is most appropriate?

A.4‑bit
B.8‑bit
C.16‑bit
D.32‑bit ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: A 32‑bit word size matches the data width, allowing the CPU to load, compute, and store a full integer in a single cycle. Smaller word sizes (4, 8, 16‑bit) would require multiple cycles or additional instructions to handle a single 32‑bit value, reducing performance. Selecting a matching word size aligns the processor’s natural data width with the application’s demands.

Q6. A microprocessor has a 4‑bit data bus but a declared 8‑bit word size. What practical limitation does this create?

A.It cannot address more than 16 memory locations
B.It must fetch each word in two bus cycles ✅
C.It cannot execute 8‑bit arithmetic instructions
D.It will overheat due to mismatched bus widths
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: With a 4‑bit bus, an 8‑bit word must be transferred in two successive cycles, effectively halving the data‑transfer rate compared to a matching 8‑bit bus. This does not restrict addressable memory directly, nor does it prevent 8‑bit arithmetic (the ALU can still operate on 8‑bit values). Overheating is unrelated to bus width. The limitation impacts throughput, which matters for time‑critical applications.

Q7. How does integrating the CPU onto a single large‑scale integrated circuit improve system performance?

A.It reduces signal propagation delay between components ✅
B.It increases the power consumption of the chip
C.It makes the CPU harder to program
D.It eliminates the need for any external memory
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Placing the CPU on one LS‑IC shortens the electrical paths between functional blocks, decreasing propagation delay and allowing higher clock speeds. Power consumption may actually decrease due to fewer interconnects, and programming difficulty is unchanged. While integration can reduce reliance on many external chips, external memory is still required for most applications. Faster internal communication directly translates to better overall performance.

Q8. In a microcomputer, the CPU must communicate with memory using control signals. If the control unit fails to assert the READ line during a fetch, what is the most likely outcome?

A.Data will be written to memory instead of read
B.The system will execute the wrong instruction
C.The CPU will stall waiting for data that never arrives ✅
D.Memory will be corrupted
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: When the READ signal is not activated, the memory does not place the requested word on the data bus, so the CPU receives no valid data and typically enters a wait state or repeats the fetch cycle. This does not cause inadvertent writes or corruption; it merely halts progress. Consequently, the system appears frozen until the control logic is corrected, highlighting the critical role of proper control‑signal timing.

Q9. Explain the relationship between a microprocessor’s word size and the width of its data bus.

A.They are always identical by definition
B.Word size determines how many bits can be transferred per bus cycle ✅
C.The data bus width is unrelated to word size
D.Word size is twice the bus width in all modern CPUs
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The word size defines the natural chunk of data the CPU processes, while the data bus width specifies how many bits can be moved in a single transfer. Ideally, the bus matches the word size so that one transfer delivers a full word; otherwise, the CPU must perform multiple bus cycles to handle one word. The two concepts are linked but not obligatorily identical, and they are not fixed at a constant ratio.

Q10. A programmer writes assembly that sets a flag bit after a comparison. If the flag is not set correctly because an instruction is missing, which subsequent conditional jump is most likely to behave incorrectly?

A.Jump if Zero (JZ) ✅
B.Jump if Carry (JC)
C.Jump if Overflow (JO)
D.Jump if Sign (JS)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The Zero flag reflects whether the result of a comparison equals zero; many conditional jumps (e.g., JZ) rely on this flag. If the flag is never updated, the JZ instruction will make a decision based on stale information, causing incorrect program flow. The other jumps depend on different flags (carry, overflow, sign) that are unaffected by the missing zero‑flag instruction.

Q11. What abbreviation is commonly used for microprocessor in technical documentation?

A.µp ✅
B.MCU
C.CPU
D.ASIC
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Technical literature frequently shortens “microprocessor” to the symbol µp, where the Greek mu denotes “micro.” MCU stands for microcontroller unit, CPU for central processing unit, and ASIC for application‑specific integrated circuit; each refers to distinct hardware categories. Recognizing the abbreviation helps students read schematics and datasheets without confusion.

Q13. Why did the shift from discrete switching devices to integrated circuits enable the rise of microcomputers in the mid‑1970s?

A.It reduced component size and cost
B.It increased the power consumption dramatically
C.It made programming languages obsolete
D.It eliminated the need for any memory devices ✅

Q14. A programmer writes assembly code that sets a flag bit after a comparison. If the flag is not set correctly due to a missing instruction, which subsequent conditional jump will behave incorrectly?

A.Jump if Zero (JZ) ✅
B.Jump if Carry (JC)
C.Jump if Overflow (JO)
D.Jump if Sign (JS)
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The Zero flag indicates whether the compared values are equal; conditional jumps like JZ depend on this flag. The other jumps rely on different status bits (carry, overflow, sign) that are unaffected by the missing zero‑flag instruction.

Q15. How does the control unit differ from the arithmetic logic unit (ALU) in a CPU?

A.CU performs arithmetic, ALU handles timing
B.CU stores data, ALU fetches instructions
C.CU orchestrates operations, ALU executes arithmetic/logic functions ✅
D.CU provides power, ALU manages memory
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The control unit acts as the brain’s scheduler, directing which operation the ALU should perform, fetching instructions, and managing data flow. The ALU, by contrast, carries out the actual calculations and logical tests. Neither unit supplies power or directly stores data; those roles belong to other subsystems. Recognizing this division clarifies how CPUs execute programs efficiently.
