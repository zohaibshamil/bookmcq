What is Addressing Modes of SAP II Computers?

Addressing modes in SAP-II define the various methods by which an instruction specifies operand locations, including immediate mode where data is directly given as or , register mode using internal registers, direct mode specifying a full -bit memory address, and implicit mode where operands are inherently understood by the opcode.

Q1. What is the word size of the Intel 4004 microprocessor?

A.4-bit ✅
B.8-bit
C.16-bit
D.32-bit
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The Intel 4004, introduced in 1971, processes data in groups of four bits, so its word size is 4‑bit. This determines the width of its data bus and the size of registers it can handle. Options B, C, and D describe larger word sizes that belong to later microprocessors such as the 8085 (8‑bit) or 80286 (16‑bit). Therefore the correct answer is A.

Q2. Why does a CPU use different addressing modes?

A.To increase clock speed
B.To provide flexibility in locating operands ✅
C.To reduce power consumption
D.To simplify hardware design
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Different addressing modes give the processor flexibility in finding the required operand, whether it is stored in a register, in memory, or as an immediate constant. This flexibility allows programs to be written more efficiently and enables the CPU to handle a variety of data layouts. Options A, C, and D describe unrelated benefits; they do not explain the primary purpose of multiple addressing modes. Hence B is correct.

Q3. A programmer needs to load the constant value 25 into accumulator A. Which instruction correctly uses immediate addressing?

A.MOV A,25 ✅
B.LD A,[25]
C.MOV A,#25
D.ADD A,25
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Immediate addressing embeds the constant directly in the instruction, usually indicated by a prefix such as “#”. The form “MOV A,#25” places the value 25 into A without referencing memory. Option A treats 25 as a memory address, option B uses indexed syntax, and option D performs an addition rather than a load. Thus the correct choice is C, which matches the definition of immediate addressing.

Q4. Memory location 0x2000 contains the address 0x3000 where the desired byte resides. Which instruction accesses the byte using indirect addressing?

A.MOV A,0x2000
B.MOV A,[0x2000]
C.MOV A,@0x2000
D.MOV A,(0x2000) ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Indirect addressing means the operand’s address is stored in memory, and the instruction must dereference that address to reach the actual data. The syntax “(0x2000)” indicates that the processor should first read the contents of 0x2000 (which is 0x3000) and then fetch the byte at that address. Options A and B access the value directly, while C uses a different indirect notation that is not standard for this context. Therefore D is correct.

Q5. Which statement best describes register addressing?

A.It accesses an operand that resides inside a CPU register
B.It uses a memory address to fetch the operand ✅
C.It can only be used with immediate values
D.It requires an index register to calculate the address
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Register addressing refers to operations where the operand is located in a CPU register, allowing the CPU to work on data without any memory fetch. This reduces access time compared with memory‑based modes. Option B describes direct addressing, option C mixes concepts incorrectly, and option D describes indexed addressing. Consequently, A correctly captures the essence of register addressing.

Q6. Register X holds the base address 0x1000. An instruction uses indexed addressing with an offset of 0x20. What effective address is generated?

A.4128 ✅
B.4096
C.32
D.4640
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Indexed addressing adds an offset to the contents of a base register to form the effective address. Adding 0x20 to the base value 0x1000 yields 0x1020. Options B and C ignore the offset, while D adds the offset twice, producing an incorrect result. Therefore the correct effective address is 0x1020, making A the right choice.

Q7. What is the main advantage of relative addressing for modern software development?

A.It allows larger address spaces
B.It enables faster execution of loops
C.It supports position‑independent code ✅
D.It reduces the total instruction count
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Relative addressing expresses the target address as a displacement from the current program counter, which makes code relocatable without needing absolute addresses. This is essential for position‑independent executables and shared libraries. Options A and B describe unrelated benefits, and D is not a guaranteed outcome. Hence C correctly identifies the primary advantage.

Q8. An array of five 8‑bit integers starts at address 0x4000. Which instruction sequence correctly computes the sum using indexed addressing?

A.LD R0,0x4000; ADD R0,R0; ...
B.LD R0,0x4000; LOOP: ADD R1,R0; INC R0; DEC COUNT; JNZ LOOP
C.LD R0,0x4000; LOOP: ADD ACC,R0; ADD R0,1; DEC N; JNZ LOOP
D.LD R0,0x4000; MOV R1,0; LOOP: ADD R1,[R0]; INC R0; DEC COUNT; JNZ LOOP; MOV ACC,R1 ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Option D uses indexed addressing “[R0]” to fetch each array element, increments the base register to step through the memory, and accumulates the result in R1 before moving it to the accumulator. The other options either omit indexed addressing, misuse registers, or lack a proper loop structure. By correctly applying indexed addressing, the sequence efficiently sums the array, so D is the right answer.

Q9. How does immediate addressing compare with direct addressing regarding memory access?

A.Immediate produces a longer instruction
B.Immediate reduces memory accesses ✅
C.Direct allows larger constant values
D.Direct is always faster than immediate
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Immediate addressing embeds the constant within the instruction itself, so the CPU does not need to perform a separate memory read to obtain the operand. Direct addressing, by contrast, requires the CPU to fetch the operand from a specified memory location, incurring an extra memory cycle. Options A and C misstate the effect on instruction length and constant size, while D incorrectly claims a universal speed advantage. Therefore B accurately describes the memory‑access difference.

Q10. Given a variable stored in a CPU register, a value in cache, a datum in main memory, and another in external RAM, which addressing mode will retrieve the data fastest?

A.Register addressing ✅
B.Direct addressing
C.Indirect addressing
D.Relative addressing
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Data already located in a register can be accessed without any memory lookup, making register addressing the quickest method. Cache, main memory, and external RAM all require progressively longer access times, and the addressing mode used to reach them cannot bypass those delays. Options B, C, and D involve memory references that are slower than a register fetch. Consequently, the fastest access is achieved with register addressing, choice A.

Q11. What role does the control unit play when the CPU selects an addressing mode for an instruction?

A.It performs arithmetic operations
B.It stores program data
C.It generates the system clock
D.It decodes the instruction to determine the addressing mode ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: The control unit interprets each fetched instruction, extracts the opcode, and determines which addressing mode is required for the operand. Based on this decoding, it orchestrates the necessary datapath signals to fetch the operand correctly. Options A and B describe the ALU and registers, while C pertains to timing circuitry, none of which directly handle addressing‑mode selection. Thus D correctly identifies the control unit’s function.

Q12. A program crashes because it uses direct addressing instead of indexed when processing a table of records. Which step should the programmer take to fix the error?

A.Change the instruction to use indexed addressing ✅
B.Increase the size of the memory region
C.Insert a NOP instruction before the problematic line
D.Recompile the program with higher optimization level
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The crash occurs because direct addressing references a fixed address that does not correctly step through the table, whereas indexed addressing adds an offset to a base register for each record. Modifying the instruction to use indexed addressing resolves the logic error. Options B, C, and D do not address the root cause of the addressing mistake. Therefore the appropriate corrective action is A.
