What is B Register of Simple as Possible (SAP) I Computer?

The B register is an \( 8 \)-bit temporary storage register that holds the second operand for arithmetic operations, receiving data directly from the data bus during ADD or SUB instructions and providing one input to the adder/subtractor while remaining unchanged during other operations unless explicitly loaded.

Q1. In a CPU, which component sends control signals to the ALU to start an addition operation?

A.Output Unit
B.Control Unit ✅
C.B-Register
D.Arithmetic Unit
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The Control Unit generates the control signals that tell the ALU which operation to perform, so it initiates addition. The Output Unit only displays results, the B‑Register is a storage element, and the Arithmetic Unit is part of the ALU itself, not a controller. In a real computer, when a program requests an addition, the control unit decodes the instruction and activates the ALU; this coordination is essential for correct computation.

Q2. After the ALU computes a result, which unit is responsible for delivering that result to a monitor or printer?

A.Control Unit
B.B-Register
C.Output Unit ✅
D.Memory
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The Output Unit receives the result from the ALU and converts it into a form that humans can see, such as on a screen or printer. The Control Unit directs the operation but does not present the data, the B‑Register only holds intermediate values, and memory stores data for later use. In everyday use, after a calculation finishes, the output unit is what you look at to verify the answer, making it the final link in the processing chain.

Q3. If a B-Register initially contains the value 5 and the ALU adds 3, what value will the B-Register hold after the operation?

A.2
B.8 ✅
C.5
D.3
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The B‑Register is often used to hold intermediate results. If it starts with the value 5 and the ALU adds 3, the arithmetic operation is \(5+3=8\). After the ALU completes the addition, the result is written back to the B‑Register, so the register now contains 8. Choices 2 and 3 are results of subtraction or the original value, while 5 is the unchanged input. This illustrates how a register updates its contents after an ALU operation in a real processor.

Q4. If a computer's clock pulse is missing, which unit's sequencing would be directly affected?

A.Output Unit
B.B-Register
C.Control Unit ✅
D.ALU
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The sequencing of all operations in a CPU relies on timing signals from the clock, which are interpreted by the Control Unit. If a clock pulse is absent, the Control Unit cannot advance to the next instruction, causing the whole process to stall. The Output Unit merely displays data, the B‑Register stores values, and the ALU performs calculations, none of which generate timing signals themselves. In practice, a missing clock pulse would freeze program execution, highlighting the Control Unit’s central role in timing.

Q5. Why does the control unit need to coordinate with the ALU?

A.To provide power ✅
B.To store data
C.To direct operation sequencing
D.To display results
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The Control Unit must tell the ALU which operation to carry out, such as addition or logical AND, because the ALU cannot decide on its own what to compute. Providing power (Option A) is handled by the power supply, storing data (Option B) is a function of registers or memory, and displaying results (Option D) belongs to the output unit. Directing operation sequencing ensures that the correct instruction is executed at the right time, which is essential for accurate processing in any computer system.

Q6. How does integrating ALU and Control Unit into a single CPU improve performance compared to having them separate?

A.Reduces latency
B.Increases power consumption ✅
C.Decreases instruction set
D.Simplifies user interface
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Combining the ALU and Control Unit into a single CPU chip reduces the distance that control signals and data must travel, which cuts propagation delay and speeds up instruction execution. Increased power consumption (Option B) is a possible side effect but does not explain performance gain. Decreasing the instruction set (Option C) would limit functionality, not improve speed. Simplifying the user interface (Option D) is unrelated to internal processing. Therefore, the primary benefit is lower latency, a key factor in high‑performance computing.

Q7. What is the primary role of the output unit in a computer system?

A.Perform arithmetic ✅
B.Store programs
C.Display results
D.Control timing
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The output unit’s main purpose is to present the results of computation to the user, whether on a monitor, LED panel, or printer. Performing arithmetic (Option A) is the job of the ALU, storing programs (Option B) is handled by memory, and controlling timing (Option D) belongs to the control unit. By converting binary data into a human‑readable form, the output unit completes the information cycle, allowing users to see and act upon the processed data.

Q8. Which component is commonly abbreviated as ALU?

A.Arithmetic Logic Unit
B.Automatic Loading Unit ✅
C.Advanced Linking Utility
D.Array List Utility
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The abbreviation ALU stands for Arithmetic Logic Unit, which is the part of the CPU that performs both arithmetic (add, subtract) and logical (AND, OR) operations. Automatic Loading Unit (Option B) is not a standard computer component, Advanced Linking Utility (Option C) and Array List Utility (Option D) are unrelated software terms. Knowing the correct expansion helps students identify the function of this critical hardware block in any processor architecture.
