Q1. A simple calculator needs to add two 8‑bit numbers and show the sum on an LED display. Which unit first performs the arithmetic operation?

🔹 A. Control Unit
🔹 B. Arithmetic and Logic Unit
🔹 C. Output Unit
🔹 D. Memory Unit

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The Arithmetic and Logic Unit (ALU) is responsible for executing arithmetic functions such as addition, subtraction, multiplication, and division. In the calculator scenario, the ALU receives the two 8‑bit numbers and produces their sum, after which the result is passed to the output hardware. The Control Unit only directs operations, the Output Unit merely displays data, and a Memory Unit would store data but does not compute. Therefore option B correctly identifies the unit that first performs the addition.

Q2. Why is the Control Unit regarded as the most important component in a computer system?

🔹 A. It stores program instructions
🔹 B. It performs arithmetic calculations
🔹 C. It coordinates the activities of all other units by issuing timing and control signals
🔹 D. It provides power to the hardware

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The Control Unit generates timing and control signals that synchronize the actions of the ALU, memory, and I/O devices, ensuring that each step occurs in the correct order. This coordination is essential for any computation, much like a conductor directing musicians in an orchestra. Storing instructions is the role of memory, performing calculations belongs to the ALU, and power distribution is handled by the power supply. Hence, option C accurately describes the primary function of the Control Unit.

Q3. A designer wants to implement a process where a user presses a button, the system adds a stored constant to the input value, and the result is printed. Which sequence correctly represents the activation order of the units?

🔹 A. Output → Control → ALU
🔹 B. Control → ALU → Output
🔹 C. ALU → Control → Output
🔹 D. Control → Output → ALU

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

First, the Control Unit receives the button signal and issues a command to the ALU to add the constant to the user’s input; this ensures the correct operation is performed. After the ALU computes the sum, the Control Unit directs the Output Unit (printer) to display the result. The other sequences place the Output or ALU before the Control Unit, which would either try to display data before it is computed or perform an operation without proper timing coordination. Thus, option B reflects the proper flow of control, computation, and output.
