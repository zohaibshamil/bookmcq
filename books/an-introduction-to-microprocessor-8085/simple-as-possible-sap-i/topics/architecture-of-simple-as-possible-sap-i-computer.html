Q1. What does the acronym ALU stand for in computer architecture?

🔹 A. Arithmetic Logic Unit
🔹 B. Artificial Language Utility
🔹 C. Advanced Linking Unit
🔹 D. Array Load Utility

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The correct answer is Arithmetic Logic Unit because ALU is the component that performs arithmetic and logical operations on binary data. The other choices are unrelated terms that do not describe this hardware function. Understanding the meaning of ALU helps students recognize its role in processing calculations, which is essential for any computer system.

Q2. Which component of the CPU is responsible for generating the timing signals that synchronize operations?

🔹 A. Arithmetic Unit
🔹 B. Control Unit
🔹 C. Output Unit
🔹 D. Memory Unit

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The Control Unit generates clock pulses that coordinate the timing of each step in the instruction cycle. Without these signals, the CPU could not orchestrate data movement or operation sequencing. The other options either perform calculations (Arithmetic Unit), present results (Output Unit), or store data (Memory Unit), none of which produce the timing signals required for synchronization.

🔹 A. Monitor, Speaker, Keyboard
🔹 B. CRT, LED, Printer
🔹 C. Touchscreen, Mouse, Plotter
🔹 D. LCD, Scanner, Modem

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The correct answer lists CRT, LED, and Printer because those are the specific devices cited as examples of output hardware. The other groups contain devices that are either input, storage, or unrelated to the described output unit. Recognizing the typical output devices clarifies how processed data leaves the computer and becomes visible or printable to users.

Q4. Why does the control unit need to sequence instructions rather than executing them all at once?

🔹 A. To reduce power consumption
🔹 B. Because instructions depend on previous results
🔹 C. To increase memory size
🔹 D. To enable parallel processing

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The control unit sequences instructions because many operations rely on the results of earlier steps, creating data dependencies. This ensures correct program behavior. Options A, C, and D describe unrelated benefits; power consumption, memory capacity, and parallelism are not the primary reasons for sequencing. Understanding this dependency explains why a CPU follows a defined order.

Q5. How does the ALU interact with the control unit during an addition operation?

🔹 A. Control unit supplies operands and signals the ALU to add
🔹 B. ALU decides which operation to perform
🔹 C. Control unit stores the result directly
🔹 D. ALU provides clock pulses

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The control unit provides the two numbers (operands) and tells the ALU to perform addition, after which the ALU returns the sum. The ALU does not choose the operation itself, nor does it store results or generate clock signals. This interaction illustrates the division of labor between control logic and computation, a core concept in CPU design.

Q6. What is the main advantage of integrating the ALU and control unit into a single CPU component?

🔹 A. It simplifies hardware design
🔹 B. Allows unlimited parallelism
🔹 C. Eliminates need for memory
🔹 D. Improves network latency

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

The advantage is that integration simplifies hardware design because a single chip can house both computation and control logic, reducing interconnect complexity and fabrication cost. Options B, C, and D describe benefits that are not directly tied to merging these two units. Recognizing design simplification helps explain why many processors combine ALU and control functions.

Q7. In what way does the control unit influence data flow between the ALU and memory?

🔹 A. By physically moving data cables
🔹 B. By issuing control signals that enable read/write operations
🔹 C. By encrypting data
🔹 D. By changing voltage levels

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The control unit sends read or write signals that tell memory when to accept data from the ALU or provide data to it. It does not physically relocate cables, encrypt data, or alter voltages for this purpose. This explanation highlights the control unit’s role as the traffic director that orchestrates the movement of information within the computer.

This conversion step is essential for users to understand the computer’s computed results.

Q9. Why is a clock pulse essential for the control unit’s operation?

🔹 A. It powers the CPU
🔹 B. It synchronizes the timing of each instruction step
🔹 C. It stores data
🔹 D. It reduces heat

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Clock pulses provide a regular timing reference that the control unit uses to step through each stage of an instruction, ensuring orderly execution. Power provision, data storage, and heat reduction are separate concerns not directly handled by clock signals. Understanding the clock’s role clarifies how coordinated timing enables reliable processing across all CPU components.

Q10. Explain how the control unit determines the next instruction address after a conditional branch.

🔹 A. By adding a fixed offset
🔹 B. By evaluating the condition flag and selecting either sequential address or target address
🔹 C. By resetting the program counter
🔹 D. By consulting the ALU

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When a condition flag is set, the control unit evaluates it and decides whether to continue with the next sequential address or jump to a specified target address. This decision-making process depends on the flag’s state, not on fixed offsets, resets, or direct ALU queries. Grasping this mechanism explains how programs can change flow based on computed results.

Q11. What would happen to program execution if the control unit failed to send a ‘store’ signal after an ALU addition?

🔹 A. The result would be lost, and subsequent instructions would use outdated data
🔹 B. The CPU would overheat
🔹 C. The output unit would display an error
🔹 D. Memory would double its capacity

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

If the store signal is omitted, the computed result remains only in the ALU’s internal registers and is not written back to memory, causing later instructions that rely on that value to use stale data. Overheating, output errors, or memory expansion are unrelated effects. This scenario emphasizes the importance of the control unit’s coordination for correct data persistence.

Q12. How does the separation of control logic from data path (ALU) affect the scalability of a processor design?

🔹 A. It makes adding more ALU units easier without redesigning control signals
🔹 B. It reduces instruction set size
🔹 C. It eliminates need for registers
🔹 D. It forces serial execution

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Separating control logic allows designers to add additional ALU units without having to redesign the entire control circuitry, facilitating scalability. The other options either misstate the impact on instruction set size, remove essential registers, or incorrectly claim forced serial execution. Recognizing this modularity explains why modern CPUs can grow performance by replicating data‑path units.

Q13. If an instruction requires both addition and logical AND, how does the control unit orchestrate the use of the ALU?

🔹 A. It performs both operations simultaneously in a single cycle
🔹 B. It schedules two separate ALU cycles, directing the appropriate operation each time
🔹 C. It delegates one operation to the output unit
🔹 D. It ignores one operation

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The control unit cannot execute two distinct ALU operations in one cycle; instead, it issues two sequential control signals, each telling the ALU which operation to perform. This ensures both results are computed correctly. Simultaneous execution, delegating work to the output unit, or ignoring an operation would produce incorrect program behavior.

🔹 A. To increase instruction throughput for specific operations

🔹 D. To avoid using a control unit

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

Using several specialized ALUs can boost throughput because each unit can handle a particular operation (e.g., multiplication) more efficiently than a single universal ALU. The other options do not directly relate to the performance benefits of specialization. This reasoning helps students understand design trade‑offs that favor parallelism for speed-critical tasks.

🔹 A. Control Unit
🔹 B. Output Unit
🔹 C. ALU
🔹 D. Memory

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The ALU must receive the two operands because it is the part of the CPU that actually performs addition. The control unit orchestrates the operation but does not compute; the output unit displays results, and memory stores data after computation. Recognizing the flow from operands to ALU clarifies the basic data path in simple arithmetic programs.

Q16. During program execution, the CPU must wait for an I/O device. Which unit typically issues the wait signal?

🔹 A. ALU
🔹 B. Control Unit
🔹 C. Output Unit
🔹 D. Arithmetic Unit

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The control unit monitors the status of I/O devices and issues a wait or stall signal when the device is not ready, pausing further instruction fetching. The ALU performs calculations and does not manage device readiness, while the output unit simply renders data. Understanding the control unit’s supervisory role explains how CPUs handle asynchronous peripheral operations.

Q17. When the ALU finishes a multiplication, which unit is responsible for displaying the result on a screen?

🔹 A. Control Unit
🔹 B. Memory Unit
🔹 C. Output Unit
🔹 D. Input Unit

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The output unit takes the computed value from the ALU (via the control unit) and translates it into visual signals for the monitor. Neither the control unit nor memory directly render data, and the input unit handles user input, not output. This answer highlights the final step in the processing pipeline where results become visible to the user.

Q18. A program includes an IF statement that jumps to label L1 when register R1 equals zero. Which unit evaluates the condition and decides the next address?

🔹 A. ALU
🔹 B. Control Unit
🔹 C. Output Unit
🔹 D. Memory

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The ALU performs the comparison of R1 with zero and sets a condition flag; the control unit then reads this flag to decide whether to branch to L1. While the control unit ultimately chooses the address, the actual evaluation occurs in the ALU, making it the correct answer. This distinction clarifies the collaborative nature of condition testing and flow control.

Q19. If the clock pulse frequency is doubled, what immediate effect does this have on the control unit’s instruction cycle time?

🔹 A. Instruction cycle time halves
🔹 B. Instruction cycle time doubles
🔹 C. No change
🔹 D. CPU shuts down

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Doubling the clock frequency reduces the period of each pulse, so the instruction cycle time becomes half as long, allowing more cycles per second. The other options either describe the opposite effect, no impact, or an extreme failure, none of which match the direct relationship between clock speed and cycle duration.

Q20. A high‑performance server uses two parallel ALUs to compute vector addition. How must the control unit coordinate these ALUs?

🔹 A. Issue identical operation signals and separate operand sets to each ALU
🔹 B. Synchronize both ALUs with a single control signal while providing distinct operands
🔹 C. Merge results before operation
🔹 D. Let ALUs decide themselves

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The control unit must send a common operation command (e.g., vector add) while supplying each ALU with its own portion of the data, ensuring both perform the same type of work in lockstep. Simply issuing identical signals without distinct operands would cause data collisions, and having ALUs decide independently would break coordinated execution. This coordination is vital for parallel processing.

🔹 A. Binary‑to‑BCD conversion
🔹 B. Encryption
🔹 C. Compression
🔹 D. Parity check

📖 Explanation:

Binary‑to‑BCD conversion translates the binary result into a decimal-coded format that printers and displays can render as human‑readable digits. Encryption, compression, and parity checking are unrelated to the visual representation of numeric data. This step shows how internal binary results become printable characters.

Q22. If the control unit sends an incorrect opcode to the ALU, what is the most likely result?

🔹 A. The ALU performs an unintended operation
🔹 B. The CPU will increase speed
🔹 C. The output unit will correct it
🔹 D. Memory will reset

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

An incorrect opcode causes the ALU to execute the wrong operation, leading to erroneous results. The CPU does not automatically speed up, the output unit cannot fix opcode errors, and memory reset is unrelated. Recognizing this cause‑effect relationship helps students anticipate faults in instruction decoding.

Q23. A loop executes 100 times, each iteration performing an addition. Which unit ensures that the next addition starts only after the previous one finishes?

🔹 A. Control Unit
🔹 B. ALU
🔹 C. Output Unit
🔹 D. Input Unit

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The control unit schedules each iteration, waiting for the ALU to complete the addition before issuing the next instruction. The ALU itself only performs the calculation; it does not enforce sequencing. Output and input units handle different tasks. This explanation underscores the control unit’s role in maintaining correct order in repetitive computations.

Q24. When a program stores a computed value back to memory, which sequence of units is correctly ordered?

🔹 A. ALU → Control Unit → Memory
🔹 B. Control Unit → ALU → Memory
🔹 C. ALU → Memory → Control Unit
🔹 D. Control Unit → Memory → ALU

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

First the ALU produces the result, then the control unit issues a store command, and finally memory writes the value. The other sequences either place the control unit before the computation or misorder the memory write, which would break the correct data‑flow process.
