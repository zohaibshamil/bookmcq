What is Adder Subtractor of Simple as Possible (SAP) I Computer?

The adder/subtractor is an \( 8 \)-bit combinational circuit composed of full adders and XOR gates that performs addition when the SUB control signal is low and subtraction when it is high by converting the B register input to two’s complement, producing a result that can be loaded into the accumulator under controller direction.

Q1. A 4‑bit adder‑subtractor receives A = 1011₂ (11) and B = 0101₂ (5) with the control set for subtraction. Which output correctly shows the 4‑bit difference and the overflow condition?

A. Result 0110, Overflow
B. Result 0110, No overflow ✅
C. Result 1110, Overflow
D. Result 1110, No overflow

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The subtraction 1011₂ – 0101₂ equals 0110₂ (6). In two’s‑complement 4‑bit arithmetic this result fits without exceeding the sign range, so overflow does not occur. Choice B matches both the correct binary result and the correct overflow flag. Choice A shows the right result but incorrectly claims overflow. Choices C and D give the wrong binary value (1110₂) and therefore are both incorrect. This mirrors how a processor would flag an error only when the sign bit is corrupted.

Q2. Why does integrating an adder‑subtractor into a CPU typically reduce overall hardware compared to having separate adder and subtractor blocks?

A. It reduces power consumption
B. It increases latency
C. It allows larger operand size
D. It reduces gate count ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

A single adder‑subtractor uses one set of adders and a control line that conditionally inverts the second operand, eliminating the need for duplicate circuitry. This saves gates, which directly cuts silicon area and cost. Option D states this reduction of gates, making it correct. The other options describe effects that are not generally true: power may even drop, latency does not necessarily increase, and operand size is unchanged.

Q3. What is the definition of an adder‑subtractor circuit?

A. A circuit that can add or subtract two binary numbers based on a control signal ✅
B. A circuit that only adds binary numbers
C. A circuit that only subtracts binary numbers
D. A memory register that stores intermediate results

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

An adder‑subtractor is designed to perform either addition or subtraction on two binary operands, the operation being selected by a single control input. This matches option A. Options B and C describe only half of the functionality, and option D is unrelated to arithmetic operations, so they are incorrect.

Q4. An 8‑bit adder‑subtractor in two’s‑complement mode subtracts Y = 0001 1110₂ (30) from X = 0010 0101₂ (37). What 8‑bit result is produced?

A. Result 0000 1111
B. Result 1111 1001
C. Result 0000 0111 ✅
D. Result 0010 1111

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Subtracting 30 from 37 yields 7, which in 8‑bit two’s‑complement is 0000 0111₂. Option C presents exactly this binary result. Option A (1111) corresponds to 15, Option B is the two’s‑complement of –7, and Option D (0010 1111) equals 47, none of which match the correct arithmetic. In a real processor, the circuit would output 0000 0111₂, confirming option C.

Q5. How does the control signal determine whether the circuit performs addition or subtraction?

A. It adds an extra carry‑in when subtracting
B. It XORs each bit of the B operand with the control signal ✅
C. It changes the clock frequency
D. It swaps the A and B inputs

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When the control line is high for subtraction, each bit of operand B is XORed with 1, effectively complementing B; the circuit then adds a carry‑in of 1, producing A + (¬B) + 1, which is A − B. This mechanism is described in option B. Adding a carry‑in alone (option A) is incomplete without bitwise inversion, changing the clock (C) does not affect arithmetic, and swapping inputs (D) merely changes operand order, not the operation type.

Q6. A 16‑bit adder‑subtractor computes A − B where A = 0x7FFF and B = 0x0001. What is the 16‑bit result and does signed overflow occur?

A. Result 0x7FFE, No overflow ✅
B. Result 0x8000, Overflow
C. Result 0x7FFE, Overflow
D. Result 0x8000, No overflow

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

0x7FFF (32767) minus 0x0001 (1) equals 0x7FFE (32766), which still has a leading 0 sign bit, so no signed overflow occurs. Option A captures both the correct hexadecimal result and the correct overflow status. Options B and C incorrectly claim overflow, and option D gives an incorrect result (0x8000) that would indicate overflow, making them wrong. This reflects how a CPU would set or clear the overflow flag after a subtraction.

Q7. Why does two’s‑complement representation let the same adder hardware perform subtraction without extra circuitry?

A. Because subtraction can be expressed as addition of the complement plus one ✅
B. Because two’s‑complement uses sign‑magnitude encoding
C. Because it eliminates the need for a carry bit
D. Because it relies on floating‑point arithmetic

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

In two’s‑complement, subtracting B is equivalent to adding the bitwise complement of B and then adding 1, which an adder can handle directly when a control line forces the complement and sets the initial carry‑in. Option A describes this exact principle. Options B, C, and D describe unrelated concepts: sign‑magnitude does not allow the same simple addition, carries are still needed, and floating‑point is a different representation.

Q8. A 5‑bit adder‑subtractor computes the difference between operands 01101₂ (13) and 10101₂ (21). What is the 5‑bit result and the borrow flag?

A. Result 00110, Borrow 0
B. Result 00110, Borrow 1
C. Result 11000, Borrow 0
D. Result 11000, Borrow 1 ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Subtracting a larger number from a smaller one yields a negative result; in 5‑bit two’s‑complement this is 11000₂ (‑8) and a borrow (or carry‑out) of 1 is generated. Option D correctly lists both the binary result and the borrow flag. Option A gives the magnitude of 6 with no borrow, which is the opposite situation. Option B pairs the correct magnitude with an incorrect borrow, and option C shows the correct negative magnitude but omits the required borrow flag, so they are all wrong. This mirrors how hardware signals a borrow when the minuend is smaller.
