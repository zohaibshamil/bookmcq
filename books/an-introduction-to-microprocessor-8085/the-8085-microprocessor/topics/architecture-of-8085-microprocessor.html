Q1. A program needs to store the 16‑bit address 0x3A7F using register pairs. Which pair should be used so that the high‑order byte is in the first register?

🔹 A. B‑C pair
🔹 B. D‑E pair
🔹 C. H‑L pair
🔹 D. A‑B pair

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

In the 8085, the registers H and L are paired to form a 16‑bit register HL. The high‑order byte of a 16‑bit value is stored in H, while the low‑order byte resides in L. Therefore, to hold the address 0x3A7F, the HL pair must be used, placing 0x3A in H and 0x7F in L. The other pairs (BC, DE, AB) are not intended for address storage, so they would give incorrect ordering.

Q2. When does the Sign flag (S) become set after an arithmetic operation on the accumulator?

🔹 A. When the result is zero
🔹 B. When the most significant bit of the accumulator is 1
🔹 C. When there is a carry out
🔹 D. When the parity of the result is odd

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The Sign flag reflects the most significant bit (MSB) of the accumulator after an operation. In two’s‑complement representation, an MSB of 1 indicates a negative value, so the flag is set (S = 1). It is unrelated to zero results, carry out, or parity; those conditions affect the Zero, Carry, and Parity flags respectively. Understanding this behavior helps programmers test for negative outcomes without extra comparisons.

Q3. Adding 0xA5 and 0x3C in the accumulator using the ADD instruction, what will be the state of the Carry flag?

🔹 A. Set
🔹 B. Reset
🔹 C. Toggle
🔹 D. Indeterminate

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Adding \(0xA5\) (\(165_{10}\)) and \(0x3C\) (\(60_{10}\)) gives \(0xE1\) (\(225_{10}\)). The binary addition does not produce a carry beyond the eighth bit because the sum is less than \(256\). Consequently, the Carry flag, which signals an overflow from the most significant bit, is cleared (reset). Options that claim the flag is set or toggles are therefore incorrect, and “Indeterminate” does not apply to a defined operation.

Q4. Which statement correctly distinguishes the roles of the Program Counter (PC) and the Stack Pointer (SP) in the 8085 microprocessor?

🔹 A. PC holds address of next instruction while SP holds address of current instruction
🔹 B. PC points to top of stack and SP points to next instruction
🔹 C. PC contains address of next instruction to fetch; SP points to the most recent location pushed onto the stack
🔹 D. PC and SP are interchangeable registers used for any memory addressing

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The Program Counter (PC) always contains the address of the next instruction to be fetched from memory, so it increments automatically after each fetch. The Stack Pointer (SP), on the other hand, points to the top of the stack; it is decremented on a PUSH and incremented on a POP, allowing temporary storage of return addresses or registers. Option C captures this distinction accurately. The other options either confuse the two registers or suggest they are interchangeable, which is not true in the 8085 architecture.

Q5. Identify the four flags present in the 8085 flag register.

🔹 A. Sign, Zero, Carry, Parity
🔹 B. Overflow, Auxiliary Carry, Sign, Zero
🔹 C. Negative, Positive, Carry, Borrow
🔹 D. Interrupt Enable, Direction, Sign, Parity

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The 8085 flag register consists of four single‑bit flags that give status information after arithmetic or logical operations. They are the Sign flag (S), indicating a negative result; the Zero flag (Z), indicating a result of zero; the Carry flag (CY), indicating an overflow out of the most significant bit; and the Parity flag (P), indicating whether the number of 1‑bits in the result is even. The listed set matches the hardware design, while the other options introduce flags that belong to different processors.
