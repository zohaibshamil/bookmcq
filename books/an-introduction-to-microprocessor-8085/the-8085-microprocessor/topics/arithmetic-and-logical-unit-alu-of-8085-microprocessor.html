What is Arithmetic and Logical Unit (ALU) of 8085 Microprocessor?

Definition:
The ALU is the 8-bit combinational circuit inside the 8085 that performs arithmetic operations such as addition, subtraction, increment, and decrement, as well as logical operations including AND, OR, XOR, complement, and compare. It takes one operand from the accumulator and the other from a temporary register or an internal register, produces an 8-bit result, and updates the flag register according to the result.

Working:
When an arithmetic or logic instruction is decoded, the control unit supplies the appropriate operation-select signals to the ALU. The ALU then combines the two 8-bit inputs, and the result is written back to the accumulator. The flag register is updated simultaneously: the Carry flag is set if there is a carry out of bit 7, the Zero flag is set if the result is 00H00_H00H​, the Sign flag reflects bit 7 of the result, the Parity flag indicates whether the number of 1s in the result is even or odd, and the Auxiliary Carry flag reflects a carry out of bit 3.

Example:
If A=3AHA = 3A_HA=3AH​ and B=27HB = 27_HB=27H​, the instruction ADDBADD BADDB produces 61H61_H61H​ in the accumulator. The Carry flag is reset, the Zero flag is reset, the Sign flag is reset because bit 7 is 0, and the Parity flag is set because 61H=01100001261_H = 01100001_261H​=011000012​ contains three 1s—wait, three 1s is odd, so Parity would be reset. This highlights the need to count carefully.

Reason:
Separating the ALU from the registers allows the same arithmetic and logic hardware to serve all instructions, reducing chip area and power while keeping the instruction set powerful enough for general-purpose computing.

Common Misconceptions:
Many students believe the ALU can directly access memory; it cannot—it only operates on data already placed in the accumulator or internal registers. Another misconception is that the Sign flag is the same as the Carry flag; the Sign flag simply copies bit 7 of the result, whereas the Carry flag indicates a carry or borrow out of the most significant bit.

Exam Preparation Tips: How to prepare this topic:
Practice computing the result and all five flags for a variety of ADDADDADD, SUBSUBSUB, ANAANAANA, ORAORAORA, and XRAXRAXRA operations. Write down the binary form of each result to count the 1s for the Parity flag and to check bit 7 for the Sign flag. Solve problems that ask you to predict the accumulator and flag contents after a short sequence of ALU instructions.

Key Terms:

  • ALU – the unit that performs arithmetic and logical operations on 8-bit data.
  • Flag Register – the register that stores the condition flags Z,CY,S,P,ACZ, CY, S, P, ACZ,CY,S,P,AC.
  • Accumulator – the register that supplies one ALU operand and receives the result.

📝 All Arithmetic and Logical Unit (ALU) of 8085 Microprocessor MCQs

Q1. What is the bit‑width of the accumulator in the SAP‑III microprocessor?

A.8‑bit ✅
B.16‑bit
C.4‑bit
D.32‑bit
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The accumulator stores the result of all arithmetic and logical operations, and in the SAP‑III design it is an 8‑bit register. This means it can represent unsigned values from 0 to 255 or signed two’s‑complement values from –128 to +127. The other options describe widths that belong to different processors or are unrealistic for this microcontroller, so the correct answer is 8‑bit.

Q2. Which flag in the SAP‑III flag register is set when the accumulator holds a negative (two’s‑complement) value?

A.Sign flag (S) ✅
B.Zero flag (Z)
C.Carry flag (CY)
D.Parity flag (P)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The Sign flag reflects the most‑significant bit of the accumulator, which is 1 for negative two’s‑complement numbers. When the result is negative the flag is set (S = 1). The Zero flag signals a zero result, the Carry flag deals with overflow or borrow, and the Parity flag indicates even or odd number of 1s, none of which directly indicate negativity.

Q3. Under what condition is the Zero (Z) flag set after an ALU operation?

A.Result equals zero ✅
B.Result is negative
C.A carry out occurs
D.Result has odd parity
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The Zero flag is asserted when the ALU output is exactly 0, meaning every bit of the result is cleared. This is independent of the sign, carry, or parity of the operation. A negative result would affect the Sign flag, a carry out would affect the Carry flag, and odd parity would affect the Parity flag, so only the first choice correctly describes the Zero flag behavior.

Q4. How does the Carry (CY) flag indicate overflow when adding two signed 8‑bit numbers?

A.Set when a carry out of the MSB occurs
B.Set when the sign bits of the operands are the same and differ from the sign of the result ✅
C.Reset when any overflow occurs
D.Set only for unsigned addition
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: For signed addition, overflow happens when two numbers with the same sign produce a result with a different sign. The hardware detects this by comparing the carry into and out of the most‑significant bit; if they differ, the Carry flag is set to indicate signed overflow. A simple carry out does not always mean overflow for signed numbers, and the flag is not limited to unsigned operations, making option B the accurate description.

Q5. A program loads 0x12 into register H and 0x34 into register L, then loads 0x00 into D and 0xFF into E. It executes a 16‑bit addition of the H‑L pair with the D‑E pair. Which register will contain the high‑order byte of the sum after execution?

A.H ✅
B.L
C.D
D.E
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The H‑L pair represents the 16‑bit value 0x1234 and the D‑E pair represents 0x00FF. Adding them yields 0x1333. In a 16‑bit addition the most‑significant byte of the result is stored back into the high register of the first operand, which is H. Therefore H receives 0x13, while L receives 0x33. The other registers hold the low byte or unchanged values, so only option A is correct.

Q6. If the ALU subtracts 0x05 from 0x03 using two’s‑complement subtraction, which flag(s) will be affected and how?

A.Zero flag set, Carry cleared
B.Carry flag set, Sign flag cleared
C.Carry flag cleared, Sign flag set ✅
D.Parity flag set, Zero cleared
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Subtracting 0x05 from 0x03 yields a negative result (0xFE) in two’s‑complement form, so the Sign flag becomes 1. Because a borrow is required, the Carry flag is cleared (0). No zero result occurs, so the Zero flag stays reset, and the parity of 0xFE (seven 1s) is odd, leaving the Parity flag cleared. Thus the combination described in option C matches the actual flag changes.

Q7. When the ALU adds 0x7F and 0x01, what are the states of the S, Z, CY, and P flags after the operation?

A.S=1, Z=0, CY=0, P=0 ✅
B.S=0, Z=0, CY=1, P=1
C.S=1, Z=1, CY=1, P=0
D.S=0, Z=1, CY=0, P=1
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Adding 0x7F (01111111) and 0x01 (00000001) produces 0x80 (10000000). The most‑significant bit is 1, so the Sign flag is set (S=1). The result is not zero, so Z=0. No carry out of the MSB occurs, leaving CY=0. The result contains a single ‘1’, an odd number, so the Parity flag is reset (P=0). Only option A reflects this exact combination.

Q8. A logic operation XOR is performed on bytes 0xAA and 0x33. After the operation, what is the state of the Parity (P) flag?

A.Set (even number of 1s) ✅
B.Reset (odd number of 1s)
C.Set only if result is zero
D.Reset only if carry occurs
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: XORing 0xAA (10101010) with 0x33 (00110011) yields 0x99 (10011001). Counting the ones in 0x99 gives four, which is an even number. The Parity flag in the SAP‑III is set when the result contains an even number of 1s, regardless of the result’s value. Therefore the flag is set, matching option A; the other choices describe unrelated conditions.
