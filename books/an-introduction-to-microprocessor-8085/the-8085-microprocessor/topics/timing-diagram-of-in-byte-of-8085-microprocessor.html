Q1. What is the size of the accumulator in the SAP‑III CPU?

🔹 A. 8‑bit
🔹 B. 16‑bit
🔹 C. 4‑bit
🔹 D. 32‑bit

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The accumulator in the SAP‑III is an 8‑bit register, meaning it can hold values from 0 to 255 unsigned or –128 to +127 signed. Option A states this size, so it is correct. Options B, C, and D describe sizes that do not match the hardware specification and would lead to incorrect assumptions about the range of values the CPU can process. Understanding the accumulator width is essential for writing correct assembly code and for interpreting timing diagrams.

Q2. Which flag is set when the accumulator holds a negative two’s‑complement value?

🔹 A. Zero flag
🔹 B. Sign flag
🔹 C. Carry flag
🔹 D. Parity flag

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

In two’s‑complement representation, a negative value has the most‑significant bit equal to 1, causing the Sign flag (S) to be set. Therefore option B is correct. The Zero flag indicates a value of zero, not negativity, so A is wrong. The Carry flag is related to arithmetic overflow, not sign, making C incorrect. The Parity flag reflects the evenness of the number of 1 bits, unrelated to sign, so D is also wrong. Recognizing the Sign flag helps interpret status changes during IN operations.

Q3. How does pairing the H and L registers allow the CPU to handle 16‑bit data?

🔹 A. They are concatenated to form a 16‑bit register
🔹 B. They share the same bus line
🔹 C. They automatically increment together
🔹 D. They act as separate 8‑bit registers only

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When H and L are used as a pair, the high‑order byte (H) and low‑order byte (L) are treated as a single 16‑bit register, enabling the CPU to move or compute on 16‑bit values directly. Option A describes this concatenation correctly. Option B is inaccurate because the registers do not share a single bus line; each has its own 8‑bit path. Option C suggests automatic increment, which is not a built‑in feature. Option D ignores the paired functionality, so only A captures the true mechanism.

Q4. In the timing diagram for the IN instruction, after the address of the I/O port is placed on the address bus, which state occurs next?

🔹 A. Data hold state
🔹 B. Data read state
🔹 C. Acknowledge state
🔹 D. Idle state

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Once the address of the I/O port is presented, the CPU asserts the read control line and the peripheral places the requested byte on the data bus. This period is called the Data read state, making option B correct. The Data hold state would follow a read operation, not precede it. The Acknowledge state is used for interrupt handling, not for normal IN reads. The Idle state occurs when no bus activity is occurring, so D is incorrect. Knowing this order is vital for interpreting the timing diagram of an IN byte.

Q5. If the accumulator contains \(0xFF\) and the program executes an IN instruction that reads \(0x00\) from the port, which flags will be set after the operation?

🔹 A. Zero and Carry flags
🔹 B. Zero flag only
🔹 C. Carry flag only
🔹 D. No flags are set

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Reading \(0x00\) replaces the previous \(0xFF\) value, causing the Zero flag to be set because the accumulator becomes zero. At the same time, the transition from \(0xFF\) to \(0x00\) generates a carry out of the most‑significant bit, setting the Carry flag. Therefore option A is correct. Option B omits the Carry flag, and option C omits the Zero flag; both miss part of the result. Option D claims no flags change, which contradicts the defined behavior of the flags after a load operation.

Q6. A programmer wants to store the 16‑bit address \(0x1234\) in the D‑E register pair before a jump. Which sequence of operations correctly loads the address?

🔹 A. Load D with \(0x12\) then E with \(0x34\)
🔹 B. Load E with \(0x12\) then D with \(0x34\)
🔹 C. Load H with \(0x12\) then L with \(0x34\)
🔹 D. Load B with \(0x12\) then C with \(0x34\)

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The D‑E pair forms a 16‑bit register where D holds the high‑order byte and E holds the low‑order byte. To store \(0x1234\), the high byte \(0x12\) must be loaded into D first, followed by the low byte \(0x34\) into E, making option A correct. Option B reverses the order, producing the wrong endianness. Options C and D involve different register pairs (H‑L and B‑C), which would not affect the D‑E pair, so they are incorrect. Correct loading ensures the subsequent jump uses the intended address.

Q7. Why is the Carry flag used to detect overflow when adding two signed two’s‑complement numbers in the SAP‑III?

🔹 A. It indicates a borrow in subtraction
🔹 B. It shows that the most significant bit changed
🔹 C. It reveals an extra bit beyond the 8‑bit limit
🔹 D. It toggles whenever any arithmetic is performed

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

When two signed two’s‑complement numbers are added, an overflow occurs if the sum requires a ninth bit beyond the 8‑bit capacity. The Carry flag captures this extra bit, so option C correctly explains its role. Option A describes a borrow, which is relevant to subtraction, not addition overflow. Option B refers to the sign bit change, which alone does not guarantee overflow. Option D suggests the flag changes for any arithmetic, which is inaccurate because it only reflects a carry out of the most‑significant bit. Recognizing this behavior is crucial for interpreting flag results after an IN‑byte operation that may involve arithmetic.

Q8. During an IN operation that reads three consecutive bytes from ports 0x20, 0x21, and 0x22, which part of the timing diagram repeats for each byte after the first?

🔹 A. Address setup phase
🔹 B. Data read phase
🔹 C. Bus release phase
🔹 D. Interrupt acknowledge phase

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

For each subsequent byte, the CPU must again assert the read control line and wait for the peripheral to place the next byte on the data bus. This repeated interval is the Data read phase, making option B correct. The Address setup phase occurs only when the new port address is presented, which is not repeated for each byte after the first. Bus release follows the read, not before it, and the Interrupt acknowledge phase is unrelated to normal IN reads. Understanding the repeating phases helps students map real‑world I/O sequences onto timing diagrams.
