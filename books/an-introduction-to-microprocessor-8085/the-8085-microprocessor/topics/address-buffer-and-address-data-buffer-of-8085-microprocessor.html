📝 Address Buffer and Address Data Buffer of 8085 Microprocessor (8 MCQs)

Separate Functions of Address and Address-Data Buffers

The 8085 uses address buffers and multiplexed address-data buffers to connect its internal address and data paths with external memory and input/output devices. The higher-order address lines A8–A15 are provided through address buffers, while AD0–AD7 share the lower-address and data functions. This arrangement allows a 40-pin processor to communicate using sixteen address bits and eight data bits.

Higher-Order Address Buffer and Lower-Order Multiplexing

The address buffer connected to A8–A15 carries the higher-order address byte during bus operations. The bidirectional AD0–AD7 buffer carries the lower-order address during the first clock state and transfers data during subsequent states. The external data direction depends on whether the processor is performing a read or write operation.

ALE and External Latch Operation

During T1, the lower-order address appears on AD0–AD7 and ALE becomes high. An external latch, commonly a 74LS373 or equivalent, captures these eight address bits. When ALE returns low, the latched address remains available while AD0–AD7 are reused for data transfer. This separates the address from the multiplexed bus.

Example of Address Latching During Memory Access

For a memory operation at 2050H, the higher byte 20H appears on A8–A15 and the lower byte 50H appears on AD0–AD7 during T1. ALE enables the external latch to retain 50H. The processor then reuses AD0–AD7 for the data byte during the read or write portion.

Role in Memory Interfacing and Bus Design

Address buffers provide stable address information for selecting external memory locations, while multiplexed buffers reduce the number of processor pins required. The latch preserves the lower address throughout the remainder of the machine cycle. These connections work with RD, WR and IO/M to complete memory and input/output transfers.

Misconceptions About Multiplexed Address and Data Lines

'AD0–AD7 carry only data' overlooks their lower-address function during T1. 'ALE transfers the memory data byte' is incorrect because it enables address latching. 'A8–A15 are bidirectional data lines' confuses the higher-order address buffer with the multiplexed, bidirectional AD0–AD7 connections.

Buffer Connections and ALE Timing Questions

Identify the functions and directions of A8–A15 and AD0–AD7. Interpret the T1 address phase and subsequent data-transfer phase, and explain how ALE controls an external latch. Questions may involve reconstructing a sixteen-bit address, identifying the purpose of a 74LS373 or tracing read and write operations.

Address Buffer and Multiplexed Bus Terminology

  • Address Buffer - Carries higher-order address bits.
  • AD0–AD7 - Multiplexed address and data lines.
  • A8–A15 - Higher-order address lines.
  • ALE - Enables external address latching.
  • Latch - Retains the lower address byte.
  • 74LS373 - Common eight-bit address latch.

📝 All Address Buffer and Address Data Buffer of 8085 Microprocessor MCQs

Q1. A program needs to store the address of the next instruction in the address buffer while also storing the opcode in the data buffer. Which pair of registers is best suited for holding the 16‑bit address?

A.H‑L pair ✅
B.B‑C pair
C.D‑E pair
D.Accumulator and Flags
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The H‑L pair forms a 16‑bit register, exactly matching the width of the address buffer. Storing the address there lets the CPU fetch the next instruction address while the accumulator can hold the opcode for the data buffer. The B‑C and D‑E pairs are also 16‑bit but are typically used for general data, not for program‑counter purposes. The accumulator and flag register are only 8‑bits wide, so they cannot hold a full address.

Q2. What is the width of the address buffer used for storing memory addresses in the SAP‑III computer?

A.8 bits
B.16 bits ✅
C.24 bits
D.32 bits
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The address buffer must be able to address any location in the 64 KB memory space of the SAP‑III, which requires 16 bits (2^16 = 65,536). An 8‑bit buffer could only address 256 locations, far too few for the system. Wider buffers such as 24 or 32 bits are unnecessary because the architecture does not support more than 64 KB of addressable memory.

Q3. Why does the SAP‑III architecture provide separate address and data buffers instead of a single combined register?

A.It allows simultaneous fetch of address and operand, improving execution speed. ✅
B.It reduces overall power consumption of the CPU.
C.It simplifies handling of the four flag bits.
D.It increases the number of general‑purpose registers available to the programmer.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Having distinct buffers lets the CPU fetch the next memory address while at the same time retrieving the data located at the previous address. This overlap reduces the number of bus cycles per instruction, speeding up program execution. Power savings and flag handling are unrelated to buffer separation, and the extra general‑purpose registers come from other parts of the register file, not from splitting buffers.

Q4. If a 16‑bit pointer is stored in the H‑L pair and needs to be increased by the decimal value 5, which instruction sequence correctly updates the address buffer?

A.INX H; INX H; INX H; INX H; INX H ✅
B.DCR H; DCR L; DCR H; DCR L; DCR H
C.MVI A,05; ADD L; MOV L,A; DCR H
D.LXI H,0005; DAD H
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The INX instruction increments the HL register pair by one. Executing it five times adds exactly 5 to the 16‑bit address stored in HL, correctly updating the address buffer. The DCR sequence would decrement, not increment. The MVI/ADD sequence only changes the low byte and then incorrectly decrements the high byte. LXI loads a constant and DAD adds HL to itself, which would double the address rather than add 5.

Q5. When loading a signed 8‑bit offset into the accumulator, how does the sign flag (S) affect subsequent address calculations that use the address buffer?

A.The sign flag is ignored for address calculations.
B.The sign flag determines whether the offset is added or subtracted from the base address. ✅
C.The sign flag is copied into the high‑order bit of the address buffer.
D.The sign flag triggers an automatic increment of the address buffer.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The sign flag indicates whether the accumulator holds a negative (S = 1) or positive (S = 0) value. In address calculations, a negative offset must be subtracted from the base address, while a positive offset is added. Therefore the CPU uses the sign flag to decide the direction of the address modification. The flag is not transferred into the address buffer itself, nor does it cause automatic increments; it merely guides the arithmetic operation.

Q6. A routine must copy 256 bytes from a source block whose base address is in the D‑E pair to a destination block whose base address is in the H‑L pair, using auto‑increment on both address buffers. Which pseudo‑code snippet correctly performs the copy without overwriting source data?

A.LOOP: MOV A,M ; (DE) MOV M,A ; (HL) INX D ; INX E INX H ; INX L DCR B JNZ LOOP ✅
B.LOOP: MOV A,M ; (HL) MOV M,A ; (DE) INX H ; INX L INX D ; INX E DCR B JNZ LOOP
C.LOOP: LDAX D ; (DE) STAX H ; (HL) INX D ; INX H DCR B JNZ LOOP
D.LOOP: LDAX D ; (DE) STAX H ; (HL) DCR B JNZ LOOP
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The correct snippet loads a byte from the source address (DE) using LDAX, stores it to the destination address (HL) with STAX, then increments both DE and HL to point to the next locations. The loop counter B ensures 256 iterations. Option A swaps source and destination, causing data loss. Option B reads from the destination first, also corrupting data. Option D never increments the pointers, so it would repeatedly copy the same byte. Only option C follows the required sequence.

Q7. Explain why the address buffer is designed as a 16‑bit register while the data buffer is only 8‑bits in the SAP‑III architecture.

A.Because the CPU must address a 64 KB memory space, requiring 16 bits, whereas it processes data a byte at a time. ✅
B.Because 16‑bit data would be too large for the accumulator’s internal bus.
C.Because the flag register occupies the remaining bits, leaving only 8 bits for data.
D.Because the original 8085 design mandated this split.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The SAP‑III can address up to 65,536 distinct locations, which necessitates a 16‑bit address buffer (2^16 = 65,536). Data operations, however, are performed on single bytes, so an 8‑bit data buffer matches the width of the accumulator and the external data bus. This separation optimizes hardware cost and keeps instruction execution fast. The other options misinterpret the role of the flag register or impose unnecessary constraints from earlier designs.

Q8. During an interrupt, the CPU pushes the current program counter (PC) onto the stack at the address given by the stack pointer, then loads a new address from the address buffer (holding 0x3F2A) to continue execution. If the stack pointer initially is 0xFF10, what will be the address of the next instruction after the interrupt service routine executes a RET instruction?

A.16170
B.65296
C.The value previously stored at 0xFF10 ✅
D.The value at 0xFF12
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: When the interrupt occurs, the CPU stores the original PC at the location pointed to by the stack pointer (0xFF10) and then decrements the stack pointer. After the ISR finishes, the RET instruction pops the saved PC from the stack, restoring the original execution point. Therefore the next instruction address is the value that was saved at 0xFF10, not the address buffer’s content (0x3F2A) nor any other stack location. This behavior ensures program flow resumes exactly where it left off.
