Q1. What is the maximum number of DMA channels that the Intel 8257 controller can support?

🔹 A. 2
🔹 B. 4
🔹 C. 8
🔹 D. 16

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The Intel 8257 is designed with four independent channels, each capable of handling a separate DMA transfer. Therefore the maximum number of channels it can support is four, making option B correct. Options A and C underestimate and overestimate the hardware capability, while option D suggests sixteen channels, which the 8257 does not provide. Knowing the channel count is essential when planning system architecture and peripheral connections.

Q2. Why does using DMA reduce CPU involvement during large data transfers?

🔹 A. CPU is freed from moving each byte, allowing it to perform other tasks.
🔹 B. DMA uses a faster clock than the CPU.
🔹 C. DMA compresses data before transfer.
🔹 D. DMA eliminates the need for address lines.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

DMA moves data directly between memory and an I/O device, so the CPU no longer needs to fetch each byte, store it in the accumulator, and write it back. This frees the processor to execute other instructions, improving overall system throughput. Option A states this benefit, making it correct. Option B is false because DMA does not change clock speed, option C is incorrect as DMA does not compress data, and option D misrepresents the role of address lines.

Q3. A system using the 8257 sets the address register of channel 2 to 0x3000 and requests a transfer of 2000 bytes. Assuming the address increments after each byte, what address will the address register contain after the transfer completes?

🔹 A. 14288
🔹 B. 16000
🔹 C. 16384
🔹 D. 10752

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The address register starts at 0x3000. For each of the 2000 bytes transferred, the address increments by one. Adding 2000 (decimal) to 0x3000 gives 0x3000 + 0x07D0 = 0x37D0. Therefore after the transfer the register holds 0x37D0, which matches option A. Options B, C, and D result from incorrect arithmetic or neglecting the increment, so they are wrong. This calculation demonstrates how the DMA controller updates its internal address pointer after each byte, a behavior essential for sequential block transfers.

Q4. In the 8257 count register, which bits indicate the type of DMA operation to be performed?

🔹 A. The two least significant bits
🔹 B. The two most significant bits
🔹 C. All bits are used for counting only
🔹 D. Only the middle eight bits

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Within the 8257 count register, the two most significant bits are reserved to define the transfer mode, such as read, write, or verify operations. This makes option B the correct choice. Option A incorrectly points to the least significant bits, which are used for the actual byte count. Options C and D misunderstand the register’s purpose, as the count register does not serve any function beyond counting and mode indication.

Q5. If auto‑initialization is disabled on an 8257 channel and a transfer of 512 bytes finishes, what is the controller’s next action?

🔹 A. It automatically restarts the same transfer
🔹 B. It raises an interrupt and waits for new programming
🔹 C. It continues transferring with the same address
🔹 D. It disables the DMA request line permanently

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When auto‑initialization is turned off, the 8257 does not reload the address and count registers after a transfer finishes. Consequently, once the 512‑byte block is moved, the controller signals completion, typically via an interrupt, and then waits for the programmer to load new values before starting another transfer. Option B describes this behavior correctly. Options A and C suggest automatic restart, which only occurs with auto‑initialization enabled, and option D incorrectly claims permanent disabling of the request line.

Q6. During a DMA request, how does the 8257 coordinate bus arbitration with the CPU, and why is the acknowledge (ACK) signal critical?

🔹 A. The 8257 asserts HOLD, CPU releases buses, and ACK tells peripheral that transfer may begin
🔹 B. The 8257 directly controls the CPU clock, and ACK resets the CPU
🔹 C. The 8257 does not interact with the CPU; ACK is only for peripheral timing
🔹 D. The 8257 uses ACK to signal the end of the entire program

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The 8257 initiates DMA by asserting the HOLD line, causing the CPU to release the address and data buses. While the CPU is in a bus‑grant state, the DMA controller takes control of the buses to perform the transfer. The peripheral then receives an ACK signal, confirming that the bus is now allocated to the DMA operation and that data can be moved safely. Option A correctly outlines this sequence. Options B, C, and D misstate the role of ACK or ignore the arbitration process, making them incorrect.

Q7. Two peripherals simultaneously request DMA service. Channel 0 has higher priority than channel 1. Which channel will be granted first, and what happens to the other request?

🔹 A. Channel 1 gets service first; channel 0 is denied
🔹 B. Channel 0 gets service first; channel 1 remains pending until channel 0 finishes
🔹 C. Both channels share the bus simultaneously
🔹 D. The 8257 randomly selects one channel

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The 8257 resolves simultaneous DMA requests by priority: lower channel numbers have higher priority unless programmed otherwise. When channels 0 and 1 both request service, channel 0 is granted first because it has the highest priority. The controller then services channel 0 while keeping channel 1’s request pending. After channel 0 completes, the pending request on channel 1 is serviced. Option B captures this behavior. Options A and C contradict the priority rule, and option D suggests randomness, which the 8257 does not use.

Q8. A designer wants to transfer a block of 1024 bytes from memory to a printer using channel 3. The count register is loaded with 0x03FF. After the transfer, what value will the count register hold?

🔹 A. 0
🔹 B. 1
🔹 C. 1023
🔹 D. 1024

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The count register holds the number of bytes remaining to be transferred. It is decremented after each byte is moved. Starting with 0x03FF (which equals 1023 in decimal) and transferring 1024 bytes, the register underflows to 0x0000 after the final decrement. Therefore the register ends up at zero, matching option A. Options B and D give non‑zero values, and option C repeats the initial value, all of which are incorrect for a completed transfer.
