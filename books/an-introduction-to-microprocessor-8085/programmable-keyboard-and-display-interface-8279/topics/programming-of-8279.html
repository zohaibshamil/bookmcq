📝 Programming of 8279 (8 MCQs)

Definition:
Programming the 8279 involves writing command words to the command register and data to the data register to configure the chip's operating modes and control its functions. The command words set the keyboard/display mode, program the clock, define read/write operations, and control display blanking. The data words are written to display RAM or read from FIFO. Proper programming is essential for correct operation of the 8279 in a system.

Working:
The CPU writes a command word to the command register by setting A0=1 (for 8279) and writing to the appropriate address. The command word bits define the mode, clock divider, and other settings. Data is written to or read from the data register by setting A0=0. The status register is read to check FIFO status and error flags.

Example:
To initialize the 8279 for keyboard/display mode, encoded scan, 8-character display, left entry, write command 00H to command register. To set clock divider to 20, write command 0x34 (00110100) to command register. To write display data, write to data register.

Reason:
Programming is necessary to configure the 8279 for the specific application. Different applications require different modes, clock frequencies, and display settings.

Common Misconception:
Students often forget to set A0 correctly. A0=1 for command/status, A0=0 for data. Also, the command register is write-only; status register is read-only.

Exam Preparation Tips: How to prepare this topic
Memorize the command formats. Practice writing initialization code. Understand the difference between command and data registers.

Key Terms:

  • Command Register - holds command words.
  • Data Register - holds data for display or from FIFO.
  • A0 Line - selects command/status (1) or data (0).

📝 All Programming of 8279 MCQs

Q1. A microcontroller must generate a periodic interrupt using counter 0 of the 8253. Which pin provides the output signal that can be connected to the interrupt line?

A.OUT 0 (pin 10) ✅
B.GATE 0 (pin 11)
C.CLK 0 (pin 9)
D.CS (pin 21)
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The OUT 0 pin (pin 10) carries the counter’s output pulse, which can be wired to an interrupt input on the microcontroller, making it the correct choice. GATE 0 merely enables counting and does not produce an external pulse, so it cannot trigger an interrupt. CLK 0 is an internal timing source, not an output. CS is used for device selection, not for generating interrupts. Using the proper output pin ensures reliable interrupt generation in real hardware.

Q2. To load a new count value into counter 2 while the system is operating, which combination of control signals must be asserted according to the 8253 control‑signal table?

A.CS=0, RD=1, WR=0, A1=1, A0=0 ✅
B.CS=0, RD=0, WR=1, A1=1, A0=0
C.CS=1, RD=1, WR=0, A1=0, A0=1
D.CS=0, RD=1, WR=1, A1=1, A0=1
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The table shows that loading counter 2 requires CS low, RD high, WR low, with address lines A1=1 and A0=0, matching option A. Option B has RD low and WR high, which corresponds to a read operation, not a load. Option C sets CS high, disabling the chip, so no load occurs. Option D asserts WR high, which prevents the write cycle. Correct signal sequencing guarantees the new count is correctly captured while the system runs.

Q3. During a DMA setup, the CPU needs to write a mode word to configure counter 1 as a rate generator. Which pins are involved in this operation and what must be the state of the WR line?

A.CS low, WR low, A1=0, A0=1 ✅
B.CS low, WR high, A1=0, A0=1
C.CS high, WR low, A1=1, A0=0
D.CS low, WR low, A1=1, A0=1
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Writing a mode word requires the chip‑select (CS) and write (WR) signals to be asserted low, with the address lines set to select counter 1 (A1=0, A0=1). Option A satisfies all these conditions. Option B keeps WR high, which would prevent any write. Option C disables the chip by setting CS high, so no data is accepted. Option D selects the wrong counter (counter 2) while still writing a mode word, leading to an unintended configuration. Proper pin control ensures the correct mode is programmed.

Q4. If pin 21 (CS) is connected to an active‑low enable circuit but is left floating (high‑impedance) during operation, what is the most likely effect on the 8253 device?

A.The device will operate normally because CS defaults to high.
B.The device will be permanently enabled.
C.The device may enter an undefined state, leading to unpredictable behavior. ✅
D.The device will be permanently disabled.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: When CS is floating, its voltage is undefined, so the chip cannot reliably determine whether it should be enabled or disabled, resulting in unpredictable behavior (option C). Assuming a default high (option A) is unsafe because the pin is not tied to a defined level. Permanent enable (option B) or permanent disable (option D) would require CS to be firmly driven low or high, which is not the case with a floating line. In real designs, leaving control pins unconnected can cause intermittent failures.

Q5. What primary function does the GATE input serve for each counter in the 8253 timer chip?

A.It provides the clock signal to the counter.
B.It enables or disables counting based on the gate level. ✅
C.It resets the counter to zero.
D.It selects the counter for read/write operations.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The GATE input controls whether the counter is allowed to count; a high level typically enables counting while a low level pauses it, making option B correct. Option A describes the clock input, not the gate. Option C would be a reset function, which is handled by other pins. Option D refers to address selection, which involves A0/A1 and CS, not the gate. Understanding the gate’s role helps designers pause timers without losing the current count.

Q6. How do the address lines A0 and A1 influence which counter or register is accessed in the 8253?

A.They determine the operating mode of the selected counter.
B.They select one of the three counters or the control word register for reading or writing. ✅
C.They provide power supply levels to the chip.
D.They are used only for debugging purposes.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: A0 and A1 act as address selectors: the combination 00 selects counter 0, 01 selects counter 1, 10 selects counter 2, and 11 selects the control word register, which matches option B. Option A confuses address selection with mode selection, which is set via the mode word. Option C is unrelated to addressing, and option D is incorrect because the lines are essential for normal operation, not just debugging. Proper addressing ensures the correct component of the timer is programmed.

Q7. Why does the 8253 require both the CS (chip‑select) and WR (write) signals to be low when writing a mode word, rather than relying on WR alone?

A.To allow the device to differentiate between a mode‑word write and a counter‑value write.
B.To ensure that only the intended device on a shared bus is addressed, preventing accidental writes to other peripherals. ✅
C.To synchronize the write operation with the internal clock of the chip.
D.To automatically reset all counters after a mode word is written.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: CS low indicates that the 8253 is the intended target on a potentially shared bus, while WR low initiates the actual write; together they prevent other devices from being unintentionally programmed, making option B correct. Option A is partly true but does not explain the need for CS in a multi‑device environment. Option C incorrectly suggests clock synchronization, which is handled separately. Option D is false because writing a mode word does not reset counters. In real systems, both signals are essential for safe and accurate bus transactions.

Q8. Which pin number on the 8253 corresponds to the clock input for counter 1?

A.10
B.14
C.15 ✅
D.18
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The clock input for counter 1 is pin 15, as defined in the pinout table, so option C is correct. Pin 10 is OUT 0, pin 14 is GATE 1, and pin 18 is CLK 2 for counter 2. Knowing the exact pin numbers is critical when wiring the timer to ensure that the correct clock source drives the intended counter.
