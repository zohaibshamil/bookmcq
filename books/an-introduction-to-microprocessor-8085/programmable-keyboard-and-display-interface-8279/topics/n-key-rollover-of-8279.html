What is N key Rollover of 8279?

N-Key Rollover is an advanced operating mode of the 8279 that allows every individual key press to be recognized and queued in the FIFO buffer even when multiple keys are held down simultaneously, ensuring that no valid keystroke is lost regardless of how many keys (up to the FIFO depth of \( 8 \)) are pressed at once, which is essential for fast typing applications.

Q1. A designer connects the 8253 to a keyboard matrix. Pin 11 (GATE 0) is wired to a row line, and pin 10 (OUT 0) drives an LED. Which condition will cause the LED to change state when a key in that row is pressed?

A. The LED toggles whenever the GATE 0 line goes low, regardless of clock input.
B. Pressing a key that generates a clock pulse on CLK 0 will increment the counter, causing OUT 0 to toggle. ✅
C. The LED changes only when the counter reaches its terminal count, independent of key presses.
D. The LED never changes because OUT 0 is unrelated to the keyboard matrix.

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

When a key is pressed, the keyboard matrix typically produces a pulse on the clock line that feeds the counter. Pin 10 (OUT 0) reflects the counter’s output state, which toggles each time the counter advances. Therefore, the LED will change only when a clock pulse occurs on CLK 0, not merely by the GATE 0 level. Options A and C misunderstand the role of GATE 0, and D is incorrect because the counter does affect the LED.

Q2. To write a mode word for counter 2, the CPU must assert specific control signals. Which combination of CS, RD, WR, A1, and A0 will correctly load the mode word into counter 2 without affecting counters 0 or 1?

A. CS = 0, RD = 1, WR = 0, A1 = 1, A0 = 0
B. CS = 0, RD = 1, WR = 0, A1 = 1, A0 = 1
C. CS = 0, RD = 0, WR = 1, A1 = 1, A0 = 0
D. CS = 0, RD = 1, WR = 0, A1 = 0, A0 = 1 ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Table 9.2 shows that loading a mode word requires CS low, WR low, RD high, and the address lines selecting the desired counter. For counter 2 the address bits are A1=1 and A0=1. Option D matches this exact pattern, ensuring only counter 2 receives the mode word. Options A and B select the wrong counter (A1/A0 values), while C uses WR = 1, which would read rather than write, so it does not load the mode word.

Q3. Why are the CS, RD, and WR signals of the 8253 designed as active‑low inputs, and what benefit does this provide when interfacing with a typical microprocessor?

A. Active‑low signals simplify wiring by allowing a single pull‑up resistor, reducing noise susceptibility.
B. Active‑low logic matches the microprocessor’s internal bus drivers, which default to a high state when idle. ✅
C. Active‑low design ensures that a low voltage level consumes less power than a high level.
D. Active‑low inputs allow multiple devices to share the same bus lines without conflict.

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Active‑low inputs are common because most microprocessors provide open‑collector or open‑drain outputs that naturally pull the line low, while a high state is achieved by a pull‑up resistor. This arrangement reduces the chance of accidental activation due to noise, because a stray high voltage is less likely than a stray low. Option B misstates the default bus state, C is irrelevant to logic level choice, and D describes a bus‑sharing technique but does not explain the power or noise advantage.

Q4. Examine Table 9.2. If CS is low, RD is high, WR is low, and both A1 and A0 are high (an undefined state), what operation will the 8253 perform?

A. It will load counter 2 with the supplied data. ✅
B. It will write the mode word to the control register.
C. It will perform no operation and enter a three‑state condition.
D. It will read the current count from counter 2.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The table indicates that when CS is low and WR is low, the operation depends on the address lines. However, the combination A1=1 and A0=1 for a write operation is marked as undefined (X). In undefined cases the device defaults to a no‑operation (3‑state) to avoid unintended changes. Therefore the correct response is that the chip does nothing. Option A assumes a load, B assumes a mode‑word write, and D assumes a read, all of which require defined address combinations.
