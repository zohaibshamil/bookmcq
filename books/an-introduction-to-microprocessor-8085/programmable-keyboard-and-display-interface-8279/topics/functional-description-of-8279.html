📝 Functional Description of 8279 (14 MCQs)

CPU Interface and Internal Data Processing Functions

The 8279 manages communication between an eight-bit microprocessor and keyboard or display hardware. Its CPU interface accepts commands, receives display data, supplies keyboard information and reports status. Internal control registers determine operating modes, while timing circuitry manages scanning and display refresh independently of the processor's normal instruction execution.

Keyboard Section and Automatic Debouncing

The keyboard section uses RL0–RL7 as return inputs and receives scan signals from SL0–SL3. It detects closed switches, validates key operations through debounce logic and records accepted key information in FIFO RAM. SHIFT and CNTL/STB provide additional status or strobe information depending on the selected keyboard mode.

Display Section and Multiplexed Output Generation

The display section stores sixteen eight-bit character patterns in display RAM. Its output registers provide two four-bit groups through OUT A0–A3 and OUT B0–B3. The scan signals select display positions sequentially, while BD blanks the display during switching or when programmed display blanking is required.

Example of Coordinated Keyboard and Display Operation

Consider a calculator using the 8279. When a key is pressed, the keyboard circuitry debounces it and places its code in FIFO RAM. The CPU reads the code, calculates the required result and writes the corresponding display pattern into display RAM. The 8279 automatically refreshes the display.

Timing Control and Processor Interrupt Communication

The programmable prescaler derives internal timing from the external clock, providing suitable scanning and debounce intervals. The IRQ output informs the CPU about available keyboard or sensor information. This arrangement reduces software polling and display-refresh requirements, allowing the processor to concentrate on calculations and application control.

Misconceptions About Internal 8279 Operations

'Debouncing is performed entirely by the 8085' is incorrect because the 8279 contains dedicated debounce logic. 'IRQ directly carries keyboard character data' is incorrect because IRQ only indicates a service request. 'BD stores display characters' confuses display blanking with the separate display RAM storage.

Functional Operation and Signal Identification Questions

Explain how keyboard detection, debouncing, FIFO storage and IRQ generation work together. Identify the display RAM and output registers and describe automatic multiplexing. Practise tracing the complete sequence from key depression through CPU reading to display updating, including the roles of scan and timing circuitry.

8279 Functional Operation Terminology

  • Debouncing - Eliminates false key transitions.
  • FIFO - Stores accepted input entries.
  • Prescaler - Divides the external clock frequency.
  • IRQ - Indicates a pending service request.
  • BD - Controls display blanking.
  • SHIFT - Supplies additional keyboard status.

📝 All Functional Description of 8279 MCQs

Q1. Which pin provides the output signal for counter 0?

A.GATE 0
B.OUT 0 ✅
C.CLK0
D.CS
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The OUT 0 pin is the designated output line for counter 0, delivering the count pulses to external circuitry. GATE 0 controls counting, not output, while CLK0 supplies the clock and CS is the chip‑select line. Knowing the correct output pin lets a designer connect the timer’s signal to the rest of the system, ensuring the counted pulses appear where needed.

Q2. Which pin must be driven low to enable the 8253 device?

A.RD
B.WR
C.A0
D.CS ✅
💡 Difficulty: easy | ✅ Correct: D

📖 Explanation: CS (Chip Select) is an active‑low input; pulling it low tells the 8253 to listen to the bus. RD and WR are read/write signals, and A0 is an address line, none of which enable the device. Using the proper enable pin prevents bus contention and guarantees that the counter logic only responds when intended.

Q3. What voltage is supplied to the +VCC pin?

A.+5 V ✅
B.+12 V
C.+3.3 V
D.Ground
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The 8253 is powered from a standard +5 V supply, which is applied to the +VCC pin. Supplying any other voltage could damage the IC or cause it to operate incorrectly. The other options are unrelated power levels or ground, which would either leave the chip unpowered or short it, leading to failure of all counters.

Q4. To write a mode word to counter 2, which set of control signal levels is required?

A.CS=0, RD=0, WR=1, A1=1, A0=0
B.CS=0, RD=1, WR=0, A1=0, A0=1
C.CS=0, RD=1, WR=0, A1=1, A0=1 ✅
D.CS=1, RD=0, WR=0, A1=1, A0=1
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Writing a mode word to counter 2 requires CS low (active), RD high (no read), WR low (write), and the address lines set to A1=1 and A0=1 to select counter 2. Option C matches this exact combination. The other options either keep WR high, select the wrong counter, or disable the chip, so they would not program the mode register correctly.

Q5. When reading the current count from counter 1, which signals must be asserted?

A.CS low, RD low, WR high, A1=0, A0=1 ✅
B.CS low, RD high, WR low, A1=0, A0=1
C.CS high, RD low, WR high, A1=1, A0=0
D.CS low, RD low, WR low, A1=1, A0=1
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Reading counter 1 requires CS low to select the device, RD low to indicate a read operation, WR high (inactive), and the address lines set to A1=0, A0=1 to target counter 1. Option A satisfies all these conditions. The other choices either invert RD/WR, select the wrong counter, or disable the chip, preventing a valid read.

Q6. To select counter 2 via the address lines, what values should A1 and A0 have?

A.A1=0 A0=0
B.A1=1 A0=0 ✅
C.A1=0 A0=1
D.A1=1 A0=1
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The address decoding table assigns A1=1 and A0=0 to counter 2, directing bus commands to that specific counter. Option B reflects this assignment. The remaining combinations address counter 0, counter 1, or the control word register, so using them would communicate with the wrong part of the 8253.

Q7. Why is the CS (Chip Select) input active low?

A.To simplify wiring
B.To match other pins
C.To reduce power consumption
D.To ensure the device is disabled when the pin is high ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: CS being active low means the device is enabled only when the pin is driven low, and it stays disabled when the pin is high (or floating). This convention allows multiple chips to share a bus without accidental activation and provides a clear, noise‑immune way to turn the 8253 off when not needed. The other answers describe unrelated benefits.

Q8. What is the relationship between a GATE pin and its corresponding CLK pin?

A.GATE enables counting on each clock edge ✅
B.GATE provides the output signal
C.GATE supplies power to the counter
D.GATE resets the counter
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The GATE input acts as an enable line: when GATE is high, the counter responds to each rising (or falling) edge on its CLK pin and advances its count. If GATE is low, clock pulses are ignored. Therefore, GATE controls whether the clock pulses actually affect the count. The other options mischaracterize the function of the gate line.

Q9. What can happen if the A0 and A1 address lines are left floating?

A.Device always selects counter 0
B.Selection becomes unpredictable ✅
C.Device performs no operation
D.Control word register is selected
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Floating address lines can pick up noise and assume indeterminate logic levels, causing the 8253 to intermittently select different counters or the control word register. This leads to erratic behavior. The other statements assume a fixed selection or a specific operation, which is not guaranteed when the lines are not driven.

Q10. What is the primary purpose of the RD and WR signals?

A.Both read data from the device
B.Both write data to the device
C.RD reads while WR writes ✅
D.They are unused control lines
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: RD (Read) is asserted low when the CPU wants to read data from the 8253, while WR (Write) is asserted low when the CPU wants to send data (mode word or count) to the chip. This separation lets the processor perform distinct read and write cycles. The other options incorrectly describe the function of these control lines.

Q11. To generate a periodic interrupt using counter 2 while keeping its gate permanently enabled, which pins must be tied together?

A.Connect GATE 2 to VCC and CLK 2 to an external clock source ✅
B.Connect GATE 2 to OUT 2
C.Connect GATE 2 to ground and use CLK 2 as the clock source
D.Connect GATE 2 to VCC and leave CLK 2 unconnected
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: For continuous counting, GATE 2 must be held high (tied to VCC) so the counter never disables counting. The CLK 2 pin still needs a regular clock signal to drive the count; leaving it unconnected would stop counting. Option A supplies both requirements, whereas the other options either disable counting or omit the necessary clock.

Q12. Which method correctly resets counter 0 without affecting counters 1 and 2?

A.Pull GATE 0 low then high
B.Toggle CS low then high
C.Write a mode word using the load command for counter 0 ✅
D.Use a low‑level pulse on RD
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Loading a mode word with the load command for counter 0 overwrites its current count and control settings, effectively resetting it while leaving the other counters untouched. Pulling GATE 0 low only pauses counting, toggling CS affects the whole chip, and a pulse on RD does not modify the count. Hence, option C is the precise reset technique.

Q13. Why are three‑state outputs used for CS, RD, and WR signals?

A.To allow multiple devices to share the bus ✅
B.To increase the maximum operating speed
C.To reduce overall power consumption
D.To simplify programming of the chip
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Three‑state (high‑impedance) capability lets each control line be driven by several chips on a common bus without causing contention; when a chip is not selected, it places its outputs in a high‑impedance state. This sharing is essential in multi‑device systems. The other options describe benefits that are not the primary reason for three‑state behavior.

Q14. What is the likely impact of miswiring the ground pin (pin 12) on device operation?

A.The device will function but with added noise
B.Counter outputs will be inverted
C.The device may not reset properly, leading to undefined behavior ✅
D.There will be no effect on operation
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Pin 12 provides the reference ground for the entire IC. If it is not correctly connected, internal circuits lose their reference, preventing proper reset and causing unpredictable behavior across all counters. Noise or inversion of outputs are not typical consequences of a missing ground, and the device certainly will not operate correctly without a solid ground connection.
