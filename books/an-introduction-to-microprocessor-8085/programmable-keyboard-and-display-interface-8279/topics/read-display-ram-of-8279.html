📝 Read Display RAM of 8279 (16 MCQs)

Accessing the Sixteen-Byte Display Memory

The Read Display RAM command enables the processor to retrieve character patterns previously stored in the 8279 display memory. The display RAM contains sixteen eight-bit locations, addressed from 0 to 15. Reading these values allows software to examine the current display contents, verify programmed character data or modify selected display positions.

Command Format and Display Address Selection

The command format is 011AIAAAA. The upper three bits select the Read Display RAM operation, AI controls automatic address incrementing and AAAA identifies one of sixteen display RAM locations. When AI is one, the address advances after successive display RAM read or write data operations.

Processor Read Sequence and Internal Address Management

The processor first writes the read-display command with A0 high and WR active low. It then performs data reads with A0 low and RD active low. The 8279 supplies the selected display RAM byte through DB0–DB7 and advances the address when auto-increment is enabled.

Example of Reading Three Display RAM Locations

To read three consecutive display bytes beginning at address 02H with auto-increment enabled, the command is 70H. The processor issues this command and performs three data reads. The returned bytes represent the contents of display RAM locations 02H, 03H and 04H respectively.

Applications in Display Verification and Data Updating

Reading display RAM allows a program to inspect stored patterns without relying solely on visual output. It is useful for display-status checking, character verification and applications where software needs to preserve or compare existing display contents. The same internal address counter is used for display reading and writing operations.

Misconceptions About Display RAM Reading

'Read Display RAM retrieves keyboard codes' is incorrect because keyboard information is read from FIFO. 'The command directly reads a physical display segment' is incorrect because it retrieves the stored RAM byte. 'AI automatically advances after every processor instruction' is incorrect because it advances after applicable display RAM data transfers.

Display Address and Auto-Increment Examination Questions

Practise interpreting 011AIAAAA and constructing commands for selected display locations. Trace the address sequence during consecutive reads and distinguish data-register access from command-register access. Questions may provide several display RAM bytes and ask for their returned order or the next address after an auto-incremented read.

Display Memory Reading Terminology

  • Read Display RAM - Selects display memory for reading.
  • AAAA - Specifies a display RAM address.
  • AI - Enables automatic address incrementing.
  • Display Byte - Eight-bit stored character pattern.
  • RD - Activates the data-read operation.
  • DB0–DB7 - Carry the returned display byte.

📝 All Read Display RAM of 8279 MCQs

Q1. In a circuit using the 8253 timer, which pin must be connected to ground to ensure proper operation of counter 0?

A.Pin 10 (OUT 0)
B.Pin 12 (GROUND) ✅
C.Pin 21 (CS)
D.Pin 22 (RD)
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The ground pin for the 8253 is pin 12, providing the reference voltage needed for all internal circuitry, including counter 0. Connecting pin 10, pin 21, or pin 22 to ground would either output a signal, enable the chip, or read data, none of which supplies the required reference. Using the correct ground pin lets the counter count accurately and matches real‑world wiring practices where a solid ground connection is essential for reliable timing.

Q2. Why is the Chip Select (CS) input of the 8253 defined as an active‑low signal?

A.Because active‑low inputs reduce power consumption
B.Because most TTL logic families use active‑low control lines ✅
C.Because it simplifies PCB routing
D.Because high voltage could damage the chip
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: TTL logic commonly uses active‑low signals, meaning the device responds when the pin is at a low voltage. This convention allows the chip to be disabled with a simple high level, preventing unintended activation and reducing noise. The other options either describe unrelated effects or are inaccurate; power reduction is a minor benefit, routing is not a primary reason, and high voltage does not inherently damage the chip. Understanding this helps designers correctly interface the 8253 with standard TTL circuits.

Q3. A CPU wants to read the current count from counter 1. Which combination of control signals must be asserted?

A.CS = 0, RD = 0, WR = 1, A1 = 0, A0 = 1 ✅
B.CS = 0, RD = 1, WR = 0, A1 = 0, A0 = 1
C.CS = 1, RD = 0, WR = 0, A1 = 0, A0 = 1
D.CS = 0, RD = 0, WR = 0, A1 = 0, A0 = 1
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Reading counter 1 requires the chip to be selected (CS = 0), the read line active (RD = 0), and the write line inactive (WR = 1). The address lines must point to counter 1, so A1 = 0 and A0 = 1. Option A matches this exact pattern. Option B keeps RD high, preventing a read; Option C disables the chip with CS = 1; Option D sets WR low, which would trigger a write operation. Applying the correct control signals ensures the CPU receives the correct count value without disturbing other counters.

Q4. What is the primary function of the GATE inputs on each counter of the 8253?

A.They provide the clock source for the counter
B.They enable or disable counting when asserted ✅
C.They reset the counter to zero
D.They select which counter is addressed
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The GATE pins control whether a counter is allowed to count; when the gate input is high (or low, depending on mode), counting proceeds, and when it is low (or high), counting is halted. This enables precise timing control in real applications. Supplying the clock source is the role of the CLK pins, resetting is done by loading a new value, and selecting counters is performed via the address lines A0/A1. Knowing the gate function helps engineers design systems where counting must be started or stopped on demand.

Q5. Which pin number carries the CLK2 (clock input for counter 2) signal?

A.16
B.17
C.18 ✅
D.19
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The clock input for counter 2 is assigned to pin 18, labeled CLK 2 in the 8253 pinout. Pin 16 is the gate for counter 2, pin 17 is the output, and pin 19 is the address line A0. Recognizing the correct pin is essential when wiring the timer to an external clock source, ensuring that the counter receives timing pulses and operates as intended.

Q6. To read the value of counter 2 without affecting counters 0 or 1, which control signal states should be set?

A.CS = 0, RD = 0, WR = 1, A1 = 1, A0 = 0 ✅
B.CS = 0, RD = 1, WR = 0, A1 = 1, A0 = 0
C.CS = 0, RD = 0, WR = 0, A1 = 1, A0 = 0
D.CS = 1, RD = 0, WR = 1, A1 = 1, A0 = 0
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Reading counter 2 requires the chip to be selected (CS = 0) and the read line active (RD = 0) while keeping the write line inactive (WR = 1). The address lines must point to counter 2, so A1 = 1 and A0 = 0. Option A matches this configuration. Option B disables the read line; Option C incorrectly asserts WR low, which would start a write operation; Option D disables the chip altogether. Correctly setting these signals isolates counter 2, allowing its value to be retrieved without influencing the other counters.

Q7. According to Table 9.2, what operation occurs when CS = 0, RD = 0, WR = 1, A1 = 1, A0 = 1?

A.Load counter 2
B.Read counter 2
C.Write Mode Word
D.No operation (3‑state) ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: The combination CS = 0, RD = 0, WR = 1 with both address lines high (A1 = 1, A0 = 1) is defined as a no‑operation or 3‑state condition in Table 9.2. This means the device does not perform any load, read, or write action. Loading counter 2 would require WR = 0, reading counter 2 needs RD = 0 with WR = 1 and address 1 0, and writing a mode word uses address 1 1 with WR = 0. Recognizing this idle state prevents unintended actions during system design.

Q8. If the CPU places the binary address 10 on the A1/A0 lines, which component of the 8253 is selected?

A.Counter 0
B.Counter 1
C.Counter 2 ✅
D.Control Word Register
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The address lines A1 and A0 form a two‑bit binary number. Binary 10 corresponds to A1 = 1 and A0 = 0, which selects counter 2 according to the mapping in the 8253. Selecting counter 0 would require 00, counter 1 requires 01, and the control word register uses 11. This knowledge allows designers to correctly map software addresses to the desired hardware counter for accurate timing operations.

Q9. Which pin of the 8253 is used as the Chip Select (CS) terminal?

A.Pin 21 ✅
B.Pin 22
C.Pin 23
D.Pin 24
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The CS (Chip Select) line is pin 21 and it is active‑low, meaning the device is enabled when this pin is driven low. Pin 22 is the RD line, pin 23 is WR, and pin 24 supplies +5 V. Selecting the correct pin ensures the processor can activate the 8253; using any other pin would leave the chip disabled, preventing any counter or mode operations.

Q10. What is the primary function of the active‑low CS signal in the 8253?

A.Enables the device when low ✅
B.Disables the device when low
C.Selects a specific counter
D.Provides the clock input
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: When CS is asserted low, the 8253 becomes active and can respond to further control signals. This enables the counters and the control word register to be accessed. If CS were high, the chip would stay in a high‑impedance state, ignoring RD, WR, and address inputs, so no counting or mode configuration would occur.

Q11. How does the combination CS = 0, RD = 0, WR = 1, A1 = 1, A0 = 0 affect the 8253?

A.Load counter 1
B.Read counter 1 ✅
C.Write Mode Word
D.No operation
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: With CS low the device is enabled. RD low and WR high indicate a read operation. The address bits A1 = 1 and A0 = 0 select counter 1, so the chip reads the current count of counter 1 and places it on the data bus. Loading a counter or writing a mode word would require WR low, which is not the case here.

Q12. Why must the A0 and A1 address lines be connected to the address bus when selecting counters in the 8253?

A.To provide data to the counters
B.To select a specific counter or the control word register ✅
C.To generate the clock signal
D.To set the supply voltage
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: A0 and A1 act as selection bits that tell the 8253 which internal register—counter 0, 1, 2, or the control word register—is being addressed. Connecting them to the CPU’s address bus allows software to choose the desired component by placing the appropriate binary value on those lines, enabling precise configuration and reading of each counter.

Q13. A system needs a periodic interrupt every 10 ms using counter 2. If the input clock is 1 MHz, which mode word should be written to configure counter 2 in rate‑generator mode?

A.52
B.180 ✅
C.196
D.118
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Rate‑generator mode is mode 2. For counter 2, the select bits are 10, the access mode should be lo/hi (11), and BCD is 0. Combining these gives binary 1011 0100, which is hexadecimal 0xB4. Writing this mode word loads counter 2 to divide the 1 MHz clock, producing the required 10 ms interval. The other options represent incorrect selections of counter, access mode, or mode number.

Q14. During testing, a programmer writes a mode word to counter 1 but mistakenly asserts CS low while RD is also low. What unintended operation occurs, and how can it affect the subsequent read of counter 1?

A.Loads counter 1
B.Writes mode word to counter 0
C.Reads counter 1 ✅
D.No operation
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: When CS is low the chip is active. RD low and WR high indicate a read operation, not a write. Because the address lines are set for counter 1 (A1 = 0, A0 = 1), the chip reads the current count of counter 1 instead of storing the new mode word. This unexpected read can overwrite the data the CPU expects, leading to incorrect timing configuration.

Q15. A designer connects pin 22 (RD) to ground permanently, assuming it will always allow reading data. What problem will this cause when the CPU attempts to write a mode word to counter 0?

A.Mode word will be written correctly
B.Counter 0 will be loaded instead of mode word ✅
C.Device will be disabled
D.No operation will occur
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Pin 22 is the RD (Read) line; tying it low forces the 8253 to interpret every transaction as a read. When the CPU drives WR low to write a mode word, the chip still sees RD low, so the combination corresponds to the “Load counter 0” operation rather than “Write Mode Word.” Consequently, the counter receives an unintended count value.

Q16. If A0 = 0 and A1 = 1, which internal component of the 8253 is selected?

A.Counter 0
B.Counter 1 ✅
C.Counter 2
D.Control‑word register
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The address bits A1 and A0 form a two‑bit selector: 00 selects counter 0, 01 selects counter 1, 10 selects counter 2, and 11 selects the control‑word register. With A1 = 1 and A0 = 0 the binary value is 10, which corresponds to counter 2. However, the given combination is 01 (A1 = 0, A0 = 1), so the correct selection is counter 1.
