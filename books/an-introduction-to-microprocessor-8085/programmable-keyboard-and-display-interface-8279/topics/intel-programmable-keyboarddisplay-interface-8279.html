What is INTEL Programmable Keyboard/Display Interface 8279?

The Intel 8279 is a programmable peripheral chip that manages both keyboard scanning and display refreshing independently, allowing the microprocessor to handle other tasks while the 8279 automatically detects key presses using \( N \) scan lines and updates up to 16 alphanumeric characters without constant CPU intervention.

Q1. A system needs to generate a periodic interrupt using counter 0. Which pin should be connected to the interrupt line?

A. OUT0 (Pin 10) ✅
B. GATE0 (Pin 11)
C. CLK0 (not listed)
D. CS (Pin 21)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The interrupt line must receive the output of counter 0, which is provided on the OUT0 pin (pin 10). Connecting GATE0 would only control when the counter counts, not deliver the count value. CLK0 is not a defined pin for the 8253, and CS is used only to enable the whole chip. Therefore, OUT0 is the correct choice, ensuring the periodic signal reaches the interrupt circuitry.

Q2. What is the primary role of the CS (Chip Select) pin on the 8253?

A. It enables the device when driven low ✅
B. It provides the clock signal
C. It selects which counter to use
D. It reads data from the counter

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

CS is an active‑low input; when it is low the 8253 becomes operational and can respond to other control signals. It does not generate clocks, select individual counters (A0/A1 do that), or perform read operations. Hence the correct description is that CS enables the device when driven low, allowing the rest of the pins to function.

Q3. To write a mode word that configures counter 1 for square‑wave operation, which combination of control signals must be active? Use 0 for low and 1 for high.

A. CS=0, RD=1, WR=0, A1=1, A0=1 ✅
B. CS=0, RD=0, WR=0, A1=1, A0=0
C. CS=0, RD=1, WR=1, A1=0, A0=1
D. CS=1, RD=1, WR=0, A1=1, A0=1

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

According to the control‑signal table, writing a mode word requires CS low, RD high, WR low, and address lines A1 = 1, A0 = 1 to target the mode‑word register. Option A matches this exact pattern, while the other options either set RD low (which would initiate a read) or set the address lines incorrectly, preventing the mode word from being stored.

Q4. Why are the A0 and A1 terminals tied to the address bus in the 8253?

A. They allow selection of individual counters or the control word register ✅
B. They provide power to the device
C. They generate the clock signal
D. They reset the counters

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A0 and A1 are address inputs that let the CPU choose between counter 0, counter 1, counter 2, or the control‑word register. They do not supply voltage, produce clocks, or issue resets. By connecting them to the address bus, the processor can issue the proper command to the desired internal register, which is essential for correct operation of the three counters.

Q5. A microprocessor wants to read the current count of counter 2. Which control‑signal pattern should it assert?

A. CS=0, RD=0, WR=1, A1=1, A0=0 ✅
B. CS=0, RD=1, WR=0, A1=1, A0=0
C. CS=0, RD=0, WR=0, A1=1, A0=1
D. CS=1, RD=0, WR=1, A1=0, A0=0

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Reading counter 2 uses the combination CS low, RD low, WR high, and the address lines set to A1 = 1, A0 = 0, as shown in the table for “Read counter 2”. Option A follows this exact pattern. The other options either set RD high (which would not initiate a read) or use the wrong address bits, leading to reading the wrong counter or no operation.

Q6. Which pin number on the 8253 is designated for the ground terminal?

A. Pin 10
B. Pin 12 ✅
C. Pin 21
D. Pin 24

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The ground reference for the 8253 is provided on pin 12. Pin 10 is OUT0, pin 21 is the active‑low chip‑select line, and pin 24 supplies +5 V. Correctly connecting the ground pin ensures the device has a common reference voltage, which is essential for reliable digital operation.

Q7. If GATE2 is mistakenly wired to the same line as OUT1, what functional problem is most likely to occur?

A. Counter 2 will never start because its gate is tied to an output
B. Counter 1 cannot be gated, disabling its operation
C. Both counters will be gated simultaneously, causing unintended synchronization ✅
D. The device will enter a disabled 3‑state condition

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

OUT1 is an output pin that reflects the count of counter 1, while GATE2 is an input that controls counting for counter 2. Sharing the same line means the gating of counter 2 becomes dependent on the output state of counter 1, causing both counters to be enabled or disabled together and leading to unintended timing relationships. The other options describe effects that do not follow from this wiring error.

Q8. How does the active‑low nature of the RD and WR signals influence the timing when the CPU reads a counter value?

A. The CPU asserts RD low, keeping WR high; data becomes valid while RD stays low, then RD returns high. ✅
B. The CPU asserts WR low, keeping RD high; data is valid while WR stays low.
C. Both RD and WR must be low simultaneously to read data.
D. RD and WR are irrelevant for read operations.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

During a read, the CPU pulls the RD line low (active‑low) while WR remains high, signaling the 8253 to place the requested count on the data bus. The data stays valid as long as RD is low, and the CPU releases RD (returns it high) after capturing the value. Using WR low would indicate a write operation, and requiring both lines low would not match the defined protocol, making option A the only correct description of the timing behavior.
