What is Display Modes of 8279?

Display Modes define how the 8279 organizes and presents data on connected displays, offering options such as left-entry typewriter mode, right-entry calculator mode, and various digit grouping configurations that determine whether new characters appear at the beginning or end of the display field and how cursor positioning behaves during write operations.

Q1. Which pin on the 8253 is designated as the Chip Select (CS) terminal?

A. Pin 21 ✅
B. Pin 22
C. Pin 23
D. Pin 24

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The CS terminal is used to enable the device and is active low. On the 8253 pinout, CS is assigned to pin 21, allowing the processor to select the chip when the signal is low. Pin 22 is the RD line, pin 23 is WR, and pin 24 supplies +5 V, so those answers are incorrect. This knowledge helps designers connect the chip correctly in hardware.

Q2. A microcontroller needs to read the current count value from counter 2 of an 8253. Which combination of control signals (CS, RD, WR, A1, A0) should be asserted?

A. CS=0 RD=0 WR=1 A1=1 A0=1
B. CS=0 RD=0 WR=1 A1=1 A0=0 ✅
C. CS=0 RD=1 WR=0 A1=1 A0=0
D. CS=1 RD=0 WR=1 A1=1 A0=0

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Reading a counter requires CS low to enable the chip, RD low to indicate a read, and WR high because no write is occurring. For counter 2 the address lines must be A1=1 and A0=0 according to the selection table. Option B matches this exact pattern, while the other options either select the wrong counter or perform a load or no‑operation, making them incorrect.

Q3. If the address lines A0 and A1 are set to binary 01, which component of the 8253 is selected?

A. Counter 0
B. Counter 1 ✅
C. Counter 2
D. Control word register

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The address bus selects the internal element: A1 A0 = 00 selects counter 0, 01 selects counter 1, 10 selects counter 2, and 11 selects the control word register. Therefore binary 01 activates counter 1. Options A, C, and D correspond to different address codes, so they do not match the given setting. Understanding this mapping is essential for correct programming of the timer.

Q4. When the CS signal is driven low but the WR signal remains high, what operation does the 8253 perform?

A. Loads a counter
B. Writes the mode word
C. No operation (3‑state)
D. Disables the device ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Both CS and WR must be low to write a mode word; CS low alone does not cause any action. With WR high, the chip is not receiving a write command, so the control lines are ignored and the device enters a three‑state (no operation) condition. Options A and B describe write actions that require WR low, and option D describes the disabled state when CS is high, leaving option C as the correct answer.

Q5. Why are the CS, RD, and WR inputs of the 8253 defined as active‑low signals in typical microprocessor interfacing?

A. Because microprocessors only generate low voltages
B. To simplify wiring and reduce power consumption ✅
C. To provide noise immunity and allow wired‑AND bus structures
D. Because high levels could damage the chip

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Active‑low logic is common because many microprocessors use open‑collector or open‑drain outputs that can safely pull a line low while allowing multiple devices to share the line, creating a wired‑AND function and improving noise immunity. This design also tolerates higher voltage levels without harming the device. Options A and D misstate the reason, and option B ignores the bus‑sharing advantage, so option C correctly explains the rationale.

Q6. In a system with two 8253 timers sharing the same data bus, what is the proper method to prevent bus contention while accessing each timer?

A. Assert both CS pins low simultaneously ✅
B. Assert only the CS pin of the desired timer low while keeping the other high
C. Toggle the WR pin of both timers together
D. Use the RD pin to isolate the inactive timer

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Each 8253 has its own Chip Select line; only the selected device should have CS driven low to enable it, while the other device’s CS stays high (inactive). This prevents both timers from driving the bus at the same time, avoiding contention. Option A would enable both chips, causing conflicts. Option C manipulates WR without addressing selection, and option D does not control the enable state, making option B the correct approach.
