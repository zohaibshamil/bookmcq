What is Memory Mapped I/O in 8085 Microprocessor?

Memory Mapped I/O is a technique where input/output devices are treated as memory locations within the standard \(64\text{KB}\) address space, allowing the microprocessor to use regular memory instructions like \(LDA\) or \(STA\) to read from or write to peripherals using their unique \(16\)-bit addresses instead of special I/O commands.

Q1. Which opcode complements the accumulator in the 8085 instruction set?

A.CMA
B.DAA
C.RLC ✅
D.STC
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The correct answer is CMA because it directly inverts every bit of the accumulator, producing the one’s complement. DAA adjusts a binary‑coded decimal result, RLC rotates bits left, and STC simply sets the carry flag; none of these alter the accumulator contents. Understanding the specific role of CMA helps a programmer select the right instruction when implementing two’s complement logic, ensuring the correct bitwise operation is performed.

Q2. Why is the carry flag essential when forming the two’s complement of a multi‑byte number?

A.It indicates overflow from the low‑order byte to the next byte ✅
B.It stores the most significant bit of the original number
C.It determines whether the number is signed or unsigned
D.It has no effect on multi‑byte operations
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The carry flag must be propagated because two’s complement addition may generate a carry out of the least‑significant byte. That carry becomes the next byte’s addition input, ensuring the overall complement is correct across all bytes. Ignoring the flag would leave higher bytes unchanged, producing an incorrect result. Recognizing this behavior is crucial when extending the algorithm to larger data structures.

Q3. What purpose does register B serve in the program that computes two’s complement for N bytes?

A.It temporarily holds the carry generated by adding 01 H ✅
B.It stores the original value of N for later use
C.It acts as a pointer to the destination address
D.It contains the most significant byte of the input data
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Register B is used to hold either 01 H or 00 H, representing the carry from the previous byte’s addition. When the next byte is processed, the instruction ADD B adds this carry to the complemented value, correctly propagating the overflow. The other options describe unrelated roles: B is not a pointer, does not retain N, and does not store data bytes. This design enables accurate multi‑byte two’s complement computation.

Q4. Given N = 03 H and the three source bytes at 2101 H–2103 H are FF H, 00 H, 01 H, what will be stored at 2201 H–2203 H after the program finishes?

A.00 H, FF H, FE H ✅
B.01 H, FF H, FF H
C.00 H, 00 H, FE H
D.01 H, 00 H, FF H
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The program first complements FF H (11111111₂) to 00 H, adds 01 H yielding 01 H, but a carry is generated and stored in B for the next byte. The second byte 00 H is complemented to FF H, B adds the previous carry, resulting in 00 H with no new carry. The third byte 01 H becomes FE H after complement and adding zero carry. Thus the destination contains 00 H, FF H, FE H, matching option A. All other options mis‑handle the carry propagation.

Q5. To relocate the result buffer from 2201 H to 2300 H, which instruction should be altered?

A.Change the LXI D instruction to load 2300 H ✅
B.Modify the LXI H instruction to load 2300 H
C.Replace the STAX D instruction with STA 2300 H
D.Adjust the INX D instruction to skip to 2300 H
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The destination address is controlled by the D‑E register pair, which is initialized by the LXI D instruction. Updating that instruction to load 2300 H moves the base of the result buffer. Changing LXI H would affect the source address, not the destination. Replacing STAX D with STA would lose the indirect addressing advantage, and altering INX D would only affect subsequent increments, not the initial start address.

Q6. If the JNC NXT instruction were omitted, what consequence would most likely occur?

A.The program would ignore a generated carry, producing an incorrect two’s complement ✅
B.The program would halt unexpectedly due to an illegal opcode
C.The source pointer would never advance, causing an infinite loop
D.The carry flag would be permanently cleared, affecting later arithmetic
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Without the JNC NXT test, the program would always assume no carry after each addition. When a byte generates a carry, the subsequent byte would miss the required increment of B, leading to an erroneous complement for higher‑order bytes. The other choices describe unrelated effects: omitting JNC does not change opcode legality, does not affect pointer movement, and does not forcibly clear the carry flag.

Q7. What is the role of the INX H instruction inside the processing loop?

A.It advances the HL pair to the next source byte ✅
B.It increments the carry flag for the next addition
C.It loads the next immediate value into the accumulator
D.It resets the program counter for the next iteration
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: INX H adds one to the HL register pair, which points to the current source memory location. By incrementing HL, the program fetches the next byte in the sequence for processing. The other options misinterpret the function: INX H does not affect the carry flag, does not load immediate data, and does not modify the program counter directly. This step is essential for sequentially handling multi‑byte data.

Q8. If N = 01 H and the single byte at 2101 H is 80 H, what two’s complement value will be stored at 2201 H?

A.80 H
B.7F H
C.80 H (with carry) ✅
D.7F H (with carry)
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The byte 80 H (10000000₂) is complemented to 7F H (01111111₂). Adding 01 H yields 80 H, and a carry is generated but discarded because there is no higher‑order byte. Therefore the stored result is 80 H, matching option C. Options involving a persistent carry are incorrect because the program terminates after the single byte, and the option 7F H ignores the required addition of 01 H.

Q9. Why does the program use DCR C followed by JNZ LOOP after processing each byte?

A.To decrement the byte counter and repeat until all bytes are handled ✅
B.To clear the accumulator before loading the next byte
C.To reset the carry flag for the next iteration
D.To increment the destination address for the next result
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: C holds the count of remaining bytes. DCR C reduces this count after each iteration, and JNZ LOOP branches back only while the count is non‑zero, ensuring the loop processes exactly N bytes. Clearing the accumulator or resetting the carry flag are performed by other instructions, and the destination address is advanced by INX D, not by this pair.

Q10. How does the program guarantee that the least significant byte is processed first?

A.It starts reading from address 2101 H, which holds the LSB ✅
B.It uses a reverse loop that counts down from the most significant byte
C.It swaps the bytes before processing
D.It relies on the hardware to automatically order the bytes
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The source data begins at 2101 H, and the specification states that this location contains the least significant byte. By loading HL with 2100 H and then incrementing it once (INX H), the program points to 2101 H as the first byte to complement. No swapping or hardware reordering is needed; the address layout itself enforces the correct order.

Q11. When adapting the program to compute the ten’s complement instead of two’s complement, which instruction must be altered?

A.Replace ADI 01 H with ADI 09 H ✅
B.Replace CMA with DAA
C.Replace STAX D with STA D
D.Replace JNC NXT with JC NXT
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Ten’s complement for a decimal digit is obtained by subtracting the digit from 9, which in binary is equivalent to adding 09 H after taking the one’s complement. Therefore the ADI 01 H instruction, responsible for converting one’s complement to two’s complement, must be changed to ADI 09 H. The other instructions either handle binary adjustments or address storage and are unrelated to the decimal complement operation.

Q12. In a memory‑mapped I/O system, why is it advantageous to place the result buffer at a different address range than the source data?

A.It prevents accidental overwriting of the original data during processing ✅
B.It allows the CPU to access the result faster than the source
C.It enables the use of a separate bus for output devices
D.It reduces the need for address decoding logic
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: Keeping the result buffer separate ensures that as each source byte is read, the transformed byte can be written without risking overwriting bytes that have not yet been processed. This separation simplifies verification and debugging. While performance and bus considerations may matter, the primary benefit in this algorithm is data integrity, which directly supports correct two’s complement computation across multiple bytes.
