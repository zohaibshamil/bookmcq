What is Programmed I/O Data Transfer in 8085 Microprocessor?

Programmed I/O Data Transfer is a method where the \(CPU\) actively controls the entire data exchange process by repeatedly executing instructions to check device status and move data, which is simple to implement but inefficient because the processor remains busy waiting in a loop until the \(I/O\) operation completes.

Q1. A microcontroller stores N = 03h at address 2100h and the three bytes 12h, 34h, 56h at addresses 2101h‑2103h (least significant first). After executing the 8085 program, which value will be stored at address 2202h?

A. 204
B. 203 ✅
C. 205
D. 201

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The program first loads N (03h) and processes the LSB at 2101h. Complementing 12h gives EDh; adding 01h yields EEh with no carry, so B becomes 00h. The next byte 34h is complemented to CBh and B (00h) is added, leaving CBh unchanged, which is stored at 2202h. Hence 0xCB is the correct result, while the other choices either ignore the complement step or mis‑handle the carry.

Q2. Given N = 02h stored at 2100h and bytes FFh and 01h at 2101h‑2102h (LSB first), what value will appear at 2201h after the program runs?

A. 1 ✅
B. 0
C. 255
D. 254

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The first byte FFh is complemented to 00h, then ADI 01h produces 01h with no carry, so B is set to 00h. This result (01h) is stored at 2201h. Because there is no carry, the second byte 01h is merely complemented to FEh and B (00h) is added, yielding FEh, which is stored at 2202h. Thus 0x01 is the correct answer for the first destination location; the other options either miss the addition of 01h or misinterpret the carry.

Q3. For N = 03h with bytes 00h, FFh, FFh at 2101h‑2103h (LSB first), what value will be stored at 2203h after execution?

A. 0 ✅
B. 1
C. 255
D. 254

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Processing the first byte 00h: CMA yields FFh, ADI 01h produces 100h, so the accumulator wraps to 00h and sets the carry flag. The program stores 00h and sets B to 01h. The second byte FFh is complemented to 00h; adding B (01h) gives 01h with no new carry, so B becomes 00h and 01h is stored. The third byte FFh is complemented to 00h, B (00h) added yields 00h, which is stored at 2203h. Therefore 0x00 is correct; other options ignore the initial carry propagation.

Q4. If the memory location 2100h contains 00h (meaning N = 0), what will the program do?

A. It will enter an infinite loop ✅
B. It will process one byte and halt
C. It will halt immediately without processing
D. It will store zero at 2201h

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When N is zero, the program loads C with 00h and immediately proceeds to the loop where it decrements C (DCR C) resulting in FFh, which is non‑zero. The subsequent JNZ LOOP therefore branches back to the start of the loop, causing the program to repeat indefinitely. No HLT instruction is reached, so the program never terminates. The other answers incorrectly assume termination or processing of data.

Q5. To store the result beginning at address 2300h instead of 2201h, which instruction should be modified?

A. Change LXI H, 2100h to LXI H, 2300h
B. Change LXI D, 2201h to LXI D, 2300h ✅
C. Change MOV C, M to MOV C, 2300h
D. Change STAX D to STAX 2300h

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The destination address is set by the DE register pair, which is initialized with the instruction LXI D, 2201h. To redirect the output to 2300h, only this instruction needs to be altered to LXI D, 2300h. Changing LXI H would affect the source address, MOV C, M already uses the correct source, and STAX D automatically stores to the address held in DE, so those options would not achieve the required relocation.

Q6. What is the primary purpose of the CMA instruction in the 2's complement routine?

A. To invert all bits of the accumulator (1's complement) ✅
B. To add 1 to the accumulator
C. To store the accumulator value in memory
D. To rotate the accumulator left

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

CMA stands for Complement Accumulator; it flips each bit of the accumulator, producing the 1's complement of the original byte. This step is essential before adding 1 (via ADI 01h) to obtain the 2's complement. The other options describe different operations: adding 1 is performed by ADI, storing uses STAX, and rotation is achieved with RLC/RRC instructions.

Q7. Why does the program use register B to hold a value after testing the carry flag?

A. To propagate the carry into the next byte’s addition
B. To keep a constant value of 1 for later use ✅
C. To store an intermediate result of the complement
D. To control the loop counter

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

After each addition, the program checks the carry flag with JNC. If a carry occurred, it loads B with 01h; otherwise, B receives 00h. This value is then added to the next byte (ADD B), effectively propagating the carry from the previous byte’s 2's complement calculation. The other choices misinterpret B’s role: it is not a constant, not a complement result, and loop counting is handled by C.

Q8. If the instruction ADI 01h were replaced by ADI 00h, how would the program’s output change?

A. The output would be the 1's complement of each byte, not the 2's complement ✅
B. The output would remain the same as before
C. The program would crash due to an illegal instruction
D. The carry flag would always be set for every byte

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Removing the addition of 01h means the program only performs the CMA step, which yields the 1's complement of each source byte. Consequently, no extra 1 is added, so the results are not true 2's complements, and the carry handling for multi‑byte numbers is also altered. The other options are incorrect because the instruction is valid, the output changes, and the carry flag behavior depends on the actual addition.

Q9. Why does the program execute INX H and INX D after each iteration?

A. To advance to the next source and destination memory locations ✅
B. To increment the loop counter
C. To reset the processor flags
D. To skip over unused memory locations

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

INX H increments the HL pair, moving the source pointer to the next byte in the input sequence, while INX D increments the DE pair, moving the destination pointer to the next location where the result will be stored. This ensures that each byte is processed sequentially. The loop counter is held in C, not in HL or DE, and the flags are unaffected by these increments.

Q10. Where is the count of bytes N stored for the program to read?

A. 2100h ✅
B. 2101h
C. 2200h
D. 2201h

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The program begins with LXI H,2100h and then uses MOV C,M to load the value at the address pointed to by HL into register C. Since HL was set to 2100h, the byte at 2100h holds the number of bytes N that the routine will process. The other addresses are used for the data bytes (2101h onward) or the result storage (2201h onward).
