What is I/O Mapped I/O or Isolated I/O in 8085 Microprocessor?

I/O Mapped I/O, also known as Isolated I/O, keeps peripheral devices separate from the main memory map by using dedicated \(IN\) and \(OUT\) instructions with an \(8\)-bit port address ranging from \(00H\) to \(FFH\), which activates the \(IO/M\) control signal to distinguish I/O operations from memory access.

Q1. Given N = 03H stored at 2100H and the three bytes 34H, A5H, 00H at addresses 2101H-2103H (LSB at 2101H), after the program finishes, what value will be stored at memory location 2202H?

A. 34H
B. 5AH ✅
C. A5H
D. FFH

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The program first complements 34H, adds 1, and stores 0xCC at 2201H. The carry generated is cleared, so B is set to 00H. For the second byte A5H, CMA produces 0x5A, and because the previous carry is 0, the ADD B step adds 0, yielding 0x5A which is stored at 2202H. Thus the middle byte of the two’s‑complement result is 5AH. All other options represent either the original byte or the high‑order byte, not the correct middle result.

Q2. To modify the program so it produces the 1's complement of each byte instead of the 2's complement, which instruction should be replaced?

A. Replace CMA with XRA A
B. Replace ADI 01H with NOP ✅
C. Replace STAX D with MOV M,A
D. Replace JNC NXT with JC NXT

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The two’s complement is obtained by complementing the bits (CMA) and then adding one (ADI 01H). To generate only the one’s complement, the addition of one must be omitted. Replacing the ADI 01H instruction with a NOP (or removing it) leaves the program performing only the CMA step, which yields the one’s complement of each byte. Changing CMA, STAX D, or the jump instructions would not eliminate the extra increment, so only option B correctly modifies the algorithm.

Q3. If the carry flag is set after processing the first byte, what value is loaded into register B for the next iteration?

A. 00H
B. 01H ✅
C. FFH
D. 80H

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

After processing the first byte, the program tests the carry flag with JNC. If the carry is set, it executes the path that loads 01H into register B (MVI B,01H). This value is then used in the subsequent ADD B instruction to propagate the carry into the next byte’s two’s complement calculation. Therefore, when the carry flag is set, B receives 01H, while the other options either clear the carry or are unrelated.

Q4. When N = FFH (255 bytes), which of the following problems is most likely to occur because the program does not check the end of memory space?

A. Overwrite data beyond 22FFH causing loss of other program ✅
B. Program will halt due to stack overflow
C. Carry flag will always be cleared
D. No problem because 8085 has unlimited memory

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The program assumes that the destination area beginning at 2201H has enough space for N bytes. When N = FFH, the program will write up to address 2200H + FFH = 22FFH. If the system’s RAM ends before this address, the final writes will overwrite whatever follows, possibly corrupting other variables or program code. This overflow does not affect the stack or carry flag, and the 8085 does not have unlimited memory, making option A the realistic consequence.

Q5. If the system uses isolated I/O instead of memory‑mapped I/O, which instruction in the program will fail to access the peripheral correctly?

A. LXI H,2100H
B. STAX D ✅
C. INX H
D. JNC NXT

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

In isolated I/O, peripheral devices are accessed with the IN and OUT instructions using port numbers, not through ordinary memory addresses. The program stores results with STAX D, which writes to the memory location pointed to by the D‑E pair. If the destination were intended to be an I/O port, STAX D would attempt a memory write and the peripheral would not receive the data. Hence the instruction that would fail under isolated I/O is the store operation, option B.

Q6. Why does the program use the sequence CMA followed by ADI 01H to obtain the 2's complement rather than using a single SUB instruction on the accumulator?

A. CMA+ADI sets the carry flag correctly for multi‑byte propagation ✅
B. SUB cannot complement a value
C. CMA+ADI is faster on 8085
D. SUB would require extra registers

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The sequence CMA followed by ADI 01H first produces the one’s complement and then adds one, which is the standard method for obtaining a two’s complement. Using SUB would require the accumulator to contain zero and subtract the original value, but this does not set the carry flag correctly for multi‑byte propagation. The chosen method ensures that the carry generated after adding one is captured and forwarded to the next byte via register B, making option A the accurate reason.

Q7. In the program, the source address is held in the H‑L pair while the destination address is held in the D‑E pair. How does this use of separate register pairs illustrate the concept of isolated I/O?

A. It shows that I/O and memory share the same address space
B. It demonstrates that separate address spaces can be accessed using different register pairs ✅
C. It indicates that only one register pair can be used for I/O
D. It proves that D‑E pair is reserved for I/O ports

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Isolated I/O separates the address spaces for memory and I/O devices. By keeping the source address in the H‑L pair and the destination address in the D‑E pair, the program demonstrates how two distinct address registers can be used to access different regions without mixing them. This mirrors the concept that I/O ports can be addressed independently from memory, which is why option B correctly describes the illustration of separate address spaces.

Q8. Which statement best explains why a designer might choose isolated I/O over I/O‑mapped I/O for a peripheral that requires slower access times on an 8085 system?

A. Isolated I/O uses dedicated IN/OUT instructions that can be timed independently of memory cycles ✅
B. I/O‑mapped I/O allows faster access, making it unsuitable for slow peripherals
C. Isolated I/O reduces the number of address lines needed, simplifying hardware
D. I/O‑mapped I/O cannot be used with 8085

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Isolated I/O uses dedicated IN and OUT instructions that operate on port numbers rather than memory addresses, allowing designers to control the timing of I/O cycles separately from memory cycles. For a peripheral that requires slower access, this separation lets the system insert wait states or slower clocking without affecting memory performance. Options B, C, and D contain inaccurate statements about speed or compatibility, while option A correctly explains the timing advantage of isolated I/O.

Q9. When computing the multi‑byte 2's complement, the program uses JNC to decide whether to set the carry flag in register B. What would be the effect of replacing JNC with JC?

A. Carry would be propagated opposite to the intended direction, producing an incorrect complement ✅
B. The program would run faster
C. No effect on the result
D. The program would enter an infinite loop

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The JNC instruction jumps when the carry flag is not set, meaning that a zero carry leads to a path where B is loaded with 00H. Replacing JNC with JC would cause the program to load B with 01H when there is **no** carry, reversing the intended propagation logic. This would add an unwanted carry to the next byte, producing an incorrect two’s complement result. Therefore, the effect described in option A accurately reflects the consequence of such a change.

Q10. What is the 8085 mnemonic for loading the immediate value 01H into register B?

A. MVI B,01H ✅
B. LXI B,01H
C. MOV B,01H
D. ADI 01H

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The 8085 instruction that loads an immediate 8‑bit constant into register B is the Move Immediate (MVI) mnemonic. The syntax is “MVI B, 01H”, which places the value 01H directly into B. LXI loads a register pair, MOV copies between registers, and ADI adds an immediate to the accumulator, none of which perform a direct immediate load into B. Hence option A is correct.
