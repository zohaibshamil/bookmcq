Q1. What does ALE stand for in the 8085 microprocessor?

🔹 A. Address Latch Enable
🔹 B. Accumulator Load Enable
🔹 C. Alternate Logic Enable
🔹 D. Automatic Line Enable

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The ALE signal is short for Address Latch Enable. It tells external hardware when the multiplexed AD lines contain a valid address, allowing an external latch to capture that address. Option A matches this definition. Options B, C, and D describe unrelated concepts; they do not correspond to ALE's purpose. Understanding ALE is essential because without it the processor cannot separate address and data, causing bus errors in real hardware designs.

Q2. Why is the ALE signal required when the 8085 operates in Mode 1?

🔹 A. Because it generates the clock signal
🔹 B. To select between opcode and operand
🔹 C. To indicate when AD lines carry a valid address
🔹 D. To enable the data bus driver

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

In Mode 1 the address and data share the same AD lines, so the processor must tell external circuitry when the lines hold an address. ALE goes high for one clock cycle at the end of the address phase, signaling the latch to store the address. Option C correctly describes this role. The other options either confuse clock generation, opcode selection, or data driving, none of which are ALE's function.

Q3. How does the IO/M control signal differentiate between a memory access and an I/O port access?

🔹 A. IO/M high selects memory, low selects I/O
🔹 B. IO/M low selects memory, high selects I/O
🔹 C. IO/M toggles every bus cycle
🔹 D. IO/M is not used for selection

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

IO/M is a binary indicator: when the line is low (\(0\)), the processor treats the address as a memory location; when it is high (\(1\)), the address is interpreted as an I/O port. Option B captures this behavior. Option A reverses the logic, while options C and D describe functions that IO/M does not perform. Recognizing this signal is critical for designing correct memory‑mapped or I/O‑mapped peripherals.

Q4. During a bus cycle, which pair of signals indicates that the processor is writing data to a peripheral?

🔹 A. \(\overline{RD}\) low and \(\overline{WR}\) high
🔹 B. \(\overline{RD}\) high and \(\overline{WR}\) low
🔹 C. Both \(\overline{RD}\) and \(\overline{WR}\) high
🔹 D. Both \(\overline{RD}\) and \(\overline{WR}\) low

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

When the 8085 writes, it asserts the write line (\(\overline{WR}\) goes low) while keeping the read line (\(\overline{RD}\)) high, so the correct combination is \(\overline{WR}\) low and \(\overline{RD}\) high, which corresponds to option D. Options A and B describe read or mixed conditions, and option C would leave both lines inactive, preventing any data transfer. This distinction is vital for ensuring that peripherals receive write commands correctly.

Q5. A designer needs to store the address of an I/O device on an external latch while using Mode 1. Which control signal should be connected to the latch’s enable input?

🔹 A. ALE
🔹 B. IO/M
🔹 C. \(\overline{RD}\)
🔹 D. \(\overline{WR}\)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

In Mode 1 the address appears on the AD lines during the first part of the bus cycle, and ALE goes high for one clock period to indicate that the address is valid. Connecting ALE to the latch’s enable input guarantees that the latch captures the address at the right moment. IO/M only distinguishes memory from I/O, while \(\overline{RD}\) and \(\overline{WR}\) relate to read/write operations, not address latching.

Q6. If the ALE line is inadvertently held low for three consecutive clock periods, what immediate effect will occur on address/data multiplexing?

🔹 A. The address will be latched twice
🔹 B. The data bus will be disabled
🔹 C. Address and data will be mixed, causing incorrect reads/writes
🔹 D. The processor will reset

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Keeping ALE low prevents the external latch from seeing the high pulse that signals a valid address. Consequently, the latch never captures the address, and the AD lines remain multiplexed, so the data bus cannot be driven correctly. Option B reflects this loss of proper data bus operation. Options A and C describe different timing issues, and option D is unrelated to ALE behavior.

Q7. Multiple 8‑bit I/O devices share the data bus. Which signal ensures that only the device with the matching address responds?

🔹 A. \(\overline{WR}\)
🔹 B. \(\overline{RD}\)
🔹 C. IO/M
🔹 D. ALE

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

When several devices share the bus, each device typically has an address decoder that watches the address lines and the ALE pulse. ALE indicates when the address is present on the AD lines, allowing the decoder to compare the address with its own. Only the device whose decoded address matches will enable its output. Therefore, ALE is the key signal, making option D correct. The other signals control read/write but do not perform address selection.

Q8. Given a timing diagram where \(\overline{RD}\) goes low at clock cycle 4 and \(\overline{WR}\) stays high, at which cycle is the data on the AD lines guaranteed to be valid for the CPU?

🔹 A. Cycle 3
🔹 B. Cycle 4
🔹 C. Cycle 5
🔹 D. Cycle 6

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

When \(\overline{RD}\) becomes active (low) at cycle 4, the address phase has already completed, and the data phase begins. The data becomes stable one clock after \(\overline{RD}\) is asserted, i.e., at cycle 5. Option C correctly identifies this timing. Cycle 3 is before the read, cycle 4 is the transition, and cycle 6 is later than necessary. Accurate timing ensures reliable data capture in real hardware.

Q9. To read a byte from I/O port \(0x30\) using Mode 1, which sequence of control signals is asserted by the 8085?

🔹 A. \(\overline{WR}\) low, ALE high, \(\overline{RD}\) high
🔹 B. ALE high, \(\overline{RD}\) low, \(\overline{WR}\) high
🔹 C. \(\overline{RD}\) low, ALE high, \(\overline{WR}\) high
🔹 D. \(\overline{WR}\) high, \(\overline{RD}\) low, ALE low

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Reading an I/O port requires the processor to place the address on AD lines, pulse ALE to latch it, keep \(\overline{WR}\) high (no write), and then assert \(\overline{RD}\) low to enable the peripheral to place data on the bus. Option B matches this order. Option A describes a write operation, option C misorders the signals, and option D lacks the ALE pulse, making them incorrect.

Q10. What is the result of asserting both \(\overline{RD}\) and \(\overline{WR}\) simultaneously during a bus cycle?

🔹 A. The bus enters an undefined state, potentially causing contention
🔹 B. The processor performs a combined read‑write operation
🔹 C. Only the read operation takes effect, write is ignored
🔹 D. Only the write operation takes effect, read is ignored

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Simultaneously pulling both active‑low signals low violates the 8085 protocol, leading to an undefined bus condition where multiple devices may try to drive the lines, causing contention and possible data corruption. Option A accurately describes this hazardous situation. The other options suggest defined behavior that the processor does not support; the 8085 never performs a combined read‑write in a single cycle.

Q11. A microcontroller requires a delayed write operation: after asserting \(\overline{WR}\) the data must be held for two extra clock cycles before being latched. Which additional external circuitry, used with Mode 1, can achieve this?

🔹 A. A flip‑flop triggered by \(\overline{WR}\)
🔹 B. An edge‑triggered monostable multivibrator tied to ALE
🔹 C. A two‑stage latch enabled by \(\overline{RD}\)
🔹 D. A programmable delay line controlled by IO/M

💡 Difficulty: hard | ✅ Correct: D

📖 Explanation:

A programmable delay line can be triggered by the IO/M or another control line and configured to extend the effective write window by two clock cycles, ensuring the peripheral receives the data for the required duration. Option D provides the flexibility needed. A simple flip‑flop (option A) would not create the needed delay, the monostable tied to ALE (option B) would affect address latching, and a latch enabled by \(\overline{RD}\) (option C) relates to read operations, not delayed writes.
