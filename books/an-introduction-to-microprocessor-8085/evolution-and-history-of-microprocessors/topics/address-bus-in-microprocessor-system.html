What is Address Bus in Microprocessor System?

The address bus is a unidirectional set of signal lines used by the microprocessor to specify the unique location of memory or I/O devices, where the total number of address lines \( n \) determines the maximum addressable memory space calculated as \( 2^n \) distinct locations, enabling the CPU to select specific registers or storage cells for read and write operations.

Q1. A microcontroller has a 16‑bit address bus. What is the maximum number of distinct memory locations it can address?

A. 8 KB
B. 65536 ✅
C. 32 KB
D. 4 KB

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The address bus carries binary numbers that identify memory cells. With 16 bits there are \(2^{16}=65,536\) possible binary patterns, each pattern points to one location. Therefore the processor can address up to 65,536 unique locations. Options A, C, and D correspond to fewer locations because they assume fewer bits; they are incorrect. In real hardware this means a 16‑bit bus can directly address 64 KB of memory, matching many small embedded designs.

Q2. Why does increasing the width of the address bus directly increase the addressable memory space?

A. It allows faster data transfer
B. It reduces power consumption
C. More bits mean more unique address combinations
D. It changes the CPU clock speed ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Each line in the address bus represents one binary digit of the address. Adding another line doubles the number of possible binary codes, so the total count of unique addresses grows from \(2^{n}\) to \(2^{n+1}\). This directly expands the memory range the processor can reach. Options A and B describe effects of the data bus and power design, not address capacity. Option D is unrelated because clock speed is independent of address width. In practice, a 24‑bit bus can address 16 MB, while a 32‑bit bus reaches 4 GB, illustrating the principle.

Q3. A system designer needs to connect a 1‑MB ROM to a processor with a 20‑bit address bus. Which statement is true?

A. The ROM requires a 10‑bit address bus ✅
B. The ROM cannot be accessed because 1‑MB exceeds 20‑bit limit
C. Only lower 10 bits are used
D. The 20‑bit bus can address up to 1,048,576 bytes, matching the ROM size

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

A 20‑bit address bus can generate \(2^{20}=1,048,576\) distinct addresses, which equals exactly 1 MB (since 1 MB = 1,048,576 bytes). Therefore the processor can fully address a 1‑MB ROM without any extra hardware. Option A is wrong because the ROM does not need a separate 10‑bit bus; it uses the existing 20 bits. Option B misinterprets the limit—20 bits are sufficient, not insufficient. Option C suggests only half the bits are used, which would limit the range to 1 KB, not 1 MB. In real designs, matching bus width to memory size ensures proper access.

Q4. What term describes the set of wires that carry the memory location identifier from the CPU to memory?

A. Address bus
B. Data bus ✅
C. Control bus
D. Status bus

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The address bus is the dedicated group of conductors that transmit the binary address of the memory cell the CPU wants to read or write. It does not carry actual data, only the location identifier. The data bus (option B) moves the payload, while the control bus (option C) carries signals like read/write and clock. Option D, a status bus, is not a standard term in typical architectures. Understanding the address bus role is essential when designing memory maps for any computer system.

Q5. A microprocessor with a 24‑bit address bus is being used in a system where two separate memory modules, each 8 MB, need to be mapped without overlap. Which of the following address ranges correctly maps both modules?

A. Module 1: 0x000000–0x7FFFFF, Module 2: 0x800000–0xFFFFFF
B. Module 1: 0x000000–0x3FFFFF, Module 2: 0x400000–0x7FFFFF ✅
C. Module 1: 0x000000–0x00FFFF, Module 2: 0x010000–0x01FFFF
D. Module 1: 0x000000–0xFFFFFF, Module 2: 0x1000000–0x1FFFFFF

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A 24‑bit address bus can generate \(2^{24}=16,777,216\) distinct addresses, which equals 16 MB of address space. To place two 8 MB modules without overlap, each must occupy exactly half of that space. The range 0x000000–0x7FFFFF covers the first 8 MB, and 0x800000–0xFFFFFF covers the second 8 MB, together using the full 16 MB range. Option B only maps 4 MB each, leaving unused space; Option C maps only 1 KB each, far too small; Option D exceeds the 24‑bit limit, requiring a 25‑bit address. Therefore option A correctly maps both modules without conflict.

Q6. How does the width of the address bus affect the design of memory decoding circuitry in a computer system?

A. Wider buses eliminate the need for decoders ✅
B. Wider buses increase the number of decoder lines required
C. Bus width determines the voltage level of decoders
D. Decoder complexity is independent of bus width

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The address bus width tells how many address bits the CPU can output, and each bit must be fed to the memory decoder. When the bus widens, the decoder needs more input lines to differentiate the larger set of possible addresses. For example, moving from a 16‑bit to a 24‑bit bus adds eight extra decoder inputs. Option A is false because decoders are still required; option C mixes voltage with logical width; option D ignores the direct link between address bits and decoder complexity. Designers therefore size the decoder to match the bus width to guarantee correct memory selection.

Q7. In a DMA (Direct Memory Access) transfer, the peripheral device must place the target address on the address bus. If the system uses a 32‑bit address bus but the peripheral only provides a 24‑bit address, what is the most common method to handle this mismatch?

A. The peripheral pads the upper bits with zeros
B. The system ignores the lower 8 bits ✅
C. The CPU expands the address using a lookup table
D. The transfer cannot occur at all

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When a peripheral supplies only 24 address bits to a system that uses a 32‑bit address bus, the common practice is to extend the missing upper bits with zeros, effectively placing the peripheral in the lower 16 MB of the address space. This method preserves the intended address while keeping the bus protocol consistent. Option B would discard useful information, option C adds unnecessary complexity, and option D needlessly restricts system capability. In many real designs, zero‑padding allows legacy devices to operate on wider buses without hardware redesign.
