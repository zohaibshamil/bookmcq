What is Control Bus in Microprocessor System?

The control bus comprises various individual signal lines that manage the timing and coordination of system activities by carrying commands like read, write, and interrupt requests from the microprocessor to other components, ensuring that data transfer occurs synchronously and that all hardware modules operate in the correct sequence during instruction execution.

Q1. A designer connects a microprocessor to RAM and needs to ensure the processor can signal a read operation. Which control bus line must be asserted to initiate the read cycle?

A. Write Enable
B. Read Enable ✅
C. Address Latch
D. Data Strobe

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The read operation is started by asserting the Read Enable line on the control bus. Write Enable is used for write cycles, Address Latch holds the address, and Data Strobe indicates data transfer timing. By using Read Enable, the processor tells memory to place the requested data on the data bus. This matches the typical control‑bus protocol, so B is correct while the others describe different signals.

Q2. In a system where the microprocessor shares the data bus with an I/O device, a designer must prevent bus contention during a write operation. Which combination of control‑bus signals should be used to safely allow the processor to write data while keeping the I/O device from driving the bus?

A. Assert Read Enable and De‑assert Write Enable
B. De‑assert Read Enable and Assert Write Enable ✅
C. Assert both Read Enable and Write Enable
D. De‑assert both Read Enable and Write Enable

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

During a write, the processor must drive the data bus while the I/O device remains high‑impedance. De‑asserting Read Enable ensures the I/O device does not try to place data on the bus, and asserting Write Enable tells memory or peripherals that a write is occurring. The other options either keep the I/O device active or disable the write altogether, leading to contention or no data transfer.

Q3. A microcontroller is programmed to toggle an LED each time it receives an external interrupt. Which control‑bus line is typically used to acknowledge the interrupt after the CPU has started servicing it?

A. Interrupt Acknowledge ✅
B. Reset
C. Clock
D. Chip Select

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When an interrupt is serviced, the CPU sends an Interrupt Acknowledge signal on the control bus to inform the interrupting device that the interrupt has been recognized and processing is underway. Reset forces a full system restart, Clock provides timing, and Chip Select selects a particular peripheral. Therefore, the correct line for acknowledging the interrupt is the Interrupt Acknowledge signal, making option A correct.

Q4. When designing a multiprocessor system, the architects decide to use a single control bus to distribute clock and reset signals to all CPUs. If a CPU fails to start, which control‑bus signal is most likely being incorrectly generated?

A. Chip Select
B. Read Enable
C. Reset ✅
D. Write Enable

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

A CPU that does not start is often held in a reset state. The Reset line on the control bus forces the processor into a known initial condition; if it is not asserted correctly, the CPU will remain inactive. Chip Select chooses a device, Read Enable and Write Enable control data transfers, none of which directly start a processor. Hence, the Reset signal is the most probable culprit.

Q5. What primary purpose does the control bus serve in a microprocessor system?

A. Transfer program instructions
B. Carry data values
C. Convey timing and command signals ✅
D. Store permanent data

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The control bus does not move data or addresses; instead, it carries timing, command, and status signals such as read/write, interrupt, and reset. These signals coordinate the actions of the CPU, memory, and I/O devices, ensuring that operations occur in the correct order. Options A and B describe the data and address buses, while D refers to storage, leaving option C as the correct description.

Q6. How does the control bus interact with the address bus to ensure that the correct memory location is accessed during a read cycle?

A. It provides the address bits
B. It signals the memory to place data on the data bus after the address is stable ✅
C. It carries the data itself
D. It resets the address lines

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

First the address bus carries the desired memory address to the memory module. Once the address is stable, the control bus asserts the Read Enable signal, telling the memory that a read is requested. The memory then places the data onto the data bus. The control bus does not supply address bits, carry data, or reset the address lines, so option B correctly describes the coordination.

Q7. Which of the following is NOT a typical line found on a control bus?

A. Interrupt Request
B. Power Supply ✅
C. Read Enable
D. Write Enable

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

Control‑bus lines include signals that manage operations, such as Interrupt Request, Read Enable, and Write Enable. Power Supply is not a control signal; it is provided by the power distribution network, not the control bus. Therefore, option B is the only choice that does not belong to the set of standard control‑bus lines.
