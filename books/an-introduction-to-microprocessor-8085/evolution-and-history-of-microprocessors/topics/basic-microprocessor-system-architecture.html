📝 All Basic microprocessor system architecture MCQs

Q1. Which component directly supplies data and instructions to the memory of a microcomputer?

🔹 A. Input Unit
🔹 B. Memory Unit
🔹 C. Control Unit
🔹 D. Output Unit

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The Input Unit captures user commands and program code from devices such as keyboards or sensors and forwards them to memory, so the processor can fetch and execute them. The Memory Unit stores data but does not provide new input, the Control Unit orchestrates operations, and the Output Unit sends results outward. In a real system, without the Input Unit the computer would have nothing to process.

Q2. A designer needs to choose between ROM and RAM for storing a program that must be retained after power loss. Which memory type should be used?

🔹 A. ROM
🔹 B. RAM
🔹 C. Cache
🔹 D. Register

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

ROM retains its contents without power, making it the proper choice for programs that must survive power cycles. RAM loses data when power is removed, so it cannot guarantee persistence. Cache is a fast temporary storage that also loses data, and a register holds only a few bytes inside the CPU. In embedded devices, ROM ensures the firmware is always available.

Q3. Why is the Input Unit essential for the execution of a program in a microprocessor system?

🔹 A. It provides power
🔹 B. It stores results
🔹 C. It feeds data and instructions
🔹 D. It controls timing

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The Input Unit delivers external data and program instructions to memory, enabling the processor to fetch and act on them. Power is supplied by the power supply, results are stored in memory, and timing signals come from the control unit. Without the Input Unit, the system would have no new information to process, so no program could start.

Q4. In a simple microcontroller, a switch is connected to an input pin that triggers an LED. Which block of the microprocessor system processes the switch signal first?

🔹 A. Output Unit
🔹 B. Input Unit
🔹 C. Memory Unit
🔹 D. Arithmetic Logic Unit

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When the switch closes, the voltage change is detected by the Input Unit, which converts the physical action into a digital signal for the processor. The Output Unit only drives the LED after processing, the Memory Unit stores data but does not sense signals, and the ALU performs calculations, not signal acquisition. Real devices rely on the Input Unit to capture user actions.

Q5. What does the acronym ROM stand for?

🔹 A. Read Only Memory
🔹 B. Random Operating Machine
🔹 C. Readable Output Module
🔹 D. Rapid Object Memory

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

ROM means Read Only Memory, a type of storage that can be read but not written during normal operation, ensuring firmware remains unchanged. The other options are fabricated terms; RAM stands for Random Access Memory, not Random Operating Machine, and none of the other phrases describe actual computer components. Knowing the correct expansion helps identify where permanent code resides.

Q6. How does the Memory Unit differentiate between storing program code and storing user data?

🔹 A. By using separate chips
🔹 B. By using different address ranges
🔹 C. By encrypting data
🔹 D. By varying voltage levels

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Memory controllers assign distinct address ranges for code and data, allowing the processor to fetch instructions from one region and manipulate variables in another. Separate chips are sometimes used but not required; encryption is a security feature, not a basic distinction; voltage levels do not encode type. In practice, address mapping lets the system keep code and data organized.

Q7. A microprocessor needs to perform the calculation \(5 + 3\) and then display the result. Which block performs the arithmetic operation?

🔹 A. Input Unit
🔹 B. Memory Unit
🔹 C. Arithmetic Logic Unit
🔹 D. Control Unit

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The Arithmetic Logic Unit (ALU) carries out addition, subtraction, and other logical operations, so it computes \(5 + 3\). The Input Unit gathers external data, the Memory Unit stores values, and the Control Unit directs the sequence of actions. In a calculator, the ALU is the part that actually adds the numbers before the result is sent to the display.
