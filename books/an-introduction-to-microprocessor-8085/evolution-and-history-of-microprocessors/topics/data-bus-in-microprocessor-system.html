Q1. What is the primary function of a data bus in a microprocessor system?

🔹 A. Transfer data between the CPU, memory, and I/O devices
🔹 B. Provide timing and control signals for synchronization
🔹 C. Store program code and constants
🔹 D. Select memory addresses for read/write operations

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The data bus’s main role is to move binary information among the processor, memory, and peripheral components. Option A describes this movement directly, making it correct. Option B confuses the data bus with the control bus, which carries timing signals. Option C refers to storage, which is the job of memory, not the bus. Option D describes the address bus’s purpose. Understanding the data bus clarifies how a computer actually exchanges the values it processes.

Q2. How does increasing the width of a data bus affect the data transfer rate of a microprocessor?

🔹 A. It allows more bits to be transferred each clock cycle, raising overall bandwidth
🔹 B. It reduces the clock frequency required for the same throughput
🔹 C. It changes the voltage levels needed for signaling
🔹 D. It increases the number of addressable memory locations

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Widening the bus adds parallel lines, so each clock tick can carry a larger chunk of data. This directly boosts the bandwidth, which is the product of bus width and clock frequency. Option A captures this effect. Option B is incorrect because bus width does not dictate clock speed; a narrower bus could still run fast. Option C mixes electrical characteristics with logical width, and Option D confuses address space with data width. Recognizing this relationship helps designers choose appropriate bus sizes for performance goals.

Q3. A CPU must read a 32‑bit word from memory, but the system’s data bus is only 8 bits wide. Which technique will the processor most likely use to obtain the full word?

🔹 A. Serial transmission of the 32‑bit word over the 8‑bit bus
🔹 B. Parallel burst transfer, reading four consecutive 8‑bit cycles
🔹 C. Pipelined transfer that overlaps address and data phases
🔹 D. Direct Memory Access (DMA) to bypass the CPU

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

With an 8‑bit bus, the processor cannot receive the whole 32‑bit word in one cycle. Instead, it performs a burst read, fetching the first 8 bits, then the next three groups in successive cycles, reassembling the full word internally. This is the standard parallel burst approach. Option A describes a serial method, which is slower and not typical for parallel buses. Option C implies overlapping phases, which still requires multiple cycles for a wider word. Option D delegates the transfer to a DMA controller, which does not solve the width limitation for the CPU’s immediate read.

Q4. A system uses a 16‑bit data bus to transfer a contiguous 64 KB block of data from memory to a peripheral. How many bus cycles are required to move the entire block, assuming each cycle transfers the full bus width?

🔹 A. 16,384 cycles
🔹 B. 32,768 cycles
🔹 C. 65,536 cycles
🔹 D. 128,000 cycles

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

A 16‑bit bus moves 2 bytes per cycle. The total data size is 64 KB, which equals 65,536 bytes. Dividing the total bytes by the bytes per cycle gives 65,536 / 2 = 32,768 cycles. Option B matches this calculation. Option A would be correct for an 8‑bit bus, Option C would double‑count the cycles, and Option D vastly overestimates them. Knowing how bus width translates to bytes per transfer is essential for estimating transfer time and designing efficient DMA or burst operations.

Q5. Which statement best describes the relationship between the address bus and the data bus in a typical microprocessor architecture?

🔹 A. The address bus carries memory locations while the data bus carries the actual data; both operate simultaneously on separate lines
🔹 B. The address bus and data bus are combined into a single set of lines that alternate between address and data signals
🔹 C. The address bus determines the speed of the data bus, so a wider address bus always means a faster data bus
🔹 D. The data bus is only used during write operations, whereas the address bus is used for both reads and writes

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

In most designs, the address bus presents the location to be accessed, and the data bus conveys the value to be read or written, with both buses active at the same time but on distinct pins. This separation enables independent addressing and data movement. Option A correctly captures that dual‑line operation. Option B describes a multiplexed bus, which is a special case not typical for standard microprocessors. Option C incorrectly links width to speed, and Option D misstates the role of the data bus, which is essential for both reads and writes. Understanding this division helps engineers troubleshoot timing and pin‑count issues.

Q6. Two peripherals share a common data bus, and one device asserts a bus‑request signal to gain control. Which arbitration method most commonly resolves such contention in simple microcontroller systems?

🔹 A. Daisy‑chaining priority where the first device in the chain wins
🔹 B. Centralized controller that polls each device sequentially
🔹 C. Round‑robin scheduling that rotates access equally among devices
🔹 D. Token‑passing where a special token circulates to grant bus rights

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Daisy‑chaining is a straightforward hardware technique where each device passes the request line to the next; the first device in the chain that asserts the request gains control, providing a deterministic priority without complex logic. Option A reflects this method. Option B would require additional logic not typical in simple systems. Option C implies software‑managed fairness, which is more complex. Option D describes a network‑style token protocol, rarely used in basic microcontroller bus arbitration. Recognizing daisy‑chain arbitration helps in designing reliable shared‑bus architectures.

Q7. If a data bus operates at 100 MHz and is 32 bits wide, what is the theoretical maximum data throughput expressed in megabytes per second (MB/s)?

🔹 A. 200 MB/s
🔹 B. 400 MB/s
🔹 C. 800 MB/s
🔹 D. 1.6 GB/s

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Throughput equals frequency times bus width: 100 MHz × 32 bits = 3.2 × 10⁹ bits/s. Converting bits to bytes (divide by 8) yields 400 × 10⁶ bytes/s, or 400 MB/s. Option B matches this calculation. Option A would be half the correct value, Option C doubles it, and Option D further doubles again, reflecting common mis‑conversions. Accurately converting frequency and width to bandwidth is crucial when evaluating system performance or comparing bus technologies.
