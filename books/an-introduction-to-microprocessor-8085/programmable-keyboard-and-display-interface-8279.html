📖 Programmable Keyboard and Display Interface: 8279

Chapter Overview:

The Intel 8279 is a programmable keyboard and display controller designed to simplify communication between an 8085 microprocessor and human-operated input and output devices. Its architecture integrates keyboard scanning, automatic key debouncing, FIFO buffering, display scanning, and display RAM management. Different operating modes accommodate simultaneous key presses, sensor matrices, strobed inputs, and alternative display-entry arrangements. Its command structure provides software control over scanning, timing, memory access, and interrupt handling, while 8085 interfacing connects these functions to assembly-language applications.

Prerequisites:

Students should understand 8085 input/output instructions, isolated I/O addressing, address decoding, data bus communication, and peripheral interfacing. Familiarity with hexadecimal values, binary control words, multiplexed displays, matrix keyboards, scanning signals, FIFO organization, and interrupt requests is important. Basic knowledge of 8253 programmable timing, memory read/write operations, and assembly-language programming will help students understand controller configuration and communication with external devices.

Learning Objectives:

Students should be able to explain the internal architecture and functional organization of the 8279, describe keyboard scanning and debouncing, distinguish two-key lockout from N-key rollover, explain scanned sensor matrix and strobed input operations, compare left-entry and right-entry display modes, interpret keyboard/display mode and program clock commands, perform FIFO, sensor RAM, and display RAM operations, explain display write inhibition and blanking, interpret status register information, describe end interrupt/error mode control, explain the relationship between the 8279 and 8253, and demonstrate interfacing with the 8085.

Topics Covered:

  • Intel 8279 and Functional Block Diagram - Examines keyboard, scan, display, CPU interface, FIFO, and internal RAM organization.
  • Keyboard Scanning and Input Modes - Covers scanned keyboards, two-key lockout, N-key rollover, sensor matrices, and strobed input.
  • Display Interface and Display Modes - Explains multiplexed display operation, left-entry typewriter mode, and right-entry calculator mode.
  • 8279 Programming and Command Structure - Covers mode selection, program clock, FIFO access, sensor RAM, and display RAM.
  • 8253 Programmable Timer/Counter - Introduces programmable timing and event counting in interconnected microprocessor systems.

  • Interfacing 8279 with 8085 - Connects controller registers, I/O addresses, processor instructions, and peripheral communication.

Chapter Learning Path:

Begin with the 8279 block diagram and functional organization to identify its keyboard, scanning, display, and processor-interface sections. Study keyboard scanning before examining two-key lockout, N-key rollover, sensor matrix, and strobed input operations. Progress to display organization and compare left-entry and right-entry arrangements. Next, learn the command structure, beginning with keyboard/display mode selection and programmable clock configuration. Study FIFO and RAM access, display control, and the associated 8253 timer. Finish with status-register interpretation, interrupt/error control, and practical interfacing with the 8085.

How the Topics Connect:

The block diagram establishes how the keyboard, scanning, display, and processor-interface sections cooperate. Keyboard operating modes determine how pressed keys and sensor changes are recognized, while FIFO and sensor RAM preserve input information for processor access. Display modes determine how characters are organized and refreshed. Programming commands configure these operations, and status information reports controller conditions. Interrupt/error commands manage servicing, while 8085 interfacing connects the complete input and display process to processor software.

End-to-End Flow:

Consider an 8085 system using I/O address 80H for 8279 data and 81H for commands and status. With a 2 MHz clock input, the processor writes 34H to command port 81H to select a divide-by-20 prescaler, producing a 100 kHz internal timing frequency. The controller scans a matrix keyboard in N-key rollover mode. When a user presses the key 5, its scanned position enters the FIFO and IRQ signals the processor. Software reads the FIFO, identifies the character, selects its display pattern, and writes it into display RAM for automatic scanning.

Why This Chapter Matters:

Keyboard scanning and display refreshing require continuous coordination that would otherwise consume substantial processor attention. The 8279 handles these activities through dedicated scanning, buffering, and display-control hardware. Understanding its programming commands and status mechanisms is essential for designing interactive microprocessor systems involving keyboards, numeric displays, sensors, and external input devices.

Common Confusions Across Topics:

'Two-key lockout and N-key rollover recognize simultaneous keys identically' is incorrect because they use different policies for handling multiple key presses. 'Left-entry and right-entry modes change the keyboard scanning direction' is incorrect because they control display data entry positions. 'FIFO RAM and display RAM store the same information' is incorrect because FIFO handles keyboard or sensor input, whereas display RAM stores display data. The separate 8253 timer is not an internal section of the 8279.

Exam Focus Areas:

Frequently tested problems involve interpreting the 8279 block diagram, identifying keyboard scan modes, comparing two-key lockout with N-key rollover, and analyzing sensor and strobed input operations. Students should construct and interpret hexadecimal command words, calculate clock prescaler values, trace FIFO and display RAM access, distinguish left-entry and right-entry behavior, interpret status bits, and explain interrupt/error handling. Interfacing questions commonly examine I/O addresses, control signals, and processor instructions.

Chapter Summary:

The 8279 integrates keyboard input processing and display management into a programmable peripheral controller. Its scanning mechanisms recognize key presses and sensor changes, while FIFO buffering makes input information available to the processor. Display RAM and programmable entry modes organize output presentation. Command words configure operating behavior, clock timing, and memory access, while status and interrupt mechanisms coordinate servicing. Interfacing connects these capabilities with 8085-based applications.

Key Terms:

  • 8279 PPI - A programmable keyboard and display interface for microprocessor-based systems.
  • Two-Key Lockout - A keyboard operating method that prevents multiple simultaneously detected key presses from being independently accepted.
  • N-Key Rollover - A keyboard operating method that recognizes multiple key presses and records their corresponding codes.
  • FIFO - First In First Out storage that preserves keyboard or sensor entries in arrival order.
  • Sensor RAM - Internal memory that records the states of switches in a scanned sensor matrix.
  • Display RAM - Internal memory that stores character or segment data for display output.
  • Program Clock - A programmable prescaler configuration that determines the internal timing frequency of the 8279.
  • IRQ - An interrupt request signal used by the 8279 to notify the processor of conditions requiring service.
