B. To ensure previous data does not affect the result ✅
C. To speed up execution
D. To reset the program counter

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Clearing the accumulator ensures that the first AND operation starts with a known value (all ones after XRA A), preventing residual bits from previous computations from influencing the outcome. Option B correctly explains. Option A is unrelated. Option C is not a significant factor. Option D is unrelated to accumulator state. Proper initialization is key for reliable bitwise logic.

Q47. A firmware update requires writing a constant pattern 0xAA to 50 consecutive memory locations starting at 3000H. Which loop construct efficiently accomplishes this?

A. MVI B,32, LXI H,3000H, LOOP: MVI A,AAH, MOV M,A, INX H, DCR B, JNZ LOOP
B. MVI B,50, LXI H,3000H, LOOP: MVI A,AAH, STAX H, INX H, DCR B, JNZ LOOP ✅
C. MVI B,50, LXI H,3000H, LOOP: MOV A,B, STA 3000H, INX H, DCR B, JNZ LOOP
D. MVI B,32, LXI H,3000H, LOOP: MVI A,AAH, STA 3000H, INX H, DCR B, JNZ LOOP

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Option B sets a counter of 50 (0x32) and uses MVI A,AAH to load the pattern, then STAX H to store it at the address pointed by HL, incrementing HL each iteration. Option A incorrectly uses 32 as counter. Option C misuses MOV A,B and stores at fixed address. Option D repeats the same error. Efficient looping is essential for bulk memory initialization in firmware.
