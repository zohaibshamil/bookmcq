Q1. A student needs to divide the 8‑bit value 0x96 (150 decimal) by 0x05 using an 8085 routine that expects the dividend in the accumulator and the divisor in register B. Which of the following instruction sequences correctly prepares the registers before calling the subroutine DIV8?

🔹 A. MVI A,96H; MVI B,05H; CALL DIV8
🔹 B. MVI B,96H; MVI A,05H; CALL DIV8
🔹 C. MVI A,05H; MVI B,96H; CALL DIV8
🔹 D. MVI A,96H; MVI C,05H; CALL DIV8

💡 Difficulty: easy | ✅ Correct: A

Q2. Memory location 3000H holds the dividend and 3001H holds the divisor. Which code fragment correctly computes the 8‑bit quotient and stores it at 3002H while storing the remainder at 3003H using a repeated‑subtraction routine?

🔹 A. LDA 3000H; MOV B,A; LDA 3001H; MOV C,A; CALL DIV8; STA 3002H; MOV A,B; STA 3003H
🔹 B. LDA 3000H; MOV B,A; LDA 3001H; MOV C,A; CALL DIV8; STA 3002H; MOV A,C; STA 3003H
🔹 C. LDA 3000H; MOV B,A; LDA 3001H; MOV C,A; CALL DIV8; MOV A,B; STA 3002H; MOV A,C; STA 3003H
🔹 D. LDA 3000H; MOV B,A; LDA 3001H; MOV C,A; CALL DIV8; STA 3002H; MOV A,B; STA 3003H

💡 Difficulty: medium | ✅ Correct: D

Q3. To divide two signed 8‑bit numbers using two’s complement on the 8085, which sequence correctly handles sign conversion and restores the correct sign of the quotient?

🔹 A. 1. Load dividend into A; if negative, CMA+INR and set sign flag. 2. Load divisor into B; if negative, CMA+INR and toggle sign flag. 3. CALL DIV8 (unsigned). 4. If sign flag set, CMA+INR on A.
🔹 B. 1. Load dividend into A; if negative, DAA. 2. Load divisor into B; if negative, DAA. 3. CALL DIV8. 4. No further steps needed.
🔹 C. 1. Load dividend into A; CALL DIV8; then CMA+INR on A if dividend was negative.
🔹 D. 1. Load dividend into A; if negative, CMA+INR. 2. Load divisor into B; CALL DIV8. 3. If divisor was negative, CMA+INR on A.

💡 Difficulty: hard | ✅ Correct: A
