What is Arithmetic Group of Instructions of SAP-III Computer?

The arithmetic group of SAP-III instructions performs mathematical operations on 8-bit data in the accumulator A A A, including addition via ADD  R ADD \; R ADDR which computes A←A+R A \leftarrow A + R A←A+R, subtraction via SUB  R SUB \; R SUBR which computes A←A−R A \leftarrow A - R A←A−R, and increment/decrement operations that modify register values while updating status flags accordingly.

Knowing the exact opcode is essential for assembling correct machine code, and it reflects the design choice of using a 4‑bit field to keep the instruction format compact for an 8‑bit processor.

Understanding the word length is crucial for memory alignment and for developers to calculate program size accurately.
