Q1. What is the maximum number of bytes that can be transferred in a single DMA operation using the 8257 controller?

🔹 A. 8 KB
🔹 B. 16 KB
🔹 C. 32 KB
🔹 D. 64 KB

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The 8257 uses a 14‑bit field in the terminal count register to hold the transfer size, allowing values from 0 up to \(2^{14}-1 = 16383\). Because the count represents bytes, the highest practical transfer is 16 KB (16 384 bytes) when the controller is programmed to use the full range. Option B reflects this limit. The other choices either exceed the register capacity or are too small, making them incorrect.

Q2. Which bits of the 16‑bit terminal count register are used to store the operation code that selects read or write mode?

🔹 A. Bits 15‑14
🔹 B. Bits 13‑12
🔹 C. Bits 7‑6
🔹 D. Bits 1‑0

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

The two most significant bits of the terminal count register (bits 15 and 14) are reserved for the operation code, indicating whether the DMA channel will perform a read or a write. This design lets the controller quickly determine the transfer direction. Bits 13‑12, 7‑6, and 1‑0 are used for other purposes such as the actual count, so they do not define the mode.

Q3. A system programmer configures a DMA channel to move 20 000 bytes. Will the 8257 accept this transfer without processor intervention?

🔹 A. Yes, because 20 000 < 16 384
🔹 B. No, because 20 000 > 16 384
🔹 C. Yes, because the controller can auto‑extend the count
🔹 D. No, because only the lower 8 bits are used

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The terminal count register can store only 14 bits for the byte count, giving a maximum of \(2^{14}=16 384\) bytes. Since 20 000 bytes exceeds this limit, the controller cannot complete the transfer on its own and would require the CPU to intervene or split the transfer. Therefore option B is correct; the other statements either misinterpret the limit or ignore the register size.

Q4. What role does the HRQ (HOLD Request) pin play in coordinating DMA with the CPU?

🔹 A. It signals the CPU to pause and grant bus control
🔹 B. It resets the DMA controller
🔹 C. It acknowledges data receipt
🔹 D. It selects the DMA channel

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

HRQ is asserted by the DMA controller when it needs control of the system bus. The CPU, upon seeing HRQ, must complete any current bus cycles, place the bus in a high‑impedance state, and wait for the HLDA (HOLD Acknowledge) signal. This handshake ensures that the DMA transfer can proceed without contention. Resetting the controller, acknowledging data, or selecting a channel are unrelated functions, making the other options incorrect.

Q5. In a configuration where Channel 2 is assigned to a disk drive, the address register holds 0x1A00 and the terminal count register holds 0x0C00. How many bytes will be transferred before the terminal count is reached?

🔹 A. 3072 bytes
🔹 B. 4096 bytes
🔹 C. 5120 bytes
🔹 D. 6144 bytes

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The terminal count register stores the byte count in its lower 14 bits. Hexadecimal 0x0C00 equals \(0x0C00_{16}=3072_{10}\) bytes. The DMA controller decrements this count each byte transferred until it reaches zero, signalling completion. Therefore the transfer length is 3072 bytes, matching option A. The other numeric options arise from mis‑reading the hex value or adding extra bytes that are not represented in the register.

Q6. How does the DACK (DMA Acknowledge) signal interact with the IOR and IOW lines during a read operation?

🔹 A. DACK asserts IOR low to indicate a read
🔹 B. DACK asserts IOW low to indicate a write
🔹 C. DACK simultaneously asserts both IOR and IOW
🔹 D. DACK does not affect IOR or IOW

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

During a read cycle, the DMA controller asserts DACK to inform the peripheral that it is the current bus master. At the same time, the IOR (I/O Read) line is driven low to indicate that a read transaction is occurring. IOW remains high because no write is taking place. Hence option A correctly describes the coordination. Options B and C describe write‑related behavior, and D is inaccurate because DACK does influence the I/O control lines.

Q7. A microprocessor issues a HOLD request while a DMA transfer is in progress. If the DMA controller asserts HLDA, what should the CPU do next?

🔹 A. Continue executing instructions
🔹 B. Stop bus cycles and wait for HLDA to be de‑asserted
🔹 C. Immediately release the bus
🔹 D. Reset the DMA controller

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When the DMA controller drives HLDA high, it is granting the bus to the DMA engine. The CPU must cease any further bus activity and wait until HLDA is de‑asserted before resuming normal operation. Continuing execution (option A) would cause bus contention, while immediately releasing the bus (option C) is redundant because HLDA already indicates control transfer. Resetting the DMA controller (option D) is unnecessary and would abort the transfer.

Q8. Why does the 8257 include a separate Mode Set Register for each channel?

🔹 A. To allow independent configuration of transfer type and address increment
🔹 B. To store the data being transferred
🔹 C. To generate interrupts
🔹 D. To provide power management

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Each DMA channel can operate in a different mode—such as demand, single, block, or cascade—and may require distinct address increment or decrement behavior. The Mode Set Register holds these per‑channel settings, enabling the controller to manage multiple devices with differing requirements simultaneously. Storing actual data, generating interrupts, or handling power are not functions of the Mode Set Register, so the remaining choices are incorrect.

Q9. A system uses channel 0 for a printer that requires block transfers of 256 bytes. The programmer loads the terminal count register with 0x0100. After the transfer completes, which pin indicates that the count has reached zero?

🔹 A. TC (Terminal Count)
🔹 B. HRQ
🔹 C. READY
🔹 D. MARK

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

When the terminal count register decrements to zero, the 8257 asserts the TC (Terminal Count) pin to signal that the programmed byte count has been exhausted. This pin can be used to trigger an interrupt or to start a new operation. HRQ relates to bus arbitration, READY indicates peripheral readiness, and MARK is used for modulo addressing, none of which directly indicate count exhaustion.

Q10. What is the effect of setting the MARK pin high while the DMA controller is operating in auto‑initialize mode?

🔹 A. It disables further DMA requests
🔹 B. It forces the address register to reload the initial value
🔹 C. It clears the terminal count register
🔹 D. It generates an interrupt

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When MARK is asserted, the controller interprets it as a signal to reload the address registers with the values stored in the base registers during auto‑initialize. This allows continuous circular transfers without CPU intervention. The other options describe functions that are not associated with MARK: disabling requests, clearing counts, or generating interrupts are handled by different pins or registers.

Q11. A designer connects DRQ3 to a peripheral that generates requests at irregular intervals. Which pin must be monitored by the CPU to know when the DMA controller has finished the current transfer?

🔹 A. TC
🔹 B. READY
🔹 C. HRQ
🔹 D. RESET

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The TC (Terminal Count) pin goes active when the DMA channel’s count reaches zero, indicating that the programmed transfer has completed. Monitoring TC lets the CPU determine when the bus is again available or when it should prepare for the next operation. READY signals peripheral status, HRQ is used for bus arbitration, and RESET merely initializes the controller, so they do not directly convey transfer completion.

Q12. Explain how the combination of AEN (Address Enable) and ADSTB (Address Strobe) pins allows the 8257 to perform address multiplexing on the system bus.

🔹 A. They enable simultaneous data and address transfer
🔹 B. AEN disables address lines while ADSTB provides timing for address latch
🔹 C. AEN provides clock and ADSTB provides reset
🔹 D. They are unrelated signals

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

AEN is asserted when the DMA controller wants to place an address on the bus, temporarily disabling other address drivers. ADSTB then generates a strobe that tells the system to latch the presented address. This coordinated action lets the controller share the same physical lines for both address and data, reducing pin count. The other statements mischaracterize the pins’ functions or claim no relationship, which is inaccurate.

Q13. A system requires a DMA transfer of exactly 16 384 bytes from memory to an I/O device. The programmer sets the terminal count register to its maximum value. Which two most significant bits of the register must be cleared to indicate a write operation, and what is the hexadecimal value written to the register?

🔹 A. Bits 15‑14 = 00, value 0x3FFF
🔹 B. Bits 15‑14 = 01, value 0x7FFF
🔹 C. Bits 15‑14 = 10, value 0xBFFF
🔹 D. Bits 15‑14 = 11, value 0xFFFF

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The terminal count register uses bits 15‑14 for the operation code; clearing them (00) selects a write operation. The remaining 14 bits hold the byte count, and the largest value they can represent is \(2^{14}-1 = 16383\) decimal, which is 0x3FFF in hexadecimal. Therefore the correct combination is 00 for the mode bits and 0x3FFF for the count, matching option A. The other options either set the mode bits incorrectly or exceed the 14‑bit count limit.

Q14. During a DMA operation, the CPU reads the status word register and sees the bits pattern 0b0101 0010. Interpreting this pattern, which of the following statements is true?

🔹 A. Channel 1 is active and Terminal Count has not been reached
🔹 B. Channel 2 has encountered an error
🔹 C. All channels are idle
🔹 D. Channel 0 has completed its transfer

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

In the 8257 status word, bits 7‑4 indicate which channel is currently active, and bit 2 (TC) signals whether the terminal count has been reached. The pattern 0101 0010 shows bit 6 (channel 1 flag) set while the TC bit (bit 2) is low, meaning the channel is active and the count is still pending. Hence option A correctly describes the situation. The other statements either misread the bit fields or assume error flags that are not present in this pattern.

Q15. Why does the 8257 require both a separate Data Bus Buffer and a Read/Write Logic block instead of using a single bidirectional buffer?

🔹 A. To reduce propagation delay
🔹 B. To allow independent control of data direction and timing
🔹 C. To increase power consumption
🔹 D. To simplify pin count

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The Data Bus Buffer isolates the DMA controller from the system data lines, while the Read/Write Logic determines whether the transfer is a read or a write and generates the appropriate control signals. Keeping these functions separate lets the controller manage data direction and timing independently, improving reliability and allowing precise coordination with peripheral signals. Reducing delay, increasing power, or minimizing pins are not the primary reasons for this architectural split.

Q16. If the clock input (CLK) to the 8257 is driven at 4 MHz and a DMA transfer moves one byte per clock cycle, how long will it take to transfer the maximum 16 K bytes?

🔹 A. 4 ms
🔹 B. 8 ms
🔹 C. 16 ms
🔹 D. 32 ms

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

At 4 MHz, the controller can transfer 4 000 000 bytes each second. The maximum transfer size is 16 384 bytes. Dividing the byte count by the transfer rate gives \(16384 / 4{,}000{,}000 = 0.004096\) seconds, which is approximately 4 ms. Therefore option A is correct. The other time values correspond to slower clock rates or multiple‑byte cycles, which do not match the given conditions.

Q17. How does the modulo (MARK) pin influence the address generation when the DMA controller is set to page mode, and what advantage does this provide for circular buffer implementations?

🔹 A. It resets the address to zero each transfer
🔹 B. It forces the address to wrap to a predefined page boundary
🔹 C. It disables address increment
🔹 D. It triggers an interrupt on overflow

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

When MARK is asserted in page mode, the address generator treats the high‑order bits of the address as a fixed page value, causing the low‑order bits to wrap around once they reach the page limit. This behavior creates a natural circular buffer without software intervention, allowing continuous streaming of data. Resetting to zero, disabling increment, or generating interrupts are unrelated to the paging function, making the other options incorrect.
