📝 Receiver Section in 8085A Microprocessor

📖 From An Introduction To Microprocessor 8085 • 14. Serial Communication and Programmable Communication Interface • 9 questions available

What is Receiver Section in 8085A Microprocessor?

The receiver samples incoming serial data on the \( RxD \) pin synchronized by the \( RxC \) clock, detects start bits in asynchronous mode or sync characters in synchronous mode, deserializes the bit stream into parallel form, checks for errors like parity or overrun, and presents valid data to the 8085A when \( RxRDY \) is asserted.

Q1. What is the number of bits used in the terminal count register to store the byte count for a DMA transfer?

A. 8 bits
B. 14 bits ✅
C. 16 bits
D. 32 bits

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The terminal count register uses the least‑significant 14 bits to hold the transfer count, allowing up to \(2^{14}=16384\) bytes (16 KB). This limitation defines the maximum block size a single DMA operation can handle. Options A, C, and D are incorrect because they either underestimate or vastly overestimate the register width, which would change the addressable range. Understanding this size is essential when planning DMA‑driven data moves.

Q2. Why are the two most significant bits of the terminal count register used to indicate the operation to be performed by the device on that channel?

A. They are unused and can be ignored
B. They define the DMA mode (single, block, demand)
C. They specify address increment or decrement
D. They store control flags that specify the operation ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

The two high‑order bits act as operation flags, telling the peripheral whether to read, write, or perform other functions during the transfer. This encoding lets the DMA controller convey command information without extra pins. Choices A and B misinterpret their purpose, and C describes address handling, which is controlled elsewhere. Recognizing the role of these bits helps designers configure correct channel behavior.

Q3. A system needs to move 20 KB of data using the 8257 DMA controller. Which strategy correctly accomplishes the transfer without exceeding the 16 KB limit of a single DMA operation?

A. Perform two DMA transfers: first 16 KB, then the remaining 4 KB
B. Increase the terminal count register to 20 KB and ignore overflow ✅
C. Split the data into four 5 KB transfers across four channels
D. Use a single transfer and rely on the CPU to handle the extra bytes

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The controller can only handle up to 16 KB per operation because the terminal count register holds 14 bits. Therefore the transfer must be broken into two segments: a full 16 KB block followed by a 4 KB remainder. Option B exceeds the register capacity, C unnecessarily complicates the process, and D defeats the purpose of DMA by involving the CPU.

Q4. During a DMA cycle, which pin indicates that the DMA controller has granted the bus to the peripheral after a hold request?

A. HLDA ✅
B. HRQ
C. READY
D. HOLD

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

HLDA (Hold Acknowledge) is asserted by the DMA controller to signal that it has granted bus control to the peripheral, allowing the DMA transfer to proceed. HRQ is the request line sent by the DMA controller, READY shows peripheral readiness, and HOLD is driven by the CPU to request the bus be given up. Confusing these pins leads to timing errors, so recognizing HLDA’s role is vital for correct bus arbitration.

Q5. How does the Mode Set Register influence the behavior of an individual DMA channel?

A. It selects the DMA channel number
B. It defines the transfer mode (single, block, demand) and address increment/decrement ✅
C. It sets the priority level of the channel
D. It determines the voltage level of the DMA pins

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The Mode Set Register configures each channel’s operation, specifying whether transfers occur in single, block, or demand mode and whether the address counter increments or decrements after each byte. This determines data flow characteristics. Options A and C describe functions handled by other registers (channel select and priority), while D is unrelated to logical configuration. Properly setting this register ensures efficient and error‑free DMA transfers.

Q6. A microcontroller has four DMA channels, but Channel 0 is reserved for a high‑priority audio stream. An I/O device requires an 8‑bit interface and a 10 KB transfer. Which channel should be assigned to this device?

A. Channel 0
B. Channel 1
C. Channel 2 ✅
D. Channel 3

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Channel 2 is the appropriate choice because Channel 0 is unavailable, and Channels 1 and 3 may already be allocated to other peripherals or have incompatible width constraints. Selecting Channel 2 keeps the high‑priority audio stream untouched and provides a free channel that can handle the 8‑bit device and the 10 KB block (within the 16 KB limit). Options A, B, and D either conflict with reserved usage or assume unavailable resources.

Q7. When the terminal count register reaches its maximum value, which bits are effectively ignored for the byte count?

A. Least‑significant bits
B. Most‑significant bits ✅
C. All bits are used equally
D. No bits are ignored

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Only the two most‑significant bits of the 16‑bit terminal count register are repurposed as operation flags, leaving the lower 14 bits to represent the actual byte count. Consequently, the high‑order bits do not contribute to the numeric count and are ignored for size calculations. Options A and C misstate which portion of the register holds the count, and D suggests no bits are ignored, contradicting the register’s design.

Q8. Why is the DMA Address Register loaded by the CPU rather than the DMA controller itself?

A. Because the CPU owns the address bus and can place the start address onto it ✅
B. Because the DMA controller cannot read memory addresses
C. To allow the system to set a dynamic start address for each transfer
D. Because loading the register would cause timing conflicts

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The CPU programs the DMA Address Register with the starting memory location, enabling flexible placement of the transfer source or destination for each operation. This flexibility is essential for varied data blocks. Option A is partially true but focuses on bus ownership rather than flexibility; B is false since the DMA can access memory; D misattributes the issue to timing rather than configurability.

Q9. A peripheral signals it is not ready to accept data during a DMA transfer. Which pin should the DMA controller monitor to pause the transfer until the peripheral becomes ready?

A. DRQ
B. HRQ
C. READY ✅
D. MEMR

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

The READY pin reflects the peripheral’s ability to accept or provide data; when it is de‑asserted, the DMA controller must stall the transfer to avoid data loss. DRQ indicates a request for DMA, HRQ is a hold request from the DMA controller, and MEMR signals a memory read operation. Misreading these signals would cause premature or delayed transfers, so correctly using READY ensures reliable synchronization between DMA and the peripheral.
