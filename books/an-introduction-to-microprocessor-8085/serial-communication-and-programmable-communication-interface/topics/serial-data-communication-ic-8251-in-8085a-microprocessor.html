Q1. What is the maximum number of bytes that a single DMA transfer can move without CPU intervention?

🔹 A. 8192 bytes
🔹 B. 16384 bytes
🔹 C. 32768 bytes
🔹 D. 4096 bytes

💡 Difficulty: easy | ✅ Correct: B

📖 Explanation:

The 8257 DMA controller can transfer up to 2^14 bytes, which equals 16384 bytes (16 K). This limit comes from the 14‑bit field in the terminal count register that stores the byte count. Option B matches this value, while the other options are either half or double the correct limit. Knowing the maximum transfer size helps designers decide when DMA is appropriate for large data blocks, ensuring efficient use of the bus without CPU overhead.

Q2. Which two bits of the terminal count register determine the type of DMA operation performed?

🔹 A. Least significant bits
🔹 B. Bits 7 and 8
🔹 C. Most significant bits
🔹 D. Bits 12 and 13

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

The two most significant bits of the terminal count register are reserved to indicate the operation (e.g., read, write, verify) that the DMA channel will perform. These bits are separate from the 14‑bit count field. Option C correctly identifies the most significant bits, whereas the other options refer to positions that do not control the operation mode. Understanding this layout is essential for configuring the controller correctly.

Q3. How does the HRQ (HOLD Request) signal interact with the HLDA (HOLD Acknowledge) line during a DMA cycle?

🔹 A. HRQ is asserted by the CPU and HLDA is ignored
🔹 B. HRQ is generated by the DMA controller and HLDA is asserted by the CPU to pause it
🔹 C. HRQ is generated by the DMA controller and HLDA is asserted by the CPU to grant bus control
🔹 D. HRQ and HLDA are unrelated signals

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

When a DMA channel needs the system bus, the controller raises HRQ. The CPU responds by asserting HLDA, indicating that it has released the bus for DMA use. This handshake ensures that the DMA controller can take control without data corruption. Option C describes this correct sequence; the other choices either invert the roles or claim no relationship, which would prevent coordinated bus sharing.

Q4. A system uses channel 2 of the 8257 to transfer a block of data. The terminal count register is loaded with the value 0x3FFF. How many bytes will actually be transferred?

🔹 A. 16383 bytes
🔹 B. 16384 bytes
🔹 C. 32767 bytes
🔹 D. 32768 bytes

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The terminal count register stores the byte count in its lower 14 bits. The hexadecimal value 0x3FFF corresponds to binary 0011 1111 1111 1111, which uses all 14 bits set to 1, giving a decimal count of 2^14 − 1 = 16383 bytes. Option A therefore matches the actual transfer size. Options B–D either add an extra byte or double the count, which do not reflect the 14‑bit limitation.

Q5. Why does the Mode Set Register need to be programmed before starting a DMA transfer on a channel?

🔹 A. It sets the CPU clock speed
🔹 B. It defines transfer type, address increment, and auto‑initialization
🔹 C. It controls the power supply to the DMA controller
🔹 D. It selects which IRQ line to use

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The Mode Set Register configures crucial parameters such as whether the transfer is single‑ or block‑mode, the direction of address increment (increment or decrement), and whether the channel will auto‑initialize after completion. These settings directly affect how the DMA controller moves data. Options A, C, and D describe unrelated functions, so they are incorrect. Properly programming the register ensures the DMA operates as intended for the specific peripheral.

Q6. In a DMA operation, the DRQ0 line is asserted while the CPU is executing an instruction that requires the data bus. What will the 8257 controller do to resolve this conflict?

🔹 A. It will ignore DRQ0 until the CPU finishes
🔹 B. It will assert HRQ, causing the CPU to release the bus
🔹 C. It will reset the DMA channel
🔹 D. It will force the CPU to wait state without bus release

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

When a DMA request (DRQ) arrives, the controller raises the HOLD Request (HRQ) signal. The CPU, upon seeing HRQ, acknowledges it with HLDA and relinquishes the bus, allowing the DMA transfer to proceed. This handshake prevents bus contention. Option B correctly describes this behavior; the other options either suggest inaction or disruptive actions that would halt the DMA process.

Q7. How does the 8257’s address enable (AEN) pin affect the ability of the DMA controller to access memory when multiple devices share the address bus?

🔹 A. AEN disables all DMA activity
🔹 B. AEN allows the DMA controller to place its address on the bus only when asserted
🔹 C. AEN forces the CPU to halt
🔹 D. AEN selects the DMA channel automatically

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The AEN pin acts as a gate: when asserted, the DMA controller is permitted to drive the address lines onto the shared bus, enabling it to fetch or store data. If AEN is not asserted, the DMA controller must wait, preventing bus conflicts with other devices. Options A, C, and D misrepresent the pin’s purpose, making B the accurate description.

Q8. A programmer loads the DMA address register of channel 1 with 0x2000 and the terminal count register with 0x1000. The channel is set to auto‑initialize mode. After the first transfer completes, what address will the DMA controller use for the next byte if the transfer is not restarted manually?

🔹 A. 8192
🔹 B. 12288
🔹 C. 8193
🔹 D. 4096

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

In auto‑initialize mode, once the terminal count reaches zero, the DMA controller automatically reloads the original address and count values from the address and terminal count registers. Therefore, the next byte will start again at the original address 0x2000. Options B and C assume the address increments, while D confuses the count value with an address, so they are incorrect.

Q9. During a high‑speed serial communication, the system requires continuous data flow without CPU interruption. Which DMA channel configuration (single‑mode vs. block‑mode) is most appropriate, and why?

🔹 A. Single‑mode because it transfers one byte at a time
🔹 B. Block‑mode because it transfers a whole block defined by terminal count
🔹 C. Single‑mode because it reduces bus contention
🔹 D. Block‑mode because it disables the READY line

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Block‑mode allows the DMA controller to move an entire block of data defined by the terminal count register in one uninterrupted burst, which is ideal for high‑speed streams where the CPU must remain idle. Single‑mode would require repeated handshaking for each byte, increasing overhead. Options A and C misinterpret the benefits, while D describes an unrelated effect, making B the correct choice.

Q10. What role does the READY signal play in coordinating DMA transfers with peripheral devices?

🔹 A. It indicates that the peripheral is ready to accept or provide data
🔹 B. It resets the DMA controller
🔹 C. It selects the DMA channel
🔹 D. It clocks the DMA logic

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The READY line is a handshake signal used by many peripherals to tell the DMA controller that the device can either supply data (for a read) or accept data (for a write). When READY is asserted, the DMA transfer proceeds; otherwise it stalls. Options B, C, and D describe functions that belong to other control lines, so they are not correct.

Q11. If the terminal count register of a channel is loaded with the value 0x4000 (binary 0100 0000 0000 0000), how many bytes will actually be transferred, and why?

🔹 A. 16384 bytes because only lower 14 bits are used
🔹 B. 0 bytes because the most significant bits are ignored
🔹 C. 16384 bytes because the value exceeds 14‑bit limit
🔹 D. 0 bytes because the register overflows

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

The terminal count register uses only the lower 14 bits to store the byte count. The value 0x4000 has bit 14 set and all lower 14 bits cleared, so the effective count is zero. Consequently, no bytes are transferred. Option B correctly explains this outcome; the other options either assume the high bit is counted or misinterpret overflow behavior.
