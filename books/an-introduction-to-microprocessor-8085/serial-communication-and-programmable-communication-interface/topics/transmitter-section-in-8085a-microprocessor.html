A.8 KB
B.16 KB ✅
C.32 KB
D.64 KB
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: The 14‑bit count field can represent values from 0 to , which equals 16383, allowing a transfer of up to 16384 bytes. This is commonly expressed as 16 KB. Option B matches this value. Options A, C, and D correspond to 8 KB, 32 KB, and 64 KB, which exceed or fall short of the allowed range. Understanding the size limit is essential when planning DMA transfers, as exceeding it would require multiple operations.

Q2. Why are the two most significant bits of the terminal count register used to indicate the type of operation for a DMA channel?

A.They store part of the address
B.They select read/write mode
C.They signal whether the transfer is memory‑to‑memory, I/O‑to‑memory, memory‑to‑I/O, or I/O‑to‑I/O ✅
D.They are unused and reserved
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: The two most significant bits are reserved for operation coding, allowing the controller to differentiate among four possible transfer directions. This coding tells the DMA logic whether data moves between memory and I/O or between two memory locations. Option C correctly describes this purpose. Options A and B misinterpret the bits as address or mode controls, while D incorrectly claims they are unused. Proper use prevents incorrect data routing.

Q3. How does the DMA Address Register interact with the terminal count register during a block transfer?

A.Address register remains fixed while count decrements
B.Both registers are loaded with the same value
C.Address register increments automatically as each byte is transferred, while the terminal count decrements ✅
D.The terminal count increments the address register after the transfer completes
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: During a block transfer, the address register provides the starting location and is automatically incremented (or decremented) after each byte, allowing sequential access. Simultaneously, the terminal count register counts down from the loaded value until it reaches zero, signalling completion. Option C captures this coordinated behavior. Option A suggests the address does not change, which would cause all data to be written to the same location. Option B is false because the registers serve different purposes, and D reverses the direction of operation.

Q4. What role does the HRQ (HOLD Request) line play in coordinating DMA activity with the CPU?

A.It provides power to the DMA controller
B.It signals the CPU to release the bus so the DMA can take control ✅
C.It resets the DMA controller
D.It acknowledges completion of a DMA transfer
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: HRQ is an output from the DMA controller to the CPU, indicating that the DMA needs control of the system bus. When asserted, the CPU responds by placing its bus cycles on hold, allowing the DMA controller to become the bus master. This coordination avoids bus contention. Option B correctly describes this handshake. Option A confuses HRQ with a power signal, C misidentifies it as a reset, and D describes the DACK line rather than HRQ. Proper use ensures smooth data movement without interrupting the CPU.

Q5. In the 8257 DMA controller, what is the effect of setting the MODE bits to “Auto‑Initialize” for a channel, and why might this be advantageous for continuous data streaming?

A.The channel stops after one transfer
B.The address and count registers are automatically reloaded after terminal count, allowing uninterrupted successive transfers ✅
C.The DMA controller disables interrupts
D.The channel ignores DRQ signals
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Auto‑Initialize causes the DMA controller to automatically reload the address and count registers from their preset values once the terminal count reaches zero. This creates a looped transfer that can continue indefinitely, ideal for streaming data such as audio or video where the same buffer size repeats. Option B reflects this behavior. Option A describes the opposite effect, C incorrectly links it to interrupt handling, and D suggests the channel becomes insensitive to requests, which would halt data flow.

Q6. A system needs to transfer exactly 4 KB of sensor data from I/O port 0x30 to memory starting at address 0x2000 using Channel 2. Which values should be loaded into the DMA Address Register and the terminal count register (lower 14 bits) for Channel 2?

A.Address 0x2000, Count 0x1000 ✅
B.Address 0x2000, Count 0x0400
C.Address 0x30, Count 0x1000
D.Address 0x30, Count 0x0400
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Four kilobytes equal bytes, which is in hexadecimal. The address register must contain the destination memory address, 0x2000, while the count register holds the number of bytes to move, 0x1000, fitting within the 14‑bit limit. Option A matches these requirements. Option B uses the correct address but an incorrect count (0x0400 = 1024 bytes). Options C and D mistakenly place the I/O port address in the DMA address register, which is not how the controller stores destination addresses.

Q7. During a DMA transfer, the DRQ line for Channel 1 is never asserted, but the CPU mistakenly enables the channel. What is the most likely outcome?

A.The DMA controller will transfer data continuously without CPU involvement
B.The transfer will never start, and the CPU will remain idle waiting for completion ✅
C.The DMA controller will generate a bus error and halt the system
D.The channel will perform a single‑byte transfer and then stop
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: DRQ (DMA Request) is the signal that tells the DMA controller a peripheral needs service. If DRQ is never asserted, the controller has no reason to begin the transfer, even though the channel is enabled. Consequently, the DMA engine stays idle, and any software waiting for the transfer to finish will block, leading to a stalled CPU. Option B captures this. Option A would require a valid DRQ, C exaggerates the fault, and D is not how the controller behaves without a request.

Q9. A DMA channel is set to “Read” mode while connected to a peripheral that only supports write operations. Which of the following problems is most likely to occur?

A.The peripheral will ignore the DMA request and operate normally
B.The DMA controller will cause data corruption by writing to the wrong bus direction ✅
C.The transfer will complete instantly with zero bytes transferred
D.The DMA controller will generate an interrupt indicating an illegal mode
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: In “Read” mode the DMA controller expects to receive data from the peripheral and places it onto the bus as a read operation. If the peripheral only drives the bus for writes, the direction is reversed, causing the controller to attempt to read while the device is trying to write, leading to mismatched control signals and potential data corruption. Option B describes this mismatch. Option A assumes silent failure, C unrealistically assumes immediate completion, and D misidentifies the typical response; most controllers do not automatically generate an interrupt for a mode mismatch.

Q10. A designer wants to use the 8257 to service four UARTs simultaneously, each requiring 256 bytes of buffer space. Assuming the DMA controller can only handle one active request at a time, which arbitration scheme should be employed to ensure each UART gets service without missing data?

A.Fixed‑priority arbitration with the UART having the highest data rate given the highest priority
B.Round‑robin arbitration where each UART receives an equal time slice ✅
C.Random arbitration based on a pseudo‑random generator
D.No arbitration is needed because the DMA controller can handle all requests concurrently
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Round‑robin arbitration cycles through each request in turn, giving each UART an equal opportunity to obtain the bus. This prevents any single device from monopolizing the DMA controller and ensures that all four buffers receive service within their timing constraints. Option B reflects this balanced approach. Fixed‑priority (A) could cause lower‑priority UARTs to miss data, random (C) offers no guarantee, and D is incorrect because the 8257 can only service one request at a time.
