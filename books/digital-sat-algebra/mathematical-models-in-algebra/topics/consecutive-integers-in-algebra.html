What is Consecutive Integers in algebra?

Definition:
Consecutive integers in algebra are numbers that follow each other in order without gaps, differing by 1. If the first integer is xxx, then the next consecutive integers are x+1x+1x+1, x+2x+2x+2, x+3x+3x+3, and so on. Problems often involve their sum or product.

Working:
For example, 'The sum of three consecutive integers is 72.' Let the first be xxx, so integers are x,x+1,x+2x, x+1, x+2x,x+1,x+2. Equation: x+(x+1)+(x+2)=72x + (x+1) + (x+2) = 72x+(x+1)+(x+2)=72. Simplify: 3x+3=723x + 3 = 723x+3=72, subtract 3: 3x=693x = 693x=69, divide: x=23x = 23x=23. The integers are 23, 24, 25.

Example:
Problem: 'Find three consecutive integers whose sum is 60.' Let xxx be first, equation: x+(x+1)+(x+2)=60x + (x+1) + (x+2) = 60x+(x+1)+(x+2)=60, 3x+3=603x+3=603x+3=60, 3x=573x=573x=57, x=19x=19x=19. Integers: 19, 20, 21.

Reason:
This is a common type of number problem that tests understanding of sequential relationships and equation formulation.

Q1. Three consecutive integers have a sum of 727272. Which equation correctly models the situation if the smallest integer is xxx?

A.x+x+1+x+2=72x+x+1+x+2=72x+x+1+x+2=72 ✅
B.x+x+2+x+3=72x+x+2+x+3=72x+x+2+x+3=72
C.3x+1=723x+1=723x+1=72
D.x+(x+1)+(x+3)=72x+(x+1)+(x+3)=72x+(x+1)+(x+3)=72
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: If the smallest integer is xxx, the next two consecutive integers must be x+1x+1x+1 and x+2x+2x+2. Adding them gives x+(x+1)+(x+2)=72x+(x+1)+(x+2)=72x+(x+1)+(x+2)=72, so option A correctly represents both the consecutive relationship and the total.

Q2. Which statement best distinguishes three consecutive integers from three integers that merely differ by some amount?

A.Their average must always be zero.
B.Each integer differs from the previous integer by exactly 111. ✅
C.Their product must always be positive.
D.The largest integer must be twice the smallest.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Consecutive integers are defined by a constant difference of exactly 111. Therefore, if the first integer is xxx, the next two are x+1x+1x+1 and x+2x+2x+2. The other statements are not required properties.

Q3. A student models three consecutive integers as x−1x-1x−1, xxx, and x+1x+1x+1. Another student uses xxx, x+1x+1x+1, and x+2x+2x+2. Which conclusion is correct?

A.Only the second model can represent consecutive integers.
B.Only the first model can represent consecutive integers.
C.Both models represent consecutive integers, but they use different choices for the variable. ✅

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Both models correctly describe three consecutive integers. The first chooses xxx as the middle integer, while the second chooses xxx as the smallest. A valid algebraic model can use different reference integers as long as the relationships remain correct.
