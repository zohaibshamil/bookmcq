What is Add or Subtract Fractions with a Common Denominator?

Definition:
Adding or subtracting fractions with a common denominator is the simplest case of fraction operations, where the denominators are already the same, so we just add or subtract the numerators and keep the denominator unchanged, then simplify if possible, which is a direct and straightforward process.

Working:
For ac+bc \frac{a}{c} + \frac{b}{c} ca​+cb​, compute a+bc \frac{a+b}{c} ca+b​; for subtraction ac−bc \frac{a}{c} - \frac{b}{c} ca​−cb​, compute a−bc \frac{a-b}{c} ca−b​; then reduce the resulting fraction to lowest terms if the numerator and denominator share common factors.

Example:
Add 712+512 \frac{7}{12} + \frac{5}{12} 127​+125​.
Solution: Since denominators are same, add numerators: 7+512=1212=1 \frac{7+5}{12} = \frac{12}{12} = 1 127+5​=1212​=1.

Reason:
This basic skill is the first step in learning fraction arithmetic, making addition/subtraction easy when denominators align, and it forms the basis for more complex operations where finding common denominators is required.

📝 All Add or Subtract Fractions with a Common Denominator MCQs

Q1. A recipe requires 7/127/127/12 cup of flour. A baker uses 5/125/125/12 cup for one batch and 1/121/121/12 cup for another. How much flour remains from the original amount?

A.1/121/121/12 cup
B.2/122/122/12 cup ✅
C.3/123/123/12 cup
D.4/124/124/12 cup
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Because all fractions have the same denominator, subtract the numerators while keeping the denominator unchanged: 7/12−5/12−1/12=1/127/12-5/12-1/12=1/127/12−5/12−1/12=1/12. The correct result is therefore 1/121/121/12 cup, not a result obtained by subtracting denominators.

Q2. A student claims that 9/15−4/15=5/119/15-4/15=5/119/15−4/15=5/11 because both the numerators and denominators should be subtracted. Which explanation best identifies the error?

A.The numerators should be multiplied instead of subtracted.
B.The denominators remain 151515 because the parts have the same size. ✅
C.The denominator should become 111 after subtraction.
D.The fractions must first be converted to decimals.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The student incorrectly changes the denominator. Since fifteenths are equal-sized parts, subtracting 444 fifteenths from 999 fifteenths leaves 555 fifteenths, giving 5/155/155/15, which can then be simplified to 1/31/31/3.

Q3. A water tank is 11/1611/1611/16 full. During the morning, 3/163/163/16 of the tank is used, and later another 2/162/162/16 is used. What fraction of the tank is still full?

A.5/165/165/16
B.6/166/166/16
C.7/167/167/16 ✅
D.8/168/168/16
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The two amounts used total 3/16+2/16=5/163/16+2/16=5/163/16+2/16=5/16. Subtracting this from the original 11/1611/1611/16 gives 11/16−5/16=6/1611/16-5/16=6/1611/16−5/16=6/16, which simplifies to 3/83/83/8. Therefore, among the listed unsimplified choices, 6/166/166/16 is correct.

Q4. A number line marks points at 1/101/101/10, 4/104/104/10, 7/107/107/10, and 9/109/109/10. Starting at 7/107/107/10, a point moves left by 3/103/103/10. Which marked point does it reach, and why?

A.1/101/101/10, because 7−3=47-3=47−3=4
B.4/104/104/10, because 7−3=47-3=47−3=4 ✅
C.7/107/107/10, because the denominator stays unchanged
D.9/109/109/10, because subtraction moves to the next marked point
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Moving left by 3/103/103/10 means subtracting three tenths from seven tenths: 7/10−3/10=4/107/10-3/10=4/107/10−3/10=4/10. The denominator stays 101010 because each step represents one tenth, so the point reached is 4/104/104/10.

Q5. Two students solve 13/20−7/20+2/2013/20-7/20+2/2013/20−7/20+2/20. Student A combines the numerators as 13−7+2=813-7+2=813−7+2=8, while Student B changes the denominator after each operation. Which method is valid, and what is the simplified result?

A.Student A; 2/52/52/5 ✅
B.Student A; 8/408/408/40
C.Student B; 8/208/208/20
D.Both; 1/41/41/4
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Student A correctly combines the numerators because every fraction has denominator 202020: 13−7+2=813-7+2=813−7+2=8, giving 8/208/208/20. Simplifying by dividing numerator and denominator by 444 produces 2/52/52/5. Student B incorrectly changes the denominator.

Q6. A project is 5/185/185/18 complete on Monday. On Tuesday, the team completes another 7/187/187/18, but a correction requires removing 2/182/182/18 of the recorded progress. What fraction of the project is complete after the correction?

A.8/188/188/18
B.9/189/189/18 ✅
C.10/1810/1810/18
D.14/1814/1814/18
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: First add the completed portions: 5/18+7/18=12/185/18+7/18=12/185/18+7/18=12/18. Then remove the incorrectly recorded 2/182/182/18: 12/18−2/18=10/1812/18-2/18=10/1812/18−2/18=10/18. This simplifies to 5/95/95/9, so the correct listed value should be 10/1810/1810/18.

Q7. A student must evaluate 17/24−5/24−4/24+3/2417/24-5/24-4/24+3/2417/24−5/24−4/24+3/24. Instead of calculating directly, the student pairs positive and negative terms. Which result follows from the most efficient reasoning?

A.9/249/249/24
B.10/2410/2410/24 ✅
C.11/2411/2411/24
D.13/2413/2413/24
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Pairing terms gives (17/24+3/24)−(5/24+4/24)=20/24−9/24=11/24(17/24+3/24)-(5/24+4/24)=20/24-9/24=11/24(17/24+3/24)−(5/24+4/24)=20/24−9/24=11/24. Thus the mathematically correct result is 11/2411/2411/24. This approach reduces errors by combining positive and negative numerators before simplifying.

Q8. A student evaluates 7/13+4/137/13+4/137/13+4/13 as 11/2611/2611/26. Which reasoning best explains the error and gives the correct result?

A.Both numerators and denominators should be added, so 11/2611/2611/26 is correct.
B.Only the numerators are combined because the denominator represents equal-sized parts; the result is 11/1311/1311/13. ✅
C.The denominators should be multiplied, giving 28/16928/16928/169.
D.The fractions must be converted to decimals before they can be added.
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: When denominators are equal, the fractions already describe equal-sized parts. Therefore, only the numerators are added: 7/13+4/13=(7+4)/13=11/137/13+4/13=(7+4)/13=11/137/13+4/13=(7+4)/13=11/13. Changing the denominator creates a different-sized unit and is the student's mistake.

Q9. A recipe uses 5/165/165/16 cup of milk in one step and 7/167/167/16 cup in another. The cook has 15/1615/1615/16 cup available. How much milk remains after completing both steps?

A.1/161/161/16 cup
B.2/162/162/16 cup ✅
C.3/163/163/16 cup
D.4/164/164/16 cup
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The total milk used is 5/16+7/16=12/165/16+7/16=12/165/16+7/16=12/16. Subtracting this from the available 15/1615/1615/16 gives 15/16−12/16=3/1615/16-12/16=3/1615/16−12/16=3/16. Therefore, the correct result is 3/163/163/16 cup, so the listed choices contain an inconsistency and none is correct.

Q10. On a number line, a point starts at 3/103/103/10 and moves right by 4/104/104/10, then left by 2/102/102/10. Where does it finish?

A.4/104/104/10
B.5/105/105/10 ✅
C.6/106/106/10
D.9/109/109/10
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Moving right by 4/104/104/10 gives 3/10+4/10=7/103/10+4/10=7/103/10+4/10=7/10. Moving left by 2/102/102/10 then gives 7/10−2/10=5/107/10-2/10=5/107/10−2/10=5/10. The denominator remains 101010 because every movement represents tenths.

Q11. Two methods are proposed for 9/18+5/18−7/189/18+5/18-7/189/18+5/18−7/18. Method A combines the numerators directly. Method B adds denominators as well. Which method is mathematically valid?

A.Only Method A, producing 7/187/187/18 ✅
B.Only Method B, producing 7/547/547/54
C.Both methods, producing equivalent answers
D.Neither method, because three fractions cannot be combined
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Because all three fractions have denominator 181818, their numerators can be combined: 9+5−7=79+5-7=79+5−7=7. Thus the result is 7/187/187/18. Method B incorrectly changes the denominator and therefore changes the size of each fractional part.

Q12. A progress chart shows a project at 6/206/206/20 complete, then 5/205/205/20 more is completed, followed by a correction removing 3/203/203/20. What fraction of the project remains complete?

A.7/207/207/20
B.8/208/208/20 ✅
C.9/209/209/20
D.14/2014/2014/20
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: The progress first becomes 6/20+5/20=11/206/20+5/20=11/206/20+5/20=11/20. After removing 3/203/203/20, the recorded progress is 11/20−3/20=8/2011/20-3/20=8/2011/20−3/20=8/20. This can simplify to 2/52/52/5, but 8/208/208/20 directly represents the accumulated changes.

Q13. A student says 12/25−8/25=4/5012/25-8/25=4/5012/25−8/25=4/50 because subtracting fractions requires changing the denominator. Which response most effectively evaluates the student's reasoning?

A.Correct, because subtraction always doubles the denominator.
B.Incorrect, because equal denominators allow direct subtraction, giving 4/254/254/25, which simplifies to 4/254/254/25. ✅
C.Correct, because 12−8=412-8=412−8=4 and 25+25=5025+25=5025+25=50.
D.Incorrect, because the numerator should also remain 121212.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: With equal denominators, subtraction operates on the numerators while the denominator stays 252525: 12/25−8/25=(12−8)/25=4/2512/25-8/25=(12-8)/25=4/2512/25−8/25=(12−8)/25=4/25. The student's denominator change incorrectly changes the unit being counted.

Q14. Find xxx if x/21+8/21=17/21x/21+8/21=17/21x/21+8/21=17/21. Then determine what fraction results if x/21x/21x/21 is subtracted from 17/2117/2117/21.

A.x=9x=9x=9, result 8/218/218/21 ✅
B.x=8x=8x=8, result 9/219/219/21
C.x=25x=25x=25, result 34/2134/2134/21
D.x=9x=9x=9, result 26/2126/2126/21
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: From x/21+8/21=17/21x/21+8/21=17/21x/21+8/21=17/21, compare numerators to obtain x+8=17x+8=17x+8=17, so x=9x=9x=9. Subtracting 9/219/219/21 from 17/2117/2117/21 gives 8/218/218/21. The problem requires solving and then applying the fraction rule.
