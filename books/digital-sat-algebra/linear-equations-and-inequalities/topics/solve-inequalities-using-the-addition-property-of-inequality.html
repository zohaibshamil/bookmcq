What is Solve inequalities using the Addition Property of Inequality?

Definition:
The Addition Property of Inequality states that adding the same number to both sides of an inequality maintains the inequality direction. If a>ba > ba>b, then a+c>b+ca + c > b + ca+c>b+c. This is used to eliminate subtracted constants.

Working:
For y−3<5y - 3 < 5y−3<5, add 3 to both sides: y−3+3<5+3y - 3 + 3 < 5 + 3y−3+3<5+3, giving y<8y < 8y<8. The direction remains the same.

Example:
Solve p−2≥−6p - 2 \geq -6p−2≥−6. Add 2: p≥−4p \geq -4p≥−4. The solution includes all numbers greater than or equal to -4.

Reason:
This property works identically to its equality counterpart, making it intuitive for students who have learned solving equations.

Q1. Which inequality is equivalent to x-7&gt;12 after using the Addition Property of Inequality correctly?

A.x&gt;5
B.x&gt;19 ✅
C.x&lt;19
D.x&lt;5
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Adding 7 to both sides preserves the direction of the inequality because the same quantity is added to each side. Thus x-7+7&gt;12+7, giving x&gt;19.

Q2. Which value of kkk makes the inequality k−15≤−4k-15\leq-4k−15≤−4 equivalent to k≤11k\leq11k≤11?

A.4
B.11
C.15 ✅
D.19
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: To remove the −15-15−15, add 15 to both sides. This produces k≤−4+15k\leq-4+15k≤−4+15, so k≤11k\leq11k≤11. Therefore, the value being added is 15.

Q3. Consider y+6≥14y+6\geq14y+6≥14. A student subtracts 6 from both sides and obtains y≥20y\geq20y≥20. What is the best diagnosis of the error?

A.The inequality should reverse when subtracting 6.
B.The student should add 6 instead, obtaining y≥20y\geq20y≥20.
C.The student used the wrong operation; subtracting 6 gives y≥8y\geq8y≥8. ✅
D.The variable must be divided by 6 before solving.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Subtracting 6 from both sides is appropriate because it cancels the positive 6 attached to yyy. The calculation gives y+6−6≥14−6y+6-6\geq14-6y+6−6≥14−6, so y≥8y\geq8y≥8, not 20.

Q4. Which inequality has the same solution set as m+18&lt;7?

A.Student A is correct because 24 should be added to both sides. ✅

C.Both are correct because either direction can represent the same solution.

Q8. A number-line graph shows an open circle at -3 with shading extending to the right. Which inequality matches the graph?

Q10. A student transforms r+5&lt;2 into r&lt;-3, then says the inequality should become r&gt;-3 because subtraction was used. What is wrong with the student's final statement?

A.Subtraction always reverses an inequality.
B.Only multiplication reverses an inequality.
C.Subtracting the same number from both sides does not reverse the inequality. ✅
D.The number 5 should be multiplied instead of subtracted.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: Subtracting 5 from both sides gives r+5-5&lt;2-5, so r&lt;-3. The inequality direction remains unchanged. Reversal occurs when multiplying or dividing by a negative number, not when adding or subtracting.

📖 Explanation: The statement is valid because subtracting aaa from both sides isolates xxx, giving x&gt;b-a. If aaa itself is negative, subtracting a negative number is equivalent to adding its positive opposite, but the inequality direction still does not reverse.
