What is Solve inequalities using the Subtraction Property of Inequality?

Definition:
The Subtraction Property of Inequality states that subtracting the same number from both sides of an inequality preserves the inequality direction. For a<ba < ba<b, a−c<b−ca - c < b - ca−c<b−c. This is used to eliminate added constants on the variable side.

Working:
For x+7>12x + 7 > 12x+7>12, subtract 7 from both sides: x+7−7>12−7x + 7 - 7 > 12 - 7x+7−7>12−7, giving x>5x > 5x>5. No sign reversal occurs.

Example:
Solve m+4≤10m + 4 \leq 10m+4≤10. Subtract 4: m≤6m \leq 6m≤6. The solution is all numbers less than or equal to 6.

Reason:
This property allows us to isolate the variable by removing constants, just like in equations, but without changing the inequality.
