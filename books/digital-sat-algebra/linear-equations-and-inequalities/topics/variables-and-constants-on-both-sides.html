What is Variables and Constants on Both Sides?

Definition:
Variables and constants on both sides refer to equations where the unknown variable appears on both the left and right sides, and constant terms also appear on both sides. Solving such equations requires moving variable terms to one side and constant terms to the other using addition or subtraction.

Working:
Choose a side to collect variables (usually the side with the larger coefficient to avoid negatives) and the opposite side for constants. Use the Addition or Subtraction Property to move terms. Then simplify and solve. For example, solve 3x+2=x+103x + 2 = x + 103x+2=x+10: subtract xxx from both sides: 2x+2=102x + 2 = 102x+2=10, subtract 2: 2x=82x = 82x=8, divide by 2: x=4x = 4x=4.

Example:
Solve 5y−3=2y+95y - 3 = 2y + 95y−3=2y+9. Subtract 2y2y2y: 3y−3=93y - 3 = 93y−3=9, add 3: 3y=123y = 123y=12, divide by 3: y=4y = 4y=4. Check: 5(4)−3=20−3=175(4)-3 = 20-3=175(4)−3=20−3=17, 2(4)+9=8+9=172(4)+9=8+9=172(4)+9=8+9=17.

Reason:
This method systematically organizes the equation, making it possible to solve more complex problems where the variable is not confined to one side.

D.Divided 4x by 4 but forgot to divide the constant 5

📖 Explanation: The student likely added 3x 3x 3x to both sides (getting 7x+5=−2 7x + 5 = -2 7x+5=−2) and then made further errors. The correct step is to subtract 3x 3x 3x from both sides to get x+5=−2 x + 5 = -2 x+5=−2, so x=−7 x = -7 x=−7. The student's answer of 3 suggests they added 3x 3x 3x incorrectly.

Q5. The equation 2(3x+4)=6x+8 2(3x + 4) = 6x + 8 2(3x+4)=6x+8 is an example of which type of equation?

A.Contradiction (no solution)
B.Identity (infinite solutions) ✅
C.Conditional (one solution)
D.Quadratic (two solutions)
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: Expanding the left side: 6x+8=6x+8 6x + 8 = 6x + 8 6x+8=6x+8. This simplifies to 8=8 8 = 8 8=8, which is true for all x x x. This is an identity, meaning any real number is a solution. Students often think if variables cancel but constants equal, it's 'no solution'—that's a contradiction like 8=9 8=9 8=9.

Q11. If ax+b=cx+d ax + b = cx + d ax+b=cx+d has no solution, which of the following must be true?

A.a=c a = c a=c and b=d b = d b=d
B.a=c a = c a=c and \( b eq d \) ✅
C.\( a eq c \) and b=d b = d b=d
D.\( a eq c \) and \( b eq d \)
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: For a linear equation ax+b=cx+d ax+b = cx+d ax+b=cx+d, rearranging gives (a−c)x=d−b (a-c)x = d-b (a−c)x=d−b. If a=c a=c a=c, the variable term disappears. Then if \( b eq d \), we get 0=d−b 0 = d-b 0=d−b, which is false, so no solution. If a=c a=c a=c and b=d b=d b=d, infinite solutions. If \( a eq c \), one unique solution. This requires abstract reasoning with parameters—a higher-order skill.
