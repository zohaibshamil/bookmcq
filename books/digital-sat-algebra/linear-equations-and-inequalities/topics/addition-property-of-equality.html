What is Addition Property of Equality?

Definition:
The Addition Property of Equality states that adding the same number to both sides of an equation preserves equality. Mathematically, if a=ba = ba=b, then a+c=b+ca + c = b + ca+c=b+c. It is used to eliminate subtraction terms on one side to solve for the unknown variable.

Working:
To solve y−5=9y - 5 = 9y−5=9, we use this property by adding 5 to both sides: y−5+5=9+5y - 5 + 5 = 9 + 5y−5+5=9+5, which yields y=14y = 14y=14. The addition cancels the −5-5−5 term.

Example:
Solve p−8=3p - 8 = 3p−8=3 using the Addition Property. Add 8 to both sides: p−8+8=3+8p - 8 + 8 = 3 + 8p−8+8=3+8, so p=11p = 11p=11. Verify: 11−8=311 - 8 = 311−8=3.

Reason:
This property is the inverse of subtraction, enabling us to undo subtraction. It ensures the equation remains balanced while we isolate the variable.

Q1. A student solves the equation x−7.2=3.8x - 7.2 = 3.8x−7.2=3.8 and writes x=3.8−7.2x = 3.8 - 7.2x=3.8−7.2, getting x=−3.4x = -3.4x=−3.4. Which statement best describes this error?

A.The student incorrectly added 7.2 to both sides but wrote the operation backwards; the correct result is 11.0. ✅
B.The student correctly applied the Addition Property but made a decimal subtraction error; the correct result is -3.4.
C.The student should have subtracted 3.8 from both sides, not 7.2, because the variable term must be isolated first.
D.The student confused the Addition Property with the Multiplication Property; division by 7.2 is needed.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The student's equation x=3.8−7.2x = 3.8 - 7.2x=3.8−7.2 shows they moved 7.2 to the right side without changing its sign, which is a common 'transposing' error. The correct step is to add 7.2 to both sides: x−7.2+7.2=3.8+7.2x - 7.2 + 7.2 = 3.8 + 7.2x−7.2+7.2=3.8+7.2, giving x=11.0x = 11.0x=11.0. This is a conceptual misunderstanding of the Addition Property, which requires adding the same number to both sides to maintain equality.

The inverse operation is subtraction, so you subtract 23\frac{2}{3}32​ from both sides: y=−14−23=−312−812=−1112y = -\frac{1}{4} - \frac{2}{3} = -\frac{3}{12} - \frac{8}{12} = -\frac{11}{12}y=−41​−32​=−123​−128​=−1211​. Option B is a common error of using the wrong inverse operation, and C/D show incorrect fraction addition.

Q3. A car's fuel gauge reads ggg gallons. After adding 4.5 gallons, the gauge reads 11.3 gallons. Which equation models this situation, and what was the original amount of fuel?

A.g+4.5=11.3g + 4.5 = 11.3g+4.5=11.3; g=6.8g = 6.8g=6.8 gallons ✅
B.g−4.5=11.3g - 4.5 = 11.3g−4.5=11.3; g=15.8g = 15.8g=15.8 gallons
C.4.5−g=11.34.5 - g = 11.34.5−g=11.3; g=−6.8g = -6.8g=−6.8 gallons (impossible)
D.g=11.3+4.5g = 11.3 + 4.5g=11.3+4.5; g=15.8g = 15.8g=15.8 gallons
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The situation describes an increase in fuel, so addition is correct: original ggg plus added 4.5 equals new total 11.3. To solve, subtract 4.5 from both sides: g=11.3−4.5=6.8g = 11.3 - 4.5 = 6.8g=11.3−4.5=6.8. Option D incorrectly adds the 4.5 to the final reading, which would double-count the added fuel. This is a direct application of the Addition Property in a real-world context.

Q4. Consider the equation −5=x+9-5 = x + 9−5=x+9. A student says, 'Since it's −5-5−5, I should add 5 to both sides.' Is this correct? If not, what is the correct step?

A.Correct, because you add the opposite of the constant on the left to both sides.
B.Incorrect; you should subtract 9 from both sides because 9 is being added to xxx. ✅
C.Incorrect; you should add 9 to both sides to make the left side zero.
D.Correct, because the Addition Property says you can add any number to both sides.
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: The student's reasoning focuses on the sign of the left side, which is irrelevant. The goal is to isolate xxx, so you must undo the addition of 9 on the right side. The inverse operation is subtraction of 9 from both sides: −5−9=x+9−9-5 - 9 = x + 9 - 9−5−9=x+9−9, giving x=−14x = -14x=−14. Option A is a common distractor for those who confuse the sign of the result with the operation needed.

Q5. A number line shows a point at ppp. If you move 4 units to the right, you land at 2. What is the value of ppp, and which property justifies your solution?

A.p=−2p = -2p=−2; Addition Property of Equality ✅
B.p=6p = 6p=6; Subtraction Property of Equality
C.p=−2p = -2p=−2; Subtraction Property of Equality
D.p=6p = 6p=6; Addition Property of Equality
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Moving right on a number line means adding a positive value. The equation is p+4=2p + 4 = 2p+4=2. To solve, subtract 4 from both sides (which is the Addition Property with a negative number): p=2−4=−2p = 2 - 4 = -2p=2−4=−2. The justification is the Addition Property of Equality (adding -4 to both sides). Option C incorrectly labels the property as 'Subtraction' when it's fundamentally addition of a negative.

Q6. Two students solve 3.2=m−5.63.2 = m - 5.63.2=m−5.6. Student A adds 5.6 to both sides; Student B subtracts 3.2 from both sides. Which method is correct, and who will arrive at the correct solution?

A.Both are correct; Student A will get m=8.8m = 8.8m=8.8 and Student B will get m=−2.4m = -2.4m=−2.4.
B.Only Student A is correct; Student B's method creates a new equation but can still lead to the same m=8.8m = 8.8m=8.8 if they continue correctly. ✅
C.Only Student B is correct; Student A's method is algebraically invalid.
D.Neither is correct; the equation should be solved by multiplying both sides by 5.6.
💡 Difficulty: hard | ✅ Correct: B

📖 Explanation: Student A applies the Addition Property directly by adding 5.6 to both sides: 3.2+5.6=m−5.6+5.63.2 + 5.6 = m - 5.6 + 5.63.2+5.6=m−5.6+5.6, giving m=8.8m = 8.8m=8.8. Student B subtracts 3.2 from both sides: 3.2−3.2=m−5.6−3.23.2 - 3.2 = m - 5.6 - 3.23.2−3.2=m−5.6−3.2, which simplifies to 0=m−8.80 = m - 8.80=m−8.8, then adding 8.8 to both sides yields m=8.8m = 8.8m=8.8. So both methods are mathematically valid if fully executed. Option A gives the wrong second solution. This is a conceptual comparison question.

Q7. Given the equation x3−5=2\frac{x}{3} - 5 = 23x​−5=2. A student performs the following steps: Step 1: x3=7\frac{x}{3} = 73x​=7 (added 5). Step 2: x=21x = 21x=21 (multiplied by 3). Which property is used in Step 1, and is the step correct?

A.Addition Property; correct because 5 was added to both sides. ✅
B.Subtraction Property; correct because 5 was subtracted from both sides.
C.Addition Property; incorrect because they should have added 2, not 5.
D.Division Property; correct because they divided both sides by 3.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Step 1: The equation is x3−5=2\frac{x}{3} - 5 = 23x​−5=2. To isolate the fraction, we add 5 to both sides: x3=7\frac{x}{3} = 73x​=7. This is the Addition Property of Equality. The step is correct. Option B is wrong because it's addition, not subtraction. Option C misunderstands which constant to target. This is a direct recall of the property's application in a multi-step context.

Q8. The equation 2x+7=132x + 7 = 132x+7=13 is solved by a student who first adds −7-7−7 to both sides, getting 2x=62x = 62x=6, then divides by 2 to get x=3x = 3x=3. A second student first divides both sides by 2, getting x+3.5=6.5x + 3.5 = 6.5x+3.5=6.5, then subtracts 3.5 to get x=3x = 3x=3. Which statement about these methods is correct?

A.Both are valid, as they both maintain equality using the Addition Property at different stages. ✅
B.Only the first is correct because you must isolate the variable term before dividing.
C.Only the second is correct because you must simplify fractions before using the Addition Property.
D.Both are invalid because the Addition Property cannot be used when there is a coefficient on xxx.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: This question tests the understanding that the Addition Property can be applied in any valid order. The first student uses it first (adding -7), the second student uses it after dividing. Both paths are algebraically sound and lead to x=3x = 3x=3. Option A is correct. The other options represent common misconceptions about a fixed 'order of operations' for solving equations, which does not exist as long as equality is maintained.

Q9. The equation 4=2+t4 = 2 + t4=2+t is graphed as a horizontal line on a number line at 4, with a point at 2. How can the Addition Property be visualized on this graph to find ttt?

A.Moving the point from 2 to 4 requires adding 2, so t=2t = 2t=2. ✅
B.Moving the point from 4 to 2 requires subtracting 2, so t=−2t = -2t=−2.
C.The distance between 2 and 4 is 2, but the solution is t=−2t = -2t=−2 because the equation is t=2−4t = 2 - 4t=2−4.
D.The graph shows t=2t = 2t=2 because you add 2 to both sides.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: On a number line, the equation 4=2+t4 = 2 + t4=2+t means that starting at 2, moving ttt units lands at 4. The distance and direction are +2, so t=2t = 2t=2. Algebraically, subtract 2 from both sides: 4−2=t4 - 2 = t4−2=t, so t=2t = 2t=2. Option B incorrectly interprets the direction. Option C mistakes the sign. This graph-based question requires visualizing the property as a translation on the number line.

Q10. A student solves 5=c−85 = c - 85=c−8 by adding 8 to both sides, getting 13=c13 = c13=c. They check by substituting c=13c = 13c=13: 13−8=513 - 8 = 513−8=5, which works. Now they are given −5=c−8-5 = c - 8−5=c−8. They reason that because it's '-5' instead of '5', the solution must be negative. They add 8 and get 3=c3 = c3=c. Is this correct?

A.Yes, because adding 8 to both sides is the correct operation, and c=3c = 3c=3 satisfies −5=3−8-5 = 3 - 8−5=3−8. ✅
B.No, they should have subtracted 8 because the number is negative.
C.Yes, but only because the equation is symmetric; the solution is c=−13c = -13c=−13.
D.No, they should have added -8, giving c=−13c = -13c=−13.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: The student correctly applies the Addition Property: add 8 to both sides of −5=c−8-5 = c - 8−5=c−8 to get −5+8=c-5 + 8 = c−5+8=c, which simplifies to 3=c3 = c3=c. Checking: 3−8=−53 - 8 = -53−8=−5, which is true. The student's reasoning about 'negative' is a misconception, but their operation was correct. Option D is a common error of adding a negative instead of the positive inverse of -8.

Q11. The equation a−2.3=−1.7a - 2.3 = -1.7a−2.3=−1.7 is solved by a student. They write the solution as a=−4.0a = -4.0a=−4.0. Which of the following best describes the error?

A.The student subtracted 2.3 instead of adding it; correct is a=0.6a = 0.6a=0.6. ✅
B.The student added 2.3 but incorrectly combined signs; correct is a=0.6a = 0.6a=0.6.
C.The student correctly added 2.3 but made a decimal alignment error; correct is a=−4.0a = -4.0a=−4.0.
D.The student should have added 1.7 to both sides, not 2.3; correct is a=−4.0a = -4.0a=−4.0.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The equation is a−2.3=−1.7a - 2.3 = -1.7a−2.3=−1.7. To isolate aaa, you must add 2.3 to both sides: a=−1.7+2.3=0.6a = -1.7 + 2.3 = 0.6a=−1.7+2.3=0.6. The student's answer −4.0-4.0−4.0 indicates they subtracted 2.3 (−1.7−2.3=−4.0-1.7 - 2.3 = -4.0−1.7−2.3=−4.0), which is a classic error of using the wrong inverse operation. Option B describes correct operation but wrong sign handling, which is also possible but less likely given the exact value -4.0.

Q12. In the equation x+p=qx + p = qx+p=q, if ppp and qqq are both negative integers, which of the following statements about the solution xxx is always true?

A.xxx is positive if qqq is less than ppp.
B.xxx is always negative.
C.xxx is always positive.
D.xxx is zero if p=qp = qp=q. ✅
💡 Difficulty: hard | ✅ Correct: D

📖 Explanation: Given x+p=qx + p = qx+p=q, solving gives x=q−px = q - px=q−p. If ppp and qqq are negative, the sign of xxx depends on their relative values. For example, p=−3,q=−5p = -3, q = -5p=−3,q=−5 gives x=−2x = -2x=−2 (negative), but p=−5,q=−3p = -5, q = -3p=−5,q=−3 gives x=2x = 2x=2 (positive). However, if p=qp = qp=q, then x=0x = 0x=0 regardless of their values. Option D is always true. This is an abstract reasoning question that tests the conceptual understanding of the property without numeric values.

Q13. Consider the two equations: (I) 2x−5=112x - 5 = 112x−5=11 and (II) 2x=162x = 162x=16. A student claims that equation (II) is obtained by using the Addition Property on equation (I). Another student claims you must also divide by 2. Who is correct, and why?

A.The first student is correct; adding 5 to both sides of (I) gives (II).
B.The second student is correct; the Addition Property only applies to adding zero.
C.Both are correct because the Addition Property is used to get (II), then division is used to solve. ✅
D.Neither is correct because (II) is not equivalent to (I).
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: Equation (I): 2x−5=112x - 5 = 112x−5=11. Adding 5 to both sides (Addition Property) yields 2x−5+5=11+52x - 5 + 5 = 11 + 52x−5+5=11+5, simplifying to 2x=162x = 162x=16, which is equation (II). So the first student is correct about the transformation. The second student is correct that to solve for xxx, you must then divide by 2, but that's a different property. Option C captures that both statements are true in context. This question tests the distinction between transformation and solution steps.
