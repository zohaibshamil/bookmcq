📝 Translate sentences to equations and solve

📖 From Digital SAT Algebra • 2. Linear Equations And Inequalities • 13 questions available

What is Translate sentences to equations and solve?

Definition:
Translating sentences to equations and solving involves converting verbal statements into algebraic equations, then using algebraic techniques to find the unknown value. This combines translation skills with equation-solving methods to produce a numeric answer from a worded problem.

Working:
First, assign a variable to the unknown, then translate keywords into operations. Write the equation, simplify if needed, and solve using addition, subtraction, multiplication, or division properties. Finally, interpret the result in words. For example, 'A number decreased by 8 is 15' translates to \(x - 8 = 15\), then solve \(x = 23\).

Example:
Translate 'The product of 6 and a number is 54' to an equation. Let the number be \(n\). 'Product of 6 and a number' is \(6n\), so \(6n = 54\). Divide by 6: \(n = 9\). The number is 9.

Reason:
This process enables solving word problems by converting them into a form that can be manipulated mathematically, making it a practical skill for real-life applications.

Q1. A student translates "Twice a number, decreased by 5, is 3 more than the number" as \(2x - 5 = x + 3\) and solves to get \(x=8\). However, they check and find \(2(8)-5 = 11\) and \(8+3=11\). Is their translation correct? If not, what is the correct equation and solution?

A. The translation is correct; \(x=8\) is the solution. ✅
B. The translation is incorrect; it should be \(2x - 5 = 3x + 3\), giving \(x=-8\).
C. The translation is incorrect; it should be \(2x - (5) = 3 - x\), giving \(x = 2.67\).
D. The translation is correct in structure but solving gave a mistake; actual solution is \(x=2\).

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The student's translation and solution are both correct. The phrase "decreased by 5" means subtract 5 from \(2x\), and "3 more than the number" means \(x+3\). Solving \(2x-5 = x+3\) gives \(x=8\), and checking confirms. This question tests the ability to verify a translation and identify that no error exists, a key HOTS skill in error analysis.

Q2. The perimeter of a rectangle is 60 cm. The length is 4 cm more than twice the width. A student writes \(2(w + 2w+4) = 60\) and solves \(w = 9.33\). Another writes \(2(w) + 2(2w+4) = 60\) and gets \(w = 8.67\). Which equation is correct and what is the actual width?

A. Student 1: \(w=9.33\) is correct.
B. Student 2: \(w=8.67\) is correct. ✅
C. Both are algebraically equivalent and give \(w=9.33\).
D. Neither; the correct equation is \(w + (2w+4) = 60\), giving \(w=18.67\).

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The correct perimeter formula is \(2w + 2l = 60\) with \(l = 2w+4\), so \(2w + 2(2w+4)=60\) simplifies to \(6w+8=60\) → \(w=8.67\). Student 1 used \(2(w + 2w+4)\) which simplifies to \(6w+8\) as well, actually both give the same \(w=8.67\) if solved correctly. Wait, Student 1's equation \(2(w+2w+4)=60\) → \(2(3w+4)=60\) → \(6w+8=60\) → \(w=8.67\). So both are correct and equivalent. But option B says Student 2 gives 8.67, which is correct. However, Student 1 also gives 8.67 if solved correctly, but the option says 9.33 which is a solving error. So correct is B.

Q3. The sum of three consecutive odd integers is 57. If the smallest is \(n\), which equation correctly models this and what is the largest integer?

A. \(n + (n+1) + (n+2) = 57\); largest = 20
B. \(n + (n+2) + (n+4) = 57\); largest = 21 ✅
C. \(n + (n+2) + (n+4) = 57\); largest = 23
D. \(n + (n+1) + (n+3) = 57\); largest = 21

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Consecutive odd integers differ by 2, so if the smallest is \(n\), the next two are \(n+2\) and \(n+4\). The equation \(n + (n+2) + (n+4) = 57\) gives \(3n+6=57\) → \(n=17\), so the integers are 17, 19, 21; largest is 21. Option A uses consecutive integers, not odd, a common misconception.

Q4. A car rental company charges a flat fee of $30 plus $0.20 per mile. Another company charges $50 flat with $0.10 per mile. For what mileage is the cost the same? A student sets \(30 + 0.20m = 50 + 0.10m\) and solves \(m=200\). A second student sets \(30m + 0.20 = 50m + 0.10\) and gets \(m=0.005\). Which student is correct and what does the solution represent?

A. First student: \(m=200\) miles is correct. ✅
B. Second student: \(m=0.005\) miles is correct.
C. Neither; the correct equation is \(30 + 0.20 = 50 + 0.10\) so no solution.
D. Both are correct because they are equivalent.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The flat fee is a one-time charge, not per mile, so the variable \(m\) must multiply the per-mile rate only. First student's equation is correct: \(30 + 0.20m = 50 + 0.10m\) → \(0.10m = 20\) → \(m=200\). Second student incorrectly multiplied the flat fee by \(m\), a classic misconception. At 200 miles, both cost $70.

Q5. The graph of \(y = 2x + 3\) and \(y = -x + 9\) intersect at point P. Write an equation to find the x-coordinate of P. If a student says the equation is \(2x+3 = -x+9\) and solves \(x=2\), what is the y-coordinate and what does the intersection represent?

A. \(y=7\); intersection is where the two lines have the same x and y values. ✅
B. \(y=5\); intersection is the solution to the system.
C. \(y=9\); intersection is the y-intercept of the second line.
D. \(y=3\); intersection is where both slopes are equal.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

Setting the two equations equal gives the x-coordinate of intersection: \(2x+3 = -x+9\) → \(3x=6\) → \(x=2\). Substituting into either gives \(y=2(2)+3=7\). The intersection point (2,7) is the solution to the system, meaning both equations are satisfied. This connects algebraic solving to graphical interpretation, a key HOTS skill.

Q6. A number is such that if you add 4 to three times the number, you get the same as subtracting the number from 20. A student translates as \(3x + 4 = 20 - x\) and solves \(x=4\). Another student translates as \(3x + 4 = x - 20\) and solves \(x=-12\). Which translation is correct and why?

A. First is correct because "subtracting the number from 20" means \(20 - x\). ✅
B. Second is correct because "subtracting the number from 20" means \(x - 20\).
C. Both are correct because subtraction is commutative.
D. Neither; the correct equation is \(3x + 4 = 20 + x\).

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The phrase "subtracting the number from 20" translates to \(20 - x\), not \(x - 20\). The order matters in subtraction. First student's equation \(3x+4 = 20-x\) is correct; solving gives \(4x = 16\) → \(x=4\). Second student reversed the order, a common error. This tests understanding of operational order in verbal phrases.

Q7. The length of a rectangle is 5 cm more than its width. If the perimeter is 38 cm, a student writes \(w + (w+5) = 38\) and solves \(w=16.5\), giving length 21.5. Another student writes \(2w + 2(w+5) = 38\) and solves \(w=7\), giving length 12. Which solution is correct and what is the area?

A. First student: width 16.5, length 21.5, area 354.75 cm²
B. Second student: width 7, length 12, area 84 cm² ✅
C. First student is correct but area is 354.75; second student forgot to multiply by 2.
D. Second student is correct but area should be 84; first used wrong perimeter formula.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Perimeter formula is \(2w + 2l = 38\). With \(l = w+5\), we get \(2w + 2(w+5) = 38\) → \(4w+10=38\) → \(w=7\), \(l=12\), area \(= 84\). First student used \(w + l = 38\) which is half the perimeter, a common mistake. This question tests the ability to distinguish between perimeter and semi-perimeter and to compute area from correct dimensions.

Q8. A student solves the equation from "five less than twice a number is 15" as \(2x - 5 = 15\) and gets \(x=10\). A peer says the equation should be \(5 - 2x = 15\), giving \(x=-5\). Who is correct and what is the number?

A. First student: \(x=10\) is correct. ✅
B. Second student: \(x=-5\) is correct.
C. Both are correct because \(2x-5\) and \(5-2x\) are equivalent.
D. Neither; the equation should be \(2x + 5 = 15\), giving \(x=5\).

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

'Five less than twice a number' means start with \(2x\) and subtract 5, i.e., \(2x - 5\). The equation \(2x-5=15\) gives \(2x=20\) → \(x=10\). The peer's equation \(5-2x=15\) represents 'twice a number less than 5', which is a different phrase. This tests the ability to correctly translate subtraction order in verbal expressions, a frequent source of errors.

Q9. The sum of a number and its reciprocal is \( \frac{5}{2} \). Write an equation and solve. A student writes \(x + \frac{1}{x} = \frac{5}{2}\) and multiplies by \(2x\) to get \(2x^2 - 5x + 2 = 0\), giving \(x=2\) or \(x=\frac{1}{2}\). A second student writes \(x + \frac{1}{x} = \frac{5}{2}\) and multiplies by \(x\) to get \(x^2 + 1 = \frac{5}{2}x\), then solves to get \(x=2\) only. Which solution is fully correct?

A. First student: \(x=2\) and \(x=\frac{1}{2}\) are both solutions. ✅
B. Second student: only \(x=2\) is correct because reciprocal of \(1/2\) is 2, sum is 2.5.
C. Both are correct because they are the same solutions.
D. Neither; the equation should be \(x + x = \frac{5}{2}\) giving \(x=1.25\).

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The equation \(x + 1/x = 5/2\) is correct. Multiplying by \(2x\) gives \(2x^2 + 2 = 5x\) → \(2x^2 -5x +2=0\) → factors to \((2x-1)(x-2)=0\) → \(x=1/2\) or \(x=2\). Both are valid because the reciprocal of \(1/2\) is 2, and sum is \(0.5+2=2.5\). Second student missed the \(1/2\) solution due to not clearing the fraction completely or dividing incorrectly. This is an Olympiad-style problem testing algebraic manipulation and checking for extraneous roots.

Q10. The equation \(3(x-4) = 2(x+1)\) is solved by two students. Student A expands to \(3x-12 = 2x+2\) and gets \(x=14\). Student B divides both sides by \(x-4\) to get \(3 = \frac{2(x+1)}{x-4}\) and then solves to get \(x=14\). Which method is valid and why?

A. Both methods are valid because they give the same answer.
B. Only Student A is valid; Student B's division by \(x-4\) is risky if \(x=4\) but here it's fine. ✅
C. Only Student A is valid; Student B's method is invalid because you cannot divide by a variable expression.
D. Both methods are invalid because the equation has no solution.

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Student A's expansion is straightforward and valid. Student B divides by \(x-4\), which is allowed only if \(x eq 4\). Since \(x=4\) does not satisfy the original equation (3(0)=2(5) → 0=10 false), division is safe and the method works. However, it's a riskier approach and can lead to loss of solutions if the expression could be zero. This question tests understanding of the validity of algebraic operations and when division by a variable is permissible.

Q11. A line graph shows two lines: one passes through (0,2) and (2,6), the other through (0,8) and (4,4). Write equations for both and find the x-value where they intersect. If a student says the equations are \(y=2x+2\) and \(y=-x+8\), and solves \(2x+2 = -x+8\) to get \(x=2\), is the intersection point (2,6)?

A. Yes, (2,6) is the intersection and satisfies both equations. ✅
B. No, the intersection is (2,4) because second line has slope -1.
C. No, the intersection is (1,5) because solving gives \(x=1\).
D. Yes, but the intersection is (2,8) because first line has y-intercept 2.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

First line slope = (6-2)/(2-0) = 4/2=2, so \(y=2x+2\). Second line slope = (4-8)/(4-0) = -4/4=-1, so \(y=-x+8\). Setting equal: \(2x+2 = -x+8\) → \(3x=6\) → \(x=2\), then \(y=2(2)+2=6\). (2,6) satisfies both: first gives 6, second gives -2+8=6. So the student is correct. This tests the ability to derive equations from a graph and solve the system, connecting graphical and algebraic representations.

Q12. A number is divided by 3 and then 2 is added, giving 10. A student writes \(\frac{x}{3} + 2 = 10\) and solves \(x=24\). Another writes \(\frac{x+2}{3} = 10\) and solves \(x=28\). Which translation is correct and what is the number?

A. First: \(x=24\) is correct because order is division then addition. ✅
B. Second: \(x=28\) is correct because the whole number plus 2 is divided by 3.
C. Both are correct because they are equivalent.
D. Neither; the equation should be \(3x + 2 = 10\) giving \(x = 2.67\).

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The phrase "divided by 3 and then 2 is added" means division operation happens first, then addition: \(\frac{x}{3} + 2 = 10\). Solving gives \(\frac{x}{3}=8\) → \(x=24\). The second equation \(\frac{x+2}{3}=10\) represents "add 2 to the number, then divide by 3", which is a different order of operations. This tests the ability to correctly sequence operations from verbal descriptions, a key HOTS application.

Q13. A student claims that the equation \(4(x-2) = 2x + 6\) can be solved by first adding 2 to both sides to get \(4x = 2x + 8\), then solving \(x=4\). Is this valid? If not, what is the correct solution and what error was made?

A. Valid; \(x=4\) is correct.
B. Invalid; the error is adding 2 instead of distributing; correct solution \(x=7\). ✅
C. Invalid; the error is adding 2 to only one side; correct solution \(x=5\).
D. Invalid; the error is combining unlike terms; correct solution \(x=1\).

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

The student's step: \(4(x-2) = 2x+6\) → adding 2 to both sides gives \(4x = 2x+8\) is INCORRECT because \(4(x-2)\) is \(4x-8\), not \(4x-2\). To isolate, you must first distribute: \(4x-8 = 2x+6\) → \(2x = 14\) → \(x=7\). The error was treating \(4(x-2)\) as \(4x-2\), a common distributive property mistake. Correct solution is \(x=7\). This tests error analysis in multi-step equation solving.
