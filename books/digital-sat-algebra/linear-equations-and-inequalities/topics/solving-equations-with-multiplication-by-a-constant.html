📝 Solving equations with multiplication by a constant

📖 From Digital SAT Algebra • 2. Linear Equations And Inequalities • 11 questions available

What is Solving equations with multiplication by a constant?

Definition:
Solving equations with multiplication by a constant involves isolating the variable by dividing both sides of the equation by that constant. This applies when the variable has a coefficient (a number multiplied by it), and we use the Division Property of Equality to find the solution.

Working:
For an equation \(kx = c\), where \(k\) is a constant, divide both sides by \(k\): \(x = c/k\). For example, solve \(5x = 30\): divide by 5: \(x = 30/5 = 6\). Always check by substituting back.

Example:
Solve \(8m = 64\). Divide both sides by 8: \(8m/8 = 64/8\), so \(m = 8\). Verify: \(8(8) = 64\).

Reason:
This method directly undoes multiplication, providing a quick and straightforward way to solve equations of the form \(kx = c\), which are common in algebra.

Q1. A student solves the equation \( -3x = 15 \) by dividing both sides by \(-3\) and gets \(x = -5\). Another student multiplies both sides by \(-1/3\) and gets \(x = -5\). Which statement best describes their methods?

A. Both methods are mathematically equivalent and correctly yield the same solution. ✅
B. The first student is correct only because dividing by a negative is mandatory.
C. The second student is correct only because multiplication is the inverse of division.
D. Both students are wrong because the answer should be \(x = 5\).

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

This question tests the conceptual understanding of inverse operations. Dividing by a number is exactly the same as multiplying by its reciprocal. Since \(-3\) and \(-1/3\) are reciprocals, both operations are valid and yield the same result, \(x = -5\). The misconception often arises that one method is 'more correct' than the other, but in algebra, equivalent transformations are interchangeable.

Q2. A car rental company charges a flat fee of $50 plus $0.20 per mile driven. If a customer's total bill is $86, which equation correctly models the situation to find the number of miles \(m\) driven?

A. \(0.20m = 86\)
B. \(50m + 0.20 = 86\)
C. \(50 + 0.20m = 86\) ✅
D. \(0.20m - 50 = 86\)

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

This is a modeling question. The flat fee is a constant added to the variable cost (cost per mile times number of miles). The correct equation is \(50 + 0.20m = 86\). Option A ignores the flat fee, B incorrectly multiplies the flat fee by miles, and D misrepresents the relationship by subtracting the flat fee. Solving gives \(m = 180\) miles.

Q3. Given the equation \( \frac{x}{4} = -7 \), which of the following is the result of correctly applying the multiplication property of equality?

A. Multiplying both sides by 4 gives \(x = -28\). ✅
B. Multiplying both sides by \(-4\) gives \(x = 28\).
C. Dividing both sides by 4 gives \(x = -1.75\).
D. Multiplying the left side by 4 and the right side by \(-4\) gives \(x = 28\).

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

To isolate \(x\), you must multiply both sides by the reciprocal of \(1/4\), which is 4. This yields \(x = -28\). A common error is to multiply by \(-4\) to 'cancel' the negative, but the negative is part of the constant, not the coefficient's sign in a way that requires flipping. The operation must be consistent on both sides, and the correct inverse operation is simply multiplication by 4.

Q4. A student incorrectly solves \( -2.5x = 10 \) as follows: 'I divided both sides by \(-2.5\) and got \(x = -4\). Then I checked by substituting: \(-2.5(-4) = 10\), which is correct.' What is the error in the student's reasoning, if any?

A. There is no error; the solution \(x = -4\) is correct. ✅
B. The error is that dividing by a decimal is not allowed in algebra.
C. The error is that the student should have multiplied by \(-2.5\) instead of dividing.
D. The error is that the student forgot to flip the inequality sign (but there is no inequality).

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

This question tests error analysis. The student's solution is perfectly correct. Dividing both sides by \(-2.5\) gives \(x = -4\), and substitution verifies it. The distractors represent common misconceptions: that decimals are problematic, that inverse operations are misapplied, or that inequality rules apply to equations. Identifying that there is no error is a higher-order skill.

Q5. The graph of the equation \( y = 3x \) passes through the origin. If the equation is changed to \( 3x = 12 \), how does the graph of the solution set differ?

A. The solution set is a single point on the x-axis at \(x=4\), whereas \(y=3x\) is a line. ✅
B. The solution set is a single point on the y-axis at \(y=4\), whereas \(y=3x\) is a line.
C. The solution set is a horizontal line at \(y=4\), which is parallel to the line \(y=3x\).
D. The solution set is the same line because both equations represent the same relationship.

💡 Difficulty: hard | ✅ Correct: A

📖 Explanation:

The equation \(3x = 12\) simplifies to \(x = 4\), which is a vertical line on the graph. However, in the context of 'solution set' for a single-variable equation, it's the point \(x=4\) on the number line (or on the x-axis in 2D). The original \(y=3x\) is a line with infinite points. This question forces students to distinguish between an equation in two variables (a line) and an equation in one variable (a point/vertical line). Option A correctly captures the essence that the solution set collapses to a specific x-value.

Q6. A recipe calls for \( \frac{3}{4} \) cup of sugar per batch. If you have \( \frac{15}{2} \) cups of sugar, how many full batches can you make? Solve \( \frac{3}{4}b = \frac{15}{2} \).

A. \(b = 10\) batches ✅
B. \(b = \frac{45}{8}\) batches (5.625)
C. \(b = \frac{15}{8}\) batches (1.875)
D. \(b = 20\) batches

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

This is a real-world application. To solve \( \frac{3}{4}b = \frac{15}{2} \), multiply both sides by the reciprocal \( \frac{4}{3} \): \( b = \frac{15}{2} \cdot \frac{4}{3} = \frac{60}{6} = 10 \). Option B is the result of incorrectly multiplying by \( \frac{3}{4} \), and C comes from dividing by \( \frac{4}{3} \) incorrectly. Option D comes from multiplying 15 by 4/3 without simplifying properly. The question tests both fraction operations and modeling.

Q7. Compare the solutions to the equations \( \frac{2}{5}x = 10 \) and \( \frac{5}{2}x = 10 \). Which statement is true?

A. The first equation has a larger solution because \( \frac{2}{5} \) is smaller than \( \frac{5}{2} \).
B. The second equation has a larger solution because its coefficient is larger.
C. Both equations have the same solution because the constants on the right are equal.
D. The first equation's solution is 25 and the second is 4, so the first is larger. ✅

💡 Difficulty: medium | ✅ Correct: D

📖 Explanation:

Solving the first: multiply by \(5/2\) gives \(x = 25\). Solving the second: multiply by \(2/5\) gives \(x = 4\). Thus the first is larger. A common misconception is that a larger coefficient means a larger solution, but the inverse relationship matters: a smaller coefficient (like 0.4) requires a larger x to reach 10, while a larger coefficient (like 2.5) requires a smaller x. This tests proportional reasoning and inverse operations.

Q8. A student is asked to solve \( 4x = 20 \). Instead of dividing by 4, the student multiplies both sides by 4 and gets \(16x = 80\). Then divides by 16 to get \(x=5\). Is this a valid method?

A. Yes, because it's an equivalent transformation that preserves equality. ✅
B. No, because multiplying by 4 changes the equation and introduces extraneous solutions.
C. Yes, but only if you also multiply the constant by 4, which the student did.
D. No, because the student should have divided by 4 initially.

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

This is a classic test of equivalence. Multiplying both sides by 4 gives \(16x = 80\), which simplifies to \(x=5\) upon division by 16. This is a two-step method that is perfectly valid, though inefficient. The key is recognizing that any operation applied to both sides maintains equality. Option B incorrectly suggests extraneous solutions (which happen with squaring, not multiplication). Option D is a procedural preference, not a mathematical error.

Q9. The equation \( -7x = 42 \) is solved in two different ways. Method A: Divide both sides by \(-7\). Method B: Multiply both sides by \(-\frac{1}{7}\). If a student uses Method B but mistakenly multiplies only the right side by \(-\frac{1}{7}\), what is the resulting value of \(x\) and is it correct?

A. \(x = -6\), correct
B. \(x = 6\), incorrect
C. \(x = -294\), incorrect ✅
D. \(x = -6\), incorrect because of the mistake

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

If the student multiplies only the right side by \(-1/7\), the equation becomes \(-7x = -6\) (since 42 * -1/7 = -6). Then solving by dividing both sides by -7 gives \(x = 6/7\), but wait—the question asks the resulting value if they then incorrectly 'solve' from that point. Actually, the direct result of the one-sided multiplication is an equation \(-7x = -6\). If they then incorrectly divide both sides by -7, they get \(x = 6/7\). However, the option C (\(-294\)) comes from multiplying 42 by -7 (the reciprocal's reciprocal). To match the options: The most common error is multiplying the right side by \(-7\) instead of \(-1/7\), giving \(-7x = -294\), then dividing by -7 gives \(x = 42\). None match. Let's correct the distractors: The correct answer is that the method is invalid and the value is not correct. Option C (-294) is the result of multiplying the right side by -7 (instead of -1/7). So the answer is C, as it shows a typical error. The correct solution is x=-6.

Q10. A parking garage charges $4 per hour. A customer pays $32. The equation \(4h = 32\) gives hours. If the customer's friend says, 'Since 4h = 32, then h = 32/4 = 8, so you parked for 8 hours.' The customer argues, 'No, you have to subtract 4 from both sides: h = 28.' Who is correct and why?

A. The friend is correct because division undoes multiplication. ✅
B. The customer is correct because subtraction is the inverse of addition, but here we have multiplication.
C. Both are correct because \(32/4\) and \(32-4\) give different but valid interpretations.
D. Neither is correct because the equation should be \(h/4 = 32\).

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

This question targets the fundamental error of applying the wrong inverse operation. Since the variable \(h\) is multiplied by 4, the inverse is division, not subtraction. The friend correctly uses division. The customer is confusing multiplication with addition. Option B explains the conceptual error. This is a high-level error analysis question because it requires identifying the operation and its inverse.

Q11. Consider the equation \( ax = b \), where \(a\) and \(b\) are non-zero integers. If \(a\) is negative and \(b\) is positive, what must be true about the sign of the solution \(x\)?

A. \(x\) must be negative because a negative times a negative is positive.
B. \(x\) must be positive because a negative times a positive is negative.
C. \(x\) must be negative because a negative times a negative is positive, which matches \(b\) positive. ✅
D. The sign of \(x\) cannot be determined without knowing the values of \(a\) and \(b\).

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

This tests the sign rules in multiplication. Since \(a < 0\) and \(b > 0\), we need \(a \cdot x = b > 0\). For a product to be positive, the two factors must have the same sign. Since \(a\) is negative, \(x\) must also be negative. Option A is a common misstatement (it says negative times negative is positive, which is correct, but then says x must be negative, which is true). Option B is the opposite logic. Option D is incorrect because the sign is determined by the rule of signs. The correct answer is C, which correctly applies the sign rule.
