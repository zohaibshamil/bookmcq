What is Solving equations with multiplication by a constant?

Definition:
Solving equations with multiplication by a constant involves isolating the variable by dividing both sides of the equation by that constant. This applies when the variable has a coefficient (a number multiplied by it), and we use the Division Property of Equality to find the solution.

Working:
For an equation kx=ckx = ckx=c, where kkk is a constant, divide both sides by kkk: x=c/kx = c/kx=c/k. For example, solve 5x=305x = 305x=30: divide by 5: x=30/5=6x = 30/5 = 6x=30/5=6. Always check by substituting back.

Example:
Solve 8m=648m = 648m=64. Divide both sides by 8: 8m/8=64/88m/8 = 64/88m/8=64/8, so m=8m = 8m=8. Verify: 8(8)=648(8) = 648(8)=64.

Reason:
This method directly undoes multiplication, providing a quick and straightforward way to solve equations of the form kx=ckx = ckx=c, which are common in algebra.

Q1. A student solves the equation −3x=15 -3x = 15 −3x=15 by dividing both sides by −3-3−3 and gets x=−5x = -5x=−5. Another student multiplies both sides by −1/3-1/3−1/3 and gets x=−5x = -5x=−5. Which statement best describes their methods?

A.Both methods are mathematically equivalent and correctly yield the same solution. ✅
B.The first student is correct only because dividing by a negative is mandatory.
C.The second student is correct only because multiplication is the inverse of division.
D.Both students are wrong because the answer should be x=5x = 5x=5.
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: This question tests the conceptual understanding of inverse operations. Dividing by a number is exactly the same as multiplying by its reciprocal. Since −3-3−3 and −1/3-1/3−1/3 are reciprocals, both operations are valid and yield the same result, x=−5x = -5x=−5. The misconception often arises that one method is 'more correct' than the other, but in algebra, equivalent transformations are interchangeable.

A.0.20m=860.20m = 860.20m=86
B.50m+0.20=8650m + 0.20 = 8650m+0.20=86
C.50+0.20m=8650 + 0.20m = 8650+0.20m=86 ✅
D.0.20m−50=860.20m - 50 = 860.20m−50=86
💡 Difficulty: easy | ✅ Correct: C

📖 Explanation: This is a modeling question. The flat fee is a constant added to the variable cost (cost per mile times number of miles). The correct equation is 50+0.20m=8650 + 0.20m = 8650+0.20m=86. Option A ignores the flat fee, B incorrectly multiplies the flat fee by miles, and D misrepresents the relationship by subtracting the flat fee. Solving gives m=180m = 180m=180 miles.

C.The error is that the student should have multiplied by −2.5-2.5−2.5 instead of dividing.
D.The error is that the student forgot to flip the inequality sign (but there is no inequality).
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: This question tests error analysis. The student's solution is perfectly correct. Dividing both sides by −2.5-2.5−2.5 gives x=−4x = -4x=−4, and substitution verifies it. The distractors represent common misconceptions: that decimals are problematic, that inverse operations are misapplied, or that inequality rules apply to equations. Q5. The graph of the equation y=3x y = 3x y=3x passes through the origin. If the equation is changed to 3x=12 3x = 12 3x=12, how does the graph of the solution set differ?

A.The solution set is a single point on the x-axis at x=4x=4x=4, whereas y=3xy=3xy=3x is a line. ✅
B.The solution set is a single point on the y-axis at y=4y=4y=4, whereas y=3xy=3xy=3x is a line.
C.The solution set is a horizontal line at y=4y=4y=4, which is parallel to the line y=3xy=3xy=3x.
D.The solution set is the same line because both equations represent the same relationship.
💡 Difficulty: hard | ✅ Correct: A

📖 Explanation: The equation 3x=123x = 123x=12 simplifies to x=4x = 4x=4, which is a vertical line on the graph. However, in the context of 'solution set' for a single-variable equation, it's the point x=4x=4x=4 on the number line (or on the x-axis in 2D). The original y=3xy=3xy=3x is a line with infinite points. This question forces students to distinguish between an equation in two variables (a line) and an equation in one variable (a point/vertical line). Option A correctly captures the essence that the solution set collapses to a specific x-value.

Q7. Compare the solutions to the equations 25x=10 \frac{2}{5}x = 10 52​x=10 and 52x=10 \frac{5}{2}x = 10 25​x=10. Which statement is true?

A.The first equation has a larger solution because 25 \frac{2}{5} 52​ is smaller than 52 \frac{5}{2} 25​.
B.The second equation has a larger solution because its coefficient is larger.
C.Both equations have the same solution because the constants on the right are equal.
D.The first equation's solution is 25 and the second is 4, so the first is larger. ✅
💡 Difficulty: medium | ✅ Correct: D

📖 Explanation: Solving the first: multiply by 5/25/25/2 gives x=25x = 25x=25. Solving the second: multiply by 2/52/52/5 gives x=4x = 4x=4. Thus the first is larger. Q8. A student is asked to solve 4x=20 4x = 20 4x=20. Instead of dividing by 4, the student multiplies both sides by 4 and gets 16x=8016x = 8016x=80. Then divides by 16 to get x=5x=5x=5. Is this a valid method?

A.Yes, because it's an equivalent transformation that preserves equality. ✅
B.No, because multiplying by 4 changes the equation and introduces extraneous solutions.
C.Yes, but only if you also multiply the constant by 4, which the student did.
D.No, because the student should have divided by 4 initially.
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: This is a classic test of equivalence. Multiplying both sides by 4 gives 16x=8016x = 8016x=80, which simplifies to x=5x=5x=5 upon division by 16. This is a two-step method that is perfectly valid, though inefficient. The key is recognizing that any operation applied to both sides maintains equality. Option B incorrectly suggests extraneous solutions (which happen with squaring, not multiplication). Option D is a procedural preference, not a mathematical error.

Q11. Consider the equation ax=b ax = b ax=b, where aaa and bbb are non-zero integers. If aaa is negative and bbb is positive, what must be true about the sign of the solution xxx?

A.xxx must be negative because a negative times a negative is positive.
B.xxx must be positive because a negative times a positive is negative.
C.xxx must be negative because a negative times a negative is positive, which matches bbb positive. ✅
D.The sign of xxx cannot be determined without knowing the values of aaa and bbb.
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: This tests the sign rules in multiplication. Since a &lt; 0 and b &gt; 0, we need a \cdot x = b &gt; 0. For a product to be positive, the two factors must have the same sign. Since aaa is negative, xxx must also be negative. Option A is a common misstatement (it says negative times negative is positive, which is correct, but then says x must be negative, which is true). Option B is the opposite logic. Option D is incorrect because the sign is determined by the rule of signs. The correct answer is C, which correctly applies the sign rule.
