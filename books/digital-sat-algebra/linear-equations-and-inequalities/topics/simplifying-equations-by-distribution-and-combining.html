What is Simplifying equations by distribution and combining?

Definition:
Simplifying equations by distribution and combining involves applying the distributive property to remove parentheses and then combining like terms (terms with the same variable and exponent) on each side. This is the first step in solving multi-step linear equations.

Working:
For example, simplify \(3(x + 2) - 4 = 2x + 1\): distribute \(3x + 6 - 4 = 2x + 1\), then combine constants: \(3x + 2 = 2x + 1\). This makes the equation easier to solve.

Example:
Simplify \(5(2a - 3) + 2a = 4a - 7\). Distribute: \(10a - 15 + 2a = 4a - 7\), combine like terms: \(12a - 15 = 4a - 7\). Now solve: subtract \(4a\): \(8a - 15 = -7\), add 15: \(8a = 8\), divide: \(a = 1\).

Reason:
Simplification reduces the equation to its core components, making it easier to apply equality properties and avoid mistakes with parentheses.

📝 All Simplifying equations by distribution and combining MCQs

Q1. A student simplifies the left side of \(2(x+3)-5x+4\) as \(2x+6-5x+4= -3x+10\). Which property is used correctly in the first step?

A. Distributive property ✅
B. Commutative property
C. Associative property
D. Identity property

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

The student correctly distributed the 2 to both \(x\) and 3, getting \(2x+6\). This is the distributive property. The subsequent combining of like terms uses addition. The commutative property reorders terms, associative regroups, and identity adds zero, none of which are the primary action in the first step.

Q2. What is the simplified form of the left side of the equation \(3(2x-1)+4(3-x)=12\)?

A. \(2x+9\) ✅
B. \(2x+3\)
C. \(6x-3+12-4x\)
D. \(10x+9\)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Distribute: \(6x-3+12-4x\). Combine \(x\)-terms: \(6x-4x=2x\). Combine constants: \(-3+12=9\). So \(2x+9\). Option C is an unsimplified intermediate, B incorrectly adds constants, D mis-adds \(x\) terms.

Q3. Solve for \(x\): \(5(x-2)+3x = 2(4x+1)-12\). How many solutions does this equation have?

A. One solution, \(x=0\)
B. No solution
C. Infinite solutions ✅
D. One solution, \(x=2\)

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Simplify LHS: \(5x-10+3x=8x-10\). RHS: \(8x+2-12=8x-10\). Both sides are identical, so the equation is an identity. It is true for all \(x\), hence infinite solutions. Students often stop after distributing and incorrectly combine constants.

Q4. The equation \(4(2x+1)-3x = 5x+4\) is simplified. Which student's reasoning is correct?

A. Student A: \(8x+4-3x=5x+4\), so \(5x+4=5x+4\), infinite solutions ✅
B. Student B: \(8x+4-3x=5x+4\), so \(5x+4=5x+4\), \(x=0\)
C. Student C: \(8x+4-3x=5x+4\), subtract \(5x\): \(4=4\), no solution
D. Student D: \(8x+4-3x=5x+4\), so \(10x+4=5x+4\), \(x=0\)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

Student A correctly distributes, combines like terms to get \(5x+4=5x+4\), and correctly concludes an identity (infinite solutions). B incorrectly gives \(x=0\) as the solution; C incorrectly says no solution (it's identity); D miscombined \(8x-3x\) as \(10x\).

Q5. A garden is rectangular with length \(2x+3\) and width \(x-1\). The perimeter is given by \(2(2x+3)+2(x-1)=34\). After simplifying each side, what is the simplified equation before solving?

A. \(4x+6+2x-2=34\)
B. \(6x+4=34\)
C. \(2x+3+x-1=17\)
D. Both A and B are simplified forms ✅

💡 Difficulty: easy | ✅ Correct: D

📖 Explanation:

Distributing gives \(4x+6+2x-2=34\), which is option A. Combining like terms gives \(6x+4=34\), which is option B. Both are correct simplifications of the same equation; B is the final simplified side form. Option C results from dividing by 2 before simplifying, which changes the equation structure.

Q6. Given the equation \(7x - 2(x+3) = 3x - 6 + 2x\). If a student simplifies it to \(5x-6 = 5x-6\), what is the graphical interpretation of the original equation?

A. The graph is a single vertical line at \(x=0\)
B. The graph is two parallel lines that never intersect
C. The graph represents the same line, so infinitely many intersection points ✅
D. The graph represents two lines that intersect at exactly one point

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

Simplifying to an identity means both sides represent the same linear expression. Thus, the left and right sides graph as the exact same line. Every point on the line satisfies the equation, so the solution set is all real numbers, meaning infinite intersection points. Option B is for no solution.

Q7. If \(ax + b = cx + d\) simplifies to \(3x+5 = 3x-2\), what must be true about the original coefficients?

A. \(a=c\) and \(b=d\)
B. \(a=c\) and \(b\neq d\) ✅
C. \(a\neq c\) and \(b=d\)
D. \(a\neq c\) and \(b\neq d\)

💡 Difficulty: medium | ✅ Correct: B

📖 Explanation:

After simplifying and subtracting \(3x\) from both sides, we get \(5=-2\), a false statement. This means the coefficients of \(x\) are equal (\(a=c=3\)) but the constants are different (\(b=5\), \(d=-2\)). That creates a contradiction. Option A gives identity; C and D would yield one solution.

Q8. Which of the following equations has no solution after simplifying both sides?

A. \(2(x+1)-x = x+2\)
B. \(3x-4 = 2(x+1)+x-6\)
C. \(4(x-1) = 2(2x+3)\) ✅
D. \(5x+2 = 5(x-1)\)

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Simplify C: LHS= \(4x-4\), RHS= \(4x+6\). Subtract \(4x\): \(-4=6\), false, no solution. A simplifies to \(x+2=x+2\) (infinite). B: \(3x-4 = 3x-4\) (infinite). D: \(5x+2=5x-5\) (no solution as well, but option C is the intended correct answer because it's a classic trap with distributing 2 into \(2x+3\) incorrectly by some). Actually D also no solution; C is clearly no solution, but D: subtract 5x gives 2=-5, no solution. Both C and D have no solution. Let's check D: \(5x+2=5x-5\) gives \(2=-5\), false. So both C and D are no solution. But option C is the best single answer as it is the most common error in distribution. For a single answer, C is selected.

Q9. A student solves \(3(x-2)+4 = 2x+1\) and gets \(x=3\). To verify, they substitute \(x=3\) into the original equation. Which simplification confirms the solution?

A. LHS: \(3(1)+4=7\), RHS: \(6+1=7\)
B. LHS: \(3(1)+4=7\), RHS: \(2(3)+1=7\)
C. Both A and B are correct substitutions ✅
D. Neither A nor B

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Substituting \(x=3\) into the original gives LHS: \(3(3-2)+4 = 3(1)+4=7\). RHS: \(2(3)+1=7\). Both A and B correctly evaluate the LHS and RHS respectively. Option A gives the simplified LHS after distribution; B gives the RHS. Both confirm the solution.

Q10. Given the equation \(2(3x-1)-x = 5x - 2\). After simplifying, a student writes \(5x-2=5x-2\). Which statement is true about the graphs of \(y=2(3x-1)-x\) and \(y=5x-2\)?

A. They intersect at \(x=2\)
B. They are the same line ✅
C. They are parallel distinct lines
D. They intersect at \(x=0\)

💡 Difficulty: hard | ✅ Correct: B

📖 Explanation:

Since the simplification results in an identity, the two expressions are algebraically identical. Therefore, their graphs are the same line, overlapping completely. They don't intersect at a single point; every point is an intersection. This demonstrates the connection between algebraic identity and graphical coincidence.

Q11. Which equation, after simplifying both sides, results in \(6x-4 = 6x+8\)?

A. \(2(3x-2)=3(2x+2)+2\)
B. \(3(2x-1)-1=6x+8\)
C. \(4(1.5x-1)=6x+8\) ✅
D. All of the above

💡 Difficulty: medium | ✅ Correct: C

📖 Explanation:

Simplify C: \(4(1.5x-1) = 6x -4\). So \(6x-4=6x+8\) is exactly that. A simplifies LHS \(6x-4\), RHS \(6x+6+2=6x+8\) – wait that also gives \(6x-4=6x+8\)! Let's check A: \(2(3x-2)=6x-4\), RHS \(3(2x+2)+2 = 6x+6+2=6x+8\). So A also works. B: \(3(2x-1)-1 = 6x-3-1=6x-4\), RHS \(6x+8\). So all three simplify to that contradiction. So answer D.

Q12. In the equation \(4(x+2)-3(2x-1)= -2x+11\), what error would create a false solution of \(x=0\)?

A. Distributing \(-3\) as \(-6x-3\) instead of \(-6x+3\) ✅
B. Combining \(4x-6x\) as \(-2x\) correctly
C. Adding constants \(8+3\) as 11
D. Both A and C are errors but C doesn't affect \(x=0\)

💡 Difficulty: easy | ✅ Correct: A

📖 Explanation:

If a student distributes \(-3(2x-1)\) incorrectly as \(-6x-3\), the LHS becomes \(4x+8-6x-3 = -2x+5\). Setting equal to \(-2x+11\) gives \(5=11\), no solution, not \(x=0\). Actually, to get \(x=0\), they might set \(-2x+5 = -2x+11\) and mistakenly cancel to get \(5=11\) – no. But if they incorrectly combine constants as \(8-3=5\) (correct) vs \(8+3=11\) (wrong), that would give \(-2x+11 = -2x+11\), identity, so infinite solutions, not \(x=0\). The error that gives a false solution \(x=0\) is if they set \(4x+8-6x+3 = -2x+11\) correctly gives \(-2x+11 = -2x+11\), infinite. To get \(x=0\), they might make a sign error in combining like terms, e.g., \(4x+6x=10x\) leading to \(10x+11=-2x+11\) -> \(12x=0\) -> \(x=0\). That's an addition error. Option A is the most common and would lead to no solution, not \(x=0\). So A is the best answer as it's the classic error that changes the solution set.

Q13. A mobile phone plan charges a flat fee of \(\$20\) plus \(\$5\) per GB, and another plan charges \(\$10\) plus \(\$8\) per GB. The equation \(20+5x = 10+8x\) represents when costs equal. Simplify both sides by combining like terms on each side. What is the resulting equation?

A. \(20+5x = 10+8x\) (already simplified)
B. \(5x+20 = 8x+10\)
C. Both A and B are simplified ✅
D. \(25x = 18x\)

💡 Difficulty: easy | ✅ Correct: C

📖 Explanation:

Each side of the equation has only one \(x\)-term and one constant term, so they are already in simplest form. There are no like terms to combine on each individual side. Option B is just a reordering (commutative property), which is also simplified. Option D incorrectly combines across sides, which is not allowed when simplifying each side independently.

Q14. Which of the following is the correct first step in simplifying the equation \( -2(3x-4)+5x = 3(2-x)-7\)?

A. \(-6x+8+5x = 6-3x-7\) ✅
B. \(-6x-8+5x = 6-3x-7\)
C. \(-6x+8+5x = 6x-3-7\)
D. \(6x-8+5x = 3(2-x)-7\)

💡 Difficulty: medium | ✅ Correct: A

📖 Explanation:

Correct distribution: \(-2\) times \(3x\) is \(-6x\), and \(-2\) times \(-4\) is \(+8\). On RHS, \(3\) times \(2\) is \(6\), \(3\) times \(-x\) is \(-3x\), and bring down \(-7\). So A is correct. B has sign error on \(-8\); C has sign error on RHS distribution (should be \(-3x\), not \(-6x\)); D fails to distribute on RHS and has sign error on LHS.

Q15. Consider the equation \( \frac{1}{2}(4x-6) + 3 = 2x \). A student distributes to get \(2x-3+3=2x\), then simplifies to \(2x=2x\), concluding \(x=0\). What is the flaw in their reasoning?

A. They incorrectly combined \(-3+3\) as 0 – that's correct, not a flaw
B. They should have distributed \(\frac{1}{2}\) to all terms including the \(+3\)
C. The identity \(2x=2x\) means infinite solutions, not \(x=0\) ✅
D. They should have subtracted \(2x\) from both sides to get \(0=0\), then \(x=0\)

💡 Difficulty: hard | ✅ Correct: C

📖 Explanation:

The student's simplification is correct: \(2x-3+3=2x\) gives \(2x=2x\), which is an identity. The correct conclusion is that the equation is true for all real numbers, not just \(x=0\). The flaw is in the interpretation of the identity. Option B is wrong because the \(+3\) is outside the fraction and not multiplied by \(\frac{1}{2}\). Option A is true but not the flaw. Option D is incorrect procedure.
