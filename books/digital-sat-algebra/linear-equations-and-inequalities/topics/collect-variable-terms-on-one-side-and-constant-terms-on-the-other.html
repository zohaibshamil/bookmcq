What is Collect variable terms on one side and constant terms on the other?

Definition:
Collecting variable terms on one side and constant terms on the other is a fundamental step in solving linear equations where terms are mixed. It involves using addition or subtraction to move all terms containing the variable to one side and all number-only terms to the opposite side, setting up the equation in the form ax=bax = bax=b.

Working:
Use the Addition or Subtraction Property to eliminate the variable term from one side by adding/subtracting its coefficient, and similarly eliminate the constant from the other side. For example, solve 3x+7=2x−53x + 7 = 2x - 53x+7=2x−5: subtract 2x2x2x from both sides to collect variables on left: x+7=−5x + 7 = -5x+7=−5; then subtract 7 to collect constants on right: x=−12x = -12x=−12.

Example:
Solve 7p−4=3p+87p - 4 = 3p + 87p−4=3p+8. Subtract 3p3p3p: 4p−4=84p - 4 = 84p−4=8, add 4: 4p=124p = 124p=12, divide: p=3p = 3p=3. Variables on left, constants on right.

Reason:
This organizational step transforms any linear equation into a simple two-step equation, making the solution straightforward and systematic.

Q1. A student solves 5x+9=3x−75x + 9 = 3x - 75x+9=3x−7 and writes 5x+3x=−7−95x + 3x = -7 - 95x+3x=−7−9. Which error did the student make?

A.Added 3x3x3x to both sides instead of subtracting ✅
B.Subtracted 999 from both sides instead of adding
C.Moved 5x5x5x to the right side incorrectly
D.Multiplied both sides by 333 instead of adding
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The student incorrectly moved 3x3x3x to the left side. To collect variables on one side, we must subtract 3x3x3x from both sides, giving 5x−3x=−7−95x - 3x = -7 - 95x−3x=−7−9. Adding 3x3x3x changes the sign incorrectly and is a common misconception about 'moving' terms.

Q2. Which of the following represents the correct first step to solve 7x−12=4x+157x - 12 = 4x + 157x−12=4x+15 by collecting variable terms on the left?

A.Add 121212 to both sides
B.Subtract 4x4x4x from both sides ✅
C.Add 4x4x4x to both sides
D.Subtract 151515 from both sides
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: To collect variable terms on the left side, we need to eliminate 4x4x4x from the right. Subtracting 4x4x4x from both sides gives 3x−12=153x - 12 = 153x−12=15, which correctly places all xxx-terms on the left. This step is foundational for isolating the variable.

Q3. A taxi charges a flat fee of \4 plus \2.50 per mile. Another company charges \$1.50 per mile with no flat fee. If the total cost is the same, which equation correctly models the situation where mmm is miles?

A.4+2.50m=1.50m4 + 2.50m = 1.50m4+2.50m=1.50m ✅
B.4m+2.50=1.50m4m + 2.50 = 1.50m4m+2.50=1.50m
C.2.50m=4+1.50m2.50m = 4 + 1.50m2.50m=4+1.50m
D.4+2.50m=1.50+m4 + 2.50m = 1.50 + m4+2.50m=1.50+m
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The first company's cost is 4+2.50m4 + 2.50m4+2.50m, and the second is 1.50m1.50m1.50m. Setting them equal gives 4+2.50m=1.50m4 + 2.50m = 1.50m4+2.50m=1.50m. Solving requires collecting mmm-terms on one side (subtract 2.50m2.50m2.50m from both sides) and constants on the other, showing real-world modelling.

Q4. A student solves 8x−3=5x+98x - 3 = 5x + 98x−3=5x+9 and gets x=2x = 2x=2. Check the solution: is it correct? If not, where is the error?

A.Correct solution
B.Incorrect; error in subtracting 5x5x5x ✅
C.Incorrect; error in adding 333
D.Incorrect; error in both steps
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Substitute x=2x=2x=2: LHS = 16−3=1316-3=1316−3=13, RHS = 10+9=1910+9=1910+9=19. Not equal. Correct steps: 8x−5x=9+38x-5x=9+38x−5x=9+3 gives 3x=123x=123x=12, so x=4x=4x=4. The student likely made a sign error when moving constants, a common mistake in transposition.

Q5. The equation 3(x−4)=2(x+5)3(x-4) = 2(x+5)3(x−4)=2(x+5) is solved. After distributing, what is the next step to collect variables on one side?

A.Add 121212 to both sides
B.Subtract 2x2x2x from both sides ✅
C.Add 2x2x2x to both sides
D.Divide both sides by 333
💡 Difficulty: medium | ✅ Correct: B

📖 Explanation: After distribution: 3x−12=2x+103x - 12 = 2x + 103x−12=2x+10. To collect variables on one side, subtract 2x2x2x from both sides, giving x−12=10x - 12 = 10x−12=10. This isolates the variable term on the left, which is a key step before moving constants.

Q6. If 4x+7=3x−24x + 7 = 3x - 24x+7=3x−2, which of the following is the correct rearrangement to get variable terms on the left and constants on the right?

A.4x−3x=−2−74x - 3x = -2 - 74x−3x=−2−7 ✅
B.4x+3x=−2+74x + 3x = -2 + 74x+3x=−2+7
C.4x−3x=2−74x - 3x = 2 - 74x−3x=2−7
D.4x+3x=2+74x + 3x = 2 + 74x+3x=2+7
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: Subtract 3x3x3x from both sides to get 4x−3x=−2−74x - 3x = -2 - 74x−3x=−2−7. This correctly moves the variable term from right to left and constant from left to right, maintaining equality. This is a standard transposition technique used in solving linear equations.

Q7. A student claims that the equation 2x+5=2x−32x + 5 = 2x - 32x+5=2x−3 has no solution because the variable terms cancel. Is this reasoning valid?

A.Yes, because 2x2x2x cancels from both sides ✅
B.No, because the constants also cancel
C.Yes, because 555 and −3-3−3 are different
D.No, because xxx can be any value
💡 Difficulty: easy | ✅ Correct: A

📖 Explanation: The student's reasoning is valid. Subtracting 2x2x2x from both sides gives 5=−35 = -35=−3, a false statement, so no solution exists. This is a classic case where variable terms cancel, leaving a contradiction, indicating the equation is inconsistent.

📖 Explanation: The student correctly moves 3y3y3y to left (subtract) and 888 to right (subtract), giving 2y=−122y = -122y=−12, so y=−6y = -6y=−6. This demonstrates proper transposition: variable terms on left, constants on right, with sign changes correctly applied—a common HOTS application.

Q10. If 2(3x−1)=3(2x+1)2(3x - 1) = 3(2x + 1)2(3x−1)=3(2x+1), after distributing and collecting variable terms, what is the resulting equation?

A.0x=50x = 50x=5 ✅
B.6x−2=6x+36x - 2 = 6x + 36x−2=6x+3
C.0x=−50x = -50x=−5
D.x=5x = 5x=5
💡 Difficulty: medium | ✅ Correct: A

📖 Explanation: Distribute: 6x−2=6x+36x - 2 = 6x + 36x−2=6x+3. Subtract 6x6x6x from both sides: −2=3-2 = 3−2=3, or 0x=50x = 50x=5. This leads to no solution, as the variable cancels out. This question tests distribution, collection, and interpretation of a false statement—higher-order reasoning.

Q11. Which of the following equations has the solution x=4x = 4x=4 after collecting variable terms on one side?

A.2x+3=x+72x + 3 = x + 72x+3=x+7
B.3x−2=2x+23x - 2 = 2x + 23x−2=2x+2
C.Both A and B ✅
D.x+6=2x+2x + 6 = 2x + 2x+6=2x+2
💡 Difficulty: hard | ✅ Correct: C

📖 Explanation: A: 2x−x=7−32x - x = 7 - 32x−x=7−3 gives x=4x=4x=4. B: 3x−2x=2+23x - 2x = 2+23x−2x=2+2 gives x=4x=4x=4. C is correct. D: x−2x=2−6x - 2x = 2-6x−2x=2−6 gives −x=−4-x = -4−x=−4 so x=4x=4x=4 as well—wait, D also gives x=4x=4x=4! Actually D: x+6=2x+2x+6=2x+2x+6=2x+2 → x−2x=2−6x-2x=2-6x−2x=2−6 → −x=−4-x=-4−x=−4 → x=4x=4x=4. So all give x=4x=4x=4, making the question a trick to test careful collection and sign handling—true Olympiad-style reasoning.
