What is Solve inequalities using the Division Property of Inequality?

Definition:
The Division Property of Inequality states that dividing both sides of an inequality by a positive number preserves the inequality direction. However, if you divide by a negative number, you must reverse the inequality sign. For a<ba < ba<b and c>0c > 0c>0, a/c<b/ca/c < b/ca/c<b/c; if c<0c < 0c<0, a/c>b/ca/c > b/ca/c>b/c.

Working:
For 6x≤246x \leq 246x≤24, divide by positive 6: x≤4x \leq 4x≤4 (no reversal). For −4x>20-4x > 20−4x>20, divide by -4 and reverse: x<−5x < -5x<−5.

Example:
Solve 8y≥408y \geq 408y≥40. Divide by 8 (positive): y≥5y \geq 5y≥5.

Reason:
This property is crucial for isolating the variable when it has a coefficient, and the sign reversal rule is a key distinction from equations.

Q1. Solve -6x &gt; 42. Which solution set correctly describes all possible values of xxx?

A.x &gt; -7
B.x &lt; -7 ✅
C.x &gt; 7
D.x &lt; 7
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Dividing both sides by −6-6−6 requires reversing the inequality symbol because the divisor is negative. Thus x &gt; 42/(-6) would be incorrect; the correct result is x &lt; -7.

Q2. A student solves 15x≤9015x \leq 9015x≤90 by dividing both sides by 15. Which statement best explains why the inequality symbol does not change?

A.Any division keeps the symbol unchanged
B.The divisor is positive, so the order of the numbers is preserved ✅
C.The variable is on the left side
D.The constant on the right side is positive
💡 Difficulty: easy | ✅ Correct: B

📖 Explanation: Dividing an inequality by a positive number preserves the original order of the two sides. Therefore, dividing 15x≤9015x \leq 9015x≤90 by 15 gives x≤6x \leq 6x≤6 without reversing the inequality symbol.

Q3. A delivery company allows a package to weigh at most 48 kg. If each identical container weighs 6 kg, which inequality represents the maximum number nnn of containers that can be loaded?

A.n≥8n \geq 8n≥8
B.n &lt; 8
C.n≤8n \leq 8n≤8 ✅
D.n &gt; 8
💡 Difficulty: medium | ✅ Correct: C

📖 Explanation: The total weight is 6n6n6n, and the requirement is 6n≤486n \leq 486n≤48. Dividing both sides by the positive number 6 preserves the inequality, giving n≤8n \leq 8n≤8. Thus at most eight containers can be loaded.

Q7. Which inequality has the same solution set as -12y &gt; 36?

A.y &gt; -3

C.y &gt; 3

Q8. A teacher asks two students to solve -5x &lt; 25. Student A writes x &lt; -5, while Student B writes x &gt; -5. Which student is correct, and why?
